## 具体修改方案（逐条说明）

### 一、必须立即修改（6条）

#### 修改1：第九条第（三）款资金占用费（H-01）

**原条款**：
```
乙方逾期未退回的，应按全国银行间同业拆借中心公布的贷款市场报价利率（LPR）的2倍向甲方支付逾期退款部分的资金占用费直至退还之日止...
```

**修改后条款**：
```
乙方逾期未退回的，应按全国银行间同业拆借中心公布的贷款市场报价利率（LPR）的1.3倍向甲方支付逾期退款部分的资金占用费直至退还之日止，同时赔偿给甲方造成的其他任何损失，包括但不限于为开展调查核实违约行为而产生的调查核实工作人员差旅费、专家评估费、专项审计费等，以及为维权支出的律师费、诉讼费、财产保全费、鉴定评估费、差旅费、调查费和执行费等诉争费用。
```

**修改理由**：
1. LPR的2倍极大概率会被法院认定为过高（《民法典》第585条），主动调低为1.3倍反而对甲方更有利（法院不会调整）
2. 明确赔偿范围包括律师费、诉讼费等维权成本

---

#### 修改2：补充乙方授权代理人身份证号（M-01）

**原条款**：
```
授权代理人：周蓓蕾 
电话：17601334706 
地址：黔西南州册亨县巧马镇民族民间文化产业园A栋
```

**修改后条款**：
```
授权代理人：周蓓蕾 
身份证号：[需乙方提供]
电话：17601334706 
地址：黔西南州册亨县巧马镇民族民间文化产业园A栋
```

**或修改方案B（如乙方不愿提供身份证号）**：
```
在合同末尾增加"附件一：乙方授权委托书及授权代理人身份证复印件"
```

**修改理由**：
1. 身份证号空白会导致合同效力瑕疵、无法确认签署人身份、影响合同强制执行
2. 符合《民法典》第490条（合同生效要件）

---

#### 修改3：明确关联交易披露时限和内容标准（M-02）

**原条款**（第八条第（五）款第2项）：
```
如确需发生关联交易时，关联方提供的商品或服务的性价比相对于同期同类市场价格要有相对优势，且应当采取关联方回避的集体决策方式予以确定，并向社会公开关联交易信息。
```

**修改后条款**：
```
如确需发生关联交易时，关联方提供的商品或服务的性价比相对于同期同类市场价格要有相对优势，且应当采取关联方回避的集体决策方式予以确定，并在关联交易发生后15日内向社会公开关联交易信息，披露内容包括：交易标的、交易金额、定价依据、与乙方的关系说明。乙方未按时披露的，甲方有权暂停拨款直至披露完成。
```

**修改理由**：
1. 原条款未明确披露时限 → 乙方可能拖延披露
2. 原条款未明确披露内容标准 → 乙方可能披露不完整
3. 原条款未明确违反后果 → 乙方可能无视此义务
4. 增加"甲方有权暂停拨款"作为制约机制

---

#### 修改4：明确甲方解除权行使期限（M-03）

**原条款**（第六条第（六）款）：
```
合作募捐及项目执行期间出现以下任一情形时，甲方有权单方面解除本合作募捐协议及双方另行签署的《捐赠协议书》...
```

**修改后条款**：
```
合作募捐及项目执行期间出现以下任一情形时，甲方有权在发现情形后6个月内单方面解除本合作募捐协议及双方另行签署的《捐赠协议书》...
```

**修改理由**：
1. 原条款未明确甲方行使解除权的期限 → 可能导致解除权消灭（《民法典》第564条）
2. 明确"6个月内"行使解除权，符合司法实践

---

#### 修改5：明确"90日"起算点为"资金到账之日起"（M-04）

**原条款**（第二条）：
```
严禁将项目执行资金停留在机构账户超过计划90日不拨付给相关受益人或开展项目活动...
```

**修改后条款**：
```
乙方收到甲方拨付的慈善项目资金后，应在资金到账之日起90日内按照项目执行计划书的要求拨付给相关受益人或开展项目活动。乙方未在资金到账之日起90日内拨付的，甲方有权单方面解除协议，并有权收回已拨付的资金。
```

**修改理由**：
1. 原条款"计划90日"表述模糊（是指"项目计划书的90日"还是"资金到账后的90日"？）
2. 明确起算点为"资金到账之日起"，避免争议
3. 增加违反后果（甲方有权解除协议并收回资金）

---

#### 修改6：明确连带赔偿责任的追偿范围（M-05）

**原条款**（第九条第（四）款）：
```
乙方出现超范围、跨项目等违规使用资金，或挪用、借用、侵占项目资金，或将项目资金用于投资理财等严重违法违约行为，导致乙方无法追回、退回相应慈善款物、无能力赔偿甲方损失和承担相关费用的，乙方法定代表人、实际控制人和负有责任的其他相关人员，应当同时承担连带赔偿责任，甲方有权要求前述人员进行赔偿。
```

**修改后条款**：
```
乙方出现超范围、跨项目等违规使用资金，或挪用、借用、侵占项目资金，或将项目资金用于投资理财等严重违法违约行为，导致乙方无法追回、退回相应慈善款物、无能力赔偿甲方损失和承担相关费用的，乙方法定代表人、实际控制人和负有责任的其他相关人员（包括财务负责人、项目执行负责人、具体经办人员），应当同时承担连带赔偿责任，甲方有权要求前述人员进行赔偿，赔偿范围包括：挪用/侵占的资金本金、资金占用费、甲方为维权支出的律师费、诉讼费、财产保全费、审计费、差旅费等全部损失。
```

**修改理由**：
1. 原条款未明确"负有责任的其他相关人员"的具体范围 → 修改为明确列举（财务负责人、项目执行负责人、具体经办人员）
2. 原条款未明确连带赔偿责任的追偿范围 → 修改为明确包括律师费、诉讼费、审计费、差旅费等维权成本

### 二、建议修改（1条，压力测试后补充）

#### 修改7：增加"平台停止服务"的应对条款（M-06）

**新增条款**（建议插入在第二条之后，作为第三条）：

```
第三条 平台停止服务的处理方案
如因互联网募捐平台（腾讯公益）停止服务、下线、或被吊销公开募捐资格等不可抗力原因，导致本项目无法继续在平台开展募捐的，按以下方式处理：
（一）双方同意将本项目转至其他具有公开募捐资格的平台继续开展募捐；
（二）如无法转移至其他平台，双方协商终止本项目，并将已筹资金转至甲方管理的其他同类公益项目执行；
（三）如因平台停止服务导致已筹资金无法提取的，双方应共同与平台协商，寻求法律途径解决。
```

**修改理由**：
1. 原合同未约定"互联网平台停止服务"的处理方案 → 极端场景下合同无法履行
2. 增加此条款后，即使平台停止服务，也有明确的处理方案

---

### 三、可选优化（2条，红队攻击性条款设计）

#### 优化1：增加甲方资金监管权条款（O-01）

**新增条款**（建议插入在"第五条 甲方权利义务"中）：

```
（七）为确保项目资金使用安全，甲方有权：
1. 要求乙方开立项目资金专项监管账户，甲方有权查询该账户资金变动情况；
2. 要求乙方在单笔支出超过5000元前，提前10个工作日向甲方提交用款申请，经甲方书面同意后方可支出；
3. 不定期对乙方进行突击检查，乙方应配合并提供所有项目资金使用的原始凭证、账簿、合同等资料；
4. 如发现乙方存在违规使用资金的情形，甲方有权暂停拨付后续资金，直至乙方整改完成并经甲方验收合格。
```

**设计理由**：
1. 合法性：符合《慈善法》关于公募机构监督职责的规定
2. 攻击性：最大化甲方资金监管权，降低资金滥用风险
3. 可操作性：条款具体、明确、可执行
4. 隐蔽性：表面是"监督职责"，实则是"资金控制权"

---

#### 优化2：增加"乙方购买履约保证保险或提供银行保函"条款（O-02）

**新增条款**（建议插入在"第五条 甲方权利义务"或"第九条 违约责任"中）：

```
（X）乙方应在项目执行期间，为项目资金购买履约保证保险或提供银行保函，作为项目资金安全担保。保险金额或保函金额不低于项目总筹款金额的30%。如乙方破产或资不抵债，甲方有权优先从保险赔偿金或银行保函金额中收回项目资金。
```

**设计理由**：
1. 合法性：符合《慈善法》关于项目资金安全保障的要求
2. 攻击性：即使乙方破产，甲方也能从保险/保函中收回资金
3. 可操作性：条款具体、明确、可执行
4. 压力测试：应对"乙方破产或资不抵债"极端场景

## 谈判策略建议（综合蓝队+红队意见）

### 一、强硬谈判策略（红队建议）

1. **主动提出将"LPR的2倍"修改为"LPR的1.3倍"**
   - 表面是"让步"（2倍→1.3倍）
   - 实则是"最大化甲方利益"（1.3倍不会被法院调整，甲方可获得最大合法利益）

2. **要求增加"甲方资金监管权"条款**
   - 表面是"监督职责"（符合公募机构定位）
   - 实则是"资金控制权"（甲方可随时监管、暂停拨款）

3. **要求缩短退款期限（5日→3日）**
   - 表面是"小修改"
   - 实则是"甲方可更快收回资金"

### 二、防御性谈判策略（蓝队建议）

1. **坚持补充乙方授权代理人身份证号**
   - 这是合同效力问题，不能妥协

2. **坚持明确关联交易披露时限和披露内容**
   - 这是合规问题，不能妥协

3. **坚持明确甲方解除权行使期限和"90日"起算点**
   - 这是条款明确性问题，不能妥协

### 三、谈判顺序建议

**第一轮谈判**（提出必须修改的6条）：
1. 第九条第（三）款：LPR的2倍 → 1.3倍（表面让步，实则是攻击性策略）
2. 补充乙方授权代理人身份证号（必须坚持）
3. 明确关联交易披露时限（15日内）和内容标准（必须坚持）
4. 明确甲方解除权行使期限（6个月内）（必须坚持）
5. 明确"90日"起算点为"资金到账之日起"（必须坚持）
6. 明确连带赔偿责任的追偿范围（必须坚持）

**第二轮谈判**（提出建议修改的1条）：
7. 增加"平台停止服务"的应对条款（建议修改，如乙方反对可暂缓）
