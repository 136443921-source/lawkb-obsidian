# 小德医院合规管理系统 — 字段配置表（医院版）

> **架构**：1 张项目主表 + 2 张业务附表 + 5 张专项表 = **8 张表**。
> 通用字段组 0.1–0.4 全量移植慈善版（审计留痕／接线三字段／关联／组织主体资格），医院特有字段见专项表。

---

## 〇、三类通用字段组（全表套用）

### 0.1 🔴 审计留痕字段组（P0 · 8 张表全量）
| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 创建人 | 用户（自动） | 是 | 系统自动记录，不可编辑 |
| 创建时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 最后修改人 | 用户（自动） | 是 | 系统自动记录 |
| 最后修改时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 版本号 | 数字（自动递增） | 是 | 每次保存 +1 |
| 操作日志 | 子表／长文本（append-only） | 是 | 记录"谁-何时-改了什么-改前值-改后值" |

### 0.2 🔌 接线三字段（P0 · 8 张表全量）
| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 合规依据 | 多行文本 | 否 | 法条／制度条款（如"医疗纠纷条例 24；制度 Z3 §2"） |
| 经验卡ID回写 | 文本 | 否 | 沉淀后回填 card_id，形成表单→卡库反哺 |
| LTI校验状态 | 下拉单选 | 是 | 未校验／校验中／**通过**／**REJECT** |

### 0.3 🔗 关联字段规范（P1 · 全量）
一律改用 Lookup／Relation 关联，开启级联保护；主记录删除时附表置"已作废"，防证据灭失。

### 0.4 🏛️ 组织主体资格字段组（医院版 · 全局参数）
| 字段名 | 类型 | 取值域 | 必填 | 用途 |
|---|---|---|---|---|
| `机构类型` | 单选 | 社区卫生服务中心／乡镇卫生院／一级医院／二级医院 | 🔴 | 客群定级 |
| `床位规模` | 数字 | ≥0 | 否 | 资源配置核验 |
| `医调委备案状态` | 单选 | 已备案／未备案 | 否 | 纠纷转介判定（条例 32） |
