# 小德医疗纠纷调解系统 — 审批流（调解版）

> **架构**：10 个控制节点，对应六阶段 M1–M6（母本 8.3）。法条全部本地源（医疗纠纷条例 + 人民调解法）。
> 治理主体：医调委／调解员。

---

## 一、调解审批节点总表

| # | 节点 | 控制规则 | 法条依据 |
|---|---|---|---|
| M1 | 受理途径告知 | 医患双方可通过协商/人民调解/行政调解/诉讼解决 | 条例 **22** |
| M1b | 申请方式 | 双方共同申请；一方申请的须征得另一方同意 | 条例 **31** |
| M1c | 🔴 涉诉终止 | 已起诉或已申请行政调解并被受理→不予受理/已受理终止 | 条例 **31** 后段 |
| M2 | 证据固定 | 封存/启封病历须医患双方在场 | 条例 **24** |
| M2b | 实物封存 | 疑似输液/输血/注射/用药不良→双方共同封存现场实物 | 条例 **25** |
| M2c | 尸检时限 | 死因有异议→死亡后 48 小时内尸检（冻存可延长） | 条例 **26** |
| M2d | 重大报告 | 重大医疗纠纷→报告县级以上卫生主管部门 | 条例 **28** |
| M3 | 调解实施 | 专门场所；可咨询专家（条例 33）；需鉴定按规定启动（条例 34） | 条例 **30**·**33**·**34** |
| M4 | 协议达成 | 调解协议可申请司法确认（30 日窗口） | 人民调解法 **31**–**33** |
| M5 | 履行回访 | 协议履行登记；发现系统性风险→回喂②建整改卡 | 本手册 8.6 |

| 慈善版 | 调解版 |

---

## 三、红线节点（🔴 一票否决）

- **M1c 涉诉终止**：已诉/已行政调解受理→立即终止调解，转小强律师系统。
- **M3 场所红线**：协商须在专门场所，不得影响正常医疗秩序（条例 30）。
