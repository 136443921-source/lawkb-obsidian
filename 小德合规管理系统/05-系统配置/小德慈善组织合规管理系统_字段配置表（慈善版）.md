# 小德慈善组织合规管理系统 — 字段配置表（慈善版）

> **架构**：1 张项目主表 + 3 张业务附表 + 6 张专项表 = **10 张表**
> **核心改造**：审计留痕组全量补齐／关联改 Lookup／风险敞口+剩余风险／时限计算+超期判定／接线三字段／合规健康分

---

## 〇、三类通用字段组（全表套用）

### 0.1 🔴 审计留痕字段组（P0 · 10 张表全量套用）

> **合规系统的命根子。** 合规系统本质是**证据系统**，缺了不可篡改留痕，在监管检查或诉讼举证时等于白建。

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 创建人 | 用户（自动） | 是 | 系统自动记录，不可编辑 |
| 创建时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 最后修改人 | 用户（自动） | 是 | 系统自动记录 |
| 最后修改时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 版本号 | 数字（自动递增） | 是 | 每次保存 +1，历史版本可追溯 |
| 操作日志 | 子表／长文本（自动追加） | 是 | **append-only**，记录"谁-何时-改了什么-改前值-改后值" |

> 🚩 **实现要求**：以上 6 项**全部设为只读/系统自动字段**，禁止人工填写或覆盖；操作日志**只增不改不删**。

### 0.2 🔌 接线三字段（P0 · 10 张表全量套用）

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 合规依据 | 多行文本 | 否 | 该记录所依据的法条／制度条款（如"慈善法第 26 条；制度10 §3.1"） |
| 经验卡ID回写 | 文本 | 否 | 沉淀后回填 `card_id`，形成"表单 → 卡库"反哺闭环 |
| LTI校验状态 | 下拉单选 | 是 | 未校验／校验中／**通过**／**REJECT**（默认"未校验"） |

> 💡 `LTI校验状态` 是这套系统相对普通低代码模板的**唯一护城河**——竞品没有 LTI 文本监控器，做不出来。

### 0.3 🔗 关联字段规范（P1 · 全量改造）

> **原设计缺陷**：主表与附表靠"合同编号（文本）"关联 —— 手改一个字符即断链，且无级联保护。
> **改造**：一律改用 **Lookup / Relation 关联字段**（单向关联 + 双向引用），并开启级联保护。

| 原设计 | 改造后 |
|---|---|
| `关联合同编号`（文本） | `关联项目`（**Lookup → 慈善项目主表**，显示主表"项目名称+编号"，值为系统 ID，不可手改） |
| 无 | `级联规则`：主记录删除时，附表记录**禁止删除**（改为置"已作废"状态），防止证据灭失 |

### 0.4 🏛️ 组织主体资格字段组（P0-7 新增 · 2026-09-12 · 全局参数）

> **为什么需要**：N8/N9 的分档判定**先决于组织自身属性**——主体类型、公募资格、净资产。
> 这三个字段属于**组织级全局参数**（不随项目变化），一次录入、全系统复用，
> **缺失它们，财务红线节点 N8/N9/N16–N18 全部无法运算。**

| 字段名 | 类型 | 取值域 | 必填 | 用途 |
|---|---|---|---|---|
| `主体类型` | 单选 | 基金会／社会团体／社会服务机构 | 🔴 必填 | 分档判定 STEP 1 |
| `公开募捐资格` | 单选 | 有／无 | 🔴 必填 | 分档判定 STEP 2 |
| `上年末净资产` | 金额（元） | ≥0 | 🔴 必填 | 分档判定 STEP 3（无公募资格时） |
| `上年总收入` | 金额（元） | ≥0 | 🔴 必填 | 有公募资格时支出下限分母 |
| `登记为慈善组织日期` | 日期 | — | 🟠 | 判定第 14 条①「登记未满 1 年」例外 |

> ⚠️ `主体类型`＋`公开募捐资格`＋`上年末净资产` 三者构成 N8/N9 的**判定主键**，
> 任一为空 → 系统**禁止执行**财务红线校验，并提示"主体资格参数不全，无法判定"。

## 十三、🔴 年度支出 · 管理费 · 募捐成本 分档判定字段组（P0-7 新增 · 2026-09-12）

> **改造缘由**：原字段表**无任何字段**支撑 N8/N9 的分档判定——系统只能套「70% / 10%」单一阈值，
> 而该阈值仅对**有公开募捐资格的基金会**成立。缺字段 = 红线节点必然算错。

### 13.1 财务基数字段（运算输入）

| 字段名 | 类型 | 口径说明（🔴 分母不可混用） | 必填 |
|---|---|---|---|
| `年度慈善活动支出` | 金额（元） | 依**民发〔2026〕12号第 4 条**归集于「业务活动成本」下 | 🔴 |
| `年度管理费用` | 金额（元） | 依**第 5 条**归集（理事会/监事会经费、党建、行政人员薪酬、办公费等） | 🔴 |
| `年度募捐成本` | 金额（元） | 依**第 6 条**归集于「筹资费用」下；**本组织场地设备与工作人员费用不得计入** | 🔴 |
| `当年总支出` | 金额（元） | **管理费上限的分母**（全部主体、全部档位统一） | 🔴 |
| `上年总收入` | 金额（元） | **有公募资格**时支出下限的分母；口径见第 11 条第 2 款 | 🔴 |
| `上年末净资产` | 金额（元） | **无公募资格**时支出下限的分母 | 🔴 |
| `前三年收入平均数` | 金额（元） | 第 11 条**调节器**：可代替「上年总收入」 | 🟠 |
| `前三年年末净资产平均数` | 金额（元） | 第 11 条**调节器**：可代替「上年末净资产」 | 🟠 |
| `前三年捐赠收入平均数` | 金额（元） | **募捐成本上限的分母**（第 15 条，第三个独立口径） | 🔴 |

### 13.2 系统计算字段（只读 · 自动生成）

| 计算字段 | 公式 | 触发节点 |
|---|---|---|
| `适用主体档位` | 由 `主体类型` + `公开募捐资格` + `上年末净资产` 查 §2.5.2 矩阵得出 | 全财务节点 |
| `支出下限比例` | 查矩阵取 6%/7%/8%/70% | N8 |
| `支出下限金额` | 适用分母 × 支出下限比例 | N8 |
| `管理费上限比例` | 查矩阵取 10%/12%/13%/14%/15%/20% | N9 |
| `管理费上限金额` | `当年总支出` × 管理费上限比例 | N9 |
| `支出是否达标` | `年度慈善活动支出` ≥ `支出下限金额`（<100 万档还需 ≥ 上年总收入 50%） | N8 |
| `管理费是否超标` | `年度管理费用` > `管理费上限金额` **且** `年度管理费用` ≥ 20 万元 | N9 |
| `管理费豁免标记` | `年度管理费用` < 20 万元 → `豁免（第13条）` | N9 |
| `募捐成本上限金额` | `前三年捐赠收入平均数` × 3% | N16 |
| `募捐成本是否超标` | `年度募捐成本` > `募捐成本上限金额` | N16 |

### 13.3 校验规则（系统强制）

| # | 规则 | 违反动作 |
|---|---|---|
| R1 | `主体类型`/`公开募捐资格`/`上年末净资产` 任一为空 | **禁止执行**财务红线校验 + 红色提示 |
| R2 | `支出是否达标` = 否 | 触发报告 + 公开（N8） |
| R3 | `管理费是否超标` = 是 | 触发报告 + 公开（N9） |
| R4 | `募捐成本是否超标` = 是 | **硬拦截** + 报告 + 公开（N16） |
| R5 | 经合作方/项目执行方/信托受托人转付，款物**未到达最终受益人** | **不得计入**慈善活动支出（N17，第 12 条） |
