# 小德医疗纠纷调解系统 — 字段配置表（调解版）

> **架构**：1 张调解案件主表 + 2 张业务附表 + 3 张专项表 = **6 张表**。通用字段组 0.1–0.4 全量移植。
> 治理主体：医调委／调解员。法条全部本地源（条例 22–35 + 人民调解法）。

---

## 〇、三类通用字段组（全表套用）

### 0.1 🔴 审计留痕字段组（P0 · 6 张表全量）
| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 创建人 | 用户（自动） | 是 | 不可编辑 |
| 创建时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 最后修改人 | 用户（自动） | 是 | 系统自动记录 |
| 最后修改时间 | 日期时间（自动） | 是 | 系统自动记录 |
| 版本号 | 数字（自动递增） | 是 | 每次保存 +1 |
| 操作日志 | 子表／长文本（append-only） | 是 | 谁-何时-改了什么 |

### 0.2 🔌 接线三字段（P0 · 6 张表全量）
| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 合规依据 | 多行文本 | 否 | 法条／制度条款（如"条例 24；人民调解法 31"） |
| 经验卡ID回写 | 文本 | 否 | 沉淀后回填 card_id |
| LTI校验状态 | 下拉单选 | 是 | 未校验／校验中／**通过**／**REJECT** |

### 0.3 🔗 关联字段规范（P1 · 全量）
一律 Lookup／Relation 关联 + 级联保护。

### 0.4 🏛️ 调解主体字段组（调解版 · 全局参数）
| 字段名 | 类型 | 取值域 | 必填 | 用途 |
|---|---|---|---|---|
| `纠纷类型` | 单选 | 医疗损害/服务态度/费用/其他 | 🔴 | 分流 STEP 1 |
| `涉诉状态` | 单选 | 未诉/已诉/已行政调解 | 🔴 | M1c 终止判定 |
| `医调委备案号` | 文本 | — | 否 | 条例 32 备案 |
