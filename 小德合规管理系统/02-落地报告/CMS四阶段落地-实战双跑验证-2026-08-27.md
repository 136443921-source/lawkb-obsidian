# 小德合规管理系统（CMS）· 实战双跑验证

> 验证目标：确认 CMS 双子模板路由正确、六域框架贯通、跨模板经验可互哺。
> 验证日期：2026-08-27 ｜ 关联：四阶段搭建方案 Phase 4

---

## 一、路线A · 慈善（走子模板A）

**场景**：厚德基金会年度合规体检（内部制度 + 财务 + 信息公开）

```
请求：厚德基金会年度合规体检
  ↓ L0 父路由识别「基金会/慈善」→ 子模板A：[[慈善组织合规|慈善组织合规]]与纠纷处理
  ↓ 六域体检：
     制度 → 对照《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》139 条
     财务 → [[民间非营利组织会计制度|民间非营利组织会计制度]] / 募捐成本规定（2026）
     运营 → 项目执行追踪 / 重大活动备案
     人资 → 专职人员薪酬 / 志愿者管理
     税务 → 公益性捐赠税前扣除资格
     流程 → 信息公开流程 / 年度报告
  ↓ 输出：基本情况→合规分析→风险提示→整改建议（制度模板可直接用）
  ↓ 留痕：05-调用/ + 经验卡 → 慈法合规/ 或 非诉合规/
```

**验证点**：内规强制引用生效、139 条手册为单一可信源、纠纷分支（如捐赠人诉讼）红线转小强系统。

## 二、路线B · 医院（走子模板B）

### B-1 韩杰医生案（刑事辩护）→ 转小强系统（已详述于独立验证文档）
- 医疗事故罪再审辩护 = 涉刑 → ⛔ 红线转小强律师数字分身系统 + 医疗纠纷专项
- 子模板B 仅提供行业背景支撑，不越位 ✅（见 `韩杰案路由验证-医院子模板B-2026-08-27.md`）

### B-2 某医院常年顾问合规体检（纯合规层）→ 子模板B 接管
```
请求：XX医院常年法律顾问年度合规体检
  ↓ L0 父路由识别「医院/医疗机构」→ 子模板B：医院合规与纠纷处理
  ↓ 六域体检（8 章指南卡重映射）：
     制度 → 设立主体资格 / 风控基础（第三、四章）
     流程 → 常年顾问 SOP / 合同审查（第二章）
     运营 → 资产运营 / 医保基金合规（第七、八章）
     财务 → 设备药品采购反商业贿赂（第六章，药企赞助红线）
     人资 → 医护聘用 / 劳动争议（第五章）
     税务 → 转「税务合规审查」
  ↓ 输出：六域风险点清单 + 法规依据 + 整改建议
  ↓ 留痕：05-调用/周合规巡检/ + 经验卡 → 医院合规/
```

**验证点**：医院 8 章指南卡已翻译为六域工作流、药企赞助红线被纳入财务域排查、涉诉请求不误入本模板。

## 三、跨模板经验互哺验证

CMS 的六域框架使慈善与医院两套知识可对话。示例：

| 源模板 | 经验 | 反哺目标 | 互哺路径 |
|---|---|---|---|
| 子模板B（医院） | 设备药品采购反商业贿赂（药企赞助红线） | 子模板A 慈善投资活动合规 | 基金会对外投资 / 关联交易的利益输送防控，复用「反商业贿赂 + 关联方披露」逻辑 |
| 子模板A（慈善） | 139 条内规的「重大活动备案」机制 | 子模板B 医院重大医疗活动合规 | 医院新技术 / 新项目伦理审查与备案，复用「重大事项内部审批 + 外部报备」框架 |
| 子模板B（医院） | 医保基金骗保风险防控 | 子模板A 慈善资金 misuse 防控 | 善款挪用识别，复用「资金流向监控 + 异常预警」模型 |

> 互哺机制：经验卡在 `慈法合规/` `医院合规/` `非诉合规/` 三区经 `03-连接` 双向链接，周合规巡检与日常调用自动触发跨域检索（呼应跨案件模式识别同构）。
