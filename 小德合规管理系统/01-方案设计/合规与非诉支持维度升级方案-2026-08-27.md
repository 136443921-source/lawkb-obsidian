# 合规与非诉支持维度 · 升级方案与可行度评估

> 评估基准：2026-08-27 实地核查（非记忆回放）
> 评估对象：数字分身八维支撑地图第 7 维「合规与非诉支持」（当前成熟度：中）

## 一、现状真实诊断（实地数据）

| 核查项 | 真实结果 | 结论 |
|---|---|---|
| 小德是否为独立技能 | 否，是 user-memory 封装的慈善合规专家身份，由多个慈善技能 + LawKB 知识库支撑 | 入口散装，未成统一调度中枢 |
| [[数据合规审查|数据合规审查]]技能 | 338 行 SKILL.md + `risk_rules/legal_basis/check_list` 3 套 JSON 配置 | **真能力，已就绪** |

### 根因（一句话）
**不是"能力缺失"，是"激活机制缺失"** —— 资产都在，但没有编排器门禁、没有自动化节拍、没有调用留痕习惯，导致这一维长期处于"待命不用"状态。非诉业务类型覆盖也确实偏窄（仅数据/税务/备忘录/慈善四类）。

## 二、升级方案（三层递进）

### 🟢 A 层 · 激活层（杠杆最高 / 成本最低 / 可行度最高）
**核心思路：不新建能力，把已有的用起来。**

- **A1 非诉门禁接入编排器**
  在「案件全生命周期·门禁体系」增列 **G8 非诉合规门禁**：任何非诉文书（法律备忘录/律师函/尽调报告/合规审查意见）起草后，强制走「非诉文书红蓝复核工作流 → LTI 五维 → 六维门禁」，与现有 G2/G6 对齐。
  - 可行度：**高**（门禁体系已成熟，仅追加声明）
  - 成本：低（Edit 门禁 SKILL.md + [[MEMORY|MEMORY]] 铁律）
  - 杠杆：高（一次性改写，所有非诉文书自动过机检）

- **A2 合规巡检周自动化**
  新建一个每周自动化（如周日 21:00），对「在办案件 + 在管基金会/企业客户」跑一轮轻量合规体检（调用数据合规/税务合规/小德慈善技能），产出《周合规巡检简报》并写入 `05-调用`。
  - 可行度：**高**（复用现有技能 + 已有 automation 框架，六-B 铁律已覆盖）
  - 成本：低（写一个 prompt 自动化）
  - 杠杆：中高（把"0 自动化"变成"有节拍"，调用量自然拉起）

- **A3 小德封装为统一入口技能**
  新建 `小德慈善合规中枢` 技能，统一调度慈善纠纷处理/财务合规/制度体系/公益文书四个子技能，内嵌《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》139 条索引，作为慈善合规唯一入口。
  - 可行度：**中高**（user-memory 已有完整小德画像 + LawKB 知识库就绪，整合成本低）
  - 成本：中（新建/整合 1 个 skill）
  - 杠杆：高（消除"散装入口"，慈善合规一键调度）

### 🟡 B 层 · 扩面包层（补齐业务类型 / 可行度中等）
**核心思路：把非诉覆盖面从 4 类扩到常见 8-10 类。**

- **B1 补齐高频非诉业务技能**
  在现有「法律备忘录 919 行」范式基础上，快速复制出：股权架构与投融资合规、劳动用工合规、知识产权合规、合同合规体检、监管处罚应对 5 类。每类沉淀方法论 + 检查清单 + 法规库（仿数据合规的 config 结构）。
  - 可行度：**中**（模板可复用，但每类需逐一定制方法论，投入较大）
  - 成本：高（5 类 × 300 行级技能）
  - 杠杆：中（覆盖广度的质变）

- **B2 非诉经验卡沉淀机制**
  每次非诉调用强制产出 1 张「非诉经验卡」（仿经验卡片 frontmatter：案由/风险点/法规依据/处置要点/置信度），回填 `02-提炼/经验卡片/非诉合规/`，并同步更新调用记录（消灭 `knowledge_called:无` 的空调用）。
  - 可行度：**高**（沿用现有经验卡 schema）
  - 成本：低（SOP 固化 + 模板）
  - 杠杆：中（让知识飞轮真正接住非诉经验）

### 🔵 C 层 · 体系化层（统一调度 / 可行度中高）
- **C1 非诉调用 SOP 强制留痕**
  把"非诉文书必留调用记录 + 必产经验卡"写入 MEMORY 铁律（与"入案先回填""出文必过机检"并列），使 AI 在任何非诉场景主动执行，而非等你叫。
  - 可行度：**高**
  - 成本：低

## 四、建议落地路径（分三批，不混做）

**第一批（P0 · 零成本激活，今天可收口）**：A1 + A2 + C1
- 把现有技能"接上电"：门禁声明 + 周巡检自动化 + 调用留痕铁律。
- 预期效果：非诉调用从 ≈1 条/月 拉到 周级节拍，且每次必过机检、必留痕。

- 小德封装为统一入口 + 非诉经验卡沉淀机制跑通。
- 预期效果：慈善合规一键调度，非诉知识开始反哺飞轮。

**第三批（P2 · 扩面，按需）**：B1

- 预期效果：非诉广度从 4 类 → 9 类，成熟度由"中"升"高"。

## 五、诚实边界

- 本维升级**不需要新建底层能力**（数据/税务/备忘录技能已就绪），最大杠杆是"激活 + 留痕"，不是"从零造"。
- **唯一需你拍板的付费/外部依赖**：若 B1 要覆盖"税务跨境/数据出境"等强监管细分，可能需接入专业数据库（如威科/北大法宝，当前连接器均 disconnected）——这是 P2 阶段再议，不影响 P0/P1。
- 小德统一入口（A3）整合时需注意：现有慈善子技能（charity-*）若在别的工作区/未在当前 skills 列表，需先确认可访问性再封装。
