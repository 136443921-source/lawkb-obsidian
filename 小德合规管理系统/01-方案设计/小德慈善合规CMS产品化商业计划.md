# 小德慈善合规 + CMS 产品化商业计划

> 定位：把"10 年慈善法实务 + 《贵州省厚德公益基金会合规管理手册（试行）（2025版）》7 章 139 条内部规则 + AI 合规助手小德 + CMS 制品体系"打包成慈善组织**买得起的合规年度顾问包 / SaaS**，解决其"强监管下持续合规、不踩行政处罚红线"的刚需。
> 说明：市场规模、定价、收入测算为**逻辑假设**，标注【待核】，须以真实客群调研校准；法条仅引 LTI 缓存已核验覆盖条号。

---

## 一、一句话价值主张
**慈善组织最怕的不是"不懂法"，而是"不知道自己哪条线踩雷"。** 小德 CMS 用"内部手册 + AI 体检 + 人工复核门禁"把模糊的合规要求变成可执行的季度体检报告与年度顾问服务——让一家基金会用一顿饭钱，避开一次可能吊销资格的重大违规。

---

## 二、市场与客群（谁付钱、为什么付）

慈善组织合规是**强监管刚需、周期性、不合规即行政处罚/吊销**，付费意愿刚性远高于一般法律顾问。

| 客群分层 | 典型组织 | 核心痛点（付费驱动） | 付费能力 |
|---|---|---|---|
| A 类·基金会 | 公募/非公募基金会 | 年度支出比例、管理费用比例硬指标（《慈善法》第 61 条）、信息公开（第 78 条）、公开募捐方案（第 22 条） | 高（有运营费/政府购买） |
| B 类·慈善总会/社会服务机 | 慈善总会、民办非企业 | 登记管理、劳动人事、志愿服务、重大活动合规 | 中高 |
| C 类·筹备设立 | 拟成立慈善组织 | 设立合规、章程起草、登记流程 | 中（一次性） |
| G 类·监管方 | 民政部门 | 辖区内组织合规培训、数字化监管工具 | 中（政府采购） |

【待核】全国慈善组织存量百万级、贵州县级民政辖区组织数百家量级——具体 TAM/SAM 需以民政部门公开名录校准，本计划收入测算按"可服务存量"保守取数。

## 三、产品形态（复用现有资产，零重造）

CMS 已建成 canonical 经验卡片家（`LawKB/小德合规管理系统/03-经验卡片/`，含慈法合规、医院合规、医疗纠纷章卡）。产品直接包装三层：

### 1. 轻量版 · 慈法合规自检 SaaS【年费】
- 复用 **周合规巡检 automation（automation-1787843981235）** 改造为"客户组织体检引擎"：定期扫描组织公开信息/年报/募捐活动，输出合规体检报告。
- 交付物：季度体检报告（自动生成，过 LTI 防火墙零幻觉）。

### 2. 标准版 · 年度顾问包【年费 + 人工复核】
- 含 SaaS + 定期人工复核 + 重大活动合规审查。
- 强制走既有**非诉文书红蓝复核工作流（门禁 G8）→ 子模板 A（慈法合规）专项体检 → LTI 防火墙**；调用记录必写 `05-调用/非诉文书复核调用记录/`。
- 复用资产：139 条内部手册（决策须引内规条款）、慈法合规章卡库。

### 3. 定制版 · 单案合规专项【项目制收费】
- 联合劝募方案设计（《慈善组织公开募捐管理办法》+ 2026 新规）、关联交易审查、涉外活动合规、数字化执行方案。
- 复用：小德子模板 A + 数据/税务专项体检子模板。

**关键卖点（壁垒）**：所有交付物过 LTI 防幻觉——AI 法律产品最难的"不出假法条"，你已用 R101 条号越界 + C301 金额硬矛盾 + 正文比对关进笼子。这是同行 AI 合规工具普遍做不到的信任背书。

## 五、冷启动 / GTM（首批客户从哪来）

1. **讲座获客入口**：贵州县级慈善组织 90 分钟讲座《慈善组织互联网筹款与数字化运营》已规划——直接触达县级民政 + 慈善从业者，讲座即转化场景。
2. **标杆案例包装**：厚德基金会（你已深度服务）包装成 case study，作为标准版样板客户。
3. **连接器变现**：`gongyi-open-mcp`（腾讯公益机构服务平台）当前 **disconnected**，需 UI 重新授权——接上后可直连公益机构数据，实现"机构数据自动同步体检"，是 v2 关键杠杆。
4. **民政政府采购**：G 类客群走政府购买服务采购流程，讲座+培训打包。

## 六、运营交付流程（复用门禁，零重造）

```
客户委托 → 非诉文书红蓝复核工作流（G8）
         → 子模板 A（慈法合规）专项体检
         → 数据/税务专项体检（如涉）
         → LTI 防火墙（零幻觉校验）
         → 交付物 + 调用记录写入 05-调用/非诉文书复核调用记录/
         → 周合规巡检 automation 持续监控（标准版客户）
```
所有环节均为既有门禁，**产品化不新增流程，只把"内部能力"对外封装**。

- **双线实务经验**：慈善 + 民商事诉讼交叉视角，能识别"合规瑕疵如何演变为诉讼/行政处罚"。

## 八、风险与合规边界（必须前置告知客户）

- **律师执业规范**：合规咨询属法律服务，须注意执业范围、利益冲突、客户数据保密。
- **不承诺结果**：只能"降低违规风险"，**严禁向客户承诺"绝不处罚"**（避免虚假承诺）。
- **数据合规**：组织财务/受益人数据须签保密协议，脱敏处理。
- **主业平衡**：产品化占你时间建议 < 30%，主线诉讼（人伤/股权/合同）不松——慈善合规是增量线，不是替代线。
