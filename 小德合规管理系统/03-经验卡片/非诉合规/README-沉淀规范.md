## 三、内容结构

1. **交付物定位**：适用场景 / 客户价值
2. **结构骨架**：可直接套用的章节框架（带占位符）
3. **法源依据**：本地源优先；本地缺失一律标 `statute_text_pending` 不编造
4. **SLA 与交付标准**：频次 / 时限 / 签字要求
5. **互哺提示**：与①②③⑤模板的复用关系

## 四、本地法源（✅ 现成）

《民法典》全文、《公司法》（2023 修订）、《劳动合同法》（2012 修正）。
