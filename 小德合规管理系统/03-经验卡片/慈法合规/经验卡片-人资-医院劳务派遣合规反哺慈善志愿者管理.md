# 经验卡片-人资-医院劳务派遣合规反哺慈善志愿者管理（跨模板互哺 · 医院→慈善）

> CMS「双子模板知识互哺」验证卡。医院劳务派遣的用工边界管控，可反向强化慈善组织志愿者管理的法律关系厘清。

## 一、基本情况
- 互哺方向：子模板B（医院）→ 子模板A（慈善）。
- 同源问题：医院劳务派遣"临时/辅助/替代"三性边界，与慈善组织"志愿者非劳动关系但有侵权责任边界"高度同构——核心都是**法律关系定性 + 责任边界**。

## 二、风险点对照
| 医院人资侧 | 慈善志愿者侧 |
|---|---|
| 主营业务岗位用派遣工、超10%比例（《劳动合同法》第66条） | 将志愿者当廉价雇工长期使用，模糊劳动关系边界 |
| 派遣工工伤/侵权雇主责任不清 | 志愿者致他人/自身损害的责任承担（《民法典》第1191/1192条） |
| 薪酬工时争议 | 志愿者补贴标准与税务合规（超标准涉劳务报酬） |

## 三、互哺机制
- 医院"岗位三性 + 比例红线"审查框架 → 复用为慈善组织"志愿者/雇员边界判定清单"。
- 医院用工责任保险 → 复用为慈善组织志愿者意外险配置建议。

## 四、整改建议（双向）
- 慈善组织：建立"志愿者 vs 雇员"判定标准（持续性、从属性、报酬），签署志愿服务协议而非劳动合同。
- 志愿者活动须购意外险，明确致害责任分担（呼应志愿者与基金会纠纷案例）。

## 五、互哺提示
- ← 反向：慈善组织志愿者管理中的"关系定性 + 保险兜底"经验，可反哺医院对规培生/临时用工的合规管理。
