## 一、基本情况

慈善组织的发起人、主要捐赠人以及管理人员（统称"关联方"）与慈善组织发生交易行为（采购、服务、租赁、投资等）时，构成**关联交易**。该类交易是慈善财产流失与公信力危机的高发区，亦是民政部门现场检查重点。

## 二、风险点（标注法规依据）

1. **决策未回避**：关联方参与涉及自身利益的交易决策，违反慈善法第十四条"不得参与慈善组织有关该交易行为的决策"。
2. **未公开**：交易情况未向社会公开，违反同条"有关交易情况应当向社会公开"的信息公开义务。
3. **认定缺口**：仅识别显名关联方，漏判近亲属、实际控制企业等隐性关联，导致回避制度形同虚设。

## 三、合规分析（六域映射 + 处置路径）

| 域 | 落点 |
|---|---|
| 制度 | 章程须载明关联交易回避与披露条款；内控制度设"关联方清单 + 年度更新"机制 |
| 流程 | 任何涉关联方交易 → 触发回避表决（关联理事退场）→ 独立评估定价公允性 → 理事会决议留痕 |
| 财务 | 关联交易单独列示于年度财报；重大交易附公允性说明 |
| 运营 | 交易情况在统一信息平台公开，接受捐赠人查询 |

**法条锚定**：慈善法第十四条明确"不得利用其关联关系损害慈善组织、受益人的利益和社会公共利益"，并课以"不参与决策 + 情况公开"双重义务。基金会治理参照《基金会管理条例》第二十二条理事回避。

## 四、整改建议（可直接用）

1. 制度条款模板：「本组织任何与发起人、理事、主要捐赠人及其关联方的交易，关联董事/理事须回避表决，交易标的须经独立第三方评估或市场比价，结果于决议后 [X] 工作日内在指定平台公开。」
2. 流程卡点：在审批流增设"关联交易识别"节点（对应①模板 N 系列控制节点），未通过回避 + 公允性审查不得付款。
3. 红线：关联方借款、无偿占用资产、明显高于市场价采购 → 一律禁止。

## 五、互哺提示

- 反向哺②医院合规：医院设备/药品采购中的供应商关联关系审查（反商业贿赂）与本卡"关联方清单 + 回避"同源，可共用识别引擎。
- 反向哺④非诉：常年顾问客户（慈善/医院）年度合规义务地图须单列"关联交易披露"一项。
