## 一、基本情况

联合劝募 = 不具有公开募捐资格的组织/个人，与具有公开募捐资格的慈善组织**合作**开展公募。慈善法第二十六条是其唯一合法基础，但实践中最易被异化为"资格出借"。

## 二、风险点（标注法规依据）

1. **自行公募**：合作方以联合劝募为名直接面向公众募捐，违反慈善法第二十六条"合作方不得以任何形式自行开展公开募捐"。
2. **资格转包**：有资格方仅"出借证书"，不评估、不签约、不监督，构成实质转包 → 依慈善法第一百一十一条可吊销证书。
3. **账外循环**：合作募得款物未纳入有资格方账户统一核算（违反第二十六条"将全部收支纳入其账户"），慈善财产失控。

## 三、合规分析（六域映射 + 处置路径）

**三红线（联合劝募合规底线）**：

| 红线 | 法条依据 | 操作要求 |
|---|---|---|
| 红线① 不得自行公募 | 慈善法第二十六条 | 合作方一切募捐行为须以有资格方名义，页面/物料显著标注有资格方 + 方案 |
| 红线② 不得转包/出借资格 | 慈善法第二十六条 + 第一百一十一条 | 有资格方须事前评估合作方、签书面协议、载入募捐方案、全过程指导监督 |
| 红线③ 全额入账核算 | 慈善法第二十六条 | 合作募得款物 100% 进入有资格方账户，统一会计核算，合作方不得经手资金 |

| 域 | 落点 |
|---|---|
| 制度 | 联合劝募合作方准入评估标准 + 书面协议范本 |
| 流程 | 合作立项 → 资格校验 → 协议签订 → 方案载明合作方 → 资金归集 → 监督披露 |
| 财务 | 合作款物独立辅助账，与自有项目隔离 |
| 运营 | 募捐页面双标注（有资格方 + 合作方），避免公众混淆 |

## 四、整改建议（可直接用）

1. 合作方评估清单： registry 状态、过往公募合规记录、资金归集能力。
2. 协议强制条款：「合作方确认不以自身名义自行公募；全部捐赠资金径入甲方账户；甲方对募捐信息真实性负总责」。
3. 监督节点：月度资金对账 + 项目执行双签，对应①模板履约域控制节点。

## 五、互哺提示

- 反向哺④非诉：常年顾问客户做联合劝募前，非诉交付物须出具"合作方资质 + 协议合规"审查意见（D4 重大活动审查范畴）。
- 反向哺②医院：医院慈善募捐（如医疗救助项目）走联合劝募时，同样适用三红线，防"以医代募"违规。

> ⚠️ 待核验声明：《慈善组织公开募捐管理办法》对专项基金与合作募捐的细化条款本地库暂缺，本条以《慈善法》第二十六条为母法依据；专门办法核验后摘帽。
