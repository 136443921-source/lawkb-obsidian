# 医院合规经验卡 · 沉淀规范

> 本目录是「小德合规管理系统」**子模板B（医院合规与纠纷处理）** 的经验沉淀区，与 `慈法合规/`、`非诉合规/` 并列。
> 触发规则、frontmatter 模板、命名规范如下，供周合规巡检（automation-1787843981235）与日常医院合规调用自动回填。

---

## 一、触发沉淀的规则（任一即强制产卡）

1. **周合规巡检**命中医疗机构体检风险点（gate-config G8 + 铁律第6条）
2. **子模板B（医院合规与纠纷处理）** 激活并产出合规建议
3. **医疗纠纷专项 / 医疗损害非诉处置** 形成可复用经验
4. **父路由 L0** 分发至医院模板且产生新知识
5. **门禁 G8** 通过的非诉医院合规交付物

> 凡经 `医院合规与纠纷处理` 技能调用的高价值经验，必抽 1 张卡落本目录，呼应铁律第6条「必产卡」。

---

## 二、frontmatter 模板（融合慈法卡格式 + 留痕字段）

```yaml
---
title: 经验卡片-<医院合规主题>
type: 经验卡片
domain: 医院合规          # 六域之一：制度/流程/运营/财务/人资/税务
sub_domain: <如 设备药品采购 / 医保基金 / 医护人资>
case_type: <合规体检 | 纠纷非诉处置 | 制度搭建>
tags: [医院合规, <六域>, <主题>]
risk_points: [<风险点1>, <风险点2>]
legal_basis:
  - 《XX法》第X条
  - 《医疗保障基金使用监督管理条例》第X条
confidence: 0.XX           # 0-1
knowledge_called: <实际检索的卡/法规，不得为"无">
source_skill: 医院合规与纠纷处理
created: 2026-08-27
---
```

> `knowledge_called` 非空为硬要求（与 G8 门禁消灭 `knowledge_called:无` 同源）。

## 三、命名规范

`经验卡片-<六域>-<主题>.md`，例：
- `经验卡片-财务-医院设备采购反商业贿赂.md`
- `经验卡片-运营-医保基金骗保风险防控.md`
- `经验卡片-人资-医护人员劳务派遣合规.md`

---

## 四、内容结构（与慈法合规卡对齐）

1. **基本情况**：医疗机构类型 / 触发场景
2. **风险点**：逐条列出（标注法规依据条号）
3. **合规分析**：六域映射 + 处置路径
4. **整改建议**：可直接用的制度条款 / 流程卡点
5. **互哺提示**：该经验能否反哺慈善子模板A（如医院采购合规 ↔ 慈善投资活动合规）
