# 经验卡片-制度-AI工具PHI保密红线

> 专项卡（提炼自「医疗合规 AI 提效全景指南」），规范医疗机构使用 AI 工具时的患者健康信息（PHI）保密红线，属**制度域数据安全**。

## 一、基本情况
- 适用：临床、法务、行政人员使用公开/第三方 AI 工具辅助诊疗、文书、科研场景。
- AI 提效与 PHI 保护须平衡：效率不能以泄露患者隐私为代价。

## 二、风险点（标注条号）
1. **PHI 输入公开 AI 工具**：将可识别患者信息（姓名/身份证/病历号/影像）粘贴至公开大模型（《个人信息保护法》第28条：医疗健康属敏感个人信息，处理须单独同意+严格保护）。
2. **云端泄露**：未加密传输、跨境 API 调用致数据出境风险。
3. **训练数据含病历**：用真实病历训练/微调模型，违反最小必要原则。
4. **第三方 API 无数据处理协议**：供应商无合规 DPA（数据处理协议）。
5. **去标识不充分**：仅删姓名但保留可识别组合（生日+病种+科室）。

## 三、合规分析（六域映射）
- 制度域 × 数据安全：须写入机构 AI 使用管理制度，明确"禁止输入 PHI 至无协议公开工具"。
- 与「数据合规审查」技能联动（父路由 L0 已约定转数据合规）。

## 四、整改建议
- 发布"AI 工具使用三禁令"：禁输入 PHI、禁未授权跨境、禁用无 DPA 第三方。
- 推广机构内部脱敏/去标识工具 + 本地化部署模型处理临床数据。
- 全员签署 AI 使用保密承诺，纳入合规培训。

## 五、互哺提示
- → 慈善：基金会受助人健康/贫困信息同属敏感个人信息，AI 使用红线可互鉴。
