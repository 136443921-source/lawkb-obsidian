# 经验卡片-财务-设备药品采购反商业贿赂

> 专项深化「财务-医保基金与设备药品采购合规」枢纽卡，聚焦采购与供应商关系的反商业贿赂红线。

## 一、基本情况
- 适用：设备/药品/耗材采购、药企学术合作、科室赞助、第三方服务采购。
- 反商业贿赂是医疗机构合规高压线，直接关系机构信誉与从业人员执业安全。

## 二、风险点（标注条号）
1. **药企回扣**：以处方量返点、账外暗中给予财物（《药品管理法》第98条；涉刑转小强系统）。
2. **科室赞助**：药企直接向科室提供经费/设备，绕开机构公对公。
3. **学术会议利益绑定**：赞助与处方、用量挂钩。
4. **供应商虚高定价**：关联供应商虚高报价套取资金。
5. **第三方服务返点**：检测/配送/维保等服务商返利未入账。

## 三、合规分析（六域映射）
- 财务域 × 制度域：采购内控制度 + 供应商黑名单 + 利益冲突申报。
- 与慈善子模板A互哺：医院采购反商业贿赂 ↔ 慈善组织关联交易公允性（见 Batch 3 互哺卡）。

## 四、整改建议
- 药企赞助"三不"红线：不绑定处方、不进个人账户、不涉科室分成。
- 学术会议赞助走公对公 + 披露 + 与用量脱钩。
- 采购全流程留痕：招标→合同→验收→入库→付款，对应《政府采购法》《招标投标法》。
- 从业人员签署《廉洁从业九项准则》承诺书，设举报通道。

## 五、互哺提示
- → 慈善：基金会接受企业捐赠/采购服务，同样须防范利益输送与关联交易不公（慈善法第40条关联交易规制）。
