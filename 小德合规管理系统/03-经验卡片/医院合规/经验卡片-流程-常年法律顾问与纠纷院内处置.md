# 经验卡片-流程-常年法律顾问与纠纷院内处置

> 子模板B（医院合规）**流程域枢纽卡** · 萃取第二/十五/十六章（常年法律顾问服务内容与流程、纠纷院内处置、人民调解与行政调解），规范"服务SOP + 纠纷院内处置闭环"。

## 一、基本情况
- 适用：医疗机构常年法律顾问日常服务 + 医疗纠纷（非诉层）院内处置。
- 边界：涉诉/涉裁/涉刑（医疗事故罪）→ 红线转小强律师数字分身系统 + 医疗纠纷专项；本卡仅覆盖非诉处置层。

## 二、风险点
1. **纠纷受理无双登记**：患方来访/投诉未做受理登记，致后续举证不能（R-PI-162：纠纷受理双登记）。
2. **病历封存滞后**：发生争议未于2小时内启动病历封存，存在被推定过错风险（《[[医疗纠纷预防和处理|医疗纠纷预防和处理]]条例》第23条；R-PI-148 加插封存病历系篡改推定）。
3. **赔偿超1万元私了**：线下和解金额超1万违反内部管控（R-PI-162：赔偿超1万禁私了）。
4. **告知义务无书面留痕**：无书面沟通记录视为未履行告知义务（R029 / [[R-PI-144|R-PI-144]]）。
5. **调解路径误选**：未优先引导人民调解，径行诉讼放大对抗。

## 三、合规分析（六域映射）
- 流程域是"制度→运营"的传动轴：常年顾问 SOP 把制度落到日常。
- 纠纷院内处置 = 非诉处置层，属 CMS 子模板B 职责边界。

## 四、整改建议
- 建立"医疗纠纷应急五步闭环"：受理登记 → 病历封存(2h) → 风险评估 → 路径引导(协商/人民调解) → 结案留痕（R-PI-171）。
- 顾问服务 SOP：合同审查流程 + 重大决策合规审查流程 + 年度合规培训。
- 引导人民调解优先：《医疗纠纷预防和处理条例》第22条列明四种解决途径，人民调解具专业、免费、可司法确认优势。

## 五、互哺提示
- → 慈法合规：基金会纠纷调解（捐赠纠纷、项目执行纠纷）可借鉴医院人民调解路径。
- 与运营枢纽卡"病历书写败诉漏洞"强联动。
