# 经验卡片-制度-医院合规治理框架

> 子模板B（医院合规）**制度域枢纽卡** · 萃取医法知识库第一/三/四章（医院法律风险管理基础、设立与主体资格），覆盖医疗机构从设立登记到内部治理的全链条制度合规入口。

## 一、基本情况
- 适用对象：公立医院、民营医院、诊所、卫生院等各类医疗机构。
- 触发场景：新设/变更主体、年度合规体检、内部审计、接受卫健行政检查。
- 制度域是六域总闸：章程 + 内控制度 + 重大决策合法性审查，统摄其余五域。

## 二、风险点（标注条号）
1. **主体性质混淆**：非营利性与营利性医疗机构在登记、税收、利润分配规则迥异，混淆将致登记瑕疵与后续合规连锁风险（《基本医疗卫生与健康促进法》第38条：医疗卫生机构依法登记取得法人资格）。
2. **无证 / 超科目执业**：未取得《[[医疗机构执业许可证|医疗机构执业许可证]]》执业，或未按登记诊疗科目开展活动（《医疗机构管理条例》第23、24、26条）。
3. **使用非卫生技术人员**：聘用未取得相应资格人员从事医疗卫生技术工作（《医疗机构管理条例》第27条，罚则第47条）。
4. **内部治理架构缺位**：未设合规管理、法务或法律顾问机制，重大决策未过合法性审查。
5. **医疗质量安全管理制度不健全**：未制定并实施医疗质量安全管理制度（《[[医疗纠纷预防和处理|医疗纠纷预防和处理]]条例》第9、10条）。

## 三、合规分析（六域映射）
- **制度域**：主体资格 + 章程 + 内控制度 + 重大决策审查。
- 与**人资域**交叉：主体资格合规含医护人员执业注册（见人资枢纽卡）。
- 与**运营域**交叉：执业科目登记决定可开展的诊疗活动边界。
- 与**税务域**交叉：非营利/营利性质直接决定免税资格适用。

## 四、整改建议（可直接用的制度条款）
- 设立合规清单：执业许可证、诊疗科目登记、法人登记证"三证一致"。
- 建立"重大决策合规审查"制度：涉法事项须法务/法律顾问出具书面意见后方可上会（呼应 R-PI-161 审核应审尽审）。
- 将"不得使用非卫生技术人员"写入人事制度红线，并设资质年审。
- 设立医疗质量安全管理委员会，落地核心制度（首诊负责、三级查房、会诊、分级护理、值班交接班等）。

## 五、互哺提示
- → 慈法合规：基金会主体资格与内部治理（章程/理事会/关联交易制度）可反向借鉴医院治理框架。
- ← 反向：医院"重大决策合法性审查"制度可复用于慈善组织重大事项决策。
