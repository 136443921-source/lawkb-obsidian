# 经验卡片-财务-医院采购合规反哺慈善投资活动合规（跨模板互哺 · 医院→慈善）

> CMS「双子模板知识互哺」验证卡。医院采购反商业贿赂的防控逻辑，可反向强化慈善组织投资活动/采购的关联交易合规。

## 一、基本情况
- 互哺方向：子模板B（医院）→ 子模板A（慈善）。
- 同源风险：医疗机构药企赞助、供应商利益绑定，与慈善组织关联交易、投资活动利益输送，本质都是"公共/受托资金 + 利益关联方"的公允性失控。

## 二、风险点对照
| 医院采购侧 | 慈善投资/采购侧 |
|---|---|
| 药企回扣/科室赞助（《药品管理法》第98条） | 关联方以不公平对价与基金会交易（《慈善法》第40条） |
| 供应商虚高定价套取 | 投资标的为关联方，未回避决策 |
| 采购未招标 | 大额采购未履行理事会决策/公开程序 |

## 三、互哺机制
- 医院侧"公对公 + 披露 + 与用量脱钩"的赞助红线 → 复用为慈善组织"关联交易回避 + 公允定价 + 信息披露"三原则。
- 医院供应商黑名单 → 复用为慈善组织合作方尽职调查清单。

## 四、整改建议（双向）
- 慈善组织：投资/采购关联交易须理事会回避表决 + 独立评估 + 年报披露（呼应内规关联交易制度）。
- 医院：供应商准入尽调与慈善组织合作方尽调同构。

## 五、互哺提示
- ← 反向：慈善组织"关联交易公允性"审查框架亦可前置于医院采购合规培训。
