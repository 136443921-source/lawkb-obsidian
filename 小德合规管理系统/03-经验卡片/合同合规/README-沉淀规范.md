> 本目录是 CMS 合同合规审查专项（子模板C）的 **canonical 经验卡家**。

## 一、卡片分类

| 类别 | 落点 | 说明 |
|---|---|---|
| 合同合规经验卡 | 本目录 `03-经验卡片/合同合规/` | 每次审查后的经验/教训（含思维轨迹 frontmatter） |
| 思维轨迹 | 卡片 frontmatter 字段 `思维轨迹` | 审查推理链路，**不独立成卡**（避免与 `知识飞轮系统/02-提炼/经验卡片/思维轨迹/` 重复） |
| 决策思维卡（DEC） | `知识飞轮系统/04-LOG/决策日志/` | 重大决策对齐 `decision-capture` 决策卡格式（DEC 编号），**不存本目录** |

## 三、与双系统边界（不可逾越）

- **起草 / 文本生成** → 归「合同文书管理系统(L0)」，本专项不碰
- **本行业合同**（慈善捐赠/联合劝募/医院采购/医护聘用等）→ 走子模板 A/B「本行业合同」分支（注入行业强监管规则）
- **通用商事合同**（股权转让/货物采购/租赁/服务协议/技术转让/承揽等）→ 走子模板C
- **合同引发的诉讼/仲裁**（如 6658 吊顶案、6660 雅菲案）→ 一律转小强律师数字分身系统，本专项不介入诉讼策略

## 四、门禁与铁律

- 每次审查产出须过 **G8**（非诉文书红蓝复核工作流 → LTI 五维 → 六维法理逻辑门禁）
- **铁律第6条**：非诉调用必留痕（`knowledge_called` 非空）+ 必产卡（本目录）
- **周合规巡检**：暂未纳入 `automation-1787843981235`，待老强确认后扩展覆盖范围
