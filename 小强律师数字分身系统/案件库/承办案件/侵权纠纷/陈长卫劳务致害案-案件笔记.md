# 案件笔记：陈长卫劳务致害案

> 真实案件分析报告归档（依据 (2023)黔03民终5221号 二审民事判决书，2023-10-31）。

## 一、案件要素
- **案由**：提供劳务受害者责任纠纷（高压电致人损害）
- **我方身份**：提供劳务者 — 陈长卫
- **对方当事人**：遵义供电局、遵义光明电力实业有限公司、润通公司、王远飞、陈宗元等
- **审理法院**：一审 (2023)黔0302民初1174号；二审 遵义中院 (2023)黔03民终5221号（2023-10-31）
- **处理结果**：**二审改判** — 供电局承担20%责任；陈长卫自身过错自担20%；其余60%由违法分包链条主体连带承担

## 二、胜败诉要点
- **我方胜诉核心**：① 成功证明"三牌更换"不属于原分包范围（关键改判点）；② 成功适用《民法典》第1239条（高压电无过错责任），供电局作为经营者不能因发包关系免除；③ 法院支持大部分赔偿项目。
- **我方部分败诉**：自身过错比例一审10%→二审20%（有电工资质未尽安全注意义务，过失相抵《民法典》第1173条）；部分赔偿项目被酌减。

## 三、可复用裁判规则 / 经验
- 高压电经营者承担无过错责任，不因发包关系免除（《民法典》第1239条，特别法优于一般法）。
- "重新立项"视为新合同关系，不属于原分包范围（关键证据：原承包方"无力完成"书面说明）。
- 违法分包+违法转包+雇主无资质 → 链条各方承担连带责任；一人公司法定代表人不能证明财产独立 → 连带责任（《民法典》第1168条）。
- 被侵权人有过错 → 过失相抵（《民法典》第1173条）。
