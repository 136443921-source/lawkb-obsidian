## 三、日常运营 SOP

### 3.1 每日节拍
1. **08:30** 知识摄入自动化（v1.23）启动。
2. 办案：新案第一动作**入案回填**（G0/G7 门禁）；出文**红蓝复核 → LTI 校验 → 六维门禁**。
3. **19:00** CaseDrop 归档。
4. **23:30** 摄入稳定性守卫（连接器健康监测）。

### 3.2 每周节拍
- **周日 20:30** self-improve + 链接刷新。
- **周日 21:00** 周合规巡检（G8 门禁，产出落 `05-调用/周合规巡检/`）。
- **周五 17:00** 周报。

### 3.3 入案 / 出文铁律
- 入案先回填；跨案识别主动调用。
- 出文必过机检：红蓝 → LTI 五维（R/L/C/T/P）→ 六维门禁（G2+G6）→ **REJECT=0 才交付**。
- 非诉交付物（含经验卡）：必走「非诉文书红蓝复核 → 专项体检 → LTI 防火墙」，调用记录写 `05-调用/非诉文书复核调用记录/`（`knowledge_called` 非空）。

## 四、安全铁律（车规 · 最高优先级）

1. **六-B 铁律**：写入型 automation / 批量操作必含「先排查 / 确认非误报 / 再批量修改 / 含安全扫描 + dry-run + 备份 / 回滚」。已扩展至全部写入型 automation（P0-1 闭环）。
2. **不凭记忆灌条文**：法条须从本地权威源 / 元典 `rh_ft_detail` / pkulaw 回填；凭记忆写条号错误率实测 22%（慈善法高达 75%）。
3. **不代点 UI**：连接器重连 / 授权 / 令牌刷新由老强亲手；令牌不可凭空造。
4. **先备份再动手**：`cp -n` 防覆盖；单源重建备份 `/tmp/时间戳`。
5. **红线**：REJECT=0 才交付；草稿态 / 待 LTI 校验 / 两库断开等提示须加粗重点提醒。

- **SSO 门禁版已上线**：`https://lq-command-gate-2026.app.workbuddy.link/`

  > 🔴 **2026-09-12 22:12 更新**：`oidc.enabled` 虽为 `true`，但 `oidc.issuer` 与 `oidc.clientId` **均为空**，OIDC **并未真正接通**，实际登录仍回落本地演示令牌。真接入 IdP 前，本门禁不构成安全边界。生产升级 4 步（写于 rbac.js 注释）：换 OIDC `id_token` 标准验签 + 用户→角色映射迁服务端 + 子驾驶舱消费 `?token=` 端到端 SSO + 接入真实 IdP（Authing / Keycloak / WorkBuddy SSO）。
