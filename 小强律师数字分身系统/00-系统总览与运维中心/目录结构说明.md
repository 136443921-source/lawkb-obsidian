# 小强律师数字分身系统 · 目录结构说明

> **配套**：《数字分身系统运维手册（EV 版）》+《数字分身系统运维套件索引》。
> **重构日期**：2026-09-03。**目的**：按运维手册章节编号重组子文件夹，实现「看手册第 N 章 → 开对应文件夹」。

## 一、设计原则

1. **顶层 10 个编号文件夹**对应手册主要章节（00 总览 → 09 备份），编号即阅读顺序。
2. **本地文件直接入册**：设计文档 / 对外分身 / 搭建史 / 案件 / 快照 在本目录内，已物理搬移至对应编号文件夹。
3. **外部资产不搬、只放指针**：飞轮 / LTI / 技能 / 连接器 / 自动化 / 04-LOG 物理上散落在 `LawKB/知识飞轮系统`、`~/.workbuddy/skills`、WorkBuddy 连接器与自动化面板。为避免搬动打断系统链接与自动化，各对应章内放 `README-资产位置.md` 指针，写明实际路径。
