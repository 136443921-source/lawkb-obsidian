## 四、归口纪律（新增文件必须先查本册）

1. **先查后放**：往 `00/` 放任何文件前，先查本册是否已有同类；有则**引链接**，不复制。
2. **双态必标**：凡不属于 §二「现行受控」的文件，落地时**就地打 `🗄 status: archive` 行**，并登记本册。
3. **归档不删**：归档＝停止引用，**绝不删除**（与 LTI v1「永不删除」同纪律）。
4. **HTML 特殊**：`.html` 用 `<!-- 🗄 status: archive ... -->` 注释标记，**不得用 Markdown 引用语法**（否则渲染成裸文本）。
5. **启用须升版**：某归档件要重新启用，先在本册 §三 删行、升版并注明，再改文件状态 —— 禁止"悄悄改回来"。
6. **台账随行**：本册每次改动，页眉版本 + 日期 + 变更记录**三同步**（🔒 版本三同步纪律）。
