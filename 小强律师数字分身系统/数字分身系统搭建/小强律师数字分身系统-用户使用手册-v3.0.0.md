## 📊 系统概述

### 系统简介

"**小强律师数字分身系统**" 是一个专为律师和法律工作者设计的AI智能体系统，包含 **17个专业智能体技能**，覆盖从**客户面谈**到**经验总结**的完整法律服务流程。

### 系统特点

✅ **全流程覆盖**：从客户面谈 → 案件归档的完整闭环  
✅ **智能联动**：所有技能之间形成了有机的联动关系  
✅ **知识管理**：经验总结与知识沉淀技能实现知识积累和传承  
✅ **质量保障**：所有技能输出都经过LTI文本监控器检查  
✅ **实战导向**：所有功能都基于实际工作需求设计

### 18. 合同审查工作流（v1.0.0）

#### 功能概述
封装完整的合同审查流程，将多个分散的技能（蓝队律师合同审查、红队律师合同审查、LTI文本监控器等）整合为一个统一的工作流，用户只需输入合同文本，即可自动完成全流程审查。

#### 触发词
`合同审查工作流`、`快速审查合同`、`一键审查合同`、`工作流审查`

#### 工作流程

```
用户输入合同文本
├─ 启动【第一阶段：蓝队律师合同审查】
│  ├─ 输入：合同文本（Word/PDF/图片）
│  ├─ 处理：10维度精细核验
│  └─ 输出：蓝队审查报告（初稿）
├─ 询问用户：是否需要红队对抗性审查？
│  ├─ 是 → 启动【第二阶段：红队律师合同审查】
│  │  ├─ 输入：蓝队审查报告
│  │  ├─ 处理：对抗性审查、反向质疑、压力测试
│  │  └─ 输出：红队审查报告
│  └─ 否 → 跳过第二阶段
├─ 启动【第三阶段：审查报告生成】
│  ├─ 输入：蓝队审查报告 + （可选）红队审查报告
│  ├─ 处理：整合审查意见，生成最终审查报告
│  └─ 输出：最终审查报告 + 修改标注版合同（Word文档）
├─ 启动【第四阶段：LTI文本监控器检查】
│  ├─ 输入：最终审查报告
│  ├─ 处理：LTI v2.9.1文本质量检查
│  └─ 输出：通过LTI检查的最终报告
└─ 输出最终结果
   ├─ 最终审查报告（Word文档）
   ├─ 修改标注版合同（Word文档）
   └─ 风险清单（Markdown文档）
```

#### 输入
- **合同文本**（必须）：支持Word（.docx）、PDF（.pdf）、图片（.png/.jpg）、纯文本
- **审查重点**（可选）：用户指定的重点关注条款

#### 输出
- **最终审查报告**（Word文档）：结构化的审查报告，包含 all 审查意见和修改建议
- **修改标注版合同**（Word文档）：在合同文本中标注需要修改的地方
- **风险清单**（Markdown文档）：风险分级清单
- **红队审查报告**（可选）：如用户要求红队审查

#### 注意事项
1. **蓝队审查必须完成**：第一阶段（蓝队律师合同审查）是必须完成的，不能跳过。
2. **红队审查可选**：第二阶段（红队律师合同审查）是可选的，用户可以选择跳过。
3. **LTI检查必须完成**：第四阶段（LTI文本监控器检查）是必须完成的，不能跳过。
4. **所有输出必须经过LTI检查**：最终输出给用户的文本，必须通过LTI检查。

#### 联动技能
- **输入来源**：用户上传的合同文本
- **输出去向**：用户（最终输出）

#### 使用建议
1. **首次使用**：建议先使用"蓝队律师合同审查"技能，了解单个技能的使用方法。
2. **效率优先**：当熟悉合同审查流程后，使用本技能可以快速完成全流程审查。
3. **质量优先**：如需最高质量的审查结果，建议启用红队审查（对抗性审查）。

## 🔒 LTI文本监控器使用说明

### LTI文本监控器概述

**LTI文本监控器系统 v2.0（统一版）** 是一个"防火墙式"的文本质量检查工具，对所有AI生成的法律文本执行强制拦截检查，严格执行 **"未通过LTI文本监控器不出文本"** 原则。

### 核心功能

LTI文本监控器包含三大检查官：

| 检查官 | 职责 | 检查内容 |
|--------|------|----------|
| **Verifier（法条核查员）** | 核查法律条文有效性 | 已废止法律、法律效力状态、法条编号准确性 |
| **Auditor（逻辑审计员）** | 审计文书逻辑一致性 | 时间线矛盾、金额计算错误、逻辑漏洞 |
| **Editor（语言净化器）** | 校正专业术语与格式 | 法律术语规范、标点符号使用、版式排版 |

### 裁决逻辑

LTI文本监控器对检查结果进行裁决，决定输出方式：

| 检查结果 | 裁决结果 | 输出方式 |
|----------|----------|----------|
| CRITICAL错误 ≥ 1 | REJECT（拒绝） | 禁止输出，抛出`LTIRejectError`异常 |
| 仅WARNING错误 | AUTO_FIX（自动修正） | 自动修正后输出，添加"⚠️ LTI 监控结果：AUTO_FIX"标记 |
| 无错误 | PASS（通过） | 直接输出，添加"✅ 文本监控器参与说明" |

### 使用方式

#### 方式1：Python函数调用（推荐）

```python
from main import wrap_output, LTIRejectError

# 待检查文本
text = "根据《[[中华人民共和国民法典|中华人民共和国民法典]]》第一千一百六十五条..."

# 输出前必须调用 wrap_output()

    output_text = wrap_output(text, ai_participation="AI生成的法律分析")

except LTIRejectError as e:
    # 未通过LTI，禁止输出原始文本
    print(f"❌ 文本被LTI拦截：{e}")
    # 只输出错误信息，绝不输出原始文本
```

## ❓ 常见问题解答（FAQ）

### 问题1：如何触发某个技能？

**回答**：在WorkBuddy对话中，使用技能的**触发词**即可触发。

**示例**：
```
用户：请使用谈案律师技能，为以下案件生成案件分析报告：...
```

### 问题2：技能输出保存在哪里？

**回答**：所有技能的输出文件默认保存至 `/Users/chenyouqiang/Desktop/龙虾/` 目录。

**修改保存路径**：可以编辑技能的SKILL.md文件，修改"输出格式与保存路径"部分。

### 问题3：LTI文本监控器检查不通过怎么办？

**回答**：LTI检查不通过时，会根据错误级别采取不同措施：

1. **CRITICAL错误**（如引用已废止法律）：输出被拦截，禁止输出。需要修改文本，移除已废止法律引用，重新提交检查。
2. **WARNING错误**（如术语使用错误）：文本被自动修正后输出。可以查看修正内容，确认是否符合预期。

### 问题4：技能之间如何传递数据？

**回答**：技能之间主要通过**文件**传递数据：

1. 前序技能输出文件（保存至 `/Users/chenyouqiang/Desktop/龙虾/`）
2. 后续技能读取前序技能的输出文件
3. 后续技能基于读取的内容，继续生成自己的输出

### 问题5：如何查看技能版本和更新历史？

**回答**：每个技能的SKILL.md文件开头都有版本信息和更新历史。

**查看方式**：
```bash
# 查看谈案律师技能版本
head -20 /Users/chenyouqiang/.workbuddy/skills/tanan-lvshi/SKILL.md
```

### 问题6：技能可以单独使用吗？

**回答**：是的，所有17个技能都可以**单独使用**。

但是，为了发挥最大效用，建议按照"技能联动关系图"的顺序使用，形成完整的法律服务流程。

### 问题7：如何添加新技能？

**回答**：添加新技能需要：

1. 创建技能目录：`/Users/chenyouqiang/.workbuddy/skills/技能名称/`
2. 创建SKILL.md文件：定义技能功能、触发词、输入输出、联动关系
3. 添加LTI检查说明：确保技能输出经过LTI文本监控器检查
4. 测试技能功能：确保技能正常工作
5. 更新用户使用手册：将新技能添加到手册中

### 问题8：LTI文本监控器可以检查哪些错误？

**回答**：LTI文本监控器可以检查以下错误：

1. **已废止法律引用**（如《合同法》《物权法》）
2. **术语使用错误**（如"法人代表"应为"法定代表人"）
3. **逻辑错误**（如诉讼时效计算错误）
4. **标点符号错误**（如法律条文引用格式错误）

### 问题9：如何反馈技能使用问题或改进建议？

**回答**：您可以直接在WorkBuddy对话中反馈问题或改进建议。

**示例**：
```

```

我会记录您的反馈，并在后续版本中优化技能功能。

### 问题10：系统支持多人协作吗？

**回答**：当前系统（v3.0.0）主要支持**个人使用**。

但是，技能输出的文件（保存至 `/Users/chenyouqiang/Desktop/龙虾/`）可以通过云盘（如iCloud、OneDrive）共享，实现简单的多人协作。

后续版本可以考虑增加：
