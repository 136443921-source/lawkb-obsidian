## 一、系统概述

### 1.1 什么是"小强律师数字分身系统 3.0"？

**定义**：一个基于 WorkBuddy 平台的纯 AI 法律数字分身系统，专为律师、法务、法律从业者设计。

**核心特点**：
- ✅ **纯 WorkBuddy 方案**（无需复杂依赖，如 Neo4j、Redis、MinIO）
- ✅ **三层知识结构**（原始素材层 → 知识页面层 → 规则配置层）
- ✅ **三大核心能力**（定时任务自动化、智能提醒与跟踪、知识库自动归档）
- ✅ **17 个工作流程**（覆盖律师日常工作全流程）
- ✅ **9 个技能包**（扩展专业能力边界）
- ✅ **LTI 文本监控器**（法律文本质量防火墙）

**适用场景**：
- 案件分析与策略制定
- 法律文书起草与审查
- 合同审查与风险识别
- 法规检索与案例研究
- 庭审准备与模拟法庭
- 客户沟通与面谈助手
- 知识管理与经验沉淀

---

### 1.2 系统架构

```
小强律师数字分身系统 3.0/
├── 01-Raw/              # 原始素材层（AI 只读不写）
├── 02-Wiki/              # 知识页面层（结构化知识网络）
├── 03-GUIDE/            # 规则配置层（宪法 + 流程 + 风格）
│   ├── constitution.md    # 身份与原则
│   ├── process.md        # 工作流程
│   └── style-guide.md   # 输出风格指南
├── 04-LOG/              # 日志层（每日工作记录）
└── 05-REVIEW/           # 复盘层（每周/每月复盘报告）
```

**三层结构说明**：

| 层级 | 名称 | 功能 | AI 权限 |
|------|------|------|----------|
| **01-Raw/** | 原始素材层 | 存放原始资料（Obsidian 笔记、案件材料、法律文书等） | 只读不写 |
| **02-Wiki/** | 知识页面层 | AI 将原始素材提炼、摘要，形成结构化知识网络 | 读写 |
| **03-GUIDE/** | 规则配置层 | 分身的"宪法"或"员工手册"，固化身份、工作流、风格、红线 | 读写 |
| **04-LOG/** | 日志层 | 记录每日工作日志、知识增量、工作建议 | 读写 |
| **05-REVIEW/** | 复盘层 | 每周/每月复盘报告、经验总结、知识成长报告 | 读写 |

## 二、核心功能复盘

### 2.1 三大核心能力

#### ✅ 能力 1：定时任务自动化

**功能**：
- 自动执行每日/周/月的固定任务
- 无需人工干预，系统自动运行

**已配置的定时任务**：

| 任务名称 | 执行时间 | 功能描述 |
|---------|---------|----------|
| **每日自学习** | 每天 22:00 | 扫描 01-Raw/ → 更新 02-Wiki/ → 生成今日知识增量 → 写入 04-LOG/ |
| **每周复盘** | 每周五 22:00 | 读取本周 04-LOG/ + 02-Wiki/ 变更 → 生成本周工作复盘 + 知识库成长报告 → 写入 05-REVIEW/ |

**技术实现**：
- 使用 WorkBuddy 的 `automation_update` 工具
- 任务 ID：`automation-1781157480047`（每日自学习）、`automation-1781157492026`（每周复盘）
- 状态：ACTIVE（已激活）

---

#### ✅ 能力 2：智能提醒与跟踪

**功能**：
- 主动跟进项目进度、客户 Deadline 和待办事项

**实现方式**：

### 2.4 LTI 文本监控器

**功能**：
- 对 AI 生成的所有文本执行"防火墙式"拦截检查
- 严格执行"未通过 LTI 文本监控器不出文本"原则

**检查内容**：
1. **术语修正**：自动修正法律术语错误（如"法人代表" → "法定代表人"）
2. **法律时效性检查**：检查引用的法条、案例是否生效、修订、废止
3. **自动修正文本**：自动修正文本中的错误、不一致、不完整之处

**集成方式**：
- 在所有规则文件中强制要求：所有输出前必须通过 LTI 检查
- 在 `style-guide.md` 中明确 LTI 检查规范
- 在定时任务的 prompt 中添加 LTI 检查要求

**版本**：v2.9.1（功能增强版，已实现 R015-R024 检查器）

## 六、故障排查

### 6.1 规则文件加载失败

**症状**：
- 系统回答与预期不符（未加载 `constitution.md`）
- 工作流程未触发（未加载 `process.md`）
- 输出格式不规范（未加载 `style-guide.md`）

1. **检查规则文件是否存在**
   - 路径：`03-GUIDE/constitution.md`、`process.md`、`style-guide.md`
2. **检查规则文件格式是否正确**
   - 确保是 Markdown 格式，无语法错误
3. **检查规则文件内容是否完整**
   - 确保包含所有必填内容（参考本文档第三章）
4. **重启 WorkBuddy 会话**
   - 有时需要重启会话才能加载新规则

---

### 6.2 Obsidian 知识库读取失败

**症状**：
- 系统无法读取 Obsidian 笔记
- 系统回答未引用 Obsidian 知识库中的内容

**排查步骤**：
1. **检查 Obsidian vault 路径是否正确**
   - 查看 `constitution.md` 中的路径配置
   - 确保路径存在，且有权限读取
2. **检查 Obsidian vault 中是否有资料**
   - 确保至少有 1 个 Markdown 文件
3. **检查文件权限**
   - 确保文件可读（读权限正常）
4. **手动测试读取**
   - 在 WorkBuddy 中输入：`读取 /Users/chenyouqiang/Documents/xiaoqianglawkb/README.md`

### 6.3 技能联动失败

**症状**：
- 说出触发关键词，但未联动相应技能
- 技能联动错误（联动了错误的技能）

**排查步骤**：
1. **检查技能是否已安装**
   - 输入 `/skills`，查看已安装技能列表
2. **检查触发关键词是否正确**
   - 查看 `process.md` 中的触发关键词
   - 确保触发关键词与技能触发词匹配
3. **检查技能配置是否正确**
   - 查看技能目录中的 `SKILL.md` 文件
   - 确保技能配置无误
4. **手动调用技能**
   - 尝试手动调用技能，验证是否正常工作

### 6.4 定时任务未执行

**症状**：
- 到了预定时间，定时任务未自动执行
- `04-LOG/` 目录中未生成今日日志文件

   - 如果状态是 PAUSED，需要激活
3. **检查定时任务时间配置是否正确**
   - 确保时间配置无误（时区、小时、分钟）

   - 输入 `/automations`，查看定时任务的执行历史
