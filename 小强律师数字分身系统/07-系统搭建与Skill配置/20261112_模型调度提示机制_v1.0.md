## 1. 为什么是「提示式」而不是「自动切换」

| 事实 | 出处 |
|---|---|
| 模型切换是用户在输入框下拉菜单的操作，AI 改不了主会话模型 | 官方 Task-Bar 文档「切换模型」段 |
| 中途切换**下一轮**才生效，且可能降低性能、增加积分消耗 | 同上 |
| L0[23] 前半段锁「不得擅自切换」，留例外「用户明确要求使用其他模型时从其指定」 | `L1-05-工具与操作.md` 第 50–63 行 |
| L0[23] 后半段**授权型号仅 `hy4`／`deepseekv41`**；其它型号须事先提示 + 明确许可；例外是「用户**明确点名**」 | 同文件第 64–71 行（**v1.0 漏读，R1 补上**） |

→ 「提示 + 等明确点名」是零冲突、零技术风险的路径。两个硬约束型号**恰好都在 [23] 授权清单内**，机制零越界；GLM／MiniMax／Kimi 降为「许可例外区」，不主动推荐。

**D3／D6 均已核实**：下拉菜单 DeepSeek 侧＝`V4.1-Flash-1017`（23:03）、hy4 侧显示＝`Hy4`（23:09）。方案原文对 `DeepSeek-V4.1-Flash-1017` 的定位是「长文档精读／案卷梳理／证据清单整理／多文件对比／精细化文书优化」，**恰好支撑案卷文书域裁定**；该能力描述仍标 `[自述待验]`。书写值映射表见 SSOT §1.1。

⏰ **Hy4 限时免费（R3）**：UI 文案「最新旗舰模型，Agent 与多模专长｜11月4日–11月15日，每日赠送免费额度」。今日 2026-11-12 **在期内**；「Agent 与多模专长」支撑系统搭建域裁定。cockpit 的 `hy4-preview ≈136 积分/次` 为**历史快照**，免费期内不必然适用，**历史数据文件禁改**；**11-15 后须重评成本口径**（D8）。

## 2. 机制闭环（R3）

```
接单（四问后、动手前）
  → 按产物判定业务域（法律文书 → 案卷文书域；系统组件 → 系统搭建域）
  → 系统搭建域 = 默认 Hy4：静默执行，不弹卡
  → 案卷文书域 ≠ Hy4：输出一次提示卡，不阻断
  → 老强明确点名型号（如「用 V4.1-Flash-1017」）→ 下一轮生效
  → 未点名 / 明示「维持 Hy4」→ 按 Hy4 继续，标注「与裁定口径不符，本次豁免」
```

**不纳入分工**：定时任务 automation、AI 自动换主模型、中途来回切；第三方型号不主动推荐。
