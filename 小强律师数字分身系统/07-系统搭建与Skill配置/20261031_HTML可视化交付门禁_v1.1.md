## 3. 中文排版刻度（不只是照搬 1.2 倍率）

英文 1.2 倍率直接套中文会让层级过密。本系统取**中文可读优先的 6 级刻度**：

| 级别 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| h1 | 22px | 1.3 | 500 | 页面主标题（单页仅 1 个） |
| h2 | 18px | 1.45 | 500 | 区块标题 |
| h3 | 15px | 1.5 | 500 | 卡片标题 |
| body | 14px | **1.7** | 400 | 正文（中文方块字需更疏） |
| small | 12.5px | 1.6 | 400 | 表格/说明 |
| micro | 12px | 1.5 | 400 | 角标（**绝对下限，禁 <12px**） |

**字重只有两档**：400 常规 / 500 强调。**禁用 600/700 大面积加粗**——中文粗体在屏幕上会糊成墨块。

**数字与英文**：表格金额、案号、百分比用 `--font-mono` + `font-variant-numeric: tabular-nums`，保证列对齐。

## 4. 字体栈（离线优先，零外部依赖）

🔴 **禁止引入 Google Fonts / 任何境外 CDN 字体**——本机离线打开概率高，且字体加载失败会退化为宋体导致版面崩。

```css
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Hiragino Sans GB", "Microsoft YaHei",
             "Source Han Sans SC", "Noto Sans SC", system-ui, sans-serif;
--font-serif: "Songti SC", "Source Han Serif SC", "Noto Serif SC", "SimSun", serif;
--font-mono: "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

**场景分工**：
- 正文/表格/看板 → `--font-sans`（黑体系）
- 判决书分析、长文阅读页 → `--font-serif`（衬线，阅读耐受度高）
- 案号/金额/代码 → `--font-mono`

> 插件原生推荐的 Fraunces / Outfit / Satoshi / Instrument Serif **一律不采用**：无中文覆盖、需外网、与法律场景调性不符。

## 5. 美学白名单

插件给了 11 种美学，法律场景**只留 4 种**：

| ✅ 允许 | 适用 | 理由 |
|---|---|---|
| **Dark & Premium** | 大屏、战情室、cockpit 首页 | 深色底 + 单一强调色，庄重、低干扰 |
| **Swiss Typography** | 判决书分析、严谨对照页 | 网格对齐、克制、黑白 + 单色强调 |
| **Editorial** | 长文阅读、类案卡片族 | 强层级 + 衬线标题，适合阅读 |
| **Bento Grid** | KPI 卡片墙、数据总览 | 模块化，信息密度可控 |

| ❌ 禁用 | 理由 |
|---|---|
| Neobrutalism（粗黑边+硬阴影） | 与法律专业感冲突，像设计作业 |
| Y2K / Cyber（霓虹+故障风） | 轻浮，客户场合不可用 |
| Kawaii / Memphis（圆润+彩色几何） | 完全不适用 |
| Glassmorphism（毛玻璃） | 透明度降低正文可读性，且渲染性能差 |
| Japanese Zen（大留白玄学） | 信息密度过低，与"一屏看全"目标相反 |

## 6. 反模式 10 条（中文法律场景改写）

> 每条都是「AI 生成痕迹」的强信号。**出现即记 1 项**，累计进 §7 评分。

**① 标题上方的小徽章**（"AI 赋能""全新升级""Beta"）
❌ `<span class="pill">✨ AI 驱动</span><h1>...</h1>`
✅ 直接把话说进标题：`<h1>6658 号二审答辩要点</h1>`

**② 通用英文无衬线字体**（Inter / Roboto / Arial / Open Sans / Poppins）
✅ 用 §4 中文栈

**③ 紫蓝渐变铺白底**（`from-purple-600 to-blue-500`）
❌ 装饰性紫→蓝渐变 + 白色背景（通用 SaaS 风）
✅ 深色底 + 单一强调色（`--red` 表对抗、`--purple` 表主强调）
⚪ **唯一豁免**：红蓝对抗态势类页面（战情室、推演图、对抗卡族）允许 `linear-gradient(90deg, var(--redbg), var(--bluebg))`——红=对方、蓝=我方，是案件核心心智模型，非装饰性；**前提：深色底，且禁止配白底**。

**④ 装饰性色块/模糊圆球**（`blur-3xl` + 半透明圆）
✅ 不加装饰；要分隔就用 `--line` 实线 1px

**⑤ 全场 `border-radius` 16px+ 的圆角</br>**（每张卡都像药丸）
✅ 卡片 12px 上限，表格/数据区用 6px 或直角——圆角本身传递"软"，法律内容要"定"

**⑥ 模板三段式布局**（居中 Hero → 三列特性 → 客户评价 → 紫色 CTA）
✅ 按信息关系排版：时间轴、要件对照矩阵、证据链图

**⑦ 空话文案**（"一站式赋能""全面提升效率""数字化转型"）
✅ 写具体动作与数字："上诉期 15 日自送达起算；四方送达日未核"

**⑧ 低对比深色模式**（灰 #6b7280 写正文、`#333` 套 `#1a1a1a`）
✅ 正文一律 `--tx`（15.68:1）

**⑨ 无意义动画**（按钮 pulse、图标 spin、整页 fade-in-up）
✅ 只保留 hover / focus 反馈，且 `@media (prefers-reduced-motion: reduce)` 下归零

**⑩ 通用图库照片**（握手、指屏幕、团队围坐笑）
✅ 不用图；或只用真实案件截图/图表

## 7. 三表评分门禁（交付前必跑）

### 表一 · 反模式（6 项，出现即 ❌）

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 无标题徽章/药丸标签 | ✅ / ❌ |
| 2 | 无通用英文字体（Inter/Roboto/Arial） | ✅ / ❌ |
| 3 | 无紫蓝渐变铺白底 | ✅ / ❌ |
| 4 | 无装饰性模糊色块 | ✅ / ❌ |
| 5 | 无全场大圆角（>12px 滥用） | ✅ / ❌ |
| 6 | 无模板三段式布局 + 空话文案 | ✅ / ❌ |

### 表二 · 设计原则（5 项）

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 层级清晰（h1/h2/h3 尺寸有明确落差） | ✅ / ⚠️ / ❌ |
| 2 | 对齐一致（同一区块同一基线/网格） | ✅ / ⚠️ / ❌ |
| 3 | 对比达标（正文 ≥4.5:1，大字 ≥3:1） | ✅ / ⚠️ / ❌ |
| 4 | 留白充足（区块 padding ≥16px，容器有 max-width） | ✅ / ⚠️ / ❌ |
| 5 | 色值全部走 token，无裸十六进制 | ✅ / ⚠️ / ❌ |

### 表三 · 可访问性（7 项）

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 语义标签齐全（header/main/nav/footer/section） | ✅ / ❌ |
| 2 | 仅一个 h1，标题层级不跳级 | ✅ / ❌ |
| 3 | 有可见 focus 态（禁 `outline:none` 无替代） | ✅ / ❌ |
| 4 | 图片有 alt（装饰图 `alt=""`） | ✅ / ❌ |
| 5 | 尊重 `prefers-reduced-motion` | ✅ / ❌ |

| 7 | 表格有 `<th>` + `scope`，非纯 div 拼表 | ✅ / ❌ |

### 结论三档

| 结论 | 条件 | 处置 |
|---|---|---|
| **PASS** | 18 项全 ✅ | 可交付 |
| **PASS-A** | ⚠️ ≤2 项，且表一无 ❌ | 交付时备注「已知轻微项：…」 |
| 🔴 **REJECT** | 表一任一 ❌ ／ 表二第3项 ❌ ／ 表三任一 ❌ | **不得交付**，修完重跑 |

## 8. 交付形态铁律

| # | 铁律 |
|---|---|
| 1 | **单文件自足**：CSS/JS 内联，双击可开，无构建、无 npm |
| 2 | **离线可开**：不得依赖任何境外 CDN（Tailwind CDN / Google Fonts / unpkg 一律禁） |
| 3 | 编码 UTF-8，`<html lang="zh-CN">` |
| 4 | 响应式：至少在 1366 / 1920 / 移动 375 三档不横向溢出 |
| 5 | 内容零占位：禁 `Lorem ipsum`、禁 `示例数据` 冒充真实（与数据完整性门禁一致） |
| 6 | 内部流转稿加 AI 水印；对外终稿不加（沿用既有规则） |
