# 一、总评

该提示词是一份质量中上的**通用代理词生成器**：把「搬运」（散记录→清单→提纲→成文）与「判断」（哪句是自认、哪个争点不值得回应）分开，方向正确，纪律条款（待核、不自认、不写情绪词）也扎实。

但它与你既有体系是**并联**关系，不是串联：

- 不读 `case-state.json`，重复索取系统已有的事实；
- 不产出可回写 `stage / gates / deadlines` 的字段；
- 自建「交件核对十项」替代 LTI（G6），绕过风控门禁；
- 人格是「执业十五年诉讼律师」（中立专家），不是「蓝队防御型参谋」；
- 组织轴是「庭审记录」，而代理词的裁判轴应是「法官六维度」。

一句话：**它按「写一份完整文书」设计，你的体系按「把防御漏洞清零」设计。二者 KPI 不同。**

# 二、定位错位 · 三处断线（CLM 基准）

庭后代理词在 CLM 中的正确位置：**③ 法律文书起草 / G2 文书门禁**（G2 判据＝蓝队+红队复核通过 + 证据目录齐备 + 质证齐备）。

| # | 断线 | 后果 | 接法 |
|---|---|---|---|
| 1 | 输入不看 case-state | 当事人/案号/阶段/我方位/争点须人工二次填写，且易与权威源冲突 | 首段强制 `Read case-state.json`，自动填充案件基本信息与 stance |
| 2 | 输出不回写 deadlines | 提示词内置「提交期限」却无处落地，d3 类期限台账脱节 | 产物末尾输出 JSON 片段：`{deadline:{name,due,type,level}}` 供回写 |
| 3 | 十项核对替代 LTI | G6 风控门禁被绕过，REJECT 机制失效 | 十项核对**降为 LTI 前的前置自查**，不得替代 `wrap_output(..., caller=...)` |

# 三、心智错位 · 它不是蓝队

| 维度 | 提示词 | 蓝队心智卡（blue_persona_v1） |
|---|---|---|
| 身份 | 执业十五年诉讼律师（中立专家） | 老强席位上的**防御型参谋** |
| 唯一 KPI | 产出完整八部分文书 | **让老强在庭上答得上来**（明载：不是写出漂亮文书） |
| 组织轴 | 庭审记录驱动 | **法官六维度驱动** |
| 质量判据 | 交件核对十项 | 四防御维度 + 反面案例库 112 条对照 |
| 迭代方式 | 一次成文 | **三轮冲击**（蓝→红批驳→蓝改→再批） |
| 强度档位 | 无 | D1–D4，默认 D2；6658 应 `procedure_heavy` |
| 弹药来源 | 用户提供的材料 | 卡库 `ruling.support / elements / negative_note`，**禁通用知识裸判** |
| 终检 | 无 | 法官三问必带尾段 |

四防御维度（与红队四攻击维度一一对应）：要件逐项举证 / 法条效力自查 / 证据三性自检 / 红队预攻击封堵。**提示词对后三项基本空白。**

# 四、两条硬冲突（原文实锤）

## 冲突一 · 自认句式正好命中禁用清单 🔴

- 提示词第七部分：「凡对我方不利的事实，只能以『不作认可』或『**即便成立亦不能证明……**』处理」
- 蓝队 SKILL.md：「答辩状/代理词中**禁用**以下假设性表述（写了＝替对方承认了前提）：`即便`、`即使`、`如法院认为`、`退一步讲`、`纵然`、`假定`」

即：提示词在教 AI 写全库中自认风险最高的句式，而它第八部分又要求「逐句列出可能构成自认的表述」——**自相矛盾**。

## 冲突二 · 三级编号与输出模板铁律冲突 🔴

- 提示词第六部分：强制「结构不超过三级：一、／（一）／1.」
- 蓝队 SKILL.md 代理词输出模板：「**禁止论文化写法**：无加粗元信息块、**无编号小标题**、无独立『法律依据』板块」

# 五、结构错位 · 三个部分是复盘资产，不是代理词素材

提示词八部分中，**第一（庭审留痕）、第二（法官发问清单）、第五（辩论复盘）**属训练/复盘资产，对应蓝队「调用记录 + 文书防御要点卡」，不属于 G2 交付物。

实证依据：反面案例库第 48 条「重复庭审内容·总类——完全复制庭审笔录，未补充新观点 → 法官认为『无实质参考价值』」。**把庭审记录搬进代理词生产线，正是该条的成因。**

> 建议拆分：技能 A「庭后复盘」（产调用记录 + 争点收敛表 + 防御要点卡）→ 技能 B「庭后代理词」（只吃 A 的产物，走 G2）。

# 七、6658 号案的三个前提须反转

1. **对手不是原告**：2026-10-28 核实，唯一上诉人是**黄茂姣（共同被告）**，丁戊祥/欧派店/我方均未上诉。二审我方为被上诉人，主对手是黄茂姣，丁戊祥为原审原告。提示词「对方书面材料：起诉状（答辩状）」的二元结构装不下三方。
2. **代理身份待核**：`case-state.json` 记 `counselRole: "代书（未正式代理）"`。若二审仍未正式委托，「代理词」文书名与自称（"本代理人认为"）不成立，应为当事人具名意见。**该字段建立后未见更新，须先核实。**
3. **审级错位**：提示词八部分按一审开庭设计；二审询问式审理可能无「法官当庭归纳焦点」环节，第二、五部分会空转。

# 八、改造建议（最小改动）

1. **头部加 CLM 接线块**：读 case-state → 填基本信息 → 产物回写 deadlines JSON。
2. **四防御维度替换十项核对**（或建立映射），并强制 D 档位 + `defense_profile` 头字段；6658 建议 D3 + procedure_heavy。
3. **自认句式替换**：删「即便成立亦不能证明」→ 改「该事实不属本案要件事实」「对方就该事实未提交任何证据」「××不成立，理由如下（直接否定＋己方要件论证）」。
4. **拆两个技能**：复盘归复盘，代理词归代理词。
