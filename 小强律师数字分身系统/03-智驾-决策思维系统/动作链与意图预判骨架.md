# 🔗 决策思维树 · 动作链与意图预判骨架

> 本文件补全 `03-智驾-决策思维系统` 的"空壳"短板：把老强的高频**组合动作链**显式建模，让分身在识别到某一节点时**主动预判下一步**，实现"想在你前头"。
> **机器可读 SSOT** = 同目录 `action_chains.yaml`（引擎加载源）；**触发引擎** = `intent_predict.py`（匹配链→识别节点→输出预判，只提议不自动执行）；**历史倾向挖掘** = `decision_miner.py`（--style 出决策风格画像、--tree 回流决策树 `decision_tree_from_dec.json`）。
> 联动：`01-用户偏好/USER-PROFILE.md`（决策风格源）、`_AI-Memory-Hub/03-决策档案/DEC-2026-*`（历史决策模式，注：真实位置在此非本目录）、`知识飞轮系统/06-沉淀/HOW-I-THINK`（灵魂层）、`~/.workbuddy/skills/decision-capture`（决策落卡）。
> 本目录其他组件见 `README-资产位置.md`（导航指针）。

## 一、动作链模型（Action Chain）
- **节点（Node）**：老强 recurrent 的一个操作单元（如"起草""LTI 校验""双目录同步"）。
- **链（Chain）**：有序节点序列，带**触发节点**与**终止条件**。
- **预判（Anticipation）**：系统识别到节点 N 完成 → 提示/准备节点 N+1。
- **授权纪律**：预判**只提议不自动执行**（除非老强明说"直接做"）—— 遵守 PREF-010 与"决策权留用户"。

## 二、已建模动作链（持续补全）
### 链-A｜法律文书交付链（命中 PREF-002 / PREF-004 / PREF-005）
`起草` → `读本地源核对一致性` → `LTI 五维 QC（REJECT=0）` → `docx 导出（修订标记+干净版双轨）` → `双目录同步（案件目录+桌面归档）` → `IMA/WorkBuddy 回传` → `工作日志` → `飞轮 LOG 追加` → `零残留验证` → `主动提议沉淀`
- **触发**：任何"写文书/起草 X"类请求。
- **预判点**：起草完成 → 主动问"是否过 LTI + 导出 docx"；导出完成 → 主动问"是否双目录同步 + 回传"。

### 链-B｜批量处置链（命中 PREF-003 / PREF-005）
`读源确认现状` → `dry-run 出拟变更清单` → `分批 ≤10` → `执行` → `确认幂等` → `双目录同步` → `日志`
- **触发**："批量改/挂载/重编号"类请求。
- **预判点**：dry-run 出 → 主动问"是否执行第一批"；每批完 → 主动报告幂等结果。

### 链-C｜系统升级/回写链（命中 2026-10-20 复盘实录）
`侦查（读 DB/文件）` → `出方案` → `老强批准` → `执行` → `回写四系统（运维手册/LTI/模拟法庭/CLM）` → `日志` → `轨迹卡`
- **触发**："升级 X / 改 Y 系统 / 回写"类请求。
- **预判点**：执行完 → 主动问"是否回写其余三系统 + 写日志"。

### 链-D｜复盘迭代链（命中 PREF-005）
`诊断` → `批准补丁` → `"请继续"` → `下一轮`
- **触发**：老强说"请继续 / 迭代推进"。
- **预判点**：补丁交付 → 主动问"是否进入下一轮 or 收尾六件套"。

### 链-E｜事故/排障收尾链（命中 PREF-005 / PREF-009）
`修复` → `主动提议沉淀成卡` → `HIR / 中枢 / LTI 分流` → `日志`
- **触发**：任何 bug 修复 / 隐患挖掘。
- **预判点**：修复完成 → **必须**主动问"要不要沉淀成卡"（PREF-005 强制，不机械化打扰纯查询类）。

## 三、预判机制实现约定
1. 每条链定义 `trigger_keywords` 与 `nodes`（机器可读版见同目录 `action_chains.yaml`，本文件为其叙述视图，禁双源分叉）；引擎 `intent_predict.py` 每轮匹配链 + 识别已完成节点 + 取下一节点作预判提议。
2. 预判提议格式：`[预判·链X] 检测到 N 已完成，建议下一步 Y（只提议，不自动执行）`。
3. 历史决策调用：若下一步涉及重大判断，用 `decision_miner.py --style` 拉老强历史倾向（A/B/C 频次 + 属性偏好），作为预判依据；历史 DEC 真实位置 = `_AI-Memory-Hub/03-决策档案/DEC-2026-*`；决策风格源 = `USER-PROFILE.md §三`。
4. 链可扩展：新增链走本文件模板（见第四节）并同步 `action_chains.yaml`，落卡进 `decision-capture` 同步 `HOW-I-THINK`。
