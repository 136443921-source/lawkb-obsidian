## 二、隔离铁律（务必遵守）

1. **单向归属**：凡涉及「律所分身 / 中小律所模板 / 组织级数字分身」的资料，**全部存入本库**；**不得**写入 `小强律师数字分身系统/` 或其子目录。
2. **互不混入**：律师个人的案件卷宗、个人偏好、个人记忆，**不得**存入本库。
3. **命名前缀**：本库文件用 `00-/01-/02-…` 序号前缀，保持与模板方案一致，便于克隆时对齐。
4. **隐私隔离**：当事人证件号 / 银行卡 / 手机号 / 证据原件**禁止入本库**，只提炼方法论与模板。
