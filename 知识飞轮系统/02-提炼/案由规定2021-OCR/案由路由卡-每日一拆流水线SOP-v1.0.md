## 2. 每日执行步骤（10 步，顺序执行）

1. **定位待拆**：读排期表，找下一个状态为 `⬜` 且**非**「不新建／复用」的行，记录其案由、卡型、正文位置。
2. **停止判定优先级（🔴 2026-09-26 修订·治「每日空转」）**：按序判定，**命中即停、不再往下走**——
   1. **① 无 ⬜ 且全批次已收官** → 停止并报告「当前批次已收官、AY 域已饱和（如 R-AY-001~321 全建），待老强立新批次 / 排期表出现新 ⬜ 行后方可续建」。**该情形直接跳过下册检测**，避免每日自动化空转一轮。
   2. **② 有 ⬜ 但源文件缺失** → 停止并报告「源文件缺失（OCR 无对应【释义】正文，或法〔2025〕227号三源不可达）」，**不编造 commentary、不凭记忆填编号**。
   3. **③ 有 ⬜ 且源文件可得** → 才检查 OCR 目录是否出现下册全文（文件名含「下册」）：到货则拆批次6+；未到货则报告「上册已拆完，待下册补购」，当日不建卡。
   > 🔴 **重要认知（2026-09-26 实证）**：「下册到货」**不等于**「有新批次可拆」。下册源到货后，其对应批次早已在既往运行中拆毕——批次8 侵权责任·第十部分（R-AY-131~166）、批次11 公司证券票据信托破产·第八部分（R-AY-271~308）、批次13 信用证独立保函·第九部分（R-AY-309~321）。**是否可拆的唯一判据，是排期表是否存在 `⬜` 行，而不是 OCR 目录里有没有下册文件。**
3. **实地取号**（`ls` 落盘目录）：AY 物理 max 为准，下一可用 = max+1，**一次连续取满本批**（单案由取 1 个；若本批含 L2 定性分野 + 配套 L1，连续取 2 个）。**禁止预分配号段**。
4. **读源书**：在 OCR 全文中定位该案由【释义】【管辖】【法律适用】【确定该案由应当注意的问题】段（用 Grep 查案由名＋行号）。
5. **版本校正四件套**（见 §4）：填 `code_2020`（书内 2020 版）、`code_2025`（联网核验）、`version_status`、`version_delta`。
6. **卡型判定**：按定性分野卡 SOP「立项三问」判 L1 单案由 / L2 定性分野；**重叠检查**——与已建卡重叠→**不建冗余卡**，改在排期表标「复用 R-AY-xxx」并报告，跳到下一张。
7. **写卡文件**：frontmatter（`rule_id`/`card_type`/`card_subtype`/`code_2020`/`code_2025`/`version_status`/`version_delta`/来源/关联）＋ 正文（释义/管辖/法律适用/定性边界/在办案件应用/翻车标本/关联）。
8. **更新编号规范**（见 §5）：frontmatter `version`+`updated` 升一档、`第二节` 白名单 AY 在库卡数、`第七节` AY 基线、`变更日志` 追加。**单条顺序 Edit，每处 Edit 后 Read 回查**。
9. **更新排期表**（见 §5）：总览表该行状态、批次表格行号段/状态。**同样单条顺序 Edit + Read 回查**。
10. **挂日志 + 校验**：向当日工作日志 append 一段；交付校验（§6）。

## 4. 版本校正四件套（🔴 严禁算术推定）

| 字段 | 填法 |
|---|---|
| `code_2020` | 书内 2020 版编号（杨万明上册依 2020 版 929 案由） |
| `code_2025` | **联网核验**：法〔2025〕227号全文（hncourt 镜像 / 北大法宝 / 华宇元典）逐条核对；2026-01-01 施行 |
| `version_status` | 编号变更（±N）／名称与结构是否变更 |
| `version_delta` | 漂移机理说明，**须注明核验源** |

> 🔴 **铁证（禁用 +N 推定）**：同属合同编，买卖 84→88（**+4**）、赠与 102→107（**+5**）、定金 111→112（**+1**）。各段偏移差异巨大（2025 版总案由 929→1055，+126，含新增「第六部分 数据/网络虚拟财产」致整体顺延）。**任何 2025 编号必须联网逐条核验，绝不许按 +4/+5 推算**。

## 6. 停止 / 报告条件

- **排期表无 `⬜`（不论下册到货与否）** → 停止，报告「当前批次已收官、AY 域已饱和（如 R-AY-001~321 全建），待老强立新批次 / 排期表出现新 `⬜` 行后方可续建」。⚠️ 判定细则与优先级见 **§2 步骤 2「停止判定优先级」**，本条与其保持一致，**不再以「下册是否到货」作为停止前置条件**（2026-09-26 修订：下册到货 ≠ 有新批次可拆）。
- 遇到「待拍板」情形（重叠争议需人工决策、卡型存疑）→ **停下报告，不擅自建冗余卡**。
- 联网核验 2025 编号失败（三源皆不可达）→ 停下报告，不凭记忆填编号。
