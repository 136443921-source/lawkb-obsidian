# 房屋代持协议（借名买房）范本与审查要点

> 原型：IMA 合同文书库《房屋代持协议（参考及注意事项）》（2026-08-01 新增，窗口内唯一新增项）。本协议系"实际出资人（甲方）出资、名义登记人（乙方）代持"的借名买房安排，本质是**债权性代持合意**，而非物权变动。以下按蓝队（防御/甲方视角）与红队（攻击/乙方及第三人视角）双线拆解。

## 一、协议骨架速览

| 模块 | 核心条款 | 实务意义 |
|---|---|---|
| 代持关系 | 乙方确认无出资、无所有权/收益权/处分权；甲方可随时要求过户 | 固定"借名"性质，切断乙方确权基础 |
| 甲方权利 | 占有/使用/收益（租金归甲）/处分（乙方配合出售抵押） | 收益权归属，防乙方截留租金 |
| 乙方义务 | 未经书面同意不得处分；配合过户不得设障 | 限制处分权，但**无公示对抗力** |
| 过户 | 自愿过户（随时）+ 强制过户（违约时诉讼，费用乙方承担） | 触发机制明确，但依赖乙方配合 |
| 违约 | 乙方擅自处分：按市场价__%违约金+全损赔偿；逾期过户：日__% | 违约金比例为空白，须填实 |
| 争议解决 | 房屋所在地法院管辖 | 与不动产专属管辖（《民诉法》第34条）一致 ✅ |

## 二、🔵 蓝队审查要点（甲方/实际出资人防御）

### 必补条款（范本留白或未覆盖）
1. **出资凭证链闭环**：首付款转账凭证、每月还贷转入乙方贷款账户的流水、税费票据——须作为附件（范本附件1-3）留存，这是未来确权/排除执行的核心证据。
2. **抵押反担保**：范本仅在"注意事项"提示"可约定乙方将房屋抵押给甲方"，但**正文无此条款**。应补入正文：乙方配合办理房屋抵押登记给甲方作为代持担保（《民法典》第394条），以对抗乙方债权人。
3. **违约金比例填实**：第六条两处 `__%` 必须量化（建议擅自处分 20%-30%、逾期过户 日万分之五），避免约定不明导致举证困难。
4. **公证条款**：范本建议"办理公证增强效力"，应升级为正文义务（双方配合公证），强化证据效力。

### 蓝队核心风险（不可靠协议单独消除）
- **对抗第三人能力弱**：代持协议仅约束甲乙双方，不产生不动产登记公示效力。乙方债权人申请执行房屋时，甲方只能提**案外人执行异议之诉**（《民诉法》第234条），但借名人通常不符《执行异议复议规定》第28条"无过错买受人"要件（非从开发商处买受、非支付全部价款），**难以排除执行**。
- **限购/政策房无效风险**：借名购买经济适用房、人才房等政策性保障房，因违反公共政策/强制性规定，代持协议**无效**（《民法典》第153条）；普通商品房规避限购，效力存地域分歧（京沪多认定无效，最高法倾向不当然无效）。
- **名义人信用雷**：贷款房代持，甲方逾期还贷直接损乙方征信；乙方离婚/继承/负债均可能导致房屋被分割或执行。

## 三、🔴 红队攻击点（乙方/名义登记人及第三人视角）

1. **善意取得突破**：乙方擅自将房屋出售/抵押给善意第三人，第三人依《民法典》第311条善意取得物权，甲方只能向乙方索赔，**无法追回房屋**。此点范本靠"不得擅自处分+违约金"无法实质阻止。
2. **乙方债权人执行**：如前所述，乙方对外负债，房屋作为登记在乙方名下的财产可被强制执行，甲方代持协议不能对抗。
3. **甲方违约反噬乙方**：甲方逾期还贷→乙方征信受损；甲方隐瞒限购导致代持无效→法律后果由甲方自担（但乙方仍卷入诉讼）。

## 四、条款级修改建议（可直接落地）

- 第四条第2款"强制过户"：补充"甲方可不经诉讼直接凭本协议+公证文书申请强制执行公证"路径（若做赋强公证）。
- 第三条第2款：将"注意事项"中的抵押反担保、公证上升为正文义务。
- 第九条第2款"乙方确认理解风险"：建议增加乙方配偶同意代持、放弃主张房屋权益的书面声明，防离婚财产分割争议。
- 争议解决：保留"房屋所在地法院"，与专属管辖一致，无需改。

## 五、关联规则

- 裁判规则 [[R-HT-025]]：借名买房代持协议有效但仅具债权效力，实际出资人不得对抗名义登记人之债权人强制执行；规避政策房代持存在无效风险。
