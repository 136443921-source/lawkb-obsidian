# 民事纠纷私了和解协议书（标准文本）— 蒸馏笔记

> 来源：法喵人间（湖南），2026-08-07 19:18。原始形态为通用「一次性赔偿/支付」和解协议模板，覆盖交通事故、货款合同、人身损害侵权等纠纷的私下和解场景。
> 本文从**蓝队（付款方/甲方风险防控）**与**红队（收款方/乙方权益回收）**双视角拆解，提炼可落地执业动作。

## 一、协议骨架（四段式）

| 模块 | 核心要素 |
|------|----------|
| 一、赔偿/支付金额及方式 | 一次性总额（大小写）+ 含项列举（医疗费/误工/护理/交通/后续治疗/财产损/精神损害抚慰金 或 货款本金/违约金/利息）+ 支付方式与收款账户 |
| 二、双方权利义务 | 甲方付清后乙方「一切损失已全部受偿、不得再主张」+ 乙方出具谅解书/撤诉/撤诉配合义务 + 互不追究 |
| 三、违约责任 | 甲方逾期按日____%违约金；乙方反悔须**全额退还+赔偿甲方损失** |
| 四、其他约定 | 真实意思表示声明（无欺诈胁迫重大误解）+ 一式两份签字捺印生效 |
| 附：使用提示（5 条） | 一次性了结条款为核心 / 大小写标注 / 人身伤害待伤情稳定 / 保留付款凭证 / 复杂金额找律师审 |

## 二、蓝队视角（甲方：付款了结方）风险清单

1. **一次性了结条款必须写满赔偿项目**——否则乙方收钱后以「还有漏掉的损失」为由再诉，无条款兜底即被动。模板已列举但未穷尽，应结合个案增列。
2. **人身伤害类务必延迟签署节点**——应在伤情稳定、治疗基本终结后签。协议仅了结「签约前已发生」费用，后续治疗费超预期属新发生费用，原协议挡不住（除非明示概括放弃后续一切权利，但概括放弃后续治疗费条款可能因显失公平被调整，需审慎）。
3. **付款凭证闭环**——现金支付当场收收据；转账留银行流水/截图。无凭证 = 付款事实举证不能。
4. **违约金比例填实不空置**——模板留白____%需填定，否则逾期责任无计算依据。
5. **乙方撤案/谅解配合义务要写死时限**——「____日内出具谅解书/撤回起诉」须填期，避免付款后乙方拖延。

## 三、红队视角（乙方：受偿方）攻防要点

1. **赔偿项目与金额须逐项核足**——医疗费含后续治疗预估、误工费按实际误工天数×收入、伤残含残疾赔偿金与精神损害抚慰金。模板「包括但不限于」表述对乙方有利（兜底），但建议显名列项以防甲方主张「已含」。
2. **付款先行，配合在后**——乙方出具谅解书/撤诉应以「收到全部款项」为前置条件，不可先撤后付。
3. **甲方逾期违约金要可量化**——日____%留白须填，过低则违约成本低；可主张按 LPR 四倍或约定合理比例。
4. **反悔退还条款双向对称**——乙方反悔退全款+赔损失，甲方亦应受同等约束（甲方若伪造损失诱导和解，乙方保留撤销权，受欺诈可诉请撤销）。

## 四、执业动作清单（可直接套用）

- [ ] 签约前：厘清纠纷性质（侵权/合同）、核算法定赔偿总额，避免「私了价」显著低于法定额致显失公平争议。
- [ ] 人身损害：调取病历、医疗票据、伤残鉴定（如有），待治疗终结/鉴定后定稿金额。
- [ ] 模板填空：违约金比例、付款期限、收款账户、撤案配合时限**四项必填**。
- [ ] 金额大小写同列；现金支付附收据、转账留痕。
- [ ] 重大/复杂金额（建议 ≥ 争议额 10 万或涉伤残）：签约前律师审一遍，成本远低于事后撤销之诉。
- [ ] 归档：协议 + 付款凭证 + 谅解书/撤诉裁定，三件套一并留存。

## 五、关联与延伸

- 同类文书：交通事故赔偿协议书、家庭财产分家协议（均见本期摄入）。
- 法条锚点：《民法典》第 143 条（民事法律行为有效要件）、第 151 条（显失公平可撤销）、第 577 条（违约责任）、第 1187 条（损害赔偿一次性给付）。
- 程序衔接：涉刑案件（如交通肇事）私了不影响刑事责任，仅影响量刑（谅解书），不可误认为「赔了就不追究刑责」。
