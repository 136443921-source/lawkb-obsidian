# 建设工程招标代理合同范本及写作要点

> 来源：高云合同（2026-08-11）｜回补 w_2026-08-12 漏窗｜关联 [[R-HT-050]]
> 一句话价值：**招标代理合同是"操作规则+风险分配机制"**，将《招标投标法》《民法典》转化为流程控制点，防"程序空转"与"越位代理"。

## 一、合同定位

- 招标环节涉及发包人/投标人/评标专家/监管部门/最终使用者多方，代理机构是"程序守护者"。
- 需将抽象法规转化为：代理权限、时间节点、文件审核责任、异议处理程序。
- 常见争议根因：代理范围含糊、费用结算节点不清、招标失败责任划分缺失。

## 二、范本结构（17条）

合同目的 / 工程概况 / 代理内容 / 代理报酬 / 代理期限 / 双方权利义务（6.1委托人-6.2受托人）/ 其他费用 / 款项支付 / 声明承诺 / 索赔 / 变更或解除 / 终止 / 转包分包 / 不可抗力 / 违约责任 / 争议解决 / 附则

## 三、蓝队（防御审查·写审改要点）

| 条款 | 风险点 | 修改建议 |
|---|---|---|
| 代理内容 | 范围不清→"越位代理"或"漏项" | 明确是否含工程量清单编制、暂估价项目后续招标；用"包括但不限于"防遗漏 |
| 代理报酬 | 支付节点与质量脱钩 | 与"代理事项完毕+验收合格"挂钩；约定逾期付款违约金（日万分之三） |
| 代理期限 | 无上限→无限拖延 | 约定"自签订之日起至招投标活动结束，不超过X个月" |
| 索赔程序 | 无时限→证据灭失 | 事件后7日内发索赔报告、对方7日内答复、逾期视为认可（10.2条已内置，审查时勿删） |
| 转包分包 | 代理机构转包→质量失控 | 未经书面同意不得转包/分包，违约按合同总金额【】%赔偿（13.1） |
| 受托人保密 | 泄标风险 | 不得泄露招标/评标/定标过程依法保密内容，合同终止后仍负保密义务（6.2(13)） |
| 违约责任 | 责任无上限 | 受托人赔偿上限=代理报酬金额（扣除税金）（15.2）——受托方谈判要点 |

## 四、红队（攻击分析·强弱主体博弈）

- **强势甲方（委托人）视角**：违约责任严格化、代理报酬与质量挂钩、争议解决选甲方所在地、有权更换不称职代理人员、终止权+追偿权（6.1(7)）。
- **强势乙方（受托人）视角**：报酬及时支付（5日内+逾期违约金）、拒绝违法要求权（6.2(4)）、知识产权归受托人（6.2(6)）、赔偿上限锁定、代理期限不少于3个月、拒绝分包需书面同意。
- **博弈策略**：招标代理费"由中标人支付"条款（8.2）风险大——若招标失败则无人付款，甲方宜坚持"委托人支付+中标人支付为备位"。

## 五、执业提示

- 招标代理合同常与工程总承包/监理/施工合同条款联动，代理授权不清会导致后续数份合同基础数据失效。
- 电子招标环境下，数据电文法律效力需通过合同条款固化。
- 不得接受与本工程招标范围相关的投标咨询业务（6.2(10)）——利益冲突红线。
