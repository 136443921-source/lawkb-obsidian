# R-HT-336 设备买卖合同（蓝红双视角）

> 源：IMA·合同文书AI助手「《设备买卖合同》有哪些要注意的？附模板」（文件AI，2026-04-24）。`source_verified:true / ima_true:true`；法条正文待回源（`statute_text_pending:true`）。

## 一、蓝队（买受人 / 甲方起草视角）
- **"全新"界定**（第一条7）：主要部件生产日期交货前6个月内；运行时间0小时；外观内部无使用/磨损/维修痕迹——防翻新机样机。
- **付款分期**：30%首付款（发票后）、50%出厂款（签《出厂确认单》+发票）、15%验收款、5%质保金（2年）（第三条表）。
- **发票前置**：所有付款以收到合规增值税专用发票为前提；迟延开票甲方付款顺延不违约（第三条重要约定）。
- **风险转移**：运抵交货地点书面签收前毁损灭失由出卖人承担（第四条3）。
- **逾期交货**：超15日可解除+退全款+20%违约金；不解除则日万分之三（第四条4）。
- **验收**：安装调试后5工作日；空载8h+负载4h无故障（第五条）。
- **质保**：验收合格起2年；3h响应、24h到场（第六条2）；代位维修费可从质保金扣（第六条3）。
- **非全新违约**：15日内更换+10%违约金；拒不更换解除+退全款+30%违约金（第七条1）。
- **IP保证**：不侵权，侵权全赔（含诉讼费/律师费/经营损失）（第八条1）。

## 二、红队（出卖人 / 乙方抗辩视角）
- **付款能力风险**：买方收货后拖尾款/质保金。
- **验收拖延**：以瑕疵为由不签验收证明，致验收款/质保金无法收。
- **出厂确认拖延**：买方故意不确认《出厂确认单》致无法回款。
- **非全新严苛**：微小瑕疵（运输磨损）也可能被主张非全新→更换/违约金/解除。
- **代位维修失控**：买方自委第三方，费用不受控。
- **质保金回收难**：期满买方以质量问题扣款，卖方需举证无问题。

## 三、关联在办业务
- **至善公司设备/资产交易、含灵生物生产类采购**：大型设备买卖验收与付款节点条款参照。
- **娄山华庭房产租房合同**：买卖与租赁风险转移、验收条款对照。
