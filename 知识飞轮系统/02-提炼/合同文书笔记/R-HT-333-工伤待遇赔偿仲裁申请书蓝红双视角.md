# R-HT-333 工伤待遇赔偿仲裁申请书（蓝红双视角）

> 源：IMA·合同文书AI助手「工伤待遇赔偿劳动人事争议仲裁申请书（参考版本）」（苏成生律师，2026-06-14）。`source_verified:true / ima_true:true`；法条正文待回源（`statute_text_pending:true`）。

## 一、蓝队（申请人 / 工伤职工代理视角）
- **前提证据链**：劳动关系证明（工资记录/考勤/工牌）→《认定工伤决定书》→《劳动能力鉴定结论书》（本案七级）。
- **未参保全赔规则**：应当参保而未参保的，由用人单位按工伤保险待遇项目和标准支付费用（工伤保险条例62条）。
- **计算基数**：本人工资无法确定的，按统筹地区上年度职工月平均工资计（如吉林省办法50条）——本案以月社平工资为基数。
- **七级伤残待遇结构**：一次性伤残补助金13个月本人工资（37条）+ 一次性工伤医疗补助金（省级办法）+ 一次性伤残就业补助金（省级办法）+ 停工留薪期工资（33条）+ 医疗/护理/住院伙食补助。
- **证据目录**：身份证、认定工伤决定书、鉴定结论书、企业信用报告、住院病历、医疗费发票、护工发票、诊断证明。

## 二、红队（被申请人 / 用人单位抗辩视角）
- **劳动关系否认**：主张劳务/承揽而非劳动关系 → 切断工伤前提（需工资发放记录、考勤反证）。
- **工伤认定异议**：对《认定工伤决定书》应在法定期限内复议/诉讼，逾期则生效。
- **本人工资举证**：单位掌握工资支付记录，劳动者可主张由单位举证；单位不能举的，按社平工资对劳动者有利。
- **停工留薪期合理性**：多处伤情可主张13个月，但需诊断/医嘱支撑，否则可抗辩缩短。
- **已付费用抵扣**：单位已付部分医疗/护理费用，主张从总额中扣减。
- **时效抗辩**：工伤认定与仲裁申请须在法定时限内。

## 三、关联在办业务
- **韩杰医生医疗事故罪再审辩护**：医疗损害/人身损害赔偿结构参照。
- **航合物流 2026-09-01 事故**：贵C09782D 货车致死事件，死者/伤者工伤待遇与雇主赔偿责任衔接。
