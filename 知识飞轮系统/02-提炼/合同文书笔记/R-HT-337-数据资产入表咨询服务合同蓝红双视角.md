# R-HT-337 数据资产入表咨询服务合同（蓝红双视角）

> 源：IMA·合同文书AI助手「《数据资产入表咨询服务合同》范本」（法律教练，2026-04-23）。`source_verified:true / ima_true:true`；法条正文待回源（`statute_text_pending:true`）。

## 一、蓝队（委托人 / 甲方起草视角）
- **服务内容四阶段**：资产化潜力梳理→登记与权属确认申报→质量评价与价值评估→入表指导（第二/三条）。
- **付款**：30%预付款（乙方开6%增值税发票后15工作日）+70%终验款（交付方案完成终验后15工作日）（第三条）。
- **发票前置**：乙方未提供发票甲方可推迟付款不违约（第三条28）。
- **保密**：长期有效；泄密承担法律及经济赔偿（第五条）。
- **技术成果归属**：乙方完成的软件著作权归甲方或指定第三方（第七条）。
- **IP保证**：乙方自主拥有或获合法授权，侵权由乙方处理并担全责（第七条48）。
- **验收**：未通过5日内改正；重新交付仍不通过甲方可解除+退已付款+赔偿损失（第八条）。
- **风险责任**：乙方现有水平难以克服的技术困难致失败，责任由乙方承担（除非甲方豁免）（第九条1）。
- **出口管制**：遵守中美欧贸易管制，冲突时中国法优先（第十二条4）。

## 二、红队（受托人 / 乙方抗辩视角）
- **验收主观风险**："达到甲方预期效果"标准模糊，甲方可借机不验收。
- **付款挂钩客户验收**：甲方客户迟延验收/付款，甲方可同等迟延付款且不违约（第五条33）——乙方现金流受压。
- **风险责任严苛**：技术困难失败乙方全担（除非甲方豁免）。
- **违约金空白**：延迟每日按"【】"未填，须填具体比例防争议。

## 三、关联在办业务
- **厚德基金会数字化运营 / 慈善组织数据合规**：数据资产梳理与合规服务合同范式。
- **至善公司股权转让**：技术成果归属与IP保证条款参照。
