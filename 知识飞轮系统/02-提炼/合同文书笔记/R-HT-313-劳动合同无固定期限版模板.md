# 劳动合同（无固定期限版）参考模版｜附使用说明+风险提示

## 一、蓝队视角（防御审查 / 风控）
- **先判"应当订立"情形**：连续工作满十年、连续二次固定期限合同后续订、初次实行劳动合同制度/国企改制满十年且距退休不足十年——三种法定情形下劳动者提出或同意续订的，单位必须订无固定期限合同（劳动合同法第14条第二款）。
- **"连续工作满十年"起算**：自用工之日起算，含劳动合同法施行前年限（实施条例第9条）；非因本人原因被安排到新单位的，原单位年限合并计算（第10条）。
- **劳动者主动选固定期限须留证据**：法定情形下劳动者提出订固定期限的，单位可订固定期限，但应由劳动者出具书面申请/声明并留存，避免事后被追索二倍工资。
- **二倍工资高风险点**：应订未订无固定期限合同的，单位自应当订立之日起按月付二倍工资（第82条第二款）；用工满一年未签任何书面合同，直接视为已订无固定期限合同并应立即补订。
- **解除前核查第42条禁止情形**：医疗期内、三期女职工、连续工作满十五年且距退休不足五年等，不得依第40/41条解除；规章制度须履行民主程序（第4条）方可作为解除依据。

## 二、红队视角（攻击分析 / 抗辩）
- **拒订二倍工资抗辩**：连续满十年或连续二次固定期限后续订时，劳动者提出/同意续订而单位拒订无固定期限合同的，自应订之日起按月付二倍工资（第14条第二款、第82条第二款）——劳动者可主张。
- **规避工龄无效**：通过关联单位轮换签约、强迫辞职重签切断工龄的，工龄仍可能合并计算（实施条例第10条）；规避行为还可能被认定违法解除。
- **"自愿放弃"条款无效**：约定"自愿放弃签订无固定期限合同/自愿放弃社保"因违反强制性规定无效，劳动者事后仍可主张订立及二倍工资，单位不能以"曾经自愿"抗辩。
- **违法解除二倍赔偿金**：违法解除按经济补偿标准二倍付赔偿金（第48/87条）；老员工连续年限长，赔偿金基数与年限均高，解除前务必逐项核查事实证据。
- **违约金仅限法定情形**：除服务期（第22条）、竞业限制（第23条）外不得约定劳动者承担违约金（第25条）——"提前离职赔N个月工资"条款无效。

## 三、裁判规则 / 实务要点抽取
- [[R-HT-313]] 应当订立无固定期限劳动合同而拒订的二倍工资规则（劳动合同法第14条、第82条第二款）。

## 四、与本案/业务关联
- 关联小强律师劳动用工合规/企业顾问业务：审查劳动合同须先排查是否触发强制无固定期限订立，规范二倍工资与违法解除风险；慈善组织用工亦同此规则。
