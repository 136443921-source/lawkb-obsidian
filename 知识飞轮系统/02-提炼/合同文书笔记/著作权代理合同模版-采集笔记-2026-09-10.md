# 著作权代理合同模版 · 采集笔记（2026-09-10）

> 来源：合同文书AI助手(IMA) · 公众号「跃马扬鞭的查理」《著作权代理合同模版》，2026-09-03

## 一、正文结构（十六章）
委托代理作品与权属 → 委托事项 → 代理权限与授权方式 → 期限地域 → 转委托 → 代理费佣金 → 收益收取结算转付 → 乙方义务 → 甲方义务 → 对外合同签订 → 侵权监测维权 → 变更解除 → 违约责任 → 争议解决 → 其他 → 通知送达。

## 二、蒸馏要点
1. **代理≠卖版权**：著作权始终留委托人，代理人仅代谈判/收付/维权（区别于许可、转让、集体管理）。
2. **授权书具体化**（民法典165）：避免"全权代理"概括授权，越笼统越权风险越大。
3. **越权/表见代理**（172）：越权签约相对人有理由相信有代理权则行为有效，委托人被直接约束。
4. **任意解除权双刃**（933）：有偿委托解除方赔直接损失+可得利益。
5. **代收款项挪用高发**（927）：须写死转付期限、对账周期、逾期违约金。
6. **维权收益分配**（著作权法54）：先扣成本还是先分成结果差异巨大。
