# 交通事故赔偿协议书（参考）— 蒸馏笔记

> 来源：知法用法小分享（江苏），2026-08-08 12:53。通用交通事故私下赔偿协议模板，七段式结构，含 8 项法定赔偿项目列举与保险理赔配合条款。
> 拆解**蓝队（赔偿方/甲方/常驾车险方）**与**红队（受害方/乙方）**双视角，并标注与上一期《民事纠纷私了和解协议书》的结构差异。

## 一、协议骨架（七段式 vs 私了协议四段式）

| 模块 | 要点 |
|------|------|
| 一、事故责任认定 | 锚定《交通事故认定书》的责任比例（甲方____%/乙方____%），赔偿前提 |
| 二、赔偿项目及金额 | **8 项法定列举**：医疗/误工/护理/交通/住院伙食补助/营养/残疾赔偿金(如有)/精神损害抚慰金(如有)，末行合计 [ ] |
| 三、支付方式及时间 | 指定银行账户 + 一次性付款截止日 [ ] |
| 四、双方权利义务 | 乙方**配合甲方保险理赔材料**义务（本模板特有）+ 甲方付清后一次性了结 + 诚信履行 |
| 五、违约责任 | 甲方逾期日____%违约金；乙方不配合理赔致甲方损失的赔偿责任；其他违约赔偿 |
| 六、争议解决 | **事故发生地人民法院**管辖（专属连接点） |
| 七、其他条款 | 签字生效 + 一式两份 |

## 二、蓝队视角（甲方：赔偿/被保险人）要点

1. **责任比例必填且须与认定书一致**——模板留白____%，若填「全责」而认定书为「主次责」，协议赔偿基数失真，保险拒赔风险上升。
2. **保险理赔配合条款是甲方核心护城河**——明确乙方须在____日内提供理赔材料，否则甲方可主张损失赔偿。实务中乙方不配合理赔 = 甲方垫资后追偿困难。
3. **8 项赔偿「如有」项要显式勾选/划除**——残疾赔偿金、精神损害抚慰金标注「如有」，签约时应据伤残鉴定/伤情确定是否计列，避免空白被填高额。
4. **违约金比例与付款期限填实**——逾期日____%留白，建议填定可举证的合理比例。
5. **一次性了结 + 不主张任何权利**——与私了协议同效，但本模板更强调「赔偿事宜」一次性了结，建议加「含后续治疗费」明示以彻底封口。

## 三、红队视角（乙方：受害方）攻防

1. **赔偿项目不可漏列**——8 项均应据实填额；误工费按误工天数×收入、护理费按护理期×标准、残疾赔偿金按伤残等级×受诉法院地上一年度城镇居民人均可支配收入×20 年（60 岁以上递减）。
2. **理赔配合义务设边界**——配合「办理保险理赔所需材料」合理，但不等于放弃对甲方的直接索赔；甲方怠于向保险公司索赔时，乙方可代位或直接诉甲方。
3. **付款先于一切配合**——乙方提供理赔材料应以甲方按期付款为条件，防「材料交了钱没到」。
4. **管辖条款对乙方中性偏利**——事故发生地法院通常即侵权行为地，便于乙方就近诉讼。

## 四、双模板结构差异速记

| 维度 | 私了和解协议书（法喵人间） | 交通事故赔偿协议书（知法用法） |
|------|--------------------------|------------------------------|
| 适用 | 通用（交通/合同/侵权） | 专交通事故 |
| 责任基础 | 无单列 | 单列《事故认定书》责任比例 |
| 赔偿项 | 概括列举 | 8 项法定细化 |
| 保险配合 | 无 | 乙方配合理赔义务 |
| 管辖 | 无约定 | 事故发生地法院 |

## 五、执业动作清单

- [ ] 先固化责任：调取《交通事故认定书》，填准责任比例。
- [ ] 核算 8 项赔偿额，伤残情形同步做伤残鉴定再定稿。
- [ ] 甲方视角：保险配合条款 + 一次性了结（含后续治疗）双保险；乙方视角：项目核足、付款先行。
- [ ] 违约金比例、付款日、收款账户三项必填。
- [ ] 归档：协议 + 认定书 + 医疗票据 + 付款凭证 +（伤残）鉴定报告。

## 六、法条锚点

- 《民法典》第 1179 条（人身损害赔偿范围）、第 1213 条（交通事故责任承担顺序：保险→侵权人）、第 1187 条（一次性给付）。
- 《道路交通安全法》第 76 条（赔偿责任划分）。
- 管辖：《民事诉讼法》第 29 条（侵权纠纷由侵权行为地或被告住所地法院管辖）。
