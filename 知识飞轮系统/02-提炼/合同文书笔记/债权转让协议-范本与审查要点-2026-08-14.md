# 债权转让协议-范本与审查要点（蓝红双视角）

> 原文：《合同范本 | 债权转让协议模板（详细版）》（扬律讼典，2026-07-20）

## 协议骨架（16条+附件一）
定义 → 标的资产转让及通知（5日内发债权转让通知）→ 转让价款及支付（预付款+分期+资金成本年化）→ 资产交割（15日内，50%款项后协助抵押权变更登记）→ 税费负担 → 违约责任 → 不可抗力（法律政策变化不视为不可抗力）→ 变更 → 解除（含返还价款+年化6%资金成本）→ 权利义务转让 → 声明保证 → 保密 → 争议解决（签署地法院）→ 通知联络 → 其他 → 生效

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 转让标的不明确 | 附件一《债权资产明细表》决定标的范围，正文仅引用 | 强制核对附件与台账一致，明细表需列明每笔债权本金/利息/违约金/担保权益 |
| 债权转让通知缺失 | 2.3条约定甲方签署后5日内通知丙方及担保人 | 明确通知方式（书面+EMS留痕）、通知义务完成时点及未通知的后果；《民法典》546条通知债务人才对其生效 |
| 6条倾斜性条款 | 乙方未按时足额付款→协议自动解除且乙方不担责 | 对出让方不利，应改为"按日万分之X支付违约金"或保留解除权但承担违约责任 |
| 资产瑕疵披露义务 | 11.2甲方保证披露真实完整，4.6乙方确认知悉瑕疵 | 增加"甲方未披露重大瑕疵的，乙方有权解除并索赔"的对等保护 |
| 解除后资金成本 | 9.4解除后甲方返还价款+年化6%资金成本 | 核对6%是否合理，是否应随LPR调整 |
| 管辖 | 13.2签署地法院 | 评估签署地对我方是否有利，可争取"被告住所地/主要财产所在地" |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **通知瑕疵抗辩**：若甲方未按2.3条通知债务人，债务人对甲方清偿仍有效（《民法典》546条），受让人可据此主张转让价款扣减或解除
2. **附件缺失攻击**：附件一未随附或与台账不符时，可主张转让标的不特定、协议未成立/未生效
3. **权利瑕疵攻击**：标的债权存在已清偿、已豁免、已过诉讼时效情形而未披露的，受让人可主张欺诈撤销或索赔
4. **放弃撤销权条款**：11.1.3不可撤销放弃重大误解/显失公平撤销权——可论证该条款为格式条款排除主要权利而无效（《民法典》497条）
5. **债务人抗辩承继**：债务人可援引对原债权人（甲方）的抗辩对抗受让人（《民法典》548条），含抵销权
6. **诉讼时效博弈**：已过时效债权转让后，受让人起诉的，债务人可主张时效抗辩

## 裁判规则
- R-HT-055：债权转让未通知债务人的，对债务人不发生效力，债务人向原债权人清偿的债务消灭；债权转让通知不得撤销，但经受让人同意的除外
- R-HT-056：债权受让人承继债权的同时承继债权上的瑕疵与从权利，债务人可向受让人主张其对让与人的抗辩（含抵销权）

## 实务清单（代理要点）
- 受让方尽调三查：查债权凭证/查时效/查担保登记
- 交割时点三件套：债权转让通知+资产文件清单+权利主体变更（诉讼执行程序变更）
- 附件管理：附件一+附件文件与正文同等效力，逐页签章
