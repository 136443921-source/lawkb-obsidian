# 工程类合同法律审核八个方面17个审核要点（蓝红双视角）

> 源：IMA「合同文书AI助手」公众号文章《工程类合同法律审核八个方面的17个审核要点》（凉水河畔1，2025-10-12）。A0.2 漏窗回补（2026-11-11~11-16）选入，双源核验未摄入（状态文件0/本地全库0）。全文含八大部分、17 个审核要点，逐点附法条依据。

## 审核要点全景（八方面·17点）

| 方面 | 要点编号 | 核心审查对象 |
|---|---|---|
| 一、合同效力与主体资格 | 1-2 | 施工资质、必须招标程序 |
| 二、工程范围与承包方式 | 3-4 | 承包范围界定、承包方式 |
| 三、工期条款 | 5-6 | 开竣工日期、工期顺延 |
| 四、价款与支付条款 | 7-9 | 计价方式、进度款、结算 |
| 五、工程质量与验收 | 10-12 | 质量标准、隐蔽验收、竣工验收 |
| 六、质量保修条款 | 13 | 保修范围、最低保修期 |
| 七、违约责任条款 | 14-15、17 | 工期违约、付款违约、签证 |
| 八、争议解决与其他 | 16 | 争议方式、管辖 |

## 🔵 蓝队视角（代理发包人/建设方 · 防御与管控）

- **主体与效力（要点1-2）**：签约前必查承包人资质证书与等级（《建筑法》第26条）；无资质/超越资质签约将导致合同无效（建工解释一第1条）。属必须招标项目的，须核招标程序合规，防程序瑕疵致无效。
- **范围锁定（要点3）**：通过工程量清单、施工图纸将承包范围具体化，**禁用"等""包括但不限于"模糊词**，防"无底洞"增量索赔。
- **工期管理（要点5-6）**：明确开工以开工通知为准；把工期顺延申请设为"须书面申报+时限"，并约定发包方逾期不答复**不当然视为认可**（红队会争取"视为认可"，蓝队须警惕该条款反噬）。
- **结算控制（要点9）**：对"逾期不答复视为认可送审结算价"（建工解释一第21条）**保持警惕**——这是承包人有力武器，发包人应设置合理审核期并在期内书面答复，避免默认认可虚高结算。
- **签证权限（要点17）**：约定有效签证须经发包人书面确认并加盖公章，明确签字权限人，防现场人员越权签证形成费用。
- **保修（要点13）**：核对保修期不低于法定最低（防水5年、电气管线/给排水/装修2年、地基主体为设计合理使用年限——《建设工程质量管理条例》第40条），明确质保金返还时间/方式/条件。

## 🔴 红队视角（代理承包人/施工方 · 进攻与维权）

- **资质与效力（要点1-2）**：如自身资质存在瑕疵，注意合同无效但工程合格仍可参照约定折价补偿（民法典793条，本卡延伸），未必丧失工程款请求权。
- **工期顺延（要点6、8）**：争取约定"发包方逾期不答复视为认可工期顺延"；任何顺延事由（设计变更、工程量增加、不可抗力、发包人原因）严格按程序时限书面报审——民法典803条支持发包人未提供场地/资金时承包人顺延并索赔停工窝工损失。
- **结算利器（要点9）**：**务必备"逾期答复视为认可"条款**（建工解释一第21条），并在竣工后按期提交结算文件、留存送达证据，为后续"默认认可"打基础。
- **价款调整（要点7）**：可调价格须明确调整方法；固定价格须锁死风险范围，避免材料涨价吞噬利润。
- **违约金（要点14-15）**：约定违约金计算方法；注意约定过高可被法院/仲裁适当减少（民法典585条），宜设与实际损失相称的计算式。
- **争议管辖（要点16）**：建设工程施工合同纠纷适用**专属管辖，由工程所在地法院管辖**（民诉法第34条 + 民诉法解释第28条）；仲裁须写全称。

## 核心风险防范六条（原文提炼）

1. **锁死工程范围**：附件具体化，禁用模糊词。
2. **紧盯付款与结算**：付款挂钩形象进度；争取/防范"逾期视为认可"；保留催告证据。
3. **工期签证是生命线**：顺延/增费事件严格按时限办书面签证。
4. **争议解决切实可行**：施工合同纠纷专属管辖在工程所在地。
5. **文件构成与解释顺序明确**：协议书、专用条款、图纸、清单优先级写清。
6. **保修期与质保金不可忽略**：不低于法定最低，返还条件明确。

## 关联法条（本文引用）

- 《建筑法》第26条（资质等级承揽）
- 建工解释一第1条（无资质合同无效）、第21条（逾期答复视为认可结算）
- 民法典第790条（招投标公开公平公正）、第795条（施工合同内容）、第803条（发包人未提供条件承包人顺延索赔）、第585条（违约金调整）
- 《建设工程质量管理条例》第40条（最低保修期）
- 民诉法第34条 + 民诉法解释第28条（建设工程施工合同纠纷专属管辖）
