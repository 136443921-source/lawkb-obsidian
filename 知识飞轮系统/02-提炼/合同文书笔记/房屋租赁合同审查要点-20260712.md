# 房屋租赁合同审查要点（参考模板提炼）

> 来源：知法用法小分享《房屋租赁合同（参考及操作建议）》2026-07-12。审查要点提炼，非可直接套用范本。

## 一、合同审查四要件视角
1. **主体与权属**：出租方须提供房产证原件，核对地址与产权人；警惕"二房东"——承租人须取得原房东同意转租证明；商用租赁须确认房屋规划用途为"商业"。
2. **用途明确**：住宅/商用须勾选并约定，商用须注"乙方承诺用于____经营活动"。
3. **租金押金与费用**：押金作为房屋及设施完好、费用结清的担保，退还须附费用清单；滞纳金建议不超过 LPR 的 1.5 倍。
4. **维修责任**：主体结构/基础设备（管道老化、墙体裂缝）由甲方承担；小额维修（≤约定金额）可由乙方承担。

## 二、关键风险条款
- **转租限制**：未经甲方书面同意不得转租、分租、出借；住宅可约定短期（≤X日）转租提前告知。
- **解除**：协商解除 + 法定解除（不可抗力/危房自动解除，互不担责）。
- **送达条款**：载明联系地址为法律文书送达地址。
- **备案**：住宅非强制备案；商用建议备案（部分城市为办照前提）。
