# 设备采购安装合同（范本结构与审查要点）

> 来源：IMA「合同文书AI助手」公众号范本（甲方采购方 / 乙方供应安装方）。
> 定位：买卖+承揽混合合同，衔接《民法典》买卖合同章与承揽合同章。

## 一、协议结构（范本逐条）

| 条款 | 内容要点 |
|------|---------|
| 一、项目名称 | 设备名称、规格型号、数量（详见附件一报价单） |
| 二、项目地址 | 交货/安装地点 |
| 三、项目内容 | 设备采购安装相关工作 |
| 四、质量标准 | 国标/行业标准/技术参数；质保期 |
| 五、工期与交付 | 交货期、安装调试期、验收节点 |
| 六、价款与支付 | 预付款/进度款/验收款/质保金比例 |
| 七、验收与质保 | 验收标准、质保期起算、响应时限 |
| 八、违约责任 | 逾期交付/质量不符的违约金与解除 |
| 九、争议解决 | 管辖法院/仲裁 |

## 二、蓝队（防御审查）要点

1. **性质界定** — 含"安装调试"属买卖+承揽混合，质量异议期、定作人监督权和任意解除权（第 787/778 条）须明确，避免被乙方主张纯买卖短期异议期。
2. **验收标准量化** — 必须写清技术参数、第三方检测标准；仅写"合格"致质量争议无法举证（第 615 条买受人检验义务）。
3. **质保金闭环** — 留 5%~10% 质保金，质保期（建议 ≥2 年）满无质量问题才付；明确乙方接到故障通知后响应/到场时限。
4. **发票与付款挂钩** — 先票后款须约定"发票不作为付款前提"的除外，防止乙方以未开票抗辩付款。

## 三、红队（攻击/抗辩）空间

- 乙方可主张甲方**未依约提供安装条件**（场地、水电）构成先履行抗辩（第 525 条），顺延工期不担责。
- 甲方逾期付款，乙方可行使**留置权/同时履行抗辩**，但须注意设备已交付占有后的留置边界。
- 隐蔽质量缺陷超出约定质保期但属**根本性不符**，可援引第 610 条（标的物瑕疵担保）在合理期限主张。
