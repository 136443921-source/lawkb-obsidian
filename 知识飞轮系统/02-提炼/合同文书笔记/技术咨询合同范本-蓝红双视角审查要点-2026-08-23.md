# 《技术咨询合同》范本及写作要点｜蓝红双视角解读

> 来源：高云合同（2026-07-14）｜关联 [[R-HT-096]]
> **核心命题**：技术咨询合同是"对未知的管理工具"——不保证结论正确，但保证**责任边界清晰**。审查重点不在交付物那页纸，而在知识转移全生命周期的定义条款与通知条款。

## 🔵 蓝队（受托方/乙方立场）审查要点

1. **咨询内容界定**：必须把"提供技术咨询服务"落为**可执行的范围清单 + 排除项**（哪些不在范围内），防止"超范围服务不收费"的隐性义务。
2. **验收标准数据化**：模板 5.2 条"不能令人满意"是形容词，须转化为**可操作的数据或动作**（如"报告结论与复检数据偏差 ≤X%"）。这是乙方自保的关键闸门。
3. **责任上限条款（4.6）**：合同总价封顶 + 故意/重大过失除外——**必须保留**，是咨询机构的生存条款。注意兜底表述"保证期满后责任解除"。
4. **知识产权归属（1.5）**：报告及其附件归委托方财产，但乙方**保留复印件且不得用于本项目之外**——乙方应争取保留"通用方法论/底层知识库"的使用权（模板 1.6 已含，勿删）。
5. **付款节点绑定**：咨询费固定价（2.3）"不随通胀波动"对乙方不利，须预留不可抗力调整 + 超范围服务"协商修改总价"的书面程序。

## 🔴 红队（委托方/甲方立场）攻击点

1. **乙方免责过宽**：4.6 责任封顶 + 5.3 保证期满解除——若咨询结论直接导致甲方决策失误，甲方应主张**侵权责任（过错责任）不因合同保证期届满而消灭**，或在合同中排除"保证期届满免责"适用。
2. **违约金畸低风险**：9.1 迟延违约金按"万分之X/周"空白填空，甲方必须填足，否则乙方迟延交付成本极低；9.2 违约金总额上限条款可能被乙方援引为**责任天花板**，甲方应要求违约金与"因迟延导致的直接损失"择高。
3. **"按实结算"陷阱（2.1(2)）**：若只写"项目完成验收后按实结算"而不写上限，甲方成本失控；应设**总价上限 + 超支审批程序**。
4. **咨询报告第三人使用责任**：模板未覆盖"报告被转发第三方使用出错"的追责——甲方应增加**乙方对报告的瑕疵担保责任不因转发而免除**（乙方通常拒绝对第三方担责，属博弈焦点）。

## 裁判规则（R-HT-096）

**技术咨询合同的核心审查基准**：咨询人的义务是"尽到与咨询任务相适应的注意义务"而非"保证咨询结论正确"。约定验收标准不明确的，法院以合同目的能否实现与通常专业标准综合认定；咨询报告存在重大缺陷导致委托人损失的，按过错程度与因果关系分担，咨询人可依约主张责任限额（但故意/重大过失除外）。

## 适用范围

- 技术咨询/技术尽调/专家论证类合同审查
- 委托方 vs 受托方强弱地位条款博弈
- 咨询成果知识产权归属与验收争议

## 关联法条

- 《民法典》第878条（技术咨询合同定义）、第881条（咨询报告未达到约定要求的责任）
- 《民法典》第509条（诚信履行）、第585条（违约金调整）

## 实务要点

1. **写审改三问**：验收标准能否数字化？责任上限是否保留？报告衍生成果归谁？
2. 强弱主体条款清单：强势甲方锁范围+严违约；强势乙方锁封顶+留通用知识使用权。
3. 涉技术咨询诉讼：先查**验收标准条款**是否把"形容词验收"落为"数据验收"，再查责任封顶条款效力。
