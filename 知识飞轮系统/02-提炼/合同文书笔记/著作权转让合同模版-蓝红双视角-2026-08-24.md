# 著作权转让合同模版 — 蓝红双视角审查笔记

> 来源：微信公众号「跃马扬鞭的查理」（河北），2026-08-23 发布，收于 IMA 合同文书AI助手库。适用场景：著作权人将作品财产权在保护期内**永久转移**给受让方（"卖断"），涵盖文字/音乐/美术/摄影/视听/计算机软件等。

## 一、交易结构与核心概念

- **转让 ≠ 许可**：许可是"借用"（权利保留，限期限范围）；转让是"卖断"（剩余保护期内整体转移，转让人不得再行使）。
- **仅限财产权**：署名权、修改权、保护作品完整权属人身权，保护期不受限制、不可转让（《著作权法》第10条第1款第2-4项、第22条）。
- **未明确转让的权利视为保留**（《著作权法》第29条），须逐项勾选复制权/发行权/出租权/展览权/表演权/放映权/广播权/信息网络传播权/摄制权/改编权/翻译权/汇编权等12项+兜底。

## 二、🔵 蓝队审查要点（受让方/防御视角）

1. **权属核查前置**：签约前核查转让方是否真权利人——作品登记证书、创作底稿、原始创作合同；合作作品须全体合作作者同意（第18条），职务作品核对权属约定（第19条）。
2. **权利种类逐项勾选**：避免笼统写"全部版权"，未列明权利受让方不得行使。
3. **在先许可书面列明**：要求转让方书面列明已签全部许可合同（附件四），隐瞒在先许可可依《民法典》第500条追缔约过失责任；在先许可不因转让失效（须承继承受）。
4. **权利转移时点与付款挂钩**：建议约定"价金付清至一定比例后"权利转移（5.1条勾选），避免权利先转移而价金未付。
5. **备案非强制但强烈建议**：《著作权法实施条例》第25条——发生"一权多转"时备案记录是关键证据。
6. **未发表作品安排发表权**：发表权仍归作者，行使复制/发行/信息网络传播必然涉及首次公开，须按7.3款明确"视为同意发表"。

## 三、🔴 红队攻击分析（转让方/攻击视角）

1. **人身权"转让"条款无效**：合同约定"连人身权一并买断"不发生转移效力，改署他人姓名构成侵权——可反向利用：主张该约定无效，署名权仍归作者。
2. **权利范围不明确即可扩张解释**：若合同笼统约定"买断全部版权"而未逐项列明，依《著作权法》第29条未列明权利仍归转让人——转让方可主张保留。
3. **一权多转防御**：转让人再就同一权利转让/许可第三人构成侵权（第52、53条），受让人可主张专项高额违约金（10.4条），违约金以实际损失30%为参照上限（第585条第2款）。
4. **在先许可承继**：转让前已合法订立的许可合同不因转让失效，受让人须承继——转让方可利用此点主张受让人已接受限制。

## 四、关键风险提示（模板自带8大风险）

人身权转让无效 / 未明确权利不得行使 / 转让人再行使构成侵权 / 隐瞒在先许可须赔偿 / 一权多转风险 / 权属瑕疵连带侵权 / 未发表作品行使受阻 / 违约金过高可被调整。

## 五、交付版使用说明

- 签约前务必书面列明在先许可清单并核对；
- 大额转让分期付款，尾款在交付完成+备案后支付；
- 注意剩余保护期与价金匹配（作者去世多年作品价值折减）；
- 计算机软件著作权转让另参照《计算机软件保护条例》。
