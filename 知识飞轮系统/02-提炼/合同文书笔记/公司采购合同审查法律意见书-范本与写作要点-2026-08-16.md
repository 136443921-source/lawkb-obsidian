# 公司采购合同审查法律意见书：范本框架与写作要点

> 来源：IMA「合同文书AI助手」· 熊猫法律星球（2026-05-29）。
> 定位：商事合同审查集大成训练——把"审过"升级为"审好"，是律师与业务/财务/管理层沟通的标准接口。

## 一、文书定位（三种角色）

1. **商业意图的翻译者** — 把"尽快交货"转化为明确的逾期罚则与催告程序；
2. **权利义务的平衡师** — 避免单方负担过重构成实质不公平，进而被认定格式条款；
3. **证据链的编织者** — 每个修改点都要对应未来可能的举证场景。

## 二、范本七段式结构

| 部分 | 核心内容 |
|------|---------|
| 一、合同基本信息 | 名称/编号/签约方/标的/金额付款/履行期限 |
| 二、合同合法性审查 | 主体资格（营业执照/经营范围）、内容合规（民法典/公司法、国家管控商品许可）、交易结构与条款合理性（显失公平） |
| 三、重点条款分析 | 付款（分期/预付/票据约束）、交付验收（地点时间/验收标准程序）、质量保证与瑕疵担保（第三方检测）、违约责任（违约金约20%）、争议解决（仲裁/诉讼+管辖）、保密（范围+违约赔偿） |
| 四、风险提示建议 | 供应商资信调查、价格波动调整机制、不可抗力及通知程序 |
| 五、综合结论 | 合法但需完善条款清单 |
| 六、审查声明 | 仅限文本合法性合规性，不构成业务保证 |
| 七、签章 | 律所+律师+签发日期 |

## 三、🔵 蓝队（防御/采购方）审查要点

- **付款条款**：分期+预付降低资金风险；增加票据支付约束（银行背书）防票据欺诈；付款节点与交付成果挂钩。
- **质量条款**：约定第三方检测机构结果为准；供应商承诺符合标准并担质量保证责任。
- **违约金**：明确标准（如合同金额 20%），避免约定不明被酌减。
- **保密**：列明具体保密信息范围 + 违约赔偿责任，防商业秘密泄露。
- **管辖**：约定己方所在地法院/仲裁机构，避免不利管辖。

## 四、🔴 红队（攻击/供应商）审查要点

- **违约金过高抗辩**：《民法典》第 585 条，约定违约金超过损失 30% 可请求酌减——审查意见书中"20%违约金"条款留酌减空间。
- **验收标准模糊反制**：若验收条款只有程序无客观标准，供应商可主张"合理检验期间"抗辩（第 620-623 条）。
- **付款节点脱钩**：若付款与交付成果脱钩，供应商可主张先履行/同时履行抗辩。
- **免责条款缺口**：不可抗力通知程序（如 10 日内通知）若未约定，双方均可利用。
- **格式条款无效之诉**：单方解除权、不合理违约金若属预先拟定未协商，可主张第 497 条无效。

## 五、写作要点速记

1. **"建议-理由-实施路径"逻辑**：每条建议都要可操作、有法条支撑。
2. **风险与建议一一对应**：不写空泛的"建议完善"。
3. **审查声明必须保留**：限定审查范围=律师执业风险防火墙。
4. **示范写法**："经查，双方均具备合法经营资质，且未超出经营范围开展业务。"
