# 债权转让协议（范本与审查要点）

> 来源：IMA 合同文书AI助手 · 扬律讼典《合同范本｜债权转让协议模板（详细版）》（2026-07-20）。三方结构（甲方转让方／乙方受让方／丙方债务人），属民事通用版不良资产/应收账款转让范本。

## 一、范本结构速览

| 模块 | 条款 |
|------|------|
| 定义 | 标的资产、标的债权、瑕疵、转让基准日、资产交割、债权转让通知 |
| 转让与通知 | 标的以附件《债权资产明细表》为准；签署后 5 日内通知债务人及担保人 |
| 价款支付 | 分期付款＋自基准日至实付日的年化资金成本 |
| 资产交割 | 15 日内一次性交割；抵押权变更以乙方付款达 50% 为启动条件 |
| 其他 | 税费、违约、不可抗力、变更解除、保密、争议解决（签署地法院） |

## 二、关键审查要点（受让方/转让方双向）

1. **债权转让通知（第2.3条）** — 《民法典》第546条：未经通知，对债务人不发生效力。通知是债权转让对债务人生效的要件，须固化送达凭证（EMS单号＋签收回执），建议在交割义务中单列。
2. **标的债权瑕疵披露（第1.3、4.3条）** — 不良资产收购特有风险。应要求甲方对"资产文件"完整性与真实性作陈述保证，并约定未披露瑕疵的赔偿责任与退价机制。
3. **价款与资金成本（第3.2条）** — 分期＋年化资金成本，利率留白须补全，避免约定不明导致争议。
4. **抵押权变更触发比例（第4.4条）** — "付款达 50% 始协助变更抵押登记"对受让方存在权利瑕疵风险；建议改为"签约即配合变更"或大幅降低触发比例，并约定逾期协助的违约责任。
5. **解除条款不对等（第9.2-9.4条）** — 乙方逾期付款则"协议自动解除且乙方无需承担违约责任"，但甲方解除须返还价款＋6%资金成本。双向公平性易受质疑：受让方立场可接受，转让方立场应修订为对等违约救济。
6. **管辖（第13.2条）** — "签署地有管辖权法院"，须与实际签署地一致并写清，避免管辖争议。

## 三、适用边界

金融不良资产批量转让、应收账款融资、合同债权抵债等。金融类还需叠加《金融资产管理公司资产处置管理办法》等特别规则，本范本不覆盖。
