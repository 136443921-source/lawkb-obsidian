# 出口合同审查清单（模板）— 基于上海律协 2024 出口指引

> **用法**：复制本文件，替换 `{{占位符}}`，逐项勾选（✅/❌/⚠️）。覆盖指引五大模块 + 出口专项四件套。
> **依据**：上海市律师协会《（试行）律师从事国际贸易合同（出口）业务操作指引（2024）》，非强制性规范，仅供参照。

## 模块一：主体与基础信息

- [ ] 买方签约主体资格审查（境外公司注册地、资信、是否有权签约）
- [ ] 卖方（我方/客户）履约能力评估（产能、许可、出口资质）
- [ ] 合同语言与版本效力（以何文本为准）
- [ ] 合同适用法律（准据法）明确约定

## 模块二：不可抗力条款（第一章 第一节）

- [ ] 采用**概括式定义**（非穷举列举），覆盖疫情/自然灾害/行政管制等
- [ ] 明确约定优先于法定（"本合同不可抗力范围包括但不限于…"）
- [ ] **通知义务**：时限、方式、送达地址
- [ ] **证明义务**：须提供客观可印证材料（疫情证明/行政通告/时间轴）
- [ ] 免责后果边界（部分/全部免责、期限）
- [ ] 举证分配：主张免责方承担"不可抗力直接导致不能履行"的举证责任（《民法典》第 180 条 + 最高法 2020 疫情司法解释）

## 模块三：情势变更条款（第一章 第二节）

- [ ] 设置再协商机制（成本剧变时的重新议价触发条件）
- [ ] 明确：须**当事人请求**法院/仲裁变更或解除（《民法典》第 533 条，机构不得主动适用）
- [ ] 显失公平的判断时点 = **债务人履行债务的时间**
- [ ] 区分路径：不可抗力→免责；情势变更→变更/解除（二选一逻辑清晰）
- [ ] 通知+证明+变更请求的书面操作链条约定

## 模块四：国际结算（第二章）

- [ ] 结算方式明确（T/T、托收、信用证 L/C）
- [ ] 信用证：**单证严格相符**要求 + 不符点处理机制
- [ ] 警惕信用证**软条款**（须买方配合才能满足的单证）
- [ ] 单证交付清单与时限（提单、发票、装箱单、产地证、保险单）
- [ ] 单证迟延/交付困难的抗辩与后果约定

## 模块五：交货与运输（第三章）

- [ ] 贸易术语（Incoterms 2020）明确风险划分点
- [ ] 装运期、装运港/目的港、分批/转运约定
- [ ] **运费大幅上涨**的风险分担/调价机制
- [ ] **进口国管控**（配额、禁运、检验检疫）致买方接收迟延的处理
- [ ] 货运迟延的责任边界与免责衔接

## 模块六：违约与争议（第四章 + 第五章）

- [ ] 交货迟延的违约认定与解除权行使期限
- [ ] 违约金与定金条款（**不可并用**，依《民法典》第 588 条，约定违约金过高可请求调减）
- [ ] 赔偿范围（直接损失/可预见规则）
- [ ] **争议解决方式**：仲裁 or 诉讼，机构、地点、规则、语言明确
- [ ] 涉外证据：公证认证链 + 经公证翻译件要求
- [ ] 适用法律审查（是否适用 CISG《联合国国际货物销售合同公约》）

## 模块七：出口专项四件套（审单必查）

| # | 要件 | 检查点 |
|---|------|--------|
| 1 | 不可抗力通知/证明 | 时限+方式+材料清单是否可执行 |
| 2 | 情势变更协商 | 再谈判触发条件与操作链条 |
| 3 | 信用证单证 | 单证清单+严格相符+软条款排查 |
| 4 | 争议解决准据法 | 机构/地点/规则/语言/CISG 适用 |
