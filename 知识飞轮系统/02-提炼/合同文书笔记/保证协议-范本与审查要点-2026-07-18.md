# 保证协议（范本结构与审查要点）

> 来源：IMA「合同文书AI助手」公众号范本（债权人甲方 / 债务人乙方 / 保证人丙方 三方）。
> 定位：担保合同审查主线，衔接《民法典》合同编典型合同·保证合同章。

## 一、协议结构（逐条拆解）

| 条款 | 内容要点 |
|------|---------|
| 一、主债权概况 | 主合同名称/编号、债务金额、履行期（分期见附件《债务明细表》） |
| 二、保证方式 | 一般保证 / 连带责任保证（勾选）；未约定→一般保证 |
| 三、保证范围 | 本金 + 利息（无约定按 LPR）+ 违约金 + 实现债权费用（律师费/诉讼费/保全费/差旅） |
| 四、保证期间 | 主债务届满起 ≥6 个月（建议 2 年）；分期自最后一期届满起算 |
| 五、权利义务 | 甲方可要求提前担保/清偿；丙方恶化时披露义务（重大事15日书面通知）；丙方代偿后追偿 |
| 六、违约责任 | 丙方逾期按日付息；隐瞒负债/虚假资料→立即清偿+违约金；乙方擅改主合同→加重部分免责 |
| 七、争议解决 | 协商不成，甲方所在地法院管辖 |
| 八、其他 | 自然人签字捺印 / 企业法定代表人签字+公章；主合同变更需三方书面确认 |

## 二、审查要点（附法律依据）

1. **保证方式必须明示** — 连带责任需明确约定"连带责任保证"，否则依法推定为**一般保证**（《民法典》第 686 条）。金融机构担保通常要求连带，须特别注明。
2. **保证期间合规** — 未约定法定 6 个月（主债务届满起，《民法典》第 692 条）；建议约定 **2 年** 以延长主张期限，避免脱保。
3. **保证人资格红线** — 国家机关、以公益为目的的非营利法人/非法人组织**不得为保证人**（《民法典》第 683 条）；企业保证须核验章程授权 + 内部决议（股东会/董事会决议附卷）。
4. **追偿权落地** — 明确"丙方代偿后乙方 X 日内偿还，否则按 LPR×2 计息"，并约定反担保物处置权。
5. **特殊场景** — 最高额保证须约定"最高债权额 + 债权确定期间"；共同保证须明确按份 or 连带共同保证。

## 三、实务风险卡片

- **脱保三大雷区**：方式未写（变一般）、期间过短（法定6月）、期内未主张（一般保证未诉讼/仲裁，连带未通知）。
- **主合同变更陷阱**：未经丙方书面同意延长债务期/增加金额，丙方对加重部分不担责（第 695 条精神）。
- **公益组织特别注意**：基金会等以公益为目的法人不得作保证人，对外担保条款一律无效。
