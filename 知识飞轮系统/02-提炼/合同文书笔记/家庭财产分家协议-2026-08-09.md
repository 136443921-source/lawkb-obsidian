# 家庭财产分家协议（参考及操作建议）— 蒸馏笔记

> 来源：知法用法小分享（江苏），2026-08-07 18:10。家庭共有财产分割 + 父母赡养一体化协议模板，结构最完整（六段 + 四类操作建议），含居住权、养老备用金、遗产分配挂钩等精细设计。
> 以**蓝队（子女/财产受让方：关注产权过户、补偿支付、债务切割）**与**红队（父母/弱势方：关注居住权、赡养落实、养老保障）**双视角拆解。

## 一、协议骨架（六段式）

| 模块 | 要点 |
|------|------|
| 一、分割原则 | 自愿平等公平 + **优先保障父母晚年** + 实物分配为主、货币补偿为辅 |
| 二、财产分割明细 | 房产（含父母居住权特殊约定）/ 存款（父母留养老备用金）/ 车辆 / 家具家电 / 债务（共同+个人切割） |
| 三、父母赡养义务 | 居住安排 + 生活费（月付+大额均摊）+ 医疗护理（轮流/护工） |
| 四、违约责任 | 逾期日____%违约金 + 不得擅变 + **因分割不均拒赡养→遗产不分或少分** |
| 五、争议解决 | 父母居住地人民法院管辖 |
| 六、其他条款 | 全体签字（捺印）+ 见证人 + **公证后生效** |

## 二、蓝队视角（子女/财产受让方）

1. **房产过户节点必填**——模板提示「甲方需在____年__月__日前办理过户，乙方配合签字」，未过户 = 产权仍登记在父母/对方名下，处分受限。补偿款支付与过户应设先后履行顺序（建议先付补偿后过户，或资金监管）。
2. **补偿款支付留痕**——转账备注「分家协议房产补偿款」，防付款事实举证不能。
3. **共同债务切割要公示**——模板将共同债务按____元/____元拆分由各子女承担，但对外仍可能连带；建议同步通知债权人或取得免责确认，否则内部约定不能对抗外部债权人。
4. **违约金 + 遗产挂钩威慑**——违约拒付赡养→「遗产不分或少分」是强约束，但属约定，效力以不违反强制性规定为限，宜与遗嘱规划衔接。
5. **农村宅基地特别标注**——宅基地房须注「仅限本村集体成员继承/分配」，不符资格者不得受让，防无效分配。

## 三、红队视角（父母/弱势方）

1. **居住权要写死期限与权能**——模板「父母享有居住权至____年__月__日，无需付租，子女不得干涉」，建议据《民法典》第 366 条设立**书面居住权并登记**，期限可设至身故，防止子女卖房驱离。
2. **养老备用金独立保留**——存款分配中明确「父母保留____元作为养老备用金」，且该部分不纳入子女分割，保障现金流。
3. **赡养费量化 + 大额均摊**——月付____元 + 医疗/物业大额凭票均摊；建议约定「超____元费用由子女均摊」，避免小额频繁扯皮。
4. **特殊情形倾斜**——残疾子女可约定多分____%；出资贡献大者（如婚前出资建房）可多分，体现公平，也减少日后确权争议。

## 四、四类操作风险清单（来自原文建议，提炼）

| 风险域 | 关键动作 |
|--------|----------|
| 产权清晰化 | 房产明确过户时限；宅基地限本集体成员 |
| 赡养义务细化 | 随住子女可免付赡养费但保居住；超额定医疗费均摊 |
| 证据留存 | 存款以____日银行流水为准各方签字；补偿款转账备注 |
| 特殊情形 | 残疾/出资贡献倾斜多分，写入协议 |

## 五、执业动作清单

- [ ] 先确权：查清房产登记状态、宅基地属性、存款流水时点。
- [ ] 父母居住权建议单立《居住权合同》并登记（不动产登记中心），不仅靠分家协议条款。
- [ ] 补偿款与过户设履行顺序 + 资金监管/收据闭环。
- [ ] 共同债务切割同步书面通知债权人；个人债务各自承担条款单列。
- [ ] 赡养量化（月费+大额均摊+医疗护理轮值），违约挂钩遗产分配须与遗嘱一致。
- [ ] 公证：重大分家协议建议公证增强对抗第三人效力。

## 六、法条锚点

- 《民法典》第 304 条（共有物分割）、第 366–371 条（居住权）、第 1067 条（赡养义务）、第 1130 条（遗产分配：不尽赡养义务者可不分或少分）、第 1124 条及以下（遗嘱）。
- 宅基地：《土地管理法》第 62 条（一户一宅、集体成员限制）。
