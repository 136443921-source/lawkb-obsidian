# R-HT-332 抵押合同（蓝红双视角）

> 源：IMA·合同文书AI助手「抵押合同（参考及注意事项）」（知法用法小分享，2026-06-07）。`source_verified:true / ima_true:true`；法条正文待三通道回源（`statute_text_pending:true`）。

## 一、蓝队（抵押权人 / 债权人起草视角）
- **登记是生命线**：不动产（房产、土地）抵押必须登记，抵押权自**登记时设立**；动产（车辆、设备）抵押合同生效即设立，但**未经登记不得对抗善意第三人**——务必登记。
- **担保范围写全**：本金 + 利息 + 违约金 + 损害赔偿金 + 实现抵押权的费用（律师费/诉讼费/评估费/拍卖费）。
- **抵押物清单 + 权属证明**作为附件，确认无查封、无在先抵押、无共有权瑕疵（共有财产需全体共有人同意）。
- **禁止流押条款**：不得写"到期不清偿抵押物归乙方所有"，该约定无效；应约定折价/拍卖/变卖后优先受偿。
- **实现路径**：协商折价 → 请求法院拍卖/变卖 → 价款优先受偿，超出部分归抵押人、不足部分债务人继续清偿。

## 二、红队（抵押人 / 债务人抗辩视角）
- **流押条款无效抗辩**：对方主张"直接取得所有权"的，依民法典401条主张无效。
- **未登记不对抗抗辩**：动产抵押未登记，抵押人已转让且买受人善意 → 抵押权人不得追及。
- **重复抵押 / 超额抵押**：同一财产多次抵押，按登记先后或债权比例清偿（414条），可抗辩超额主张。
- **价值减损通知义务边界**：仅在"价值减少"时补担保，正常市价波动不触发。
- **解除登记请求权**：主债务清偿完毕，抵押人有权要求配合注销登记（对方拖延可诉请）。

## 三、关联在办业务
- **王德明担保合同纠纷案**：物保（抵押/质押）与人保（保证）并存时清偿顺序（民法典392/409/415），混合担保追偿问题。
- **航合物流 2026-09-01 事故**：车辆、设备属动产，设立动产抵押须登记方可对抗善意第三人。

## 四、关联法条（statute_text_pending）
- 《民法典》第三百九十四条（抵押定义）、第三百九十五条（可抵押财产）、第三百九十九条（禁止抵押财产）、第四百零二条（不动产抵押登记设立）、第四百零三条（动产抵押登记对抗）、第四百零四条、第四百零五条（买卖不破租赁）、第四百一十条（抵押权实现）、第四百一十一条（孳息）、第四百一十四条（清偿顺序）、第四百一十九条（存续期间）、第四百零一条（禁止流押）。
