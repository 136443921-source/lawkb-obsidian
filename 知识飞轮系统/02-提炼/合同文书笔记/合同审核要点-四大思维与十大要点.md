# 合同审核要点-四大思维与十大要点

## 一句话摘要
合同审核不是文字校对，而是对商业交易的风险预判、权责锁定、损失兜底；须以「交易本位 / 风险对等 / 穷尽风险 / 证据留存」四大思维为底层，覆盖主体→争议解决全流程十大要点。

## 🔵 蓝队视角（我方审查防御）
1. **四大核心思维**：① 交易本位——条款贴合真实交易，口头约定落书面；② 风险对等——排查霸王条款（我方全责/对方免责）；③ 穷尽风险——预设交付延迟、质量瑕疵、欠款、解约、政策变动等异常场景；④ 证据留存——沟通、交付、验收、付款、送达全部书面化可追溯。
2. **十大要点**：主体资质与履约能力 → 合同目的 → 标的（合法/数量质量验收/服务者资格/物品权证）→ 框架 → 交付（包装运输） → 支付（币种/单价总价/税费负担） → 权利义务（均衡、排除权、履行顺序、安装培训保修） → 违约（5种责任形式、可操作性） → 争议解决（约定我方所在地/仲裁、败诉方担合理费用） → 兜底（送达、保密、生效、冲突处理、消灭歧义）。

## 🔴 红队视角（对方可能攻击/我方漏洞）
- 模板条款与实际交易脱节 → 条款无效、无法落地；
- 违约责任缺可操作性（如未约定计算方式）→ 法院难以支持；
- 争议管辖约定在对方所在地 → 异地诉讼成本高；
- 验收标准模糊 + 「逾期视为合格」条款被滥用 → 质量异议失权。

## 关联在手案件
- **面瘫针灸医疗服务协议**：属「定制服务」性质，须用「交易本位+证据留存」思维，疗效承诺/治愈保证须作合规边界处理（禁绝对化保证）。
- **含灵生物商标转让合同**：支付条款（币种/税费）、违约形式可操作性、管辖地为本所着力点。

## 行动建议
审查清单化：每次出审报告附「十大要点核对表」，重点标注风险对等项与管辖地。
