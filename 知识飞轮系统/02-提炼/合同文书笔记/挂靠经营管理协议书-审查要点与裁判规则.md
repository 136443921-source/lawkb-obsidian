# 挂靠经营管理协议书（参考）— 审查要点与裁判规则

> 模板来源：微信公众号「知法用法小分享」（安徽），发布时间 2026-07-25 10:15，收于 IMA 合同文书AI助手库。性质为**参考模板**，不可直接套用。

## 一、协议定位与交易结构

甲方（资质/被挂靠方）授权乙方（挂靠方/实际经营人）以甲方名义开展经营活动，乙方**自主经营、自负盈亏**，向甲方缴纳管理费，甲方提供经营手续与文件。本质是**资质借用 + 内部承包**型交易，常见于建筑、运输、危化等需特许资质的行业。

## 二、核心条款结构（模板已含）

经营项目及期限 → 双方权利义务 → 管理费及支付（每月固定 + 0.5%/日滞纳金，逾期30日可解除）→ 财务管理（收入经甲方账户结算，扣费后7日内转付）→ 保密 → 通用条款（通知送达/变更/争议解决/不可抗力）→ 债权债务纠纷处理 → 查封抵押禁止 → 员工管理·保险·工伤 → 违约责任 → 解除与终止 → 其他。

## 三、蓝队审查要点（风险敞口）

1. **协议效力风险（行业强相关）**
   - 建设工程领域：挂靠（借用资质）签订的建设工程施工合同**无效**（《建工司法解释（一）》第1条）。但建设工程合格，可参照合同约定折价补偿（第24条）；发包人可请求出借方与借用方**承担连带责任**（第7条）。
   - 其他行业（如一般商贸）挂靠经营协议原则上有效，但不得违反资质管理的效力性强制规定。
   - ✅ 审查动作：先识别行业，若属建设工程，向委托人揭示"协议可能无效 + 连带赔偿"双重风险，不要仅做条款美化。

2. **税务与发票风险（高危）**
   - 模板约定"乙方经营收入经甲方账户结算"——甲方账户代收代付，易被税务机关认定为甲方经营收入，产生增值税/企业所得税义务；乙方无票列支，易触发**虚开发票**嫌疑（资金流、发票流、合同流不一致）。
   - ✅ 建议：明确结算路径与票据开具主体，约定税费承担与虚开责任归属，必要时改用"乙方直接收款 + 甲方收取服务费"结构。

3. **对外责任隔离≠绝对隔离**
   - 模板约定"债权债务均由乙方自行承担"，但该内部约定**不能对抗善意第三人**。乙方以甲方名义缔约/举债，相对人善意时甲方须先对外担责，再依协议追偿。
   - ✅ 建议：增加"越权行为预先书面授权 + 表见代理防控 + 对外担保绝对禁止"条款。

4. **员工与工伤责任**
   - 乙方自聘员工、自购社保、自担工伤，但甲方作为**名义用人单位/挂靠单位**，在工伤认定、劳动仲裁中可能被列为共同当事人（尤其建筑领域工伤保险责任由具备用工主体资格的发包/被挂靠方承担）。
   - ✅ 建议：要求乙方提供社保/雇主责任险凭证，约定甲方被诉后的全额追偿 + 律师费转嫁。

5. **查封、抵押、担保禁止条款**（模板第八、九条）方向正确，但应补强"甲方定期检查权 + 违约高额赔偿"可执行性。

## 四、裁判规则（可检索锚点）

- **R-HG01** 挂靠经营内部约定"乙方自负盈亏"不能对抗外部善意相对人，被挂靠方对外担责后，依协议向挂靠方追偿应予支持。
- **R-HG02** 建设工程施工合同借用资质（挂靠）无效；工程验收合格可参照约定折价补偿；发包人主张出借方与借用方就工程质量、工期等承担连带责任的，法院支持（《建工司法解释（一）》第1、7、24条）。
- **R-HG03** 被挂靠方因挂靠方以甲方名义举债/担保被诉的，内部追偿范围含直接损失、利息、律师费、诉讼费（以协议约定为据）。
- **R-HG04** 建筑领域工伤保险：具备用工主体资格的被挂靠单位对挂靠人聘用的从业人员承担工伤保险责任（不以劳动关系为前提）。

## 五、实务建议

- 此类模板**仅适用于非强监管行业的轻资产挂靠**；建设工程、金融、危化等强监管领域须另行定制并提示无效/连带责任风险。
- 给顾问单位的底线话术："挂靠可以签，但要把'对外先扛、对内追偿、税务隔离、工伤兜底'四道闸做死，否则一张传票就让你从收管理费的变成赔钱的。"
