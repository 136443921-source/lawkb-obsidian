# R-HT-335 模具定作合同（蓝红双视角）

> 源：IMA·合同文书AI助手「《模具定作合同》范本及写作要点」（高云合同，2025-09-16）。`source_verified:true / ima_true:true`；法条正文待回源（`statute_text_pending:true`）。

## 一、蓝队（定作人 / 甲方起草视角）
- **法律定性**：模具定作属承揽合同（民法典770条以下），兼具"技术+法律"双重属性，须嵌入试模次数、修改权限、寿命保证等工业特殊条款。
- **技术指标 / 寿命 / 材料**：明确模具寿命、技术标准（以合同及订单技术资料为准）、材料选择（无要求由承揽人自定但须保证长期有效）（第1条）。
- **定作费**：含税总价+税率，价款含设计开发、制作、试模、送样、技术支持和质保等全部费用（3.1/3.2）。
- **定作期限**：明确制作起止、样品提供、完成时间（4.1）。
- **验收**：以《模具制作技术标准》为准；无标准则以符合批量生产为最终标准（5.3）。
- **知识产权**：定作人享模具及技术资料所有权与全部知识产权，承揽人仅限本合同目的使用（9.3）；承揽人不得留存复制品（9.4）。
- **保密**：保密义务不因合同解除/终止而终止（10.5）；违约方对接收方雇员等泄密承担连带责任（10.5）。
- **质保**：7×24技术支持，接要求24h内提供方案（5.6）。
- **违约**：按定作费总额每日万分之五（15.1）；不可抗力15日内书面告知（14.1）。

## 二、红队（承揽人 / 乙方抗辩视角）
- **技术指标合理**：材料选择具灵活性，保障自身生产安排。
- **定作费**：计算方式与支付条件合理，保障收益（结算三种方式：验收后/订单日/随货款月结）。
- **定作期限合理**：避免过苛交付压力。
- **验收标准合理**：避免不必要的质量纠纷。
- **IP/保密**：保护自身模具设计与生产中的知识产权。
- **违约/争议合理**：违约责任与争议解决机制合理。

## 三、关联在办业务
- **至善公司52%股权转让 / 含灵生物商标转让**：技术类资产交易中的知识产权归属与保密条款设计参照。
- **面瘫针灸医疗服务协议合规审查**：承揽/服务类合同质保与违约责任条款范式参照。
