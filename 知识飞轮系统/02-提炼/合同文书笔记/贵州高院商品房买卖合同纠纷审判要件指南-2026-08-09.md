# 贵州高院《商品房买卖合同纠纷案件审判要件指南》（2025）

> **对老强的特殊价值**：这是**贵州本地**（执业地）的高院裁判口径文件，效力上虽非司法解释，但对省内两级法院具有实际拘束力。商品房买卖纠纷在贵阳属高发案由，本指南可直接作为**立案前风险预判 + 庭审争点清单**使用。
> 文件结构：五章 —— 概述、审理难点、审查思路（核心）、其他问题（11 类疑难）、附录 5 个案例。

## 一、五大审理原则（裁判倾向的"底层参数"）

| 原则 | 实务含义 | 对代理策略的影响 |
|------|----------|------------------|
| **意思自治** | 有约定严格按约定，不轻易否定、不轻易调整 | 合同文本审查是第一战场，补充协议条款要逐条抠 |
| **鼓励交易** | 区分效力性/管理性强制规定，违反管理性规定**一般不认定无效** | 主张合同无效的成功率低，慎选无效路径 |
| **利益平衡** | 顾及出卖人经营困境，避免"房财两空"连锁反应 | **解除合同的诉请门槛被抬高**，优先走违约金路径 |
| **系统思维** | 关注个案对同一项目/本地市场的示范效应 | 群体性楼盘案件，法院会考虑"合政策性评价" |
| **协同联动** | 府院联动、多元解纷、行业调解优先 | 出险项目案件调解压力大，需提前评估调解方案 |

> ⚠️ **策略提示**：原则二、三合起来意味着——在贵州，代理买受人时**"请求解除合同+退款"往往不如"继续履行+主张逾期交房违约金"落地**。指南明确写"轻易解除合同，买受人将面临无法收回购房款的巨大风险"。

## 二、合同订立：预约 vs 本约（最高频争点）

### 1. 广告宣传构成要约的三要件（须同时满足）
- **对象限于开发规划范围内**的房屋及相关设施 → 周边学校/医院/地铁的宣传**不构成要约**，只能走《民法典》第500条缔约过失
- **明确具体、可特定化、无歧义** →「理想居所」「名牌电梯」「高档瓷砖」不构成；「绿化率40%」「容积率2.0」「日本原装三菱电梯两部」构成
- **对订约及房价确定有重大影响**
- 🔴 **反制条款**：若宣传册载明"不构成要约"或补充协议约定"宣传资料仅供参考"，一般认定为要约邀请 → **代理买受人时须第一时间检查有无此免责表述**

### 2. 预约/本约识别四维度
| 维度 | 预约 | 本约 |
|------|------|------|
| 合同目的 | 以将来订立本约为目的，阶段性 | 直接形成买卖关系 |
| 名称 | 认购书/订购书/预订书 | 住建部示范文本 |
| 内容 | 仅姓名、位置面积、价款 | 含付款、交付、办证、质量、违约责任、争议解决 |
| 判定关键 | **是否存在法律或事实障碍导致条款缺失** | 无障碍则不问名称一律视为买卖合同 |

- **违反预约的责任边界**：守约方**无权要求交款交房**（本约义务），只能适用定金罚则或其他违约责任；**司法不能强制缔约，不能判决签订本约**。
- **预约转本约的双要件**（《审理商品房买卖合同案件解释》第5条）：① 内容完整性（欠缺内容若非主要权利义务、不影响履行、可通过第466/510/511条填补则不影响认定）+ ② 实际履行行为（**收受部分购房款即可**，不要求全款）。
- 出卖人**已交房或已办过户** → 直接认定形成买卖合同关系。

### 3. 备案登记 ≠ 预告登记（四点区别）
| | 备案登记 | 预告登记 |
|---|---|---|
| 效力 | 仅行政监管；一房多卖时在先者优先，但**不产生物权效力** | 未经权利人同意处分**不发生物权效力**；可对抗前手抵押权、**司法机关不得强制执行** |
| 程序 | 出卖人单方义务（《城市房地产管理法》第45条第2款） | 双方合意，任一方可申请 |
| 范围 | 仅商品房预售合同 | 所有不动产交易 |
| 机关 | 建设/房产管理部门 | 房屋登记机构 |

## 三、合同效力：13 类情形的效力结论表

| 情形 | 效力结论 | 依据/要点 |
|------|----------|-----------|
| 未采书面形式 | **不影响效力** | 书面要求系配套备案的行政管理目的 |
| 未取预售许可证签**预约** | **有效** | 预售许可非预约的生效要件 |
| 预售许可证**事后失效**（撤销/期满未续） | **不影响效力** | 信赖保护原则；签约时有证即具资格 |
| 预售合同**未备案** | **有效** | 解释第6条第1款明确 |
| 未取预售许可但**已达办证条件** | 督促补办；出卖人主张无效**不予支持**（第159条恶意阻却条件成就）；买受人主张则可支持 | 体现对不诚信方的否定评价 |
| 未取预售许可但**已具备现售条件**（竣工验收合格） | **有效** | 规范目的已补正 |
| 预售商品房**转让** | 仅转让债权请求权→有效但不能突破合同相对性（除非代位权）；**概括转移→须出卖人同意** | 第535条、第555条、第140条 |
| **阴阳合同** | **价格条款无效，合同有效**，按真实价格定权利义务 | 第146条第1款；增加税费一般按法定负担 |
| **"首付贷"借款合同** | **无效** | 第153条第2款＋民间借贷规定第13条＋建房〔2017〕反洗钱通知 |
| **架空层买卖** | 独立可区分且已登记/约定归开发商→有效；属共有部分→无权处分**不影响合同效力**但承担违约责任 | 建筑物区分所有权解释第3条、第278条 |
| **绿地买卖/赠与** | 明示属个人（须规划批准＋销售时明示）→有效；公共或共有绿地→无权处分，合同有效但违约 | 第274条 |
| **"赠送置业大礼包"** | **有效**（变相返本销售仅违反管理性规定） | 《商品房销售管理办法》第11条系管理性规定 |
| 第三方收取**"团购费"** | **有效**（违反建房〔2018〕58号等文件但非强制性规定） | 退还分四种情形，见下 |

**"团购费"退还四分法**：① 已订立且继续履行 → **不退**；② 未签或因第三方原因无效/解除 → 向第三方主张退还；③ 因出卖人原因无效/解除且向第三方主张不能 → **可向出卖人主张赔偿损失**；④ 因买受人自身原因 → 不退。

## 四、合同履行：交付与质量的认定标准

### 1. 质量问题两档
- **主体结构质量不合格**（解释第9条）→ 解除＋赔偿，**支持**
- **严重影响正常居住使用**（解释第10条）→ 解除＋赔偿，**支持**；认定四因素：① 非主体结构问题；② 与房屋本身特性有关（功能缺失、排污排烟无法使用；**通常不含配套/公共设施**）；③ 达到"严重"（危及生命财产安全健康、严重干扰居住秩序）；④ **经多次修复仍难解决**
- 保修期内一般质量问题 → 修复责任；拒修/拖延 → 买受人自行或委托修复，**费用及期间损失由出卖人承担**

### 2. 装修质量
- 设**样板房**未作说明的 → **实际交付须与样板房一致**（重要举证提示：看房时应固定样板房证据）
- 救济：修复 或 减少价款，**可同时适用**，但**修复部分不可重复主张减价**
- 责任主体：条款在买卖合同/补充协议内 → 出卖人；单独装修合同有约定从约定；无约定且出卖人与装修公司为委托关系 → 依第925条**可向出卖人主张**

### 3. 交付认定（三种情形）
| 情形 | 结论 |
|------|------|
| 符合约定条件 + 期限届满 + 已通知，买受人无正当理由拒收 | **视为期限届满之日已交付** |
| 不符合约定条件，但买受人**已实际接受**且无严重质量问题 | **认定已交付**，逾期交房违约责任**不予支持**（但不免除质量担保责任） |
| 违反约定条件交付 | 买受人**可拒绝接受** |

- **竣工合格证明**：以建设单位组织设计、勘察、施工、监理的**五方验收合格文件**为准（建房〔2010〕53号＋《建筑法》第61条＋《城市房地产管理法》第27条）；合同约定标准更高的从其约定。
- **补充协议变更交付条件**（如"备案文件"改为"竣工验收报告"）：三步审查 —— 是否格式条款 → 是否成为合同内容 → 是否属无效格式条款。若未限制买受人选择权、未降低质量安全标准 → **有效**。
- **物业费/维修基金抗辩**：分属不同法律关系，出卖人**不得**以未缴为由拒绝交房或拒办过户；合同即使有此约定，出卖人须履行**提示说明义务**，否则买受人可主张该条款未订入合同。

## 六、可直接复用的执业动作

1. **接案清单**：① 查合同性质（预约/本约）② 查预售许可时点与状态 ③ 查宣传资料有无"不构成要约"免责语 ④ 查补充协议是否变更交付条件 ⑤ 查是否有阴阳合同/首付贷/团购费
2. **诉请选择**：贵州口径下，**优先"继续履行＋逾期交房违约金"**，解除合同作为备选并须论证"合同目的不能实现"
3. **证据固定**：样板房影像、宣传册原件、五方验收文件申请调取、交房通知与拒收理由书面化
4. **调解预案**：出险项目须提前准备府院联动/行业调解方案，法院有强烈调解导向
