# 和解协议（庭外和解）— 范本与审查要点（2026-07-24）

> 来源：IMA 合同文书AI助手（扬律讼典，2026-07-23）。本文提取货款欠款场景下的庭外和解协议范本，并标注对乙方（欠款方）显著不利的关键条款与实务审查要点，供起草/审查参考。

## 一、范本正文结构（货款欠款庭外和解）

| 条款 | 内容要点 |
|------|----------|
| 主体 | 甲方（供货方/债权人）、乙方（购货方/债务人），含住所地、联系电话 |
| 一、欠款确认 | 甲方向乙方供应货物，合计货款 \_\_ 元（大写），乙方均未支付 |
| 二、付款安排 | 签订之日起 \_\_ 日内支付 \_\_ 元；于 \_\_ 年 \_\_ 月 \_\_ 日 18 时前支付剩余全部货款 \_\_ 元 |
| 收款账户 | 收款账号 / 开户银行 / 开户名称 |
| 三、违约责任 | 足额支付→不追究违约责任；未按约支付→未付金额 **10% 违约金** + 甲方有权就全部剩余本金及违约金起诉并采取财产保全 |
| 四、撤诉条件 | 协议签订后甲方应于 \_\_ 年 \_\_ 月 \_\_ 日前撤回对乙方在 xxx 法院案号（xxxx）xxx 民初 xxx 号诉讼；**如甲方未撤回诉讼，本协议付款金额、时间节点不发生法律效力** |
| 五、纠纷了结 | 履行后双方就合同履行及货款支付再无任何纠纷 |
| 六、保密 | 双方对协议内容保密，不得向第三方泄露 |
| 七、生效 | 一式两份，盖章签字之日起生效 |

## 二、关键审查要点（重点：乙方风险）

### 1. 第四条「撤诉前提」是乙方最大陷阱条款
> "如甲方未按约定撤回诉讼，本协议约定的乙方付款金额、时间节点不发生法律效力。"

- **后果**：乙方依约先付款，若甲方拖延/拒绝撤诉，乙方已付部分款项将陷入"协议付款条款无效"的尴尬——付款义务丧失合同依据，却已实际支付。
- **修改建议**：
  - 将撤诉义务与首付款挂钩为**同时履行**或**先撤诉后付款**；至少约定"甲方撤回诉讼（提交撤诉裁定/法院受理撤诉通知）后 \_\_ 日内乙方支付首期款"。
  - 明确撤诉的具体动作与凭证（法院《准予撤诉裁定书》或案号注销证明），并约定甲方逾期撤诉的违约责任（如按日违约金、乙方有权拒付且已付款项视为预付、可要求返还）。
  - 增加"协议自双方签字且甲方实际撤诉之日起生效"的**生效前提条款**，而非第七条笼统的"签字生效"。

### 2. 违约金 10% 的合理性
- 依《民法典》第 585 条，约定违约金低于/过分高于损失的可请求法院或仲裁机构调整。"未付金额 10%"在货款纠纷中通常处于合理区间，但需结合标的额、资金占用损失（LPR 四倍以内）判断。
- 建议明确违约金计算基数（"未付金额"是否含已产生的利息/保全费），避免歧义。

### 3. 财产保全衔接
- 第三条赋予甲方"采取财产保全措施"的权利。乙方应要求：若达成和解并部分履行，甲方应**同步解除/缩保**已查封财产，避免超额冻结。
- 实务中可约定"乙方支付首期款后 \_\_ 日内，甲方申请解除对乙方 \_\_ 账户的冻结"。

### 4. 第五条"再无任何纠纷"的兜底范围
- 该条款构成一次性了结。乙方应确认：是否涵盖利息、逾期付款损失、维权费用（律师费/保全费/担保费）？若未付部分含这些费用，应在第二条付款金额中**明确打包数额**，否则"再无纠纷"可能被甲方解释为仅指本金。

### 5. 管辖与案号
- 第四条案号、法院须与真实诉讼文书一致；若尚未立案（仅意向起诉），应将"撤回诉讼"改为"放弃起诉/不再就本欠款提起诉讼"，避免虚构案号。

## 三、与「诉讼中调解」的区分

| 维度 | 庭外和解（本协议） | 诉讼中调解 |
|------|-------------------|------------|
| 制作主体 | 双方自行签署 | 法院出具《调解书》 |
| 强制执行力 | 无（需另诉） | 有（可直接申请执行） |
| 撤诉约束 | 靠协议约定 | 调解书送达即生效，原告申请撤诉 |
| 风险点 | 甲方不撤诉时乙方付款依据悬空 | 内容反悔难，但效力确定 |

> 提示：若追求"付清即了结、可直接强制执行"的效果，应引导当事人走**诉讼/仲裁调解**路径，并以《调解书》固定；纯庭外和解更适合尚未立案或双方信任度较高的场景。

## 四、可复用条款清单（起草时逐项核对）

- [ ] 欠款金额、已付/未付数额、大写一致
- [ ] 付款节点与金额可操作（避免"18时前"等过细时限引发履行争议，可改为"当日 18:00 前"并注明时区）
- [ ] 撤诉义务前置或设违约救济
- [ ] 违约金基数与调整机制明确
- [ ] 保全解除/缩保条款
- [ ] 纠纷了结范围（是否含利息、维权费用）
- [ ] 生效条件（建议加"甲方实际撤诉后生效"）
- [ ] 保密与争议解决条款（建议增加"本协议争议由 xxx 法院管辖"）
