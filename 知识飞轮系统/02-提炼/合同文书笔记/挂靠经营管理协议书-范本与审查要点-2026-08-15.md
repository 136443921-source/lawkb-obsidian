# 挂靠经营管理协议书-范本与审查要点（蓝红双视角）

> 原文：《挂靠经营管理协议书（参考）》（知法用法小分享，2026-07-25）
> 关联：[[股权转让协议（参考及注意事项）]]、[[公司合同审查及法律风险防控-体系框架-2026-08-10]]

## 协议骨架（十二条）
经营项目及期限 → 双方权利义务 → 管理费及支付 → 财务管理（收入经甲方账户结算）→ 保密 → 通用条款 → 债权债务处理 → 查封抵押条款 → 员工管理/保险/工伤 → 违约责任 → 解除终止 → 其他

## 法律定性（关键）
- 挂靠经营=乙方以甲方名义经营，实质借用资质/名号（建筑行业常见）
- 内部协议仅约束双方，对外甲方作为名义主体可能承担连带责任（尤其涉及第三人）
- 员工工伤：名义雇主（甲方）vs 实际用工（乙方）分离，工伤责任界定复杂

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 挂靠合规性 | 建筑/医药等行业资质借用可能违反行业管理法规 | 明确仅限合法行业；提示挂靠本身的合规风险（《建筑法》禁止挂靠） |
| 对外责任穿透 | 第七条约定乙方债权债务自担，但对外甲方名义签约仍可能担责 | 增加"乙方以甲方名义对外签约须经甲方书面授权"条款；印章管理严控 |
| 资金过账风险 | 第四条收入经甲方账户结算——税务（收入归属甲方）与现金流风险 | 明确代收代付性质、税务申报义务归属；避免被认定甲方收入 |
| 工伤责任 | 第九条约定乙方担责，但挂靠关系下工伤认定可能涉及甲方 | 建议乙方以自己名义为员工参保；明确工伤连带责任边界 |
| 管理费调整 | 第三条约定可调整但无标准 | 明确调整程序（书面+提前通知+协商） |
| 管辖 | 乙方所在地法院（对乙方有利） | 甲方争取改为甲方所在地/合同履行地 |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **挂靠无效抗辩**：若挂靠违反法律强制性规定（如《建筑法》禁止借用资质），可主张协议无效，据此抗辩管理费/违约金请求
2. **表见代理攻击**：乙方以甲方名义对外签约且甲方知情或放任的，可能构成表见代理，甲方对第三人担责（《民法典》172条）
3. **资金归属抗辩**：收入经甲方账户结算可能被认定甲方收入，税务风险转移
4. **工伤连带**：挂靠人以被挂靠单位名义经营发生工伤的，司法实践常判被挂靠单位承担工伤保险责任（人社部发〔2013〕34号）
5. **违约金过高**：0.5%/日滞纳金年化约182%，可主张过分高于损失调减（民法典585条）

## 裁判规则
- R-HT-061：挂靠经营协议仅约束内部双方，被挂靠方对挂靠方以自己名义从事的经营行为，可能因表见代理或挂靠关系对外承担民事责任；挂靠违反法律强制性规定的协议无效
- R-HT-062：挂靠单位以被挂靠单位名义经营期间发生工伤的，被挂靠单位可能承担工伤保险责任；内部约定不免除对外责任

## 实务清单
- 被挂靠方（甲方）：严格授权管理/印章管控/工伤责任切割/税务安排
- 挂靠方（乙方）：保留经营自主权/明确费用范围/争取有利管辖
- 行业提示：建筑挂靠风险极高，建议转为分包/合作模式
