# 限期付租否则解除租赁合同通知函——审查要点与裁判规则

## 一、文档来源与定位
- **来源**：IMA 合同文书AI助手库《关于限期付租否则解除租赁合同的通知函》（佛山田律师，2026-07-28 入库）
- **援引**：《民法典》第562条（约定解除）、第565条（解除权行使程序）
- **文书性质**：出租人向逾期付租承租人发出的"限期履行+逾期即解除"通知，兼具催告与解除意思表示预告。

## 二、蓝队视角（出租方起草 / 防御型）
1. **解除权基础须先确证**
   - 约定解除：租赁合同明确约定"逾期付租 X 日出租方有权解除"；
   - 法定解除：无约定时依第563条第1款第（三）项"迟延履行主要债务，经催告后在合理期限内仍未履行"，须先催告。
2. **通知须含三项要素**
   - 明确欠款金额、逾期天数；明确限期（建议≥合理期限，通常 3–15 日）；
   - **明确表达解除意思**："逾期则自本函到达之日起解除租赁合同"，避免仅催款不构成解除。
3. **送达留痕（关键证据）**
   - 采用 EMS 特快专递，面单备注"解除租赁合同通知函"，保留邮寄凭证、妥投截图、签收记录；可同步公证或发视频存证。
4. **解除后衔接**
   - 通知中一并告知腾退期限、租金结算、保证金扣抵、占有使用费计算标准。

## 三、红队视角（承租方 / 攻击点）
1. **抗辩1：解除权未发生**——出租人未先催告或约定期限未届至即发出解除，通知不生效。
2. **抗辩2：期限不合理过短**——如"限 1 日付清否则解除"，可能被认定未给合理期限，解除有瑕疵。
3. **抗辩3：送达瑕疵**——未有效送达（拒收未留证、地址错误），解除意思未到达，不发生效力。
4. **抗辩4：违约金/占有使用费过高**——可请求调减（《民法典》第585条、第591条减损规则）。
