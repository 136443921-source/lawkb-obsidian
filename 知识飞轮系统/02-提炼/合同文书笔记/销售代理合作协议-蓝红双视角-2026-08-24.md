# 销售代理合作协议（参考）— 审查要点与裁判规则

> 来源：微信公众号「知法用法小分享」（安徽），2026-07-24 发布，收于 IMA 合同文书AI助手库。性质为**参考模板**，不可直接套用。

## 一、协议定位与交易结构

甲方（委托方/供货方）授权乙方（代理方/渠道商）在指定区域推广销售甲方产品，乙方利用自有渠道拓客，甲方提供产品、价格体系与市场支持。本质是**委托代理（代销）关系**，区别于买卖（买断）、劳动关系、特许经营——法律关系定性直接影响管辖、报酬性质与责任分配。

## 二、核心条款结构（模板已含）

合作内容（区域/产品授权）→ 合作期限（提前30日续签）→ 产品价格与结算（款到发货/月结，逾期0.5%/日违约金，超30日可解除/停供）→ 销售目标与奖励 → 甲方权利义务 → 乙方权利义务 → 市场推广与品牌建设 → 保密（合作结束后5年）→ 违约责任 → 争议解决 → 其他。

## 三、🔵 蓝队审查要点

1. **授权范围明确性**：产品清单、区域范围、渠道类型（线上/线下）、是否独家，必须书面锁定；"区域"含糊会引发串货争议。
2. **价格调整机制**：甲方调价须"提前通知+缓冲期"（模板5日），避免单方变价导致乙方已订订单亏损。
3. **销售目标合理性**：目标需书面明确（年度/季度/月度），并配套"未达标时先协商调整合作方式、提前30日通知"的程序约束，防止甲方直接终止。
4. **报酬/奖励结算**：奖励标准、计算基数、支付时点须可验证（模板以"完成目标的__%"留白，须填实）。
5. **禁止转售/跨区**：乙方不得擅自降价、跨区域销售——违约后果与举证方式（发货记录、销售数据）应明确。

## 四、🔴 红队攻击分析

1. **"代理" vs "经销"定性之争**：若乙方自负盈亏、买断货物再销售，实为经销（买卖合同）；若以甲方名义对外签约，才构成代理。定性错误 → 主张适用《民法典》买卖合同章/委托合同章的不同规则。
2. **格式条款风险**：甲方单方调价权、销售目标未达即终止等条款若属格式条款，未提示说明的，乙方可主张不成为合同内容（《民法典》第496条）。
3. **保密期限过长**：合作结束后5年保密期+违约金并存，可主张超出合理范围限制从业自由（结合竞业限制规则审慎评估）。
4. **违约金调整**：逾期0.5%/日 ≈ 年化182.5%，远超LPR四倍——可依《民法典》第585条第2款请求调减（司法实践以实际损失30%为参照）。

## 五、裁判规则要点

- 合同性质（代理/经销/行纪）依**实质履行**而非名义判断；
- 代理人对授权范围内行为负责，超越授权以被代理人名义实施的，相对人善意时可构成表见代理（《民法典》第172条）；
- 逾期付款违约金过高时法院依申请调减。
