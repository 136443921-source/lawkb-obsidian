# 特许经营合作合同-范本与审查要点（蓝红双视角）

> 原文：《特许经营合作合同》范本及写作要点（高云合同，2026-07-21）
> 关联：[[债权转让协议-范本与审查要点-2026-08-14]]、[[公司合同审查及法律风险防控-体系框架-2026-08-10]]

## 协议骨架（十五条）— BOT 联合体模式
项目概况 → 合作事项（联合体投标）→ 合作方式（股权8:18:2+对外连带）→ 投标事宜 → 保证金/资金/利益分配 → 中标后合作（项目公司/股权限制/第四方≤5%）→ 义务责任 → 保密（独立条款）→ 违约责任（垫付取代权益）→ 免责（不可抗力+情势变更）→ 补充合同 → 争议解决（项目所在地）→ 生效（未中标自动终止）→ 其他 → 份数

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 股权比例失衡 | 甲方8% vs 乙方18% vs 第三方2%——小股东权益保护 | 明确重大事项一致同意/一票否决事项；避免被多数方架空 |
| 对外连带责任 | 第三条对外各方承担连带责任 | 明确内部追偿权行使程序与时限；履约担保安排 |
| 资金垫付条款 | 第九条垫付15日未还→垫付方直接取代权益 | 评估"取代权益"条款合理性；明确取代的定价/程序 |
| 未中标自动终止 | 第十三条未中标自动终止+费用分担 | 明确"前期付出费用"范围与分担比例；避免争议 |
| 股权转让限制 | 第六条不得随意退股/转让+优先购买权 | 明确优先购买权行使程序（通知/期限/价格）；评估限制合理性 |
| 第四方引入 | 第六条可引入第四方≤5% | 明确第四方引入程序与条件；防稀释 |
| 管辖 | 项目所在地法院 | 评估项目所在地对我方是否有利 |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **股权比例反制**：小股东（甲方8%）可通过章程约定重大事项一致同意，对抗多数方
2. **连带责任追偿**：对外担连带责任后可向违约方追偿（第三条），注意保留追偿凭证
3. **垫付取代条款**：若资金未按期到位，垫付方取代权益——违约方将丧失项目权益，属强博弈筹码
4. **未中标费用争议**：自动终止后费用分担范围模糊，可谈判空间大
5. **情势变更免责**：第十条"合同基础重大变化"解除权——政策变化（特许经营监管）可作解除依据

## 裁判规则
- R-HT-065：联合体成员对外承担连带责任后，有权向违约方追偿；内部约定的责任分担比例不影响对外连带责任
- R-HT-066：特许经营合作协议因未中标自动终止的，各方按约定分担前期费用；无约定的按公平原则处理

## 实务清单
- 小股东（甲方）：重大事项否决权/知情权/审计权
- 大股东（乙方）：主导决策/资金管理/防稀释
- 各方：明确连带责任追偿程序、垫付取代条款边界、未中标费用分担
