# 模板结构（18 条 + 使用说明 + 九大风险）
适用：全日制劳动关系、无固定期限劳动合同（协商直接订 / 法定应当订两类）。

# 应当订立的三种法定情形（第14条二款）
1. 连续工作满十年，劳动者提出或同意续订；
2. 初次实行合同制度/国企改制重订，满十年且距退休不足十年；
3. 连续订立二次固定期限合同后续订（劳动者无第39条、第40条一/二项情形）。

# 关键红线
- 二倍工资：应订未订自应订之日起按月付二倍（第82条二款）；用工满一年未签视为已订无固定期限并应立即补订（第14条三款、实施条例第7条）。
- 工龄连续：非因本人原因被安排到新单位，原单位年限合并（实施条例第10条）；规避轮换无效。
- 试用期：同一单位同一劳动者只能一次，最长六个月；续订不得再设（第19、83条）。
- 解除仍适用第36—41条；违法解除二倍赔偿（第48、87条）。
- 第42条禁止：职业病未离岗检查、工伤丧失劳动能力、医疗期、三期女职工、连续满15年距退休不足5年→不得依第40、41条解除。
- 违约金仅限服务期（第22条）、竞业限制（第23条）（第25条）。

# 九大风险
符合条件拒签二倍工资；规避连续工龄无效；满一年未签视为无固定期限；"自愿放弃"条款无效；违法解除二倍赔偿；遗漏第42条保护；续订重复试用期；违约金仅限法定；享受养老保险待遇时点衔接。
