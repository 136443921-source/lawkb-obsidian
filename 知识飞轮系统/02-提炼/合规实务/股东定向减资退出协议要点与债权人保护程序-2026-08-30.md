# 股东定向减资退出协议要点与债权人保护程序

> 来源：天平启示录《参考：股东定向减资退出协议》（2025-10-25），基于 2023 修订《公司法》

## 一、协议架构（三方：存续股东/减资股东/目标公司）

鉴于条款 → 减资基本情况 → 减资后股权结构 → 减资定价与评估 → **债权人保护程序** → 减资价款支付 → 减资股东退出后权利义务 → 优先购买权放弃 → 保密 → 违约责任 → 送达 → 不可抗力 → 争议解决 → 法律适用 → 附则

## 二、新《公司法》两大核心条款

### 1. 第224条 · 定向减资（非等比例减资）

- **有限责任公司**：须**全体股东一致同意**（第3款「全体股东另有约定」例外情形）。
- **股份有限公司**：须经股东会**特别决议**（出席股东所持表决权 **2/3 以上**通过）。

### 2. 第225条 · 债权人保护程序（减资的生死线）

| 步骤 | 要求 |
|------|------|
| 通知已知债权人 | 减资股东会决议作出后 **10 日内**书面通知（名单附后），留存回执 |
| 公告 | 决议后 **30 日内**在国家企业信用信息公示系统及**省级以上公开发行报纸**发布公告，**公告期不少于 45 日** |
| 申报债权处理 | 公告期内申报的，**15 日内**清偿或提供债权人认可的担保 |
| **未履行后果** | 导致债权人主张权利的，**丙方及存续股东、时任董事承担连带赔偿责任**，减资股东在**减资款范围内承担补充赔偿责任** |

## 三、关键条款注释

| 条款 | 内容 | 风险点 |
|------|------|--------|
| 减资定价 | 共同委托第三方评估，价款含实缴返还+股权溢价补偿 | 定价须公允，不得损害债权人利益（否则被撤销） |
| 价款支付条件 | 债权人保护程序完成（公告期届满无未决争议）+ 取得《准予变更登记通知书》后 10 日内支付 | 先程序后付款，顺序不可颠倒 |
| 退出后权利 | 工商变更完成日起不再享有表决权/分红权/知情权；移交资料 5 日内，逾期每日违约金 | 交接清单须列明（印章、股权凭证、合同） |
| 债务隔离 | 仅履行债权人保护程序后才不担新增债务 | 未履行→债权人追偿→可向丙方及甲方全额追偿 |
| 优先购买权放弃 | 全体存续股东确认放弃（仅限有限责任公司） | 附签字/盖章确认页，防反悔 |
| 争议解决 | 丙方住所地法院诉讼（排除仲裁） | 管辖确定性 |

## 四、适用场景

- **至善公司 52% 股权转让**：若采取减资路径退出（而非股权转让），须全体股东一致同意 + 完整债权人保护程序。
- **含灵生物股权转让**中部分股东退出安排。
- 习水光伏尽调：核查目标公司历史减资是否履行 225 条程序（未履行→存续股东连带风险）。
