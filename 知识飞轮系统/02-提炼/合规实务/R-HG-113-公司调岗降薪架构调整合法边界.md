# 公司调岗、降薪、架构调整的合法边界（劳动用工合规全景）

> 📌 本文为劳动用工专项「合规边界」素材：调岗/降薪/架构调整本质均为劳动合同变更，合法基础＝协商一致 + 法定单方例外；司法审查三要件＝目的正当性、程序合法性、结果合理性。

## 🔵 蓝方视角（企业合法操作路径）

1. **调岗三大合法情形**：① 双方协商一致（劳动合同法第35条第1款，书面优先，口头履行超1月且无违法可认定有效）；② 法定单方调岗（劳动合同法第40条三情形：医疗期满不能从事原工作／不胜任工作经培训或调岗仍不胜任／客观情况重大变化致合同无法履行且协商不成）；③ 劳动合同约定的合理调岗（约定不免除法定责任、排除劳动者权利，且须具合理性）。
2. **降薪四种合法情形**：① 协商一致降薪（书面，不得低于最低工资）；② 法定单方降薪（不胜任经培训/调岗后仍不胜任；或法定过错依合法有效规章制度扣减绩效，幅度合理）；③ 客观情况变化配套合理降薪（与调岗匹配、不低于最低工资）；④ 依法代扣（个税/社保/公积金/法院裁定抚养费赡养费，不超当月20%且余薪不低于最低工资）。
3. **架构调整三正当性**：目的正当（真实经营所需，非虚构避义务）、程序合法（提前告知、协商安置、裁员提前30日告知工会/职工并向劳动行政部门报告）、安置合理（调岗匹配技能、薪资匹配岗位价值、依法支付经济补偿N、不裁禁裁人员）。
4. **裁员法定程序**：裁20人以上或占职工总数10%以上；提前30日说明并听取意见；方案报劳动行政部门；优先留用长期合同/无固定期限/家庭无其他就业人员；依法支付经济补偿。

## 🔴 红方视角（违法风险 / 劳动者维权）

1. **违法调岗6种**：未协商也无法定单方情形强制调岗；侮辱性/惩罚性调岗；薪资福利大幅降低无依据；跨市跨省无补偿；针对「三期」女职工/五六级工伤职工擅自调岗；以调岗逼辞。
2. **违法降薪7种**：单方强制降薪；低于最低工资；末位淘汰降薪；经营困难无证据单方降；针对「三期」/停工留薪期降薪；以降薪逼辞；擅扣工资作罚款/违约金无依据。
3. **举证责任在企**：主张调岗/降薪/架构调整合法须证明目的正当、程序合法、结果合理；无法举证则调岗无效、补差额、付赔偿金。
4. **赔偿杠杆**：违法解除/违法裁员＝2N；劳动者因违法调整解除＝N；拒绝违法调岗可继续原岗，企业不得据此辞退。

## ⚖️ 实务落点（老强视角）

- 老强在办劳动用工合规（含民营企业、厚德基金会）：调岗降薪一律「书面 + 协商一致 + 合理性说明 + 举证留痕」四件套；架构调整须附经营必要性证据（财报/股东会决议/业务方案），避免「虚构部门撤销逼辞」被认定目的不正当。
