# 纸面合规识别与有效性评价

> **一句话内核**：2026 央企合规收官年，最大风险不是"没建体系"，而是"建了体系但无效"。验收不看材料厚度，只看运行痕迹；不看框架，只看是否嵌入业务。

---

## 一、内容结构（四层拆解）

| 层次 | 核心命题 | 关键论据 | 实务落点 |
|---|---|---|---|
| 问题定性 | 体系建成只是及格线，体系有效才是通关线 | 多家单位督导反馈"纸面合规"扣分：业务不执行、风险两张皮、审查流于形式、无闭环 | 审计/巡视/国资委督导直接判定"体系运行无效" |
| 识别特征 | 纸面合规四大典型特征 | 制度静态化、清单模板化、流程形式化、责任悬空化 | 没有运行、没有闭环、没有联动 = 纸面合规 |
| 评价维度 | 体系有效性只看五大能力 | 制度完备性、责任穿透性、流程嵌入性、风险可控性、闭环改进性 | 对标国资委验收标准+中石化/中船/中铝标杆实践 |
| 落地方法 | 一套可直接照搬的自评流程 | 资料对标→业务穿透→问题归因→整改闭环 | 制度用得上、流程跑得通、风险管得住、责任落得下、问题改得掉 |

---

## 二、蓝队视角（防御方：企业如何自查自改、告别纸面合规）

### 1. 纸面合规四大典型特征（先对号入座）
- **制度静态化**：制度多年不更新、不匹配最新监管、不贴合业务实际。
- **清单模板化**：照搬集团/外网模板，无本土化裁剪、无子企业穿透。
- **流程形式化**：合规审查后置、先决策后补流程、重大事项未刚性前置。
- **责任悬空化**：考核不挂钩、追责不落地、业务部门无合规压力。

### 2. 五位一体有效性评价——五大维度对标
| 维度 | 验收要点 |
|---|---|
| 制度完备性 | 4 个核心制度齐全，重点领域专项制度全覆盖，每年至少 1 次评估修订 |
| 责任穿透性 | 三级责任体系完整，配齐兼职合规管理员，首席合规官履职到位，子企业穿透 |
| 流程嵌入性 | 重大决策/大额合同/重大项目 100% 前置审查，留痕完整，否决事项真实落地 |
| 风险可控性 | 年度全面风险识别评估，红黄橙三级分级，重大风险一险一预案 |
| 闭环改进性 | 年度合规专项审计、体系自评、问题台账齐全，发现问题有整改/复核/销号 |

### 3. 体系有效性自评流程（四步可照搬）
1. **资料对标排查（查"有没有"）**：对照五位一体框架，逐项核对组织/制度/清单/机制/保障/考核/追责台账是否齐全。
2. **业务穿透抽查（查"用没用"）**：随机抽查投资、合同、采购、项目、资金等真实业务单据，核查是否前置审查、流程完整、真实落地。
3. **问题归因打分（查"好不好"）**：缺陷归类——制度/流程/责任/人员/机制问题。
4. **整改闭环迭代（查"改没改"）**：问题清单→整改清单→责任清单→销号清单，持续升级。

## 三、红队视角（攻击方：监管/督导/审计会怎么判定"无效"）

| 攻击点 | 具体打法 | 防守失败的典型表现 |
|---|---|---|
| 审查零否决 | 核查合规审查台账 | 全通过、零否决、零退回——典型形式化审查 |
| 风险无分级 | 看风险清单 | 全部标"高风险"，无分级无重点——风险管控失效 |
| 模板复用 | 抽查子企业 | 完全复制总部模板——未穿透、无本土化 |
| 自查零问题 | 查全年记录 | 无风险事件/预警/自查问题——自查流于形式 |
| 培训空转 | 抽问业务人员 | 台账齐全但一线不懂合规红线——培训无效 |
| 考核悬空 | 查薪酬挂钩 | 占比达标但从未实际扣分——考核不落地 |

> **红队最狠一刀**：真实运行痕迹缺失时，审计/巡视/国资委督导直接判定"体系运行无效"，一切制度文本不再构成抗辩。

---

## 四、规则抽取

**核心规则（见配套规则卡 R-HG-104）**：纸面合规识别与有效性评价。
- 判定标准：以"运行痕迹 + 嵌入业务 + 闭环改进"为唯一有效证据，制度文本厚度不抗辩。
- 六大高频扣分项（红队清单）构成自查明细。
- 五维评价 + 四步自评构成可复用方法论。
