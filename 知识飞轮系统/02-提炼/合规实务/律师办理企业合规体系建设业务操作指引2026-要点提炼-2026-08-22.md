# 律师办理企业合规体系建设业务操作指引（2026）（试行）要点

> 性质：上海律协业务操作指引，**非强制性/规范性规定**，仅供律师执业参考。
> 蓝队（企业/防御）：体系四要素——组织职责、制度建设、运行机制、合规文化；治理架构分层清晰，可据此搭建或体检。
> 红队（监管/攻击）：合规风险=违规引发行政/刑事/民事责任+经济声誉损失的可能性；"合规"须覆盖国家监管+行业自律+国际监管+企业内部四层要求。

## 一、制定依据（第2条）
《民法典》《刑法》《律师法》《公司法》《企业国有资产法》+《中央企业合规管理办法》《中央企业合规管理指引》《企业境外经营合规管理指引》+ **GB/T35770:2022** / **ISO37301:2021** + 各省国资委合规办法。

## 二、合规要求四层分类（第3条·名词解释）
1. **国家监管要求**：法律法规、地方法规、部门规章、地方政府规章、规范性文件、强制国标、监管规定/政策、司法解释、党内法规制度。
2. **行业自律要求**：行业规范/准则/标准、自律管理规定、通行惯例、商业惯例、最佳实践、商业道德规范。
3. **国际监管要求**：国际条约、规则、规范、国际合规管理趋势。
4. **企业内部要求**：章程、规章制度、合规政策、企业标准、内控要求、自愿/社会承诺、自设合规标准与道德准则、合同/协议约定义务。

## 三、治理架构与职责（第二章·核心）
| 主体 | 职责定位 |
|---|---|
| 党委（党组织） | 领导作用：把方向、管大局、促落实；国企党委(党组)统领，非公党组织政治引领 |
| 董事会 | 最高决策机构：审议批准基本制度/方案/年报，决定合规负责人任免薪酬，评价体系有效性 |
| 经理层 | 执行：将合规要求转为业务规则，组织应对重大风险事件，纠正不合规行为 |
| 企业主要负责人 | 法治建设**第一责任人**：重大决策法律与合规**双审制**、高风险业务分级管控、合规绩效挂钩 |
| 合规委员会 | 统筹协调（董事会下设专委会或法治建设领导小组） |
| 首席合规官/业务及职能部门/监督部门 | 各负其责 |

## 四、体系建设方法（第三章·框架）
合规管理体系四要素：**建立合规制度 + 完善运行机制 + 培育合规文化 + 强化监督问责**。将合规深度融入经营管理全过程，转化为核心竞争力。

## 五、不同类型企业合规要点（第四章）
国企/民企/外企/上市公司/金融机构等分型要点（指引详列，此处留源备查）。重点差异在党组织定位、境外经营合规、信息披露合规等。
