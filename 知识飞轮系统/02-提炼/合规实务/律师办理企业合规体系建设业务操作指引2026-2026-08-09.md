# 律师办理企业合规体系建设业务操作指引（2026）（试行）——上海律协

> **性质**：上海市律师协会企业合规专业委员会编制，**非强制性、非规范性规定**，属行业最佳实践参考。
> **对老强的价值**：这是目前国内**最系统的"律师视角"合规业务操作手册**——不是讲企业怎么做合规，而是讲**律师怎么把合规做成一门业务**。四章：总则 / 体系概述 / 业务方法 / 分类型企业要点。可直接作为承接合规顾问业务的作业底稿。

## 一、概念地基（第三条名词解释，务必精确使用）

**合规要求 = 四类来源**：
1. **国家监管要求**：法律法规、地方性法规、部门规章、规范性文件、强制性国标、监管政策、司法解释、**党内法规制度**
2. **行业自律要求**：行业规范/准则/标准/自律规定/通行惯例/商业道德
3. **国际监管要求**：国际条约、规则、国际规范、国际合规趋势
4. **企业内部要求**：章程、规章制度、合规政策、企业标准、内控要求、自愿性承诺、社会承诺、**合同中的合规义务**

**合规风险**：因违规引发行政/刑事/民事责任、经济或声誉损失及其他负面影响的可能性。
**监管机构**（范围比想象的宽）：行政处罚机关 + 公安/检察院/法院/监察机关 + 审计机关。
**合作伙伴**：供应商、中间商、代理商、服务商、经销商、客户、合资联营方等**任何有业务往来的第三方**。

## 二、组织架构：九类主体的合规职责（第4–12条）

| 主体 | 定位 | 关键职责摘要 |
|------|------|--------------|
| 党委（党组织） | 国企"把方向管大局促落实"；民企可政治引领 | 重大合规事务研讨、选人用人、党风廉政主体责任 |
| **董事会** | 最高决策机构，核心责任 | 审批基本制度/建设方案/年度报告；决定合规部门设置；**决定合规负责人任免与薪酬**；评价体系有效性 |
| 经理层 | 执行与管理 | 拟订方案与基本制度；**确保合规要求融入业务**；应对重大风险事件；及时制止纠正 |
| 企业主要负责人 | **法治建设第一责任人** | 推行**重大决策法律与合规双审制**；高风险业务分级管控；合规绩效挂钩 |
| 合规委员会 | 统筹协调 | 董事会下设专委会或与法治建设领导机构合署；定期开会、指导监督 |
| **首席合规官** | 专业领导（任职形式灵活） | 国企可由**总法律顾问兼任**；民企可由法务总监/运营高管兼任；外企可设区域合规官。**兼任者本职不得与合规职责冲突** |
| 业务及职能部门 | **第一道防线** | "管业务必须管合规"；须设专/兼职**合规管理员**（业务骨干担任） |
| 合规管理部门 | 牵头统筹 | 制度拟定、合规审查、风险识别处置、有效性评价、举报受理、培训与信息化 |
| 监督部门 | 独立监督 | 纪检监察/审计/巡视巡察；调查违规线索、问责整改 |

> 💡 **业务切入点**：绝大多数中小企业根本没有"首席合规官"这一层。指引明确其**可兼任**，这为律师提供了"外部合规官/合规顾问"的角色空间。

## 三、制度体系：三层结构 + 15 个重点领域

**三层结构**：基本制度（纲领）→ 具体制度/专项指南（针对性）→ 操作指引（细化流程）

**基本制度五要素**：总体目标、机构职责、运行机制、考核评价、监督问责。

**15 个重点领域**：公司治理、安全生产、环境保护、财务税务、劳动人事、知识产权、信息数据、反舞弊及反商业贿赂、反垄断、反洗钱、招标采购、关联交易、投资并购、资产租赁（管理）、融资担保。

**行业适配（重要方法论）**：
- 通用领域（**所有企业**）：公司治理、劳动用工、采购招标、财务税收
- 医药行业 → 反舞弊反商业贿赂、反垄断
- 互联网行业 → 信息数据
- 制造出口行业 → 知识产权、环境保护
- 金融行业 → 反洗钱

## 四、运行机制：十大机制（第18–28条）

风险识别 → 风险评估 → 风险预警 → 风险应对 → **合规审查** → 合规整改 → 违规举报 → 追责问责 → 协同运作 → 有效性评价 + 考核评价

**风险评估方法**：
- 定性：红黄绿灯分类法、五级分类法、**风险矩阵图法**、LEC 风险评价法、重大损失法
- 定量：潜在经济损失 × 发生概率

**合规整改的三大触发情形**（这是刑事合规的接口）：
1. **面临监管调查、可能被行政处罚或追究刑责 → 通过整改换取宽大处理**（"去违法化/去犯罪化"）
2. 违规已致声誉受损，需重塑信任
3. 日常发现制度缺陷，主动预防

**整改方案四层**：制度层（修订制度）+ 组织层（明确责任人与审批权限）+ 执行层（培训、风险预警系统、定期合规审计）+ 监督层（引入外部监管、**公开听证会验收**）

**违规举报机制的红线**：对举报人身份和事项**严格保密**；**禁止任何形式打击报复**（解雇、降职、骚扰）；企业须明确宣贯**反打击报复政策**。

## 五、第三章：律师作业方法（业务落地核心）

### 合规管理体系建设业务：十步法
1. **前期准备与工作规划**（五步）：启动倡议（签《合规承诺书》）→ 成立专项工作组（领导小组＋执行小组，可引入外部律所）→ **现状初步诊断与差距分析**（制度层/组织层/执行层三视角）→ 制定总体规划（短期1年、中长期3–5年含 ISO37301 认证）→ 建立沟通与保障机制（独立预算）
2. **梳理合规义务**：建法规数据库，从行业共性风险／地域监管特殊要求／企业自身业务特点三维度构建**合规义务清单并持续更新**，必要时**直接向监管机构咨询**
3. **目标企业合规审查**
4. **合规风险评估**
5. **出具合规管理体系建设方案**
6. **制定合规管理文件**
7. **体系实施**（六项落地动作）
8. **合规监督**（年度监督＋举报监督）
9. **持续改进**（义务清单动态更新＋运行反馈改进）

### 合规审查"四步法"（可直接抄作业）
① 业务部门提交审查申请 → ② 律师核查文件完整性/合法性 → ③ 按**合规审查清单**逐项核验作风险研判 → ④ 出具**《合规审查意见书》**，有问题则列问题清单、整改后复审

**六种审查手段**：问卷调查、访谈（须覆盖管理层/中层/基层关键人员）、资料查阅、**现场观察**、数据分析、第三方数据库查询。

**审查覆盖率标准**：常规业务可按固定模板抽查（如**每季度抽检 20% 合同**）；高风险业务建议 **100% 全覆盖**。

### 风险应对四策略
**规避**（终止高风险业务）/ **降低**（增加控制措施）/ **转移**（购买合规保险，如**董事责任险**）/ **接受**（低风险持续监控）

### 合规培训业务
- **五类培训对象差异化设计**：管理层（合规管理职责与引领作用）／合规法务风控岗（监管要求详解＋方法论）／全员（基本监管要求＋企业制度文化＋违法后果）／**合作伙伴**（反商业贿赂、数据安全、知识产权）／各业务部门（财务→财税；生产→安全环保；市场采购销售→反商业贿赂；HR→劳动用工；涉外→跨境支付/反洗钱反恐融资）
- **四个时间节点**：入职培训、定期培训、重大变化/风险培训、**不合规行为发生后的再培训**
- **培训记录留存**（律师服务的基础凭证）：培训资料、通知及签到、活动日程、评价、考核及处罚记录
- ⚠️ **协调性提醒**：避免脱离业务强调风险与禁令，造成部门与员工间对立

### 合规顾问/咨询业务的两个坑
1. 常年合规顾问合同**须与常规法律顾问服务明确区分**，写清具体内容与职责
2. **不得把合规咨询做成单纯的"法律风险提示"** —— 风险识别的同时必须给解决建议

## 六、第四章：四类企业合规要点对照

| 类型 | 核心抓手 | 特有风险点 |
|------|----------|------------|
| **国有企业** | **"三重一大"写进公司章程和合规制度**；合规审查＋党委前置研究＋管理层集体决策"三段式" | 国有资产保值增值与防流失（投资并购/资产处置/股权变动/关联交易/对外担保）、反腐倡廉、境外经营、**报告请示程序合规** |
| **涉外企业** | 出海企业：境外合规体系＋境内总部与境外实体的**合规汇报机制**；外商投资企业：聚焦**本地合规义务**兼顾母公司要求 | 反腐败、反洗钱反恐融资、出口管制与制裁、数据合规、反补贴、反垄断、国家安全审查。🔴 **禁止为被列入不可靠实体清单/出口管制与制裁清单的主体提供法律服务** |
| **上市企业** | 公司治理／关联交易／信息披露／证券交易与市场行为／日常经营重点领域 | 关联方清单动态维护＋关联董事回避表决；内幕信息"产生—流转—登记—知悉范围—保密"全链条防火墙；短线交易预防监控；减持合规 |
| **民营企业** | **先评估企业家及管理层的合规价值观** | 🔴 **如企业家对合规底线缺乏敬畏，律师应谨慎承接，不得为规避监管甚至违法犯罪提供帮助**；重点处理**人格混同、账户混同、资金挪用、财产侵占** |

> 🔥 **民企部分最狠的一条**：把"客户价值观评估"写成了**执业风险控制的前置程序**。这实际上是律师的自我保护条款——合规业务做不好会被反噬。

## 七、可复用的执业动作清单

1. **承接前**：评估实控人合规价值观（民企）／确认是否涉制裁清单主体（涉外）
2. **诊断阶段**：制度层—组织层—执行层三视角差距分析表
3. **交付物清单**：合规义务清单、合规风险识别清单、合规风险清单（含等级/损失/概率）、《合规审查意见书》、合规管理体系建设方案、基本制度＋重点领域制度＋操作指引、《合规风险评估报告》（季度报董事会）、年度合规报告
4. **收费结构建议**：体系建设（项目制）＋ 首年落地辅导（顾问制）＋ 年度考核服务（可续期）
