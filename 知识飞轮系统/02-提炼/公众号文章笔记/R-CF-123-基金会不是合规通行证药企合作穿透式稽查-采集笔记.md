# 采集笔记

## 一、文章主旨
驳斥"拉基金会进来就合规"的迷思。审计署2024审计报告（2025-06）已点名：4家基金会打着慈善旗号营利3.41亿、12家学协会不当获利3.08亿；国家卫健委"六个应当、六个严禁"（国卫办医急函〔2023〕469号）严禁药企直接给医生讲课费、严禁学术讲课与产品推广挂钩。基金会合作≠合规，穿透式稽查看"五流是否一致+闭环"。

## 二、关键蒸馏点
- 四类违规特征：资金闭环、指定受益、变相推广、费用转嫁 → 任一即高危红旗。
- 五流合一（合同/信息/资金/票据/业务）是财税穿透核心。
- 内部管控四领域：数据/流程/权责/风险。
- 非学术项目（患者教育/疾病筛查/基层培训/市场调研/数字化平台）可直接与专业第三方合作，不必硬拉基金会。
- 警惕"过票型"基金会（无独立能力/管理费畸高/信披缺失/关联交易）。
- 评估矩阵：公益性/独立性/透明度/必要性/风险可控性。

## 三、与在办案件/顾问衔接
- 厚德基金会承接药企合作（医疗救助、科研资助、患者教育）前须过"公益性+独立性+必要性"三关。
- 与 R-CF-122（关联交易）、R-CF-125（三道关）、R-CF-114（韩红采购疑云）形成药企×基金会合规卡族。
