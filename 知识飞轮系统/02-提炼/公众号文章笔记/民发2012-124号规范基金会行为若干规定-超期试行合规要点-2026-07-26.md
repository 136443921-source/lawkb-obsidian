# 民发〔2012〕124号《关于规范基金会行为的若干规定(试行)》— 超期试行与合规要点

> 说明：本文为 IMA 慈善库《民政部124号文超期试行》提炼。原文 IMA 取文受限（code 220030），以下以**民发〔2012〕124号《关于规范基金会行为的若干规定(试行)》**（民政部2012-07-10印发）原文及后续配套规范为骨。该文件标题即带"试行"且已逾14年未转正，其"超期试行"状态本身是慈善合规治理的观察点。

## 一、文件定位与效力

- 文号：民发〔2012〕124号；性质：**部门规范性文件（试行）**，现行有效但长期处于"试行"。
- 上位法：《公益事业捐赠法》《基金会管理条例》《基金会信息公布办法》。
- 适用：各级各类基金会（含具有公开募捐资格的慈善组织参照）。

## 二、核心规范要点（小德视角逐条）

### （一）接受公益捐赠
1. 与捐赠人明确权利义务，按需订立**书面捐赠协议**。
2. 实际收到捐赠后**据实开具捐赠票据**；匿名/不需求的也须开票留存备查。
3. 非现金捐赠：受赠财产未经基金会验收确认、由捐赠人直接转第三方的，**不得作为捐赠收入、不得开票**。
4. 入账价值：有发票/报关单凭据的以凭据为准；凭据金额与公允价值差异大的以公允价值为准；固定资产/股权/无形资产/文物文化资产须第三方评估；无法评估的不计入收入、不得开票、另册登记。

### （二）使用公益财产
- 严格按捐赠协议/章程宗旨使用；不得擅自改变用途。
- 项目终止后剩余财产：按协议或章程处理，及时公开（衔接《慈善组织信息公开办法》第九条）。

### （三）保值增值（投资）
- 合法、安全、有效原则；须经理事会决议；不得向个人/利害关系人违规出借或担保。
- 投资活动风险控制：建立投资决策与风险控制机制。

### （四）关联交易
- 基金会与理事/监事近亲属及其控制企业交易须**回避表决**；交易条件不得优于非关联方。
- 关联交易信息依法公开。

### （五）信息公开
- 主动、及时、准确公开公益资助项目、捐赠接受使用、财务收支等信息。

## 三、"超期试行"的合规反思

1. **规范层级问题**：作为"试行"部门规范性文件，其部分要求已被2016《慈善法》、2018《慈善组织信息公开办法》、2023修法、2026-01-01施行的新修订《慈善组织信息公开办法》吸收并升级；适用时应**以新法优先**，旧文仅作操作细化参考。
2. **与现行法冲突处理**：如旧文某项与新修订《慈善组织信息公开办法》（2026-01-01施行）不一致，依**新法优于旧法、上位法优于下位法**适用。
3. **基金会内控落地**：厚德基金会应将该文要点内化进《财务管理办法》《捐赠管理办法》《投资管理办法》《关联交易管理办法》，而非仅依赖"试行"文件。

## 四、对厚德基金会的具体动作清单

- [ ] 修订《捐赠管理办法》：明确非现金捐赠验收确认前置、票据据实开具
- [ ] 修订《投资管理办法》：理事会决议留痕、关联方回避、第三方评估
- [ ] 关联交易：建立关联方清单 + 回避表决 + 信息公开"三件套"
- [ ] 项目剩余财产处理：终止后3个月内公开（衔接新信息公开办法第九条）
- [ ] 年度财务会计报告须经审计（新信息公开办法第六条）+ 重大资产变动30日内公开

> 内规引用：依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》相关章节（捐赠管理、预决算管理、投资活动、关联交易、信息公开），本笔记要点应纳入手册年度复审。

## 五、风险提示

| 风险点 | 后果 | 防控 |
|---|---|---|
| 非现金捐赠未验收即开票 | 票据违规、税务风险 | 验收确认前置 |
| 保值增值无理事会决议 | 决策瑕疵、追责 | 决议留痕+回避 |
| 关联交易未回避 | 利益输送嫌疑、信息公开违规 | 关联方清单+回避表决 |
| 依赖"试行"文件忽略新法 | 合规滞后 | 以2026新信息公开办法为准 |
