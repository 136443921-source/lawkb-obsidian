# 企业常见法律问题100问（上） — 商事合规要点提炼

> 说明：本文为 IMA 合规监管库《企业常见法律问题100问（上）》提炼。原文 IMA 取文受限（code 220030），以下以法院系统发布的企业法律风险防控指南（孝南《企业法律风险防范120条》、梅州中院《民营企业常见法律风险防范指南》136条、济源中院《企业常见法律风险及防范指南》）为骨，按五大板块归纳高频风险点。

## 一、合同管理（最高频）

1. **主体确定风险**：公司与股东个人不分，忽略合同相对人确定 → 债务责任主体争议。签约时看清抬头/落款用的是公司还是个人名义。
2. **文本保存风险**：完备书面合同缺失致逃避违约责任 → 签署一式多份、内容一致、妥善保存。
3. **员工授权风险**：授权不明由企业对业务人员越权担责 → 授权书细化范围，业务结束及时收回，离职发客户通知。
4. **履行证明风险**：收货/付款无有权人员签收或凭证 → 保留签收与付款凭证，向公司或有权人交付。
5. **质量异议风险**：异议超期或检材灭失致抗辩不采信 → 约定期内提异议、固定样品。
6. **效力认定风险**：违反效力性强制规范/公序良俗→合同无效 → 审查合同内容合法性。

## 二、劳动用工

1. **不签书面合同**：超1个月付双倍工资，超1年视为无固定期限 → 入职即签。
2. **未投工伤保险**：发生工伤由单位按标准全额支付 → 依法参保。
3. **违法解除**：无法举证合法解除→支付赔偿金；未按时转社保致不能享失业待遇→赔偿。
4. **规章制度**：未公示/未民主程序→制度无效；调岗降薪须协商一致。

## 三、知识产权

1. **商标抢注/不规范使用**：注册后不规范使用仍侵权；攀附知名商品构成侵权。
2. **图片字体侵权**：从图库随意取图用于宣传→著作权侵权。
3. **合法来源抗辩**：购进商品侵权但无发票收据→抗辩不成立→赔偿。
4. **商业秘密**：核心算法/客户名单未签保密协议→被离职员工带走维权无据。

## 四、合规经营（行政）

- 市场监管：虚假宣传、不正当竞争、**垄断行为**
- 税务：偷税漏税、发票违规
- 环保/安全生产：超标排放、未落实安全保障
- 数据：非法收集/泄露用户信息（违反《数据安全法》《个人信息保护法》）

## 五、企业家刑事风险

- 集资诈骗、非法吸收公众存款（特许经营）
- **拒不支付劳动报酬罪**：转移财产/逃匿逃避支付，经政府责令仍不支付→定罪；公诉前支付+赔偿可减轻免除
- 虚假诉讼、职务侵占、挪用资金

## 律师服务衔接

上述风险点可直接转化为：企业法律顾问《法律风险体检清单》、合同模板库审查要点、劳动用工合规 SOP。与同日《公司法务反垄断合规极简手册》合并构成"企业法务合规双轴"（反垄断 + 商事通用风险）。

> 关联：厚德基金会作为非营利组织，合同/劳动/知识产权风险亦适用（如物资采购合同、员工劳动合同、徽标著作权）；刑事风险中"拒不支付劳动报酬"与公益组织劳务用工密切相关。
