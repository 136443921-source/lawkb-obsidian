# 社会组织换届：社会团体与社会服务机构的规则分野

> **一句话内核**：换届的合规风险，八成来自"用错类型的规则"。社会团体受**届次 + 年龄**双重限制，社会服务机构（民非）**只受年龄限制、可连选连任**。

---

## 一、基本原则与程序要求

**根本遵循**：依章程而行，按程序推进。

| 要求 | 具体内容 |
|---|---|
| 按时换届 | 必须按照**章程规定的任期**，按时完成换届 |
| 延期/提前 | 因特殊原因需延期或提前换届的，须**事先**向业务主管单位和登记管理机关**提出申请，获批后方可实施** |
| 公开公正 | 换届全过程应公开、公正，符合《社会团体登记管理条例》《民办非企业单位登记管理暂行条例》及本组织章程 |

---

## 二、核心对比：社团 vs 民非

| 维度 | 社会团体（协会/商会/联合会等） | 社会服务机构（民办非企业单位） |
|---|---|---|
| **负责人范围** | 会长（理事长）、副会长（副理事长）、**选举制**秘书长、监事长 | 理事长、理事等理事会成员及负责人 |
| **届次限制** | 同一职务**连任不得超过两届** | **不受届次限制，可连选连任** |
| **年龄上限** | 原则上**不超过 70 周岁** | 同样**不超过 70 周岁** |
| **政策考量** | 促进领导层良性更替，保持组织活力与治理公正 | 保持特定专业领域内领导与管理的**稳定性与专业性** |

### 易错点：选举制秘书长
若秘书长**由选举产生**，则同样适用届次与年龄限制；若为聘任制，则不落入该限制范围。**判断标准是产生方式，不是职务名称。**

### 民非"可连任"≠"不用换届"
虽可连选连任，但**任期届满仍应依章程履行换届程序**；需更换负责人或法定代表人的，在符合条件的前提下按程序进行。

## 三、换届流程四步（含时点）

```
T-6个月  启动筹备 → 成立换届工作领导小组 → 制定换届方案
   ↓
方案沟通  报业务主管单位 + 登记管理机关，必要时预先审核
   ↓
程序执行  理事会 → 会员（代表）大会 → 选举投票 → 形成决议 → 报送备案
          （每一步留有记录、可追溯）
   ↓
换届后    向登记管理机关报送材料，办理负责人备案 + 必要时事项变更登记
```

**关键时点**：至少**提前半年**启动换届筹备。

---

## 四、蓝队视角（机构自检清单）

- [ ] **类型识别**：先确认本机构是社会团体还是社会服务机构，再套用对应规则（这是最容易出错的第一步）
- [ ] **任期核算**：对照章程逐一核算现任负责人的届次与年龄，提前锁定"到届"与"到龄"人员
- [ ] **秘书长产生方式**：核查章程规定的秘书长是选举制还是聘任制，确定是否受限
- [ ] **时点倒排**：以章程任期届满日倒推 6 个月，设置筹备启动闹钟
- [ ] **延期/提前审批**：如需变更时点，务必**事前**申请，不得先斩后奏
- [ ] **留痕完整**：理事会决议、大会签到、选票、计票记录、决议文本逐项归档
- [ ] **备案闭环**：换届完成后及时报送，避免"选了没备案"的悬空状态

## 五、红队视角（监管/异议方会打哪里）

| 攻击点 | 破绽表现 | 后果 |
|---|---|---|
| **超届次连任** | 社团会长连任第三届 | 选举结果不予备案，决议效力存疑 |
| **超龄任职** | 负责人已超 70 周岁仍当选 | 备案受阻，需重新选举 |
| **类型混用** | 民非套用社团届次限制被迫换人，或社团套用民非"可连任"超届 | 治理结构失当，可能引发内部争议诉讼 |
| **逾期未换届** | 章程任期届满未换届亦未申请延期 | 属治理失范，可能触发年检降级、责令改正 |
| **未事前审批** | 先开会换届，事后补报延期/提前申请 | 程序违法，换届效力可被否定 |
| **留痕缺失** | 无签到表、无计票记录 | 内部成员提起决议撤销之诉时机构举证不能 |
| **备案脱节** | 换届已完成但未办理负责人备案/变更登记 | 对外法定代表人与实际负责人不一致，签约效力风险 |

## 六、实务风险卡片

**卡片 1｜"到届"与"到龄"的双重筛查**
- 场景：社团换届，拟连任会长已满两届且年满 68 岁。
- 结论：届次限制单独即构成障碍，年龄尚未触线但下一届任期内将超龄。
- 动作：换届方案中同步做**本届 + 下届**的任职资格预判，避免中途被迫补选。

**卡片 2｜民非的稳定性红利与治理风险并存**
- 场景：民非理事长连任五届，理事会长期未更新。
- 结论：法律上不违规（不受届次限制），但**内部制衡弱化**是实质风险，易滋生关联交易、内部人控制。
- 动作：即便可连任，也应通过监事设置、独立理事、任期届满重新选举等机制维持制衡；对照本机构章程与内部合规手册的治理条款自查。

**卡片 3｜换届与法定代表人变更的衔接**
- 场景：换届选出新理事长，但未办理法定代表人变更登记。
- 结论：对外仍以登记机关记载为准，新任负责人以机构名义签约存在越权代表风险。
- 动作：换届备案与法定代表人变更登记**同步办理**，过渡期内对外文件签署权限书面明确。

> **内规衔接提示**：厚德基金会等具体机构操作时，除上述通用规则外，还应对照《贵州省厚德公益基金会合规管理手册（试行）（2025版）》"机构架构"与"劳动人事"相关章节的任职资格、决策程序与备案要求逐项核验，以内规条款为直接依据。
