# 慈善组织公开募捐合规要点（蓝红双视角）

> 来源：公开权威源降级摄入（民政部《慈善组织公开募捐管理办法》2024 版 + 新修改《慈善法》）。原定 IMA「慈善组织合规AI助手」库摄入，因 IMA 运行态掉线改用公开源。基金会内部可对接《贵州省厚德公益基金会合规管理手册（试行）（2025版）》公募章节深化。

## 一、蓝队视角（慈善组织·合规路径）

1. **公募资格取得**（2024 版办法第 5 条，门槛已由"满2年"降为"满1年"）
   - 条件：治理结构规范；理事会来自同一/关联组织不超 1/3、近亲属不同时在任；监事履职（省级以上登记须 3 名以上监事的监事会）；健全内控制度；慈善支出与管理费用合规；纳税合规；评估 3A 及以上（成立不满 2 年除外）；未列异常/失信；申请前 1 年无处罚。
   - 民政 20 日内决定，发公开募捐资格证书。

2. **募捐方案备案**（活动前 10 日报民政）
   - 单次活动一般不超 3 年（重大突发事件不超 1 年）；**每项单独备案，不得合并**；
   - 内容：目的、起止时间与地域、负责人、接受捐赠方式、银行账户、预期数额、受益人（不得为特定个人）、用途、募捐成本（最必要原则）、剩余财产处理。

3. **活动规范**
   - 现场/载体显著位置公布组织名称、证书、方案、联系方式、查询方法；
   - 互联网募捐须在民政部指定平台；
   - 合作募捐：有资格方主导、评估合作方、签书面协议、全部收支纳入有资格方账户，合作方不得自行募捐。

4. **财产与公开**
   - 变更用途须理事会审议 + 备案 + 公开；采购不高于市场公允；
   - 周期超 6 月每 3 月公开一次，结束 3 月内全面公开；项目超 6 月同频。

## 二、红队视角（监管/合规审查·风险面）

- **无资格擅自公募**：警告 + 责令退财 + 收缴 + 2–20 万元罚款（慈善法第113条）。
- **一般违规**：伪造出借证书、超期/超地域、未公布信息 → 警告 + 限期改正；未报备方案 → 依慈善法第110条处理。
- **吊销**：不符条件或违法 → 立即停止公募，吊销后 **5 年内不得再次申请**。
- **合作方责任黑洞**：无资格方以自身名义募捐导致责任主体不清，有资格方承担法律责任——评估与协议是防火墙。

## 三、可复用合规清单

- [ ] 资格存续（证书有效、未列异常）
- [ ] 方案单独备案（不合并、不超期）
- [ ] 合作方评估报告 + 书面协议 + 账户统一
- [ ] 现场/平台信息完整公示
- [ ] 成本最必要 + 用途变更理事会决议 + 公开
