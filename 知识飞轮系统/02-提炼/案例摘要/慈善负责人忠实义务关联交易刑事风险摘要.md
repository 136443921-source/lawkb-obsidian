# 案例摘要：慈善组织负责人忠实义务与关联交易刑事风险

- **案由**：慈善组织治理/关联交易/刑事合规
- **核心规则**：慈善法第14条禁止发起人/主要捐赠人/管理人员利用关联关系损害慈善组织利益；关联交易须回避表决+公开。
- **典型案例素材**：
  - 儿慈会案：监事未发现/未制止前受助人私自以项目名义诈骗近千万元 → 民政部停止活动三个月、列入严重违法失信名单、相关负责人移送司法。
  - 某教育基金会案（2024）：未披露关联交易被处罚，近半资金流向理事亲属控股服务商。
  - 韩学臣案（慈孝特困老人救助基金会）：虚构项目侵占资金+向社会集资未用于公益 → 集资诈骗罪无期徒刑。
- **裁判/合规要旨**：违背忠实义务操纵不正当关联交易致重大损失 → 可能构成失职/滥用职权类犯罪；负责人须落实"回避+公开+公允"三要件。
- **关联法条**：慈善法14条、基金会管理条例20–24条、刑法253条之一（侵犯公民个人信息）
