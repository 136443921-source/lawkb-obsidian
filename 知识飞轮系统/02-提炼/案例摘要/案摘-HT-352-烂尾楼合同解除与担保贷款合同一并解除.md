# 案例摘要 · R-HT-352 烂尾楼合同解除与担保贷款合同一并解除
- **案号/入库**：(2024)苏09民终4784号 / 入库编号2025-07-2-091-001（最高法入库参考案例）
- **案由**：房屋买卖合同纠纷（商品房预售 + 担保贷款）
- **核心裁判要旨**：开发商不能交房致使合同目的落空，买受人可一并解除商品房买卖合同与担保贷款合同；合同解除后由出卖人承担已收受的购房贷款、购房款本金及利息返还责任。
