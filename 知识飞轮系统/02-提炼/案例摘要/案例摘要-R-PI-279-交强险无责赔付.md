# 基本案情

机动车交通事故中，无责方车辆未依法投保交强险。受害人请求无责方及其保险公司在交强险范围内赔偿。保险公司以无责为由拒赔。

# 裁判理由

交强险具强制性、无过错赔偿性，赔付不以被保险车辆驾驶人过错/责任为前提（皖高院、青山区法院案例）。无责方保险公司须在无责限额内承担无责赔付。多车事故未超各车限额之和的，按限额比例分摊（道交赔偿解释第21条）。未依法投保交强险的，投保义务人在交强险责任限额范围内赔偿（道交赔偿解释第16条）。重庆高院案例：未投保无责方万某应在无责限额内按比例赔钟某。(2023)包头青山区法院：张某未投交强险及三者险，与骑电动车主责的赵某碰撞，判张某在限额内无过错赔137,218.45元，二审维持。

# 裁判要旨

1. 交强险无责也赔（无过错责任），无责限额19900（医疗1800/伤残18000/财产100），有责20万（医疗1.8万/伤残18万/财产0.2万）。
2. 未投保交强险→投保义务人在限额内承担无过错赔偿。
3. 赔偿顺序：交强险→商业险→侵权人（民法典1213）。
