# 基本案情

患者就诊后，医疗机构诊疗过错与患者原发病情、个人体质等共同造成人身损害。患方主张医疗机构承担全部赔偿责任。

# 裁判理由

法院认定"多因一果"：医疗过错、原发疾病、个人体质共同致损。诊疗过错、因果关系及原因力大小，以有医疗专业资质鉴定机构结论为主要判断依据（(2022)豫民申2385号河南高院）。法院依原因力比例判赔，医方仅对其过错参与度部分担责。赔偿计算：先按"一果"算全赔额，再按各侵权人原因力比例分摊，分担之和不超全赔额（(2020)宁民申749号）。无法鉴定时，医方隐匿/伪造病历致鉴定不能的承担举证不能全赔后果。

# 裁判要旨

1. 原因力六分（全部/主要/同等/次要/轻微/无），鉴定意见须明确表述。
2. 医方仅对其过错参与度部分担责；比例实证：最高法公报王某主动脉夹层案酌定20%，江苏"不当用药"轻微因素案酌定25%。
3. 过错推定三情形（民法典1222）：违反诊疗规范、隐匿拒供病历、伪造篡改销毁病历。

# 关联法条

- 民法典第1218条："患者在诊疗活动中受到损害，医疗机构或者其医务人员有过错的，由医疗机构承担赔偿责任。"（来源：《中华人民共和国民法典》·主席令第45号·现行有效·[qcc-legal](https://www.qcclegal.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1713?source=mt)）
- 民法典第1222条："患者在诊疗活动中受到损害，有下列情形之一的，推定医疗机构有过错：（一）违反法律、行政法规、规章以及其他有关诊疗规范的规定；（二）隐匿或者拒绝提供与纠纷有关的病历资料；（三）遗失、伪造、篡改或者违法销毁病历资料。"（来源：同上·[qcc-legal](https://www.qcclegal.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1717?source=mt)）
- 医疗损害司法解释(2020)第11条："委托鉴定书，应当有明确的鉴定事项和鉴定要求。……下列专门性问题可以作为申请医疗损害鉴定的事项：（一）实施诊疗行为有无过错；（二）诊疗行为与损害后果之间是否存在因果关系以及原因力大小；……"（来源：最高人民法院《关于审理医疗损害责任纠纷案件适用法律若干问题的解释（2020年修正）》·法释〔2020〕17号·现行有效·[qcc-legal](https://www.qcclegal.com/regulation/0ea3c264ecc91eec80ad0834f946e7ed/11?source=mt)）
- 医疗损害司法解释(2020)第12条："鉴定意见可以按照导致患者损害的全部原因、主要原因、同等原因、次要原因、轻微原因或者与患者损害无因果关系，表述诊疗行为或者医疗产品等造成患者损害的原因力大小。"（来源：同上·[qcc-legal](https://www.qcclegal.com/regulation/0ea3c264ecc91eec80ad0834f946e7ed/12?source=mt)）
- 医疗损害司法解释(2020)第16条："对医疗机构或者其医务人员的过错，应当依据法律、行政法规、规章以及其他有关诊疗规范进行认定，可以综合考虑患者病情的紧急程度、患者个体差异、当地的医疗水平、医疗机构与医务人员资质等因素。"（来源：同上·[qcc-legal](https://www.qcclegal.com/regulation/0ea3c264ecc91eec80ad0834f946e7ed/16?source=mt)）
