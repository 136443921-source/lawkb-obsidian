# 基本案情

职工异地工作，在法定节假日/约定休息日提前一日从居住地返回单位宿舍途中发生交通事故受伤。人社局以"事发非工作日、非上班途中"不予认定工伤，复议维持。职工提起行政诉讼。

# 裁判理由

重庆市第一中院（(2019)渝01行终310号·最高法公报2022年第5期）：王志国家住重庆江北、工作地万州相距约280公里，惯常假期最后一日返岗。为次日上班作准备、提前一日18时返岗符合常理与公司考勤要求，具备"上下班目的"正当性与"合理时间+合理路线"。撤销不予认定工伤决定。同理（(2015)盐行终字第00079号）：提前下班途中受非本人主要责任交通事故，依法认定工伤（提前下班系劳动纪律问题，不剥夺工伤救济权）。

# 裁判要旨

1. "上下班途中"三要素：合理时间+合理路线+合理目的，不要求唯一/最短路径。
2. 提前下班、异地提前返岗均可能认定；违反禁止性规定且不具备合理性（如高速应急车道行走）则不认定。
3. 合理路线四情形（法释〔2014〕9号第6条）。

# 关联法条

工伤条例14(6)；法释〔2014〕9号第6条（本地缺源，statute_text_pending）。
