# 案摘-PI-603 · 缺陷医疗产品的惩罚性赔偿

**案由**：医疗产品责任纠纷｜**来源**：最高法医疗损害解释（法释〔2017〕20号，2020修正）第22–23条
**关联规则**：R-PI-603

**核心裁判要旨**：生产者/销售者**明知**医疗产品（药品/器械/血液）存在缺陷仍生产、销售，造成患者死亡或健康严重损害的，被侵权人可请求赔偿损失及所受损失**二倍以下惩罚性赔偿**（参照消法第55条第2款）；缺陷产品与医疗机构过错共同致损的，患者可请求连带责任。

**要点**：① 惩罚性赔偿以"明知+缺陷+严重损害"为要件；② 一般医疗产品责任（无过错/过错推定）与惩罚性赔偿须区分。
