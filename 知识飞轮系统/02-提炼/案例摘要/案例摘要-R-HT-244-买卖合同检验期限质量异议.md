# 基本案情

买受人签订买卖合同购货架/建材等，收货后长期未提质量异议，后拒付货款并另诉以质量瑕疵要求解除合同。出卖人主张买受人已付款/使用标的物视为认可质量。

# 裁判理由

法院依《民法典》第620、621条：买受人收到标的物应及时检验并在合理期限/约定检验期限内通知；无约定且未在**收到货物之日起二年内**通知的，视为数量或质量符合约定（二年为不变期间）。买受人在二年最长期间经过后主张质量不符，不予支持。出卖人已交付发票、有货单照片佐证交付，付款请求成立。

# 裁判要旨

1. 质量异议须于合理期限或二年最长期间内提出，逾期失权（视为符合约定）。
2. 已付款/使用标的物**不视为放弃异议**（法释〔2020〕17号第13条），但本案买受人系"根本未提异议"而非"提了异议后被反推放弃"，故不适用第13条保护。
3. 锚定：雅菲案6660"货款已清=质量认可"防御依第13条不成立；6658案质量异议超期则失权。

# 关联法条

民法典620/621/622；法释〔2020〕17号12/13/14条（本地2012旧版须回填）。
