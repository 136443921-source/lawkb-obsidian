# 基本案情

某基金会以"捐赠"为名帮助企业推广养生茶等营利产品，被民政部门认定违反公益慈善无偿性、公益性、非营利性及章程宗旨，作出行政处罚；基金会提起行政诉讼，主张其活动符合公益目的。

# 裁判理由

北京市高级人民法院（(2019)京行终2321号）：基金会以捐赠为名帮助公司从事营利活动、推广产品，违背了公益慈善的无偿性、公益性、非营利性特征，亦违反章程规定的宗旨和业务范围。行政机关处罚有据，法院维持。同批民政部处罚案例（民罚字〔2017〕14号等）涉及超业务范围活动、未妥善保管捐赠财产（养生茶过期损失36万）等。

# 裁判要旨

1. 慈善组织关联交易受《慈善法》第14条两款约束：不得利用关联关系损害利益 + 交易须回避决策并信息公开。
2. 以捐赠为名附利益回报、帮企业营利，构成违法，触发第99条责任（警告→停活整改→吊销）。
3. 合规双程序：回避决策 + 信息公开；不得附加企业宣传/产品销售条件。

# 关联法条

慈善法14/99条；基金会管理条例20–24条；《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易治理条款。
