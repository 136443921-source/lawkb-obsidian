# 律师办理民事案件案由选择操作指引（2026）（试行）

> 来源：IMA 律师库（上海市律协民事专业委员会，2025-12 通过、2026 试行，依据法〔2020〕347 号《民事案件案由规定》）。聚焦案由的体系定位与检查顺序。

## 蓝队视角（防御·案由选定方法论）

案由是案涉民事法律关系性质的概括，直接决定管辖、审理庭室、案件方向与结果。选定须"先纵后横"：

1. **纵向定位顺序**（确保思考完整性，避免前提问题干扰）：
   非讼程序案由 → 特殊诉讼程序案由 → 特殊侵权责任纠纷（侵权责任编具体案由优先）→ 特殊法律关系纠纷（婚姻继承/劳动/知识产权/海商/公司证券保险票据）→ 合同纠纷 → 无因管理 → 物权纠纷 → 不当得利 → 人格权 → 一般侵权责任。
   *逻辑*：特殊优先于一般；合同须双方约定最特殊故劣后；无因管理阻却物权/侵权违法性故先于物权；物权变动结果后于原因行为（合同）。
2. **横向定位顺序**：优先第四级案由，无则第三级，再第二级，再第一级（从特殊到一般）。
3. **物权纠纷协调适用**：诉讼请求仅涉一种物权请求权的，优先"所有权/用益物权/担保物权纠纷"四级案由；涉两种以上请求权的，适用相应三级/二级案由。

## 红队视角（攻击·案由攻防要点）

- **案由非起诉条件**：法院不得以"无对应案由"裁定不予受理或驳回起诉（第十一条）。对方以案由不当抗辩受理的，直接引此驳回。
- **请求权竞合时的策略选择**：特殊侵权与合同等竞合时，按证据与诉请选最有利请求权基础定案由（如电视机爆炸可产品责任或买卖合同）。
- **立案与审理阶段分属不同主体**：立案案由由原告定（竞合时由当事人选择）；审理中法院依查明关系变更。增加/变更诉请致关系变化的，法院变更案由。
- **选择性案由须拆分**：如"生命权、身体权、健康权纠纷"应按实际选其一，不得整组直接引用（第十二条）。

## 实务要点 / 规则提炼

- 区分物权变动的"原因行为"（合同/准合同→合同纠纷、无因管理项下）与"结果行为"（物权设立/权属/效力→物权纠纷项下）。
- 涉多个法律关系的，按诉争关系确定；均为诉争的并列确定案由（第十条）。
