# 实习律师指南（一）：民事案件的咨询与接案

> 来源：李乐多整理薛晓蔚《实习律师指南》｜IMA 律师AI助手库定点摄入（backlog 补摄）

## 一、核心框架（九步）
电话约见 → 约见前准备 → 倾听 → 判断 → 建议 → 接案 → 办手续 → 收费 → 差旅费。

## 二、提炼要点
1. **电话约见即第一印象**：用声音传递自信，简短有力沟通；以"好吗"征询意见体现尊重；初次会见地点原则上在律所，勿在饭店贪图享受而赴约。
2. **倾听先于判断**：先浏览当事人材料再听叙述；告知当事人律师须知真相、有保密义务；只听"事情经过"不听"对是非的评论"，避免被带偏独立思考。
3. **判断"能不能打、值不值得打"**：原告侧先查主体资格（利害关系）、证据充分性、法律依据、案件性质与管辖；被告侧评估原告主张是否充分，给出和解/不出庭（仍交书面答辩）/应诉三出路。
4. **接案审慎**：明显有理或无理的简单案件，可坦诚告知当事人律师参与意义有限；不熟领域不盲目接案"临阵磨枪"。
5. **手续与授权**：委托合同须由**律所**与当事人签订（不得私自接案）；授权应区分一般授权与特别授权，特别授权须明确范围且向当事人释明意义，不主动索要。
6. **收费合规**：政府指导价+累进计费；风险代理仅限财产关系民事案件且受除外情形限制（《律师服务收费管理办法》——婚姻继承、社保低保、赡养抚养抚育抚恤救济金工伤赔偿、劳动报酬等**禁止**风险代理；刑/行/国家赔偿/群体性诉讼亦禁止；最高不超标的额30%）。

## 三、执业警示（老强批注）
- "看活不看死"：败迹明显的案子不接，避免当事人将败诉归咎于律师水平；但众律所皆判无望而你独辟蹊径翻盘者，方为大律师。
- 切勿为少交事务所而"降代理费、增差旅费"耍小心眼，易损声誉。
