# 韩杰医生完整申诉原文与7大疑点（医疗事故罪再审辩护镜像素材）

> 📌 本文为老强在办「韩杰医生医疗事故罪再审辩护」案的镜像素材。原文含韩杰完整申诉书 + 作者归纳7大疑点，核心命题：「医疗疏漏≠刑事犯罪，常规过失≠严重不负责任」。

## 🔵 蓝方视角（对韩杰 / 再审申请有利）

1. **申诉基调清晰**：韩杰在申诉原文中明确「承认诊疗存在疏漏、愿担行政/民事责任，但坚决不认可达到刑法『严重不负责任』、构成医疗事故罪的程度」——先划清「错的性质」边界。
2. **疑点① 无尸检倒推因果链**：患儿死亡后未做尸检，鉴定死因仅为「可能性大」。刑事定罪标准要求「排除合理怀疑」，「可能性大」不足以支撑因果链唯一性。
3. **疑点② 嵌顿发生时间存疑**：凌晨接诊时腹部「稍膨隆、尚软」、无剧烈腹痛；上午7点仍排大量绿色稀便（肠道未完全停止排空）；真正恶化集中在下午1点（交班之后）。「嵌顿发生在谁当班」无法仅凭病变倒推。
4. **疑点③ 上级查房背书却不担刑责**：上午8点科主任查房认可方案、未提出纠错，卫健委对上级亦仅警告停职。上级查房背书过的方案，刑责却全由基层值班医生一人承担。
5. **疑点④ 多环节介入、一人背全责**：接班医生、上级查房、外科接诊、家属自行驱车2小时转院，全程多环节介入；法院认定医院承担85%民事责，但100%刑责归韩杰。
6. **疑点⑤ 家属转运决策未评估**：已出现剧烈腹痛、面色苍白、腹胀加重的患儿，家属自行转运2小时，途中呼吸心跳骤停——该决策在因果链中的权重未被评价。
7. **疑点⑥ 执业仅4月：能力性失误 vs 态度性失误**：安排了立位片、补液、生化检查，主观有救治意愿；漏诊嵌顿疝更偏经验不足。1987年《医疗事故处理办法》曾区分技术事故与责任事故，技术过失不予刑事立案。
8. **疑点⑦ 同案不同判**：福建李建雪案（产妇大出血死亡，一审判有罪）二审改判无罪，关键理由＝未做尸检死因不明 + 全程规范履职；韩杰案争议点几乎一致，结果却相反。

## 🔴 红方视角（不利 / 风险提示）

1. **既定裁判未动摇**：一审已判医疗事故罪（有期徒刑一年）、二审维持；申诉改判门槛极高，终审未回应其三项核心质疑（首诊负责制 / 严重违反诊疗规范 / 漏诊延误救治）。
2. **多因叠加但归责于韩杰**：省儿童医院死亡诊断五项叠加（心跳骤停、感染性休克、肠梗阻、嵌顿疝、多脏器衰竭），法院将主要责任锁定于首诊漏诊。
3. **实务铁律**：医疗事故罪再审翻案极难，通常需新证据（尸检报告、新鉴定）或明确法律适用错误；单纯「疑点列举」不足以启动再审。
4. **风险外溢**：同类「基层夜班医生执业数月即入刑」案型，对青年医师执业风险具有普遍警示意义，亦提示医疗机构应压实三级查房与交接班留痕。

## 🔗 与老强业务关联

- **韩杰案再审辩护**：本文直接支撑「医疗事故罪构成要件争议」「因果关系证明标准」「严重不负责任认定」三大再审突破口；李建雪案可作类案检索锚点（未尸检→无罪）。
- **人伤执业通用**：急诊首诊、交接班留痕、病历记载「需陪护/加强营养」等合规要点，与人伤案件证据战同源。
