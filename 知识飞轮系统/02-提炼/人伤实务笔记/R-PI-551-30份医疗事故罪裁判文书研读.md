# 30份医疗事故罪裁判文书研读——「严重不负责任」越过刑事红线的类型化

> 📌 基于30份公开裁判文书的样本统计与类型化分析（已匿名）。样本：30起独立案件，22起致死（73%），法定最高刑3年。

## 🔵 蓝方视角（辩护 / 出罪边界）

1. **定罪四要件**：①特殊主体（取得执业资格的医务人员）；②主观过失且限于「责任事故」（技术事故不构罪）；③客观「严重不负责任」+ 法定损害后果；④刑法因果关系要求医疗过错对损害起「主要以上」作用。
2. **罪与非罪界限**：仅「就诊人死亡」或「二级以上（含二级）医疗事故（重伤/严重残疾）」才入罪；四级（明显人身损害）不入罪。界分医疗差错、医疗意外、医疗技术事故。
3. **从宽情节普遍**：坦白/自首/认罪认罚/积极赔偿谅解 → 缓刑与免罚适用率高。免予处罚4起多因「医方仅次要责任 + 积极赔偿取得谅解」。
4. **标杆无罪案**：福建李建雪案、厦门大学附属第一医院案均因「未做尸检、死因不明、因果关系不具唯一性」改判无罪——印证因果关系与死因严格证明是罪与非罪关键。

## 🔴 红方视角（风险集中带 / 控方统计）

1. **样本画像**：致死22起（73%）；量刑实刑15（47%，刑期多6月—2年）、缓刑10、免予处罚4、拘役1、驳回自诉1。定罪案件中实刑与非实刑约各半。
2. **违规类型化（六类）**：
   - 用药不当 15起（50%）：未皮试即静点头孢/青霉素致过敏性休克死亡、配伍禁忌混用；
   - 超范围执业/无资质操作 7起（23%）：助理医师无指导主刀、无麻醉资质实施全麻、医美无主诊资质；
   - 擅离职守/未观察 4起（13%）；
   - 违反无菌操作/交叉感染 2起（7%）：重复使用器材致38人染丙肝、5人染HIV；
   - 手术/诊疗技术失误 1起（3%）；其他自诉案1起。
3. **主体分布**：乡村医生/基层53%、执业医师及技术人员30%、护士及护理13%——有资质者同样可因业务过失入罪。
4. **医美独立高风险板块**：无全麻资质下脂肪填充致肺栓塞死亡、违规抽脂致19岁坏死性筋膜炎死亡等。
5. **责任程度不阻却定罪**：即便医方仅次要责任，只要刑法因果关系成立仍定罪，仅量刑从宽。

## 🔗 与老强业务关联

- **韩杰案再审**：直接引用「因果关系主要以上」「技术事故不构罪」出罪逻辑；对比样本「擅离职守/未观察」型与韩杰「漏诊」型之异同。
- **医疗美容合规**：含灵生物等医美类业务审查可参照「超范围执业/无资质操作」红线与无麻醉条件下操作的高风险定性。
- **人伤辩护通识**：医疗事故罪与过失致人死亡罪（特殊主体 vs 一般主体，法条竞合特别法优先）、与非法行医罪（有/无执业资格）的界分。
