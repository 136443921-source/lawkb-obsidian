# 医院法治建设刚性化：合规审核一票否决与三路径全流程嵌入

> 📌 四部门《关于加强医院法治建设的意见》落地：合规从"事后补救"转为"法治先行、风险预判、全程留痕、闭环溯源"；2026 公立医院合规由"可选"升级为"必守底线"。

## 🔵 蓝方视角（医疗机构 / 合规体系建设）
1. **三条刚性红线**：①重大事项合规审核"一票否决"（未审不得上会/实施，审核结果入决策档案，倒查追溯）；②法治穿透业务一线（质控、病历、知情告知、耗材、学术交往常态化自查）；③一案双查（诊疗风险+行风+法律责任同步溯源，同类反复追科室主任/职能/院级一岗双责）。
2. **三路径嵌入**：质控（制度合法性前置审查+日常法律风险核查清单+不良事件法治复盘）、行风反腐（廉洁风险排查法治化、线索处置程序闭环、科室一岗双责）、纠纷处置（事前预警、事中封存留痕严禁擅自认错、事后多元调解+司法确认+根因复盘）。
3. **三级责任清单**：院领导（第一责任人，会前学法/年终述法）、职能中枢（医务/质控/行风，法律风险核查+纠纷复盘台账）、临床科主任（一线法治第一关口，规范告知与病历、苗头上报不私了）。
4. **时间表**：2026 年底制度搭建→2027 中期流程落地→长期合规文化。

## 🔴 红方视角（监管 / 问责风险点）
1. **"先实施、后补手续"留法律隐患**：新规明确杜绝，重大事项未过法务审查即上会实施将被倒查。
2. **网络医闹纳入应急**：自媒体造谣炒作须第一时间固定电子证据、依法报警，线上线下同步处置。
3. **高额赔付个人敲定风险**：大额赔偿方案须法务审核+班子集体研判，杜绝个人私自敲定。

## 🔗 与老强业务关联
- **厚德基金会 / 小德慈善医疗合规**：基金会所涉医疗服务合作、捐赠资助须对照"廉洁风险排查法治化"与"合规审核一票否决"建立审查机制。
- **韩杰案延伸**：医院"一案双查"与"严禁未经核查擅自承认过错"恰是医疗纠纷处置的合规底线，可反向印证个案中程序瑕疵。
