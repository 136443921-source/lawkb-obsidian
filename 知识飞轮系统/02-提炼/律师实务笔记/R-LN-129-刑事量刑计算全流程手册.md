# 刑事量刑计算全流程手册（四层结构＋调节比例总表）

## 一句话摘要
量刑不是套公式，而是"定性为主、定量为辅"的四层结构（起点刑→基准刑→情节调节→宣告刑）；辩护发力点在于把每一个从宽情节坐实并争取到上限比例，且认罪认罚与自首/坦白等不作重复评价。

## 🔵 蓝队视角（辩护/量刑协商）
**一、规范地图（双层结构）**
- 中央定框架：两高《关于常见犯罪的量刑指导意见（试行）》（2021-07-01，规范23种犯罪）+《（二）（试行）》（法〔2024〕132号，2024-07-01，新增7种，合计30种）。
- 各省定刻度：具体月数由省级法检实施细则填充，脱离本地细则谈"几个月"不可靠；两套文件并用并核对现行版本。

**二、量刑四层结构**
1. 起点刑：依基本犯罪构成事实，在法定刑幅度内确定；
2. 基准刑：依其他影响构成的数额/次数/后果，在起点刑上增加刑罚量；
3. 情节调节：自首/立功/认罪认罚/累犯/退赃等，同向相加、逆向相减；
4. 宣告刑：调节结果加全案综合考量，五规则校验，必要时20%幅度内微调。
- 分工：起点刑、基准刑依据"犯罪事实"（已然危害）；情节调节依据"量刑情节"（可谴责性与预防需要）。把退赃塞进基准刑、把次数当情节重复调节，均为结构性错误。

**三、调节比例总表（现行有效幅度，逐项对应原文）**
- 从宽：未成年人12-16岁减30%-60%、16-18岁减10%-50%；75岁以上故意/过失减40%以下或20%-50%；又聋又哑/盲人减50%以下；未遂比照既遂减50%以下；从犯减20%-50%；自首减40%以下；坦白一般/同种较重/避免严重后果减20%以下/10%-30%/30%-50%；当庭自愿认罪减10%以下；一般/重大立功减20%以下/20%-50%；退赃退赔减30%以下；赔偿谅解（赔+谅/仅赔/仅谅）减40%以下/30%以下/20%以下；刑事和解减50%以下；羁押表现好减10%以下；认罪认罚一般减30%以下、兼具自首等减60%以下。
- 从重：累犯增10%-40%（一般不少于3个月）；前科增10%以下；对象为老幼残孕等增20%以下；灾害期间故意犯罪增20%以下。

**四、多情节并存算法**
- 调节结果＝基准刑×（1－从宽比例之和＋从重比例之和）；先适用责任刑修正情节（未逐/中止/从犯等），再适用预防刑与政策情节（自首/认罪认罚等）。
- 20%是"微调"不是"重算"；只有从轻情节、调节结果再低也只能落法定最低刑，突破须有法定减轻情节。

## 🔴 红队视角（公诉/量刑建议反制 + 辩护误区）
- 连乘法（0.6×0.7×0.8）会系统性低估从宽幅度（实应同向相加），公诉人用连乘会给出偏重建议、辩护人用连乘会低估可争取空间；
- 重复评价：认罪认罚与自首、坦白、退赃退赔、赔偿谅解、刑事和解、羁押表现好不作重复评价，逐一叠加求和是常见错误；
- 只有从轻情节却期待突破法定最低刑，不可能；应通过"认定从犯""认定自首"等法定减轻情节打开空间；
- 直接用中央指导意见幅度当本地结论，忽略省级实施细则的月数换算标准。
