# 捐赠返利骗局与退捐两难：公募机构募捐风控

> 📌 本文为厚德基金会「互联网募捐反诈/退捐风控」素材：广州多家公募机构遭「捐赠返利」刷单诈骗围猎，恤孤助学会四年间涉诈退捐1138宗、53.26万元；机构陷「退款助长骗局、不退频遭投诉」两难。

## 🔵 蓝方视角（机构风控可落地动作）

1. **骗局链条识别**：① 养信任钓小鱼——微信群发布「捐款返利」任务，诱导在正规平台小额捐、兑现返利、教以「误捐」理由申请退款，形成套利错觉；② 核心收割——转私码/陌生链接大额转账，资金不经机构对公账户。
2. **异常特征筛查**：固定小额（19/29元）、短时间高频重复捐赠、批量任务群刷屏虚假退款截图；平台大数据风控可拦截异常小额批量捐款。
3. **守住不退底线**：捐款完成即转化为对受助群体刚性承诺，随意退款透支行业公信力、伤害真正困难群体；行业共识＝不退不是冷血，是守护初心。
4. **多方共治建议**：民政/公安/金融监管/支付平台联动建慈善账户反诈白名单；推动行业统一涉诈捐赠退款标准，消除规则漏洞。

## 🔴 红方视角（法律边界 / 两难风险）

1. **公益捐赠不可随意撤销**：慈善法——公益捐赠属无偿、自愿、不可随意撤销民事行为；民法典——存在重大误解/受欺诈的捐赠，须由法院或仲裁机构依法裁决撤销，机构无自主判定、随意退款权限。
2. **退与不退皆有隐患**：退款助长套利（成功退款截图被传播成「可随意退捐」凭证）；不退则遭舆情反噬、监管投诉、账户冻结（在途善款/救助项目停摆）。
3. **核查权有限**：警方立案仅代表侦查流程，不证实被骗事实；机构不具备核查诈骗真伪、甄别虚假申诉的能力与权限。
4. **尺度不一被利用**：部分机构息事宁人退款、部分依规不退，「可拿捏」机构被精准围猎，加剧诈骗泛滥。

## ⚖️ 实务落点（老强视角）

- 厚德基金会互联网募捐：① 前台醒目反诈提示（引用公安部民政部2024-12-18风险提示）；② 退捐严格核查、仅凭法院/仲裁撤销裁决或警方实证办理，不自主退款；③ 异常高频小额捐赠联动平台风控；④ 遇围猎统一口径、留存证据、及时报警并报告民政。
