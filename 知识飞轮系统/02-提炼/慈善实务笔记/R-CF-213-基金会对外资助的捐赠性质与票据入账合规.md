# 基金会对外资助的捐赠性质与票据入账合规

> 📌 本文为厚德基金会「对外资助/资助票据」合规素材：财政部2026-05答疑称「基金会资助不属于对外捐赠、不得使用公益事业捐赠票据」，引发行业误读。核心澄清＝资助法律性质仍是捐赠，答疑仅限票据管理。

## 🔵 蓝方视角（对基金会/受资助方有利 / 可落地结论）

1. **资助本质就是捐赠**：符合「自愿、无偿、用于公益事业」三要素即构成法律意义上的捐赠；慈善法第34条、公益事业捐赠法第2条均未区分「捐赠」「资助」为不同法律行为，二者仅语境不同。
2. **财政部答疑范围＝票据管理，非法律定性**：依据是公益事业捐赠法第17条（基金会每年资助额不得低于规定比例），本意是防止同一笔善款重复开票、重复统计；财政部职权限于票据管理，无权对「捐赠」法律含义作终局解释。
3. **受资助方仍作捐赠收入入账**：依据民间非营利组织会计制度，受资助方凭「资助协议＋银行转账凭证＋收款收据」确认捐赠收入（而非捐赠票据），按是否限定明细核算；不受票据规范影响。
4. **免税待遇不受影响**：企业所得税法第26条、实施条例第85条、财税〔2009〕122号明确「接受其他单位或个人捐赠的收入」为免税收入；资助款属此列，取得免税资格即享优惠。

## 🔴 红方视角（风险提示 / 易踩坑）

1. **重复开票风险**：基金会用募集捐款资助时，若受资助方再开捐赠票据，导致同一笔慈善资金统计重复——正是财政部答疑要封堵的乱象，机构须主动避免。
2. **自有资金资助例外**：基金会用「自有资金（募集捐赠款以外资金）」对外捐赠，接受方可以开捐赠票据；须分清资金来源再决定票据口径。
3. **实操三件套**：① 签书面资助协议明确资金用途与性质；② 受资助方不开捐赠票据、以协议+转账+收据入账；③ 会计仍确认捐赠收入并明细核算。

## ⚖️ 实务落点（老强视角）

- 厚德基金会对外资助（含专项/社区基金拨付）：一律签书面资助协议、取得收款收据入账、受资助方不开捐赠票据；会计确认捐赠收入并按限定性明细核算，免税资格下依法享优惠。
