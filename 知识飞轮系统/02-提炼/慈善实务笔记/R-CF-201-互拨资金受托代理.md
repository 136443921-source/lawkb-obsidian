# R-CF-201 基金会互拨资金受托代理 vs 捐赠收入认定（实务笔记）

## 一、蓝队视角（合规立场 / 良性理解）
- 厘清"别的基金会拨来的钱"究竟记什么科目，是基金会财务、审计的高频难题。
- 核心定论：**合作基金会拨付的、属对方对外募集的公益资金，接收方不确认捐赠收入，仅按受托代理资产核算**。
- 受托代理资产范围依据《民间非营利组织会计制度》涵盖资金、存货、固定资产、无形资产等资产类科目。

## 二、红队视角（风险 / 审查立场）
- **科目误用风险**：把受托代理资金错记捐赠收入 → 收入虚增、科目混用，年度审计/民政检查/税务稽查中易被整改扣分。
- **边界误判风险**：受托代理只认"钱和物"，**不含服务类业务**；纯服务委托无资产转移，不能套用受托代理账务。
- **口径缺失风险**：服务类合作民非制度无统一核算标准，开票（是否开增值税发票）及账务处理以税务机关认定为准，属财税灰色地带，须谨慎、勿随意入账开票。

## 三、规则抽取（对应规则卡 R-CF-201）
- 判定规则：对方以自有非募捐资金（结余、投资收益）无偿捐赠 → 可记捐赠收入；对方募集而来的资助款项 → 一律受托代理，禁计捐赠收入。
- 受托代理边界：仅适用于资产类业务（资金/实物/无形资产），服务类合作不适用。
- 服务类合作：以税务机关官方认定意见为准。
- 关联票据义务：若误将受托代理记为捐赠收入并开具捐赠票据，将触发慈善法第三十八条的票据合规问题。

## 四、业务关联（厚德基金会合规）
- 关联《贵州省厚德公益基金会合规管理手册（试行）（2025版）》收入确认与受托代理核算相关章节，具体条款以手册文本为准。
- 建议：① 与兄弟基金会互拨前先做"资金来源性质"判定（募捐资金 / 自有非募捐资金）；② 建立受托代理台账，与捐赠收入科目严格隔离；③ 服务类委托合作单独走服务核算流程，开票前先取得税务口径确认，避免票据违规。
