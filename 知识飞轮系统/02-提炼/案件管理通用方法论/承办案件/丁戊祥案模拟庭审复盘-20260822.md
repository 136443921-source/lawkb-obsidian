## 四、临场最大变量与预案

1. **丁戊祥不到庭**：程序战推进受阻 → 坚持笔迹鉴定+调取授权委托书；实体战同步备位；
2. **丁戊祥到庭但反悔**（称"起诉是我授意的"）：立即出示《未起诉说明》原件+现场照，申请法官当庭询问"为何此前书面否认、何时改变主意、授权何人起诉"——**当场对质**；
3. **丁戊祥到庭确认未起诉**：程序战当场锁定，请求当庭裁定驳回起诉+审查冒名诉讼；
4. **法官倾向"补正继续审理"**：立即切换实体战（合同相对性+买受人黄茂姣+金额矛盾），并继续保留追责后手。

## 五、风险提示（执业层面）

1. **与丁戊祥的接触合规**：所有取证（书写说明、拍照、补签）须有见证人/录音，防被反指"诱导伪证"（《刑法》306条/《律师法》40⑤）；
2. **笔迹鉴定周期**：耗时数月，程序战节奏需与法院排期配合，勿孤注一掷等鉴定；
3. **刑事控告审慎**：虚假诉讼罪有认定门槛，作为威慑牌而非必胜牌（民诉法115条+刑法307条之一）；
4. **勿在庭审中过度主张**：避免"必然虚假诉讼"等绝对化表述，用"恳请审查"留余地（10号异议书已规范）。

## 六、可复用方法论：冒名诉讼庭审攻防清单（沉淀）

**识别四查**：无公章 / 本人否认 / 签名与登记姓名不符 / 幕后利害关系人操控
**证据三件套**：本人书面说明+现场照 / 盖章自认书证 / 登记信息（身份证+营业执照）
**庭审三请求**：通知到庭核实 / 笔迹鉴定（起诉状+授权委托书一并）/ 调取委托材料查实际委托人
**反扑三应对**：笔误补正→"前提是本人所签" / 授权真实→"签名真实≠授权起诉+查委托人" / 诱导伪证→"见证人+录音+现场照"
**追责后手**：案内制裁（民诉法111）→ 刑事控告（刑法307-1）→ 行政投诉（律师法40⑤/49/50）→ 民事赔偿（民法典1165）

## 七、v2 增量环节经验（2026-08-22 23:37 第二轮模拟，QC-Controller 全程管控）

**新增三个实战环节及经验**：

### 增量1：授权委托书"三查"打法（钥匙证据）
当庭核验授权委托书不止看签名，要一次要齐三样：
1. **查签名**——与起诉状签名笔迹比对（一致则两处均系冒签，一并送鉴定）；
2. **查委托人**——调取律所《委托代理合同》看委托人是黄茂姣还是丁戊祥（委托人=黄茂姣则"冒名起诉"闭环）；
3. **查关联**——授权委托书与起诉状是否同一批材料、同一时间形成（立案卷宗可查）。
> 一句话：**"看签名是入门，查委托人是命门"**。

### 增量2：证据"自认"点破术（新增筹码，胜率+2%）
对方对登记信息类证据（身份证/营业执照）常当庭自认无异议——**主动逼出这个自认**，再反手一击：
- 原告自认登记姓名"丁戊祥" → 起诉状签名"丁茂祥"写的是不存在的名字 → 签名人不知真实姓名 → 冒签逻辑闭环；
- 战术要点：让法庭"记入笔录"，把对方自认固化为书证，再与签名检材对照。
> 一句话：**"逼对方自认登记信息，然后让签名自己打脸"**。

### 增量3：丁戊祥到庭"三连问"对质预案（防反悔）
情形B（到庭反悔）是程序战唯一破绽，预案：
1. 2026-08-20 为何亲笔签署《未起诉说明》并愿出庭作证？
2. 今日改称授意起诉，**授意何人、何时、以何方式**？
3. 起诉状"丁茂祥"署名是否本人所书？
> 配合《未起诉说明》原件+现场照当庭出示，请求法庭先查说明真实性。
> 一句话：**"反悔不可怕，三连问+原件对质锁死矛盾"**。
