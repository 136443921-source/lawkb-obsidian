# 实习律师全流程 SOP 体系（27 项标准操作流程）

> 来源：IMA「律师AI助手」· 魏水水（2026-07-20）。
> 定位：从接案到结案的完整标准化流程，把重复性/高风险/能力训练型工作固化为 SOP——实习律师进阶的底层操作系统。

## 一、27 项 SOP 全景（七大板块）

| 板块 | SOP 编号 | 内容 |
|------|---------|------|
| 一、案件接收与信息整理 | 1-4 | 新案件建档、材料接收归档、时间轴整理、利益冲突检索 |
| 二、法律检索与研究 | 5-7 | 法律检索、类案检索、法律备忘录 |
| 三、诉讼/仲裁文书 | 8-13 | 起诉状、答辩状、证据目录、质证意见、代理意见、调解和解方案 |
| 四、庭前准备与庭审支持 | 14-16 | 庭前准备、庭审记录、庭后复盘 |
| 五、客户沟通与团队协作 | 17-19 | 会议纪要、材料清单、工作汇报 |
| 六、程序推进与执行 | 20-24 | 立案材料、保全申请、执行申请、上诉/再审、送达签收 |
| 七、风险控制与质量管理 | 25-27 | 期限管理、文件校对、结案归档 |

## 二、高价值 SOP 要点提炼

### SOP 1 新案件建档（价值最大）
利冲检索 → 建文件夹 → 统一命名 → 案件信息表 → 当事人梳理 → 法院/案号/法官/书记员记录 → **录入重要期限** → 材料目录 → 标注缺失材料 → 案件类型确认 → 收费/开票确认。

### SOP 5 法律检索（核心基本功）
明确问题 → 拆关键词 → 查法规 → 查司法解释 → 查指导/公报/典型案例 → **查本地法院裁判观点** → **查相反观点** → 输出结论+依据+链接+不确定性标注。
强制项：有无相反案例？本地口径？最新解释/纪要？是否区分案由/层级/时间/地域？

### SOP 8 起诉状（请求部分专项检查清单）
本金准确？利息起算日有据？暂计日期明确？律师费/保全费/担保费？诉讼费承担？多被告共同/连带/分别？

### SOP 10 证据目录（最易出错）
按证明目的分组 → 编号 → 名称 → 页码 → 证明目的 → 原件/复印件核对 → 电子纸质一致 → 编号连续 → 名称与附件一致 → 证明目的对应诉请。

### SOP 11 质证意见（避免空泛）
不认可真实性要具体到："该材料系单方制作，未加盖我方印章，且无原始载体佐证；即便真实性成立，也不能证明对方主张的付款义务已经届满。"

### SOP 16 庭后复盘（成长最快）
庭审结果 → 法官关注点 → 对方新观点 → 我方亮点/短板 → 补充材料清单 → 下一步 → 案件走向判断。

### SOP 21 保全（金额防错）
保全金额≠诉请金额机械相等，核对本金/利息/违约金/费用是否重复计算；诉前保全注意起诉期限。

### SOP 25 期限管理（绝不犯错）
识别期限 → 记录起算日 → 计算届满日 → 节假日顺延核对 → **两级提醒** → 同步负责律师 → 案件表记录 → 区分法定期限/法院指定期限（后者可申请延期）→ 每周一核对机制。

## 三、SOP 化的三类工作

1. **重复性**：归档、证据目录、立案材料、庭前准备；
2. **高风险**：期限管理、金额计算、文书校对、保全申请；
3. **能力训练型**：法律检索、类案检索、时间轴、质证意见、庭审复盘。

> 心得：SOP 不是一次写完不改——每过一个案件反向沉淀新步骤/检查点/分支。
