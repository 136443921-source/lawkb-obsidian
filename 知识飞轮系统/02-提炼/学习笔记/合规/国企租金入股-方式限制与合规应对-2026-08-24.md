# 国有企业"租金入股"的方式、限制与合规应对 — 贵州视角笔记

> 来源：微信公众号「言若商业合规律师」（北京浩天贵阳分所杨茜律师，贵州），2026-03-16 发布，收于 IMA 合规与政府监管AI助手库。政策背景：贵阳《关于加快推进全市产业用房高质量发展的指导意见》（筑府发〔2025〕13号）创新"以房招商"；2026-01-01《中央企业违规经营投资责任追究实施办法》施行。

## 一、法律定性

"租金入股"本质是股东以其对目标公司享有的**租金债权作价出资**。
- 《公司法》第48条：股东可以货币、实物、知识产权、土地使用权、股权、**债权**等可用货币估价并可依法转让的非货币财产出资；
- 《市场主体登记管理条例实施细则》第13条：债权出资须权属清楚、权能完整、可评估可转让、符合章程；
- 《企业国有资产评估管理暂行办法》第6条：整体资产或部分资产租赁给非国有单位、以非货币资产对外投资，**应当评估**。

三个法定条件：①可评估作价（须评估机构评估，不得自行定价）；②可依法转让（租赁合同无禁止转让条款）；③权属清楚、权能完整（无质押等负担）。

## 二、三种主要模式

1. **模式一：租金债权直接转股**——园区将物业出租给目标公司，同时以租金债权作价出资成为股东。适用成长期企业。须**双重评估**（租金债权+目标公司股权）+公开招租。
2. **模式二：租金缓交+股权转化**——设考核期，签附条件生效的转股协议（《民法典》第158条附条件民事法律行为），达标则债权评估作价入股，未达标补缴租金+资金占用费。宜昌三峡创谷8%股权认购权案例。
3. **模式三：先收租金后货币投资**——严格区分"租金收取债权"与"货币投资股权"两个法律关系，合规性最高。可适用《贵州省国资委监管企业国有资产评估管理暂行办法（修订）》（2025-10）第8条公开挂牌+3个以上近期成交信息的评估豁免。

## 三、合规风险（案例警示）

1. **程序违规**：未履行公开招租程序 → 国资监管要求解约（5000万五年租金果品市场案例）；
2. **尽调缺失**：未尽职调查+可行性研究即投资 → 违规经营投资（昆山蛋壳公寓6亿国资案例，负责人被纪委调查）；
3. **退出机制缺失/小股东权益架空**：未约定知情权、退出机制 → 国企被套牢3年损失超亿（依《国有企业参股管理暂行办法》第10条）；
4. **集体决策≠集体免责**：《中央企业违规经营投资责任追究实施办法》——集体决策违规造成损失须承担集体责任+个人责任，明确反对者可免责。

## 四、八步合规流程

尽职调查（资产+合作方）→ 投资可行性研究 → 资产评估（关键环节）→ 内部决策与国资审批（"三重一大"留痕）→ 协议设计（对赌调整机制/小股东保护/预设退出通道/禁止转租）→ 公开招租 → 履约与登记 → 投后管理与动态监控。

## 五、对赌条款合规

九民纪要立场：对赌协议有效，但实际履行与公司减资或利润分配程序严格绑定；违反国资进场交易程序可能无效。租金优惠建议作为定价依据在招租文件明确披露，不宜事后随意减免。
