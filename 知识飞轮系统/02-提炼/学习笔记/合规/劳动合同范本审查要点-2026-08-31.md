# 劳动合同范本（供参考）审查要点 蒸馏笔记

> 原文：企业法律顾问团队（2026-01-02）——劳动合同书标准范本。

## 一、范本结构（对应 R-LN-041）

| 章 | 内容 | 关键条款 |
|---|---|---|
| 一 | 劳动合同期限 | 固定/无固定/以完成工作任务为期限三型；试用期约定 |
| 二 | 工作内容和工作地点 | 岗位（工种）、工作区域、工作标准 |
| 三 | 工作时间和休息休假 | 标准/综合计算/不定时工时；特殊工时须行政许可 |
| 四 | 劳动报酬 | 月薪+试用期工资（≥同岗位最低档 80% 且≥最低工资）；待工生活费 |
| 五 | 社会保险 | 依法参保；患病/工伤待遇 |
| 六 | 劳动保护/职业病防护 | 安全防护措施、劳保用品、职业病防治 |
| 七 | 解除/终止/经济补偿 | 出具证明+15日内转移档案社保；交接后支付补偿 |
| 八 | 其他约定 | 补充条款 |
| 九 | 争议处理 | 调解→仲裁；可直接仲裁 |

## 二、合规要点

1. **试用期工资红线**：≥本单位相同岗位最低档工资 80% 或约定工资 80%，且≥当地最低工资
2. **工时制度**：综合计算/不定时工时须事先取得人社部门行政许可
3. **解除证明与转移**：解除/终止时出具证明，15 日内办理档案+社保转移手续
4. **经济补偿**：办结工作交接时支付
5. **文本双签**：一式两份，甲乙各执一份

## 三、在办业务连接

- 厚德基金会/企业顾问：劳动合同审查与员工关系合规
- 慈善组织劳动人事合规（基金会用工）

## 四、法条体检

- 《劳动法》✅ 现行有效
