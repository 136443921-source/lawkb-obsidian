# 公司合规与风控法律意见书：范本框架与写作要点

> 来源：IMA「合规与政府监管AI助手」· 熊猫法律星球（2026-04-22）。
> 定位：企业合规法律服务核心文书——识别评估企业运营法律风险、提供合规指导与风险防控措施，作为企业履行合理注意义务的证明。

## 一、文书六段式结构

| 部分 | 核心内容 |
|------|---------|
| 一、前言 | 目的+审查基础（基于公司提供材料及适用法规） |
| 二、适用法律与政策依据 | 公司法/民法典/税收征管法/劳动法/反垄断法/网安法数据安全法个保法+行业规范；按法律层级排列 |
| 三、公司合规现状分析 | 公司治理（董事会/章程）/合同管理（模板/签约流程）/财税（纳税申报/关联交易转移定价）/劳动用工（合同/社保公积金）/知产与数据（商标专利/个保法） |
| 四、潜在法律风险及防控建议 | 逐项对应：修订章程/风险预警机制/标准合同库/签约授权清单/税务顾问/财务信息化/劳动合同优化/数据合规手册 |
| 五、紧急预案及危机处理 | 法律顾问制度/危机管理预案（合同违约/劳动纠纷/数据泄露）/定期更新风险评估 |
| 六、结论 | 总结+落实分工+动态调整 |

## 二、写作要点（"建议-理由-实施路径"逻辑）

1. **前言**：简洁交代审查背景，强调资料客观性全面性；
2. **法律依据**：按层级排列（先国家法律后行业标准），覆盖合同/税/劳动/数据保护；结合行业增加特定法规；
3. **现状分析**：按板块逐一分析，每部分=当前做法+发现问题+对公司影响；缺陷与风险点具体描述；
4. **风险与建议一一对应**：如"合同管理建议→建立标准合同库→定期法务审查"；
5. **危机预案**：针对不同类型法律风险给出具体应急步骤；
6. **结论**：概括+明确落实方向（部门分工执行）+动态评估优化。

## 三、常见风险与问题

- 信息不全或不准确→建议不全面；
- 法规更新未涵盖→体系需调整；
- 建议缺乏可操作性→难以实施；
- 过于依赖通用建议→忽视行业与公司特殊性。

## 四、实务定位

- 文书价值：帮助理解法律地位与责任、预防纠纷、保护企业股东利益、减少诉讼成本；也是律师提升合规领域专业技能、增强客户信任的抓手；
- 与诉讼文书差异：非对抗性文书，面向企业管理层/决策层，重"诊断+方案"而非"论证+请求"。
