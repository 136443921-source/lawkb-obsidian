# 公益行业薪酬是否合理，到底谁说了算（四把尺子+四方决策）

> 来源：公益慈善论坛（2026-07-18）｜当日摄入（backlog 补位）｜关联 [[R-CF-051]]
> 一句话价值：**薪酬合理性=法律划底线+市场给参照+岗位定等级+绩效证价值**；决定权在理事会拍板、法律把关、市场参照、公众监督四方制衡；最大障碍是观念（公众道德绑架+行业自我阉割）。

## 一、合理薪酬四把尺子

1. **法律红线**：《慈善法》60 条——公募基金会年度管理费用（含薪酬）不得超过当年总支出 **10%**；财政部/税务总局——非营利组织工作人员平均工资不超过当地同类岗位平均水平 **2 倍**。超线即违法。陈行甲恒晖 5.3%、韩红 2.86% 均远低于红线。
2. **市场秤杆**：公益需与企业抢人。《基金会薪酬观察报告（2025）》：秘书长年薪中位数仅 **9.11 万元**、专职人员仅 **6.6 万元**，公益平均薪酬约为市场同类岗位 **六成**。
3. **岗位砝码**：管 3 亿资金的秘书长 vs 管 3 万物资的专员，责任天差地别；韩红基金会年收入逾 7 亿、5A 级组织 86 名员工人均年薪 14.9 万——结合体量看比例并不离谱。**专业价值=懂政策法规/懂项目设计/懂财务法务/懂传播动员**，与企业项目经理/公关总监能力同源。
4. **绩效照妖镜**：受益人反馈纳入考核、第三方影响力评估、区分岗位差异（筹资经理看募款额与转化率/项目经理看执行质量/秘书长看战略推进）；**摒弃平均主义，向关键岗位核心人才倾斜**。

## 二、谁说了算（四方制衡）

1. **理事会——拍板签字**：薪酬制度与关键岗位薪酬最终由理事会依《慈善法》和章程决定（陈行甲 73 万即理事会研究决定）；
2. **法律法规——划红线（一票否决）**：超标=年检不合格/免税资格取消/行政处罚；
3. **人才市场——用脚投票**：给少招不来人，给多（哪怕合法）公众质疑+捐赠人流失；结合组织类型/地域/规模/发展阶段综合考量；
4. **公众与捐赠人——盯着账本**：知情权+监督权；**《慈善组织信息公开办法》（2026-01-01 施行）**——公募慈善组织须按年度公开本组织领取报酬从高到低排序**前五位人员的报酬金额**。

## 三、四方坐不齐的现实障碍

- **理事会不敢定**："这个数捐资人会不会骂"→默契压低薪酬；招聘"面议"成常态（没体系写不出/太低不敢写/怕争议不愿写）；
- **法律管上限不管下限**：只划 10%/2 倍红线，不规定最低→一线月薪三四千；把"合规"当"合理"全部；
- **市场信号失灵**：薪酬数据长期不透明，直到《基金会薪酬观察报告（2025）》才首次提供坐标系；
- **公众监督变绑架**："省下的工资能多救几个人"零和思维；善款与行政成本同处一碗→道德绑架。

## 四、观念是最大障碍

- **"苦行僧"文化基因**：善人形象=倒贴家产粗茶淡饭；
- **"零和博弈"认知陷阱**：薪酬和救助款是抢食的两张嘴，而非做蛋糕的酵母；
- **情感投射**：捐款买的是道德优越感，"纯粹"崇高感被工资条击碎；
- **预设"道德绑架线"**：公益薪酬应低于企业/政府/营利机构——管上亿资金秘书长年薪 20 万仍被骂"高薪"；
- **行业"自我阉割"**（最致命）：管理者自己设坎"定高了捐赠人跑/同行笑"，习惯性说"我们这公益行业工资没法跟企业比"——自我矮化压低了全行业薪酬天花板，人才流失加速、能力下滑。

## 五、合规要点（厚德适用）

1. **薪酬上限自查**：管理费 ≤ 总支出 10%（公募）；平均工资 ≤ 当地同类岗位 2 倍——两条硬红线；
2. **理事会决策留痕**：薪酬制度/关键岗位薪酬须理事会审议表决，留存决议（对应《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》薪酬管理相关章节）；
3. **信息公开**：公募组织须按年度公开报酬前五名（《慈善组织信息公开办法》2026 施行）——提前准备口径；
4. **招聘透明**：写明具体薪酬而非"面议"，是行业体面也是专业自信。
