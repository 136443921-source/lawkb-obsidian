# 青年律师如何从0到1建立一个万粉公众号（操作指南）

> **一句话内核**：做律师这行，表达是基本功，更是长期主义。用文字记录思考、用输出倒逼成长——这件事越早开始越好；公众号不是"获客工具"，而是执业者个人价值与专业能力的**长期复利资产**。

---

## 一、原文核心框架（五步搭建）

| 步骤 | 操作 | 要点 |
|---|---|---|
| 01 注册 | mp.weixin.qq.com → 立即注册 → 选**订阅号**（适合个人内容创作者）→ 主体选**个人** | 个人可注册 1 个；个体工商户/企业可注册 2 个；政府媒体 50 个；个人号暂不支持微信认证、微信支付及高级接口 |
| 02 装 App | 下载**订阅号助手** | 手机发文、回复留言、看数据 |
| 03 建数据感 | 每天登录看首页：原创内容、总用户数、昨日阅读/分享/新增关注 | 数据是选题与内容迭代的唯一客观依据 |
| 04 顶层设计合集 | **发布第一条前**先设计合集：为谁做？解决什么？分几步？ | 越早建合集，越易做长期价值 IP，避免内容散乱 |
| 05 配置自动回复与菜单 | 关键词回复（资料包自动发链接）、被关注回复（自我介绍话术）、AI 回复；菜单挂用户管理/数据分析/广告服务 | 承接流量，把"看客"变"关注者" |

## 二、操作细节备忘

- **转载**：需对方开白名单（"合法转载许可证"）。电脑端：内容与互动→原创→原创文章管理→转载设置；手机端：订阅号助手→已发布→设置转载。
- **内容复用**：草稿箱"选择已有内容"可换标题内容复用排版。
- **下篇预告**：变现路径（流量主、接广等）。

---

## 三、蓝队视角（青年律师如何稳扎稳打）

1. **内容定位先行**：先想清楚"为谁写"——目标客户（企业主/劳动者/同行）决定选题池；合集即内容地图。
2. **合规底线**：公众号推广属于律师业务推广，须对照《律师业务推广行为规则（试行）》——不承诺结果、不做虚假宣传、不贬损同行、不泄露客户信息。
3. **素材纪律**：案例写作用公开裁判文书或脱敏素材；不引用个案卷宗、不披露当事人信息（与 LawKB 案件管理隐私红线一致）。
4. **时间投入**：订阅号每日更新频率低（1 篇/日上限），适合实习期碎片化写作；数据周复盘。

## 四、红队视角（这套打法会在哪里失守）

| 攻击点 | 破绽 | 加固动作 |
|---|---|---|
| **自我感动式输出** | 只写"我学到了什么"，不解决读者问题 | 每篇回答一个具体问题，标题即问题 |
| **合规擦边** | 用咨询案例引流、承诺胜诉率、点名同行 | 对照推广规则逐条自查后再发 |
| **无留存闭环** | 文章爆了但没有自动回复/菜单承接 | 关键词回复 + 合集 + 个人介绍话术三件套 |
| **数据失真** | 只关注阅读量，忽略新增关注与分享 | 以"新增关注/篇"为核心 KPI |
| **三天打鱼** | 更新断档，公众号算法权重下降 | 固定更新节奏（周更/双周更），宁少勿断 |
