## 三、四条检索式（通道恢复后逐条跑，元典优先；元典不可用转法宝/qcc-legal；两皆不可用则挂起）

> **一轮润色要点（2026-09-14）**：① 删冗余定语，直击「争点要件词」；② 每条给 **语义版**（元典向量检索·自然语言整句）+ **关键词版**（法宝/qcc-legal·分词短语）双格式，按通道选投；③ 撤诉线明示法条锚点（民诉法解释 214/247）；④ **二轮（2026-09-14 16:1x）补排除词提纯 + 以案找案关联检索式**。

1. **货款已清/已付清抗辩**
   - 语义版：`窗帘软装买卖合同中，买方已向实际供货的装修承包方付清全部货款，出卖人就同一标的重复向非买受人主张价款，法院不予支持`
   - 关键词版：`买卖合同纠纷 买方已向装修承包方付清全部货款 出卖人重复主张同一标的价款 驳回`
   - 排除：`-挂靠 -建设工程施工合同 -装饰公司资质`
2. **签收=验收不担责**
   - 语义版：`被告在送货单或订货单上签字仅表示收到并验收货物，不构成对买受关系的确认，不应承担付款责任`
   - 关键词版：`买卖合同纠纷 被告送货单签字仅表收到验收 非确认买受关系 不承担付款责任`
   - 排除：`-建设工程施工 -挂靠经营 -确认劳动关系`（注意：不排"职务签收"，南城案属此类有利）
3. **滥用诉权/重复起诉**
   - 语义版：`原告明知相对方并非真实买受人且货款已结清，仍起诉主张付款，构成滥用诉权，裁定驳回`
   - 关键词版：`买卖合同纠纷 原告明知非真实买受人且货款已清仍起诉 滥用诉权 裁定驳回`
   - 排除：`-执行异议 -破产债权 -虚假诉讼刑事`
4. **撤诉后程序后果**
   - 语义版：`原告撤诉后，又以同一事实理由再次起诉的，依民诉法解释第214条、第247条裁定不予受理或驳回起诉`
   - 关键词版：`撤诉后 同一事实理由再次起诉 不予受理 驳回起诉 民诉法解释214 247`
   - 排除：`-离婚纠纷 -管辖权异议 -反诉`

> 过滤：案由=买卖合同纠纷；文书=判决书/裁定书；地域优先贵州/重庆/江西（与经验卡候选同源）；元典向量检索投语义版，法宝/qcc-legal 投关键词版 + 排除词；命中后取「本院认为」原文 + source_url 回填。

5. **以案找案关联检索式（种子：宁波北仑案、南城案；目标：直奔有利案命中，回填 LC-011/012）**
   - **种子定位①（宁波北仑案）**：`宁波 北仑 买卖合同 被告签收送货单仅表验收 不承担付款责任` → 锁定准确案号 + 全文（特征：北仑法院 + 软装/窗帘 + 签收性质）
   - **种子定位②（南城案）**：`(2025)赣1021 买卖合同 职务签收 不担责` 或 `南城 2025 职务行为 签收 不担责` → 锁定 (2025)赣1021 全文
   - **同类扩检①（北仑类·签收性质）**：`买卖合同 签收送货单 仅证明收货 非买受人 不承担付款责任` 限地域 赣/渝/黔 → 扩同类有利案
   - **同类扩检②（南城类·职务签收）**：`买卖合同 业务员 项目经理 职务行为 签收 不担责` → 扩职务签收不担责类有利案
   - **关联产出**：命中后回填 LC-011 主卡（签收性质二分）+ LC-012 有利段（原告明知非被告仍诉=滥用诉权）；反面风险案（新干/奉节/成都/定南）仍作对照段。
