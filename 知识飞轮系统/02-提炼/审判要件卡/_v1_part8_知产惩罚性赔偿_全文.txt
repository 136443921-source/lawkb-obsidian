概
述
知识产权侵权惩罚性赔偿是指人民法院在审理知识产权民事侵权纠纷
中，对于故意侵权且情节严重的行为，在补偿性赔偿的基础上，依法判决
侵权人承担超出被侵权人实际损失，或者侵权人违法所得，或者侵权人因
侵权所获利益的额外赔偿。在审理侵害知识产权民事案件中适用惩罚性赔
偿制度，
旨在惩罚严重的故意（恶意）侵权行为，威慑潜在侵权人，强化
知识产权保护，维护公平竞争秩序，营造法治化营商环境，激发创新创造
活力。
随着我国知识产权强国战略的深入推进，惩罚性赔偿制度作为强化知
识产权保护的核心机制已在我国知识产权立法中确立。在贵州省知识产权
审判实践中，对惩罚性赔偿的适用呈现快速增长趋势，审判经验持续提
升，裁判规则不断完善。但是，由于惩罚性赔偿制度在知识产权领域总体
发展时间不长，现行法律体系中相关规定较为零散甚至模糊，因此知识产
权民事侵权案件适用惩罚性赔偿仍然面临着多重实践困境。如普遍存在的
当事人较少诉请惩罚性赔偿、提出诉请不规范、举证方向错误等问题，以

审理瞧点
一、主观故意认定难
故意是适用惩罚性赔偿的核心要件之一，但实践中侵权人往往否认其
主观状态。故意的认定需要从外部行为推断内部意图，实践中存在以下难
点：（1 ) 证明标准难以把握。如何认定明知，如何认定希望或放任的主观
状态，缺乏明确标准。( 2 ) 证据获取困难。侵权人的主观状态证据多存在
于其内部文件、决策记录中，权利人难以获取。( 3 ) 推断规则的适用不统
一。对于哪些外部行为可以推断主观故意，不同法院把握尺度不一。
二、情节严重把握难
情节严重与否需要综合多方面因素判断，缺乏量化标准，栽量空间
较大，实践中存在以下难点：（l ）多重因素的权衡。需要综合考量侵权规
模、后果、持续时间、是否以侵权为业等因素，各因素权重如何分配缺乏
指引。( 2 ) 行业差异的影响。不同行业、不同知识产权类型的清节严重标
准可能存在差异。( 3 ) 地域因素的考量。侵权行为的影响范围是否限千特
定地区，还是全国范围，认定标准不一。

三、赔偿基数确定难
惩罚性赔偿须以实际损失、违法所得、侵权获利或许可使用费为基础
计算基数，实践中存在以下难点：（1 ) 证据获取障碍。侵权获利证据多由
侵权人掌握，但其往往拒不提供或提供不完整证据。( 2 ) 计算方法复杂。
涉及多产品、多渠道销售时，如何区分侵权贡献度、合理扣除成本等存在
技术难度。( 3 ) 裁量基准不统一。在证据不完整情况下，不同法院对赔偿
基数的裁量标准存在差异。
四、赔偿倍数裁量难
倍数确定须与主观恶意和情节严重程度等相适应，实践中存在以下难
点：（1 ）梯度标准的缺乏。对于不同程度的恶意和情节，对应何种惩罚倍
数，缺乏细化的指引。( 2 ) 比例原则的把握。如何避免惩罚过低难以体现
惩罚功能，或惩罚过高违反比例原则，需要谨慎权衡。( 3 ) 与其他责任的
协调。侵权人可能同时承担行政罚款、刑事罚金，如何协调与惩罚性赔偿
的关系需要明确。

法适用、比例协调、补偿与惩罚并重等原则。在充分尊重和体现知识产权
价值的基础上，立足产业创新发展规律，着力完善精细化审理，严格依法
适用惩罚性赔偿，加大侵权惩罚力度，实现惩罚性赔偿对故意严重侵害知
识产权行为的打击功能和遏制作用。
（一）积极稳慎原则
以激励创新、维护公平为核心目标，既通过积极适用惩罚性赔偿，强
化制度保护效能，激发社会创新活力；又秉持稳慎态度，注重平衡各方利
益，防范权利滥用与保护过度，维护公共领域、竞争秩序及国家安全。
（二）依法适用原则
惩罚性赔偿的适用必须以法律规定为前提，严格依据法律、司法解释
等规定的审查启动条件、构成要件、裁量条件等适用惩罚性赔偿，遵守法
定程序，充分保障当事人合法权益，不得通过类推扩大其适用范围。

惩罚性赔偿倍数与幅度的确定，应当与侵权行为的事实、性质、情

（三）基数的三种计算模式
1 ．权利人损失的计算
确定权利人因被侵权所受到的损失时，可考虑以下因素：权利人商品
销售减少量或侵权商品销售量与权利人商品单位利润的乘积；权利人因用
户数量下降、交易机会丧失所导致的损失；权利人为修复商誉实际支出的
合理广告费等费用；商业秘密被非法公开时权利人对其的研发成本等。
2．侵权人获利的计算
确定被诉侵权人因侵权所获利益时，可考虑以下因素：侵权产品销售

的乘积；被诉侵权人自认的销售数量及价格；公证书、时间戳电子存证等

（五）赔偿倍数的确定
惩罚性赔偿的倍数确定，应当综合考虑被告主观过错程度、侵权行为
的情节严重程度等因素。
1 ．倍数确定的一般规则
赔偿倍数的确定，应当综合考虑被侵害的知识产权价值、被侵权产品
的知名度以及赔偿额是否足以阻遏侵权行为，并与被诉侵权人的主观恶意
程度及情节严重程度相适应。此外，还可以考虑以下因素：以侵权为业
的，可考虑适当提高倍数；帮助、教竣侵权的，可考虑适当降低倍数；伪
造、毁坏或者隐匿侵权证据，以暴力、胁迫等方式阻碍行政执法、证据保
全，以及有其他影响司法公正恶劣行为的，应当提高倍数；侵权行为对国
家安全、消费者生命健康、生态环境等重大利益或公共利益造成侵害，或
者对行业、社会造成严重不良影响的，应当提高倍数，直至顶格判赔。惩
罚性赔偿的倍数应在法定范围内确定，可以不是整数。

2．倍数确定的特定类型考量因素
( 1 ) 侵害著作权：作品处千热播期、热映期、热卖期或者集中宣传推
广期间的，可考虑适当提高倍数；网络环境中，侵权传播范围广、技术危
害大、后果严重不可逆的，可考虑适当提高倍数。（2 ) 侵害商标权：侵害
驰名商标的，可考虑适当提高倍数；除造成相关公众对商品来源产生误认
混淆外，还对商标所负载的商誉造成较大贬损的，可考虑适当提高倍数；
在伪劣商品上使用侵权标识的，可考虑适当提高倍数。（3 ) 侵害专利权：
侵害国家行政主管部门认定的关键核心技术、重点领域或者新兴产业的技
术、国家重点支持的高新技术等高价值专利的，可考虑适当提高倍数；侵
害发明专利权的，可考虑适当提高倍数；侵害实用新型专利权、外观设计
专利权的，可考虑适当降低倍数；请求保护的专利权存在否定性结论评价
报告，但被诉侵权人未提出抗辩的，可考虑适当降低倍数。( 4 ) 侵害商业
秘密：侵害技术秘密的，可考虑适当提高倍数；

（六）惩罚性赔偿的约定适用
被告与原告达成和解协议后重复侵权，可以参照在先和解协议约定的
和解金额作为惩罚性赔偿的计算基数，但被告举证证明该约定明显具有惩
罚性，或过分高于原告损失或被告侵权获利的除外。原告和被告对再次侵
权事先约定了惩罚性赔偿的，从其约定。当事人明确约定了惩罚性赔偿计
算的基数和倍数，但该倍数不在法定范围内的，可以依法进行调整。
（七）法定赔偿中的惩罚性考量
对于故意侵权且情节严重的侵害知识产权案件，权利人请求适用惩罚
性赔偿，但实际损失数额、违法所得数额、因侵权所获得的利益均难以计
算，且无可参照的权利许可使用费，也不能根据证据概括确定惩罚性赔偿
计算基数，需要适用法定赔偿的，酌情从高确定赔偿数额。
六、先行判决、部分适用与分别适用
（一）先行判决
对于侵权事实清楚、能够认定侵权行为成立，但案件标的额较高、赔
偿基数较难确定的案件，可以依法先行判决停止侵权。确定赔偿金额需要
对相关财务数据、会计资料等进行评估或鉴定以查明赔偿基数的，可以在
后判决确定。
