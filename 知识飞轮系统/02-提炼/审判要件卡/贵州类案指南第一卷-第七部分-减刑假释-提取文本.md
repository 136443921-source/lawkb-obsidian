一、实质化审理落实难
实质化审理要求法官不能仅依据书面材料进行形式审查，而且要深人
探究罪犯是否悔改，全面审查罪犯改造的成果是否真实。但在实践中，案
卷材料往往格式化，通过书面审和远程庭审也较难全面把握罪犯改造的真
实情况，法官受限千案多人少、司法资源紧缺等现实困难，较难通过实地
调查、走访问询等方法核实其改造情况，对其主客观改造表现并重难以落
地，导致实质化审理的要求难以完全落实，罪犯虚假悔改、骗取减刑假释
的情况时有发生。
二、确有悔改表现的认定难
确有悔改表现是绝大多数罪犯获得减刑、假释的核心条件，但其内涵
抽象，缺乏统一、量化且易于操作的客观标准，
目前监狱的考核体系过分
侧重于考核计分制，虽然看似公平统一，但是易受政策和一线工作人员个
人因素等的影响，未必能够真实反映罪犯内心的悔改态度和人身危险性的
变化。法官在审理时，难以对罪犯的主观恶性和改造成效进行全面精准的
判断，导致认定结果可能存在偏差。此外，罪犯服刑期间违规如何处理、
认罪悔罪材料效力如何认定、罪犯申诉是否必然认定其不具有悔改表现等
具体问题，更导致法官难以认定罪犯是否确有悔改表现。

四、财产性判项履行与减刑、假释的关联难
罚金、退赃、附带民事赔偿等财产性判项的履行情况也是衡量罪犯诲
改表现的一个重要指标。但是在司法实践中，无财产履行、不愿履行边界
模糊，履行不能等情况也时有发生。加之法院审理减刑、假释案件时间
短、任务重，难以调查核实其经济状况、家庭财产情况等，若简单将未全
部履行财产性判项视为不认罪悔罪，可能有失公平。如何在减刑、假释案
件审理环节对此妥善处理，具有一定难度。
五、没有再犯罪危险的认定难
假释案件要求对罪犯进行调查评估，如何预测罪犯在假释后没有再犯
罪危险本质上具有不确定性。目前主要依赖千罪犯的犯罪性质和服刑改造
表现进行评估，但缺乏明晰统一的操作标准和科学可行的评估模型。

一、全面依法审查
审理减刑、假释案件应当全面审查刑罚执行机关报送的材料，既要注
重审查罪犯交付执行后的表现，又要注重审查罪犯犯罪的性质和具体情
节、社会危害程度、原判刑罚及生效裁判中财产性判项的履行情况等，依
法作出公平、公正的裁定，防止将考核分数作为减刑、假释的唯一依据。
依据《刑法》第七十八条、第七十九条、第八十一条、第八十二条的规
定，减刑、假释案件由执行机关向中级以上人民法院提出减刑、假释建议
书。人民法院应当组成合议庭进行审理。
审查范围包括：执行期间罪犯表现，包括但不限千审查罪犯教育改造
等情况；立功或重大立功事实；罚金、退赃、附带民事赔偿等财产性判项
履行情况；对刑罚执行机关报送材料的齐备性、证据真实性及计分考核程
序是否规范进行审查；对罪犯确有悔改表现及减刑、假释起始时间、间隔
时间是否符合《办理减刑、假释案件规定》《办理减刑、假释案件补充规
定》和本指南等相关规定进行审查；其他应当审查的事项。

七、认罪悔罪材料的效力认定
认罪悔罪是认定罪犯确有悔改表现的法定条件之一，也是罪犯主观上
能够积极接受改造的前提。认罪悔罪材料主要包括罪犯的认罪悔罪书、思

准可能存在差异。( 3 ) 地域因素的考量。侵权行为的影响范围是否限千特
定地区，还是全国范围，认定标准不一。

三、赔偿基数确定难
惩罚性赔偿须以实际损失、违法所得、侵权获利或许可使用费为基础
计算基数，实践中存在以下难点：（1 ) 证据获取障碍。侵权获利证据多由
侵权人掌握，但其往往拒不提供或提供不完整证据。( 2 ) 计算方法复杂。
涉及多产品、多渠道销售时，如何区分侵权贡献度、合理扣除成本等存在
技术难度。( 3 ) 裁量基准不统一。在证据不完整情况下，不同法院对赔偿
基数的裁量标准存在差异。
四、赔偿倍数裁量难
倍数确定须与主观恶意和情节严重程度等相适应，实践中存在以下难
点：（1 ）梯度标准的缺乏。对于不同程度的恶意和情节，对应何种惩罚倍
数，缺乏细化的指引。( 2 ) 比例原则的把握。如何避免惩罚过低难以体现
惩罚功能，或惩罚过高违反比例原则，需要谨慎权衡。( 3 ) 与其他责任的
协调。侵权人可能同时承担行政罚款、刑事罚金，如何协调与惩罚性赔偿
的关系需要明确。
