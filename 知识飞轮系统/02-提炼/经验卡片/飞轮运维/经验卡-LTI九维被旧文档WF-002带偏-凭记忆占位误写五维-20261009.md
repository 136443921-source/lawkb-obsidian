## 一、事故回放（2026-10-09 · 费曼框架评估轮）

### 误写经过

- **场景**：老强提出用费曼学习法重构知识飞轮 / 元心智自学习机制（5 步外壳），请我评估可行性。我在评估与复盘文字中，把 LTI 写作**「五维 QC 闸门（R/L/C/T/P）」**，并顺手引用了全局工作流 **WF-002（法条 LTI 五维 QC 门禁）** 作为依据。
- **老强当场纠正**：「LTI 五维 QC（R/L/C/T/P）是'准确性闸门'不是五维，是**九维**」。
- **我的第一反应**：仍引用 WF-002 旧文档试图辩解——这就是**错上加错**：拿一份**已脱节**的二级产物当权威。
- **实地核验（纠偏）**：读现行真源 `lti_dimensions_v9.json`，确证：
  - 版本 **4.9.0**，名称「LTI 九维文本质检维度规范」；
  - `upgraded_from: "v4.8.1（五维 R / L / C / T / P）"`——**九维是在五维基础上扩展而来**；
  - 九维全表：**R 法条真实性 / L 法理逻辑 / C 一致性 / T 溯源 / P 程序 / S 策略契合度（扩展）/ V 风险预判（扩展）/ W 表达规范（扩展）/ E 证据闭环（扩展）**；
  - 门禁：「逐维勾选；任一 ❌ 即阻断交付，REJECT=0 才准交付」；自动维 C/P，部分自动 R/T/W，手动 L/S/V/E。
- **承认错误**：我上条凭的是**旧框架（WF-002 那份仍写"五维"的文档）**，而非现行配置——正是老强反复警告的**「凭记忆占位」**。

## 二、根因

1. **把二级产物（旧文档结论）当成事实本身**：WF-002 是「我对 LTI 的summary」式二级文本，不是 LTI 本身；我没去读真源 `lti_dimensions_v9.json`，直接采信了旧文档的"五维"结论。
2. **凭记忆占位（用户铁律直击）**：老强在用户记忆中立的「否定型结论铁律 / 裁决项二次核验铁律」已明确——**未换第二种工具复核前，不得写断言**。本案是同一毛病的正向版（不是"不存在"，而是"是五维"），同样源于**未实地查真源**。
3. **与既有经验卡同构**：
   - 与「**规范清单硬编码必漂移·单一真源教训**」同构：把一份**会漂移的副本**当单一真源；
   - 与「**存在性断言须实证**」同构：本案是**肯定型**断言（"是五维"），但机制一样——**副本/印象给不出真值**；
   - 与「**待裁决项须二次核验·七处误判**」同源：裁决项/配置类断言，未二次核验即输出，必踩坑。
4. **未执行「先读现行真源再落笔」闸**：凡涉及系统维度/配置/版本，第一动作应是 `Read lti_dimensions_v9.json`，而非回忆或翻旧文档。
