# 问错字段得出「零疑本」：sxx 与 source_verify 承载两个不同维度

## 一、一句话结论

**`sxx` 记的是「这部法律本身是否现行有效」，`source_verify` + `statute_text_pending` 记的是「本地卡体是否为现行版本」——两个维度，不可互相代表。**
只读 `sxx` 去数疑本，等于**问错了字段**，得出的「零疑本」是假阴性。

---

## 二、事故经过（2026-10-15 实测）

| 环节 | 现象 |
|---|---|
| 触发 | 法条银行复盘，需统计「有多少张卡不可安全引用」 |
| 我的做法 | 只读 `sxx` 字段 → 实测 `现行有效` 101 / `已被修改` 4 / `已废止` 1 / **待核验 0** |
| 我的结论 | ❌ **「sxx 零待核验 → 库里没有疑本」**，并据此写入复盘报告，标为「最需老强拍板的一条」 |
| 老强追问 | 「这是核验真做完了，还是标记被误抹了？」 |
| 换字段复核 | 读 `source_verify` + `statute_text_pending` → **5 张疑本卡标记完整存在，一个都没丢** |
| 根因 | **字段语义混淆**——把「法本身时效」当成了「本地卡版本时效」 |

### 5 张疑本卡（标记全部完整）

| # | 卡片 | 疑本原因 |
|---|---|---|
| 1 | 买卖合同解释 | 卡体为 **2012 原版**，官方现行为法释〔2020〕17号·2021-01-01，**版本漂移** |
| 2 | 网络安全法（主席令第53号） | 已被 2025 修正（主席令第61号）取代 |
| 3 | 医疗纠纷预防和处理条例（701号） | 重定向桩，条文在主卡 |
| 4 | 慈善法（主席令第16号） | 重定向桩，条文在主卡 |
| 5 | 技术合同解释（法释〔2004〕20号） | 重定向桩，条文在法释〔2020〕19号主卡 |

买卖合同卡的完整标记（**证明标记从未被抹**）：
```
sxx: 现行有效                                    ← 法本身现行
statute_text_pending: true                       ← 本地卡体不可直引
source_verify: 待核验（本地正文标注2012-07-01施行，
               未含2020修正版2021-01-01，待人工更新正文）  ← 疑本原因在这
```

**看：同一条卡上 `sxx: 现行有效` 与 `statute_text_pending: true` 并存并不矛盾**——
前者说「买卖合同这部法还有效」，后者说「你手上这张卡是过期的版本」。

## 三、险情等级：高（会实质影响案件）

若按我「零疑本」的错误结论起草 **6660 雅菲软装窗帘案**（买卖合同纠纷）代理词：

| 危害 | 说明 |
|---|---|
| 引错版本 | 会引用 **2012 原版《买卖合同司法解释》** |
| 条号错位 | 官方现行是法释〔2020〕17号（2021-01-01 施行），**条号已重排** |
| 举证受损 | 引用条号与法官手头现行版本对不上，直接影响论证可信度 |

> ⚠️ 这不是「文档写错一个字」级别的问题，是**会写进法院文书**级别的错误。

## 四、与既有铁律的呼应（同一失效模式的第四次出现）

| 既有铁律 | 本例对应 |
|---|---|
| 🔴 **否定型结论铁律**（假阴性防护） | 「零疑本」是否定型结论，未换字段复核前不得采信 |
| 🔴 **单点证据结论须实证** | 只看 `sxx` 一个字段就下结论，未做第二字段交叉验证 |
| 经验卡-门禁扫描0张不等于通过（2026-10-15） | **同族**：那次是「扫描范围为空」致假阴性，这次是「字段选错」致假阴性 |

**共同内核**：**先自问「我查的这个字段/范围，能否证伪目标命题？」**
- `sxx == 待核验` 的计数**不能**证伪「存在版本漂移卡」——因为版本漂移根本不记在 `sxx` 上。
- **不能证伪的指标 = 无效指标。**

## 六、可复用检查清单（下次判断「有无疑本/风险项」前）

1. **先问「这个风险记在哪个字段」**——不要拿一个字段的干净去推断全库干净。
2. **列出全部相关字段再数**——本例须同时读 `sxx`（法时效）+ `source_verify`（卡版本）+ `statute_text_pending`（可否直引），三者缺一不可。
3. **看到「全都好」要警觉**——101 张全「现行有效」、零异常值，这种「过于整齐」的分布往往是口径太窄的信号。
4. **抽样反查**——随机取一张已知有问题的卡（本例：买卖合同），确认它在你用的口径下**能否被检出**。检出不了 → 口径错。
5. **区分「实体时效」与「载体时效」**——法条库、案例库、合同库都有这对概念，不限于本库。
