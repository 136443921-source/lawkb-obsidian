# 利率换算跨主体套用与利害方向误判事故卡

## 事故一句话
壹鑫典当案执行异议利息核算中，AI 把央行「金融机构存贷款」计息规则（银发〔2005〕129号：日利率=年利率÷360）当作普适规则套用到**典当行（非银行业金融机构）**，并武断下"÷365 无明文依据、法源更弱；÷360 有明文依据"的结论，推荐采纳 ÷360——结果多让利息、且 ÷360 使实际年化 24.33% 突破裁决书 24% 上限，对债务人（我方当事人）不利。

## 误判链（三层叠加）
1. **跨主体套用规章**：只见 129号"日利率=年÷360"明文，未核其适用范围；129号只管人民币存贷款**金融机构**，典当行依《典当管理办法》第3条系"专门从事典当活动的企业法人"，非银行业金融机构，129号不当然适用。
2. **未判利害方向**：未算 ÷360 的实际年化 = 24%÷360×365 = **24.33%**，突破 24% 上限、抬高利息，对债务人不利；反而当成"权威口径"推荐给债务人一方。
3. **武断否定 ÷365**：把"÷365 无专门明文"错说成"无依据、法源弱"，忽略其系民间借贷/典当按自然年折算的主流口径、且恰好守住 24% 上限。

## 加固铁律（写入本卡 + 用户级 MEMORY [58]）
1. **引部门规章/规范性文件前必核适用范围三要素**：主体（谁）、业务（什么业务）、地域/时效；金融机构计息规则不当然及于典当行、民间借贷。
2. **利率/金额换算必先判利害方向**：算清"此口径对哪一方有利"，站在当事人立场选有利口径，或至少并列两种口径+利害提示，禁默认采纳对己方不利口径。
3. **凡涉利率上限（24%/4倍LPR）必校验换算后实际年化是否突破上限**：÷360=×365/360 会突破，÷365 才守住。

## 正确结论（本案）
- 段C 持续利息（年24%、18万基数、2025-09-18 至收据日 2026-10-22）应按 **÷365** 折算：日利率=24%÷365，而非 ÷360。
- 段A/B 为裁决已定固定额（954.18、4212），不可改；仅段C 的"率定额不定"部分可主张 ÷365。
- ÷360 会突破 24% 上限，应主动反驳对方按 ÷360 的主张。

## 直接损失与处置
- 误荐 ÷360 使含息总债务多算约 895.89 元（251,943.18 vs 251,047.29），超付少算约 895.89 元，且默认让渡了"÷360 突破 24% 上限"的有利抗辩点。
- 已更正：v2 草稿本为 ÷365（正确），后续"采纳 ÷360 出 v3"方向撤回；定稿按 ÷365 折算。
