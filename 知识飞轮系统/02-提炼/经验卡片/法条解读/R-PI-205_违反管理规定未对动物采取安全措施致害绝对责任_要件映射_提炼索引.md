# R-PI-205 提炼索引（指针）

## 主卡位置
- 权威正文：[[R-PI-205-违反管理规定未对动物采取安全措施致害绝对责任]]（06-沉淀/裁判规则库/人伤法/）

## 提炼要点（一句话）
典型翻车：误将 1246 与 1245 的减责事由等同 → 1245 含"重大过失"减责，1246 **仅"故意"可减责**；主张被侵权人重大过失减责在 1246 下通常不被支持。；误以为"拴养/圈养=已采取安全措施" → 拴养但仍失控咬人（如本案巨型犬），一般认定为"未采取安全措施"；安全措施须达到防止动物致人损害的实际控制程度。；误将 1246 与 1247 混同 → 1247（禁养烈性犬）更严，连"故意"外的任何减责均不成立；1246 至少保留"故意可减责"空间。
