# R-PI-206 提炼索引（指针）

## 主卡位置
- 权威正文：[[R-PI-206-动物园动物致害过错推定责任]]（06-沉淀/裁判规则库/人伤法/）

## 提炼要点（一句话）
典型翻车：误将一般饲养动物（宠物犬、看护犬、农家犬）套用 1248 过错推定 → 实际应适用 1245 无过错责任（如甘08民终1518明确区分）。归责原则选错将导致举证责任分配错误。；误以为"动物园张贴警示即尽到管理职责" → 1248 的"尽到管理职责"是综合性、过程性标准（设施、警示、巡检、应急），单靠标识不能免责。；混淆 1248（过错推定）与 1247（禁养烈性犬绝对责任）→ 动物园若在园内设危险动物互动项目，仍受 1248 过错推定约束，而非 1247 绝对责任。
