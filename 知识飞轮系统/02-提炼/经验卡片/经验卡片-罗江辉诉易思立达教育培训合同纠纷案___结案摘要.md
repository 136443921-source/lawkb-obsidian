# 经验卡片 - 罗江辉诉易思立达教育培训合同纠纷案（真实结案）

> ⚠️ **真实案件标识**：本卡源于 **2026-07-31 CaseDrop 投递《结案摘要》**（真实判决，(2026)黔0103民初XXXX号，云岩区法院 2026-05 判决），非演练。与 `经验卡片-罗江辉诉易思立达教育培训合同纠纷.md`（模拟演练卡）内容同源但性质不同——**本卡是真实经验，可触发 P1 人格蒸馏**。

## 案件信息
- **案由**：教育培训合同纠纷（预付式消费）
- **争议焦点**：①被告1闭店是否构成根本违约/原告解除权；②退费按折扣价还是原价、资金占用损失起算日；③被告2茂楠公司（代开票代收款）是否承担连带责任
- **法律关系**：教育培训服务合同关系（预付式消费）
- **证据类型**：收据 NO.7053321、闭店通知、微信聊天记录+课程记录照片、被告2代收收据
- **诉讼标的**：¥7,083.00（剩余 174 课时）+ 资金占用损失（LPR）
- **处理结果（真实判决）**：部分胜诉——合同解除+退费7,083元+LPR利息均获支持；被告2连带责任被驳回；利息起算日由主张的 2025-03-01 调整为起诉之日
- **审理法院**：贵州省贵阳市云岩区人民法院，案号 (2026)黔0103民初XXXX号
- **结案日期**：2026年5月（判决）

## 经验提炼

### ✅ 成功策略
- **《预付式消费解释》第18条精准适用**：提前算好折扣单价（7,830÷260=30.12元/课时）并在代理词列明计算公式；被告1主张"按原价"但未举证 → 法院按折扣价判。**启示：原告算好折扣价 + 被告举证不能 = 退费金额获支持。**
- **根本违约三重事实锁死**：闭店通知 + 截至庭审未复课 + 无明确复课时间表 = 合同目的不能实现（《预付式消费解释》第13条 + 《民法典》第563条双重请求权基础）。
- **课时数量举证妨碍策略**：原告持微信聊天记录+课程记录照片；被告1异议但拿不出自持课程记录 → 法院采信原告 174 课时主张。**启示：对方掌握不出具的证据，主张对方举证不能比自行补证更高效。**

### ❌ 失败教训
- **被告2连带责任证据链过浅**：仅有"代出具收据"一层证据，未挖掘银行流水往来、人员混同、地址混同、财务混同。要件（《预付式消费解释》第4条"允许使用其名义从事预付式消费经营"）不满足 → 请求被驳。
- **代理词与证据脱节（信誉风险）**：代理词声称"法院调取的银行流水显示代收费用未全部转交"，但判决书查明原告并未实际取得该证据 → 代理词写了无支撑的表述，实务大忌。
- **利息起算日失利——未保留送达证据**：主张自 2025-03-01（《解除通知》之日）起算，但无快递单/签收记录/微信送达截图 → 法院改为起诉之日。暴露证据保全意识不足。

### 💡 关键决策点
- **是否追加被告2为共同被告**：追加前先做证据可行性评估——能否拿到深于"代收据"的证据（流水/混同）。证据链只到"代收据"时，追加边际收益低、分散庭审焦点。
- **利息起算日如何主张**：送达证据不到位时，与其主张无法证明的日期被驳回，不如务实主张起诉之日起算，或在起诉前补发解除通知并留痕。

## 可复用知识
- **裁判规则（关联规则卡）**：
  1. 经营者闭店且未复课 = 根本违约，消费者可依《预付式消费解释》第13条解除合同（关联 [[知识飞轮系统/06-沉淀/裁判规则库/合同风险/R-HT-037|R-HT-037]] 教育培训合同审查·退费规则）；
  2. 非因消费者原因退费按折扣价计算（解释第18条），经营者主张原价未举证 → 举证不能；
  3. 资金占用损失按 LPR 计息，自起诉之日（无送达证据时）起算；
  4. 名义收款方连带责任须证明"允许使用其名义"（解释第4条），仅代开票/代收款不足；
  5. 关联 [[知识飞轮系统/06-沉淀/裁判规则库/商事纠纷/R-SH-012|R-SH-012]]（职业闭店人受让股权虚假清算→债权人赔偿，类案防守维度）。
- **证据组织技巧（预付式消费三件套）**：①付款凭证（收据/转账记录）②剩余课时证据（课程记录/微信截图）③经营者违约证据（闭店通知/停业公告）。
- **庭审话术模板**：被告主张"正在积极复课"时 → "被告主张正在积极寻找新场地复课，但截至庭审之日未提供任何证据（新场地租赁合同、复课通知等），根据《民事诉讼法》第67条应承担举证不能的后果。"
