# 经验卡片 · 单点证据不得定论·当事人陈述矛盾扫描铁律

> **类别**：correction / best_practice（法律推理 + AI 工作流安全）
> **触发场景**：对「当事人意思表示 / 授权 / 主观状态 / 自认」类事实下肯定性结论时（尤其制裁 / 控告 / 代理词 / 可行性评估）
> **一句话**：仅凭单一陈述 / 单一时点言词证据即定论"授权真实 / 已追认 / 真实意思为 X"，未扫描该当事人全案矛盾陈述、未判法院是否实质采信 → 视为未验证，禁写入文档。
> **关联铁律**：否定型结论铁律（阴阳对称）、裁决项二次核验铁律、LTI E 维度（证据闭环）

## 一、事故回放（6658 案 · 司法制裁可行性评估，2026-10-09/10）

- 评估"向法院提请司法制裁原告 / 黄茂姣 / 陈宇"时，就"授权是否真实"下结论："丁戊祥当庭自认委托律师、妻子代章 → **授权真实获本人承认**"。
- 该结论仅锚定开庭笔录 P4/8/9 一句，忽略丁戊祥在全案的其他陈述：
  - 8-19《情况说明》+ 8-20《未起诉说明》（**两份手书给被告**）均否认授权；
  - 8-24 刘维录音"我没有" + 法官龙雅清电话（证据⑨）"应该是带人过来的那个人去起诉"均否认、指认黄茂姣发动；
  - 7-14 刘维通话亦否认。
- 丁就"是否授权"共 **五处陈述**：四次否认、一次开庭改口。我取其一、弃其四。
- 用户指正后核验：判决书拆解 §六 定案证据仅列协议 / 微信 / 收据 / 当庭陈述，**两份情况说明与两份录音均未入册** → 法院悬置授权争议（程序回避），未认授权有效、未认冒名伪造。

## 二、根因（六层）

1. **单点证据定论（anchoring）**：把单一陈述当干净定论，未查同一陈述人的其他矛盾陈述。
2. **确认偏误**：该自认贴合我"冒名前提已被否定、我方胜诉、制裁不可行"的预设，抓取支撑项、不主动查反证。
3. **未建陈述时间轴**：丁的言词散落 7-14 通话 / 8-19 书面 / 8-20 书面 / 8-24 两录音 / 9-1 开庭，未整合即下笔；33 号申请、29/35 号分析本已铺好时间轴我却未合并。
4. **混淆三层事实位阶**：把"当事人当庭说 X"（可能被矛盾 / 未被采信的陈述）误等同"法院确认 X"。未区分：(a) 法院实质认定 (b) 当事人陈述 (c) 证据入定案证据册。
5. **误读"未采用"**：以为"法院不采用录音"= 对方自认被证实；实为材料不入定案证据即不能用于认定事实，法院沉默 ≠ 授权有效。
6. **铁律不对称**：既有"否定型结论须实证"只防假阴性，无对称规则防"单点肯定结论未实证"——本错即该盲区。

---

## 三、固化铁律（每次对当事人意思 / 授权类事实下结论前必念）

| # | 铁律 | 说明 |
|---|---|---|
| 🔴 1 | **建陈述时间轴** | 同一争点，把该当事人全案各时点陈述（通话 / 书面 / 录音 / 笔录）列成轴，不止看一处 |
| 🔴 2 | **矛盾即悬置** | 时间轴 ≥2 处不一致 → 该事实标"悬而未决 / 争议中"，禁写"已确认 / 获承认"，须注矛盾点 |
| 🔴 3 | **法院采信三分层** | 仅「法院实质认定」可作已确认；「当事人陈述」可能被矛盾 / 未采信；「证据未入定案册」≠ 对立陈述被证实 |
| 🔴 4 | **未采用 ≠ 自认成立** | 法院不采用某录音 / 书证，仅使该材料不能进事实认定，不验证对立陈述；沉默 ≠ 确认（典型"程序回避"） |
| 🟢 5 | **单点结论须实证** | 任何"授权真实 / 已追认 / 真实意思为 X"类肯定结论，下笔前须完成 1-4 并留痕 |

## 四、正确执行流（范本）

1. 列"丁戊祥 · 授权意思表示"时间轴：7-14 否认 → 8-19 书面否认 → 8-20 书面否认 → 8-24 两录音否认 → 9-1 开庭改口。
2. 标注矛盾：四否认 vs 一自认 → 结论为"授权在案卷悬而未决，庭前记录强烈指向未经授权，法院未予查明"。
3. 查判决书定案证据：确认情况说明 / 录音未入册 → 法院悬置争议，非确认授权。
4. 据此修正评估：制裁原告 / 黄不可行（不变）；陈宇律师投诉线 B（授权手续矛盾）升格主强。

## 五、复盘金句

> **"当事人的一句话不是事实，是他在这个时间点的立场；把它当定论前，先看他之前说过什么、之后改没改口、法院认没认。"**
> 单点证据定论 = 把"某人某时说 X"偷换成"X 为真"。这是法律推理与 AI 结论的共同死穴。
