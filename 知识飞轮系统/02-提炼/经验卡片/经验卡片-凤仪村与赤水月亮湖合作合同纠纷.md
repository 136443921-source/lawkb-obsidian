# 经验卡片 · 凤仪村与赤水月亮湖合作合同纠纷（被告视角）

## 一、可复用方法论：合作合同纠纷「被告视角」应诉框架
1. **三步应对法**：积极应诉（禁缺席）→ 全面抗辩（事实 / 法律 / 程序三向）→ 灵活调解（降本速决）。
2. **三大抗辩方向**（按证明难度排）：
   - 我方已按约履行（《民法典》509，需履行记录 / 现场照片，证明难度中高）
   - 对方解除通知程序不合法（《民法典》565 条第 2 款，有《复函》则在异议期内异议，难度低）
   - 对方付款 / 返还条件未成就（同时履行抗辩 525 / 526，难度中）
3. **反诉门槛**（《民诉法》54）：与本诉有牵连、向同院提；证据不足则败诉 + 增成本 + 激化矛盾 → 优先抗辩 + 调解。
4. **另诉红线**（《民诉法》124）：易构成重复起诉被驳 → 在本诉抗辩解决，不另诉。
5. **证据册标准**：一级分组 → 二级清单(名称/页码/证明目的) → 三级关键条款标注；编号 `证据册-组别-序号`。

## 二、关键程序节点（被告必记）
- 收起诉状 **15 日内** 提交答辩状；举证期限届满前交齐证据；开庭前 7 日庭前准备。
- 收到起诉状 24h 内分析主张 → 3 日集证 → 7 日起草答辩 → 10 日决反诉 → 15 日交答辩。

## 三、经验得失
- ✅ **核心认知**：被告方胜败首要变量是「证据是否充分」，系统整理证据是成败关键，优先于任何实体抗辩。
- ✅ **调解优先**：诉讼费减半、速决、效力强；须书面明确调解底线避免让步过度。
- ⚠️ **实习律师提醒**：预测报告阶段即应建立完整证据册与时间轴，避免临开庭证据散乱（本案自评"准备度不足"即此因）。

## 四、法律适用要点
- 合同解除权行使：通知到达即解除（《民法典》565），但程序瑕疵（未给异议期）可被推翻 → 我方《复函》及时异议是关键反制。
- 解除后果：恢复原状 / 赔偿损失（566），损失赔偿范围受可预见规则限制（584）。

## 五、跨案件复用提示
- 适用于一切「我方为合同解除争议中被告」场景（合作、租赁、服务、买卖均可套用三步法 + 三大抗辩）。
- 与王德明担保合同案互补：王德明是「我方为担保人被诉」的进攻翻案；本案是「我方为履约方被诉解除」的防御应诉。
