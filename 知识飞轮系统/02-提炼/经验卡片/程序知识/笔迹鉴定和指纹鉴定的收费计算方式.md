# 笔迹鉴定和指纹鉴定的收费计算方式（经验卡片）

> 转写自飞轮投喂笔记 `02-提炼/案件管理通用方法论/通用程序知识/笔迹鉴定和指纹鉴定的收费计算方式.md` ｜ 原始出处：案件管理/承办案件/王德明担保合同纠纷案/笔迹鉴定和指纹鉴定的收费计算方式.md

## 触发场景（trigger）
办理「笔迹鉴定和指纹鉴定的收费计算方式」程序事项（报案/举报/鉴定/检察监督/量刑分析）时

## 应当做（do）
- "一件" = 一个鉴定事项（如：鉴定一份合同上的签名是否系某人所写）
- 不是按页数收费：即使合同有10页，只要只鉴定其中的签名，就按"一件"收费
- 不是按字数收费：即使签名只有3个字，也是按"一件"收费
- 一份合同上有一个签名需要鉴定 = 一件 = 800-1500元
- 一份合同上有三个签名需要鉴定 = 三件 = 800×3 = 2400-4500元
- 两份不同合同上各有一个签名需要鉴定 = 两件 = 800×2 = 1600-3000元
- 多页合同：如合同有5页，但只需要鉴定最后一页的签名，按一件收费
- 多份合同：如需要鉴定3份不同合同上的签名，按三件收费
- 复杂鉴定：如需要鉴定书写时间+签名真伪，可能按两件收费
- 一份合同上有一个指纹需要鉴定 = 一件 = 800-1500元

## 不应当做（dont）
- 避免重复鉴定：确保检材质量，避免多次鉴定
- 要求出具收费清单：避免隐形收费
- 明确鉴定事项：避免后期争议
- 明确收费标准：避免随意加价
