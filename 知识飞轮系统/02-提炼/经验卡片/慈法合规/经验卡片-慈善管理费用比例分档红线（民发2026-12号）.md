## 一、权威规则
民发〔2026〕12号第九、十、十三条。

## 二、核心规则
| 组织类型 | 管理费用上限（占当年总支出） |
|---|---|
| 公募基金会 | ≤ **10%** |
| 非公募基金会（净资产≥1000万） | ≤ **13%** |
| 非公募基金会（净资产500-1000万） | ≤ **14%** |
| 非公募基金会（净资产100-500万） | ≤ **15%** |
| 非公募基金会（净资产<100万） | ≤ **20%** |
| 年度管理费用 < 20万元 | **豁免**比例限制 |
