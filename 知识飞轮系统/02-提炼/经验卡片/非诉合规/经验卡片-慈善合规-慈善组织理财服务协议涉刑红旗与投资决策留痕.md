# 经验卡片-慈善合规-慈善组织理财服务协议涉刑红旗与投资决策留痕

> 来源：周合规巡检（2026-08-30）R1 重大风险点沉淀 · 子模板A（慈善）· 铁律第6条强制产卡。

## 一、基本情况
慈善组织（基金会）与一家社会工作服务中心签订《公益理财服务协议》，对方负责人被立案侦查（经济犯罪），导致其民事追偿被一审以"涉嫌经济犯罪"裁定驳回/移送。本会投资活动与资金安全暴露重大合规缺口。

## 二、风险点（标注条号）
1. **重大投资决策程序缺失**：慈善组织投资须经理事会组成人员三分之二以上同意（《慈善法》第54条），本案未见决策留痕。
2. **交易对手尽调缺失**：与无理财资质主体签"理财服务协议"，且对方涉刑，提示变相委托理财/资金出借风险。
3. **关联交易未排查**：须依《慈善法》第14条排查是否构成关联交易并回避。
4. **投资范围合规**：须遵守《慈善组织保值增值投资活动管理暂行办法》（民政部令第28号）禁投清单（直接买卖股票、直接购买商品及金融衍生品等）。

## 三、合规分析
慈善财产投资的核心约束是"合法、安全、有效 + 收益全部用于慈善目的 + 程序合规"。本案三重失守：程序（无理事会决议）、对手（涉刑无资质）、范围（疑似变相出借）。刑民交叉下法院倾向"先刑后民"，但民事时效不中止，须双轨并行。

## 四、整改建议（可直接用）
- 重大投资事前：理事会决议模板 + 交易对手尽调表 + 关联交易排查声明，三件套归档。
- 事后：向理事会专项风险报告 + 评估协议性质（投资/出借/关联）+ 民事追偿与刑事配合并行推进。
- 制度：将"投资决策程序 + 对手尽调 + 关联回避"写入基金会投资管理制度（呼应手册投资活动域）。
