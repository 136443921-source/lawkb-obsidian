# 非诉合规经验卡 · 沉淀规范（v1.0.0）

> 本目录承接「合规与非诉支持」维度 P1-B2 升级，是周合规巡检（automation-1787843981235）与日常非诉调用的经验回流落点。
> 目标：把"非诉/合规调用"从"用了就忘"变成"调用必产卡、反哺飞轮"。

## 一、哪些调用必须产卡（触发规则）

满足以下任一即**强制**沉淀 1 张经验卡到本目录：
1. 周合规巡检（周日 21:00）命中高价值风险点
2. 「小德慈善合规中枢」激活且 `knowledge_called` 非空
3. 「[[数据合规审查|数据合规审查]]」「税务合规审查」产出可复用合规要点
4. 法律备忘录 / 律师函 / 合规审查意见交付后
5. 任何非诉文书经 G8 门禁（非诉文书红蓝复核 → LTI 五维 → 六维门禁）通过

> 低价值/一次性事项可不产卡，但调用记录仍须写入 `05-调用/`。
