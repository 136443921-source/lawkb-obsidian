# 医疗纠纷诉讼实务全流程操作指引（经验卡片）

> 转写自飞轮投喂笔记 `02-提炼/人伤法/医疗纠纷/医疗纠纷诉讼实务全流程操作指引.md` ｜ 原始出处：IMA 人伤法律实务助手 / 公众号「医疗大健康法律圈」《医疗纠纷诉讼实务全流程操作指引》

## 触发场景（trigger）
办理人身损害/工伤/交通事故/医疗损害案件，涉及「医疗纠纷诉讼实务全流程操作指引」认定或赔偿计算时

## 应当做（do）
- 易忽略点：美容整形、非法行医、疫苗不良反应等特殊类型是否属于医疗损害纠纷，需特别注意案由选择。
- 适用3年普通诉讼时效，自权利人知道或应当知道权利受损及义务人之日起算。
- 实务技巧：不以出院日期作为唯一起算点；连续治疗、鉴定期间可主张时效中断；接案时务必要求当事人确认是否存在时效中断证据（微信记录、信访材料、投诉回执等）。
- 原则：患者就"诊疗行为 + 损害后果 + 因果关系"承担举证责任；医方就"无过错"承担举证责任（《民法典》第1222条）。
- 推定过错情形（第1222条）：(1) 违反诊疗规范；(2) 隐匿或拒绝提供病历；(3) 遗失、伪造、篡改或违法销毁病历。
- 提出申请：向医方医务科/医患办提交书面封存申请（保留送达回执）；
- 双方到场：封存时医患双方均应到场，制作封存笔录；
- 复印备份：封存原件前先行复印全部病历，复印件由医方盖章确认；
- 封存清单：逐页编号并制作封存清单，双方签字确认；
- 保管方式：可委托医院或第三方保管，应拍照留存封存状态。

## 不应当做（dont）
- 医疗纠纷周期长、专业壁垒高，收案阶段须完成精准评估，避免"接得下、打不赢"。
- 诊疗行为 + 损害后果 + 因果关系 + 过错，四项缺一不可，收案时逐一快速排查：
- 代理提示：接受患方委托时，不应依赖"举证责任倒置"旧观念，应主动搜集证明医方过错的证据。
- 撰写要点：每条过错须有病历原文支撑（精确到页）；引用规范标注章节、条目、版本；语言客观专业，避免情绪化。
