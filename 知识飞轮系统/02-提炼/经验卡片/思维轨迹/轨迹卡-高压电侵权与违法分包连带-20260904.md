# 思维轨迹卡：高压电侵权无过错责任 + 建设工程多层违法分包连带主张路径

> 2026-09-04 结案回填型轨迹卡（陈长卫劳务致害案·真实已结案·胜诉·二审改判）。法条引用：民法典 1239/1191/1192/1173 条由 `02-提炼/经验卡片/人伤/经验卡片-陈长卫劳务致害案.md` 锚定；strategy_result_map 已 v1.1 判断力校准（3 策略均回填实际结果）。本案"高压电经营者身份锁定+原承包方书面说明"二件套是建设工程人伤案件的核心武器；2026-07-01 后超龄劳动者双轨（工伤+侵权）并行须特别提示。

## 一、问题演进

最初问"陈长卫被高压电击伤，找谁赔" → 锁定"供电局是否担责" → 追问"供电局抗辩'属原分包范围'" → 进一步审查"违法分包链条各方怎么分" → 收敛到"高压电无过错+违法分包连带+重新立项认定"三线 → 反思"超龄劳动者是否双轨主张"。

## 二、思维逻辑链

1. **锁定供电局"高压电经营者"身份（第一优先级）**：
   - 民法典 1239 条：从事高空、高压、地下挖掘活动或者使用高速轨道运输工具造成他人损害的，经营者应当承担侵权责任——**无过错责任**
   - 身份证据：电力设施产权登记、运行维护单位证明、供电合同
   - 关键校准：**不要因发包/分包关系主张免除供电局责任**——高压电经营者责任与发包/分包关系是两条独立线
2. **用原承包方书面说明推翻"原分包范围"抗辩（决定性证据）**：
   - 供电局抗辩"三牌更换属原分包范围" → 试图将责任推给承包方
   - 反制：原承包方出具书面说明"三牌更换不属原分包范围" → 重新立项认定成立
   - 关键校准：**仅凭单方证据（与后续事实矛盾）不足**，须有原承包方书面文件支撑
3. **违法分包链条全部主体连带（建设工程五层关系链）**：
   - 民法典 1191 条（违法分包）+ 1192 条（违法转包）
   - 发包→总包→违法分包→违法转包→个人雇佣——查链条全部主体身份证据
4. **受害人自身安全注意义务比例（过失相抵）**：
   - 民法典 1173 条——可主张过失相抵减少赔偿
   - **但不得免除高压电经营者无过错责任**（仅比例调整，不消灭责任）
5. **超龄劳动者 2026-07-01 后双轨并行**：
   - 《超龄劳动者基本权益保障暂行规定》生效后，超龄劳动者事故可同时主张工伤认定+侵权连带
   - **但本案 2023 已决**，工伤新规**法不溯及既往**，勿作再审事由

## 四、分歧与纠偏

- **纠偏点 1**：初版思路"以发包/分包关系主张免除供电局责任" → 校准为**锁定供电局"高压电经营者"身份独立主张无过错责任**——高压电经营者责任与发包/分包关系是两条独立线，不能混为一谈。
- **纠偏点 2**：仅凭单方证据（与后续事实矛盾） → 校准为**关键证据须有原承包方书面文件支撑**——单方陈述证据强度不足。
- **纠偏点 3**：忽视受害人自身安全注意义务比例 → 校准为**过失相抵可主张但不得免除高压电经营者无过错责任**（仅比例调整，不消灭责任）。
- **纠偏点 4**：以 2026-07-01 工伤新规作为 2023 已决案的再审事由 → 校准为**法不溯及既往原则**——工伤新规不适用于本案。
- **校准结论**：高压电侵权胜诉的"二件套"=供电局经营者身份锁定 + 原承包方书面说明；其余（违法分包连带/过失相抵）作为辅助线。

## 五、收敛结论（结案回填）

**主线**：
- 民法典 1239 条高压电无过错责任 → 供电局承担 20% 无过错责任 ✓
- 原承包方书面说明 → 重新立项认定成立，推翻"原分包范围"抗辩 ✓

**辅线**：
- 违法分包链条全部主体连带 → 经二审调整 ✓
- 受害人过失相抵比例 → 二审部分采纳

**下一步**：
- 同类建设工程人伤案件可直接复用本卡"二件套"路径
- 2026-07-01 后新发生的超龄劳动者事故须双轨主张（工伤+侵权）
- 2023 及以前已决案不适用工伤新规（法不溯及既往）
