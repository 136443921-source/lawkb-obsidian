# 思维轨迹卡：附条件付款条件成就的举证攻防 + 协商解除函 vs 单方解除的措辞边界

> 2026-09-04 结案回填型轨迹卡（冒井渔业案·真实已结案·部分胜诉）。法条引用：民法典 158/159/562/565 条由 `02-提炼/经验卡片/合同文书/经验卡片-冒井渔业vs厚德渔业合同纠纷.md` 锚定；元典 rh_ft_detail 已核验现行有效（2026-08-31 缓存）。本案三大失分点（未主张159条+冒井举证不能+6月再审窗闭）已固化至失败教训。

## 一、问题演进

最初问"厚德该不该付这 52.5 万" → 锁定附条件付款条款 → 追问"环评未通过算不算条件未成就" → 进一步审查厚德发函措辞是"协商解除"还是"单方解除" → 收敛到"条件未成就抗辩+函件措辞抗辩"双线 → 反思"民法典159条是否本可作为翻盘武器" → 评估再审可行性。

## 二、思维逻辑链

1. **锁定条款类型**：本案为附条件付款协议（《退出补偿协议》），付款分四期、挂钩"环评通过"等行政审批——这是整个抗辩的入口。
2. **客观阻碍锁定**：厚德主张"环评未通过"——需以**行政机关正式文件**（环评不予批准通知）证明客观事实，而非当事人主观陈述；行政文书是法院采信的关键。
3. **函件措辞审查（关键校准）**：厚德发函称"协商解除"，**不构成**单方解除通知（民法典562条协商解除 vs 565条单方解除）——函件措辞不同法律效果天差地别，**避免被反诉违约解除**。
4. **举证责任分配（民法典159条）**：附条件付款条款，主张条件成就的一方负举证责任——本案冒井公司未能举证第二/三/四期条件成就，承担不利后果。
5. **恶意阻碍条件成就（民法典159条·本案未主张）**：若一方有义务促成条件成就却恶意阻碍，视为条件已成就——冒井公司作为协议项下促成方，是否有义务推动环评？厚德未主张此条，丧失关键法律武器。
6. **再审评估**：二审超 6 个月再审窗（民诉法 211 条），程序救济窗口基本关闭；实体虽留 159 条空间但需补强证据——**C 级（谨慎申请）**。

## 四、分歧与纠偏

- **纠偏点 1**：初版思路倾向"直接否认协议效力/主张已解除" → 校准为"抗辩付款条件未成就"——后者举证门槛低（行政文书）、风险小（不破坏协议框架）、胜诉路径稳；厚德主张履行，应保持协议有效+条件未成就二分。
- **纠偏点 2**：函件措辞险些被认定为单方解除 → 校准为**措辞审查须逐字比对法律效果**（"协商""解除""终止""履行不能"等用词对应不同法律效果）。
- **纠偏点 3**：未主张民法典159条 → 校准为**附条件付款案件务必双武器并用**（条件未成就抗辩+159条恶意阻碍），即使对方举证不能，本方仍可主张对方未履行促成义务。
- **校准结论**：附条件付款抗辩的胜负手在"行政文书+函件措辞+159条三件套"，缺一即败诉一半。

## 五、收敛结论（结案回填）

**主线**：附条件付款条件未成就抗辩——用"环评不予批准通知+协议条款挂钩关系"锁定客观阻碍；厚德胜诉。
**辅线**：协商解除函措辞抗辩——避免被反诉违约解除；厚德胜诉。
**三大失分点**（再审窗内的反思）：
- 民法典159条（恶意阻碍条件成就）未主张 → 丧失举证责任倒置武器
- 第二/三/四期条件成就的举证未主导 → 法院未支持
- 二审超 6 个月再审窗 → 程序救济基本关闭

**下一步**：再审评估 C 级（谨慎申请）；实体补强证据（如冒井曾承诺推动环评的书面记录）后再判断是否值得冒险。
