# 思维轨迹卡：光伏项目合同审查中乙方 SPV 嫌疑的问询推理路径

> 2026-09-07 沉淀。源起甲方国明对《贵州习水县100MW光伏项目资源合作协议》审查中，乙方贵州振绥强新能源有限责任公司（统一社会信用代码 91520323MAE4X70EXN）的主体资质疑问。
> **本卡工商数据均经 2026-09-07 华宇元典 rh_company_info 真调用核验**，信用代码 91520323MAE4X70EXN，非凭记忆。

## 一、问题演进

起点是老强一句澄清请求：**「SPV 怀疑是什么意见」**。

老强把这条线往下拽了四层：

| 轮次 | 老强的追问/指令 | 把我逼到的位置 |
|---|---|---|
| 1 | 「SPV 怀疑是什么意见」 | 解释 SPV＝特殊目的公司，明确其属备忘录§8第3项「内部待核实🔴」，对外版不提 |
| 2 | 「查乙方工商登记、拉尽调清单、做SPV画像、纳入审查环节」 | 调华宇元典坐实，而非凭外观推断 |
| 3 | 工商返回后 | 六维画像确认SPV，升级为 P0-6，协议改担保/付款/资质三处 |
| 4 | 「将第六号文件存入合同审查备忘录」 | 第六号报告全文固化进§3 P0-6，备忘录自包含（v1.6） |

**收敛到的问题**：对「对方疑似壳公司」类负面判断，应先实证还是先外观推测？坐实后如何转化为可执行的合同保障？

## 二、思维逻辑链

### 1. 澄清层：先定性质，不对外暴露

SPV 在备忘录里是**内部待核实项**（§8第3项🔴），不是既定事实。对外版（第五号致乙方）严守§14禁忌——不提 SPV、不提无效/刑事/内部会议。这一步把「内部判断」与「对外表述」隔开，避免未核实断言外溢。

### 2. 实证层：用工商数据坐实，不用外观推断

乙方有三个外观特征指向 SPV：名称像项目公司、协议由其草拟且条款偏乙方、一身兼任投标+运营主体。**但这些只是 C 级证据（外观推测）**，不能直接等同「壳公司」。

对应解法：调华宇元典工商登记——

| 字段 | 返回 | 证据级 |
|---|---|---|
| 注册资本 | 150万人民币 | A（与800万资源费严重不匹配） |
| 实缴 | 股东详情实缴字段为空（未公示） | A（疑似零实缴） |
| 企业类型 | 有限责任公司（自然人独资） | A（无母公司） |
| 成立 | 2024-11-07 | A（不足2年，疑似项目专设） |
| 行业 | 水的生产和供应业 | A（与光伏无关，壳特征） |
| 变更 | 一年内三变→王满英100% | A（控制权两度易手） |
| 资质 | 仅电气安装/劳务分包/道路货运 | A（无新能源发电资质） |

### 3. 定性层：六维画像确认

设立目的/资本实力/实缴/股权结构/经营范围/资质匹配六维全部指向 SPV。**结论：高度疑似为本次光伏项目专设的 SPV/壳公司**——此时才有 A 级数据支撑，可写进交付物。

### 4. 处置层：把定性转化为合同保障（三处改动）

| 原协议假设 | 实证后的修正 | 依据 |
|---|---|---|
| 第二号设想「母公司担保」 | 自然人独资无母公司 → 改**实控人（王满英+疑似幕后张元利）个人连带保证**+财产抵押/银行保函 | P0-6 |
| 第5.2条「背靠背付款」 | 改「**分期+挂钩里程碑（核准/备案/并网）+实控人担保**」三重闸门 | P0-6 |
| 乙方独立投资建设 | 资质不符 → 须**联合有资质主体或明确分包** | 国能发新能规〔2025〕7号第12条 |

### 5. 固化层：报告进备忘录，自包含

第六号报告（工商表+变更轨迹+六维画像+尽调清单8项+处置建议）全文嵌入备忘录§3 P0-6（v1.6），使备忘录不依赖外部 docx 即可讲清 SPV 全貌。

## 三、事实思考方向（核查清单）

| # | 核查项 | 动作 | 分级 |
|---|---|---|---|
| 1 | 工商登记基础 | 华宇元典 rh_company_info 按名检索→信用代码→detail 查实缴/股东/变更 | A 级 |
| 2 | 行业与资质匹配 | 比对行业登记、许可经营范围与项目性质 | A 级 |
| 3 | 实控人穿透 | 创始股东是否幕后代持，索乙方书面声明 | B 级 |
| 4 | 履约能力 | 验资报告/银行资信/近一年财报 | B 级 |
| 5 | 外观特征 | 名称/角色/文本草拟倾向 | **C 级，不得作为事实断言** |

**证据分级**：A 级＝工商登记原始数据；B 级＝乙方书面披露；**C 级＝外观推测，只能标「待核实」，严禁写进对外文件**。

## 四、分歧与自省

本卡无老强直接纠偏。自省一处关键风险：

若把「名称像项目公司」「协议由乙方草拟」等外观直接等同「壳公司」并写进给乙方的正式文件——

- 违反防幻觉纪律（内部推断外溢为事实断言，见轨迹卡-AI内部推断外溢为事实断言的拦截路径）；
- 违反备忘录§14对外禁忌（暴露对乙方资质的未核实疑虑、且提前亮底牌）；
- 未核实前下结论不专业。

→ 校准路径：**工商实证 → 再定性 → 再处置**，与防幻觉拦截路径同源。

## 五、收敛结论

1. **一个纪律**：对负面主体判断，必须先权威源坐实（工商登记），再定性，再处置；外观推测只配「待核实」。
2. **一个转化**：坐实后的风险必须落到协议具体条款（担保主体/付款闸门/资质联合），否则只是无约束力口头提示。
3. **一个闭环**：报告固化进备忘录正文，使知识自包含、不随外部文件散落。
4. **姊妹卡分工**：防幻觉卡管「脑内≠外部」的通用拦截；**本卡管「对方疑似壳公司」这一具体场景的核查路径与合同转化**。

## 复用提示

凡合同审查/非诉中遇「对方疑似空壳/无履约能力/刚设立」类质疑，直接套用：

- 先问：这是**工商查到的**，还是**我看出来的**？看出来的 → 标「待核实」，不写进对外文件。
- 有工商数据 → 六维画像（设立目的/资本/实缴/股权/经营范围/资质）定性 → 落到协议保障（担保/付款/资质）。
- 报告进备忘录，自包含。
