# 思维轨迹卡（项目级）：习水100MW光伏项目合同审查整链推理路径

> 2026-09-07 沉淀。覆盖从「收到乙方草拟合同」到「形成可签署方案 + 活备忘录自包含」的完整推理链。
> 本卡为**项目级总轨迹**，串起 P0-1/P0-2/P0-4/P0-5/P0-6 与各号意见书；子卡见 [[轨迹卡-光伏项目乙方SPV问询的推理路径-20260907]]。
> **全部法条与工商数据均经核验**（华宇元典 rh_company_info / 北大法宝·元典 MCP），非凭记忆。

## 一、问题演进

起点是单一指令：「帮我审查一下这个合同」。

老强在审查中逐层把问题往下拽，最终收敛为一条主线：

| 轮次 | 老强的追问/事实补充 | 主线推进 |
|---|---|---|
| 1 | 「审查合同」 | 第一号全文审查，识别 P0 四维致命风险 |
| 2 | 补充事实：我方代表国明、协议乙方草拟、公益入厚德、我方系厚德发起人、将写入投标文件、分布式、一般纳税人 | 风险重估：新增 P0-4/P0-5/P1-11 |
| 3 | 「贵州是否有规定禁止公益证明作投标条件，写进投标文件风险？」 | 投标红线专项（第三号）→ 贵州明文体系 |
| 4 | 「检索规章具体条款，汇总合作方式，给法律分析意见」 | 第四号合作方式三维分析 |
| 5 | 「给乙方（拟将计提专项基金作投标内容）出意见」 | 第五号致乙方投标文件专项（对外脱敏） |
| 6 | 「查乙方工商登记、做SPV画像、纳入审查环节」 | 第六号 SPV 核验 + P0-6 |
| 7 | 「第六号存入备忘录」→「SPV问询提炼成思维轨迹卡」→「整条审查线提炼项目级总轨迹卡」 | 固化：备忘录 v1.6 自包含 + 本卡总链 |

**收敛到的问题**：分散的 P0 与六号意见，如何串成一条可复用的审查主线？

## 二、思维逻辑链（主线六节点）

### ① 起点：协议由乙方草拟、条款偏乙方

第一号审查即发现条款整体偏向乙方（无保底、无排他、无反规避、背靠背付款、不对称违约）。这是一切风险的**结构性成因**——乙方既是草拟方又是风险推卸方。

### ② P0-5 投标红线（最薄弱一环）

公益捐赠拟写入投标文件与项目宣讲。规范体系：

```
法律：招标投标法51条（罚则）
  ↓
行政法规：实施条例32条（二）（七）框架条款
  ↓
部门规章：16号令第6/7条 + 99号令第15条
  ↓
省级地方性法规：贵州省优化营商环境条例13条（补加分条件缺口，效力高于165/816）
  ↓
省级规范性文件：165号文标准六七 + 816号文第六项（点名"慈善公益证明"）
  ↓
参照：交公路规〔2025〕1号 + 浙市监反垄断〔2025〕12号（最完整表述）
```

三档定性：A 仅倡导合法 / B 作加分项违规 / C 作资格或指定捐赠禁止。

**关键识别——风险传导链**：投标文件问题 → 异议投诉 → 乙方失标 → 800万资源费落空 → 厚德对价性受质疑 → 反向强化153条无效。故其处置优先级**高于**商业条款谈判。

### ③ P0-1 合同效力

8万/MW 按并网规模计取（结果导向）+ 鉴于条款"打通政府层级关系"（对价指向人际）。民法典153条2款无效风险高；裁判参照如皋李堡（借款找关系获取指标→合同无效）、颍上阜阳（居间费80万过高→无效酌定10万）。

### ④ P0-4 关联交易

我方兼厚德基金会发起人，与乙方（捐赠人）经我方形成闭环。慈善法14条：回避+公开+不参与使用决策；61条3款：捐协议约定管理费上限（建议≤5%）。

### ⑤ P0-6 SPV（工商实证）

乙方统一社会信用代码 91520323MAE4X70EXN：注册资本150万、实缴未公示、自然人独资、成立不足2年、行业「水的生产」、一年内三变→王满英100%、无新能源资质。六维画像确认 SPV。**协议三处转化**：担保主体改实控人个人连带（无母公司）、付款改「分期+里程碑+担保」三重闸门、资质须联合有资质主体或分包。

### ⑥ 固化：各号意见 → 活备忘录自包含

第一~六号意见书（约6份 docx）→ 活备忘录 v1.6：§0.5 合作方式 / §1.1 方案 / §3 P0-1~P0-6 详解 / §5 厚德路径 / §6 投标红线专项+条文原文 / §13 关联文件全链。报告全文嵌入（第六号进 §3 P0-6），不依赖外部 docx。

## 三、整链核查清单（下次直接套）

| # | 节点 | 查什么 | 证据级 |
|---|---|---|---|
| 1 | 投标红线 | 招标文件是否列公益捐赠为评分/资格/中标条件；索165号文审查表第12项 | A级法规/B级乙方披露 |
| 2 | 合同效力 | 服务是否结果导向、对价是否指人际关系；改成果清单+里程碑 | A级条文 |
| 3 | 关联交易 | 我方是否基金会发起人；知情权是否切割；管理费上限 | A级法条 |
| 4 | SPV | 工商登记（信用代码/资本/实缴/股东/变更/资质）+实控人穿透 | A级工商数据 |
| 5 | 对外脱敏 | 不提无效/刑事/SPV/内部会议；反规避改"合作稳定性" | 纪律（§14） |

## 四、自省与纪律

- **传导链视角**：各 P0 孤立看会低估；必须串成主线，投标文件是最薄弱一环。
- **实证优先**：SPV 等负面判断必须工商坐实，外观推测只配 C 级「待核实」，禁写对外文件（呼应防幻觉纪律 + §14 禁忌）。
- **分流阀**：老强反复问"怎么查/怎么串/怎么复用"= 方法路径，沉淀轨迹卡而非决策卡。

## 五、收敛结论

1. **一条主线**：投标红线（最薄弱）→ 合同效力 → 关联交易 → SPV，经风险传导链交织，处置优先级自上而下。
2. **一个抓手**：投标文件公益捐赠环节，索165号文审查表第12项是最有力交涉支点。
3. **一套转化**：定性必须落到协议条款（担保/付款/资质/隔离），否则只是口头提示。
4. **一个闭环**：各号意见 → 活备忘录自包含 → 思维轨迹卡，下次同域项目整链复用。

## 复用提示

凡光伏/新能源/分布式项目**合同审查**，启动即调本卡 + 子卡（SPV），套第三节核查清单六步；凡涉「公益捐赠进投标文件」直接跳 P0-5 三档定性。
