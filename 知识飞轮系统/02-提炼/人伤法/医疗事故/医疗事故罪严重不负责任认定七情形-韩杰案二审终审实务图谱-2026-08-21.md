# 医疗事故罪"严重不负责任"认定体系——韩杰案二审终审后的七情形实务图谱

> 来源：WebSearch（财新/南都/南方网/大律师网，2026-08-21 检索）｜A2 医疗三类·事故方向

## 核心命题

韩杰案二审（2026-05-28 抚州中院）维持原判——漏诊致患儿死亡，医疗事故罪获刑一年+禁业三年，成为医疗过失刑事化分水岭案例。**"严重不负责任"是本罪核心立案与认定标准**，其七种法定情形（最高检公安部《立案追诉标准（一）》）构成实务判断图谱，且行刑衔接（卫健委移送→公安→检察→法院）路径已定型。

## 一、刑法第335条与本罪四要件

医务人员由于严重不负责任，造成就诊人死亡或者严重损害就诊人身体健康 → 三年以下有期徒刑或拘役。

1. **主体**：医务人员（医生/护士/药剂人员等依法取得执业资格的医疗卫生技术人员）；单位不构成本罪（民事赔偿由医疗机构承担）
2. **主观**：过失（疏忽大意/过于自信）；故意则可能构成故意伤害/杀人罪
3. **客观**：严重不负责任 + 就诊人死亡或严重损害健康后果
4. **因果**：违规诊疗过失行为与损害后果间须有刑法上的直接因果关系；损害主要由疾病自身发展导致或介入因素切断因果链的不构成

## 二、"严重不负责任"七种法定情形（立案追诉标准）

1. 擅离职守
2. 无正当理由拒绝对危急就诊人实行必要医疗救治
3. 未经批准擅自开展试验性医疗
4. 严重违反查对、复核制度
5. 使用未经批准使用的药品、消毒药剂、医疗器械
6. **严重违反国家法律法规及有明确规定的诊疗技术规范、常规**
7. 其他严重不负责任的情形

**"严重损害就诊人身体健康"** = 造成严重残疾、重伤、感染艾滋病/病毒性肝炎等难以治愈的疾病或其他严重损害后果。

## 三、韩杰案认定逻辑（第七→第六情形）

- 患儿航航存在呕吐、肚子痛肠梗阻症状；腹股沟查体、B超、CT及请外科会诊均为常规诊疗措施
- 法院认定：韩杰**未进行必要的辅助检查、未请外科会诊** → 违反第六情形"严重违反诊疗技术规范、常规"
- 医疗事故前置：抚州市医学会认定构成**一级甲等医疗事故**；民事一审（2025-03-28）医院承担**85%过错责任**、赔付约146.5万元
- 时间线：2025-06-11 刑拘→06-18 逮捕→2025-09-04 临川区检察院公诉→2025-11-17 一审（一年+禁业三年）→2026-05-28 二审维持

## 四、行刑衔接程序（重要）

医疗事故罪**不是自诉案件**：正常路径 = 卫健委做行刑衔接（主要证据在卫生部门）→ 公安立案 → 检察院公诉 → 法院判决。家属不能直接追刑责，须经行政移送。

## 五、辩护与实务争议（罗翔"折中说"）

- 罗翔观点：认定"严重不负责任"须**代入性思维**——站在被指控医生立场，考虑地方差异、学科差异、各地医疗水平不同，能否"轻轻松松"发现问题避免事故
- 争议点：① 患儿死亡系多环节（其他医生失误、家属自驾长途转院风险）共同导致，不宜仅对一人追刑责；② 未尸检的鉴定报告证明力；③ 民营司法鉴定机构（江西开元，诚信等级B）结论的可靠性
- 医院对患者执意自行转院：应履行**风险告知义务**并让家属签字确认后再离开
