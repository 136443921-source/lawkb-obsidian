# 医疗事故罪与非法行医罪界分实务

> A2 每日自学习 · 医疗三类之二（医疗事故 · 刑事）
> 锚定案例：（2016）皖13刑终25号（安徽宿州中院二审）

## 一、为什么这个界分值得较真

法定刑差距悬殊：

| 罪名 | 法定刑 |
|---|---|
| 医疗事故罪（§335） | 三年以下有期徒刑或者拘役（**顶格三年**） |
| 非法行医罪（§336①） | 三年以下；严重损害健康三至十年；致人死亡**十年以上** |

同一起"护士实施麻醉致患者死亡"的事实，定非法行医罪可能十年以上，定医疗事故罪最高三年。**罪名争夺就是刑期争夺**，这是辩护的第一战场。

## 二、界分标准："擅自"要素的组织嵌入性

### 2.1 文本起点

《刑法》第 336 条第 1 款："未取得医生执业资格的人**擅自**行医"。

"擅自"不是赘语，是构成要件要素。它指向行为的**秩序脱离性**——行为人自立门户、脱离合法医疗组织与监管体系。

### 2.2 梁某案的三问检验法

对涉案行为逐一追问，三问皆"是"则"擅自"不成立：

1. 行为是否发生在**合法成立的医疗机构**内？
2. 行为是否由**有资质的医生安排**？
3. 行为是否处在医院**既定的诊疗流程/手术规程**中？

梁某案中，护士在合法私立医院内、经医生安排、在手术流程中实施麻醉——三问皆是。且死亡后果与医院对医护人员资格、诊疗行为、手术规程的**管理漏洞**明显相关。故出非法行医罪，入医疗事故罪。

### 2.3 反面情形（仍构成非法行医罪）

- 护士在自家、租住房、美容院等场所自行接诊；
- 虽在医疗机构内但系私下收费、脱离医院流程"接私活"；
- 医疗机构本身不合法（无证黑诊所）。

## 三、医疗事故罪构成要件精解

| 要件 | 内容 | 辩护攻击点 |
|---|---|---|
| **主体** | 特殊主体：医务人员。护士、药剂师、技师均包含，不限于执业医师 | 行为人是否属"医务人员"（如实习生、进修人员、行政人员） |
| **客观行为** | 严重不负责任 | 须落实到**具体违反的诊疗护理规范、常规条款**，泛泛而论不足 |
| **危害结果** | 就诊人死亡 或 严重损害身体健康 | 结果与行为的因果关系、介入因素 |
| **主观** | 过失，且为**重大业务过失**——违反业务上特定注意义务 | 一般业务过失 vs 重大业务过失的界分；行为人是否已尽岗位注意义务 |

### 3.1 "职务行为不阻却个人刑责"

本案明确：即使属所就职医院安排的职务行为，**行为人个人仍存在重大业务过错的，仍构成本罪**。

辩护上不能停留在"我只是听命令"，须进一步论证**个人层面已尽注意义务**——如：已向上级报告资质不足、已提出异议被驳回、操作本身符合规范但因医院设备/流程缺陷致害。

### 3.2 医疗事故责任认定书：必要非充分

本案确立的证据法规则：认定书是认定医疗事故罪的**必要条件而非充分条件**，仅为全案证据之一，法院可综合全案证据独立认定。

推论：
- 认定书不利 → 可举反证推翻，申请鉴定人出庭质证；
- 无认定书 → 原则上不能定罪（必要条件）；
- 认定书有利 → 不当然出罪，控方仍可举证。

## 四、办案检查清单

**辩护方**
- [ ] 调取医院排班表、手术通知单、上级医师指令，证明行为的组织嵌入性
- [ ] 调取医院资质管理制度、人员配置记录，指向医院管理漏洞
- [ ] 比对具体诊疗护理规范条款，论证已尽岗位注意义务
- [ ] 审查医疗事故责任认定书的鉴定程序、鉴定人资质、材料完整性
- [ ] 评估自首、赔偿谅解等量刑情节

**控方 / 被害方**
- [ ] 锁定被违反的具体规范条款与操作步骤
- [ ] 固定"个人重大业务过错"的独立证据（区别于医院管理过错）
- [ ] 并线推进医院民事赔偿（《民法典》第 1218 条）与行政处罚

## 五、待深化问题

1. 各地对护士超范围执业的定性仍有摇摆，"组织嵌入性"标准尚未统一，需持续检索最新判例。
2. "重大业务过失"缺乏量化标准，是否可借鉴过错参与度鉴定结论作为参考，实务未定。
