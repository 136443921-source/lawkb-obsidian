# 医患沟通书面记录与告知义务红线 · 缺痕即缺证

> **一句话内核**：告知义务与病历记录的"书面留痕"是医疗合规与诉讼攻防的锚点——《民法典》1219条、1222条与《医疗纠纷预防和处理条例》13/15/47条、《医师法》25/55条共同确立：**无书面记录=未履行告知沟通义务**；隐瞒/拒交/伪造/篡改病历直接**过错推定**；未按规定填写保管病历、未签知情同意书，即使无患者损害也面临 1-5 万元行政处罚与执业处罚。补录是补记录，不是补"证明力"。

---

## 一、法条体系（蓝队·合规锚点）

| 法源 | 条款 | 核心义务 |
|------|------|---------|
| 《民法典》 | 1219条 | 手术/特殊检查/特殊治疗须**书面同意**；未尽告知义务造成损害→医疗机构赔偿 |
| 《民法典》 | 1222条 | 违反诊疗规范 / 隐匿拒交病历 / 伪造篡改销毁病历 → **推定过错**（法律推定，不可推翻） |
| 《民法典》 | 1225条 | 按规定填写并妥善保管病历；患者有权查阅复制，须及时提供 |
| 《医疗纠纷预防和处理条例》 | 第13条 | 手术/临床试验等特殊检查治疗须**书面同意**；紧急情况经负责人批准可实施 |
| 《医疗纠纷预防和处理条例》 | 第15条 | 按规定填写并妥善保管病历资料 |
| 《医疗纠纷预防和处理条例》 | 第47条 | 违规填写/保管病历等 → 责令改正、警告、并处 1-5 万元罚款 |
| 《医师法》 | 第25/26条 | 医师告知义务+书面知情同意；临床试验须伦理审查书面同意 |
| 《医师法》 | 第55/56条 | 未履行告知/未取得知情同意 → 警告；情节严重暂停执业 6 月-1 年直至吊销证书 |

## 二、执法实践四类典型（红队·攻击/防御要点）

1. **拒绝提供病历**（桂林卫健委）：医院拒绝提供病历→患者向卫生监督部门投诉→行政调查+处罚；诉讼中直接触发 1219/1222 过错推定→败诉风险。
2. **未签知情同意书+未按规定填写病历**（莆田秀屿·口腔诊所）：拔牙属一级手术未履行告知+无书面同意，违反条例13条；未填写门诊病历/处方违反15条→诊所罚 2 万、医师罚 1.5 万。
3. **知情同意书形式瑕疵**（杭州·医美门诊）：同意书"替代治疗方法"栏空白、未经医师本人签名；检验报告单无检验师签名→警告+罚 2 万。**签名与内容完整性均是核查点**。
4. **药物流产随访档案缺失**（桂林·妇科）：无术前检查记录/随访记录表/未建用药档案→罚 1.2 万。

## 三、合规清单（蓝队·书面留痕四道闸门）

- **知情同意**：手术/特殊检查/特殊治疗三场景必签；替代方案、风险告知须**具体**（不写"可能并发症"笼统语）；医师本人签名+患者/近亲属签名；紧急情况补办程序留痕。
- **病历填写**：住院志/医嘱单/检验报告/手术麻醉记录/病理/护理记录/费用记录七类齐备；检验报告须有检验师签名；随访记录、用药档案完整。
- **保管与提供**：妥善保管；患者要求查阅复制须及时提供（拒绝=1222 过错推定）。
- **补录纪律**：补录只补"记录"不补"证明力"——质控发现遗漏应及时规范补记并标注，但诉讼中补录内容证明力弱、易被质疑篡改。

## 四、诉讼攻防（红队视角）

- **患方攻击点**：先查同意书签名与内容完整性 → 再查病历七类记录缺失/无签名 → 以 1222 主张过错推定 → 举证责任转移给医方。
- **医方防御**：证明"告知义务已履行"靠的是**当时留痕**（同意书/沟通记录/术前讨论），事后补证难获采信；建议术前沟通采用"书面知情同意+沟通记录双轨留痕"。
- **律师实务**：代理患方优先申请病历封存+电子病历完整性校验；代理医方重点审查告知留痕完整性，缺痕时评估和解止损。
