# 员工自身过错受伤，到底算不算工伤？· 工伤认定无过错责任

> **一句话内核**：劳动者自身存在过错（违规操作、疏忽大意、赶工期、不按流程），**不影响工伤认定**。工伤认定实行**无过错责任原则**，只要满足"在工作时间、工作场所、因工作原因"三要件，企业不得以"员工违规"拒赔。法定排除情形仅四类：故意犯罪、醉酒吸毒、自残自杀、法定其他。

---

## 一、法条体系（蓝队·合规锚点）

| 法源 | 条款 | 核心规则 |
|------|------|---------|
| 《工伤保险条例》 | 第14条 | 工作时间前后/工作场所内，从事预备性或收尾性工作（含吃饭、喝水、上厕所、换衣、休息）受事故伤害 → 工伤 |
| 《工伤保险条例》 | 第14条第6项 | 上下班途中，受**非本人主要责任**的交通事故/轨道/轮渡/火车事故伤害 → 工伤 |
| 《工伤保险条例》 | 第16条 | 排除工伤：**故意犯罪 / 醉酒或吸毒 / 自残或自杀 / 法定其他** |
| 人社部办公厅答复意见 | 现行有效 | 非机动车事故（自行车/电动车）能否认定工伤各地规定不同，以当地社保部门认定为准 |

## 二、核心规则拆解（红队·攻防要点）

### 1. 违规操作 ≠ 自残（主观故意是分水岭）
- 《工伤保险条例》第16条"自残"指**蓄意伤害本人身体的主观故意**；违规操作多因疏忽、大意、赶工期，**无伤害自己的故意**。
- 用人单位若主张"自残"，须举证劳动者有蓄意自伤的主观故意（如事前表达轻生意图、事故前异常行为）。**无证据即不能认定自残**。

### 2. 四类法定排除情形（除此外无任何例外）
1. 故意犯罪导致的伤亡（破坏设备、违规易燃易爆作业构成犯罪、寻衅滋事打架斗殴犯罪）；
2. 醉酒、吸毒后作业受伤（须达**醉酒标准且醉酒直接导致事故**；轻微饮酒不当然排除）；
3. 自残、自杀（主观故意伤害自己，与工作风险无关）；
4. 法定其他情形（兜底条款，实务几乎从未适用）。

### 3. 企业四大拒赔理由均不成立
| 拒赔理由 | 法律定性 |
|---------|---------|
| "员工自己违规，公司无责" | 工伤看因果关系不看过错；违规背后是企业安全管理缺失 |
| "公司有明文规定，员工明知故犯" | 内部规章不能凌驾《工伤保险条例》，不能免除法定赔偿责任 |
| "员工不听管理、擅自作业，后果自负" | 属普通作业过失，不在法定免赔范围 |
| "纯属个人粗心，与工作无关" | 履职过程中受伤，个人粗心不切断因果关系 |

### 4. 两套法律关系分离（避免两极认知）
- **工伤赔偿关系**：无过错、全额赔付。医疗费、住院伙食补助、护理费、停工留薪期工资、伤残补助金等**法定待遇必须足额支付，不按过错比例分摊**。
- **企业内部管理关系**：员工严重违规、重大过失造成设备损坏/物料报废/停产损失，公司可通报批评、合规扣绩效奖金（不违规扣工资）、符合条件解除合同、造成重大损失可起诉索赔。
- **要点**：工伤赔付必须给，内部处罚可以有，两者互不冲突、互不抵消。

## 三、员工实操维权指南

1. **第一时间固定证据**：事故现场照片/视频/监控；工友证言、微信/工作群记录；考勤排班、工牌、入职记录（证劳动关系）；诊断证明、病历、缴费单据。
2. **申报时效（过期作废）**：单位申报 30 日内；员工个人申报 **1 年内**。公司不主动申报、拖延、口头拒绝，员工可**自行**去人社局申报，无需公司同意/盖章/配合。
3. **遭拒认/驳回**：可提行政复议、行政诉讼，此类案件员工改判胜诉比例高。
4. **认定后索赔**：持工伤认定书+劳动能力鉴定，申请劳动仲裁主张全部待遇；**未购工伤保险的，全部费用由公司全额承担**。

## 四、企业合规管理（事前规避而非事后甩锅）
1. 全员足额缴纳工伤保险，合法转嫁用工风险；
2. 做实岗前培训、安全交底、设备定期检修，留存完整台账；
3. 事故发生后积极救治、依法申报，避免恶意拒赔引发加倍赔偿；
4. 完善制度规范作业流程，从源头减少事故。

## 五、小强律师执业提示
- 工伤行政案件办案中，凡遇用人单位以"违章操作、违反厂规"拒认，**直接援引第16条反面列举+无过错责任原则**，将举证责任推回用人单位（其须证成"故意犯罪/醉酒吸毒/自残自杀"之一，否则败诉）。
- 上下班交通事故工伤认定，务必调取交警《事故责任认定书》，锁定"非本人主要责任"（同等/次要/无责任均可认，主要/全部责任不可认）。
- 关联在办案件：陈长卫劳务致害案可结合超龄劳动者工伤新规（2026-07-01 施行）评估路径。
