# 《医法仁心》案例分析之二：因告知不充分，医疗机构承担赔偿责任

> 来源：山东中医药大学第二附属医院法规办《医法仁心》法治专栏（2026-07-24）；原案来源：泰州市中级人民法院。本篇为 220030 失败文于 2026-08-28 恢复可 fetch 后回补。

## 一、基本案情
赵某因间断便血住院，诊断为"直肠恶性肿瘤"。医院评估后拟行"经腹直肠癌切除术"；术中改行"腹腔镜下直肠癌根治术"，与先前术式相比**需将患者肛门一并切除**。术后患者主张：医院选择手术方式不当，且**术中改变术式时未与患者家属沟通**，侵害知情同意权，要求承担侵权赔偿责任。

鉴定意见：患者不良后果系自身疾病特点及治疗方式所致，医院采取"腹腔镜下直肠癌根治术"符合诊疗规范；但**术前谈话对手术方式选择及可能改变手术方式未作重点告知，保肛利弊未与患方充分沟通，术中决定更改术式亦未再次沟通**，未尽到告知义务。

## 二、过错分析与裁判规则（对应 R-PI-176）
1. 手术方式选择符合诊疗规范，**不当然免责**——告知义务独立于诊疗技术合规性。
2. 依据《民法典》第 1219 条：实施手术、特殊检查、特殊治疗，医务人员应**及时向患者具体说明医疗风险、替代医疗方案**等并取得**明确同意**；不能或不宜向患者说明的，应向**近亲属**说明并取得明确同意；未尽告知义务造成损害的，医疗机构承担赔偿责任。
3. 法院判令医院承担相应侵权赔偿责任。

## 三、实务要点（三记三防）
- **术前谈话莫走形**：手术方式选择、可能变更术式、替代方案（如保肛 vs 切除）必须书面重点告知。
- **术中变动必再沟通**：术式变更/扩大范围时，需再次与患方沟通并留痕（补签字、谈话记录、录音/见证），不能"技术合规即免责"。
- **书面同意笔莫停**：知情同意书 + 术前讨论记录 + 谈话记录三件套缺一不可。

## 四、对接知识飞轮
- 与 R-PI-175（术前告知阻却过错推定）形成正反两面：已充分告知+选择自愿 → 减责；未告知/术中变更未沟通 → 担责（即便术式合规）。
- 与 R-PI-174（医疗质量安全核心制度留痕）联动：术前讨论、知情同意、谈话记录均属核心制度留痕载体。
- 与 R-PI-157（告知义务代签与举证不能）互补：告知义务的举证责任在医方。
