# 医疗合规 · 医疗纠纷 · 医疗事故：三类界分与责任路径

> **一句话结论**：三者不是程度差异，而是**三套规范体系、三种责任性质、三条程序路径**。混用是人伤医疗案件最致命的开局失误——它会直接决定你选错请求权基础、选错管辖、选错鉴定类型。

## 一、三类的规范定位（横向对照）

| 维度 | 医疗合规 | 医疗纠纷（医疗损害责任） | 医疗事故 |
| --- | --- | --- | --- |
| 规范体系 | 《医师法》《基本医疗卫生与健康促进法》《医疗机构管理条例》《广告法》《医疗保障基金使用监督管理条例》 | 《民法典》第七编第六章（1218–1228条） | 《医疗纠纷预防和处理条例》（行政）+《刑法》第335条医疗事故罪（刑事） |
| 责任性质 | **行政责任**为主（警告、罚款、暂停执业、吊销执业证书）+ 内部问责 | **民事赔偿责任** | **行政责任 + 刑事责任** |
| 核心要件 | 是否违反执业规范、准入资质、广告与宣传边界 | 过错 + 因果关系 + **原因力比例** | 医疗事故等级 + **严重不良后果**（刑事需“严重损害就诊人身体健康”） |
| 认定主体 | 卫健行政部门 / 医保部门 | **人民法院**（依医疗损害鉴定） | 医学会医疗事故技术鉴定 / 卫健部门 / 公安司法机关 |
| 鉴定类型 | 无（合规审查/行政调查） | **医疗损害鉴定**（司法鉴定机构或医学会） | **医疗事故技术鉴定**（医学会，分四级） |
| 时效/期限 | 行政处罚追责时效 | 诉讼时效 3 年（自知道或应当知道受损害及义务人起） | 行政：条例程序；刑事：追诉期限 |

## 二、责任路径分岔图（涵摄顺序）

```
患者受损
  │
  ├─① 有无民事赔偿请求？ → 民法典1218（过错）/1222（推定过错）
  │      └→ 鉴定：医疗损害鉴定 → 原因力比例 → 赔偿数额
  │           （详见 R-PI-213）
  │
  ├─② 医方有无违规执业？ → 医师法/条例 → 卫健部门行政处罚
  │      └→ 患方可举报、可作为民事案件中1222条第1项“违反诊疗规范”的证据
  │
  └─③ 是否构成医疗事故（乃至医疗事故罪）？
         → 医疗事故技术鉴定（四级）
         → 刑法335条：严重不负责任 + 就诊人死亡或严重损害身体健康
              ⚠️ 刑事因果关系标准**严于**民事原因力，民事担责50%≠刑事成立
```

## 三、今日重点吸收：三个易错点

### 错点1｜把行政上认定"违规"直接等同民事"有过错并全赔"
违反诊疗规范触发 **1222条第1项过错推定**，但**因果关系与原因力仍须查明**。行政处罚决定书是极强的证据，却不是赔偿数额的直接依据。

### 错点2｜刑民混淆——原因力比例被误用于刑事辩护
民事原因力 50% 属"同等原因"，但刑法上的因果关系要求**危害结果与严重不负责任行为之间具有刑法意义上的因果性**，且需"严重不负责任"这一规范评价。**民事鉴定的原因力结论不能直接推导刑事因果成立**。这是**韩杰医生医疗事故罪再审辩护**的核心切入口之一：以民事鉴定的低原因力反推刑事"严重不负责任"不成立，同时质疑鉴定意见的送检材料完整性。

### 错点3｜医疗服务合同中的"疗效承诺"被当成纯合同问题
疗效承诺/治愈保证同时触发**三层规范**：
| 层级 | 规范 | 后果 |
| --- | --- | --- |
| 硬法层 | 《广告法》第16条（禁止表示功效、安全性的断言或保证；禁止说明治愈率或有效率） | 行政处罚、罚款 |
| 民事层 | 《民法典》第496–497条（格式条款/不合理免责无效）、第1219条（说明义务）、第148条（欺诈可撤销） | 条款无效、可撤销、赔偿 |
| 专门法层 | 《医疗纠纷预防和处理条例》《医师法》执业规范 | 执业处罚、机构整改 |

→ 对应**面瘫后遗症针灸调理医疗服务协议合规审查**：协议中凡"保证痊愈""有效率 XX%""无效退款"表述均需删改；替代表述为"根据患者个体情况制定调理方案，疗效因人而异，本机构不作疗效承诺"，并配套书面告知与签字确认（同时满足 1219 说明义务）。

## 四、贵州本地衔接

- 医疗损害赔偿的具体项目与计算标准适用《贵州省-2026年度赔偿标准》（本库 A2.5 实时库，已于 2026-08-30 校正丧葬费 **53,285 元**口径）。
