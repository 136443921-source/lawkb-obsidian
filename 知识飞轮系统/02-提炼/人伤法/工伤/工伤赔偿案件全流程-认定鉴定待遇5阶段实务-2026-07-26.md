# 工伤赔偿案件全流程 — 认定·鉴定·待遇 5阶段18步实务

> 说明：本文为 IMA 人伤库《工伤赔偿案件全流程》提炼。原文 IMA 取文受限（code 220030），以下以《[[工伤保险条例|工伤保险条例]]》、人社部《工伤认定办法》、《劳动能力鉴定 职工工伤与职业病致残等级》(GB/T 16180) 及《湖北省工伤保险实施办法》(2026-06-01施行) 为骨，按"5阶段18步"重构实务流程，时限以最新地方立法校准。

## 阶段一：工伤认定申请（第1-4步）

**第1步 单位申报（30日）**
- 单位应自事故伤害发生/职业病诊断之日起**30日内**向参保地人社部门提出申请；特殊情况经同意可延长。
- 单位未在前述时限内提交申请，期间符合规定的工伤待遇等费用由**该单位承担**。

**第2步 个人或近亲属/工会申报（1年）**
- 单位未申请的，职工/近亲属/工会可在**1年内**直接申请（起算点同）。

**第3步 提交材料 + 受理审核（15日）**
- 材料：工伤认定申请表 + 劳动关系证明 + 医疗/职业病诊断证明。
- 人社部门收到后**15日内**审核：材料完整→受理/不受理决定；不完整→一次性书面告知补正，补正后15日内决定。

**第4步 调查核实与中止**
- 可调查核实（2名以上工作人员）；需以司法/行政结论为依据的，时限中止（不计入认定期），中止情形消失及时恢复。

## 阶段二：工伤认定决定（第5-6步）

**第5步 作出决定（60日 / 15日）**
- 自受理之日起**60日内**作出决定；事实清楚、权利义务明确的**15日内**决定。
- 作出决定后**20日内**送达职工/近亲属及单位。

**第6步 不予认定情形**
- 故意犯罪、醉酒/吸毒、自残/自杀（及法律行政法规规定的其他情形）；认定须以有权机关法律文书/生效裁判为依据。

## 阶段三：劳动能力鉴定（第7-11步）

**第7步 申请时机**
- 经治疗伤情相对稳定后存在残疾、影响劳动能力，或停工留薪期满，及时申请。

**第8步 提交材料 + 审核（5个工作日）**
- 有效诊断证明 + 完整病历材料 + 身份证明；材料不完整→5个工作日内一次性告知补正。

**第9步 作出结论（60日 / +30日）**
- 自收到申请**60日内**作出结论；伤情复杂可延长**30日**。
- 结论作出后**15日内**送达职工及单位。

**第10步 再次鉴定（15日，省级终局）**
- 对初次/复查结论不服，自收到之日起**15日内**向省级鉴定委员会申请再次鉴定；省级结论为**最终结论**。

**第11步 复查鉴定（1年后）**
- 结论作出之日起**1年后**，伤残情况变化可申请复查鉴定。

## 阶段四：工伤保险待遇申领（第12-16步）

**第12步 基金支付项目**
- 医疗费/康复费、住院伙食补助、统筹区外交通食宿费、辅助器具费、生活护理费（评残且确认需要）、一次性伤残补助金、1-4级伤残津贴、一次性工伤医疗补助金（解除合同时）、工亡三金（丧葬/供养亲属抚恤/一次性工亡补助）。

**第13步 单位支付项目**
- 停工留薪期工资福利、5-6级伤残津贴、一次性伤残就业补助金（解除合同时）。

**第14步 待遇核定与申领**
- 工伤认定 + 劳动能力鉴定结论信息录入后推送伤残待遇；凭证：待遇申请表、鉴定费票据、解除/终止合同证明、社保卡。
- 1-4级：以伤残津贴为基数缴基本养老/医疗/工伤保险至退休年龄；退休后养老待遇低于伤残津贴的，由基金补差。

**第15步 未参保/欠缴处理**
- 未依法缴费→单位支付全部待遇；补缴+滞纳金后，基金支付**新发生**费用；未足额缴费致待遇降低的，降低部分由单位支付。

**第16步 新就业形态职业伤害（试点）**
- 11家试点平台在山东省内接单的网约车/外卖/快递/货运人员，按"一键报案→平台上报→审核认定→异议处理→鉴定领待遇"流程，待遇与普通工伤拉齐。

## 阶段五：争议处理与执行（第17-18步）

**第17步 争议救济**
- 对认定/待遇不服：行政复议或行政诉讼；劳动关系争议：劳动仲裁。
- 职工主张工伤、单位否认的，**单位承担举证责任**（举证责任倒置）。

**第18步 执行与跟踪**
- 待遇通过社保卡/银行卡直发；异地就医需经办机构同意；定期复查伤残变化启动复查鉴定。

## 时限速查表

| 节点 | 时限 | 起算 |
|---|---|---|
| 单位申报工伤 | 30日 | 事故发生/诊断日 |
| 个人申报工伤 | 1年 | 同上 |
| 受理审核 | 15日 | 收到材料日 |
| 认定决定 | 60日（简案15日） | 受理日 |
| 认定送达 | 20日 | 决定作出日 |
| 鉴定材料审核 | 5工作日 | 收到申请日 |
| 鉴定结论 | 60日（+30） | 收到申请日 |
| 再次鉴定申请 | 15日 | 收到初次结论日 |
| 复查鉴定 | 1年后 | 结论作出日 |

## 律师实务提示（小强视角）

1. **时效是生命线**：1年个人申报期、15日再次鉴定期均为不变期间，逾期失权；立案即应固定证据链。
2. **举证责任倒置**是工伤案件核心武器——单位否认工伤时主动将举证责任压向单位。
3. **超龄劳动者**（2026-07-01《超龄劳动者基本权益保障暂行规定》施行）必须缴费、适用条例、违法转包连带，与本文阶段四衔接。
4. **医疗费垫付回转**：认定前由医保/单位/个人垫付的合规费用，认定后由基金支付——注意留存票据。
5. **贵州本地**：可考虑结合本省实施办法（本文以湖北2026版为示范，代理贵州案件须核对《贵州省工伤保险条例》及最新口径）。
