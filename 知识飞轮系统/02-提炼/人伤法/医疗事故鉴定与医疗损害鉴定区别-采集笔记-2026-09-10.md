# 采集笔记｜医疗事故鉴定与医疗损害鉴定的本质区别

- **来源**：IMA·人伤法律实务助手 /《医疗事故鉴定与医疗损害鉴定的区别》昌博谈法说医 2026-09-03
- **蒸馏日期**：2026-09-10 → 规则卡 R-PI-289
- **正文结构**：误区纠正 / 都评因果 / 损害后果理解不同 / 四档vs六档 / 原因力分析路径 / 三层不等价 / 不构成事故≠不赔
- **蒸馏要点**：
  - 事故鉴定四档（完全/主要/次要/轻微，无同等）；损害鉴定六档（全/主要/同等/次要/轻微/无）。
  - 二者都评因果，区别在损害后果界定与结论体系；条例规定医学会/司法鉴定机构均可受托医疗损害鉴定。
  - 三层：有无因果→原因力大小→赔偿比例；"主要原因"≠固定赔偿比。
  - 不构成医疗事故≠不赔，须看过错认定与机会丧失等评价。
- **红队攻击点**：①责任程度直接换算赔偿比例 ②只看构成/不构成 ③临界案件落档差异。
- **关联在办**：韩杰案（事故定性）、R-PI-278（多因一果原因力）。
