# 病历管理合规义务集群与行政处罚风险

> 医疗合规（行政监管类）高价值专题：病历是医疗质量「生命线」也是纠纷定责「关键证据」；行政罚则密集，是医疗机构合规最易踩雷区。

## 一、核心法定义务（医疗纠纷预防和处理条例）

- **第15条**：医疗机构及其医务人员应按国务院卫生主管部门规定**填写并妥善保管**病历资料（法定义务）。
- **第16条**：发生医疗纠纷时，应**告知**患者/近亲属病历查阅、复制及封存、启封规定。
- **第23条**：发生纠纷需封存、启封病历的，**医患双方在场**进行；封存可为原件或复制件，由医疗机构保管；尚未完成的可对已完成部分先封存。
- **第24条**：封存须开列**封存清单**，双方签字/盖章各执一份；封存满**3年**未再提解决要求的，医疗机构可自行启封。

## 二、患者知情权与病历权利（民法典/医师法/条例）

- 患者有权**查阅、复制**全部病历（门诊病历、住院志、体温单、医嘱单、化验单、影像、同意书、手术/麻醉记录、病理、护理记录、费用等）。
- 复制应提供并加盖证明印记；可收工本费（标准公开）；患者死亡其近亲属可查阅复制。
- **民法典1222**：隐匿/拒绝提供/遗失/伪造/篡改/违法销毁病历 → **推定医疗机构有过错**（民事实体后果）。
- **民法典1225**：医疗机构及其医务人员按规定填写并妥善保管病历。

## 三、行政处罚矩阵（条例第45/46/47条 + 病历书写基本规范）

| 违法行为 | 罚则 | 条款 |
|---|---|---|
| 篡改、伪造、隐匿、毁灭病历 | 对直接责任人降级/撤职；有关医务人员暂停6月~1年执业；造成严重后果开除/吊证；构成犯罪追刑 | 第45条 |
| 未制定实施医疗质量安全管理制度 / 未告知病情风险替代方案 / 高风险诊疗未预备方案 / **未按规定填写保管病历** / 拒绝复制 / 未建投诉制度 / **未按规定封存保管启封** / 未报告重大纠纷 | 责令改正+警告+**1万~5万罚款**；情节严重降级撤职、医务人员暂停1~6月执业；追刑 | 第47条 |
| 未通过技术评估和伦理审查将医疗新技术用于临床 | 没收违法所得+**5万~10万罚款**+降级撤职/吊证 | 第46条 |

- **2025 秦皇岛案**：门诊病历空项、无主诉、超权限开休假证明 → 警告+罚款（参照省级裁量）。
- **2025 佛山案**：未按规定保管病历+拒绝患者查阅 → 警告+罚款1万元（分别裁量合并处罚）。

## 四、合规红线清单（蓝队视角·医疗机构顾问）

1. **书写规范**：客观、真实、完整、及时、规范（病历书写基本规范第3条）；门诊病历须含主诉、体格检查、辅助检查、诊疗建议。
2. **权限管控**：休假证明/处方开具不超医师权限；建立内部审批留痕。
3. **封存流程**：纠纷发生即刻启动告知+双方在场封存+清单双方执；满3年启封留痕。
4. **查阅复制**：设专岗、明程序、可收工本费但**不得拒绝/阻挠**（不得以报警代履职）。
5. **禁止行为**：绝不篡改/伪造/隐匿/毁灭；电子病历系统留痕防篡改。
6. **投诉与报告**：建统一投诉管理部门+重大医疗纠纷上报卫生主管部门。
