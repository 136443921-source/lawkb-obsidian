# A2 医疗合规日课 · 医疗美容广告"疗效承诺/治愈保证"禁止红线（2026-09-29）

> **医疗三类优先 · 医疗合规（行政监管类）**。本日课服务于**面瘫后遗症针灸调理医疗服务协议合规审查**——协议须将"疗效承诺/治愈保证"列为禁止条款，仅作风险/替代方案书面告知。

## 一、法条红线（行政监管层）
1. **《广告法》第16条**（医疗/药品/医疗器械广告）：不得含有表示功效、安全性的断言或者保证；不得说明治愈率或者有效率；不得与其他药品/医疗器械的功效和安全性比较；不得利用广告代言人作推荐证明；须显著标明禁忌、不良反应。
2. **《广告法》第46条**：发布医疗、药品、医疗器械、农药、兽药等广告，**须在发布前由广告审查机关审查**；未经审查不得发布。
3. **《广告法》第28条**：商品/服务信息与实际情况不符、对购买行为有实质性影响的，属虚假广告。
4. **《医疗纠纷预防和处理条例》**：医疗机构须向患者说明病情、医疗措施、医疗风险、替代方案等，并取得书面同意（说明义务）。

## 二、2025–2026 典型处罚案例（监管口径）
- **南京煕涵倾城/徐州方华时代医美**（江苏·2025-04）：美团/抖音团购广告与审查批准内容不一致 → 违反广告法46条 → 各罚款1万元。
- **苏州元熙兰积医美**（江苏·2025-01）："紧致嫩肤/抗衰黑科技"功效无合法依据、虚假欺骗 → 违反广告法28条 → 罚款4万元。
- **浙江临海王女士线雕案**（2025-03）："瞬间年轻十岁"保证性承诺 + 无法提供进口器械注册证 → 虚假宣传+未注册器械，责令退款罚款。
- **成都金牛华欣美辰/米兰柏羽**（四川·2026-05/07）：虚构"营养点滴"功效、虚构整形案例、违规用患者形象 → 反不正当竞争法/广告法 → 罚款10万/4.3万。
- **济南美思慕医美**（2026-07）：未建医疗质量安全管理制度（违反《医疗纠纷预防和处理条例》47条1项）→ 卫健警告+罚款4万；线上虚假广告 → 市监罚款。

## 三、合规操作结论（可直接写入面瘫针灸协议）
1. 协议中**禁止**出现"保证治愈/无效退款/100%有效/无副作用"等断言或保证性表述（对应广告法16条禁止情形，亦是医疗服务合规边界）。
2. 须将**医疗风险、替代方案、不保证治愈**写入书面《知情同意/服务告知书》并留痕（对应条例说明义务 + 民法典1219）。
3. 若机构对外发布服务广告，须**先取得医疗广告审查批准文件**，发布内容与批准一致；不得用患者形象作证明、不得宣称疗效保证。
4. 注射用玻尿酸/肉毒素/线雕材料属III类医疗器械，须可出示注册证；否则涉嫌未依法注册器械+虚假宣传双风险。
