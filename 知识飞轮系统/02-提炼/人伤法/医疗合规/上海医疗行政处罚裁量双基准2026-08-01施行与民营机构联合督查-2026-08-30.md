# 2026-08-01 上海医疗行政处罚裁量"双基准"施行与民营机构三部门联合督查

> 来源：A2 每日自学习（2026-08-30），官方政策解读 + 地方督查方案 + 执法实证，经 LTI 法条体检。**医疗合规（行政监管）方向**。
> 对应规则卡：[[R-HG-057-2026上海医疗行政处罚裁量双基准与民营机构联合督查]]

## 一、为什么要关注"双基准"

自 **2026-08-01** 起施行（有效期至 2031-07-31）：
- 《上海市医疗机构行政处罚裁量权基准》—— 机构侧 **4 项**违法行为
- 《上海市医师行政处罚裁量权基准》—— 医师侧 **15 项**违法行为

修订方向是与 **《医师法》（2022-03-01 施行）** 和 **2022 年修订《医疗机构管理条例》（诊所审批制改备案制）** 衔接。虽为上海地方基准，但**反映了全国医疗行政监管的四条趋势线**，对贵州本地执法亦有参照价值。

## 二、机构侧：4 项违法行为的结构性变化

| 变化 | 内容 |
|---|---|
| 新增 | 诊所**未经备案执业** |
| 扩展 | "超出登记范围" → **"超出登记或者备案范围"** |
| 删除 | 无证擅自执业、出卖/转让/出借许可证 → 改依《基本医疗卫生与健康促进法》 |
| 删除 | 逾期不校验许可证仍执业（无裁量空间） |

**两个重要定义**：
- **禁止类技术** = 安全性/有效性不确切、存在重大伦理问题、已被临床淘汰、未经临床研究论证的医疗新技术
- **造成危害后果** = 包括但不限于对患者造成伤害、**对用人单位等相关单位造成经济损失**

## 三、医师侧：15 项违法行为，四大变化

1. **新增 2 项**（与《医师法》衔接）
   - **违反诊疗规范，对患者实施不必要的检查、治疗造成不良后果** ← 本轮最具冲击力
   - **未按照注册的执业地点、执业类别、执业范围执业**
2. 多因素综合裁量细化
3. **向无/限制行为能力人实施违法行为的，处罚更严厉**（衔接《未成年人保护法》）
4. 违法行为 7 增加 **"泄露亡故者个人信息"**

## 四、裁量技术性规则（直接影响量罚，易被忽略）

- "以上"**不含本数**，"以下"**含本数**
- "初次违法" = **二年内**未因相同违法行为受处罚
- "曾因相同违法行为被处罚" = **二年内**曾受处罚

## 五、执法实证：医疗质量安全制度不健全可单独处罚

**马卫医罚〔2026〕6号**（马鞍山市卫健委，2026-08-14）
- 相对人：德驭医疗马鞍山总医院有限公司
- 事由：**院外会诊程序上管理缺失**，医疗质量安全措施不健全
- 依据：《基本医疗卫生与健康促进法》第101条 + 《安徽省卫生健康行政处罚裁量权基准》"医疗服务管理类"第7条第1处罚阶次
- 结果：**警告 + 罚款 2 万元**

→ **启示**：院外会诊、外请专家等"灰色便利操作"已是**独立可罚事项**，不依附于具体损害后果。医院合规自查须覆盖**程序性管理制度**，不能只看诊疗结果。

## 六、民营机构：三部门联合督查五域

常州市钟楼区《民营医疗卫生机构专项督查行动实施方案（征求意见稿）》（2026-08-27）显示联合督查范式：
- **联合主体**：区卫健局 + 区市场监管局 + 医保分局（联合部署、排查、执法、惩戒）
- **督查对象**：民营医院、门诊部、诊所、**医疗美容机构**
- **卫健领域三重点**：
  1. 依法执业（许可证/备案凭证有效期、诊疗科目、超范围执业、非卫生技术人员、**执业医师违规挂证**）
  2. 医疗质量安全（核心制度落实、病历规范完整、**医疗技术临床应用管理**、院感消毒）
  3. 行风建设与医德医风
- **其余两域**：医保基金使用、价格收费与广告宣传

## 七、与在办业务的连接（面瘫针灸调理协议）

[[禁止疗效承诺与治愈保证-医疗合规规则卡-2026-08-23]] 提供的是**民事/广告法层**依据，本轮补齐**行政层**：
- 疗效承诺 → 广告宣传域（市场监管 + 卫健联合督查重点）+《广告法》
- 调理类服务超范围 → "超出登记或者备案范围"
- 非必要治疗项目 → **"不必要的检查、治疗造成不良后果"**（医师侧新增违法）
