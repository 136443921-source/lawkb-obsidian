# 一、问题意识（教义学定位）

面瘫后遗症针灸调理，本质系**医疗技术服务合同**与**医疗行为**的叠加。其合规风险不在"治不治好"，而在**意思表示的边界**——服务提供方若在协议中作出"治愈保证""无效退款""百分百有效"等断言，即越过《广告法》第16条与《医疗纠纷预防和处理条例》的红线，使一份本属民事承揽/服务合同的意思表示，蜕变为**违法广告 + 潜在欺诈**的复合违法事实。

此处须作法哲学区分：**疗效的可能性描述**（"多数患者经规范针灸后面部功能有改善"）属事实陈述范畴，受《民法典》第7条诚信原则约束但非当然违法；而**疗效的确定性承诺**（"保证治愈""签约即愈"）则是对结果的不当担保，法律评价上构成对消费者决策的不当诱导，故被一律禁止。此即"可能性 vs 确定性"的语义鸿沟，是协议起草的命门。

# 二、规范依据分层（已核填·现行有效）

| 层级 | 规范 | 核心约束 |
|---|---|---|
| 硬法 | 《广告法》第16条 | 医疗广告不得含功效/安全性断言、治愈率/有效率说明 |
| 硬法 | 《广告法》第58条 | 违法医疗广告之行政责任（责令停止、罚款、吊照） |
| 民事层 | 《民法典》第1219条 | 医务人员说明义务与患者知情同意 |
| 民事层 | 《民法典》第496–498条 | 格式条款提供者之提示说明义务，加重对方责任条款可能无效 |
| 专门法 | 《医疗纠纷预防和处理条例》第13、15条 | 如实书写病历、充分告知风险 |
| 消费者 | 《消费者权益保护法》第55条 | 虚假/引人误解宣传构成欺诈的三倍赔偿 |

### 已核填 verbatim（本地权威源·现行有效，2026-09-29 据本地库抽取）

- **《广告法》第16条**：医疗、药品、医疗器械广告不得含有下列内容：
(一)表示功效、安全性的断言或者保证；(二)说明治愈率或者有效率；(三)与其他药品、医疗器械的功效和安全性或者其他医疗机构比较；(四)利用广告代言人作推荐、证明；(五)法律、行政法规规定禁止的其他内容。
药品广告的内容不得与国务院药品监督管理部门批准的说明书不一致，并应当显著标明禁忌、不良反应。处方药广告应当显著标明“本广告仅供医学药学专业人士阅读”，非处方药广告应当显著标明“请按药品说明书或者在药师指导下购买和使用”。推荐给个人自用的医疗器械的广告，应当显著标明“请仔细阅读产品说明书或者在医务人员的指导下购买和使用”。

- **《广告法》第58条**：第五十八条　有下列行为之一的，由市场监督管理部门责令停止发布广告，责令广告主在相应范围内消除影响，处广告费用一倍以上三倍以下的罚款；广告费用无法计算或者明显偏低的，处十万元以上二十万元以下的罚款；情节严重的，处广告费用三倍以上五倍以下的罚款，广告费用无法计算或者明显偏低的，处二十万元以上一百万元以下的罚款，可以吊销营业执照，并由广告审查机关撤销广告审查批准文件、一年内不受理其广告审查申请：（一）违反本法第十六条规定发布医疗、药品、医疗器械广告的；（余略，详见本地《广告法》第58条全文）

- **《民法典》第1219条**：第一千二百一十九条　医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施手术、特殊检查、特殊治疗的，医务人员应当及时向患者具体说明医疗风险、替代医疗方案等情况，并取得其明确同意；不能或者不宜向患者说明的，应当向患者的近亲属说明，并取得其明确同意。医务人员未尽到前款义务，造成患者损害的，医疗机构应当承担赔偿责任。

- **《民法典》第496条**：第四百九十六条　格式条款是当事人为了重复使用而预先拟定，并在订立合同时未与对方协商的条款。采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款，按照对方的要求，对该条款予以说明。提供格式条款的一方未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容。

- **《民法典》第497条**：第四百九十七条　有下列情形之一的，该格式条款无效：（一）具有本法第一编第六章第三节和本法……（详见本地《民法典》第497条全文）

- **《民法典》第498条**：第四百九十八条　对格式条款的理解发生争议的，应当按照通常理解予以解释。对格式条款有两种以上解释的，应当作出不利于提供格式条款一方的解释。格式条款和非格式条款不一致的，应当采用非格式条款。

- **《医疗纠纷预防和处理条例》第13条**：第十三条　医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施手术，或者开展临床试验等存在一定危险性、可能产生不良后果的特殊检查、特殊治疗的，医务人员应当及时向患者说明医疗风险、替代医疗方案等情况，并取得其书面同意；在患者处于昏迷等无法自主作出决定的状态或者病情不宜向患者说明等情形下，应当向患者的近亲属说明，并取得其书面同意。紧急情况下不能取得患者或者其近亲属意见的，经医疗机构负责人或者授权的负责人批准，可以立即实施相应的医疗措施。

- **《医疗纠纷预防和处理条例》第15条**：第十五条　医疗机构及其医务人员应当按照国务院卫生主管部门的规定，填写并妥善保管病历资料。因紧急抢救未能及时填写病历的，医务人员应当在抢救结束后6小时内据实补记，并加以注明。任何单位和个人不得篡改、伪造、隐匿、毁灭或者抢夺病历资料。

- **《消费者权益保护法》第55条**：第五十五条　经营者提供商品或者服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；增加赔偿的金额不足五百元的，为五百元。法律另有规定的，依照其规定。经营者明知商品或者服务存在缺陷，仍然向消费者提供，造成消费者或者其他受害人死亡或者健康严重损害的，受害人有权要求经营者依照本法……（详见本地《消费者权益保护法》第55条全文）

# 三、协议审查的"红绿线"清单

**🔴 红线（一律剔除）：**
- "保证治愈""签约必愈""无效全额退款"
- "治愈率95%""有效率100%"等量化断言
- "无风险""零副作用"等安全性断言
- 将"调理改善"偷换为"治疗痊愈"的模糊措辞

**🟢 绿线（可保留并强化）：**
- "基于个体体质的中西医结合调理，旨在改善面部神经功能"
- 明确"疗效因个体差异而异，不承诺特定结果"
- 完整的风险告知 + 知情同意书（载明适应症、禁忌、可能的不良反应）
- 疗程、频次、费用的透明计价，不与"结果"挂钩
