# 医疗质量（安全）不良事件报告义务与行政处罚裁量——双轨报告制度的合规红线

## 一、问题定位

多数医院把"医疗质量（安全）不良事件报告制度"当作**内部质量改进的软性管理工具**：鼓励上报、非惩罚性、用于持续改进。这个理解在管理学上没错，在法律上却是危险的误判。

2026年公开的一批卫生行政处罚决定显示：**未落实《医疗质量（安全）不良事件报告制度》被直接认定为"未按规定实施医疗质量安全管理制度"，依《医疗纠纷预防和处理条例》第47条第1项处罚**。也就是说，这项"软制度"已经硬化为行政处罚的构成要件。

本库医疗合规方向已有两篇（病历书写不规范三层责任、执业资质双线合规与罚则竞合），缺的正是**报告义务**这条线。本篇厘清两套并行的报告轨道，并给出2026年最新的裁量基准与追责时效判断。

## 二、规范依据

1. **《医疗纠纷预防和处理条例》第10条**
   - 第1款：医疗机构应当**制定并实施医疗质量安全管理制度**，设置医疗服务质量监控部门或配备专（兼）职人员，加强对诊断、治疗、护理、药事、检查等工作的规范化管理。
   - 第2款：应当加强医疗风险管理，完善医疗风险的识别、评估和防控措施，定期检查落实情况，及时消除隐患。
2. **《医疗纠纷预防和处理条例》第47条**（罚则）：医疗机构及其医务人员有下列情形之一的，由县级以上卫生主管部门责令改正、给予警告，并处**1万元以上5万元以下罚款**；情节严重的，对直接负责的主管人员和其他直接责任人员给予或责令给予降低岗位等级或撤职的处分，对有关医务人员可以**责令暂停1个月以上6个月以下执业活动**；构成犯罪的依法追究刑事责任。
   - 第1项：未按规定制定和实施医疗质量安全管理制度；
   - 第2项：未按规定告知患者病情、医疗措施、医疗风险、替代医疗方案等；
   - 第4项：未按规定填写、保管病历资料，或者未按规定补记抢救病历。
3. **《医疗质量管理办法》**（原国家卫计委令第10号）
   - 第17条：医疗机构及其医务人员应当遵循临床诊疗指南、临床技术操作规范、行业标准和临床路径等要求开展诊疗工作，**严格遵守医疗质量安全核心制度**，做到合理检查、合理用药、合理治疗。
   - 第44条第3项：医疗质量管理制度不落实或落实不到位，导致医疗质量管理混乱的，责令限期改正；逾期不改的，给予警告，并处**3万元以下罚款**；对公立医疗机构负有责任的主管人员和其他直接责任人员依法给予处分。
4. **《医疗质量安全核心制度要点》**（18项核心制度）：首诊负责、三级查房、会诊、术前讨论、手术安全核查、危急值报告、病历管理等，是认定"制度是否落实"的具体标尺。
5. **《医疗事故处理条例》第14条**：发生**重大医疗过失行为**的，医疗机构应当在**12小时内**向所在地卫生行政部门报告——(一)导致患者死亡或者可能为二级以上的医疗事故；(二)导致3人以上人身损害后果；(三)国务院及省级卫生行政部门规定的其他情形。
6. **《行政处罚法》第36条第1款**：违法行为在**二年**内未被发现的，不再给予行政处罚；**涉及公民生命健康安全且有危害后果的，延长至五年**。
7. **地方裁量基准**：以《江西省卫生健康行政处罚裁量权基准》（2026年版，赣卫政法发〔2026〕5号）为例，对条例第47条作了细化分档（详见下）。**贵州省的现行裁量基准需另行核查（待核）**。
8. 病历类：《病历书写基本规范》《电子病历应用管理规范（试行）》——2026年泸州某案（泸市卫医罚〔2026〕5号）即以《电子病历应用管理规范（试行）》第12条第1款、《病历书写基本规范》第22条第8项认定违法事实，以条例第47条第4项作处罚依据，警告并罚款12000元。

## 三、裁判/执法要点

### （一）两条报告轨道，性质完全不同（核心蒸馏点）

| 维度 | 轨道A：医疗质量（安全）不良事件报告 | 轨道B：法定强制报告 |
|---|---|---|
| 规范来源 | 《医疗质量管理办法》体系、核心制度要点、院内制度 | 《医疗事故处理条例》第14条等法定报告义务 |
| 触发门槛 | 广义不良事件、未遂事件（near miss）均可上报 | 达到法定情形（死亡/可能二级以上事故/3人以上损害等） |
| 报告方向 | 主要为**院内**质量监控部门，行业上报为辅 | **外部**——所在地卫生行政部门（12小时内） |
| 制度取向 | 非惩罚性、鼓励主动上报、用于改进 | 强制性、逾期即违法 |
| 违反后果 | 制度未建立/未落实 → 条例第47条第1项、办法第44条第3项 | 未按时报告 → 单独的行政违法 |

> **蒸馏增量①**：医院最常见的合规漏洞是**把两条轨道混为一谈**——认为"我们有不良事件上报系统"就等于履行了法定报告义务，或者反过来，认为"没到医疗事故程度就不用报"。前者漏掉12小时外部报告，后者漏掉院内制度运行留痕。两者都会被处罚，且**处罚依据不同、不构成一事不二罚**。

> **蒸馏增量②**：轨道A的"非惩罚性"仅指**院内**对上报人不予追责，绝不意味着**行政机关**不追究医疗机构。淮南某妇产医院案（淮卫医罚〔2026〕21号，淮南市卫健委2026年7月27日作出、8月5日公告送达）中，该院为一未成年人实施终止妊娠手术后未及时向公安、卫健部门报告，被认定"**未落实《医疗质量（安全）不良事件报告制度》，即未按规定实施医疗质量安全管理制度**"。这是"软制度硬处罚"的典型样本。

### （二）检察建议已成为行政处罚的触发源

上述淮南案的证据清单第1项即为**区人民检察院《检察建议书》**（大检未行公建〔2026〕1号）。这条链路值得高度关注：**未成年人保护领域的强制报告制度 → 检察机关公益诉讼/未检部门发出检察建议 → 卫健部门启动查处 → 行政处罚**。医疗机构涉未成年人诊疗（终止妊娠、性侵伤情诊治等）未履行强制报告的，风险已不止于卫健系统内部。

### （三）裁量基准的地方化：同一条文，罚多少看省

以江西2026年版基准对条例第47条第1项的细化为例（赣卫政法发〔2026〕5号）：

| 档次 | 违法情形 | 处罚标准 |
|---|---|---|
| 较轻 | 未制定和实施医疗质量安全管理制度**1项** | 警告 + 1万~2.2万元 |
| 一般 | 未制定和实施**2项以上6项以下** | 警告 + 2.2万~3.8万元 |
| 严重 | **6项以上**，或**导致医疗事故发生** | 警告 + 3.8万~5万元；对有关医务人员可责令暂停1~6个月执业 |

同一基准对第47条第2项（告知义务）亦分三档，其中"未按规定告知病情、医疗措施、医疗风险、替代医疗方案等，**导致发生医疗事故或其他医疗纠纷等不良后果**"的，处3.8万~5万元并**责令暂停执业1~6个月**（此档为"应当"暂停，而非"可以"）。

> **蒸馏增量③**：裁量基准把"**未落实的制度项数**"作为分档因子，这直接决定了行政复议/行政诉讼的攻防焦点——**不是争"有没有违法"，而是争"算几项"**。执法认定为6项以上就跳到最高档并附加暂停执业，代理时必须逐项核对：卫健部门列举的每一项是否都属于独立的核心制度、是否有重复计算、是否属于同一事实的不同表述。

### （四）病历类违法是执法高频命中区

2026年公开的多份处罚决定呈现高度一致的画像：住院病历错别字、**代签其他医务人员姓名**、手术部位（左/右）前后矛盾、缺术前讨论记录与手术安全核查记录、病危通知书缺失、授权委托书签字处空白、患者出院后**补签**、抢救记录缺失（宿州砀山县中医医院宿卫医罚〔2026〕4号、萧县中医院〔2026〕5号、梁园区中州社区卫生服务中心梁卫医罚〔2026〕1号等，均为地方政府网站公示信息）。这些看似"笔误"的问题，在执法上被整体评价为**医疗质量安全核心制度不落实**。

### （五）追责时效按五年，不是两年

梁园区案明确援引《行政处罚法》第36条第1款，认定病历违规**涉及公民生命健康安全且有危害后果**，追责期限延长至**五年**。这意味着：医疗机构不能以"事情过去两年多了"作为抗辩，五年内的病历都在射程内；反过来，代理医方时应精确核算发现之日与违法行为终了之日，超过五年的部分坚决主张不予处罚。

> **蒸馏增量④**：行政处罚决定是**未来民事诉讼中的现成过错证据**。患方律师的高性价比动作是先向卫健部门投诉、推动查处，拿到处罚决定书后再起诉——处罚认定的"违反诊疗规范"事实可直接支撑《民法典》第1222条第1项（违反法律、行政法规、规章及诊疗规范的规定）的过错推定。这条路径成本远低于自行举证。

## 四、举证与证据要点

- **医方自证合规的材料包**：18项核心制度文本 + 培训签到 + 质控部门设置文件与人员任命 + 不良事件上报台账（含未遂事件）+ 定期质量分析会纪要与整改闭环记录 + 12小时报告的书面回执。**只有制度文本没有运行记录，等于未落实**——这是执法认定的通行口径。
- **患方/投诉方的取证路径**：向属地卫健部门书面投诉并要求书面答复；申请政府信息公开调取处罚决定；查询省市卫健委"行政处罚公示"栏目（大量决定书全文在线可查，含违法事实与证据清单）。
- **行政程序中的证据形态**：处罚决定书证据清单通常包含询问笔录、病历复印件、《医疗机构执业许可证》副本、专项许可证（如母婴保健技术服务执业许可证）、制度文本调取件。医方在被询问阶段的陈述会成为定案依据，需按前述医疗事故篇的思路审慎应对。

## 五、实务动作清单

1. **给顾问单位做一张"报告义务双轨对照卡"**：左栏轨道A（院内不良事件，含未遂），右栏轨道B（12小时法定报告 + 涉未成年人强制报告 + 传染病/药械不良事件），标明触发情形、时限、报送对象、留痕要求，贴在医务科墙上。
2. **核心制度落实做"证据化改造"**：每项核心制度配一份可调取的运行记录（术前讨论记录、手术安全核查表、危急值登记本、交接班记录），确保执法检查时"制度—记录—整改"三件套齐备。
3. **立即核查贵州省现行卫生健康行政处罚裁量基准**（省卫健委政务公开/政策法规栏目），建立本地分档表；在此之前引用外省基准仅作参考，**不得写入正式法律意见书**。
4. **病历专项自查按处罚高频项走**：代签、左右部位矛盾、术前讨论缺失、手术安全核查表签名空白、病危通知书缺失、补签——六项逐份抽查，比泛泛的"规范书写"培训有效得多。
5. **代理行政复议/诉讼时，主攻"项数认定"与"时效"两点**：逐项拆解卫健部门的制度项数计算是否重复，并核算五年追责时效起止；这两点比争议"是否违法"更容易取得实效。
