# 产品责任致人身损害责任实务

> 产品责任（《民法典》第1202–1207条）以"生产者无过错＋被侵权人择一索赔"为核心，与医疗产品责任（1223）、物件损害（1252–1258）区分适用。本笔记在既有 [[产品责任致人身损害责任实务-2026-08-19]]（缺陷三分类/惩罚性赔偿）基础上，补足供应链第三人过错追偿与流通后缺陷防控两条实务线，新增 [[R-PI-284]]、[[R-PI-285]]。

## 一、责任链条与归责

| 条号 | 规则 | 归责/性质 |
|------|------|-----------|
| 1202 | 产品缺陷致害生产者责任 | 无过错 |
| 1203 | 被侵权人向生产者或销售者择一索赔；内部按过错追偿 | 不真正连带 |
| 1204 | 运输者/仓储者等第三人过错致缺陷→生产者销售者赔偿后追偿 | 内部追偿（[[R-PI-284]]） |
| 1205 | 缺陷危及安全→停止侵害/排除妨碍/消除危险 | 预防性责任 |
| 1206 | 流通后发现缺陷应及时停止销售/警示/召回；不力致扩大损害就扩大部分担责+负担召回必要费用 | 延续防控义务（[[R-PI-285]]） |
| 1207 | 明知缺陷仍产销/未有效补救致死亡或健康严重损害→惩罚性赔偿 | 惩罚性 |

## 二、实务攻防要点

1. **对外直告生产者/销售者**：缺陷源于供应链第三人（运输/仓储）不阻断受害人对生产者、销售者的直接请求权（1203），避免陷入追偿拉锯。
2. **第三人过错追偿（1204）**：生产者/销售者先对外赔付，再固定运输单、监控、温湿度记录向有过错第三人追偿；能证缺陷完全源于第三人且己方无过错的可实质出清。
3. **流通后缺陷防控（1206）**：责任限于"扩大的损害"——须证"已发现缺陷＋未补救/补救不力＋损害扩大"；召回必要费用（如退回运费、检测费）由生产者/销售者负担。
4. **与医疗产品区分**：药品/血液/医疗器械缺陷致害适用 1223（无过错＋不真正连带＋惩罚性），与本条普通产品责任并行时按致害产品性质择条。

## 三、办案衔接
- **受害人方**：缺陷产品＋人身损害＋因果即可，直指无过错；流通后缺陷案追加"扩大损害+召回必要费用"；
- **生产者/销售者方**：对外赔付后及时追偿；缺陷发现后速启召回+充分警示以限缩扩大损害。
