# [[交通事故责任纠纷过错认定与赔偿（蓝红双视角）|交通事故责任纠纷过错认定与赔偿（蓝红双视角）]]

> 来源：公开权威源降级摄入（山东法院/腾讯新闻 2026 最高法道交解释二报道 + 《民法典》第1213条 + 《道交法》第76条 + 交强险限额）。原定 IMA「人伤法律实务助手」库摄入，因 IMA 运行态掉线改用公开源。

## 一、蓝队视角（受害方·索赔路径）

1. **赔偿顺序（《民法典》第1213条）**
   - 交强险责任限额内 → 商业三者险按合同 → 不足由侵权人赔偿。

2. **交强险限额（2020版）**
   - 有责任：死亡伤残 18万、医疗费用 1.8万、财产损失 2千。
   - 无责任：死亡伤残 1.8万、医疗费用 1800、财产损失 100。

3. **责任认定口径（《道交法》第76条）**
   - 机动车之间：有过错方赔，双方过错按过错比例分担。
   - 机动车—非机动车/行人：非机动车/行人无过错，机动车全赔；有过错适当减轻；机动车无错承担≤10%；故意碰撞不赔。

4. **实务要点**：人身伤亡与财产损失均在交强险覆盖；停运损失、替代交通工具费属商业险/侵权人范畴。

## 二、红队视角（侵权方/保险人·攻防面）

- **行政定责 ≠ 民事赔偿**：交警认定"交通意外、双方无责"，不当然免除民事赔偿责任。民事赔偿看是否尽合理注意义务 + 行为与损害有无法律因果关系（弹起木棍砸车案：压到木棍方担责）。
- **商业险免责**：酒驾、肇事逃逸，保险人就免责条款尽提示说明义务的，商业三者险免除赔偿（最高法道交解释二典型案例）。
- **共同侵权（开门杀）**：驾驶人未提醒 + 乘车人开车门碰撞，二者结合构成共同侵权；对受害人而言驾驶人及乘车人均属"机动车一方"整体，保险整体赔付。
- **车辆所有人过错**：明知饮酒仍交车，在过错范围内承担相应比例（如40%）。

## 三、可复用攻防清单

- [ ] 核对交强险/商业险投保与事故期间
- [ ] 审查免责条款提示说明义务是否履行（酒驾/逃逸抗辩前提）
- [ ] 主张"行政定责≠民事过错"，举证注意义务违反
- [ ] 共同侵权情形下整体主张机动车一方责任
