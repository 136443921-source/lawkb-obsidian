# 精神损害抚慰金酌定标准

> 定向补强·人伤法主线｜精神损害抚慰金是人身损害中最"软"的项目，无统一法定限额，高度依赖法官自由裁量。本笔记梳理酌定规则、司法实践档次与攻防要点。

## 一、法律定位与依据

- **独立赔偿项目**：精神损害抚慰金与残疾/死亡赔偿金、医疗费等**并列独立**，不相互吸收（法释〔2020〕17号第1条）。
- **请求权基础**：因人身权益（生命权、健康权、身体权、姓名权、名誉权等）受侵害，或具有人身意义的特定物受损，致"严重精神损害"方可主张。
- **现行规范**：《民法典》第1183条 + 法释〔2020〕17号（2021年修正）。

## 二、适用前提——"严重精神损害"

1. 一般轻微伤、未达伤残等级，原则上不予支持；但**侵害自然人具有人身意义的特定物**（如遗照、骨灰）不受"严重程度"限制。
2. 造成**残疾、死亡**的，当然认定为严重精神损害，应予抚慰。
3. 法释〔2020〕17号已删除原"非法使被监护人脱离监护"等列举情形，回归《民法典》第1183条的"严重"概括标准。

## 三、酌定考量因素（法释〔2020〕17号第5条）

法院确定数额时综合考量：

| 因素 | 说明 |
|------|------|
| 侵权人的过错程度 | 故意 > 重大过失 > 一般过失 |
| 侵害的手段、场合、行为方式 | 公然、恶劣手段应加重 |
| 侵权行为所造成的后果 | 伤残等级、死亡为关键权重 |
| 侵权人的获利情况 | 经营性侵权（如非法买卖个人信息）加重 |
| 侵权人承担责任的经济能力 | 兼顾执行可行性 |
| 受诉法院所在地平均生活水平 | 地区差异显著 |

> **城乡是否统一？** 2022年人身损害赔偿城乡统一后，**残疾/死亡赔偿金**已同命同价；但精神损害抚慰金本就非按"收入标准"计算，而是按上述六因素酌定，故**不适用城乡区分**，全国统一按上述因素裁量。

## 四、司法实践档次（参考，非法定）

各地高院多以"伤残等级/死亡"为基准设指导意见（下列为常见区间，具体以受诉法院为准）：

- **死亡**：普遍 5万–10万（京沪约8万–10万，中西部约5万–7万）。
- **伤残**：多按伤残等级每级对应系数，如十级约 5000元、每升一级递增约 5000元，一级/植物状态接近死亡标准。
- **未达伤残但严重后果**：数千元酌定，支持难度大。

## 五、与交强险、商业险的衔接

1. **交强险优先赔付精神损害**：法释〔2020〕17号第16条（道交解释）允许受害人请求在交强险"死亡伤残"限额内**优先赔付精神损害抚慰金**——这是伤者方应主动主张的排序技巧（见 [[R016-交强险限额内不分责先行赔付]]）。
2. 商业三者险合同多将精神损害列为**免责**，故精神抚慰金常最终由侵权人自行承担，应在诉请中单列。

## 六、庭审攻防要点

- **原告方**：① 达到伤残/死亡即应主张，勿遗漏；② 主张交强险内优先赔付；③ 以"过错程度+后果"为主轴组织证据（如侮辱性手段的录音录像、伤残鉴定意见）。
- **被告/侵权方**：① 抗辩"未达严重精神损害"；② 主张受害人**故意或重大过失**可减轻（如自甘风险情形，见 [[R020-自甘风险文体活动损害免责]]）；③ 经营性侵权注意获利因素推高数额。

## 七、争议与前沿

- **同命同价后的精神抚慰金**：既然残疾/死亡赔偿金已统一，精神抚慰金是否也应设全国统一上限？目前仍授权地方法院，存在地区"同残不同价"现象，学界呼吁上限规范化。
- **刑事附带民事诉讼**：依现行解释，刑附民**不支持**精神损害赔偿（仅可单独提民事诉讼），此"刑民二元"格局仍是实务痛点。
