# 人伤伤残鉴定攻防：重新鉴定与鉴定人出庭质证实务

> 配套裁判规则：[[R-PI-066]]（重新鉴定启动条件）、[[R-PI-067]]（鉴定人出庭）、[[R-PI-068]]（人损与工伤双标准对比）
> 索引：[[人伤法索引]]

## 一、两套伤残标准的适用边界（[[R-PI-068]]）

| 标准 | 适用法律关系 | 特点 |
|------|--------------|------|
| 《人体损伤致残程度分级》（两院三部，2017） | 普通民事侵权（交通/一般人身损害/医疗损害） | 10级，晋级规则自成体系 |
| GB/T 16180-2014《劳动能力鉴定》 | 工伤保险 | 10级，门类/晋级与前者不同 |

**竞合案件**（如上下班途中交通事故）：分别委托两类鉴定；残疾赔偿金（侵权）与一次性伤残补助金（工伤）可兼得，医疗费不得重复（[[R-PI-036]][[R-PI-037]]）。等级不可直接换算。

## 二、重新鉴定的法定事由（[[R-PI-066]]）

申请重新鉴定须具备下列情形之一，法院审查决定，**非"不服即重鉴"**：
1. 鉴定机构/人员不具备相关资格；
2. 鉴定程序严重违法；
3. 鉴定意见明显依据不足；
4. 经质证不能作为证据使用的其他情形；
5. 同一专门性问题出现相互矛盾结论。

有缺陷的鉴定结论，优先通过**补充鉴定、重新质证**解决，不予重新鉴定。医疗损害中警惕"以鉴代审"——应主动拆解诊疗过错（见 [[医疗损害责任纠纷中从诉讼视角对司法鉴定意见的法律分析]]）。

## 三、鉴定人出庭与质证（[[R-PI-067]]）

- 当事人有异议或法院认为必要，**鉴定人应当出庭**；经通知拒不出庭的，鉴定意见**不得作为定案依据**，并可要求返还鉴定费。
- 质证五维：**资质 / 程序 / 检材 / 依据 / 分析方法**，而非仅否定结论。
- 可配合**专家辅助人**（《民诉法》第82条）出庭，就专业问题发表意见。

**攻防清单**：
- [ ] 举证期限内书面申请重新鉴定/出庭，明确具体法定事由
- [ ] 庭前提交书面质询要点（五维框架）
- [ ] 对方鉴定无瑕疵时，反对不必要的出庭/重鉴
- [ ] 鉴定人拒不出庭 → 主张意见不采信 + 退费
