# 误工费·护理费·营养费计算实务

> 定向补强·人伤法主线｜三项"期间性"费用，举证密度高、易被压缩，是庭审攻防重点。

## 一、误工费（司法解释第7条）

### 1. 计算公式
```
误工费 = 误工时间 × 收入标准
```

### 2. 误工时间
- 依医疗机构出具的**证明**确定（病历、诊断证明、休假建议）。
- 因伤致残**持续误工**的，误工时间可计算至**定残日前一天**。

### 3. 收入标准（三档举证）
| 情形 | 计算方式 | 举证材料 |
|------|----------|----------|
| 有固定收入 | 据实计算减少部分 | 工资流水、单位减发证明、个税记录 |
| 无固定收入 | 最近三年平均收入 | 完税凭证、收入合同、银行流水 |
| 无法举证近三年 | 参照相同/相近行业上年度职工平均工资 | 统计年鉴行业工资数据 |

> **实务陷阱**：单位出具的"减发工资证明"须与银行流水、个税申报相互印证，孤证常被对方以"关联方虚假证明"抗辩。

## 二、护理费（司法解释第8条）

### 1. 计算公式
```
护理费 = 护理人数 × 护理期限 × 护理标准
```

### 2. 三要素
- **护理人数**：原则 1 人；医疗机构或鉴定意见有明确要求的可 2 人及以上。
- **护理期限**：至受害人恢复生活自理能力止；受害人因残疾不能恢复的，可根据年龄、健康状况等确定合理护理年限，但**最长不超过 20 年**。定残后护理依护理依赖程度（完全/大部分/部分护理依赖）确定。
- **护理标准**：
  - 有收入的护理人员：参照误工费规定。
  - 无收入或雇佣护工：参照当地护工从事同等级别护理的劳务报酬标准。

## 三、营养费（司法解释第11条）

- **计算依据**：根据受害人**伤残情况**参照**医疗机构的意见**确定。
- 无医嘱营养费/加强营养建议的，主张营养费通常难获支持；应主动申请载明"建议加强营养 X 个月"的医疗意见。

## 四、住院伙食补助费（司法解释第10条，附带速查）
```
住院伙食补助费 = 住院天数 × 当地国家机关一般工作人员出差伙食补助标准
```
必要时经批准到外地治疗、因客观原因无法住院的本人及陪护人员的合理食宿费，也予赔偿。

## 五、庭审攻防要点

1. **误工时间对齐定残日**：致残案件误工可算至定残日前一天，切勿只算到出院日，易漏算大额。
2. **护理期限锚定护理依赖鉴定**：定残后主张长期护理费须有"护理依赖程度"鉴定支撑，否则仅支持至治疗终结。
3. **营养费须有医嘱**：无医疗意见的营养费主张普遍被驳，务必固定书面医嘱。
4. **票据 vs 标准的择优**：交通费、住院伙食等据实票据与法定标准取合理者，避免票据缺失导致全额驳回。
