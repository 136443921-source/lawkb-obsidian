# 医疗费赔偿项目及相关法律问题 蒸馏笔记

> 原文：北京资深医疗律师张金荣（2025-12-03）——医疗费赔偿范围、计算与程序救济。

## 一、核心规则（对应 R-PI-193）

### 医疗费范围与计算
- **计算公式**：医疗费赔偿金额 = 已发生医疗费用（不含原发病费用）+ 预期医疗费用
- **构成**：门诊费（挂号/检查/治疗/医药）+ 住院费（住院/药费/治疗/会诊/输血/手术）+ 材料费（固定架/颈托/钢板等）

### 举证与关联性（关键）
1. 门诊：发票 + 处方/诊断证明/门诊手册（证明与医疗损害有关）
2. 住院：发票 + 药品清单/诊断证明/住院病历
3. **排除原发病**：不含治疗原发病或无关疾病的费用
4. **转院**：须提供转院证明，否则可能认定自行扩大损失；外购药须医生诊疗意见；多家医院分别统计
5. **康复费**：已发生可计入；未发生的凭医疗单位证明可一并计算一次性赔偿

### 继续治疗费
- 分**必然发生**与**可能发生**：必然发生的可评估或凭诊断证明/治疗方案确定；可能发生或难以确定的，**可待实际发生后另行起诉**

### 先予执行（程序救济）
- 依《民事诉讼法》第109条：追索医疗费用的可申请先予执行
- 条件（第110条）：①权利义务关系明确，不先予执行将严重影响生活/生产经营 ②被申请人有履行能力；可责令提供担保

## 二、在办业务连接

- 人伤/医疗损害案件赔偿计算：医疗费举证清单（发票+病历+关联性证明）
- 韩杰案家属索赔侧：医疗费构成与继续治疗费计算

## 三、法条体检

- 《民事诉讼法》第109/110条（先予执行）✅ 现行有效
- 《人身损害赔偿司法解释》第6条（医疗费）✅ 现行有效
- 《民法典》第1179条（人身损害赔偿范围）✅ 现行有效
