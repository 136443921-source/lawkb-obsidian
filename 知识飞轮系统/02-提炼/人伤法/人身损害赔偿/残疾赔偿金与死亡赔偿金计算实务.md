# 残疾赔偿金与死亡赔偿金计算实务

> 定向补强·人伤法主线｜两大"收入能力损失"项目，金额占比最高、争议最集中。

## 一、残疾赔偿金（司法解释第12条）

### 1. 计算公式
```
残疾赔偿金 = 上一年度城镇居民人均可支配收入 × 赔偿年限 × 伤残赔偿系数
```

### 2. 三要素拆解
- **赔偿年限**：自定残之日起计 20 年；60 周岁以上，年龄每增加 1 岁减少 1 年；75 周岁以上按 5 年计算。
- **伤残赔偿系数**：一级伤残 100%，每下降一级递减 10%，十级 10%。
- **多处伤残综合计算**：以最高伤残等级确定基准（如最高为二级 = 90%），其余伤残每处附加 1%~10% 的"伤残附加指数"，累计不超过 10%，总系数封顶 100%。
  ```
  综合系数 = 最高等级系数 + Σ附加指数（附加指数上限累计10%，总额≤100%）
  ```

### 3. "劳动能力丧失说" vs "收入丧失说"
- 我国司法解释采**劳动能力丧失说**：只要构成伤残，即推定劳动能力受损，不以实际收入减少为要件。
- 例外抗辩：加害方举证受害人**实际收入未减少**的，法院可对残疾赔偿金作相应调整（第12条第2款），但抚慰性、能力补偿性部分仍应支持。

## 二、死亡赔偿金（司法解释第15条）

### 1. 计算公式
```
死亡赔偿金 = 上一年度城镇居民人均可支配收入 × 20 年
（60 岁以上每增 1 岁减 1 年；75 岁以上按 5 年）
```

### 2. 性质与分配
- **性质**：财产损害赔偿（对家庭预期收入损失的填补），**非遗产**，不用于清偿被继承人生前债务。
- **分配**：由近亲属按扶养/继承关系合理分配，非严格按继承份额；实务中综合考虑与死者共同生活紧密度、扶养依赖程度。

## 三、被扶养人生活费（司法解释第17条）

- **计算**：城镇居民人均消费支出 × 扶养年限。
  - 未成年人：算至 18 周岁。
  - 无劳动能力又无生活来源的成年近亲属：计 20 年，60 岁以上递减，75 岁以上按 5 年。
- **分摊**：有其他扶养人的，只赔加害行为人依法应负担的份额；被扶养人有数人的，年赔偿总额累计不超过上年度城镇居民人均消费支出额。
- **⚠️ 防重复**：已**计入**残疾赔偿金或死亡赔偿金（第17条明定），起诉时须在赔偿总额中体现，不得作为独立项目重复主张。

## 四、就高原则（司法解释第19条精神）

受害人住所地或经常居住地的城镇居民人均可支配收入 / 消费支出**高于**受诉法院地标准的，残疾赔偿金、死亡赔偿金、被扶养人生活费可按较高标准计算。
- **举证要点**：经常居住地满 1 年——居住证、租赁合同、社保缴纳、暂住登记、连续工资流水等形成证据链。

## 五、计算模板（示例）

> 假设：受害人 45 岁，八级伤残，受诉法院地上年度城镇居民人均可支配收入 40,000 元/年。
```
伤残系数（八级）= 30%
赔偿年限 = 20 年（未满 60 岁）
残疾赔偿金 = 40,000 × 20 × 30% = 240,000 元
```

## 六、实务注意事项

1. **数据锚定**：以一审法庭辩论终结时最新可得的省级统计年鉴"城镇居民人均可支配收入"为准。
2. **定残时点**：残疾赔偿金年限自"定残之日"起算，鉴定意见的定残日期直接影响年限，务必核对。
3. **多份鉴定冲突**：以程序合法、方法规范、鉴定资质齐备者为准，必要时申请重新鉴定或鉴定人出庭。
4. **精神损害抚慰金另列**：依《民法典》第1183条及精神损害赔偿解释单独主张，不并入残/死赔金。
