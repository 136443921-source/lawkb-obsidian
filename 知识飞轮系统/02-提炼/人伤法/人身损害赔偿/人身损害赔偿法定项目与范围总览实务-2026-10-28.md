# 人身损害赔偿法定项目与范围总览实务（2026-10-28）

> 本笔记以民法典1179为总纲，串联合期新增 R-PI-619 与既有赔偿计算卡（R-PI-017/019/247/051/546/547），形成"项目清单→计算标准→口径锁定"的人伤赔偿实务地图。

## 一、1179 法定赔偿项目（三层结构）

```
人身损害赔偿（1179）
├─ 基础赔偿（未致残疾/死亡）
│   ├─ 医疗费、护理费、交通费、营养费、住院伙食补助费（"等"含康复费、后续治疗费）
│   └─ 误工费（因误工减少的收入）
├─ 残疾附加：辅助器具费 + 残疾赔偿金（含被扶养人生活费，并入计算）
└─ 死亡附加：丧葬费 + 死亡赔偿金（含被扶养人生活费）
```

**关键**：1179为开放兜底，"为治疗和康复支出的合理费用"可涵盖后续治疗费、整容费、康复护理费，被告不得仅以"未列明"抗辩剔除。

## 三、实务雷区

1. **医疗费合理性审查**：过度医疗、与事故无关治疗费可剔除，被告应要求原告举证"关联性+必要性"。
2. **标准锁定双口径**：残疾/死亡赔偿金须严格锁定"受诉法院所在地"或"经常居住地"标准（R-PI-546），避免城乡混算；"上一年度"须为"一审法庭辩论终结时上一统计年度"（R-PI-547），非事故发生时。
3. **被扶养人生活费并入**：2022年人损解释已将其计入残疾/死亡赔偿金，单列主张易致重复，须按R-PI-051年维度封顶核算。
4. **精神抚慰金独立**：不与1179物质损害赔偿混同，刑事附带民事原则上不支持（见R-PI-069）。
