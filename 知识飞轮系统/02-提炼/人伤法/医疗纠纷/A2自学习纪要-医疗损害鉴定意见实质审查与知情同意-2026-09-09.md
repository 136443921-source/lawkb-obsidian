# 一、今日学习锚点

围绕在办**韩杰医疗事故罪再审**与**面瘫后遗症针灸调理协议合规**两条主线，聚焦两个实务高频争点：**医疗损害鉴定意见的实质审查**与**知情同意（告知义务）的边界**。

# 二、医疗损害鉴定意见的实质审查

最高法《医疗损害责任纠纷案件审理思路和裁判要点》明确：医疗损害鉴定旨在借助专家知识辅助法官判断专门事实，但法官不得"以鉴代审"，须对鉴定意见作实质审查。

- **鉴定启动**：当事人申请为主、法院依职权为辅；医学会或司法鉴定机构组织。
- **材料质证前置**：鉴定材料须先经质证；当事人对病历真实性/完整性异议的，可笔迹鉴定或电子病历鉴定；病历造成鉴定无法客观进行的，终止鉴定（B医院丢产程记录→举证不能全赔）。
- **重新鉴定门槛**：鉴定人不具备资格、程序严重违法、意见明显依据不足等（新民诉证据规定第40条）。
- **⚠️ 形式瑕疵≠过错推定**：病历书写不规范、不及时属形式瑕疵，不构成民法典1222条过错推定；只有篡改"实质性内容"才触发。
- **原因力六分**：全部/主要/同等/次要/轻微/无因果关系，鉴定意见须明确表述（呼应 R-PI-278）。

# 三、知情同意与告知义务边界

- **一般告知**：医务人员在诊疗活动中应向患方说明病情、医疗措施；特殊检查/特殊治疗须说明医疗风险、替代方案，取得明确同意（民法典1219）。
- **例外**：抢救生命垂危等紧急情况可不经同意；不能/不宜向患者说明的，向近亲属说明并取得同意。
- **实务风险点（面瘫针灸协议可直接套用）**：
  - 疗效承诺/治愈保证属《广告法》与医疗纠纷预防条例红线（见 R-PI-276），协议中不得出现"包治"" guaranteed 痊愈"等表述。
  - 知情同意书须载明"医疗风险、替代方案、可能的不良后果"，并由患方签字；针灸属有创/侵人性操作，须单独告知晕针、血肿、感染、神经损伤等风险。
  - 病历书写须规范完整，避免"形式瑕疵"升级为"实质性篡改"争议。

# 四、回流办案

- **韩杰案**：再审辩护锚定"以鉴代审否定 + 鉴定意见实质审查 + 重新鉴定门槛"三件套；医疗事故罪"严重不负责任"须有鉴定意见/事故技术鉴定书支撑，不能仅凭损害后果倒推。
- **面瘫针灸协议**：依本纪要第三部分设计合规条款，明确风险告知清单与免责边界，规避疗效承诺红线。
