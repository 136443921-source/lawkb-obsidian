# 缺陷医疗产品与不合格血液致害责任（民法典1223）

> 医疗纠纷（民事类）高价值专题：区别于一般医疗损害「过错责任」（民法典1218），医疗产品致害走**无过错责任**轨道，是患者求偿最有利的两条路径之一。

## 一、规范定位（法教义学）

- **民法典第1223条**〔药品、消毒产品、医疗器械的缺陷，或输入不合格血液的侵权责任〕：患者可向**药品上市许可持有人、生产者、血液提供机构**请求赔偿，也可向**医疗机构**请求赔偿；向医疗机构请求赔偿的，医疗机构赔偿后有权向负有责任的生产者/持有人/血液提供机构**追偿**。
- 本条由《侵权责任法》第59条演来；归责原则与产品责任一致，为**无过错责任**（严格责任）。
- 与民法典1218一般医疗损害（过错责任）形成「二元归责」：普通诊疗过失需患者证过错；医疗产品/血液缺陷只需证**缺陷+因果关系**，不问医疗机构过错。

## 二、责任主体（外部不真正连带责任）

| 主体 | 归责 | 备注 |
|---|---|---|
| 医疗机构 | 无过错（对外） | 便利患者求偿被列为责任主体；赔偿后可追偿 |
| 药品上市许可持有人(MAH) | 无过错 | 2019《药品管理法》新增；境外MAH境内代理人连带 |
| 医疗器械注册人/备案人 | 无过错（类推MAH） | 据《医疗器械监督管理条例》第103条类推适用 |
| 生产者/销售者 | 生产者无过错；销售者过错（不能指明生产者/供货者则担责） | 销售者未明列但可依产品责任一般规则追偿 |
| 血液提供机构（血站） | 无过错（拟制为产品） | 医疗机构自行采血则自身为血液提供机构 |

- **外部责任形态=连带责任**（不真正连带）：患者可只诉医疗机构，也可一并诉生产者；医疗机构担责后单向追偿（民法典1223第2句）。
- **惩罚性赔偿空间**：责任主体**明知**缺陷仍使用致患者死亡/健康严重损害，可适用惩罚性赔偿（产品质量法第1207条类推）。

## 三、缺陷/不合格的认定标准

- 以「**不合理危险**」为基本标准，强制性标准为辅助标准（武亦文评注）。
- 医疗产品范围（封闭式列举）：药品、消毒产品、医疗器械；血液及血液制品。
- 临床试验阶段医疗产品致害**不属**本条（未投入市场流通）。

## 四、举证分配（抗辩事由）

- 医疗机构/生产者/销售者/MAH主张不担责的，对「医疗产品不存在缺陷」或「血液合格」等抗辩事由**承担举证责任**（医疗损害责任司法解释第21条）。
- 患者举证门槛低：仅需证使用医疗产品/输入血液 + 损害 + 因果关系；因果关系不明可申请**鉴定**。

## 五、实务抗辩要点（红队视角）

1. **医疗机构免责/减责突破口**：证明缺陷**非因医疗机构过错**产生（如生产者制造缺陷）→ 对外仍赔但追偿成功即实质转移。
2. **适用范围抗辩**：患者从医疗机构**之外渠道**购得缺陷产品 → 落一般产品责任，医疗机构不担1223责任。
3. **因果中断**：损害系患者自身疾病/不当使用所致，与产品缺陷无因果关系 → 全免责。
4. **追偿闭环**：代理医疗机构时，应在诉讼中依司法解释第21条**申请追加生产者/销售者为共同被告**，固化追偿权。
