# 医疗损害责任纠纷诉讼时效起算实务

> A2 每日自学习 · 医疗三类之一（医疗纠纷 · 民事）
> 锚定案例：（2022）粤民再152号（广东高院再审）

## 一、问题意识

医疗损害案件的时效抗辩，是医方最常用、也最容易被机械适用的防御手段。实践中大量法院直接以"手术日""出院日""死亡日"起算三年，导致患方在鉴定尚未完成、过错尚未查明时即被判超过时效。这一做法的根本问题在于：**把第 188 条的主观起算要件客观化了**。

## 二、教义学梳理

### 2.1 规范文本

《民法典》第 188 条第 2 款：诉讼时效期间自权利人**知道或者应当知道权利受到损害以及义务人**之日起计算。

两个认知对象：① 权利受到损害；② 义务人。缺一不构成起算。

### 2.2 医疗领域的解释难点

| 认知对象 | 一般侵权 | 医疗损害 |
|---|---|---|
| 权利受损 | 直观可感（车撞了、打伤了） | 损害结果与疾病自然转归高度混同 |
| 义务人 | 通常明确 | 多机构就诊时主体识别困难 |
| 因果关系 | 常识可判 | 须专业鉴定，普通人无从判断 |
| 过错 | 常识可判 | 须比对诊疗规范，专业壁垒极高 |

正因如此，吕某案确立：**"知道"的对象不是"身体出了事"，而是"诊疗行为符合侵权责任构成要件"**——违法行为、损害、因果关系、过错四要素的认知。

### 2.3 举证负担的实质配置

裁判要点的表述是关键：**"在没有证据证明患方知道或者应当知道诊疗行为符合侵权责任构成要件的情况下"**。

这一句把时效抗辩的举证负担压给了主张时效届满的医方。逻辑链条是：
1. 时效抗辩是权利妨碍抗辩，主张者负举证责任（一般规则）；
2. 医疗领域的认知障碍是常态而非例外（经验法则）；
3. 故推定患方在鉴定完成前不具备构成要件认知，医方欲推翻须举反证。

## 三、实务操作

### 3.1 患方：起算点重设的证据锚点（由早到晚排列，取最晚可证者）

| 节点 | 证明材料 | 强度 |
|---|---|---|
| 病历封存/复印日 | 封存记录、复印回执 | 弱（仅取得材料，未必理解） |
| 向卫健部门投诉日 | 信访登记表 | 中（已有怀疑，未必有构成要件认知） |
| 自行委托专家论证日 | 委托书、专家意见 | 强 |
| 医疗事故技术鉴定书出具日 | 鉴定书 | 强 |
| **司法鉴定意见书送达日** | 送达回证 | **最强（推荐主位主张）** |

多机构就诊的，额外主张：在鉴定明确各机构原因力之前，无从确定"义务人"，第 188 条第二个认知对象未成就。

### 3.2 医方：反证方向

- 患方早期投诉材料中若已明确指控"医院误诊/漏诊导致后果"，可主张其彼时已形成构成要件认知；
- 患方曾自行委托鉴定并已收到不利/有利结论的时间点；
- 医患协商记录中患方提出具体赔偿数额的时间（表明已完成损害评估）；
- 网络发帖、媒体采访中的表述。

### 3.3 硬顶：二十年最长保护期

《民法典》第 188 条第 2 款后段：自权利受到损害之日起超过**二十年**的，人民法院不予保护。此为客观期间，不因主观认知延后。特殊情况可申请延长。

## 四、与既有知识的衔接

- 与 [[R-PI-071]]（生存期缩短赔偿计算）联动：生存期缩短类案件的时效争议尤为突出——损害后果（死亡）与过错认知（鉴定）时间跨度大，本规则提供了关键的时效防线。
- 与 [[R-PI-072]] 为同一规则的卡片化沉淀。

## 五、待深化问题

1. "应当知道"应采一般理性人标准还是具体患方标准？现有裁判说理不统一，需继续跟踪。
2. 患方委托鉴定被医方拒绝配合、导致鉴定延迟的，延迟期间是否计入时效？可探索适用《民法典》第 194 条时效中止。
