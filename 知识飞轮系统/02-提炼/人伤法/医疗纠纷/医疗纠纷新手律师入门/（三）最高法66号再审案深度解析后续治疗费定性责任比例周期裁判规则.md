# 医疗纠纷新手律师入门（三）：最高法66号再审案深度解析｜后续治疗费定性、责任比例、周期裁判规则

在前两篇医疗纠纷文中，我们分别讲了：从《医师法》抓医生程序违规、跳出司法鉴定依赖，主动拆解诊疗实质过错。但实务中还有一类最难、最容易败诉、最容易被法院驳回的医疗纠纷案件：伤残终身存续、需要终身持续治疗、多年后二次、三次起诉的后续费用纠纷。今天我们一起来深入学习（2020）最高法民再66号经典医疗损害再审大案，该案是最高检抗诉、最高法提审改判的标杆案例，也是目前医疗后续治疗费纠纷中最权威的参考判例。# 
## 一、案件基础事实

1987年，当事人俞明因交通事故造成骨盆、膀胱、尿道严重损伤，送入宁夏医科大学总医院救治。医院在诊疗过程中存在多处实质诊疗过错（无明显程序瑕疵，完全是实质诊疗失误）：1. 遗漏骨盆骨折伴随的尿路损伤诊断；
2. 拔除导尿管后，未采取有效尿液引流措施，加重会阴感染、尿瘘风险；
3. 护理不到位，导致患者褥疮生成，进一步影响骨骼复位与体态畸形；
4. 手术未充分履行知情同意规范。

后续患者被迫行人工可控膀胱、尿道改道手术，终身依赖导尿管、瘘口换药、储尿囊冲洗维持生命，构成一级伤残。案件核心时间线：1. 交通事故案件：肇事方赔偿部分费用；
2. 第一次医疗纠纷诉讼：法院按普通导尿管8.5元/根、4根/天，判20年器具费25万余元；
3. 20年期限未到，但原标准完全无法满足现实治疗需求，患者二次起诉主张后续终身治疗费；
4. 一审、二审、高院再审均驳回核心诉求，认为属于重复主张、证据不足；
5. 最高检抗诉，最高法提审，撤销多审判决、改判支持大额后续医疗费用。

# 二、新手律师必学：本案三大核心改判裁判规则

规则一：区分「残疾辅助器具费」与「维持生命型医疗费」，是本案颠覆性要点

这是90%律师、基层法院都会踩的法律误区，也是本案再审翻盘的最核心关键点。✅ 最高法明确界定：1. 残疾辅助器具：提升生活质量（假肢、轮椅等），属于生活辅助属性；
2. 终身导尿、瘘口换药、储尿囊冲洗：维持生命必需的诊疗行为，属于后续医疗费，而非器具费。

❌ 原审错误：将患者保命必须的持续医疗行为，错误定性为普通残疾辅助器具费，直接限制赔偿标准、压缩赔偿空间。💡 律师办案实操：凡是伤残后需要终身持续性医疗处置、换药、冲洗、防感染、维持器官功能的费用，一律主张为后续必然发生的医疗费，不按辅助器具费抗辩，不受普通器具赔偿标准限制。## 规则二：多因一果（原发外伤+医疗过错）责任比例固定规则

本案患者损伤根源是交通事故（原发重伤），医院诊疗过失是加重、扩大损害的次要原因。✅最高法裁判观点：1. 原发交通事故是一级伤残的主要、直接原因；
2. 医方漏诊、未引流、护理失误，是损害扩大的次要原因；
3. 结合过错程度与原因力，医方30%责任比例合法、适度，不予调整。

💡 新手避坑：多因一果医疗纠纷，不要盲目主张全责！法院严格按照「原因力大小」划分责任，原发损伤严重的，医方普遍承担30%—40%责任，过度主张全责极易被全盘不支持。## 规则三：后续必然发生医疗费，可突破“实际发生后再起诉”原则

很多律师被固有思维困住：后续费用没实际发生，不能起诉。✅ 最高法明确突破：根据医疗机构明确诊断证明，伤情终身存在、必须终身治疗、费用必然持续发生，无需等待逐笔实际发生，可依法一并判决支持长期后续治疗费。同时明确：不能仅凭患者短期票据、少量消费记录，否定终身治疗的客观必要性。# 三、本案暴露的3个医疗案高阶痛点

1、基层法院普遍存在法律定性错误只要是伤残后长期使用的耗材、器具，一律粗暴认定为「残疾辅助器具费」，压低赔偿标准、缩短赔偿周期，这是医疗后续费用案件的高频错判点，也是律师核心质证突破口。2、诊断证明与实际消费票据冲突的质证难题本案中，医院诊断证明写明每日4根、终身使用，但患者多年实际消费票据极少，原审据此全盘驳回。最高法纠正核心逻辑：票据是实际支出佐证，不能否定终身治疗的医学必要性，患者自行简化护理、减少耗材使用，不能免除侵权人的后续赔偿责任。3、超长期后续赔偿，并非只能等期满再诉很多新手律师不知道：人身损害赔偿，确定必然发生的后续治疗费可预判赔付，无需逐年起诉、无需等原赔偿周期届满，只要有明确医疗证明即可主张。# 四、结语

看完本案可以发现：本案没有新的医疗过错事实、没有程序违规、没有颠覆性鉴定结论。再审改判的核心，完全是律师抓准法律定性、突破法院惯性裁判思维、活用司法解释。这也印证了我们前两篇的核心观点：医疗纠纷不靠等鉴定、不靠碰运气，靠的是律师主动拆解、精准定性、规则适用。对于所有终身伤残、持续换药、持续耗材、长期护理的医疗纠纷案件，本案就是最高法权威判例，可直接援引对抗基层法院的保守裁判观点，大幅提升案件赔付金额与胜诉概率。
