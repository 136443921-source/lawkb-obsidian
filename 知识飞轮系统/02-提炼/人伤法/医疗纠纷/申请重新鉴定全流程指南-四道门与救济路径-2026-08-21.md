# 申请重新鉴定：不是"再来一次"，而是"纠正错误"——全流程指南

> 来源：医疗大健康法律圈·贾有芬律师（2026-08-20）｜IMA 人伤法律实务助手（鉴定实务系列五篇终章）

## 核心命题

重新鉴定是救济链条**分量最重、门槛最高**的一环。"鉴定不公平"不是法定事由；证明案件落入《证据规定》第40条**四道门中的某一扇**，法院"应当准许"。门只对有准备的人打开。

## 一、法定四道门（《证据规定》第40条）

1. **鉴定人不具备相应资格**（最硬最好论证）：不在司法行政登记名册/执业范围不含医疗损害/无有效执业证/专业方向不对口 → 资质审查留证据（官网名册查询结果、执业证打印存档随申请书提交）
2. **鉴定程序严重违法**：应回避未回避、材料未经质证即作依据、剥夺陈述意见权利、私自接收一方材料、超范围鉴定
3. **鉴定意见明显依据不足**（最常用最难论证）：关键认定与病历直接矛盾、引用规范已废止或不适用、对重要事实只字未提、原因力评定缺乏说理、依据材料不完整不真实 → 逐段比对"结论—依据"断点
4. **其他不能作为证据使用的情形**（兜底）：与在案其他证据根本性矛盾、违反法律禁止性规定

## 二、两个案例对照

- **案例一**（驳回）：仅以"鉴定结论太低不公平"为由申请 → 无具体法定瑕疵依据 → 驳回
- **案例二**（准许）：逐页比对发现三问题（引用的术后监护记录与封存病历不一致/认定"死亡主要系基础疾病"缺病理学依据且未调取尸检材料/陈述环节未通知患方到场程序瑕疵）+每项附证据 → 重新鉴定后认定医院主要责任

## 三、程序与时机（四点）

1. **期限内提出**：举证期限届满前或法院指定期限内
2. **书面申请逐项列明**：法定事由/具体事实/对应证据/法律依据，每项独立成段
3. **主动回应"能否修复"**：法院先看"能不能修"，须证明是触及根基的实质缺陷而非瑕疵
4. **部分异议部分申请**（八民会纪要第35条）：仅对异议部分重新鉴定或补充鉴定，缩减范围和次数

## 四、申请被驳回后的四手段

① 坚持质证（质疑证明力，法院可能调整责任比例）；② 申请鉴定人出庭（当庭暴露薄弱环节）；③ 二审继续主张；④ 申请专家辅助人出庭（专业对专业）。

## 五、获准后的三件事

1. **选好新机构**：资质/专业对口/中立性/既往采信率；异地机构或换体系（医学会↔司法鉴定）
2. **材料无可挑剔**：第一次未交的补充材料（新检查报告/外院会诊）、被忽略的证据（尸检材料/影像原始数据）全部补上
3. **陈述全力投入**：针对原鉴定缺陷有的放矢，明确"哪里误、为何误、正确判断应是什么"
