# 医疗纠纷再审翻盘五大错误 — 要点提炼

> 来源：微信公众号「医事法学团队」（山东），IMA 人伤法律实务助手库收录 2026-07-27。面向[[医疗损害责任|医疗损害责任]]纠纷再审代理。

## 一、一审二审最致命的 5 大错误（再审突破口排名）

1. **盲从司法鉴定结论，放弃病历质证与鉴定合法性审查**：原审惯性将鉴定作为定案唯一依据，不审程序合法性。再审价值：鉴定程序违法或依据虚假 → 《民事诉讼法》第 207 条"认定基本事实缺乏证据证明"，翻案率高。
2. **忽视病历真实性/完整性，放过过错推定抓手**：最高法口径——病历真实性优先于鉴定结论；伪造/篡改/隐匿可**直接推定医疗机构过错**，无需依赖鉴定。属"主要证据伪造"法定事由。
3. **举证责任分配错误，照搬普通侵权规则**：医疗损害责任中医疗机构负病历保管、诊疗合规举证义务；病历遗失/隐匿/拒供时转由医方举证无过错。错误分配属"适用法律确有错误"。
4. **因果关系与责任比例认定混乱**：将"损伤参与度"直接等同"赔偿责任比例"、以"自身疾病为基础"减轻医院责任，混淆事实因果与法律因果。属基本事实认定错误。
5. **核心诉讼权利被剥夺，程序违法未被二审纠正**：鉴定机构选择未通知当事人、听证剥夺患方陈述权、关键病历未经质证送鉴、应回避未回避、应开庭迳判等。程序严重违法是最"硬"的再审事由。

## 二、再审破局方法论（5 条实操）

1. **全卷宗逆向复盘**：调取一审至二审全部卷宗（庭审/质证/鉴定听证笔录），抛弃原审思路，倒推漏洞；庭审原话（鉴定人自认依据不全、医院自认补记）是再审新证据。
2. **只抓法定再审事由，拒绝情绪化**：一页一证据、一条一法条，对应判决书页码/卷宗位置 + 援引《民事诉讼法》第 207 条款项。
3. **医学+法律双线论证**：以国家级诊疗指南、统编教材、卫健委规范逐条比对，形成《诊疗行为合规性审查报告》，效力高于单方专家意见，免高额鉴定费。
4. **区分"根本性错误"与"轻微瑕疵"**：只聚焦四类——鉴定程序严重违法/依据虚假、病历真实性存疑影响结论、举证/因果法律适用错误、剥夺核心诉讼权利程序违法。
5. **标准化证据包**：前置《原审核心错误对照表》（≤5 项+法条）、配套《病历矛盾点对比表》、附同类再审改判判例摘要。

## 三、给小强律师实务的启示

- 医疗案件二审败诉≠死案；鉴定、病历、举证、因果、程序五环节任一可逆转错误即可能启动再审。
- 接再审案件首步：调全卷 → 审鉴定合法性 + 病历真实性 → 固化程序违法点，而非重复原审实体争辩。
