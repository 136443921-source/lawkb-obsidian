# 新生儿缺血缺氧性脑病医疗损害鉴定案（司法部入库案例）— 蒸馏笔记

> 来源：医学与法学（山东），2026-08-08 10:00。司法部司法行政（法律服务）案例库入库案例：某妇幼保健所分娩致新生儿缺血缺氧性脑病之医疗损害法医临床鉴定。
> 本案是「产程监护过失 → 新生儿损害」类医疗纠纷的**过错认定范本**，直接服务于人伤法·医疗纠纷方向的办案与鉴定审查。

## 一、案情骨架

| 项 | 内容 |
|----|------|
| 分娩 | 2018-07-05 陈某于某妇幼保健所自然分娩，娩出女婴安某 |
| 娩出异常 | 1 分钟 Apgar 5 分、5 分钟 8 分；羊水 400ml Ⅲ度；出生后无自主呼吸 |
| 转院诊断 | 新生儿窒息、缺血缺氧性脑病、胎粪吸入性肺炎、Ⅰ型呼衰、蛛网膜下腔出血、硬膜外血肿、气胸 |
| 后续诊断 | 新生儿脑病、颞骨骨折（右）、硬膜外血肿、蛛网膜下腔出血、特大婴儿（4200g）等 |
| 鉴定 | 2020-10-14 听证会；某司法鉴定中心出具医疗损害鉴定 |

## 二、过错分析核心逻辑（鉴定说理拆解）

1. **宫内乏氧的影像学/临床证据链**：娩出后无自主呼吸、发绀、Apgar 低分 → 肺部 CT「双肺吸入性改变」→ 上级医院「胎粪吸入综合征」→ 反向印证**娩出前已存在宫内乏氧**。胎粪吸入机制：宫内缺氧→迷走兴奋→肛门括约肌松弛排胎粪→呼吸运动将胎粪吸入。
2. **胎心监测断裂 = 注意义务违反的关键事实**：该院仅在 7-05 11:00 静滴缩宫素后做过一次胎心监测（11:33–11:52 正常），**第一产程后期、第二产程再无胎心监测记录**。规范要求每次宫缩后或每 5 分钟监测一次、间歇期听诊 ≥30–60 秒，异常即阴道检查。
3. **第二产程时限过长 + 巨大儿管理缺位**：第二产程 1h50m；预估体重 4050g、实际 4200g（巨大儿）。体重 >4000g 无糖尿病者应阴道试产，但须**放宽剖宫产指征、充分评估、必要时产钳、准备处理肩难产**。除会阴侧切外无其他处置记载。
4. **因果与参与度**：未尽监护致未发现宫内乏氧、未及时结束分娩 → 新生儿窒息 → 缺血缺氧性脑病。参照《医疗事故技术鉴定暂行办法》第 36 条（二）款，认定**医疗过失与损害后果有因果关系，参与度为主要原因力**。

## 三、蓝队视角（患方/代理律师）办案抓手

- [ ] 调取并逐页审阅**产程图、胎心监护图、分娩记录、首次病程记录**——寻找「监测空白期」即过错突破口。
- [ ] 锁定「预估体重 vs 实际体重」「巨大儿处置规范」落差，论证未充分评估。
- [ ] 鉴定意见「主要原因力」是赔偿比例谈判与诉讼的核心依据（一般对应主要责任的较高赔偿比例区间）。
- [ ] 注意鉴定时机：本案出生后 2 年余才鉴定，损害已稳定，时点选择利于客观评定。

## 四、红队视角（医方/代理律师）抗辩要点

- [ ]   抗辩「主要原因力」过高：可否主张自身为「同等原因」或「次要」，举出产妇自身因素（如宫内窘迫始发原因、巨大儿不可完全预见）。
- [ ] 起搏点：胎心监护单次正常记录可主张已尽基础注意；产程处理符合当时基层机构常规。
- [ ] 程序：听证会双方意见记录，确保医方陈述入卷。

## 五、执业动作清单（医疗纠纷办案可直接套用）

- [ ] 接案即封存、复印全部病历（产程图/监护图是重中之重）。
- [ ] 委托医疗损害鉴定前，先用「监测连续性 + 巨大儿管理 + 及时终止分娩」三把尺子做初步过错判断。
- [ ] 鉴定书重点审查：因果关系表述、参与度等级（主要/同等/次要）、依据条款。
- [ ] 赔偿计算以「主要原因力」对应责任比例为基数，叠加伤残（如构成）相关项目。

## 六、法条/规范锚点

- 《医疗事故技术鉴定暂行办法》第 36 条（医疗事故中医疗过失行为责任程度：完全/主要/次要/轻微）。
- 《民法典》第 1218 条（[[医疗损害责任|医疗损害责任]]归责）、第 1221 条（诊疗过错认定：未尽与当时医疗水平相应的诊疗义务）。
- 产科规范：胎心监护频次、巨大儿阴道试产处理共识（实务引用）。
