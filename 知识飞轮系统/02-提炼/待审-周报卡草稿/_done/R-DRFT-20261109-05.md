# 【裁判规则】离职高管"口述披露"技术配方亦构成侵犯商业秘密罪

## 规则要点

- 深圳坪山区法院（2026-11-05/06 一审）：新宙邦前半导体事业部总经理康威，违反保密义务，通过**口述方式**向他人披露钼蚀刻液、水性剥离液技术配方并指导生产，构成**侵犯商业秘密罪**，**判处有期徒刑一年二个月、缓刑二年，罚金16万元**；判决前已支付公司**赔偿款2000万元**（记入营业外收入）。
- 明确边界：**口述披露技术配方亦可构罪**；民事赔偿与刑事责任可并行，且民事赔偿先于刑事判决达成可作量刑情节。

## 律师实务提示

- 企业侧"离职即设防"三道闸：签署保密协议 + 代码/文件分级管理 + 离职审计；侵权方应把握"先民事和解赔偿、再争取量刑从宽"的减损顺序。
- 代理侵权方时，可据已全额赔偿、认罪认罚争取缓刑。
