# 职务犯罪量刑梯度：自首+退赃认罪认罚实质下压刑期下限（2026年9月宣判集群观察）

## 一句话经验要点
2026年9月密集宣判的职务犯罪案件呈现清晰"金额—刑期梯度"，且**自首（益西达瓦1706万→八年六个月）+认罪认罚+积极退赃可突破"数额特别巨大→十年以上"下限**；无自首但如实供述+退赃的（冯志斌6071万→十四年、王达利2192万→十一年三个月）在对应幅度内从轻——辩护空间在从宽情节的实质化组织，而非数额之争。

## 法律依据
- 《中华人民共和国刑法》第三百八十五条、第三百八十六条（受贿罪）——本地源待核。
- 《中华人民共和国刑法》第三百八十八条之一（利用影响力受贿罪）——本地源待核。
- 《中华人民共和国刑事诉讼法》第十五条（认罪认罚从宽）——**statute_text_pending**（刑诉法全文未入库）。
- 《中华人民共和国监察法》第三十一条、第三十二条（从宽处罚建议）——**statute_text_pending**（未入库）。
- "两高"《关于办理贪污贿赂刑事案件适用法律若干问题的解释》——**statute_text_pending**（未入库）。

## 案例锚点
- 益西达瓦（四川省民政厅原厅长，1706万·自首→八年六个月）：2025-03-31主动投案如实供述系自首，受贿未遂，认罪认罚+积极退赃→减轻处罚突破十年下限。
- 冯志斌（6071万·十四年）、王达利（贵州本地·2192万·十一年三个月）：无自首但如实供述+退赃→幅度内从轻。

## 实务指导意义
1. 量刑预判模型：接案按金额区间+从宽情节组合快速预判刑期，管理当事人预期；
2. **主动投案/交代"尚未掌握"事实是刑期下限级情节**——监察阶段自书材料、谈话策略须在辩护人介入时点重点规划；
3. 退赃责任的数额分担直接影响各共犯量刑，辩护方案须含退赃分担谈判；
4. ⚠️ 表述红线：本卡为量刑规律经验观察，非规范性量刑标准；个案受数额、情节、地区平衡等多因素影响，不得机械套用。
