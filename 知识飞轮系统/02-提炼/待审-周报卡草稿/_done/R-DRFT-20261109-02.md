# 【裁判规则】两高"新型、隐性"职务犯罪6件典型案例——商业机会型受贿识别

## 规则要点

- "两高"2026-11-02 发布依法惩治新型、隐性职务犯罪典型案例 **6 件**，落实二十届五中全会"丰富防治新型腐败和隐性腐败的有效办法"部署。
- **案例一 王某某受贿、利用影响力受贿案**（关键词：商业机会 / 无实质经营 / 不承担风险 / 实际获利）：王某某（某贸易中心原党委书记、主任，2010—2022）为他人在工程承揽中提供帮助，非法收受 **1931 万元**；其中安排行贿人为其女儿成立"影子公司"（中某商贸），由行贿人提供注册场所、资本金、启动费、财务人员并介绍生产商，该公司**未实质经营、不承担风险**，借供应钢材获取交易差价 **1155 万元**，法院认定实质为权钱交易，构成受贿罪。
- **识别标准**：判断权钱交易核心在于"是否真实经营、是否承担市场风险、获利是否源于职务便利"；代持/影子公司/虚假交易/商业机会输送/期权变现为典型隐性手法。

## 律师实务提示

- 辩护切入点：围绕"影子公司是否实际开展经营、利润是否来自市场而非职务便利、获利与职务行为因果关系"展开，区分真实商业合作与变相受贿。
- 合规侧：国企/事业单位须将"配偶子女经商""供应商准入白名单"纳入廉洁风险核查，前置阻断隐性输送。
