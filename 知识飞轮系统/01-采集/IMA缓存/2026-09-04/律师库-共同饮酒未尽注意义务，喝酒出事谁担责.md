# 共同饮酒未尽注意义务，喝酒出事谁担责？

> 来源：公众号「判例研究」（中国司法案例研究中心）｜发布：2026-03-03 08:32｜发布地：河南｜正文 2484 字

## 一、案情

- 2024-07-06 19:39，覃某电话邀受害人莫某寒到其经营的水泥砖厂食堂吃饭饮酒。
- 覃某自述 22 时许自行洗澡后到隔壁休息室休息；莫某寒继续自酌自饮。
- 次日 6 时许覃某未到食堂查看即进山做工。
- 7 日 6:03、6:04，莫某寒妻子胡某两次拨打其电话未接通；8:30 案外人谭某发现莫某寒低头弯腰坐沙发上无反应，拨打 120。
- 医生到场认为已死亡多时，未抢救。
- 公安到场提取血液：**乙醇含量 412.37mg/100ml**（80mg/100ml 即为醉酒状态）。
- 未尸检（家属同意），排除刑事案件。
- 卫生院《居民死亡医学证明（推断）书》：呼吸心跳骤停；派出所《死亡证明》：**窒息死亡（吸入性窒息）**。
- 覃某事发当日下午垫付 30000 元处理后事。
- **案例来源：广西壮族自治区柳州市柳江区人民法院**

## 二、裁判要旨（可直接引述）

> 共同饮酒行为是一种共饮者之间自主、自发的行为，对于共同饮酒人的人身安全是以**自我保护为主**，以其他人的安全保障义务为**补充**。基于共同饮酒的**先行行为**，同饮人相互之间产生一种**特殊的照顾义务**，即饮酒中**提醒、劝阻**，饮酒后**妥善照顾**，处于醉酒状态时**及时通知家属、及时提供救助、及时送医**等义务。

- 受害人系完全民事行为能力人，应认识并预见过量饮酒的潜在危险，其放纵自己大量饮酒致认知控制能力下降，与死亡后果存在**最直接、最主要**的因果关系；
- 无证据证实共饮者存在**劝酒、斗酒、强迫喝酒**行为 → 受害人承担**主要责任**。
- 覃某作为**同桌饮酒人及主人**（邀约方 + 场地提供者），应尽扶助、注意、提醒、护送等基本安全保障义务，但其**径直自行休息**，未尽全面安全保障义务，存在一定过错。
- **判赔比例：被告承担 8%，其余 92% 由受害人本人自行承担。**

## 三、注意义务的边界（三段论）

1. **义务来源**：先行行为引发的风险防控责任。主动邀约、参与饮酒 → 使他人陷入饮酒过量、意识减弱的潜在危险 → 依法产生**附随义务**。
2. **边界核心 = 补充性**：受害人对自身安全负**首要责任**，同饮者仅承担**辅助性**保障义务。
3. **内容清单（五项必要行为）**：提醒、劝阻、照顾、救助、通知家属。
   - 不是"全程贴身监管"；
   - 以**普通人可预见、可实施**为限，**不要求专业救助能力**；
   - 但**拒绝履行基本照料即构成过错**。
4. **本案突破点**：覃某在莫某寒独自继续饮酒时未提醒劝阻 → 自行休息 → 次日径直离岗未查看 → **消极不作为**突破注意义务合理边界。

## 四、责任分担与比例认定

- 归责：**过错责任原则 + 过失相抵规则**。
- 受害人侧：自主大量饮酒至 412.37mg/100ml（远超醉酒标准），主动将自身置于高度危险状态 → 损害发生的**主要原因** → 依《民法典》第 1173 条减轻侵权人责任 → **自我责任优先**。
- 同饮者侧：无**积极加害行为**，过错仅为"未履行补充性保障义务"，**过错程度显著轻微** → 仅负**次要补充责任**；其消极不作为与损害后果为**间接因果关系**。
- **8% 的裁量逻辑**：既明确同饮者未尽法定义务的后果、守住生命权保护底线，又**避免责任泛化**，不过度加重普通社交行为的法律负担。

## 五、可直接复用的代理要点

**原告（受害方）举证清单**
1. 共同饮酒的事实（邀约记录、同桌证据、消费记录、监控）；
2. 饮酒量/醉酒程度（**血液乙醇鉴定**、送医记录、呕吐物/现场照片）；
3. 死亡/损害原因（**死亡医学证明、死亡证明**、急救记录）；
4. 同饮者未履行义务的证据（未劝阻、未安置、未送医、未通知家属、径行离开）；
5. 存在**劝酒、斗酒、强迫喝酒、灌酒**的证据（有则责任比例显著上升）。

**被告（同饮者）抗辩清单**
1. 无劝酒、斗酒、强迫喝酒行为；
2. 已尽提醒劝阻、安置、护送、通知家属义务（通话记录、送回家视频、证人）；
3. 受害人系完全民事行为能力人，自我责任优先（第 1173 条过失相抵）；
4. 中途离席且离席时受害人状态正常（→ 义务已尽）；
5. 因果关系的介入因素/无死因鉴定 → 死因不明时削弱因果链。

**贵州本地互链**：贵州高院《共同饮酒者侵权责任纠纷案件审判要件指南》（黔高法〔2025〕189 号）——本批入库前未在 vault 内检索到已拆卡片，本卡按**外省（广西柳江）裁判**建卡，援引贵州口径须以 189 号指南为准。
