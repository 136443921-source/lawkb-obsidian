# 一次性伤残就业补助金的仲裁时效，从哪天起算？

## 一、知识要点（原文两条，本卡核心）

> **1、申请一次性伤残就业补助金的仲裁时效，应以认定劳动能力伤残等级日期为准，自劳动能力伤残等级做出之日起 1 年，而不是以受伤者与所在单位解除劳动合同日期为准。**
>
> **2、申请劳动能力伤残等级鉴定的时效，应在治疗伤情相对稳定后，一般以最后一次治疗结束（最后一次出院）之日起算，1 年内申请劳动能力伤残鉴定。**

## 二、时间轴（本案事实）

| 时间 | 事件 |
|---|---|
| 2021.08.01 | 原告 X 某与某甲公司签订固定期限劳动合同 |
| 2023.11.05 | 原告在派遣从事投递工作过程中**滑倒受伤** |
| 2023.11.29 | 淄博市人社局作出**工伤认定决定书**（依《工伤保险条例》第十四条认定为工伤） |
| 2024.01.31 | 原告**因个人原因**与甲公司**解除劳动合同** |
| 2023.11.05–11.19 | 第一次住院（左侧胫骨开放性粉碎性骨折、左侧小腿皮肤及软组织挫裂伤） |
| 2024.11.27–12.02 | 第二次住院（左侧胫骨骨折术后，内固定物留存） |
| **2025.03.11** | 原告**申请劳动能力鉴定**（距第二次出院 2024.12.02 未超过一年） |
| **2025.05.22** | 淄博市劳动能力鉴定委员会作出初次鉴定结论：**劳动功能障碍程度玖级，无生活自理障碍** |
| 2025.05.06 / 05.27 | 甲公司申请**简易注销**（承诺债权债务已清算完结）／ **05.27 注销** |
| **2025.06.13** | 原告申请劳动仲裁（仲裁委以**被申请人主体不适格**不予受理）→ 起诉唯一股东王某 |
| 2025.07.04 | 淄博市张店区人民法院立案 |

## 三、双方时效之争（裁判理由原文要点）

**被告（用人单位方）主张**：
- 原告与甲公司劳动合同已于 **2024.01.31** 解除 → 一次性伤残就业补助金的仲裁时效应**从 2024.01.31 起算**，至 **2025.01.31 届满**；
- 退一步，自离职日 2024.01.31 至被鉴定为九级伤残的 2025.05.22，**也超过了一年**。

**法院认定（予以驳回）**：
1. 依《工伤保险条例》**第二十一条**：职工发生工伤，经治疗**伤情相对稳定后**存在残疾、影响劳动能力的，**应当进行劳动能力鉴定**；
2. 原告两次住院**均系治疗案涉伤情**；第二次治疗 **2024.12.02 出院**，至**申请劳动能力鉴定之日 2025.03.11 并未超过一年**，**并非怠于行使权利**；
3. 且淄博市工伤职工劳动能力鉴定网络终端申请表上**某甲公司加盖公章**，可见**甲公司认可对原告进行劳动能力鉴定**；
4. 结论：原告主张一次性伤残就业补助金**须以认定劳动能力伤残等级为前提**，故应当自原告被认定为九级伤残 **2025.05.22 的次日**起算仲裁时效，至申请劳动仲裁的 **2025.06.13**，**不超一年**。

## 四、金额计算（山东口径示例）

- 依《工伤保险条例》**第三十七条**：职工因工致残被鉴定为**七级至十级**伤残的，劳动、聘用合同期满终止，或者**职工本人提出解除**劳动、聘用合同的，由**工伤保险基金**支付一次性工伤医疗补助金，由**用人单位**支付**一次性伤残就业补助金**；具体标准由**省、自治区、直辖市人民政府规定**。
- 依《**山东省**贯彻〈工伤保险条例〉实施办法》第二十五条：以**解除劳动合同时**统筹地区**上年度职工平均工资**为基数（本案为 2023 年度山东省全口径城镇单位就业人员平均工资 **88,313.00 元**），计算原告 **12 个月**的一次性伤残就业补助金 = **88,313.00 元**。
- 原告自愿要求支付 **88,308.00 元**，系对自己权利的处分，法院予以支持。

## 五、⚠️ 附带要点：公司简易注销后股东连带责任

- 某甲公司为**一人有限责任公司**，股东为王某；
- 简易注销时**全体投资人承诺书**载明"已将债权债务清算完结……如果违法失信，则由全体投资人承担相应的法律后果和责任"，公司盖章、王某签名；
- 法院据此判令**唯一股东王某对该债务承担连带责任**（另引《公司法》第二百四十条、《社会保险法》第三十九条）。

## 六、裁判观点的分歧面（本卡须提示的"不同裁判观点"）

| 起算点 | 主张理由 | 本案态度 |
|---|---|---|
| **A. 劳动合同解除/终止之日** | 一次性伤残就业补助金的支付条件是"合同终止或职工本人提出解除"，条件成就时即可主张 | **本案未采纳**（被告主张被驳回） |
| **B. 劳动能力鉴定结论作出之日** | 补助金数额与伤残等级绑定，**未定残则请求权范围不确定，无从主张** | **本案采纳** |
| **C. 治疗终结/最后一次出院之日**（针对**申请劳动能力鉴定的及时性**，非仲裁时效本身） | 《工伤保险条例》第21条"伤情相对稳定后" | **本案作为"是否怠于行使权利"的审查标准** |

> 提示：本案系**山东淄博张店区法院**个案，**贵州省口径须另行核验**（见待回源）。
