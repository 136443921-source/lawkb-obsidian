# 李振斌｜交通肇事罪的有效辩护

> 来源：公众号「刑辩福塔」（李振斌律师，郑州）｜发布：2026-02-09 12:05｜发布地：河南
> 核心命题：**公安机关的责任认定，是行政视角的责任划分，而刑事定罪的责任认定，必须坚持实质审查。**

## 〇、总纲

> 交通肇事罪，从不是"出了事、有伤亡"就必然定罪。**交警的责任认定书不是铁证，逃逸的认定不靠形式，酒驾毒驾也未必一概定重罪。**

辩护从来不是**否定事故本身**，而是回到**事实与证据**，拆解**责任、主观过错与因果关系**。交通肇事罪是**过失犯罪**，刑事审判的重点是**实质合理性，而非机械套用规则**。

## 一、突破口一：交警定的"全责"，刑事审判中未必作数 ⭐

- 行政责任 vs 刑事责任：**行政责任侧重道路交通安全管理，讲究秩序导向；刑事责任侧重行为人的实质过错，讲究罪责自负**。认定原则本就不同。
- 刑事审判应结合**事故的因果关系、各方过错的原因力大小重新判断**，**而非直接采信交警的认定书**（《关于审理交通肇事刑事案件具体应用法律若干问题的解释》，*条号待回源*）。

**案例 1｜张某案（一人重伤 + 无证驾驶 + 交警全责 → 无罪）**
- 交警认定：无证驾驶 + 未注意观察路况 → **全责**，公安以交通肇事罪立案。
- 辩护动作：**调看现场监控** → 发现电动车驾驶人**逆行且突然闯入机动车道**，才是事故**主要原因**；认定书**完全忽略这一关键事实**。
- 结果：法院采纳 → **不构成犯罪**，被扣押车辆顺利取回。

**案例 2｜江苏苏州李某案（超速 + 一行人死亡 → 不构成犯罪）**
- 交警以**超速**定全责，致一行人死亡，立案。
- 辩护动作：**调取测速记录** → 所谓"超速"系交警**误算**；且**行人翻越护栏横穿高速**才是事故主因。
- 结果：法院**推翻认定书**，认定李某**仅负次要责任，不构成交通肇事罪**。

> **律师动作清单**：第一时间调取**现场监控、测速记录、行车记录仪、EDR 数据、痕迹鉴定、道路环境证据**，重建原因力。

## 二、突破口二："离开现场"≠逃逸，主观目的才是核心 ⭐

- **逃逸的核心不是"离开现场"，而是"为逃避法律追究而逃跑"**（《关于审理交通肇事刑事案件具体应用法律若干问题的解释》，*条号待回源*）。
- 刑期影响：**三年以下 → 三年以上**。
- **认定逃逸要坚持主客观相一致**：
  - 主观：行为人**明知发生了交通事故**；
  - 客观：行为目的**必须是逃避法律追究**。

**案例 3｜浙江宁波王某案（送医后离开 → 不认定逃逸，判缓刑）**
- 王某撞伤行人后**第一时间送伤者去医院**；见家属情绪激动扬言动手，**暂时离开医院去附近派出所报警说明情况** → 被以逃逸立案。
- 辩护：离开是为**躲避人身伤害**，而非逃避法律追究；且**主动报警、接受调查** → 不符合逃逸的**主观要件**。
- 结果：法院采纳 → **未认定逃逸情节**，仅判**缓刑**。

**两种易混淆的极端**：
| 情形 | 是否逃逸 | 理由 |
|---|---|---|
| 留在现场，却**藏匿在人群中不配合调查** | **是** | 看似没离开，实为逃避追究 |
| 送伤者就医后，为**筹钱暂时离开**，事后**主动归案** | **否** | 看似离开，但无逃避追究目的 |

> **律师证据清单**：**报警记录、通话记录、证人证言**、就医缴费凭证、返回现场/投案的到案经过。

## 三、突破口三：酒驾、毒驾肇事，未必一概定以危险方法危害公共安全罪 ⭐

- **两罪核心区别 = 行为人对危害后果的主观心态**：**过失 → 交通肇事罪；故意 → 以危险方法危害公共安全罪**。
- 《关于办理醉酒危险驾驶刑事案件的意见》（*条号待回源*）给出的参考标准：
  - **一次冲撞** → 原则上认定**过失** → **交通肇事罪**；
  - **肇事后继续驾车冲撞**，造成重大伤亡 → 认定**故意** → **以危险方法危害公共安全罪**。

**关键辨析（易错点）**：
> 酒驾本身是故意行为，**不能直接推定行为人对肇事后果具有故意**。
> 行为人明知酒驾违法 → 这是对**行政法义务**的故意违反；
> 但对**肇事的伤亡后果**，绝大多数是**过于自信的过失**或**疏忽大意的过失**。
> **只有肇事后继续驾车冲撞、无视公共安全的，才能认定为对危害结果的故意。**

**案例 4｜广东深圳赵某案（以危险方法危害公共安全罪 → 交通肇事罪，判 2 年）**
- 赵某醉酒驾车，与非机动车发生**一次冲撞**致人死亡，公安以**以危险方法危害公共安全罪**立案。
- 辩护点：案发时**行驶速度较慢**，且**采取了避让措施** → 主观系**过于自信的过失**，而非放任的故意 → 属典型**一次冲撞**。
- 结果：法院采纳 → 改定**交通肇事罪**，判处**有期徒刑二年**（远低于以危险方法危害公共安全罪量刑档）。

**毒驾更复杂，不能套用"二次冲撞"标准**，须回到**行为人对危害结果的认知程度**：其是否**明知**自己吸毒后驾车会引发事故，是否对危险持**放任**态度；结合**吸毒经历、毒驾经历、肇事时状态**综合判断：
- **长期吸毒者**，明知吸毒后驾车极易失控仍执意开车 → 即便**一次冲撞**，**也可能**认定故意；
- **初次吸毒者**，误判毒品对驾驶的影响，驾车时出现幻觉连续冲撞 → **未必**认定故意。

## 四、突破口四："因逃逸致人死亡"，关键在审查刑法上的因果关系 ⭐

- 《刑法》第 133 条：**因逃逸致人死亡的，处七年以上有期徒刑**（交通肇事罪最高量刑档），*条号待回源*。
- **核心要件**：被害人的死亡**必须是因肇事者逃逸导致得不到及时救治造成的**——这是**刑法意义上的因果关系，缺一不可**。
- ⚠️ 实务误区：简单将"**逃逸 + 死亡**"等同于"**因逃逸致人死亡**"。

**案例 5｜山东济南陈某案（"因逃逸致人死亡" → 降档为"交通运输肇事后逃逸"，判 3 年）**
- 陈某肇事致行人李某重伤后逃逸，李某被**路人送医**后抢救无效死亡，公安以"因逃逸致人死亡"立案。
- 辩护动作：**申请法医鉴定** → 死因为**重型颅脑损伤**，**即便当场送医也无救治可能**。
- 结果：法院认定**死亡与逃逸无刑法上的因果关系**，仅认定**交通运输肇事后逃逸**，判处**有期徒刑三年**。

**二次碾轧情形**：肇事者逃逸后，被害人被其他车辆碾轧致死——**通常仍需承担责任**，因为应当预见被害人受伤后处于通行道路中**可能发生二次伤害**；但**不是绝对的**，须结合**第一次撞击的伤情、最终死亡原因、后车驾驶人责任**综合判断，**不能直接定"因逃逸致人死亡"**。

> **结论口径**：认定"因逃逸致人死亡"须回到因果关系本质——**逃逸行为是死亡结果发生的直接原因**。若被害人**当场死亡**，或**即便及时救治也无法挽回生命**，即便肇事者逃逸，也**不能适用该量刑档**。

## 五、当事人第一时间的动作清单（可直接转述给当事人）

1. **救人、报警、保护现场**（前提）；
2. **不要轻易认责**，更不要慌不择路逃离；
3. **不要稀里糊涂签责任认定书**（出事后慌不择路签认责是最常见的失误）；
4. 被立案也不要认为"铁板钉钉"——本罪是**过失犯罪**，实质合理性优先。

## 六、四大突破口速查表

| 突破口 | 核心命题 | 关键证据 | 可能结果 |
|---|---|---|---|
| ① 责任认定 | 行政责任 ≠ 刑事责任，刑事须**实质审查** | 现场监控、测速记录、行车记录仪、痕迹鉴定 | 推翻全责 → 仅次要责任 → **无罪** |
| ② 逃逸 | 核心是"**为逃避法律追究而逃跑**"，非"离开现场" | 报警记录、通话记录、证人证言、到案经过 | 打掉逃逸 → 刑期回到**三年以下** |
| ③ 酒驾毒驾定性 | **过失 → 交通肇事罪；故意 → 以危险方法危害公共安全罪**；酒驾故意 ≠ 肇事故意 | 车速、避让措施、冲撞次数、吸毒经历 | 改定交通肇事罪（**2 年** vs 十年以上） |
| ④ 因逃逸致人死亡 | 须有**刑法上的因果关系**：逃逸导致得不到及时救治 | **法医鉴定**（死因、可否救治）、送医时间线 | 降档为交通运输肇事后逃逸（**7 年以上 → 3 年**） |
