## 案例一｜（2025）冀民申7149号 · 买卖合同纠纷（合同槽位）

| 字段 | 内容 |

| 案件名称 | 河北某甲公司 与 河北某乙公司 买卖合同纠纷再审审查 |
| 裁判法院 | 河北省高级人民法院 |
| 审理程序 | 再审审查（民事） |
| 案由 | 买卖合同纠纷 |
| 结案日期 | 2025-11-25 |
| 案例类型 | 精选案例库 |
| 入库标识 | scid: `7722bb1e5604903ebc7dadd3d2f79007` |
| 原文链接 | https://ydzk.chineselaw.com/ydzk/caseDetail/case/7722bb1e5604903ebc7dadd3d2f79007 |

**基本案情**
《购销合同》对检验期限及质量不符的处理方式有明确约定。买受人某甲公司未在约定的检验期限内提出质量异议，再审阶段主张标的物质量不符合约定、要求出卖人担责。

**裁判理由**
依《民法典》第621条，当事人约定检验期限的，买受人应在该期限内将标的物质量不符合约定的情形通知出卖人，怠于通知的视为质量符合约定。某甲公司作为理性商事主体理应知悉并遵守检验条款；其未能举证证明检验期限内存在客观障碍导致无法完成全面检验，检验期限应依合同约定执行。原审综合考虑玻璃已实际投入使用、双方对鉴定标准未达成一致等事实，认定其未在检验期内提出异议，依法视为质量符合约定，驳回其请求正确。

**裁判要旨**
约定检验期限的，买受人未在期限内就质量不符合约定情形通知出卖人，且无证据证明存在客观障碍的，视为标的物质量符合约定，其后不得再以质量瑕疵主张拒付/减价。**质量异议期间制度对买受人具有严格约束力。**

**关联法条**：《民法典》第621条 —— 未登记，引用前建议核验现行有效性

**产出规则卡**：[[R-HT-115-约定检验期限怠于通知视为质量符合约定]]

## 案例二｜（2026）冀05民终706号 · 医疗损害责任纠纷（人伤槽位·医疗优先）

| 字段 | 内容 |

| 案号 | （2026）冀05民终706号 |
| 案件名称 | 张某乙等 与 某甲医院 医疗损害责任纠纷二审 |
| 裁判法院 | 河北省邢台市中级人民法院 |
| 审理程序 | 二审（民事） |
| 案由 | 医疗损害责任纠纷 |

| 案例类型 | 精选案例库 |
| 入库标识 | scid: `a0224530f13a6925bc74381b9367fba5` |
| 原文链接 | https://ydzk.chineselaw.com/ydzk/caseDetail/case/a0224530f13a6925bc74381b9367fba5 |

**基本案情**
患者因胸痛、心跳呼吸停止 5 分钟急诊就诊，诊断为急性前壁心肌梗死。诉前经法院委托北京中衡司法鉴定所鉴定：医方未及时考虑急诊 PCI（该院具备 PCI 条件却未使用），存在过错，与死亡有因果关系；原因力"如未应用抗栓药物则轻微至次要，如已应用则为轻微"。鉴定人出庭接受质询。一审酌定医方承担 20% 赔偿责任。

**裁判理由**
医疗损害责任以合法鉴定意见为重要依据。本案鉴定程序合法、机构具备资质、鉴定人出庭就关键问题（未及时考虑急诊 PCI、未充分评估溶栓/介入机会）作出专业说明，结论合法有效。医方主张已应用抗栓药物与病历记载（到急诊时已心跳停止 5 分钟）不符，不予采信；心电图时间误差不影响过错认定。一审按鉴定意见原因力酌定 20% 责任，符合过错与原因力相适应原则。

**裁判要旨**
① 法院委托的合法鉴定意见（含原因力"轻微至次要"区间）是责任比例认定的主轴；② 医方抗辩须在鉴定程序中提出并举证，事后仅以时间误差等质疑不足以推翻鉴定意见；③ 具备 PCI 条件的医院未及时实施急诊 PCI 构成医疗过错，按原因力酌定责任比例。

**关联法条**：《民法典》第1218条（未登记，建议核验）；鉴定程序依《民事诉讼法》第79条

**产出规则卡**：[[R-PI-190-具备介入条件的医院未及时行急诊PCI构成过错按原因力担责]]

## 案例三｜（2026）鄂9005民初445号 · 股权转让纠纷（商事槽位）

| 字段 | 内容 |
|---|---|
| 案号 | （2026）鄂9005民初445号 |
| 案件名称 | 李某 与 许某甲、许某乙 股权转让纠纷一审 |
| 裁判法院 | 湖北省潜江市人民法院 |
| 审理程序 | 一审（民事） |
| 案由 | 股权转让纠纷 |
| 结案日期 | 2026-04-07 |
| 案例类型 | 精选案例库 |
| 入库标识 | scid: `8715f1492ec14852081490acc2081a2e` |
| 原文链接 | https://ydzk.chineselaw.com/ydzk/caseDetail/case/8715f1492ec14852081490acc2081a2e |

**基本案情**
李某将 11.2% 股权以 240 万元转让给许某甲，分三期付款（2025/2026/2027 年各 80 万），许某乙提供连带责任保证（保证期间为每期债务履行期届满后 12 个月）。李某完成变更登记后，许某甲未支付首期款项，逾期逾八个月。李某主张未到期两期 160 万加速到期。

**裁判理由**
依《民法典》第578条，一方以行为表明不履行主要债务的，对方可请求其承担违约责任。许某甲逾期付款超过总价 1/5、长期不履行主要债务，构成预期违约，支持未到期款项加速到期。违约金以 80 万为基数按日万分之一（合同约定，未超法定限度）自逾期之日起算；律师费按约定由违约方承担。保证方式：协议约定"不按时、足额履行支付义务时承担保证责任"，依《民法典》第686条第2款、第687条属**约定不明→一般保证**，许某乙仅在强制执行后仍不能清偿部分承担补充责任，不支持连带责任。

**裁判要旨**
① 股权转让款分期付款场景下，受让人逾期不付首期且金额超总价 1/5，可依预期违约（非《民法典》第634条分期买卖）主张未到期款项加速到期；② 保证条款未明确"连带责任"字样的，认定为一般保证，保证人承担补充责任；③ 合同约定违约金+律师费承担条款有效。

**关联法条**：《民法典》第578、686、687条（均未登记，建议核验）；第634条（分期付款买卖规则，股权转让不机械适用）

**产出规则卡**：[[R-SH-036-股权转让款逾期预期违约加速到期与保证方式约定不明推定为一般保证]]
