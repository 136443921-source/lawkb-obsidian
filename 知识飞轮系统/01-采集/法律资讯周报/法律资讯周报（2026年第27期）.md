## 一、政策法规更新摘要

### （一）7月1日新法施行批次——本年度最重要的集中落地窗口

2026年7月1日，一批涵盖社会救助、劳动权益、对外投资、行政复议、民族事务等领域的法律法规同步施行，标志法治建设在系统化、精细化方向迈出坚实步伐。

#### 1.《中华人民共和国社会救助法》——社会救助领域首部专门法律

> **来源：** 十四届全国人大常委会第二十二次会议通过（2026-04-30）；**施行：** [[2026-07-01]]；**结构：** 7章78条

| 核心维度 | 具体内容 |
|---------|---------|
| **救助对象扩容** | 在特困人员、最低生活保障家庭基础上，增加"最低生活保障边缘家庭""刚性支出困难家庭" |
| **分层分类体系** | 国家建立健全分层分类社会救助体系，按困难程度给予基本生活救助、专项社会救助、急难社会救助 |
| **信息化建设** | 第10条明确加强低收入人口动态监测信息平台建设，实现精准识别、常态化帮扶——从"人找政策"转向"政策找人" |
| **配套部署** | 民政部等7部门联合印发学习宣传贯彻通知（2026-07-01） |

**实务意义（慈善领域）：** 社会救助法与慈善事业衔接，慈善组织参与"救急难"项目需注意与社会救助制度衔接，避免重复救助或职能越界；急难社会救助的法定化为慈善应急项目划定了边界。

#### 2.《超龄劳动者基本权益保障暂行规定》——首部超龄劳动者权益专门规章

> **来源：** 人社部、国家卫健委、应急管理部、税务总局、国家医保局令第56号（2026-05-10公布）；**施行：** 2026-07-01

| 保障维度 | 具体规则 |
|---------|---------|
| **劳动报酬** | 及时足额支付，不低于当地最低工资标准 |
| **休息休假** | 一般不安排加班；安排加班的按150%/200%/300%执行 |
| **劳动安全卫生** | 按身体状况确定合适岗位与劳动强度，进行安全与职业卫生教育培训 |
| **工伤保障（核心）** | 用人单位必须参加工伤保险并缴费，个人不缴费；企业不得再以"超龄非劳动关系"拒赔工伤 |

**实务意义（人伤+劳动）：** 超龄用工从"民事关系"正式跨入"劳动保障"时代。代理超龄劳动者工伤案件时，可径行主张工伤保险待遇；为企业提供用工合规建议时，须将返聘人员全部纳入工伤保险。

#### 3.《国务院关于对外投资的规定》——首部对外投资领域行政法规

> **施行：** 2026-07-01

| 核心要点 | 内容 |
|---------|------|
| **适用范围突破** | 首次将**个人投资者**纳入（含红筹结构返程投资及其他以获得股权/控制权为目的的对外直接投资） |
| **投资壁垒调查** | 我国投资者在境外遭遇投资壁垒或其他经营障碍时，主管部门可依法开展调查并采取措施 |
| **立法目的** | 推进高水平对外开放，促进对外投资高质量发展，保护投资者合法权益 |

**实务意义（企业法律顾问）：** 涉外企业及个人境外投资合规框架成型，律师可提供对外投资合规咨询、投资壁垒应对服务。

#### 4. 新修订《中华人民共和国行政复议法实施条例》

> **来源：** 国务院令第836号（2026-04-29公布）；**施行：** 2026-07-01；**结构：** 8章77条

- 补充明确可复议事项：对被行政机关列入失信惩戒"黑名单"不服的，可申请行政复议
- 细化申请规定、完善案件办理制度、加强复议指导监督
- 闯红灯被罚、开店被吊销执照、工伤不认定等行政行为均可通过复议解决争议

**实务意义（民商事诉讼/行政）：** 行政救济渠道拓宽，涉企行政处罚、资格罚可优先在复议阶段化解争议。

#### 5. 新修订《行政法规制定程序条例》

> **来源：** 国务院令第838号（2026-05-15公布）；**施行：** 2026-07-01

- 首次将"两个更加注重"写入行政法规（注重立法与改革发展稳定相协同、注重保障促进社会公平正义）
- 对调整范围单一、无较大争议、急需的行政法规建立快速响应机制

#### 6. 其他7月1日施行新规

| 法规名称 | 要点 |
|---------|------|
| 《中药注册管理专门规定》 | 说明书禁忌/不良反应/注意事项任一仍为"尚不明确"的，不予再注册 |
| 医保目录调整 | 2025年目录未续约的8种谈判药（贝那鲁肽、达诺瑞韦钠、盐酸拉维达韦、阿利西尤单抗、度维利塞、八氟丙烷脂质微球、甘露特钠、林普利塞）不再报销 |
| 《中华人民共和国民族团结进步促进法》 | 序言+7章65条，"各民族一律平等"以法律形式巩固 |

### （二）司法解释

#### 《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）》（法释〔2026〕12号）

> **发布：** 2026-06-29；**施行：** [[2026-06-30]]；**结构：** 共23条（22条实体规则）

**七大核心板块：**

| 板块 | 核心规则 |
|------|---------|
| **资质借用/挂靠（重点）** | 各类资质借用协议一律无效；出借方主张的挂靠费、资质使用费不予支持；建立线索移送行政机关机制 |
| 合同无效折价 | 参照"合同关于工程价款的约定"折价补偿；自行达成的折价补偿协议依意思自治支持 |
| 固定总价合同 | 可按比例核算已完工价款 |
| 无审计报告 | 非承包人原因无审计报告的，可司法鉴定定价款 |
| 质保金 | 合同无效/解除且未完工的，以承包人应得工程价款为基数，返还期自退场/解除日起算 |
| 优先受偿权 | 明确建设工程价款优先受偿权行使规则 |
| 配套案例 | 同步发布6件建工典型案例（见下文判例部分） |

**实务意义（民商事诉讼）：** 建工类案件代理思路需全面更新，挂靠/出借资质方风险显著上升。

## 二、重要判例要点提炼

### （一）最高人民法院发布六个建设工程施工合同纠纷典型案例（2026-06-29）

> 配套建工解释二发布，覆盖资质借用、农民工工资、固定总价核算、无审计定价、质保金起算、僵局合同六大场景。

| 案例 | 裁判规则 |
|------|---------|
| **案例一** 资质借用折价 | 发包人订立合同时知道资质借用情形的，借用资质的人可向发包人请求支付折价补偿款 |
| **案例二** 农民工工资 | 分包单位拖欠农民工工资，农民工请求分包单位和施工总承包单位支付工资的，依法支持 |
| **案例三** 固定总价比例法 | 固定总价合同中已完工部分工程价款可按比例法确定 |
| **案例四** 无审计司法鉴定 | 非因承包人原因审计机关未出具审计报告，可通过司法鉴定方式确定工程价款 |
| **案例五** 质保金起算 | 施工合同解除后承包人退场、已施工部分质量合格的，质量保证金返还期限从退场之日起算 |
| **案例六** 僵局合同先行移交 | 施工合同履行陷入僵局，发包人请求移交施工现场的，可以先行处理 |

### （二）知识产权领域重要判例

#### 1. 米哈游诉拼多多不正当竞争案——最高法驳回再审（2026-07-03）

- **案由：** 拼多多未经授权发布《原神》主题推广任务，挂载"1元抢一万原石"虚假引流链接
- **裁判结果：** 最高法驳回拼多多再审申请，浙江高院二审判决（停止侵权、消除影响、赔偿100万元）生效
- **裁判要点：** 《原神》及"原石"具较高知名度，拼多多整体使用行为极易导致混淆，构成虚假宣传及仿冒混淆

#### 2. 惩罚性赔偿新司法解释首案——汕头中院（2026-07-06）

- **法律依据：** 《最高人民法院关于审理侵害知识产权民事纠纷案件适用惩罚性赔偿的解释》（法释〔2026〕7号，5月1日施行）
- **案情：** 被告在前案达成执行和解并付清赔偿后，仍在原网店大量销售侵权商品（销量18760件、销售额99.5万元）
- **裁判：** 适用1倍惩罚性赔偿，判赔40.3万元；"和解绝非'护身符'，生效判决更不是'免责金牌'"

#### 3. "无尽雪"侵权"香雪"植物新品种案——最高法（[[2026-07-02]]）

- **裁判要点：** 明确田间观察检测（DUS测试）和分子标记检测（DNA检测）均为植物品种真实性验证的重要鉴定方法，对两种鉴定方法的适用规则作出司法指引

## 三、实务热点问题与趋势分析

### （一）超龄劳动者用工合规——人伤与劳动法交叉新课题

随着渐进式延迟法定退休年龄改革推进，大量超龄劳动者活跃于就业市场。新规落地后，企业用工合规面临三大转变：

| 转变方向 | 合规要求 |
|---------|---------|
| 工伤保障强制化 | 所有返聘/超龄用工必须参加工伤保险，不得以"劳务关系"抗辩 |
| 报酬规范化 | 不低于最低工资、加班费法定倍数 |
| 岗位适配化 | 按身体状况安排岗位，不得安排危险作业 |

**律师业务机会：** 超龄劳动者工伤认定与待遇主张、企业超龄用工合规审计、用工合同模板修订。

### （二）社会救助体系升级对慈善组织的影响

社会救助法构建分层分类救助体系，与慈善事业形成"政府救助+慈善帮扶"衔接格局：

- **衔接点：** 急难社会救助的法定化，为慈善"救急难"项目划定边界
- **风险点：** 重复救助、职能越界、信息共享合规
- **建议：** 慈善组织建立与社会救助部门的协作机制，明确各自救助对象与标准

### （三）建工案件裁判尺度统一——民商事诉讼重大调整

建工解释二全面否定资质借用/挂靠，对建工领域产生深远影响：

- 出借资质方收益不受保护，倒逼行业去挂靠化
- 固定总价比例法、无审计司法鉴定等规则统一裁判尺度
- 质保金、优先受偿权规则明确，减少争议

### （四）知识产权惩罚性赔偿落地——企业合规新压力

法释〔2026〕7号施行后首案宣判，释放明确信号：和解/前案判决不构成后续侵权免责事由。企业知识产权合规需从"被动应对"转向"主动排查"。
