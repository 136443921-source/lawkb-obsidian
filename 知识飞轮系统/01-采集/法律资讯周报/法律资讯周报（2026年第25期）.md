## 一、政策法规更新摘要

### （一）全国人大常委会第二十三次会议即将召开——三项法律草案二审

> **来源：** 新华社、中新网（2026年6月16日、6月22日）  
> **会议时间：** 2026年6月23日至26日

6月16日，十四届全国人大常委会第六十八次委员长会议决定，十四届全国人大常委会第二十三次会议将于6月23日至26日在北京举行。全国人大常委会法工委发言人黄海华于6月22日举行记者会，介绍了将提请本次会议审议的三项法律草案二审情况。

#### 1. 南极活动与环境保护法草案（二审）

**核心修改内容（5项）：**

| 修改维度 | 具体内容 |
|---------|---------|
| **国际条约义务履行** | 规定开展南极渔业活动须遵守南极海洋生物资源养护委员会制定的养护措施 |
| **突发环境事件处置** | 优化突发环境事件的报告及信息通报制度 |
| **渔业制度衔接** | 与《渔业法》做好制度衔接，明确载有南极渔获物国际航行船舶入境程序 |
| **梯度法律责任** | 根据对南极环境的损害程度和恢复难度，对应设置相应法律责任，提升违法成本与损害后果的匹配度 |
| **概念界定** | 明确"视察、观察与检查"等法律概念的具体含义 |

> **立法背景：** 该草案于2025年12月提请常委会第十九次会议初次审议，是我国首部专门规范南极活动的法律。

#### 2. 国家消防救援人员法草案（二审）

**核心修改内容（4项）：**

| 修改维度 | 具体内容 |
|---------|---------|
| **休息休假权利** | 建立适配消防救援职业特点的休息休假制度，依法享有年休假、探亲假等法定权利 |
| **职业健康保障** | 定期健康检查，开展心理咨询、心理疏导，实行适配职业特点的保障制度 |
| **执法主体资格** | 明确国家消防救援人员的行政执法主体资格，规范消防救援执法行为 |
| **政府专职消防员** | 新增规定：省级政府可参照本法对地方政府专职消防员管理作出规定 |

> **实务意义：** 政府专职消防员群体首次被纳入国家法律保障视野，为地方制定管理办法提供上位法依据。

#### 3. 商标法修订草案（二审）——重拳规制"心机商标"

**背景：** 近年来，部分企业在商标注册和使用上将商标作为误导消费者的"套路工具"，严重扰乱商标管理秩序。本次修法对此类"心机商标"设置**三类规制措施**：

| 规制维度 | 具体措施 |
|---------|---------|
| **严把审查注册关** | 明知标志带有欺骗性仍申请注册、造成不良影响的，对申请人处**十万元以下罚款**；对违规准予注册的公职人员**依法给予处分** |
| **畅通投诉举报** | 任何单位或个人有权向商标执法部门投诉、举报误导公众使用注册商标的违法行为 |
| **加大法律责任** | 违法经营额5万元以上的，处违法经营额**五倍以下罚款**；不足5万元的，处**二十五万元以下罚款**；逾期不改正的，**撤销注册商标** |

> **实务提醒：** 企业法务和商标代理机构应关注"心机商标"的界定标准，提前排查存量商标的合规风险；商标侵权诉讼中可援引新法加大对恶意抢注、误导性使用的打击力度。

### （二）《道路交通事故损害赔偿司法解释（二）》施行倒计时

- **法规名称：** 《交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|交通事故司法解释二-全文-2026|[[交通事故司法解释二-全文-2026|最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释（二）]]》
- **文号：** 法释〔2026〕9号
- **通过时间：** 2025年12月23日（最高法审委会第1963次会议）
- **发布时间：** 2026年5月6日
- **施行时间：** ⚡ **2026年6月30日**（距施行仅剩8天）
- **条文数量：** 共12条

**七大核心变化速览：**

| 变化维度 | 要点 |
|---------|------|
| 责任主体 | 明确"开门杀"等非驾驶行为侵权责任主体认定 |
| 责任认定 | 细化多车事故、非机动车与机动车事故责任划分 |
| 赔偿计算 | 统一城乡赔偿标准，细化后续治疗费、康复费计算 |
| 程序规定 | 明确交通事故认定书的证据效力及异议程序 |
| 保险赔付 | 规范交强险、商业险赔付顺序及追偿权 |
| 特种车辆 | 救护车、消防车等特种车辆事故责任认定规则 |
| 新业态 | 网约车、代驾等新业态交通事故责任主体认定 |

> **实务提醒：** 律师应尽快熟悉12条全部内容，尤其是责任主体认定和赔偿计算的新规则，为新司法解释施行后的案件代理做好准备。保险理赔律师应重点关注交强险与商业险赔付顺序的新规定。

## 二、重要判例要点提炼

### （一）最高人民法院发布未成年人权益保护典型案例（6件）

> **发布时间：** 2026年6月2日  
> **来源：** 最高人民法院、国家市场监督管理总局  
> **专题领域：** 未成年人消费权益、网络安全、产品责任

**背景：** 随着网络经济、文创产业、新型消费业态快速发展，面向未成年人的不安全商品、违规经营、危险玩具售卖等问题日益突出。最高法会同国家市场监督管理总局联合发布这批典型案例。

#### 代表性案例要点

| 案例类型 | 核心规则 |
|---------|---------|
| **不安全商品** | 面向未成年人销售不符合安全标准的商品，依法承担惩罚性赔偿责任 |
| **违规经营** | 违规向未成年人提供网络服务、游戏充值等服务，合同无效，经营者承担相应责任 |
| **危险玩具** | "萝卜刀"等危险玩具致人损害的，生产者、销售者承担连带责任 |
| **网络保护** | 网络平台未履行未成年人保护义务的，依法承担相应民事责任 |
| **产品责任** | 未成年人使用产品遭受损害的，适用举证责任缓和规则 |
| **公益诉讼** | 涉及众多未成年人权益的，检察机关可提起公益诉讼 |

> **实务意义：** 这批案例明确了未成年人消费权益保护的裁判规则，为律师代理未成年人权益保护案件提供了参考依据。

|---------|---------|

| **生态修复** | 检察机关可建议法院判令被告以"替代性修复"方式承担修复责任 |

## 三、实务热点问题与趋势分析

### 趋势一：商标注册和使用进入"严监管"时代——"心机商标"规制升级

**背景：** 商标法修订草案二审对"心机商标"设置三重规制措施，标志着商标注册和使用进入"严监管"时代。

**实务影响：**
- 商标代理机构将面临更严格的执业规范，违规者可能被处以罚款甚至停止执业
- 企业应及时排查存量商标，对可能构成"心机商标"的及时整改
- 商标侵权诉讼中的惩罚性赔偿适用将更加严格
- 电商平台对入驻商家的商标合规审查责任加重

**应对建议：**
- 企业法务：开展商标合规自查，重点关注带有欺骗性、误导性的商标
- 律师：研发商标法修订应对专项法律服务，帮助企业排查风险
- 电商平台：完善商标合规审查机制，建立投诉举报处理流程

---

### 趋势二：生态环境法治进入"法典时代"——环保合规成为企业刚需

**背景：** 生态环境法典将于2026年8月15日正式施行，最高法正在起草时间效力司法解释。

**实务影响：**
- 环保合规从"按法规办事"升级为"按法典办事"，合规要求全面提升
- 律师可研发生态环境法典专项法律服务产品（合规体检、培训、争议解决）
- 企业环保合规将从"被动应对"转向"主动合规"
- 生态环境公益诉讼案件数量预计将持续增长

**应对建议：**
- 环保、矿产、化工、制造等行业企业：立即开展环保合规体检
- 律师：抓紧学习生态环境法典，研发专项法律服务产品
- 检察机关：继续加大生态环境公益诉讼办案力度

---

### 趋势三：道路交通事故损害赔偿规则升级——保险理赔和侵权诉讼面临调整

**背景：** 《道路交通事故损害赔偿司法解释（二）》将于2026年6月30日施行，这是2012年原司法解释实施14年后的首次全面修订。

**实务影响：**
- 保险理赔规则调整，交强险和商业险赔付顺序有新规定
- 网约车、代驾等新业态交通事故责任认定有明确规则
- "开门杀"等非驾驶行为纳入侵权责任规制范围
- 城乡赔偿标准统一，农村居民交通事故赔偿标准提高

**应对建议：**
- 保险公司：及时调整理赔规则和格式条款
- 律师：抓紧学习新司法解释，更新交通事故案件代理思路
- 网约车平台：完善乘客伤害赔偿责任分担机制

---

### 趋势四：未成年人权益司法保护持续加强——多部门协同保护格局形成

**背景：** 最高法、最高检近期相继发布未成年人权益保护典型案例，未成年人司法保护形成"民事+刑事+公益诉讼"多轮驱动格局。

**实务影响：**
- 未成年人权益保护案件数量持续增长
- 检察机关未成年人检察工作专业化建设持续推进
- 网络平台未成年人保护合规责任加重
- 玩具、食品、文具等未成年人用品生产销售企业面临更严格合规要求

**应对建议：**
- 网络平台：完善未成年人保护合规体系
- 生产企业：加强产品安全管理，避免侵害未成年人权益
- 律师：可研发未成年人权益保护专项法律服务

---

### 趋势五：消防救援队伍法治化建设提速——职业保障法治化

**背景：** 国家消防救援人员法草案二审明确消防救援人员休息休假、职业健康保障等权利，政府专职消防员首次被纳入国家法律保障视野。

**实务影响：**
- 消防救援队伍职业保障法治化水平提升
- 政府专职消防员管理将有上位法依据
- 消防救援执法行为将更加规范
- 消防救援人员相关劳动争议案件将有明确法律依据
