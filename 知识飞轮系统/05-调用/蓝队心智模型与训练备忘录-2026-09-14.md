|---|---|---|---|---|

### 三条底层信条（训练时反复强化）

1. **法官视角优先** —— 不是「我方想说什么」，而是「法官需要听到什么才会支持我」。
2. **先自查再挨打** —— 主动读 `negative_note` 翻车标本，自己先暴露薄弱点。藏了红队照样打出来，藏只是让老强在庭上才第一次听到。
3. **要件逐项举证** —— 每个要件后必须跟证据编号，严禁笼统举证。缺一项 = 红队一个攻击点。

### 蓝队的心智算法

```
输入案情
  → ① 案由定性：grep 案由路由 R-AY-* 定域（定性错，后面全跑偏）
  → ② 取要件：elements / review_step / burden_of_proof（严禁自拟）
  → ③ 配证据：逐项标注证据编号（不笼统）
  → ④ 找支撑：ruling.support（正向弹药）
  → ⑤ 排雷：negative_note 自查，先于红队修正
  → ⑥ 法官校验：这一步法官会问什么？我答得上来吗？
  → ⑦ 结构化输出 → LTI → 挨打 → 迭代
```

## 二、红蓝弹药对照（训练的核心抓手）

红蓝共用同一把尺，但取用不同弹药字段——这是整个体系最精妙的设计：

| 维度 | 🔵 蓝队 | 🔴 红队 |
|---|---|---|
| 主弹药 | `ruling.support` 正向支撑规则 | `negative_note` 翻车标本 → 攻击点 |
| 副弹药 | `elements` 逐项组织举证 | `ruling.reject` 击破反向依据 |
| 检验尺 | `elements` 缺一项 = 我方致命 | `elements` 缺一项 = 一个攻击点 |
| 输出物 | 大事记/质证/辩论/代理词 v1~v3 | 《致命漏洞战报》S/A/B 三级威胁表 |
| 话语风格 | 稳健、可采信 | 致合伙人内部战报，残酷 |

> **训练推论**：让蓝队在红队开火前，先用红队的取弹逻辑（`negative_note` + `ruling.reject`）把自己扫一遍。做到位的话，三轮冲击第一轮就该「无 S 级漏洞」。

### 第 2 步：出稿——逼它按要件走

```
按以下顺序出稿，缺一步不许往下走：
1. 案由定性（grep 案由路由，报出 R-AY 编号）
2. 要件清单（elements 逐项，每项后标证据编号）
3. 我方支撑（ruling.support，报 rule_id）
4. 自查排雷（negative_note 命中几项？补救方案？）
5. 法官三问（法官最可能追问的三个问题 + 我的应答）
```

### 第 3 步：挨打——红队四维度全开

逻辑断层 / 法理精准度 / 证据三性 / 法官视角。要求红队出具 **S/A/B 三级威胁表，S 级必须在 v2 前清零**。

### 第 4 步：迭代 v2/v3——只补洞，不重写

**v2 只回应红队战报中的 S/A 级**，不做无谓润色。每轮 diff 要能说清「这一版比上一版多堵了哪个洞」。

### 第 5 步：回写——战报转防御要点卡

每轮战报 → 提炼 → 写入 `06-沉淀/` 形成防御要点卡 → 下一案蓝队开局即可消费。
**这是让蓝队越用越强的唯一机制，不做就等于每次从零开始。**
