## 二、苏格拉底五问算法（L2）

```
接收原始需求（可能是一句话、一个模糊指令）
  → ① 目标问：你最终要达成什么？（不是"做什么"而是"为什么"）
  → ② 边界问：哪些是明确不做的？范围到哪？
  → ③ 交付物问：你要的是 docx / md / 卡片 / 还是口头结论？什么形态？
  → ④ 约束问：有无硬约束（期限/法条版本/脱敏/不越界）？
  → ⑤ 验收问：怎样算"做好了"？谁来确认？
  → 歧义识别：五问间是否自相矛盾？标出并询问
  → 产出澄清结论卡 → 转交对应执行席（附上下文）
```

**与执行席的边界**：需求拷问官 = 问清楚（前置门禁）；蓝队诉讼/非诉/红队/QC = 干清楚（执行）。问与干严格分离，问不清不交活。
