# 协同命中记录规范（效用度量 · 知识飞轮第5层）

> **目的**：把「分身每次问答实际命中了哪些飞轮资产（经验卡片 / 裁判规则卡）」结构化留痕，
> 供**每月 28 日知识复利报告**计算 **协同命中率 = 命中有效问答数 / 问答总数**，
> 从而把飞轮从"只进不出"推进到"可量化效用"。
>
> **与 `协同效果日志.md` 的关系**：`协同效果日志.md` 是 per-Q&A 的实时流水；本目录是其**结构化归档层**，
> 按月份聚合，字段更规范，便于复利报告直接汇总。二者互补，不重复。

---

## 一、何时记一条

- 每次**分身问答**（场景化知识推送 / 类案检索 / 非诉复核 / 诉讼文书复核 / 合同审查 / 法律文书 / 庭审准备 / 模拟法庭）**实际调用了飞轮资产（卡片或规则卡）** → 记一条。
- **无真实命中不记**（未调用任何卡片/规则卡，纯模型生成）→ 不计入命中，但可在当月汇总表里标注"未命中"以计算分母。
- 一条 = 一次问答（无论命中几张卡片）。

## 二、记录粒度

- 文件名：`协同命中记录-YYYY-MM.md`（每月一个聚合文件，追加行）。
- 每条一行规范结构（见下方模板），便于复利报告脚本 `grep` 统计。

## 三、字段定义

| 字段 | 含义 | 取值 |
|---|---|---|
| `date` | 问答日期 | YYYY-MM-DD |
| `skill` | 触发技能/场景 | 场景化知识推送 / 类案检索 / 非诉复核 / 诉讼文书复核 / 合同审查 / 文书写作 / 庭审准备 / 模拟法庭 |
| `q` | 用户问题摘要 | 一句话 |
| `hit` | 命中资产 | `R-xxx`（规则卡）/ `经验卡片-xxx`（经验卡），多个用 `、` 分隔 |
| `effective` | 命中是否有效提升产出 | ✅有效 / ⚠️弱命中 / ❌未命中（记未命中用于计算分母） |
| `note` | 备注 | 命中如何融入回答 / 质控要点 |

## 四、模板

```markdown
## 协同命中记录-YYYY-MM

| date | skill | q(摘要) | hit(资产) | effective | note |
|---|---|---|---|---|---|
| YYYY-MM-DD | 场景化知识推送 | <问题一句话> | R-HT-109、经验卡片-XXX | ✅有效 | <如何融入> |
| YYYY-MM-DD | 类案检索 | <问题一句话> | R-PI-175 | ✅有效 | <如何融入> |
| YYYY-MM-DD | 非诉复核 | <问题一句话> | R-SH-032 | ⚠️弱命中 | <说明> |
```

## 五、复利报告联动

- 每月 28 日复利报告读取本目录 `协同命中记录-YYYY-MM.md`：
  - **协同命中率** = `effective=✅有效` 行数 / 总行数（含 ❌未命中）
  - **高频命中卡 TOP5** = 统计 `hit` 列出现频次
  - **弱命中/未命中** 项 → 反哺 `02-提炼/经验卡片` 与 `06-沉淀/裁判规则库` 补强

## 六、质量红线

1. `hit` 必须指向**本次问答真实调用**的资产，且文件名（去 `.md`）须与 `02-提炼/经验卡片/` 或 `06-沉淀/裁判规则库/` 中真实文件一致。
2. 不得为凑数虚构命中（虚构会污染命中率，违背效用度量初衷）。
3. 与 `05-调用/调用记录规范.md` 七类场景记录互补：本目录记"问答级命中"，调用记录记"交付级调用"。
