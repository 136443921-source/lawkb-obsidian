# 6658号吊顶案 · 法律检索助手 v2.5.0 卡库前置接线验证

> **验证目的**：确认「法律检索助手」v2.5.0 检索入口已接本地卡库（案由路由定性先行），闭环 P0 漏网之鱼。
> **配套**：模拟法官 v3.0.0 已于 2026-09-08 用同案跑通（调用记录 `模拟法庭调用记录/20260908-6658号吊顶案-法官v3.0.0接线验证对抗.md`），本记录补检索入口层。

## 一、检索入口动作（v2.5.0 新增强制）

1. **先定案由**（在"厘清核心法律关系"之前）：
   `grep -rl "装饰装修\|吊顶\|买卖合同\|承揽" 06-沉淀/裁判规则库/案由路由/`
   → 命中 `R-AY-001-买卖合同承揽合同装饰装修合同定性分野`。
2. **取卡消费**：R-AY-001 七字段（`discriminator`/`jingxia`/`counter_case`/`negative_note`/`geo_scope` 等）作为检索报告「本地卡库参照」小节。
3. **外部源交叉印证**：元典 rh_ft_search 核验民诉法§34①、§24、解释§28 现行有效性，与卡内 source 一致。

## 二、本地卡库参照（核心命中）

- **R-AY-001**：买卖/承揽/装饰装修定性分野。
  - `discriminator`：看工作成果与报酬对价性质——转移所有权(买卖§595)/交付劳务成果(承揽§770)/不动产构建施工(建设工程§788)。
  - `jingxia`：买卖·承揽＝一般合同管辖(§24)；建设工程含装饰装修＝**不动产专属管辖**(§34①+解释§28)。
  - `negative_note`：照抄2020版案由编号84/114/115已失效（现88/119/120）；照抄民诉法旧条号§23/§33/§34亦失效（现行§24/§34/§35）。
  - `geo_scope`：全国（最高法统一口径）。
- **降级消费**（合同域审判要件卡仅商品房+保险，与吊顶案不适配）：R-HT-125(货款已清主防线·§509)、R-HT-116(发票不能单独证交付)、R-HT-231(票据新债清偿)，显式标注"非对口审判要件卡，降级消费"。

## 三、对抗链增量（零挂载时不可能的战术点）

6658 吊顶案"丁戊祥诉刘九零/刘维"——原告主张买卖合同：
- 若交易含安装施工 → 定性**装饰装修合同** → 属**建设工程** → **不动产专属管辖**（被告住所地/合同履行地法院受限，可能动摇受诉法院管辖权）。
- 纯买卖/承揽仅一般合同管辖(§24)。
- 程序战价值：管辖权异议/受诉法院适格性质疑，为主张"冒名诉讼程序战"（原告'丁茂祥'≠身份证/营业执照'丁戊祥'）提供并行程序切入点。
