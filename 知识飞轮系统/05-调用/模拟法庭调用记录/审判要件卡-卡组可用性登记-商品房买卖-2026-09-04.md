## 一、卡组：商品房买卖合同纠纷（R-HT-151~178，28 张）

### 1.1 适用场景触发词

商品房预售 / 现售 / 认购书 / 预约转本约 / 预售许可证 / 逾期交房 / 逾期办证 / 面积误差 / 五通费 / 一房多卖 / 精装房质量 / 装修质量 / 虚假宣传 / 沙盘 / 样板间 / 首付贷 / 团购费 / 以房抵债 / 商品房消费者 / 价款返还优先权 / 阶段性担保 / 人防车位 / 拆迁安置房 / 经适房 / 违法建筑。

### 1.2 高价值调用路径（按立场）

| 立场 / 场景 | 优先卡 | 用途 |
|---|---|---|
| **买受人·宣传资料构成要约** | R-HT-151 | 广告要约三要件（对象/内容/影响 + 无要约邀请声明） |
| **买受人·预约还是本约**（决定能否强制履行） | R-HT-152 | 预约↔本约识别与转化，**含第二卷新增案例六** |
| **买受人·逾期交房违约金** | R-HT-168 → 169 | 违约金确定与调整 → 期间能否叠加、时效抗辩 |
| **买受人·解除合同并返还** | R-HT-166 → 167 | 解除权实质审查 → 返还范围（利息/维修基金/契税） |
| **买受人·对抗执行或破产**（生存权优先） | R-HT-171 → 173 | 消费者身份认定 → 价款返还请求权优先顺位与时间效力 |
| **买受人·质量与装修瑕疵** | R-HT-160 | 主体结构 → 严重影响居住 → 一般瑕疵的层级化救济 |
| **买受人·一房多卖** | R-HT-164 | 多重买卖的权利顺位 |
| **开发商·否定惩罚性赔偿**（高价值抗辩） | R-HT-170 | **「退一赔一」已被 2020 修正删除**，商品房领域不再适用 |
| **开发商·交付条件与拒绝收房** | R-HT-161 → 162 | 竣工合格证明 / 约定变更交付条件 → 买受人拒绝收房是否成立 |
| **开发商·违约金过高抗辩** | R-HT-168 | 违约金调整（守约方损失 / 合同履行程度 / 过错） |
| **开发商·预售许可与效力补正** | R-HT-155 → 156 | 起诉前取得许可可补正 + 恶意阻却条件成就 |
| **以房抵债受让人** | R-HT-172 → 177 | 受让人地位与付款要件 → 以房抵债的诺成性与新旧债关系 |
| **特殊标的** | R-HT-175 / 176 / 178 | 政策性房屋 / 违法建筑 / 抵押查封房 / 人防车位 / 被拆迁人 |
| **开发商·阶段性担保与追偿** | R-HT-174 | 阶段性担保责任的认定与承担后的追偿权 |

### 1.3 必查的四条分野（防翻车）

1. **惩罚性赔偿版本陷阱（最易错）**：《商品房买卖司法解释》**2003 年版第 9 条**曾规定「退一赔一」，**2020 修正（法释〔2020〕17号）已删除**。商品房买卖领域**不再适用惩罚性赔偿**（R-HT-170）。引用时**必须锁定 2020 修正版**。
2. **时效分野**：**房屋交付请求权**（债权性）适用诉讼时效；**协助办证请求权**（物权性）不适用诉讼时效（R-HT-163）。二者不可混为一谈。
3. **预约 vs 本约**：认购书 + 补充协议具备主要内容且当日付全款 → 认定为本约；换房确认书属标的变更亦为合同内容（R-HT-152，第二卷新增案例六）。
4. **优先权顺位与时间效力**：商品房消费者价款返还请求权优先于建设工程价款优先受偿权与抵押权，但须审《批复》的时间效力（R-HT-173）。

### 1.4 新旧对撞结论（本卡组独有价值）

与《贵州高院商品房买卖合同纠纷案件审判要件指南（2025）》单行本对撞：**正文四章重合 97.51%、逐字一致，无裁判尺度漂移**。唯一实质增量为**新增案例六（吴某铭再审案·预约转本约）**，已落 R-HT-152。→ **2025 年依单行本形成的办案口径仍然有效**，可放心沿用。

## 二、与其他卡组的协同

| 组合 | 场景 |
|---|---|
| R-HT-171/173（商品房消费者） **+** R-PR-041（商品房消费者排除执行） | 生存权优先：执行异议之诉与商品房消费者认定的**双向印证** |

| R-HT-164（多重买卖） **+** R-PR-038~047（执行异议之诉） | 一房多卖下的**权利顺位**与执行程序救济 |
