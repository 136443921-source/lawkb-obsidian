## 一、卡组：保险合同纠纷（R-HT-188~230，43 张）

### 1.1 适用场景触发词

保险合同 / 投保人 / 被保险人 / 受益人 / 关系人 / 如实告知 / 免除责任 / 免责条款 / 格式条款 / 不利解释 / 明确说明 / 提示 / 理赔 / 核定 / 保险金给付 / 代位求偿 / 责任保险 / 第三者直接给付 / 团意险 / 雇主责任险 / 工伤 / 医疗费用保险 / 猝死 / 自杀 / 故意犯罪 / 危险程度增加 / 重复保险 / 超额保险 / 挂靠运输 / 顺风车 / 网络投保 / 现金价值 / 鉴定费 / 资金占用 / 校方责任险 / 投资型保险适当性。

### 1.2 高价值调用路径（按立场）

| 立场 / 场景 | 优先卡 | 用途 |
|---|---|---|
| **保险人·主张解除（未如实告知）** | R-HT-190 → 191 | 告知义务范围与履行 → 违反之后果（解除/不赔） |
| **保险人·弃权抗辩（限制解除权）** | R-HT-192 | 明知未告知仍承保/收保费 → 弃权，解除权受限 |
| **投保人/被保险人·免责条款不生效** | R-HT-193 → 194 | 信息提供义务与免责范围 → 提示与「明确说明」审查标准 |
| **投保人·格式条款作不利解释** | R-HT-195 | 不利解释规则 + 绝对无效情形 |
| **被保险人·理赔迟延/拒赔** | R-HT-198 | 保险人核定与理赔义务（30 日核定、及时给付） |
| **受益人·保险金给付争议** | R-HT-199 | 受益人指定、变更与保险金请求权 |
| **保险人·法定免赔抗辩** | R-HT-200 | 自杀（2 年）、故意犯罪免责的构成要件 |
| **保险人·代位求偿** | R-HT-217 → 221 | 代位适用范围 → 处分行为影响 → 第三者生效裁判 → 挂靠运输 → 机动车与非机动车 |
| **责任险·第三者直接给付** | R-HT-215 / 216 | 责任险直付第三者；寄宿生校方责任险 |
| **团意险/雇主险·双赔边界** | R-HT-211 / 212 / 213 | 雇主意外险金与雇主赔偿双赔 / 团意险金与工伤双赔 / 雇主责任险本质为责任替代 |
| **网络投保·交付与说明** | R-HT-205 / 206 / 207 | 条款交付认定 → 明确说明义务与举证 → 团意险说明对象 |
| **危险程度显著增加** | R-HT-224 / 225 | 顺风车 / 非营业货车营运用途，未通知可拒赔 |
| **诉讼时效** | R-HT-201 | 保险合同纠纷诉讼时效起算与中断 |
| **投资型保险适当性** | R-HT-208 | 适当性义务（销售适配、风险揭示） |
| **物流/运输企业涉保险** | R-HT-220 / 221 / 227 | 挂靠运输公司代位 / 机动车代位 / 物流责任险增值税扣除 |

### 1.3 必查的五大分野（防翻车）

1. **如实告知 vs 弃权**：保险人明知未告知仍承保或收受保费，构成弃权（R-HT-192），解除权受《保险法》第 16 条第 6 款限制；不能以「未告知」反言拒赔。**解除权还受 2 年不可抗辩期约束**（R-HT-191）。
2. **明确说明义务举证责任**：网络投保中保险人须证明已向**投保人个人**履行提示与明确说明（R-HT-206 高频争议）；团意险说明对象为投保人或其代表（R-HT-207），非每一位被保险人。
3. **代位求偿适用范围**：**人身险（意外/健康给付型）不适用代位**（R-HT-217 适用范围）；但**医疗费用补偿型**可适用损失补偿原则（R-HT-210），二者不可混同。
4. **双赔边界**：雇主意外险金属**被保险人之受益**，与雇主工伤赔偿可双赔（R-HT-211）；团意险金与工伤待遇可双赔（R-HT-212）；而**雇主责任险**本质是责任替代，赔付后即填平雇主责任（R-HT-213）。
5. **危险程度显著增加**：顺风车（R-HT-224）、非营业货车改变用途营运（R-HT-225）导致危险程度显著增加而未通知，保险人可依《保险法》第 52 条拒赔——但须证明「显著增加」且「影响承保决定」。

### 1.4 本卡组独有价值

- **网络投保三连击**（R-HT-205/206/207）直击当下互联网保险诉讼最高频争点，与 2025 单行本相比新增了电子送达、勾选式说明的举证标准。
- **代位求偿五连击**（R-HT-217~221）覆盖机动车/挂靠/第三者裁判三大实务场景，与航合物流（贵 C09782D 事故）类运输案件高度契合。
- **双赔边界三连击**（R-HT-211/212/213）厘清了「给付型险金」与「责任替代型险」的本质差异，是工伤 + 保险交叉案件的必查分野。

## 二、与其他卡组的协同

| 组合 | 场景 |
|---|---|
| R-HT-211/212/213（保险双赔） **+** 工伤卡组 | 工伤待遇 + 商业险金的**可双赔性**双向印证 |
| R-HT-217~221（代位） **+** R-JT（交通侵权） | 机动车代位求偿与交通事故责任的衔接 |
| R-HT-215（责任险直付） **+** R-PR（侵权赔偿） | 第三者直接给付与侵权损害赔偿的顺位 |
| R-HT-220/221/227（运输保险） **+** 航合物流案件 | 挂靠运输代位、机动车代位、物流责任险增值税扣除的实战映射 |
| R-HT-225（货车营运） **+** R-GS（公司/运输） | 非营业货车改变用途营运的保险抗辩与企业运输合规 |
