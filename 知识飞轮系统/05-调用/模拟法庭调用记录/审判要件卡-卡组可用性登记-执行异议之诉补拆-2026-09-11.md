# 卡组可用性登记｜R-PR-069~083 案外人执行异议之诉·程序性处理与未拆子类

| 项 | 结论 |
|---|---|
| 可用性 | ✅ **可用**（候选推理，须人工确认） |
| 覆盖审理环节 | 立案审查 → 程序性处理 → 实体审理 → 类案参酌 |

| 死链 | 0 |

## 二、法官心智调用路径（四步推理链）

1. **定位审理环节** → 读 `review_step`：本组覆盖「立案审查·制度定性」「立案审查·异议对象分流」
   「程序性处理·终结审查／终结诉讼／依据错误分流／破产衔接／再审衔接」「实体审理·被拆迁人／预告登记／代为清偿」「类案参酌」。
2. **逐项涵摄** → 用 `elements` 逐项比对本案事实。
3. **举证校验** → 用 `burden_of_proof` 判断哪方未举证。
4. **裁判预判 + 但书提醒** → 用 `ruling.support` / `ruling.reject` 给**候选结论**，同时触发 `negative_note`。

## 四、🔴 调用纪律（三条）

1. **口径 vs 条文分层**（SKILL 坑 30）：R-PR-069/070/072/075/078 中的
   「三类异议之诉」「三不问」「并存时仅审标的异议」「实质审查 vs 外观判断」等
   均为《指南》**裁判口径细化 / 教义归纳**，**不是条文原文**。
   法官输出时须标注口径属性，不得表述为"依据第X条"。
2. **9 条待回源不得作裁判依据**：民诉法解释 §302/303/305/306/308/309、
   《复议规定》§6/§8、〔2014〕民立他字第29号答复——卡内已标「待回源」，
   **正式文书引用前必须二次核对**（国家法律法规数据库 https://flk.npc.gov.cn/）。
3. **时间效力**：《执行异议之诉解释》（法释〔2025〕10号）**2025-07-24 施行**，
   对施行前已受理或已终审案件须先行判断时间效力，不得径行溯及适用。
