## 二、调用纪律（法官心智四步推理链）

1. **定位审理环节** → 读 `review_step`
2. **逐项涵摄** → 用 `elements` 逐项比对本案事实
3. **举证校验** → 用 `burden_of_proof` 判断哪方未举证
4. **裁判预判 + 但书提醒** → 用 `ruling.support` / `ruling.reject` 给**候选结论**，同时触发 `negative_note`

> **铁律 R2**：机器只给候选（`【候选·待人工确认】`），**不自动裁判**。

## 三、⚠️ 调用前必读的六个要点

1. **🔴 婚后父母出资购房已换版**（本批最高价值）：解释一第二十九条第二款**仍现行有效**（2026-09-07 元典核填·现行有效），但其「婚后父母出资无约→按民法典第1062条第一款第四项认定为共同财产、原则均分」的裁判路径**已由后法特别规则解释二第八条重构**（法释〔2025〕1号，**2025-02-01 施行**）为「**以出资来源及比例为基础 + 综合考量**」，**不再当然各半**，就该情形解释二第八条优先适用 → [[R-HY-030-父母出资购房分割]]。凡 2025-02-01 后受理案件**禁引旧推定**。
2. **夫妻间房屋给予不再径行适用任意撤销权**：未过户的，**不再径行适用民法典第 658 条**，改由法院依**解释二第五条**判决房屋归属并确定是否补偿；给予方**仅在法定四类情形**下可撤销，**第三款未规定「撤销即无须补偿」**（2026-09-07 回源复核订正） → [[R-HY-025-房屋给予未过户的分割与撤销]]。
3. **彩礼返还 ≠ 全退**：按共同生活时间长短、有无生育、彩礼数额与实际用途、双方过错、当地经济水平**酌定比例**；「闪婚闪离且未共同生活」才全额返还 → [[R-HY-020-彩礼返还比例裁量]]、[[R-HY-055-案例十闪婚闪离高额彩礼全额返还]]。生活困难须**从严认定**（无法维持当地基本生活水平，非相对下降）→ [[R-HY-021-生活困难从严认定]]。
4. **身份关系不能调解/不能自认**：婚姻效力、身份关系确认不适用调解与自认规则，调解优先但**不久调不决** → [[R-HY-004-审理四原则]]、[[R-HY-016-调解程序边界]]。
5. **共同债务「共签共认 + 家庭日常生活」双轨**：超出家庭日常生活需要的，债权人须举证用于共同生活/共同生产经营或基于共同意思表示 → [[R-HY-027-夫妻共同债务认定]]。
6. **地域效力**：本卡组系**贵州高院**裁判尺度统一指引，**非全国统一司法解释**；跨省援引须核当地口径（每卡 `geo_scope` 已标注）。
