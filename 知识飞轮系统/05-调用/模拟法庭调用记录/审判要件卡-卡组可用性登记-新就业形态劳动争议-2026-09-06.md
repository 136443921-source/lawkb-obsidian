## 二、调用纪律（法官心智四步推理链）

1. **定位审理环节** → 读 `review_step`
2. **逐项涵摄** → 用 `elements` 逐项比对本案事实
3. **举证校验** → 用 `burden_of_proof` 判断哪方未举证
4. **裁判预判 + 但书提醒** → 用 `ruling.support` / `ruling.reject` 给**候选结论**，同时触发 `negative_note`

> **铁律 R2**：机器只给候选（`【候选·待人工确认】`），**不自动裁判**。

## 三、⚠️ 调用前必读的六个陷阱

1. **职业伤害保障办法换版**：涉及「执行平台订单任务期间」的，**先按事故发生日**以 **2025-07-01** 为界选版本（新办法第十一条，无「完成后 1 小时」宽限）→ R-LD-040。
2. **案由不是子案由**：2026-01-01 后「新就业形态用工纠纷」是**第二级案由**，与劳动争议并列 → R-LD-010。
3. **地域效力**：本卡组系**贵州高院裁判尺度统一指引**，跨省援引须核当地口径（每卡 `geo_scope` 已标注）。
4. **🔴 二倍工资须过解释二第七条（2025-09-01 起）**：法释〔2025〕12号第七条采「**支持为原则 + 三项封闭式例外**」（不可抗力 / 劳动者本人故意或重大过失 / **法律、行政法规**规定的其他情形）。贵州指南的「**意外事件**」不在列举内，**不得单独免责** → R-LD-024。
5. **⚖️ 先分层次再叠加（R-LD-024 核心）**：「是否已订立书面劳动合同」（**构成要件层**，含实质书面化 / 入职材料替代，**前置判断**）与「未订立后是否免责」（**法律效果层**，解释二第七条三项）**是两个问题**。前者成立则第七条前提自始不成立，二者不冲突。
6. **计算规则已统一**：二倍工资**按月计算**，不满一个月按该月**实际工作日**（解释二第六条），地方「按日折算」「最长十一个月」口径让位。
