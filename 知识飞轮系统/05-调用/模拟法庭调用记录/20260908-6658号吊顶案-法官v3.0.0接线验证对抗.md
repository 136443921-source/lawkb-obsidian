### ② 法官追问（v3.0.0 新增·接线前不会问）

> **"原告，案涉吊顶交易是『纯供货』，还是『供货＋安装施工』？"**
> ——若含安装施工，可能被定性为**装饰装修合同**（2025版案由 120 第(7)项），
> 从而落入**不动产专属管辖**（民诉法§34第一项＋民诉法解释§28）；
> 若为纯买卖或承揽，则仅适用一般合同管辖（民诉法§24）。

**价值评估**：这是 v3.0.0 接线后才可能提出的管辖抗辩点。
v2.0.0 法官（零挂载）只会做"管辖权/当事人适格/诉请"三性筛查的**通用问法**，
**不会**把"交易含不含安装"与"专属管辖"精确挂钩。此即接线增量。

## 第三步｜法庭辩论与法律发现（裁判规则探寻＋翻车拦截）

### ① 正反成对呈现（`ruling.support` / `ruling.reject`）

**R-AY-001 定性之争——双方路径**：

| 立场 | 路径 | 法律后果 |
|---|---|---|
| 原告（主张买卖/承揽） | 一般合同管辖（民诉法§24） | 维持现法院管辖 |
| 我方被告（主张装饰装修） | **不动产专属管辖**（民诉法§34①＋解释§28） | 可能引发管辖异议 |

### ② 翻车拦截（`negative_note`）

⚠️ 本域审判要件卡（商品房/保险）与吊顶案**不适配**，
**严禁**把"商品房买卖"或"保险合同"的要件与翻车标本套用到本案——
此为 v3.0.0 接线后**新增的核心风险**（接线前无卡可套，反无此风险）。
已在资源段规则④以"域覆盖诚实提示"明示。

### ③ 地域效力（`geo_scope`）

R-AY-001 为 `全国（最高人民法院统一口径，非贵州特化）` → **可跨省援引，无需核贵州口径**。
（对比：合同域审判要件卡多为 `贵州省（贵州高院裁判尺度统一指引，跨省援引须核当地口径）`，
引用时须区别对待，不得混为一谈。）

**预判（程序争点优先）**：

1. **原告主体瑕疵**为最硬程序立足点：起诉状署名与身份证、营业执照**用字不同**，

## 接线成效评估

| 维度 | v2.0.0（接线前） | v3.0.0（接线后） |
|---|---|---|
| 检索动作 | 无（引用数 0） | 强制：案由路由先行定性 → 域卡组 → 五字段消费 |
| **战术增量** | 通用三性筛查 | ⭐ **挖出「交易含安装 → 装饰装修 → 专属管辖」抗辩链** |
| 要件来源 | 凭通用知识自拟 | 强制取卡；无对口卡时降级并**显式标注** |
| 翻车拦截 | 无 | 读 `negative_note`；并新增"防误套域"警示 |
| 地域效力 | 不区分 | 区分「全国口径」与「贵州口径」，跨省援引须核 |
| 说理溯源 | 可无源 | 禁无源说理，须标 `rule_id` |

**结论**：接线生效，法官由"通用法律常识裁判"转为"**可回溯卡源的规则裁判**"。
