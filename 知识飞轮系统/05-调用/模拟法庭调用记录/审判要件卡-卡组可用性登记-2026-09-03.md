## 一、卡组 A：共同饮酒者侵权责任纠纷（R-PI-227~239，13 张）

### 1.1 适用场景触发词

酒局 / 聚餐 / 劝酒 / 同饮 / 醉酒死亡 / 醉酒受伤 / 酒精中毒 / 酒后驾车 / 酒驾致死 / 酒后溺亡 / 酒后摔伤 / 未成年人饮酒 / 红白事酒席 / 组织者责任。

### 1.2 高价值调用路径（按角色）

| 立场 | 优先卡 | 用途 |
|------|--------|------|
| **被告（共饮者）** | R-PI-227 → 232 → 236 | 四要件总纲 → 注意义务边界 → 四类免责事由 |
| **被告（责任比例）** | R-PI-235 → 234 | 饮酒人自负为主 → 按份而非连带 |
| **被告（因果切断）** | R-PI-233 | 介入因素四项判断 + 无死因鉴定的高度关联性抗辩 |
| **原告** | R-PI-231 → 232 → 237 | 强迫性劝酒 → 注意义务违反 → 未成年人加重 |
| **管辖异议** | R-PI-229 | 侵权行为地/被告住所地竞合 |

### 1.3 必查的两条分野（防翻车）

1. **请求权基础分野**：共饮者走 **民法典 1165（过错责任）**；饭店/酒吧/浴池等经营者走 **民法典 1198（安全保障义务人责任）**。**要件与归责不同，不可混用**（见 R-PI-239）。
2. **公平责任审慎**：不得因"有人死了"就适用 1186 条公平责任分担损失（见 R-PI-230）。

## 二、卡组 B：第三人撤销之诉（R-PR-048~057，10 张）

### 2.1 适用场景触发词

撤销之诉 / 案外人救济 / 生效裁判损害第三人 / 6个月起诉期 / 有独立请求权第三人 / 无独立请求权第三人 / 虚假诉讼救济 / 债权人撤销生效裁判。

### 2.2 高价值调用路径

| 场景 | 优先卡 | 用途 |
|------|--------|------|
| **立案狙击（被告/被撤销方）** | R-PR-048 → 049 → 051 | 四要件缺一 → 九类不适格 → 6个月不变期间 |
| **主体资格攻防** | R-PR-049 → 050 → 053 | 不适格 → 债权人三类例外 → 不能归责事由判断 |
| **实体抗辩** | R-PR-054 | 证明标准「足以推翻」（高于高度盖然性） |
| **路径选择（易错）** | R-PR-057 | 撤销之诉 / 申请再审 / 执行异议之诉 **三择一，一经选择不得回转** |

### 2.3 必防的版本陷阱

- 本书用 **2023 修正版**民诉法条号。
- 民诉法解释(2022修正)内部引用的「民事诉讼法第二百三十四条」是 **2021 修正版**条号，对应 2023 修正版 **第二百三十八条**。
- **起草文书时务必锁定版本**，否则条号全错。
