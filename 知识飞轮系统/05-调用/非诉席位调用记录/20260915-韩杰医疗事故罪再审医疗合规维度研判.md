# 韩杰医疗事故罪再审 · 医疗合规维度研判（蓝队非诉 · 🟨B 医院支柱）

> 任务定位：本案为刑事再审辩护（医疗事故罪，《刑法》第335条），蓝队非诉律师**不入庭、不辩护**，
> 仅从「医疗机构合规」维度做**非诉合规风险研判 + 内控整改建议**——这是 🟨B 医院支柱的标准实战形态。
> 事实源锚定 `经验卡片-韩杰医疗事故罪刑事申诉`（is_simulation: false，真实在办申诉案）。

## 一、案件事实锚定（脱敏摘要）

- **案由**：医疗事故罪 / 刑事申诉·抗诉（二审维持后进入申诉阶段）
- **原审认定**：一级甲等医疗事故、医方负主要责任 → 径行推定医疗事故罪成立
- **核心争点**：①死因未尸检→因果链存合理怀疑；②医疗事故认定≠有罪（梁某/李某规则源）；③团队责任≠个人罪责（李建雪类案）；④注意义务标准匹配执业资质
- **体系性介入**：案发春节值班日儿科未专人值班、交接班体系断裂 → "二次风险拦截"失灵

## 二、医疗合规五维研判（🟨B 核心）

### 1. 医疗质量安全核心制度失灵（体系性缺口）
- 依据《医疗质量安全核心制度要点》（国卫医发〔2018〕8号）：三级查房、值班交接班、首诊负责制构成诊疗"风险拦截链"。
- 案发春节值班儿科无人、交接班断裂 → 该拦截链在关键环节失灵，属**注入诊疗过程的独立体系性因素**，其风险不归责于个人医师（刑法个人责任原则）。
- **合规结论**：这是机构合规体系缺口，整改对象应是排班/交接班合规机制，而非仅追责个人。

### 2. 病历与鉴定材料合规（R-PR-124）
- 原审鉴定意见的根据（病历等）未经开庭质证 → 鉴定意见合法性存疑（R-PR-124 鉴定材料未经质证的后果）。
- **合规结论**：医疗机构应建立「病历书写—归档—质证留痕」合规流程，确保涉诉鉴定材料可经质证，前置降低证明风险。

### 3. 严重不负责任七情形边界（R-PI-152）
- 入罪以"严重不负责任七情形"为立案标准（R-PI-152），须区分**责任过失 vs 技术过失**——仅严重责任过失具入罪基础。
- **合规结论**：合规培训须把七情形讲透，避免把技术过失误判为刑事责任，误伤医师。

### 4. 注意义务匹配执业资质
- 案发时申诉人独立执业仅约4月，不得以"五年专科经验"过高标准评价注意义务违反程度。
- **合规结论**：机构排班与授权应匹配资质层级，合规口径须与法律责任评价口径一致。

### 5. 尸检与死因告知合规（R-PI-183 / R-PI-129）
- 患者死亡未尸检 → 死因建立在盖然性推断上，刑事证明缺口在控方（R-PI-183 尸检缺失存疑有利被告；R-PI-129 未尸检不影响效力但死因非排他）。
- **合规结论**：医疗机构应建立「死亡病例死因告知 + 尸检建议」合规话术与书面留痕，避免将证明缺口转嫁医师、并保护机构自身举证利益。

## 三、非诉交付物（医疗机构合规整改包）

1. **《医疗质量安全核心制度合规体检清单》**——三级查房/值班交接班/首诊负责制落地核查表
2. **《病历质控与鉴定材料质证留痕 SOP》**——从书写到涉诉质证的闭环留痕
3. **《医师执业资质-注意义务匹配培训要点》**——七情形边界 + 责任/技术过失区分
4. **《死亡病例尸检建议合规话术》**——告知+建议+留痕三件套

> 以上为纯非诉合规建设产出，供涉案机构内控整改与同类机构合规前置；不直接参与刑事辩护。
