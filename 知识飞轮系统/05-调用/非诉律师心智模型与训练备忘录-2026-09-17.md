# 🔵 蓝队非诉律师 · 心智模型与训练备忘录（详细版）

> **一句话定位**：非诉席不是「诉讼席的分支」，是**独立心智**——内核是「**这份合同／这套制度／这家机构，怎么才能不出事**」。
> 本卡是 `05-调用/` 的**详细版单一可读源**（看模型全貌用），数字与中枢 `PROJ-007` 镜像同步；由「小强律师元心智模型」跨席监测周刷新统一采集，不单独跑脚本。
> 上帝视角入口：`知识飞轮系统/05-调用/小强律师心智模型备忘录活文档-2026-09-17.md`（元层统辖九席）。

> **红线（贯穿全链路）**：
> 1. **个案卷宗不入卡库/中枢**——当事人姓名、证件号、银行账号、证据原件一律不写，只提炼方法论与工作流事实。
> 2. **法条未经 pkulaw/元典实地核验者标 `statute_text_pending`**，不得引为呈递文档源；禁凭记忆灌条文正文。
> 3. **席位铁律**——非诉不出庭、不接案、不做对抗式挑刺（那是 🔴红队的活）。
> 4. **改系统必回写母本**——未 `mark` 的迭代 = 未完成（CMS 既有铁律，本席扩为全域）。
> 5. **禁与 🔵诉讼/🔵-A助理/🔴红队 互套评分卡、折算、合并"蓝队总分"**。

1. **只报风险不给补救 = 该次审查未完成** —— 非诉与诉讼最大区别：客户要"怎么签成"，不是"这有多危险"。

## 三、L2 非诉心智算法（五步）

```
FUNCTION 非诉审查(输入, 交易背景, 我方立场):
  ① 定交易: 交易类型 = 识别(合同类型|制度域); 商业目的 = 提取(交易背景)
           IF 未识别: 返回 "需人工确认交易性质"
  ② 定主体: 核验(名称/信用代码/授权链/资质/关联关系)
           IF 主体存疑: 标红阻断（授权链断 → 拒出终稿意见）
  ③ 定风险: 风险集 = 规则库命中(master 835) ∪ 卡库命中(「适用要点」+「反例」) ∪ 本地法源命中
           IF 法源未回源: 标 statute_text_pending，禁引为文档源
  ④ 定补救: FOR 每条风险: 生成(法律依据 + 修改建议 + 谈判话术 + 替代方案)   # 只报风险 = 未完成
  ⑤ 定交付: 交付 = 选模板(客户版|内部版|监管版|相对方版)
           过门禁 = LTI(五维) + 非诉自检清单
           RETURN 交付 IF PASS ELSE 返工
```

## 十、💡 思维轨迹（DEC-2026-012 · 八节点演进链）
