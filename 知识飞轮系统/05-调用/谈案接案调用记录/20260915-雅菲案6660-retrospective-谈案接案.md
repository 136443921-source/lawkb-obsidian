# 谈案接案记录（retrospective 推演）：雅菲案6660

> **训练属性声明**：本记录为**路径 B（在办案 retrospective 谈案推演）**，依据现有案卷（`case-state.json` + `10_起诉真实性异议书` + `2026-09-03 法律骨架`）还原客户（被告刘九零、刘维）就本案首次咨询委托时的规范谈案流程，**非实时接案实录**，仅供蓝队 D6 谈案维度训练与度量，不写入正式案卷。

## 1. 接谈笔录

- **当事人**：刘九零（被告一，身份证 522132198909202218）、刘维/别名刘军（被告二，身份证 522132198805102212）；系夫妻/共同被诉。
- **诉求**：被习水县焦鹏雅菲软装经营部（经营者焦联鹏）以窗帘货款未付起诉，诉求为"不担责、最好原告撤诉或驳回"。
- **事实脉络**：房屋系刘九零以包工包料发包给"欧派门业习水专卖店"（负责人黄茂姣）整体装修，窗帘属包工包料范围由承包方采购；2025-09-25 黄茂姣选货下单，2025-11-25 原告制订货单刘维仅签收；2026-01-22 原告催款，被告方明确指向黄茂姣。
- **证据初判**：装修合同、报价单（窗帘 5000 元含于整装 178000 元）、原告 2025-08-19 亲笔《情况说明》自认黄茂姣为真实买受人且货款已结、微信催款记录。
- **期望目标**：驳回起诉 / 不承担责任。
- **情绪与底线**：对"莫名其妙被起诉"有怒意，但配合度高；底线"不花冤枉钱、不背无中生有的债"。

## 2. 风险评估报告

- **案由定性**：买卖合同纠纷（窗帘），被告方应诉；争点为合同相对性、货款清偿、起诉真实性。
- **胜诉率区间**：偏高（案件态势 65/100，趋势 up）。核心支撑：①合同相对性——窗帘属承揽人采购义务，被告为定作人；②货款已清——原告亲笔自认黄茂姣付清；③滥用诉权——自认与起诉矛盾。
- **主要风险点**：
  1. 录音证据（2026-07-14 刘维↔丁戊祥 10分50秒、2026-08-24 3分13秒）须裁定送达前刻录附卷，否则灭失；
  2. 原告撤诉后可能依《民诉法解释》第214条第1款原样再诉，须以自认钉死+附卷阻断；
  3. 撤诉法条曾凭记忆误用 145 条，正确为 148 条第 1 款——法条引用须实地核验；
  4. 金额混乱（"295二元"笔误 vs 微信 5000），再诉时须咬死原告举证责任。
- **程序路径**：答辩→（原定 9/1 开庭，原告撤诉）→撤诉窗口期处置→裁定送达前自认钉死+录音附卷→封堵再诉。
- **时效提示**：撤诉裁定送达即生效、不可上诉不可复议，窗口期一旦关闭无补救；所有动作须在送达前完成。

## 3. 报价方案

- **计费方式**：建议**固定收费**（应诉阶段打包），另设**风险代理可选项**（若达成驳回/不担责结果追加奖励）。
- **金额区间（框架示范，以正式协议为准）**：应诉基础包（答辩状+举证+质证+代理词+预案）固定费率；若涉追加第三人、调查取证申请、反诉，按事项另计。
- **支付节点**：签约付 50% → 递交答辩状付 30% → 结案/裁定送达付 20%。
- **差旅成本**：本地（习水县）诉讼，差旅低，可含于基础包。

## 4. 委托协议草稿

- **代理权限**：特别授权（应诉、答辩、举证、质证、代收法律文书、参与调解）。
- **双方义务**：客户如实提供材料并配合；律师勤勉尽责、保密、及时汇报。
- **解除条款**：客户可随时解除，已发生合理费用不退；律师发现客户隐瞒关键事实可终止代理。
- **保密条款**：案卷信息仅用于本案，不得用于无关用途。
- **利益冲突声明**：见第 5 项；若存在冲突须书面披露并经客户确认。

## 5. 利益冲突审查

- **相对方/关联主体**：原告焦联鹏（雅菲经营部）、承包方黄茂姣（欧派门业）、关联案（2026）黔0330民初6658号丁戊祥诉刘九零吊顶案（同被告、同承包方黄茂姣交叉）。
- **本所既有客户冲突筛查**：6658 与 6660 被告均为刘九零/刘维，立场一致、互补不冲突；黄茂姣在两案均系案外人/承包方，须向客户披露其双重身份，避免利益误判。
- **结论**：**无禁止性冲突**；存在关联案交叉（6658 吊顶 + 6660 窗帘，均涉黄茂姣），已向客户披露并在档案标注跨案关联，符合披露义务。

## 6. 客户预期管理

- **红线告知**：不承诺具体结果（尤其不承诺"一定驳回"）；诉讼结果由法院依证据裁判。
- **周期预期**：一审应诉 + 撤诉窗口期处置约 1–3 个月；若原告撤诉后再诉，周期相应拉长。
- **配合义务**：保留全部微信记录、收据、合同原件不删；收到法院任何裁定书/传票第一时间拍照告知。
- **风险自担确认**：撤诉不等于免责，须完成自认钉死与录音附卷方能封堵再诉；诉讼有成本，客户已知悉并签字确认。
