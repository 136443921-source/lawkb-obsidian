## 一、风险地图：商标转让协议里，惩罚性赔偿从哪来（R-SH-042）

转让协议本身不是侵权，但**三类场景**会触发知识产权惩罚性赔偿（民法典第一千一百八十五条 + 商标法第六十三条第一款），且均须满足 R-SH-042 的**双要件**：故意（E2）+ 情节严重（E3）+ 原告明确请求（E4）。

| 场景 | 触发方 | 合同可预设的防线 | 对应卡 |
|---|---|---|---|
| ① 转让方瑕疵担保缺口：含灵转让的商标实际侵犯第三人 IP（含灵无清洁权属） | 第三人诉至善（受让方被动卷入）；或至善对含灵主张违约/侵权 | 权属承诺与瑕疵担保赔偿条款 | R-SH-042 E2/E3 |
| ② 转让后转让方继续使用：含灵转让后仍以近似商标经营 | 至善（新权人）诉含灵，若含灵"故意+情节严重"→ 惩罚性 | **不竞争/不继续使用条款 + 违约赔偿公式** | R-SH-042 + R-SH-053 |
| ③ 受让方自身侵权：至善取得后使用侵犯他人 | 至善自担，与含灵无关 | 交付后 IP 合规承诺（至善单方） | R-SH-042 |

**R-SH-042 四项审理原则映射**：依法适用（不得类推扩大）／比例协调（倍数与情节相适应）／补偿与惩罚并重／积极稳慎。合同应**预设举证责任分配与责任触发条件**，把"故意+情节严重"的事实认定前置到违约条款中，降低日后争议。

## 二、基数×倍数闭环（R-SH-049 + R-SH-052）

### 2.1 公式结构（R-SH-049 E1）
> **惩罚性赔偿数额 ＝ 基数 × 倍数**；**赔偿总额 ＝ 惩罚性数额 ＋ 维权合理开支**（两者分别计算、不得混同）。

### 2.2 基数四源（R-SH-049 E2–E5，须真实可算）
| 基数来源 | 适用 | 红线 |
|---|---|---|
| 原告实际损失 | 首选 | — |
| 被告违法所得 / 侵权获利 | 次选 | — |
| 参照许可使用费 | 前三难算时 | 须合理，非凭空 |
| 法定赔偿 | **禁止作基数** | 🔴 法定赔偿是法院酌定数额，套用"法定赔偿×N"判赔属错误（R-SH-049 翻车标本 / R-SH-054） |

**合理开支隔离**：维权费用单列、不计入基数（R-SH-049 E2）。

### 2.3 倍数（R-SH-052）
- 综合**主观恶意 + 情节严重程度 + 商标价值/知名度 + 是否足以阻遏**确定；**可为非整数**（如 2.5 倍），不得机械整数档。
- **商标类型提高项**：驰名商标 / 商誉贬损 / 伪劣商品 → 可提高；以侵权为业提高、帮助教唆降低。
- **五倍封顶**：赔偿总额最高为基数 **五倍**，合理开支另算（商标法第六十三条第一款："一倍以上五倍以下"）。
- **罚款罚金折抵**：同一行为已受行政罚款/刑事罚金且执行完毕的，民事倍数应予扣减（R-SH-052 E3）。

### 2.4 闭环落地到合同
违约金/赔偿条款须引用**可算基数**（如"许可使用费 × N 倍"），**不得写"法定赔偿×N"**；倍数约定**须 ≤5**，否则依 R-SH-053 E3 依法调整。

## 三、约定适用 —— 本合同最关键锚点（R-SH-053）

R-SH-053 明确惩罚性赔偿**可约定适用**，三要件：

- **E2 事先约定**：当事人事先约定惩罚性赔偿的，从其约定。
- **E3 倍数调整**：约定基数和倍数但倍数不在法定范围内的，依法调整（≤5）。
- **E1 和解金额参照**：和解后重复侵权，可参照在先和解金额作基数，但被告证明显具惩罚性或过分高于损失/获利的除外。

### 3.1 在商标转让协议怎么嵌
在协议中嵌入**「不竞争 / 不继续使用」条款 + 违约赔偿约定**（针对场景②转让后继续使用）：

1. 含灵承诺：转让登记完成后，**不以任何形式使用**该注册商标及近似商标、不许可第三人使用；
2. 违约/再次侵权 → 赔偿＝**许可使用费 × N 倍（1≤N≤5）**，基数须真实可算；
3. 维权合理开支单列、不计入基数。

### 3.2 边界警示（🔴 必读）
- 惩罚性赔偿本质是**法定侵权救济**（民法典1185 + 法释〔2021〕4号）。合同预先约定的"惩罚性"条款，法院可能按**违约金**（民法典第五百八十五条）审查，若"过分高于造成的损失"可予调减。
- 故：基数须**锚定真实损失/许可费**，避免被调减（R-SH-053 翻车标本：直接以和解100万作基数未审是否过高 → 应调整）。
- 双重约束：**民法典585 违约金调整** ＋ **法释4号 五倍上限**，条款须同时满足。

## 五、条款建议模板（套入定稿版）

```markdown
第X条 不竞争与不继续使用
1. 转让方（含灵生物）承诺：自转让核准公告之日起，不以任何形式使用、许可他人使用
   该注册商标及与其近似之商标，亦不以该商标相同或近似标识从事经营活动。
2. 转让方违反本条约定的，应按如下标准向受让方（至善）支付违约赔偿：
   违约赔偿 = 该商标许可使用费 × N 倍（1 ≤ N ≤ 5，N 由违约情节确定）；
   许可使用费以【同行业同类商标许可市场费率 / 双方原许可记录】为基数，须真实可算。
3. 受让方因维权支出的合理开支（律师费、调查费、公证费等）在违约赔偿之外另行计算，
   不计入上述基数。
4. 本条约定之赔偿以法定倍数上限为限；如约定倍数超出法定范围，依法调整。
5. 转让方保证所转让商标权属清洁、不侵犯任何第三人知识产权；因权属瑕疵致受让方
   被第三人追索的，转让方承担全部赔偿及合理开支。
```

> 注：N 的具体取值、许可使用费基准，须结合定稿版协议对价与 kdocs 原文确定；本模板为结构骨架，非最终条款。

## 六、法条核验提示（引用前二次核对）

- **民法典第一千一百八十五条**（故意侵害知识产权+情节严重→惩罚性）：现行有效。
- **商标法第六十三条第一款**（恶意侵犯商标专用权，情节严重，1–5倍）：现行有效。
- **法释〔2021〕4号**：正式公布文本**仅 §1–§7**。其中 §1（故意含恶意）/ §3（故意认定因素）/ §5（基数总论·合理开支不计入·参照许可费·法定赔偿不作基数）/ §7（倍数综合裁量·可非整数）。**指南第8–13条系细分重排索引，非真实条号**，引用须以真实条号为准。
- 官方核验：国家法律法规数据库 https://flk.npc.gov.cn/ ＋ 最高人民法院官网 https://www.court.gov.cn/。
