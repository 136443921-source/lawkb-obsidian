# R-HT-101 代理意见写作规范——结论先行·结构递进·格式合规

## 规则表述
1. **标题规范**：须含「案件名称 + 当事人身份 + 哪方代理意见」，便于法官快速识别。
2. **结论先行**：开头用5-6行~小半页提炼核心结论，后文主要观点提前总结；合同类逻辑顺序为「效力→违约→解除→责任承担」。
3. **正文展开**：以「结论 + 事实 + 证据 + 法律依据」为骨架，引用证据标注具体页码，减少情感化表达，杜绝无效铺陈。
4. **格式硬规**：层级序数「一、」「（一）」「1．」「（1）」四级，（一）（1）后不加顿号；首次引法律写全称注简称（加书名号），再审文书禁用「原审」指代具体审级，条文序号用汉字数字。

## 适用场景
民商事诉讼/仲裁代理意见、庭后补充代理意见、答辩意见类文书起草。

## 攻防要点
- 代理意见的判分点在「精准」而非「全面」；三段式（结论先行+证据锚定+逻辑递进）覆盖80%庭审。
- 与 [[R-HT-083 诉讼代理方案三大底层思维与事实重构框架]] 互为表里：先有事实重构，方有精准展开。
- 证据引用必须可核验（「见证据一第X页」），避免「据相关资料显示」式空话。

## 法条依据
《民事诉讼法》文书规范精神；《人民法院民事裁判文书制作规范》法〔2016〕221号；《标点符号用法》GB/T 15834-2011；《出版物上数字用法》GB/T 15835-2011。
