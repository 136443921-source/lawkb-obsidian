# R-LN-094 人民法院案例库工伤行政裁判要旨汇编（工伤篇）

## 一、核心要旨
截至2026-08-22，案例库工伤类共：指导案例4 + 工伤保险资格/待遇认定24 + 给付工伤保险金9 + 行政批复1 + 行政复议4 + 行政非诉强制执行1。高频争点集中在"违法转包责任单位""上下班途中合理时间/路线""平台骑手劳动关系""三工认定""用人单位注销后救济"。

## 二、关键裁判要旨（ distilled ）
1. **违法转包→工伤保险责任单位**（指导案例191号）：建筑企业将工程交自然人实际施工，自然人因工伤亡，社保部门参照《工伤保险行政案件规定》第3条第1款认定承包企业为工伤保险责任单位，法院应予支持。同类：转包给无用工主体资格组织/自然人（含被吊销执照组织）聘用的职工伤亡，用工单位为责任单位（案例2、4）；但**加工承揽关系不适用**，不得泛化（案例13）。
2. **工作原因/场所/过失**（指导案例40号）：工作原因=与本职工作有关联关系；工作场所含多个场所间合理区域；**工作过失不属第16条排除情形（故意犯罪/醉酒吸毒/自残自杀），不影响认定**。
3. **见义勇为视同工伤**（指导案例94号）：制止违法犯罪受伤=第15条第1款第2项"维护公共利益"，视同工伤。
4. **上下班途中（第14条第6项）**：回宿舍收拾行李→乘车→回家整体过程属上下班途中（案例3）；无证据证明职工承担主要责任应认定工伤（案例5、21，单方事故不必然全责）；"合理时间/合理路线"不宜过宽（案例8、18）；家庭地与工作地相隔，节假日往返宿舍→家庭住所地合理路线（案例16）。
5. **平台/骑手劳动关系**：签劳务合同但实质具组织/经济/人格从属性→劳动关系，配送中受伤属工伤（案例6、22）。判断要素：工作时间/工作量自主度、受管理控制度、遵守规则纪律、持续性、定价权。
6. **三工**：快递员送件途中交通事故适用第14条第1项（非第6项，案例10）；串岗为单位利益受伤属工作原因（案例11）；超龄务工农民工作就餐/合理延伸受伤仍适用条例（案例12、19）；冒用他人身份签约不阻却事实劳动关系（案例19）。
7. **用人单位注销后**：仍应受理工伤认定；未缴保险且注销的，可列清算组为被告，或依民法典第56条第1款处理个体户（案例14、23）。
8. **申请期限**：借民事诉讼确定用工单位耽误的时间，不计入申请期限（非职工自身原因，案例17）。
9. **48小时内抢救无效**：连续工作致不适虽未径直送医，48h内死亡应视同工伤（案例20）。

## 三、红队攻击点（用工方/侵权方抗辩）
1. 以"加工承揽"规避工伤保险责任→须审查是否实质违法转包（案例13边界）。
2. 以"非合理时间/路线"否定上下班途中→须举证职工偏离且不合常理（案例18要求严格依法）。
3. 平台以"劳务合同"否定劳动关系→从属性实质审查（案例6、22）。
4. 用人单位注销逃避→仍可追清算组/出资人（民法典56条）。

## 四、蓝队防御要点（受害方）
- 违法转包链条：锁定承包企业→主张其为工伤保险责任单位（指导案例191）。
- 交通事故工伤竞合：人身损害赔偿与工伤待遇可并行（医疗费除外）。
- 申请期限被耽误：保留借民事诉讼确定用工单位的证据，主张非自身原因。

## 五、关联在办案件
- **航合物流贵C09782D事故**：货车司机/行人交通事故致死，涉工伤竞合与违法转包责任单位认定，直接援引指导案例191。
- **王德明担保合同纠纷执行异议**：用工/责任主体抗辩参考。
