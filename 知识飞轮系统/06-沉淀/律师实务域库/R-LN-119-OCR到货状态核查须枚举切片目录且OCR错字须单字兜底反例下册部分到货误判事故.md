# R-LN-119 OCR到货状态核查须枚举切片目录且OCR错字须单字兜底反例下册部分到货误判事故

## 裁判规则（核心教训）

核查「某源文件 / 某册书是否到货、是否完整」时，两道不可跳过的铁律：
1. **枚举全部目录（含按页切片子目录）**：绝不可只看几个"汇总 / OCR全文"txt 就下结论。OCR 工作区常把正本拆成 `pages/`（全册按 PDF 页切片）、`pages_lower/`（下册 / 下半册切片）等子目录，正文主载体在切片里而非在汇总 txt。
2. **OCR 文本检索零命中必做单字兜底**：OCR 错字极普遍（如"证券"→"证劵"/"証券"、"票据"→"粟据"）。精确案由名 grep=0 不等于"段缺失"——必须用单字（证/票/保/信/破/货/托/券）兜底复核，再下"缺失"结论。

违反任一道即构成「源状态误判」，会连锁误导下游（如错判"待回源清单"、把停止理由写错）。

## 事故回放（反例 · 2026-09-23）

- **背景**：案由路由卡每日一拆自动化判定"排期表无 ⬜ → 停止"，并在报告中称"下册部分到货（仅第八部分到货，证券/保险/票据等段缺失）"。
- **误判动作**：① 仅 `grep 下册` 看了 3 个 `下册-XXX-OCR全文.txt` 片段 + 盗版空壳 `下册-OCR全文.txt`（19239 字节 / 0【释义】），**漏查 `pages/`（611 切片）与 `pages_lower/`（271 切片）两个按页切片目录**；② 用精确案由名 `grep pages_lower "证券纠纷"` = 0，未单字兜底即下"第八部分证券段缺失"结论。
- **纠正（用户指正后重查）**：用户指出"下册正文 556–1262 全文已到货"。单字兜底核查 `pages_lower/` → 证107 / 票51 / 保161 / 信23 / 破46 / 货36 / 托21 / 券52 切片，**第八部分全段（证券/期货/信托/保险/票据/破产）正文均在**；第九部分（信用证/独立保函）37 切片；第十部分（侵权责任）有专门文件（28【释义】）。下册八/九/十部分以切片全量到货，用户"全文已到货（556–1262）"成立。
- **根因**：核查范围不全（漏切片目录）＋ 检索方法不鲁棒（未单字兜底受 OCR 错字误导）。
- **实质影响**：此前"22 张方案C留白卡待回源"误判——实际第八部分段（R-AY-299~303 ＋ L2 R-AY-306/307）本书有【释义】且 `pages_lower` 源已到 → 可回源；仅第九部分（R-AY-309~321，法〔2025〕227号新增、本书 2021 无释义）维持诚实模板。

## 操作要点（两铁律落地）

1. **到货核查清单**：`ls -R` / 枚举全目录 → 区分"汇总 txt"与"按页切片子目录"（pages / pages_lower 等）→ 确认各案由段落在哪；不凭"几个片段文件"推断全集。
2. **OCR 检索兜底**：精确命名 grep 命中即采信；**0 命中时必用单字 / 部首兜底**（如"证券"→"证"+"券"分别计数）→ 高计数即证内容在（仅 OCR 错字）；仍 0 才下"缺失"。
3. **下游联动**：源状态变更须同步修正"待回源清单""停止理由"，避免误判沉积（本次已写入自动化记忆 65bf1c80 ＋ 今日工作日志 09-23 修正段）。
