# R-CF-190 慈善组织信息公开义务·改变捐赠用途·无资格募捐的法律责任

## 裁判规则（慈善·信息公开与财产合规）

1. **未依法履行信息公开义务的后果**：慈善组织未依法履行信息公开义务的，由县级以上民政部门责令限期改正、予以警告并没收违法所得；逾期不改正的，责令限期停止活动并进行整改（《慈善法》第110条第1款第（七）项，2023修正）；直接负责的主管人员和其他直接责任人员处二万元以上二十万元以下罚款并没收违法所得，情节严重的禁止其一至五年担任慈善组织管理人员（第112条）。
2. **擅自改变捐赠财产用途的后果**：慈善组织擅自改变捐赠财产用途的，依第110条第1款第（四）项同档处罚（警告+没收违法所得+逾期停活整改）。
3. **无资格擅自公开募捐的后果**：不具有公开募捐资格的组织或个人擅自开展公开募捐的，由民政部门警告、责令停止、退还违法募集财产（无法退还的收缴转其他慈善组织）；情节严重的对组织者处二万元以上二十万元以下罚款（第113条）。
4. **叠加违法与信用惩戒**：同一慈善组织同时违反信息公开、改变用途、无资格募捐多项义务的，可叠加适用上述处罚，并依《社会组织信用信息管理办法》列入活动异常名录或严重违法失信名单（西安市民政局西民罚〔2025〕3号即据此将"西安市蒲公英慈善公益中心"列入异常名录）。

## 法条依据（WebSearch 公开来源回填，待回源）

- 《中华人民共和国慈善法》（2023修正）第13条（年报报送）、第75/77/78条（信息公开义务与平台）、第109-113条（法律责任）。
- 《慈善组织信息公开办法》第3-4条、第13条（基本信息、募捐与项目信息、关联交易信息的公开要求）。
- 依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》：本卡所涉信息公开时限与内容、捐赠财产专款专用、公开募捐资格等，须与手册"信息公开/捐赠管理/公开募捐"章节逐条核对后落地（手册为内部规范摘录，具体条款号待交付前与原文核对）。

## 实务要点（贴合厚德基金会合规服务）

1. **信息公开留痕**：年度工作报告与财务会计报告须按时在"慈善中国"平台公开；发起人、主要捐赠人、管理人员、关联交易情况须主动披露，避免"经责令整改后逾期不改"升级为停活处罚（参照北京好意慈善基金会案）。
2. **捐赠用途刚性**：定向捐赠用途变更须取得捐赠人同意或备案（衔接 R-CF-095），擅自改变用途直接触发第110条第（四）项。
3. **资格红线**：未取得公开募捐资格证书不得在互联网或公开场所募捐；合作募捐须由有资格方开展并三项留痕（衔接 R-CF-189）。
4. **内部合规衔接**：上述三项违法后果与 R-CF-185（关联交易）、R-CF-189（募捐资格）一并纳入年度合规自查清单与信息公开台账。
