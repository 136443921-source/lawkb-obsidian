# R-CF-208 基金会合规指南2024·七章要点（实务规则卡）

> 一句话：《基金会合规指南（2024版）》七章 139 条的结构化审查清单，供合规体检逐项对照。原 wave-2 计划定为「规范要点卡」，复查后源文件为行业指南、无政府文号，改判为实务规则卡。

## 一、规则要旨（正向 · 怎么用）

把 7 章合规指南压缩为"机构合规 + 业务活动合规"两张自查表，季度体检直接勾选。

## 二、审查要点（操作路径，编号步骤）

- **第一章 总则**（基本原则）
- **第二章 合规管理体系**（体系搭建）
- **第三章 机构合规**：资格状态 / 党的建设 / 决策机制 / 人事管理 / 分支（代表）机构
- **第四章 业务活动合规**：预决算 / 收支 / 公益项目 / 投资管理 / 捐赠募捐 / 关联交易 / 涉外活动 / 重大业务活动 / 评比达标表彰（十节，逐项自查）
- **第五章 信息沟通与公开**
- **第六章 监督与改进**
- **第七章 附则**
- **落地动作**：对照第四章十节建自查表，重点查募捐单备、投资合规、关联交易披露、重大事项报告。

## 三、构成要件与举证

合规证据链 = 制度文本 + 决策记录 + 财务凭证 + 信息公开截图。

## 四、法条依据（权威源回填，非凭记忆）

依据《慈善法》《基金会管理条例》及配套规章。✅ **LTI 双证回填（2026-10-07）**：《慈善法》(2023修正) 主席令第16号·施行2024-09-05·现行有效；《基金会管理条例》国务院令第400号·施行2004-06-01·现行有效。两源经文企查查+元典双库核验一致。

## 五、抗辩与但书

指南为非强制参照，但内容对应法定合规义务，违反仍担责。

## 六、翻车标本（负向拦截 · HIR）

- 关联交易未披露 → 处罚；
- 重大业务活动未报告 → 违规；
- 募捐未单备 → 整改。

## 七、来源与地域效力

来源 = 知识库《基金会合规指南2024版》（WebSearch 降级，未核验）。全国通用。
