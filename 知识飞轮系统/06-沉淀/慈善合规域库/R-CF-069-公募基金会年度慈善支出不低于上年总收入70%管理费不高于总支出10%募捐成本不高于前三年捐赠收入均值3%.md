# R-CF-069｜公募基金会年度慈善支出不低于上年总收入70%管理费不高于总支出10%募捐成本不高于前三年捐赠收入均值3%

## 裁判规则

依据民发〔2026〕12号（2026施行，废止民发〔2016〕189号）：公募基金会年度慈善活动支出 ≥ 上年总收入70%、管理费用 ≤ 当年总支出10%（公募社团/社服机构管理费 ≤ 13%）；非公募基金会按上年末净资产分档（≥6000万：支出≥6%、管理费≤12%……<400万：支出≥8%、管理费≤20%）；慈善活动支出以到达最终受益人的款物为准（经合作方转付的在到达前不计入）；年度管理费用低于20万元不受比例限制；募捐成本 ≤ 前三年捐赠收入平均数3%。违反的由民政部门依慈善法第110条第1款第6项处罚并通报财政税务部门。

## 适用范围

- 慈善组织年度支出/管理费用/募捐成本合规审查与整改
- 年检、等级评估、捐赠税前扣除资格维持
- 审计核查（三项指标年度报告披露义务）

## 关联法条

- 民发〔2026〕12号（本规定）
- 《慈善法》第110条
- 《[[法条银行/行政法律规章/民间非营利组织会计制度|民间非营利组织会计制度]]》（业务活动成本/筹资费用核算）

## 实务要点

1. 计算口径：可用前三年平均数替代上年基数；限定性收入扣除与解除时间限定净资产加回
2. 管理费用 < 20万/年豁免比例限制（小型组织重要出路口）
3. 例外情形（登记未满1年等）须报告登记机关+向社会公开说明
4. 慈善活动支出须"主要用于受益人"，发票收据凭证留痕
