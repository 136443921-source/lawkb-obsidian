# R-CF-185 慈善组织关联交易与重大投资信息公开义务及违法责任

## 裁判规则（行政监管口径）

1. **重大关联交易须公开**：慈善组织与关联方发生借款、担保等关联交易及重大资金往来，应当依照《慈善法》《慈善组织信息公开办法》向社会公开；未公开的，登记管理机关可依法处罚（贵州省民政厅2025公告：宏立城公益基金会因"与出资人借款1亿元、4790余万未收回且关联交易未公开"被撤销登记；集善公益慈善联合会因借款关联交易未公开被警告）。
2. **重大资产投资须公开**：慈善财产重大投资行为（如向关联方投资导致慈善财产重大损失）未向社会公开的，依《慈善法》第110条处罚（善道公益基金会因重大投资未公开被停止活动3个月）。
3. **基本信息与关联交易信息须平台公开**：未按规定在"慈善中国"平台公开基金会基本信息、关联交易信息的，登记管理机关可警告并列入活动异常名录（民政部对南都公益基金会等处罚先例）。
4. **违法后果阶梯**：警告 → 停止活动 → 撤销登记，并可视情列入社会组织严重违法失信名单；造成慈善财产重大损失的，关联责任人可被追责乃至移送司法。

## 法条依据（WebSearch 公开处罚回填，待回源）

- 《中华人民共和国慈善法》第110条：慈善组织违反信息公开、关联交易等规定的法律责任（警告、责令停止活动、吊销登记证书等）。
- 《基金会管理条例》第42条：基金会违反财产管理、关联交易、信息公开规定的处罚。
- 《慈善组织信息公开办法》《关于规范基金会行为的若干规定（试行）》：关联方关系及关联交易情况须公布。

## 内规衔接（厚德基金会合规）

- 依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易与信息公开相关章节：基金会开展关联交易须履行决策回避、重大事项披露程序；具体条款号以手册原文为准（本卡交付前须与手册逐条核对，不凭记忆引具体条号）。
- 合规红线：关联交易事前理事会审议 + 利害关系人回避 + 事后信息公开"三步走"，缺一环即触发本卡所述行政责任。

## 实务要点（贴合厚德基金会服务）

1. **交易前**：识别关联方（理事、监事、主要负责人及其近亲属控制的企业），预判是否构成关联交易。
2. **决策中**：关联交易议案关联理事/监事回避表决，会议记录留痕。
3. **公开后**：在"慈善中国"及基金会自有渠道及时、完整公开交易性质、金额、定价依据。
4. **预警**：凡"借款给关联方""重大投资给关联方"一律按本卡最高风险等级管控，避免重蹈宏立城案"撤销登记"结局。
