# R-PI-091 饲养动物致害的无过错责任

## 规则表述

饲养的动物造成他人损害的，动物饲养人或者管理人承担**无过错侵权责任**。但能够证明损害是因被侵权人**故意**造成的，不承担责任；因被侵权人**重大过失**造成的，可以减轻责任。

## 要件

1. 致害主体为"饲养的动物"（非野生动物，除非驯养繁殖参照 1251）；
2. 归责不要求饲养人过错，只问动物 + 损害 + 因果关系（危险责任）；
3. 免责事由：受害人**故意**（如故意挑逗、殴打致动物反击）；
4. 减责事由：受害人**重大过失**（如翻墙入宅被狗咬、明知危险仍靠近）。

## 适用要点（攻防）

- **受害人（攻）**：固定动物特征/是否牵绳/疫苗、伤情与因果证据；一般动物情形下重点反驳"故意"；
- **饲养人（防）**：举证受害人故意（监控挑衅、投喂激怒）→ 免责；或重大过失 → 减责。
