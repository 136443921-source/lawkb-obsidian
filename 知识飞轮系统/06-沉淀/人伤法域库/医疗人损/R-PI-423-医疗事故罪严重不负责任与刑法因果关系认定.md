# R-PI-423 医疗事故罪"严重不负责任"与刑法因果关系认定

## 裁判规则（刑事）

1. **罪名与构成要件**：医务人员由于严重不负责任，造成就诊人死亡或者严重损害就诊人身体健康的，构成医疗事故罪（《刑法》第335条）。核心二要件：①**严重不负责任**（违反医疗卫生管理法律、行政法规、部门规章和诊疗护理规范、常规）；②**刑法意义上的因果关系**（严重不负责任行为与死亡/重伤结果之间具因果关系）。
2. **"严重不负责任"的认定**：指多个诊疗环节违反明确规定的诊疗技术规范，而非一般技术性过失。典型表现：无独立执业资格违规实施手术、无术前评估、术中无进程记录、术后无用药处方及医嘱、患者出现严重不良反应后未及时诊查抢救（最高检医疗美容典型案例要旨）。
3. **因果关系认定**：须结合《法医病理鉴定意见书》《医疗事故鉴定书》、证人证言、被告人供述等综合判断；"严重不负责任"与危害后果之间须具刑法因果关系。辩护方"多重因素/无必然因果关系"抗辩，须由客观鉴定证据反驳（李某某案公诉答辩要旨）。
4. **事故等级与责任程度不影响罪名成立**：一级甲等医疗事故、医方承担主要/完全责任，是量刑与民事赔偿的重要情节，但罪名成立关键在于"严重不负责任 + 因果关系"。

## 法条依据（WebSearch 公开来源回填，待回源）

- 《刑法》第335条：医疗事故罪（严重不负责任，造成就诊人死亡或严重损害就诊人身体健康）。
- 《医疗事故处理条例》《医疗纠纷预防和处理条例》《医疗美容服务管理办法》等：诊疗规范与常规（认定"严重不负责任"的规范依据）。

## 实务要点（贴合韩杰案再审辩护）

1. **技术性过失 vs 严重不负责任**：韩杰案核心争点——漏诊嵌顿性腹股沟斜疝属"医疗技术过失"还是"严重不负责任"？再审辩护应聚焦：是否违反明确诊疗规范（如腹股沟区体格检查、外科会诊的强制性规范），还是仅属经验性判断偏差；后者通常不达"严重不负责任"门槛。
2. **多环节过错与介入因素**：韩杰案存在"交接班后下班 + 家属自驾跨城转院途中恶化"等介入因素；因果关系辩护须论证医疗行为本身是否具"直接、主要"原因力，还是多种因素竞合（参照李某某案"多重因素"抗辩思路，但本案已有医疗事故鉴定+司法鉴定支撑）。
3. **无尸检的因果认定**：韩杰案"无尸检因果认定"为制度争议点，再审应审查医学会鉴定与法医鉴定的论证链条是否充分。
4. **量刑与从业禁止**：已构成犯罪的，可争取量刑情节（自首、赔偿谅解、认罪认罚）；"禁止从事医疗卫生行业"属附加处罚，须审查适用前提。
