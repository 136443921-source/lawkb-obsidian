# R-PI-186｜医疗损害「二元鉴定模式」选择与赔偿标准双轨

## 规则表述

医疗损害纠纷存在**医疗事故鉴定**（医学会）与**医疗损害司法鉴定**（司法鉴定机构）并行的二元模式，且二者分别锁定**《医疗事故处理条例》第50条**与**《人身损害赔偿司法解释》(2022修正)**两套赔偿标准。**选择鉴定模式前必须先确定纠纷解决路径（行政/调解 v. 诉讼）**，路径与鉴定模式互相锁定。

## 二元鉴定对照速记

| | 医疗事故鉴定 | 医疗损害司法鉴定 |
|---|---|---|
| 费用 | **低**（有时免预付） | **高**（患方预付） |
| 公信力 | 待提高 | **高** |
| 覆盖 | 事故+等级；仍需另做伤残/三期 | **一次性**：过错+原因力+伤残+三期 |
| 赔偿依据 | 医疗事故处理条例**50条** | 人损司法解释**2022修正** |

## 核心裁判/实务规则

1. **患方一般应选「诉讼 + 医疗损害司法鉴定」**：条例50条标准通常显著低于人损司法解释。
2. 损害事实两种法定形态：违反知情同意权（民法典**1219条**，例外**1220条**紧急救治）／未尽与当时医疗水平相应诊疗义务（民法典**1221条**）。
3. 过错及过错程度、因果关系及原因力，均须经鉴定确定（鉴定材料须经**质证**）。
4. 医疗事故鉴定由**医学会**组织（专家须受聘于医疗机构/教研机构、任高级技术职务**3年以上**）。

## 适用场景

- 患方医疗损害索赔路径设计（含贵州本地案件）
- 韩杰医疗事故罪再审的刑民交叉民事赔偿线
- 医疗纠纷调解/诉讼咨询
