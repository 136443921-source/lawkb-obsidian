# R-PI-429 机动车交通事故·交强险限额先行赔偿与受害人特殊体质不减责规则

## 裁判规则（人伤·交通事故）

1. **赔偿顺序法定：交强险 → 商业险 → 侵权人**。《民法典》第1213条确定赔偿顺位：机动车发生交通事故造成损害、属于该机动车一方责任的，**先由承保机动车强制保险的保险人在强制保险责任限额范围内予以赔偿**；不足部分，由承保机动车商业保险的保险人依约赔偿；仍不足或没投保商业险的，由侵权人赔偿。《道路交通安全法》第76条同旨，交强险在责任限额内先行赔付。
2. **交强险责任限额标准（2020年9月19日车险综改后）**：有责总责任限额 **20万元**（死亡伤残18万、医疗费用1.8万、财产损失0.2万）；无责总责任限额 **1.99万元**（死亡伤残1.8万、医疗费用1800元、财产损失100元）。限额内不区分过错比例，由保险公司在各分项限额内依法赔付。
3. **受害人特殊体质（如骨质疏松）不减轻侵权人责任（指导案例24号要旨）**：交通事故受害人原有疾病或特殊体质（老年性骨质疏松等）仅是损害发生的客观介入因素，**不属于可以减轻侵权人责任的法定过错**，侵权人应按其过错程度承担全部赔偿责任；"损伤参与度"仅在确定交强险赔付范围之外、涉及受害人自身疾病与损害后果的因果比例时谨慎适用，不得据此削减侵权赔偿。
4. **超出交强险分项限额的处理**：超出交强险各分项限额的损失，依事故责任比例在商业三者险或侵权人之间分担；侵权人未投保商业险的，超出部分由侵权人自行承担。

## 攻防要点

- **受害人（攻）**：先锁定交强险分项限额主张保险优先赔付；对侵权人主张"受害人骨质疏松应减责"的抗辩，援引指导案例24号阻断参与度扣减。
- **侵权人/保险（守）**：在交强险限额内依分项标准核赔；商业险/侵权人责任部分可就事故过错比例、免责条款（如无证、醉驾、逃逸）提出抗辩，但不得以特殊体质为由减责。
