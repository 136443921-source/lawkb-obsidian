# R-PI-093 遗弃、逃逸动物致害的责任归属

## 规则表述

遗弃、逃逸的动物在遗弃、逃逸期间造成他人损害的，由**原动物饲养人或者管理人**承担侵权责任。动物脱离控制期间致害，原主仍负危险责任，以遏制随意弃养并保障受害人救济。

## 要件

1. 动物处于"遗弃"（主动放弃）或"逃逸"（非自愿脱离控制）状态；
2. 致害发生于遗弃/逃逸期间；
3. 责任主体为**原**饲养人或管理人（非现拾得人/临时照料人，除非其构成新的饲养关系）；
4. 归责原则同一般动物无过错（1245 框架），可结合 1249 直接适用。

## 适用要点（攻防）

- **受害人（攻）**：证明动物来源/原主身份（芯片、照片、邻里证言、既往疫苗记录）；
- **原主（防）**：仅能依 1245 的受害人故意免责/重大过失减责抗辩，不得仅以"已遗弃"脱责；现实际管理人若形成新饲养关系则可能并列为共同被告。
