# R-LD-063 上下班途中工伤认定"合理路线 + 合理时间"

## 裁判规则

1. **四要件缺一不可**：认定为工伤须同时具备——①劳动关系；②在合理时间的上下班途中；③非本人主要责任的交通事故（含机动车/非机动车/城市轨道交通/客运轮渡/火车）；④伤害由上述事故导致（《工伤保险条例》第14条第6项 + 最高法工伤保险规定）。
2. **"合理路线"不限于最近路径**：上下班途中指职工在合理时间内，为上下班而往返于住处与工作单位之间的合理路径；路径可有多种选择，既不机械理解为最近路径，也不以用人单位指定路径为唯一路径（最高法公报北京国玉大酒店案要旨）。
3. **"合理时间"含异地提前返岗**：异地工作职工为次日准时上班，提前于假期最后一日从家中出发返回单位宿舍，处于合理时间范围内，应认定"以上班为目的"的合理时间（王志国案要旨）；若苛求当日凌晨出发方构成，既不合生理条件也不符常理。
4. **脱逸"上下班目的"不认定**：职工从单位回宿舍后，再乘车去城区找朋友途中受伤，因已脱离"上下班"目的，不属上下班途中（闫程伟案(2018)最高法行申10337号）。

## 法条依据（WebSearch 公开来源回填，待回源）

- 《工伤保险条例》第14条第6项：上下班途中，受到非本人主要责任的交通事故或者城市轨道交通、客运轮渡、火车事故伤害的，认定为工伤。
- 《最高人民法院关于审理工伤保险行政案件若干问题的规定》第6条：合理时间内往返于工作地与住所地/经常居住地/单位宿舍的合理路线，或从事日常生活所需活动且在合理时间合理路线，社保部门认定为上下班途中的，法院应予支持。

## 实务要点（贴合人伤执业工伤方向）

1. **被告/用人单位抗辩支点**：否认工伤时，须击破四要件之一——尤其"非本人主要责任"（交通事故认定书责任划分）与"合理路线/时间"（是否脱逸上下班目的）。
2. **劳动者举证**：工伤认定申请须提供劳动关系证明、交通事故认定书（非本人主要责任）、上下班路线/时间证据。
3. **合理时间弹性**：异地用工、倒班、节假日调休等特殊工时，合理时间认定具弹性，王志国案为同类情形有利先例。
4. **路线选择自由**：用人单位以"不在指定路线"否认工伤的，法院不予支持（北京国玉大酒店案）。
