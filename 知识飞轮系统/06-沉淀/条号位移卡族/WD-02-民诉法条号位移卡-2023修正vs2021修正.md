# 民诉法条号位移卡·2023修正 vs 2021修正

> 定位：条号位移地图（旧→新），与 LTI 缓存互补。本卡只给位移。

## 一、速览

- 旧法：民事诉讼法(2021修正)，共 **291** 条
- 新法：民事诉讼法(2023修正)，共 **291** 条（条文总数未变，但涉外编整体后移、新增 11 条 + 指定遗产管理人节）
- 施行：2024-01-01（修改决定）
- 位移性质：**国内编多数同号，涉外编集体后移 + 新增第十五章第四节「指定遗产管理人案件」（第194-197条）**。

## 四、同号修改·最易踩坑（号未移但内容已变）

| 条号 | 修改要点 |
|---|---|
| 第40条 | 独任制扩张：基层法院基本事实清楚、权利义务明确的第一审，可独任审理普通程序 |
| 第47条第四款 | 回避适用对象扩至法官助理、书记员、司法技术人员、翻译、鉴定人、勘验人 |
| 第115条 | 虚假诉讼扩至「单方捏造基本事实」提起诉讼 |
| 第130条第二款 | 应诉管辖新增「但违反级别管辖和专属管辖除外」 |
| 第140条第二款 | 开庭核对新增「法官助理、书记员等名单」 |
| 第184条 | 特别程序增列「指定遗产管理人案件」 |

> ⚠️ 这些条号「看上去没变」，但正文已改。引用 2021 版第40/115/130条内容于 2024-01-01 后案件，须用新正文（LTI 缓存应已为新版）。

## 五、过渡期适用要点

- 见 **WD-04**。程序法一般从新：2024-01-01 起未审结案件适用新法；但已生效裁判的再审、已确定的程序事项不当然回头适用。

## 六、主题核对提醒

1. 涉外案件：先确认援引的是否为「涉外编」位移后条号（如管辖已从 272→276）。
2. 虚假诉讼：第115条已含单方捏造，勿仅按旧「恶意串通」理解。
3. 独任制：第40条普通程序独任须「基本事实清楚、权利义务明确」。
4. 指定遗产管理人：旧法无此特别程序，勿援引旧特别程序章。
