# 慈善法条号位移卡·2023修正 vs 2016版

> 定位：条号位移地图（旧→新），与 LTI 缓存互补。

## 一、速览

- 旧法：慈善法(2016)，共 **112** 条（12章）
- 新法：慈善法(2023修正)，共 **125** 条（13章，新增第八章「应急慈善」）
- 施行：2024-09-05（修改决定）
- 位移性质：**第八章应急慈善整体插入，致后续章节大规模后移；另有多条因内容扩充后移（募捐/监管/法律责任章）**。

## 四、同号修改·最易踩坑（号未移但内容已变）

| 条号 | 修改要点 |
|---|---|
| 第4条 | 增加第一款「慈善工作坚持中国共产党的领导」 |
| 第6条 | 民政部门主管+业务主管单位监督表述调整 |
| 第10条第二款 | 认定时限 20 日（原未单列） |
| 第13条 | 年度报告增「募捐成本/与境外合作」 |
| 第22条 | 公募资格「依法登记满一年」 |
| 第26条 | 合作募捐「评估+全部收支纳入账户」 |

> ⚠️ 第101条是重灾区：旧第101条（募捐违法/平台责任）已拆为**新第112、113、114条**，而新第101条是**全新的「信用记录」条款**。引用「第101条」务必分清新旧。

## 五、基金会高频提示（老强·厚德基金会场景）

- 互联网募捐：旧23③→新27（平台义务，法宝核填✅）。
- 年度支出/管理费/募捐成本：旧60→新61（新增「募捐成本」单独计，法宝核填✅）。
- 信息公开：旧73→新79（时限）；旧69→新75（统一平台）。
- 监管措施：旧93→新104（可查金融账户）；旧95→新106（信用/评估）。
- 公募资格/合作募捐：同号（22/26）但内容收紧，须用新正文。

## 六、过渡期适用要点

- 见 **WD-04**。2024-09-05 起施行；此前已开展的慈善活动按「法不溯及既往」处理，但持续性的信息公开/年度支出折算等衔接依主管部门口径。

## 七、主题核对提醒

1. 引用慈善法条号前，先确认是 2016 版还是 2023 修正版（尤其 23/60/69/73/77/84/87/92/93/95/98/101/105/107 等已位移条）。
2. 第101条新旧完全不同，严禁混淆。
3. 应急慈善（新71-74）为全新制度，旧法无，旧案无援引基础。
4. 正式文书：法宝复核位移 + LTI 回填正文。
