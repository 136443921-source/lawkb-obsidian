# OPC 子科室新增标准路径（经验卡）

> **一句话结论**：任何 OPC 四大中台（业务/数字资产/运营/可视化）下属「子科室」治理实体化，走同一模板——可行性评估 → 老强四项裁决 → 阶段0 四件套文档落地 → 独立 PROJ → 双目录同步 → 实战流程 Skill 固化。**零章程改动、不增编、权属顺**。
> 来源：模拟法庭科室（2026-09-23 评估 / 2026-09-24 阶段0 闭环）实战提炼，并复用法条银行科室（数字资产中台）同构范式。

---

## 一、适用场景

- 在既有中台下新增**职能子科室**（仿「法条银行科室」「模拟法庭科室」B 形态）
- **不**新建平行中台（守章程 §1 四部门裁决）、**不**新增智能体（编制维持 10 岗）
- 需要"治理实体化"但**不碰系统配置**（纯文档层）

---

## 二、标准路径（六步模板）

1. **可行性评估**：对标已落地的同构科室，写评估稿（现状盘点 / 同构对照 / 裁决项 / 红线接口 / 阶段0路线 / 待决项）；§6 全部 `[x] 已定` 后再进阶段0。
2. **老强四项裁决**（须拍板，AI 不代决）：
   - 落点：子科室 or 平行中台
   - 负责人：兼任 or 新建智能体
   - 跨域岗归属：实线收编 or 中台保留 + 虚线借调
   - 隔离口径：单元不拆解 or 可拆补别岗
3. **阶段0 四件套文档落地**（纯文档）：
   - 部门规章制度：职责表增行 + 子章节（成员**三态归属表**：实线 / 虚线 / 中台共享）
   - 新建科室治理 SOP（链接式：成员归属 + 标准步骤 + 质量门禁）
   - 岗位手册：速览表 + 相关岗章节增"子科室角色"段
   - persona：相关智能体增"内部治理角色"心智段（两顶帽子，不改原红线）
4. **独立 PROJ**：`PROJ-<科室>.md` 独立成册（治理定位 / 三态归属 / 职责边界 / 红线咬合 / 决策溯源 / 遗留闭环），**不并入训练备忘录**。
5. **双目录同步**：workspace 工作态 → 中枢 `09-OPC`，md5 零残留校验。
6. **Skill 固化**：把该路径踩过的坑 / 铁律固化进复用 Skill（如 `红蓝复核批量修正工作流`）。

---

## 三、关键纪律（铁律）

- **四类 R 仅老强决策**：对外出件 / 定价发布 / 批量删改 / 新增改造，AI 不代决。
- **单元不拆解**：核心岗不被拆散补别岗，保留跨域共享资产价值（如模拟法官 98 分共享资产）。
- **消歧红线**：实体裁判岗 ≠ 程序质控岗（类 `RULE-QCJUDGE-DISAMBIG`），质量闸门**只闸程序不闸裁判**。
- **双目录同步不能靠 exit code 判断**：必须**显式 md5 校验零残留**（沙箱会静默拦截写卷）。
- **链接式不重写**：SOP 只写"何时调 / 谁调 / 落哪 / 门禁"，流程正文引源不漂移。

---

## 四、踩坑实录（必读）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **沙箱静默拦截写卷** | 写 Documents/LawKB 卷 `cp` 报 `exit=0` 但磁盘未变、md5 仍 DIFF | 用 `dangerouslyDisableSandbox` 跑 cp；回写后**必显式 md5 校验**再 claim 完成 |
| **Edit 静默失效** | 含中文标点长行报 success 但磁盘未变 | 改用 Python `s.replace` + `assert count==1`，绝不部分写入 |
| **版本记录漏行** | 新建/修改治理文件后版本变更记录易漏 v1.x 行 | 改完同步补版本行，再回写中枢 |
| **引用 dangling** | PROJ 并入训练备忘录导致检索分散 | 独立成册 + SOP/索引/训练备忘录三处指针统一 |

## 五、实例（已验证）

- **模拟法庭科室**（业务中台）：2026-09-23 评估 / 2026-09-24 阶段0 闭环。AI 模拟法官兼庭长、QC 中台保留 + 虚线借调、庭审战情室中台共享。产出：部门规章制度 v1.1 + SOP-BUS-04 + 岗位手册 v1.1 + PROJ-模拟法庭科室 v1.0；固化 `红蓝复核批量修正工作流` v1.1.0。
- **法条银行科室**（数字资产中台，前例）：行长心智模型，SOP-AST-08 科室 CRUD 治理。
- **（待回填）第二个子科室实例**：本六步模板目前仅经模拟法庭科室（实例1）端到端验证，法条银行科室为同构前例参考，**尚无第二个真实端到端实例**。待业务中台/其他中台**真正新增第二个子科室**时，回填至此作为实例2，并校验六步模板是否站得住——重点复验「老强四项裁决」口径与「双目录同步」md5 零残留铁律；若有偏差在此修正后再升 `version`。（占位 · 非真实例 · 不凭记忆预填）
