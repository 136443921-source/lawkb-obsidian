# 审判要件卡·保险合同：保险人代位求偿举证责任分配

> **rule_id**：R-HT-303　**card_type**：审判要件卡　**领域**：合同风险（保险）
> **来源**：《贵州法院类案审判要件指南（第二卷）》保险代位求偿节；《中华人民共和国保险法》第60/61/63条

> ⚠️ 本卡输出**候选推理（【候选·待人工确认】）**，非自动裁判。（铁律 R2：审判要件卡输出候选推理，非自动裁判）

## 一、裁判规则（正向·该怎么判）

一、保险人依保险法第60条行使代位求偿权，须对以下要件承担举证责任：
（一）第三者对保险标的实施了损害（侵权或违约），且该损害与保险事故之间具有因果关系；
（二）保险人已向被保险人赔偿保险金——赔付事实是代位权取得的前提，亦界定代位范围上限；
（三）代位请求金额在保险人赔偿金额范围内。

二、被保险人对代位权成立本身无举证责任；但其依保险法第61条，未经保险人同意不得放弃对第三者的赔偿请求权（弃权害及代位，保险人可相应扣减或拒赔）；依第63条，保险人代位时应向保险人提供必要的文件和所知的有关情况（协助义务）。

三、第三者（被告）得以"损害非其造成 / 保险标的非财产性（人身险不代位，见 R-HT-217）/ 赔付事实不成立 / 代位超赔偿范围 / 被保险人已先从第三者获赔（第60条2款扣减）"抗辩。

## 二、审查要点（审理思路）

1. 先审代位权成立前提：赔付事实 + 财产性标的（排除人身险）。
2. 再审第三者损害要件：保险人举证损害事实与因果关系。
3. 再审代位范围：是否超出赔偿金额。
4. 审查被保险人有无损害代位权的行为（弃权 / 不实协助）。

## 三、构成要件与举证（核心·举证分配）

要件：第三者损害事实 + 因果关系 + 保险人已赔付 + 代位金额 ≤ 赔偿金额。

举证分配：
- **保险人（代位权行使方）**：对"第三者损害事实 + 因果关系""已赔付""代位金额"三项负举证责任。
- **被保险人**：不负代位成立举证责任；负协助义务（第63条）与不得弃权义务（第61条）。
- **第三者（被告）**：对免责 / 扣减 / 超范围等抗辩事实负举证责任。

## 四、法条依据（statute_text_pending·待 qcc-legal 逐字核填·现行有效）

**《中华人民共和国保险法(2015修正)》第六十条**（statute_text_pending：本地无 verbatim，待 qcc-legal / 华宇元典逐字核填）

> （占位·待核填）因第三者对保险标的的损害而造成保险事故的，保险人自向被保险人赔偿保险金之日起，在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利。前款规定的保险事故发生后，被保险人已经从第三者取得损害赔偿的，保险人赔偿保险金时，可以相应扣减被保险人从第三者已取得的赔偿金额。保险人依照本条第一款规定行使代位请求赔偿的权利，不影响被保险人就未取得赔偿的部分向第三者请求赔偿的权利。

**《中华人民共和国保险法(2015修正)》第六十一条**（statute_text_pending：待核填）

> （占位·待核填）保险事故发生后，保险人未赔偿保险金之前，被保险人放弃对第三者请求赔偿的权利的，保险人不承担赔偿保险金的责任。保险人向被保险人赔偿保险金后，被保险人未经保险人同意放弃对第三者请求赔偿权利的，该行为无效……

**《中华人民共和国保险法(2015修正)》第六十三条**（statute_text_pending：待核填）

> （占位·待核填）保险人代位行使被保险人对第三者请求赔偿的权利时，被保险人应当向保险人提供必要的文件和其所知道的有关情况。

## 五、抗辩与但书

- 人身险（含意外/健康）不代位（R-HT-217），第三者以此抗辩成立。
- 被保险人已先从第三者获赔部分，保险人可相应扣减（第60条2款）。
- 被保险人弃权害及代位（第61条），保险人可拒赔对应部分；但保险人赔偿后未经同意的弃权无效。

## 六、翻车标本（负向拦截·HIR）

- 保险人未证"已赔付"即主张代位 → 代位权未成立。
- 把人身意外险纳入代位范围（与 R-HT-217 冲突）。
- 忽视被保险人协助义务（第63条），未要求其提供第三者资料，致代位不能行使。
