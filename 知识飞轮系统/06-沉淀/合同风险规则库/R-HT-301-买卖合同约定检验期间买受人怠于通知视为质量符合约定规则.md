# R-HT-301 买卖合同约定检验期间·买受人怠于通知视为质量符合约定

## 裁判规则（合同·买卖质量异议）

1. **约定检验期间优先**：买卖合同当事人约定检验期限的，买受人应当在检验期限内将标的物数量或质量不符合约定的情形通知出卖人；买受人怠于通知的，视为标的物的数量、质量符合约定（《民法典》第621条第1款；对应原《合同法》第158条第1款）。
2. **检验期间解决"交付时是否存在瑕疵"**：检验期间与质量保证期分属不同概念——检验期间解决交付时是否存在瑕疵，质保期解决正常使用期限内的瑕疵；当事人约定检验期间的，不适用质保期或二年合理期间的规定（人民法院案例库 2024-16-2-084-001，最高法(2021)最高法民申2163号，某电池公司诉某汽车公司案）。
3. **检验期限过短仅及外观瑕疵**：当事人约定的检验期限过短，依标的物性质与交易习惯买受人在该期限内难以完成全面检验的，该期限仅视为对标的物外观瑕疵提出异议的期限；约定的检验期或质保期短于法定期间的，以法定期间为准（《民法典》第622条）。
4. **隐蔽瑕疵不受当场验收约束**：买受人主张检验期过短仅适用于外观瑕疵的，须举证证明标的物性质、交易习惯确致无法在期内完成全面检验，且应在合理期限内针对隐蔽瑕疵提出异议；大型设备买受人自行拟定合同、未举证期内提异议亦未证明确有隐蔽质量的，30日检验期主张不成立（辽源(2025)吉04民终170号）。

## 法条依据（WebSearch 公开来源回填，待回源）

- 《中华人民共和国民法典》第620条（约定/及时检验义务）、第621条（检验期限与怠于通知视为合格）、第622条（检验期过短仅及外观瑕疵）。
- 人民法院案例库入库编号 2024-16-2-084-001（某电池公司诉某汽车公司买卖合同纠纷，最高法(2021)最高法民申2163号）。

## 实务要点（贴合在办买卖合同抗辩）

1. **出卖人抗辩锚点**：合同已约定检验期且买受人期内未提异议 → 直接援引第621条第1款"视为符合约定"，阻断买受人质量瑕疵索赔。
2. **买受人破局路径**：异议超期时须转向第622条"检验期过短仅及外观瑕疵" + 举证隐蔽瑕疵（如家电压缩机出厂密封缺陷）在收货时无法肉眼察觉，且在发现后及时报修、检测、减损。
3. **格式条款风险**：买受人自行拟定超短检验期且未提示说明的，法院可能结合交易性质、标的物种类认定不合理；出卖人拟定方亦须避免"霸王条款"被否定。
