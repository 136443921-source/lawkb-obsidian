# R-CF-084 贵州省慈善条例红线清单（2024.9.5施行）

## 规则表述
1. **9项制度强制**：慈善组织须建内部治理、会计核算、公开/定向募捐、捐赠、财产管理使用（含关联交易/重大投资/专项基金/剩余资产）、项目管理、档案、信息公开、年度工作报告等9领域制度（第10条）。
2. **[[公开募捐资格|公开募捐资格]]**：须取得资格并备案；互联网募捐须在国务院民政部门指定平台；合作募捐全部收支纳入有资格组织账户统一核算（第13-15条）。
3. **定向募捐禁变相公开**：限于特定对象，说明目的/用途/管理费用/起止时间，不得变相公开募捐（第17条）。
4. **个人求助边界**：须对真实性负责、指定平台发布、合理上限、超额/目的实现须退或转赠慈善组织并公开（第19条）。
5. **信息一致义务**：慈善组织须在统一慈善信息管理平台发信息，各渠道须一致，不得以新闻/广告代替信息公开（第26条）。

## 适用场景
贵州慈善组织合规体检、公开/定向募捐方案审查、个人求助转发审核、民政监管应对。

## 攻防要点
- 《条例》将《慈善法》「应当」在省级具体化，是贵州慈善合规的红线清单。
- 办案涉基金会公开募捐资格、定向捐赠变更、个人求助转发，优先引第10/15/17/19/26条，并对应《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》条款出具意见。
- 第26条「三端信息一致」是高频处罚诱因（IMA知识库/公众号/民政平台）。

## 法条依据
《贵州省慈善条例》（2024.7.31通过，2024.9.5施行）第9/10/13-15/17-20/26/33-34条；《[[中华人民共和国慈善法|中华人民共和国慈善法]]》。
