## 二、五层语义分工：每种卡回答什么问题

这是理解全库最关键的一张表。**卡型之间的区别不是"领域不同"，而是"推理方向不同"。**

| 层 | 卡型 | 回答的问题 | 推理方向 | 触发时机 |
|---|---|---|---|---|
| **L1 负向拦截** | 要件映射卡 | 「引用错了吗？」 | 负向（涵摄断裂检测） | 文书生成**后**校验 |
| **L2 正向裁判** | 审判要件卡 | 「该怎么判？」 | 正向（审理思路→结论） | 庭审推演**中** |
| | 裁量尺度卡 | 「数额/比例/倍数怎么酌定？」 | 量化正向 | 数额预判 |
| | 通用裁判规则卡 | 「这条规则是什么？」 | 规则本体沉淀 | 通用检索 |
| | 实务规则卡 | 「具体怎么操作？」 | 正向操作路径 | 文书生成 |
| **L3 正向定量** | 赔偿计算卡 | 「该算多少钱？」 | 正向定量（公式→基数→顺位→扣减） | 赔偿清单/精算/调解 |
| **L4 路由导航** | 案由路由卡 | 「该定什么案由？」 | 横向路由 | 立案/答辩/管辖异议 |
| | 条号位移卡族 | 「条文在新旧法第几条？」 | 正向导航 | 引用前核对 |
| **L5 规格范式** | 文书范式卡 | 「该怎么写文书？」 | 正向规格 | 起草/复核前 |
| | 庭审主持卡 | 「该怎么主持庭审？」 | 正向主持（动作+话术） | 庭审推演主持时 |
| **专项** | 证据规则卡 | 「谁来举证/怎么质证？」 | 举证分配 + 攻防 | 证据审查质证 |
| | 请求权基础卡 | 「请求权基础怎么搭/竞合怎么选？」 | 鉴定式三分（竞合/聚合/不真正连带） | 起诉状起草/救济设计 |
| | 类案检索报告卡 | 「有没有类似判例？」 | 判例类比 | 类案检索/代理词 |
| | 合规审查卡 | 「合不合规？」 | 合规判断 | 慈善组织合规审查 |

### 2.1 最容易踩的三组混淆（务必区分）

| 易混组 | 关键区别 |
|---|---|
| **审判要件卡 vs 要件映射卡** | 前者**正向裁判**（该怎么判），后者**负向拦截**（引错没）。物理隔离、双轨并行，不可互相替代 |
| **审判要件卡 vs 裁量尺度卡** | 前者定性+裁判结论，后者只补**数值锚点**（违约金 30%、惩罚性赔偿倍数、精神损害等级区间） |
| **通用裁判规则卡 vs 审判要件卡** | **两代卡片**：通用型是 2026-07/08 第一代（结构自由、无 `geo_scope`/`library`、七段式仅 7%）；审判要件卡是 2026-09 第二代（七/八段式、带地域效力标记） |

## 四、重点：添加了心智模型的智能体

### 4.1 核心命题：卡片是弹药，心智模型是枪

| 组合 | 状态 | 后果 |
|---|---|---|
| 有卡库 + **无**心智 | 有弹无枪 | 卡库堆着没人会调用，智能体仍凭通用知识裸判 |
| 有心智 + **无**卡库 | 有枪无弹 | 人设到位但输出无卡源可回溯，仍是幻觉风险区 |
| **心智 + 卡库接线** | ✅ 目标态 | **可回溯卡源的规则裁判** |

### 4.3 心智模型给智能体带来的四项增量

1. **人格稳定性**：从「每次提问重新生成人设」变为「读固定 persona 卡」，跨会话行为一致（红队始终残酷攻击、书记员始终中立不裁判）。
2. **取卡纪律内化**：persona 接驳章写死「取哪个库的哪个字段」——如红队只取 `negative_note`/`ruling.reject`/`elements` 作弹药，蓝队取 `ruling.support` 作防御。**没有这层约束，智能体面对 1892 张卡会随机抓取。**
3. **强度可分级可回归**：红队 persona 含 **L1–L4 强度档位 + 三套维度权重**，庭审战情室可据档位评估对抗强度；R-PR-061 含 **51 项断言可回归 eval**，使心智可量化评测而非主观感受。
4. **成熟度可追踪**：`clerk_maturity.py` 等脚本按 D1–D5/10 维评分卡自动打分，形成成长曲线（红队 56→63 有据可查）。
