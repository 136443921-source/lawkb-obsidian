# 元典主法律条目不返回 doc_no，仅「修改决定/修正案」子条目返回文号

## 规则陈述（一句话）
用华宇元典 `yuandian_search_laws_and_regulations` 核验法条卡时，**法律/法规的主条目（如「中华人民共和国律师法(2026修正)」「中华人民共和国刑法(2023修正)」）通常不返回 `document_number` 字段；真正带文号的，是与其关联的「修改决定」「修正案」子条目（如「关于修改《XX法》的决定」=主席令第84号、刑法修正案(十二)=主席令第18号）——而这些子条目是另一部独立法规（不同 regulation_id）。**

## 实证（2026-10-06 重查元典确认）
- **律师法(2026修正)**：regulation_id `4fb9fa94348e23738c73e6c903e9fb1e` 对上元典主条目，**无 document_number**；其「修改决定」子条目（id `b09f24969f54343f2a83c3432d9a288e`）带 `document_number=中华人民共和国主席令第84号`，但属不同 regulation。
- **刑法(2023修正)**：regulation_id `aecabfbe6b0843642509a7f1ff865413` 对上元典主条目，**无 document_number**；带文号的是修正案(十二)=主席令第18号、修正案(十一)=主席令第66号等独立子条目。
- **行业/团体规范**（如法医临床检验规范 SF/T 0111—2021）：元典亦不提供 document_number。
- **贵州高院等地方司法文件**：元典未收录 → 同样无 doc_no。

## 由此推出：7 张卡 `yuandian_doc_no` 为空 ≠ 漏填
法条银行 100 张已核验卡中，7 张 `yuandian_doc_no` 为空（律师法 / 刑法节选 / 法医 / 4 张贵州高院本地文件）。经重查确认**全部是元典确实未返回**，空值如实反映元典数据，**维持空值即正确**。

## ⚠️ 防坑要点（本规则核心价值）
- **禁止为「补全」而把卡体 `doc_no` 填入 `yuandian_doc_no`**：`yuandian_*` 字段的语义是「元典实际返回的值」，不是「卡体值」。强行填入 = 伪造元典返回值 = 转录错误（正是深层 QC 要查的问题）。
- 若元典主条目确实无 doc_no，正确处置：① `yuandian_doc_no` 留空；② 在 `yuandian_verify_note` 注明「元典该条目未返回 document_number，空值属实（非漏填）」，使空值自证、避免被误判为缺失。
- doc_no 比对做 QC 时，须先归一化（去「中华人民共和国」前缀、方括号→〔〕、中文数字→阿拉伯、去尾部括号备注）再比，否则会把同号不同写法误判为不一致（首版脚本曾因此误报 26 处假阳性）。

## 适用范围
- 法条银行 / 任何用华宇元典 MCP 回填 `yuandian_*` 字段的场景。
- 反向也成立：若某卡 `yuandian_doc_no` 有值，应来自元典主条目或关联子条目的 `document_number`，而非卡体 doc_no 的照抄。
