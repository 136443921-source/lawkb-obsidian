# 裁判规则 R021 - 违法分包/转包，具备用工资格的发包方承担工伤主体责任

**规范来源**：《关于执行〈工伤保险条例〉若干问题的意见（三）》人社部发〔2025〕62号第10条；《最高人民法院关于审理工伤保险行政案件若干问题的规定》（法释〔2014〕9号）第3条
**审理法院**：各级法院普遍规则
**裁判要旨**：具备用工主体资格的单位违法将承包业务**转包、分包**给不具备用工主体资格的组织或自然人，该组织或自然人招用的劳动者因工伤亡的，**即使双方不存在劳动关系**，具备用工主体资格的发包单位仍应承担**工伤保险责任**。
**适用要点**：
1. 三类情形均适用：违法发包/转包/分包；个人挂靠经营招用人员伤亡；法规规定的其他情形。
2. **突破劳动关系要件**：不以认定劳动关系为前提，直接确认工伤主体责任，保护实际施工人员。
3. 用人单位未依法参保的，工伤待遇由该责任单位**全额承担**。
4. 与民事侵权竞合时，医疗费不重复，其余可双重救济。
**关联法条**：《工伤保险条例》第14、43、62条
