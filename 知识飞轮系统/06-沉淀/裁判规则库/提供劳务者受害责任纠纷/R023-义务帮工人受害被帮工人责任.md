# 裁判规则 R023 - 义务帮工人受害，被帮工人原则上承担赔偿责任

**规范来源**：《民法典》第1192条（劳务关系一般规则）及原《人身损害赔偿解释》帮工规则沿革
**审理法院**：各级法院普遍规则
**裁判要旨**：为他人**无偿提供劳务（义务帮工）**的帮工人，在帮工活动中因第三人侵权或自身以外原因受到损害的，被帮工人**应当承担赔偿/补偿责任**；帮工人对损害的发生有故意或重大过失的，可减轻被帮工人责任；被帮工人明确拒绝帮工的除外。
**适用要点**：
1. 义务帮工的本质是无偿劳务，受害救济向被帮工人（受益方）倾斜。
2. 帮工人存在**故意或重大过失**的，相应减轻被帮工人责任。
3. **被帮工人明确拒绝帮工**的，不承担责任，但可在受益范围内适当补偿。
4. 第三人侵权的，帮工人可请求第三人赔偿，也可请求被帮工人补偿，补偿后向第三人追偿。
**关联法条**：《民法典》第1192条、第1165条
