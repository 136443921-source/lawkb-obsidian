# 裁判规则 R022 - 个人之间形成劳务关系，受害按双方过错分担

**规范来源**：《民法典》第1192条第1款
**审理法院**：各级法院普遍规则
**裁判要旨**：个人之间形成劳务关系，提供劳务一方因劳务受到损害的，根据**双方各自的过错**承担相应的责任。提供劳务一方因第三人行为受损的，可请求第三人赔偿，也可请求接受劳务一方补偿，接受劳务一方补偿后有权向第三人追偿。
**适用要点**：
1. 区别于用人单位用工（第1191条无过错替代责任），个人劳务采**过错分担**（比例责任）。
2. 接受劳务方是否尽到必要安全注意、提供劳务方是否有操作不当，均影响过错比例。
3. 第三人侵权时形成"补偿 + 追偿"链条，受害人可选择救济路径。
4. 与"提供劳务致他人损害"（第1192条第2款，接受劳务方对外担责）区分适用。
**关联法条**：《民法典》第1191条（用人单位责任）、第1179条（赔偿项目）
