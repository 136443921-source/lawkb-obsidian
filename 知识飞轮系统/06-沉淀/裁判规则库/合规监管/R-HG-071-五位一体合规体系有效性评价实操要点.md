# 五位一体合规体系有效性评价实操要点

## 一、核心命题
2026年央企合规收官年，最大风险不是"没建体系"，而是"建了体系但无效"。体系建成只是及格线，**体系有效才是通关线**。国资委督导、巡视、审计判定"体系运行无效"的典型情形：业务不执行合规流程、风险清单与业务两张皮、审查流于形式、无运行痕迹、无整改闭环。

## 二、纸面合规四大典型特征（高频扣分点）
1. **制度静态化**：多年不更新、不匹配最新监管、不贴合业务。
2. **清单模板化**：照搬集团/外网模板，无本土化裁剪、无子企业穿透。
3. **流程形式化**：合规审查后置、先决策后补流程、重大事项未刚性前置。
4. **责任悬空化**：考核不挂钩、追责不落地、业务部门无合规压力。

## 三、有效性评价五大维度（对标国资委验收+标杆实践）
| 维度 | 验收要点 |
| -- | -- |
| 制度完备性 | 4个核心制度齐全，重点领域专项制度全覆盖，每年至少1次评估修订 |
| 责任穿透性 | 三级责任体系、部门配齐兼职合规管理员、首席合规官履职、子企业穿透 |
| 流程嵌入性 | 重大决策/大额合同/重大项目100%前置审查，审查留痕完整，否决事项真实落地 |
| 风险可控性 | 年度全面风险识别评估，红黄橙三级分级，重大风险有预案 |
| 闭环改进性 | 年度合规专项审计、体系自评、问题台账齐全，发现问题有整改、复核、销号 |

## 四、体系有效性自评四步流程
1. **资料对标排查**（查"有没有"）：对照五位一体框架逐项核对组织、制度、清单、机制、保障、考核、追责台账。
2. **业务穿透抽查**（查"用没用"）：随机抽查投资/合同/采购/项目/资金真实单据，核查是否前置审查、流程完整、真实落地。
3. **问题归因打分**（查"好不好"）：缺陷归类——制度/流程/责任/人员/机制问题。
4. **整改闭环迭代**（查"改没改"）：问题清单→整改清单→责任清单→销号清单。

## 五、最易被判定纸面合规的六大高频问题
1. 审查全通过、零否决、零退回（形式化审查）；
2. 风险全部高风险、无分级无重点（管控失效）；
3. 子企业完全复用总部模板（未穿透）；
4. 全年无风险事件、无预警、无自查问题（流于形式）；
5. 培训台账齐全但业务人员不懂红线（培训无效）；
6. 考核占比达标但从未实际扣分挂钩薪酬（考核悬空）。

## 六、实践底线
真正有效的五位一体体系唯一标准：**制度用得上、流程跑得通、风险管得住、责任落得下、问题改得掉**。
