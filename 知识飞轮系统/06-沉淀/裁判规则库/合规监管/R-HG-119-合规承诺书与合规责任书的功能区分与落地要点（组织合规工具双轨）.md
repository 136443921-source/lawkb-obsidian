# R-HG-119 合规承诺书与合规责任书的功能区分与落地要点（组织合规工具双轨）

> 来源：IMA「合规与政府监管AI助手」库《合规实务 |《合规承诺书》与《合规责任书》》（法律教练，2025-12-17）。B 阶段回补摄入（2026-10-26 通道恢复后补齐 10-26 漏跑）。

## 一、规则要旨：两份文件、两种功能，不可互相替代

| | 《合规承诺书》 | 《合规责任书》 |
|---|---|---|
| **签署主体** | **全员**（逐人签署） | **企业负责人 + 部门负责人**（甲乙双方，上级对下级） |
| **功能定位** | 提升全员合规意识的**方式/仪式/工具** | 直接给负责人、部门负责人**划定合规责任**，强化中高层干部合规意识 |
| **核心内容** | 个人七项承诺（见下） | 六项责任内容 + 考核周期 + 考核与奖惩 |
| **考核挂钩** | 无 | 有：依据《合规管理规定》《合规手册》进行**年度考核** |
| **适用定位** | 全员合规文化渗透 | 中高管合规责任落实 |

**源文立场**：**仪式与意识同样重要，能够相互促进、相互转化**。"搞形式并非搞形式主义"——编制合规手册、召开合规大会、签署合规承诺书、拍摄合规宣传片，都是有效形式；**形式是意识的载体，意识需通过形式固化**。

🔴 **关键区分**：承诺书解决"**知不知道自己该守什么**"，责任书解决"**出了问题谁负责、考核谁**"。二者缺一则体系悬空——只有承诺书而无责任书，无人真正担责；只有责任书而无承诺书，责任书沦为签署仪式而员工无感。

## 二、《合规承诺书》七项承诺（源文全文结构）

签署前提：**本人已仔细阅读并理解《公司合规手册》全部内容**，清楚公司合规管理相关要求。郑重承诺：

1. 认同公司合规管理理念，积极履行合规义务；
2. 遵守法律法规、监管规定、行业准则以及国际条约、规则等要求；
3. 全面了解并遵守公司章程、规章制度，严守工作纪律，依规履责；
4. 遵守社会公德、公共秩序，尊重不同风俗习惯，维护公司社会形象；
5. 积极主动接受合规培训，增强合规意识；
6. 宣扬公司合规文化，鼓励、支持、引导其他相关人员遵守公司合规管理规定；
7. 拒绝违规履职行为，**主动举报违规行为**。

> 落款：本人签字 + 年月日。

**要点**：第7项"主动举报违规行为"与第6项"宣扬合规文化"构成**双向机制**（既向下传递又向上反馈），是承诺书区别于普通员工手册签收的核心价值——签署后即产生**举报义务**，可能反向影响员工行为（提示：企业须配套举报渠道与反报复机制，否则该条流于形式）。

## 三、《合规责任书》六项责任内容 + 考核（源文全文结构）

**依据与目的**：根据集团《合规管理规定》《合规手册》等，结合公司实际签订，以全面完成公司年度主要任务、依法合规经营管理、建立合规管理体系、防范和有效控制合规风险、保障持续健康发展。

**考核周期**：2026-01-01 至 2026-12-31（**年度**）。

**责任内容六项**：
1. 建立合规管理领导机构，明确**合规管理牵头人**，确定合规管理部门及其职责，健全合规管理组织体系；
2. 建立合规管理**基本制度和流程**，将合规管理要求融入经营管理各项制度和流程，不断优化完善制度流程体系；
3. 组织开展**合规风险识别和应对、合规审查**，完善违规问责机制，有效防控本企业合规风险；
4. 组织开展**合规考核评价、合规培训**，积极培育合规文化；
5. 发生**重大违规事项或重大合规风险事项，应及时向公司报告**；
6. 履行有关制度规定的其他合规职责。

**考核与奖惩**：依据公司《合规管理规定》《合规手册》等有关规定，进行年度考核。
**生效与份数**：经双方签字后生效；一式两份，双方各执一份。

> ⚠️ **源文签署日期为 2025-12-28，与考核周期起点 2026-01-01 衔接**——模板使用时须同步更新考核周期与签署日期，避免出现"签署日在周期之前"的瑕疵。

## 四、配套法律依据（本地法条银行逐字 · 已三通道核验）

**《民法典》第七条**【诚信原则】
> 民事主体从事民事活动，应当遵循诚信原则，秉持诚实，恪守承诺。

**《民法典》第一百五十三条**【强制性规定与公序良俗】
> 违反法律、行政法规的强制性规定的民事法律行为无效。但是，该强制性规定不导致该民事法律行为无效的除外。
> 违背公序良俗的民事法律行为无效。

**《民法典》第四百九十六条**【格式条款提示说明义务】
> 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款，按照对方的要求，对该条款予以说明。提供格式条款的一方未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容。

**合规责任书作为内部文件的效力基础（法理推演，非源文明示）**：
- 承诺书与责任书均为**企业内部管理文件**，一般不直接构成劳动合同的必备条款，其约束力主要源于**劳动纪律/规章制度**路径及**《民法典》第七条诚信原则**；
- 🔴 若以责任书中的考核奖惩直接影响薪酬、晋升或解除劳动合同，可能被认定为**涉及劳动者切身利益的规章制度**，则须履行《劳动合同法》第四条规定的**民主程序（讨论、协商）与公示告知程序**——未履行的，在争议中可能不被采信为处理依据。**（提示：《劳动合同法》第四条本次未逐字回填，正式意见前须回本地法条银行/元典核验）**

## 五、蓝队 / 红队要点

- **蓝队（企业侧落地）**：
  1. **分层签署**：全员签承诺书、中高管签责任书，两者分开留痕，不混用；
  2. **责任书必须与考核挂钩**，且考核指标可量化（重大违规上报时效、违规问责机制落地率、合规培训完成率、审查发现问题整改率）；
  3. **承诺书配套举报机制**（独立渠道 + 匿名选项 + 反报复条款），否则第7项承诺无承接；
  4. **动态更新**：合规手册修订后须重新签署或以"确认页"方式确认，否则承诺内容与手册脱节；
  5. 责任书签订**时点与考核周期对齐**，避免"先签后考核周期未开始"的争议。
- **红队（风险审查视角）**：
  1. 审查承诺书是否**逐人签字**，是否仅签收式批量签署（无签字即无承诺效力证据）；
  2. 审查责任书**考核条款是否有配套的制度依据**（《合规管理规定》《合规手册》是否真实存在且已生效）；
  3. 审查责任书与劳动合同、绩效协议的**冲突条款**（如考核扣薪与工资法最低工资红线冲突）；
  4. 审查承诺书/责任书作为**格式条款**的提示说明义务履行情况（民法典§496），特别是免责/加重对方责任类表述。

## 六、适用场景

- 企业/社会组织建立合规管理体系时的**工具选型与分工**（承诺书 vs 责任书）；
- 厚德基金会合规管理制度清单的补强（与既有《贵州省厚德公益基金会合规管理手册（试行）（2025版）》体系衔接）；
- 合规责任制落地检查（组织架构是否明确牵头人、是否建立制度流程、是否有风险识别与审查机制、重大事项报告路径是否通畅）；
- 内部合规宣贯仪式设计（形式与意识相互转化）。
