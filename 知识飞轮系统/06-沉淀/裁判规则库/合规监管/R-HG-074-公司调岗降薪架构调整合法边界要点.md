# 核心要旨

调岗、降薪、架构调整本质均属**劳动合同内容变更**，合法基础是《劳动合同法》**协商一致**（第35条），辅以**法定单方调整**特殊情形。司法审查三要件：**目的正当性、程序合法、结果合理**。本卡锚定**航合物流**等用工单位的调岗降薪合规边界。

## 一、调岗合法边界

1. **协商一致调岗（最优先）**：第35条第1款"用人单位与劳动者协商一致，可变更劳动合同；应采书面形式"。口头协商实际履行超1个月且不违法亦可有效，但企业应优先书面。
2. **法定单方调岗（第40条，须满足严格条件）**：
   - 医疗期满不能从事原工作（需医疗期满+无法胜任原岗证据）；
   - 不能胜任工作，经培训或调岗仍不能胜任（需客观量化胜任标准+充分证据+先培训/调岗）；
   - 客观情况重大变化致合同无法履行，协商不成（企业拆迁/合并/业务转型/部门撤销；须先协商）。
   调岗后岗位应与身体/能力相适应，不得侮辱性、惩罚性，薪资不得随意降。
3. **约定合理调岗**：合同约定"企业可根据经营需要合理调整岗位"且不违法、不免除法定责任、不排除劳动者权利的，可调但须"合理性"。仅凭"企业有权调整员工应服从"将技术岗调保洁、一线调偏远无补贴，仍属无效。

**违法调岗**：强制单方（无协商无情形）、侮辱惩罚性、薪资大幅降、跨市跨省无补偿、针对孕期/工伤特殊群体、以调岗逼离职。

## 二、降薪合法边界（比调岗更严）

1. **协商降薪（第35条）**：唯一无争议主动降薪，须书面、真实意思，不得低于最低工资。
2. **法定单方降薪（极少）**：①不胜任经培训调岗后仍不胜任，按新岗价值单方降（不低于最低工资+书面通知）；②过错依合法有效规章降薪（规章经民主程序公示、过错有证据、幅度合理、不低于最低工资）。
3. **客观情况变化配套降薪**：与架构调整/调岗配套，依新岗价值合理降，须协商（不成亦须合理）。
4. **依法代扣（非降薪）**：《工资支付暂行规定》可代扣个税/社保/公积金/法院裁定抚养费赡养费；幅度不超当月工资20%，扣后不低于最低工资；不得擅自扣罚款/违约金。

**违法降薪**：单方强制、低于最低工资（即使协商亦无效）、末位淘汰（不代表不胜任）、经营困难无证据、特殊群体、逼离职、擅自罚款。

## 三、架构调整合法边界

1. **目的正当**：为正常经营（提效/降成本/市场变化），不得虚构（如为辞退虚构部门撤销）规避义务。
2. **程序合法**：提前告知方案影响、听取意见；大规模调整提前30日向工会/全体职工说明；引发岗位变动优先协商安置；裁员须满足：裁20人或占10%以上+提前30日说明+向劳动行政部门报告+优先留用特定人员（长固定期/无固定期/家庭无其他就业需扶养老幼）+支付经济补偿（N）。
3. **安置合理**：调岗与新岗技能经验适应、不侮辱惩罚；薪资与新岗价值匹配、降幅合理不低于最低工资；裁员依法付补偿（N）、不裁法定禁止人员（孕期/工伤1-6级/连续满15年距退休不足5年等）；特殊群体特殊保护。
4. **违法情形**：虚构架构调整逼离、未协商强制调降且不合理、裁员未走法定程序、未合理安置直接辞退不付补偿、重大变化无补偿。

## 四、责任与举证

- 企业主张调岗降薪架构调整合法须**举证**目的正当、程序合法、结果合理；无法举证承担不利后果（调岗无效、补差额、付赔偿金）。
- **违法解除赔偿金2N**；员工因此解除可主张**经济补偿N**。
- 员工权利：拒违法调降、在原岗工作不被辞；要求补差额；解除主张N；被违法辞主张2N。

# 办案衔接

- 航合物流（含外包/自有司机）调岗降薪须优先书面协商；架构调整（如部门合并）须先证明目的正当、走告知协商程序，特殊群体（孕期、工伤）不得单方处置。
- 用工单位以"客观情况重大变化"单方调岗/解除，须完成"先协商→不成"前置；直接解除风险2N。
- 与 R-LD-048（外包司机事实劳动关系）衔接：外包关系下调岗降薪主体应为外包单位，物流公司须避免被认定为实际用工方而承担连带责任。
