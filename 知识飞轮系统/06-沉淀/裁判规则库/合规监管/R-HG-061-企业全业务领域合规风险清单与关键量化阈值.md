# R-HG-061 企业全业务领域合规风险清单与关键量化阈值

## 一、七大领域风险地图

| 领域 | 核心环节 | 高发风险四字诀 |
|---|---|---|
| 一、综合管理 | 三重一大决策、印信、公文、档案 | 界定模糊 / 程序缺失 / 记录不全 / 执行偏离 |
| 二、业务运营 | 采购、销售、合同、供应商 | 资质审查不严 / 流程不透明 / 验收走形式 / 回款无跟踪 |
| 三、财务管理 | 资金、账务、税务、预算 | 备用金混乱 / 票据不合规 / 漏报税种 / 预算失控 |
| 四、人力资源 | 招聘、合同、薪酬、培训、离职 | 歧视性招聘 / 未签合同二倍工资 / 加班费错算 / 离职证明逾期 |
| 五、知产与保密 | 商标专利著作权、商业秘密 | 注册滞后 / 保密措施不到位 / 员工泄密 / 合作方泄密 |
| 六、安全环保 | 安全生产、环境保护 | 制度不健全 / 设施失维 / 应急预案空转 / 事故迟报 |
| 七、市场客户 | 客户信息、营销、投诉、竞争 | 超范围收集 / 绝对化用语 / 价格欺诈 / 商业贿赂 |

## 二、关键量化阈值速查（⚠️ 区分法定与管理建议）

### （一）【法定】劳动人事

| 事项 | 标准 | 依据 |
|---|---|---|
| 加班费 | 工作日延长 **150%**、休息日不能补休 **200%**、法定节假日 **300%** | 劳动法 |
| 试用期上限 | 合同 3个月–1年 **≤1个月**；1–3年 **≤2个月**；3年以上及无固定 **≤6个月** | 劳动合同法 |
| 试用期工资 | 不低于本单位同岗最低档工资 **80%**，且不低于当地最低工资 | 劳动合同法 |
| 离职证明 | 离职后 **15日内**出具并办理档案与社保关系转移 | 劳动合同法 |
| 社保登记 | 员工入职后 **30日内**办理 | 社会保险法 |
| 专项培训违约金 | **不得超过企业提供的培训费用**，且不超过服务期未履行部分分摊额（例：培训费3万/服务期3年/已服务1年 → 违约金上限2万） | 劳动合同法第22条 |
| 竞业限制期限 | **不超过2年** | 劳动合同法 |

### （二）【管理建议】合规管理阈值（可写进制度，非法定）

| 事项 | 建议阈值 |
|---|---|
| 三重一大"大额度资金" | 中小型企业 **≥50万元**、大型企业 **≥200万元** |
| 决策会议 | 材料提前 **3个工作日**送达；参会人数须达全体成员 **2/3以上**；缺席须书面授权 |
| 公开招标起点 | 采购金额 **≥50万元** |
| 履约保证金 | 大额采购（>200万）按合同金额 **5%–10%** |
| 备用金 | 差旅费 **≤5000元/人**，借支期限 **≤1个月** |
| 银行账户清理 | 闲置 **>6个月** 及时注销 |
| 关联方拆借利率 | **不超过 LPR 的 4 倍** |
| 档案库房 | 恒温 **14–24℃**、恒湿 **45%–60%**；纸质档案不得带出库；销毁须多部门共同监销 |
| 公文流转 | 超 **24小时**未处理自动提醒；下发后 **10个工作日内**归档 |
| 客户信息 | 保存期限建议交易完成后 **3年**；敏感信息 AES 加密；每月审计使用 |
| 安全培训 | 新员工 **≥24小时**（特殊工种 **≥72小时**）；每季度在职培训；每半年应急演练 |
| 事故报告 | 安全生产事故、环境污染事故均 **1小时内**报主管部门 |
| 投诉响应 | 线上提交 **1小时内**回复；**1个工作日**分派；**2个工作日**沟通方案；咨询类当日、质量类 **≤5个工作日** |
| 促销"原价" | 应为活动前 **7日内**实际销售的最低价格（禁止虚构原价/先提后折） |
| 商标续展 | 有效期满前 **6个月内**办理 |
| 供应商考核 | 每季度考核，得分 **<60分** 限期整改，整改不合格启动退出 |
| 回款催收分级 | 逾期 **1–30天 / 31–60天 / 60天以上** 分级，全程书面留痕以中断诉讼时效 |

## 三、十二个最易被追责的"老大难"

1. **先用印后补审批** —— 印信管理第一杀手。须《印信使用申请单》+ 保管人核对文件内容一致，杜绝无审批用印。
2. **公章单人保管无交接** —— 须"专人保管、专柜存放"、保管人签《责任书》、交接须三方（交接人/接任人/监交人）签字。
3. **废旧印章随意丢弃** —— 须总经理批准后由法务、财务、审计共同参与销毁并全程录像。
4. **会议纪要会后修改** —— 须含参会人员、讨论意见、表决结果（同意/反对/弃权人数及理由），签字确认后存档，**严禁会后修改**。
5. **销售部门只留合同复印件** —— 原件未移交档案部门 → 纠纷时无法举证。
6. **虚开发票 / 虚假发票报销** —— 支付前须通过税务系统核查发票真伪。
7. **漏报印花税、未代扣代缴个税** —— 税种申报不全的典型。
8. **高温补贴、节日福利未并入工资总额计缴个税**。
9. **"自愿放弃社保"条款** —— 违反法律，条款无效。
10. **招聘信息含性别/年龄/民族/地域歧视** —— 违反就业促进法。
11. **绝对化用语（"行业第一""最优"）与无依据的功效宣称** —— 违反广告法，须留存检测报告。
12. **商业贿赂** —— 回扣、购物卡、免费旅游、子女升学帮助均属之；大额合作（>500万）建议法务+审计联合合规审查。

## 四、执业要点

1. **本卡定位为"合规自查手册"而非裁判规则**：可作为企业合规体检的核查清单与制度起草的阈值参考，但**不宜直接作为法条引用**——除第二节（一）【法定】部分外，其余均为管理建议。
2. **为企业起草制度时的用法**：第二节（二）的阈值可直接写入内控制度（因其本就是"制度建议值"），但须结合企业规模与行业特点调整，并在条款中写明"本阈值为公司内控标准，法律法规另有规定的从其规定"。
3. **与厚德基金会的衔接**：基金会虽非生产企业，但**三重一大决策、印信管理、档案与公文、采购与供应商、客户（受益人/捐赠人）信息保护、反商业贿赂**六大板块可平移适用；涉及慈善特性的（捐赠物资计价、公开募捐备案、进口物资减免税）见 [[R-CF-096-慈善组织捐赠物资计价与捐赠票据开具合规规则|R-CF-096]]、[[R-CF-097-慈善组织公开募捐方案备案全流程合规要点|R-CF-097]]、[[R-CF-098-社会团体和基金会办理进口慈善捐赠物资减免税手续规则|R-CF-098]]。
4. **个人信息合规是独立红线**：客户/捐赠人信息受《个人信息保护法》规制，收集须"必要且最小范围"+ 告知同意，变更用途须重新取得同意，向第三方提供须签《保密协议》。
