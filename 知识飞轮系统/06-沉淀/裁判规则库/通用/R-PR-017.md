# R-PR-017 军用土地保全解除的"听证＋磋商"柔性解纷方法（裁判规则）

## 规则摘要
军用土地划拨地块与被查封土地重叠致登记受阻的，拥军法庭可采取"听证＋磋商"柔性解纷模式，协调查封法院组织部队单位、被执行企业、主要债权人与自然资源规划部门共同听证，并协同政府制定土地置换方案，促成债权人主动申请解除保全，实现国防利益与当事人合法权益的兼顾。

## 适用要点
- **适用场景**：军事用地因与他案被查封土地重叠导致权属登记受阻，影响国防建设任务推进。
- **方法路径**：拥军法庭牵头 → 协调查封法院 → 组织多方（部队单位、被执行企业、主要债权人、自然资源规划部门）听证 → 政府制定土地置换方案 → 债权人主动申请解除保全。
- **价值平衡**：兼顾国防利益（军用土地及时确权）与债权人合法权益（置换方案保障债权实现），避免硬性裁判激化矛盾。
- **协同主体**：法院（拥军法庭/查封法院）、政府（自然资源规划部门）、部队单位、被执行企业、主要债权人。

## 反例 / 常见错误
- 仅机械驳回军用土地登记或径行解除保全，未搭建多方协商平台，导致国防任务受阻或债权人权益受损。
- 以"涉及军事"为由回避程序透明，未组织听证即单方处置。
- 置换方案缺乏自然资源部门与债权人共识，落地失败。

## 关联案件 / 组织
- 涉军用土地、国防设施权属争议与保全解纷；拥军法庭工作机制。
