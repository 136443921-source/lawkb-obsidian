# R-PR-019 越权担保与善意相对人规则

## 规则
法定代表人超越权限订立担保合同，相对人善意的，担保合同对公司发生效力；相对人非善意（明知或应知越权）的，公司不担责但可向法定代表人追偿。关联担保须股东会决议且关联股东回避。

## 规范依据
《民法典》第504条；《公司法》第15、16条（2023修订）；《最高人民法院关于适用〈民法典〉有关担保制度的解释》第7-11条。

## 适用要件
1. 相对人已对决议作"合理审查"（签名、表决比例形式真实）；
2. 相对人对决议实质瑕疵不负有审查义务；
3. 关联担保：股东会决议、关联股东回避、无关联表决权过半数通过；
4. 上市公司担保须披露并满足股东大会决议门槛。

## 实务提示
- 债权人放贷前务必索要并核验章程与决议原件，仅看印章不足以免险；
- "合理审查"非"实质审查"，把握边界避免过度勤勉；
