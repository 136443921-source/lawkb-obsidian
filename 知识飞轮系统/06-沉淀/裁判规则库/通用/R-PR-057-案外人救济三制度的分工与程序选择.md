# 案外人救济三制度的分工与程序选择（审判要件卡·第三人撤销之诉）

> **卡型**：审判要件卡（正向裁判规则 · 法官心智）｜**编号**：`R-PR-057`｜**域**：PR（程序）

## 一、裁判规则（正向·该怎么判）

**（1）制度格局**

第三人撤销之诉、案外人执行异议之诉、案外人申请再审**共同构成我国案外人救济制度**。其中：

- 第三人撤销之诉规定于《民事诉讼法》**第五十九条**；
- 案外人申请再审与案外人执行异议之诉均规定于《民事诉讼法》**第二百三十八条**。

**（2）适用场景**

- 案外人认为**生效裁判确有错误**损害其权益的，通过**提起第三人撤销之诉**或者**申请再审**的方式进行救济；
- **案外人执行异议之诉**则**不以否定作为执行依据的生效裁判为目的**，其旨在**排除对特定标的物的执行行为**。从程序上而言，案外人依据《民事诉讼法》第二百三十八条的规定提出执行异议被驳回的，即可向执行法院提起执行异议之诉。

**（3）启动前置条件的差异**

案外人申请再审和第三人撤销之诉均为解决案外人因生效法律文书错误导致权利受损时的救济制度。二者的重要区别在于：**案外人申请再审中，案外人认为执行依据错误损害其对执行标的享有的权利，从而请求排除执行，其诉讼前置条件为执行程序启动；而第三人撤销之诉则不必依托执行程序启动。**

**（4）程序选择权的限制**

案外人申请再审与第三人撤销之诉在功能上近似，如果案外人既有申请再审的权利，又符合第三人撤销之诉的条件，对于案外人是否可以行使选择权，司法解释对此采取了**限制**的司法态度。

《民事诉讼法解释》第三百零一条明确规定：

1. 第三人提起撤销之诉后，未中止生效判决、裁定、调解书执行的，执行法院对第三人依照《民事诉讼法》第二百三十八条提出的执行异议，**应予审查**。第三人不服驳回执行异议裁定，申请对原判决、裁定、调解书再审的，**人民法院不予受理**。
2. 案外人对人民法院驳回其执行异议裁定不服，认为原判决、裁定、调解书内容错误损害其合法权益的，**应当根据《民事诉讼法》第二百三十八条申请再审，提起第三人撤销之诉的，人民法院不予受理**。

《全国法院民商事审判工作会议纪要》第122条规定，实务中应注意，**按照程序启动的先后，案外人只能选择相应的救济程序**：

1. 案外人**先启动执行异议程序**的，对执行异议裁定不服，认为生效裁判内容错误损害其合法权益的，**只能向作出原裁判的人民法院申请再审，而不能提起第三人撤销之诉**；
2. 案外人**先启动了第三人撤销之诉**，即便在执行程序中又提出执行异议，**也只能继续进行第三人撤销之诉，而不能申请再审**。

**（5）程序吸收及例外**

根据《民事诉讼法解释》第二百九十九条的规定，第三人撤销之诉案件审理期间，人民法院对生效判决、裁定、调解书裁定再审的，受理第三人撤销之诉的人民法院应当裁定**将第三人的诉讼请求并入再审程序**。

**但有证据证明原审当事人之间恶意串通损害第三人合法权益的，人民法院应当先行审理第三人撤销之诉案件，裁定中止再审诉讼。**注意符合「但书」规定情形的，**第三人撤销之诉优先审理**。

第三人诉讼请求并入再审程序审理的，按照下列情形分别处理：

1. 按照**一审程序**再审的，人民法院应当对第三人的诉讼请求一并审理，所作的判决**可以上诉**；
2. 按照**二审程序**再审的，人民法院**可以调解**，调解达不成协议的，应当裁定撤销原判决、裁定、调解书，**发回一审法院重审，重审时应当列明第三人**。

**（6）与案外人执行异议之诉的关系**

案外人先启动执行异议程序，对执行异议裁定不服，**认为与原判决、裁定无关**的，按照《民事诉讼法》第二百三十八条的规定，**以案外人执行异议之诉作为后续救济途径，不能提出第三人撤销之诉**。

案外人先启动第三人撤销之诉，在执行程序中又提出执行异议，对执行异议裁定不服的，如前述只能继续进行第三人撤销之诉，不能申请再审。**此种情形下，亦不能提出执行异议之诉**，因为法律赋予的救济途径是继续进行第三人撤销之诉，而非其他途径。

## 二、审查要点（审理思路）

1. **第一步：看程序启动的先后**——先执行异议还是先撤销之诉？这一步决定了一切。
2. **第二步：看异议的内容**——认为原裁判错误（走再审／撤销之诉），还是与原裁判无关（走执行异议之诉）？
3. **第三步：适用选择限制**——
   - 先执行异议 + 认为原裁判错误 → **只能申请再审**；
   - 先执行异议 + 与原裁判无关 → **只能执行异议之诉**；
   - 先撤销之诉 → **只能继续撤销之诉**，不得再审、不得执行异议之诉。
4. **第四步：审查恶意串通但书**——有证据证明原审当事人恶意串通损害第三人权益的，撤销之诉优先审理，中止再审。
5. **路径判断必须在启动前完成**：一旦走错，期间（6个月法定不变期间）不因纠错而恢复。

## 三、构成要件与举证

| 启动顺序 | 异议内容 | 唯一救济路径 |
|---|---|---|
| 先执行异议 | 认为原裁判内容错误 | 案外人申请再审 |
| 先执行异议 | 与原裁判无关 | 案外人执行异议之诉 |
| 先第三人撤销之诉 | 原裁判内容错误 | 继续第三人撤销之诉（不得再审、不得执行异议之诉） |
| 无执行程序 | 生效裁判错误损害权益 | 第三人撤销之诉（或案外人申请再审，若已启动执行） |

## 四、法条依据（权威源回填）

**《中华人民共和国民事诉讼法》（2023修正）第五十九条**

> 对当事人双方的诉讼标的，第三人认为有独立请求权的，有权提起诉讼。
> > 对当事人双方的诉讼标的，第三人虽然没有独立请求权，但案件处理结果同他有法律上的利害关系的，可以申请参加诉讼，或者由人民法院通知他参加诉讼。人民法院判决承担民事责任的第三人，有当事人的诉讼权利义务。
> > 前两款规定的第三人，因不能归责于本人的事由未参加诉讼，但有证据证明发生法律效力的判决、裁定、调解书的部分或者全部内容错误，损害其民事权益的，可以自知道或者应当知道其民事权益受到损害之日起六个月内，向作出该判决、裁定、调解书的人民法院提起诉讼。人民法院经审理，诉讼请求成立的，应当改变或者撤销原判决、裁定、调解书；诉讼请求不成立的，驳回诉讼请求。

## 五、抗辩与但书

**但书（恶意串通优先）**：有证据证明原审当事人之间恶意串通损害第三人合法权益的，人民法院应当**先行审理第三人撤销之诉案件，裁定中止再审诉讼**。这是「程序吸收」规则的唯一例外，体现了对虚假诉讼的优先打击。

## 六、翻车标本

**标本**：案外人对执行标的提出执行异议被驳回后，另行提起第三人撤销之诉，法院受理并撤销原裁判。

**为什么错**：《民事诉讼法解释》第三百零一条与九民纪要第122条已明确「按程序启动的先后，案外人只能选择相应的救济程序」。先启动执行异议程序的，认为原裁判错误的**只能申请再审**。受理其撤销之诉，等于允许当事人通过程序挑选规避司法解释的明确限制。

**正确姿势**：立案时必查「此前是否提出过执行异议」。这一项询问应当成为撤销之诉立案审查的固定动作。
