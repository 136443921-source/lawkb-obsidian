# R-PR-032 抚养费迟延利息一般不予支持

## 规则内容
抚养费给付义务具有人身属性，系基于父母对子女的法定抚养义务而非当事人之间的约定，并非普通金钱债务；父母之间无迟延履行后果约定的，对抚养费迟延支付利息之诉请不宜予以支持。

## 关联法条
《民法典》第1067条（法定抚养义务）

## 实务要点
- 不宜参照《民法典合同编解释》关于违约金的规定
- 拒不履行法院生效文书确定抚养义务的可罚款、拘留，构成犯罪的追究刑事责任
- 履行路径：申请强制执行（含迟延履行金，依据民诉法规定）
