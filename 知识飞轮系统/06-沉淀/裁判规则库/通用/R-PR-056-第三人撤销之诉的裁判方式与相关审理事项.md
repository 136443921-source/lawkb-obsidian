# 第三人撤销之诉的裁判方式与相关审理事项（审判要件卡·第三人撤销之诉）

> **卡型**：审判要件卡（正向裁判规则 · 法官心智）｜**编号**：`R-PR-056`｜**域**：PR（程序）

## 一、裁判规则（正向·该怎么判）

**（1）裁判方式**

对第三人提出的撤销或者部分撤销发生法律效力的判决、裁定、调解书的请求，人民法院经审理，按下列情形分别处理：

1. 请求成立且确认其民事权利的主张全部或部分成立的，**改变**原判决、裁定、调解书内容的错误部分；
2. 请求成立，但确认其全部或部分民事权利的主张不成立，或者未提出确认其民事权利请求的，**撤销**原判决、裁定、调解书内容的错误部分；
3. 请求不成立的，**驳回诉讼请求**。

原判决、裁定、调解书的内容**未改变或者未撤销的部分继续有效**。对前款规定裁判不服的，当事人可以上诉。

**（2）合议庭组成**

对第三人撤销之诉案件，**无论受理的法院是何种审级的法院**，都应当按照**第一审普通程序**审理，而**不适用简易程序**审理。审理时应当**组成合议庭**，一般在**原案合议庭之外，另行组成合议庭**开庭审理。第三人撤销之诉本质上属于新诉，法律未明确要求必须「另行组成」合议庭，也未禁止原审审判人员参与审理。**为避免争议，以另行组成合议庭为宜。**

**（3）诉的合并**

第三人在撤销之诉中同时提出对原审诉讼标的确认权属、履行合同等诉讼请求，**该请求系作为认定第三人提起撤销之诉的权利基础的，可以一并审理**。多个第三人对同一生效裁判文书提起撤销之诉且均符合起诉条件的，可以合并审理。

**（4）调解**

第三人撤销之诉案件可以遵循当事人自愿原则，在事实清楚的基础上分清是非进行调解。第三人与原案当事人自愿达成调解协议且不损害国家利益、社会公共利益、他人合法权益的，可以根据当事人的申请制作调解书。为解决调解书生效后与原生效裁判的关系问题，可建议当事人在调解协议中增加相应内容：「**本协议生效后，各方同意×××号判决书／裁定书／调解书涉及×××事项的内容不再执行。**」

**（5）涉案标的物被转让的处理**

第三人提起撤销之诉所主张的特定标的物在原生效判决、裁定、调解书生效后**已经转让给案外人**的，经审查第三人的撤销请求成立的，**可以判决撤销该生效裁判，但不得直接对案外人受让的标的物进行处理**，第三人可另行提起诉讼与案外人解决相关争议。

**（6）申请财产保全**

第三人撤销之诉审理过程中，**原则上可以对相关标的物进行诉讼保全**。但该诉讼并非普通类型诉讼，对查封标的、担保物要**严加审查，以免当事人通过诉讼过度拖延执行**；在原告提供**充分、有效担保**的情况下，经审查认为其申请符合法律规定的，可以对生效裁判文书主文确定的特定标的物或者特定权利对应的款项进行保全，但该特定标的物或者特定权利对应的款项**已经被采取执行措施的，告知原告应申请中止执行**。

原告主张原诉构成虚假诉讼的，也可以申请对原诉当事人依据生效裁判取得的财产或者对应的等值财产进行保全。

**（7）上诉和再审**

当事人对第三人撤销之诉的**一审判决**以及**不予受理、驳回起诉、管辖权异议裁定**不服的，可以提起上诉；不服二审判决或裁定的，可以申请再审。但**一审法院判决驳回第三人要求撤销或者改变原生效裁判诉讼请求的，原诉案件当事人不得提出上诉，亦不得申请再审**。当事人对第三人撤销之诉的调解书不服的，可以依法申请再审。

**（8）审理期间原裁判文书的执行**

第三人撤销之诉案件审理期间，**原则上不中止**原生效判决、裁定、调解书的执行。原告提供充分、有效的担保、请求中止执行的，可以在其请求撤销或者变更范围内裁定中止执行，并及时通知相关法院执行机构；**已经执行完毕的除外**。

**（9）恶意及虚假诉讼**

第三人提起撤销之诉的原诉裁判文书内容如有错误、可能存在原诉当事人恶意串通虚假诉讼损害第三人权益的情形，判断是否存在虚假诉讼时，可根据《最高人民法院关于防范和制裁虚假诉讼的指导意见》第一条、第二条等的规定，结合案情实际进行判断；**存在虚假诉讼的，应当支持第三人的诉讼请求**，并依法对相关当事人采取相应司法惩戒措施，涉嫌犯罪的将线索移送公安机关处理。

第三人撤销之诉案件审理过程中，**第三人与原案当事人恶意串通，滥用诉权，或者通过伪造证据、捏造案件基本事实进行虚假诉讼的**，应当依法采取相应司法惩戒措施，涉嫌犯罪的将线索移送公安机关处理。**诉讼代理人、证人、鉴定人等诉讼参与人适用前款规定。**

## 二、审查要点（审理思路）

1. 先确定程序规格：一审普通程序 + 合议庭（以另行组成为宜）。
2. 再按三分支处理：确认权利主张成立→改变；不成立或未提出→撤销；请求不成立→驳回。
3. 标的物已转让的，**只撤裁判、不处理标的物**，告知另行起诉。
4. 保全从严审查，防止以撤销之诉拖延执行。
5. 执行以不中止为原则，中止为例外（须充分有效担保）。
6. 全程警惕虚假诉讼——两个方向都要防：原审当事人串通，以及第三人与原审当事人串通。

## 三、构成要件与举证

| 事项 | 规则 | 例外／条件 |
|---|---|---|
| 审理程序 | 一审普通程序 + 合议庭 | 不适用简易程序 |
| 执行 | 原则上不中止 | 提供充分有效担保的可在请求范围内中止 |
| 保全 | 原则允许 | 严加审查，防止拖延执行 |
| 标的物已转让 | 可撤销裁判 | **不得**直接处理标的物 |
| 上诉权 | 双方均可上诉一审判决 | 一审驳回撤销请求的，原诉当事人不得上诉、不得申请再审 |

## 五、抗辩与但书

**但书一（标的物转让）**：判决撤销生效裁判，但**不得**直接对案外人受让的标的物进行处理——保护交易安全与案外人的信赖利益。

**但书二（上诉权的不对等）**：一审判决驳回第三人撤销请求的，**原诉案件当事人不得提出上诉，亦不得申请再审**。这是因为该判决维持了原生效裁判，原诉当事人并未因此蒙受不利。

## 六、翻车标本

**标本**：撤销之诉中一并判决「案外人返还标的物」。

**为什么错**：案外人不是撤销之诉的当事人，其受让行为发生在生效裁判之后，受交易安全保护。撤销之诉只解决「生效裁判是否错误」，不解决「标的物归谁」。直接对标的物作出处理，等于在未审理案外人抗辩的情况下剥夺其权利。

**正确姿势**：只撤裁判，告知第三人另行起诉案外人。
