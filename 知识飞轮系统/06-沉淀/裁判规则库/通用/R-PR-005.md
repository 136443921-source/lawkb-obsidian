# R-PR-005 笔迹鉴定和指纹鉴定的收费计算方式（裁判规则）

## 规则摘要
- **"一件"** = **一个鉴定事项**（如：鉴定一份合同上的签名是否系某人所写）

## 适用要点
- "一件" = 一个鉴定事项（如：鉴定一份合同上的签名是否系某人所写）
- 不是按页数收费：即使合同有10页，只要只鉴定其中的签名，就按"一件"收费
- 不是按字数收费：即使签名只有3个字，也是按"一件"收费
- 一份合同上有一个签名需要鉴定 = 一件 = 800-1500元
- 一份合同上有三个签名需要鉴定 = 三件 = 800×3 = 2400-4500元
- 两份不同合同上各有一个签名需要鉴定 = 两件 = 800×2 = 1600-3000元

## 反例 / 常见错误
- 避免重复鉴定：确保检材质量，避免多次鉴定
- 要求出具收费清单：避免隐形收费
- 明确鉴定事项：避免后期争议
- 明确收费标准：避免随意加价
