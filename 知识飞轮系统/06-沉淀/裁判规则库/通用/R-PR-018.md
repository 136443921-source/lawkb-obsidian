# R-PR-018 民间借贷利率保护上限规则

## 规则
民间借贷约定利率不得超过合同成立时一年期贷款市场报价利率（LPR）的四倍；逾期利率、违约金或其他费用合计亦受四倍上限约束，超出部分人民法院不予支持。

## 规范依据
《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》（2020修正）第25-29条；《民法典》第680条。

## 适用要件
1. 适用于自然人、法人和非法人组织之间的资金融通行为；
2. 利率判断节点为"合同成立时"的 LPR，非起诉时；
3. 2020-8-20 前成立的合同，分段适用旧"两线三区"与 LPR 四倍规则；
4. 砍头息按实际出借金额认定本金，复利未超上限部分可支持。

## 实务提示
- 主张利息须明确合同成立日期并调取当时 LPR 基准；
- 违约金+利息+服务费叠加易突破红线，起草借款协议时整体测算；
