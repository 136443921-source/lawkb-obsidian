# 夫妻一方越权代签担保合同超出家事代理范畴对被代理方不生效

## 一、核心要旨

夫妻一方为他方借款提供担保，在**续贷**时未经另一方同意、无授权手续而代其签署《保证合同》的：

1. 担保行为涉及重大财产处分，**超出家庭日常生活需要的家事代理范畴**；
2. 续贷系新的借贷法律关系，首贷时共同担保的意思表示**不能当然延续**至续贷；
3. 相对人（债权人/银行）未尽审慎义务（未要求本人签署/到场、未核实代理权限）→ **表见代理善意无过失信赖基础丧失**；
4. 被代理一方不追认的，依《民法典》第171条第1款，该担保合同对其**不发生效力**，不承担保证责任。

## 二、权威依据

- 《民法典》第171条第1款：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，未经被代理人追认的，对被代理人不发生效力。
- 《民法典》第1060条：夫妻一方因家庭日常生活需要而实施的民事法律行为，对夫妻双方发生效力（反向界定：超出日常生活需要不在家事代理范围内）。
- 参考案例：某银行诉陆某某、田某某等金融借款合同纠纷案（遵义法院入选贵州高院商事典型案例）。

## 三、实务锚点

- 担保合同相对人（金融机构）负有核实代理权限的审慎义务；代签无授权即丧失表见代理成立前提。
- 与 [[R-HT-359]] 表见代理两要件同源：代理权外观不足 + 相对人非善意无过失 → 行为对被代理人不生效。
- 可用于金融借款/民间借贷中"夫妻一方被冒名担保"的免责抗辩；亦提示律师代理担保人一方时固定"相对人未尽核实"证据。
