# 案例权威源统一规范

## 一、权威源定义
- **权威源（唯一）**：法随案例库（fasui-caselibrary MCP）。提供最高法 / 最高检 / 法答网等权威案例与裁判规则。
- **工作副本**：本目录 `Obsidian/lawkb/裁判规则库/`（及 `案例摘要/`）为本地工作副本，便于检索与推送，但**不替代**权威源。

## 二、卡片 frontmatter 约定（强制）
每张裁判规则 / 案例摘要卡片必须包含溯源锚点：

```yaml
source_case_id: <法随案例库 local_id>   # 溯源锚点，对账时校验
source_authority: 指导案例/公报案例/典型案例/法答网/普通案例
case_name: ""
court: ""
date: YYYY-MM-DD
```

无 `source_case_id` 的卡片为"孤儿卡片"，对账时会单列。

## 三、对账机制
- 月度自动化「裁判规则对账」于每月 **28 日 21:00** 执行：
  - 在线校验 `source_case_id` 在法随案例库中的存在性与权威类型；
  - 发现重复覆盖、权威库新增未收录规则时生成报告。
- 报告输出：`Obsidian/lawkb/知识飞轮系统/裁判规则对账-YYYY-MM.md`

## 四、冲突处理原则
1. 权威源与本地副本冲突 → 以法随案例库为准，更新本地卡片并标注更新日期。
2. 本地卡片源案例已从权威库移除 → 降级为"历史参考"，保留但标记失效。
3. 禁止在本地卡片中改写裁判规则核心表述而不注明来源。
