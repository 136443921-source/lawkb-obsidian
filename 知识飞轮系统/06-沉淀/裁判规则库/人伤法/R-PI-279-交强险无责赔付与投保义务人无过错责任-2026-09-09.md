# 核心要旨

交强险具有**强制性、无过错赔偿性**，无责方也须在**无责限额**内赔付；未依法投保交强险的机动车，**投保义务人在交强险限额内承担无过错赔偿责任**。本案由锚定**航合物流事故（贵C09782D 货车致死）**的保险理赔与赔偿顺位。

- **道交法第76条赔偿顺位**：先由保险公司在交强险责任限额内赔偿；不足部分按过错分担。机动车与非机动车/行人之间，机动车一方无过错的承担**不超过10%**赔偿责任（受害人故意碰撞除外）。
- **🔴 无责也赔（无过错责任）**：交强险赔付不以被保险车辆驾驶人过错/责任为前提。无责方保险公司在无责限额内承担无责赔付系法定义务（皖高院案例、青山区法院案例）。多车事故未超各车限额之和的，按限额比例分摊（道交赔偿解释第21条）。
- **🔴 未投保→投保义务人限额内无过错赔**：未依法投保交强险的机动车致损，当事人请求投保义务人在交强险责任限额范围内赔偿的，法院支持（道交赔偿解释第16条）。投保义务人与侵权人非同一人，二者在限额内承担相应责任。
- **限额口径（银保监会2020-09-19公告·须查公告非条例）**：
  - **有责**：死亡伤残18万 / 医疗1.8万 / 财产0.2万 = **20万**
  - **无责**：死亡伤残1.8万 / 医疗1800 / 财产100 = **19900元**
- **民法典第1213条**：机动车一方责任的，先由承保交强险保险人在限额内赔，不足由商业险按约赔，仍不足/无商业险由侵权人赔。

# 权威案例（公开司法源·待回源入库编号）

- **重庆市高院案例（cqgy 2024）**：未依法投保交强险的无责方万某，应在交强险**无责赔付限额内**按比例赔偿钟某。明确"事故责任≠民事责任，机动车一方不免责除非受害人故意"。
- **(2023)包头市青山区法院案（二审维持）**：张某汽车未投交强险及三者险，与骑电动车赵某（主责）碰撞，赵某十级伤残；判张某在交强险限额内无过错赔偿**137,218.45元**，二审维持。

# 办案衔接

- 航合事故：①先核各车交强险投保状态与限额（有责20万/无责19900）；②贵C09782D 若未投保交强险，投保义务人（车主/公司）在限额内承担无过错赔偿；③机动车与行人/非机动车之间，机动车无责仍担≤10%；④赔偿顺序：交强险→商业险→侵权人。
- ⚠️ 限额必须查银保监会2020-09-19公告原文，不得仅引《交强险条例》第23条（仅框架授权）。
