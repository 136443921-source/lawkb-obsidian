# 裁判规则 R-PI-078：告知义务违反的责任成立须以人身损害为要件

**规则**：医务人员违反《民法典》第1219条第1款说明义务，但未造成患者人身损害的，患者请求医疗机构承担损害赔偿责任的，不予支持。实施手术、特殊检查、特殊治疗的，医疗机构就"已尽说明义务并取得明确同意"承担举证责任；医疗机构提交患者或其近亲属明确同意证据的，可以认定其尽到说明义务，但患者有相反证据足以反驳的除外。

**规范依据**：
- 《民法典》第1219条（说明义务与"明确同意"；未尽义务**造成患者损害的**方承担赔偿责任）
- 《民法典》第1220条（紧急救治例外）
- 《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释》第5条（举证结构）、第11条第3项（说明义务可作独立鉴定事项）、第17条（未造成人身损害不予支持）、第18条（不能取得近亲属意见的五种情形）
- 《基本医疗卫生与健康促进法》第32条

**适用要件**：
1. **义务违反**：未说明病情/医疗措施，或对手术、特殊检查、特殊治疗未"具体说明"医疗风险与**替代医疗方案**，或未取得明确同意。
2. **损害后果**：须为**人身损害**。单纯知情权、自主决定权受挫，不足以单独支撑赔偿或精神损害抚慰金（第17条）。
3. **因果关系**：需回答"若充分告知，患者是否会拒绝该方案"的假设因果关系；实务多不判全赔，而将告知过错折入原因力比例酌定。
4. **举证顺序**：患方证明"就诊+损害"→ 医方提交明确同意证据 → 举证负担转回患方提出相反证据（属提出证据责任转移，非终局证明责任倒置）。
5. **抗辩**：援引第1220条紧急救治免责的，须同时具备"生命垂危+落入司法解释第18条五种情形之一+负责人或授权负责人批准"。

**实务提示**：
- 知情同意宜作为**第二条独立请求权基础**与诊疗技术过错**并行**主张，功能是抬高参与度，不宜作为唯一进攻路线。
- 申请鉴定时务必按司法解释第11条第3项，将"是否尽到说明义务、取得明确同意的义务"**单列为鉴定事项**，防止鉴定意见只答技术过错。
- 同意书质证按"六看"：签署时间、签署主体（授权）、内容具体性（替代方案栏）、术式一致性（术中变更是否重新告知）、谈话过程留痕、紧急情况批准链条。
- **民行口径分离**：民事层面《民法典》已由"书面同意"松动为"明确同意"；但《医疗纠纷预防和处理条例》第13条行政层面仍要求书面，违反者依第47条第2项罚款1万~5万元。同一份缺签告知，可能民事不赔、行政仍罚。
- 关联 [[R-PI-075]]：非近亲属好意签字并尽相当注意义务的，不因签字承担赔偿责任。
