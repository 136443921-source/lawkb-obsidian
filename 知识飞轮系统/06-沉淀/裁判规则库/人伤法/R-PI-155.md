# R-PI-155 医疗损害赔偿范围与特殊责任形态

## 规则要旨
赔偿范围原则上填平实际损失，特殊情形调整。死亡赔偿金已成死亡类案主要项目（最高法(2013)民抗字第55号，不受《医疗事故处理条例》未规定影响）；缺陷儿出生赔"特别抚养费"+精神抚慰金（(2015)二中民终字第11917号，但最高法无统一规则、各地不一）；非医保用药以合理性必要性审查不以医保范围为标准（(2010)闵民一(民)初字第12717号）。

## 特殊责任形态
1. **医美**：病理性属医疗行为；非病理性可择违约/侵权，合同纠纷可适用《消法》（(2017)粤01民终21636号）。
2. **药物临床试验**：申办者未按知情同意购险→违约责任；签字≠放弃索赔；**新版GCP（2026修订）2026-09-01施行**要求提供与风险适应的保险/保证。
3. **输血感染/器械缺陷**（《民法典》第1223条）：举证责任倒置，医方/生产者须证缺陷不存在或损害系患者故意（(2014)岩民终字第164号；(2013)费民初字第776号）。
4. **公平责任**：药品合格+医方无过错+无国家补偿+显失公平→分担（(2012)淄民再终字第76号），个案裁量。

## 维权四步
48h内尸检（冻存延7日）→ 复印封存病历+保全缺陷药械 → 鉴定质证（出庭/补鉴/重鉴） → 请求权基础选择（影响赔偿范围与举证）。
