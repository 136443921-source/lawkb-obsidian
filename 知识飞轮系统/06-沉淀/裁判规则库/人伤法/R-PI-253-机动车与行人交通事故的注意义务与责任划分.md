# 核心要旨

- 机动车行驶速度快、危险程度高，在道路通行中**负有较高注意义务**（优者危险负担原则）。
- 机动车与行人之间发生交通事故：**行人没有过错的，由机动车一方承担赔偿责任**；有证据证明行人有过错的，根据过错程度**适当减轻**机动车一方的赔偿责任。

# 关联法条

- 《民法典》第1165条（过错责任）、第1173条（过失相抵）、第1208条、第1209条（机动车交通事故侵权）。
- 《道路交通安全法》第76条（机动车与行人／非机动车事故的责任分配：无过错责任＋过失相抵）。

# 适用场景

- **航合物流 2026-09-01 事故**（贵C09782D 重型货车与行人碰撞致死）：机动车一方责任划分与减责抗辩边界——行人无过错则机动车全赔；若主张行人过错减责，须有充分证据（监控、鉴定、笔录），否则承担全责风险。
- 区别于 R-PI-241（未投交强险时投保义务人在限额内共同赔偿，程序性赔偿路径），本卡侧重**实体责任划分的注意义务标准**。
