# R-PI-575 委托监护责任：监护人仍担责，受托人有过错承担相应责任（民法典§1189）

> 降级采集声明：2026-10-22 全通道 absent（元典/qcc-legal/法随 本会话均 absent）。法条侧据本地法条银行逐字回填；案例侧无交叉核验 → `source_verified:false`。
> 适用：父母将子女托付亲友/机构照看期间致人损害、临时受托照看未成年人致害。关联笔记 [[监护与委托监护致害责任实务（§1188-1189）]]。

## 一、核心法条（已逐字核验·本地法条银行）

**《民法典》第一千一百八十九条**【委托监护责任】
> 无民事行为能力人、限制民事行为能力人造成他人损害，监护人将监护职责委托给他人的，监护人应当承担侵权责任；受托人有过错的，承担相应的责任。

## 二、裁判要旨与适用要点

1. **监护责任不随委托转移**：监护职责可委托，但**监护责任主体不转移**——监护人仍为第一责任人，不因委托而免责。
2. **受托人"相应责任"=按过错程度的责任**：受托人仅在有过错时承担"相应的责任"（按过错程度确定份额），**非连带、非补充、非全额替代**；与监护人的责任是按份并存关系，受害人可同时主张。
3. **过错判断标准**：受托人是否尽到与受托照看相适应的合理注意（如是否妥善看管、是否及时制止危险行为）。临时帮忙照看 vs 长期受托，注意义务标准不同。
4. **与 §1188 衔接**：委托人（监护人）依 §1188 担替代责任；受托人依本条按过错担相应责任，二者并行。

## 三、蓝队（受害人/代理受害方·主张路径）

- **双列被告**：同时列监护人 + 受托人，分别主张 §1188 替代责任与 §1189 相应责任，扩大责任财产。
- **锁定受托人过错**：举证受托人疏于看管（如将幼童单独留于危险处、未制止攻击行为）→ 使其落入"相应责任"区间。

## 四、红队（受托人/防御路径）

- **无过错抗辩**：证明已尽合理照看义务（在场、制止、环境安全）→ 不构成"相应责任"。
- **仅为临时帮忙**：降低注意义务预期，区分"有偿受托机构"与"亲友临时帮忙"的过错认定尺度。
- **监护人责任优先**：主张受害人应先向监护人求偿，受托人仅在过错范围内补充。

## 五、适用场景（老强在办业务）

- 父母委托祖辈/亲友临时照看未成年人，期间孩子致人损害。
- 委托托育机构、培训机构期间发生第三人受害——注意 §1189（委托监护）与 §1199-1201（教育机构/无民事行为能力人在幼儿园学校受害）的责任竞合，需区分"委托照看"与"教育机构责任"两条线。
- 与 §1188 监护人、§1191 用人单位、§1192 个人劳务的责任边界区分。
