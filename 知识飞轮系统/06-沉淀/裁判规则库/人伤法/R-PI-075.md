# 裁判规则 R-PI-075：紧急救治中"好意签字"的免责边界

**规则**：在紧急情况下，为避免患者利益受损，与患者无近亲属关系的他人出于好意，在医院出具的麻醉协议书及手术治疗知情同意书上签字，且已尽到与处理自己事务同一注意义务的，不应因签字承担医疗损害赔偿责任。

**规范依据**：
- 《民法典》第1219条（医务人员说明义务与患者知情同意；紧急情况下不能或不宜向患者说明的，应向近亲属说明并取得其明确同意）
- 《民法典》第1165条（过错责任一般条款）

**适用边界**：
- **主体**：签字人非近亲属、出于好意（好意施惠），不构成医疗关系当事人，亦非医疗过错主体。
- **主观**：尽到"与处理自己同一事务相当"的注意义务——即合理信赖医方专业判断，未误导、未隐瞒、未擅作禁忌决定。
- **归责分层**：医疗损害赔偿责任主体为医疗机构（过错医疗行为）；签字好人仅在存在过错（如虚构身份、擅自同意禁忌手术、误导医方）时才担责。本情形无此过错，故免责。

**执业要点**：
- **患方/签字人代理**：厘清"好意签字"与"医疗过错"两层次责任——签字人不因知情同意书签字而替代或连带医疗机构责任；若遭索赔，以"好意施惠 + 无过错"抗辩。
- **医方代理**：紧急救治时如无法联系近亲属，可依法由近亲属以外的关系人签字（衔接《民法典》第1220条紧急救治条款精神），但须固定"紧急情况 + 无法及时联系近亲属"证据，避免事后被指程序瑕疵。

**关联**：与今日 A2《医疗纠纷处理全流程实务地图》《双窗口管理》及 R-PI-074 串联，构成"医患知情同意—责任主体—时效鉴定"医疗纠纷证据闭环。
