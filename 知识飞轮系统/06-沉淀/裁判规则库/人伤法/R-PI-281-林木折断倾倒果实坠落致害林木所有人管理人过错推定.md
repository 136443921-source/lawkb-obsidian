# 核心要旨

因林木折断、倾倒或者果实坠落等造成他人损害的，林木的**所有人或者管理人**不能证明自己没有过错的，应当承担侵权责任（民法典第1257条）。归责为**过错推定**，受害方证明致害事实与损害即可，所有/管理人须自证已尽修剪、养护、警示标志、风险排查等管理职责。

# 适用情形
- 行道树、小区绿化树、景区林木折断砸伤路人/车辆；
- 果树果实坠落砸伤；
- 台风、积雪、虫蛀等致林木倾倒伤人（管理方以"不可抗力/自然力"抗辩的，须证已尽前置养护义务）。

# 反向提示
- 责任主体为"所有人或者管理人"，不一定是种植者；物业、市政、景区运营方作为管理人的，承担管养义务；
- 过错推定下，"已尽合理管养"是免责关键证据（定期修剪记录、巡查台账、隐患告知）；
- 第三人致林木倾倒（如车祸撞树）的，可依第1250条向第三人追偿，不当然免除所有/管理人管养过错。

# 权威案例（元典回源·已核验）

# 办案衔接
- 受害人方：固定林木归属与管养主体，举证致害形态与损害；
- 所有/管理人方：提交养护巡查记录、隐患整改通知，证已尽管养职责争取免责。
