# R-PI-092 禁止饲养危险动物致害的绝对责任

## 规则表述

违反国家规定，**禁止饲养的烈性犬等危险动物**造成他人损害的，动物饲养人或者管理人承担侵权责任。该责任为**绝对责任**——不适用第 1245 条"受害人重大过失可以减轻"的规则，体现对禁养高危物种的严厉否定评价。

## 要件

1. 动物属"禁止饲养的烈性犬等危险动物"（依地方禁养名录认定）；
2. 无论饲养人是否牵绳、是否尽管理义务，均不影响责任成立；
3. **无减责/免责事由**（区别于一般动物的故意/重大过失减免责）；
4. 与 1246（违规未管控一般动物，仅排除重大过失减责）相比，1247 更严——连"故意"外的任何减责均不成立。

## 适用要点（攻防）

- **受害人（攻）**：证明动物属禁养名录（地方养犬条例）+ 致害事实，直接主张绝对责任；
- **饲养人（防）**：绝对责任下减责抗辩基本不成立，应转向保险理赔/限额协商，或证明受害人**故意**（极端挑衅，理论边界仍有争议，实务趋向零减责）。
