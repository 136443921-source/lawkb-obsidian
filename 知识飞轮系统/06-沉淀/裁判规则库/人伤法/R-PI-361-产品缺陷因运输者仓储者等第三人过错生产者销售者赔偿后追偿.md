# 核心要旨

因运输者、仓储者等第三人的过错使产品存在缺陷，造成他人损害的，产品的**生产者、销售者**仍须向被侵权人赔偿（对外不真正连带/择一索赔，见第1203条），但赔偿后**有权向有过错的第三人追偿**（民法典第1204条）。该条解决"缺陷源于供应链第三人"时的内部责任最终归属，不阻断受害人对生产者/销售者的直接请求权。

# 适用情形
- 运输途中野蛮装卸致产品破损、变质进而致害；
- 仓储温湿度失控致药品/食品失效致害；
- 物流分拣错误致瑕疵产品流出致害。

# 反向提示
- 对外责任：受害人仍可向生产者或销售者任一请求赔偿（第1203条），不受"缺陷源于第三人"影响；
- 追偿是**内部关系**：生产者/销售者须先对外赔付，再向运输者/仓储者举证其过错追偿；
- 生产者/销售者不得以"第三人过错"对抗受害人免责抗辩；但能证缺陷完全由第三人造成且己方无过错的，追偿后可实质出清。

# 权威案例（元典回源·已核验）
- **`(2015)广民终字第287号`** — 佛山市顺德区顾家宝电器有限公司与李某某产品生产者责任纠纷（四川省广元市中级人民法院，2015）。产品缺陷因运输者、仓储者及中间供货人过错所致，生产者赔偿后依侵权法第四十四条（≡《民法典》第1204条）向终局责任人追偿，法院阐明运输/仓储环节最终责任与追偿法理。
- **`(2020)京0114民初9965号`** — 房车汇（北京）汽车销售有限公司产品责任纠纷（北京市昌平区人民法院，2020）。销售者/生产者对外赔付后，依侵权法第四十三、四十四条（≡《民法典》第1203/1204条）向过错环节追偿。
- **`(2014)虞民初字1416号`** — 王海彦与吴永峰、张艳峰产品责任纠纷（河南省虞城县人民法院，2014）。销售者赔偿后向供货销售者追偿，援引民法通则第122条/侵权法第43条。

# 办案衔接
- 受害人方：直接告生产者/销售者，避免陷入供应链追偿拉锯；
- 生产者/销售者方：对外赔付后固定运输/仓储过错证据（运单、监控、温湿度记录）及时追偿。
