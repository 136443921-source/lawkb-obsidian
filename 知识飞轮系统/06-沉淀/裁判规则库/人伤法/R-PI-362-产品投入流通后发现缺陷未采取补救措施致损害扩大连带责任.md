# 核心要旨

产品投入流通后发现存在缺陷的，生产者、销售者应当及时采取**停止销售、警示、召回**等补救措施；未及时采取补救措施或者补救措施不力造成损害扩大的，对**扩大的损害**也应当承担侵权责任（民法典第1206条）。采取召回措施的，生产者、销售者还应负担被侵权人因此支出的必要费用。该条确立"流通后缺陷发现后的持续防控义务"，将责任延伸至缺陷发现后的扩大损害。

# 适用情形
- 车企、药企、家电厂发现批次缺陷后迟延召回致新增损害；
- 销售者收到厂家召回通知仍继续销售致害；
- 警示公告不充分的，扩大损害仍归责。

# 反向提示
- 责任范围限于"**扩大的损害**"：缺陷本身原有损害按第1202/1203条处理，本条只就"本可避免而因不作为致扩大"部分担责；
- "及时""足够"采客观标准：是否启动召回、警示是否覆盖合理受众、措施是否实质有效；
- 与第1207条惩罚性赔偿衔接：明知缺陷仍不补救致死亡/健康严重损害的，被侵权人可并行请求惩罚性赔偿。

# 关联法条（本地权威源回填·非凭记忆）

- **《中华人民共和国民法典》第1206条**（现行有效·本地权威源 `法律法规库/通用实体法/中华人民共和国民法典（全文）.md` 第4387–4389行逐字回填）："产品投入流通后发现存在缺陷的，生产者、销售者应当及时采取停止销售、警示、召回等补救措施;未及时采取补救措施或者补救措施不力造成损害扩大的，对扩大的损害也应当承担侵权责任。依据前款规定采取召回措施的，生产者、销售者应当负担被侵权人因此支出的必要费用。"

# 权威案例（元典回源·已核验）
- **`(2025)陕01民终11467号`** — 西安A有限公司与张XX买卖合同纠纷（陕西省西安市中级人民法院，2025）。玉米收获机交付后持续出现质量缺陷，买受人主张"产品投入流通后发现缺陷，生产者/销售者未及时采取召回等补救措施致损害扩大，应就扩大损害担责"（《民法典》第1206条）；本案为第1206条"流通后缺陷发现后持续防控义务"的典型事实型，法院最终以合同解除、退还75%购车款处理，但原告第1206条抗辩明确了"未及时召回/补救→扩大损害"的归责逻辑。
- **`（2021）京03民终18837号`** — 永康市赫朗健身器材有限公司等与王某产品责任纠纷（北京市第三中级人民法院，2021）。免打孔单杠滑脱致未成年人受伤，被告答辩涉"未采取停止出售、警示、召回等补救措施属扩大损害行为"，体现第1206条补救义务边界。
  - 元典核验：yuandian_rh_ptal_search（全文关键词「召回 缺陷 补救措施 扩大损害」and 检索，2026-09-09）；两例均仅作裁判要旨锚定，正式引用前须二次核对。

# 办案衔接
- 受害人方：固定"已发现缺陷+未补救/补救不力+损害扩大"证据链，主张扩大部分赔偿及召回必要费用；
- 生产者/销售者方：举证已及时启动召回、充分警示，限缩扩大损害范围。
