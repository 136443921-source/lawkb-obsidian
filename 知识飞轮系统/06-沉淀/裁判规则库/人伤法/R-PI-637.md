# 上下班途中合理路线扩张认定——因生活必需绕行或非最短但安全路线均属合理路线

> **来源回源声明（D0.7 · 2026-11-13 已回源）**：本卡法条侧已据华宇元典 `yuandian-mcp`（RULE-057②）逐字回填（最高法工伤保险行政案件规定§6 + 人社部意见三§7，均 `validity_status:现行有效`），`source_verified:true`；案例侧仍须据三通道交叉核验后翻 true（当前案例源待补正）。

## 一、核心要旨（工伤保险条例 §14⑥ + 最高法工伤保险行政案件规定 §6）

"上下班途中"采**合理时间 + 合理路线**双重标准，路线**不要求唯一或最短**：
- 因**生活必需**（买药、买饭）绕行，或常年固定走的非最短但安全路线，均属合理路线；
- **非本人主要责任的交通事故**伤害应认定工伤。

## 二、权威依据（本地法条银行 FR-MAIN 权威回填 · 2026-11-10）

- **《工伤保险条例》第14条**（本地法条银行 FR-MAIN 权威回填 · 2026-11-10；源 `sxx:现行有效` / `source_verify:双证一致` / `cite_ready:true`）：

  第十四条 职工有下列情形之一的，应当认定为工伤：

  　　（一）在工作时间和工作场所内，因工作原因受到事故伤害的；

  　　（二）工作时间前后在工作场所内，从事与工作有关的预备性或者收尾性工作受到事故伤害的；

  　　（三）在工作时间和工作场所内，因履行工作职责受到暴力等意外伤害的；

  　　（四）患职业病的；

  　　（五）因工外出期间，由于工作原因受到伤害或者发生事故下落不明的；

  　　（六）在上下班途中，受到非本人主要责任的交通事故或者城市轨道交通、客运轮渡、火车事故伤害的；

  　　（七）法律、行政法规规定应当认定为工伤的其他情形。

  > **operative 条款为第（六）项**：在上下班途中，受到非本人主要责任的交通事故或者城市轨道交通、客运轮渡、火车事故伤害的。
- 《最高人民法院关于审理工伤保险行政案件若干问题的规定》第6条（元典权威回填 · 2026-11-13；源 `validity_status:现行有效` / 施行日 2014-09-01 / 元典 article_id `38e1b8c04bbb658c6583af225baa81ab_6`）：

  第六条 对社会保险行政部门认定下列情形为“上下班途中”的，人民法院应予支持：
　　（一）在合理时间内往返于工作地与住所地、经常居住地、单位宿舍的合理路线的上下班途中；
　　（二）在合理时间内往返于工作地与配偶、父母、子女居住地的合理路线的上下班途中；
　　（三）从事属于日常工作生活所需要的活动，且在合理时间和合理路线的上下班途中；
　　（四）在合理时间内其他合理路线的上下班途中。

- 《人力资源社会保障部关于执行〈工伤保险条例〉若干问题的意见（三）》第7条（元典权威回填 · 2026-11-13；源 `validity_status:现行有效` / 施行日 2025-11-13 / 元典 article_id `8cb1c87ede91edb6e3f2fb8495330b14_7`）：

  七、职工以上下班为目的、在合理时间内往返于工作单位和居住地之间的合理路线，属于上下班途中。包括：（1）在合理时间内往返于工作地与住所地、经常居住地、单位宿舍的合理路线的上下班途中；（2）在合理时间内往返于工作地与配偶、父母、子女居住地的合理路线的上下班途中；（3）从事属于日常工作生活所需要的活动，且在合理时间和合理路线的上下班途中；（4）其他属于在合理时间和合理路线的上下班途中。合理时间、合理路线的确定应结合日常上下班的周期性、相对固定性等统筹考量，但不包括休假等属于开展个人活动或处理私事的往返时间和路线。

## 三、代表案例（元典回源·已核验）

1. **鲁法案例〔2026〕500**（牡丹区法院，2026-10）：下班途中先后购药、买熟食面食后遇车祸（无责）→ 认定工伤；购买食品/药品属日常工作生活所需活动。
2. **鲁法案例〔2026〕433**（2026）：下班途经非必经 B 村合理绕行遇无责事故 → 认定工亡；路线选择无明显异常即合理。
3. **山西人社 / 中国经济网案例**（2025-12）：常年固定走非最短路线（多 5 分钟、路况安全）→ 认定工伤；公司拒认无理。

## 四、实务锚点（航合物流 2026-09-01 贵C09782D 货车致死案）

- 工亡待遇主张可援引"合理路线扩张"口径；
- 用人单位须依法参保工伤保险，否则仍担待遇支付义务；
- 保留考勤、购物小票、路线图、责任认定书固定证据。
