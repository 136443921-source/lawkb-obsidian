# R-PI-214 “开门杀”属机动车一方责任及保险人不得以乘车人非被保险人拒赔

> 一句话：**乘车人**开车门致他人损害（“开门杀”），依《道交解释（二）》（法释〔2026〕9号）第二条，其责任**属于民法典1213条所称“该机动车一方责任”**——受害人可直接请求交强险保险人在责任限额内赔偿、商业三者险保险人按合同约定赔偿；保险人**不得以“乘车人不属于被保险人或其允许的驾驶人”为由抗辩**；赔偿不足部分由乘车人、驾驶人依侵权责任编承担。**且交强险保险人赔付后向乘车人追偿的，法院不予支持（乘车人故意除外）**。

## 一、规范基底

**《道交解释（二）》（法释〔2026〕9号）第二条**（2026年6月30日施行）：
> 机动车乘车人开车门致他人损害，被侵权人一并起诉乘车人、驾驶人以及承保该机动车交通事故责任强制保险（以下简称交强险）、第三者责任商业保险（以下简称商业三者险）的保险人，主张乘车人责任属于该机动车一方责任，并依据民法典第一千二百一十三条关于交通事故责任承担主体赔偿顺序的规定，请求由承保交强险的保险人在责任限额范围内予以赔偿、承保商业三者险的保险人按照保险合同的约定予以赔偿的，人民法院应予支持；保险人以乘车人不属于被保险人或者其允许的驾驶人为由抗辩不承担赔偿责任的，人民法院对该抗辩不予支持。赔偿后不足的，由乘车人、驾驶人依据民法典第七编侵权责任的规定承担赔偿责任。
>
> 承保交强险的保险人承担赔偿责任后向乘车人追偿的，人民法院不予支持，但是损害是因乘车人故意造成的除外。

**《民法典》第一千二百一十三条**（本地权威源回填）：机动车发生交通事故造成损害，属于该机动车一方责任的，先由承保机动车强制保险的保险人在强制保险责任限额范围内予以赔偿；不足部分，由承保机动车商业保险的保险人按照保险合同的约定予以赔偿；仍然不足或者没有投保机动车商业保险的，由侵权人赔偿。

## 二、规则要旨（教义提炼）

1. **扩张解释“机动车一方责任”**：突破“被保险人/允许的驾驶人”这一保险合同主体限定，把**乘车人的开门行为**纳入机动车运行风险范畴。理论落点是**机动车运行支配与运行利益说**的场景化延伸——开门是车辆使用过程的必要环节。
2. **保险人抗辩被立法性封堵**：条文明确“对该抗辩不予支持”，这是**规范性排除**，不留裁量空间。保险人再以条款约定抗辩，属与司法解释相悖。
3. **追偿权被反向限制**：交强险保险人赔付后**原则上不得向乘车人追偿**，仅“乘车人故意造成损害”为例外。这与交强险的社会保障属性一致——交强险不是为乘车人个人担责，而是为受害人兜底。
4. **赔偿顺位固定**：交强险限额 → 商业三者险按约 → 不足部分由乘车人+驾驶人按侵权责任编承担（可构成共同侵权或按份责任，视驾驶人是否有提醒/停车位置选择过错）。
5. **驾驶人过错独立评价**：驾驶人若在非机动车道边、路口、盲区停车致开门风险升高，或未提醒乘车人观察后方，可与乘车人共同担责。

## 四、执业动作

🔵 **受害人方**：①起诉时**一并列**乘车人、驾驶人、交强险保险人、商业三者险保险人为被告（第2条以“一并起诉”为适用前提之一）；②明确援引解释（二）第2条 + 民法典1213条；③对保险人“乘车人非被保险人”抗辩直接引条文封堵；④审查驾驶人停车位置与提醒义务，扩大责任主体。

🔴 **保险人/乘车人方**：①保险人抗辩重心转向**损失数额、伤残等级、因果关系**，而非主体资格；②乘车人若被追偿，主张自身无“故意”（过失开门不构成故意）；③注意第12条时间效力——事故或案件是否落入 2026-06-30 后尚未终审的区间。

## 五、涵摄断裂标本

- 继续沿用旧观点“乘车人非被保险人，保险公司不赔” → 已被第2条明文否定，属**规范过时**。
- 把开门杀按一般侵权（民法典1165条）处理而不走 1213 保险顺位 → 受害人丧失交强险优先赔付利益。
- 忽略“一并起诉”的适用前提，只诉乘车人再另诉保险人，程序上增加障碍。
- 误认为交强险赔付后必然可向乘车人追偿 → 第2条第2款已限缩为“故意”例外。
