# 多因一果医疗损害——医疗过错与交通事故/原发病情竞合时，按原因力大小承担按份责任

> ✅ **来源回源声明（D0.7 · 2026-11-06 回源补正）**：三通道（ima-mcp / yuandian-mcp / qcc-legal）已恢复实调可用。本条法条经「本地法条银行 FR-MAIN（民法典1218/1172）+ 元典 yuandian-mcp + qcc-legal（医疗损害司法解释2020修正第11/12条）」逐字核验一致，`source_verified` 翻为 `true`。

## 一、核心要旨

1. **原因力六档分级（最高法医疗损害司法解释第12条）**：鉴定意见可按"全部原因 / 主要原因 / 同等原因 / 次要原因 / 轻微原因 / 无因果关系"表述诊疗行为或医疗产品造成患者损害的原因力大小。
2. **多因一果按份责任（民法典第1172条）**：二人以上分别实施侵权行为造成同一损害，能够确定责任大小的各自承担相应责任；难以确定责任大小的，平均承担。
3. **医疗过错与交通事故/原发病情竞合**：患者因第三人侵权（如交通事故）受伤后就诊，医院漏诊、延误或过错加重损害，构成"多因一果"，医院仅就医疗过错的原因力部分担责——先按"一果"确定全部赔偿额，再按各侵权人原因力比例分割（甘民再40号、豫民申2385号、宁民申749号）。

## 二、权威依据（三通道回源核验 · 2026-11-06 · 法条银行+元典+qcc一致）

- **《中华人民共和国民法典（全文）》第1218条**：患者在诊疗活动中受到损害，医疗机构或者其医务人员有过错的，由医疗机构承担赔偿责任。
- **《中华人民共和国民法典（全文）》第1172条**：二人以上分别实施侵权行为造成同一损害，能够确定责任大小的，各自承担相应的责任；难以确定责任大小的，平均承担责任。
- **《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释（2020修正）》第11条**：委托鉴定书，应当有明确的鉴定事项和鉴定要求。鉴定人应当按照委托鉴定的事项和要求进行鉴定。下列专门性问题可以作为申请医疗损害鉴定的事项：（一）实施诊疗行为有无过错；（二）诊疗行为与损害后果之间是否存在因果关系以及原因力大小；（三）医疗机构是否尽到了说明义务、取得患者或者患者近亲属明确同意的义务；（四）医疗产品是否有缺陷、该缺陷与损害后果之间是否存在因果关系以及原因力的大小；（五）患者损伤残疾程度；（六）患者的护理期、休息期、营养期；（七）其他专门性问题。鉴定要求包括鉴定人的资质、鉴定人的组成、鉴定程序、鉴定意见、鉴定期限等。
- **《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释（2020修正）》第12条**：鉴定意见可以按照导致患者损害的全部原因、主要原因、同等原因、次要原因、轻微原因或者与患者损害无因果关系，表述诊疗行为或者医疗产品等造成患者损害的原因力大小。

## 三、贴合在办业务

- **韩杰医疗事故罪再审**：结果归责须严格区分"医疗行为原因力"与"患者自身病情进展 / 第三人因素"，因果关系与原因力大小是"严重不负责任"与损害结果之间归责的核心辩护支点（多因一果下医方仅就过失医疗行为参与度担责）。
- **面瘫后遗症针灸调理协议合规**：知情同意边界与损害归因——患者出现不良后果时须区分"针灸诊疗行为"与"自身体质/病情"的原因力。

## 四、检索来源

- 青海司法厅（2023 案例）：甲医院过错与损害同等原因（50%），丙医院无过错不担责。
- 济南槐荫法院：原因力建议次要至同等，酌定医方承担 40%。
- 山东高法/法信"多因一果"裁判规则汇编（豫民申2385、甘民再40、陕民申3093 等）。
