# 核心要旨

未经许可进入高度危险活动区域或者高度危险物存放区域受到损害，管理人能够**证明已经采取足够安全措施并尽到充分警示义务**的，可以**减轻或者不承担责任**（民法典第1243条）。该条是高度危险责任一般条款（第1236条）下的**减责/免责特别事由**，针对"自陷风险"型受害人，举证责任在管理人。

# 适用情形
- 无关人员翻越围栏进入高压变电站、爆破作业区、危险品仓库致伤；
- 游客擅入未开放危险景区、施工禁区受损害；
- 儿童钻入危险设备区致伤（监护人过错可结合第1188条评价）。

# 反向提示
- 减责/免责前提严格：须同时证"足够安全措施＋充分警示义务"，二者缺一不可；仅设警示而无物理隔离的，未必免责；
- 与第1244条区分：第1244条免责事由为"受害人故意/不可抗力"、减责为"重大过失"；第1243条针对"未经许可进入"场景，管理人主动举证安全措施与警示充分；
- 管理人未设任何标识、无隔离的，即使受害人擅自进入，仍可能承担高度危险无过错责任（第1236条）+安保违反相应责任。

# 权威案例（元典回源·已核验）
- **`(2025)晋1181民初48号`** — 梁某某、山西某某发运有限公司健康权纠纷（山西省孝义市人民法院，2025）。受害人未经许可进入铁路桥面作业区，水泥板脱落致伤；管理人虽设部分警示但安全措施不充分，法院依《民法典》第1243条认定管理人未尽充分安全防护与警示，判令承担 **40%** 责任（减责而非免责）。

# 办案衔接
- 受害人方：主张管理人安全措施不足（无隔离/警示缺失），破减责抗辩；
- 管理人方：举证物理隔离、警示标识、巡逻制止记录，争取减责或免责。
