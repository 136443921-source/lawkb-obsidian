# 核心要旨

医疗损害责任采**过错责任**（民法典第1218条），过错与因果关系通常依鉴定意见认定，但鉴定意见只是法定证据之一，**不能替代法官法律判断**。

- **鉴定意见须依法审查，禁止"以鉴代审"**：法院应组织质证，对鉴定意见的**真实性、合法性、关联性**全面审查；鉴定意见仅为专业技术参考，裁判须由法官依全案证据作出（慈利县法院2025一审、二审维持）。
- **重新鉴定后原意见失效**：启动重新鉴定程序的，原鉴定意见**不得再作为定案依据**；新意见仍须接受审查，法院可在鉴定数值区间外结合案情酌定参与度。
  - 例：原鉴定过错参与度 45%–55% → 重鉴下调为 5%–15% → 法院以"仅以程序瑕疵（未行术前讨论）认定低参与度明显不当"为由，**酌定 35%**。
- **漏诊漏治 + 未尽告知 = 同等责任（约 50%）**：医院术中发现其他肿物未探查切除、且未书面告知的，构成漏诊漏治与告知缺陷，与自身疾病"原因力相当"→ 承担 50% 赔偿责任；九级伤残，护理期/营养期各 90 日（来凤县法院2025，双方无异议采纳鉴定意见）。
- **重新鉴定门槛**：医方申请重新鉴定须符合"鉴定依据明显不足、程序严重违法"等法定情形；仅以"参与度偏高"不足以启动（温州中院2025 驳回重鉴、维持按鉴定意见认定次要责任）。

# 关联法条

- 《民法典》第1218条（医疗损害过错责任）、第1219条（说明义务与知情同意）、第1225条（病历资料保管）。
- 《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释》（法释〔2017〕20号，2020修正）第11–16条（鉴定程序启动、鉴定意见审查、重新鉴定、过错参与度的司法认定）。

# 适用场景

- **韩杰医生医疗事故罪再审辩护**：区分刑事"严重不负责任"与民事过错参与度，本案聚焦鉴定意见证据地位与"以鉴代审"否定思路，作为民事附带审查锚点。
- **面瘫后遗症针灸调理医疗纠纷**：预判"漏诊/操作不当 + 告知缺陷"的过错推定路径与参与度酌定逻辑，为协议合规边界（疗效承诺红线）提供反向抓手。
- **医疗损害诉讼代理**：收到鉴定高参与度意见时，依本卡审查是否具备重新鉴定法定情形；不具备时转向"鉴定数值区间外酌定"的攻防。
