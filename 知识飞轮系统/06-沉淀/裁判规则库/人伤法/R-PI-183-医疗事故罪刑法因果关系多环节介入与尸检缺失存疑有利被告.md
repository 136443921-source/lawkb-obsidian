# R-PI-183｜医疗事故罪的刑法因果关系：多环节介入与尸检缺失时的"存疑有利于被告"

## 裁判规则

医疗事故罪的成立，**民事上构成医疗事故并承担主要责任仅为前提**，刑事上仍须就"严重不负责任"与**刑法意义上的因果关系**独立达到**排除合理怀疑**的证明标准。医学会医疗事故技术鉴定关于"主要责任"的责任程度意见，系**原因力评价**，不得直接替代刑事因果关系的独立判断。

就诊人死亡**未行尸检**，致死亡原因、损害发生（如嵌顿疝发作）时点无法精确确定，且诊疗过程存在**交班、转诊、患方自主转运**等多环节介入因素的，因果链条的**起点与归属存疑**，应作有利于被告人的认定。民事证明采"高度盖然性"（《民法典》第1218条），刑事证明采"排除合理怀疑"，二者存在**证明标准落差**——民事上 85% 的过错责任判决不能反推刑事有罪。

## 适用范围

- 医疗事故罪的**再审 / 申诉**辩护（因果链条断裂抗辩）
- 医疗损害刑民交叉案件中"罪与非罪"边界厘定
- 尸检缺失案件的事实查明不能之责任归属

## 关联法条

- 《刑法》第335条（医疗事故罪，**现行有效**）
- 最高检、公安部《关于公安机关管辖的刑事案件立案追诉标准的规定（一）》——"严重不负责任"七情形，其中**第六类**"严重违反国家法律法规及有明确规定的诊疗技术规范、常规"；并界定"严重损害就诊人身体健康"为造成严重残疾、重伤、感染艾滋病/病毒性肝炎等难以治愈疾病或其他严重后果
- 《民法典》第1218条（医疗损害责任一般条款，**现行有效**）
- 《医疗纠纷预防和处理条例》（尸检通常在医患双方对死因有异议时进行）

## 实务要点

### 一、核心抗辩：证明标准落差（最强教义学支点）
| 维度 | 民事（医疗损害责任） | 刑事（医疗事故罪） |
|---|---|---|
| 证明标准 | 高度盖然性 | 排除合理怀疑 |
| 责任主体 | **医疗机构**（医务人员属职务行为） | 医务人员个人 |
| 鉴定效力 | 医学会"主要责任"可直接定责比例 | 责任程度≠刑事"严重不负责任"，须独立评价 |
| 后果 | 赔偿（146 万余元，85% 责任） | 自由刑 + 从业禁止（一年 / 禁止三年） |

**论证链**：民事判决医院担 85% 责任 → 属"高度盖然性"下的原因力分配 → 不排除其他合理怀疑 → 未达刑事定罪标准 → 罪疑从无。

### 二、五大再审争点（韩杰案·江西抚州）
1. **尸检缺失 → 死因与时点不可精确**。未尸检，无法区分嵌顿疝发作于**入院前 / 住院治疗期间 / 家属自驾转院途中**。刑法要求因果链条起点确定，起点存疑即"合理怀疑"成立。
2. **多环节介入（三地点）**。因果链上介入：①首诊医院（韩杰在岗期间漏诊）→ ②交班后接班团队"完全照搬保守补液方案、未提外科急会诊、未启动紧急转诊"→ ③**家属自驾转院途中**（私家车无急救支持，颠簸与施救操作可能加重腹腔压力）→ ④江西省儿童医院。控方仅就①追责，须审查**介入因素是否中断或稀释因果链**。
3. **交班能否转移责任**。控方（法院）认定："交班仅转移后续观察义务，**无法抵消在岗阶段形成的不可逆诊疗过错**，延误救治的因果链条自漏诊那一刻已形成"。辩方应攻击"**不可逆**"的认定基础——若尸检缺失，则无法证明在岗阶段的漏诊已形成不可逆链条。
4. **"严重不负责任"入罪标准之争**。罗翔主张**折中说**：除抽象规章制度外，须有**代入性思维**，"站在被指控人的立场思考"，考虑**地方差异、学科差异、各地医疗水平不同**；对立面为规范违反说（该查体未查体即违反规范）。与 R-PI-181"新综合说"可并用。
5. **三重追责不竞合，但可量刑酌定**。民事和解、行政处罚**不阻却刑事追诉**（民事赔了、行政罚了，家属仍可报案；公安立案由卫健委行刑衔接移送启动）。但已足额赔偿、已受行政处罚应作为**量刑酌定情节**主张。

### 三、程序性要点
- 医疗事故罪**非自诉案件**：由卫健委行刑衔接移送 → 公安立案侦查 → 检察公诉。
- 辩护切入时机：拿到医学会鉴定报告后家属即可报案，故**民事阶段即应同步部署刑事风险评估**。
