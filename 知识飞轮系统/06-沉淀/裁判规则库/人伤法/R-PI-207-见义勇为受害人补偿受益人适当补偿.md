# R-PI-207 见义勇为致自身损害由受益人适当补偿

> 一句话：因保护他人民事权益使自己受到损害的，先由**侵权人**承担民事责任，**受益人可以给予适当补偿**；无侵权人、侵权人逃逸或无力担责，受害人请求补偿的，受益人**应当**给予适当补偿。注意本条是"**补偿**"而非"**赔偿**"，具补充性、适当性。

## 一、法条基底（本地权威源回填）

- 《民法典》第183条：因保护他人民事权益使自己受到损害的，由侵权人承担民事责任，受益人可以给予适当补偿。没有侵权人、侵权人逃逸或者无力承担民事责任，受害人请求补偿的，受益人应当给予适当补偿。

## 二、规则要旨（教义提炼）

1. **责任顺位**：见义勇为致自身人身损害，第一责任人是侵权人（按相应侵权规则担责）；受益人责任是**补充性**的。
2. **"可以"与"应当"的分层**：有侵权人且可担责时，受益人补偿系"可以"（鼓励性、任意性）；无侵权人/逃逸/无力时，受益人"应当"适当补偿（强制性）。
3. **补偿≠赔偿**：补偿数额具"适当性"，综合考量——受益人受益范围、受害人实际损失、双方经济能力、当地生活水平，而非全额填平。
4. **人伤场景**：制止违法犯罪、抢险救灾、救助遇险者致自身受伤（如追小偷被车撞、救落水者自己溺水伤），均落入本条。

## 三、涵摄断裂标本（高频翻车）

- 误将受益人"补偿"主张为"全额赔偿" → 本条仅"适当补偿"，与侵权赔偿的填平原则不同；受害人应向侵权人主张赔偿，向受益人仅得补偿。
- 混淆 183（见义勇为）与 182（紧急避险）→ 182 是"为避免危险损害第三人/公共利益"，183 是"为保护他人权益自身受损"；前者针对避险行为致损，后者针对救助行为致己损。
- 误以为受益人一律免责 → 在无侵权人/逃逸/无力时，受益人"应当"补偿，属强制性义务。
