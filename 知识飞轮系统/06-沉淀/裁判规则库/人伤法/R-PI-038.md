# 裁判规则 R-PI-038：非医保用药（自费药）扣除抗辩须完成双重举证

**规则**：非医保用药 ≠ 非必需/不合理用药；保险公司主张在商业三者险内扣除非医保用药费用，须承担**双重举证责任**，缺一不可：① 保险合同"医保外用药免责"条款已履行《保险法》第17条第2款提示+明确说明义务（否则条款不生效）；② 证明案涉非医保费用"超过基本医疗保险同类医疗费用标准"，即存在同疗效、可替代的低价医保目录内药品及具体价格差额。仅以单方医疗审核报告或笼统"扣除15%"的，因举证不能不予支持。

**规范依据**：
- 《保险法解释三》第19条：保险合同约定按基本医疗保险标准核定医疗费用，保险人以超出范围拒付的不予支持；有证据证明超出同类医保费用标准的，对超出部分可拒付。
- 《人损解释》第6条：赔偿义务人对治疗必要性和合理性有异议的，应承担举证责任。
- 《保险法》第17条第2款：免除保险人责任的条款，未尽提示+明确说明义务的，不生效。

**适用场景**：
- 商业三者险范围内保险公司抗辩"扣除非医保/自费药"。
- 受害方诉请医疗费包含医保外用药。

**攻防要点**：
- 受害方（原告）：固定正规发票+病历+诊断+费用清单+外购药医嘱；论证用药由主治医生依伤情决定、受害人无选择权；查投保单/保单未见醒目提示及签字确认的，主张条款不生效。
- 保险方（被告）：提供免责条款加粗提示页+投保人签字的明确说明确认书；委托鉴定或医保目录比对证明同疗效替代药差额；必要时申请司法鉴定。
- 贵州本地：贵阳/遵义法院多审慎，原则不主动核减，除非完成双重举证。

**主题簇关联**：与 [[R-PI-036]]（基金已付医疗费抵扣）、[[R-PI-037]]（新职伤待遇不抵扣）、[[R-PI-039]]（商业险不阻却侵权）合订于 [[主题卡-人伤费用承担边界]]；与 [[R-PI-034]]（特殊体质不扣减）共组"法定赔偿项目优先于保险内部规则"。
