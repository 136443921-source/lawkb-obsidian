# 裁判规则 R-PI-066：重新鉴定的法定启动条件

**规则**：当事人对司法鉴定意见有异议，申请重新鉴定，须具备下列情形之一，由法院审查决定是否准许，**并非"不服即重鉴"**：
1. 鉴定机构或者鉴定人员不具备相关的鉴定资格的；
2. 鉴定程序严重违法的；
3. 鉴定意见明显依据不足的；
4. 经过质证认定不能作为证据使用的其他情形；
5. 同一专门性问题出现相互矛盾的鉴定结论（如前后鉴定冲突且无法采信）。
- 对有缺陷的鉴定结论，可通过**补充鉴定、重新质证或者补充质证**等方式解决，不予重新鉴定。
- 医疗损害中警惕"以鉴代审"：应主动拆解诊疗过错，而非简单依赖重新鉴定推翻。

**规范依据**：
- 《最高人民法院关于民事诉讼证据的若干规定》第40条（原第27条）。
- 《全国人大常委会关于司法鉴定管理问题的决定》第13条（鉴定人违法责任）。
- 《医疗事故处理条例》第26条（再次鉴定程序，针对医疗事故技术鉴定）。

**适用场景**：
- 人伤/医疗损害案件中对伤残等级、三期、过错参与度、因果关系鉴定结论不服，拟申请重新鉴定。
- 对方申请重新鉴定时的抗辩（指出不具备法定事由）。

**攻防要点**：
- 申请方：须在举证期限内提出，明确指向具体法定事由并举证（如鉴定机构无资质、检材污染、分析方法错误）；仅"结论不合理"不足以启动。
- 抗辩方：主张以补充鉴定/质证解决瑕疵；指出对方未在期限申请或事由不成立。
- 提示：医学会医疗事故技术鉴定与司法鉴定分属两套，医疗损害责任纠纷中多委托司法鉴定，重新鉴定亦按民诉证据规定审查。

**提炼来源**：《民事证据规定》第40条等提炼，2026-08-05；配套 02-提炼笔记《人伤伤残鉴定攻防-重新鉴定与鉴定人出庭质证实务-2026-08-05》。
