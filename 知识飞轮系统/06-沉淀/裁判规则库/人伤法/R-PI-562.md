# R-PI-562 医务人员未尽说明义务的赔偿责任（民法典§1219 知情同意）

> 降级采集声明：2026-10-17 全通道 absent。法条侧据本地法条银行逐字回填；案例侧无交叉核验 → `source_verified:false`。
> 适用：韩杰医生医疗事故罪再审辩护、面瘫针灸医疗服务协议合规审查（疗效承诺/治愈保证边界）。

## 一、核心法条（已逐字核验·本地法条银行）

**《民法典》第一千二百一十九条**【医务人员说明义务和患者知情同意权】
> 医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施手术、特殊检查、特殊治疗的，医务人员应当及时向患者具体说明医疗风险、替代医疗方案等情况，并取得其明确同意；不能或者不宜向患者说明的，应当向患者的近亲属说明，并取得其明确同意。

## 二、构成要件（说明义务违反的认定）

1. **一般说明义务**：病情 + 医疗措施（基础性告知，无需"明确同意"但须告知）。
2. **特殊情形的强化说明 + 明确同意**：手术、特殊检查、特殊治疗 → 须**具体说明医疗风险、替代医疗方案**并取得**明确同意**（区别于概括签字）。
3. **告知对象替代**：不能/不宜向患者说明时，转向近亲属并取得明确同意。
4. **举证责任**：医疗损害责任一般归过错责任；但**未尽说明义务**本身即构成过错要件之一，患方只需证明"未告知/未取得明确同意"即成立该过错（具体损害因果另证）。

## 三、蓝队（患方/代理患方·主张路径）

- **概括签字无效抗辩**：仅签署格式《知情同意书》而未就"医疗风险、替代方案"具体说明 → 主张未达 §1219"明确同意"标准，医方过错成立。
- **风险未告知**：手术并发症、替代治疗方案未告知即实施 → 即使结果符合医疗常规，仍可能因程序过错担责。
- **病历补强**：调取病历中告知记录缺失/模板化 → 反证说明义务未履行。

## 四、红队（医方/代理医院·防御路径）

- **履行留痕**：手术/特殊治疗须有"具体风险+替代方案"书面告知 + 患者/近亲属**明确签字**；模板化概括条款不足以抗辩。
- **紧急避险例外**：因抢救生命垂危等紧急情况不能取得患者/近亲属意见，经批准可立即实施相应医疗措施（《民法典》第1220条）——不构成未尽说明。
- **面瘫针灸协议专项**：疗效承诺/治愈保证类条款与 §1219 说明义务联动——协议须明确告知"疗效不确定、个体差异、可能的不良反应"，不得以"保证治愈"替代风险告知，否则既违反广告法亦违反说明义务精神。

## 五、适用场景（老强在办业务）

- **韩杰医生医疗事故罪再审辩护**：审查原审是否以"未尽说明义务"作为过错/责任依据；若原审将"未告知替代方案"作为定罪环节，本卡明确 §1219 系民事赔偿过错要件，刑事医疗事故罪须证明"严重不负责任 + 造成就诊人死亡/严重损害"，说明义务瑕疵须置于刑事构成要件下独立评价。
- **面瘫针灸医疗服务协议合规审查**：协议条款须将"风险告知 + 替代方案"作为必备模块，疗效承诺表述须合规（《广告法》禁止治愈保证）。
- **医疗损害责任纠纷**中患方以"不知情"主张赔偿的攻防。
