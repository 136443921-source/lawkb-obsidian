# 核心要旨

堆放物倒塌、滚落或者滑落造成他人损害的，实行**过错推定**——堆放人不能证明自己没有过错的，应当承担侵权责任（民法典第1255条）。受害人仅须证明堆放物致害事实与损害，堆放人须自证已尽合理堆放、固定、警示义务，否则推定有过错。

# 适用情形
- 工地、仓库、商家门前货物、建材、杂物堆放倒塌压伤路人；
- 小区楼道、阳台外置物品滚落致害；
- 农村柴草、农具堆垛滑落伤人。

# 反向提示
- 归责为**过错推定**而非无过错：堆放人举证己方无过错（稳固堆放、设置警示、合理选址、已尽管理）即可免责，区别于饲养动物（第1245条无过错）；
- 致害形态限于"倒塌、滚落、滑落"，不包括抛掷（抛掷适用第1254条高空抛物或一般侵权）；
- "堆放人"指实际堆放、控制该物之人，非当然为所有人；所有人、管理人另有过错的可叠加追责。

# 办案衔接
- 受害人方：固定堆放事实、致害形态、损害，直指过错推定减轻己方举证；
- 堆放人方：举证稳固堆放与警示记录、合理选址，争取免责或减责。
