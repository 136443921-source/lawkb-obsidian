# R-PI-198 医疗损害责任纠纷举证证明责任分配与鉴定意见采纳规则

## 一、规则要旨

1. **举证责任采"双层分配"而非单向倒置**：患方先承担"到该机构就诊 + 受到损害"的初步举证；患方无法提交过错与因果关系证据的，法院**应当准许**其鉴定申请；医疗机构主张不担责的，须就《民法典》第1224条第1款等抗辩事由举证。
2. **患方初步举证的证明标准较低**：诊疗行为可综合挂号单、交费单、病历、出院证明等综合认定，不苛求形式完备。
3. **病历瑕疵分两档**：伪造、篡改、涂改、遗失、销毁、抢夺致无法认定，或病历明显矛盾/错误且不能合理解释的，由改变或遗失一方承担不利后果；**仅错别字、未按规范格式书写等形式瑕疵，不影响病历真实性认定**。
4. **鉴定意见的采纳与重新鉴定的驳回**：医方否认鉴定意见但未提供第1224条第1款免责情形证据，且鉴定人已出庭接受质询的，法院采纳鉴定意见并**不准许重新鉴定**，可在参与度区间内酌定责任比例。

## 二、规范依据（已核验）

| 条文 | 内容要点 | 举证归属 |
|---|---|---|
| 《民法典》第1218条 | 患者在诊疗活动中受到损害，医疗机构**或者其**医务人员有过错的，由医疗机构承担赔偿责任 | 归责原则（过错责任） |
| 《民法典》第1221条 | 医务人员未尽到与当时医疗水平相应的诊疗义务致患者损害，医疗机构赔偿 | 诊疗义务标准 |
| 《民法典》第1222条 | 推定过错三情形：①违反法律、行政法规、规章及诊疗规范；②隐匿或拒绝提供病历资料；③遗失、伪造、篡改或违法销毁病历资料 | **患方举证**（推定过错事实） |
| 《民法典》第1224条第1款 | 免责三情形：①患者或近亲属不配合符合诊疗规范的诊疗；②抢救生命垂危等紧急情况已尽合理诊疗义务；③限于当时医疗水平难以诊疗 | **医方举证**（抗辩事由） |
| 《民法典》第1224条第2款 | 第1款第①项情形下，医疗机构或其医务人员**也有过错的，应承担相应的赔偿责任** | 医方过错减责不完全免责 |
| 《医疗损害司法解释（2020修正）》第4条 | 三款：患方提交就诊+损害证据；无法提交过错/因果关系证据而申请鉴定的法院应予准许；医疗机构主张不担责的应就第1224条第1款等抗辩事由举证 | 举证分配 |

> 📌 **条文沿革**：相较原司法解释，《医疗损害司法解释（2020修正）》第4条第二款将"医疗机构**及其**医务人员"修正为"医疗机构**或者其**医务人员"，与《民法典》第1218条用语保持一致。

## 三、实例：（2023）桂0821民初3*16号

**基本事实**：何某1诉平南县某甲医院医疗损害责任纠纷。

**鉴定意见**：南宁市中一司法鉴定所出具南宁中一司鉴［2022］法临鉴字第0728号，认定医方——
- 未尽高度注意义务；
- 延误诊治；
- 漏诊漏治；
- 与损害后果之间为主要因果关系；
- **过错参与度建议 56%–65%**。

**法院裁判**：
- 援引《民法典》第1218条及《医疗损害司法解释》第4条第3款；
- 医方否认鉴定意见，但**未提供第1224条第1款免责情形的证据**，且鉴定人已出庭接受质询；
- 法院**采纳鉴定意见**、**不准许重新鉴定**，在参与度区间内**酌定被告承担 60% 赔偿责任**。

> ⚠️ 案号末位数字已脱敏（`3*16`），引用时须回源核对原件。

## 四、执业要点

**（一）代理患方**
1. 立案前先固定"就诊关系 + 损害后果"两项初步证据（挂号单、缴费凭证、门诊/住院病历、出院小结、诊断证明、影像资料）。
2. 过错与因果关系无直接证据时，**务必书面提出鉴定申请**——依第4条第2款，法院"应予准许"，这是患方突破举证困境的法定通道。
3. 病历疑有改动时，围绕第1222条第②③项主张推定过错；注意区分"实质篡改"与"形式瑕疵"，后者不产生不利后果推定。
4. 参与度意见为区间时，主张取上限需配套论证（延误诊治时长、漏诊项目与损害扩大的直接关联）。

**（二）代理医方**
1. 抗辩不能止于"不认可鉴定意见"——须**具体举证第1224条第1款三项免责情形之一**，否则徒劳。
2. 若患方存在不配合诊疗情形，仍应自查有无自身过错；依第1224条第2款，医方亦有过错的**不能完全免责**，只承担"相应的"责任。
3. 申请重新鉴定须有实据（鉴定机构资质缺陷、程序违法、依据明显不足等），单纯不服参与度比例不构成准许理由。
