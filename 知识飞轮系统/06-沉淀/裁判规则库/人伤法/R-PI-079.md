# 裁判规则 R-PI-079：医疗事故罪三程序衔接与量刑变量

**规则**：民事赔偿（填补损失）、行政处罚（维护监管秩序）与刑事责任（保护公共法益）所保护法益不同，互不替代。医疗机构已足额赔偿、医务人员已被警告或暂停执业，均不构成医疗事故罪的刑事免责事由；反之，刑事未追究亦不影响民事赔偿责任成立。在法定刑仅为三年以下的量刑空间内，积极赔偿、取得谅解、认罪悔罪是能否适用缓刑的决定性变量；行政机关已给予罚款的，人民法院判处罚金时应当折抵。

**规范依据**：
- 《刑法》第335条（医疗事故罪，三年以下有期徒刑或者拘役，单一法定刑档）
- 《刑法》第72条（缓刑四要件：犯罪情节较轻、有悔罪表现、无再犯危险、对所居住社区无重大不良影响）
- 《刑法》第67条（自首）；第37条之一（职业禁止，期限三年至五年）
- 《行政处罚法》第35条第1款（行政拘留折抵刑期）、第2款（**罚款应当折抵罚金**）
- 最高检、公安部《关于公安机关管辖的刑事案件立案追诉标准的规定（一）》第56条（医疗事故案追诉标准）
- 《医疗事故处理条例》第14条（重大医疗过失行为12小时内报告）
- 《刑事诉讼法》第101条及相关司法解释（附带民事诉讼范围，参见 [[R-PI-069]]）

**适用要件**：
1. **三程序并行**：行政处罚在先不产生刑事既判力；民事赔偿数额与责任比例不构成刑责的减免依据，仅在量刑阶段作为酌定情节评价。
2. **缓刑三开关**：足额赔偿到位 + 被害方书面谅解 + 认罪认罚且有悔罪表现。三者缺"悔罪表现"一项，缓刑基本落空——坚持无罪辩护与争取缓刑在结构上高度互斥，须由当事人知情决策。
3. **罚金折抵须主动提出**：法院不会自动检索行政处罚记录，辩护人应在量刑意见中附处罚决定书与缴款凭证，明确请求依《行政处罚法》第35条第2款折抵。
4. **鉴定意见跨程序限制**：民事医疗损害鉴定回答"原因力大小"（全部/主要/同等/次要/轻微），采高度盖然性标准；刑事因果关系要求排除合理怀疑的直接因果。**参与度百分比不得直接转化为刑法因果关系的认定依据**，未经刑事程序质证的民事鉴定意见应申请重新鉴定或要求鉴定人出庭。
5. **职业禁止与行政罚的衔接**：刑事职业禁止（三至五年，自刑罚执行完毕或假释之日起算）与行政暂停执业（1~6个月）、吊销执业证书并行不悖，须分别核算起止。

**实务提示**：
- **行政调查阶段的询问笔录会成为刑事案卷证据**（公开的卫生行政处罚决定书证据清单普遍列有多份询问笔录），必须按刑事标准准备陈述，避免对"是否违反诊疗常规"形成事实自认。
- 稀释个人刑责的核心材料指向**体系过失**：会诊制度启动记录、上级医师查房记录、转诊交接记录、排班与人力配置文件。
- 患方推动刑事立案的常见路径为"持医疗损害鉴定报告向公安报案"，故民事鉴定阶段的医方陈述应预判刑事后果。
- **待核提示**：2025—2026年引发广泛讨论的江西抚州儿科医生漏诊致患儿死亡案（媒体称"韩杰案"），公开报道对判决结果（缓刑 or 实刑）、二审时间存在互相冲突的表述，**案号与判决书原文未核**，仅可作程序流程示例，不得引作量刑结论依据。
