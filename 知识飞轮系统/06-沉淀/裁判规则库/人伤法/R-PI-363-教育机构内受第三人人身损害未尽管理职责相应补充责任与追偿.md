# 核心要旨

无民事行为能力人或者限制民事行为能力人在幼儿园、学校或者其他教育机构学习、生活期间，受到教育机构**以外的第三人**人身损害的，由**第三人**承担侵权责任；幼儿园、学校或者其他教育机构**未尽到管理职责**的，承担**相应的补充责任**，且承担补充责任后可以向第三人追偿（民法典第1201条）。该条与第1199/1200条（教育机构自身侵权）并列，专指"外来的第三人"致害场景。

# 适用情形
- 校外人员闯入校园伤害学生；
- 校园周边/接送时段第三人侵权，校方安保缺位；
- 培训机构、托管机构内第三人致学员损害。

# 反向提示
- 责任顺位：第三人为**第一责任人**，教育机构仅为"相应补充责任"（非连带），份额取决于管理过错程度；
- 与第1199条（无行为能力人受侵害校方过错推定）、第1200条（限制行为能力人受侵害校方过错责任）区分：本条前提是"第三人致害"而非校方或其人员直接致害；
- 教育机构尽到门禁、巡查、护学、安保培训等管理职责的，可免责；补充责任后可向第三人全额追偿。

# 关联法条（本地权威源回填·非凭记忆）

- **《中华人民共和国民法典》第1201条**（现行有效·本地权威源 `法律法规库/通用实体法/中华人民共和国民法典（全文）.md` 第4373行逐字回填）："无民事行为能力人或者限制民事行为能力人在幼儿园、学校或者其他教育机构学习、生活期间，受到幼儿园、学校或者其他教育机构以外的第三人人身损害的，由第三人承担侵权责任;幼儿园、学校或者其他教育机构未尽到管理职责的，承担相应的补充责任。幼儿园、学校或者其他教育机构承担补充责任后，可以向第三人追偿。"

# 权威案例（元典回源·已核验）
- **`内09民终447号`** — 某国融投资发展有限公司教育机构责任纠纷（内蒙古自治区乌兰察布市中级人民法院，2025）。限制民事行为能力人在托管机构日托期间，因施工方（校园外第三人）遗留旧木板致伤；法院原文援引《民法典》第1201条，判施工方（第三人）担80%责任、托管机构未尽管理职责承担相应补充责任，并明确保管机构承担补充责任后得向第三人追偿。
- **`（2014）滕民初字第1730号`** — 王青青与滕州鲁南水泥混凝土有限公司等教育机构责任纠纷（山东省滕州市人民法院，2014）。校园内第三人（混凝土运输车/施工方）侵权致学生受伤，级索中学未隔离施工与学生活动区，法院依第1201条判校方按过错承担30%补充责任。

# 办案衔接
- 受害人方（监护人）：并列告第三人+教育机构，举证校方管理缺位（门禁失效、安保空缺）扩大受偿；
- 教育机构方：举证安保管理制度与执行记录，将责任限缩至"相应"份额并保留追偿权。
