# R-PI-676 工伤保险赔付项目与计算方式体系（甘肃2025标准·须本地化换算）

> 🔴 **本地化警示（A2.5 铁律）**：本文所有金额/基数均为**甘肃省2025年度标准**（一次性工亡补助金1,083,760元、职工月均工资7,338元、丧葬补助金44,010元等）。**贵州案件不得直接套用**，须替换为贵州属地标准后计算。本卡仅沉淀"赔付项目体系与计算规则"，金额数字仅作结构示例。

> 🔴 **版本警示（法条银行版本陷阱铁律）**：本地 `法条银行/行政法律规章/工伤保险条例.md` 标 `sxx:⚠️版本存疑`（本地载2004版，现行2010修订/2011施行），**不得据本地旧版回填条号**。卡内条文号均来自原文线索，引用前须走元典/qcc-legal核验现行条号。

## 赔付项目体系（工伤 / 工亡）

**工伤（1-10级）**
| 项目 | 计算规则 | 责任主体 |
|---|---|---|
| 一次性伤残补助金 | 1级27月、2级25、3级23、4级21、5级18、6级16、7级13、8级11、9级9、10级7（本人工资） | 工伤保险基金 |
| 一次性就业补助金 | 各省定（甘肃：5级18/6级16/7级13/8级11/9级9/10级7月） | 用人单位 |
| 一次性工伤医疗补助金 | 同上（解除劳动合同时） | 工伤保险基金 |
| 伤残津贴 | 1-4级：90%/85%/80%/75%；5-6级难以安排工作：70%/60%（本人工资，按月） | 1-4级基金 / 5-6级用人单位 |
| 工伤医疗费 | 符合目录票据据实 | 基金 |
| 住院伙食补助费 | 地方标准（甘肃：上年度城镇居民日人均消费支出40%×天数） | 基金 |
| 交通费/住宿费 | 异地就医、票据据实 | 基金 |
| 残疾辅助器具费 | 票据据实，须劳动能力鉴定确认必要性 | 基金 |
| 停工留薪期工资 | 按目录确定停工留薪期（一般≤12月），按月支付 | 用人单位 |
| 护理费 | 经鉴定需护理：完全/大部分/部分不能自理=统筹区上年度月均工资50%/40%/30% | 基金 |

**工亡**
| 项目 | 计算规则 | 责任主体 |
|---|---|---|
| 丧葬补助金 | 6个月统筹区上年度职工月均工资 | 基金 |
| 供养亲属抚恤金 | 配偶40%、其他亲属30%、孤寡老人/孤儿+10%；总额≤生前工资 | 基金 |
| 一次性工亡补助金 | 上一年度全国城镇居民人均可支配收入×20 | 基金 |

**工资认定**：各项计算所用"本人工资"=工伤职工因事故伤害或患职业病前12个月平均月缴费工资（条例64条）。
