# R-PI-167 缺陷医疗产品致害无过错责任与医疗机构追偿权

**规则**：因药品、消毒产品、医疗器械缺陷或输入不合格血液致患者损害，适用**无过错责任**；患者可择一向医疗机构或生产者/MAH/血液提供机构请求赔偿，各责任主体对外承担**不真正连带责任**；医疗机构赔偿后，向负有最终责任的生产者/MAH/血液提供机构**单向追偿**。

**适用要点**：
1. 与民法典1218一般医疗损害（过错责任）形成二元归责；患者就产品致害**无需证医疗机构过错**，仅需证缺陷+因果关系。
2. 责任主体含医疗机构、药品上市许可持有人、医疗器械注册人/备案人（类推MAH）、生产者、销售者、血液提供机构。
3. 抗辩事由（产品无缺陷/血液合格）由医疗机构及生产者等**承担举证责任**。
4. 明知缺陷仍使用致死亡/健康严重损害，有惩罚性赔偿空间。
5. 患者自医疗机构外渠道购得缺陷产品 → 落一般产品责任，不适用1223。
