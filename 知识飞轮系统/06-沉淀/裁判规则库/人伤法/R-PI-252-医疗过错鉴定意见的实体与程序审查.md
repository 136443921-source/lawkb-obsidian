# 核心要旨

- 医疗过错鉴定意见**可以作为判断被告人刑事责任大小的依据之一，而不能作为判断被告人有无刑事责任的依据**。
- 审查应**实体与程序并重**：
  - **实体审查**：结合案件事实审查鉴定意见是否客观真实，判断医疗过错是否成为介入被害人死亡的因素。
  - **程序审查**：鉴定过程中未被害方参与，并不当然属于《刑诉法解释》第98条鉴定意见不得作为定案根据的九种情形；但医院方与被告方均应参加听证并发表意见，否则实体结论的可采性存疑。

# 关联法条

- 《刑事诉讼法解释》第98条（鉴定意见排除的九种法定情形）。
- 《刑法》第335条（医疗事故罪）：严重不负责任＋就诊人死亡／严重损害就诊人身体健康。

# 适用场景

- **韩杰医生医疗事故罪再审辩护**：医疗过错／医疗事故鉴定意见的攻防——区分“责任大小依据”与“入罪依据”；程序上重点审查听证参与、检材来源、分析说明的逻辑闭环；实体上审查过错与死亡结果之间的因果关系（介入因素原因力）。
- 与 R-PI-240（梁某医疗事故案：责任认定书为必要条件非充分条件、业务过失本质）互为印证，共同构成医疗事故罪鉴定的辩护骨架。
