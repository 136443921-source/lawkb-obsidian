# 核心要旨

医疗、药品、医疗器械及医疗服务广告实行严格审查与内容限制；疗效承诺、治愈保证属明确禁止内容，是医疗服务协议与广告宣传的合规红线。

- **功效/安全性断言禁止**：医疗广告不得含有表示功效、安全性的断言或者保证，不得说明治愈率或者有效率（《广告法》第16条第1款第（一）（二）项）。
- **误导性疗效承诺后果**：在医疗服务协议、宣传物料、线上推广中使用"保证治愈""百分百有效""无风险"等表述，构成违法广告，市场监管部门可责令停止发布、罚款，情节严重吊销执照；同时可能构成对消费者的欺诈（触发《消费者权益保护法》三倍赔偿）。
- **面瘫针灸调理协议边界（直接关联在审合规审查）**：针灸/理疗类医疗服务协议**不得写入"治愈保证""疗效承诺""无效退款"等条款**；应将疗效表述为"基于个体体质的调理改善"，并充分履行说明义务与风险告知，留存知情同意。
- **权威案例（pkulaw 北大法宝核验·现行有效）**：
  - (2024)皖行申279号（合肥亚典医疗美容）：违反《广告法》第16条、第17条作疗效断言，被罚5万元，再审维持。
  - (2001)海中法民终字第139号：虚假医疗广告致消费者受损，判令双倍返还。
  - (2018)琼0105行初169号（海南伊佳）：违反《广告法》第16条作治愈率断言，被罚10万元，判决维持。
  - (2018)宁04行终42号（固原协和）：发布虚假医疗广告，被罚20万元，二审维持。

# 关联法条（pkulaw 北大法宝核验·现行有效，本地源已建）

- 《广告法》（2021修正）第4条（广告不得含虚假或引人误解内容，不得欺骗、误导消费者）、第16条（医疗广告禁止内容：功效安全性断言/保证、治愈率有效率说明、与其他药品比较、利用广告代言人作推荐证明等）、第17条（除医疗药品医疗器械广告外不得涉及疾病治疗功能）、第28条（虚假广告认定）、第58条（违反第16条责任：责令停止+消除影响+广告费1-3倍罚款，无法计算处10-20万；情节严重3-5倍/20-100万，可吊销执照/诊疗科目）。
- 《医疗纠纷预防和处理条例》（**国家版**，国务院令第701号，2018-07-31，现行有效，行政法规；本地源：法律法规库/行政法律规章/医疗纠纷预防和处理条例.md）第13条（如实告知病情、医疗措施、医疗风险、替代方案）、第15条（如实书写病历）。
- 《民法典》第1219条（医务人员在诊疗活动中应向患者说明病情和医疗措施、取得明确同意的说明义务与知情同意权）。
- ⚠️ 本地源核验：新建《中华人民共和国广告法（2021修正）》本地源（法律法规库/行政法律规章/）；医疗纠纷条例本地源经核验为国家卫健委来源**国家版**（非大连市地方版），可直接引用。

# 适用场景

- **面瘫后遗症针灸调理医疗服务协议合规审查（在办）**：审查协议文本，剔除一切疗效承诺/治愈保证表述，补强风险告知与知情同意条款；对"调理改善"类表述做合规限定。
- **厚德基金会/医疗机构合作合规**：涉及医疗服务宣传、义诊推广时，广告文案须经合规审核，避免疗效断言。
