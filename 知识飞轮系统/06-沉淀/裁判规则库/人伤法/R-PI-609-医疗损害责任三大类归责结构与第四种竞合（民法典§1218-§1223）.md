# R-PI-609 医疗损害责任三大类归责结构与第四种竞合（民法典§1218-§1223）

> 来源：IMA「人伤法律实务助手」库《〈民法典〉中的医患问题》（选择句号，2026-08-02）。B 阶段回补摄入（2026-10-26 通道恢复后补齐 10-26 漏跑）。

## 一、核心法条（本地法条银行逐字 · 已三通道核验）

**《民法典》第一千二百一十八条**【过错责任·替代责任】
> 患者在诊疗活动中受到损害，医疗机构或者其医务人员有过错的，由医疗机构承担赔偿责任。

**《民法典》第一千二百一十九条**【告知义务：一般 + 特殊 + 违反的后果】
> 医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施手术、特殊检查、特殊治疗的，医务人员应当及时向患者具体说明医疗风险、替代医疗方案等情况，并取得其明确同意;不能或者不宜向患者说明的，应当向患者的近亲属说明，并取得其明确同意。
> 医务人员未尽到前款义务，造成患者损害的，医疗机构应当承担赔偿责任。

**《民法典》第一千二百二十条**【紧急情况下的医疗措施】
> 因抢救生命垂危的患者等紧急情况，不能取得患者或者其近亲属意见的，经医疗机构负责人或者授权的负责人批准，可以立即实施相应的医疗措施。

**《民法典》第一千二百二十一条**【诊疗义务与当时医疗水平】
> 医务人员在诊疗活动中未尽到与当时的医疗水平相应的诊疗义务，造成患者损害的，医疗机构应当承担赔偿责任。

**《民法典》第一千二百二十二条**【过错推定的三种情形】
> 患者在诊疗活动中受到损害，有下列情形之一的，推定医疗机构有过错:
> (一)违反法律、行政法规、规章以及其他有关诊疗规范的规定;
> (二)隐匿或者拒绝提供与纠纷有关的病历资料;
> (三)遗失、伪造、篡改或者违法销毁病历资料。

**《民法典》第一千二百二十三条**【医疗产品责任·不真正连带责任 + 追偿】
> 因药品、消毒产品、医疗器械的缺陷，或者输入不合格的血液造成患者损害的，患者可以向药品上市许可持有人、生产者、血液提供机构请求赔偿，也可以向医疗机构请求赔偿。患者向医疗机构请求赔偿的，医疗机构赔偿后，有权向负有责任的药品上市许可持有人、生产者、血液提供机构追偿。

## 二、规则要旨：三大类责任 + 第四种竞合

医务人员在诊疗中提供三项基本服务（**实施医疗技术 / 告知病情与诊疗措施 / 使用医疗产品**），由此派生三大类损害责任。

### 1. 医疗技术损害责任（§1218）

- **归责原则**：过错责任。**举证责任在患方**——须证明因果关系 + 医疗机构或医务人员的过错。
- **责任形态**：**替代责任**（类比监护人责任）。患者起诉应告**医疗机构**，而非医务人员个人。
- ⚠️ 但"替代责任 ≠ 医务人员免责避难所"：医疗机构承担赔偿责任后，可在符合法律法规和规章的条件下对有过错的医务人员问责追究（内部追偿）。

### 2. 违反告知义务的医疗损害责任（§1219）

- 区分 **一般告知义务**（说明病情和医疗措施）与 **特殊告知义务**（手术/特殊检查/特殊治疗须具体说明医疗风险、替代医疗方案并取得**明确同意**；不能或不宜向患者说明的，向近亲属说明并取得明确同意）。
- **归责原则**：同为过错责任 + 医疗机构承担替代责任。
- **特殊告知义务的立法旨意**：压紧压实责任，防止手术与特殊治疗、特殊检查中的并发症、医疗风险、医疗意外所致损害。
- 🔴 **关键实务点**：穿刺、纤维支气管镜、胃肠镜等特殊检查，放疗、化疗、输血等特殊治疗，各级各类手术——**即便医务人员诊疗行为无任何过错**，仍可能因违反特殊告知义务成立医疗侵权。
- **告知对象**：患者本人优先（源文：法律已给明确答案，应坚持患者优先）；不能或不宜向患者说明的，向近亲属说明。**患者回复标准 = 取得"明确同意"**。
- **紧急处置权（§1220）**："不能取得患者或近亲属意见"应作**限缩解释**，不得泛化至一切场景。源文列举四种典型情形：
  1. 近亲属不明；
  2. 不能及时联系到近亲属；
  3. 近亲属拒绝发表明确意见；
  4. 近亲属之间达不成一致意见。

### 3. 医疗产品责任（§1223）

- **归责**：产品缺陷或输入不合格血液致害，患者可向**药品上市许可持有人/生产者/血液提供机构**请求赔偿，**也可向医疗机构**请求赔偿。
- **责任形态**：医疗机构与医疗产品提供者承担**不真正连带责任**。立法旨意在于**拓宽患者追诉范围**；但"冤有头、债有主"，最终赔偿的责任人是终局责任人——医疗机构赔偿后**有权向负有责任者追偿**。
- **诉讼选择权**：患者可择一起诉、共同起诉或先后起诉；可依各责任主体偿付能力选择最优诉讼策略；就未获偿部分可向另一方主张。**最优方式：将医疗机构与医疗产品提供者列为共同被告一并起诉**，既一次性解决纠纷又保障及时获赔。

### 4. 第四种责任：医疗技术损害 + 医疗产品损害竞合共同致害

依《医疗损害解释》，**缺陷医疗产品与医疗机构的过错诊疗行为共同造成患者同一损害**的，患者请求医疗机构与医疗产品的生产者或销售者承担**连带责任**的，应予支持。

- 🔴 **对患者有利**：连带责任的归责原则实际上更有利于患者，扩大追偿机会。
- 🔴 **对责任划分不利/关键**：**连带责任不等于终局比例确定**——内部追责仍须**厘清各自责任大小，按造成损害的"原因力"大小归责**，最终确定各方分担的责任份额（对应 R-PI-606：鉴定意见的原因力区间只是参考，法院可在法定范围内酌定）。

## 三、蓝队 / 红队要点

- **蓝队（医方）**：
  1. 过错责任下**举证责任在患方**——医方不必自证无过错，应把举证重心引向"因果关系不成立"或"患者自身过错/第三人原因"；
  2. 特殊告知义务是**独立归责路径**：即使诊疗无过错，仍需证明已就医疗风险、替代方案取得**明确同意**并留痕（签字、知情同意书、沟通记录、录音录像）；
  3. 紧急处置条款只在**限缩解释后的四种情形**成立，不能作为"家属不在场一律可处置"的抗辩；须有负责人或授权负责人批准记录；
  4. 病历是§1222 过错推定的靶心：**隐匿、拒绝提供、遗失、伪造、篡改、违法销毁**六种情形均推定过错——须确保电子病历原始数据与操作日志同步封存（见 R-PI-365）。
- **红队（患方）**：
  1. 特殊检查/特殊治疗/手术**并发症发生即启动特殊告知义务审查**，不以"诊疗无过错"为抗辩；
  2. 医方以"当时医疗水平"抗辩时，注意§1221 系**"与当时医疗水平相应的诊疗义务"**——且源文提示："合理诊疗义务"与"当时的医疗水平"均指医疗机构**"实然"状态**，法律不强求县乡医疗机构对标省级机构（此点对医方有利，患方不宜过度攻击）。
  3. 医疗产品责任下**优先选择共同被告一并起诉**，可一次性解决并保障获赔；已向一方获赔不足部分再向另一方主张。
  4. 竞合情形下（缺陷产品 + 过错诊疗）依《医疗损害解释》主张**连带责任**，再在内部追偿中以原因力抗辩分担比例。

## 四、适用场景

- 医疗损害责任案件的**归责路径选择**（过错责任 / 过错推定 / 产品责任 / 竞合连带责任）；
- 代理医院/医师时的**告知义务抗辩清单**与病历留痕要求；
- 代理患方时的**共同被告策略**与追偿顺序设计；
- 医疗纠纷责任比例测算中的"原因力"与"法律责任比例"区分（关联 R-PI-606、R-PI-213、R-PI-242）。
