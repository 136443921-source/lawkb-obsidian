# R-PI-059 医疗产品缺陷致害：无过错责任 + 不真正连带 + 惩罚性赔偿三层

## 规则表述

因药品、消毒产品、医疗器械的缺陷，或输入不合格血液造成患者损害的，适用**无过错责任**（《民法典》第1223条）：患者只需证明"使用缺陷产品/输入不合格血液 + 损害 + 因果关系"，无需证明任何一方过错。患者对各责任主体（药品上市许可持有人、生产者、销售者、血液提供机构、医疗机构）享有**单向选择权**，各主体之间为**不真正连带责任**——对外可择一或并举起诉，对内仅一个终局责任人，已赔偿方全额追偿（医疗损害解释第21条）。

明知缺陷仍生产、销售缺陷医疗产品的，患者可另主张**惩罚性赔偿**，存在三层位阶：
1. 《民法典》第1207条（一般产品责任，"相应"惩罚性，法院酌定）；
2. 《医疗损害解释》第23条（医疗产品场景，损失 + **二倍以下**）；
3. 《药品管理法》第144条（药品假劣场景，价款**十倍**或损失**三倍**）。

## 适用场景

- 药品不良反应（非说明书已披露的一般风险，而是成分超标/变质/设计缺陷致害）；
- 植入器械断裂、消毒耗材不达标、输血感染/血型错误；
- 生产者/持有人与医疗机构互相推诿"属对方责任"；
- 同批次产品已被监管处罚，患者主张惩罚性赔偿。

## 边界与例外

- **无过错仅及补偿**：惩罚性赔偿的"明知"要件仍由原告举证（行政罚单为最强武器）；第1223条的无过错不豁免惩罚性赔偿的主观要件。
- **共同致害按份追偿**：缺陷产品 + 过错诊疗共同致害，对外连带、对内按**原因力大小**追偿（解释第22条）。
- **医疗产品 vs 一般医疗过错**：缺陷/不合格致害走第1223条无过错；诊疗行为过错仍走第1218条过错责任（参见 R-PI-049 区分）。

## 实务指引

- 原告：先依第1223条锁定无过错路径（免举证过错），再视"明知缺陷"证据叠加惩罚性赔偿；择一起诉可避免被终局责任人牵制。
- 被告（医疗机构）：可主张已尽审慎进货查验义务，缺陷终局责任在生产者/持有人，借不真正连带内部追偿脱钩。
- 证据清单：产品注册证/批检报告、同批次召回/处罚公告、输血记录与血型复核单、诊疗记录。
