# 工伤保险待遇项目与计算标准（含工亡）

> 来源核验：IMA「人伤法律实务助手」→ 医疗伤残赔偿计算《公众普法丨工伤保险赔付项目与计算方式》（正博法言，2025-11-29）全文取回；项目与计算标准依据《工伤保险条例》。`source_verified:true`（IMA 权威源全文取回 + 法条银行可核对）。

## 一、核心要旨

工伤待遇分为**工伤**与**工亡**两类，项目及责任主体如下（金额以"职工本人工资"或"统筹地区上年度职工月平均工资/全国城镇居民人均可支配收入"为基数）：

| 类别 | 项目 | 计算方式 | 责任主体 |
|---|---|---|---|
| 工伤 | 一次性伤残补助金 | 1级27个月→10级7个月本人工资 | 工伤保险基金 |
| 工伤 | 伤残津贴 | 1-4级90%~75%本人工资（基金）；5-6级70%/60%（单位） | 基金/单位 |
| 工伤 | 一次性工伤医疗补助金 | 解除合同时按省规定（如甘肃5-10级18→7个月） | 工伤保险基金 |
| 工伤 | 一次性伤残就业补助金 | 解除合同时按省规定（如甘肃5-10级18→7个月） | 用人单位 |
| 工伤 | 工伤医疗费 | 目录内据实结算 | 工伤保险基金 |
| 工伤 | 住院伙食补助/交通/食宿 | 按地方规定据实 | 工伤保险基金 |
| 工伤 | 残疾辅助器具费 | 经鉴定确认后据实 | 工伤保险基金 |
| 工伤 | 停工留薪期工资 | 对应停工留薪期，单位按月支付（一般不超12个月） | 用人单位 |
| 工伤 | 生活护理费 | 完全/大部分/部分不能自理：统筹地区上年月均工资50%/40%/30% | 工伤保险基金 |
| 工亡 | 丧葬补助金 | 6个月统筹地区上年度职工月平均工资 | 工伤保险基金 |
| 工亡 | 供养亲属抚恤金 | 配偶40%/其他亲属30%/孤寡+10%，合计不高于生前工资 | 工伤保险基金 |
| 工亡 | 一次性工亡补助金 | **上一年度全国城镇居民人均可支配收入 × 20** | 工伤保险基金 |

- **工资基数**："职工本人工资"= 工伤前12个月平均月缴费工资（《工伤保险条例》第64条）。
- **一次性工亡补助金（2024年度）**：全国城镇居民人均可支配收入 54,188 元 × 20 = **1,083,760 元**（逐年随统计数据调整）。

## 二、权威依据

- 《工伤保险条例》第30条（医疗待遇）、第32条（辅助器具）、第33条（停工留薪期）、第35-37条（伤残待遇）、第39条（工亡待遇）、第64条（工资基数）。
- 注：文中以**甘肃省2025年度**标准为示例，各省具体标准不同，须按统筹地区规定执行。

## 三、实务锚点

- **航合物流 2026-09-01 贵C09782D 货车致死案**：死者若兼具工伤职工与侵权受害人双重身份，家属可主张**工亡待遇**（一次性工亡补助金 108.376 万 + 丧葬补助金 + 供养亲属抚恤金）**与**民事侵权赔偿并行（仅医疗费不重复，见 [[R-PI-630]]）。
- **赔付测算**：代理/应诉时须按**事故发生时最新年度**全国城镇居民人均可支配收入计算一次性工亡补助金，并核对统筹地区（贵州）上年度职工月均工资用于丧葬补助金。
- **未参保风险**：用人单位未依法缴纳工伤保险费的，相关待遇由**用人单位**自行支付（呼应 [[R-PI-631]] 未投保交强险的兜底重责逻辑）。
