# 主题卡·人伤费用承担边界（保险/基金理赔与侵权赔偿的界分）

> 本卡将六条相关裁判规则 **[[R-PI-036]]、[[R-PI-037]]、[[R-PI-038]]、[[R-PI-039]]、[[R-PI-040]]、[[R-PI-041]]** 合订为"人伤费用承担边界"主题簇，统一回答两个问题：**（1）一笔费用/待遇，到底该由侵权人赔、由保险/基金担、还是可兼得、不得重复主张？（2）与之高频共现的费用计算（误工费）与责任成立（无接触因果）争议如何处理？**

> 分组说明：**核心四规则（036/037/038/039）** 直接界定"费用抵扣·待遇兼得·商业险不免责但受条款检视"；**扩展两规则（040/041）** 为交通事故人伤案中最常与上述争议共现的"费用计算"与"责任成立"规则，纳入本卡便于诉前一体组织攻防。

---

## 一、总论（法教义学定位）

**核心命题**：保险/基金理赔 **不当然减轻侵权人赔偿责任**；但 **同一损失不得重复主张**（禁止双重受偿 / 不当得利法理）。

二者并不矛盾——前者约束的是"侵权人"（不能因受害人已获理赔而免责），后者约束的是"受害人"（已获填补的部分不得再向侵权人主张，否则构成双重获利）。

**二元区分框架（核心四规则统摄轴）**：

| 类别 | 性质 | 与侵权赔偿的关系 | 规则落点 |
|------|------|------------------|----------|
| **"费用"**（已付医疗费、垫付抢救/丧葬费） | 已现实填补的具体财产损失 | 从侵权请求中**剔除**（抵扣/基金代位追偿） | [[R-PI-036]] |
| **"待遇"**（残疾赔偿金、一次性伤残补助金、精神抚慰金等人身专属项目） | 与人身不可分、无以金钱衡量的赔偿 | 不同法律关系并行，**可兼得** | [[R-PI-037]] |
| **"商业险理赔"**（意外险、商业三者险内用药） | 投保人/被保人自身风险安排 | **不阻却**侵权，可并行；但内部免责条款受严格检视 | [[R-PI-038]] [[R-PI-039]] |

> 一句话记忆：**"费用抵扣、待遇兼得、商业险不免责但受条款检视。"**

| **[[R-PI-041]]** | 无接触交通事故责任成立 | 侵权人过错行为与损害有因果关系，即便无物理接触仍担责；责任成立看过错+因果，不看接触 | 《民法典》第1165条第1款 + 《道路交通安全法》 | 郭某华诉李某希案 (2025)粤0118民初251号（入库 2026-07-2-411-001） |

> 关联性说明：040（误工费）是"费用承担边界"中**费用如何计算**的延伸——即便确认由侵权人承担，其金额仍受举证层级与标准边界约束；041（无接触因果）是**责任是否成立**的前置——若责任不成立，则后续一切费用承担争议无从谈起。二者与核心四规则在交通事故人伤案中几乎必然共现。

## 四、决策树（执业速查）

```
问0：侵权责任是否成立？（覆盖 R-PI-041）
├─ 侵权方存在违反交规的过错行为，且与损害有因果关系
│   → 即便无物理接触（"开门杀""违规变道致急刹"），仍担责（[[R-PI-041]]）
└─ 无过错或无因果关系 → 不承担责任，后续费用争议无需讨论

问1：该笔支出/待遇是否已由保险或基金支付？
├─ 是「医疗费 / 抢救 / 丧葬费」且由医保/工伤/救助基金支付
│   → 剔除出对侵权人的请求范围（[[R-PI-036]]）
│   → 告知客户：基金经办机构将代位追偿并可能合并审理
├─ 是「商业险理赔」（意外险、商业三者险内用药）
│   → 不阻却侵权，保险与侵权可并行主张（[[R-PI-039]]）
│   → 但保险方在三者险内主张"非医保用药扣减"须走问2
└─ 是「社保待遇」（一次性伤残补助金、残疾赔偿金类人身专属项目）
    → 与侵权赔偿可兼得，不抵扣（[[R-PI-037]]）

问2：侵权人/保险方主张"扣减非医保用药（自费药）"？
└─ 须完成[[R-PI-038]]双重举证，缺一不可：
   ① 免责条款已履行《保险法》第17条第2款提示 + 明确说明义务（否则条款不生效）
   ② 证明存在同疗效、可替代的低价医保目录内药品及具体价格差额
   （仅以单方医疗审核报告或笼统"扣除15%"的，因举证不能不予支持）

问3：误工费如何计算？（覆盖 R-PI-040）
├─ 有固定收入 → 按实际减少收入
├─ 无固定收入但能举证近三年平均收入 → 按该平均收入
├─ 无固定收入且不能举证 → 参照受诉法院所在地相同或相近行业上一年度职工平均工资
│   · 超法定退休年龄但有实际劳动证据 → 仍支持（法释9号第6条）
│   · 农村受害人主张"农林牧渔业"标准 → 审查是否单位从业人员；传统农民改按"农村居民人均可支配收入"（武强案）
└─ 诉请金额锚定在法定标准内以降低举证负担（榆林93号）

问4：是否构成"同一损失重复主张"？
├─ 医疗费已获基金支付 → 不可再向侵权人主张（[[R-PI-036]]，否则双重获利）
└─ 残疾赔偿金/伤残补助 → 不因已获待遇而减（[[R-PI-037]]，不同法律关系）
```

## 五、双向攻防话术库

### 受害方 / 原告代理（进攻）
- **医疗费**：凭正规发票 + 病历 + 诊断证明 + 费用清单固定；凡基金已付部分，诉前主动剔除并仅在差额主张（[[R-PI-036]]），避免请求被驳且承担不当诉讼费。
- **非医保用药**：论证用药由主治医生依伤情决定、受害人无选择权，属法定赔偿范围；反制免责条款——查投保单/保单，未见醒目提示及投保人签字确认的，直接主张条款不生效（[[R-PI-038]]）。
- **伤残待遇/残疾赔偿金**：即便已领一次性伤残补助金、已获商业意外险理赔，仍可向侵权人全额主张残疾赔偿金、精神抚慰金（[[R-PI-037]] [[R-PI-039]]）。
- **商业险与侵权并行**：接受劳务受害案件，雇主"已购意外险"不能免责，重点攻其安全管理/指导义务及过错比例（[[R-PI-039]]）。
- **误工费**：固定事故前收入流水/微信收款/雇主证明/证人证言/土地承包合同；超龄直接援引法释9号第6条；举证不能时诉请金额锚定在相近行业职工平均工资内（[[R-PI-040]]）。
- **无接触事故**：重点证明侵权方违反交规的过错行为（行车记录仪/监控/鉴定）与损害的因果关系，无需证明物理接触（[[R-PI-041]]）。

### 侵权方 / 保险方代理（防守）
- **基金已付医疗费**：主张从赔偿总额中剔除已付医疗费；必要时申请追加基金经办机构为第三人合并审理（[[R-PI-036]]）。
- **非医保用药扣减**：必须"两手都硬"——提供免责条款加粗提示页 + 投保人签字的明确说明确认书；并委托鉴定或医保目录比对证明同疗效替代药差额（[[R-PI-038]]）。
- **已购商业险抗辩（雇主视角）**：不得以"已购意外险"免除侵权责任；只能就受害人自身过错主张过失相抵（[[R-PI-039]]）。
- **误工费抗辩**：超龄案件可主张结合年龄、劳动能力减弱酌减比例（如高某案按60%）；农村户籍主张按"农村居民人均可支配收入"而非"农林牧渔业职工平均工资"（武强案）；举证缺口攻击按法定就近行业平均工资（[[R-PI-040]]）。
- **无接触事故抗辩**：不得以"无接触"切断责任，只能从过错程度、原因力比例、受害人过错（过失相抵）角度抗辩减责（[[R-PI-041]]）。
- **禁止混淆**：不得把"伤残补助待遇"当"已付医疗费"要求抵扣（[[R-PI-037]] 与 [[R-PI-036]] 的边界）。

## 六、关联规则簇（扩展阅读）

- **[[R-PI-034]]** 荣宝英案·交通事故特殊体质不扣减——赔偿范围**扩张端**（法定赔偿项目优先于朴素正义观）。
- **[[R-PI-035]]** 限制类医疗技术未备案加重医疗机构赔偿责任——医疗费**构成端**。
- **[[R-PI-031]]** 限制类医疗技术未备案——与 [[R-PI-040]] 同属交通事故人伤费用认定链。
- **[[R-PI-024]]** 受害人特殊体质不减轻侵权人责任——与 [[R-PI-034]] 同源，构成"赔偿范围"对称理解。
- 共组立场：特殊体质不减轻赔偿、非医保用药不当然减轻赔偿、误工费不因其年龄/户籍减轻赔偿——均体现"**法定赔偿项目优先于保险/基金内部规则**"的司法立场。

## 七、贵州本地提示

贵州省高院及贵阳、遵义等地法院对"非医保用药扣除"多持审慎态度，原则上不主动核减，除非保险公司完成 [[R-PI-038]] 双重举证；对"基金已付医疗费"则严格适用法释〔2026〕9号第10条予以剔除并提示追偿风险。对超龄/农村户籍受害人误工费，原则上不因其年龄/户籍拒赔，但普遍要求举证实际劳动事实，农村受害人按"农林牧渔业"标准主张的须审查是否单位从业人员（武强案口径，见 [[R-PI-040]]）。无接触交通事故中，法院以过错+因果认定责任，不以物理接触为要件（[[R-PI-041]]）。实习律师办理本地人伤/交通事故/提供劳务受害案件时，建议以本卡决策树为诉前核算与攻防组织主线。
