# R-PI-095 被监护人致害的监护人责任

## 规则表述

无民事行为能力人、限制民事行为能力人造成他人损害的，由**监护人承担侵权责任**（替代责任，不以监护过错为要件）。监护人尽到监护职责的，**可以减轻**其责任（减责≠免责）。被监护人有财产的，从其本人财产中**先行支付**；不足部分由监护人赔偿。

## 要件

1. 致害人系无/限制民事行为能力人（含未成年人、不能完全辨认的精神障碍患者等）；
2. 归责采无过错替代——监护责任成立不要求监护有过错；
3. 尽到监护职责仅构成**减责事由**（非免责）；
4. 财产不足时的责任顺序：被监护人财产先行 → 监护人补充。

## 适用要点（攻防）

- **受害人（攻）**：列监护人及被监护人（有财产时）为共同被告，主张先行支付 + 补充；
- **监护人（防）**：举证已尽监护职责（日常管教、看护安排）主张减责；有多个监护人时主张按过错/约定分担（1189 委托监护情形下受托人按过错担责）。
