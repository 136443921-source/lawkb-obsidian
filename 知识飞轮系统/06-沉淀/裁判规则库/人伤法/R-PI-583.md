# R-PI-583 挂靠经营机动车交通事故责任（民法典§1211）

## 一、核心法条（已逐字核验·本地法条银行）

**《民法典》第一千二百一十一条**【挂靠机动车交通事故责任】
> 以挂靠形式从事道路运输经营活动的机动车，发生交通事故造成损害，属于该机动车一方责任的，由挂靠人和被挂靠人承担连带责任。

配套：《最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释》第三条（2012法释19号，现行有效）— 以挂靠形式从事道路运输经营活动的机动车发生交通事故造成损害，属该机动车一方责任，当事人请求由挂靠人和被挂靠人承担连带责任的，人民法院应予支持。

## 二、裁判要旨与适用要点

1. **连带责任不以有偿/无偿区分**：被挂靠人是否收取管理费、是否享有运营支配利益，均非免责抗辩事由；只要形成挂靠关系，即连带。
2. **"事实挂靠"认定**：车辆登记在被挂靠人名下 + 实际所有人以被挂靠人名义营运（如按月缴管理费、借运营证），即构成挂靠。分期付款买卖中车辆一直登记在出卖人/公司名下用于营运的，亦可被认定为事实挂靠。
3. **解除挂靠未办转移登记≠免责**：被挂靠人登报声明解除挂靠、注销道路运输证，但**未办理车辆注销或转移登记**，挂靠人仍以其名义营运肇事的，双方仍为事实挂靠，被挂靠人承担连带赔偿（合同相对性不得对抗第三人）。
4. **责任顺位**：先由交强险、商业险在限额内赔；不足/无保险部分，由挂靠人+被挂靠人连带赔偿。
5. **与报废/拼装车区分**：拼装或已达报废标准机动车多次转让肇事，适用道交解释第4条（所有转让人受让人连带），与§1211挂靠规则并行不悖。

## 三、典型案例（地方法院普法案例·三通道复验·保留原始标注）

- **货运车肇事挂靠公司担责案** — 山东寿光法院：邱某重型半挂车挂靠A运输公司经营且未投保交强险/商业险，判邱某与A公司连带赔偿（寿光市政府普法）。
- **登记车主连带责任案** — 中国法院网：杨某分期付款购车登记在A公司名下用于运输，形成挂靠，依§1211判A公司与杨某连带。
- **货车事故挂靠公司担责案** — 乌审旗检察院/法院：A公司登报解除挂靠并注销道路运输证，但未办转移登记，郭某某仍驾车营运肇事，A公司仍连带（解除效力不及第三人）。
- **芦溪法院2025挂靠车案** — 黎某客车挂靠某某汽运公司按月缴管理费，负事故全责，判黎某与汽运公司连带赔偿医保外费用6080元。

## 四、物流货运企业合规提示（航合物流类）

- 被挂靠方（运输公司）应：严格审查挂靠车辆资质与保险（强制投保交强险+足额商业险）；在挂靠协议中明确事故内部追偿与风险分担；**车辆退出挂靠须同步办理转移登记/注销**，仅登报声明不足以免责。
- 代理受害方：可一并列挂靠人与被挂靠人，主张连带责任，扩大责任财产范围。
- 案例说明：寿光/乌审旗/芦溪均为地方法院、检察院公开发布的典型案例或普法材料，无统一裁判案号，qcc-legal不收录，故保留原始出处标注；援引时建议核具体裁判文书。法条§1211经元典法条detail与本地法条银行逐字交叉确认。
