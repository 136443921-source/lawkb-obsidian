# R-PI-085 医疗事故罪入罪边界

## 规则表述

《刑法》第335条医疗事故罪须同时具备：**主体为医务人员 + 严重不负责任 + 造成就诊人死亡或严重损害就诊人身体健康**。入罪关键在"严重不负责任"须达**重大过失**且违反医疗质量安全**核心制度**（查对、交接班、危急值、会诊、分级护理等），一般技术过失、并发症、难以避免的医疗风险不构罪。"严重损害就诊人身体健康"参照重伤标准与残疾等级认定。

## 要件

1. 违反的是诊疗规范中的**强制性核心义务**而非边缘管理规范；
2. 行为与损害之间须有刑法上的因果关系——就诊人死亡/重伤须主要或重要归因于医疗行为，而非自身疾病自然转归；
3. 鉴定路径选择影响定性：医疗事故技术鉴定偏行政责任，医疗损害鉴定偏民事过错，刑事入罪须达"严重不负责任"的重大过失门槛；
4. 与过失致人死亡罪存在竞合可能，但本罪为业务过失特别规定，优先适用。

## 适用要点（攻防·辩护方）

- **因果关系突破**：以自身疾病参与度、病情危急程度、规范允许的合理处置区间切断"医疗行为→死亡"的必然因果；
- **核心制度认定**：区分"违反核心制度"与"一般诊疗瑕疵"，后者不达标"严重不负责任"；
- **程序防线**：管辖（医疗纠纷常涉监察/公安交叉）、专家辅助人出庭、重新鉴定申请、病历真实性质证；
- **韩杰案战略**：抗诉/申诉聚焦入罪事实不清（严重不负责任认定 + 因果鉴定瑕疵），以"证据不足、适用法律错误"为枢轴。
