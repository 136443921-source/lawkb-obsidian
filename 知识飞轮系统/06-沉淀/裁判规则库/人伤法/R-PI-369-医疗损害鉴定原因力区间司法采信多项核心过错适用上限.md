# 医疗损害鉴定原因力区间的司法采信——多项核心过错可适用上限（R-PI-369）

## 裁判规则

1. **鉴定意见的性质＝裁判参考，非法律判断替代**：司法鉴定意见的原因力区间（如50%–95%）仅为专业技术参考，不能替代法官的法律判断；法院有权在区间内结合全案事实酌定责任比例，**坚决避免"以鉴代审"**。
2. **适用区间上限的正当情形**：医疗机构存在**多项核心诊疗过错**（如术中未严密缝合硬脊膜、未履行术中异常告知义务、术后延误诊断治疗）且**未尽告知义务侵犯知情同意权**的，法院可在区间内酌定上限责任（本案一审酌定95%、二审维持）。
3. **反向边界（区间下限酌定）**：若重新鉴定后依据不足、仅从程序瑕疵认定过错，法院可酌定低于区间下限（参见慈利县法院案——重鉴5%–15%→法院酌定35%，与本案构成"上限/下限"两极对照，见 R-PI-254）。
4. **证据固定铁律（患方）**：第一时间封存全部病历、缴费凭证、沟通记录；委托专业医疗过错鉴定明确因果关系与原因力，为索赔提供核心支撑。

## 基本案情（来源：征和律所实务解读·(2025)川14民终1640号）

2023年11月，李某先因腰痛行全麻下椎管减压+植骨融合+钉棒内固定术，术后颅内感染，转院抢救无效于11月30日死亡。鉴定认定医院存在多项过错、原因力50%–95%且侵犯知情同意权。一审结合患者无重大基础疾病酌定95%责任；医院上诉主张比例过高，四川眉山中院二审（裁判日期2026-01-09）认为一系列不规范诊疗非不可预料风险，一审在区间内酌定95%并无不当，驳回上诉维持。

## 对韩杰案 / 面瘫针灸案的锚定

- **韩杰案（医疗事故罪再审）**：本罪审查"严重不负责任"与因果关系；本案明示"多项核心诊疗过错 + 告知缺失"可推高责任比例，反向提示韩杰案辩护须聚焦"是否存在多项核心过错"与"过错与损害的因果链条"。
- **面瘫针灸协议**：说明义务（知情同意）是医疗损害责任的高频争议点，协议须显式载明风险与替代方案，与第1219条对齐。
- 与 R-PI-254（以鉴代审否定·下限酌定）、R-PI-278（多因一果原因力）构成医疗过错鉴定采信的三维样本。
