# 裁判规则 R-PI-065：未参保工伤的用人单位全额赔付与基金先行支付

**规则**：用人单位**未依法缴纳工伤保险费**，发生工伤事故的，由**该用人单位按照工伤保险待遇的项目和标准支付费用**。
- 用人单位不支付的，从**工伤保险基金中先行支付**，基金先行支付后有权向用人单位**追偿**。
- 职工因第三人原因造成工伤，第三人不支付工伤医疗费用或无法确定第三人的，由工伤保险基金先行支付，基金有权向第三人追偿。

**规范依据**：
- 《工伤保险条例》第62条第2款（未参保单位支付待遇）。
- 《社会保险法》第41条（未参保工伤待遇由用人单位支付，不支付则基金先行支付并追偿）。

**适用场景**：
- 代理未参保职工工伤索赔（建筑、餐饮、灵活用工等高发）；单位常以"未参保故无待遇"抗辩，应予驳斥。
- 主张补缴工伤保险费 + 工伤待遇并行；单位拒付时引导基金先行支付程序。

**攻防要点**：
- 受害方（职工）：证明存在劳动关系+工伤事实即可主张全额待遇，无需以"已参保"为前提；可同时要求社保行政部门责令单位补缴。
- 单位：不得主张"未参保则免责"；应核算并支付全部法定待遇项目（含一次性伤残补助金、伤残津贴、工亡待遇等，见 [[R-PI-062]]）。
- 注意：未参保不影响工伤认定，仅影响待遇支付主体（单位而非基金）。

**提炼来源**：《工伤保险条例》第62条、《社会保险法》第41条提炼，2026-08-05；配套 02-提炼笔记《工伤待遇项目计算与本人工资基数实务-2026-08-05》。
