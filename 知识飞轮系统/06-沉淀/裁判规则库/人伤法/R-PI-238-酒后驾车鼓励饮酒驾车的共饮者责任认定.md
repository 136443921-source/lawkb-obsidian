# 酒后驾车、鼓励饮酒驾车的共饮者责任认定（审判要件卡·共同饮酒）

> **卡型**：审判要件卡（正向裁判规则 · 法官心智）｜**编号**：`R-PI-238`｜**域**：PI（人伤）

## 一、裁判规则（正向·该怎么判）

**（1）酒后驾车发生交通事故的责任认定**

1. **饮酒人自负主要责任**——饮酒人作为具有完全民事行为能力的成年人，是自身安全的第一责任人，理应对自身酒后的身体状况及酒后驾车的危险性有充分的认知，其疏于履行确保自身安全的义务导致酒后驾车造成自己受伤的，应对自身发生的案涉事故**自负主要责任**。

2. **共饮者的提醒照看义务**——共饮者若明知同桌饮酒人通过驾车方式回家，其作为共同饮酒人（**特别是就餐组织者**），应当对同桌饮酒人的人身安全负有应有的提醒、照看义务。

3. **义务违反的后果**——共饮者未能尽到对醉酒的同桌饮酒人的照看义务，且在明知同桌饮酒人饮酒以及**归途较远**的情况下让其独自驾车回家的，其对于同桌饮酒人醉驾发生事故受伤者也应承担一定的赔偿责任。

4. **免责情形**——同桌饮酒人**未展现出明显醉酒状态**的，因酒后驾车本身属于违法行为，不应由共饮者承担过多提醒和劝阻义务；共饮者未有同乘车辆和鼓励酒后驾车行为的，**不宜认定其承担责任**。

5. **彻底免责**——在饮酒人**故意隐瞒驾车意图或经劝阻执意驾车**时，共饮者不应对饮酒人驾车出行发生事故造成人身损害承担赔偿责任。

**（2）鼓励饮酒并放任驾车的加重认定**

1. 饮酒人在醉酒的情况下，有可能陷入意识不清、继续过量饮酒的情形，此时共饮者应予以劝阻，而不是变相地鼓励诱导醉酒者继续饮酒。
2. 若共饮者**明知饮酒人严重醉酒，不仅不加劝阻，反而继续陪同饮酒**，该行为相当于变相地对醉酒者灌酒，**超出了「情谊行为」的限度，存在明显过错**。
3. 酒后驾驶会增加行车风险，极易引发交通事故，若共饮者**放任醉酒者驾车而不加阻拦，亦存在过错**。

## 二、审查要点（审理思路）

1. 先判断受害人是否**展现明显醉酒状态**——这是共饮者义务是否启动的分水岭。
2. 再查共饮者**是否明知**对方驾车：席间是否谈及、车辆是否停在现场、是否目击其上车。
3. 区分「未劝阻」与「鼓励」：前者是消极不作为，后者是积极作为，过错程度明显不同。
4. 核查免责抗辩：饮酒人是否隐瞒意图、共饮者是否曾实际劝阻。
5. 归途较远是加重因素，应在责任比例中体现。

## 三、构成要件与举证

| 待证事实 | 常见证据 |
|---|---|
| 饮酒人明显醉态 | 监控录像、同桌证言、事故认定书、血检报告 |
| 共饮者明知驾车 | 席间对话、车辆停放位置、钥匙交接、代驾叫单失败记录 |
| 共饮者未劝阻 | 现场录像、同行人证言 |
| 共饮者鼓励酒驾 | 聊天记录、证人证言、劝酒与怂恿言语 |
| 已劝阻／隐瞒意图 | 通话记录、证人证言、代驾预约记录 |

## 四、法条依据（权威源回填）

**《中华人民共和国民法典》第一千一百六十五条**

> 行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
> > 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

*效力状态：现行有效（元典核填 2026-09-03）*

*适用提示：未履行劝阻酒驾的行为义务，构成不作为侵权*

**《中华人民共和国民法典》第一千一百七十三条**

> 被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。

*效力状态：现行有效（元典核填 2026-09-03）*

*适用提示：饮酒人是自身安全的第一责任人，其过错可显著减轻共饮者责任*

## 五、抗辩与但书

**但书一**：酒后驾车本身是违法行为，共饮者的劝阻义务以**普通理性人的合理注意**为限，不是担保义务。饮酒人未展现明显醉态时，不宜对共饮者课以过多义务。

**但书二**：饮酒人故意隐瞒驾车意图或经劝阻仍执意驾车的，共饮者**完全免责**。

## 六、翻车标本

**标本**：同桌者酒驾身亡，判令全体共饮者连带担责。

**为什么错**：三重错误叠加——① 忽略了饮酒人作为第一责任人应负主要责任；② 忽略了「未展现明显醉态时不课加过多义务」的限制；③ 忽略了按份而非连带。

**正确姿势**：按顺序过五道关：有无醉态 → 共饮者是否明知驾车 → 是否劝阻 → 有无鼓励 → 有无隐瞒或执意。五关全过才谈得上责任，且是按份。
