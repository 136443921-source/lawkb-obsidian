# R-PI-185｜医疗纠纷五条法定路径的功能分工——卫健委管处罚、医调委管调解、法院管赔偿

## 裁判规则

《医疗纠纷预防和处理条例》第22条规定医疗纠纷可通过**五种途径**解决：①双方自愿协商、②申请人民调解、③申请行政调解、④向人民法院提起诉讼、⑤法律法规规定的其他途径。三条主路的**功能产出截然不同**，选错路径将浪费最宝贵的取证窗口：

| 路径 | 规范依据 | 能给你什么 | 不能给你什么 |
|---|---|---|---|
| **卫健委**（行政） | 条例第40条（5个工作日决定受理、30个工作日完成调解）；第55条（医疗事故行政调查依《医疗事故处理条例》） | **处罚医院**（警告/罚款/暂停执业/吊销证书）+ 组织行政调解 | **不等于民事赔偿**——行政处罚是公权力惩戒，与民事赔偿是两条线 |
| **医调委**（人民调解） | 条例第31条（共同申请；一方申请须征得另一方同意）；第32条（**不得收取费用**）；第33条（专家库）；第34条（可组织医疗损害鉴定）；第42条（不公开） | **免费**居中调解、专家支持、保护隐私 | **无强制执行力**——协议靠自觉履行，反悔须再经法院确认效力才能申请执行 |
| **法院**（诉讼） | 条例第43条（协商调解不成可起诉；**也可以直接起诉**）；第44条（赔付金额依法确定） | **有国家强制力的判决**，可申请强制执行 | 时间长（含鉴定约 1–2 年）、成本（鉴定费/诉讼费/律师费） |

**路径互斥规则**：依条例第31条末段，**当事人已向法院起诉并被受理，或已申请卫生主管部门调解并被受理的，医调委不予受理**——不得"一鱼多吃"，路径一旦选定即固定。

**第一顺位动作（先于路径选择）**：无论最终走哪条路，**第一件事永远是固定证据**——①**封存病历**（条例第23条医疗机构负有告知义务；第24条封存/启封须医患双方在场）；②**别急着签任何字**（赔偿方案、和解协议、调解协议签前须经专业审查，签了可能放弃后续追责权）。

## 适用范围

- 医疗纠纷患方咨询的首轮路径分流
- 医方（医疗机构）应对投诉的策略选择
- 与 R-PI-179（卫健委投诉路径匹配四宜四不宜）配套使用

## 关联法条

- 《医疗纠纷预防和处理条例》（国务院令第701号，2018-10-01 施行）第22、23、24、30、31、32、33、34、40、42、43、44、55条 —— **均现行有效**
- 《民法典》第1218条、第1222条（诉讼路径的实体依据）**现行有效**

## 实务要点

### 一、选择决策树
```
1. 对医院责任有把握吗？
   ├─ 没把握 → 先理病历（可走医调委低成本探底），别急着起诉
   └─ 有把握 → 看金额与诚意
2. 金额大小 + 对方诚意？
   ├─ 金额不大 + 医院愿谈 → 医调委（快、免费）
   ├─ 金额大 / 医院推诿 / 怕签了不履行 → 法院（或谈时留好后手）
3. 时间压力？
   ├─ 急用钱 → 协商 / 医调委
   └─ 求确定结果 → 法院
```

### 二、律师接案的三个提醒
1. **别把"投诉"当"索赔"**——患方最常见的误区，跑一个月投诉回来，病历没封存、鉴定没申请，最佳取证窗口已过；
2. **行政处罚 ≠ 民事赔偿**——但行政处罚决定（如认定篡改病历）在民事诉讼中是**极有价值的证据**（参见 R-PI-184 第①档：卫健委处罚证实篡改 → 推定过错 → 100% 责任）；
3. **两条线可并行**——向卫健委投诉（求处罚+固定行政认定）与准备民事诉讼（求赔偿）并不冲突，但**调解路径与诉讼路径互斥**。

### 三、与既有卡的关系
- 本卡解决"**走哪条路**"（程序分流）；
- [[R-PI-179-医疗纠纷卫健委投诉路径匹配]] 解决"**投诉怎么用才有效**"（卫健委单点）；
- [[R-PI-184-病历瑕疵五档裁判梯度从推定全责到酌定因素]] 解决"**进了法院能拿到多少**"（结果预期）。
