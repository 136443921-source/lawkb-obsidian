# 交强险无责限额内赔付规则与无责机动车赔付边界（R-PI-385）

## 裁判规则

1. **《道交法》第76条——无责机动车仍担责**：机动车发生交通事故造成人身伤亡、财产损失的，由保险公司在交强险责任限额范围内予以赔偿；机动车一方**没有过错**的，承担不超过**10%**的赔偿责任（不足部分按过错分担）。
2. **交强险无责赔付限额（银保监会2020公告）**：死亡伤残赔偿限额**18,000**元 + 医疗费用赔偿限额**1,800**元 + 财产损失赔偿限额**100**元 ＝ 合计 **19,900**元（有责限额为死亡伤残18万/医疗1.8万/财产0.2万）。
3. **无责机动车须在19,900元限额内赔付**：不以"行人/他车有责"而免赔；多车连环相撞中，各无责机动车分别在其无责限额内承担赔付（2026鲁法案例414·开原市法院）。
4. **反向边界**：无责赔付以"机动车一方无责"为前提；若机动车被认定有责，则走有责限额（死亡伤残18万），二者不可混用。

## 基本案情（来源：公开裁判口径综合·莲花县法院 / 开原市法院）

- **莲花县法院案**：机动车无责情形下，交强险在无责限额内赔付约19,800元（贴近19,900上限）。
- **开原市法院·2026鲁法案例414**：多车连环相撞，各无责机动车仍分别在其交强险无责限额内赔付，否定"无责即免赔"。

## 关联法条

- 《道路交通安全法》第76条（赔偿责任与交强险）
- 《机动车交通事故责任强制保险条例》第23条（限额授权）
- 银保监会《关于调整交强险责任限额和费率浮动系数的公告》（2020-09-19施行）

## 对在办案件的锚定

- **航合物流2026-09-01交通事故**：若本车（贵C09782D）被认定无责，交强险仅在19,900元无责限额内赔付；若存在多车连环相撞，各无责方分别限额内赔。须与有责限额（18万）严格区分，避免赔付基数错配。
- 与 R-PI-279（无责赔付与投保义务人无过错责任）、R-PI-255（未投保交强险限额内共同赔偿）、R-PI-259（赔偿项目总表）形成交通赔偿组合。
