# R-PI-213 医疗过错原因力比例与鉴定意见的采信规则

> 一句话：医疗损害责任的落点不是"有没有过错"，而是**过错对损害后果的原因力占比**——1218条确立过错责任的一般规则，1222条在三种情形下**推定过错**（举证责任移转），而原因力比例（次要 20%–40%、同等 50%、主要 60%–90%）由鉴定意见提供**技术判断**、由法院作**法律判断**；法院可以不采信鉴定结论中的比例，但**必须说明理由**。

## 一、法条基底（元典核填·现行有效，含官方核验指引）

- 《民法典》第一千二百一十八条：患者在诊疗活动中受到损害，**医疗机构或者其医务人员有过错的**，由医疗机构承担赔偿责任。
- 《民法典》第一千二百一十九条：医务人员在诊疗活动中应当向患者说明病情和医疗措施。需要实施手术、特殊检查、特殊治疗的，应当及时向患者具体说明医疗风险、替代医疗方案等情况，并**取得其明确同意**；不能或者不宜向患者说明的，应当向患者的近亲属说明，并取得其明确同意。医务人员未尽到前款义务，造成患者损害的，医疗机构应当承担赔偿责任。
- 《民法典》第一千二百二十二条：患者在诊疗活动中受到损害，有下列情形之一的，**推定医疗机构有过错**：
  （一）违反法律、行政法规、规章以及其他有关诊疗规范的规定；
  （二）隐匿或者拒绝提供与纠纷有关的病历资料；
  （三）遗失、伪造、篡改或者违法销毁病历资料。

## 二、规则要旨（教义提炼）

1. **两阶构造**：先定过错（1218 一般 / 1222 推定），再定原因力。过错成立不等于全额赔偿——**原因力是损害赔偿数额的乘数**。
2. **原因力的实务档位**（司法惯例，非法定）：
   | 档位 | 常见比例 | 典型情形 |
   | --- | --- | --- |
   | 轻微 | 10%–20% | 患者自身疾病为绝对主因，医方仅程序瑕疵 |
   | 次要 | 20%–40% | 延误诊断但原发病凶险、预后本不佳 |
   | 同等 | 50% | 漏诊/误诊显著加重后果，与自身疾病难分主次 |
   | 主要 | 60%–90% | 明显违反诊疗规范直接导致损害 |
   | 全部 | 100% | 与原发病无关的纯医疗行为致害（如输错药、异物遗留） |
3. **1222条的杀伤力在病历**：隐匿/拒供/遗失/伪造/篡改病历 → **过错推定**，医方须自证无过错，实务中几乎等于败诉。**病历封存与复制是患方第一动作**。
4. **知情同意（1219）是独立请求权基础**：即便诊疗行为本身无过错，未取得明确同意造成损害亦可单独成立责任；其损害常表现为**自主决定权受侵害**，赔偿额度通常低于身体损害，但可撬动调解。
5. **鉴定意见的司法审查**：法院对鉴定意见审查①鉴定机构与鉴定人资质②送检材料是否完整真实③论证过程是否自洽④是否超出鉴定范围作法律判断。**比例结论可调，但需在判决中说理**。

## 四、执业动作（人伤代理清单）

🔵 **患方**：①24 小时内申请**病历封存**并复制全部住院/门诊病历（含护理记录、麻醉记录、知情同意书原件）；②核对知情同意书签署时间与手术时间是否倒签（撬 1219）；③申请医疗损害鉴定并**在鉴定听证中明确提出原因力争点**；④固定 1222 三情形的任一证据（拒供回执、病历前后矫改痕迹）。

🔴 **医方**：①病历规范性自查（书写时限、签名、修改留痕）；②主张原发病自然进程为主因，压低原因力档位；③对鉴定意见提出书面异议并申请鉴定人出庭；④知情同意书完整性与说明充分性举证。

## 五、涵摄断裂标本

- 把"有过错"直接等同"全额赔偿" → 漏掉原因力乘数，请求或抗辩数额失真。
- 误以为 1222 推定过错**同时推定因果关系** → 错，1222 只推定过错，因果关系与原因力仍需查明（这是最常见的教义混淆）。
- 患方不申请鉴定就主张医方过错 → 举证不能败诉（见贵州高院任某案）。
- 混淆"医疗事故"（行政/刑事概念，《医疗纠纷预防和处理条例》）与"医疗损害责任"（民事概念，民法典第七编第六章）。
