# R-PI-585 好意同乘的审查认定与减责规则（民法典§1217）

> **来源降级声明（2026-10-23）**：本运行会话 ima-mcp / yuandian-mcp / qcc-legal 三通道工具均未注入本会话工具表（经 ToolSearch 实查 absent），D 阶段案例检索全走 WebSearch 降级。法条文本已据本地法条银行逐字回填（§1217 本地逐字核验一致）；案例来源 = 最高法入库案例公开评述，未经元典/qcc 交叉核验。依 v1.30 维持 **source_verified:false**，待下轮三通道可用时复验转正。

## 一、核心法条（已逐字核验·本地法条银行）

**《民法典》第一千二百一十七条**【好意同乘的责任承担】
> 非营运机动车发生交通事故造成无偿搭乘人损害，属于该机动车一方责任的，应当减轻其赔偿责任，但是机动车使用人有故意或者重大过失的除外。

## 二、裁判要旨与适用要点

1. **减责前提**：非营运机动车 + 无偿搭乘（好意施惠） + 属机动车一方责任 → **应当减轻**驾驶人赔偿责任；但驾驶人有**故意或重大过失**的，不减责。
2. **"无偿性"为核心审查点（入库案例要旨）**：不能简单以搭乘人是否直接向驾驶人支付费用作形式判断。驾驶人虽不直接向搭乘人收费，但系根据营运客车司机委托接驳乘客、并从该司机处获取相应对价的，该接驳行为实质属**有偿客运合同组成部分**，具明显营利目的，**不构成好意同乘**，不得主张减责。
3. **减责比例酌定**：法院综合驾驶人善举、事故责任、搭乘人自身过错（如未系安全带扩大损害，依§1173过失相抵）等因素酌定。实践中常在驾驶人本应承担部分的基础上减轻（如德化法院案酌定承担60%）。
4. **减责≠免责**：好意同乘减轻的是赔偿责任，不豁免基本安全驾驶义务；搭乘人亦应尽系好安全带、避免干扰驾驶等注意义务。

## 三、典型案例（WebSearch·待三通道复验）

- **路某林诉朱某梅等机动车交通事故责任纠纷案** —— (2025)苏1282民初6751号，**最高人民法院入库案例（入库编号：2026-07-2-411-005）**，江苏省靖江市人民法院 2026-01-30 判。裁判要旨：认定好意同乘不能简单以是否直接付费形式判断；朱某梅系依客车司机李某华安排接驳乘客并从中获取报酬，该接驳属有偿客运合同组成部分，不属好意同乘，其减责主张于法无据。最终按范某65%、朱某梅25%、路某林自身未系安全带10%划分责任。
- **周某诉陈某好意同乘案** —— 德化县人民法院（2025-09 审结，二审维持）。陈某无偿搭载同事项周某下班，同等责任事故；因构成好意同乘，依§1217酌定陈某承担本应承担部分的60%（周某自担40%）。
- **未成年人无偿载友事故案** —— 2026-10 广东交警普法案例。未满16周岁骑电动车违法载友单方事故，参照§1217减责精神，法院认定驾驶人承担70%、搭乘人30%（监护人担责）。

## 四、执业提示

- 代理搭乘人（受害方）：主张驾驶人存在故意/重大过失（如酒驾、无证、严重超速）以排除减责；或证明接驳行为有偿（非纯粹好意）以否定减责适用。
- 代理驾驶人：举证搭乘无偿性、善意外加自身过错轻微，争取依§1217减责；同时提示搭乘人未系安全带等过失可援引§1173。
