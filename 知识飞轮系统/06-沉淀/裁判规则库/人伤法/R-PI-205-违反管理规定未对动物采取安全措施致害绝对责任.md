# R-PI-205 违反管理规定未对动物采取安全措施致害的绝对责任

> 一句话：违反管理规定、**未对动物采取安全措施**造成他人损害的，动物饲养人/管理人承担侵权责任；仅当损害因被侵权人**故意**造成时可减轻责任（**重大过失不当然减责**）。本条是 1245 一般规则与 1247 烈性犬绝对责任之间的"中间强度"严格责任。

## 一、法条基底（本地权威源回填）

- 《民法典》第1246条：违反管理规定，未对动物采取安全措施造成他人损害的，动物饲养人或者管理人应当承担侵权责任；但是，能够证明损害是因被侵权人故意造成的，可以减轻责任。
- 与相邻条款的强度梯度：
  - 第1245条（一般无过错）：被侵权人**故意/重大过失**→可免除或减轻。
  - **第1246条（本条）：仅被侵权人"故意"→可减轻；"重大过失"不当然减责**（严于1245）。
  - 第1247条（禁养烈性犬等）：绝对责任，**无任何减责事由**。

## 二、裁判要旨（元典回源 2026-09-02）

| 案号 | 法院 | 核心裁判要旨 |
|---|---|---|
| **（2019）晋0403民初3112号** | 长治市潞州区人民法院 | 被告违反规定饲养烈性犬、且**未采取安全措施**（拴养巨型犬）将原告咬伤。法院：应负侵权责任；原告作为成年人发现犬后未尽注意义务，酌定**自行承担10%**。即实务中对"未采取措施+违规饲养"仍按严格责任处理，仅轻微疏忽可小幅减责 |
| **（2019）鄂09民终631号** | 湖北省孝感市中级人民法院 | 高永春违反禁养规定饲养藏獒等烈性犬、未采取措施，致受害人被咬后多脏器衰竭死亡。法院：违反禁养规定+未采取措施存在明显违法性与过错，承担**全部侵权责任**；上诉人称受害人自身未尽注意应减轻——**不予采纳** |

**规律**：本条项下，饲养人"违规+未管控"两项叠加时，法院倾向认定近乎绝对责任，仅在被侵权人明显故意（如主动挑衅、投喂激怒）时酌减；一般过失或疏忽不减轻。

## 三、涵摄断裂标本（高频翻车）

- 误将 1246 与 1245 的减责事由等同 → 1245 含"重大过失"减责，1246 **仅"故意"可减责**；主张被侵权人重大过失减责在 1246 下通常不被支持。
- 误以为"拴养/圈养=已采取安全措施" → 拴养但仍失控咬人（如本案巨型犬），一般认定为"未采取安全措施"；安全措施须达到防止动物致人损害的实际控制程度。
- 误将 1246 与 1247 混同 → 1247（禁养烈性犬）更严，连"故意"外的任何减责均不成立；1246 至少保留"故意可减责"空间。
