# 未投保交强险的机动车事故投保义务人先在交强险限额内全额赔付超出按责分担

> ✅ **来源核验完成**：本卡初版由 WebSearch 降级生成，经 A0.2 回源补正（元典 + 本地法条银行双通道交叉核验）已升级为 `source_verified:true`。**条号已校正**（原引道交解释§16 已失效，现行为侵权编解释一§21）。详见第四节。

## 一、核心要旨

1. **交强险是法定强制义务**：在境内道路行驶的机动车所有人和管理人须依法投保交强险；未投保机动车不得上路，发生事故后投保义务人须自行承担交强险范围内的赔偿责任。
2. **限额内先行 100% 赔付**：未依法投保交强险的机动车发生事故，投保义务人应在交强险责任限额（**医疗 18000 / 死亡伤残 180000 / 财产 2000**）内对受害人损失承担**全额赔偿责任**，该部分赔偿与事故责任比例无关。
3. **超出部分按责分担**：交强险限额外的损失，再按交通事故认定书确定的责任比例由侵权人承担。
4. **投保义务人与侵权人分离**：二者非同一人时，被侵权人合并请求的，侵权人在限额内承担其全部责任；投保义务人在交强险限额范围内与侵权人**共同承担责任**（但各责任主体实际支付总和不超出受害人应受偿总额）；投保义务人先行赔付后，就超限额部分可向侵权人追偿。

## 二、权威依据（已双通道核验 + 条号校正）

- 《民法典》第1213条：机动车事故属该机动车一方责任的，先由承保交强险的保险人在限额内赔偿；不足部分由商业险按约赔偿；仍不足或没投保商业险的，由侵权人赔偿。
- 《最高人民法院关于适用〈民法典〉侵权责任编的解释（一）》（法释〔2024〕12号，2024-09-27 施行）**第21条**：①责任人承担全部责任；②投保义务人仅在交强险限额内共同承担；③各责任主体实付总和不得超出被侵权人应受偿损失数额；④投保义务人先行赔付后，对超限额部分可向责任人追偿。
- 《机动车交通事故责任强制保险条例》：交强险责任限额与强制投保义务。
- ⚠️ **条号校正**：原卡引《道路交通事故损害赔偿司法解释》第16条——该条已被法释〔2024〕12号第21条取代（本地 法条银行已标注"本条已被取代，勿再援引"），已更正。

## 三、实务锚点

- **航合物流 2026-09-01 贵C09782D 货车致死案 / 一般交通事故案件**：物流车辆务必核查交强险投保状态；若单位车辆未投保交强险，单位作为投保义务人须先在限额内全额赔付，超出再按责——这是"未投保"情形下的兜底重责。
- **机动车认定扩张**：二轮摩托车/电动摩托车/电动三轮车等被技术鉴定为机动车的，同样强制投保交强险；"不知道也要买"不是免责事由。
- 与 [[R-PI-241]]（未投保交强险机动车赔付）互补：本卡补强"投保义务人与侵权人分离时的共同责任 + 追偿"规则。
