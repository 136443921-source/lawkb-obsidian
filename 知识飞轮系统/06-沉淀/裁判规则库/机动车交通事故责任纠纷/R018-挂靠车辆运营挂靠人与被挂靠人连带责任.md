# 裁判规则 R018 - 挂靠车辆运营中致害，挂靠人与被挂靠人连带责任

**规范来源**：《最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释》（法释〔2020〕17号）第4条
**审理法院**：各级法院普遍规则
**裁判要旨**：以挂靠形式从事道路运输经营活动的机动车发生交通事故造成损害，属于该机动车一方责任的，由**挂靠人和被挂靠人承担连带责任**。
**适用要点**：
1. 构成前提：车辆以挂靠形式**从事运输经营**，事故发生在运营活动中。
2. 责任形态为**连带责任**，受害人可择一或一并主张，被挂靠人赔偿后可依内部约定向挂靠人追偿。
3. 与交强险关系：交强险仍先行赔付，连带责任作用于超出交强险的部分。
4. 诉讼实务：应将挂靠人、被挂靠单位、承保保险公司一并列为被告。
**关联法条**：《民法典》第1211条（挂靠情形机动车交通事故责任）
