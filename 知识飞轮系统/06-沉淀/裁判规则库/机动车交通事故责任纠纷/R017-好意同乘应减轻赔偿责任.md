# 裁判规则 R017 - 好意同乘发生事故应减轻赔偿责任

**规范来源**：《民法典》第1217条
**审理法院**：各级法院普遍规则
**裁判要旨**：非营运机动车发生交通事故造成**无偿搭乘人**损害，属于该机动车一方责任的，**应当减轻**其赔偿责任；但机动车使用人有故意或者重大过失的除外。
**适用要点**：
1. 构成要件：①非营运车辆；②无偿搭乘（顺路捎带、亲友互助等，无对价）；③损害属机动车一方责任。
2. "应当减轻"是**法定减责**，非法院自由裁量是否减，只在减多少上裁量（实务多减 10%-30%）。
3. **例外**：驾驶人存在故意或重大过失（如醉驾、严重超速、疲劳驾驶）的，不予减轻。
4. 涉及交强险时，先由交强险在限额内足额赔付，减责仅作用于**超出交强险的侵权人自负部分**。
**关联法条**：《道路交通安全法》第76条
