# 裁判规则 R031 - 超法定退休年龄但仍在劳动的，误工费应予支持

**规范来源**：最高人民法院民一庭倾向性意见（2021）；法释〔2022〕14号第7条
**案号**：（规则型·最高法民一庭倾向性意见，各地法院参照）
**审理法院**：各级法院参照适用
**裁判要旨**：受害人虽已达法定退休年龄，但能够证明其**仍从事劳动并取得收入**、因伤导致收入实际减少的，误工费**应予支持**。退休年龄不当然免除误工损失赔偿。
**适用要点**：
1. 核心证据闭环：劳动合同/劳务协议 + 工资流水 + 单位误工证明 + 完税凭证（如有），证明"受伤前在劳动、受伤后收入减少"。
2. 误工期以**三期鉴定**或医疗机构证明为准（见 [[三期鉴定实务-误工期护理期营养期]]）。
3. 若确无劳动收入（如纯居家养老且无兼业），则不支持误工费；被告可就此抗辩。
4. 收入标准参照：有固定收入按实际减少；无固定按近三年平均或受诉法院所在地相同或相近行业上一年度职工平均工资。
**关联法条**：法释〔2022〕14号第7条
