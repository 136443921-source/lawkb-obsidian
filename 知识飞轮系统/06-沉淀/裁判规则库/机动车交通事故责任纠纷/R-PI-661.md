# R-PI-661 机动车交通事故先由交强险赔付，网约车平台依风险收益对等担责

## 规则
机动车交通事故造成损害的，先由保险公司在交强险责任限额内赔偿；不足部分按过错由商业三者险/侵权人分担；受害人自身过错减轻赔偿。网约车平台因对驾驶员负准入、培训、日常安全管理义务，且每单收取服务费抽成、实质享有运营收益，须依风险收益对等原则对超出保险部分的损失承担相应赔偿责任，不得仅以"合作关系"免责。

## 适用要点
1. 赔偿顺序：交强险 → 商业三者险 → 侵权人（《民法典》第1213条）。
2. 机动车与非机动车/行人事故，优者危险负担原则下机动车方注意义务更高（道交法第76条）。
3. 受害人违法搭载、超速等自身过错，可自担交强险外部分损失（如 10%）。
4. 平台责任边界：依安全监管疏漏与收益抽成比例酌定（如超出保险部分 20%）。

## 业务提示
- 关联航合物流货车事故责任分配；参考 R-PI-608（道交法§76 机动车无过错 10% 上限）。
- 代理平台或驾驶员一方：厘清平台"合作关系"与实质运营控制，预判安全风险担责区间。
