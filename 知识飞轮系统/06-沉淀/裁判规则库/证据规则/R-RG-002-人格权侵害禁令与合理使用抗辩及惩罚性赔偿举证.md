# 裁判规则
人格权侵害可依法申请**行为禁令**（民法典第997条）：有证据证明行为人正在实施或即将实施侵害人格权的违法行为，不及时制止将致**难以弥补的损害**的，受害人可向法院申请责令停止有关行为（无需先经诉讼）。新闻报道、舆论监督等可**合理使用**姓名、名称、肖像、个人信息（第999条），但使用不合理侵害人格权的仍担责；网络发布事实有误的，受害人有权请求及时采取更正或删除等必要措施。故意侵害他人人格权**情节严重**的，被侵权人有权请求**相应惩罚性赔偿**（第996条，注意与第1185条知识产权惩罚性赔偿相区分）。

# 适用案由与场景
- 人格权侵害**正在持续或即将发生**（热点事件网暴、持续网帖、商业诋毁）
- 舆论监督/媒体报道边界争议
- 故意侵权**情节严重**主张惩罚性赔偿

# 举证责任分配
| 要件 | 举证责任 | 说明 |
|---|---|---|
| 禁令：正在/即将实施违法行为 | 申请人 | 第997条行为保全式举证：胜诉可能性+紧迫性+难以弥补损害 |
| 禁令：不及时制止致难以弥补损害 | 申请人 | 损害不可逆转性（如网暴扩散不可逆） |
| 合理使用（第999条）：舆论监督/公共利益目的 | 行为人 | 目的正当+方式合理 |
| 惩罚性赔偿（第996条）：故意+情节严重 | 被侵权人 | 主观故意+后果严重（区别于一般赔偿） |

# 法条依据·官方核验指引（企查查·法律数据核填·现行有效）

> 下列条文均经企查查·法律数据（qcc-legal）核填，现行有效（核验日期 2026-09-12）；正式文书引用前以官方文本为准。

> **【民法典第996条】**（违约损人格权可并行精神赔偿）*企查查·法律数据核填·现行有效*：因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1376）

> **【民法典第997条】**（人格权侵害禁令）*企查查·法律数据核填·现行有效*：民事主体有证据证明行为人正在实施或者即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，有权依法向人民法院申请采取责令行为人停止有关行为的措施。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1377）

> **【民法典第999条】**（合理使用（舆论监督））*企查查·法律数据核填·现行有效*：为公共利益实施新闻报道、舆论监督等行为的，可以合理使用民事主体的姓名、名称、肖像、个人信息等；使用不合理侵害民事主体人格权的，应当依法承担民事责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1379）

> **【民事诉讼法第104条】**（诉前行为保全）*企查查·法律数据核填·现行有效*：利害关系人因情况紧急，不立即申请保全将会使其合法权益受到难以弥补的损害的，可以在提起诉讼或者申请仲裁前向被保全财产所在地、被申请人住所地或者对案件有管辖权的人民法院申请采取保全措施。申请人应当提供担保，不提供担保的，裁定驳回申请。（核验：http://legal.qcc.com/regulation/9d9ce7d57d758ce2c8ac930bfbb4f327/161）
> 人民法院接受申请后，必须在四十八小时内作出裁定；裁定采取保全措施的，应当立即开始执行。
> 申请人在人民法院采取保全措施后三十日内不依法提起诉讼或者申请仲裁的，人民法院应当解除保全。

# 攻防要点
- **禁令申请**：强调紧迫性与难以弥补性，依民诉法第104条提供担保；重点证"正在/即将实施"+损害不可逆。
- **合理使用抗辩**：目的（公共利益/舆论监督）+方式合理+信息基本真实。
- **惩罚性赔偿**：须证"故意"+"情节严重"，一般过失不适用；数额与侵权获利/损害相当。

# 质证话术模板
- 申请人："被告持续发布不实信息（证据），不及时制止将导致原告社会评价不可逆下滑，依第997条申请禁令。"
- 被告："报道属第999条舆论监督，内容基本真实、方式合理，不构成侵害人格权，不适用惩罚性赔偿。"
