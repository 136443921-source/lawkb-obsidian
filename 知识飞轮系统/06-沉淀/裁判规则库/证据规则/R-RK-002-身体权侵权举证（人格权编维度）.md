# 裁判规则
身体权以身体完整与行动自由为保护内容（民法典第1003条），是人格权编第二章明定的具体人格权。侵害身体权采**一般过错责任**（第1165条①款），原告就侵害行为、损害后果、因果关系、主观过错四要件举证；**行动自由受限**（非法拘禁、非法约束身体）属身体权维度，与人身自由权（第1011条，见 [[R-RL-001-人身自由权侵权举证（非法拘禁搜查与性骚扰）]]）存在竞合，举证时择一主张或竞合主张。第1005条**法定救助义务**共通三权。人格权请求权不适用诉讼时效（第995条）。

# 适用案由与场景
- **生命权、身体权、健康权纠纷（一般案由）·身体权维度**：殴打致身体组织受损、破坏身体组织、非法搜查身体、非法约束／限制身体行动且**无对应专门案由**时适用。
- **客体区分**：身体完整受损（殴打／创伤／肢体损害）→身体权；身心健康受损（疾病／精神障碍）→健康权（[[R-RK-003-健康权侵权举证（人格权编维度）]]）；致死→生命权（[[R-RK-001-生命权侵权举证（人格权编维度）]]）。
- 与专门案由关系：机动车／医疗／产品／动物／高度危险致身体受损的，整体归专门案由。

# 举证责任分配
| 要件 | 举证责任 | 说明 |
|---|---|---|
| 原告享有身体权 | 原告 | 法定具体人格权，证受害主体适格即可（1003） |
| 侵害行为（殴打／破坏身体组织／非法搜查／限制身体行动） | 原告 | 区分客体：身体完整受损→身体权；行动自由受限亦属身体权维度（与 RL 竞合） |
| 损害后果 | 原告 | 伤情／病历／鉴定意见（身体组织受损程度） |
| 因果关系 | 原告 | 行为与身体损害之间；多因一果按份责任 |
| 被告过错 | 原告 | 一般过错责任，证故意或过失；专门案由例外（医疗过错推定见 [[R-PI-267-医疗过错举证责任与过错推定攻防]]） |
| 免责／减责事由（被害人过错／自甘风险／第三人原因） | 被告 | 第1173条被侵权人过错减轻；第1175条第三人原因；第1176条自甘风险 |
| 法定救助义务违反（1005） | 原告就义务存在与违反举证；被告证已尽合理施救 | 医疗机构拒诊、监护人遗弃、安全保障义务人怠于施救致身体损害扩大 |

# 法条依据·官方核验指引（企查查·法律数据核填·现行有效）

> 下列条文均经企查查·法律数据（qcc-legal）核填，现行有效（核验日期 2026-09-12）；正式文书引用前以官方文本为准。

> **【民法典第995条】**（人格权请求权不适用诉讼时效）*企查查·法律数据核填·现行有效*：人格权受到侵害的，受害人有权依照本法和其他法律的规定请求行为人承担民事责任。受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1375）

> **【民法典第1003条】**（身体权：身体完整与行动自由）*企查查·法律数据核填·现行有效*：自然人享有身体权。自然人的身体完整和行动自由受法律保护。任何组织或者个人不得侵害他人的身体权。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1384）

> **【民法典第1005条】**（法定救助义务（共通三权））*企查查·法律数据核填·现行有效*：自然人的生命权、身体权、健康权受到侵害或者处于其他危难情形的，负有法定救助义务的组织或者个人应当及时施救。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1386）

> **【民法典第1011条】**（非法拘禁搜查身体）*企查查·法律数据核填·现行有效*：以非法拘禁等方式剥夺、限制他人的行动自由，或者非法搜查他人身体的，受害人有权依法请求行为人承担民事责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1392）

> **【民法典第1165条】**（过错责任一般条款）*企查查·法律数据核填·现行有效*：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1655）
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

> **【民法典第1173条】**（被侵权人过错减轻）*企查查·法律数据核填·现行有效*：被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1663）

> **【民法典第1179条】**（人身损害赔偿范围）*企查查·法律数据核填·现行有效*：侵害他人造成人身损害的，应当赔偿医疗费、护理费、交通费、营养费、住院伙食补助费等为治疗和康复支出的合理费用，以及因误工减少的收入。造成残疾的，还应当赔偿辅助器具费和残疾赔偿金；造成死亡的，还应当赔偿丧葬费和死亡赔偿金。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1670）

> **【民法典第1183条】**（严重精神损害赔偿）*企查查·法律数据核填·现行有效*：侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1674）
> 因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的，被侵权人有权请求精神损害赔偿。

# 攻防要点
- **原告侧**：先固定"身体完整／行动自由受限"客体→锁定身体权维度；一般过错下四要件齐备，重点攻"过错"与"因果关系"；行动自由受限情形注意与 RL 人身自由权竞合，择有利路径。
- **被告侧**：主张被害人过错减轻（1173）、自甘风险（1176）、第三人原因（1175）、或已尽法定救助义务（1005 抗辩）。

# 质证话术模板
- 原告："被告殴打致原告身体组织受损（具体表现），侵害身体权（1003），四要件已证，请依1179判赔。"
- 被告："原告损害系其自身疾病（第三人原因／自甘风险），依1173／1175／1176应减轻或免责；或本行为属正当履职，无过错。"
