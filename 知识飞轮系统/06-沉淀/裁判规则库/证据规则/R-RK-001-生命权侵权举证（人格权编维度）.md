# 裁判规则
生命权以生命安全与生命尊严为内容（民法典第1002条），是人格权编第二章明定的最高位阶具体人格权。**致死情形下赔偿权利人依法转为近亲属**（死亡赔偿金、丧葬费、精神损害抚慰金由近亲属主张），原告须先证"赔偿权利人适格"。侵害生命权采**一般过错责任**（第1165条①款），原告就侵害行为、死亡后果、因果关系、主观过错四要件举证；凡落入专门案由（机动车交通事故、医疗损害、工伤、产品责任、高度危险）即整体移出本案由，改适用专门案由归责与举证（见 [[R-AY-012-生命权身体权健康权纠纷单案由路由卡]] 选型决策树）。第1005条另设**法定救助义务**共通三权——负有法定救助义务的组织或个人（医疗机构、监护人、安全保障义务人等）未及时施救致损害扩大（含延误救治致死）的，可就"义务违反＋扩大损失"部分举证求偿。人格权请求权不适用诉讼时效（第995条）。

# 适用案由与场景
- **生命权、身体权、健康权纠纷（一般案由）·生命权维度**：仅当侵害生命权且**无对应专门案由**（一般殴打致死、意外致死、非法阻断救治致死、拒绝法定救助致延误死亡等）时适用。
- **致死客体区分**：直接致死→生命权；身体组织受损未致死→身体权（[[R-RK-002-身体权侵权举证（人格权编维度）]]）；身心健康受损未致死→健康权（[[R-RK-003-健康权侵权举证（人格权编维度）]]）。
- 与专门案由关系：机动车／医疗／工亡／产品／高度危险致死的，整体归专门案由，本案由仅作兜底；医疗过错致死维度见 [[R-PI-267-医疗过错举证责任与过错推定攻防]]，工亡维度见 [[R-GZ-022-工伤认定不认为是工伤举证责任倒置]]。

# 举证责任分配
| 要件 | 举证责任 | 说明 |
|---|---|---|
| 赔偿权利人适格（原告为死者近亲属） | 原告 | 证死亡证明＋近亲属关系（配偶／父母／子女等）；生命权致死时权利主体转移 |
| 侵害生命权行为（殴打致死／阻断救治／拒绝救助） | 原告 | 区分客体：致死→生命权；行为与生命终结之间 |
| 死亡后果 | 原告 | 死亡证明／法医鉴定／尸检报告 |
| 因果关系 | 原告 | 行为与死亡之间；多因一果按份责任（参考胡某某诉德某餐厅生命权纠纷指导案例） |
| 被告过错 | 原告 | 一般过错责任，证故意或过失；专门案由例外（医疗过错推定见 [[R-PI-267-医疗过错举证责任与过错推定攻防]]） |
| 免责／减责事由（被害人过错／自甘风险／第三人原因） | 被告 | 第1173条被侵权人过错减轻；第1175条第三人原因；第1176条自甘风险 |
| 法定救助义务违反（1005） | 原告就义务存在与违反举证；被告证已尽合理施救 | 医疗机构拒诊、监护人遗弃、安全保障义务人怠于施救致延误死亡 |

# 法条依据·官方核验指引（企查查·法律数据核填·现行有效）

> 下列条文均经企查查·法律数据（qcc-legal）核填，现行有效（核验日期 2026-09-12）；正式文书引用前以官方文本为准。

> **【民法典第995条】**（人格权请求权不适用诉讼时效）*企查查·法律数据核填·现行有效*：人格权受到侵害的，受害人有权依照本法和其他法律的规定请求行为人承担民事责任。受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1375）

> **【民法典第1002条】**（生命权：生命安全与生命尊严）*企查查·法律数据核填·现行有效*：自然人享有生命权。自然人的生命安全和生命尊严受法律保护。任何组织或者个人不得侵害他人的生命权。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1383）

> **【民法典第1005条】**（法定救助义务（共通三权））*企查查·法律数据核填·现行有效*：自然人的生命权、身体权、健康权受到侵害或者处于其他危难情形的，负有法定救助义务的组织或者个人应当及时施救。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1386）

> **【民法典第1165条】**（过错责任一般条款）*企查查·法律数据核填·现行有效*：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1655）
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

> **【民法典第1173条】**（被侵权人过错减轻）*企查查·法律数据核填·现行有效*：被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1663）

> **【民法典第1179条】**（人身损害赔偿范围）*企查查·法律数据核填·现行有效*：侵害他人造成人身损害的，应当赔偿医疗费、护理费、交通费、营养费、住院伙食补助费等为治疗和康复支出的合理费用，以及因误工减少的收入。造成残疾的，还应当赔偿辅助器具费和残疾赔偿金；造成死亡的，还应当赔偿丧葬费和死亡赔偿金。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1670）

> **【民法典第1182条】**（侵害人身权益财产损失赔偿）*企查查·法律数据核填·现行有效*：侵害他人人身权益造成财产损失的，按照被侵权人因此受到的损失或者侵权人因此获得的利益赔偿；被侵权人因此受到的损失以及侵权人因此获得的利益难以确定，被侵权人和侵权人就赔偿数额协商不一致，向人民法院提起诉讼的，由人民法院根据实际情况确定赔偿数额。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1673）

> **【民法典第1183条】**（严重精神损害赔偿）*企查查·法律数据核填·现行有效*：侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1674）
> 因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的，被侵权人有权请求精神损害赔偿。

# 攻防要点
- **原告侧**：先固定"致死"客体→锁定生命权维度；证赔偿权利人适格（近亲属关系）是前置门槛；一般过错下四要件齐备，重点攻"过错"与"因果关系"；遇专门案由情形主动转向专门案由路径（举证可能更利我方，如医疗过错推定）。
- **被告侧**：主张被害人过错减轻（1173）、自甘风险（1176）、第三人原因（1175）、或已尽法定救助义务（1005 抗辩）；若原告误定一般案由而有专门案由，异议要求其转向专门案由。

# 质证话术模板
- 原告："被告殴打致受害人死亡（具体表现），侵害生命权（1002），四要件已证，赔偿权利人系死者近亲属，请依1179判赔死亡赔偿金及丧葬费。"
- 被告："原告损害系其自身疾病（第三人原因／自甘风险），依1173／1175／1176应减轻或免责；或本行为属正当履职，无过错。"
