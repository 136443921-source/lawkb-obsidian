# 裁判规则
自然人享有**人身自由权**（民法典第1011条）：任何组织或者个人以**非法拘禁**等方式剥夺、限制自然人行动自由，或者**非法搜查**自然人身体的，受害人有权依法请求行为人承担民事责任。机关、企业、学校等单位对**性骚扰**负有预防、受理投诉、调查处置义务（第1010条2款）；违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权依法请求行为人承担民事责任（第1010条1款）。人身自由权侵权采**过错责任**（第1165条1款），被侵权人就非法限制/搜查/骚扰行为、损害、因果、过错举证；单位未尽防治义务的，就管理过错举证（第1010条2款）。

# 适用案由与场景
- **非法拘禁、非法限制人身自由**（传销、用工扣押、非法看管）
- **非法搜查身体**（商家/单位违规搜身）
- **职场/校园/公共场所性骚扰**

# 举证责任分配
| 要件 | 举证责任 | 说明 |
|---|---|---|
| 非法剥夺/限制行动自由 或 非法搜查身体 | 原告 | 第1011条行为本身违法性 |
| 性骚扰行为（违背意愿+言语/文字/图像/肢体） | 原告 | 第1010条1款；"违背意愿"为核心 |
| 损害后果（人身自由受限/精神损害） | 原告 | 第1183条精神损害赔偿 |
| 因果关系 | 原告 | — |
| 被告过错 | 原告 | 一般过错责任 |
| 单位未尽防治义务（第1010条2款） | 原告初步+单位反证 | 单位证已尽合理预防、受理、调查处置 |

# 法条依据·官方核验指引（企查查·法律数据核填·现行有效）

> 下列条文均经企查查·法律数据（qcc-legal）核填，现行有效（核验日期 2026-09-12）；正式文书引用前以官方文本为准。

> **【民法典第995条】**（人格权请求权不适用诉讼时效）*企查查·法律数据核填·现行有效*：人格权受到侵害的，受害人有权依照本法和其他法律的规定请求行为人承担民事责任。受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1375）

> **【民法典第1010条】**（性骚扰及单位义务）*企查查·法律数据核填·现行有效*：违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权依法请求行为人承担民事责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1391）
> 机关、企业、学校等单位应当采取合理的预防、受理投诉、调查处置等措施，防止和制止利用职权、从属关系等实施性骚扰。

> **【民法典第1011条】**（非法拘禁搜查身体）*企查查·法律数据核填·现行有效*：以非法拘禁等方式剥夺、限制他人的行动自由，或者非法搜查他人身体的，受害人有权依法请求行为人承担民事责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1392）

> **【民法典第1165条】**（过错责任一般条款）*企查查·法律数据核填·现行有效*：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1655）
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

> **【民法典第1173条】**（被侵权人过错减轻）*企查查·法律数据核填·现行有效*：被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1663）

> **【民法典第1182条】**（侵害人身权益财产损失赔偿）*企查查·法律数据核填·现行有效*：侵害他人人身权益造成财产损失的，按照被侵权人因此受到的损失或者侵权人因此获得的利益赔偿；被侵权人因此受到的损失以及侵权人因此获得的利益难以确定，被侵权人和侵权人就赔偿数额协商不一致，向人民法院提起诉讼的，由人民法院根据实际情况确定赔偿数额。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1673）

> **【民法典第1183条】**（严重精神损害赔偿）*企查查·法律数据核填·现行有效*：侵害自然人人身权益造成严重精神损害的，被侵权人有权请求精神损害赔偿。（核验：http://legal.qcc.com/regulation/4a622e179c0fd24aef2f9166c77cdaa4/1674）
> 因故意或者重大过失侵害自然人具有人身意义的特定物造成严重精神损害的，被侵权人有权请求精神损害赔偿。

# 攻防要点
- **原告**：固定非法限制/搜查/骚扰证据（监控、录音、证人、伤情）；单位案中证明单位制度缺失、投诉无门、处置迟延。
- **被告**：行为经同意或法定程序（如公安依法传唤/搜查）；性骚扰案中"未违背意愿"或"方式未越界"。

# 质证话术模板
- 原告："被告非法限制原告人身自由X小时（证据），违反第1011条；或被告行为违背原告意愿构成性骚扰第1010条。"
- 被告："限制人身自由系依XX法定程序；或双方互动自愿、未违背意愿。"
