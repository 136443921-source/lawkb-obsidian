# 法条核验段标准模板（元典核填 + 官方核验指引）v1.0.0

> **一句话**：所有含法条依据的卡，建卡时第四段「法条依据」必须采用本模板——**元典/法宝核填正文 + 内嵌「官方核验指引」子节**。下次建卡直接套用，不必像 R-LN-048 那样逐张手补核验入口。
> **适用卡型**：审判要件卡、证据规则卡（R-PR/R-PI/R-GZ/R-HJ，7 段变体，关联为末段）、实务规则卡（R-LN 类，8 段）、文书范式卡、定性分野卡。凡卡内含「法条依据」段者等同适用。

---

## 法条依据（元典核填·现行有效）

> 以下条文经**华宇元典 MCP**（`yuandian_rh_ft_detail`，参数 `fgmc` + 中文条号）或**北大法宝**（`mcp__pkulaw__mcp-law-search-service.get_article`，参数 `title` + `number`）逐条核填，标注现行有效性；引用前仍须与最高法官网 / 国家法律法规数据库官方文本最终核对。
> 待回源条文标「待回源」并将 frontmatter `statute_text_pending: true`；核填完成后翻转 `source_verified: true` / `statute_text_pending: false`。

- **《<法规全名>(<年份修正>) 第 <N> 条》**（<效力状态>·元典核填）：<条文正文，逐字回填，不缩写>
- **《<法规全名>》第 <N> 条**（<效力状态>·元典核填）：<条文正文>
- （逐条独立一行，标明来源与效力状态，**禁止集中标注**；多款法条分列第 1—5 条等）

### 官方核验指引（正式文书引用前二次核对）

> 本卡条号虽经元典核填，但**正式文书引用前仍须与官方文本最终核对并注明条号来源**（见翻车风险 / 来源段）。以下为权威核验入口与逐条检索路径，可直接点击二次核对。

**① 国家法律法规数据库（全国人大官方，已验证可达）**
- 入口：https://flk.npc.gov.cn/
- 覆盖：现行法律 + 两高司法解释（含刑诉法、民诉法、各司法解释），全国人大备案权威库。
- 检索路径：首页搜索框输入文件名 / 条号 → 选对应修正或施行年份版本 → 核对条文。

**② 最高人民法院官网（已验证可达）**
- 入口：https://www.court.gov.cn/
- 覆盖：司法解释全文发布 + 「权威发布 > 最高人民法院公报」栏目（公报子站 gongbao.court.gov.cn 偶发 502，以官网栏目为准）。
- 检索路径：导航「司法解释」/「公报」栏目 → 按文件名或法释、法发文号检索。

**③ 逐条二次核对检索词（对应上方核填）**
- <法规名>(<年份修正>) 第 <N> 条 → flk 检索「<文件名>」选对应版本；或 court.gov.cn 检索「<文件名>」/「<法释〔年份〕X号 或 法发〔年份〕X号>」；
- （逐条列出文件名 + 文号，便于二次核对；元典未收录中央正文者，以官方文本为准并显式标注）

**④ 已连接权威源辅助复核**：北大法宝（pkulaw）、华宇元典（yuandian-mcp）亦可作为条文比对的交叉核验源，但**最终引用以①②官方文本为准**。
