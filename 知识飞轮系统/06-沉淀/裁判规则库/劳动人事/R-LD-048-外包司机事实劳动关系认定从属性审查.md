# 核心要旨

外包、劳务派遣等灵活用工形态下，劳动关系认定回归"用工事实"本质，而非仅凭外包协议之名义；核心审查"从属性"三要件。

- **从属性三要件**：认定事实劳动关系须综合审查①**人格从属性**（接受用人单位管理、遵守规章制度、出勤考核）；②**经济从属性**（报酬由用人单位或其指定主体支付、依赖该报酬维持生活）；③**组织从属性**（纳入用人单位业务组成部分、以该单位名义对外）。
- **外包名义不当然阻断劳动关系**：用人单位以"业务外包""合作经营"等名义规避劳动关系的，若实际履行呈现前述从属性，仍应认定事实劳动关系（"名为外包、实为劳动"）。
- **外包司机典型场景**：物流/货运平台外包司机，若由平台或实际运营方排班、考核、直接发放报酬、统一标识与调度，可认定与实际用工方存在事实劳动关系；该认定直接影响工伤待遇、第三人侵权双赔（航合物流事故关联）。
- **权威案例（pkulaw 北大法宝核验·现行有效）**：
  - (2026)鄂05民终783号（宜昌某甲）：穿透外包合同，依劳社部发〔2005〕12号三要件认定事实劳动关系。
  - (2020)渝01民终478号（冷祥平/万星）：将业务外包给有资质公司、无实际从属性，不认定劳动关系。
  - (2023)渝01民终12123号（唐某/风某）：证据不足以证明从属性，不认定劳动关系。
  - (2024)鄂01民终13615号（武汉某某/何某辉）：外包司机注册个体户仍依实际从属性认定劳动关系。
  - (2019)鄂01民终5629号（田松林/宗泰）：出租车承包经营从属性松散，不认定劳动关系。

# 关联法条（pkulaw 北大法宝核验·现行有效，本地源已建）

- 《劳动合同法》（2012修正）第7条（用人单位自用工之日起即与劳动者建立劳动关系）、第10条（建立劳动关系应订立书面劳动合同；用工前订立的，劳动关系自用工之日起建立）。
- 《关于确立劳动关系有关事项的通知》（劳社部发〔2005〕12号）第1条（认定事实劳动关系三要件：①双方具主体资格；②劳动者受用人单位管理、从事有报酬的劳动；③劳动者提供的劳动是用人单位业务组成部分）、第2条（参照凭证：工资支付凭证、工作证、招工招聘记录、考勤记录、其他劳动者证言等）、第3条（由用人单位负举证责任）。
- 《工伤保险条例》（2010修订）第14条（工伤认定七种情形，含"工作时间工作场所因工作原因受伤害"等）。
- ⚠️ 本地源核验：已新建《中华人民共和国劳动合同法（2012修正）》《劳社部发〔2005〕12号》本地源（法律法规库/通用实体法、行政法律规章/），可直接引用。

# 适用场景

- **航合物流2026-09-01事故（贵C09782D 货车致人死亡）**：涉事司机若系外包/挂靠而非正式员工，需审查其与航合物流及上游主体的从属性，以定工伤待遇、雇主责任与第三人侵权双赔路径。
- **新就业形态用工合规**：为物流/货运企业设计外包方案时，应避免"名为外包实为劳动"的合规风险，明确排班、报酬、管理的法律归属。
