# R-LD-003 上下班途中工伤认定的合理路线与合理时间扩张

## 规则要旨
1. **合理路线 ≠ 唯一/最短路线**：职工从居住地至单位的常规通行路线之一即具合理性；以通勤为直接目的、在合理时间与范围内，路线选择具备日常性、周期性、相对固定性即属"上下班途中"（《最高法工伤保险行政案件规定》第6条）。
2. **提前离岗：不是"一律不影响"，而是「正当理由 + 请假/交接手续」双要素检验**（⛔ 2026-09-01 13:12 实证修正，原表述"提前离岗不影响工伤认定"**已被 2:1 的实证裁判否定**，详见正文「提前离岗专项」）：
   - ✅ **有正当理由**（已完成本职工作、天气恶劣、身体不适等客观事由）→ 属合理时间，**认定工伤**；
   - ✅ **经单位领导同意或已办理请假/交接手续** → 仍属"上下班"范畴，**认定工伤**；
   - ❌ **擅自离岗 + 无正当理由 + 超出合理限度**（提前时长过长）→ **不予认定**；
   - ⚠️ **加重情节**：代打卡等规避考勤行为，显著强化"非合理时间"的认定；
   - ⚠️ **单位内部"早退出事与本厂无关"条款无效**（荣行初字第1号：与法相悖，效力不予认可）——但条款无效**不等于**提前离岗必然认定工伤，仍须过"正当理由"这一关。
3. **未做责任认定不排除工伤**：公安机关出具事故证明但未划分责任的，社保部门不应径直作不利认定，应调查核实；无证据证明职工负主要及以上责任的，应认定工伤（用人单位负举证责任）。
4. **核心要件**："非本人主要责任"的交通事故/城市轨道交通/客运轮渡/火车事故 + 合理时间 + 合理路线。

### ⭐ 分水岭规则（由正反对照提炼）

**规则一：「合理时间」靠客观必要性证成，不靠"提前多久"计时**
- 川13行终33号（凌晨出发、无必要）❌ vs 晋0107行初42号（跨城、不提前则无法准时）✅、陕08行终39号（岗位要求提前休息）✅
- 法院在川13行终33号确立的判准：**"若要将离正常上下班较远的时间认定为合理时间，一般应遵循一致性、必要性原则。"**
- → 代理要点：固定"距离远 / 班次要求 / 交通方式受限"等**客观必要性证据**，而非单纯争论时间跨度。

**规则二：「合理路线」扩张至"日常生活所需活动"，但不扩张至"社交娱乐"**
- 黑06行终43号（护理病危岳母·突发事件）✅ vs 金行初43号（下班聚餐）❌
- 法释〔2014〕9号第6条第（三）项"从事属于日常工作生活所需要的活动"是唯一的扩张口，解释上**限于生活必需**，不含聚餐、购物、娱乐等纯社交/ discretionary 活动。
- → 代理要点：主张绕道时，把绕道原因锚定到"必需性 + 突发性"（就医、照护、接送等），并固定证据。

**规则三：三要素（时间·路线·目的）的举证分配**
- 陕08行终39号确立：**行政机关主张路线不合理的，须提供充分证据**；举证不足则不予采信。
- 三要素是"且"的关系，缺一即不认定（金行初43号即时间、路线双缺）。

### ⭐ 修正后的「提前离岗三阶检验」（可直接使用）

```
第一阶：是否办理请假 / 下班交接手续，或经单位领导同意？
   ├─ 是 → 仍属"上下班"（赣09行终85号明示包含）→ 进入第二阶
   └─ 否 → 进入第二阶，但承担不利推定

第二阶：提前离岗是否具有客观正当理由？
   可证成事由（参照荣行初字第1号）：已完成当日主要工作 / 天气恶劣 /
   身体不适 / 临近节假日等**符合常理**的客观事由
   ├─ 有 → 属合理时间 → ✅ 认定工伤
   └─ 无 → 进入第三阶

第三阶：提前时长是否超出合理限度？
   ├─ 未超（数十分钟内 + 有正当理由）→ ✅ 认定工伤
   └─ 明显超出（赣09行终85号：提前 1 小时以上，"明显超过合理限度"）→ ❌ 不予认定
   
⚠️ 加重情节：代打卡等规避考勤行为（宝行初67号）→ 直接推定"明知违规"，显著强化不予认定
```

### 攻防要点

- **红队（代理职工/认定申请人）**：
  1. 优先固定**「已完成当日主要工作」**的证据 —— 这是荣行初字第1号胜诉的**唯一实质支点**（证人王新岗证言"事故当日下午丛日福已完成主要工作"）。可采证据：交接班记录、工作系统日志、班组长证言、当日产量/工单记录。
  2. 叠加**环境性事由**（天气、交通、身体不适），把"提前"锚定到"符合常理"，而非"违反纪律"。
  3. **孤立援引"违反内部规定不影响工伤认定"的复函是无效动作** —— 宝行初67号已明确不予采信。必须配套正当理由证据。
  4. 正面主张单位"早退出事与本厂无关"条款**与法相悖、无效**（荣行初字第1号）。

- **蓝队（代理用人单位/社保部门）**：
  1. 主攻**「无正当理由」**，而非"违反规章"。宝行初67号、赣09行终85号均以此为判决核心。
  2. 固定**考勤异常证据**（监控、代打卡记录），证明职工"明知制度严格仍规避"。
  3. 量化**提前时长**，主张"明显超过合理限度"（赣09行终85号的 1 小时可作为参照基准）。
  4. 政策说理备用（赣09行终85号原文）："劳动者提前下班应具有合理事由。如果劳动者任意违反企业规章制度，无正当事由随意离岗提前下班，必将严重侵害企业的生产经营秩序，损害企业利益……有违公平性，且会造成不良的社会导向。"

> ⚠️ **样本提示**：本轮 3 例中 2 例不予认定，但检索式 `qw=提前离岗` 本身带有**负面偏向**（法院说理中"提前离岗"多出现在不予认定文书中），存在**样本偏在**。据此可稳妥主张"提前离岗并非一律认定"（否定性结论成立），但**不宜反向主张"提前离岗原则上不认定"**（肯定性结论证据不足）。样本量仅 3 例，对外表述应留有余地。

## ⭐ 举证责任与证据失权（2026-09-01 三轮补充检索取得 ·（2014）鞍行终字第30号）

**规范依据**：《工伤保险条例》**第19条** —— "职工或者其近亲属认为是工伤，用人单位不认为是工伤的，由用人单位承担举证责任。"（判决原文引述，条款号经（2014）鞍行终字第30号确认；款号未另行核验）

**该案确立了单位抗辩的三条失权路径**（用人单位举证不能 → 维持认定工伤）：

| 单位举证 | 失权原因 |
|---|---|
| 交通事故责任认定书 | **仅证明事故主次责任，无从证明是否处于"上下班途中"**；且未认定酒驾/醉驾 |
| 书面证言（未出庭） | 证人**既未到人社局接受询问，又未出庭作证** → 不具证明力 |
| 询问笔录 | **无其他有效证据印证** → 缺乏证明效力 |
| 二审新证人 | 依《行政诉讼证据规定》**第7条**，一审无正当事由未提供、二审提供的**不予接纳** |

**🔵 蓝队（职工方）**：举证责任在单位，职工无需自证"确系上下班途中"；单位拿不出有效证据即应维持认定。可逐条对照上表攻击单位举证的形式瑕疵（未出庭、无印证、逾期提出）。
**🔴 红队（单位方）**：须在**工伤认定程序阶段**即完成取证（通知证人到人社局接受询问、形成相互印证的证据链），**不得留到二审**；仅靠"事故责任认定书"证明不了"不在上下班途中"。
