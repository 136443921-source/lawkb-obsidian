# 背靠背条款、管理费扣减与未交付资料抗辩

> **卡型**：审判要件卡（正向裁判规则·法官心智）｜**编号**：`R-JG-022`｜**建卡日期**：2026-09-03

## 一、裁判规则（正向·该怎么判）

**一、「背靠背」条款抗辩**

**第一（无效情形）**——**大型企业**与**中小型企业**约定的「背靠背」条款**无效**。此为部分条款无效的四类情形之一（见 R-JG-014）。

**第二（其他主体的五因素综合考量）**——其他主体之间约定以第三方的履行为付款方履行付款义务的条件，应结合下列因素，综合考量该约定是否予以**限制或者排除适用**：
1. **债权人期待利益**
2. **第三方履行能力**
3. **债务人是否怠于向第三方主张权利**
4. **债务人对第三方是否存在违约行为**
5. **工程交付使用时长**

**实务推论**：背靠背条款不当然是「免死金牌」。若债务人怠于向第三方主张权利，或自己对第三方存在违约行为，或工程已交付使用很长时间，法院可**限制或排除**该条款的适用，判令债务人付款。

**二、扣减「管理费」抗辩**

**第一（未参与管理 → 不支持扣除）**——收取管理费的一方**未参与工程建设管理**的，其主张在应付的工程折价补偿款中**扣除管理费**的，**不予支持**。
**第二（参与管理 → 可酌情调减）**——收取管理费的一方**参与工程建设管理**的，实际施工人主张管理费收取比例**过高请求予以调减**的，人民法院可以根据**收取管理费一方参与管理程度、管理成本、管理费比例构成、是否包含其他费用**等因素，**酌情认定**管理费比例。
**第三（已支付 → 不支持返还）**——管理费**已经实际支付**的，支付管理费的一方主张**返还**的，**不予支持**。

**配套规则**：施工合同无效时，可参照合同约定折价补偿的范围包括价格调整约定，但**「管理费」约定除外**（见 R-JG-018）。

**三、未交付工程资料抗辩**

**规则**——因承包人**拒不提供工程竣工资料**导致工程**无法竣工验收**，**除发包人擅自使用工程的情形外**，发包人抗辩不支付工程价款的，**应予支持**。

**反诉要求**——发包人**反诉请求承包人提供工程竣工资料**的，应由发包人**具体列明**请求提供的资料清单。

## 二、审查要点（审理思路）

**第一步（背靠背）·查主体身份**：是否属**大型企业与中小型企业**之间？是 → 条款**无效**，直接排除适用。

**第二步（背靠背）·五因素衡量**（非大型／中小型企业组合时）：
- 债权人的期待利益是否落空？
- 第三方有无履行能力？
- **债务人是否怠于向第三方主张权利**？（关键：怠于主张 → 限制或排除适用）
- **债务人对第三方是否存在违约行为**？（关键：自己违约 → 限制或排除适用）
- **工程交付使用时长**？（关键：已交付使用很久 → 限制或排除适用）

**第三步（管理费）·查参与度**：收取管理费方是否**实际参与**工程建设管理？
- **未参与** → 不支持扣除管理费
- **参与** → 可酌情调减过高比例（衡量参与管理程度、管理成本、比例构成、是否含其他费用）

**第四步（管理费）·查是否已支付**：已实际支付的，**不支持返还**。

**第五步（未交资料）·查因果关系与擅自使用**：承包人拒不提供竣工资料 → 工程无法竣工验收 → 发包人可抗辩不付款。**但发包人擅自使用工程的除外**。

**⚠️ 对吊顶采购类案件的特别提示**：吊顶／装饰装修链条中，中间人常以「业主还没付我钱，所以我不能付你」抗辩。被告方应逐项拦截：
1. **主体拦截**——若己方或对方属中小企业与大型企业组合，背靠背条款**直接无效**；
2. **怠于主张拦截**——对方是否曾向业主催款、起诉？怠于主张的，限制或排除适用；
3. **时长拦截**——工程已交付使用多久？时间越长越难援引背靠背；
4. **擅自使用拦截**——若己方已实际使用工程，则对方不得以未交资料抗辩不付款（但己方亦不得以未交资料为由拒付）。
反向提示：己方作为被告主张「未交资料不付款」的，须证明**己方未擅自使用工程**且**因缺资料导致无法竣工验收**。

## 五、抗辩与但书

- **背靠背条款效力抗辩（中小企业方）**：己方为中小型企业、对方为大型企业的，背靠背条款无效，对方不得以「业主未付款」拒付。
- **怠于主张抗辩（高价值）**：对方（债务人）举证证明自己曾向第三方主张权利；举证不能或长期未主张的，主张限制或排除背靠背条款适用。
- **管理费抗辩（实际施工人方）**：收取管理费方**未参与管理**的，主张不得扣除管理费；**参与管理但比例过高**的，请求酌情调减。
- **管理费返还抗辩（收款方）**：管理费已实际支付的，支付方主张返还的不予支持。
- **未交资料抗辩（发包方）**：承包人拒不提供竣工资料致无法竣工验收、且己方未擅自使用的，抗辩不支付工程价款；反诉请求提供资料的，须**具体列明资料清单**。
- **承包人方反制**：发包人**擅自使用工程**的，不得以未交资料抗辩不付款；对方反诉请求提供资料的，要求其具体列明清单，避免概括性请求。

## 六、翻车标本（负向拦截·HIR）

> **翻车风险：对中小企业与大型企业之间的背靠背条款仍按有效处理；或对已实际支付的管理费支持返还；或忽略「发包人擅自使用」这一排除未交资料抗辩的关键事实。**

> 触发时机：本卡作为正向裁判规则引导推理时，若出现上述表述，LTI 应拦截并回退至本卡第一、二节重新涵摄。
