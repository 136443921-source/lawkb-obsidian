# 工程价款责任主体的审查

> **卡型**：审判要件卡（正向裁判规则·法官心智）｜**编号**：`R-JG-015`｜**建卡日期**：2026-09-03

## 一、裁判规则（正向·该怎么判）

**一、合同有效情形下的责任主体**

**第一，合同相对性原则（基石）**——建设工程施工合同有效，基于**合同相对性原则**，一般情况下**合同相对方**为支付工程价款的责任主体。《民法典》第 465 条第二款：「依法成立的合同，仅对当事人具有法律约束力，但是法律另有规定的除外。」

**第二，委托代建关系**——代建人**以自己的名义**在建设单位的**授权范围内**与承包人订立施工合同的：
- 承包人在**订立合同时知道**代建人与建设单位之间存在代建关系的，该施工合同**直接约束建设单位和承包人**（间接代理中的「第三人知道代理关系」规则）；**有确切证据证明该合同只约束代建人和承包人的除外**。
- 承包人**不知道**代建关系的，在代建人**披露**建设单位的情况下，承包人**可以选择**建设单位或者代建人承担责任（选择权在承包人）。

**第三，合作开发房地产关系**——
- 合作各方共同组建**具有独立法人资格的项目公司**，或者**投资收购**房地产项目公司的，作为发包人的**项目公司**承担工程款支付责任（不穿透至合作各方）。
- 合作各方签订合作协议符合《民法典》**第九百六十七条**（合伙合同）的规定，但**仅以一方名义作为发包人**对外签订施工合同的，承包人依据《民法典》**第九百七十三条**主张合作各方当事人对工程款承担**连带责任**的，**应予支持**。清偿债务超过自己应当承担份额的联建人，有权向其他联建人**追偿**。

**二、合同无效情形下的责任主体**

见 R-JG-016（实际施工人）、R-JG-013（借用资质）。核心规则：转包人、违法分包人应向实际施工人承担工程折价补偿款的支付责任；借用资质人能否向发包人主张，取决于发包人签约时是否知情。

## 二、审查要点（审理思路）

**第一步·先定合同效力**：有效走本卡（相对性 + 代建 + 合作开发），无效走 R-JG-016 / R-JG-013。

**第二步·有效情形先守相对性**：原则上由合同相对方付款。这是**默认规则**，突破须有明确法律依据。

**第三步·代建关系三问**：
1. 代建人是否以**自己名义**签约？
2. 是否在建设单位**授权范围**内？
3. 承包人**订约时是否知道**代建关系？
   - 知道 → 合同直接约束建设单位与承包人（除非有确切证据证明只约束代建人与承包人）
   - 不知道 → 代建人披露后，承包人**有选择权**

**第四步·合作开发两分**：
- 有独立法人项目公司 → 项目公司担责，**不穿透**
- 合伙型合作 + 仅以一方名义对外签约 → 合作各方**连带**

**⚠️ 对吊顶采购类案件的特别提示（高价值）**：**合同相对性是被告方最重要的实体防线之一**。吊顶采购／安装合同的签约主体与实际履行主体常常分离（如合同署名为甲，实际洽谈、收货、付款为乙）。被告方应主张：己方仅与合同载明的相对方成立合同关系，至于该相对方与第三人（如涉嫌的实际买受人）之间如何结算、由谁实际付款，**属于其内部关系，不能以此约束己方**；原告若非合同载明的权利主体，须先证明权利已合法移转（债权转让并通知债务人）或存在合法授权，否则不具备主张价款的主体资格。

## 三、构成要件与举证

| 要件编号 | 要件名称 | 要件内容 |
|---|---|---|
| E1 | 合同相对方 | 建设工程施工合同有效时，合同相对方原则上为支付工程价款的责任主体 |
| E2 | 代建关系披露 | 代建人是否以自己名义在建设单位授权范围内订立合同；承包人订立合同时是否知道代建关系 |
| E3 | 合作开发结构 | 合作各方是否共同组建独立法人项目公司；合作协议是否符合合伙合同规定 |
| E4 | 无效情形替代主体 | 合同无效时是否存在转包、违法分包、借用资质的实际施工人 |

**举证责任分配**：承包人主张建设单位直接担责的，就代建人以自己名义在授权范围内订约、自己订约时知道代建关系承担举证责任；代建人主张合同只约束自己与承包人的，就「有确切证据」承担举证责任；承包人主张合作各方连带的，就合作协议符合《民法典》第 967 条、仅以一方名义对外签约承担举证责任。

## 五、抗辩与但书

- **相对性抗辩（被告方第一防线）**：主张己方仅与合同载明相对方成立合同关系，原告非合同当事人，不具备主张价款的主体资格。
- **原告主体资格抗辩**：主张原告未证明权利合法移转（债权转让未通知债务人）或未获合法授权，其意思表示自始未作出，不具备主体资格。**表述用「存疑」，不作刑事定性**。
- **代建方抗辩**：有确切证据证明合同只约束代建人与承包人的，主张建设单位不担责。
- **项目公司抗辩**：合作开发已组建独立法人项目公司的，主张由项目公司担责，不穿透至合作各方。
- **承包人方主张**：合作协议符合《民法典》第 967 条且仅以一方名义对外签约的，主张合作各方连带；代建关系中承包人不知情的，行使选择权。
- **但书**：合同相对性是原则，**法律另有规定**（如《建工解释（一）》第 43 条实际施工人制度、《民法典》第 973 条合伙连带）时方可突破。

## 六、翻车标本（负向拦截·HIR）

> **翻车风险：以「工程实际受益」为由突破合同相对性，径行判令非合同方（建设单位、合作方）支付工程款；或忽略代建关系中「承包人有选择权」的规则。**

> 触发时机：本卡作为正向裁判规则引导推理时，若出现上述表述，LTI 应拦截并回退至本卡第一、二节重新涵摄。
