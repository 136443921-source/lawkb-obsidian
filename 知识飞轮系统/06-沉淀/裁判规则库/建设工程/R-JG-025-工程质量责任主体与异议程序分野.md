# 工程质量责任主体与异议程序分野

> **卡型**：审判要件卡（正向裁判规则·法官心智）｜**编号**：`R-JG-025`｜**建卡日期**：2026-09-03

## 一、裁判规则（正向·该怎么判）

**一、承担工程质量问题的责任主体**

**（一）有效合同**
- 工程实行**总承包**的，**总承包人应当对全部工程质量负责**。工程勘察、设计、施工、设备采购的一项或者多项实行总承包的，总承包人应当对其承包的工程或者采购的设备质量负责。
- 总承包人将工程**分包**给其他单位的，应当对**分包工程的质量与接受分包的单位承担连带责任**。

**（二）无效合同**
- **转包人、违法分包人**对因转包、违法分包的工程不符合规定的质量标准造成的损失，与**转承包人、违法分承包人承担连带责任**。
- 发包人请求**借用资质人与出借资质人**对工程质量不合格等因出借资质造成的损失承担**连带赔偿责任**的，应予支持（《建工解释（一）》第 7 条）。

**二、承担质量责任的方式**

**第一**——发包人要求施工方承担质量责任的方式主要包括：**无偿修理修复、返工、改建、减少工程价款、支付修复费用**等。
**第二**——施工合同**有效**的，发包人请求承包人承担质量责任的，按照合同中关于**质量标准和责任条款**的约定处理。施工合同**无效**的，一方当事人请求对方赔偿因质量问题造成的损失，**损失大小无法确定**的，可参照合同中关于**质量标准和计价标准**的约定确定。**但合同约定不能违反有关质量强制性标准**。

**规范衔接**：《民法典》第 801 条——因施工人的原因致使建设工程质量不符合约定的，发包人有权请求施工人在合理期限内**无偿修理或者返工、改建**。经过修理或者返工、改建后，造成逾期交付的，施工人应当承担违约责任。

**三、提出工程质量异议的程序（抗辩 vs 反诉的分野）**

**（一）可以抗辩方式提出（不予支付工程价款）**
1. 工程**未经竣工验收或者经验收不合格且发包人未使用**，发包人提出质量异议，**抗辩不予支付工程价款**的；或者发包人提出质量异议，**承包人拒绝修复**，发包人提出**减少给付工程价款或者抵减自行修复费用**的。
2. 工程**未经竣工验收但发包人擅自使用**，**合理使用寿命内存在地基基础工程和主体结构质量问题**，发包人**抗辩不予支付工程价款**的。

**（二）应当反诉或者另诉**
1. 工程**竣工验收且发包人已接收使用**，发包人提出工程质量问题，**请求承包人承担质量责任**的。
2. 工程**未经竣工验收但发包人擅自使用**的，发包人提出**除地基基础工程和主体结构外**工程质量问题，**请求承包人承担质量责任**的。
3. 工程**未经竣工验收或者经验收不合格且发包人未使用**，发包人**请求承包人履行质量问题修复义务**，或者**请求承包人支付违约金和其他人身、财产损失**的。

**规范衔接**：《建工解释（一）》第 14 条——建设工程未经竣工验收，发包人**擅自使用**后，又以使用部分质量不符合约定为由主张权利的，**人民法院不予支持**；但是承包人应当在建设工程的**合理使用寿命内对地基基础工程和主体结构质量**承担民事责任。

**（三）承包人对发包人过错的抗辩**

发包人请求承包人承担工程质量责任，承包人提出抗辩，因发包人的下列原因造成工程质量缺陷的，**发包人应承担过错责任**（《建工解释（一）》第 13 条对应三项 + 指南增列三项）：
1. 发包人提供的**设计存在缺陷**；
2. 提供或者指定购买的**建筑材料、建筑构配件、设备不符合强制性标准**；
3. **直接指定分包人分包专业工程**；
4. 发包人**迫使承包人以低于成本的价格竞标**；
5. **违规任意压缩建设工程的合理工期**；
6. **指示施工人违反工程建设强制性标准降低建设工程质量**。

**附：住宅装修的严重质量缺陷**

住宅装修工程设计、施工中的**严重质量缺陷**，是指影响人身安全和健康、存在重大安全隐患、不能达到装饰装修合同目的的质量缺陷。**无论是否在保修期内**，承包人均应承担修复责任、消除安全隐患、恢复使用功能等违约责任。质量问题无法修复或者经修复仍不合格，发包人向承包人主张**解除合同、返还已支付的工程款、赔偿损失**等违约责任的，**应予支持**。

**附：农村建房质量标准**

农村建房施工合同对房屋结构、装修标准、材料选用等质量要求**有约定的，按照约定**履行。当事人就有关质量要求**约定不明确**的，按照**国家标准、行业标准**履行；没有国家标准、行业标准的，按照**通常标准或者符合合同目的的特定标准**履行。

## 二、审查要点（审理思路）

**第一步·定责任主体**：总承包？分包（连带）？转包／违法分包（连带）？借用资质（出借方与借用方连带）？

**第二步·定责任方式**：无偿修理修复、返工、改建、减少工程价款、支付修复费用。合同有约定从约定，但**不得违反质量强制性标准**。损失大小无法确定的，可参照合同质量标准与计价标准确定。

**第三步·定程序路径（本环节核心，最易翻车）**：

| 情形 | 发包人的正确路径 |
|---|---|
| 未验收或验收不合格 + **未使用** | 可**抗辩**不付款；承包人拒修的可主张减价或抵减修复费 |
| 未验收 + **擅自使用** + 地基基础／主体结构问题 | 可**抗辩**不付款 |
| **已验收且已接收使用** + 质量问题 | **反诉或另诉** |
| 未验收 + **擅自使用** + 非地基基础／主体结构问题 | **反诉或另诉** |
| 未验收或验收不合格 + 未使用 + 请求**修复义务／违约金／其他损失** | **反诉或另诉** |

**第四步·查发包人过错（承包人的减责路径）**：是否存在六类过错情形，造成质量缺陷的发包人应承担过错责任。

**第五步·住宅装修的特别规则**：是否存在「严重质量缺陷」（影响人身安全健康、重大安全隐患、不能达合同目的）？**无论是否在保修期内**均可主张。

**⚠️ 对吊顶采购类案件的特别提示（高价值）**：吊顶工程属装饰装修，**不涉及地基基础工程和主体结构**，因此：
1. **只要发包人已擅自使用（如房屋已投入使用），发包人就一般质量问题只能反诉或另诉，不能仅以抗辩拒付价款**——这是被告方主张「以质量抗辩拒付」的重大程序障碍；
2. 若工程**尚未验收且未使用**，被告方可直接以质量异议**抗辩不予支付工程价款**，或主张**减少价款、抵减自行修复费用**；
3. 若属**住宅**吊顶且存在「严重质量缺陷」（影响人身安全健康、重大安全隐患），**无论是否在保修期内**，被告方均可主张修复、解除、返还已付工程款、赔偿损失——**这是吊顶案中被告方最有力的实体抗辩之一**；
4. 质量责任方式上，被告方优先选择「**减少工程价款**」（直接抵扣原告诉请金额），而非另行主张修复费用（后者须反诉）。

## 三、构成要件与举证

| 要件编号 | 要件名称 | 要件内容 |
|---|---|---|
| E1 | 责任主体 | 工程是否实行总承包；是否分包；是否存在转包、违法分包、借用资质等无效情形 |
| E2 | 质量责任方式 | 发包人要求承担质量责任的方式：无偿修理修复、返工、改建、减少工程价款、支付修复费用 |
| E3 | 程序分野 | 发包人的质量主张属于「抗辩」还是应当「反诉或者另诉」——取决于工程是否已竣工验收、是否已接收使用、是否属地基基础与主体结构 |
| E4 | 发包人过错 | 是否存在提供设计缺陷、提供或指定购买材料不合强制标准、直接指定分包人、迫使低于成本竞标、违规压缩合理工期、指示违反强制性标准降低质量 |

**举证责任分配**：主张质量责任的发包人，就质量不合格的事实、损失大小、因果关系承担举证责任；发包人主张承包人承担质量责任时，承包人主张发包人有过错的，就发包人存在六类过错情形承担举证责任。损失大小无法确定的，可参照合同中关于质量标准和计价标准的约定确定。

## 四、法条依据

> 以下条文均经**北大法宝**核填并确认为「现行有效」，非凭记忆撰写。

**《中华人民共和国民法典》第八百零一条**

> 因施工人的原因致使建设工程质量不符合约定的，发包人有权请求施工人在合理期限内无偿修理或者返工、改建。经过修理或者返工、改建后，造成逾期交付的，施工人应当承担违约责任。

> —— 来源：北大法宝核填·现行有效

**《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第十三条**

> 发包人具有下列情形之一，造成建设工程质量缺陷，应当承担过错责任：（一）提供的设计有缺陷；（二）提供或者指定购买的建筑材料、建筑构配件、设备不符合强制性标准；（三）直接指定分包人分包专业工程。
> 承包人有过错的，也应当承担相应的过错责任。

> —— 来源：北大法宝核填·现行有效

**《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》第十四条**

> 建设工程未经竣工验收，发包人擅自使用后，又以使用部分质量不符合约定为由主张权利的，人民法院不予支持；但是承包人应当在建设工程的合理使用寿命内对地基基础工程和主体结构质量承担民事责任。

> —— 来源：北大法宝核填·现行有效

## 五、抗辩与但书

- **程序抗辩（被告方首要）**：工程已竣工验收且发包人已接收使用的，发包人提出质量问题应**反诉或另诉**，不得仅以抗辩拒付；未验收但发包人擅自使用的，除地基基础与主体结构外，亦应反诉或另诉。
- **质量抗辩不付款（未验收且未使用时）**：工程未验收或验收不合格且己方未使用的，直接抗辩不予支付工程价款。
- **减价抗辩（优先选择）**：承包人拒绝修复的，主张减少给付工程价款或抵减自行修复费用——**直接抵扣原告诉请金额，无需反诉**。
- **发包人过错抗辩（承包方减责）**：举证证明发包人存在设计缺陷、提供或指定购买材料不合强制标准、直接指定分包人、迫使低于成本竞标、违规压缩工期、指示违反强制性标准降低质量六类情形，主张发包人承担过错责任。
- **严重质量缺陷抗辩（住宅装修·强力）**：住宅装修存在严重质量缺陷（影响人身安全健康、重大安全隐患、不能达合同目的）的，无论是否在保修期内，均可主张修复、解除、返还已付工程款、赔偿损失。
- **质量标准抗辩**：合同约定的质量标准低于国家强制性安全标准的，该条款无效，按国家标准执行。
- **连带责任主张（发包方）**：转包人、违法分包人与转承包人连带；借用资质人与出借资质人对因出借资质造成的损失连带赔偿。
- **但书**：质量责任的承担方式须与工程质量状态、是否已使用、是否属地基基础与主体结构相匹配，不得错位。

## 六、翻车标本（负向拦截·HIR）

> **翻车风险：发包人在竣工验收并接收使用后就一般质量问题仅以抗辩方式提出（应反诉或另诉）；或忽略发包人六类过错可减轻承包人责任；或合同约定违反质量强制性标准仍按约定处理。**
