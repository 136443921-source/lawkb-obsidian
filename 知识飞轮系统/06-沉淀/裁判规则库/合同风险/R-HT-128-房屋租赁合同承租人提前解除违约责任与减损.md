# R-HT-128 房屋租赁合同承租人提前解除的违约责任与减损规则

> 一句话：承租人无解除权而提前退租，**不发生解除效力**，但租赁陷入履行僵局时法院可判解除并由承租人承担违约责任；约定违约金明显过高的，应综合剩余租期、再出租难度、过错程度酌减；出租人负有及时收房减损义务。

## 一、法条基底（元典核填·现行有效，含官方核验指引）

- 《民法典》第577条：违约责任一般条款（继续履行/补救/赔偿）。
- 第580条第1款：非金钱债务（如交还房屋之继续性给付）不适于强制履行或履行费用过高的，对方不得请求继续履行。
- 第591条：一方违约后，对方应采取适当措施防止损失扩大；未采取致损失扩大的，不得就扩大部分请求赔偿。
- 第585条：约定违约金低于/过分高于损失的，法院或仲裁机构可予以增加/适当减少。

> ✅ 元典 sxx 核验（2026-09-02）：民法典第577/580/591/585条均现行有效，内容与卡一致。

## 二、裁判要旨（WebSearch 降级，待回源）

1. **解除通知不当然发生解除效力**：承租人单方退租、搬离，出租人明确不同意的，不产生合同解除效果；但租期较长、继续履行显属僵局时，法院可基于第580条判令解除（婺源县人民法院 2026-07 案例：租户违约提前退租，出租人能否"强留"）。
2. **违约金过高酌减**：约定惩罚性违约金（如6万元）明显畸高的，法院结合剩余租期、房屋再出租难易、承租人过错，酌定以"数月租金"作为违约赔偿（同前案酌定7个月租金；绵阳经开区法院疫情商铺案酌定6个月租金损失）。
3. **合同终止后的交接与占有使用费**：承租方退租后未腾空交接、遗留物品致房屋无法使用的，应支付合同终止后的房屋占有使用费；但出租人不得藉屋内有物品无限期主张占有费，应及时收房减损（鲁法案例〔2025〕595 济南槐荫法院）。
4. **减损是双向的**：出租人明知承租人退出仍不收房、不挂牌再出租，扩大的空置损失不得向承租人主张。
5. **【元典回源·权威案号】上海喆米商业管理有限公司与陈伟红等房屋租赁合同纠纷（（2021）沪0115民初75160号，上海市浦东新区人民法院，元典入库编号 a84d5df5ac927c70b9628f193231934f）**：承租人欠租致合同解除，法院支持没收相当于3个月租金的租赁押金；约定解约违约金（月租金3倍）被酌减为1个月租金；疫情按公平原则酌减2个月租金；出租人未及时收房减损的扩大空置不赔。完整覆盖本卡 E1–E4 要素，可作权威锚点。

## 三、涵摄断裂标本（高频翻车）

- 误认"我发了退租通知=合同解除了" → 解除须合意或法定/约定事由，单方通知不创设解除权。
- 主张"按合同全额违约金"不作审查 → 第585条授权酌减，畸高部分不支持。
- 出租人"晾着房屋"等承租人赔满租期 → 违反第591条减损义务，扩大部分不赔。
