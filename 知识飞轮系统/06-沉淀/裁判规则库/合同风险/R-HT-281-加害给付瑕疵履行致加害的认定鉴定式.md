# 一、争点定位与请求权基础

加害给付（positive Forderungsverletzung，积极侵害债权）指债务人未依债之本旨提出给付（瑕疵履行／不完全履行），除致债权人**履行利益**减损外，还损害其**固有利益**（人身或其他财产）。本卡是 R-HT-236 卡族的"履行阶段竞合"专题，解决"瑕疵致他种损害"时，违约与侵权如何定性、是否落入第186条择一。

# 二、鉴定式审查框架

1. **是否存在有效合同＋债务人负给付义务**（前提）。
2. **债务人是否提出有瑕疵的给付**（品质/数量/方法不符，或违反附随义务）？
   - 否 → 未构成加害给付，按一般违约或缔约过失处理。
3. **该瑕疵给付是否致债权人固有利益损害**（履行利益外的人身/财产损害）？
   - 否（仅履行利益减损）→ 纯违约路径：第577条＋第584条（履行利益赔偿，可预见规则）。
   - 是（固有利益受损）→ 同时该当第1165条侵权 → 进入竞合识别（见 R-HT-279 步骤B 目的同一性测试）：
     - 给付目的同一（填补同一损害）→ **请求权竞合（第186条）→ 择一**（对齐 R-HT-237）。
     - 但：缺陷产品（第1203条）→ **不真正连带隔离**，非竞合非聚合（对齐 R-PI-140）；人格权严重精神损害 → 第996条**聚合例外**（违约＋精神损害并用，对齐 R-HT-238）。

# 三、构成要件与举证

- **加害给付四要件**：①有效合同＋给付义务；②债务人提出瑕疵给付；③该瑕疵致债权人固有利益（人身/其他财产）损害；④可归责于债务人。
- **目的同一性判定（双轴）**：损害同一性（同一人身/财产减损）＋给付等价性（违约赔偿与侵权赔偿可相互替代）→ 同一→186竞合；若固有利益损害超出合同履行利益范围且规范意旨各异→可能聚合。
- **举证**：违约部分由原告证瑕疵＋因果；侵权部分另证过错（第1165条，一般过错责任）；产品缺陷转第1203条无过错＋不真正连带。

# 四、法条依据（权威源回填，非凭记忆）

- **民法典第577条**（违约请求权基础）：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。
- **民法典第584条**（履行利益赔偿·可预见规则）：……损失赔偿额应当相当于因违约所造成的损失，包括合同履行后可以获得的利益；但是，不得超过违约一方订立合同时预见到或者应当预见到的因违约可能造成的损失。
- **民法典第1165条**（侵权请求权基础）：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
- **民法典第186条**（违约/侵权竞合授权·加害给付落点）：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。
- **民法典第996条**（聚合例外·违约+精神损害）：因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。
- **民法典第1203条**（产品责任·不真正连带，概念隔离用）：因产品存在缺陷造成他人损害的，被侵权人可以向产品的生产者请求赔偿，也可以向产品的销售者请求赔偿。
- **民法典第157条**（法律行为被撤销后果，区分合同欺诈用）：……行为人因该行为取得的财产，应当予以返还……有过错的一方应当赔偿对方由此所受到的损失。
- ⚠️ **statute_text_pending**：消费领域惩罚性赔偿（消法第55条）本地库未收录，本案型仅定性，不硬引外部条号。

# 五、抗辩与但书

- **加害给付 ≠ 合同欺诈**：加害给付是**履行阶段**瑕疵致损；合同欺诈是**缔约阶段**意思表示瑕疵（第148条，见 R-HT-282）。二者时点不同，但都可能与侵权交叉——鉴别见 R-HT-278/282（欺诈的侵权交叉属排斥型，加害给付的侵权交叉属186竞合）。
- **186竞合仅在"目的同一"时**：瑕疵致固有利益损害，若违约赔偿与侵权赔偿指向同一损害且可替代→择一；若固有利益损害独立于合同给付目的（如纯侵权后果）→不必然择一。
- **996是例外开口**：人格权严重精神损害时打破择一转聚合。
- **1203须隔离**：产品缺陷的生产者/销售者选择属不真正连带，非186竞合。

# 六、翻车标本（负向拦截·HIR）

1. **把加害给付当纯违约漏列侵权**：瑕疵致牲畜死亡仅按违约诉履行利益（饲料款），漏列固有利益（牲畜）侵权赔偿 → 漏诉请。
2. **混淆加害给付与欺诈**：以次充好既诉欺诈撤销又诉违约赔偿，未区分"虚假陈述（欺诈·R-HT-282）"与"交付物瑕疵致损（加害给付）" → 请求权基础错乱。
3. **产品缺陷误用186竞合**：缺陷产品致害按186择一并主张生产者+销售者 → 错，应走第1203条不真正连带（对齐 R-PI-140）。
4. **忽略996例外**：人格权严重受损仅按违约起诉漏列精神损害 → 违约路径下精神损害一般不被支持（除非第996条）。
