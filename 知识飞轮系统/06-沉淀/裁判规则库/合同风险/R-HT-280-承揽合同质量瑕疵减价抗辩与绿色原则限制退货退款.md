# R-HT-280 承揽合同质量瑕疵的减价抗辩与绿色原则对退货退款的限制

## 裁判规则

承揽人交付的工作成果不符合质量要求的，定作人可合理选择请求修理、重作、减少报酬、赔偿损失等违约责任（《民法典》第781条）；但瑕疵救济方式应与瑕疵程度相适应。对于专属定制、无法二次销售的定作物（定制窗帘、全屋家具等），法院不宜动辄支持退货退款，而可采"减少报酬＋定作人自行委托第三方整改"的模式，并将绿色原则（《民法典》第9条）融入裁判说理，兼顾物尽其用与社会资源保护。质量争议期间，定作人基于真实瑕疵拒付尾款具有合理抗辩事由，不构成恶意拖欠，对应逾期付款利息请求不予支持。

## 法条依据（本地缓存回填，非凭记忆）

- 《民法典》第9条：民事主体从事民事活动，应当有利于节约资源、保护生态环境（绿色原则）。
- 《民法典》第770条：承揽合同定义（加工、定作、修理、复制、测试、检验等）。
- 《民法典》第781条：承揽人交付的工作成果不符合质量要求的，定作人可以合理选择请求承揽人承担修理、重作、减少报酬、赔偿损失等违约责任。
- 《民法典》第782条：定作人应当按照约定的期限支付报酬；对支付报酬期限没有约定或约定不明确的，应当在承揽人交付工作成果时支付。
- 参照法理：承揽合同无专门"2年最长期限"规定，隐蔽瑕疵异议可参照《民法典》第621条买卖合同质量异议的"合理期限/二年不变期间"精神处理，但出卖人明知瑕疵的除外。

## 实务要点

1. **减价 vs 退货的边界**：定作物按房屋尺寸裁切、按款式定制，退货即报废、无法二次销售。绿色原则下，支持退货将造成资源无端损耗，故法院倾向"减少报酬＋自行整改"而非全额退款。
2. **减价数额酌定**：综合瑕疵轻重、整改成本、定制产品特性确定。横州案中总价6250元、尾款3750元，法院扣减1000元用于乐某另行整改，最终判付尾款2750元。
3. **拒付尾款的抗辩正当性**：承揽成果确有瑕疵时，定作人拒付尾款具合理抗辩，不属于恶意拖欠，逾期利息不予支持——但定作人应积极配合验收整改，不得无限期拖延。
4. **本所合同护权条款（6658/6660 参照）**：建材、定制类交易隐蔽缺陷多，建议在合同中将"检验期限"与"质量异议期/质保期"分项约定，明确"验收合格不视为免除隐蔽瑕疵担保责任"，避免被认定为"过短"而仅剩外观异议期。

## 关联本案（老强·吊顶采购案6658号 / 雅菲软装窗帘案6660号）

- **6660 雅菲窗帘案**：本案型直接对应——窗帘定制瑕疵，可援引第781条减价＋自行整改抗辩，绿色原则限制"拆除退货、返还定金"式主张；原告已申请撤诉，本卡可作被告方（刘九零、刘维）防御储备。
- **6658 吊顶采购案**：若原告以"已签收/已付款"主张视为合格，被告可反向援引第781条，主张材料等级等隐蔽瑕疵仍可减价，且出卖人（原告）对材料真实等级属"明知或应知"，异议权不受期限限制。
