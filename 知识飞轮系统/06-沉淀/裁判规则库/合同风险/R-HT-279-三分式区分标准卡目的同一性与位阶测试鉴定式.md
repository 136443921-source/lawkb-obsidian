# 一、争点定位与请求权基础

R-HT-236 总览给出三分式决策树后，实践真正卡壳处在于：**如何判定事实落入哪一枝**。本卡是总览的"鉴别器"，给出两项可操作测试——

- **位阶/补充关系测试（先判排斥）**：数法条间是否存在特别—一般／吸收／补充结构；
- **目的同一性测试（再判竞合或聚合）**：数请求权给付目的是否同一。

顺序不可颠倒：先排除"法条竞合（排斥型）"，再在剩余情形中区分"请求权竞合（186择一）"与"请求权聚合（179并用）"。

# 二、鉴定式审查框架（两步鉴别）

嵌入 R-HT-236 四阶的"竞合识别节点"，执行：

**步骤 A · 位阶/补充关系测试（Spezialität / Subsidiarität / Konsumtion）**
- A1 特别关系：甲基础为乙基础之特别规定 → 特别法优位（民法典第11条），仅适用特别 → **法条竞合（排斥型，不进第186条）** → 对齐 R-HT-278。
- A2 补充关系：甲基础为乙基础之补充（乙优先、甲仅于乙不足时补充适用） → **法条竞合（排斥型）**。
- A3 吸收关系：甲基础之不法内涵已为乙基础完全评价吸收 → **法条竞合（排斥型）**。
- 若 A1–A3 均否 → 进入步骤 B。

**步骤 B · 目的同一性测试（Zweckidentität）**
- B1 数请求权**给付目的同一**（填补同一损害、经济功能等价、可相互替代） → **请求权竞合（第186条）** → 择一行使 → 对齐 R-HT-237。
- B2 数请求权**给付目的各异**（规范意旨不同、功能互补） → **请求权聚合（第179条并用）** → 对齐 R-HT-238。

> **鉴别口诀**：先问"法条是否排斥"（位阶测试）→ 否，再问"目的是否同一"（目的测试）→ 同则竞合、异则聚合。

# 三、构成要件与举证

- **位阶测试判断基准**：立法意旨上是否存在"特别—一般""主—从补充""全部—部分吸收"结构。具其一即排斥。
- **目的同一性判断基准（双轴）**：
  1. *损害同一性*：是否指向同一人身/财产减损；
  2. *给付等价性*：给付能否相互替代（赔了甲不必再赔乙）。
  两轴皆满足 → 目的同一 → 竞合；任一不满足 → 目的各异 → 聚合。
- **举证**：竞合/聚合本身不增设举证负担，但**择定路径重构举证责任分配**（见 R-HT-239 六变量矩阵）。

# 四、法条依据（权威源回填，非凭记忆）

> 下列条文自本地《中华人民共和国民法典（全文）》回填，现行有效。

- **民法典第11条**（特别法优位·位阶测试支点）：其他法律对民事关系有特别规定的，依照其规定。
- **民法典第186条**（请求权竞合授权·目的同一性测试结论）：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。
- **民法典第179条**（责任方式可合并适用·聚合总规范）：……本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。
- **民法典第577条**（违约请求权基础）／**第1165条**（侵权请求权基础）：目的同一性测试之"数基础"前提。
- **民法典第187条**（跨法域聚合边界）：……不影响承担民事责任；民事主体的财产不足以支付的，优先用于承担民事责任。
- **民法典第148条**（欺诈可撤销·合同欺诈特别法优位案型锚点）：一方以欺诈手段，使对方在违背真实意思的情况下实施的民事法律行为，受欺诈方有权请求人民法院或者仲裁机构予以撤销。
- **民法典第995条**（人格权请求权不受时效）／**第996条**（聚合例外，与目的测试衔接）：人格权严重受损时即便违约与侵权目的趋同，仍许精神损害并用。
- ⚠️ **statute_text_pending**：外部特别法（消费者权益保护法、票据法、海商法、铁路法）本地库未收录，本案型仅作定性描述，不硬引外部条号，守本地源铁律。

# 五、抗辩与但书

- **位阶测试优先于目的测试**：顺序颠倒会把"法条竞合"误判为"第186条竞合"（HIR 典型翻车）。
- **目的同一性 ≠ 法条文字同一**：同一条文可因择定路径不同而生不同举证，关键在"给付目的"而非"法条表述"。
- **第996条是目的测试的例外开口**：人格权严重精神损害时，即便违约与侵权目的趋同，仍许精神损害并用（聚合例外，不落入186择一）。
- **聚合须目的各异，但目的部分重叠时**：重叠部分不得双重受偿（损益相抵／禁止得利原则）。

# 六、翻车标本（负向拦截·HIR）

1. **跳过位阶测试**：合同欺诈直接按第186条择一 → 错，应属法条竞合（特别法优位），合同法优先（对齐 R-HT-278）。
2. **目的同一性误判**：工伤待遇＋第三人侵权按第186条择一、漏列工伤待遇 → 错，二者目的各异（社保给付 vs 侵权赔偿）为聚合双赔（对齐 R-GZ-021／R-HT-238）。
3. **补充关系当并用**：雇用人责任与法人侵权责任误按聚合主张双重 → 错，属补充／特别关系，排斥或补充适用。
4. **同一条文内部双层混读**：第588条"定金/违约金择一 ＋ 超额损失聚合补足"，误把"择一"扩张到超额部分而漏列（对齐 R-HT-236 §六3／R-JG-020）。
