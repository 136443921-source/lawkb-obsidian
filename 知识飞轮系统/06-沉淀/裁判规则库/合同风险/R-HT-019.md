# R-HT-019 保密协议保密义务边界与违约金调减

## 触发场景（trigger）
- 商业合作中签署保密协议，或一方主张对方违反保密义务要求赔偿/违约金。
- 对方起草的保密协议定义过宽、期限无限、违约金畸高。

## 规则（rule）
1. **保密信息须"概括+列举+除外"明确界定**：除外条款应排除接收方在披露前已合法持有、公开渠道获得、独立开发之信息；定义过宽易被认定限制经营自由或格式条款无效。
2. **保密期限分层**：商业秘密可约定保密至公开止；普通商业信息宜设合理期限。范本实测：合作结束后1年终止 + 协议终止后满10年解除（偏长，可视交易性质压缩至2-5年）；不得单方设无限期义务（显失公平/格式条款风险，《民法典》第496、497条）。
3. **违约金应与实际损失相当**：约定违约金过高的，当事人可请求法院或仲裁机构予以调减（《民法典》第585条第2款）；建议预设损失计算口径（含调查费、律师费、商誉损失）以固定举证。
4. **强制披露安全阀**：监管/司法强制披露应设"事先书面通知+协助保护"义务，避免被动泄密即违约。

## 适用要点（do / dont）
- **do**：起草时采用三分法定义；约定损失范围与合理违约金上限；争议解决争取中立地。
- **dont**：勿接受"已公开信息也保密""无限期保密""畸高且无挂钩违约金"等对方条款而不修改。
