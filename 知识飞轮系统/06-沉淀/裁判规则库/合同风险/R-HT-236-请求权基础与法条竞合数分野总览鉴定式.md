# 一、争点定位与请求权基础

同一生活事实同时该当数个请求权基础（Anspruchsgrundlage）时，原告究竟能「同时主张」还是「只能选一个」，直接决定诉讼策略、管辖、举证与赔偿范围。本卡族（鉴定式）依王泽鉴《民法思维》通说，将「法条之间的关系」作三分式处理，并在鉴定式（Gutachtenstil）分析流程中嵌入「竞合审查节点」。

# 二、鉴定式审查框架（审查要点）

鉴定式四阶（产生→消灭→可行使），竞合审查置于「产生确认后、行使前」：

1. **请求权是否产生**：逐一检视各候选请求权基础的全部成立要件（如第577条违约、第1165条侵权）。
2. **竞合识别（本卡族核心节点）**：若同一事实该当数基础，进入三分式判断——
   - 法条间是否排斥（特别—一般／吸收／位阶）→ **法条竞合**，仅适用其一；
   - 数请求权给付目的是否**同一**（填补同一损害）→ **请求权竞合**（第186条）→ **择一行使**；
   - 数请求权给付目的是否**各异**（规范目的不同）→ **请求权聚合／责任聚合** → **可并用**。
3. **请求权是否消灭**：选定并获完全满足后，另一竞合请求权消灭。
4. **请求权是否可行使**：抗辩权（同时履行、时效、解除）及选定拘束力。

# 三、构成要件与举证

**三分式识别要件（决策树）**

- 前置：数请求权基础是否源于同一生活事实？否→各自独立分析，非竞合。
- 分支一（法条排斥）：一行为该当数法条，但法条间有特别—一般／吸收／位阶关系 → 法条竞合，**不适用第186条**，无择一问题。
- 分支二（目的同一）：数请求权给付内容相同 → 请求权竞合 → 第186条授权**择一**。
- 分支三（目的各异）：数请求权给付内容不同 → 请求权聚合 → 第179条等授权**并用**。

举证层面：竞合／聚合本身不额外增设举证负担，但**择一路径选择会重构举证责任分配**（见 R-HT-239 六变量矩阵）。

# 四、法条依据（权威源回填，非凭记忆）

> 下列条文均自本地《中华人民共和国民法典（全文）》《民事诉讼法（2023）》回填，现行有效。

- **民法典第186条**（违约/侵权竞合授权）：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。
- **民法典第179条**（责任方式可合并适用·聚合总规范）：……本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。
- **民法典第577条**（违约请求权基础）：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。
- **民法典第1165条**（侵权请求权基础）：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
- **民法典第996条**（聚合例外·违约+精神损害）：因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。
- **民法典第588条**（定金/违约金择一+超额补足）：当事人既约定违约金，又约定定金的，一方违约时，对方可以选择适用违约金或者定金条款。定金不足以弥补一方违约造成的损失的，对方可以请求赔偿超过定金数额的损失。
- **民法典第585条**（违约金可调整+补足损失）：……约定的违约金低于造成的损失的……予以增加；约定的违约金过分高于造成的损失的……予以适当减少。当事人就迟延履行约定违约金的，违约方支付违约金后，还应当履行债务。
- **民法典第1167条**（绝对权请求权·不适用时效）：侵权行为危及他人人身、财产安全的，被侵权人有权请求侵权人承担停止侵害、排除妨碍、消除危险等侵权责任。
- **民法典第187条**（民刑责任聚合·民事优先）：民事主体因同一行为应当承担民事责任、行政责任和刑事责任的，承担行政责任或者刑事责任不影响承担民事责任；民事主体的财产不足以支付的，优先用于承担民事责任。
- **民法典第1203条**（产品责任·不真正连带，概念隔离用）：因产品存在缺陷造成他人损害的，被侵权人可以向产品的生产者请求赔偿，也可以向产品的销售者请求赔偿。
- **民事诉讼法第24条**（合同管辖）：因合同纠纷提起的诉讼，由被告住所地或者合同履行地人民法院管辖。
- **民事诉讼法第29条**（侵权管辖）：因侵权行为提起的诉讼，由侵权行为地或者被告住所地人民法院管辖。
- **民法典第188条**（诉讼时效3年）：向人民法院请求保护民事权利的诉讼时效期间为三年。……自权利人知道或者应当知道权利受到损害以及义务人之日起计算。

# 五、抗辩与但书

- **法条竞合排斥第186条**：如同一欺诈同时该当合同欺诈（可撤销）与侵权欺诈（第1165条），通说认为属法条竞合，优先适用合同法，不进入第186条择一。
- **第186条是选择性竞合**：选定后原则上不得再主张另一；学说与实务多认「一审法庭辩论终结前可变更，选定获满足后消灭」。
- **第996条是例外聚合**：仅在「人格权严重精神损害」时打破择一，转为违约+精神损害并用。
- **第1203条须隔离**：产品责任的生产者/销售者选择属「不真正连带」（责任主体择一），非请求权竞合、亦非聚合，概念不可混用。

# 六、翻车标本（负向拦截·HIR）

1. **混淆竞合与聚合**：在第186条情形下同时主张「违约+侵权」要求双倍赔偿 → 法院将责令择一，诉请被部分驳回。
2. **忽略第996条例外**：人格权严重受损却仅按违约起诉、漏列精神损害 → 违约路径下精神损害一般不被支持（除非第996条情形）。
3. **把第588条内部双层当单一体**：定金与违约金是「择一」，但定金与「超过定金的损失」是「聚合补足」——同一第588条内即有择一+聚合双层，误读致漏列超额损失。
4. **法条竞合当竞合处理**：合同欺诈按第186条择一，却忽略特别法优位 → 案由/请求权基础选错。

# 九、择一的四层结构（层级辨析）

请求权基础体系中的"择一"并非单一概念，须分层识别，否则易与"聚合"混淆。本族对撞校验已确认跨域散见卡分别落入以下层级，无冲突：

| 层级 | 性质 | 法条支点 | 典型场景 | 与聚合关系 |
|---|---|---|---|---|
| ① 请求权基础择一 | 同一给付目的，违约/侵权二选一 | 民法典186条 | 加害给付（违约+侵权） | 择一，禁止并获双倍 |
| ② 责任主体择一（不真正连带） | 同一给付目的，向谁主张二选一 | 民法典1203条 | 产品缺陷（生产者/销售者） | 对外择一、内部可追偿（概念隔离） |
| ③ 履行/权利择一 | 债已成立，具体履行方式或权利二选一 | 民法典588条；R-JG-020 | 定金/违约金择一；以物抵债/票据权择一 | 择一，禁止双重受偿 |
| ④ 请求权聚合（非择一） | 给付目的各异，可并用 | 民法典179条；工伤双赔 | 违约+精神损害(996)；工伤+第三人侵权双赔 | 可并用，非择一 |

> **层级陷阱**：第588条内部即有"定金/违约金择一 + 超额损失聚合补足"双层（见 §六 翻车标本3）；R-JG-020 的"择一"属 ③ 履行/权利择一，与 ① 186择一虽同称"择一"但层级不同，不得混为请求权基础竞合。
> **对撞闭环**：R-PI-140（1203→②）·[[R-JG-020-已付工程价款抗辩以物抵债以房抵款商票择一]]（588→③）·[[R-GZ-021-工伤与第三人侵权竞合双赔边界]]/[[R-LD-006-工伤与第三人侵权竞合的双重赔偿规则]]/[[R-LD-009-工伤事故双重请求权与向部分侵权人主张]]（工伤双赔→④）均已对齐。
