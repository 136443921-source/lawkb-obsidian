# 一、争点定位与请求权基础

缔约过失责任（民法典第500条）是合同未成立/无效/被撤销时，违反先合同义务方对善意相对人的法定赔偿责任。本卡深拆第500条构成要件，并**与合同欺诈（第148/157条）撤销路径作系统对照**——二者在"欺诈缔约"情形发生竞合，是请求权基础卡族中"缔约阶段请求权分野"的关键节点。对齐 R-HT-278（排斥型）与 R-HT-282（合同欺诈）。

# 二、缔约过失责任（第500条）构成要件

- 阶段：订立合同**过程中**（合同未成立、或成立后被撤销/确认无效）；
- 违反先合同义务（诚信原则，第500条）：① 假借订立合同恶意磋商；② 故意隐瞒与订立合同有关的重要事实或提供虚假情况；③ 其他违背诚信原则的行为（一般条款）；
- 造成对方**损失**（信赖利益，非履行利益）；
- 因果关系 + 可归责（故意或过失）。
- 保密义务：第501条（知悉的商业秘密或其他应保密信息，无论合同是否成立不得泄露/不正当使用，致损赔偿）。
- 效果：信赖利益损害赔偿（缔约费用、准备履行费用、丧失订约机会的损害），受可预见限制。

# 三、与合同欺诈（第148/157）撤销路径对照（核心对照表）

| 维度 | 欺诈撤销路径（第148/157条） | 缔约过失路径（第500条） |
|---|---|---|
| 触发 | 一方欺诈使对方违背真实意思（第148） | 违反先合同义务（恶意磋商/隐瞒/背信，第500） |
| 合同状态 | 合同已成立，受欺诈方撤销 → 自始无效（第157） | 合同未成立/无效/被撤销均可 |
| 请求权基础 | 撤销权（第148）+ 撤销后赔偿（第157） | 独立的法定赔偿请求权（第500） |
| 赔偿范围 | 第157条：返还 + 过错方赔偿损失（信赖利益；履行利益存争议） | 信赖利益（缔约费用/准备费用/机会损失） |
| 与186关系 | 欺诈本身属"合同欺诈排斥型"→ 不进186（见 R-HT-282 对齐 R-HT-278） | 与侵权（第1165）特别—一般 → 排斥型（R-HT-278） |
| 竞合判定 | 欺诈是缔约过失的**特殊情形**（故意背信） | 同一欺诈损失下，与第157赔偿**目的同一** → 186竞合择一（或以第157吸收） |

**分野结论（判定树）**：

- 情形A（合同已因欺诈被撤销）：优先走第148撤销 → 第157清算赔偿；此时第500缔约过失与第157赔偿目的同一（均填信赖利益）→ **186竞合择一（R-HT-237）**，实务多采第157吸收（撤销清算优先）；
- 情形B（合同未撤销但磋商中存在背信/恶意磋商）：仅第500条独立适用，不进186；
- 情形C（缔约阶段致固有利益损害，如看样时人身安全受损）：第500缔约过失 + 第1165侵权 → 特别—一般（第11条优位）→ **法条竞合排斥型（R-HT-278）**，仅择一（通常缔约过失）；
- 情形D（独立侵权部分，目的各异）：罕见，转聚合（R-HT-238）。

# 四、与侵权的分野（排斥型，对齐 R-HT-278）

缔约过失（第500）与侵权（第1165）就"缔约阶段固有利益损害"：二者规范目的部分重叠，但第500条为缔约阶段特别规定 → 第11条特别法优位 → **排斥型**，仅适用其一（情形C）。此与 R-HT-282"合同欺诈排斥型"同源（缔约阶段特别法优位）。

# 五、鉴定式审查流程

1. 产生：缔约阶段 + 先合同义务违反（第500）+ 信赖利益损失；
2. 竞合识别（套 R-HT-279）：
   - 位阶测试：与侵权（第1165）特别—一般 → 排斥（情形C）；
   - 与欺诈撤销（第157）：目的同一 → 186竞合择一（情形A）；
   - 未撤销仅背信 → 第500独立（情形B）；
3. 消灭/可行使：选定并获完全满足后另一请求权消灭。

# 六、常见误判（HIR）

- ❌ "缔约过失只能赔缔约费用" → 含订约机会丧失等信赖利益，受可预见限制；
- ❌ "欺诈撤销后只能按第157条，不能再主张缔约过失" → 二者目的同一，186竞合择一，可择一主张；撤销清算优先为实务倾向；
- ❌ "缔约过失与侵权一律聚合" → 缔约阶段固有利益损害，第500与第1165为特别—一般排斥（R-HT-278）；
- ❌ "缔约过失赔偿可达履行利益" → 原则上限于信赖利益（区别于违约第584履行利益）。

# 七、正向裁判规则（judge_reviewer 用）

缔约阶段赔偿纠纷：① 先定位合同状态（成立/撤销/无效）；② 已撤销 → 第157清算，与第500目的同一择一（或吸收）；③ 未撤销背信 → 仅第500；④ 致固有利益损害 → 第500与第1165排斥（第11条优位）；⑤ 赔偿范围以信赖利益为限。本判决规则供给模拟法庭法官 skill 作缔约阶段竞合类案正向指引。
