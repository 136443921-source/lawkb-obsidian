# R-HT-121 借款合同要素式审查要点与利息上限合规红线

## 审查清单（八要素）

| 条款 | 审查要点 |
|---|---|
| **合同主体** | ① 双方名称、住所地、法定代表人、联系方式；自然人须含姓名、地址、联系方式、**身份证号**；② 审查借款人**资信与还款能力**、是否为失信被执行人；③ 借款人有配偶的，**建议配偶共同签字**作为共同借款人 |
| **借款条款** | ① 明确借款种类、币种；② 明确**借款用途**（如家庭生活所需），并明确不得用于违法犯罪活动；③ 金额**建议大写**，且**不得预先扣除利息**；④ 明确借款期限 |
| **利息条款** | 明确利率，可约定按 **LPR 的 X 倍**支付（**上限 4 倍**） |
| **还款条款** | ① 还款日期用**封闭式表达**（"XX年XX月XX日之前归还"）；② 明确一次性或分期；③ 明确本金与利息各多少 |
| **担保条款** | ① 明确担保方式（一般保证 / 连带保证 / 抵押 / 质押）；② 保证人须在借款合同上**签字确认**；③ 抵押须**另签抵押合同并办理抵押权登记**；④ 质押须另签质押合同并**转移质物占有** |
| **违约责任** | 针对双方义务分别设置；明确违约类型；违约金额**合理** |
| **争议解决** | 明确诉讼或仲裁；选诉讼的须明确**管辖法院** |
| **合同生效/份数/附件** | 明确生效条件、份数、附件清单 |

## 三条合规红线（易致条款无效或金额被调减）

1. **利息不得预先扣除**（《民法典》第670条）：借款的利息不得预先在本金中扣除；预先扣除的，**应当按照实际借款数额返还借款并计算利息**。
   → 执业提示：砍头息情形下，本金按实收金额认定，直接削减债权数额——代理出借人须避免此操作，代理借款人则可作为抗辩切入点。
2. **利率上限 LPR 4 倍**：超出部分不受保护（依据《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》，**具体条文号待元典回源核验**）。
3. **用途违法即无效**：借款用于违法犯罪活动的，借贷关系不受保护，须在合同中明确用途限制。

## 关联法条（已由本地权威源《中华人民共和国民法典（全文）》回填核验）

- **第670条**：借款的利息不得预先在本金中扣除。利息预先在本金中扣除的，应当按照实际借款数额返还借款并计算利息。
- 第673条：借款人未按照约定的借款用途使用借款的，贷款人可以停止发放借款、提前收回借款或者解除合同。
