# R-HT-288 买卖合同质量异议期与"检验期限过短仅及外观瑕疵"规则

## 裁判规则

1. **约定检验期限**：买受人应当在检验期限内将数量或质量不符约定的情形通知出卖人；**怠于通知的，视为标的物的数量或质量符合约定**（《民法典》第621条第1款）。
2. **未约定检验期限**：买受人应在发现或应当发现不符约定的**合理期限**内通知；自收到标的物之日起**二年**内未通知的，视为符合约定（第621条第2款，"二年"为最长合理期限、不变期间，不适用时效中止中断延长）；有质量保证期的适用质保期。
3. **出卖人明知瑕疵除外**：出卖人知道或应当知道标的物不符约定的，买受人不受上述通知时间限制（第621条第3款）。
4. **检验期限过短的限缩**：当事人约定的检验期限过短，依标的物性质与交易习惯买受人在该期限内难以完成全面检验的，**该期限仅视为对外观瑕疵提出异期的期限**；约定的检验期限或质保期短于法律、行政法规规定期限的，以法定为准（第622条）。

## 法条依据（本地缓存回填，非凭记忆）

- 《民法典》第620条：买受人收到标的物时应在约定检验期限内检验；无约定的应及时检验。
- 《民法典》第621条：检验期限/通知义务、二年最长期、出卖人明知除外。
- 《民法典》第622条：检验期限过短仅视为外观瑕疵异议期；约定期限短于法定以法定为准。
- 《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》第12条：认定"合理期限"应综合交易性质、标的种类、瑕疵性质、检验难易等，依诚信原则判断；二年为最长合理期限。

## 实务要点（贴合在办案件）

1. **6658 吊顶案 / 6660 雅菲案共同防线**：原告（买受人一方）若主张质量/数量不符，须举证已在检验期限或合理期限内提出异议；**超期未通知即推定合格**，是被告"货款已清/质量无争议"抗辩的硬支点。
2. **外观 vs 隐蔽瑕疵二分**：若合同检验期过短（如"收货当日验收"），法院仅认其为外观瑕疵异议期，隐蔽瑕疵仍可在合理期限内（最长二年）主张——被告拟制"当场验收即终局"条款时须警惕第622条限缩。
3. **出卖人明知的破口**：若出卖人对瑕疵明知（如明知材料非约定规格仍交付），买受人异议不受期限限制，被告"超期视为合格"抗辩失效。
4. **举证分配**：买受人主张质量不符，须先证明已按期通知；出卖人主张"视为合格"，须证明通知期已届满且买受人未异议。
