# R-HT-272 合同审核四大思维与十大要点

## 规则摘要
合同审核是商业交易的风险预判与权责锁定，须以四大核心思维为底层逻辑，并按十大要点覆盖合同全生命周期。

## 蓝队要点（审查清单）
- **四大思维**：① 交易本位（贴合真实交易、口头落书面）；② 风险对等（排查我方全责/对方免责的霸王条款）；③ 穷尽风险（预设延迟、瑕疵、欠款、解约、政策变动）；④ 证据留存（沟通/交付/验收/付款/送达书面化）。
- **十大要点**：主体资质与履约能力 → 合同目的 → 标的（合法/数量质量验收/服务者资格/物品权证） → 框架 → 交付 → 支付（币种/单价总价/税费） → 权利义务（均衡、履行顺序、安装培训保修） → 违约（5种责任形式+可操作性） → 争议解决（争取我方所在地/仲裁、败诉方担合理费用） → 兜底（送达、保密、生效、冲突处理、消灭歧义）。

## 红队要点（典型漏洞）
- 模板条款与实际交易脱节 → 条款无效；
- 违约责任无计算方式 → 难以执行；
- 管辖约定在对方所在地 → 异地诉讼成本高；
- 「逾期视为验收合格」被滥用 → 质量异议失权。

## 法条依据
《民法典》第496条（格式条款提示说明义务）、第510/511条（约定不明补充）、第577条（违约责任）；管辖依第24条（合同纠纷管辖）。

## 适用边界
适用于买卖、服务、合作、租赁等所有合同初审；模板化合同须先以「交易本位」校验是否贴合实际。
