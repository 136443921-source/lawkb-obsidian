# 一、争点定位与请求权基础

同一生活事实同时该当数个民法典法条（或民法典与特别法法条）的构成要件，但各法条之间并非「目的同一的请求权竞合」（不进入民法典第186条择一），亦非「目的各异的责任聚合」（非民法典第179条并用），而是因法条间存在**特别关系 / 吸收关系 / 补充关系**，仅能适用其中一法条，其余法条被排斥。此即三分式第一枝：**法条竞合（排斥型 / Gesetzeskonkurrenz）**。

# 二、鉴定式审查框架（审查要点）

1. **产生**：同一事实该当数法条。
2. **竞合识别（核心节点）**：判定竞合类型——
   - 各法条给付目的**同一** → 请求权竞合 → 民法典第186条择一（见 R-HT-237）；
   - 各法条救济目的**各异** → 责任聚合 → 民法典第179条并可（见 R-HT-238）；
   - 法条间存在**位阶排斥**（特别/吸收/补充）→ 法条竞合排斥型 → 仅适用优先法条，**不进186、非179**。
3. **法律效果（排斥型）**：依位阶仅适用特别/优先法条，被排斥法条不发生适用空间。
4. **消灭/可行使**：按唯一适用法条判断诉讼时效、行使方式与救济内容。

# 三、构成要件与识别标准

**三类排斥关系**：

- **特别关系（特别法优位）**：民法典第11条「其他法律对民事关系有特别规定的，依照其规定」。特别法条排斥普通民法典条款。典型案型：
  - 合同欺诈（民法典第148条可撤销 + 消费者权益保护法等特别法惩罚性赔偿）→ 特别法优先，不构成第186条违约/侵权择一；
  - 票据付款请求权（票据法）排斥原因关系债权（民法典）；
  - 海商法/铁路法等特别法就特定事项排斥民法典一般规定。
- **吸收关系**：一行为触犯数法条，重者吸收轻者，轻法条被吸收而不适用。民法上多见于责任方式间的吸收（如继续履行吸收部分损害赔偿请求）。
- **补充关系**：民法典为普通法，就同一事项有特别补充规定时，特别规定优先，民法典相应部分退居补充地位。

# 四、法条依据（权威源回填）

- 民法典第11条：其他法律对民事关系有特别规定的，依照其规定。
- 民法典第148条：一方以欺诈手段，使对方在违背真实意思的情况下实施的民事法律行为，受欺诈方有权请求人民法院或者仲裁机构予以撤销。
- 民法典第186条：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。（注：本卡排斥型**不进入**本条）
- 民法典第187条：民事主体因同一行为应当承担民事责任、行政责任和刑事责任的，承担行政责任或者刑事责任不影响承担民事责任；民事主体的财产不足以支付的，优先用于承担民事责任。（辨析：跨法域责任聚合且民事优先，非法条竞合排斥）
- 民法典第179条：承担民事责任的方式主要有：（一）停止侵害；（二）排除妨碍；（三）消除危险；（四）返还财产；（五）恢复原状；（六）修理、重作、更换；（七）继续履行；（八）赔偿损失；（九）支付违约金；（十）消除影响、恢复名誉；（十一）赔礼道歉。……本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。（辨析：责任聚合基础，非排斥型）
- 民法典第995条：人格权受到侵害的，受害人有权依照本法和其他法律的规定请求行为人承担民事责任。受害人的停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉请求权，不适用诉讼时效的规定。（与第1165条侵权赔偿的衔接：人格权请求权优先适用，属补充/特别关系）
- 民法典第1165条：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
- 民法典第1203条：因产品存在缺陷造成他人损害的，被侵权人可以向产品的生产者请求赔偿，也可以向产品的销售者请求赔偿。（不真正连带，隔离于186，见 R-HT-238）

> ⚠️ 外部特别法（消费者权益保护法、票据法、海商法、铁路法等）条文以本地法律法规库回填为准，本文未逐字引，statute_text_pending。

# 五、抗辩与但书

- **区分标准（两步测试）**：
  1. **目的同一性测试**：数法条是否填补同一损害/实现同一给付目的？是 → 第186条竞合；否 → 进入下一步。
  2. **位阶测试**：法条间是否特别/吸收/补充关系？是 → 仅适用优先法条（排斥型）；否且目的各异 → 第179条聚合。
- **误区**：
  - 误把排斥型当第186条竞合择一（如合同欺诈按186择一，忽略特别法优位）→ 案由/基础错位；
  - 误把聚合当排斥（如人格权受侵害仅主张侵权赔偿，漏列第995条不受时效的人格权请求权）→ 丧失停止侵害等 parallel 救济；
  - 混淆吸收与竞合：以为重行为吸收轻行为=请求权消灭，忽略仍可能构成不真正连带（第1203条）。

# 六、翻车标本（HIR）

1. **合同欺诈案援引186择一**：原告以「违约+侵权」并列，请求按第186条择一，法院指出欺诈已有民法典第148条及特别法优先规则，不进入186竞合 → 案由错位、部分诉请被指正。
2. **人格权侵害仅按1165起诉**：漏列第995条停止侵害/赔礼道歉等不受时效的人格权请求权，被告以超过侵权时效抗辩，原告丧失非时效性救济。
3. **票据纠纷主张原因债权竞合**：持票人行使票据付款请求权时，仍以原因关系（买卖违约）主张竞合，忽略票据法为特别法排斥原因关系，原因债权主张被驳回（须先行使票据权利或追索）。
