# R-HT-251 增资入股协议：先确权后出资与回购连带保证

## 一句话结论
增资入股本质"用工商确权对抗出资风险"；模板把投资方保护做到极致，但**股权永不变稀释 / 名股实债 / 原股东无限连带**三处是融资方必须重写或拒签的红线。

## 蓝队（投资方/乙方防御，模板内置）
- 先确权后出资：首期到账即启动工商变更，10工日内登记在册；尾款未清股权仍永久固定。
- 原股东（丙方）不可撤销连带保证 + 放弃先诉抗辩，保证期3年，含维权费用。
- 多情形强制回购：隐瞒债务/挪用/擅处资产/连续12月亏损/逾期分红 → 已付出资+年化8%回购。
- 满12月无理由退股，回购价取公允估值与实缴出资本金较高者。
- 专款专用 + 单笔5万以上告知，违规触发根本违约+20%违约金+回购。

## 红队（融资方/攻击）
- "10%股权永久固定不得稀释"与后续融资反稀释/同比例增资法定安排冲突，未约定反稀释对价将受制。
- 放弃优先认购权不可撤销 + 丙方连带范围极宽（含律师费），近乎无限责任。
- 年化8%固定收益+20%违约金并主张可能构成"名股实债"，且叠加收益易被调减。
- 乙方逾期出资仅0.03%/日+30日宽限期且不稀释，对甲方显失公平，应争取按比例调减股权。
- 管辖"乙方所在地法院"对甲方不利。

## 法条依据
- 《公司法》（2023修订）第227条（增资优先认购权）、第34条（股权登记对抗）
- 《民法典》第681-702条（保证）、第565-566条（解除与回购）、第585条（违约金调减）
- 最高人民法院《九民纪要》第71条（名股实债认定）
