# 一、争点定位与请求权基础

当同一事实产生的数个请求权**给付目的各异**（规范目的不同），权利人可**同时主张、一并满足**——此即请求权聚合／责任聚合，与第186条的「择一」正相对照。规范总基础为民法典第179条「承担民事责任的方式，可以合并适用」。

# 二、鉴定式审查框架（审查要点）

1. **产生**：分别独立检视各候选请求权基础是否各自成立（各算各的要件，不互相排斥）。
2. **聚合识别**：数请求权给付内容不同、规范目的各异 → 可并存。
3. **效果**：一并主张、分别满足；无「择一」限制（除非法律/约定另有择一规定，如第588条定金/违约金）。

# 三、构成要件与举证

**聚合识别标准（与竞合区分核心）**：

- 给付目的**同一**（填补同一损害）→ 竞合（第186条）→ 择一；
- 给付目的**各异**（不同给付/不同规范目的）→ 聚合 → 并用。

举证：各请求权基础独立举证，聚合不减轻任一基础的举证负担。

# 四、法条依据（权威源回填）

- 民法典第179条（聚合总规范）：……本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。
- 民法典第996条（违约+精神损害并行）：因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。
- 民法典第588条但书（定金+超额损失补足）：定金不足以弥补一方违约造成的损失的，对方可以请求赔偿超过定金数额的损失。
- 民法典第585条（违约金+补足损失/继续履行）：……约定的违约金低于造成的损失的……予以增加；当事人就迟延履行约定违约金的，违约方支付违约金后，还应当履行债务。
- 民法典第1167条（绝对权请求权）：侵权行为危及他人人身、财产安全的，被侵权人有权请求侵权人承担停止侵害、排除妨碍、消除危险等侵权责任。
- 民法典第997条（人格权禁令）：民事主体有证据证明行为人正在实施或者即将实施侵害其人格权的违法行为，不及时制止将使其合法权益受到难以弥补的损害的，有权依法向人民法院申请采取责令行为人停止有关行为的措施。
- 民法典第187条（民刑责任聚合·民事优先）：……承担行政责任或者刑事责任不影响承担民事责任；民事主体的财产不足以支付的，优先用于承担民事责任。

# 五、抗辩与但书

- **第588条内部双层结构（最易翻车）**：定金与违约金是「**择一**」（同一条款内互斥）；但定金与「超过定金数额的损失」是「**聚合补足**」——同一第588条内择一+聚合并存，须分层处理。
- **第996条是第186条的例外**：仅在「人格权严重精神损害」情形打破第186条择一，转为聚合；非人格权受损的纯财产损害仍受第186条择一约束。
- **第1203条须隔离**：产品责任的生产者/销售者选择属「不真正连带」（责任主体择一），既非请求权竞合亦非聚合。
- **违约金+定金不可聚合**：第588条明定二者择一，不得同时适用（与「定金+超额损失」不同，须区分）。

# 六、翻车标本（HIR）

1. **把第588条定金+违约金当聚合**：一并主张定金罚则+违约金 → 违反第588条择一，超额部分驳回（应择一，仅可就超定金损失补足）。
2. **忽略第996条例外边界**：非人格权受损却主张违约+精神损害并用 → 精神损害不被支持（第996条限于人格权严重损害）。
3. **混淆第1203条与第186条**：产品责任按第186条择一主张违约/侵权，忽略其本质是不真正连带（可向生产者或销售者择一索赔，非请求权基础择一）。
