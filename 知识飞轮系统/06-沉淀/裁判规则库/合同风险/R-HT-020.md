# R-HT-020 出租人解除权行使——通知解除与有效送达

## 触发场景（trigger）
- 承租方逾期支付租金，出租方拟解除租赁合同并收回房屋、主张占有使用费。
- 审查"限期付租否则解除"通知函的效力。

## 规则（rule）
1. **解除权为形成权，依通知行使**：依《民法典》第565条，解除权人以通知方式行使，通知到达相对人生效；合同自通知到达时解除。
2. **解除权基础须先存在**：约定解除（合同明确约定期限+解除权）或法定解除（《民法典》第563条第1款第（三）项：迟延履行主要债务经催告合理期限仍未履行）。无解除权基础的通知不产生解除效力。
3. **通知须明确解除意思表示**：须载明"逾期则解除租赁合同"等明确意思，仅催款不构成解除。
4. **合理期限 + 有效送达**：限期应给合理履行期限（通常不少于数日）；优先 EMS 特快专递并备注文件性质、留存邮寄凭证与妥投记录，作为解除意思表示到达的关键证据。
5. **异议机制**：相对人对解除有异议的，可请求法院或仲裁机构确认解除效力；约定异议期不明时适用司法解释相关期限。

## 适用要点（do / dont）
- **do**：先核验解除权基础→发函明确解除意思→EMS留痕→告知腾退与费用结算。
- **dont**：勿未催告即解除；勿限期过短（如1日）被认定未给合理期限；勿忽略送达证据导致"未到达"抗辩成立。
