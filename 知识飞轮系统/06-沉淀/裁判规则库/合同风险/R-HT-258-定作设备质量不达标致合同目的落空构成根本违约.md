# 定作设备质量不达标致合同目的落空构成根本违约（R-HT-258）

## 裁判规则

1. **定作合同区别于买卖合同的特性**：标的物为满足定作人**特定需求**而制作，合同目的具有"特定化"属性；工作成果是否符合约定质量是核心审查对象。
2. **根本违约的认定核心＝"合同目的能否实现"**：经合法程序委托、具备资质的鉴定确认工作成果存在重大质量瑕疵、无法满足定作人特定生产经营需求的，构成《民法典》第563条第（四）项"违约行为致使不能实现合同目的"，定作人享有法定解除权。
3. **鉴定意见的审查＝程序合法 + 实质审查相结合**：法院对司法鉴定意见应坚持"程序合法性 + 实质审查"双标准；鉴定人具备资格、程序合法、依据充分且对方无足以推翻的相反证据时，应予采信。
4. **救济路径选择**：定作人可合理选择修理/重作/减少报酬/赔偿损失（《民法典》第781条）；若明确表示不要求修理重作、双方信任基础丧失、合同陷入僵局，支持解除更有利于实质解纷（效率原则）。
5. **反向边界（轻微瑕疵≠根本违约）**：仅存在可整改的轻微质量瑕疵且已预留质保金覆盖风险的，定作人无权拒付全部到期货款（参见南阳(2025)豫13民终832号，与本案构成"重大瑕疵解除 vs 轻微瑕疵付款"的两极对照）。

## 基本案情（来源：法治日报 2025-12-21 报道·敦化市人民法院）

某粮食购销公司与某锅炉公司签订《8吨烘干炉买卖合同书》，约定锅炉保证炉膛热度达要求、达不到则更换、更换仍不达标全额退款。粮食公司付50万元后，锅炉交付设备但始终无法稳定控制炉膛温度在约定800℃–1000℃区间，无法正常烘干玉米。法院委托鉴定确认设备无法稳定达到约定温度。一审认定构成根本违约、支持解除合同返还50万元；二审维持。

## 对在办案件的锚定

- **6658 吊顶案 / 6660 雅菲案**：质量异议与"合同目的能否实现"的举证端点——本方应固化"标的物特定用途 + 质量瑕疵致用途落空"的证据链；同时注意反向边界（轻微瑕疵不当然解除），避免主张过度。
- 与 R-HT-130（非标设备要素检验法）、R-HT-131（非标定制设备根本违约）互为补充：本案提供"鉴定采信 + 合同目的特定化"的司法口径样本。
