# 一、争点定位与请求权基础

第186条的「择一」不只是实体权利选择，更**直接决定诉讼路径**：原告起诉时必须明确请求权基础（案由），不同选择带来管辖、时效、举证、赔偿范围的实质差异。本卡将第186条落到诉讼实战。

# 二、鉴定式审查框架（审查要点）

1. **选定节点**：受害方应在起诉时明确选择违约或侵权路径（案由）。
2. **程序效果**：管辖、时效起算、举证责任、赔偿范围随选定路径切换（见矩阵）。
3. **选定拘束力**：一审法庭辩论终结前可变更；选定并获完全满足后，另一竞合请求权消灭。

# 三、构成要件与举证（六变量矩阵）

| 变量 | 违约责任路径（第577条） | 侵权责任路径（第1165条） |
|---|---|---|
| 管辖 | 被告住所地/合同履行地（民诉法第24条） | 侵权行为地/被告住所地（民诉法第29条） |
| 诉讼时效 | 3年，自知道或应知权利受损+义务人之日（第188条） | 同3年；损害显现在后时「知道」时点可能推后 |
| 归责/举证 | 严格责任，证违约行为+损害即可（过错非要件） | 一般过错责任，须证过错（产品/机动车/环境/高度危险等过错推定或无过错除外） |
| 赔偿范围 | 受可预见性规则（第584条）限制，一般不含精神损害（第996条例外） | 含精神损害（一般）、残疾/死亡赔偿金，全面赔偿 |
| 免责事由 | 不可抗力、约定免责（造成人身损害/故意重大过失免责无效，第506条） | 受害人故意、不可抗力、第三人原因、正当防卫等（第1174-1179条） |
| 请求权基础/案由 | 合同纠纷 | 侵权责任纠纷 |

# 四、法条依据（权威源回填）

- 民法典第186条：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。
- 民事诉讼法第24条：因合同纠纷提起的诉讼，由被告住所地或者合同履行地人民法院管辖。
- 民事诉讼法第29条：因侵权行为提起的诉讼，由侵权行为地或者被告住所地人民法院管辖。
- 民法典第188条：向人民法院请求保护民事权利的诉讼时效期间为三年。……自权利人知道或者应当知道权利受到损害以及义务人之日起计算。
- 民法典第584条（可预见性·违约赔偿范围）：违约损失赔偿额应相当于因违约所造成的损失，包括合同履行后可获得的利益，但不得超过违约方订立合同时预见到或应当预见到的因违约可能造成的损失。
- 民法典第506条（免责条款无效）：合同中的下列免责条款无效：（一）造成对方人身损害的；（二）因故意或者重大过失造成对方财产损失的。

# 五、抗辩与但书

- **选定拘束力**：受害方起诉应明确请求权基础；一审法庭辩论终结前可变更；选定获满足后另一请求权消灭（择一本质）。实务中法院多要求原告明确，避免两头主张（hedge）。
- **违约路径下违约金/定金条款适用**：选定侵权后，原合同关系的违约金、定金等条款不再适用（已择侵权路径）。
- **释明义务**：原告未明确择一的，法院可释明；仍不明确的，按最有利于查明事实/保护权益处理，但不得创设「聚合双倍」。

# 六、翻车标本（HIR）

1. **同时主张违约+侵权求双倍**：违反第186条择一，法院责令择一，超额被驳。
2. **仅按违约起诉漏精神损害**：损害含严重人格权侵害却走违约路径 → 精神损害一般不被支持（除非第996条情形），救济缩水。
3. **管辖错配**：按侵权起诉却向合同履行地法院立案 → 可能被移送侵权行为地/被告住所地。
4. **选定后反悔追加另一路径**：一审辩论终结后主张另一竞合请求权 → 因选定消灭被驳。

# 七、来源与地域效力

# 九、择一的四层结构辨析（层级区分）

第186条的"择一"仅为"择一"概念的一层。完整层级见族总览 [[R-HT-236-请求权基础与法条竞合数分野总览鉴定式]] §九，此处仅点明实战易混点：

- **① 请求权基础择一（本卡主轴）**：违约vs侵权，给付目的同一 → 186条，选定获满足后另一消灭。
- **③ 履行/权利择一**：债已成立，具体履行/权利二选一（588定金/违约金、R-JG-020 以物抵债/票据权）→ 禁止双重受偿，但非请求权基础竞合，不改变案由（仍依原法律关系）。
- **② 责任主体择一（不真正连带）**：1203 生产者/销售者 → 概念须隔离，不得与186择一混用。
- **④ 聚合（非择一）**：179条/工伤双赔 → 可并用。

> 实战坑：把 R-JG-020 的"择一"误当作186请求权基础竞合，导致错误切换案由/管辖。二者层级不同（③ vs ①）。
