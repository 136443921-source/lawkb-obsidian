# 核心要旨

买受人对标的物的数量、质量负有及时检验并在异议期内通知的义务；怠于通知或超期通知，视为标的物符合约定。

- **约定检验期限**：当事人约定检验期的，买受人应在检验期内通知不符；怠于通知的，视为数量、质量符合约定（民法典第621条第1款）。
- **合理期限（无约定时）**：未约定检验期的，买受人在"发现或应当发现不符的合理期限内"通知；合理期限由法院综合交易性质、标的特性、瑕疵性质、检验难易、交易习惯等依诚信原则认定（买卖合同解释第12条）。
- **二年最长期间（不变期间）**：自收到标的物之日起二年内未通知的，视为符合约定；有质量保证期的适用质保期，不适用二年。该二年为**不变期间**，不适用时效中止、中断、延长（解释第12条第2款）。
- **⭐ 已付款/确认欠款/使用标的物 ≠ 放弃质量异议**：买受人已支付价款、确认欠款数额或已使用标的物的，出卖人主张其放弃异议的，法院不予支持——但当事人另有约定除外（买卖合同解释第13条）。**本条直接命中吊顶案 6658 与雅菲案 6660 核心争点**："货款已付/已使用"不能反推"质量无异议"。
- **二年期满后驳回**：检验期限、合理期限、二年期限经过后，买受人主张数量或质量不符的，法院不予支持；出卖人自愿担责后翻悔的亦不予支持（解释第14条）。

# 关联法条

- 《民法典》第620条（买受人检验义务）、第621条（通知义务与二年最长期间）、第622条（约定检验期过短视为外观瑕疵期）、第623条（对外观瑕疵约定检验期过短的处理）。
- 《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》（法释〔2020〕17号）第12、13、14条。

# 适用场景

- **吊顶采购合同纠纷案（2026黔0330民初6658号，被告立场）**：原告以"已使用/已付部分款"主张质量无问题或放弃异议的，依解释第13条予以驳斥；审查双方是否约定检验期、原告是否在合理期限/二年内提出异议。
- **雅菲软装窗帘案（2026黔0330民初6660号，被告立场）**："货款已清"抗辩不能等同于"质量异议权消灭"；被告可援引解释第13条主张原告即便付款仍保留质量异议空间，同时审查原告异议是否超合理期限/二年。
