# 一、争点定位与请求权基础

履行不能/根本违约是违约责任体系的核心违约形态。本卡聚焦：同一违约事实触发多项违约救济请求权（继续履行、补救、赔偿、解除、违约金、定金）时，各救济之间究竟是**聚合（并用）还是竞合（择一）**；以及违约救济与侵权救济（尤其固有利益损害）的边界。本卡系 R-HT-236 卡族下位专题，与 R-HT-281（加害给付）共同覆盖"履行阶段致害"全貌。

# 二、履行不能/根本违约的认定要件

- 有效合同 + 给付义务存在；
- 给付障碍：① 履行不能（法律上或事实上不能，民法典第580条第1款第(一)项）；② 履行迟延；③ 不完全给付（瑕疵给付/加害给付，见 R-HT-281）；
- 根本违约：违约致使"不能实现合同目的"（第563条第1款第(四)项），系解除权发生要件；
- 可归责性：第577条以无过错责任为原则，但风险负担、不可抗力（第590条）等除外。

# 三、违约救济请求权的并存分野（核心·套用 R-HT-279 二测试）

就"同一违约事实"，各项违约救济请求权的关系：

1. **继续履行 vs 赔偿损失**：
   - 非金钱债务：继续履行请求权（第577、580条）与赔偿请求权（第584条）目的各异（给付本身 vs 价值填补）→ **责任聚合（R-HT-238）**，可并用；
   - 但非金钱债务陷入第580条第1款第(一)(二)(三)项排除情形（不能履行／标的不适于强制／费用过高）→ 继续履行请求权**消灭**，仅余赔偿 → 此时非"择一"而是"排斥"（不能履行则无继续履行可择）。

2. **解除合同 vs 赔偿损失**：
   - 解除（第563、566条）与赔偿（第566条第2款、第584条）目的各异 → **聚合**，解除后仍有赔偿请求权（解除不消灭清算/赔偿）；
   - 注意第567条：结算和清理条款不因权利义务终止而失效。

3. **违约金 vs 赔偿损失**：
   - 违约金本质为损害赔偿预定（第585条），与赔偿请求权**目的同一**（填补同一违约损失）→ **请求权竞合（第186条）→ 择一行使（R-HT-237）**，或视为违约金吸收赔偿；
   - 违约金过分高于损失可请求酌减（第585条第2款）。

4. **定金 vs 违约金**：
   - 第588条：既约定违约金又约定定金，对方**选择适用其一**（择一）→ 与 R-HT-239 择一双层结构一致；定金不足弥补损失的可请求赔偿超过部分（第588条第2款，该超出部分为聚合）。

# 四、与侵权竞合的边界（衔接 R-HT-281/237）

- 违约致债权人**固有利益**（人身/其他财产）损害 → 违约责任（第577/584）+ 侵权责任（第1165）→ 目的同一性测试（R-HT-279步B）→ **第186条竞合择一（R-HT-237）**；
- 缺陷产品致害 → 转第1203条不真正连带**隔离（R-PI-140）**；
- 人格权严重精神损害 → 第996条**聚合例外（R-HT-238）**。
- 此点与 R-HT-281（加害给付）重叠：瑕疵履行致固有利益损害由本卡（竞合边界）+ R-HT-281（认定要件）共同覆盖。

# 五、鉴定式审查流程

1. 产生：合同有效 + 义务 + 违约事实（不能/迟延/瑕疵）；
2. 竞合识别（套 R-HT-279）：
   - 先位阶测试：有无排斥（如第580条排除实际履行 → 仅赔偿）；
   - 再目的同一性测试：各救济给付目的同一 → 186竞合择一；各异 → 聚合；
3. 消灭：选定并获完全满足后另一竞合请求权消灭；
4. 可行使：解除权/抗辩权/违约金酌减请求。

# 六、常见误判（HIR）

- ❌ "履行不能就一律免责" → 第580条仅排除**实际履行**，不免除**赔偿责任**（除非不可归责且风险已转移）；
- ❌ "违约金与赔偿可任意并用" → 目的同一，186竞合择一或以违约金为赔偿预定；
- ❌ "解除合同即消灭所有请求权" → 解除不消灭清算/赔偿（第566、567条）；
- ❌ "根本违约当然导致所有救济聚合" → 救济间仍须按目的同一性逐一判定竞合/聚合。

# 七、正向裁判规则（judge_reviewer 用）

审查违约救济并存性时：① 先判继续履行请求权是否因第580条(一)(二)(三)而消灭；② 未消灭则继续履行+赔偿为聚合；③ 违约金与赔偿目的同一应186择一；④ 致固有利益损害转侵权竞合或1203隔离；⑤ 解除与赔偿恒为聚合。本判决规则供给模拟法庭法官 skill 作竞合类案正向指引。
