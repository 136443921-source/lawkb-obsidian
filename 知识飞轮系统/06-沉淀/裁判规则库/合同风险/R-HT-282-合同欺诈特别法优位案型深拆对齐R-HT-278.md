# 一、争点定位与请求权基础

同一欺诈行为（如故意隐瞒标的物重大瑕疵）同时该当**合同欺诈**（民法典第148条可撤销＋第157条返还赔偿＋第500条缔约过失）与**侵权欺诈**（第1165条），本卡是 R-HT-278（法条竞合排斥型）的**专题落点**：因合同法为特别规定（第11条优位），属**法条竞合（排斥型）**，仅适用合同法，**不进第186条择一、非聚合**。这正是 R-HT-278 所述"合同欺诈按186错"的正解。

# 二、鉴定式审查框架（对齐 R-HT-279 步骤A 位阶测试）

1. **是否存在欺诈行为＋意思表示瑕疵**（缔约阶段）？
   - 否 → 非本卡范围，转加害给付（R-HT-281）或一般违约。
2. **同一欺诈是否同时该当合同法（148/157/500）与侵权法（1165）**？
   - 是 → 进行位阶测试（R-HT-279 步骤A）：
     - 合同欺诈（特别规定）vs 侵权欺诈（一般规定）→ **特别—一般关系** → 第11条特别法优位 → **法条竞合（排斥型）** → **仅合同法路径**（撤销＋返还＋过错赔偿），**不适用第186条**、**非聚合**。
3. **欺诈致损是否超出合同范围（纯固有利益侵权后果）**？
   - 若欺诈同时造成合同履行利益之外的独立侵权损害（如虚假宣传致健康损害），该独立侵权部分可另依第1165条主张，但意思表示瑕疵部分仍仅合同法撤销——两路径**目的各异**时方可能聚合（罕见，须个案判断）。

# 三、构成要件与举证

- **合同欺诈撤销四要件**：①欺诈行为（故意告知虚假情况/故意隐瞒真实情况）；②欺诈故意；③因果关系（相对方陷于错误，且因错误为意思表示）；④意思表示不自由。
- **法律后果**：第157条（撤销后返还财产＋折价补偿＋过错方赔偿损失）；第500条（缔约过失赔偿责任，发生于合同不成立/无效/被撤销时）。
- **举证**：原告证欺诈行为＋故意＋因果；被告可证"未隐瞒/已如实告知"或"原告明知"抗辩。撤销权除斥期间另依法律规定（本地源未引，引用前核民法典第152条）。

# 四、法条依据（权威源回填，非凭记忆）

- **民法典第11条**（特别法优位·位阶测试支点）：其他法律对民事关系有特别规定的，依照其规定。
- **民法典第148条**（欺诈可撤销·特别法路径核心）：一方以欺诈手段，使对方在违背真实意思的情况下实施的民事法律行为，受欺诈方有权请求人民法院或者仲裁机构予以撤销。
- **民法典第157条**（被撤销法律后果）：民事法律行为无效、被撤销或者确定不发生效力后，行为人因该行为取得的财产，应当予以返还；不能返还或者没有必要返还的，应当折价补偿。有过错的一方应当赔偿对方由此所受到的损失……
- **民法典第500条**（缔约过失·故意隐瞒/虚假情况）：当事人在订立合同过程中有下列情形之一，造成对方损失的，应当承担赔偿责任：（一）假借订立合同，恶意进行磋商；（二）故意隐瞒与订立合同有关的重要事实或者提供虚假情况……
- **民法典第1165条**（侵权请求权基础·被排斥的一般规定）：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
- ⚠️ **statute_text_pending**：消费者权益保护法第55条（经营者欺诈惩罚性赔偿）、民法典第152条（撤销权除斥期间）本地库未收录，本案型仅定性，不硬引外部条号，守本地源铁律；正式引用前须法宝/元典二次核对。

# 五、抗辩与但书

- **合同欺诈 ≠ 加害给付**：欺诈是**缔约阶段**意思表示瑕疵（本卡）；加害给付是**履行阶段**瑕疵致固有利益损害（R-HT-281）。二者都可能与侵权交叉，但定位不同：欺诈的侵权交叉属**排斥型**（特别法优位，本卡）；加害给付的侵权交叉属**186竞合择一**（R-HT-281→R-HT-237）。
- **排斥型不进186**：合同欺诈即便致损害，也仅合同法撤销＋赔偿，**不得**按第186条"违约/侵权择一"起诉（那是加害给付路径）。
- **撤销 ≠ 违约**：合同被撤销后自始无效，不能并行主张"违约责任"，只能依第157条/第500条主张返还与损害赔偿。
- **独立侵权部分例外**：若欺诈同时造成合同外的纯侵权损害，该部分可另依1165条，但须证明目的各异，否则仍受排斥型约束。

# 六、翻车标本（负向拦截·HIR）

1. **合同欺诈按186择一**：以欺诈诉"违约或侵权择一" → 错，应依第148条撤销＋第157条赔偿（排斥型，对齐 R-HT-278）。
2. **混淆欺诈与加害给付**：以次充好既诉欺诈撤销又诉违约赔偿，未区分"虚假陈述（本卡）"与"交付物瑕疵致损（R-HT-281）" → 请求权基础错乱。
3. **撤销后另诉违约**：合同已撤销自始无效，仍主张"违约责任" → 错，应转第157条/第500条损害赔偿。
4. **忽略独立侵权例外**：欺诈同时致健康损害却仅走撤销，漏列纯侵权部分（若目的各异）→ 漏诉请。
