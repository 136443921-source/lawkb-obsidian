# 合同效力瑕疵认定——违反效力性强制性规定或公序良俗的合同无效

> 来源核验：IMA「合同文书AI助手」→ 合同裁判案例《【人民法院案例库】关于确认合同效力的40个裁判要旨》（简法时光，2025-08-19）全文取回；内容直接引自人民法院案例库，属权威源。`source_verified:true`（IMA 权威源全文取回）。

## 一、核心要旨

1. **效力性强制性规定 / 公序良俗 → 无效**（《民法典》第153条）：合同违反法律、行政法规的**效力性**强制性规定，或违背公序良俗的，无效。
2. **违反行政规章一般不必然无效，但有例外**：规章内容涉及金融安全、市场秩序、国家宏观政策等公序良俗，经考察规范对象、监管强度、交易安全保护、社会影响等因素，认定合同存在违反国家监管政策且破坏公共秩序的，应当认定无效（案例要旨26：(2020)京03民终13370号）。
3. **恶意串通损害国家/他人利益 → 无效**（《民法典》第154条）：第三人与债务人恶意串通转移财产、逃避债务，损害债权人利益的，相关合同无效；财产无法返还时可依侵权责任判令第三人承担连带赔偿（要旨14、36）。
4. **虚假意思表示 → 无效**（《民法典》第146条）：以技术开发合作为名骗取政府专项经费、作虚假意思表示的，构成恶意串通损害国家利益，技术开发合同无效并移送犯罪线索（要旨07）。

## 二、权威依据

- 《民法典》第153条（原《合同法》第52条第5项）：效力性强制性规定 / 公序良俗。
- 《民法典》第154条：恶意串通损害他人合法权益无效。
- 《民法典》第146条：虚假意思表示无效。
- 《九民纪要》第30、31条：强制性规定的识别（效力性 vs 管理性）、违反规章是否违背公序良俗的认定。

## 三、实务锚点

- **6658 吊顶案 / 6660 雅菲窗帘案**：相对人若以"违反法律强制性规定"主张合同无效，须精准识别该规定是否属**效力性**强制性规定；仅违反管理性规定或行政规章的，不当然无效——这是被告审查原告"合同无效"抗辩边界的关键。
- **冒名/虚假署名（6658）**：起诉状署名"丁茂祥"与营业执照"丁戊祥"不一致，涉及意思表示真实性（民法典143），与本条"虚假意思表示无效"形成攻防呼应。
- **抗辩要点**：主张合同无效一方负有举证该规定为效力性强制规定或违背公序良俗的责任；法院对"违反规章即无效"持审慎态度。
