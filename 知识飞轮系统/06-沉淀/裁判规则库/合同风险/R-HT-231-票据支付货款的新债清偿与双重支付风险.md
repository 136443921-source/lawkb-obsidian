# 核心要旨

当事人约定以票据支付买卖合同货款的，买受人的货款支付义务**并非于票据背书转让之时即告完成**，而于持票人**实际获得承兑后**方履行完毕。

- 以票据支付货款，应推定为**新债清偿（间接给付）**：新债务（票据债务）履行前，原买卖合同的货款债务并未消灭。
- 出卖人将买受人用以支付货款的票据背书转让后，票据**兑付不能**的，出卖人有权**基于买卖合同关系**请求买受人支付货款。
- **防双重支付风险**：为防止买受人面临“既付货款又付票据款”的双重支付，出卖人主张货款前**须成为票据的合法持票人**。

# 关联法条

- 《民法典》第595条（买卖合同定义）、第509条（全面履行）、第577条（违约责任）。
- “新债清偿/间接给付”为司法实践认可的规则（民法典无明文，依诚实信用与合同目的解释）；票据行为另受《票据法》第27条（背书）等规范。
- 注意：旧《合同法》第161条关于支付时间的规定已被《民法典》第628条吸收，引用时注明现行条文。

# 适用场景

- **雅菲软装窗帘案（2026黔0330民初6660号）**：被告若以“已付货款/已背书票据”抗辩货款已清，须审查该支付是否构成有效清偿——新债清偿下原债务未消灭直至新债务实际履行；票据未承兑的，出卖人仍可主张买卖价款。
- 买卖合同中“以票代款”条款的起草风险提示：应明确约定票据兑付不能时的回退救济与利息责任。
