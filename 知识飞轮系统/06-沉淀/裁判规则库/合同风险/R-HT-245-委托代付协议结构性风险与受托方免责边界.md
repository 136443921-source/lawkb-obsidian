# 核心要旨

委托代付是三方结构（委托方甲／受托方乙／收款方丙），本质是"请人代管付款事务"，与债务转移、第三人代为履行均不同：

- **受托方非债务人**：乙方仅接受委托办理付款手续，不因签署/履行本协议成为原合同（甲丙之间）债务人，不承接甲方其他合同义务；甲乙间代付资金关系属内部法律关系，不对丙方产生约束力。
- **代付完成以"实际足额到账"为准**：自丙方实际足额收到款项之日起，视为甲方已完整履行原合同对应金额付款/还款义务；丙方须按原合同开具发票/收据。
- **账户变更须丙方书面公章通知为唯一依据**：丙方需变更收款账户的，应至少提前 3 个工作日向甲、乙发送加盖丙方公章的书面变更通知；未出具者，乙方向约定账户完成付款即视为适当履行，错付风险由丙方自担。
- **受托方无实质审查义务**：乙方无义务审查甲丙基础交易真实性、合法性；因甲方资金不到位、丙方账户异常、银行清算/监管故障等不可归责乙方事由致付款逾期/失败/退回的，乙方不担违约责任，仅负 3 个工作日内通知义务。
- **资金退回**：乙方完成代付后仅负及时通知甲方义务，退回后再安排、再付款由甲方负责与丙方协商。

# 适用场景

- **至善公司52%股权转让方案**：向黔北/李悦分期支付转让款若由关联方代付，须以本协议结构明确"代付≠债务承接"，并锁定收款账户书面变更程序，避免代付方被追索原合同义务。
- **航合物流款项代付**：事故处置/赔偿款若经第三方代付，须约定"到账视为委托方履约"，并隔离代付方与原债务。
