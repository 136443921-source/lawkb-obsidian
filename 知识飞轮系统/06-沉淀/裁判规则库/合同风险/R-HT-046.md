# R-HT-046 合同解除意思表示 + 主播违约违约金酌减

## 规则表述

1. **解除权行使方式**：违约方以对方履约瑕疵抗辩解除合同的，解除意思须以法定或约定方式**明确无误地向相对方发出**；仅在微博等公开平台"官宣"或直接至竞争方履约的行为，不能认定为向相对方发出明确解除通知，解除主张不成立。
2. **违约金酌减尺度**：约定违约金过高请求酌减的，以实际损失为基础，兼顾履行情况、当事人过错程度及预期利益，依公平与诚信原则衡量；**网络直播行业**平台前期投入大、主播违约损失难量化，不宜对平台苛以过重的损失举证负担，应综合主播人气收益、合同剩余履行期、双方过错等酌情裁量。

## 要件

- 解除：须存在有效合同 + 解除权事由 + **向相对方明确发出**解除意思（公开表态≠通知）。
- 酌减：须当事人主动请求 + 以实际损失为锚 + 行业特点与公平诚信加权。

## 适用要点（攻防）

- **攻（违约方/平台）**：主张解除须确保通知到达相对方；违约金抗辩应主动请求酌减并提交平台投入、行业基准证据。
- **防（守约方）**：在合同中约定解除通知的送达方式与违约方不得单方中止的条款；主张违约金时预先准备"恶意/损失"证据以对抗酌减。
- **体系位置**：与 R-HT-045（和解违约金违信不调减·指导案例166号）构成"不调减 vs 酌减"对照；二者共同框定违约金裁量两端。
