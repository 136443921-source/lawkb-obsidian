## 规则表述

来源：贵州省高级人民法院《商品房买卖合同纠纷案件审判要件指南》（2025年）。以下为对贵州辖区案件具有直接指引效力的核心裁判要件。

### 一、总原则：鼓励交易，收窄无效路径

区分**效力性强制规定与管理性强制规定**，违反房地产市场**管理性**强制规定的，**一般不能认定合同无效**。战术推论：在贵州，主张"合同无效 + 返还"路径普遍收窄，"合同有效 + 违约责任"路径被系统性拓宽。

### 二、合同订立

1. **销售广告构成要约的三要件（须同时满足）**：①限于出卖人**开发规划范围内**的房屋及设施（周边学校、医院、地铁的渲染不构成要约）；②**明确具体、可特定化、无歧义**（"理想居所""名牌电梯""高档瓷砖"不构成；"绿化率40%""容积率2.0""日本原装三菱电梯"构成）；③对合同订立或房价确定有重大影响。**宣传册注明"不构成要约"或合同约定宣传资料仅供参考的，一般不认定为要约**。
2. **预约转本约的两要件（须同时满足）**：①**内容完整性**——一般应具备《商品房销售管理办法》第16条规定的主要内容，但欠缺内容不属主要权利义务、不影响正常履行、或可经条款解释与漏洞填补者不影响完整性认定；②**实际履行行为**——出卖人**已按约定收受购房款**（全款或部分款、一次性/分期/贷款方式均可）。
3. **预约违约的责任边界**：守约方**无权要求交款交房**（属本约义务），只能适用定金罚则或其他违约责任；**司法不能强制缔约，不得判决签订本约**。
4. **预约与本约冲突**：以本约为准；预约有而本约无的内容不能直接适用，但可作为解释本约真实意思的证据。

### 三、合同效力：一般无效 + 例外救活

- 欠缺**书面形式**不影响合同效力（书面要求系与备案制度配套的行政管理目的）。
- **预售许可证明**：是预售合同有效必要条件，但**不是预约合同**生效条件；许可**失效**（撤销、期满未延续）与自始未取得不同，**不必然导致无效**且不构成欺诈；未取得但**已达办理条件**的，出卖人恶意反悔阻止条件成就，**不支持其确认无效**；未取得但房屋**已竣工验收合格转化为现售**的，**可认定有效**。
- **备案登记**不是生效要件，不影响效力。
- **阴阳合同**：虚假价格条款**无效**，按真实交易价格确定权利义务，**买卖合同整体有效**。
- **首付贷**（出卖人/中介垫付首付的借款合同）**无效**。

### 四、合同履行（三条最具杠杆的规则）

1. **交付的最低条件 = 房屋已竣工验收合格 + 出卖人已通知交付**。合同无明确约定按此认定；约定高于最低条件的，不符合约定买受人有权拒收。仅以未提供《住宅质量保证书》《住宅使用说明书》拒收的**一般不予支持**。
2. **诉讼时效的"占有分水岭"**：
   - 请求交房：未取得产权 → **债权请求权，适用时效**（自约定交付期限届满之日；届满时不具备交付条件的自知道或应当知道满足交付条件之日起算）；已取得产权后请求交房 → **物权请求权，不适用时效**。
   - 请求协助办证：买受人**未占有** → 债权请求权，适用时效；买受人**已占有** → 基于**事实物权地位，不适用诉讼时效**。
3. **抗辩权配置**：物业费、住宅专项维修资金缴纳义务与出卖人交房、协助办证义务**分属不同法律关系**，出卖人**不得**以此拒绝交房或办证；但合同约定买受人付款义务先于或同时于交房/办证义务时，出卖人可提同时履行抗辩，法院可作**同时履行判决**。
4. **多重买卖顺序**：过户登记 > 预告登记（有效期内）> 先接收房屋 > 已受理转移登记申请。**恶意抢先办理转移登记或预告登记者，不能优先于已合法占有房屋的买受人**。
5. **解除权限制**：采"违约方的违约程度是否显著轻微，是否影响守约方合同目的实现"实质审查标准。**出险项目中出卖人虽资金困难但仍尽力组织施工、政府正在纾困的，可认定解除条件不成就，不宜判决解除**，买受人转由逾期交房违约责任获偿。

### 五、违约责任（四条硬规则）

1. **逾期交房与逾期办证违约金不重合计算**：房屋长期未竣工验收而同时逾期交房与逾期办证，系**同一违约行为引发两个结果**，同一违约行为不得承担双重违约责任。**逾期办证违约期间起算 = 实际交付之次日 + 合同约定的交房至办证间隔期；合同未约定间隔期的，加 90 日**。
2. **违约金标准与调整**：无约定计算方法时，买受人逾期付款违约金参照**贷款利息标准**，出卖人逾期交房违约金参照**同地段同类房屋租金标准**（买受人主张按银行按揭贷款利息计算的倾向不予支持）。调整须由出卖人**通过反诉或抗辩**提出；出卖人仅抗辩不构成违约而未主张调减的，**法院应释明**。政策导向为"**逾期交房保业主居住权、逾期办证保市场主体**"，以补偿性为主惩罚性为辅，避免"一刀切"固定比例。
3. **违约金请求权时效**：约定固定金额的自履行期限届满之日起算；约定按日/按月以已交房价款为基数计算的，属**继续性债权，以每个个别债权分别适用诉讼时效**，保护范围为**起诉之日倒推 3 年**。
4. **双重排除惩罚性赔偿**：商品房作为不动产、特殊商品，**不属《消费者权益保护法》第55条"退一赔三"适用范围**；2020年修正已删除原解释关于一房二卖、先卖后抵"已付购房款一倍"赔偿的规定，**不应再适用"退一赔一"**。欺诈情形通过违约责任处理。
5. 合同无效或解除返还财产**包括已付购房款及利息**（本金为原物、利息为法定孳息，随原物转移）。买受人主张国家购房政策性优惠损失的**不予支持**（订约时无法预见）。

### 六、《商品房消费者权利保护批复》适用（保交楼语境王牌）

1. **消费者认定**：①一般应为**自然人**（法人购房用于安置或分配职工居住的，被安置人/职工可认定）；②房屋须为**商品房**（不含存量房、经济适用房、自建房、单位集资房）；③**以居住为目的**的住房类商品房或具居住属性的商住两用房（门面、商铺、写字楼，或为经营牟利购买住房的不认定）。数量口径延续"特定区域内名下只有一套房屋，或已有一套但所购房屋面积上仍属基本满足居住需要"。**别墅**：买受人经常居住地与别墅所在地不一致的，一般认定为度假用途，不宜认定"以居住为目的"。
2. **以房抵债受让人一般不属消费者**（目的系实现债权而非居住）。例外两类：①正常市场交易模式下的抵债房买受人（购房款付给抵债债权人，但**与出卖人签合同或出卖人出具收款收据**）；②抵债房买受人系债权人**自己或亲属**且有实际购房需求。**工抵房受让人**若原符合建设工程价款优先受偿权行使条件，**即便不符合"居住目的"，其顺位亦优先于抵押权及其他债权**。
3. **交付请求权要件**：以居住为目的 + **已支付全部价款，或在一审法庭辩论终结前已实际支付剩余价款**。"已付全部价款"含：一次性付清；只付首付但**银行已将贷款支付给出卖人**；房企以房抵债且符合合法有效以房抵债情形。
4. **优先权顺位**：商品房消费者的**房屋交付请求权、价款返还请求权优先于建设工程价款优先受偿权、抵押权以及其他债权**。
5. **返还范围**：房屋不能交付且无实际交付可能，买受人请求解除买卖合同**和按揭贷款合同**应予支持；判令出卖人将购房贷款返还**商业银行**，将买受人所付购房款**本金及利息**返还买受人。当前形势下"不能交付且无实际交付可能"应从严把握，不宜一律解除返款。

## 实务要点

- **代理买受人**：①不打无效打违约；②**抢占并证明"已实际占有"**——办证请求权即不受 3 年时效限制；③按日计算的违约金属继续性债权、倒推 3 年，故**必须尽早立案**；④保交楼案件主攻"消费者身份 + 优先顺位"，注意"在一审法庭辩论终结前补足尾款"是**可主动创造的要件**；⑤翻查宣传中的量化承诺（绿化率/容积率/品牌型号）主张构成要约。
- **代理出卖人**：①宣传免责声明前置 + 合同重申"宣传资料仅供参考"；②认购书留白关键条款且**不收购房款**（改收意向金）以保"预约"定性；③交付条件仅写法定最低线；④将买受人付款义务约定为先于/同时于交房办证义务以锁定同时履行抗辩；⑤出险项目保留"仍尽力施工 + 政府纾困"证据链阻却解除；⑥违约金调减必须以**反诉或明确抗辩**提出，并举证同地段同类房屋租金；⑦坚决主张逾期交房与逾期办证不重合计算、排除惩罚性赔偿。
- **必写合同条款**：交房至办证的**间隔期**（否则强制适用 90 日）；样板房与实际交付差异的**书面说明**（否则强制一致）。
