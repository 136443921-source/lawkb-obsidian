# 一、争点定位与请求权基础

当事人一方违约，且该违约行为同时侵害对方人身权益或财产权益（典型：加害给付／积极侵害债权——如买卖机器爆炸致买受人受伤、保管物毁损致寄存人其他财产损毁），此时：

- 违约请求权基础：民法典第577条；
- 侵权请求权基础：民法典第1165条；
- 二者并存 → 进入民法典第186条「择一行使」分野。

# 二、鉴定式审查框架（审查要点）

1. **产生**：
   - 违约请求权（第577条）：违约行为（不履行/不适当履行）+ 损害；
   - 侵权请求权（第1165条）：侵害民事权益 + 过错 + 因果关系 + 损害；
   - 同一违约事实同时满足两基础 → 竞合产生。
2. **竞合识别**：两请求权给付目的同一（填补同一损害）→ 请求权竞合。
3. **法律效果（第186条）**：受损害方**有权选择**请求违约责任或侵权责任。
4. **消灭/可行使**：选定并获完全满足后，另一请求权消灭；选定前可变更（一审法庭辩论终结前）。

# 三、构成要件与举证

**第186条自身三要件**：

- 当事人一方有**违约行为**（违反合同义务）；
- 该违约行为**损害对方人身权益或财产权益**（侵权要件同时具备）；
- → 受损害方取得**选择权**（择一）。

**举证分野（关键实务差异）**：

- 违约路径（第577条）：采**严格责任**，原告只需证明违约行为+损害，过错非要件；
- 侵权路径（第1165条）：一般**过错责任**，原告须证明过错（产品/机动车/环境/高度危险等适用过错推定或无过错除外）。

# 四、法条依据（权威源回填）

- 民法典第186条：因当事人一方的违约行为，损害对方人身权益、财产权益的，受损害方有权选择请求其承担违约责任或者侵权责任。
- 民法典第577条：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。
- 民法典第1165条：行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
- 民法典第996条（例外聚合）：因当事人一方的违约行为，损害对方人格权并造成严重精神损害，受损害方选择请求其承担违约责任的，不影响受损害方请求精神损害赔偿。

# 五、抗辩与但书

- **第996条例外**：若违约同时损害人格权并造成严重精神损害，选择违约责任的，**不影响**请求精神损害赔偿（打破择一，转为聚合）。
- **约定/法定排除**：当事人约定排除竞合、或法律另有规定（如第1203条产品责任属不真正连带）的，不适用第186条择一。
- **选定拘束力**：学说与实务——受害方起诉时应明确请求权基础（案由）；一审法庭辩论终结前可变更；选定获满足后另一请求权消灭。
- **典型场景**：加害给付（瑕疵履行致加害）是第186条最高频适用场域；纯给付不能/迟延未致固有利益损害者，仅成立违约，不生竞合。

# 六、翻车标本（HIR）

1. **误当聚合双倍索赔**：在第186条情形下并列主张违约+侵权要求双倍赔偿 → 违反择一，法院责令择一、超额部分驳回。
2. **漏列第996条精神损害**：人格权严重受损仅按违约起诉 → 违约路径精神损害一般不被支持，丧失第996条并行救济机会。
3. **错把法条竞合当第186条竞合**：合同欺诈案按第186条择一，忽略特别法优位（合同欺诈优先）→ 请求权基础/案由错位。
