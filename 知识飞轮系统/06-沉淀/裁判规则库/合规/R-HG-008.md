# R-HG-008 病历书写行政责任处罚阶梯与依法执业自查

## 规则

病历书写违规的行政处罚以《医疗纠纷预防和处理条例》第47条为轴，依情节分阶梯：

1. **一般违规**（未按规定填写/保管病历、未补记抢救病历等）：警告 + 1万—5万罚款；
2. **从轻**（初次/轻微/配合调查/已和解退赔、未落实核心制度1—6项）：警告 + 1万（下限）至 2万；
3. **合并重罚**（使用非卫生技术人员 + 病历管理缺失）：人员罚 + 制度罚合并，实务可达 8.5万；
4. **情节严重**：责令暂停执业1—6月 / 降级撤职；构成犯罪的追究刑事责任。

规范依据另含《病历书写基本规范》第3条（六性：客观真实准确及时完整规范）、第14条（门急诊病历就诊时完成）、《医疗质量管理办法》第17/23条、《医疗质量安全核心制度要点》"病历管理制度"（修改留痕可追溯）。

## 适用要点（攻防）

- **蓝队（医疗机构顾问）**：依法执业自查闭环——病历时效、六性底线、电子病历留痕、告知归档、核心制度逐项留证、禁用非卫生技术人员；
- **红队（监管/患方）**：以"未填写/保管病历"触发47条行政处罚，并向民事过错推定（1222）传导。

## 实务提示

- 2026年多地真实处罚已常态化（南县医院8.5万、烟台/常德/商丘多家警告+1万），印证"病历无小事"；
- 厚德基金会涉医疗公益（义诊/义诊备案）须同步适用诊所备案制与病历规范，衔接 [[R-HG-002]]。
