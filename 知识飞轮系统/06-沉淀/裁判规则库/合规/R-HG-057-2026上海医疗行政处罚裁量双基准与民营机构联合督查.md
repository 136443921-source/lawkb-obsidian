# R-HG-057｜2026-08-01 上海医疗行政处罚裁量"双基准"施行与民营机构三部门联合督查新态势

## 规则要旨

自 **2026-08-01** 起（有效期至 2031-07-31），《上海市医疗机构行政处罚裁量权基准》与《上海市医师行政处罚裁量权基准》同步施行，形成**机构侧 4 项 + 医师侧 15 项**违法行为清单。两项基准的修订方向与《医师法》（2022-03-01 施行）、2022 年修订《医疗机构管理条例》（诊所由审批制改**备案制**）相衔接，并将 **"违反诊疗规范实施不必要的检查、治疗造成不良后果"** 首次明确列为医师违法行为——**中医理疗、调理类服务（含疗效承诺型协议）由此落入直接监管射程**。

民营医疗机构同步面临 **卫健 + 市场监管 + 医保** 三部门联合督查（联合部署、联合排查、联合执法、联合惩戒），重点覆盖**依法执业、医疗质量安全、医保基金使用、价格收费、广告宣传**五域。

## 适用范围

- 医疗机构 / 医师行政处罚风险评估与合规整改
- 民营医院、门诊部、诊所（含中医诊所、医疗美容机构）专项督查应对
- 医疗服务协议（含疗效承诺条款）合规审查的行政法依据

## 关联法条

- 《医师法》（2022-03-01 施行）第56条（医师罚则，本轮新增违法行为的底层义务条款；**现行有效**，援引前须核条内款项序号）
- 《医疗机构管理条例》（2022 年修订，诊所改备案制）
- 《基本医疗卫生与健康促进法》第101条（医疗质量安全管理制度不健全等罚则，**现行有效**）
- 《基本医疗卫生与健康促进法》（无证执业、出卖/转让/出借《医疗机构执业许可证》的处罚依据）
- 《医疗保障基金使用监督管理条例》及其实施细则（医保基金使用域）
- 《行政处罚法》（裁量权基准制定依据）

## 实务要点

### 一、机构侧基准：4 项违法行为的结构性变化
| 变化 | 内容 |
|---|---|
| **新增** | 诊所**未经备案执业**（衔接诊所审批改备案） |
| **扩展** | "诊疗活动超出登记范围" → **"超出登记或者备案范围"**，备案制诊所纳入 |
| **删除** | 未取得《医疗机构执业许可证》擅自执业；出卖、转让、出借许可证 → 改依《基本医疗卫生与健康促进法》处罚，适用其专门裁量基准 |
| **删除** | "逾期不校验《医疗机构执业许可证》仍从事诊疗活动"（无裁量空间） |
| **定义** | "**禁止类技术**"＝安全性/有效性不确切、存在重大伦理问题、已被临床淘汰、未经临床研究论证的医疗新技术 |
| **定义** | "**造成危害后果**"包括但不限于对患者造成伤害、**对用人单位等相关单位造成经济损失** |

### 二、医师侧基准：15 项违法行为，四大变化
1. **新增 2 项**（与《医师法》衔接）：
   - **违反诊疗规范，对患者实施不必要的检查、治疗造成不良后果** ← **本轮最具实务冲击力**
   - **未按照注册的执业地点、执业类别、执业范围执业**
2. 多因素综合裁量细化（违法行为情形与处罚标准对应关系细化）；
3. **向特殊人群（无/限制行为能力人）实施违法行为的，处罚标准更为严厉**（衔接《未成年人保护法》）；
4. 违法行为 7 增加 **"泄露亡故者个人信息"**（亡故者个人信息同样受保护）。

### 三、裁量技术性规则（易被忽略但直接影响量罚）
- "以上"**不含本数**，"以下"**含本数**；
- "**初次违法**"＝**二年内**未因相同违法行为被卫生健康行政部门处罚；
- "曾因相同违法行为被处罚"＝**二年内**曾受处罚（二年内的界定直接决定是否从重）。

### 四、执法实证：医疗质量安全管理制度不健全可单独处罚
**马卫医罚〔2026〕6号**（马鞍山市卫健委，2026-08-14）：德驭医疗马鞍山总医院因**院外会诊程序管理缺失**，认定"医疗质量安全措施不健全"，依《基本医疗卫生与健康促进法》第101条，结合《安徽省卫生健康行政处罚裁量权基准》"医疗服务管理类"第7条第1处罚阶次，**警告 + 罚款 2 万元**。
→ **启示**：院外会诊、外请专家等"灰色便利操作"已属独立可罚事项，不依附于具体损害后果。

### 五、与在办业务的连接（面瘫针灸调理协议审查）
《禁止疗效承诺与治愈保证》规则卡（2026-08-23）的**民事/广告法层**依据之外，本基准补齐**行政层**依据：
- 疗效承诺 → 广告宣传域（市场监管 + 卫健联合督查重点）+《广告法》；
- 调理类服务若超出备案/登记范围 → "超出登记或者备案范围"；
- 非必要治疗项目 → **"不必要的检查、治疗造成不良后果"**（医师侧新增违法）。
