# R-CF-096 慈善组织捐赠物资计价与捐赠票据开具合规规则

## 一、规则要旨

1. **物资捐赠以书面协议为原则、其他方式达成一致为例外**：捐赠人要求签订书面协议的应当签订；未要求或因重大突发事件应急等特殊情况无法签订的，应当采取适当方式就**种类、数量、质量、用途、交付及双方权利义务**等内容达成一致。
2. **入账价值依《民间非营利组织会计制度》确定**；以公允价值入账的，须按该制度**规定的顺序**确定公允价值，不得自选方法。
3. **捐赠票据以开具为原则、不开具为例外**：应向捐赠人开具财政部门统一监（印）制的捐赠票据；**捐赠人匿名或放弃接受票据的，可以不开具，但应当做好相关记录**。
4. **公允价值确实无法可靠计量时**：可暂不开具票据，但须**设置辅助账单独登记**（名称、数量、来源、用途）并在**会计报表附注披露**，同时向捐赠人出具载明名称、数量的收到证明；后续公允价值能够可靠计量的，应在该期间确认并以公允价值计量。

## 二、八条规范要点（依原文顺序）

| 条 | 要点 | 合规动作 |
|---|---|---|
| 一 | 书面捐赠协议：捐赠人要求签的应当签；未要求或突发事件无法签的，采取适当方式就种类/数量/质量/用途/交付/权利义务达成一致 | 建立《物资捐赠确认单》留痕 |
| 二 | 捐赠物资按《民间非营利组织会计制度》确定入账价值 | 入账口径以制度为准 |
| 三 | 以公允价值入账的，按该制度**规定顺序**确定公允价值 | 禁止自选评估口径 |
| 四 | "市场价格"的认定：取得当日捐赠方自产物资**出厂价** / 捐赠方所销售物资**销售价** / **政府指导价** / **知名大型电商平台同类或类似商品价格**等 | 留存比价截图或报价单 |
| 五 | "合理的计价方法"包括**由第三方机构评估**等 | 大额/特殊物资走评估 |
| 六 | 外币计量按**取得当日市场汇率**折算人民币；汇率波动较小时可用**当期期初汇率** | 折算汇率须留档 |
| 七 | 开具**财政部门统一监（印）制**的捐赠票据；捐赠人匿名或放弃的**可以不开具，但应做好记录** | 匿名捐赠登记台账 |
| 八 | 公允价值确无法可靠计量：可暂不开票，但须**辅助账单独登记** + **报表附注披露** + **出具收到证明（载明名称、数量）**；后可计量时按公允价值确认 | 辅助账 + 附注 + 收物证明三件套 |

## 四、执业要点（厚德基金会适配）

1. **物资捐赠全流程四件套**：书面协议/确认单 → 计价依据（出厂价/销售价/政府指导价/电商比价/评估报告）→ 捐赠票据（或匿名登记记录）→ 辅助账与附注披露。
2. **高风险点**：
   - 无计价依据直接按捐赠人自报价值入账 → 违反第三、四条；
   - 匿名捐赠未做记录 → 违反第七条但书；
   - 公允价值无法计量时"既不开票也不设辅助账" → 两头落空，最易被审计/检查指出。
3. **与免税资格的衔接**：捐赠票据是捐赠人税前扣除的凭证基础，票据开具不规范直接影响捐赠人权益（2020年第27号公告）。
4. 依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》财务与捐赠募捐相关条款，物资捐赠入账与票据管理应纳入内控流程并留存完整证据链。
