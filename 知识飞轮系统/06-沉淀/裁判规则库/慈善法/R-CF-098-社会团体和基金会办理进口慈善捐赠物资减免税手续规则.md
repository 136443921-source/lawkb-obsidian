# R-CF-098 社会团体和基金会办理进口慈善捐赠物资减免税手续规则

## 一、规则要旨

1. **"先资格证明、后海关减免"两阶段**：受赠的社会团体/基金会先向**登记管理的民政部门**申请开具《慈善捐赠物资受赠人资格证明》（下称《证明》），再凭《证明》**正本**向海关办理减免税手续。
2. **民政部门出具《证明》的条件**：符合《慈善捐赠物资免征进口税收暂行办法》（财政部、海关总署、国家税务总局 2015年第102号公告，下称《暂行办法》）第五条第（三）款有关规定的社会团体和基金会，民政部门**应及时出具**。
3. **资格事后丧失的通知义务**：出具《证明》后，有关社会团体或基金会的**评估等级或宗旨不再符合**《暂行办法》规定的，民政部门应**及时通知海关**。
4. **海关审核依据**：海关凭《证明》正本 + 其他规定材料，按**海关总署 2016年第17号公告**审核确认并办理减免税手续。

## 二、操作流程

```
① 境外/境内捐赠人 → 捐赠进口物资
        ↓
② 受赠的社会团体/基金会 → 向登记管理的民政部门申请《慈善捐赠物资受赠人资格证明》
        ↓
③ 民政部门 → 审查评估等级 + 宗旨是否符合《暂行办法》第五条第（三）款 → 出具《证明》
        ↓
④ 海关 → 凭《证明》正本 + 其他规定材料，按海关总署2016年第17号公告审核
        ↓
⑤ 办理减免税手续
        ↓
（后续）评估等级/宗旨不再符合条件 → 民政部门及时通知海关
```

## 三、合规要点

1. **《证明》须用正本**，复印件不办。
2. **资格是动态的**：社会组织评估等级下降或宗旨变更导致不再符合的，民政部门负有主动通知海关的义务 —— 意味着减免税资格并非"一证终身"。
3. **省级民政部门与海关建立联系配合机制**，实务中遇阻可循此路径协调。

## 四、执业要点（厚德基金会适配）

1. 本路径仅适用于**进口**慈善捐赠物资的税收减免，与境内物资捐赠的计价/票据规则（[[R-CF-096-慈善组织捐赠物资计价与捐赠票据开具合规规则|R-CF-096]]）是两套并行规则，不可混用。
2. 基金会若有涉外/进口捐赠项目，须先行自查**评估等级**与**宗旨**是否满足《暂行办法》第五条第（三）款，再启动申请，避免申请被拒或事后被追缴税款。
3. 依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》涉外活动相关条款，进口捐赠物资的资格取得与物资使用应同步留档备查。
