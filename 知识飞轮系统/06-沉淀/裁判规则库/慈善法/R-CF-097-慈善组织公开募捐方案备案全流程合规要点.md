# R-CF-097 慈善组织公开募捐方案备案全流程合规要点

> ⏱ **强时效**：本指引 2025-11-07 印发、**2026-01-01 施行**，系公开募捐备案领域最新操作口径，此前旧口径不再适用。

## 一、规则要旨

1. **备案是开展公开募捐的前置程序**：应在开展募捐活动**十日前**通过"慈善中国"提交材料（《慈善组织公开募捐管理办法》第11条）。
2. **一项一备、一号一用**：每一项公开募捐活动须**单独备案**，不得合并备案，**不得用同一备案编号开展多项公开募捐活动**。
3. **异地募捐双重备案**：以《慈善法》第23条第1款第①项（公共场所设募捐箱）、第②项（义演/义赛/义卖/义展/义拍/慈善晚会）方式在登记管辖区域外开展的，除向登记的民政部门备案外，还须向**募捐活动所在地县级以上民政部门**备案。
4. **应急十日内补办**：为应对重大突发事件无法事前备案的，活动开始后**十日内**补办（《慈善法》第73条）。
5. **变更十日内补正**：募捐方案事项发生变化的，自变化之日起**十日内**补正并说明理由。

## 二、备案要素速查表

| 要素 | 规则 | 依据 |
|---|---|---|
| **适用范围** | 具有公开募捐资格的慈善组织，或其他法律、行政法规规定可公开募捐的非营利性组织 | 指引一 |
| **受理部门** | 县级以上人民政府民政部门 | 指引三 |
| **备案渠道** | 全国慈善信息公开平台 **"慈善中国"** 线上提交 | 指引五 |
| **时间要求** | 活动开展**十日前**提交 | 指引六 / 办法第11条 |
| **办理时限** | 材料齐备的及时受理，**十日内**对予以备案的向社会公开；不齐备的及时告知，组织须**五日内**补齐或撤回 | 指引六 |
| **收费** | **不收费** | 指引七 |
| **文件格式** | 全部为 **PDF 扫描件**，单文件 **≤50MB** | 指引八（六） |

## 三、备案材料清单

**（一）基础材料**
1. 慈善组织公开募捐方案备案表（附件1模板）
2. 慈善组织承诺书（附件2模板）
3. **内部决策文件**：①理事会、理事长办公会等决策会议纪要；②体现逐级呈报审核流程的呈报件或流程单；③其他体现内部决策程序的文件
4. **外部批准材料**：
   - 业务主管单位：盖章/负责人签字圈阅、回函复函等书面意见（有业务主管单位的须报经受权同意）
   - 公安、消防等部门：回函、复函、批复等（涉及公共安全、公共秩序、消防事项）

**（二）合作募捐附加材料**（《慈善法》第26条配套）
1. 对合作方的**评估报告**
2. **合作协议**
3. 合作方为**个人**的：居民身份证等有效身份证件复印件 + **无犯罪记录证明** + **个人信用报告**

**（三）异地募捐附加材料**（第23条第1款①②项方式）
- 募捐方案 + 公开募捐资格证书复印件 + **确有必要在当地开展的情况说明**

## 四、六项备案要求（合规红线）

1. **内部决策要求**：按章程和内部管理制度履行决策程序，形成**经法定代表人书面同意**的决策文件。
2. **外部批准要求**：有业务主管单位的须报经同意；涉公共安全/秩序/消防的另按规履行批准。
3. **单独备案要求**：一项一备，**不得合并、不得一号多用**。
4. **应急备案要求**：突发事件无法事前备案的，活动开始后**十日内补办**。
5. **补正备案要求**：事项变更之日起**十日内补正**并说明理由；有业务主管单位的须报其同意。
6. **格式要求**：PDF 扫描件，≤50MB。

## 五、执业要点（厚德基金会适配）

1. **募捐方案必备内容**（《慈善法》第24条第1款）：募捐目的、起止时间和地域、活动负责人姓名和办公地址、接受捐赠方式、银行账户、受益人、募得款物用途、**募捐成本**、**剩余财产的处理** —— 十项缺一不可。
2. **合作募捐三件套是新增硬约束**：评估报告 + 书面协议 +（个人合作方）无犯罪记录证明与信用报告。基金会以往常只签协议，现须补足评估与资信材料。
3. **内部决策链必须"看得见"**：仅有理事会纪要不够，还须有逐级呈报的呈报件/流程单，且**最终须法定代表人书面同意**。
4. **时间节点台账**：活动前10日备案 → 不齐备5日内补齐 → 变更10日内补正 → 应急活动开始后10日内补办。建议设四个提醒节点。
5. 依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》捐赠募捐与信息公开相关条款，备案材料应同步归档并与"慈善中国"公开内容保持一致。
