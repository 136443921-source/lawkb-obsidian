# 受贿罪·客观方面的审查（行为类型、为他人谋利、收受索取）

## 一、裁判规则
据《贵州法院类案审判要件指南（第一卷）》第一卷第二部分审理思路，本争点裁判规则如下：

（一）受贿行为类型的审查
1 ．一般受贿行为的审查
( 1 ) 通过查明行为人利用职权的方式，为他人谋取利益、提供帮助的
情况，以及收受财物的情况甄别指控的受贿事实，可以分为一般受贿行为
和索贿行为。
( 2 ) 从职权行使的角度看，
一般受贿行为要求国家工作人员利用职务
上的便利进行权钱交易，既包括利用本人职务上主管、负责、承办某项公
共事务的职权，也包括利用职务上有隶属、制约关系的其他国家工作人员
的职权。从谋取利益的角度看，
一般受贿行为为请托人谋取的利益，既包
括正当利益，也包括不正当利益。
2．索贿行为的审查
( 1 ) 要求国家工作人员利用职务便利进行权钱交易，但不以为他人谋
取利益为条件。
( 2 ) 行为人索取财物的时间、地点、次数、方式，接受财物的具体情
况、参与人员等重要事实。
( 3 ) 认定国家工作人员的行为是否构成索贿，不以国家工作人员是否
主动索取财物为充分要件，而应当结合国家工作人员与请托人之间是否存
在权钱交易事实，行贿、受贿双方的主观认知及国家工作人员对请托人行
贿决意的影响程度等综合考量。
( 4 ) 对于行贿、受贿双方事先存在概括性行贿、受贿犯意，即使受贿
人主动提出具体用款事项、数额等情形，一般也不宜认定为索贿行为。

## 二、审查要点
- 依指南列明的关键审查环节，逐项核实在案证据是否形成闭环。
- 区分罪与非罪、此罪与彼罪、既遂与未遂、主犯与从犯的界限。
- 对新型、隐蔽形态坚持实质审查，穿透形式外观认定法律性质。

## 三、构成要件与举证
- 控方（或提请方）须就本争点对应构成要件要素承担举证责任，证据达到确实、充分。
- 辩方（或罪犯方）可就违法性、责任阻却、情节从宽等提出证据与意见。

## 四、法条依据
- 《刑法》第三百八十五条（受贿罪）

> 【受贿罪】国家工作人员利用职务上的便利，索取他人财物的，或者非法收受他人财物，为他人谋取利益的，是受贿罪。
> 国家工作人员在经济往来中，违反国家规定，收受各种名义的回扣、手续费，归个人所有的，以受贿论处。

## 五、抗辩与但书
客观方面审查受贿行为类型（索取/收受）、‘为他人谋取利益’（承诺即可，无须实际谋利）、收受或索取财物事实、特殊情节及共同受贿中客观行为分工。

## 六、翻车标本（常见误判）
将‘承诺谋利’要求拔高为‘实际谋利’；未审查谋利与受财的对价关系。
