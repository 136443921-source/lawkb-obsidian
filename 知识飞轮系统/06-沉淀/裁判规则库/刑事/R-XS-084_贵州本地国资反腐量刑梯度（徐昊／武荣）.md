# 贵州本地国资反腐量刑梯度（徐昊 2026-10-28 / 武荣 2026-10-29）

## 规则要点
1. **徐昊（黔南中院 10-28）**：原云上贵州大数据董事长，2009—2025 年利用贵阳市工投董事长、贵阳市副市长、常务副市长、云上贵州董事长等职务便利，为他人在项目承接/土地拍卖/违建处置提供帮助，受贿**2906 万余元（部分未实际取得）**。以受贿罪判**十一年六个月**，罚金 120 万。从轻情节：**受贿未遂 + 如实供述 + 主动交代大部分未掌握事实 + 认罪悔罪 + 积极退赃且全部追缴**；当庭不上诉。
2. **武荣（安顺中院 10-29 宣判）**：犯徇私枉法罪、受贿罪、贪污罪、洗钱罪。

## 实务提示
- 贵州本地国资/政法系统反腐延续高压；"靠企吃企""未实际取得部分认定为未遂"等情节对量刑影响显著。
- 与同期王会民（4.36亿·死缓终身监禁）、杨小伟（3319万·12年）等形成金融/国资领域"倒查"严惩梯度，可据金额与从轻情节预判区间。
