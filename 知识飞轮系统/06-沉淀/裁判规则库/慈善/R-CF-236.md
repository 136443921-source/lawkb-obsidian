# 社会组织关联交易合规四原则与利益输送禁止

## 一、核心要旨

1. **关联交易非天然违规**：合法、合理的关联交易可提升组织运营效率，法律不一概禁止。
2. **合规四原则**（缺一不可）：关联交易须同时满足 **合理必要、公平公允、程序正当、公开透明**。
3. **绝对禁区**：禁止关联方之间通过交易进行**利益输送**，导致公共利益（捐赠财产/公益宗旨）受损。
4. **披露义务**：不仅慈善组织，所有执行《民间非营利组织会计制度》的机构均应披露关联交易相关信息。
5. **治理边界**：理事成员不能分享组织利润（与股东根本不同）；关联交易须回避表决、留痕审批。

## 二、权威依据

- 《慈善法》（2023 修正）：慈善组织关联交易须遵循公开、公平、公正原则，不得损害慈善组织利益（关联董事/理事回避等，具体条款见《慈善法》第十章 信息公示与信用监管及关联交易相关规定）。
- 《民间非营利组织会计制度》：要求关联交易披露。
- **《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易治理章节**：基金会内部关联交易审批、披露、回避的具体操作条款（慈善决策须以此手册为硬约束，引用须至具体条款；本卡撰写时手册具体条款号待现场核填）。

## 三、实务锚点

- 厚德基金会运营：任何与理事/关联方之间的交易（采购、服务、租赁、资金往来）须事前按手册履行**回避 + 审批 + 披露**三步；否则构成利益输送风险，触发行政责任（参见 [[R-CF-230-慈善组织关联交易三要求慈善法14条（2023修正）]] 关联交易三要求）。
- 合规自查：①交易是否合理必要 ②定价是否公允（可比市场价）③是否程序正当（回避表决、会议纪要）④是否公开透明（披露）。
- 与 [[R-CF-230-慈善组织关联交易三要求慈善法14条（2023修正）]]（慈善组织关联交易三要求·慈善法§14）互为补充：本卡偏"四原则 + 利益输送禁区"的实操提炼，[[R-CF-230-慈善组织关联交易三要求慈善法14条（2023修正）]] 偏法条层级。
