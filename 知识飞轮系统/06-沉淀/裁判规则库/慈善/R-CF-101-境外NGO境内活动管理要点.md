# 境外NGO境内活动管理法要点

> **卡型**：规范要点卡｜**编号**：`R-CF-101`｜**建卡日期**：2026-09-04

## 一、规则要旨（正向·怎么用）
境外非政府组织（NGO）在中国境内开展活动，须"登记设立代表机构"或"临时活动备案"二选一，并接受公安机关登记管理、业务主管单位业务指导。未登记且未备案的，一律不得在中国境内开展或变相开展活动，也不得委托、资助境内任何单位和个人开展活动。该法界定了准入、活动规范、便利措施、监管与法律责任，是涉外慈善/公益合作的合规总纲。

## 二、审查要点（操作路径，编号步骤）
1. **主体识别**：确认对方是否为"在境外合法成立的基金会、社会团体、智库机构等非营利、非政府社会组织"（第二条）。
2. **准入路径判断**：拟在华长期活动→申请登记代表机构（第九条、第十二条，60日内决定）；拟短期活动→与中方合作单位合作并备案（第十六条、第十七条，活动前15日备案，期限不超1年）。
3. **业务主管单位**：登记/临时活动须先经业务主管单位同意（第十一、十七条）。
4. **名称与地域**：代表机构须以登记名称在登记业务范围和活动地域内活动；不得设分支机构（第十八、二十八条，国务院另有规定除外）。
5. **资金合规**：境内活动资金限于境外合法来源、境内存款利息、境内合法取得其他资金；不得募捐；须通过备案银行账户管理（第二十一、二十二条）。
6. **年度报告**：代表机构每年1月31日前报上年度工作报告，经业务主管单位意见后3月31日前报登记机关，并接受年检、公开（第三十一、三十二条）。
7. **禁止行为红线**：不得从事/资助营利性活动、政治活动，不得非法从事/资助宗教活动；不得对中方附加违法条件（第五、二十条）。

## 三、构成要件与举证（表格：要件编号/要件名称/要件内容 + 举证责任分配）
| 要件编号 | 要件名称 | 要件内容 |
|---|---|---|
| A1 | 合法成立 | 在境外合法成立的非营利、非政府社会组织 |
| A2 | 准入手续 | 已登记代表机构 或 已备案临时活动（含中方合作单位） |
| A3 | 活动边界 | 在登记/备案的名称、业务范围、活动地域内 |
| A4 | 资金闭环 | 通过备案银行账户管理，专款专用，不募捐 |
| A5 | 禁止事项 | 不从事营利/政治/非法宗教活动，不附加违法条件 |

**举证责任分配**：登记机关/公安机关对违法事实（未登记、超范围、募捐、违法资金）负查明责任；NGO对"已登记/已备案、资金合法来源"负举证（提交登记证书、备案材料、资金来源证明等）。

## 五、抗辩与但书
- 赈灾、救援等紧急情况，临时活动备案时限不受"活动前15日"限制（第十七条第三款）。
- 国务院另有规定的，可设分支机构或发展会员（第十八、二十八条但书）。
- 境外学校、医院、自然与工程技术研究机构/学术组织与境内对应机构交流合作，按国家有关规定办理（第五十三条）。

## 六、翻车标本（负向拦截·HIR）
- **标本1**：某境外基金会未登记代表机构、未备案，直接委托境内公司开展"公益项目"并收付资金 → 依第四十六条第（四）项取缔+没收+对直接责任人员拘留；境内合作方同罚。
- **标本2**：代表机构借活动之名从事政治游说、资助宗教活动 → 依第四十七条吊销登记证书/取缔，直接责任人员15日以下拘留；涉犯罪的追究刑事责任。
- **标本3**：通过未备案账户收付项目资金、向受益人附加违法条件 → 依第四十五条责令停活、没收、情节严重吊销。
