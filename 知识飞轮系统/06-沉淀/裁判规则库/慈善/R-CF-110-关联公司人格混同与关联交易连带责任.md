# 核心要旨

- 关联公司的**人员、业务、财务**等方面交叉或混同，导致各自财产无法区分、丧失独立人格的，构成**人格混同**。
- 人格混同**严重损害债权人利益**的，关联公司相互之间对外部债务承担**连带责任**。

# 关联法条

- 《公司法》第20条第3款（法人人格否认／人格混同连带责任）。
- 《慈善法》第52条（慈善财产不得私分、挪用、截留或侵占）、第99条（关联交易决策回避与信息披露）。
- 《基金会管理条例》关于财产独立与专项使用的规范。

# 适用场景

- **厚德基金会关联交易合规**：基金会与关联方（如理事单位、发起人控制企业、航合物流等）发生交易时，须保持**财产独立、财务分离、决策回避**，留存公允对价与审批记录，防止“财产混同”被类推追责。
- 本卡为**类比警示锚点**（指导案例15号属公司法语境），并非慈善组织直接判例；慈善组织财产独立义务另有《慈善法》第52条等明文依据，二者可相互强化论证。
