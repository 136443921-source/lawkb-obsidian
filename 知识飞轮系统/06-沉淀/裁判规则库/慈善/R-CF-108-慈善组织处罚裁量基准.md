# 慈善组织处罚裁量基准

> **卡型**：规范要点卡｜**编号**：`R-CF-108`｜**建卡日期**：2026-09-04

## 一、规则要旨（正向·怎么用）
民发〔2025〕61号（民政部，2025-11-26，2026-01-01施行）将《慈善法》及其配套规章的弹性处罚幅度细化为五阶次裁量：不予/减轻/从轻/一般/从重处罚，并附《基准表》。仅适用于民政部部本级登记认定的慈善组织（地方可参照）。核心价值：给慈善组织"初违轻微及时改可免罚、主动消除后果可减轻、再犯/妨碍调查可从重"的明确预期，同时限定"不得直接作为处罚法律依据，仅作说理依据"（第十九条）。

## 二、审查要点（操作路径，编号步骤）
1. **适用范围确认**：仅民政部登记认定的慈善组织；慈善信托受托/委托人违规不适用（第二、二十二条）。
2. **裁量阶次识别**：对照第五条《基准表》；未列明事项依原则执行（第五、六条）。
3. **免罚判断**：初违+危害轻微+及时改，或无证主观过错、无危害后果（第八、十三条）。
4. **减轻/从轻情节**：主动消除后果、受胁迫诱骗、主动供述、配合立功（第九、十条）。
5. **从重情节**：情节恶劣后果重、责令后继续、多次、主谋、妨碍调查（第十一条）。
6. **时效**：违法二年内未被发现不予立案；涉生命健康/金融安全有后果延长至五年（第十三条）。
7. **合并执行**：同一违法行为不二罚，多规范罚款取高（第十四、十五条）。

## 三、构成要件与举证（表格）
| 要件编号 | 要件名称 | 要件内容 |
|---|---|---|
| H1 | 适用对象 | 民政部登记认定的慈善组织（不含慈善信托） |
| H2 | 阶次选择 | 不予/减轻/从轻/一般/从重，依《基准表》 |
| H3 | 免罚情形 | 初违轻微及时改、无主观过错、无危害后果 |
| H4 | 从重情形 | 后果重/继续/多次/主谋/妨碍调查 |
| H5 | 追责时效 | 二年（涉生命健康金融安全五年） |

**举证责任分配**：民政部门对违法事实、情节、危害负查明；当事人对已改正、无主观过错、受胁迫等免责/减责情节负举证（第八—十一条）。

## 五、抗辩与但书
- 本基准及《基准表》"不得直接作为行政处罚的法律依据"，仅可在事先告知书/决定书中用于说理（第十九条）。
- 明显不当或适用变化，经部长办公会议审议可调整适用（第二十一条）。

## 六、翻车标本（负向拦截·HIR）
- **标本1**：慈善组织首次未依法公开年报、危害轻微且接到提示后及时补正 → 可不予处罚（第八条）。
- **标本2**：被责令停活后仍继续违法、且提供虚假证据 → 从重处罚（第十一（二）（五））。
- **标本3**：违法事实成立但已超过二年未被发现且无五年例外 → 不予立案（第十三条）。
