# 核心要旨

慈善组织关联交易**并非一律禁止**，但受严格合规约束。本案由锚定**厚德基金会关联交易治理**。

- **《慈善法》第14条两款**：①发起人、主要捐赠人及管理人员**不得利用关联关系损害**慈善组织、受益人利益和社会公共利益；②其与慈善组织发生交易行为的，**不得参与该交易决策**，交易情况**应当向社会公开**。
- **《慈善法》第99条违法责任**：违反第14条造成慈善财产损失的，民政部门**警告→责令限期改正→逾期责令停活整改→一年内再犯或严重情形吊销登记证书并公告**；相关责任人承担民事责任。
- **关联交易10种类型**（天门/湖北民政政策解答）：购售商品、购售资产、提供/接受劳务、担保、提供资金（贷款/股权）、租赁、代理、研发转移、债务结算、支付关键管理人薪酬。
- **🔴 非营利性红线**：以捐赠为名帮助企业从事营利活动、违反公益慈善无偿性/公益性，构成违法。民政部处罚案例（(2019)京行终2321号）：某基金会以捐赠为名帮公司推广养生茶产品，北京高院认定违反非营利性特征及章程宗旨，**行政处罚+诉讼败诉**。
- **合规要点**：①交易须**回避决策**（关联人退出表决）；②交易情况**信息公开**；③不得附"利益回报"条件（否则取消税前扣除资格）；④捐赠人指定特定个人受益（违背不特定公众原则）亦违规。

# 关联法条（本地源核验）

- 《中华人民共和国慈善法》（2023修正）第14条（关联交易两款）、第99条（违法责任）。
- 《基金会管理条例》第20–24条（理事会决策、负责人职责）。
- 《关于公益性捐赠税前扣除有关事项的公告》（附加利益回报→取消税前扣除资格）。
- **内规引用**：依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易治理相关条款——基金会与关联方交易须经理事会非关联成员过半数同意、交易信息公开、禁止为关联方谋取不正当利益。

# 权威案例（公开司法源·待回源入库编号）

- **(2019)京行终2321号（北京市高级人民法院）**：基金会以捐赠为名帮企业推广产品，违反公益慈善无偿性、公益性、非营利性，亦违反章程宗旨和业务范围；行政机关处罚、法院维持。
- **民政部民罚字〔2017〕14号等**：超业务范围活动、未妥善保管捐赠财产（养生茶过期损失36万）等处罚先例。

# 办案衔接

- 厚德基金会任何与发起人/理事/管理人员的交易（采购、服务、租赁、劳务），须走**回避决策+信息公开**双程序，留存理事会决议与公示记录。
- 接受捐赠时不得附加企业宣传/产品销售等利益回报条件，否则触发《慈善法》第99条+税前扣除资格取消风险。
