# R-CF-180 慈善组织关联交易的"决策回避+信息公开"双义务及违法责任

## 裁判规则

1. **禁止不当关联交易，不禁止正当关联交易**：慈善组织的发起人、主要捐赠人以及管理人员，不得利用其关联关系损害慈善组织、受益人的利益和社会公共利益（前提性禁止）。
2. **决策回避义务**：上述主体与慈善组织发生交易行为的，**不得参与慈善组织有关该交易行为的决策**。
3. **信息公开义务**：有关交易情况**应当向社会公开**，接受公众监督。
4. **违法后果（阶梯式行政处罚）**：违反前述规定造成慈善财产损失的，由民政部门予以**警告、责令限期改正**；逾期不改正的，**责令限期停止活动并进行整改**；经依法处理后一年内再出现违反情形，或有其他情节严重情形的，**吊销登记证书并予以公告**；对直接负责的主管人员和其他直接责任人员处二万元以上二十万元以下罚款（慈善法第99/110/112条，2023修正）。

## 法条依据（本地缓存回填，非凭记忆）

- 《慈善法》(2023修正)第14条：关联交易禁止损害 + 决策回避 + 信息公开（双义务）。
- 《慈善法》(2023修正)第110条：违反第14条造成财产损失的，警告/责令限期改正；逾期停止活动整改；一年再犯或情节严重吊销登记。
- 《慈善法》(2023修正)第112条：对直接负责的主管人员和其他直接责任人员的罚款(2万–20万)及任职禁止(1–5年)。

## 实务要点（贴合厚德基金会合规服务）

1. **正当关联交易可为之，但须"回避+公开"双到位**：向理事单位公司股权投资、采购、租赁、担保等均属关联交易范围，程序合规即合法。
2. **决策回避是硬红线**：关联董事/理事须在关联交易议题表决时回避，会议记录须留存回避证据；未回避即构成程序违法。
3. **信息公开须留痕**：交易情况应载入年度工作报告与信息公开载体，接受社会监督；仅内部决策未公开仍属违规。
4. **内规衔接**：依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易治理条款（具体条号待交付前与原文逐条核对）落实"关联方清单+回避表决+交易披露"三件套。
