# 慈善组织负责人忠实义务与关联交易刑事风险边界（R-CF-127）

> 涉慈善决策依据：《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易与利益冲突相关条款。

## 裁判规则 / 合规要点

1. **忠实义务的制定法源头**：《慈善法》（2023修正）第14条——慈善组织的发起人、主要捐赠人以及管理人员，不得利用其关联关系损害慈善组织、受益人的利益和社会公共利益；与慈善组织发生交易行为的，不得参与有关该交易行为的决策，有关交易情况应当向社会公开。
2. **关联交易的"双护栏"**：① 决策回避（关联理事/关键管理人主动回避表决）；② 信息公开（交易情况向社会公开 + 会计报表附注披露）。
3. **禁止性情形（自我交易红线）**：以高于/低于公允价值与关联方交易、委托关联方投资收益率明显偏低、为关联方提供担保、无偿或明显低收益拆借资金给关联方等，均属损害基金会利益。
4. **刑事风险边界（背信/滥用职权类）**：负责人违背忠实义务，利用职务便利操纵基金会从事不正当关联交易、致使基金会利益遭受重大损失的，可能构成失职罪或滥用职权类犯罪；若以基金会项目为幌子向社会公众集资且未用于公益，可能构成集资诈骗罪（如慈孝特困老人救助基金会理事长韩学臣案，无期徒刑）。
5. **信息保护附属义务**：捐赠人/受益人个人信息属受保护客体，非法出售或泄露情节严重构成侵犯公民个人信息罪（刑法第253条之一）。

## 典型案例素材（公开来源，待回源）

- **儿慈会案**：内部监事未发现/未制止前受助人私自以项目名义诈骗近千万元 → 民政部停止活动三个月、列入严重违法失信名单，相关负责人被责令罢免、移送司法。
- **某教育基金会案（2024）**：未披露关联方交易被处罚，近半资金流向理事会成员亲属控股服务商 → "自我交易"违反慈善法禁止性规定。
- **河南某高校教育基金会案**：理事长兼校办企业法定代表人，基金会受捐股权半年后低价转让校办企业、差价2600万流入"小金库" → 变相输送利益，理事长被党内警告、校办企业负责人免职。

## 关联法条

- 《慈善法》（2023修正）第14条（关联交易禁止与公开）
- 《基金会管理条例》第20–24条（理事义务与决策）
- 《民间非营利组织会计制度》（关联交易会计处理）

## 对厚德基金会的锚定

- 厚德基金会日常关联交易审查须落实"回避 + 公开 + 公允"三要件；负责人决策前须自查是否落入第14条关联情形。
- 与 R-CF-111（理事忠实义务内部治理）、R-CF-122（关联交易认定）、R-CF-123（穿透式稽查）构成"治理—认定—稽查—刑事风险"完整防控链。
