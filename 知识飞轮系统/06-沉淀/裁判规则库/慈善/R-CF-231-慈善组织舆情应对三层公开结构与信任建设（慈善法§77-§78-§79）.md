# R-CF-231 慈善组织舆情应对三层公开结构与信任建设（慈善法§77/§78/§79）

> 来源：IMA「慈善组织合规AI助手」库《基金会的舆情，为何总在"解释"里打转？》（CFF2008 / 中国基金会发展论坛，2026-09-04）。B 阶段回补摄入（2026-10-26 通道恢复后补齐 10-26 漏跑）。

## 一、核心法条（本地法条银行逐字 · 已三通道核验）

**《慈善法(2023修正)》第七十七条**【信息公开三要件】
> 慈善组织、慈善信托的受托人应当依法履行信息公开义务。信息公开应当**真实、完整、及时**。

**《慈善法(2023修正)》第七十八条**【应公开内容 + 年度报告与审计】
> 慈善组织应当向社会公开组织章程和决策、执行、监督机构成员信息以及国务院民政部门要求公开的其他信息。上述信息有重大变更的，慈善组织应当及时向社会公开。
> 慈善组织应当每年向社会公开其年度工作报告和财务会计报告。**具有公开募捐资格的慈善组织的财务会计报告须经审计。**

**《慈善法(2023修正)》第七十九条**【公募信息公开频次】
> 具有公开募捐资格的慈善组织应当定期向社会公开其募捐情况和慈善项目实施情况。
> 公开募捐周期超过六个月的，至少每三个月公开一次募捐情况，公开募捐活动结束后三个月内应当全面、详细公开募捐情况。
> 慈善项目实施周期超过六个月的，至少每三个月公开一次项目实施情况，项目结束后三个月内应当全面、详细公开项目实施情况和募得款物使用情况。

**《慈善法(2023修正)》第七十六条**【民政部门应当公开的九类慈善信息】（登记事项、慈善信托备案事项、公募资格名单、税前扣除票据资格名单、税收优惠与资助补贴等促进措施、向慈善组织购买服务的信息、检查评估结果、表彰与处罚结果、法律法规规定应当公开的其他信息）

**《慈善法(2023修正)》第十三条**【年度报告报送】
> 慈善组织应当每年向办理其登记的民政部门报送年度工作报告和财务会计报告。报告应当包括年度开展募捐和接受捐赠、慈善财产的管理使用、慈善项目实施、募捐成本、慈善组织工作人员工资福利以及与境外组织或者个人开展合作等情况。

**《慈善法(2023修正)》第四十二条**【捐赠人查询复制权与救济途径】
> 捐赠人有权查询、复制其捐赠财产管理使用的有关资料，慈善组织应当及时主动向捐赠人反馈有关情况。
> 慈善组织违反捐赠协议约定的用途，滥用捐赠财产的，捐赠人有权要求其改正；拒不改正的，捐赠人可以向县级以上人民政府民政部门投诉、举报或者向人民法院提起诉讼。

**《慈善法(2023修正)》第五十六条**【用途变更规则】
> 慈善组织开展慈善活动，应当依照法律法规和章程的规定，按照募捐方案或者捐赠协议使用捐赠财产。慈善组织确需变更募捐方案规定的捐赠财产用途的，应当报原备案的民政部门备案；确需变更捐赠协议约定的捐赠财产用途的，应当征得捐赠人同意。

**《慈善法(2023修正)》第十四条**【关联交易回避与公开】（与 R-CF-230 互链）

## 二、规则要旨：舆情应对的三层公开结构

**核心诊断**："为什么一份完整的审计报告，解释不了公众对一台电脑、一笔管理费的疑问？为什么机构已经把能公开的信息都公开了，公众还是不够相信？"

**根因**：现行信息公开**首先是为满足法律规定和监管要求**而组织——"让信息可以被查到、被核对"，并不天然按公众的理解路径组织。**让信息能够被看到 ≠ 让信息能够被理解。**

**三层结构**：

| 层次 | 解决什么 | 载体 | 现状缺陷 |
|---|---|---|---|
| **法定公开** | 让信息**可获得** | 年报、审计报告、项目报告、财务数据（§13/§78/§79） | 已高度制度化，但按监管口径而非公众理解路径组织 |
| **解释性公开** | 让信息**可理解** | 项目说明、科目解释、案例讲清楚 | 缺失 → "透明不透气" |
| **关系性沟通** | 让公众**理解选择**（你为什么这样选、出了问题怎么办、我为什么愿意继续相信你） | 主动沟通、持续互动 | 基本空白 → "越解释越忙、越忙越解释" |

🔴 **结论**：**信息公开是基金会与公众建立关系的基础，而不是关系本身。**

## 三、四项操作规则

### 1. 解释工作前置到"信息公开之前、公众提问之前"

- 公众看到一笔支出会连续追问四层：**这笔钱是什么意思？为什么要这样花？基金会为什么会做出这样的选择？如果出了问题怎么办？**
- 网络传播会放大错位：原本需结合项目背景理解的一笔支出，转发后只剩"基金会花钱买设备"，机构拿出十几页补充说明时已难回到最初问题。
- **动作**：公开前先预判公众疑问；预先建立"容易被理解的解释方式"，否则同一组数据会被不同人理解成不同故事。

### 2. 舆情来了，先回应利益相关方，不是回应所有人

- 公众从来不是一个整体（长期捐赠人 / 合作伙伴 / 初次听说者 / 顺手评论者 / 真正关心者 / 借热点表达情绪者）。
- **优先顺序**：业务主管单位等监管部门 → 核心捐赠人 → 长期合作伙伴 → 其他。理由是"网络热点本身有自己的传播周期"，把全部精力投入评论区会陷入**越解释越忙、越忙越解释**的循环。
- 但**不等于沉默**：真实问题该承认就承认、该纠正就纠正、该整改就讲清整改措施。

### 3. 「合法」与「合理」是两套判断标准，不能只答前者

- 法律解决"行为有没有越过规则边界"；公众还会从**慈善组织的身份、捐赠人的期待、项目本身的合理性**出发作出判断。
- 🔴 **规则中站得住 ≠ 情理上被理解**：回应不能只停留在"证明自己没有违规"，还需换一种说法讲清**为什么这样做、当时怎么考虑、可能给谁带来什么感受**。

### 4. 人格信任 vs 系统信任：名人慈善的结构性风险

- 借卢曼的区分：**人格信任**（指向具体的人，基于经历、品格、判断）与**系统信任**（依赖制度、规则、组织结构）。
- 公益慈善通常**从人格信任开始**（先因相信某位明星/企业家/慈善家而认识机构）→ 建立快，**风险传导也快**：个人争议沿原信任链条传导，最终变成对整个组织的全面审视。
- **规则**：名人可参与传播、捐赠、公益倡导，但**项目决策、资金管理、执行、信息披露必须回到机构自身治理体系**；需长期深度绑定的身份，合作前须考虑**声誉风险与退出机制**。
- **底线**：名人是基金会进入公众视野的入口，**不能永远是唯一信用来源**——若公众永远只因相信一个人才相信机构，组织自身信用并未真正生长。

### 5. 行业"翻译者"角色与会计口径的公众化

- 行业平台型组织可承担公益慈善与公众之间的**"翻译者"**：不是替某一家机构辩护或背书，而是把行业内部习以为常的表达换成公众能听懂的语言。
- **典型案例（韩红基金会舆情）**：公众对"管理费2.86%"困惑——审计报告管理费用835万，但现金流量表员工相关现金支出1674万。合规层面，项目人员工资进入慈善活动支出是**会计上允许**的；但普通捐赠人不清楚还有部分工资与房租可**分摊**到慈善活动支出。
- **规则**：行业层面在**无舆情压力时**提前科普 → 舆情发生时不必每次从最基础概念开始解释。
- 但**行业翻译不能替代机构自己的表达**：每家机构仍需把自己的项目讲明白，用**案例或故事**（公众未必记得住数字表格，却可能记得住具体的人、具体的事）。

## 四、蓝队 / 红队要点（厚德基金会视角）

- **蓝队（主动合规与舆情前置）**：
  1. 建立"**解释性公开**"层：在法定年报/审计报告之外，为每笔重要支出配套**通俗说明卡**（金额、用途、为什么这样花、出了什么问题怎么办）；
  2. 舆情响应**分级预案**：明确"谁在多少小时内向哪个利益相关方说明什么"——监管单位 → 核心捐赠人 → 合作伙伴 → 公众；
  3. 回应模板**双轨**：合法性与合理性**两条线并行**（不能只答前者）；
  4. 对**名人/长期绑定合作方**，事前设声誉风险评估与退出机制；
  5. 主动做**行业科普**（管理费为什么存在、项目为什么需要人员成本），把解释成本前置到日常。
- **红队（舆情风险识别与合规自检）**：
  1. **法定公开底线自查**：年报与财务会计报告是否每年公开（§78第2款）？公募资格机构财务会计报告**是否经审计**（§78第2款）？募捐周期超6个月是否**至少每三个月**公开募捐情况、结束后**3个月内**全面详细公开（§79）？项目实施周期超6个月是否同样每三个月公开、结束后3个月内全面公开项目实施情况**和募得款物使用情况**（§79）？
  2. **管理费口径**是否会让公众产生"数字对不上"的疑问（对照 §78 第2款与 §13 报告项目）——审计口径与现金流量表口径差异须有解释材料；
  3. **关联交易**：是否已按 §14 回避表决并公开交易情况（关联 R-CF-230 / R-CF-063）；
  4. **捐赠用途变更**：是否按 §56 报备案/征得捐赠人同意（不得擅自变更）；
  5. **捐赠人救济**：是否已建立 §42 项下捐赠人查询复制与主动反馈机制（避免投诉、举报、诉讼路径被激活）；
  6. **信息不公开边界**：涉国家秘密、商业秘密、个人隐私及捐赠人不同意公开的信息不得公开（§82）——以"商业秘密"笼统拒绝公开须有边界。

## 五、适用场景

- 慈善组织舆情事件的**分级响应**与利益相关方沟通顺序设计；
- 慈善组织**信息公开三要件（真实·完整·及时）**的自查清单；
- 厚德基金会年度工作报告/财务会计报告的**对外可理解性**改造；
- 名人公益合作的**声誉风险与退出机制**审查；
- 公募资格机构的**募捐信息公开频次**合规核查。
