# 韩红基金会6000万救护车采购疑云风控要点

> 性质说明：本文为舆论事件素材，属"强佐证"级参考资料，非对违规的坐实认定。最终事实以监管核查结论为准。

## 一、事件脉络
韩红基金会"急速抢救"项目2024-2025年累计向上海均奕汽车科技有限公司拨付超6000万元采购救护车。供应商实缴资本10万元、社保参保2人，与订单规模形成反差，叠加价格推算差异、配置未充分公开，引发公众质疑。上海金山区市场监管局、北京市民政部门已介入核查。

## 二、可提炼的客观风险疑点（非推定违规）
1. **供应商体量反差**：实缴10万、参保2人承接数千万订单；注册地址频变。
2. **采购模式转变**：2023年整车厂直采（江铃），2024年起引入经销商（上海均奕），年报仅披露各项目总拨付金额，未拆分车型/台数/单车价。
3. **授权链不透明**：基金会称获上汽大通授权由经销商签约；但上汽大通官方经销商目录（上海44家）未检索到该企业；媒体实地探访称其不从事改装、不售医疗器械，仅做整车销售结算。
4. **历史磋商材料缺失**：官网仅公示2026-03-18之后采购文件，2024/2025年数千万采购是否执行竞争性磋商、是否落实代理商唯一授权，公开材料无法厘清。

## 三、对应合规规则锚点
- **慈善法第14条（关联交易）**：慈善组织的发起人、主要捐赠人及管理人员，不得利用其关联关系损害慈善组织、受益人和公共利益；与上述主体发生交易，不得参与决策，交易情况应向社会公开。
- **采购合规程序**：2026年磋商采用竞争性磋商+综合评分法，设六项基础资格+代理商唯一授权条款；大额采购应落实比价议价留痕、配置清单、授权文件核验。
- **信息公开义务**：年报须披露重大公益项目大额支付对象及占比；募捐方案预留车型调整条款的，大规模采购超预算基准的高配车型应专门向捐赠人说明调整缘由。
- **尽职调查义务**：厂家指定经销商模式本身不违规，但基金会须对经销商做独立尽调；授权文件不能替代独立筛选与核查。

## 四、慈善组织大额采购风控清单
1. 供应商实缴资本、社保、业绩、厂家授权链独立核验；
2. 比价清单、配置明细、合同凭证全程留痕；
3. 关联交易主动回避决策并公开；
4. 采购文件（含历史年度）依规公示，接受审计；
5. 舆情发生后第一时间以书面声明客观回应，区分"客观疑点"与"违规推定"。
