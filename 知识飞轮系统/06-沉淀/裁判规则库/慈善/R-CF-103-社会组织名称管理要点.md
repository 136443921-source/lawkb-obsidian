# 社会组织名称管理办法要点

> **卡型**：规范要点卡｜**编号**：`R-CF-103`｜**建卡日期**：2026-09-04

## 一、规则要旨（正向·怎么用）
本办法（民政部令第69号，2024-05-01施行）统一规范社会团体、基金会、民办非企业单位的名称构成、禁用情形、字号规则、组织形式与重名审查。慈善组织在设立/更名/分支（代表）机构命名时，须严格对照"构成要素+禁用清单+重名检索"，否则登记机关不予登记。

## 二、审查要点（操作路径，编号步骤）
1. **唯一性与保护**：社会组织只能登记一个名称，名称受法律保护（第五条）。
2. **构成要素核对**：
   - 社会团体：行政区划+行（事）业领域或会员组成+组织形式（第八条）。
   - 基金会/民非：行政区划+字号+行（事）业领域+组织形式（第八条）。
3. **字号规则**：基金会/民非字号≥2汉字、非语句、与行业显著区分；县级以上区划名/行业领域不得作字号；基金会禁用姓氏作字号（第十条）。
4. **组织形式后缀**：社会团体以"协会/商会/学会/研究会/促进会/联合会"等结尾；基金会以"基金会"结尾；民非以"学校/医院/中心/院/园/所/馆/站/社"等结尾，且不得含"总/连锁/集团"（第十二条）。
5. **禁用情形排查**（第十三条）：损国家尊严利益、淫秽暴力恐怖、民族宗教性别歧视、含外国文字/拼音/阿拉伯数字、使公众误解等八类。
6. **重名检索**：同登记机关内，拟用名称或字号不得与同行同组织形式已登记/注销未满1年/撤销未满3年的社会组织相同（第十六条）。
7. **使用一致**：印章、账户、法律文书、网站等须与登记证书名称一致（第二十一条）。

## 三、构成要件与举证（表格）
| 要件编号 | 要件名称 | 要件内容 |
|---|---|---|
| C1 | 唯一名称 | 仅登记一个，受法律保护 |
| C2 | 构成合规 | 按组织类型满足行政区划/字号/行业/组织形式四要素 |
| C3 | 无禁用词 | 不触碰第十三条八类禁用情形 |
| C4 | 不重名 | 同行同形式未与已登记/近期注销撤销者重名 |
| C5 | 使用一致 | 各类载体名称与登记证书一致 |

**举证责任分配**：申请人对名称材料真实准确完整负责（第十九条）；登记机关对名称合规审查、可听取利益相关方意见（第二十、二十一条）。

## 五、抗辩与但书
- 国务院民政部门登记的可不冠行政区划，经批准可冠"中国/全国/中华"（第八条）。
- 城乡社区社会组织可在县级区划后缀乡镇（街道）/村（社区）名（第九条）。
- 使用已故公益名人姓名作字号、或经自然人同意用姓名作字号，有条件允许（第十五条）。

## 六、翻车标本（负向拦截·HIR）
- **标本1**：基金会拟名"中国XX第一爱心基金会"——含"第一"误导性文字（第十一条）、且冠"中国"须国务院民政批准（第八条）→ 不予登记。
- **标本2**：民非定名"XX市天下连锁康复中心"——组织形式含"连锁"违规（第十二条）→ 不予登记。
- **标本3**：与同机关已注销仅8个月的社会组织同名 → 违反第十六条（注销未满1年）→ 驳回。
