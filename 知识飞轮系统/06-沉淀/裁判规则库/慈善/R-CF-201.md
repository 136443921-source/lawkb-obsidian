# R-CF-201 基金会互拨资金受托代理与捐赠收入认定边界

## 蓝队视角
合作基金会之间互拨资金的入账定性，应回归"资金来源性质"：对方对外募集而来的公益资金，接收方仅按受托代理资产核算；对方以自有非募捐资金（结余、投资收益等）无偿捐赠的，方可确认捐赠收入。受托代理资产依据《民间非营利组织会计制度》涵盖资金、存货、固定资产、无形资产等。

## 红队视角
- 误将受托代理记为捐赠收入 → 收入虚增、科目混用，审计/民政/税务环节易被整改扣分；
- 受托代理**仅认资产、不含服务**，纯服务委托无资产转移不得套用受托代理账务；
- 服务类合作民非制度缺统一口径，开票与入账以税务机关认定为准，属灰色地带，须谨慎。

## 规则抽取
1. **判定规则**：对方募集资金 → 受托代理，禁计捐赠收入；对方自有非募捐资金无偿捐赠 → 可记捐赠收入。
2. **受托代理边界**：仅适用于资产类业务（资金/实物/无形资产），服务类业务不适用，制度中无"受托代理服务"概念。
3. **服务类合作**：账务处理及是否开具增值税发票以税务机关官方认定意见为准。
4. **票据关联**：若误将受托代理资金记为捐赠收入并开具捐赠票据，触发慈善法第三十八条票据合规问题。

## 业务关联（厚德基金会合规）
关联《贵州省厚德公益基金会合规管理手册（试行）（2025版）》收入确认与受托代理核算章节（具体条款以手册文本为准）。建议：互拨前先做资金来源性质判定；受托代理台账与捐赠收入科目严格隔离；服务类委托单独走服务核算，开票前取得税务口径确认。
