# 慈善组织擅自改变捐赠财产用途的法律后果——从警告、异常名录到吊销登记

> ⚠️ **来源降级声明（D0.7）**：本卡由 WebSearch 检索生成（元典 / 企查查本次会话未进工具索引），**案例侧未经三通道交叉核验**，`source_verified:false`，待回源补正。法条引用为标准条文，待据本地法条银行校正。

## 一、核心要旨

1. **专款专用是红线**：慈善组织接受的捐赠财产须专款专用；**擅自改变捐赠财产用途**（含协议未约定计提管理费、以投资名义向企业借款、未备案慈善项目募集资金挪用）构成违法。
2. **梯度处罚**：轻则**警告 + 列入社会组织活动异常名录**；情节严重的**吊销登记证书 + 列入严重违法失信名单**。
3. **多违并罚**：实务中"擅自改变用途"常与"未依法履行信息公开义务""不具有公开募捐资格擅自募捐""未备案慈善项目"并发，处罚叠加。

## 二、典型案例（WebSearch 检索所得，待回源确号）

- **绿发会案（民政部·2023-04）**：接受某单位慈善捐赠后，在捐赠协议未约定的情况下计提50万元管理费用，违反《慈善法》第55条"擅自改变捐赠财产用途"，警告 + 列入异常名录。
- **西安蒲公英慈善公益中心（2025-05，西民罚〔2025〕3号）**：未依法履行信息公开义务 + 擅自改变捐赠财产用途 + 无资格擅自公开募捐，违反《慈善法》§110①④/⑦、§113及《慈善组织信息公开办法》，警告 + 异常名录。
- **西安善行公益慈善基金会（2023-06）**：以投资名义向企业提供借款 + 未信息公开 + 大量未备案慈善项目 + 擅自改变募集资金用途，违反《慈善法》§13/14②/23/54/55/72/73等，吊销登记证书。

## 三、权威依据（标准条文，待本地法条银行校正）

- 《慈善法》(2023修正) 第54条：慈善财产须专款专用。
- 第55条：慈善组织开展慈善活动须遵守募捐方案/捐赠协议约定；变更用途须备案或征得捐赠人同意。
- 第99条：擅自改变捐赠财产用途等违法情形的处罚（警告、责令停止、罚款、吊销等）。
- 第110条、第113条：信息公开义务及对应法律责任。
