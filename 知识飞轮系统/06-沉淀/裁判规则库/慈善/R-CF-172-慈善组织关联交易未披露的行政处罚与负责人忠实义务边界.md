# 慈善组织关联交易未披露的行政处罚与负责人忠实义务边界（R-CF-172）

## 裁判规则

1. **《慈善法》（2023修正）第14条——关联交易的制定法源头**：慈善组织的发起人、主要捐赠人以及管理人员，不得利用其关联关系损害慈善组织、受益人的利益和社会公共利益；与慈善组织发生交易行为的，不得参与有关该交易行为的决策，有关交易情况应当向社会公开。
2. **未披露关联交易 + 慈善支出比例不达标 → 民政行政处罚**：实务中，基金会向关联方大额借款/资金往来且未披露、年度慈善活动支出占上年度总收入比例显著低于法定标准（一般年度≥6%、净资产≥8%为基准）的，民政部门可责令停止活动若干月并列入严重违法失信名单。
3. **负责人忠实义务**：理事长/秘书长等管理人员负自我交易禁止、利益冲突回避义务；决策前须自查是否落入第14条关联情形，落实"回避 + 公开 + 公允"三要件。
4. **内部合规依据（决策须引内规）**：涉慈善决策依据《贵州省厚德公益基金会合规管理手册（试行）（2025版）》关联交易与利益冲突相关条款——日常关联交易审查须落实回避、公开、公允三要件，负责人决策前自查关联情形。

## 基本案情（来源：民政部及省级民政机关公开处罚通报综合）

- **刘彪慈善基金会案（民政部行政处罚）**：基金会向关联方大额借款约1亿元、年度慈善活动支出占比仅约2.96%、未披露关联交易 → 被责令停止活动6个月并列入严重违法失信名单。
- **同期**：永恒/增爱基金会因关联交易事项被警告；广东省民政厅通报数起慈善组织关联交易违规案例。

## 关联法条

- 《慈善法》（2023修正）第14条（关联交易禁止与公开）
- 《基金会管理条例》第20–24条（理事义务与决策）
- 《民政部行政处罚裁量权基准》（民发〔2025〕61号）相关罚则分档

## 对在办案件的锚定

- **厚德基金会日常关联交易审查**：须落实"回避 + 公开 + 公允"三要件；负责人决策前自查是否落入第14条关联情形；重大关联交易须经理事会决议并公开。
- 与 R-CF-127（负责人忠实义务与关联交易刑事风险）、R-CF-111（理事忠实义务与关联交易禁止）互为补充。
