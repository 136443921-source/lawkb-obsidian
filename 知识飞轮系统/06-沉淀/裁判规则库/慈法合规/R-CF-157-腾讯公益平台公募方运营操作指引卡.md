# 腾讯公益平台公募方运营操作指引卡

> 一句话：公募方完成慈善中国备案取得有效编号后，方可在腾讯公益平台入驻并上线公开募捐项目；非公募方须由公募方"认领"项目、经公募方审核通过后方可上线。本卡把平台侧操作拆成入驻、自有项目上线、合作认领、数据运营四块。

## 一、操作定位与适用场景

- **前置条件**：R-CF-156 慈善中国备案已完成、取得有效备案编号。
- **适用主体**：① 已入驻公募方（自有项目上线）；② 非公募方（委托公募方认领项目）；③ 公募方（审核认领项目、常态化数据运营）。
- **目标**：把"备案→入驻→上线→运营"链路落地，守住"未在备案平台 / 超备案期限 / 未备案上线即违法"的红线。

## 二、操作依据

- 《慈善组织公开募捐管理办法》(民政部令第 74 号)第 8 条：互联网募捐须在备案的指定平台发布。
- 腾讯公益平台运营规则（机构账号注册与认证、项目审核、备案号管理、子商户号）。
- 正式引用前以 mca.gov.cn / 腾讯公益官方规则二次核对条号与口径。

## 三、操作流程步骤

**1. 公募方入驻**
材料清单（PDF 扫描件加盖公章、有效期内）：慈善组织登记证书、公开募捐资格证书、法定代表人身份证（正反面）、开户许可证、微信支付业务办理授权函、公益性捐赠税前扣除资格证明、近三年度年报/财报、社会组织评估等级证书、机构公章（透明底 PNG ≥200×200px）、机构 logo、机构简介（Word 500 字内）、重要联系人信息（法人/秘书长/对接人）。
审核时限：提交后 7–10 个工作日，结果发注册手机 + 机构邮箱。

**2. 公募方自有项目上线**
- 上线前核验慈善中国备案状态：① 备案"完成"且有有效编号；② 备案有效期覆盖项目周期；③ 备案平台含"腾讯公益平台(org.gongyi.qq.com)"。三项任一不符即属违法募捐。
- 项目材料：详情介绍（Word，含名称/简介/受助对象/背景/故事/帮扶方案/计划）、配图（JPG/PNG ≥3 张、≤5MB、真实项目照片禁网图、肖像须授权书）、预算表（与备案一致）、负责人信息、受益人筛选标准。
- 新项目上线申请：基本信息 → 筹款信息（子商户号/预算/公益单位/捐赠浮层） → 详细信息（图片/视频/授权书/背景/故事/执行地/执行方/帮扶方案/计划） → 执行能力说明/负责人/票据信息 → 提交审核（7–10 个工作日）。

**3. 非公募方认领项目上线**
- 非公募方入驻（同公募方，但无需开户许可证、微信支付授权函、税前扣除资格、公章、公募资格证书、子商户号等公募资质材料）。
- 非公募方提交"新项目上线申请"并选择挂靠公募方。
- 公募方：机构运营-备案号管理"新增"已在慈善中国备案完成的备案号（平台审核通过方可用） → 审核管理-项目审核-待审核列表 审阅（核对信息/预算与备案一致） → 审核通过或驳回（填原因，非公募方修改重提） → 平台审核 7–10 工作日。

**4. 平台数据分析与运营**
- 三大看板：项目数据（捐赠金额/人数/分布）、产品数据（进展转化/视频号/月捐/一起捐/小红花码/全年行业资助计划）、执行数据（执行进展 ≥每季 1 次、用户反馈、投诉处理率 100% 且 ≤5 工作日）。
- 多项目对比分析：每季度 ≥1 次，维度含筹款能力 / 捐赠人结构 / 传播效果 / 执行进度，形成书面报告报管理层并抄送合作非公募方。

## 四、合规红线与禁止事项

- 未备案 / 备案过期 / 未在备案平台上线 = 违法募捐。
- 平台填写募捐信息须与慈善中国备案完全一致；备案号变动须同步更新平台。
- 公募方不得出借资质给无资质方；合作募捐公募方承担主体审核责任。
- 配图须真实项目照片、禁网图；涉及肖像须授权书。
- 投诉处理率 100%、时效 ≤5 工作日。

## 五、常见错误与风险

- 备案状态未核验即上线（三种不符情形）。
- 平台项目信息与备案不一致（名称/预算/期限/平台）。
- 非公募方误填公募资质材料或漏选挂靠公募方。
- 公募方审核认领项目时未核对备案一致性。
- 执行进展更新低于每季 1 次、投诉超期。

## 六、工具模板清单

- 入驻材料包（12 类 PDF/图片/Word，见第三节 1）
- 项目详情介绍（Word）
- 项目配图 + 肖像授权书
- 与备案一致的预算表
- 子商户号 / 备案号 / 捐赠票据信息（公募方先设好）
- 多项目对比分析季度报告模板
