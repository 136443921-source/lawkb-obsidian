# 慈善信息公开操作与年报审计披露卡

## 一、操作定位与适用场景

本卡面向慈善组织（含公募方与不具备公开募捐资格的非公募方/项目发起方）的信息公开与年报审计披露实务，覆盖「贵州省基层慈善组织数字化运营手册」第五章"慈善信息公开"的核心操作。

适用场景：
- 慈善组织通过**全国慈善信息公开平台（慈善中国）**履行法定信息公开义务；
- 公募方完成项目立项、实施、结项全流程信息公开；
- 非公募方（项目发起方）配合公募方完成信息公开，并在自身渠道转载已公开信息；
- 年度工作报告、经第三方审计的财务会计报告的全网公示；
- 募捐成本（2026年新规强制项）单独核算与单独披露；
- 使用微信公众号、视频号、企业微信、腾讯文档等数字化工具开展信息公开。

核心原则：信息公开是法定义务，必须严格按照法律法规要求，**及时、真实、完整**地公开法定信息。

## 二、操作依据（法规与平台规则）

- 《中华人民共和国慈善法》（2016年通过，2023年12月29日修改决定修正，2024年9月5日起施行）：
  - 第42条：捐赠人知情权核心条款，捐赠人有权查询、复制自身捐赠财产管理使用台账，组织须主动及时反馈资金落地情况；
  - 第55条：重大资产变动、重大投资、重大关联交易发生后应当公开；
  - 第77条：县级以上民政部门搭建统一全国慈善信息公开平台，慈善组织所有法定公开信息均须在该平台发布并对真实性负责；
  - 第78条：每年向社会公开年度工作报告、经第三方审计的财务会计报告；
  - 第79条：具有公开募捐资格的慈善组织应当定期公开募捐收支情况、慈善项目全流程实施情况；
  - 第80条：定向募捐须单独、及时向对应捐赠人告知募捐款物管理使用情况；
  - 第82条：捐赠人明确不同意公开的姓名、联系方式、住址等信息不得对外披露；隐私、商业秘密、国家秘密免于公开；
  - 第110条：未履行信息公开义务、披露信息虚假/不完整、泄露捐赠人隐私，民政部门责令限期改正并警告；逾期不改责令停止活动；情节严重吊销登记证书。
- 《慈善组织信息公开办法》（中华人民共和国民政部令第81号，2026年1月1日施行，现行有效）：
  - 第2条：信息公开遵循**真实、完整、及时**三原则，建立内部信息公开责任制度，不得用宣传广告替代法定披露；
  - 第3条：在全国统一慈善信息公开平台依法完整公开六大类信息（组织基础信息、年度工作报告与财务会计报告、公开募捐明细、慈善项目信息、重大资产与关联交易信息等）；
  - 第6条：每年**5月31日前**完成上一年度年报、审计报告全网公示（🔴 手册误作 6月30日，已按官方条文更正）；
  - 第10条：公开募捐活动结束后**3个月内**完整公示募款总额、支出明细、剩余资金计划；项目实施周期超过六个月的，至少每三个月公开一次项目实施情况（🔴 手册误作第8条，实为第10条）；
  - 第12条：重大资产变动、重大投资、重大关联交易发生后**30日内**公开；
  - 第15条：定向募捐无需全网公示，但须点对点向捐赠人同步资金使用进度；
  - 第16条：为每年的年度工作报告和财务会计报告、每个公开募捐活动和慈善项目建立相对独立的信息条目；
  - 第23条：未按规定时限、范围公开信息，依慈善法第一百一十条行政处罚。
- 《关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定》（民发〔2026〕12号，2026年4月27日施行）：
  - 第6、7条：募捐成本限定为募捐直接支出（场地、差旅、专业服务、汇兑损失等），本单位场地、内部人员薪酬不得计入，统一在"筹资费用"科目单独归集、据实列支；
  - 第15条：**年度募捐成本不得超过前三年捐赠收入平均数3%**，该比例为强制披露指标；
  - 第17条：必须在年度工作报告、财务会计报告、公开募捐专项公示材料中单独详细披露募捐成本发生总额、分项明细及占捐赠收入比例；
  - 第18条：未单独核算、未完整披露募捐成本属信息公开违规，依慈善法第一百一十条处罚。

## 三、操作流程步骤（分步，可含材料清单/按钮级）

### A. 公募方——慈善中国平台全流程信息公开

**1. 登录平台**
- 打开浏览器，访问"慈善中国-全国慈善信息公开平台"；
- 点击右上角"慈善组织（基金会）/红十字会"按钮，输入用户名（通常统一社会信用代码）和密码登录；
- 登录异常可联系平台技术支持（010-58123114）重置密码，或更换浏览器（Chrome、Firefox）清除缓存。

**2. 项目立项阶段（项目实施前公开）**
- 进入"慈善项目管理"模块 → 点击"新增慈善项目" → 填写项目基本信息（名称、是否公开募捐、受益人群、服务领域、运作模式、服务地区、起止时间、项目简介、剩余财产处理等）；
- 点击"保存" → 回到项目列表点击"发布" → 确认提交审核（通常3-5个工作日）；
- 合规要点：项目实施方案须含募捐目的、起止时间地域、筹款预期、负责人联系方式、对公账户、受益人群、款物用途、募捐成本测算、结余财产处置；项目预算表按业务活动成本/管理费用/筹资费用（募捐成本）分类分项列示；立项信息须在项目实施前公开并完成慈善中国线上备案。

**3. 项目实施阶段（至少每3个月公开一次进展）**
- 进入"慈善组织信息公开"模块 → "信息填报" → "慈善项目进展信息" → 选择项目 → "信息维护"；
- 填写进展周期、实施进展、受益人选拨与资助情况、资金使用情况、项目效果与影响、下一步实施计划；
- 上传进展证明材料（PDF，可从腾讯文档导出，含实施照片、受益人名单、资金使用凭证等）；
- 保存填报 → 等待审核（3-5个工作日）→ 自动公开。

**4. 项目结项阶段（结束后3个月内公开结项报告）**
- 进入"慈善组织信息公开"模块 → "信息填报" → "慈善项目进展信息" → 将活动状态改为"已完成"；
- 填写项目总体情况、资金总体情况（总收入/总支出/支出明细）、受益人总体情况、效果与影响、经验教训、结项证明材料；
- 结项报告须全面客观真实，如实披露实施偏差、资金使用问题、执行难点及整改情况；
- 归档佐证材料须完整：项目工作总结报告、专项财务收支明细、项目财务审计报告、受益人走访记录与反馈凭证、物资发放台账、阶段性公示截图。

**5. 年报与审计报告公示**
- 每年**5月31日前**，在慈善中国平台完成上一年度年度工作报告、经第三方审计的财务会计报告全网公示（🔴 手册误作6月30日，已按信息公开办法第6条更正）；
- 同步在机构官网、微信公众号等自有渠道公开（公众号发布内容须与提交民政部门的内容一致，不得隐瞒或篡改）。

**6. 重大资产/投资/关联交易与募捐成本专项披露**
- 重大资产变动、重大投资、重大关联交易发生后30日内在平台公开；
- 募捐成本单独核算、独立公示当期总额及占比、分项明细（第三方平台服务费、宣传推广费、场地租赁、外包服务等），严格区分募捐成本/管理费用/项目支出，自有人员薪酬与自有场地不得计入。

### B. 非公募方（项目发起方）——配合公募方

- 与公募方签订「合作开展公开募捐活动协议」；
- 向公募方提供项目实施方案（腾讯文档协同编制）、项目预算表（腾讯文档Excel）、可行性研究报告等；
- 配合公募方在慈善中国完成项目备案，提醒公募方及时公开；
- 在自身渠道（网站、公众号）**转载**公募方已公开的项目信息（不得擅自公开募捐信息）；
- 至少每3个月向公募方提供项目进展资料（进展报告、照片视频、受益人名单、资金使用凭证），项目结束后3个月内提供结项资料（结项报告、总结报告、财务报告、审计报告、受益人反馈）；
- 督促公募方按期公开，并对公示信息真实性、完整性承担协同配合义务（提供虚假材料致公示不实须承担连带责任）。

## 四、合规红线与禁止事项

- 不得以宣传推广、宣传广告替代法定信息公开（民政部令第81号第2条）；
- 不得隐瞒、遗漏、篡改基本公示内容，不得用虚假记载、重大遗漏替代法定披露；
- 捐赠人明确不同意公开的姓名、联系方式、住址等信息**不得对外披露**；隐私、商业秘密、国家秘密免于公开（慈善法第82条）；
- 募捐成本必须单独核算、单独披露，不得与管理费用、项目支出混同核算，自有人员薪酬、自有场地不得计入；
- 非公募方不得独立面向不特定社会公众开展公开募捐、不得单独收款、不得以自身名义发布募捐信息（慈善法第22、26条）；
- 公开募捐活动结束后3个月内、项目结束后3个月内必须完成对应披露，不得逾期；
- 重大资产变动/投资/关联交易发生后30日内必须公开；
- 年报/审计报告须在**5月31日前**公示，不得拖延（🔴 手册误作6月30日）。

## 五、常见错误与风险

- **逾期公示**：未设定时限提醒，错过年报5月31日、结项3个月、重大交易30日等节点（建议用企业微信日历设置重复提醒）；
- **漏报明细**：募捐成本未分项披露、未单独列示，合并披露或简化披露（民发〔2026〕12号第17条明令禁止）；
- **虚构/不实**：披露信息虚假、记载不实、关键明细缺失（先责令限期改正，逾期不改责令停业整改；1年内再犯或情节严重吊销登记证书并公告）；
- **线上线下不一致**：自有渠道与慈善中国平台公示内容不一致、版本不一致；
- **隐私泄露**：违规披露捐赠人不同意公开的个人信息，或受益人敏感信息未脱敏（身份证、电话、住址、病历等须打码或获授权）；
- **主体不适格**：非公募方擅自以自身名义发布募捐信息、单独收款，违反慈善法第22、26条；
- **内控缺位**：未建立信息公开责任制度与公示更新台账，导致信息长期不更新。
