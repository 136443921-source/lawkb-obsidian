# 慈善数字化运营法规工具术语速查操作指引卡

## 一、操作定位与适用场景

本卡对应「贵州省基层慈善组织数字化运营手册」第九章"附录"——全手册1–9章的"工具箱与导航图"。作用：按业务领域快速查法规清单、按功能快速查工具清单、按概念快速查术语，方便贵州基层慈善组织随手查阅与落地应用。

典型用途：起草文书前核对法规令号与生效状态；选型数字化工具时对照功能分类；培训新人时统一术语口径。

## 二、操作依据

本卡本身为"索引性操作卡"，其依据即手册第九章附录所列法规原文与官方权威有效来源链接（中国政府网、民政部门户网站、国家网信办、中国人大网、财政部等）。附录对每部法规均标注：发文机关、文号、生效日期、最新修订、效力状态、本书相关章节、核心内容、官方权威有效来源链接。

> 正式引用前以 mca.gov.cn / gov.cn / 中国人大网 / 财政部 二次核对条号与现行有效性（附录口径以2026年6月手册定稿时为准，部分条款已随新法施行而更新，见第四段红线）。

## 三、操作流程步骤

### （一）按业务领域查法规（9.1，六类）
1. 慈善组织基础法律：《慈善法》（主席令43号立、16号2023修正，2024.9.5施行，现行有效）、《基金会管理条例》（国务院令400号，2004.6.1，现行有效）、《民办非企业单位登记管理暂行条例》（国务院令251号，1998.10.25，现行有效）、《社会团体登记管理条例》（国务院令250号→666号2016修正→832号2026.3.12第二次修正，现行有效）。
2. 公开募捐与项目管理：《慈善组织公开募捐管理办法》（民政部令74号，2024.9.5施行，替代59号旧版，现行有效）、《关于慈善组织开展慈善活动年度支出管理费用和募捐成本的规定》（民发〔2026〕12号，2026.4.27施行，替代民发〔2016〕189号，现行有效）、《慈善组织项目管理规范》（T/ZCL 002—2020，团体推荐标准）。
3. 财务与审计：《民间非营利组织会计制度》（财会〔2024〕25号，2026.1.1施行，替代财会〔2004〕7号）、《基金会财务报表审计指引》（会协〔2016〕21号，2016.6.1，现行有效）。
4. 信息公开与志愿服务：《慈善组织信息公开办法》（民政部令第61号，现行至2025.12.31废止，2026.1.1新版施行，见红线）、 《志愿服务条例》（国务院令685号，2017.12.1，现行有效）、《社会工作服务项目绩效评估指南》（MZ/T 059-2014，民政行业推荐标准）。
5. 网络安全与数据合规：《网络安全法》（主席令53号，2025.10.28修正，现行有效）、《数据安全法》（主席令84号，2021.9.1，现行有效）、《互联网信息服务深度合成管理规定》（网信办等令第12号，2023.1.10，现行有效）、《慈善组织档案管理规范》（T/ZCL 001—2020，团体推荐标准）。
6. 合同与民事法律：《民法典》第三编合同（主席令45号，2021.1.1施行，现行有效）。

### （二）按功能查工具（9.2，七类）
1. 公募与项目管理平台：慈善中国（cszg.mca.gov.cn）、腾讯公益平台（org.gongyi.qq.com）、腾讯公益受益人服务（微信小程序）。
2. 财务与审计软件：用友NC、金蝶EAS、Excel/WPS、腾讯文档（在线Excel）。
3. 沟通与协作工具：企业微信、微信公众号、视频号、腾讯会议。
4. 内容与传播工具：秀米（xiumi.us）、剪映、腾讯文档（在线Word/PPT）。
5. AI与知识管理工具：WorkBuddy、腾讯元宝、IMA知识库（ima.tencent.com）、扫描全能王。
6. 舆情与信用查询工具：清博舆情、新浪舆情通、企查查（qcc.com）、天眼查（tianyancha.com）。
7. 物流与执行工具：京东物流、顺丰、中国邮政。

### （三）按概念查术语（9.3，六组）
慈善组织基础术语（慈善组织/公募方/非公募方/项目发起方/受益人/捐赠人）、财务与会计术语（民非会计制度/业务活动成本/管理费用/募捐成本/限定性与非限定性净资产/公允价值）、项目管理术语（项目预算/进度/绩效评价/数字化转型）、互联网募捐术语（互联网募捐/一起捐/月捐/募捐成本核算）、数字化工具术语（桌面AI智能体/知识库/技能/多智能体协作/知识图谱）、风险与合规术语（合规风险/舆情风险/内部审计/外部审计/专项审计）。

## 四、合规红线与禁止事项

1. **引用法规须核对"效力状态 + 生效日期"，已废止版本不得引用**：
   - 《慈善组织信息公开办法》：手册9.1.4.1列"民政部令第61号，现行至2025年12月31日废止，2026年1月1日新版施行"。由 R-CF-118/R-CF-120 已 verbatim 核填，**新版为民政部令第81号、2026年1月1日施行**；手册附录未列新版令号，引用时务必用81号令现行文本。
   - 《民间非营利组织会计制度》：手册9.1.3.1写"已发布待实施；现阶段暂执行财会〔2004〕7号旧制度"，但生效日2026.1.1**已届满（当前2026年9月）**，新版财会〔2024〕25号已施行，旧版同步废止，该表述已过时，落地以现行新制度为准。
   - 《社会团体登记管理条例》：手册列"第二次修正：国务院令第832号（2026年3月12日）"，为较新修正，引用以832号令为准。
2. **团体标准非强制**：T/ZCL 001—2020、T/ZCL 002—2020、MZ/T 059-2014 为行业/团体推荐标准，自愿参照执行，不得当作强制性法规援引。
3. **修订草案非现行**：《基金会管理条例》2024年12月仅发布修订草案征求意见稿、尚未通过，引用仍以国务院令400号现行文本为准。

## 五、常见错误与风险

1. 误引已废止法规（如仍引用信息公开办法61号令或旧民非会计制度）→ 对外文书合规风险。
2. 把团体推荐标准当强制法规写进制度文件。
3. 只记法规名不记令号/年份，导致引用时无法精确定位。
4. 把"修订草案"当成已生效条文。
