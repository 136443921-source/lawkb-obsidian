# 数字化资金拨付执行操作卡（腾讯公益·微信支付）

> 本卡为「数字工具操作卡」新卡型（方案A），拆解自《贵州基层慈善组织数字化工具与合规操作手册》第六章 6.1（p160-186）。
> ⚠️ 平台界面为 2026-06 版手册截图，平台功能可能已迭代，操作前请核对当前界面；本卡按钮路径以手册为准，正式发文前以腾讯公益机构服务平台现行界面核对。

## 一、操作定位与适用场景
腾讯公益平台「数字化执行工具」中的**资金拨付执行**模块，通过微信支付将公益补贴直接发放至受益人微信零钱（或解析银行卡拨款凭证）。解决传统发现金/银行卡转账周期长、痕迹不清、难以系统管理受益人档案的痛点。
- **适用场景**：奖学金发放（学生领微信零钱）、生活补助、医疗救助金、项目执行人员劳务补贴。
- **核心优势**：到账快（实时到微信零钱）、痕迹清（实名三要素校验）、成本低、可系统化管受益人档案、自动生成执行报告与受益人画像、自动进展反馈（复捐转化率约为图文反馈 3 倍）、兼容既有银行卡拨款模式。

## 二、按钮级步骤（操作流程）
**步骤1 创建项目**：登录 `org.gongyi.qq.com` → 左侧「数字化执行工具」→「项目管理」→ 创建项目。可选腾讯公益平台项目（自动打通进展反馈+后续财披）或其他平台/机构内部项目。
**步骤2 导入受益人**：「资助批次管理」→ 新建资助批次 → 填批次名称/资助周期/备注 → 下载 Excel 模板批量导入（后台自动校验姓名+身份证，失败给提醒）。
**步骤3 受益人身份认证**：项目管理页下载项目身份认证码，发给执行人员/受益人；受益人微信搜「公益项目助手」小程序 → 找本项目 → 认证（姓名+身份证+人脸三要素）。⚠️ 须先认证通过才能放款。
**步骤4 开通拨付通道**（二选一）：
- 银行卡拨款：直接上传从银行客户端下载的转账凭证（**勿用拍照/扫描件**）→ 支持腾讯云 OCR 或元宝 AI 解析 → 确认结果，记录沉淀至受益人资助档案。
- 微信支付拨款：①确认是否为腾讯公益下子商户号（公募机构通常已开筹款子商户号；非公募需先申请转账子商户号）；②开通运营账户（`pay.weixin.qq.com` → 产品中心 → 我的产品 → 运营账户）；③「拨款商户号管理」→ 申请开通商家转账 → 超管登录商户平台消息中心授权（**须超管**，需密码+验证码）。
**步骤5 商户号充值**：财务登录微信支付商户平台，充值到**运营账户**（须足额）。
**步骤6 向受益人拨款**：资助批次选名单 / 新建拨付单 → 微信拨付 → 确认金额（默认最大可拨付额）→ 发起，受益人收短信提醒。
**步骤7 受益人领取**：短信+小程序订阅消息提醒，点击进入小程序领取，**30 天领取有效期**。
**步骤8 下载凭证**：微信拨付 → 拨付管理 → 更多 → 下载转账凭证/转账单，供对账与审计。

## 三、关键校验点
- 受益人/监护人**实名三要素（姓名+身份证+人脸）认证通过**后方可放款；身份证号是系统唯一标识、录入后不可改。
- 微信支付拨付：姓名+身份证号必填；银行卡拨付：姓名+银行卡号必填。
- 凭证须从银行客户端下载（非拍照件/扫描件），避免 OCR 识别不准；同一转账凭证勿重复上传（系统唯一性校验）。
- 商户号运营账户须充值足额再发起拨付。
- 老模式（菜单为"商户托管"）切新模式（菜单为"商户号管理"）后：受助人需**主动领取**（不再即时到账），且超管不再收验密提醒；建议先试拨一笔再批量拨。

## 四、常见报错与处置
| 现象 | 处置 |
|---|---|
| 领款人领取提示 `function not exist` | 领取人微信更新到最新版本 |
| 拨款后提示"超过系统重试期，系统自动关闭" | 领款人点击领取后 24h 内未确认收款，系统自动接单关闭；重新发起一次拨付即可 |
| 一直无法开通商家转账到零钱 | 先查商户号/主体是否有违规记录并先行处理；仍不行按指定模板邮件申请恢复出金权限 |
| 领取提示"证书初始化失败" | 新商户号默认公钥模式，若系统未兼容可自助切平台证书模式（商户平台→账户中心→API 安全→微信支付公钥） |
| 更换监护人代领 | 更新新监护人姓名/身份证/手机号 → 发认证码给新监护人完成一次认证即可代领（受益人本人已认证的优先发本人） |
| 导入提示姓名与身份证不匹配 | 多为年龄大受益人未在公安部备案网络身份，按"如何开通网络身份识别"文档操作 |

## 五、依据（平台规则＋法定接口）
**平台规则**：腾讯公益机构服务平台 `org.gongyi.qq.com`、微信支付商户平台 `pay.weixin.qq.com`（运营账户/商家转账开通）。
**法定接口（⚠ 手册原文存在法条硬伤，已按官方现行版纠正，不照抄）**：
- 受益人/监护人信息须真实、准确（姓名、身份证、手机号）：《慈善法》（2023 修正）第 59、60 条（慈善服务）。
- 资金拨付须符合项目预算与实施方案：《关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定》（民发〔2026〕12 号）第 4、5、6 条。
- 领取/拨付记录须保存以备查：《慈善法》第 77 条（信息公开义务）；《慈善组织信息公开办法》（**民政部令第 81 号，2026-01-01 施行**）第 2 条。
  - 🔴 **纠正手册错误**：手册称"《慈善组织信息公开办法》（2023 修订）第 13、42、78 条"——①该办法现行为 **81 号令（2026.1.1 施行）**，无"2023 修订"版本；②81 号令**无第 13/42/78 条**（系慈善法条号被误串入）。本卡以官方现行版为准，正式引用前以 mca.gov.cn 二次核对条号。
- 不得泄露受益人隐私：《慈善法》第 82 条、《慈善组织信息公开办法》第 21 条。
- 📌 **平台规则 ≠ 法定义务**：手册所述"领取记录保存至少 5 年"属平台/内控要求，法定会计档案与信息公开保存年限以《会计法》《慈善组织信息公开办法》等为准；本卡不将其表述为法定强制年限。

**官方核验指引**：国家法律法规数据库 `https://flk.npc.gov.cn/` ＋ 民政部 `https://www.mca.gov.cn/` ＋ 最高法官网，正式引用前二次核对条号与令号。

## 六、风险等级
**中**。涉及受益人隐私（姓名/身份证/人脸/手机号）与资金安全（商户号出金权限、超管权限）。须严格落实机构服务平台成员管理——仅机构负责人持超管，按部门/岗位分配角色，定期盘点清理账号权限。

## 七、边界
- 本卡仅覆盖**腾讯公益平台"数字化执行工具"资金拨付**的按钮级操作，不替代法定财务核算。
- "款物到达最终受益人"的法定确认以**转账凭证＋受益人签收**为核心证据链，详见 [[R-CF-138-款物到达最终受益人财务核算合规审查卡]]。
- 非公募机构须先申请腾讯公益子商户号，方可开通微信支付拨款。
- 平台界面为 2026-06 版，迭代后路径可能变化，以现行界面为准。
