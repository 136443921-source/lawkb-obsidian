# 桌面AI智能体与知识库管理操作指引卡

## 一、操作定位与适用场景

面向慈善组织工作人员，系统规范"桌面AI智能体 + 知识库"的选择、安装、使用与日常治理。本章是「贵州省基层慈善组织数字化运营手册」第八章，定位为机构的"AI工具落地操作手册"。

典型适用场景：
- 机构首次引入AI工具（选型、安装、建知识库）；
- 项目部/财务部用AI生成项目申请书、结项报告、财务说明、合规检查清单；
- 用知识库沉淀法规、项目档案、培训资料，实现语义检索与AI引用；
- 制定AI工具推广计划、治理机制与合规风险防范。

## 二、操作依据

1. 《中华人民共和国网络安全法》（主席令第五十三号，2017年6月1日施行，2025年10月28日修正，现行有效）——网络运营者安全等级保护、日志留存、数据加密、个人信息保护义务。
2. 《中华人民共和国数据安全法》（主席令第八十四号，2021年9月1日施行，现行有效）——数据分类分级、全流程安全义务。
3. 《中华人民共和国个人信息保护法》——捐赠人个人信息处理须获授权、最小必要、脱敏。
4. 《互联网信息服务深度合成管理规定》（国家网信办、工信部、公安部令第12号，2023年1月10日施行，现行有效）——AI生成内容标识、算法管控、虚假信息处置。
5. 选型合规底线（手册8.1.4）：产品须符合上述三法；数据服务器存储境内、不涉及跨境传输；具备网络安全等级保护三级测评备案资质。

> 正式引用前以 mca.gov.cn / 国家网信办 / 中国人大网 二次核对条号与现行有效性。

#### 配套法源 verbatim（现行有效版本·本地权威源核填）

> 来源：《中华人民共和国个人信息保护法》（2021-08-20 第十三届全国人民代表大会常务委员会第三十次会议通过，2021-11-01 施行，现行有效）。以下条文为官方 verbatim 逐字引用。
> 另含 网络安全法 / 数据安全法 / 互联网信息服务深度合成管理规定 关键条文 verbatim，本地权威源已回填（见下方分节及 `法律法规库/通用法律法规/` 同名·关键条文回填版文件）。

**第13条（处理个人信息的合法性基础）**
符合下列情形之一的，个人信息处理者方可处理个人信息：（一）取得个人的同意；（二）为订立、履行个人作为一方当事人的合同所必需，或者按照依法制定的劳动规章制度和依法签订的集体合同实施人力资源管理所必需；（三）为履行法定职责或者法定义务所必需；（四）为应对突发公共卫生事件，或者紧急情况下为保护自然人的生命健康和财产安全所必需；（五）为公共利益实施新闻报道、舆论监督等行为，在合理的范围内处理个人信息；（六）依照本法规定在合理的范围内处理个人自行公开或者其他已经合法公开的个人信息；（七）法律、行政法规规定的其他情形。依照本法其他有关规定，处理个人信息应当取得个人同意，但是有前款第二项至第七项规定情形的，不需取得个人同意。

**第28条（敏感个人信息定义与处理条件）**
敏感个人信息是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。只有在具有特定的目的和充分的必要性，并采取严格保护措施的情形下，个人信息处理者方可处理敏感个人信息。

**第29条（敏感个人信息·单独同意）**
处理敏感个人信息应当取得个人的单独同意；法律、行政法规规定处理敏感个人信息应当取得书面同意的，从其规定。

#### 配套法源 verbatim·网络安全法（本地权威源核填）

> 本地权威源：`法律法规库/通用法律法规/中华人民共和国网络安全法（主席令第53号）·关键条文回填版.md`（源：人民网·中国人大网全文转载）。以下为官方 verbatim 逐字引用。

**第二十一条（网络安全等级保护制度·网络运营者安全保护义务）**
国家实行网络安全等级保护制度。网络运营者应当按照网络安全等级保护制度的要求，履行下列安全保护义务，保障网络免受干扰、破坏或者未经授权的访问，防止网络数据泄露或者被窃取、篡改：（一）制定内部安全管理制度和操作规程，确定网络安全负责人，落实网络安全保护责任；（二）采取防范计算机病毒和网络攻击、网络侵入等危害网络安全行为的技术措施；（三）采取监测、记录网络运行状态、网络安全事件的技术措施，并按照规定留存相关的网络日志不少于六个月；（四）采取数据分类、重要数据备份和加密等措施；（五）法律、行政法规规定的其他义务。

**第四十一条（个人信息收集、使用原则）**
网络运营者收集、使用个人信息，应当遵循合法、正当、必要的原则，公开收集、使用规则，明示收集、使用信息的目的、方式和范围，并经被收集者同意。网络运营者不得收集与其提供的服务无关的个人信息，不得违反法律、行政法规的规定和双方的约定收集、使用个人信息，并应当依照法律、行政法规的规定和与用户的约定，处理其保存的个人信息。

#### 配套法源 verbatim·数据安全法（本地权威源核填）

> 本地权威源：`法律法规库/通用法律法规/中华人民共和国数据安全法（主席令第84号）.md`（已升级：qcc 元信息 + 关键条文 verbatim；源：人民网·新华社全文转载）。以下为官方 verbatim 逐字引用。

**第二十一条（数据分类分级保护制度）**
国家建立数据分类分级保护制度，根据数据在经济社会发展中的重要程度，以及一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护。国家数据安全工作协调机制统筹协调有关部门制定重要数据目录，加强对重要数据的保护。关系国家安全、国民经济命脉、重要民生、重大公共利益等数据属于国家核心数据，实行更加严格的管理制度。各地区、各部门应当按照数据分类分级保护制度，确定本地区、本部门以及相关行业、领域的重要数据具体目录，对列入目录的数据进行重点保护。

**第二十七条（全流程数据安全管理制度）**
开展数据处理活动应当依照法律、法规的规定，建立健全全流程数据安全管理制度，组织开展数据安全教育培训，采取相应的技术措施和其他必要措施，保障数据安全。利用互联网等信息网络开展数据处理活动，应当在网络安全等级保护制度的基础上，履行上述数据安全保护义务。重要数据的处理者应当明确数据安全负责人和管理机构，落实数据安全保护责任。

> 官方核验指引：依据人民网（新华社全文转载）2021-06-11 文本逐字回填；正式引用前以中国人大网 / 国家法律法规数据库现行版本二次核验。

#### 配套法源 verbatim·互联网信息服务深度合成管理规定（本地权威源核填）

> 本地权威源：`法律法规库/通用法律法规/互联网信息服务深度合成管理规定（国家网信办等令第12号）·关键条文回填版.md`（源：中国政府网政策法规库）。以下为官方 verbatim 逐字引用。

**第九条（真实身份信息认证）**
深度合成服务提供者应当基于移动电话号码、身份证件号码、统一社会信用代码或者国家网络身份认证公共服务等方式，依法对深度合成服务使用者进行真实身份信息认证，不得向未进行真实身份信息认证的深度合成服务使用者提供信息发布服务。

**第十一条（辟谣机制·虚假信息处置）**
深度合成服务提供者应当建立健全辟谣机制，发现利用深度合成服务制作、复制、发布、传播虚假信息的，应当及时采取辟谣措施，保存有关记录，并向网信部门和有关主管部门报告。

**第十七条（显著标识·AI生成内容标识）**
深度合成服务提供者提供以下深度合成服务，可能导致公众混淆或者误认的，应当在生成或者编辑的信息内容的合理位置、区域进行显著标识，向公众提示深度合成情况：（一）智能对话、智能写作等模拟自然人进行文本的生成或者编辑服务；（二）合成人声、仿声等语音生成或者显著改变个人身份特征的编辑服务；（三）人脸生成、人脸替换、人脸操控、姿态操控等人物图像、视频生成或者显著改变个人身份特征的编辑服务；（四）沉浸式拟真场景等生成或者编辑服务；（五）其他具有生成或者显著改变信息内容功能的服务。深度合成服务提供者提供前款规定之外的深度合成服务的，应当提供显著标识功能，并提示深度合成服务使用者可以进行显著标识。

> 官方核验指引：依据中国政府网（政策法规库）2022-12-12 全文逐字回填；正式引用前以国家互联网信息办公室（www.cac.gov.cn）现行版本二次核验。上述义务主体多为"深度合成服务提供者"（平台侧）；慈善组织作为"使用者"合规要点——不利用 AI 制作传播虚假信息（第六条）、对外发布 AI 生成内容时督促/确认显著标识（第十七条）、建立内部事实核验与纠错机制（第十一条精神）。

## 三、操作流程步骤

### （一）桌面AI智能体选型（8.1）
1. 选型五大原则：合规性优先 → 易用性 → 集成能力 → 成本可控 → 技术支持。
2. 主流产品对比要点：WorkBuddy（腾讯，深度集成腾讯生态，基础版免费）、Notion AI（笔记+AI，10美元/人/月）、Obsidian+Copilot（本地优先、免费基础版）、Cursor（面向程序员，慈善组织不推荐）、豆包桌面版（字节，免费基础版，文本生成强）。
3. 贵州基层慈善组织推荐配置：首选 WorkBuddy（免费、集成腾讯生态、中文界面）；备选 豆包（文本生成能力）。

### （二）WorkBuddy 安装与初始配置（8.2.1）
- 系统要求：Windows 10+ / macOS 12+ / Linux（Ubuntu 20.04+）；内存 8GB 以上（推荐16GB）；稳定互联网（部分功能可离线）。
- 安装步骤：访问官网 https://www.workbuddy.cn 下载对应系统版本 → 双击安装（macOS 拖入"应用程序"）→ 首次启动用微信扫码登录、绑定手机号。
- 日常使用（8.2.2）：点击"新建任务"输入自然语言指令；点"+"上传本地/腾讯文档/ima文件（支持 Word/Excel/PDF/Markdown）；切换模式（craft/ask/plan）、模型（Auto/Deepseek/Kimi/GLM 等）、技能与第三方应用。
- 高效技巧：指令明确具体（"生成2025年'温暖贵州'项目结项报告，含背景/执行/资金/成效四部分"）；复杂任务分步执行（先大纲后正文、先分析后图表）；善用知识库；AI出错直接指出并纠正。

### （三）技能管理（8.2.3）
- 技能即预定义任务模板（类"快捷指令"），在"新建任务"中生效。
- 安装：WorkBuddy 技能市场浏览/搜索 → 点击"安装"。
- 慈善组织推荐技能包：公益文书助手、腾讯技术公益智能助手、公益财会助手、阳阳·支教志愿者智能体；进阶可"添加技能→创建技能"自定义（如"月报生成"）。

### （四）隐私与高级设置（8.2.4）
- 多模型切换（Hy3 preview / GLM / Kimi / Deepseek）；协作模式（分享任务链接多人共编）；版本管理（每版自动保存、可回溯）；API接入（需技术支持）。
- 隐私设置：本地模式（数据仅存本机）/云端模式（AES-256加密同步）；对话记录可删、可设自动删除期限；合规建议——捐赠人个人信息不上传AI、敏感信息用本地模式、定期清理已上传文件。
- 贵州推荐隐私配置：存储位置本地或云端（按设备数）；自动删除期限 90 天（呼应《慈善组织信息公开办法》要求）；敏感数据过滤开启（自动拦截身份证号、银行卡号）。

### （五）ima 知识库配置与上传（8.3）
- 创建：登录 https://ima.qq.com 或微信小程序"ima知识库" → 建"个人/共享知识库" → 命名（如"贵州省厚德公益基金会知识库"）→ 可见范围建议"仅团队成员可见"。
- 权限：管理员（上传/删除/管成员，建议秘书长/主任）/ 编辑者（上传编辑，建议项目官员）/ 查看者（仅查看搜索，建议实习生）。
- 集成 WorkBuddy：在 WorkBuddy"连接第三方应用"中找到 ima 知识库授权。
- 上传规范：支持 docx/pdf/md/xlsx/csv/jpg/png/mp4；命名 [类别]文件名_版本号_日期（如 [法规]慈善法_正式版_20240101）；加元数据标签（类别/年份/部门）；批量上传最多 100 个/次。

### （六）知识检索、引用与维护（8.3.3–8.3.4）
- 语义检索（非关键词匹配）：法规查询、项目参考、合规检查，AI自动标注引用来源并可跳转原文件；检索不到时明确告知"知识库未找到，建议补充上传"。
- 提高准确率：上传时填清晰标题+摘要；定期清理已废止/过期文件（避免AI引用旧法）。
- 维护节奏：每日查索引与反馈；每周审权限变更与重复文件；每月审访问日志与更新法规；每年全面审查与效果评估（覆盖率>80%、准确率>95%、活跃度>70%、贡献度>10个/月）。

### （七）实施路线图（8.4.1）
- 试点期（1–3月）：3–5人小团队（项目部+财务部），装WorkBuddy、建ima库、上传常用资产，月完成≥10个AI任务、至少1个流程被优化。
- 推广期（4–6月）：全员培训、建AI案例库、补知识库，80%员工熟练、知识库文件100+。
- 深化期（7–12月）：开发自定义技能、系统集成（腾讯公益/企业微信）、建AI治理机制，≥3个核心流程自动化。

## 四、合规红线与禁止事项

1. 捐赠人个人信息（姓名、电话、住址、身份证号、银行卡号）**不得上传AI**；确需引用须脱敏（"张三"→"捐赠人A"）并设访问权限。
2. 未公开的战略规划等敏感信息建议使用本地模式，不上云。
3. AI生成的重要文件（项目申请书、结项报告、合规结论）**必须经人工复核并签名确认**，不得直接对外发布。
4. 不得未经授权收集、使用捐赠人个人信息（违反《个人信息保护法》）。
5. 若AI用于自动决策（如自动拒绝某类申请），须公开算法逻辑于机构制度并提供人工复核机制。
6. AI辅助生成内容的版权归属须在员工手册中明确（建议"归机构所有"）。

## 五、常见错误与风险

1. **AI幻觉**：编造不存在的法规条款或数据 → 防：建立AI输出审核流程，指令约束"必须引用具体数据文本，不得凭空生成"。
2. **过度依赖**：员工丧失独立思考 → 防：定期"AI vs 人工"对比测试，将AI能力纳入绩效但非"唯AI论"。
3. **技术依赖**：WorkBuddy服务器故障致业务瘫痪 → 防：保留传统方式（Word手动撰写），定期导出知识库避免数据锁定。
4. **数据泄露**：敏感信息上传云端 → 防：本地模式+敏感数据过滤+定期清理。

## 六、工具模板清单
