# 核心要旨

基金会**不是"合规通行证"**。项目合规与否，从来不取决于合作方是不是基金会；借基金会"公益性"为药企学术推广提供"合规外衣"的操作，在审计署穿透式稽查下已被反复定性为"打着慈善旗号营利"。本卡锚定**厚德基金会与药企的项目合作**（医疗救助、患者教育、基层培训等），提供合作模式红线和评估框架。

## 一、审计署警钟：基金会"公益性不足"成定性关键词

- 2025年6月审计署发布**2024年度审计报告**：**4家基金会**打着慈善旗号营利，涉及金额**3.41亿元**；**12家学协会**通过论坛为企业品牌推介等不当获取收入**3.08亿元**。
- 自2023年起审查逐年收紧，"偏离定位违规获取收入""公益性不足"成为高频定性词。学协会与基金会这两个曾被视为"合规避风港"的主体，正被逐一穿透。
- 国家卫健委**"六个应当、六个严禁"**（国卫办医急函〔2023〕469号）对医务人员讲课取酬划红线：严禁直接接受医药企业给予的讲课费，严禁将学术讲课与产品推广挂钩；医药企业、会展会务公司等商业机构不在会议举办方和授课邀请方"白名单"内。

## 二、典型违规链条（借基金会"合规外衣"）

药企不能直接给医生钱 → 捐给基金会 → 基金会办学术活动 → 医生参与 → 获讲课费。该模式在"六个严禁"后更被"发扬光大"，非学术项目（患者教育、疾病筛查、基层培训）也被塞进基金会框架。**但基金会合作本身≠合规。**

审计署界定为"打着慈善旗号营利"的四类特征（任一即高危红旗）：
1. **资金闭环**：药企捐→基金会收→项目执行→受益人恰为药企目标人群；
2. **指定受益**：捐赠协议隐含或直接指定受益医生、医院、科室；
3. **变相推广**：名义"公益"，实质产品推介、品牌曝光；
4. **费用转嫁**：基金会只"过票"，策划、执行、嘉宾邀请均由药企幕后操控。

## 三、穿透式稽查：五流合一（财税角度）

监管验证"一笔钱从哪来、到哪去、中间经历什么、产生什么效果"，五流不一致即红旗：

| 维度 | 稽查要点 | 常见问题 |
|---|---|---|
| 合同流 | 捐赠协议与实际执行是否一致？阴阳合同？ | 协议写"患者教育"，实际"产品推广" |
| 信息流 | 策划书、议程、名单、照片视频是否完整？ | 只有展台无讲课，产品推介占比过高 |
| 资金流 | 是否公对公？有无回流？管理费是否合理？ | 药企→基金会→第三方→药企关联人闭环回流 |
| 票据流 | 发票内容与实际业务一致？虚开？ | 开"咨询服务费"实为活动赞助 |
| 业务流 | 真实受益人是谁？是否对公众开放？排他？ | 名义"开放学术会议"实则特指特定医院医生 |

## 四、内部管控四大领域

数据（立项依据/数据支撑/效果评估）、流程（立项审批执行结项完整留痕）、权责（业务/合规/财务/法务职责边界清晰）、风险（执行前风险评估、利益冲突/商业贿赂/数据泄露预案）。忽视内部管控完整性，即使合作方是红十字会，项目仍可能被认定违规。

## 五、纠正观念：非学术项目不必硬拉基金会

学术会议确需通过合规第三方（学协会/基金会/医院/高校）举办；但非学术项目可直接与专业第三方合作：

| 项目类型 | 合作对象 | 为何不需基金会 |
|---|---|---|
| 患者教育 | 专业患者组织、健康管理公司 | 受益人是患者群体，不涉及企业指定医生产生讲课费 |
| 疾病筛查 | 医学检验机构、体检中心 | 商业服务采购，市场定价 |
| 基层医生培训 | 医学院校、继续教育机构 | 正规机构出培训证书，路径清晰 |
| 市场调研 | 专业调研公司 | 商业委托，按合同法 |
| 数字化平台 | SaaS、技术外包 | IT采购，走招投标 |

核心原则：判断是否需要基金会，标准不是"有无学术内容"，而是**项目本身是否属公益捐赠性质、是否涉及对医疗机构/医务人员利益输送**。商业采购/专业服务委托用基金会作中间层，反而增加合规风险。

**基金会真正适用场景**（角色是公益资源整合者，非药企"合规通道"）：医疗救助（向贫困患者捐药、资助手术）、医学研究资助（独立基础/临床研究，不得指定方向或数据归属）、公共卫生项目（传染病防治、面向公众健康教育）。

## 六、警惕"过票型"基金会

1. 无独立项目管理能力（策划执行全由药企/第三方代劳）；
2. 管理费畸高（远超合理10%–15%，仅开票据+转账）；
3. 信息披露缺失（年报不披露具体项目或严重不符）；
4. 关联交易（理事、工作人员与药企关联，独立性存疑）。

与此类基金会合作，不仅不降风险，反而因"明知对方无公益能力仍合作"被认定共同违规。

## 七、给合规负责人的建议

1. **项目合规评估矩阵**：公益性（服务公共利益、含非特定公众？）、独立性（独立第三方主导、药企不过度干预？）、透明度（可公开、经得起抽查？）、必要性（必须基金会？直接采购更合理？）、风险可控性（利益冲突/回流/变相推广有应对？）。
2. **区分"捐赠"与"采购"**：公益捐赠走基金会，严格按《慈善法》《公益事业捐赠法》；商业采购走正常采购流程；学术活动走合规学协会/医疗机构，按"六个应当"执行。不把采购包装成捐赠，也不把捐赠变采购。
3. **强化内部留痕**：立项审批、会议签到议程照片纪要、合同发票流水验收、合规部书面意见。
4. **定期审计合作方**：查年报/审计报告、评执行能力与独立性、关注处罚记录。

# 办案衔接

- 厚德基金会承接药企合作项目（含医疗救助、科研资助、患者教育）前，须先过"公益性+独立性+必要性"三关；凡涉药企目标人群闭环、指定受益、产品挂钩的，一律按"过票型"高危处理，拒绝或重构。
- 基金会自身亦应建立"五流"台账与四大领域内控制度，以应对日益收紧的穿透式稽查。
- 与药企合作须走**回避决策+信息公开**双程序（参见 R-CF-122 关联交易边界），且不得附利益回报条件。
