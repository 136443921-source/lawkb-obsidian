# 裁判规则 R-SH-015：二十年最长权利保护期间的适用边界（指导案例249号）

**规则**：在债权人持续向债务人主张权利，普通诉讼时效因多次中断而期间未届满的情形下，债务人依据《民法典》第188条"自权利受到损害之日起超过二十年的，人民法院不予保护"的规定提出诉讼时效抗辩的，人民法院不予支持。

**规范依据**：
- 《民法典》第188条：普通诉讼时效期间三年（主观起算：知道或应当知道权利受损及义务人）；但自权利受损之日起超过二十年的，法院不予保护（客观起算之最长权利保护期间）。

**教义学要点（本规则的锋利之处）**：
1. **二元时效结构的"主从"关系**。第188条设两道闸门：三年普通时效（主观）+ 二十年最长保护期（客观兜底）。最长保护期不是"普通时效的升级版"，而是专门解决"权利人长期不知权利受损或不知义务人、无法主张"的例外情形。
2. **最长保护期的"短路"条件**。当权利人**已知或应知**权利受损、且**普通时效因中断而未届满**时，二十年最长保护期被排除适用——它是兜底，而非叠加罚则。本案债权人自2006年起连续催收、债务人多次签章确认，普通时效持续中断，自然不落入"长期不知"的兜底情形。
3. **诚实信用作为实质控制阀**。债务人在催收通知书上盖章签署"情况属实"，使债权人对履行产生合理期待而可能推迟诉讼；嗣后提时效抗辩有违诚信。这是法院不予支持抗辩的深层价值理由，也是实务中最难被形式化反驳的论证。

**攻防要点**：
- **蓝队（债权人/金融资管）**：在债权转让链条中保持"持续催收 + 留痕"——每次书面通知须有债务人签收或公告送达证据，构建不间断的"多次中断"证据链；债务人曾签章确认债务的，直接以诚信原则封堵其二十年抗辩。
- **红队（债务人）**：二十年最长保护期抗辩仅在"普通时效未中断 / 权利人长期不知"时成立；若曾签章确认或多次被催收，该抗辩基本被封堵，应转向利率标准、担保效力、债权转让通知瑕疵、主体资格等其它防线。

**尚存争议**：
- "权利人知道或应当知道"与"普通时效中断"的举证责任分配——债务人主张最长保护期时，是否须先证明债权人"早已知悉"，实务中证明负担有分歧。
- 最长保护期届满后，是否存在《民法典》第188条第2款但书"特殊情况法院可延长"的适用空间，指导案例未展开。
