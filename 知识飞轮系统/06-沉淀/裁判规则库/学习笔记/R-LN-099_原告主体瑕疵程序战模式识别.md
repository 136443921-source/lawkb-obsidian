# R-LN-048 原告主体瑕疵程序战模式识别

## 裁判规则（识别逻辑）

当**起诉状署名 / 身份证 / 营业执照**三处载明的原告姓名/名称出现**用字不一致**时，分身系统应**自动标记为「原告主体瑕疵」程序战疑点**，并按如下层次构建攻击：

- (a) **姓名不一致硬疑点**（本案核心）：起诉状署名「丁茂祥」≠ 身份证「丁戊祥」≠ 营业执照经营者「丁戊祥」（茂 vs 戊 用字不同），直接指向「原告真实姓名存疑、授权意思表示自始未作出」；
- (b) **本人否认起诉**（意思瑕疵）：丁戊祥本人《说明》（2026-08-20）无起诉意思 + 两份通话录音（2026-07-14 10'50"、2026-08-24 3'13"）本人否认起诉 + 法官电话核实亲耳听到否认 → 民法典第 143 条「意思表示真实」要件不满足 → 主张裁定驳回起诉；
- (c) **辅助线索（限 B 级）**：第三方企业数据平台（华宇元典）按统一社会信用代码查询营业执照未命中，仅作「建议法庭依职权核实」附证据，不作主线（个体工商户覆盖不全，查不到 ≠ 不存在）。

## 适用要点

1. **三层证据闭环（A 级 9 条 / B 级 1 条）**：署名不一致(A) + 身份证(A) + 营业执照(A) + 本人说明(A) + 当场情况说明(A) + 7-14 录音(A,9/1 庭上播放) + 8-24 录音(A,9/1 庭上播放) + 法官核实记录(A) + 元典查询(B)。A 级已闭环程序战主线。
2. **信用代码第 14 位 ≠ 核心**：营业执照统一社会信用代码 `92520330MACJE5T94X` 第 14 位为 `5`（校验位特征），属营业执照固有属性，**非**原告真实性核心疑点；核心疑点是「茂 vs 戊」用字不一致 + 本人否认起诉。
3. **逼原告到庭固化**：依《民诉法解释》第 110 条申请原告本人到庭签署保证书，拒绝到庭且待证事实缺其他证据的，法院不予认定——对原告方设「不到庭即败」两难（见 R-LN-049 / 6660 ⑨申请书）。
4. **防误关联边界**：① 刑事定性（虚假诉讼）机器不得自动得出，宁「存疑」；② 元典「查不到」不入卷、不作正式证据；③ 主体瑕疵攻防若波及并行案原告（如 6660 焦联鹏），须明确两原告非同一主体，避免口径冲突。

## 实证案例

- 6658 吊顶案（`(2026)黔0330民初6658号`）：丁茂祥（起诉状）vs 丁戊祥（身份证/营业执照）——姓名不一致 + 本人否认起诉 + 2 段录音，构成程序战主轴；异议书 10_《起诉真实性异议书》已被法庭引用。

## 援引法条（支撑性依据，非硬性裁判规则）

- 《民法典》第 143 条（民事法律行为有效要件：意思表示真实）；
- 《民事诉讼法》第 148 条第 1 款（撤诉：宣判前原告申请撤诉，是否准许由法院裁定）；
- 《最高人民法院关于适用〈民事诉讼法〉的解释》第 110 条（当事人本人到庭接受询问，拒绝到庭且待证事实缺其他证据的不予认定）。

> 注：原告主体瑕疵程序战属办案方法论，上述法条为「驳回起诉 / 逼原告到庭」的程序法支点，不作为该规则卡本身的法律效力来源。
