# R-LN-045 双锚点跨案识别规则

## 裁判规则（识别逻辑）

当两案同时命中「双锚点」——① **形式诉讼主体相同**（同被告 / 同原告 / 同当事人）② **实质交易主体相同**（同实际买受人 / 同实际交易相对人 / 同实际侵权人或受益人）——分身系统应**自动标记两案为跨案关联**，并触发以下动作：

- (a) 生成跨案关联图（以共有主体为枢纽，双案并置可视化）：
  `跨案关联图_黄茂姣_6658x6660.html`
- (b) 提示**并案核查**共有主体的交易 / 行为轨迹；
- (c) 建议**统一该主体的抗辩 / 举证口径**，避免两案口径打架；
- (d) 在知识飞轮沉淀层建立连接索引（02-提炼 / 03-连接 / 04-Log / 05-调用 / 06-沉淀）。

## 适用要点

1. **双锚点定义**：锚点一 = 形式诉讼主体（名义当事人）；锚点二 = 实质交易主体（实际买受人 / 实际相对人）。两锚点中**任一相同**即触发关联标记；**两锚点同时相同**为强关联（如本案黄茂姣同时是两案实际买受人、刘九零·刘维 同时是两案被告）。
2. **自动触发动作**：生成跨案关联图（金色枢纽 + 双案并置）→ 写入跨案模式识别调用记录 → 在飞轮沉淀层建立连接索引。
3. **证据级标注**：关联线索初判为 **B 级（待证）**，不得直接认定为已认定事实；共有主体身份须由证据坐实后方可升级为 A 级（强佐证）。
4. **防误关联边界**：① 须为"实质关联"（同主体 / 同事实 / 同标的），非仅姓名 / 字号相同；② 区分"主体混同"与"主体相同"——前者指向人格混同 / 连带责任，后者仅为线索并案；③ 刑事定性（如虚假诉讼）不得由机器自动得出，宁以"存疑"表述。
5. **实证案例**：6658 吊顶案（被告 刘九零·刘维，原告 丁戊祥，冒名诉讼）× 6660 雅菲窗帘案（被告 刘九零·刘维，原告 焦联鹏 / 雅菲软装，合同相对性），两案以"被告相同 + 实际买受人黄茂姣相同"构成双锚点强关联。

## 援引法条（支撑性依据，非硬性裁判规则）

- 《民事诉讼法》第 55 条（共同诉讼：一方或双方当事人为二人以上）；
- 《民事诉讼法》第 140 条（合并审理：可合并的诉讼请求）；
- 实体法视具体案由援引（合同相对性见《民法典》第 465 条、第 509 条；承揽 / 买卖见相关分编）。

> 注：双锚点识别属办案方法论，上述法条为"并案核查 / 统一口径"的程序法与实体法支点，不作为该规则卡本身的法律效力来源。
