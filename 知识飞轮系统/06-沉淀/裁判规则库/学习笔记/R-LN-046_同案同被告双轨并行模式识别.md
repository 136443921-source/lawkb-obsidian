# R-LN-046 同案同被告双轨并行模式识别

## 裁判规则（识别逻辑）

当两案**同时命中**——① **同一受理法院**（同一字号层级的民初案号，如均系 `(2026)黔0330民初`）② **相同被告**（自然人/法人/个体户为共同被告且主体一致）③ **近似案由**（均系买卖/承揽等合同争议）——分身系统应**自动标记为「双轨并行」关联案**，并触发以下动作：

- (a) 提示**统一两案抗辩 / 举证口径**，防止被告在双案中陈述打架（如本案 6658 走「否认原告真实性」程序战、6660 走「合同相对性 + 货款已清」实体防御，二者防御主轴不同但均须服务于「被告不担责」总目标，不得出现互相削弱的表述）；
- (b) 列出**可跨案复用证据资产**（同一录音、同一当事人说明、同一工商核验报告），提示在一案已质证的可在另一案援引；
- (c) 标注**合并审理可能性**：同法院 + 同被告 + 同类型合同，存在依《民事诉讼法》第 140 条合并审理空间，须提示法院是否合并、被告是否同意；
- (d) 在飞轮沉淀层建立跨案连接索引（02-提炼 / 03-连接 / 04-Log / 05-调用 / 06-沉淀）。

## 适用要点

1. **双轨并行的认定阈**：法院相同 + 被告相同 + 案由同族，三要件齐备即触发；仅被告相同但法院/案由不同，仅作「同案被告」弱关联标记，不当然并案。
2. **口径统一的红线**：双案被告答辩须逻辑自洽。本案实证——6658 主张「丁戊祥本人无起诉意思、原告主体不实」，6660 主张「合同相对性切断 + 黄茂姣为实际买受人、货款已清」；两案均指向「被告无过错/无给付义务」，不存在冲突，但 6658 的「原告真实性」攻防若波及 6660 原告焦联鹏，须明确两原告非同一主体。
3. **自动触发动作**：生成跨案关联图 → 写入跨案模式识别调用记录 → 沉淀层建连接索引。
4. **证据级标注**：关联线索初判 **B 级（待证）**，共有主体身份 / 共有证据须由证据坐实后方可升级 A 级（强佐证）。
5. **防误关联边界**：① 同被告但不同交易、不同标的、不同时间点，不当然合并；② 区分「主体混同」（人格混同/连带责任）与「主体相同」（仅并案线索）；③ 刑事定性（虚假诉讼）不得机器自动得出，宁「存疑」。

## 实证案例

- 6658 吊顶采购合同纠纷（`(2026)黔0330民初6658号`）：被告 刘九零·刘维，原告 丁戊祥（冒名诉讼程序战），习水法院。
- 6660 雅菲窗帘案（`(2026)黔0330民初6660号`）：被告 刘九零·刘维，原告 焦联鹏/雅菲软装，合同相对性 + 货款已清，习水法院。
- 两案以「法院相同 + 被告相同 + 买卖/承揽同族」构成双轨并行强关联；以「被告相同 + 实际买受人黄茂姣相同」构成 R-LN-045 双锚点强关联。

## 援引法条（支撑性依据，非硬性裁判规则）

- 《民事诉讼法》第 55 条（共同诉讼：一方或双方当事人为二人以上）；
- 《民事诉讼法》第 140 条（合并审理：可合并的诉讼请求）；
- 实体法视具体案由援引（合同相对性见《民法典》第 465 条、第 509 条）。

> 注：双轨并行识别属办案方法论，上述法条为「并案核查 / 统一口径 / 合并审理」的程序法支点，不作为该规则卡本身的法律效力来源。
