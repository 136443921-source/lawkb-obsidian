# 【要件映射指针】第42期·最高法/最高检典型案例集群：要件锚点与跨卡路由

## 集群概述

本期周报汇集最高人民法院、最高人民检察院发布的 5 批典型案例（竞争、商事解纷、知产、民生刑事、公益诉讼），构成"裁判规则 → 实务领域 → 智能体路由"的要件映射枢纽。本卡为**要件映射指针卡**，串联下列主卡，已随第42期一并入库；不重复承载规则细节，仅作分发与对标中枢。

> 范围说明：本指针卡仅归集"最高法/最高检（含联合发布）典型案例"类主卡 —— 02、04、05、08、09。地方法院一审宣判的重大个案（01 韩剑波、03 缅北魏家、10 倒查30年公诉动态）不属"典型案例发布"序列，不纳入本集群，避免混淆发布层级。

## 跨卡实务意义（集群级提炼）

- **司法裁判 + 行政监管双轴**：竞争法集群（02）与"内卷式"竞争行政配套（06，市场监管总局通知+严重违法失信名单）同源对标，企业合规应合并自查，避免"司法已判、行政再罚"的叠加风险。
- **从严惩治 + 行刑衔接主线**：民生刑事（08 医保骗保）与职务犯罪（01 自洗钱数罪并罚、10 倒查30年追诉）共同印证刑事政策"全链条从严、行刑无缝衔接"导向，辩护端与合规端均须前置评估。
- **公益诉讼预防性保护**：09 长征文化公益诉讼确立"未批先建即制发检察建议"的预防性保护范式，直接对接文保/文旅/地方政府项目合规，整改正向路径可走"活化利用+思政教育"。

## 关联智能体（统一分发）

- 商事合规 → 竞争法合规红线校验（02 / 06 行政配套）
- 商事纠纷 → 欠款纠纷调解路径推荐（04）
- 知识产权 → 种业侵权抗辩与赔偿计算（05）
- 刑事辩护 → 医保骗保案件定性校验（08）；职务犯罪数罪并罚/追诉审查（01 / 10）
- 行政合规 → 文保项目合规审查（09）
