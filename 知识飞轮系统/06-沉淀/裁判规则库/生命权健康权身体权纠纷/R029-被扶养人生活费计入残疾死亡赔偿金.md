# 裁判规则 R029 - 被扶养人生活费计入残疾/死亡赔偿金，年总额封顶

**规范来源**：法释〔2022〕14号第16、17、18条
**案号**：（规则型·未附个案案号，依司法解释提炼）
**审理法院**：各级法院普遍规则
**裁判要旨**：2022年人身损害赔偿标准修正后，**被扶养人生活费不再作为独立赔偿项目列项，而是计入残疾赔偿金或死亡赔偿金**。计算仍依被扶养人人数、年限、伤残等级系数，且**年赔偿总额累计不超过上一年度城镇居民人均消费支出额**。
**适用要点**：
1. 计算口径统一为**城镇居民人均消费支出**（城乡统一，不再区分农村/城镇）。
2. 多被扶养人情形须做"年总额封顶"控制，避免叠加超限额。
3. 实务中常因"是否计入、计入哪项、如何封顶"发生争议，需与残疾赔偿金分项核对。
4. 与精神损害抚慰金、医疗费等其他项目互不吸收。
**关联法条**：法释〔2022〕14号第15、16、17、18条
