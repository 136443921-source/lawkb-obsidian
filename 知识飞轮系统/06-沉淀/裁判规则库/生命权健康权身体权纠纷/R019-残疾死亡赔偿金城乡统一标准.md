# 裁判规则 R019 - 残疾/死亡赔偿金统一按城镇居民标准计算

**规范来源**：《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》（法释〔2022〕14号，2022-05-01 施行）第12、15、17、19条
**审理法院**：各级法院普遍规则
**裁判要旨**：2022 年修正后，残疾赔偿金、死亡赔偿金、被扶养人生活费**不再区分城镇与农村居民**，统一按受诉法院地上一年度**城镇居民人均可支配收入 / 城镇居民人均消费支出**计算，实现"同命同价"。
**适用要点**：
1. 引用旧解释"农村居民人均纯收入"标准的诉请与模板一律作废。
2. **就高原则**（第19条精神）：受害人住所地或经常居住地标准高于受诉法院地的，可按较高标准主张，需举证经常居住地满 1 年。
3. 被扶养人生活费已**计入**残疾/死亡赔偿金（第17条），不得作为独立项目重复主张。
4. 数据锚定一审法庭辩论终结时最新可得的省级统计年鉴。
**关联法条**：《民法典》第1179条、第1180条
