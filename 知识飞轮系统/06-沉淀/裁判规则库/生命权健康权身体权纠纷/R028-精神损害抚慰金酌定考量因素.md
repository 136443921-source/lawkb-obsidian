# 裁判规则 R028 - 精神损害抚慰金为独立项目，按六因素酌定

**规范来源**：《民法典》第1183条；法释〔2020〕17号（2021修正）第5条
**案号**：（规则型·未附个案案号，依司法解释提炼）
**审理法院**：各级法院普遍规则
**裁判要旨**：精神损害抚慰金是与残疾/死亡赔偿金**并列独立**的赔偿项目；造成残疾、死亡的当然认定"严重精神损害"应予支持。数额由法院综合**侵权人过错程度、侵害手段/场合/行为方式、侵权后果、侵权人获利、侵权人担责经济能力、受诉法院所在地平均生活水平**六因素酌定，**不适用城乡收入标准区分**。
**适用要点**：
1. 一般未达伤残等级且无其他严重情节的，原则不支持；侵害人身意义特定物（遗照、骨灰等）例外。
2. 交强险内可请求**优先赔付**精神损害（道交解释第16条），伤者方应主动主张排序。
3. 商业三者险多将精神损害列为免责，最终常由侵权人自行承担，诉请应单列。
4. 无全国统一上限，地区差异显著（死亡抚慰金京沪约8万–10万，中西部约5万–7万）。
**关联法条**：《民法典》第1183条；法释〔2020〕17号第1、5、6条
