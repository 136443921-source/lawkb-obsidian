# 请求公司收购股权、股份纠纷单案由路由卡（R-AY-284｜2025 §297／2020 §268）

> **一句话定位**：异议股东（含权益受损股东）依公司法请求**公司**以合理价格收购自身持有的公司股权/股份的**退出型诉讼**——与 296（查账）、304（分红）、305（赔偿）、298（转让退出）构成「公司纠纷退出—主张」链条的**异议回购环节**，是中小股东对抗控股股东压迫、实现「用脚投票」的法定通道。

## 二、受案范围与核心特征

股东依公司法规定，在法定情形成就时请求公司收购其持有的股权/股份：

- **有限公司（§89）**：①连续五年盈利不分配且符合分配条件；②公司合并、分立、转让主要财产；③章程营业期限届满/解散事由出现而修章存续，股东投反对票；＋③**控股股东滥用权利严重损害公司或其他股东利益**（§89 第3款，俗称「反控股股东压迫条款」，2023 新增）。
- **股份公司（§161，公开发行股份公司除外）**：①连续五年盈利不分配；②转让主要财产；③章程存续修章，股东投反对票。
- **前置程序**：自股东会决议作出之日起 **60 日内**协商，不成则 **90 日内**起诉（§89/§161）。
- **公司侧**：回购后 6 个月内依法转让或注销（§89 第3款、§161）；股份公司自身收购例外见 §162。

**核心特征 = 股东对特定决议投反对票（或控股股东滥用致损） ＋ 法定回购情形 ＋ 请求公司收购**。是股东了解公司经营、财务真实状况后**实现退出的终局手段之一**。

## 四、管辖（🔴 兜底型，弱于 281）

《民事诉讼法》2023 §27 明文列举「公司设立、确认股东资格、**分配利润**、解散」——**「请求公司收购股权、股份」不在列举项**；《民诉法解释》第22条列举（股东名册记载、请求变更公司登记、股东知情权、公司决议、公司合并、公司分立、公司减资、公司增资）亦不含本卡，仅能靠「等」兜底归入公司住所地管辖，与 R-AY-277（决议）/279（证照）/280（设立人责任）/282（损害股东利益）/283（知情权）同型（兜底型），**论证强度显著弱于 R-AY-281 公司盈余分配（「分配利润」明文列举）、R-AY-272 股东资格确认（「确认股东资格」明文列举）**。

**立案双轨策略**：起诉状同时备「公司住所地（§27 兜底）」与「被告住所地（一般地域管辖）」两派依据，避免管辖争议卡立案（同 R-AY-279/280/282/283）。

## 五、最高价值段（老强点名：讲透 297 与 296/304/298/305 的「退出—主张」链条）

### 5.1 297 自身定位：异议回购·退出环节

297 是股东在「查账（296）→分红（304）→赔偿（305）」主张均无法解决其诉求时，依法定情形**迫使公司收购自身股权/股份、实现退出**的终局手段。与小股东「用脚投票」救济直接相关，尤其 §89 第3款「反控股股东压迫条款」为缺乏退出机制的小股东提供新通道。

### 5.2 ⚠️ 297 vs 298 股权转让（最高频易混）

| 维度 | 297 请求公司收购股权、股份 | 298 股权转让纠纷 |
|---|---|---|
| 相对方 | **公司**（公司回购） | 第三人（受让股东） |
| 价金来源 | 公司 | 受让方 |
| 性质 | 法定回购退出（组织法） | 合同交易退出（交易法） |
| 触发 | 法定情形（反对决议/控股股东滥用） | 合意/强制（含优先购买权） |

🌐 股东先与第三人谈转让不成、转而依法定情形请求公司回购，则落 **297**；若仅为股权买卖纠纷则落 **298**。二案不竞合。

### 5.3 297 与 296/304/305 的「查账—主张—退出」链条

- **296 → 297**：股东查账（296）后发现公司长期不分配/压迫小股东，可进而主张 297（异议回购）。
- **304 → 297**：连续五年盈利不分配是 §89 第(一)项回购触发情形之一，分红之诉（304）常与回购之诉（297）衔接；要分钱→304、要退出→297。
- **299 → 297**：297 以「对股东会该项决议投反对票」为前提，决议（合并/分立/转让主要财产/存续）效力可能在 299 中一并争议。
- **305 ↔ 297**：§89 第3款「控股股东滥用权利严重损害其他股东利益」触发回购，与 305（控股股东损害股东利益）交叉；297 是请求公司收购退出、305 是请求赔偿。

### 5.4 「退出—主张」链条总览

```
公司纠纷·退出—主张链条
├─ 296 股东知情权纠纷 ← 查账取证（基础）
├─ 304 公司盈余分配纠纷 ← 要分钱（给付）
├─ 305 损害股东利益责任纠纷 ← 要赔钱（赔偿）
├─ 299 公司决议纠纷 ← 反对决议前提
└─ 297 请求公司收购股权、股份纠纷 ← 本卡（异议回购·退出终局）
```

🌐 **总口诀**：查不清账用 296、分不到钱用 304、赔不到钱用 305、决议侵权用 299、被压迫要退出用 297——297 是中小股东的「最后退路」。

## 六、立案/审理要点提示

1. **案由选择**：符合法定回购情形、请求公司收购→297；若为股权买卖→298；若同时主张决议撤销→另立 299；不得笼统用「股东权益纠纷」涵盖。
2. **前置程序**：须先对股东会该项决议**投反对票**，并于决议作出之日起 **60 日内**与公司协商，不成则 **90 日内**起诉（§89/§161）；未经前置或超期径诉可能被驳。
3. **回购价格**：「合理的价格」——协商不成由法院酌情（可委托评估），非当然照出资额或账面净值。
4. **控股股东滥用（§89 第3款）**：无须「反对决议」前提，只要控股股东滥用权利严重损害公司或其他股东利益即可主张，是 2023 新增的「反压迫」通道，与 305 交叉但救济方式不同（收购退出 vs 赔偿）。
5. **管辖双轨**：见四、，备「公司住所地（§27 兜底）/被告住所地」两派依据。
