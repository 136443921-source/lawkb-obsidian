## 二、释义与构成要件（本书【释义】段）

建设工程合同是承包人进行工程建设，发包人支付价款的合同（§788），包括**勘察、设计、施工**。

**主体**：发包人一般为建设单位（「业主」）；承包人包括总承包单位、勘察承包、设计承包、施工承包及分包单位。

**各第四级释义要点**：

| 第四级 | 关键界定 |
|---|---|
| 勘察合同 | 查明、分析、评价建设场地地质地理环境特征与岩土工程条件，编制勘察文件；勘察人一般为**专门地质工程单位** |
| 设计合同 | 含**初步设计合同**（立项阶段，为项目决策提供可行性资料设计）与**施工设计合同** |
| 施工合同 | 含**建筑**（对工程进行营造）与**安装**（线路、管道、设备等设施装配），有时二者合一 |
| 价款优先受偿权 | 承包人就工程折价或拍卖价款**优先受偿**（§807） |
| 分包合同 | 相对**总承包**而言，须**经发包人同意**；勘察/设计承包人分包与施工承包人分包**管辖规则不同**（见 5.3） |
| 监理合同 | **本质为委托合同**，因与建设工程密切相关而归入本项下 |
| **装饰装修合同** | **建筑装饰装修企业**与发包方订立；指对建筑物、构筑物**外表和内部进行修饰处理**的工程建筑活动 |
| 铁路修建合同 | 又称铁路建设工程施工合同 |
| 农村建房施工合同 | 农村建房户与施工方为建设房屋订立 |

## 三、管辖（🔴 条号已漂移 + ⚠️ 文义张力）

本书引《民事诉讼法》**第 33 条第 1 项**（2021 版）→ **2023 修正后现行为第 34 条第 1 项**：

> **第三十四条**　下列案件，由本条规定的人民法院专属管辖：（一）因不动产纠纷提起的诉讼，由不动产所在地人民法院管辖；……

**《民诉法解释》第二十八条**（2022 修正，北大法宝核填）：

> 第二十八条　民事诉讼法第三十四条第一项规定的不动产纠纷是指因不动产的权利确认、分割、相邻关系等引起的物权纠纷。
> **农村土地承包经营合同纠纷、房屋租赁合同纠纷、建设工程施工合同纠纷、政策性房屋买卖合同纠纷，按照不动产纠纷确定管辖。**
> 不动产已登记的，以不动产登记簿记载的所在地为不动产所在地；不动产未登记的，以不动产实际所在地为不动产所在地。

**本书的扩张解释（PDF页386 / 书页356，原文）**：

> 「根据《民事诉讼法解释》第 28 条精神，『建设工程施工合同纠纷』并不限于本案由中的第四级案由『建设工程施工合同纠纷』，还包括第四级案由『建设工程价款优先受偿权纠纷』『建设工程分包合同纠纷』『建设工程监理合同纠纷』『**装饰装修合同纠纷**』『铁路修建合同纠纷』『农村建房施工合同纠纷』。」

> **⚠️ 实务张力点（必须向法庭明示，不可只押一头）**
> 《民诉法解释》第 28 条第 2 款的**文义仅列举「建设工程施工合同纠纷」**，**未出现装饰装修等六个第四级**；本书采**扩张解释**将其纳入。
> - **主张专属管辖方**：援引本书口径（最高人民法院释义）＋《律师办理建设工程法律业务操作指引》§121.2 佐证；
> - **反对方**：可据文义作狭义抗辩，主张「装饰装修非第 28 条列明案由」。
> **→ 承办人应同时准备两套说理，并预先核查受诉法院所在地高院的口径。**

**《民法典》**（本地法律法规库核填）

**第七百八十八条**　建设工程合同是承包人进行工程建设，发包人支付价款的合同。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第八百零七条**　发包人未按照约定支付价款的，承包人可以催告发包人在合理期限内支付价款。发包人逾期不支付的，除根据建设工程的性质不宜折价、拍卖外，承包人可以与发包人协议将该工程折价，也可以请求人民法院将该工程依法拍卖。建设工程的价款就该工程折价或者拍卖的价款优先受偿。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第八百零八条**　**本章没有规定的，适用承揽合同的有关规定。**
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

## 五、定性边界 ⭐

### 5.1 建设工程 ⊆ 广义承揽，但案由各自独立

- §808 明定**本章无规定的适用承揽合同的有关规定** → 二者是**特别与一般**的关系；
- 但案由体系上**各自独立**（建设工程 120 / 承揽 119），**不得混用**；
- **不动产的修缮**引发的纠纷 → 归**承揽项下「修理合同纠纷」**，**不是建设工程**（本书明定）。

### 5.2 装饰装修的**主体门槛**（定性为建设工程的前置条件）

本书定义限定为「**建筑装饰装修企业**与发包方订立的」协议。
→ **主体不适格**（如无装饰装修经营范围／资质的个人或一般商户）时，难以定性为建设工程合同项下的装饰装修，须回落至**承揽**或**买卖**评价。

### 5.3 分包合同的**管辖分层**（易忽略）

本书明确：按不动产纠纷确定管辖的「建设工程分包合同纠纷」**主要针对施工承包人承包后的分包**；**勘察承包人、设计承包人承包后的分包，按一般合同纠纷确定管辖**。
→ 同一第四级案由，因**上游合同类型不同**而管辖规则不同。

### 5.4 全族定性决策顺序

```
① 是否属「工程建筑活动」（对建筑物/构筑物进行营造、安装、修饰处理）？
   └─ 否 → 转承揽(119) 或 买卖(88)
② 属哪一类工程活动？→ 对照 12 个第四级
③ 主体是否适格（装饰装修须为建筑装饰装修企业）？
   └─ 不适格 → 回落承揽/买卖
④ 管辖：施工类及本书扩张列举的 6 项 → 专属；勘察/设计分包 → 一般
```

## 六、在办案件应用：吊顶案（2026）黔0330民初6658号·被告立场

> ⚠️ 当事人信息以桌面原始案卷实地核实为准，本卡不凭记忆填写。

**三层进攻结构（被告立场）**：

1. **第一层·定性**：原告以「买卖合同」起诉，但标的为**吊顶材料＋安装**。若给付指向的是**安装这一特定行为及其成果**（§770 承揽逻辑）而非**交付材料这一物**（§595 买卖逻辑），则应定性为**承揽或装饰装修**，而非买卖。→ 援引 R-AY-001 第 5.1 段「目的标准」。
2. **第二层·主体门槛**：即便主张装饰装修，须先审查原告/施工方是否为「**建筑装饰装修企业**」。主体不适格 → 阻断建设工程定性，回落承揽（一般管辖）。
3. **第三层·管辖**：若成立装饰装修，依本书扩张解释应**专属管辖（工程所在地）**；若受诉法院非工程所在地 → **管辖异议**。同时准备狭义抗辩预案（解释§28 文义未列装饰装修）。

**改定性的连带后果**（择有利者主张）：

| 维度 | 买卖（88） | 承揽（119） | 装饰装修（120(7)） |
|---|---|---|---|
| 质量抗辩时点 | **检验期间**（§621：约定期间／合理期间／**收到后 2 年**） | **工作成果验收** | **工程竣工验收** |
| 解除权 | 法定解除 | **定作人任意解除权**（§787） | 依施工合同与建工解释 |
| 价款保障 | 无 | 无 | **价款优先受偿权**（§807） |
| 管辖 | 一般 | 一般 | **专属** |
