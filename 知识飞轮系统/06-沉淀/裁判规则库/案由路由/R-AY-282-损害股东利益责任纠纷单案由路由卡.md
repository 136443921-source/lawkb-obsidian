# 损害股东利益责任纠纷单案由路由卡（R-AY-282｜2025 §305／2020 §275）

> **一句话定位**：股东个人利益（知情权/表决权/分红权/优先购买权等）被公司、控股股东、实际控制人、董监高侵害，股东以**自身**利益受损为由直接诉请**损害赔偿**的纠纷——与 304（要分钱·给付）、306（公司利益·代表诉讼）、307（债权人利益·人格否认）构成「损害X利益」四兄弟，本卡守「股东个人利益＋直接诉讼」一极。

## 一、案由层级与编号（三源实证）

- **层级**：第三级案由，「二十四、与公司有关的纠纷」（2025 版；2020 版为「二十一、与公司有关的纠纷」）项下，无第四级。
- **2020 版**：**275 损害股东利益责任纠纷**（上册 OCR 目录位置 2099 / pages/p0083.txt:30 双源交叉一致）。
- **2025 版**：**305 损害股东利益责任纠纷**（法〔2025〕227号 court.gov.cn ＋ 头条整理全文 ＋ 法曜琴岛对比表「275→305」三源一致）。
- **🔴 漂移 +30**：275→305，与 R-AY-278/279/280/281 同档（双重插入点之后）；**禁算术推定第十三次实证**。
- **🔴 纯顺移非更名**：法〔2025〕227号第21条「变更…为…」序列（268→297/273→303/284→316）**不含 275**，名称保持「损害股东利益责任纠纷」；⚠️ **2025 版未加「公司」前缀**（用户拍板语「公司损害股东利益责任纠纷」为记忆偏差，本卡按官方名实写）。

## 二、受案范围与核心特征

股东利益（知情权、表决权、分红权、优先购买权、剩余财产分配请求权、新股优先认缴权等）被下列主体侵害，股东以**自身**利益受损为由直接诉请赔偿：

- **公司本身**（如违法限制股东权利、不执行有效决议致股东损失）；
- **控股股东 / 实际控制人**（滥用权利损害其他股东，§21；「影子董事」指示董高侵权连带，§192）；
- **董事 / 监事 / 高级管理人员**（违反法律、章程损害股东，§190 直接诉讼）；
- **他人**（配合侵权，§189 关联）。

**核心特征 = 股东个人利益受损 ＋ 赔偿之诉 ＋ 被告可为公司或侵权主体 ＋ 赔偿利益归股东自己**。

## 四、管辖（🔴 兜底型，弱于 281）

《民事诉讼法》2023 §27 明文列举「公司设立、确认股东资格、**分配利润**、解散」——**「损害股东利益」不在列举项**，仅能靠「等」兜底归入公司住所地管辖，与 R-AY-277（决议）/279（证照）/280（设立人责任）同型（兜底型），**论证强度显著弱于 R-AY-281 公司盈余分配（「分配利润」明文列举）、R-AY-272 股东资格确认（「确认股东资格」明文列举）**。

**立案双轨策略**：起诉状同时备「公司住所地（§27 兜底）」与「被告住所地（一般地域管辖）」两派依据，避免管辖争议卡立案（同 R-AY-279/280）。

## 五、最高价值段（老强点名：接 R-AY-281 §5.2 伏笔，讲透 305 与 304/306/307 分界）

### 5.1 305 自身定位：股东个人利益 + 直接诉讼

305 本质是**股东为自己的利益**提起的侵权赔偿之诉（§190 直接诉讼为主，§21/§192 扩张被告）。与「损害X利益」族其他三兄弟的根本分界是**赔偿利益归属**——归股东自己→305。

### 5.2 ⚠️ 305 vs 304 公司盈余分配（最高频易混·收口 R-AY-281 §5.2）

| 维度 | 304 公司盈余分配 | 305 损害股东利益责任 |
|---|---|---|
| 诉的类型 | **给付之诉**（要分钱） | **赔偿之诉**（要赔钱） |
| 被告 | 公司 | 公司/控股股东/董高/他人 |
| 核心事实 | 有可分配利润应分而不分/不足额 | 股东利益（含分红权）被侵权致损 |
| 请求权基础 | §59/§210/§211 | §190/§21/§192 |
| 口诀 | **要分钱→304** | **要赔钱→305** |

🌐 **同一「分红权受侵」事实的两种落点**：
- （a）公司营利且股东会已作**有效分配决议**但拒不执行 → **304**（给付之诉，依决议请求支付）；
- （b）控股股东/董高**滥用权利导致公司不分配利润**、造成其他股东损失 → **305**（赔偿之诉，依 §21/§190 请求赔偿）。
二请求可并列（304+305）但须分别列明，不得笼统概括「分红纠纷」。

### 5.3 305 vs 306 损害公司利益责任（「三兄弟」之二）

| 维度 | 305 损害股东利益 | 306 损害公司利益 |
|---|---|---|
| 受损利益 | **股东个人**利益 | **公司**利益 |
| 诉讼形式 | 股东**直接诉讼**（§190） | 公司直接诉 / 股东**代表诉讼**（§189） |
| 赔偿归属 | 归股东自己 | 归公司 |
| 被告 | 公司/侵权股东/董高 | 董高/控股股东/实控人/他人 |

🌐 **分界关键**：赔偿利益归属——归股东自己→305，归公司→306。实务中股东为公司利益起诉董高，表面「股东在诉」但本质是公司利益受损，应落 **306（股东代表诉讼）**，非 305。§189（代表诉讼）与 §190（直接诉讼）是区分两条案由的宪法性条文。

### 5.4 305 vs 307 损害公司债权人利益责任（「三兄弟」之三）

| 维度 | 305 损害股东利益 | 307 损害公司债权人利益 |
|---|---|---|
| 受损利益 | 股东个人利益 | **公司债权人**利益 |
| 法律依据 | §21/§190/§192 | §23（人格否认连带责任） |
| 被告 | 公司/侵权股东/董高 | 股东/实际控制人 |
| 赔偿归属 | 股东自己 | 债权人 |

🌐 同一控股股东滥用行为可同时损股东（→305）又损债权人（→307），两案可分别立、不竞合。

### 5.5 「损害X利益」四兄弟总览（305 守「股东个人利益＋直接诉讼」一极）

```
公司有关的纠纷·损害责任族
├─ 304 公司盈余分配纠纷（给付·被告公司·要分钱）
├─ 305 损害股东利益责任纠纷 ← 本卡（赔偿·股东个人利益·直接诉讼 §190）
├─ 306 损害公司利益责任纠纷（赔偿·公司利益·代表诉讼 §189）
└─ 307 损害公司债权人利益责任纠纷（赔偿·债权人利益·人格否认 §23）
```

🌐 **总口诀**：要分钱→304；股东自己被侵权赔钱→305；公司被侵权→306（代表诉讼）；债权人被侵权→307（人格否认）。

## 六、立案/审理要点提示

1. **案由选择**：先定「受损利益归属」——股东个人→305，公司→306，债权人→307，给付分配→304；不得笼统用「损害股东利益」涵盖公司/债权人利益受损。
2. **前置程序**：305 股东直接诉讼（§190）**无前置**；306 股东代表诉讼（§189）**须书面请求监事会/董事会起诉**（交叉请求被拒/30日/紧急情况除外）——这是 305/306 程序分流硬界限。
3. **被告扩张**：控股股东/实控人依 §192「影子董事」规则承担连带，起诉时可一并列明。
4. **管辖双轨**：见四、，备「公司住所地（§27 兜底）/被告住所地」两派依据。
