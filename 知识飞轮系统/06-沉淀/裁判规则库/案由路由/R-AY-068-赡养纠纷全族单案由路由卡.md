# 赡养纠纷全族单案由路由（24）

> **本卡回答**：晚辈对长辈的生活供养争议（成年子女对父母、孙辈对祖辈），定 **24 赡养纠纷**。🔴 唯一方向＝**晚辈→长辈**（成年子女→父母、孙子女→祖父母）。

## 一、释义核录

赡养是晚辈对长辈的法定供养义务。全族含：① 成年子女对父母的赡养费与生活照料；② 孙子女/外孙子女对祖父母/外祖父母的补充赡养（§1074 第2款）；③ 弟妹对兄姐的逆向赡养性扶养（§1075 第2款）。老年人权益保护重点案由。

## 二、管辖

一般地域管辖（§22／§24），无专属管辖。多个成年子女分属不同住所地，可对任一义务人住所地起诉，便于老年人维权。

## 三、法律适用

- **§1067 第2款**：成年子女不履行赡养义务的，缺乏劳动能力或者生活困难的父母，有要求成年子女给付赡养费的权利。
- **§1074 第2款**：有负担能力的孙子女、外孙子女，对于子女已经死亡或者子女无力赡养的祖父母、外祖父母，有赡养的义务。
- **§1075 第2款**：由兄、姐扶养长大的有负担能力的弟、妹，对缺乏劳动能力又缺乏生活来源的兄、姐有扶养义务（逆向）。

## 四、定性边界

1. **24 vs 22/23 三费**：唯一区分＝主体关系方向（晚辈→长辈）。详见 R-AY-051 分野卡。
2. **24 vs 遗弃（刑）**：拒不赡养情节恶劣涉遗弃罪，但民事诉讼案由仍为 24，可刑民并行。
3. **多义务人分担**：数个子女均有义务，可一并列为被告，法院按能力分份额。

## 五、在办案件应用

- **航合物流事故处置**（2026-09-01 致死）：死者父母（无劳动能力）对被扶养人生活费的赡养关系主张，立案定性回归 24。
- 与 R-AY-051 三费分野联动：方向鉴别定 24。

## 六、翻车标本

1. 把"父母养成年子女"立 24 → 方向反，应为 22（若子女未成年）或根本不成立；
2. 遗漏 §1074 孙辈补充赡养义务（父母双亡/无力时孙辈有责）；
3. 仅列部分子女为被告，未列全部义务人 → 份额难执行；
4. 赡养费与 DS 继承混诉，未区分身份给付与财产分割。
