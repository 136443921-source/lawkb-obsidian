# 劳动合同 vs 劳务合同 定性分野

> **本卡回答**：一个"我给你干活、你给我钱"的事实，到底定**劳动合同纠纷 205** 还是 **劳务合同纠纷 144**？
> ——这直接决定**要不要先仲裁、去哪个法院、适用劳动法强制保护还是民法意思自治、赔偿按工伤待遇还是按过错人损**五件事。
>
> 🔴 **一句话结论**：**看从属性与主体资格**。一方是《劳动合同法》§2的"用人单位"、另一方是受其管理并领取报酬的"劳动者"（人格/经济/组织从属）→ **劳动合同 205**（仲裁前置、劳动法特别保护）；双方均为平等民事主体、按约定完成工作、不受持续劳动管理 → **劳务合同 144**（直接诉讼、民法典合同编）。

## 二、释义与构成要件（源书核录）

**劳动合同纠纷（205）**：用人单位与劳动者因订立、履行、变更、解除和终止劳动合同发生的争议（《劳动争议调解仲裁法》§2；杨万明书行18083-18089）。源书采纳**广义**劳动合同概念，涵盖确认劳动关系、报酬、经济补偿、工伤等（行18167）。

**劳务合同纠纷（144）**：提供劳务一方与接受劳务一方以书面/口头等形式达成协议，由一方提供劳务、另一方按约定给付报酬，因劳务（雇佣）关系发生的纠纷（杨万明书行13604-13607）。源书明定本条指**狭义劳务合同＝雇佣合同**，由民法调整（行13628-13631）。

## 五、定性边界 ⭐（本卡最高价值段）

### 5.1 五变量差异矩阵（Q2 的书面落地）

| 变量 | 劳动合同纠纷 205 | 劳务合同纠纷 144 |
|---|---|---|
| **主体资格** | 一方须为《劳动合同法》§2用人单位，另一方为劳动者 | 双方均为平等民事主体（自然人/法人/非法人组织） |
| **从属性** | 人格+经济+组织三重从属（受规章管理、报酬按月、纳入组织） | 独立作业、按约交付、不受持续劳动管理 |
| **法律适用** | 劳动法/劳动合同法（强制保护：最低工资·社保·工时·经济补偿·工伤） | 民法典合同编（意思自治为主） |
| **争议解决** | 仲裁前置→15日内起诉 | 直接诉讼 |
| **赔偿标准** | 工伤待遇/经济补偿（法定） | 按约定/按过错（民法典§1192） |

> **五项实质不同 → Q2 通过，本卡成立。**

### 5.2 鉴别器三层展开

#### 第一层 · 原文照录
> 杨万明书行18505："劳动合同纠纷不同于劳务合同纠纷。劳务合同有广义与狭义之分…狭义的劳务合同仅指雇佣合同…劳务（雇佣）合同纠纷是指以一方当事人提供劳务为合同标的，在履行合同过程中，因劳务（雇佣）关系发生的纠纷。在劳务合同中，雇主处于支配地位，雇员则处于被支配的从属地位。"

#### 第二层 · 教义学拆解
判定结构是**"主体是否用人单位 + 是否从属"**：
- 单位（企业/个体户/民办非企业/机关事业团体）聘用自然人、签劳动合同/缴社保/受考勤规章管理 → **劳动关系 → 劳动合同 205**；
- 自然人雇佣自然人、单位与退休返聘/实习生/挂靠经营者、按次结算的承揽 → **平等民事关系 → 劳务合同 144**（或承揽 119）。
- 从属性是劳动关系本质特征，也是区别于劳务/承揽的根本标尺。

#### 第三层 · 反向推论（counter-case）
**反例 A——表面像劳务，实为劳动**：物流公司给司机配工牌、排班、按月发"工资"、缴社保，却签"劳务协议"。从属性具备 → 实为**劳动关系 205**，不得因名为"劳务"而定 144。
**反例 B——表面像劳动，实为劳务/承揽**：退休返聘人员到单位做临时顾问、自行安排时间、按项目领酬、不缴社保 → **劳务合同 144**（2025新增 144(1) 超龄劳动者劳务合同更精准）。
**反例 C——货车挂靠经营**：个人车挂靠物流公司、自担经营风险 → 司机与公司的关系未必是劳动关系；若发生事故，2025专设 **209 承包人·被挂靠人用工主体责任纠纷** 处理主体责任，不宜硬套 205。

### 5.3 定性决策树（每条路径唯一出口）

```
Step 1  一方是否为《劳动合同法》§2用人单位、另一方是否为其劳动者（人格/经济/组织从属）？
        ├─ 是（签劳动合同/缴社保/受管理调度） → 劳动合同纠纷 205（仲裁前置），终止
        └─ 否（平等民事主体/退休返聘/挂靠/承揽） ↓
Step 2  提供劳务一方是否超龄或属新就业形态？
        ├─ 超龄人员提供劳务 → 劳务合同纠纷 144(1) 超龄劳动者劳务合同，终止
        └─ 否 ↓
Step 3  是否违法转包/分包/挂靠下的底层劳动者权益争议？
        ├─ 是 → 承包人·被挂靠人用工主体责任纠纷 209，终止
        └─ 否 → 劳务合同纠纷 144（直接诉讼，民法典合同编），终止
```

## 六、在办案件应用：航合物流用工

> ⚠️ 当事人信息一律以桌面原始案卷实地核实为准，本卡不凭记忆填写。

航合物流（用人单位）与货车司机之间的用工性质，是本案定性第一关：
- 若司机与航合物流**存在劳动关系**（签合同、缴社保、受调度管理）→ 工资、工伤、解雇等争议走 **劳动合同纠纷 205**（仲裁前置）；
- 若司机系**个体承包/挂靠/退休返聘** → 定 **劳务合同 144** 或 **承揽 119**；
- 若底层劳动者因违法转包/分包/挂靠受损 → 2025专设 **209 承包人·被挂靠人用工主体责任纠纷**；
- 2026-09-01 贵C09782D 撞行人致死事件：先辨死者/司机与单位关系——死者若为本单位执行职务的劳动者，走**工伤 206(2)**＋用人单位责任；死者为第三人则走机动车交通事故人损（见 R-AY-033）。
