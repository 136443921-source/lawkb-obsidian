# 买卖合同全族与检验期间·质量异议

> **本卡回答**：一个「卖货收钱」的纠纷，到底该定第三级「买卖合同纠纷 88」还是它项下 8 个第四级之一？以及——**买方说货有问题，为什么可能会「说不出来」？**
>
> 🔴 **一句话结论**：**检验期间不是诉讼时效，是失权期间。** 买方怠于在 §621 的期间内通知，**法律直接拟制「标的物符合约定」**——这不是证据问题，是**权利本身消灭**。吊顶案与雅菲案的胜负手，很大程度上就压在这个时点上。

## 〇、卡型说明（为何不是定性分野卡）

本卡为**单案由路由卡（全族纵向梳理型）**，非定性分野卡，故不设 `discriminator` / `discriminator_source` / `counter_case` 三字段。

**判据**：本卡处理的是**同一第三级案由「88」内部**的第四级分野与实体规则（纵向梳理），不是「88 与其他案由」的横向易混对比。与 `R-AY-004`（建设工程合同全族）同型。
> 横向对比（买卖 vs 承揽 vs 装饰装修）见 [[R-AY-001-买卖合同承揽合同装饰装修合同定性分野]]；本卡不重复。

## 二、释义与构成要件（源书【释义】段，OCR 原文核录）

> 「依据《民法典》第 595 条的规定，买卖合同是指出卖人转移标的物的所有权于买受人，买受人支付价款的合同。有效买卖合同，**出卖人的主要义务是：交付标的物、转移标的物所有权、权利瑕疵担保和物的瑕疵担保以及其他从义务等。买受人的主要义务是：支付价款、检验、保管以及及时领受等。**」

🔴 **注意：源书把「检验」明确列为买受人的主要义务之一**——这是 §620-624 检验期间规则的体系定位，也是本卡第六段的立论起点。

**八个第四级的释义要点**（源书【释义】，PDF页305-306／书页260-261）：

| 第四级 | 释义要点 |
|---|---|
| (1) 分期付款 | 标的物交付后，买受人将总价款在一定期限内**分批**支付的特殊买卖 |
| (2) 凭样品 | 选定样品后约定交付标的物应与样品及其说明质量相同；**买受人不知样品有隐藏瑕疵的，交付物应符合同种物的通常标准** |
| (3) 试用 | 成立时交付试用，买受人在试用期内可购买亦可拒绝；**试用期届满未作表示的，视为购买** |
| (4) 所有权保留 | 约定买受人支付价款或履行其他义务**之前**出卖人保留标的物所有权 |
| (5) 招标投标 | 经招标、投标、开标验标、评标定标订立；《招标投标法》第 3 条规定的项目**必须招标** |
| (6) 互易 | 以物易物，**互相交换金钱以外的财产**并转移所有权 |
| (7) 国际货物买卖 | **营业地分处不同国家或地区**的当事人之间订立的货物买卖合同 |
| (8) 信息网络买卖 | 出卖人在互联网等信息平台展示并发出要约、买受人通过信息网络作出承诺而订立 |

## 四、法律适用（请求权基础，元典核填·现行有效，含官方核验指引）

**《民法典》**（本地法律法规库核填）

**第五百九十五条**　买卖合同是出卖人转移标的物的所有权于买受人，买受人支付价款的合同。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百一十五条**　出卖人应当按照约定的质量要求交付标的物。出卖人提供有关标的物质量说明的，交付的标的物应当符合该说明的质量要求。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百一十七条**　出卖人交付的标的物不符合质量要求的，买受人可以依据本法第五百八十二条至第五百八十四条的规定请求承担违约责任。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百二十条**　买受人收到标的物时应当在约定的检验期限内检验。没有约定检验期限的，应当及时检验。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百二十一条**　当事人约定检验期限的，买受人应当在检验期限内将标的物的数量或者质量不符合约定的情形通知出卖人。**买受人怠于通知的，视为标的物的数量或者质量符合约定。**
当事人没有约定检验期限的，买受人应当在发现或者应当发现标的物的数量或者质量不符合约定的合理期限内通知出卖人。**买受人在合理期限内未通知或者自收到标的物之日起二年内未通知出卖人的，视为标的物的数量或者质量符合约定；但是，对标的物有质量保证期的，适用质量保证期，不适用该二年的规定。**
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百二十二条**　当事人约定的检验期限过短，根据标的物的性质和交易习惯，买受人在检验期限内难以完成全面检验的，**该期限仅视为买受人对标的物的外观瑕疵提出异议的期限**。
约定的检验期限或者质量保证期短于法律、行政法规规定期限的，应当以法律、行政法规规定的期限为准。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百二十三条**　当事人对检验期限未作约定，**买受人签收的送货单、确认单等载明标的物数量、型号、规格的，推定买受人已经对数量和外观瑕疵进行检验**，但是有相关证据足以推翻的除外。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**第六百二十四条**　出卖人依照买受人的指示向第三人交付标的物，出卖人和买受人约定的检验标准与买受人和第三人约定的检验标准不一致的，**以出卖人和买受人约定的检验标准为准**。
> *效力状态：现行有效（本地《中华人民共和国民法典（全文）》核填）*

**《民事诉讼法》（2023修正）**（本地程序法库核填）

**第二十四条**　因合同纠纷提起的诉讼，由被告住所地或者合同履行地人民法院管辖。

## 五、全族第四级分野与「专门案由优先」（源书【确定该案由应当注意的问题】）

**原文照录**（PDF页307-308／书页263-264）：

> 「**需要注意的是，首先，这里的第四级案由都是特殊形态的买卖合同纠纷，对其他更大量的普通买卖合同纠纷而言，直接以第三级的买卖合同纠纷来确定案由即可。其次，对一些特定标的物的买卖合同，如果其他案由已作专门规定的，就应适用专门的案由，不能再将之确定为买卖合同纠纷**，如房屋买卖合同发生纠纷后案由就应确定为房屋买卖合同纠纷，而不用本案由。**最后，国际货物买卖合同纠纷不包括涉港、澳、台买卖合同纠纷。**」

**三条规则拆解**：

| # | 规则 | 实务后果 |
|---|---|---|
| 1 | 第四级＝**特殊形态**；普通买卖直接定第三级 88 | 不必硬套第四级；无特殊形态的，写「买卖合同纠纷 88」即可 |
| 2 | **专门案由优先**于一般买卖 | 房屋（96）、拍卖（89）、建设用地使用权出让/转让（90）等已有专门案由的，**不得**定 88 |
| 3 | **国际货物买卖 88(7) 不含涉港澳台** | 涉港澳台买卖**不列** 88(7)；但其管辖与法律适用仍参照涉外程序处理 |

**第四级选型决策树**：

```
Step 0  是否已有专门案由吸收？（房屋 96／拍卖 89／建设用地使用权 90…）
        └─ 有 → 适用专门案由，不得定 88，终止
Step 1  是否属八种特殊形态之一？
        ├─ 分期付款 → 88(1)     ├─ 凭样品 → 88(2)
        ├─ 试用     → 88(3)     ├─ 所有权保留 → 88(4)
        ├─ 招标投标 → 88(5)     ├─ 互易（以物易物）→ 88(6)
        ├─ 营业地分处不同国家/地区 → 88(7)
        │     └─ ⚠️ 涉港澳台 → 不适用 88(7)
        └─ 通过信息网络平台订立 → 88(8)
Step 2  均非上述 → 第三级「买卖合同纠纷 88」
```

## 六、检验期间与质量异议专章 ⭐（本卡核心，吊顶／雅菲案主战场）

### 6.1 三层结构（§620 → §621 → §622/623）

```
第一层  §620  检验义务：有约定从约定；无约定→「及时」检验
                  ↓
第二层  §621  异议通知与失权（核心）
        ├─ 有约定检验期限：期内通知；怠于通知 → 视为数量/质量符合约定
        └─ 无约定检验期限：发现或应当发现的「合理期限」内通知
              └─ 合理期限内未通知 **或** 自收到之日起「二年」内未通知
                 → 视为符合约定（有质保期的，适用质保期，不适用二年）
                  ↓
第三层  §622/623  矫正机制
        ├─ §622 约定期限过短 → 仅视为「外观瑕疵」异议期；短于法定以法定为准
        └─ §623 未约定期限 + 签收单载明数量/型号/规格 → **推定已检验数量和外观瑕疵**
```

### 6.2 🔴 三个最易搞错的点

| # | 常见误解 | 正解 |
|---|---|---|
| 1 | 检验期间＝诉讼时效 | ❌ **检验期间是失权期间（除斥性质）**，§621 的二年**不是** §188 的三年时效；不适用中止、中断；期间经过后**权利本身消灭**，非仅胜诉权消灭 |
| 2 | 检验期间只管质量 | ❌ §621 明定管**「数量或者质量」**两者；§623 更明定推定已检验的是**「数量和外观瑕疵」** |
| 3 | 有质保期就一律按质保期 | ⚠️ 仅**无约定检验期限**时才进入「合理期限／二年 vs 质保期」的判断；且**有质保期的，适用质保期而不适用二年**——但质保期通常**长于**二年，对买方未必有利 |

### 6.3 检验期间 vs 验收程序（吊顶案的定性命门）

| | 买卖 88 | 承揽 119 | 装饰装修/建工 120(7) |
|---|---|---|---|
| 质量争议规则 | **检验期间**（§620-624） | **工作成果验收**（§780-782） | 竣工验收＋竣工结算 |
| 买方/定作人失权时点 | 约定检验期届满，或合理期限／**二年** | **验收合格**时 | **竣工验收合格**时 |
| 未及时提出的后果 | **拟制符合约定**（§621） | 视为验收合格 | 进入结算与质量保修轨道 |
| 对被告（买方/定作人）利弊 | 🔴 **不利**——逾期即视为合格，质量抗辩直接失权 | 🟢 有利——须先经验收，**未验收则付款条件未成就** | 🟢 有利——同上，且涉资质审查 |

> 🔴 **由此得出吊顶案的定性战术结论**：原告以「买卖合同 88」起诉，**对我方（被告）恰恰是最不利的定性**——一旦定性为买卖，被告未在检验期内提出异议即被**拟制为货物符合约定**，质量抗辩当场失权；
> 反之，若定性为**承揽 119 或装饰装修 120(7)**，则走**验收程序**，**未经验收则付款条件尚未成就**，被告可主张先验收后付款。
> → **被告方应积极推动定性由「买卖」转向「承揽／装饰装修」**（完整分野论证见 [[R-AY-001-买卖合同承揽合同装饰装修合同定性分野]]）。

### 6.4 §623 的双刃性（雅菲案关键）

**§623 推定规则**：未约定检验期限，且买受人签收的送货单、确认单等**载明数量、型号、规格** → **推定买受人已对数量和外观瑕疵进行检验**。

- **对卖方有利**：一旦签收单载明规格，即推定买方已验收数量与外观，卖方交货义务锁死；
- **对买方不利**：不能再以「数量不符」「外观瑕疵」抗辩；
- **但可反驳**：条文但书「**有相关证据足以推翻的除外**」——买方仍可举证推翻。

> 在雅菲案中，若原告以送货单/确认单证明交付，则 §623 推定**我方（被告）已检验数量和外观**；此时我方的抗辩重心**必须移出"数量/外观"**，转向**付款事实**（货款已清）——这正是 §621-623 在本案作为「程序支点」的含义：**它先把争点锁死在"付没付钱"，堵住原告改口重构的空间。**

## 七、张力点：双说理（🔴 承办人须备两套）

### 张力点一：无约定检验期限时，「合理期限」如何认定

- **攻方（买方／主张期限未过）**：标的物瑕疵具隐蔽性（如吊顶材料内部结构、窗帘色牢度），非外观检验可发现，「合理期限」应自**发现或应当发现**之日起算，且应结合专业检测所需时间；
- **守方（卖方／主张已失权）**：§621 第 2 款另有**二年**的最长兜底，且 §623 已推定外观与数量检验完毕；买方长期未提异议反而继续付款/使用的，应认定期限经过；
- **结论**：两套都备。**关键在于固定"何时发现"的证据**（检测报告日期、报修记录、微信沟通记录），这是「合理期限」起算点的唯一抓手。

### 张力点二：检验期间与质量保证期并存时的适用顺序

- **攻方（买方）**：有质保期即应适用质保期（§621 第 2 款但书），质保期内提出即可，不受二年限制；
- **守方（卖方）**：质保期仅覆盖**约定的质量保证范围**，超出范围的瑕疵仍受「合理期限／二年」约束；且质保期系**约定**义务，与法定检验期间性质不同；
- **结论**：**先界定争议瑕疵是否在质保范围内**——在，则按质保期；不在，则回落合理期限／二年。不可笼统主张「有质保期就都不受限」。

### 张力点三：混合合同（买卖＋安装）中检验期间的适用

- **攻方（买方）**：合同含安装、调试，属混合合同，应整体按承揽的**验收**规则，不适用买卖的检验期间；
- **守方（卖方）**：应依**主要给付义务**定性，若核心价值在货物本身（如吊顶材料、窗帘布），安装仅为附随义务，则仍适用买卖的检验期间（§620-624）；
- **结论**：与 R-AY-001 的「给付义务指向」标准一致。**先定性，再定适用何种质量规则**——顺序不能颠倒。
