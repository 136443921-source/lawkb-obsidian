# 生命权、身体权、健康权纠纷（案由路由卡·单案由路由卡）

> **一句话**：本案由是人格权项下**一般案由**，仅当**无对应专门案由**（如机动车/医疗/产品责任）时才适用；三权客体不同（生命/身体完整/身心健康），侵害认定各异。
> 本卡为**批次2人格权线 L1①**，人伤基础案由。属单案由路由卡（纵向梳理型），**不设 discriminator**（无横向易混对标，设了反而错标，见 SOP 7.7）。

## 二、释义与构成要件（源书 OCR 核录）

> 生命权、身体权、健康权纠纷是指他人实施侵害生命权、身体权、健康权行为而引起的纠纷。（行2920）

- **生命权**（行2923-2933）：以维护生命安全和生命尊严为内容；侵害后果特殊性——被侵权人死亡的，赔偿请求由近亲属主张。
- **身体权**（行2935-2947）：以身体完整和行动自由为保护内容；客体是身体（主体+附属部分）；破坏有机构成即侵身体权。
- **健康权**（行2958-2965）：以身心健康为保护内容；客体是健康（身体+心理）。

**三权区分关键**（行2965-2982）：
- 健康权与身体权区别在于**客体**（健康 vs 身体完整）。
- 殴打、尸体损害→构成**身体权**非健康权（行2980）；性骚扰致精神失常→构成**健康权**（行2981-2982）。

## 五、专门案由优先·选型决策树（本卡核心价值）

源书行2999-3016明定：**存在相应专门案由时，不适用本案由，而适用专门案由**。

```
Step 0  侵害生命权/身体权/健康权的事实？
        └─ 否 → 不适用人格权纠纷
Step 1  是否存在对应专门案由？
        ├─ 机动车交通事故致害 → 机动车交通事故责任纠纷（专门）
        ├─ 医疗活动致害 → 医疗损害责任纠纷（专门，见 R-AY-005）
        ├─ 产品缺陷致害 → 产品责任纠纷（专门）
        ├─ 饲养动物致害 → 饲养动物损害责任纠纷（专门）
        ├─ 高度危险致害 → 高度危险责任纠纷（专门）
        └─ 无上述专门案由（一般侵权/意外） → 本案由（生命权、身体权、健康权纠纷）
```

> **铁律**：专门案由 > 一般案由。源书行3010-3016："不应适用……'生命权、身体权、健康权纠纷'案由，也不应适用……'物权纠纷'……"而应用相应专门案由。

## 六、在办案件应用（人伤基础）

| 场景 | 定性 | 对我方影响 |
|---|---|---|
| 航合物流交通事故致死 | 机动车交通事故责任纠纷（专门） | 不归本案由；走道交法路径 |
| 医疗事故致人身损 | 医疗损害责任纠纷（专门） | 见 R-AY-005 双路线 |
| 一般殴打致伤 | 本案由（生命权身体权健康权） | 举证三权客体区分 |

**战术要点**：
1. 立案先查有无专门案由，避免误定一般案由被法官依职权变更。
2. 三权客体区分决定举证重心（身体完整 vs 身心健康）。
3. 法条引用禁用民诉法第28条，一律第29条。
