# 基金会视角慈善服务合同族 · 案由路由串联卡

> **本卡定位**：厚德基金会法律服务的**案由路由全景枢纽**。不重复任何定性分析（那一层在 R-AY-003／006／039），只把基金会高频合同场景「一张图路由」到正确的案由与既有卡，并标出《慈善法》合规叠加点。
>
> 🔴 **一句话结论**：基金会收捐赠→**赠与/公益捐赠（107，R-AY-003）**；委托他人执行项目→**委托（124）/承揽（119）/服务（142，R-AY-006）**；自管/委托储货→**保管（122，R-AY-039）/仓储（123）**；机构名誉维权→**名誉权（6）/荣誉权（7，R-AY-008/013/017）**。

## 二、基金会协议路由决策树

```
收到一份以基金会为当事人的协议
  ↓
Step 1  给付指向「无偿转移财产所有权」？
        ├─ 是 → 赠与合同 107（公益捐赠＝107(1)） → R-AY-003
        └─ 否 ↓
Step 2  给付指向「替我看着东西、原物返还」？
        ├─ 是（无仓库资质／可无偿） → 保管 122 → R-AY-039
        ├─ 是（专业仓储／开仓单／有偿） → 仓储 123（待建）
        └─ 否 ↓
Step 3  给付指向「处理委托人事务」？
        ├─ 是（风险归基金会、付报酬） → 委托 124 → R-AY-006 §7.2
        └─ 否 ↓
Step 4  给付指向「交付可验收工作成果」？
        ├─ 是 → 承揽 119 → R-AY-006
        └─ 否 ↓
Step 5  给付指向「服务产品本身」（非实物、不可储存）？
        ├─ 是 → 服务 142 → R-AY-006
        └─ 否 ↓
Step 6  涉机构人格权益（名誉/荣誉）？
        └─ 是 → 名誉权 6／荣誉权 7 → R-AY-008/013/017
```

## 三、基金会特有风险（慈善法合规叠加）

本卡所有合同路由**均须叠加《慈善法》《公益事业捐赠法》特别要求**，不可纯按民法典合同编定案由：

1. **公益捐赠的强制公益属性**：受赠人须具「公益性社会团体／公益性非营利事业单位」资格（R-AY-003 §5.4）；资格瑕疵→影响案由定性与撤销权规则。
2. **捐赠财产使用与信息公开**：募捐方案、财产使用、剩余财产处理须同时满足特别法（R-AY-003 §6）。
3. **项目执行的解除合规边界**：基金会作委托方虽可主张任意解除（§933），但解除权的行使受《慈善法》及内部治理规则约束，**不能纯以成本论**（R-AY-006 §7.2）。
4. **物资保管的公益属性**：捐赠物资毁损灭失，除合同法§896/§897 责任外，还涉捐赠协议约定的公益目的实现瑕疵——双重审查。
