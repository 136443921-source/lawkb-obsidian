# 工伤保险待遇（工伤基金赔付） vs 普通人身损害/雇主责任 定性分野

> **本卡回答**：一个人"干活时受了伤/死了"，到底走 **工伤保险待遇 206(2)**、还是 **雇主责任/普通人身损害（侵权）**？
> ——这直接决定**要不要先认定工伤、赔钱的是基金还是侵权方、按无过错还是按过错、走仲裁还是直接诉讼**四件事。
>
> 🔴 **一句话结论**：**看有没有劳动关系**。受伤者与单位存在劳动关系 → 走**工伤 206(2)**（基金赔付、无过错、仲裁前置）；是劳务/雇佣关系或纯第三人侵权 → 走**雇主责任/人损**（民法典§1192/§1191/§1165，按过错、直接诉讼）。

| # | 门槛问句 | 本卡作答 |
|---|---|---|
| Q1 | 同一事实能否被两种定性同时涵摄？ | ⚠️ 否（互斥）。同一受害事件要么属工伤（劳动关系）、要么属侵权（劳务/第三人），定性不同则赔付体系全不同 |

| Q3 | 有无权威源给出的明确区分标准？ | ✅ 有。《社会保险法》/《工伤保险条例》以劳动关系为工伤认定前提；《民法典》§1191/§1192 区分用人单位责任与劳务关系受害；杨万明书行18566-18568 工伤定义 |

## 二、释义与构成要件（源书核录）

**工伤保险待遇（206(2)）**：劳动者在从事生产劳动或与之相关工作时发生意外伤害（事故伤残、职业病及因此死亡），由政府（工伤保险基金）向劳动者或其供养直系亲属提供物质帮助的社会福利制度（杨万明书行18566-18568）。**法定前提：存在劳动关系且经工伤认定（《工伤保险条例》§14）**。

**雇主责任/普通人身损害（侵权）**：非劳动关系下的受害/致害，依《民法典》：
- §1191 用人单位工作人员因执行工作任务致人损害 → 用人单位担责（用人单位责任纠纷）；
- §1192 个人之间劳务关系，提供劳务一方因劳务受害 → 按双方过错；因劳务致第三人损害 → 接受劳务一方担责；
- §1165 一般过错侵权（第三人侵权、机动车交通事故等）。

## 五、定性边界 ⭐（本卡最高价值段）

### 5.1 四变量差异矩阵（Q2 的书面落地）

| 变量 | 工伤保险待遇 206(2) | 雇主责任/普通人身损害 |
|---|---|---|
| **前提关系** | 劳动关系（工伤认定要件） | 劳务/雇佣关系 或 纯第三人侵权 |
| **赔付主体** | 工伤保险基金＋用人单位（未缴时） | 侵权方/接受劳务方/用人单位（依§1191/§1192） |
| **归责原则** | 无过错（工伤认定义定即赔） | 过错（§1165）或法定替代责任（§1191） |
| **程序** | 行政认定＋仲裁前置＋诉讼 | 直接诉讼 |

> **四项实质不同 → Q2 通过，本卡成立。**

### 5.2 鉴别器三层展开

#### 第一层 · 原文照录
> 杨万明书行18566："工伤保险，是指劳动者在从事生产劳动或与之相关的工作时，发生意外伤害…由政府向劳动者本人或其供养的直系亲属提供物质帮助的一项社会福利制度。"

#### 第二层 · 教义学拆解
判定结构是**"受伤者与致害/用工一方有无劳动关系"**：
- 有劳动关系 + 因工受伤 → **工伤 206(2)**，走基金赔付、无过错；
- 劳务关系下受伤/致害 → **雇主责任（民法典§1192）**，按过错；
- 与单位无关系之第三人被单位人员/车辆致害 → **普通侵权/机动车交通事故人损（§1165/道交）**。

#### 第三层 · 反向推论（counter-case）
**反例 A——劳务关系硬走工伤**：退休返聘人员/承揽人在工地受伤，与单位无劳动关系 → 不能定工伤 206(2)，应定雇主责任或人损（§1192）。
**反例 B——工伤当人损索赔**：签劳动合同缴社保的司机执行职务车祸身亡，家属直接按人损起诉肇事方 → 应先走工伤认定 206(2)，基金赔付优于单纯侵权（且用人单位未缴社保时由用人单位全额支付）。
**反例 C——忽略2025专名**：平台骑手职业伤害 → 应定 **216 新就业形态职业伤害保障纠纷**，不宜套普通工伤或人损。

### 5.3 定性决策树（每条路径唯一出口）

```
Step 1  受害/死者与致害方是否存在劳动关系（签合同/缴社保/受管理）？
        ├─ 是（且因工受伤） → 工伤保险待遇 206(2)（认定前置+仲裁），终止
        └─ 否 ↓
Step 2  受害方与致害方是否为劳务/雇佣关系（个人劳务 §1192）？
        ├─ 是 → 雇主责任（提供劳务者受害/致害责任，按过错），终止
        └─ 否（纯第三人侵权） ↓
Step 3  致害是否单位工作人员执行职务（§1191）或机动车交通事故？
        ├─ 是 → 用人单位责任纠纷 / 机动车交通事故责任纠纷，终止
        └─ 否 → 普通人身损害（过错侵权 §1165），终止
```

## 六、在办案件应用：航合物流 2026-09-01 事故

> ⚠️ 当事人信息一律以桌面原始案卷实地核实为准，本卡不凭记忆填写。

贵C09782D 重型特殊结构货车与行人碰撞致人死亡，定性三分支：
- **死者系航合物流执行职务的劳动者**（如跟车员、装卸工）→ 走**工伤 206(2)**＋用人单位责任（§1191），基金/单位赔付；
- **死者系第三人（路人）** → 走**机动车交通事故责任纠纷**（道交人损），保险+侵权人赔付；
- **司机与航合物流系劳务/挂靠关系** → 司机受害或致害走**雇主责任 §1192 / 209 承包人·被挂靠人用工主体责任纠纷**；
- 若涉平台/新就业形态从业者 → 2025专设 **216 新就业形态职业伤害保障纠纷**。
→ 正式表态发言（四段式）须先锁定上述关系定性，再定整改与赔付口径。
