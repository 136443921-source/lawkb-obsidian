# 隐私权·个人信息保护定性分野（案由路由卡·对比型）

> **一句话**：隐私权重在"私密"（不愿人知），个人信息重在"可识别"（不论私密）。分野硬标准——被侵害的是**私密空间/活动/部位**还是**可识别自然人的信息**；二者交叉（私密信息）**优先隐私权**，纯非私密信息归个人信息保护。
> 本卡为**批次2人格权线 L2 深度卡②**。源书给出罕见的**三向规则**，是 Q3（权威鉴别器）最充分的一张。

## 二、释义与构成要件（源书 OCR 核录）

### （一）隐私权（上册 PDF129-133，行3492-3590 区域）

> 隐私权、个人信息保护纠纷是指因侵害他人的隐私权、个人信息……（行3497）。《民法典》第1032条：隐私是自然人的私人生活安宁和不愿为他人知晓的私密空间、私密活动、私密部位。（据 §1032 权威源核填）

- **客体**：私生活安宁 + 私密空间/活动/部位（自然人专属，法人无隐私权）。
- **历史沿革**：2009《侵权责任法》第2条首将隐私权列为独立民事权利；此前司法实践多纳入名誉权间接保护（行3500-3502）。

### （二）个人信息保护（上册 PDF129-134，行3529-3562 区域）

> 所谓个人信息，是指以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人的各种信息，包括姓名、出生日期、身份证件号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等。（行3532-3537，据 §1034 核填）

- **专门法**：2021-11-01《个人信息保护法》施行，确立"识别说"之外的"关联说"（行3563-3569），与《民法典》定义口径不同。
- **敏感个人信息**：分一般/敏感，处理规则不同（行3569-3571）。

## 四、法律适用（法条正文·逐条标效力）

- **《民法典》第1032条**（隐私权/私密定义）：现行有效。
- **《民法典》第1034条**（个人信息定义+私密信息交叉规则）：现行有效。第1034条第3款明确"私密信息适用隐私权规定，无规定的适用个人信息保护规定"。
- **《民法典》第1035条**（信息处理合法正当必要原则）：现行有效。
- **《个人信息保护法》第4条**（个人信息定义·关联说）：现行有效（2021-11-01施行）。
- **《民诉法》第29条**：现行有效（替代原第28条）。
- **《民诉法解释》第25条**：现行有效。
- **《人脸识别司法解释》**：在个人信息框架下，人脸信息侵害人格权益一般适用个人信息保护案由；同时侵害肖像/名誉/隐私权的依诉请定相应案由（行3700-3704）。

## 五、定性边界 ⭐（鉴别器三层展开）

### 第一层·原文照录

**交叉规则**（上册 PDF129，行3538-3540）：

> 对于个人信息中的私密信息，应当适用有关隐私权的规定；没有规定的，适用有关个人信息保护的规定。

**三向适用规则**（上册 PDF133-134，行3689-3699）：

> 适用上述案由时需要注意：对于侵害隐私权引发的纠纷，适用"隐私权纠纷"；对于侵害个人信息引发的纠纷，一般适用"个人信息保护纠纷"；但侵害的个人信息中既有非私密信息又有私密信息的，适用"隐私权、个人信息保护纠纷"。

### 第二层·教义学拆解（判定结构）

> **判定对象**：被侵害的客体性质。
> - 指向「私密空间/私密活动/私密部位/私生活安宁」→ **隐私权纠纷（8(1)）**（§1032）
> - 指向「可识别特定自然人的信息，且非私密」→ **个人信息保护纠纷（8(2)）**（§1034/个保法）
> - 指向「同一行为既侵私密信息又侵非私密信息」→ **隐私权、个人信息保护纠纷（8，合并案由）**

收敛为一句话：**私密→隐私权；可识别但非私密→个人信息保护；二者交织→合并案由**。

### 第三层·反向推论（counter_case）

公开渠道收集他人**已公开手机号**用于推销，未涉私密空间/活动——虽"侵害个人信息"，但属非私密可识别信息，不构成隐私权侵害 → 定**个人信息保护纠纷（8(2)）**，非隐私权纠纷（8(1)）。若同一行为人既爬取私密聊天记录又倒卖已公开手机号，则升格为"隐私权、个人信息保护纠纷（8）"。

### 决策树（唯一出口）

```
Step 0  被侵害的是"人格利益中的信息/安宁类"？
        └─ 否 → 考虑名誉权/一般人格权
Step 1  客体是否"私密空间/活动/部位/私生活安宁"？
        ├─ 是（且仅私密） → 隐私权纠纷（8(1)）
        └─ 否（可识别但非私密） → Step 2
Step 2  同一行为是否同时侵私密信息+非私密信息？
        ├─ 是 → 隐私权、个人信息保护纠纷（8，合并）
        └─ 否 → 个人信息保护纠纷（8(2)）
```

## 六、张力点·双说理（"私密信息"边界）

- **攻方说理（主张隐私权）**：我方健康信息/行踪系"私密信息"，依 §1034 第3款优先适用隐私权，举证重心在"私密性+安宁受损"。
- **守方说理（主张个人信息保护）**：该信息已脱敏/已公开，非私密，应适用《个保法》而非隐私权；即便私密，也仅在"无规定"时才转隐私权，而个保法已有明确规定，应直接定个人信息保护纠纷。
- **结论（须备两套）**：按 §1034 第3款"私密信息→隐私权优先，无规定→个人信息保护"的**阶梯适用**处理；举证"是否私密"为定性枢纽，两案由请求权基础并行准备。

## 七、在办案件应用（人脸信息/数字化运营场景）

| 定性 | 实战影响 | 抗辩武器 |
|---|---|---|
| 隐私权（8(1)） | 举证"私密性+安宁受损"；可主张精神损害 | 合理隐私期待边界 |
| 个人信息保护（8(2)） | 举证"未获同意/过度处理"（个保法§13/§6） | 合法正当必要原则（§1035）、同意例外 |

**战术要点**：
1. 厚德基金会等机构数字化运营收集受益人信息，须先区分"私密信息"与"一般个人信息"，分别设计同意与脱敏流程。
2. 人脸信息场景直接引《人脸识别司法解释》——一般定个人信息保护案由（行3702）。
3. 法条引用禁用民诉法第28条，一律第29条。

## 八、翻车标本（≥4）

| # | 错误做法 | 后果 |
|---|---|---|
| 1 | 凡"信息被收集/泄露"一律定隐私权纠纷 | 非私密可识别信息（已公开手机号）只构成个人信息保护，错定架空个保法独立案由 |
| 2 | 把"隐私权、个人信息保护纠纷"当独立三级案由 | 它是三级"8"项下的**合并适用表述**，非新案由；漏列四级 8(1)/8(2) 致录入错误 |
| 3 | 仍引民诉法第28条 | 已废，现行第29条 |
| 4 | 忽略 §1034 第3款阶梯适用 | 私密信息应优先隐私权，误定个人信息保护致请求权基础偏离 |
| 5 | 立案用 2020 版"6.隐私权纠纷" | 2025版应为 8(1)，编号漂移 |
