# R-AY-085 集成电路布图设计合同纠纷 单案由路由卡（L1）

> 知识产权合同族串联节点之一。与 R-AY-084 植物新品种合同共享「**管辖高度分化**」这一核心路由点——错定管辖直接被移送，是代理该类案第一道生死线。

## 一、案由释义（2020/2025 同序，编号 150→156）

集成电路布图设计合同纠纷，是指当事人就集成电路布图设计的**创作、有关权利的转让和许可使用**等内容所订立的合同而发生的纠纷。

四级案由（2025 版 156 项下，与 2020 版 150 项下一致）：
- **(1) 集成电路布图设计创作合同纠纷**：就布图设计的创作所订立的合同而发生的纠纷，含**委托创作**、**合作创作**。
- **(2) 集成电路布图设计专有权转让合同纠纷**：就布图设计专有权的转让所订立的合同而发生的纠纷。
- **(3) 集成电路布图设计许可使用合同纠纷**：就布图设计的许可使用所订立的合同而发生的纠纷。

> 实务补充（书内确认）：**集成电路布图设计代理合同**未单列，但参照专利/商标代理合同归类，亦作为布图设计合同纠纷受理。

## 二、管辖（🔴 核心路由点·三级分化）

| 四级子案由 | 管辖法院 | 依据 |
|---|---|---|
| **(1) 创作合同** | 非专属管辖 → **一般合同管辖**（被告住所地/合同履行地，民诉法§23）；且属知识产权技术类合同，应同时适用知识产权技术类合同管辖规定 | 书内【管辖】段 |
| **(2) 专有权转让合同** | **特定中级人民法院专属一审**：各省/自治区/直辖市人民政府所在地、经济特区所在地、及大连、青岛、温州、佛山、烟台市的中级人民法院 | 《最高法关于开展涉及集成电路布图设计案件审判工作的通知》第1、2条 |
| **(3) 许可使用合同** | **中级以上人民法院**管辖；高院可报最高法批准指定若干基层法院管辖 | 《最高法关于审理技术合同纠纷案件适用法律若干问题的解释》§43 第1、2款 |
| **北/上/广/海南自贸港** | 知识产权法院**专属**：北/上/广知产法院所在市辖区内布图设计一审案件全部由其管辖；海南自贸港知产法院管辖海南省有关一审知产民事案件 | 《北/上/广知产法院管辖规定》§1、§7；《海南自贸港知产法院设立决定》§2 |
| **上诉审** | 不服高院/知产法院/中院作出的布图设计一审民事判裁提起上诉的 → **最高法知识产权法庭**审理 | 《最高法知识产权法庭规定》§2 第1款 |

## 三、法律适用（请求权基础）

- **一般法源**：《民法典》第123条（知识产权客体，布图设计为法定知识产权客体之一）。
- **专有权转让/许可合同**：《民法典》第876条（技术合同参照适用）、《集成电路布图设计保护条例》第22条、《实施细则》第10条第2款、第11条。
- **创作合同**：《集成电路布图设计保护条例》第10条、第11条。
- **代理合同**：《集成电路布图设计保护条例实施细则》第4条。
- **纠纷类型界分**（最高法审判工作通知第1条列举11项布图设计纠纷）：第2项=专有权转让合同（本案由）；第1、3项=权属/侵权（见专有权权属、侵权纠纷）；第4项=临时措施（诉前停止侵害/诉前保全）；第5-10项=行政纠纷。

## 四、定性边界（确定该案由应当注意的问题）

1. **与「技术合同纠纷」的界分**：《民法典》第876条规定布图设计专有权等转让、许可参照适用技术合同有关规定——**仅涉法律适用，不涉案由确定**。除非合同主要权利义务是关于**利用布图设计提供咨询、服务、培训**，不应定为技术合同纠纷。
2. **创作合同 vs 专有权权属纠纷**：创作合同含因合作/委托创作发生的合同纠纷，但**涉及专有权权属争议除外** → 应按「集成电路布图设计专有权权属纠纷」定案由，不落本案由。
3. **代理合同**：未具体列举，但参照专利/商标代理合同归类，应作为布图设计合同纠纷受理。
4. **与植物新品种合同（R-AY-084）同源**：二者均为「知识产权技术类合同」，管辖逻辑同构（创作=一般合同、转让=专属中院、许可=技术合同§43），可交叉引用。

## 五、在办案件应用

- 当前在办案件（吊顶/雅菲/面瘫/王德明担保/航合物流/厚德基金会）均不直接涉及布图设计合同，本卡主要作为**知识产权合同族路由串联节点**与**管辖分化范式**备用。
- 高价值复用场景：任何知识产权技术类合同（含植物新品种、专利、布图设计、技术秘密）的**管辖论证**——直接调取本卡 + R-AY-084 的「管辖三级分化」矩阵，避免管辖错误被移送。

## 六、翻车标本（易错点）

1. ❌ 把专有权转让合同按一般合同（被告住所地）起诉 → 应专属特定中院，普通基层法院无管辖权，立审阶段即被移送。
2. ❌ 把许可使用合同按基层法院普通合同立案 → 应中级以上法院（技术合同§43），高院指定基层为例外需查本地名录。
3. ❌ 北/上/广/海南将布图设计合同立到普通中院 → 应知识产权法院专属管辖。
4. ❌ 创作合同混同技术合同纠纷 → 创作合同是知识产权合同，非技术合同，案由定性错误影响法律适用与管辖。
5. ❌ 委托创作中夹带专有权权属争议 → 权属争议应剥离定「专有权权属纠纷」，不落本案由。
