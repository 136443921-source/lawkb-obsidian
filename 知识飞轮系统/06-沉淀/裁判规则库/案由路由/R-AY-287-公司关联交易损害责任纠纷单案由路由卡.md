# 公司关联交易损害责任纠纷单案由路由卡（R-AY-287｜2025 §310／2020 §278）

> **一句话定位**：**公司自身**因控股股东、实际控制人、董事、监事、高级管理人员利用关联关系实施不公平关联交易、转移/侵占公司利益而受损，请求侵权主体赔偿损失的**商事侵权类案由**（关联损害·§22＋§182＋民法典§84＋解释五第1条）——与 304（要分钱）、305（要赔股东）、306（要赔公司）、307（要追债权人）构成「损害X利益」系列的**关联交易专项环节**，🔴 法律不禁止关联交易本身、只规制不公允关联交易的赔偿责任，且**程序抗辩（已披露/已决议）法院不予支持**。

## 二、受案范围与核心特征

公司（或符合条件股东代位）请求下列主体赔偿因不公平关联交易给公司造成的财产损失：

- **控股股东、实际控制人**（§22）——利用关联关系损害公司利益。
- **董事、监事、高级管理人员**（§22＋§182）——自我交易/关联交易未报告决议、或利用职务便利谋取公司商业机会（§183）、同业竞争（§184）。
- **董监高近亲属及其控制企业、其他关联人**（§182 扩张范围）——与董监高本人同受报告决议程序约束。
- **"影子董事/事实高管"**（实质重于形式）——未任职务但实际行使高管职权、主导不公平关联交易的，参照董监高担责（最高法(2019)最高法民申2728号）。

**核心特征 = 受害主体为公司自身 ＋ 要件为"利用关联关系＋不公平交易＋公司实际损失" ＋ 法律后果为赔偿责任**。🔴 关联交易**本身合法中性**，法律只规制不公允关联交易；审查采**程序公平（披露＋决议＋回避）＋实质公平（对价公允）**双重要件。

## 四、管辖（🔴 侵权纠纷型，与 306 兜底型分轨）

🔴 **310 定性为侵权纠纷**（致琨律所专题研究＋最高法案例库 最高法民再181号 明确"关联交易损害公司利益为侵权责任纠纷"），**不适用民诉法 §27 专属管辖**，而适用**一般侵权管辖**＝《民事诉讼法》§29「**侵权行为地或者被告住所地**」人民法院管辖（侵权行为地含实施地、结果发生地）。

**与 R-AY-285（306）管辖分轨要点**：
- **306 损害公司利益**：属「与公司有关纠纷」，靠 §27「等」兜底，论证弱但可力争公司住所地（兜底型）。
- **310 关联交易损害**：属侵权纠纷，**直接按被告住所地/侵权行为地**，不引用 §27，管辖依据清晰、与 306 分轨。
- **307 损害公司债权人**：同属侵权（§29），与 310 同阵营。

⚠️ **310 管辖弹性点**：若关联交易涉及公司内部组织机构运行事宜（如须经股东会/董事会决议），司法实践中存在由公司住所地管辖的情形（最高法(2014)皖民二初字第00029号：涉及内部组织运行的股东代表诉讼由公司住所地管辖）。故 310 原则上按 §29 侵权管辖，**涉及内部组织运行的可争公司住所地**——此点与 307 纯侵权管辖略有弹性。

## 五、最高价值段（老强点名：讲透 310 与 304/305/306/307 的「损害X利益」系列＋专项vs一般竞合）

### 5.1 310 自身定位：公司受害·关联交易专项

310 是「损害X利益」系列中**受害主体为公司自身、且由关联交易引发**的环节，核心＝关联损害赔偿责任（§22＋§182＋民法典§84＋解释五第1条）。🔴 与 306（广义损害公司利益一般案由）存在**专项优于一般**关系——关联交易致损应优先立 310。

### 5.2 ⚠️ 310 vs 306 损害公司利益（专项vs一般·最高频易混）

| 维度 | 310 公司关联交易损害（本卡） | 306 损害公司利益（R-AY-285） |
|---|---|---|
| 致损原因 | **不公平关联交易**（利用关联关系） | 广义损害公司利益（含关联但不限于） |
| 案由性质 | 商事侵权（§22/§182） | 组织法救济（§188/§189） |
| 管辖 | **§29 侵权**（被告住所地/侵权行为地） | §27「等」兜底（公司住所地弱管辖） |
| 适用规则 | **专项优于一般**，关联交易优先 310 | 非关联交易的一般损害公司利益 |

🌐 关联交易致公司受损→310（专项）；非关联的一般损害公司利益→306；二案受害主体同为"公司"，但 310 有专项案由优先适用，不得一律以 306 兜底。

### 5.3 「损害X利益」系列总览（304/305/306/307/310）

- **304 公司盈余分配纠纷** ← 要分钱（给付之诉，股东诉公司）
- **305 损害股东利益责任纠纷** ← 要赔股东个人（股东直接诉 §190）
- **306 损害公司利益责任纠纷** ← 要赔公司（代表诉讼 §189·§27兜底）—**一般案由**
- **307 损害公司债权人利益责任纠纷** ← 外部债权人受害（§23人格否认·§29侵权）
- **310 公司关联交易损害责任纠纷** ← **本卡**（公司受害·关联交易专项·§22/§182·§29侵权）

⚠️ **310 vs 299 公司决议（程序分野）**：关联交易经董事会/股东会决议通过的，仍可能被认定为 310（解释五第1条：程序抗辩不予支持）；若决议本身违法（关联董事未回避、决议不成立），公司可另立 299 主张决议瑕疵——实体赔偿（310）与决议效力（299）二案进路不同，不竞合。

### 5.4 「损害X利益」系列链条总览

```
公司纠纷·损害X利益系列（含关联交易专项）
├─ 304 公司盈余分配纠纷 ← 要分钱（给付）
├─ 305 损害股东利益责任纠纷 ← 要赔股东个人（§190 直接诉）
├─ 306 损害公司利益责任纠纷 ← 要赔公司（代表诉讼 §189·§27兜底·一般案由）
├─ 307 损害公司债权人利益责任纠纷 ← 外部债权人受害（§23人格否认·§29侵权）
└─ 310 公司关联交易损害责任纠纷 ← 本卡（公司受害·关联交易专项·§22/§182·§29侵权）
```

🌐 **总口诀**：分不到钱用 304、赔不到股东用 305、赔不到公司用 306（一般）/关联交易致损用 310（专项）、追不到债权人用 307——310 是公司与中小股东规制不公平关联交易的法定通道，🔴 法律不禁止关联交易本身、只规制不公允交易，且**程序抗辩法院不予支持**。

## 六、立案/审理要点提示

1. **案由选择**：关联交易致公司受损→**310（专项优先）**；非关联的一般损害公司利益→306；外部债权人受害→307；股东个人受损→305。不得一律以 306 兜底吞噬 310。
2. **管辖**：310 按**被告住所地/侵权行为地（§29）**侵权管辖，**不引用 §27**；涉及公司内部组织运行的可争公司住所地（皖民二初字第00029号弹性）。
3. **双重要件**：程序公平（披露＋决议＋回避，§182/§185）＋实质公平（对价公允）；🔴 **被告仅以"已履行程序"抗辩的法院不予支持**（解释五第1条）——程序完备不豁免实质审查。
4. **关联主体扩张**：§182 将董监高近亲属、其控制企业、其他关联人纳入关联人范围；"影子董事/事实高管"参照担责（最高法民申2728号）。
5. **股东代表诉讼**：公司怠于起诉时，符合条件股东可代位提起 310（前置程序＋书面请求监事会/董事会），系程序路径而非独立案由。
6. **与 299 边界**：关联交易经决议的，实体赔偿仍归 310；决议瑕疵另行 299 处理，二案不竞合。
