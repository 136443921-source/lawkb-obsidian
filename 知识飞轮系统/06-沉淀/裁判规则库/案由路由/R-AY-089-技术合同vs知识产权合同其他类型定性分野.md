# R-AY-089 技术合同 vs 知识产权合同其他类型 定性分野（L2）

> **本卡回答**：都是"与技术有关的合同"，到底定 **158 技术合同纠纷**，还是定更具体的 **知识产权合同纠纷**（150 著作权／151 商标／152 发明专利／153 实用新型专利／154 外观设计专利／155 植物新品种／156 集成电路布图设计／157 商业秘密）？源书第五部分【知识产权合同纠纷】段明文给出**排他性路由规则**——这是知识产权合同族最高频的定性分野，定错直接改变管辖与法律适用。

---

## 〇、立项三问（定性分野卡 SOP 前置校验）

| 立项三问 | 结论 |
|---|---|
| **① 是否存在两个以上案由的定性竞合？** | ✅ 是。源书第五部分明确："**凡是能以其他知识产权合同纠纷确定案由的，就不适用技术合同纠纷案由**"（OCR 行14287）；并列举计算机软件著作权转让/许可、专利申请权转让、专利权转让、三类专利实施许可、植物新品种申请权/权转让/实施许可、集成电路布图设计专有权转让/许可、技术秘密让与/许可等，均"不适用本案由"。技术合同(158) 与知识产权合同其他类型(150-157) **构成排他性竞合**。 |
| **② 定性错误是否产生实质后果差异？** | ✅ 是，且差异巨大。**管辖法院不同**（技术合同纠纷由具有一般知识产权案件管辖权的中级人民法院受理，见《技术合同解释》§43；而专利/植物新品种/集成电路/技术秘密等技术类知识产权合同由知识产权法院/最高法院知产法庭专门管辖，级别与专属规则更严）、**法律适用不同**（专利/植物新品种等须适用对应专门法＋知产司法解释，而非单纯《技术合同解释》）、**统计与案由体系归属不同**。 |
| **③ 是否已有单案由卡或既有分野卡覆盖？** | 🟡 否（本卡为首张技术合同分野卡）。R-AY-086 已建立"商业秘密合同优先于技术合同"的单点路由，本卡将其**泛化为全知识产权合同族的排他性路由规则**，与 R-AY-086 互补不重叠。 |

> ✅ 三问全过，**立 L2 定性分野卡**。

## 二、⭐ 排他性路由判别（本卡最高价值段）

源书第五部分核心规则（OCR 行14255-14294）：

> "考虑到知识产权合同纠纷案由划分的科学性、系统性和司法统计的实用性以及过去确定有关技术合同案由的传统，也为了避免案由交叉，《民事案件案由规定》将作为第三级案由的技术合同纠纷的范围作了进一步限缩性的规定，**凡是能以其他知识产权合同纠纷确定案由的，就不适用技术合同纠纷案由**。"

### 2.1 判别口诀

```
第一步：争议标的是否涉及特定知识产权客体的合同权利义务？
  └ 否（纯技术开发/咨询/服务/培训/中介，不指向特定知产客体权属） → 158 技术合同
  └ 是 ↓
第二步：能否归入更具体的知识产权合同案由？
  └ 计算机软件著作权转让/许可          → 150 著作权合同
  └ 专利申请权/专利权转让、专利实施许可 → 152/153/154 专利合同
  └ 植物新品种申请权/权转让/实施许可    → 155 植物新品种合同
  └ 集成电路布图设计专有权转让/许可      → 156 集成电路合同
  └ 技术秘密/经营秘密让与/许可          → 157 商业秘密合同
  └ 商标权转让/使用许可                → 151 商标合同
  └（兜底）不能归类于上述特定知产客体    → 158 技术合同（保留"技术转让合同纠纷"第四级收容）
```

### 2.2 🔴 例外：技术进出口合同

除应当适用《技术进出口管理条例》的技术进出口合同之外，其他各类技术转让合同纠纷，依所涉及技术成果的知识产权类型，相应在各类知识产权合同纠纷项下确定案由。**技术进口/出口合同纠纷（158(10)/(11)）是技术合同项下保留的特例**，因受《技术进出口管理条例》特别规制，不强行归入知产合同。

## 四、法律适用（本地核填·现行有效，含官方核验指引）

### 4.1 技术合同纠纷（民法典合同编第 20 章 技术合同）

**第八百四十三条**　技术合同是当事人就技术开发、转让、咨询或者服务订立的确立相互之间权利和义务的合同。
> *效力状态：现行有效（本地核填）*

**第八百四十四条**　订立技术合同，应当有利于知识产权的保护和科学技术的进步，促进科学技术成果的研发、转化、应用和推广。
> *效力状态：现行有效（本地核填）*

**第八百六十二条**　技术转让合同是合法拥有技术的权利人，将现有特定的技术成果的相关权利让与他人所订立的合同。技术许可合同是合法拥有技术的权利人，将现有特定的技术成果的相关权利许可他人实施、使用所订立的合同。
> *效力状态：现行有效（本地核填）* 🔴 **技术许可从技术转让分立（2025 版第四级据此新增(5)技术许可合同）**

**第八百七十八条**　技术咨询合同是当事人一方以技术知识为对方就特定技术项目提供可行性论证、技术预测、专题技术调查、分析评价报告等所订立的合同。技术服务合同是当事人一方以技术知识为他方解决特定技术问题所订立的合同，不包括建设工程合同和承揽合同。
> *效力状态：现行有效（本地核填）* 🔴 **技术服务≠建设工程/承揽（回指 R-AY-004/R-AY-006）**

### 4.2 排他性路由的外部规范

- 《最高人民法院关于审理技术合同纠纷案件适用法律若干问题的解释》§1、§2、§43——技术成果定义、技术合同范围、管辖；
- 《民法典》第 123 条——知识产权客体（专利/植物新品种/集成电路/商业秘密/著作权等均属知识产权）；
- 各知识产权专门法（专利法/植物新品种保护条例/集成电路布图设计保护条例/反不正当竞争法§9 商业秘密/著作权法）——对应知产合同优先适用。

## 五、定性边界与排除清单 ⭐

### 5.1 🔴 "技术上有关"≠"知识产权合同"

| 合同特征 | 定性 | 案由 |
|---|---|---|
| 技术开发/转让/咨询/服务，但**不指向特定知识产权客体权属**（如通用技术咨询、非专利专有技术转让） | 技术合同 | 158 |
| 计算机软件**著作权**转让/许可 | 著作权合同 | 150 |
| 专利（申请权/权）转让、专利实施许可 | 专利合同 | 152/153/154 |
| 植物新品种权转让/实施许可 | 植物新品种合同 | 155 |
| 集成电路布图设计专有权转让/许可 | 集成电路合同 | 156 |
| 技术秘密/经营秘密让与/许可 | 商业秘密合同 | 157 |

### 5.2 与技术秘密的界分（回指 R-AY-086）

技术秘密让与/许可合同本质属商业秘密合同（知识产权合同），定 157；但若合同主要权利义务是关于"利用技术提供咨询、服务、培训"而非技术秘密权属转移/许可，则定技术合同 158。本书【确定该案由应当注意的问题】明定"凡是能以其他知识产权合同纠纷确定案由的，就不适用技术合同纠纷案由"。

### 5.3 技术服务 vs 建设工程/承揽

技术服务合同不包括建设工程合同纠纷和承揽合同纠纷（民法典§878 明示）。技术成果构成复杂性下，不能归类于特定知产客体的技术转让/许可，可纳入 158 兜底"技术转让合同纠纷"第四级（源书行15172-15176）。

## 六、在办案件应用（占位·须实地核实）

> ⚠️ 具体当事人、合同标的、知产客体类型以原始合同与权属登记实地核实为准，本卡不凭记忆填写。

**涉农植物新品种技术合同定性四问**（适用于厚德基金会/航合物流涉农技术合作场景）：

1. **合同标的是否为特定植物新品种的申请权/权转让或实施许可？** → 是则落 **155 植物新品种合同**（知产专门管辖）；否则落 158。
2. **是否涉及技术秘密让与/许可？** → 是则落 **157 商业秘密合同**（再分技术/经营秘密定管辖，见 R-AY-086）。
3. **是否纯技术开发/咨询/服务、不指向特定知产客体？** → 是则落 **158 技术合同**（中院一般知产管辖）。
4. **是否受《技术进出口管理条例》规制？** → 是则保留 158(10)/(11) 技术进出口合同特例。
