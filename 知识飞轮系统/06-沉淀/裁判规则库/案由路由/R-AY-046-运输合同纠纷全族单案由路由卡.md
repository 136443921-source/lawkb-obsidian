# 运输合同纠纷全族 · 单案由路由卡

> **本卡回答**：运输出事了，定第几个四级案由、去哪个法院起诉？本案由是**合同纠纷项下四级案由最多的一族**（2025 版达 **18 项**），且**管辖规则全族特殊**——不走 §24 一般合同管辖，而走 §28 运输专属地域管辖，铁路类还要进铁路运输法院、海上类直接改姓海事海商。**定错四级案由＝管辖错＋法院错。**

## 二、释义与全族定义核录（本书【释义】段）

**运输合同**：承运人将旅客或者货物从**起运地点**运输到**约定地点**，旅客、托运人或者收货人支付票款或者运输费用的合同（民法典§809）。主体是**承运人**与**旅客、托运人**。

**两种分类维度**：
- 按运输对象 → **旅客运输合同** ／ **货物运输合同**
- 按运输方式 → 公路、水路、航空、铁路、管道、多式联运

### 2.1 各四级案由定义（本书逐项核录·含边界限定）

| 四级案由 | 定义要点 | 🔴 边界限定 |
|---|---|---|
| 公路旅客运输 | 承运人在公路上使用汽车和其他运输工具从事旅客运输 | 也称**城乡道路运输**，**不包括城镇内公共汽车的运输** |
| 公路货物运输 | 在公路上使用汽车等将托运人货物安全运至指定地点交付收货人 | — |
| 水路旅客运输 | 以适合运送旅客的船舶经水路将旅客及其自带行李**从一港运至另一港**，旅客付票款 | 限**国内水路**（见 5.1） |
| 水路货物运输 | 以船舶经水路将货物从一港运至另一港 | 🔴 **仅指经营性运输行为**引起的纠纷；**非营业性水路运输引起的争议不适用本案由** |
| 航空旅客运输 | 以航空器将旅客及其行李安全运送至目的地 | — |
| 航空货物运输 | 使用航空器和其他设备，将托运人货物以航空方式运抵指定地点交收货人 | — |
| 出租汽车运输 | 以出租汽车为工具，将乘客及随身物品运至约定地点并收运费 | 与城市公交**互相排除** |
| 管道运输 | 以管道作为运输方式运输货物 | 通常为石油、天然气等**液体、气体或其他易于流动的货物** |
| 城市公交运输 | 一个城镇内的公共运输企业利用公共汽车、电车、地铁列车、索道缆车以及城市水上客运船运送旅客 | 🔴 **不包括出租汽车** |
| 联合运输 | 多个承运人以**同一种运输方式**共同完成货物运输；托运人只与其中一个（通常是第一个）承运人签约 | 又叫**相继运输合同** |
| 多式联运 | 多式联运经营人以**两种以上不同运输方式**将货物从接收地运至目的地交付收货人，收取全程运费 | 见 5.2 与联合运输的四点区别 |
| 铁路货物运输 | 铁路运输企业按约定或国务院铁路主管部门规定期限将货物运至目的地，托运人或收货人付运费 | 铁路运输法院管辖 |
| 铁路旅客运输 | 铁路运输企业按**车票载明的日期、车次**将旅客运至目的地 | 铁路运输法院管辖 |
| 铁路行李运输 | 铁路运输企业将旅客自用的被褥、衣服及其他旅行必需品运至目的地 | 铁路运输法院管辖 |
| 铁路包裹运输 | 铁路运输企业将**小件货物放置于旅客列车行李车内随车运送**至目的地 | 铁路运输法院管辖 |
| 国际铁路联运 | 国际联运承运人按与托运人的约定，**通过铁路跨国**运送货物 | 铁路运输法院管辖 |

## 三、管辖 🔴（本卡最高风险段）

### 3.1 基础规则：特殊地域管辖，不走一般合同管辖

本书【管辖】段（行12008-12011）：

> 根据《民事诉讼法》第 27 条规定，因铁路、公路、水上、航空运输和联合运输合同纠纷提起的诉讼，由**运输始发地、目的地或者被告住所地**人民法院管辖。

**现行条号核填**（本地《中华人民共和国民事诉讼法（2023）》）：

> **第 28 条**　因铁路、公路、水上、航空运输和联合运输合同纠纷提起的诉讼，由运输始发地、目的地或者被告住所地人民法院管辖。

> 🔴 **书内§27 已废，现行为§28**。且运输合同纠纷**不适用**§24（被告住所地／合同履行地）——多出"运输始发地、目的地"两个连接点，是原告选择法院的重要战术空间。

### 3.2 铁路类五项 → 铁路运输法院

依《最高人民法院关于铁路运输法院案件管辖范围的若干规定》**第 3 条**，下列由**铁路运输法院管辖**：
- 铁路旅客和行李、包裹运输合同纠纷
- 铁路货物运输合同纠纷
- 国际铁路联运合同纠纷
- **铁路运输企业作为经营人的多式联运合同纠纷**

> ⚠️ 第四项是暗坑：多式联运本身不专属铁路法院，但**经营人是铁路运输企业**时进铁路运输法院。

### 3.3 水路类：先分海事，再定普通法院

本书【管辖】段口径：

> 确定管辖的关键在于将**水路旅客／货物运输合同纠纷**与**海上、通海水域货物运输／旅客运输／行李运输合同纠纷**相互区分。一般而言，属于海上、通海水域相关运输合同的，起诉至人民法院时**优先按照相关的海上、通海水域运输合同纠纷确定案由，由相应的海事法院管辖**；不属于海上、通海水域相关运输合同的，则按相关的水路运输合同纠纷确定案由，**由普通法院管辖**。

```
水上运输起诉前必答一问：是否属海上／通海水域？
  ├ 是 → 案由改姓「海事海商纠纷」→ 海事法院
  └ 否 → 121(3)/(4) 水路旅客／货物运输 → 普通法院 + §28
```

## 四、法律适用（本地核填·现行有效，含官方核验指引）

**《民法典》合同编第 19 章 运输合同**（本地《中华人民共和国民法典（全文）》核填，现行有效）

### 4.1 一般规定

**第八百零九条**　运输合同是承运人将旅客或者货物从起运地点运输到约定地点，旅客、托运人或者收货人支付票款或者运输费用的合同。
> *效力状态：现行有效（本地核填）*

**第八百一十条**　从事公共运输的承运人不得拒绝旅客、托运人通常、合理的运输要求。
> *效力状态：现行有效（本地核填）* 🔴 **强制缔约义务——公交、出租、铁路客运拒载类纠纷的直接依据**

**第八百一十一条**　承运人应当在约定期限或者合理期限内将旅客、货物安全运输到约定地点。
> *效力状态：现行有效（本地核填）*

### 4.2 客运合同

**第八百一十四条**　客运合同自承运人向旅客出具客票时成立，但是当事人另有约定或者另有交易习惯的除外。
> *效力状态：现行有效（本地核填）* 🔴 **出票即成立——不以实际乘坐为成立要件**

**第八百一十五条**　旅客应当按照有效客票记载的时间、班次和座位号乘坐。旅客无票乘坐、超程乘坐、越级乘坐或者持不符合减价条件的优惠客票乘坐的，应当补交票款，承运人可以按照规定加收票款；旅客不支付票款的，承运人可以拒绝运输。
　　实名制客运合同的旅客丢失客票的，可以请求承运人挂失补办，承运人不得再次收取票款和其他不合理费用。
> *效力状态：现行有效（本地核填）* 🔴 **第2款是"实名制票丢失被要求二次买票"类纠纷的请求权基础**

**第八百二十三条**　承运人应当对运输过程中旅客的伤亡承担赔偿责任；但是，伤亡是旅客自身健康原因造成的或者承运人证明伤亡是旅客故意、重大过失造成的除外。
　　前款规定适用于按照规定免票、持优待票或者经承运人许可搭乘的无票旅客。
> *效力状态：现行有效（本地核填）* 🔴 **承运人无过错责任＋两项免责；第2款把免票／优待票／许可搭乘的无票旅客一并纳入保护**

**第八百二十四条**　在运输过程中旅客随身携带物品毁损、灭失，承运人有过错的，应当承担赔偿责任。
　　旅客托运的行李毁损、灭失的，适用货物运输的有关规定。
> *效力状态：现行有效（本地核填）* 🔴 **随身物品＝过错责任；托运行李＝货运规则（§832 无过错＋四免责）——责任基础完全不同**

### 4.3 货运合同

**第八百二十五条**　托运人办理货物运输，应当向承运人准确表明收货人的姓名、名称或者凭指示的收货人，货物的名称、性质、重量、数量，收货地点等有关货物运输的必要情况。
　　因托运人申报不实或者遗漏重要情况，造成承运人损失的，托运人应当承担赔偿责任。
> *效力状态：现行有效（本地核填）*

**第八百二十六条**　货物运输需要办理审批、检验等手续的，托运人应当将办理完有关手续的文件提交承运人。
> *效力状态：现行有效（本地核填）*

**第八百三十二条**　承运人对运输过程中货物的毁损、灭失承担赔偿责任。但是，承运人证明货物的毁损、灭失是因不可抗力、货物本身的自然性质或者合理损耗以及托运人、收货人的过错造成的，不承担赔偿责任。
> *效力状态：现行有效（本地核填）* 🔴 **无过错责任＋四项法定免责（不可抗力／自然性质／合理损耗／托运人收货人过错），举证责任在承运人**

**第八百三十三条**　货物的毁损、灭失的赔偿额，当事人有约定的，按照其约定；没有约定或者约定不明确，依据本法第五百一十条的规定仍不能确定的，按照交付或者应当交付时货物到达地的市场价格计算。法律、行政法规对赔偿额的计算方法和赔偿限额另有规定的，依照其规定。
> *效力状态：现行有效（本地核填）* 🔴 **顺位：约定 → §510 补充解释 → 到达地市场价；末句为《铁路法》《民航法》责任限额留出口**

**第八百三十四条**　两个以上承运人以同一运输方式联运的，与托运人订立合同的承运人应当对全程运输承担责任；损失发生在某一运输区段的，与托运人订立合同的承运人和该区段的承运人承担连带责任。
> *效力状态：现行有效（本地核填）* 🔴 **联合运输（相继运输）责任条——与本书 5.2 口径完全对应**

**第八百三十五条**　货物在运输过程中因不可抗力灭失，未收取运费的，承运人不得请求支付运费；已经收取运费的，托运人可以请求返还。法律另有规定的，依照其规定。
> *效力状态：现行有效（本地核填）*

### 4.4 多式联运合同

**第八百三十八条**　多式联运经营人负责履行或者组织履行多式联运合同，对全程运输享有承运人的权利，承担承运人的义务。
> *效力状态：现行有效（本地核填）* 🔴 **无论与其他承运人如何约定，全程责任归多式联运经营人**

**第八百四十二条**　货物的毁损、灭失发生于多式联运的某一运输区段的，多式联运经营人的赔偿责任和责任限额，适用调整该区段运输方式的有关法律规定；货物毁损、灭失发生的运输区段不能确定的，依照本章规定承担赔偿责任。
> *效力状态：现行有效（本地核填）* 🔴 **区段法律适用规则；区段无法确定时回落民法典本章**

## 五、定性边界 ⭐

### 5.1 🔴 水路运输 vs 海上、通海水域运输

本书【确定该案由应当注意的问题】"一是"（行12041-12050）：

> 本案由中的水路运输指的是**国内水路运输**。按照《国内水路运输管理条例》第 2 条第 2 款的规定，国内水路运输，是指**始发港、挂靠港和目的港均在中华人民共和国管辖的通航水域内**的经营性旅客运输和货物运输。在案由的确定上，可以考虑**不属于海上、通海水域运输合同纠纷的才确立为水路运输合同纠纷**。

| 判别项 | 水路运输（121(3)(4)） | 海上、通海水域运输 |
|---|---|---|
| 港口范围 | 始发港、挂靠港、目的港**均在我国管辖通航水域内** | 涉海上或通海水域 |
| 经营性 | 🔴 **限经营性**（非营业性不适用本案由） | — |
| 案由归属 | 合同纠纷项下 | **海事海商纠纷**项下独立案由 |
| 管辖法院 | 普通法院＋§28 | **海事法院** |
| 特别法 | 《国内水路运输管理条例》 | **《海商法》** |

> ⚠️ **确定顺序是"先排海事、后落水路"**——不是先看是不是水路，而是先看是否属海上／通海水域。

### 5.2 🔴 联合运输 vs 多式联运（四点区别）

本书"二是"（行12052-12064）：

| 区别项 | **联合运输（121(10)）** | **多式联运（121(11)）** |
|---|---|---|
| 运输方式数 | **只有一种**运输方式 | **两种以上**不同运输方式 |
| 责任承担首要原则 | 由**与托运人订立合同的承运人**对全程运输承担责任；损失明确发生在某区段的，该区段承运人与订约承运人承担**连带责任**（§834） | 🔴 **不管多式联运经营人与其他承运人如何约定，均由多式联运经营人对全程运输负责任**（§838） |
| 赔偿责任与责任限额的法律适用 | 运输方式单一 → 适用法律**单一** | 🔴 因运输区段不同而**适用不同法律**（§842） |
| 区段不能确定时 | — | 依民法典运输合同章承担赔偿责任（§842 后段） |

> 📌 战术含义：**联合运输可把区段承运人拉进来共同被告（连带责任）；多式联运则直接锁定经营人**，无须逐段查责——起诉主体选择完全不同。

### 5.3 运输合同 vs 货运代理合同

| 项 | 运输合同（121） | 货运代理合同（124(2)，见 R-AY-045） |
|---|---|---|
| 合同标的 | **运输行为** | **处理事务** |
| 直接目的 | 运送货物 | 代办运输相关事务 |
| 管辖 | §28 特殊地域管辖 | §24／§35 一般合同管辖 |

### 5.4 城市公交 vs 出租汽车 vs 公路旅客运输（三者互斥）

| 情形 | 四级案由 |
|---|---|
| 城镇内公共汽车、电车、地铁、索道缆车、城市水上客运船 | (9) 城市公交运输 |
| 出租汽车 | (7) 出租汽车运输（🔴 城市公交明文**不含**出租汽车） |
| 公路上汽车等从事城乡道路旅客运输 | (1) 公路旅客运输（🔴 明文**不含**城镇内公共汽车运输） |

## 六、在办案件应用（占位·须实地核实）

> ⚠️ 具体承运人、始发地／目的地、运单与票据以原始案卷实地核实为准，本卡不凭记忆填写。

**运输类案件立案前五查清单**：
1. **查运输方式** → 定四级案由（18 项中择一）；涉外航空／公路的，**2026-01-01 后走新增 (17)(18)**。
2. **查水域性质** → 涉水的先排海事（海上／通海水域→海事法院），再落水路。
3. **查承运主体** → 铁路运输企业相关（含其作为多式联运经营人）→ **铁路运输法院**。
4. **查连接点** → §28 给出**运输始发地、目的地、被告住所地**三个可选法院，比较诉讼便利与裁判倾向后择优。
5. **查损失客体** → 旅客伤亡（§823 无过错＋两免责）／随身物品（§824 第1款**过错**责任）／托运行李与货物（§832 无过错＋**四**免责）——责任基础与举证分配三分天下。

**承运人一方应诉要点**：§832 四项免责由**承运人举证**（不可抗力／货物自然性质／合理损耗／托运人收货人过错）；同时核查 §825 托运人是否申报不实（可反诉或抗辩），并主张 §833 末句的单行法**责任限额**（《铁路法》《民航法》）。

> 📌 **与在办物流行业事故的接口**：涉重型货车运输致行人损害的，属**侵权责任**路径（非本案由）；但若同时存在货物运输合同关系，须区分"对第三人的侵权之诉"与"运输合同项下托运人索赔之诉"两条线，案由与管辖各行其道。具体事实以案卷核实为准。
