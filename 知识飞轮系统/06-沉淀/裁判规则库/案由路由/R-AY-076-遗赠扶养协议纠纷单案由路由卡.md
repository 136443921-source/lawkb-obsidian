# 遗赠扶养协议纠纷单案由路由（33）

> **本卡回答**：自然人与继承人以外的组织/个人订立**生前有偿扶养协议**（对方承担生养死葬、享受遗赠权）发生争议的，定 **33 遗赠扶养协议纠纷**。🔴 关键＝遗赠扶养是**双务有偿生前协议**，效力**优先于遗嘱和遗赠**（§1158 优先于 30/32）。

## 一、释义核录

遗赠扶养协议是自然人生前与扶养人（继承人以外的人/组织）订立的双务合同：扶养人负生养死葬义务，享受遗赠权。全族含：① 协议效力与履行（扶养人是否尽义务）；② 协议解除/违约（扶养人不履行则可解除、不享遗赠）；③ 与遗嘱冲突时的效力优先。性质上属合同，但具身份色彩。

## 二、管辖

一般地域管辖（§22／§24），无专属管辖。履行争议以扶养人（被告）住所地法院管辖为宜。

## 三、法律适用

- **§1158**：自然人可以与继承人以外的组织或者个人签订遗赠扶养协议；按照协议，该组织或者个人承担该自然人生养死葬的义务，享有受遗赠的权利。
- **效力优先**：遗赠扶养协议效力优先于遗嘱和遗赠——被继承人生前所立遗嘱/遗赠与协议抵触的，协议优先执行（法理与继承编体系一致）。

## 四、定性边界

1. **33 vs 32 遗赠**：遗赠是单方死因处分（无对价），遗赠扶养是双务有偿生前协议（有对价）。这是质的分界。
2. **33 vs 30 遗嘱继承**：遗嘱继承单方法律行为，无扶养义务对价。
3. **33 vs 一般合同**：名实混淆时（如"养老协议"），应按遗赠扶养本质定 33 而非普通服务合同。

## 五、在办案件应用

- **家事/养老咨询**：孤寡老人与侄辈/养老机构签扶养协议 → 立 33，重点审查义务履行与违约救济；
- 与 075 遗赠对比：有扶养对价则 33，纯赠与性死因处分则 32。

## 六、翻车标本

1. 扶养人未尽生养死葬义务却主张受遗赠 → 可解除协议、剥夺受遗赠权；
2. 把遗赠扶养当普通赠与/服务合同 → 案由定性错，遗漏身份优先效力；
3. 遗嘱与协议冲突，误按遗嘱执行 → 协议效力优先（33 优先于 30/32）；
4. 协议主体为"继承人" → 实为遗嘱继承或附义务遗嘱，非 33。
