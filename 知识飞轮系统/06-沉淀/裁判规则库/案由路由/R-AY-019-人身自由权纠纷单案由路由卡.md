# 人身自由权纠纷（案由路由卡·单案由路由卡）

> **一句话**：人身自由权重在"身体自由不受非法限制"，民法典未单列其为具体人格权、系一般人格权重要组成（§109），具双重属性——定性时须考量其作为多数权利基础的一面。
> 本卡为**批次2人格权线 L1⑧**。单案由路由卡（纵向梳理型），不设 discriminator。

## 二、释义与构成要件（源书 OCR 核录）

> 人身自由权纠纷是指侵害他人人身自由权而引起的纠纷。（行3770）

- **宪法基础**：公民人身自由不受侵犯（行3776）。
- **性质三说**（行3813-3831）：①政治权利说；②一般人格权说；③具体人格权说。《民法典》第109条、第990条将人身自由、人格尊严产生的权益归入一般人格权，**未单列人身自由权为具体人格权**，故其系一般人格权重要组成部分（行3828-3831）。
- **双重属性**（行3832-3838）：既是多数权利基础（一般人格权组成），又非民法典明示的具体人格权。

## 四、法律适用（法条正文·逐条标效力）

- **《宪法》第37条**（人身自由）：根本法依据。
- **《民法典》第109条**（一般人格权·人身自由人格尊严）：现行有效。
- **《消费者权益保护法》**（侵害人身自由，行3795）：现行有效。
- **《民诉法》第29条**：现行有效（替代原第28条）。

---

## 五、双重属性·选型要点

源书行3832-3838：人身自由权是很多权利的基础，是一般人格权重要组成；若能确定属具体人格权侵害，则定相应具体案由，否则定本案由。

```
Step 0  侵害是否"非法限制身体自由"？
        └─ 否 → 考虑其他
Step 1  能否归入具体人格权（如名誉/身体权）？
        ├─ 能 → 定相应具体案由
        └─ 否（纯人身自由受限） → 本案由（人身自由权纠纷）
```
