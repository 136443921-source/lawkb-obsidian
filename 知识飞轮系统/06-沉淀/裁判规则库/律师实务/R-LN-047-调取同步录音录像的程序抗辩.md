# 辩护人调取讯问同步录音录像的程序抗辩路径

> **卡型**：实务规则卡（刑事辩护·程序性操作）｜**编号**：`R-LN-047`｜**建卡日期**：2026-09-04

## 一、规则要旨（正向·怎么用）

同步录音录像不是可有可无的材料，而是**证明取证合法与否的核心证据**，是非法取证的"照妖镜"。其三重作用：**还原真实讯问场景**、**核对笔录是否伪造删减篡改**、**作为排除非法证据的最关键依据**。

**核心逻辑（一句话，全程贯穿）**：
> `不给录像 = 无法证明取证合法 = 供述必须排除`

**全域程序公式**：
> 书面申请 + 全程留痕 + 当庭固定拒供事实 + 庭外监督兜底 → 推定/认定取证违法 → 相关供述排除

## 二、审查要点（操作路径，四步）

### 第一步：书面申请调取（申请时点 = 尽早，庭前/审查起诉阶段即提）

**申请话术（向检察官/法官）**：
> "根据最高法刑诉解释第 74 条，辩护人申请调取**本案全部**讯问同步录音录像。当事人提出讯问存在非法取证线索，无录音录像无法排除非法取证可能。请法庭准许并**记录在案**。"

**必须留痕（三选一，逐级加压）**：
1. 邮寄 **EMS，保留回执**；
2. 现场提交要**签收**；
3. 不给签收就**当庭反复提出，记入庭审笔录**。

> 案例（受贿案）：连续三次书面申请，法院拒不提供 → 当庭**固定"拒不出具录音录像"的程序事实** → 法院**推定取证违法**，关键供述不予采信。

### 第二步：遭遇推诿，五类借口当场反击 ⭐

| 借口 | 反击要点 | 规范支点 |
|---|---|---|
| ①"录像不是证据，不用给你" | 录像系法定**视听资料**，是取证合法性的**直接证据**，**效力高于书面笔录**；合法性存疑时必须出示，否则排除供述 | 刑诉法第 56 条（*待回源*） |
| ②"只能看，不能复制" | 依最高法批复，**除国家绝密外**辩护律师有权**复制**；只许看不许复制 = **剥夺质证权**、限制律师执业权利 | 最高法批复（*待回源*） |
| ③"设备坏了、丢了、没录上" | 讯问室有**双备份 + 不间断电源**，不存在"意外丢失"；应提供而拒不提供/不能提供且**不能合理解释** → **供述直接排除**；主张**证明妨害** | 刑诉法解释第 74 条第 2 款（*待回源*） |
| ④"监委的录像拿不到" | 对检察官：**审查起诉阶段检察院负有调取留置录音录像的法定义务**，不调取即未履行**法律监督职责**；对法官：申请法庭**向监察机关调取** | 《监察法实施条例》第 60 条（*待回源*） |
| ⑤"你没有非法取证线索，不许看" | **辩方只需提供线索，不是举证**；取证合法性的**举证责任在控方**，控方须用录像**自证清白**，**一份《情况说明》无效** | 排非举证责任规则（*待回源*） |

**对应战果案例**：①诈骗案——比对发现笔录**完全篡改**供述 → **判决无罪**；③非法采矿案——录像"丢失" → 主张**证明妨害** → **三份有罪供述全部排除**，指控崩盘。

### 第三步：录像到手，"四对照"打法

1. **对时间**：讯问起止时间、提讯时间、**是否疲劳审讯**；
2. **对内容**：是否**诱供、指供、威胁、引诱**；
3. **对笔录**：是否**断章取义、删减、改写**；
4. **对画面**：是否身体不适、精神异常、被体罚暗示。

发现问题当庭话术：
> "该份笔录与录音录像内容**不一致**，不是真实供述，不得作为定案依据，申请依法排除。"

### 第四步：庭内不给，庭外兜底（救济途径）

1. **12309 检察监督 + 书面控告**：
   > "办案机关拒不依法调取、提供同步录音录像，严重程序违法，请求监督纠正。"
2. 向**上级法院、人大、监委**投诉；
3. 申请**律协维权**。

## 三、构成要件与举证

| 要件编号 | 要件名称 | 要件内容 | 举证责任 |
|---|---|---|---|
| E1 | 应当录像的案件范围 | 可能判处无期徒刑、死刑的案件或其他重大犯罪案件；检察院自侦案件每次讯问；监委留置讯问；认罪认罚具结过程 | 辩方指明案件落入法定范围 |
| E2 | 辩护人已依法申请 | **书面**申请调取**全部**讯问同步录音录像，并留痕（EMS 回执 / 签收 / 庭审笔录） | **辩方**（程序事实自证） |
| E3 | 非法取证的**线索** | 当事人提出诱供、威胁、疲劳审讯等具体线索——**辩方只提供线索，不承担证明责任** | **辩方**（仅线索） |
| E4 | 控方拒不提供/不能提供 | 无录像、录像丢失损毁、拒不出示、只许看不许复制 | 辩方固定（当庭反复提出、记入笔录） |
| E5 | 不能作出合理解释 | 办案机关对未录/丢失/损毁**不能给出合理解释**（如"设备坏了"不成立：双备份+UPS） | **控方**（解释义务） |
| E6 | 排除的法律后果 | 相关供述**不得作为定案依据**（应录未录 / 笔录与录像不一致以录像为准 / 真实性无法确认） | 法庭认定 |

**举证责任分配（关键）**：
- **取证合法性的举证责任在控方**；
- 辩方**只需提供非法取证的线索**，**不是举证**；
- 控方须以**录音录像**自证清白，**一份《情况说明》无效**；
- 控方**不能提供且不能合理解释** → 承担**举证不能的不利后果** → 供述排除。

## 五、抗辩与但书

**辩方（本卡立场）可主张**：录像为取证合法性直接证据、效力高于笔录；辩方只负线索责任；只许看不许复制剥夺质证权；"设备损坏"不构成合理解释（双备份 + UPS）；监委案件检察院在审查起诉阶段负法定调取义务；应录未录 + 不能合理解释 → 一律排除。

**控方/法庭可能的反向主张与边界**：
1. "录像不属于证据材料，无需随案移送" → 反驳：即便不移送，取证合法性审查阶段仍须**出示**，否则不能证明合法；
2. "涉及国家秘密/侦查秘密" → 反驳：**除国家绝密外**均可复制，且可采取**脱敏 + 限制使用范围**方式，不能整体拒绝；
3. "辩方无具体线索" → 边界：辩方线索需**具体化**（时间、地点、人员、方式），但**证明标准远低于控方**，不得以"未达证明标准"为由拒绝出示；
4. "一般案件无强制录像义务" → 边界：须**先确认本案是否落入法定强制录像范围**（无期/死刑/重大/自侦/留置/认罪认罚具结）；**不落入**的，"应录未录"路径不成立，应改走**笔录真实性**与**疲劳审讯/诱供**路径。

## 六、翻车标本（负向拦截·HIR）

> ⚠️ **翻车风险一**：**口头申请、不留痕**——未 EMS、未签收、未记入庭审笔录，事后无法证明"曾申请"，排除主张落空。
> ⚠️ **翻车风险二**：**未先确认案件是否落入强制录像范围**，对一般案件硬套"应录未录"，被控方一句话驳回，损害辩护可信度。
> ⚠️ **翻车风险三**：**把"线索"当成"举证"**——自行承担取证违法的证明责任，被控方以一份《情况说明》打发。
> ⚠️ **翻车风险四**：**直接引用本卡条号作文书引用源**——本卡条号全部来自公众号转载，本地库无源，**未经回源核对不得写入法律文书**。
> ⚠️ **翻车风险五**：拿到录像后**只看不做"四对照"**，或发现问题未当庭即时提出并记入笔录，丧失排除时机。
> ⚠️ **翻车风险六**：监委案件**只找监委、不向检察院主张调取义务**，错失审查起诉阶段最有力的程序施压点。
