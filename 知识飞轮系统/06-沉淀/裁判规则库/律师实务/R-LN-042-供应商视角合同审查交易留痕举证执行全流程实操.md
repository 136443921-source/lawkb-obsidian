# R-LN-042 供应商视角合同审查·交易留痕·举证·执行全流程实操与股东穿透执行

> 核心命题：**诉讼的本质是证据的较量**——把交易过程中收集到的材料，淬炼成法庭上可用的证据。

## 一、合同审查四件事

**核实主体 → 明确标的与价款 → 把握风险（违约/拖欠）条款 → 约定清楚管辖条款**

| 检查项 | 细化要点 |
|---|---|
| **对方主体** | 营业执照（统一社会信用代码）、经办人身份证；对方为公司的，确认法定代表人与**经办权限**，索要**授权委托书并加盖公章**；自然人的须**核验身份证原件**（防无权代理/超越权限） |
| **公司资信与对外关系** | 国家企业信用信息公示系统 / 天眼查 / 企查查查分支、被执行记录、股权穿透（**截图存证**） |

**关键条款设计要点**：
- **付款**：明确付款节点（含对账单、开票条件）、付款账户、担保/保证金、逾期利息或违约金计算方法；
- **交付与验收**：指定检验标准、取样方案、验收期、验收人名单、验收单样式（签字盖章为佳）；
- **履约担保**：推荐定金 / 履约保证金、连带保证（自然人或第三方）、银行保函；
- **违约条款**：对双方主要违约行为分别设定（供方：迟延交货、质量不符；采购方：迟延付款、迟延验收、拒收合格货物）；
- **争议解决**：约定供应商所在地法院管辖，或选择仲裁（须写明**具体仲裁机构名称**）；**明确约定律师费、差旅费由败诉方承担**；
- **所有权保留**（注意）：民法典已作规范，但须注意**登记/公示**问题，**不可当作万能条款**（见法条）。

## 二、交易留痕必做 8 个动作

1. **订单/合同**：PDF + 盖章合同，并对签署过程（视频/录屏/邮件往来）留底；
2. **对方付款**：银行转账凭证原件、银行流水截图（保留银行出具的交易记录复印件或调取凭证）；
3. **出货与物流**：装车单、运单（**含签收人、身份证复印件、收货照片/视频**）；
4. **验收单**：收货方签字盖章并写明"**经检验合格**"；
5. **对账**：以邮件、微信记录或带时间戳系统（如财务系统导出对账单）为准并保存；
6. **聊天/通话记录**：**保存原始手机**，保留原始聊天记录；
7. **担保文件**：保证合同、保证人身份证与授权；企业保证的须留存资质、股东结构复印件及**股东会决议**；
8. **价款协商记录**：一切减免、延期、分期协议**书面化**（邮件/盖章确认）。

## 三、举证清单（起诉时）

| 证据 | 必备样式与说明 |
|---|---|
| 合同文本 | 加盖公章/签字的原件，或经双方盖章的电子合同 |
| 交付/收货 | 运单、收货签收单、验收单（照片、视频） |
| 发票/对账 | 发票原件、对账邮件或对账单 |
| 聊天记录 | **保存原始载体**（手机、电脑） |
| 付款证据 | 银行转账凭证原件、对方回执、平台流水截图（附银行证明） |
| 担保证据 | 担保合同/承诺书、股东会决议 |
| 律师费 | 委托代理合同、支付凭证、发票 |

**诉前准备三步**：保存证据 → 发律师函/催款函 → 必要时**立即申请诉前保全**。

## 四、执行技巧：财产线索与股东穿透

**法院三大线索来源**：① 申请执行人提供；② 被执行人报告财产；③ 法院网络查控与调查。
申请执行人应提前填写财产调查表，提供具体账户、固定资产、关联公司、股东名单。

**调查令可用渠道**（实务清单）：
- 全国法院执行信息公开网 / 中国执行信息公开网（执行信息、被执行人名单）；
- 全国工商信息公示系统（企业登记/股权）、天眼查/企查查初步穿透；
- 不动产登记中心（房产）、车管所（车辆）、税务部门（异常发票/纳税记录）；
- **支付宝、微信资金流水及理财**（携调查令）；
- **出入境管理局**调取护照信息（匹配海外房产交易、查规避限高令乘机/出入境，为司法惩戒铺垫）；
- **住房公积金中心**调取账户及余额；
- 悬赏公告发动社会力量；对拒不执行者申请罚款、拘留直至追究拒执罪。

**追加股东（人格否认穿透）**：成功率高度依赖证据链——公司与个人银行往来、资金用于个人消费、抽逃出资证据、关联交易合同及对价缺失。
- 起诉时：一并起诉控股股东/实际控制人为共同被告或第三人，理由写明"财产混同/抽逃出资/以公司规避债务"；
- 已判决公司无财产的：申请执行并提交**股东混同证据**（关联转账、资金挪用、共同账户、借贷担保人证据），请求按人格否认规则追加；
- 近亲属名下房屋可能是被执行人财产，可结合资金流向视情启动**债权人撤销权之诉**。

## 关联法条（已由本地权威源《中华人民共和国民法典（全文）》回填核验）

- **第641条**（所有权保留）：当事人可以在买卖合同中约定买受人未履行支付价款或者其他义务的，标的物的所有权属于出卖人。**出卖人对标的物保留的所有权，未经登记，不得对抗善意第三人**。
- **第642条**（取回权）：买受人未按约定支付价款经催告仍未支付 / 未完成特定条件 / 出卖、出质或作其他不当处分的，出卖人有权取回标的物；协商不成的，**可参照适用担保物权的实现程序**。
- **第586条**：定金合同自实际交付定金时成立；**定金数额不得超过主合同标的额的 20%**，超过部分不产生定金效力。
- **第587条**（定金罚则）：给付定金方不履行致合同目的不能实现的，无权请求返还；收受方不履行的，应当**双倍返还**。
- **第588条**：既约定违约金又约定定金的，一方违约时对方**可以选择适用**违约金或者定金条款；定金不足弥补损失的，可请求赔偿超过定金数额的损失。
- **第538条**（无偿处分撤销）：债务人以放弃债权、放弃债权担保、无偿转让财产等方式无偿处分财产权益，或恶意延长到期债权履行期限，影响债权实现的，债权人可请求法院撤销。
- **第539条**（不合理对价撤销）：以明显不合理低价转让 / 高价受让 / 为他人债务提供担保，影响债权实现且相对人知道或应当知道的，债权人可请求撤销。
- **第541条**：撤销权自债权人知道或应当知道撤销事由之日起 **1 年**内行使；自债务人行为发生之日起 **5 年**内没有行使的，该撤销权消灭。
