# R-LN-140 解决法律问题的四步顺序（道德底线→立案法律原则→具体规则→指导案例）

> 来源：IMA「律师AI助手」库《指导案例是学习法律的起点，解决法律问题的顺序是这样的》（深圳洪丽律师，2025-06-03 发布）。B 阶段回补摄入（2026-10-26 通道恢复后补齐 10-26 漏跑）。

## 一、规则要旨：检索顺序颠倒 = 类案不同判的根因

**核心命题**：案例（指导案例/类案）不是解决法律问题的**起点**，而是**最后一个环节**。很多人遇案第一件事是去检索类案，且因"趋利避害"本能只找支持自己的案例 → 检索式被立场污染 → 得出"类案不同判"的错误结论。

**正确顺序（四步）**：

| 步骤 | 做什么 | 为什么不能跳过 |
|---|---|---|
| **第一步 · 道德与公序良俗** | 先问本案处理是否符合社会道德标准与公序良俗 | 违背者即使证据材料齐全也可能败诉；即便胜诉亦被社会否定。源文以"彭宇案"为喻：法院、代理人、原被告四方皆输 |
| **第二步 · 立案法律要义与法律原则** | 按案件类型锁定该类案的核心法律原则 | 脱离"该类案件适用规则的设定逻辑与社会意义"单独谈条文会缘木求鱼 |
| **第三步 · 具体法律条文（含条件与逻辑）** | 进入具体规则，注意条文的适用条件 | 法律条文的适用都是有条件和逻辑的，同类法律关系仅要件略有差别，正是律师"讲故事"的空间 |
| **第四步 · 找指导案例/类似案例** | 了解规则实践运用 + 查漏补缺（寻找未考虑的抗辩） | 案例只是办案参考，不能反推结论 |

## 二、各案型核心原则速查（第二步的"原则地图"）

源文给出的原则类型化清单：

- **国际法律问题** → 国家主权原则
- **民商事案件** → 诚实信用
- **刑事诉讼、行政诉讼** → 除实体公平正义外，**着重程序正义**
- **婚姻家事案件** → 保护未成年人权益与弱势一方权益
- **劳动争议** → 保护弱势劳动者一方，同时兼顾用人单位合法权益

**源文给出的反直觉判断（法律关系类型决定裁判逻辑，不因当事人情感而改变）**：
- 夫妻**未作婚前/婚内财产协议**、按"纯经济合作模式"生活 → 财产分割**不按合伙或公司股权比例**，而按夫妻共同财产规定（源文指出此种模式在中国环境下易分崩离析）；
- 单纯**股权纠纷** → 法律规定按比例分割利益，裁判者几乎没有情感考量的自由裁量空间；强调付出与情感属多余。

## 三、配套法律依据（本地法条银行逐字 · 已三通道核验）

**《民法典》第七条**【诚信原则】
> 民事主体从事民事活动，应当遵循诚信原则，秉持诚实，恪守承诺。

**《民法典》第一百五十三条**【违反强制性规定与公序良俗】
> 违反法律、行政法规的强制性规定的民事法律行为无效。但是，该强制性规定不导致该民事法律行为无效的除外。
> 违背公序良俗的民事法律行为无效。

**《民法典》第四百九十六条**【格式条款提示说明义务】
> 采用格式条款订立合同的，提供格式条款的一方应当遵循公平原则确定当事人之间的权利和义务，并采取合理的方式提示对方注意免除或者减轻其责任等与对方有重大利害关系的条款，按照对方的要求，对该条款予以说明。提供格式条款的一方未履行提示或者说明义务，致使对方没有注意或者理解与其有重大利害关系的条款的，对方可以主张该条款不成为合同的内容。

## 四、蓝队 / 红队要点（自用方法论，非对抗）

- **蓝队（自检清单）**：
  1. 拿到案子先写"第一步"结论：即便法律上站得住，情理上/公序良俗上站不站得住？
  2. 定案件类型 → 写出该类型的核心法律原则（不是先找条文）；
  3. 在原则框架内再检索条文，**每条条文先列适用条件**，逐条核对要件是否成就；
  4. 最后一步才做类案检索，且检索**必须同时检索不利案例**（避免"只找支持案例"的立场污染）。
- **红队（自我反驳）**：
  1. 检索式是否被立场污染（只搜了有利关键词）？
  2. 是否跳过第一步/第二步直接跳到条文和案例？
  3. 所引类案是否具备可比的裁判尺度（法院层级/地区/年份/争点一致）？
  4. 若出现"类案不同判"，先问：**是不是顺序搞反了**（源文明确指出这是根本原因），而非直接归因于"法官自由裁量"。

## 五、适用场景

- 首次接触陌生案由时的检索路径设计；
- 类案检索报告写作（先立原则框架，再填案例）；
- 类案不同判时的原因排查；
- 模拟法庭/红蓝对抗推演中的"检索前置检查"环节；
- AI 辅助法律检索的流程编排（先原则、后条文、最后案例，避免模型以案例倒推结论）。
