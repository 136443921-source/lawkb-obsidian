# 裁判规则 R026 - 医疗损害一般适用过错责任，患者对过错与因果关系负初步举证责任

**规范来源**：《民法典》第1218条、第1222条；法释〔2020〕17号
**案号**：（规则型·未附个案案号，依民法典提炼）
**审理法院**：各级法院普遍规则
**裁判要旨**：患者在诊疗活动中受损，医疗机构承担赔偿责任的前提是**存在医疗过错且该过错与损害后果有因果关系**。一般情形下实行**过错责任**，由患者初步证明医方过错；但医方**违反法律、行政法规、规章以及其他有关诊疗规范，或隐匿、拒绝提供、伪造篡改销毁病历**的，推定过错（举证责任倒置至医方）。
**适用要点**：
1. 患者初步举证达到**高度盖然性**即可，无需排除一切怀疑。
2. 过错认定多依赖**医疗损害司法鉴定**的过错参与度评定（完全/主要/同等/次要/轻微）。
3. 病历瑕疵（隐匿、涂改、缺失）是患者触发过错推定的最强突破口，诉前应第一时间封存病历。
4. 限于当时医疗水平难以诊疗的，医方免责（第1224条）。
**关联法条**：《民法典》第1218条、第1222条、第1224条
