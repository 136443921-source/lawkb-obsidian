# R-PI-477 医院专利技术管理与著作权技术秘密操作指引

## 一、可专利主题筛查（医疗领域的排除与例外）

- **排除**：《专利法》第25条明确，**疾病的诊断和治疗方法不授予专利权**。医生独创的手术方案、诊断流程、治疗方案不能获得专利保护。立法本意：医疗方法关乎生命健康，授予垄断权将阻碍技术传播。
- **可申请的四类创新**：
  1. **医疗器械和装置**——新型手术器械、植入物、康复设备（发明或实用新型）；
  2. **药物和制剂**——医院制剂室开发的独特配方制剂（发明）；
  3. **检测方法和试剂盒**——诊断方法本身不可专利，但**试剂盒、试剂组合物，以及检测方法中涉及的中间步骤（如样本处理方法）**可以；
  4. **医疗信息系统和软件中涉及的技术方案**。

## 二、职务发明权属的操作路径

- **法定规则**：执行本单位任务，或**主要利用本单位物质技术条件**完成的发明创造，属职务发明创造；申请专利的权利**属于该单位**，申请批准后单位为专利权人。
- **争议高发点**："主要利用本单位物质技术条件"的认定。医生利用医院实验室设备、科研经费、患者数据完成的发明，无疑属职务发明；但**主要依靠个人专业知识和临床经验、业余在家完成**的发明，需个案判断。
- **操作建议**：在**聘用合同或知识产权协议中预先明确**职务发明的认定标准、权利归属、奖励报酬；医院应建立**发明创造登记制度**，医生完成发明后及时申报，由医院评估决定是否申请专利。

### 翻车标本（案例四 · 某三甲医院职务发明权属纠纷案）

- **案情**：骨科主任张医生在职期间研发新型脊柱固定装置，获实用新型专利，**专利权人已记载为医院**；离职后到另一家医院工作，主张系利用业余时间完成的个人发明，要求确认其为专利权人。
- **裁判**：法院认定研发属其**本职工作范围**，研发中使用了医院实验室和科研经费，且有医院同事参与辅助实验；依《专利法》第6条属职务发明，**专利权归医院**，驳回张医生诉请。
- **要点**：权利人记载与权属认定的一致性；"本职工作范围 + 物质技术条件"双重认定标准。

## 三、著作权管理（含委托开发的致命陷阱）

- **诊疗规范、临床路径**：属文字作品，医院享有著作权；但保护范围是**表达形式而非思想内容**——其他医院可 reference 其医学原理和基本思路自行编写，不得照搬照抄。
- **医疗信息系统软件**：属计算机软件，受著作权法保护。

### 翻车标本（委托开发著作权归属纠纷）

- **案情**：某医院委托软件公司开发门诊管理系统，**合同对著作权归属未作约定**。系统上线后，软件公司稍作修改即卖给其他医院。医院以侵犯著作权起诉。
- **裁判**：委托创作作品的著作权归属由委托人与受托人**合同约定**；**合同未明确约定的，著作权属于受托人**。故软件著作权归软件公司，医院**仅享有使用权**，无权阻止其向其他医院销售。
- **教训与操作动作**：审查委托开发合同时**必加著作权归属条款**——至少约定医院为著作权人，或约定医院享有**独占使用权 + 源代码交付**。

## 四、技术秘密管理（三要件）

- **保护路径**：无专门立法，靠**反不正当竞争法 + 民法典商业秘密制度**。
- **三要件（缺一不可）**：① 不为公众所知悉（**秘密性**）；② 具有商业价值（**价值性**）；③ 经权利人采取**合理保密措施**（**保密性**）。
- **可保护对象**：特色诊疗技术、秘方制剂、独家数据处理方法。
- **高频管理短板**：无保密制度；未与关键技术人员签**保密协议和竞业限制协议**；技术资料未加密、未分级管理。一旦技术人员跳槽带走技术秘密，往往因**无法举证"采取了合理保密措施"**而无法获得救济。
