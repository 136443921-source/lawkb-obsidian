# R-PI-464 民营医院采购法律适用与五项内控制度

## 一、合规红线（法律适用三层面）

民营医院不受《政府采购法》约束，但仍受三重约束：

1. **项目属法定必须招标**（招标投标法第 3 条）→ 必须招标；大型基础设施、公用事业等关系公共利益项目即便非国有资金也可能须招标。
2. **使用政府专项补贴或纳入医保定点**→ 可能受特殊政策约束（如集采）。
3. **一律受《民法典》合同编＋《反不正当竞争法》＋《药品管理法》约束**。

## 二、审查要点（五项内控制度）

| 制度 | 核心内容 |
|---|---|
| 采购决策制度 | 一定金额以上集体决策，不得个人独断；重大设备须可行性论证＋投资回报分析 |
| 供应商管理制度 | 准入＋评估机制，合格供应商名录；新供应商实地考察＋资质审查 |
| 比价和招标制度 | 分档：如 5 万下科室比价／5-20 万采购部比价或谈判／20 万上院内或邀请招标 |
| 合同审查制度 | 签订前经法务或外聘律师审查合法性、完整性、风险防控 |
| 验收制度 | 使用科室＋设备科（药剂科）＋采购部门共参与，验收记录签字确认 |

## 三、攻防要点（合同特别注意事项）

- **相对方审查**：小型代理商资金有限，须要履约保证金或银行保函。
- **知识产权担保条款（以案）**：某民营医院从代理商购进口超声，半年后原厂发律师函称代理商未授权，拒售后与软件升级。建议在合同中加知识产权担保条款，供应商保证不侵权并全赔。
- **解除权**：经营变化（搬迁等）需解除，须约定合理解除条件＋费用结算＋设备退还。
- **争议解决**：优先约定医院所在地法院管辖；仲裁须明确机构名称，避免「由仲裁委员会仲裁」无效。

## 四、避坑（顾问归纳，非源书案例）

- 民营医院最大风险：采购由院长一人独断、无比价、制度形同虚设 → 价格虚高＋商业贿赂刑险。
- 《民法典》合同编全文本地已收录，可直引；但反不正当竞争法、药品管理法在采购场景的具体适用须结合 [[R-PI-469-采购商业贿赂四形态与反法刑法认定体系]] 与 [[R-PI-467-药品采购渠道合法与集采三条红线]]。
