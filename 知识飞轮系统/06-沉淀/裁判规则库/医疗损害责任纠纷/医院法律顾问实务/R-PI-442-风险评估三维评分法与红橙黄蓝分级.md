# R-PI-442 医院法律风险评估三维评分法与红橙黄蓝分级

## 一、裁量尺度：为何要评估

风险识别完成后**必须进行风险评估，否则无法区分"轻重缓急"，资源投入就会盲目**。评估指对已识别风险点，从**发生可能性、损害后果、防控难度**三个维度进行量化与分级，最终确定高、中、低风险等级，为应对策略提供依据。

## 二、三大核心指标（量化锚点）

### 指标一 · 风险发生概率（可能性）——四档

| 档位 | 口径 |
|---|---|
| 极高 | 每月/经常发生 |
| 较高 | 每季度发生 |
| 一般 | 每年度发生 |
| 较低 | 数年偶发 |

**评估依据**：历史发生频率；行业普遍发生情况；监管检查频次与重点；人员资质、培训、执行力水平；流程标准化程度。

**示例**：病历书写不规范在绝大多数医院属"极高概率风险"；放射防护违规属"较高概率风险"；重大医疗事故罪属"**较低概率但极高危害风险**"。

### 指标二 · 风险损害后果（严重性）——五维综合

从民事、行政、刑事、声誉、经济五个维度综合判断：

| 档位 | 口径 |
|---|---|
| 轻微 | 投诉提醒、口头整改、小额赔偿 |
| 一般 | 行政处罚、一般赔偿、内部处分 |
| 较大 | 大额赔偿、停业整顿、重点监管、舆情发酵 |
| 严重 | **吊销证照、负责人追责、涉刑、医院品牌崩塌** |

> **坚持一个原则：概率低但后果极其严重的风险，一律按最高等级对待。** 例如医保诈骗、涉刑案件、院感暴发、重大伤亡事件。

### 指标三 · 风险防控难度（可控性）——四档

| 档位 | 口径 | 示例 |
|---|---|---|
| 易防控 | 制度完善、流程清晰、培训到位即可解决 | 知情同意书缺失 |
| 较易防控 | 投入少量资源、优化流程即可降低 | — |
| 较难防控 | 涉及多部门、人员意识薄弱、历史遗留问题 | 患者跌倒 |
| 难防控 | 外部依赖强、患者因素不可控、行业共性难题 | 突发公共卫生事件处置 |

## 三、三维评分法＋风险矩阵（计算公式）

```
概率得分（1–4）  ×  后果得分（1–4）  ×  防控难度系数  =  综合得分
```

| 得分区间 | 等级 | 处置口径 |
|---|---|---|
| **红色** | 高风险 | 必须立即整改、重点监控 |
| **橙色** | 中高风险 | 限期整改、责任到人 |
| **黄色** | 中风险 | 常规防控、定期检查 |
| **蓝色** | 低风险 | 一般关注、纳入管理 |

> **使用提示**：防控难度是**系数而非简单得分**，实务中的取值须按医院实际与属地监管强度校准，本卡不给固定数值——**凡需量化，先记录取值依据，避免事后倒推**。

## 四、产出：《医院法律风险评估报告》

内容包括：风险总体概况；高风险点清单及分布；重点科室、重点环节、重点人群；风险趋势分析；优先整改建议。

**该报告直接提交医院院长办公会、党委会，作为管理决策依据。**

## 五、翻车标本：轻视评估导致一级甲等事故（来源：本书 3.3.2 以案说法）

某二级综合医院**既往连续发生 3 起**术前评估不足、术中应急准备不到位引发的纠纷，均以调解结案。法务部门在风险识别时**已将其列为"高风险、高后果"**，但院方认为"概率不高、赔偿金额不大"，**未升级防控、未强化麻醉与手术管理**。

半年后发生一例术中猝死事件，引发家属围堵、网络舆情、卫健委介入调查、**医学会鉴定为一级甲等医疗事故、主要责任**，最终医院赔偿数百万元，科室负责人、经治医师被处分，医院等级评审受到直接影响。

> **律师点评**：本案是典型的风险**评估轻视化、防控滞后化**。医疗机构最容易犯的错误是"**没死人、没重罚、没曝光，就不算风险**"。但医疗风险具有**累积效应与突变效应**，小差错不断必然酿成大事故。法律顾问的价值，就是在"风平浪静"时指出"暗流涌动"。

## 六、攻防要点

- **己方（顾问）说服口径**：用"累积效应＋突变效应"论证升级防控的必要性，而非只讲赔偿金额——院方的认知偏差恰恰是"概率不高就不算风险"。
- **反向筛查**：审一个医院的风控报告，先看它的评估是不是走过场——看是否真的区分了红橙黄蓝并给了处置时限与责任人。
- **注意**：概率低＋后果严重的风险（涉刑、医保诈骗），**必须按最高等级对待**，这是本书明确的强制口径。

## 七、法条依据（本地源核验）
