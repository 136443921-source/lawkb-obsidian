# R-PI-459 薪酬法定底线规则与医院薪酬结构设计

## 一、操作指引：五条法定底线规则

劳动争议案件中**超过 60% 集中于工资、加班费、绩效、社保未缴、公积金欠缴**。医院的薪酬结构呈明显行业特征：基本工资、岗位工资、绩效工资、夜班费、加班费、值班补助、科室奖励、科研奖励、教学补贴、节假日福利；用工身份又分编制内、编外、备案制、劳务派遣、外包、退休返聘等多种形式，极易出现**差额、漏缴、低缴、拖欠、结构混乱**。

| 底线 | 口径 |
|---|---|
| **货币支付** | 工资必须以法定货币支付，**不得以实物、药品、体检卡、餐券等替代** |
| **按月足额** | 至少每月支付一次；约定支付日遇节假日**应当提前支付**；不得无故拖欠、克扣 |
| **不低于最低工资** | 劳动者在法定工作时间内提供正常劳动的，工资**不得低于当地最低工资标准（含试用期）** |
| **同工同酬** | 相同岗位、相同工作量、相同业绩、相同资质者享有相同工资分配权利，**不得以编制身份、户籍、性别、年龄等理由歧视** |
| **加班费法定标准** | 工作日延长工作时间 ≥**150%**；休息日加班又不能安排补休 ≥**200%**；法定休假日加班 ≥**300%** |

> **医院高发场景**：急诊、病房、手术室、重症监护、核酸采样、公共卫生应急等岗位，**加班费争议常年高发**。

## 二、操作步骤表：医院薪酬结构的合法设计

| 模块 | 构成 |
|---|---|
| 固定工资 | 基本工资、岗位工资 |
| 浮动工资 | 绩效工资、科室提成、科研奖励 |
| 补贴补助 | 夜班费、值班费、交通补贴、住房补贴 |
| 加班工资 | **依法单独核算，不得包含在固定工资中** |

> ⚠️ **最常见的违法操作**：大量医院将"**加班费打包进绩效**""不单独核算"——**这在仲裁诉讼中一律被认定无效**。

## 三、操作要点：薪酬管理的四项落地动作

1. **工资结构必须合法拆分**：固定工资、绩效工资（有制度、有考核、有签字）、夜班费、值班补助（按天数、班次核算）、加班费（**单独列项、依法计算**），**任何补贴都不能模糊打包**。
2. **必须制作并交付工资条**：每月发放时提供书面或电子工资条，明确列明基本工资、绩效、加班费、社保个人部分、公积金、实发金额，**要求劳动者签字确认，存档至少两年**。
3. **严禁拖欠、克扣工资**：遇资金困难，必须**书面协商、签署延期支付协议**，不得单方面扣发、缓发绩效、补助。
4. **加班费必须依法核算**：保存排班表、值班记录、考勤表；**法定节假日加班必须支付 3 倍工资，不得以补休代替**；**综合计算工时、不定时工作制必须经人社部门审批**。

## 四、避坑清单：四类高频败诉点

| 败诉点 | 后果 |
|---|---|
| 工资发放无书面记录、无工资条 | 法院与仲裁委普遍认定医院**无法举证**工资构成、已付加班费，**直接采信劳动者主张** |
| 拖欠、克扣绩效工资、夜班费 | 只要无合法制度、无明确考核标准、无劳动者确认，**一律判令足额补发** |
| 加班费不核算、不发放、打包发放 | 只要劳动者能证明加班事实（排班表、值班记录、病历书写时间、监控、工作群记录），**医院必须支付加班费** |
| 编制与编外同工不同酬 | 只要岗位相同、工作内容相同，**法院一律判令补足工资差额** |

## 五、翻车标本（来源：本书 5.4 以案说法·案例三）

某医院 ICU 护士长期夜班、节假日加班，医院在工资中笼统发放"**绩效补贴**"，**未单独列明加班费**。护士提交排班表、护理记录、夜班登记本证明加班事实，主张补发两年加班费。

法院认为：医院未依法单独核算、足额支付加班费，所谓"**绩效包含加班费**"**无制度依据、无劳动者确认，不予采信**。判令补发加班费共计 **113600 元**。

> 医院最常见的操作，恰恰是最违法、最容易败诉的操作。**加班费必须单独计算、单独列明、足额发放。**

## 六、攻防要点

- **己方（顾问）说服口径**：用"**工资条签字率**"和"**加班费单独列项率**"两个指标说话，比谈金额更有说服力——这两个指标一旦做成，绝大多数争议就没了。
- **反向筛查**：拿到工资条样本，看有没有**单独列明的加班费栏位**。没有栏位、只有笼统"绩效"的，打包发放无效。
- **注意**：综合计算工时、不定时工作制**必须经人社部门审批**，未经审批一律按标准工时制核算加班费。急诊、保安、行政后勤岗位是重灾区。
- **注意**：遇资金困难**不能单方面扣发绩效**，必须书面协商并签延期支付协议。
