# R-PI-480 医疗服务价格双轨与医保定价合规规范要点

## 一、"政府指导价 + 市场调节价"双轨体制

| 价格形式 | 适用范围 | 约束 |
|---|---|---|
| **政府定价 / 政府指导价** | **基本医疗服务项目**，由**省级医疗保障部门**制定和调整；凡**纳入医保支付范围的**，公立医院**必须执行政府指导价**，**不得自行加价或变相加价** | 《价格法》《社会保险法》明确要求 |
| **市场调节价** | **特需医疗服务**及竞争充分、个性化需求较强的项目，由医院**自主定价** | 仍须遵守价格法基本原则：**不得价格欺诈、不得价格垄断** |

- **改革动向**：2021 年国家医保局等**八部门**联合印发《深化医疗服务价格改革试点方案》，在**五个试点城市**探索目标导向的价格管理新机制；总体方向为规范价格项目、建立价格总量调控机制、优化价格结构、完善动态调整机制。

## 二、医保定价四项合规要点

1. **严格执行医保目录和支付标准**——纳入国家医保目录的基本医疗服务，须按医保规定的**支付标准**收费，**不得高于标准**；目录外项目须**事先告知患者并取得书面同意**，不得强制或诱导使用。
2. **不得分解收费、重复收费**——
   - **分解收费**：将完整项目拆成多个子项目分别收费；
   - **重复收费**：对同一患者同一诊疗项目收取两次或以上费用。
   - 二者均属价格违法，严重的可构成**骗取医保基金的犯罪行为**。
   - 典型陷阱（源书实例）：骨科手术中"骨折切开复位内固定术"与"骨折切开复位术"同时收费——前者依当地医保规定已包含"切开复位"操作，不得另行收费。
3. **不得串换项目编码**——将目录中低价项目编码替换为高价项目编码收费，是骗取医保基金的典型手段。
4. **DRG/DIP 支付方式下的三类新违规**：
   - **"高编高套"**：将患者分入费用更高的 DRG 组以获取更高支付；
   - **"推诿重症"**：拒绝收治费用可能超标的重症患者；
   - **"分解住院"**：将一次住院拆为多次住院以获取多次支付。
   - 三者均属**骗取医保基金**，被查处后果极重。建议建立 DRG/DIP 合规管理制度，定期审核编码质量、对异常病例自查。

## 三、法条依据

- ✅ **已核**：《中华人民共和国社会保险法》（主席令第25号·2018修正）**第 87 条**——以欺诈、伪造证明材料或者其他手段骗取社会保险基金支出的，由社会保险行政部门**责令退回骗取的社会保险金，处骗取金额二倍以上五倍以下的罚款**。本地 verbatim 命中，现行有效。
- ⚠️ **规范指向·非文书法源**：《深化医疗服务价格改革试点方案》（国家医保局等八部门，2021）；《价格违法行为行政处罚规定》；《禁止价格欺诈行为的规定》及国家发改委《关于〈禁止价格欺诈行为的规定〉有关条款解释的通知》；DRG/DIP 支付方式改革相关技术规范——本地法条银行**均无对应文件**，条文正文待回源核填。
