# R-PI-463 政府采购流程七大关键合规节点

## 一、操作指引（七节点合规表）

| 节点 | 合规要点 | 典型风险 |
|---|---|---|
| 预算与计划 | 无预算不得采购；临时需求须先走预算调整程序 | 先采购后补预算 |
| 采购需求论证 | 技术复杂须邀专家论证；参数不得照搬单一品牌说明书 | 排他性投诉、项目废止 |
| 采购文件编制 | 公平公正；不得地域歧视（如要求本地售后）、评分畸轻畸重 | 文件被认定违规 |
| 信息公告 | 省级以上指定媒体发布；公开招标≥20 日等标期（法定最低） | 时限缩水违法 |
| 评审专家抽取 | 从专家库随机抽取；利害关系主动回避 | 干预抽取→结果撤销 |
| 中标结果公告 | 确定之日起 2 个工作日内公告 | 拒公告／延迟公告 |
| 合同签订备案 | 中标通知 30 日内签合同；7 工作日报备；不得另签背离实质补充协议 | 合同被认定无效 |

## 二、操作要点

- **合同一致性红线（以案）**：某公立医院中标供应商承诺质保 5 年，签合同时医院为降单价改 3 年——实质改变采购文件实质内容，另一未中标供应商投诉，合同被认定无效，重新组织采购。签合同内容须与采购文件＋中标响应文件一致，不得另签补充协议改变实质。
- 采购文件不得设不合理条件限制排斥潜在供应商（技术参数倾向性、本地机构歧视、价格分畸低）。

## 三、避坑

- 《政府采购法》第 46/47 条（签合同期限、结果公告、备案）本地节选版未收录，相关时限按书录口径记录但**不得引法条正文**，须回源核填。
- 验收环节走过场（参数照搬某品牌）→ 排他性投诉是政府采购最高频雷区。

> 本卡法条依据详见 [[R-PI-462-公立医院政府采购范围界定与六种采购方式]]；采购文件编制、需求论证的合规深度见 [[R-PI-464-民营医院采购法律适用与五项内控制度]] 的内控视角。
