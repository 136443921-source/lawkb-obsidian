# R-PI-462 公立医院政府采购范围界定与六种采购方式

## 一、规范要点

**范围两要件（须同时满足）**：

1. **资金来源为财政性资金**——公立医院全部资金均属财政性资金，以所有权为标准（不论财政拨款或事业收入）。
2. **在集中采购目录内或达到采购限额标准**——由省级以上政府制定公布，各省市差异大，须熟悉本地规定。

**六种采购方式及适用条件**（《政府采购法》第 26 条列举）：

| 方式 | 适用条件 |
|---|---|
| 公开招标 | 主要方式；达法定数额标准必须采用，不得化整为零规避 |
| 邀请招标 | 特殊只能有限范围供／公开招标费用占比过大；须随机≥3 家 |
| 竞争性谈判 | 无合格标重招／技术复杂性质特殊不能确定规格／应急急需／不能算总价 |
| 单一来源 | 唯一供应商／不可预见紧急／添购原项目一致配套且添购≤原合同 10%（门槛最严） |
| 询价 | 规格标准统一、现货足、价幅小；被询价≥3 家 |
| 竞争性磋商 | 2014 新增；政府购买服务／技术复杂等 |

## 二、实务判断

- **典型误判（以案）**：某省货物类政府采购限额 40 万元，医院拟采购 80 万设备，采购部门以「资金源于自有收入」为由不走的政府采购程序——错误。公立医院自有收入仍属财政性资金，80 万远超限额，必须纳入政府采购。
- 单一来源缺乏竞争性、易滋生腐败，适用须充分证据证明唯一性。
