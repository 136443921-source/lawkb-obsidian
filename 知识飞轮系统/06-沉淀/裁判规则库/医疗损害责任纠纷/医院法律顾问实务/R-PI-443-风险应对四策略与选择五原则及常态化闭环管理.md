# R-PI-443 风险应对四策略与选择五原则及常态化闭环管理

## 一、实务规则表述：四种应对策略

医院法律风险应对策略分为**规避、降低、转移、承受**四种，不是孤立使用而是组合运用。

### 1. 风险规避——坚决不做、立即停止
对于法律明确禁止、后果极其严重、无法防控、不可承受的风险，采取停止、放弃、拒绝、退出的方式，从根源消除风险。

**适用场景**：超出医院执业范围、技术能力、设备条件的高风险手术/诊疗项目；**无资质人员独立执业**；明显违法违规的医保操作、虚假宣传；存在重大法律瑕疵的合作项目、采购项目；违规义诊、违规体检、违规外出手术。

> **原则：法律红线绝对不碰，刑事风险绝对规避。**

**实证**：某医院拟与外部机构合作开展"**干细胞治疗**"项目，经顾问审查该项目未获批准，涉嫌非法行医与虚假宣传，风险等级极高，建议直接否决。医院采纳后避免了行政处罚与刑事风险。

### 2. 风险降低——优化流程、强化管理、全员培训（最常用、最核心）
通过制度、流程、培训、技术、监督等手段降低发生概率、减轻损害后果。

**主要措施**：完善并严格执行医疗质量安全核心制度；规范病历书写、强化三级查房、查对、会诊、危急值报告；全流程知情同意告知；加强院感防控、消毒隔离、手卫生；强化医保合规管理（禁止串换项目、重复收费、过度诊疗）；加强药品、耗材、设备全生命周期管理；定期法律培训、风险警示、案例复盘；引入信息化系统实现**流程留痕、智能预警**。

### 3. 风险转移——通过合同、保险分担责任
医疗行业主要转移方式：
1. **医疗责任保险**：发生医疗损害时由保险公司在限额内赔偿，减轻医院经济压力
2. **公众责任险、物业责任险、特种设备险**：转移患者在院内摔倒、电梯事故、火灾等意外风险
3. **合同责任划分**：外包合同明确安保、保洁、餐饮、后勤的侵权赔偿责任；合作协议明确技术、财务、法律责任边界；设备采购合同明确质量责任、召回责任、损害赔偿责任

> **边界：风险转移不是"甩锅"，是合理配置责任，必须符合法律规定与公平原则，不能通过合同免除自身法定义务。**

### 4. 风险承受——合理接受、做好预案
对低概率、低后果、防控成本过高、属于医疗行业合理固有风险的部分，在依法依规、充分告知、完善预案的前提下予以接受。

**适用场景**：医学上无法完全避免的并发症、副作用、医疗意外；极低概率的不良事件；防控成本远高于可能损失的一般性风险。

> **风险承受不等于放任不管**，必须同时满足四项：已尽到合理诊疗义务、已充分告知风险、已完善应急预案、已做好证据留存与投诉应对。

### 5. 策略选择五原则
1. 高风险优先规避或降低
2. 不可控风险优先转移
3. 合规风险零容忍
4. 刑事风险绝对规避
5. 策略组合使用

## 二、常态化闭环管理

法律风险管理不是"一阵风""一次运动"，而是**常态化、制度化、标准化、信息化、全员化**的长期工作。只有形成闭环管理，才能实现"事前防范、事中控制、事后化解"。

### 组织体系：主要负责人负总责
《医疗机构管理条例》《医疗纠纷预防和处理条例》均明确**医疗机构主要负责人是第一责任人**。

| 层级 | 责任主体 |
|---|---|
| 第一责任人 | 院长/法定代表人 |
| 统筹部门 | 法务/法律顾问 |
| 主责部门 | 医务科、质控科 |
| 协同部门 | 护理、院感、医保、药学、设备、人事、后勤、安保、纪检、审计 |
| 基层责任 | 科主任、护士长为科室风控第一责任人 |

> 实际做法：将**法律风险防控纳入科室绩效考核、职称评聘、评优评先**，真正实现"风险与利益挂钩"。

### 闭环流程（八环节）
**识别 → 评估 → 应对 → 监控 → 检查 → 整改 → 再评估 → 再更新**

**五项关键机制**：
1. **风险清单动态更新**——新法规出台、新政策实施、新纠纷发生、新行政处罚、新合作项目、新流程上线，必须立即更新清单
2. **培训教育常态化**——新员工岗前法律培训、在职人员年度培训、重点岗位专项培训、典型案例每月通报
3. **投诉纠纷预警**——投诉即预警，小投诉早处理，防止演变为信访、诉讼、舆情
4. **监督检查**——法务＋医务＋质控联合检查，定期通报、限期整改、回头看
5. **考核问责**——对防控不力、整改不到位、屡教不改的科室与个人严肃问责

### 嵌入运营全流程
**重大决策先法务审查；重大合同先法务审核；重点项目先风险评估；新业务先合规论证；突发事件先依法处置。**

### 动态更新：紧跟法律与政策变化
医疗行业法律政策更新极快——《民法典》对医疗损害责任的调整；《医师法》对医师执业、告知义务的强化；《医保基金使用监督管理条例》实施后监管趋严；医疗纠纷人民调解、诉前鉴定机制不断完善；医疗广告、互联网诊疗、远程医疗政策持续更新。

> **动态更新的核心是：法律变、政策变、流程变、文书变、培训变。**

**实证**：某三甲医院自 2018 年起引入全面法律风险管理体系，坚持年度风险识别、季度排查、月度培训、案件复盘、医保合规自查、信息化风控预警。2022 年当地医保局飞行检查，该院因事前已完成全流程自查整改，违规项目极少，**仅受轻微整改提示，未被罚款、未被暂停医保结算**；同区域多家医院被处以数百万罚款、暂停医保、限期整改。

> **律师点评**：法律风险管理投入是最具性价比的投入。**事前投入 10 万元完善风控，可以避免事后 100 万元、1000 万元的损失。**

## 三、攻防要点

- **风险转移的正确姿势**：不能只买保险不练内功——保险转移的是经济赔偿，但行政处罚、声誉损失、执业资格限制无法转移。
- **风险承受的四要件不能省**：已尽诊疗义务、已充分告知、已完善预案、已留存证据。缺一件，"医疗意外"抗辩就站不住。
- **闭环管理的检验标准**：能否拿得出一份"上次整改的回头看记录"——运动式整治的共同特征是没有回头看。
