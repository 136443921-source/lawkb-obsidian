# R-PI-451 医疗机构执业许可证申领变更延续与注销全流程

## 一、操作指引：许可证的法律地位（四个专属性）

《医疗机构执业许可证》是医院合法执业的**唯一凭证**，属行政许可证件，具有：

| 专属性 | 含义 |
|---|---|
| 主体专属性 | 只能由持证机构自身使用，不得出借 |
| 地点专属性 | 对应特定执业地址，异地执业须另行审批 |
| 范围专属性 | 对应核准登记的诊疗科目，超科目执业违法 |
| 期限专属性 | 有有效期限，逾期不校验即失效 |

> 一句话记忆：**医院的"身份证 + 营业执照 + 行医资格证"三合一证件。逾期一天未校验，都属于无证执业。**

## 二、操作步骤表：申领 / 变更 / 延续 / 注销

| 环节 | 事项 | 操作要点 |
|---|---|---|
| **申领** | 条件 | 取得设置批准书 → 符合基本标准 → 人员设备制度到位 → 消防环保合格 |
| | 登记事项 | 名称、地址、法人、诊疗科目、床位、所有制形式、有效期限 |
| **变更** | 必须变更的事项 | 名称、地址、法人、主要负责人、诊疗科目、床位、所有制形式 |
| | 程序 | **30 日内申请** → 审核 → 换发新证 |
| | 特殊情形 | **跨区域迁移**：须原机关注销，新机关重新审批 |
| **延续/校验** | 校验周期 | 床位 **＜100 张**：每年校验 **1 次**；床位 **≥100 张**：每 **3 年**校验 1 次 |
| | 不合格后果 | 暂缓校验 → 仍不合格则**注销** |
| **注销** | 情形 | 终止执业、歇业满 1 年、被吊销、撤销、合并分立解散等 |
| | 程序 | 申请 → 卫健委核准 → 收缴证件 → 公告 |

> **注意**：床位规模决定校验频次，这是院方最容易记错的一条。100 张床位是一条硬分界线——**从 99 张增至 100 张，校验频次从"每年"变为"每 3 年"，但院方往往只记得改了床位数，忘了许可证上的登记事项也要一并变更**。

## 三、操作要点：法务必须建立的许可证到期预警机制

**提前 90 日启动延续流程**——这是本书明确的强制口径。实务做法：

1. **建立证照台账**：执业许可证、设置批准书、放射诊疗许可、麻精药品购用许可、消防验收、环保备案，**每一项登记有效期与发证机关**。
2. **提前 90 日预警**：系统或人工双重提醒，落到具体责任人。
3. **变更时限硬约束**：登记事项变更须在 **30 日内**申请，逾期可能被认定未按规定办理变更登记。

## 四、避坑清单

- **逾期未校验** → 被注销许可证 → 继续接诊即认定**无证行医** → 负责人移送公安机关**追究刑事责任**。
- **跨区域迁移未先注销** → 新机关不予审批，形成"两头无证"状态。
- **出现证照台账与实际情况不符**（如科室已调整但诊疗科目未变更）→ 超范围执业风险。

## 五、翻车标本：逾期未校验被注销许可证案（来源：本书 4.5 以案说法）

某医院因管理混乱，**逾期 6 个月未申请校验**，卫健委依法注销《医疗机构执业许可证》。医院仍继续接诊，被认定**无证行医**，负责人被移送公安机关**追究刑事责任**。

> **律师点评**：执业许可证是医院的"身份证+营业执照+行医资格证"三合一证件。**逾期一天未校验，都属于无证执业**。法务必须建立**许可证到期预警机制，提前 90 日启动延续流程**。

## 六、攻防要点

- **己方（顾问）说服口径**：不要谈"我们今年能不能过校验"，而是谈"**台账有几项在 90 日预警期内**"。把许可证管理做成一个可打勾的台账，比任何说教都有效。
- **反向筛查**：拿到一份医院证照清单，先看**有没有证照台账**，再看**台账上的有效期是否与实物一致**。没有台账的医院，逾期是必然的。
- **注意**：校验不合格的后果是"暂缓校验 → 仍不合格则注销"，**这是一个渐进过程，给了整改窗口**。顾问应当善用这个窗口期推动整改，而不是等到注销后再救火。

## 七、法条依据（本地源核验）

| 规范 | 条文 | 本地 verbatim |
|---|---|---|
| 《医疗机构管理条例》（国务院令第752号·2022-05-01·现行有效） | 第14条 医疗机构执业，必须进行登记，领取《医疗机构执业许可证》；诊所按照国务院卫生行政部门的规定向所在地的县级人民政府卫生行政部门备案后，可以执业 | ✅ 已核（本地法条银行） |
| 《医疗机构管理条例》 | 第23条 任何单位或者个人，未取得《医疗机构执业许可证》或者未经备案，不得开展诊疗活动 | ✅ 已核 |
| 《医疗机构管理条例》 | 第26条 医疗机构必须按照核准登记或者备案的诊疗科目开展诊疗活动 | ✅ 已核 |

> ⚠️ **本地 verbatim 缺口说明**：第 14 条已核；但"校验周期（＜100 张每年、≥100 张每 3 年）"与"30 日内申请变更"的具体操作规则，**本地法条银行《医疗机构管理条例》摘录版未收录相应条文**（本地仅有第 14/23/26/47 条）。此项标注 `规范指向·非文书法源`，**仅按本书口径记录操作规则，未引法条正文，不得引为文书法源**。
