# R-PI-435 科室出租承包禁止与一院一策差异化服务

## 一、合规红线：科室外包／出租承包科室

| 情形 | 法律后果 |
|---|---|
| 科室外包、出租、承包科室 | 违反《医疗机构管理条例》**明令禁止行为**，**可被吊销执业许可证** |
| 外包＋利润分成 | 涉嫌商业贿赂、医保骗保，**刑事风险极高** |
| 对外合作规避上式 | 须改为"医院统一管理、人员统一招聘、财务统一核算、技术合作服务付费" |

> **审查要点**：见到"科室外包""利润分成""保底收益""使用医院品牌""自主聘用医师"等要素任意组合，先判模式合法性，再谈条款。模式违法时，合同条款无意义。

**服务差异化的合规意义**：我国医院分为公立/民营、综合/专科、营利/非营利，治理结构、监管重点、风险类型差异显著，**法律顾问必须定制化服务，不可一套模板通吃**。

## 二、四类医院的差异化服务口径

### 1. 公立医院（非营利性）
- **监管重点**：财政资金、国有资产、医保合规、招标采购、人事编制、廉政风险、公益属性
- **风险高发**：医保违规、招标采购合规、医患纠纷、审计追责、商业贿赂
- **服务重点**：重大决策合法性审查、政府采购合规、医保风控、医疗纠纷标准化处理、事业单位人事管理、廉政合规

### 2. 民营医院（营利/非营利）
- **监管重点**：依法执业、广告宣传、价格收费、医保定点、科室合作、医疗质量
- **风险高发**：虚假宣传、超范围执业、**出租科室**、骗保、劳动争议、股权纠纷
- **服务重点**：股权架构、商业模式合规、广告审查、医保风控、劳动用工、纠纷快速处置

### 3. 综合医院
- **风险点集中**：内科、外科、产科、急诊、重症、介入、手术等髙风险科室
- **服务重点**：全科室风险防控、重大手术知情同意、急诊应急合规、院感防控、多学科纠纷处理

### 4. 专科医院（风险高度集中）
| 专科 | 高发风险点 |
|---|---|
| 妇产医院 | 产科出血、新生儿损伤 |
| 骨科 | 内固定失败 |
| 眼科 | 手术并发症 |
| 医美 | 美容纠纷 |
| 口腔 | 种植修复 |
| 精神卫生 | 非自愿医疗 |

- **服务重点**：专科专项合规、专科诊疗规范、专科知情同意书、专科纠纷应对

> **实务总结**：**公立医院重合规与审计，民营医院重生存与模式，综合医院重全域风控，专科医院重专科精准防控。法律顾问必须"一院一策"。**

## 三、攻防要点

- **己方防御**：为新客户做服务方案前，先做"医院类型识别"——不同类型的高发风险完全不同，用错套路的后果是"律师觉得医院不配合、医院觉得律师不接地气"。
- **常见误判**：把综合医院的"全域风控"方案直接套给专科医院，导致精力摊薄、专科风险（如非自愿医疗、种植修复）反而漏掉。
- **反向筛查**：接手民营医院顾问业务时，第一件事查"科室外包"——这是民营医院最高频、最致命的合规病灶。

## 四、法条依据（本地源核验）

《医疗机构管理条例》禁止出租、承包科室的规定，**本地法条银行实测仅存第14/23/26/47条精选条、无本条 verbatim**（文件：`法条银行/医事法律法规库/医疗机构管理条例（国务院令第752号）.md`）→ 引用须另经北大法宝／华宇元典回源核填，**规范指向·非文书法源，不得凭记忆写入本卡**。

## 五、翻车标本（来源：本书 1.4.4 以案说法）

某民营医院拟与第三方合作开展医美科室外包，约定利润分成。法律顾问指出科室外包属《医疗机构管理条例》明令禁止行为、可被吊销执业许可证，且涉嫌商业贿赂与医保骗保，刑事风险极高。医院采纳建议，**重新设计"统一管理＋统一招聘＋统一核算＋技术服务付费"的合法合作模式**，避免重大合规风险。

## 六、来源与地域效力

- 来源：《医院法律顾问与医疗纠纷解决》第一章 1.4
- 效力：科室出租承包禁止规则全国通用；**专科化服务重点与属地监管重点相关**
