# R-PI-460 社保五险与公积金强制缴存的风险管控

## 一、合规红线：社保是强制义务，"放弃声明"一律无效

我国实行强制社会保险制度，包含**养老保险、医疗保险、失业保险、工伤保险、生育保险**（部分地区已合并至医疗保险）。

> **任何免除、放弃、替代社保的约定均绝对无效**——包括员工签署《自愿放弃社保声明》、以现金补贴代替社保、约定"工资含社保"等，**均不能免除医院的法定缴纳义务**。

## 二、审查要点：社保缴纳的四项基本原则

| 项 | 口径 |
|---|---|
| **全员覆盖** | 与医院建立劳动关系的**所有劳动者**均应参保 |
| **及时登记** | 用人单位应当**自用工之日起 30 日内**为劳动者办理社保登记 |
| **据实核定基数** | 按照劳动者**实际工资收入**核定缴费基数 |
| **共同承担** | 单位与个人共同承担社保费用，**单位缴纳部分不得全部转嫁给劳动者** |

## 三、审查要点：七类用工身份的社保规则

| 身份 | 社保口径 |
|---|---|
| 编制内人员 | 机关事业单位养老保险、职业年金 |
| 编外聘用制人员 | 城镇职工社会保险 |
| 备案制人员 | 多数地区参照事业编制或统一纳入职工社保 |
| 劳务派遣人员 | **由派遣单位参保** |
| 退休返聘人员 | 已享受养老待遇，**可不再缴纳五险**（建议购买商业意外险） |
| 规培医师、进修医师 | 按协议发放补助、生活补贴；**建立劳动关系的依法参保** |
| 实习生 | 一般不参保，须核实用工性质 |

## 四、合规红线：住房公积金同样是强制缴存

| 项 | 口径 |
|---|---|
| 核心依据 | 《住房公积金管理条例》（国务院令第710号） |
| 强制性 | **属于强制缴存项目，不是"可选福利"** |
| 时限 | 单位录用职工，应当**自录用之日起 30 日内**办理缴存登记 |
| 基数与比例 | 按职工本人上一年度月平均工资计算；缴存比例由各地在法定区间内确定，**单位与个人同比例缴存，公积金全部归职工个人所有** |
| 法律责任 | 逾期不缴或少缴的，公积金管理中心**责令限期缴存；逾期仍不缴存的，可以申请人民法院强制执行** |

> 实践中大量医院误以为公积金"可缴可不缴"，最终被投诉、被强制执行，**成本远高于正常缴存**。

## 五、审查要点：七大高频败诉点

| 序号 | 败诉点 | 后果 |
|---|---|---|
| 1 | 工资发放无书面记录、无工资条 | 直接采信劳动者主张 |
| 2 | 拖欠、克扣绩效工资、夜班费 | 无合法制度、无考核标准、无确认的，**一律足额补发** |
| 3 | 加班费不核算、不发放、打包发放 | 劳动者能证明加班事实的，**必须支付加班费** |
| 4 | 社保未缴、漏缴 | 责令补缴并**承担滞纳金**；导致无法享受医保报销、生育津贴、工伤待遇的，**由医院全额赔偿** |
| 5 | 以"自愿放弃社保"免责 | 全国口径统一，声明无效，医院仍需补缴、赔偿 |
| 6 | 试用期不缴社保 | 试用期**属于劳动合同期限**，必须缴纳社保 |
| 7 | 公积金不缴、少缴 | 劳动者向公积金中心投诉后，**医院基本无抗辩空间**，只能全额补缴 |

## 六、翻车标本（来源：本书 5.4 以案说法·四案例）

**案例一 · 未缴工伤保险，员工工伤后医院全额赔偿 16 万元**：某民营医院为节约成本未为保洁员刘某缴纳工伤保险。刘某拖地滑倒致股骨颈骨折，经人社局认定为工伤，劳动能力鉴定为**九级伤残**。因无工伤保险，所有工伤待遇均由医院自行承担。仲裁委裁决医院一次性支付各项工伤待遇共计 **162800 元**。

> 最典型的"省小钱、赔大钱"——医院每月仅需支付几十元工伤保险费，一旦发生工伤，全部费用由单位兜底。

**案例二 · 未缴社保致生育津贴无法领取，医院全额赔偿**：某医院护士王某入职 10 个月，医院一直未缴社会保险。王某怀孕分娩，因无生育保险无法享受生育医疗费用报销与生育津贴，损失 32000 余元。仲裁与法院均认定因医院未依法缴纳社保导致劳动者无法享受生育保险待遇，**损失应由医院全额赔偿**，判令支付 **32600 元**。

> 女职工生育待遇是法定刚性待遇，未缴社保的赔偿责任**直接、确定、无免责理由**。

**案例四 · 住房公积金被强制执行，医院补缴 38 万元**：某公立医院长期不为编外人员缴纳住房公积金，17 名护士集体向住房公积金管理中心投诉。公积金中心责令限期补缴，医院仍不履行的，**依法申请法院强制执行，从医院账户直接划扣 38.2 万元**。

> 公积金具有强制执行力，**不是可协商、可拖欠的福利**。

## 七、攻防要点

- **己方（顾问）动作**：每月开展一次**薪酬社保合规自查**六问——①工资发放是否有记录；②加班费是否核算；③社保是否全员参保；④公积金是否正常缴存；⑤工资条是否签字；⑥制度是否公示。做到这几项，**90% 的薪酬社保争议可从源头消灭**。
- **反向筛查**：审一个医院的用工，先查**社保名册人数 vs 在岗人数**。对不上就是漏缴，一查一个准。
- **注意**：《自愿放弃社保声明》**一律无效**，医院不能因为"员工主动要求"就免责——这是最常见的认知误区。
- **注意**：发生工伤须**30 日内申报工伤认定**，逾期费用全部自担。
