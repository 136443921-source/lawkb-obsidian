# R-PI-458 资质管理七大风险与"入口严·过程控·出口清·台账全"操作体系

## 一、操作指引：七大高频风险与统一口径

| 序号 | 风险 | 后果 |
|---|---|---|
| 1 | **使用非卫生技术人员从事诊疗活动** | 无资质人员独立看诊、书写门诊病历、开具处方、实施手术、操作有创操作 → 行政处罚、民事赔偿、追究刑事责任 |
| 2 | **超执业类别、超执业范围执业** | 临床医师从事中医诊疗、中医医师开展临床手术、内科医师开展外科手术 → **一旦发生患者损害，直接推定医院过错** |
| 3 | **执业注册未及时变更** | 员工入职/离职未办理执业地点变更，出现"证在岗不在、人在岗证不在" → 卫健检查**一律按违规处理** |
| 4 | **注册到期未延续、证书失效** | 医师、护士、药师证书过期**视为无证** → 医院必须建立预警台账 |
| 5 | **出租、出借、挂靠执业证书** | 法律明确禁止，**双方均会被处罚、吊销证书** |
| 6 | **规培医师、进修医师、实习生管理不当** | 未在带教医师指导下独立执业、无处方权人员开具处方等 |
| 7 | **多点执业未备案** | 不必然导致处罚，但**发生纠纷时医院极易被认定过错** |

> **一句话总结风险传导**：在司法实践中，**只要存在资质瑕疵，医院在医疗损害案件中几乎必然承担主要责任甚至全部责任**，在劳动争议中也会陷入被动。

## 二、操作步骤表：全周期四关（十六字方针）

### （一）入口关 · 入职"三查三验"，缺一不可

| 查 | 内容 |
|---|---|
| 查资格证 | 核实医师、护士、药师资格证书真实有效 |
| 查执业证 | 确定执业证书在有效期内 |
| 查注册信息 | 确定电子化注册系统可查，执业地点、范围与岗位匹配 |
| 验真伪 | 在国家卫健委官网、电子化注册系统核验 |
| 验无处罚 | 无被吊销、注销、暂停执业情形 |
| 验健康状况 | 符合卫生技术人员健康标准 |

> 凡是资质不全、无效、超范围的，**一律不得录用、不得上岗、不得安排独立工作**。人力资源部门必须建立《医务人员资质入职审查表》，由**人事、医务、科室三方签字确认，归档永久保存**。

### （二）过程关 · 建立动态预警台账，杜绝"过期、失效、空挂"

台账须记录：资格证取得时间、执业证注册时间、有效期、执业地点、类别、范围、延续注册截止日期、变更注册记录、定期考核结果、多点执业备案情况。

| 管理动作 | 时限要求 |
|---|---|
| 到期前 3 个月 | 预警，启动延续注册流程 |
| 岗位调整当日 | 启动变更注册 |
| 考核不合格 | **立即停岗** |
| 证书丢失、损毁 | 立即补办 |
| 挂证、借证、租证 | **严禁任何形式** |

> 法务与医务科要**定期联合抽查，形成检查记录**——这是应对卫健检查的核心证据。

### （三）出口关 · 离职当日启动变更，绝不拖延

1. 员工提交离职申请后，**人事、医务同步启动**执业变更/注销流程；
2. 离职交接单必须包含：执业证书变更办理情况；处方权、医嘱权限、系统权限注销；电子病历、医保系统权限关闭；
3. **严禁以"未交违约金""未完成工作""科室不同意"为由扣押证书、拖延变更**；
4. 离职后 **15 日内**完成全部手续。

### （四）特殊人群严格区分

| 人群 | 要求 |
|---|---|
| 规培医师 / 进修医师 | 必须在**带教医师指导下**工作，无独立处方权、独立诊疗权 |
| 实习生 / 见习生 | 只能辅助，**不得独立操作、独立接诊** |
| 退休返聘医师 | 执业证书有效、注册有效；**年龄不影响资质**，但健康状况必须符合要求 |

## 三、操作要点：资质合规与劳动用工的衔接

1. 劳动合同中**必须明确约定**：员工承诺资质真实、有效、合法；资质失效、被吊销、注销的医院有权调岗；无法调岗的可依法解除劳动合同；因资质虚假给医院造成损失的承担赔偿责任。
2. 一旦发现资质问题，**先停岗、再核查、后处理**，程序合法、书面留痕。
3. 因医院原因未及时注册、变更造成员工损失的，**主动协商解决**，避免矛盾激化。

## 四、翻车标本（来源：本书 5.3 以案说法·四个案例）

**案例一 · 使用未注册医师独立执业，重罚并赔偿**：某民营医院招聘临床医师陈某，陈某**仅通过医师资格考试取得医师资格证，但未办理执业注册**。医院负责人认为"资格证到手就可以先上班"，安排陈某独立接诊、书写病历、开具处方。陈某误诊误治致患者病情加重。卫健部门查实：陈某未取得医师执业证书独立从事诊疗活动、医院使用非卫生技术人员 → 处罚**责令立即改正、罚款30000元、暂缓校验《医疗机构执业许可证》**。诉讼中法院依司法鉴定意见认定医院使用未注册人员独立执业违反强制性规定，**直接推定医疗机构存在全部过错**，判决赔偿医疗费、误工费、残疾赔偿金、精神损害抚慰金等共 **28 万余元**。

> **资格证 ≠ 执业证**，这是所有医院管理者、人力资源、医务、法务必须刻在脑子里的底线。

**案例二 · 护士离职未变更注册，原医院被罚**：护士李某 2021 年 5 月辞职到外地医院工作，原医院人事部门**未办理护士执业地点变更注册**，也未及时注销或备案。李某在新单位发生护理差错，当地卫健部门倒查资质，发现其执业地点仍登记在原医院。原医院被认定**执业注册信息不实、管理混乱**，给予警告、罚款 **5000 元**。

> 员工离职之日，就是资质变更启动之时。医院对执业注册具有**法定管理义务，不因员工离职而自动免除**。

**案例三 · 内科医师超范围开展外科手术，承担全部赔偿**：某乡镇卫生院内科医师王某，在无外科资质、无手术室条件下为患者实施疝气修补手术，造成患者神经损伤。医院主张"乡镇医院条件有限、医师一人多岗是惯例"。法院认定：①王某超执业范围执业违反《医师法》强制性规定；②卫生院使用卫生技术人员超范围执业，**等同于使用非卫技人员的严重过错**；③医院承担 **100% 赔偿责任**，共 **19 万余元**。

> 行业惯例、客观条件、基层困难，都不能对抗法律强制性规定。

**案例四 · 实习生独立操作致损害，带教老师与医院共同担责**：某教学医院护理实习生张某，在未取得护士执业证书、无带教老师现场监督情况下独立进行静脉穿刺，致患者肢体损伤。法院认定实习生不具备执业资格不得独立从事护理工作，医院及带教老师未尽管理监督义务，**医院承担全部赔偿责任**。

## 五、攻防要点

- **己方（顾问）动作**：把"十六字方针"做成**一张流程图挂进医务科和人事科**——入口严（三查三验）、过程控（五条管理动作）、出口清（15 日闭环）、台账全（电子台账字段清单）。
- **反向筛查**：卫健飞行检查来之前，先看医院有没有**资质电子台账**。没有台账的，检查组一查一个准。
- **注意**：扣押执业证在实务中**"一告一个准"**——轻则行政处罚，重则赔偿员工无法就业的经济损失。
- **注意**：**年龄不影响执业资质有效性**，退休返聘医师只要证书有效、健康达标即可执业，医院常误以为超龄就不能用。
