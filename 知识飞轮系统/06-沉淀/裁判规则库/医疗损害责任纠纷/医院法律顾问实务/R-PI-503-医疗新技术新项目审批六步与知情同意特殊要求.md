# R-PI-503 医疗新技术新项目审批六步与知情同意特殊要求

## 一、三类技术分类与"备案制 + 负面清单"改革

| 类别 | 定义 |
|---|---|
| **第一类技术** | 安全性、有效性确切，医疗机构通过常规管理能够保证其安全有效的技术 |
| **第二类技术** | 安全性、有效性确切，但**涉及一定伦理问题或者风险较高**，卫生行政部门应当加以控制管理的技术 |
| **第三类技术** | 具下列情形之一：涉及**重大伦理问题**、**高风险**、安全性有效性**尚需进一步验证**、需要**使用稀缺资源**等 |

- **2018 年修订《医疗技术临床应用管理办法》的关键变化**：**取消**第三类医疗技术临床应用准入审批，转为**备案管理 + 负面清单制度**——**禁止类技术不得应用，限制类技术实施备案管理**。
- **风险转移结论（本卡最重要的一条）**：行政审批简化**同时将更多安全管理责任转移到医疗机构自身**。医院引进新技术新项目**不能以"已经备案"为满足**，必须建立**更严格的内部审查与风险管控制度**。

## 二、医院内部审批六步流程（法律顾问建议标准动作）

| 步 | 环节 | 具体内容 |
|---|---|---|
| **1** | **科室申报** | 提交项目申请报告，含：技术名称和来源、国内外应用现状、**适应症和禁忌症**、技术操作规范、可能的风险及**应对预案**、**人员资质和培训情况**、设备设施条件、伦理审查意见等 |
| **2** | **医务处初审** | 形式审查 + 初步评估，重点审查：是否属于**禁止类技术**、是否属于**限制类技术需备案**、科室和人员是否具备**相应资质条件**、设备设施是否满足技术要求 |
| **3** | **医疗技术临床应用管理委员会评审** | **审批核心环节**。委员会应由院领导、医务处、质控部门、相关科室专家、**伦理委员会代表**等组成，对**安全性、有效性、伦理合规性、经济合理性**全面评审；评审**应形成书面意见**，明确是否同意开展、需满足的条件、需限制的范围 |
| **4** | **伦理委员会审查** | 涉及人体研究的医疗新技术新项目，应通过伦理委员会审查。重点：研究方案的伦理合理性、**知情同意的充分性**、受试者权益保护措施、**利益冲突披露** |
| **5** | **备案与报告** | 属限制类技术的，按要求向卫生健康行政部门**备案**；备案后按规定**定期报告**技术临床应用情况 |
| **6** | **临床应用后的持续评估** | 建立持续评估机制，定期评估技术的**安全性、有效性和经济性**；出现**严重不良事件应立即暂停并报告** |

## 三、新技术新项目知情同意的三项特殊告知

> 要求**高于常规诊疗**——因新技术的不确定性与风险不确定性更大。

| # | 特别告知内容 | 反面样本与风险 |
|---|---|---|
| **1** | **技术的"新"属性** | 应明确告知：该技术是**新技术**、临床应用经验有限、**远期效果和风险可能尚不明确**。反面样本：医院介绍时**过分强调"先进性"而淡化"不确定性"** → 患者事后主张"我不知道这是新技术，我以为已经很成熟了" → **知情同意无效风险** |
| **2** | **替代方案的充分告知** | 对**有成熟替代方案**的患者，应详细告知替代方案利弊、**选择新技术的额外风险**。案例：医院为患者实施新型微创手术，术后效果不理想，患者主张"如果知道传统手术效果更确定，我就不会选择新技术"——而医院知情同意时**未充分比较新旧方案利弊** → **被认定告知不充分** |
| **3** | **随访和长期观察的要求** | 新技术新项目通常需**长期随访**以评估远期效果与风险。同意书应告知**随访的重要性与具体安排**，并明确**患者配合随访的义务**。若患者不配合随访致远期并发症未及时发现，**责任认定中可能需要考虑患者自身因素** |

## 四、临床研究 vs 临床应用的划界（"就高不就低"原则）

| 情形 | 定性 | 程序要求 |
|---|---|---|
| 已在国内外**权威指南中推荐** / 已获**国家药品监督管理局批准** | **常规临床应用** | 适用一般性知情同意规定 |
| **尚处临床试验阶段** / 仅在**少数病例中有个案报告** | **临床研究** | 须经**伦理审查**，知情同意要求**更严格**（依《涉及人的生命科学和医学研究伦理审查办法》） |
| **灰色地带**：已在国外获批但未在国内获批 / 已在其他医院应用但**本院首次开展** | **就高不就低** | 按**更严格**的审查与知情同意程序执行，以降低法律风险 |

- **法理提示**：将本应属研究性质的新技术应用按常规临床应用处理，**可能违反研究伦理的法律要求**。

## 五、以案说法

**案例六：达芬奇机器人手术的法律争议 → 主要责任**
2021 年，某省级医院引进达芬奇手术机器人系统后，普外科为 62 岁直肠癌患者实施**机器人辅助直肠癌根治术**。术中，机器人**机械臂操作出现异常抖动**，术者**未及时转换为开腹手术**，导致患者**肠管多处损伤**，术后严重腹腔感染和肠瘘；经多次二次手术后**遗留短肠综合征**。
- **患方主张**：引进机器人后**术者培训时间不足即开展手术**；术中出现异常未及时转换术式；术前知情同意书**未告知设备故障风险**，告知不充分。
- **医院抗辩**：达芬奇手术已国内外广泛应用，**不属新技术**；术者已取得操作资质；术中异常系**设备偶发故障，属不可预见的并发症**。
- **鉴定意见（三条全部支持患方）**：
  1. 达芬奇手术全球范围虽非新技术，但该院**引进设备仅 3 个月、术者独立完成不足 10 例**，**在该院仍属新技术新项目**。按该院《新技术新项目管理办法》，新技术开展初期**应有上级医师指导**，本案术者独立操作、未请有经验的上级医师台下指导，**不符合医院自身管理制度**。
  2. 术中机械臂异常后，术者**观察约 20 分钟**方决定转换开腹，其间**肠管损伤加重**。按操作规范，设备异常时应**优先考虑患者安全、及时转换手术方式** → **延迟转换存在过错**。
  3. 知情同意书仅笼统提"手术风险"，**未特别告知机器人手术的设备故障风险和转换开腹的可能性** → **告知不充分**。
  法院综合鉴定意见，判决医院承担**主要责任**。
- **点评三启示**：
  1. **"新技术"的界定不应仅看该技术在全国乃至全球的普及程度，更应看在该院的应用阶段**——刚引进设备的医院，即便全球成熟的技术，对该院仍是新技术，应适用新技术新项目管理制度。
  2. **医院内部管理制度一旦制定就必须严格执行**，否则诉讼中**反受其害**——"你自己定的制度都不遵守，何谈规范诊疗？"
  3. **新技术知情同意应针对技术特殊性告知**，不能套用一般性手术知情同意模板。

## 六、法条依据

- ✅ **已核（verbatim）**：
  - 《医疗纠纷预防和处理条例》**第 11 条**——"医疗机构应当按照国务院卫生主管部门制定的**医疗技术临床应用管理规定**，开展与其技术能力相适应的医疗技术服务，保障临床应用安全，降低医疗风险；**采用医疗新技术的，应当开展技术评估和伦理审查**，确保安全有效、符合伦理。"（`法条银行/行政法律规章/医疗纠纷预防和处理条例.md` 本地 verbatim 命中，L54）
