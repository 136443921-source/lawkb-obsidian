# R-PI-437 三种服务模式（驻场·专项咨询·定期巡检）

## 一、操作指引

医疗机构最常用、最有效的三种服务模式——**驻场服务、专项咨询、定期巡检**。三种模式并非相互排斥，而是组合使用，形成"**日常＋重点＋应急**"的立体服务体系。

### 模式一 · 驻场服务

**定义**：法律顾问按约定固定时间、固定人员、固定地点在医院办公，直接参与医院日常管理。

| 要素 | 操作口径 |
|---|---|
| 适用对象 | 三级医院、大型三甲医院、纠纷高发医院、正在进行重大改革/建设的医院、管理基础薄弱的新建医院 |
| 驻场频率 | 常见每周 1–2 天，或每月不少于 8 天；重大活动、敏感时期可增加 |
| 工作内容 | 现场接待咨询、现场审核文件、现场参与科室会议、现场指导投诉处理、现场梳理流程 |
| 优势 | 响应速度快、熟悉医院真实情况、便于跨部门协调、能及时发现隐性风险 |
| **注意事项** | 驻场律师必须遵守医院规章制度，尊重医疗规律，**不干涉临床诊疗决策**，坚持"只提法律建议、不替代专业判断" |

**实证**：笔者曾为一家大型三甲医院提供每周两天驻场服务。期间医院门诊量、住院量、手术量大幅增长，但**医疗纠纷发生率下降 60% 以上，诉讼率下降近 70%**，核心原因是法律顾问深度融入管理，把大量风险消灭在萌芽状态。

### 模式二 · 专项咨询

**定义**：医院就特定事项、特定问题、特定项目提出咨询，顾问以口头答复、书面回复、法律意见书等形式提供专业意见。

- **适用场景**：突发舆情、重大投诉、疑似医疗事故、医保检查、设备引进、对外合作谈判、规章制度制定
- **特点**：一事一议、针对性强、专业度高、时效性强
- **形式分层**：紧急事项电话/微信即时答复 → 重要事项出具书面咨询意见 → 重大事项出具正式《法律意见书》
- **价值**：为重大决策提供法律依据，避免因决策违法违规造成不可挽回的损失

**实证**：某医院拟与外部机构合作开展医美项目，合同初稿由对方提供，明显加重医院责任、免除对方主要义务，且存在医疗广告违法、执业范围超纲等问题。经顾问全面审查提出十余项修改意见后，医院重新谈判，**避免了后续可能发生的巨额赔偿与行政处罚**。

### 模式三 · 定期巡检

- **周期**：季度、半年度、年度，对重点领域、重点制度、重点环节进行系统性"法律体检"
- **巡检内容**：医疗质量安全、合同管理、人事管理、药品耗材采购、基建工程、医保合规、信息安全、知识产权、投诉处理流程
- **输出成果**：《医院法律风险巡检报告》《风险问题清单》《整改建议表》《责任分工表》
- **核心目的**：从"被动应对"转向"主动防控"，实现风险治理常态化、制度化
- **定位**：定期巡检是**公立医院绩效考核、现代医院管理制度建设、平安医院建设**的重要组成部分，也是医院等级评审中"法治建设"指标的重要支撑

## 二、组合标准配置

三种模式组合通常形成标准结构：**日常咨询 ＋ 定期驻场 ＋ 季度巡检 ＋ 年度体检 ＋ 专项应急**——这也是目前国内头部医院法律顾问服务的标准配置。

## 三、操作要点与避坑

1. **驻场不是"坐班"**：驻场价值来自"在场"带来的信息优势与响应速度，若只做书面工作，驻场意义消失。
2. **专项咨询的书面化分层不能省**：紧急答复留痕、重要意见书面化、重大事项出具法律意见书——这三层既是质量控制，也是日后证明"已尽责"的证据。
3. **巡检报告必须落到"责任分工表"**：只有问题清单没有责任分工，巡检必然沦为走过场。

## 五、翻车标本（来源：本书 2.1.3 专项咨询实证）

医美项目合作中，对方提供的合同初稿"加重医院责任、免除对方主要义务＋医疗广告违法＋执业范围超纲"——**三项问题叠加**。若仅审合同条款不审模式合法性，会同时踩中民事、行政、行业监管三线。
