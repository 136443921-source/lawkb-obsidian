# R-PI-517 医务人员未尽说明义务侵犯知情同意权造成患者损害医疗机构赔偿

## 规则要旨
医务人员在诊疗活动中应当向患者说明病情和医疗措施；需要实施**手术、特殊检查、特殊治疗**的，应当及时向患者**具体说明医疗风险、替代医疗方案**等情况，并取得其**明确同意**；不能或者不宜向患者说明的，应当向患者的**近亲属**说明并取得明确同意（民法典第一千二百一十九条第一款）。

**归责要点**：
- 医务人员未尽到前款说明义务，**造成患者损害的，医疗机构应当承担赔偿责任**（第1219条第二款）。
- 判定核心：**告知不充分 → 使患者丧失选择机会 + 损害后果 → 因果关系成立 → 医方担责**。典型情形：检查发现手术禁忌症却仅告知"有手术指征"、未告知属禁忌症，使患者丧失不手术的选择机会，术中因该禁忌致损害。
- 法理基础：患者自主决定权是重要人格权益，医方须在患者决定前提供充足医疗资讯；摒弃"医疗父权"思维，尊重自我决定权。
- 边界：紧急情况（抢救生命垂危）不能取得患者或近亲属意见的，经医疗机构负责人/授权负责人批准可立即实施（第1220条）；隐匿/拒绝提供/伪造篡改病历的，推定医方有过错（第1222条）。

## 关联法条
- 《民法典》第一千二百一十九条（说明义务与知情同意权）
- 《民法典》第一千二百二十条（紧急情况知情同意特殊规定）
- 《民法典》第一千二百二十二条（推定医疗机构有过错：违反诊疗规范/隐匿病历/伪造篡改销毁病历）

## 来源（来源降级·WebSearch）
- 中国法院网（2021-10）《未充分保障患者知情权，医方是否承担侵权责任？》：老年患者心脏瓣膜畸形属手术绝对禁忌症，医方仅告知有手术指征、未告知属禁忌症，患者丧失选择机会术中血管损伤救治无效死亡 → 告知不足与损害有因果关系，医方担责。
- 最高人民法院"学法典读案例答问题"（民法典颁布两周年）：刘阿姨案，医生未经说明直接用最贵方案致无力承担 → 未尽说明义务侵害知情同意权，造成损害医院赔偿（选A）。
