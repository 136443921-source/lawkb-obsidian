# R-PR-216 涉外与港澳台判决承认与执行（承认条件·不予承认情形·复议）举证证据规则

## 裁判规则（证据规则·正向）

**外国法院判决的承认与执行**：外国法院作出的发生法律效力的判决、裁定，需要人民法院承认和执行的，可以由当事人**直接向有管辖权的中级人民法院**申请，也可以由外国法院依照条约规定或**互惠原则**请求（民诉法第298条）。审查标准：依照中华人民共和国缔结或参加的国际条约，或者按照互惠原则进行审查后，认为**不违反中华人民共和国法律的基本原则且不损害国家主权、安全、社会公共利益**的，裁定承认其效力；**需要执行的，发出执行令**，依照本法有关规定执行（第299条）。**不予承认和执行的情形**：经审查有下列情形之一，裁定不予承认和执行——①外国法院对案件**无管辖权**（依第301条认定：依其法律无管辖权或与纠纷无适当联系、违反我国专属管辖规定、违反当事人排他性选择法院协议）；②被申请人**未得到合法传唤**或虽经传唤但未获得合理陈述、辩论机会，或无诉讼行为能力人未得到适当代理；③判决、裁定通过**欺诈**方式取得；④人民法院**已对同一纠纷作出判决**，或已承认第三国对同一纠纷的判决；⑤**违反我国法律基本原则**或损害国家主权、安全、社会公共利益（第300条）。同一纠纷**正在人民法院审理**的，可以裁定**中止诉讼**（第302条）。**救济**：当事人对承认和执行或不予承认和执行的裁定不服的，可以**自裁定送达之日起十日内向上一级人民法院申请复议**（第303条）。**域外仲裁裁决**：需要人民法院承认和执行的，当事人可以向**被执行人住所地或财产所在地的中级人民法院**申请（第304条）。**申请材料与审查**：应提交**申请书**并附判决、裁定**正本或经证明无误的副本及中文译本**；缺席判决应同时提交该外国法院**已合法传唤的证明文件**（解释第541条）。**无条约无互惠**的，裁定驳回申请（但承认**离婚判决**除外），驳回后可向人民法院**起诉**（解释第542条）。**先承认后执行**：需执行的应先申请承认，裁定承认后再依第三编执行；仅申请承认的，仅审查应否承认（解释第544条）。**申请期间**适用申请执行时效的规定（解释第545条）。**合议庭审查**：应当组成合议庭审查，将申请书送达被申请人、被申请人可陈述意见，裁定**一经送达即发生法律效力**（解释第546条）。**港澳台**：人民法院审理涉及**香港、澳门特别行政区和台湾地区**的民事诉讼案件，**可以参照适用涉外民事诉讼程序的特别规定**（解释第549条）。

🔴 审查三重门：**①管辖权（第300条第一项+第301条）②程序正当（合法传唤/陈述辩论机会，第二项）③公共秩序（法律基本原则/主权安全社会公共利益，第五项）**——任一不满足即不予承认。港澳台裁判**参照**涉外程序特别规定（解释第549条），非直接适用。

## 适用案由与场景

适用于：① 当事人申请**承认与执行外国法院生效判决/裁定**（第298条）及审查（第299/300条）；② 被申请人对承认提出**不予承认**抗辩（无管辖权、未合法传唤、欺诈取得、平行判决、公共秩序）；③ 与人民法院**正在审理的同一纠纷**竞合时的中止诉讼（第302条）；④ **域外仲裁裁决**的承认与执行（第304条，衔接 R-PR-207）；⑤ 承认/不予承认裁定后的**复议救济**（第303条）；⑥ **中国香港、澳门、中国台湾地区**民事裁判参照涉外程序特别规定的处理（解释第549条）；⑦ 申请材料（译本、传唤证明）与**申请期间**争议（解释第541/545条）。典型：境外离婚判决/商事判决在我国申请承认执行，被申请人以"未获合法传唤""判决系欺诈取得"抗辩；中国香港地区法院判决在内地申请认可与执行（参照适用）。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 承认申请适格（管辖法院、申请材料，第298条、解释第541条） | **申请人** | 申请书、判决/裁定**正本或经证明无误副本+中文译本**、缺席判决的**合法传唤证明** |
| 符合条约或**互惠**关系（第299条、解释第542条） | **申请人** | 双边/多边条约依据、互惠关系的证明（先例、外交文件） |
| 不违反法律基本原则、不损害主权安全社会公共利益（第299条） | 申请人（初步）/法院审查 | 判决内容合法性的说明 |
| 外国法院**无管辖权**（第300条第一项、第301条） | **被申请人（抗辩方）** | 外国法院管辖依据、与纠纷有无适当联系、是否存在我国专属管辖或排他性协议 |
| **未获合法传唤/陈述辩论机会**（第二项） | **被申请人** | 缺席事实、未收到传唤的证据、未获合理陈述辩论机会的记录 |
| 判决系**欺诈**取得（第三项） | **被申请人** | 欺诈的客观证据（伪造证据、虚假陈述等） |
| **平行判决**（第四项） | 被申请人 | 人民法院或第三国对同一纠纷的判决/承认裁定 |
| 同一纠纷**正在审理**（第302条中止诉讼） | 法院 / 主张方 | 正在审理案件的立案与进展材料 |
| **申请期间**（解释第545条，援引第246条→现行第250条） | 申请人 | 判决生效日、申请承认/执行的时间（倒推时效） |
| **港澳台**参照适用的主张（解释第549条） | 提出方 | 裁判作出地为中国香港/澳门/台湾地区的证明、相应安排/协议 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民事诉讼法》（2023修正）第298条（本地核填·现行有效）："外国法院作出的发生法律效力的判决、裁定，需要人民法院承认和执行的，可以由当事人直接向有管辖权的中级人民法院申请承认和执行，也可以由外国法院依照该国与中华人民共和国缔结或者参加的国际条约的规定，或者按照互惠原则，请求人民法院承认和执行。"
2. 第299条（本地核填·现行有效）："人民法院对申请或者请求承认和执行的外国法院作出的发生法律效力的判决、裁定，依照中华人民共和国缔结或者参加的国际条约，或者按照互惠原则进行审查后，认为不违反中华人民共和国法律的基本原则且不损害国家主权、安全、社会公共利益的，裁定承认其效力；需要执行的，发出执行令，依照本法的有关规定执行。"
3. 第300条（本地核填·现行有效）："对申请或者请求承认和执行的外国法院作出的发生法律效力的判决、裁定，人民法院经审查，有下列情形之一的，裁定不予承认和执行：（一）依据本法第三百零一条的规定，外国法院对案件无管辖权；（二）被申请人未得到合法传唤或者虽经合法传唤但未获得合理的陈述、辩论机会，或者无诉讼行为能力的当事人未得到适当代理；（三）判决、裁定是通过欺诈方式取得；（四）人民法院已对同一纠纷作出判决、裁定，或者已经承认第三国法院对同一纠纷作出的判决、裁定；（五）违反中华人民共和国法律的基本原则或者损害国家主权、安全、社会公共利益的。"
4. 第301条（本地核填·现行有效）："有下列情形之一的，人民法院应当认定该外国法院对案件无管辖权：（一）外国法院依照其法律对案件没有管辖权，或者虽然依照其法律有管辖权但与案件所涉纠纷无适当联系；（二）违反本法对专属管辖的规定；（三）违反当事人排他性选择法院管辖的协议。"
5. 第302条（本地核填·现行有效）："当事人向人民法院申请承认和执行外国法院作出的发生法律效力的判决、裁定，该判决、裁定涉及的纠纷与人民法院正在审理的纠纷属于同一纠纷的，人民法院可以裁定中止诉讼。外国法院作出的发生法律效力的判决、裁定不符合本法规定的承认条件的，人民法院裁定不予承认和执行，并恢复已经中止的诉讼；符合本法规定的承认条件的，人民法院裁定承认其效力；需要执行的，发出执行令，依照本法的有关规定执行；对已经中止的诉讼，裁定驳回起诉。"
6. 第303条（本地核填·现行有效）："当事人对承认和执行或者不予承认和执行的裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议。"
7. 第304条（本地核填·现行有效）："在中华人民共和国领域外作出的发生法律效力的仲裁裁决，需要人民法院承认和执行的，当事人可以直接向被执行人住所地或者其财产所在地的中级人民法院申请。被执行人住所地或者其财产不在中华人民共和国领域内的，当事人可以向申请人住所地或者与裁决的纠纷有适当联系的地点的中级人民法院申请。人民法院应当依照中华人民共和国缔结或者参加的国际条约，或者按照互惠原则办理。"
8. 《民诉法解释》第541条（本地核填·现行有效）："申请人向人民法院申请承认和执行外国法院作出的发生法律效力的判决、裁定，应当提交申请书，并附外国法院作出的发生法律效力的判决、裁定正本或者经证明无误的副本以及中文译本。外国法院判决、裁定为缺席判决、裁定的，申请人应当同时提交该外国法院已经合法传唤的证明文件，但判决、裁定已经对此予以明确说明的除外。"
9. 第542条（本地核填·现行有效）："当事人向中华人民共和国有管辖权的中级人民法院申请承认和执行外国法院作出的发生法律效力的判决、裁定的，如果该法院所在国与中华人民共和国没有缔结或者共同参加国际条约，也没有互惠关系的，裁定驳回申请，但当事人向人民法院申请承认外国法院作出的发生法律效力的离婚判决的除外。承认和执行申请被裁定驳回的，当事人可以向人民法院起诉。"
10. 第544条（本地核填·现行有效）："对外国法院作出的发生法律效力的判决、裁定或者外国仲裁裁决，需要中华人民共和国法院执行的，当事人应当先向人民法院申请承认。人民法院经审查，裁定承认后，再根据民事诉讼法第三编的规定予以执行。当事人仅申请承认而未同时申请执行的，人民法院仅对应否承认进行审查并作出裁定。"
11. 第545条（本地核填·现行有效）："当事人申请承认和执行外国法院作出的发生法律效力的判决、裁定或者外国仲裁裁决的期间，适用民事诉讼法第二百四十六条的规定。当事人仅申请承认而未同时申请执行的，申请执行的期间自人民法院对承认申请作出的裁定生效之日起重新计算。"
12. 第546条（本地核填·现行有效）："承认和执行外国法院作出的发生法律效力的判决、裁定或者外国仲裁裁决的案件，人民法院应当组成合议庭进行审查。人民法院应当将申请书送达被申请人。被申请人可以陈述意见。人民法院经审查作出的裁定，一经送达即发生法律效力。"
13. 第549条（本地核填·现行有效）："人民法院审理涉及香港、澳门特别行政区和台湾地区的民事诉讼案件，可以参照适用涉外民事诉讼程序的特别规定。"

🔴 条号位移提示：解释第545条援引"民事诉讼法第二百四十六条"作为申请期间条号，而现行民诉法（2023修正）第246条实为**执行检察监督**条款、申请期间现位于**第250条**（参见 R-PR-206 位移警示）。

## 攻防要点

- **攻方（申请人）**：① 备齐**形式要件**（正本/副本+中文译本、缺席判决的传唤证明，解释第541条）；② 论证**条约或互惠**关系（第299条、解释第542条）；③ 未同时申请执行的，主张"仅承认"审查（解释第544条），并注意**申请期间自承认裁定生效之日起重新计算**（解释第545条）；④ 对**中国港澳台**裁判，主张参照适用涉外程序特别规定（解释第549条）。
- **防方（被申请人）**：① 以第300条五情形逐项抗辩，**最高频的是第一项（无管辖权）与第二项（未获合法传唤/陈述辩论机会）**；② 以第301条细化"无管辖权"（无适当联系、违反专属管辖、违反排他性协议）；③ 主张判决系**欺诈**取得（第三项）；④ 以**平行判决**（第四项）或**公共秩序**（第五项）抗辩；⑤ 以同一纠纷正在审理主张中止（第302条）。
- **救济与期限**：对承认/不予承认裁定不服，**十日内向上一级法院申请复议**（第303条）；申请期间适用申请执行时效（解释第545条）。
- **港澳台的特殊性**：不作为"外国"处理，而是**参照适用**涉外程序特别规定（解释第549条）——表述上须规范（使用"中国香港/中国澳门/中国台湾地区"）。

## 质证话术模板

- 申请承认与执行："申请人提交××国法院××号生效判决书正本及经证明无误的中文译本，该国与我国共同参加××国际条约，依《民事诉讼法》第298条、第299条请求裁定承认其效力并发出执行令。"
- 不予承认抗辩（未合法传唤）："××国法院作出的是**缺席判决**，被申请人从未收到合法传唤、亦未获得合理的陈述与辩论机会，依《民事诉讼法》第300条第二项应裁定不予承认和执行。"
- 无管辖权抗辩："该外国法院与本案纠纷无适当联系，且违反当事人达成的排他性选择法院管辖协议，依《民事诉讼法》第301条应认定其无管辖权，据第300条第一项不予承认。"
- 港澳台参照适用："本案裁判系中国香港特别行政区法院作出，依《民诉法解释》第549条，可以参照适用涉外民事诉讼程序的特别规定办理认可与执行。"
- 复议救济："本申请人对××号不予承认和执行裁定不服，依《民事诉讼法》第303条，于裁定送达之日起十日内向上一级人民法院申请复议。"

- 涉外/港澳台裁判的"进入"是**承认（认可）→ 执行**两步走（解释第544条），承认是门槛：不获承认，执行无从谈起。
- **审查三重门**必须逐一核对：管辖权（第301条细化）、程序正当（合法传唤/陈述辩论机会）、公共秩序（第300条第五项）。实务中**缺席判决的传唤证明**（解释第541条）是申请人的高频失分点。
- **港澳台定位要规范**：中国香港、中国澳门、中国台湾地区的裁判**参照适用**涉外程序特别规定（解释第549条），表述上须用"中国香港/中国澳门/中国台湾地区"，不得作为"外国"处理。
