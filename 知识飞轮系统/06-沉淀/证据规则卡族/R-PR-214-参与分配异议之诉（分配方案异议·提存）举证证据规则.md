# R-PR-214 参与分配异议之诉（分配方案异议·提存）举证证据规则

## 裁判规则（证据规则·正向）

多个债权人对执行财产申请参与分配的，**执行法院应当制作财产分配方案，并送达各债权人和被执行人**；债权人或者被执行人对分配方案有异议的，应当**自收到分配方案之日起十五日内向执行法院提出书面异议**（解释第509条）。对书面异议的处理：执行法院**应当通知未提出异议的债权人、被执行人**；未提出异议者**自收到通知之日起十五日内未提出反对意见**的，执行法院依异议人的意见对分配方案**审查修正后进行分配**；**提出反对意见**的，应当通知异议人；**异议人可以自收到通知之日起十五日内，以提出反对意见的债权人、被执行人为被告，向执行法院提起诉讼**（即"**参与分配方案异议之诉**"）；异议人**逾期未提起诉讼**的，执行法院按照**原分配方案**进行分配；**诉讼期间进行分配的，执行法院应当提存与争议债权数额相应的款项**（解释第510条）。参与分配的资格基础：被执行人为公民或其他组织，执行程序开始后，其他已取得执行依据的债权人发现被执行人财产不能清偿所有债权的，可以申请参与分配；对查封、扣押、冻结的财产有**优先权、担保物权**的债权人，可以直接申请参与分配、主张优先受偿权（解释第506条）。分配主持：对参与被执行人财产的具体分配，应当由**首先查封、扣押或冻结的法院**主持进行；首封法院的执行措施如系为执行**财产保全裁定**，具体分配应在该院**案件审理终结后**进行（执行工作规定第56条）。

🔴 程序链条铁律：**分配方案送达 → 15日内书面异议 → 通知未异议人 → 未异议人15日内不反对则修正分配 / 反对则异议人15日内以反对者为被告起诉 → 诉讼期间提存争议款项**。三条"十五日"期限构成异议之诉的完整时间框架，逾期即按原方案分配。

## 适用案由与场景

适用于：① 债权人认为分配方案中**自己的债权数额/顺位被低估**，或**其他债权人不应参与分配**，提出书面异议；② 异议经其他债权人**反对**后，异议人提起**分配方案异议之诉**（以反对者为被告）；③ **提存**争议款项的请求与监督；④ 参与分配**资格**争议（是否已取得执行依据、是否享有优先权/担保物权，衔接 R-PR-191）；⑤ 多个法院竞合时的**分配主持法院**争议（首封法院主持，执行工作规定第56条，衔接 R-PR-205/210）。典型：普通债权人认为优先权债权人的债权不实或已受偿、不应优先，提出分配方案异议并起诉；或首封法院与轮候查封法院就分配主持权发生争议。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 分配方案已依法制作与送达（解释第509条） | 执行法院（程序） | 分配方案原件、送达回证、各债权人及被执行人签收记录 |
| 书面异议在**十五日内**提出（第509条） | **异议人** | 分配方案送达日、异议书及递交凭证（倒推十五日） |
| 异议成立（债权数额/顺位/参与资格有误） | **异议人（本证方）** | 执行依据、债权数额凭证、受偿情况、优先权/担保物权证明 |
| 反对意见的实体理由（第510条） | **提出反对意见的债权人/被执行人** | 反对所依据的债权与顺位材料 |
| **异议之诉在十五日内提起、被告适格**（第510条） | **异议人（原告）** | 反对意见通知送达日、起诉状及立案记录（倒推十五日）、以**反对者为被告**的当事人列明 |
| 争议款项**提存**（第510条） | 执行法院（诉讼期间分配时） | 争议债权数额、提存凭证 |
| 参与分配**资格**（解释第506条） | **申请参与分配的债权人** | 已取得的执行依据、财产不能清偿的证明、（优先权/担保物权人）权利凭证 |
| 分配**主持法院**（执行工作规定第56条） | 主张主持方 | 首封/首冻结的时间证明、是否保全裁定及其案件审理状态 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民诉法解释》第509条（本地核填·现行有效）："多个债权人对执行财产申请参与分配的，执行法院应当制作财产分配方案，并送达各债权人和被执行人。债权人或者被执行人对分配方案有异议的，应当自收到分配方案之日起十五日内向执行法院提出书面异议。"
2. 第510条（本地核填·现行有效）："债权人或者被执行人对分配方案提出书面异议的，执行法院应当通知未提出异议的债权人、被执行人。未提出异议的债权人、被执行人自收到通知之日起十五日内未提出反对意见的，执行法院依异议人的意见对分配方案审查修正后进行分配；提出反对意见的，应当通知异议人。异议人可以自收到通知之日起十五日内，以提出反对意见的债权人、被执行人为被告，向执行法院提起诉讼；异议人逾期未提起诉讼的，执行法院按照原分配方案进行分配。诉讼期间进行分配的，执行法院应当提存与争议债权数额相应的款项。"
3. 第506条（本地核填·现行有效）："被执行人为公民或者其他组织，在执行程序开始后，被执行人的其他已经取得执行依据的债权人发现被执行人的财产不能清偿所有债权的，可以向人民法院申请参与分配。对人民法院查封、扣押、冻结的财产有优先权、担保物权的债权人，可以直接申请参与分配，主张优先受偿权。"
4. 《执行工作规定》（法释〔2020〕21号）第56条（本地核填·现行有效）："对参与被执行人财产的具体分配，应当由首先查封、扣押或冻结的法院主持进行。首先查封、扣押、冻结的法院所采取的执行措施如系为执行财产保全裁定，具体分配应当在该院案件审理终结后进行。"

🔴 被告确定铁律：参与分配异议之诉**以提出反对意见的债权人、被执行人为被告**（解释第510条）——而非以执行法院或其他债权人为被告；被告列错将导致主体不适格。

## 攻防要点

- **攻方（异议人/原告）**：① 严守三条"十五日"期限（异议、起诉各十五日）；② **被告列明**为"提出反对意见的债权人、被执行人"（解释第510条）；③ 就优先权债权人的债权，举证其**债权不实、已受偿或优先权不成立**，动摇其顺位；④ 就参与资格，质疑对方**未取得执行依据**；⑤ 请求**提存**争议款项，防止分配既成事实。
- **防方（反对者/其他债权人）**：① 以异议人**逾期未起诉**（超过十五日）抗辩，主张按**原分配方案**分配；② 以**被告不适格**抗辩；③ 论证己方**优先权/担保物权**合法有效、债权真实；④ 就首封法院主持分配，以执行工作规定第56条维护分配主持权。
- **程序与实体的双层**：异议之诉既审查**程序**（是否逾期、被告适格），也审查**实体**（债权数额、顺位、参与资格），两会合缺一不可。
- **提存的保护功能**：诉讼期间分配时提存争议款项，是防止"先分配、后改判"的救济保障，异议人应主动申请。

## 质证话术模板

- 提起异议之诉："本债权人于×年×月×日收到××号反对意见通知，依《民诉法解释》第510条，于十五日内（×年×月×日）以提出反对意见的债权人××、被执行人××为被告，向执行法院提起诉讼，请求确认本债权在分配方案中的顺位与数额。"
- 参与分配资格异议："××号债权人未提交任何执行依据，依《民诉法解释》第506条不具备参与分配资格，其不应列入本次分配方案，请求对该部分予以修正。"
- 优先权质疑："主张优先受偿的××债权人，其所谓担保物权未经登记/债权已部分受偿，优先权不成立，依《民诉法解释》第506条第二款不应优先受偿，本代理人据此提出分配方案书面异议。"
- 请求提存："本案分配方案异议之诉尚在审理期间，依《民诉法解释》第510条第三款，执行法院分配时应当提存与争议债权数额相应的款项，本代理人请求依法提存，防止争议款项被先行分配。"
- 逾期抗辩（反对者）："异议人自收到反对意见通知之日起已逾十五日未提起诉讼，依《民诉法解释》第510条，执行法院应当按照原分配方案进行分配。"

## 相关笔记

- 参与分配异议走的是"**分配方案异议之诉**"这一**独立诉讼**，而非执行行为异议/复议（R-PR-208）——两者极易混淆：**对分配方案的内容不服 = 异议之诉；对分配行为本身程序违法 = 执行行为异议**。
- 三条"十五日"是本卡的操作核心：**异议十五日 → 未异议人反对十五日 → 异议人起诉十五日**，任一环节逾期，权利即丧失（按原方案分配）。
- **被告列错是最常见的形式错误**：必须以"提出反对意见的债权人、被执行人"为被告，不能以执行法院或全体债权人为被告。
- **提存**是诉讼期间分配的保护阀，异议人务必主动申请，避免"赢了官司输了钱"。
- 与 R-PR-191 分工：191 解决"谁参与、按什么顺序受偿"（实体），本卡解决"对分配方案不服怎么办"（程序救济）。
