# R-PR-206 申请执行与申请执行时效（二年期间·中止中断与时效抗辩）举证证据规则

## 裁判规则（证据规则·正向）

生效法律文书当事人必须履行，一方拒绝履行的，对方当事人**可以向人民法院申请执行，也可以由审判员移送执行员执行**（调解书和其他应由人民法院执行的法律文书同此，民诉法第247条）。**申请执行的期间为二年**，该时效的**中止、中断适用诉讼时效中止、中断的规定**；期间自法律文书规定履行期间的**最后一日起算**，分期履行的自**最后一期履行期限届满之日**起算，未规定履行期间的**自法律文书生效之日**起算（第250条）。**超过申请执行时效期间申请强制执行的，人民法院仍应受理**，但被执行人**提出时效异议**、经审查异议成立的，人民法院**裁定不予执行**；被执行人履行全部或部分义务后，又以不知时效届满为由请求执行回转的，人民法院**不予支持**（解释第481条）。申请恢复执行原生效法律文书适用申请执行期间的规定，且**申请执行期间因达成执行中的和解协议而中断，自和解协议约定履行期限的最后一日起重新计算**（解释第466条）。**终本后申请执行人发现可供执行财产再次申请执行的，不受申请执行时效期间的限制**（解释第517条）；因撤销申请而终结执行后，当事人在申请执行时效期间内再次申请执行的，人民法院应当受理（解释第518条）。

🔴 关键裁判取向：**时效是抗辩事项而非起诉要件**——超期申请法院"应予受理"，不因时效届满而拒绝立案，只有被执行人正式提出异议且审查成立才裁定不予执行。这使时效抗辩成为被执行人的**主动进攻点**，而非法院的依职权审查事项。

## 适用案由与场景

适用于：① 被执行人以申请执行时效届满为由提出执行异议，请求裁定不予执行；② 申请执行人证明时效中断（部分清偿、书面还款承诺、达成和解、有效催收）以延续二年期间；③ 未约定履行期限或分期履行的文书，起算点争议（最后一日起算 versus 生效之日起算）；④ 执行和解后恢复执行时的时效重新计算争议（解释第466条）；⑤ 终本后再次申请执行是否受时效限制（解释第517条）；⑥ 撤销申请终结执行后重新申请的执行。典型：判决生效三年后申请执行，被执行人以时效届满抗辩；申请执行人举证期间内被执行人曾分批支付部分货款并出具还款计划，主张时效中断。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 申请执行本身合法（生效文书、给付内容可执行，第247条） | 申请执行人 | 生效判决书/调解书、履行期届满证明、被执行人未履行证据 |
| **时效未届满**（第250条二年期间未被超越） | 主张时效未届满一方（通常为申请执行人） | 文书生效证明、履行期限届满日、送达回证、终本报告 |
| **时效中断**（中止中断适用诉讼时效规定，第250条） | **主张中断一方（申请执行人）** | 部分清偿凭证、书面还款承诺/对账单、和解协议、催收短信/函件及送达回证、对方主张权利的意思表示证据 |
| 起算点（最后一日/最后一期/生效之日，第250条） | 主张特定起算点一方 | 判决书主文履行期表述、分期付款计划表、未定履行期的文书生效日证明 |
| 时效届满抗辩成立（解释第481条） | **被执行人（异议提出方）** | 申请执行人超期申请的执行案件材料、其二审/执行异议申请书 |
| 被执行人履行后又主张执行回转（第481条末段） | **被执行人**举证已履行 | 履行凭证；**履行后不得再以不知时效为由请求回转**为法院不予支持的判定规则 |
| 终本后再申请不受时效限制（解释第517条） | 申请执行人 | 终本裁定、发现可供执行财产的证明（新财产线索） |
| 撤销申请后时效内再申请应受理（解释第518条） | 申请执行人 | 撤销申请及终结执行裁定、再次申请时间在时效内 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民事诉讼法》（2023修正）第247条（本地核填·现行有效）："发生法律效力的民事判决、裁定，当事人必须履行。一方拒绝履行的，对方当事人可以向人民法院申请执行，也可以由审判员移送执行员执行。调解书和其他应当由人民法院执行的法律文书，当事人必须履行。一方拒绝履行的，对方当事人可以向人民法院申请执行。"
2. 第250条（本地核填·现行有效）："申请执行的期间为二年。申请执行时效的中止、中断，适用法律有关诉讼时效中止、中断的规定。前款规定的期间，从法律文书规定履行期间的最后一日起计算；法律文书规定分期履行的，从最后一期履行期限届满之日起计算；法律文书未规定履行期间的，从法律文书生效之日起计算。"
3. 《民诉法解释》第481条（本地核填·现行有效）："申请执行人超过申请执行时效期间向人民法院申请强制执行的，人民法院应予受理。被执行人对申请执行时效期间提出异议，人民法院经审查异议成立的，裁定不予执行。被执行人履行全部或者部分义务后，又以不知道申请执行时效期间届满为由请求执行回转的，人民法院不予支持。"
4. 第466条（本地核填·现行有效）："申请恢复执行原生效法律文书，适用民事诉讼法第二百四十六条申请执行期间的规定。申请执行期间因达成执行中的和解协议而中断，其期间自和解协议约定履行期限的最后一日起重新计算。"
5. 第515条（本地核填·现行有效）："债权人根据民事诉讼法第二百六十一条规定请求人民法院继续执行的，不受民事诉讼法第二百四十六条条规定申请执行时效期间的限制。"
6. 第517条（本地核填·现行有效）："经过财产调查未发现可供执行的财产，在申请执行人签字确认或者执行法院组成合议庭审查核实并经院长批准后，可以裁定终结本次执行程序。依照前款规定终结执行后，申请执行人发现被执行人有可供执行财产的，可以再次申请执行。再次申请不受申请执行时效期间的限制。"
7. 第518条（本地核填·现行有效）："因撤销申请而终结执行后，当事人在民事诉讼法第二百四十六条规定的申请执行时效期间内再次申请执行的，人民法院应当受理。"

🔴🔴 **条号位移警示（本卡最高价值，切勿按旧号引法）**：上述第466条、第515条、第518条**原文援引"民事诉讼法第二百四十六条"作为申请执行期间条号**，但本地《民事诉讼法》（2023修正）核验结果确认：**第246条实为"人民检察院有权对民事执行活动实行法律监督"（执行检察监督条款）**，申请执行期间条款现位于**第250条**。这是 2021 年修正前后民诉法条文序号位移的结果（旧法第246条=申请执行期间）。因此：
- 引用《民诉法解释》第466/515/518条时，**其所述"申请执行期间"应对应现行《民事诉讼法》第250条**；
- **切勿**直接以"解释第466条对应旧民诉法第246条、与现行第246条（检察监督）对应"作出错误援引；
- 第515条另援引"民事诉讼法第二百六十一条"，该条与现行条号的对应关系尚待官方文本逐条核验，标 statute_text_pending，正式文书中不得直接按旧号引用。
- 本位移现象与 R-PR-198（限高规定第11条援引旧第111条=现行第114条）同构，属执行类条文援引的**高频踩坑点**。

## 攻防要点

- **攻方（被执行人）**：提出**申请执行时效届满异议**（解释第481条），异议审查成立即裁定不予执行——注意必须在执行程序中主动提出，法院不主动审查时效。同时以"超期申请、法院应予受理"的现实倒逼申请执行人补强中断证据。
- **防方（申请执行人）**：① 以第250条"中止中断适用诉讼时效规定"为桥梁，系统提交**中断证据链**（部分清偿、书面承诺、和解协议、有效催收）；② 精细论证起算点（尤其未定期限的自生效之日、分期履行的最后一期）；③ 援引解释第466条，以"达成执行和解致时效中断、自和解约定履行期最后一日起重新计算"重建期间；④ 若案件已终本，援引解释第517条主张**再申请不受时效限制**；⑤ 若曾撤销申请，援引解释第518条主张时效内再申请法院应受理。
- **反制规则（第481条末段）**：被执行人**已履行全部或部分义务后**，又以其不知时效届满为由请求执行回转的，法院不予支持——防止被执行人"先付款、后以时效抗辩"的双重获利。
- **证据时效**：中断证据须能证明"权利人向义务人主张权利"或"义务人同意履行"，单纯的沉默或消极不作为不构成中断。

## 质证话术模板

- 被执行人时效抗辩："申请执行人于×年×月×日才申请强制执行，距法律文书规定履行期届满已逾二年，且本代理人已依《民诉法解释》第481条在本次执行程序中明确提出时效异议，请求审查后裁定不予执行。"
- 申请执行人中断抗辩："被申请执行人在时效期间内于×年×月×日支付部分货款并出具《还款计划》，构成对债务的认可与同意履行，依《民事诉讼法》第250条申请执行时效中断的认定标准，时效应自×年×月×日重新计算，申请执行并未超期。"
- 起算点抗辩："本案判决未约定分期履行，依《民事诉讼法》第250条，未规定履行期间的申请执行期间自法律文书生效之日起算，本代理人以×年×月×日裁判文书生效日为起算点并无不当。"
- 终本后对抗时效："本案已依《民诉法解释》第517条终结本次执行程序，现本代理人的新财产线索显示被执行人名下××房产可供执行，再次申请执行依前条规定**不受申请执行时效期间的限制**，请求依法立案执行。"
- 反制执行回转："被申请执行人在×年×月×日已实际履行部分清偿义务，其后又以不知申请执行时效期间届满为由请求执行回转，依《民诉法解释》第481条末段，其请求不予支持。"

- 申请执行时效是**被执行人最锋利的执行程序反击武器**——它不攻击执行依据的实体效力，却可导致"裁定不予执行"这一程序性终结后果。律师代理申请执行人时，务必在立案前把**时效中断证据链**做扎实：部分清偿凭证、书面还款计划、和解协议、有效催收函件及送达回证，缺一不可。
