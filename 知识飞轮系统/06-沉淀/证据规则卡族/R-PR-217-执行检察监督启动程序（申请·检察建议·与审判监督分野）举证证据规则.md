# R-PR-217 执行检察监督启动程序（申请·检察建议·与审判监督分野）举证证据规则

## 裁判规则（证据规则·正向）

**检察监督是民事诉讼（含执行）的一条法律监督主线**：人民检察院有权对民事诉讼实行法律监督（民诉法第14条），并**有权对民事执行活动实行法律监督**（第246条）。**当事人启动检察监督的通道**（审判监督语境）：有下列情形之一的，当事人可以向人民检察院申请检察建议或者抗诉——①人民法院驳回再审申请；②人民法院逾期未对再审申请作出裁定；③再审判决、裁定有明显错误；人民检察院对当事人的申请应当在**三个月内进行审查**，作出提出或者不予提出的决定，且**当事人不得再次向人民检察院申请检察建议或者抗诉**（第220条）。**调查核实权**：人民检察院因履行法律监督职责提出检察建议或者抗诉的需要，可以向当事人或者案外人**调查核实**有关情况（第221条）。**执行检察监督与审判监督的分野**：审判监督针对**生效判决、裁定、调解书**（第216~224条，抗诉/再审检察建议，导向再审程序）；执行检察监督针对**民事执行活动**（第246条，以**检察建议**为主要形式，督促执行法院纠正违法执行行为），二者监督对象、监督方式、法律后果各不相同。执行检察监督的**具体启动与审查程序**（受理范围、申请材料、审查期限、检察建议的制发与回复）由《人民检察院民事诉讼监督规则》专门规范（本地暂无源，见法条依据段）。

🔴 分野铁律：**审判监督（第216~224条）**针对"裁判错"→ 抗诉/再审检察建议 → 导向**再审**；**执行监督（第246条）**针对"执行乱"→ **检察建议** → 督促执行法院纠正。当事人想把"执行中的违法"塞进第220条的再审通道，属路径错误。

## 适用案由与场景

适用于：① 当事人认为**执行法院的执行行为违法**（如违法查封、超期不执、违法终本、违法分配），向人民检察院申请**执行检察监督**（第246条）；② 检察院在履职中发现执行违法，**依职权**启动监督；③ 当事人混淆**执行监督与审判监督**，误以第220条"当事人申请检察建议或抗诉"的通道处理执行问题；④ 检察院为监督需要**调查核实**有关情况（第221条）；⑤ 与执行行为异议/复议（R-PR-208）的关系与顺序（监督是外部检察监督，异议复议是内部救济）。典型：申请执行人认为执行法院消极执行、长期不采取查控措施，向检察院申请执行监督，检察院经审查向执行法院发出检察建议。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 属**执行监督**范畴（监督对象是执行活动，第246条） | **申请人（当事人）** | 执行案件材料、执行行为违法的证据（查封清单、执行笔录、不予立案通知） |
| 执行行为**违法**的具体事实 | 申请人 | 违法执行的时间、方式、后果证据（超标的查封、超期未执、违法终本等） |
| 已穷尽**内部救济**（异议/复议，衔接 R-PR-208） | 申请人 | 执行异议/复议申请及裁定（是否已用尽内部救济） |
| 检察院**调查核实**的必要性（第221条） | 人民检察院（依职权） | 需核实的事实与证据线索 |
| 属**审判监督**而非执行监督的分流 | 审查方（检察院） | 监督对象是生效裁判还是执行活动 |
| 申请**未重复**（第220条"不得再次申请"的界限） | 申请人/检察院 | 此前申请记录、审查结论 |
| 检察建议的**落实与回复** | 执行法院 | 检察建议书、执行法院纠正/回复材料 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《人民检察院民事诉讼监督规则》本地未收录，执行监督具体程序标注待核填。

1. 《民事诉讼法》（2023修正）第14条（本地核填·现行有效）："人民检察院有权对民事诉讼实行法律监督。"
2. 第246条（本地核填·现行有效）："人民检察院有权对民事执行活动实行法律监督。"
3. 第220条（本地核填·现行有效）："有下列情形之一的，当事人可以向人民检察院申请检察建议或者抗诉：（一）人民法院驳回再审申请的；（二）人民法院逾期未对再审申请作出裁定的；（三）再审判决、裁定有明显错误的。人民检察院对当事人的申请应当在三个月内进行审查，作出提出或者不予提出检察建议或者抗诉的决定。当事人不得再次向人民检察院申请检察建议或者抗诉。"
4. 第221条（本地核填·现行有效）："人民检察院因履行法律监督职责提出检察建议或者抗诉的需要，可以向当事人或者案外人调查核实有关情况。"
5. 《人民检察院民事诉讼监督规则》（高检发释字〔2021〕1号·2021-08-01施行，现行有效，qcc-legal 逐字核填；取代2013年高检发释字〔2013〕3号试行版）第三十条（执行检察监督的受理管辖）："当事人认为民事审判程序中审判人员存在违法行为或者民事执行活动存在违法情形，向人民检察院申请监督的，由审理、执行案件的人民法院所在地同级人民检察院负责控告申诉检察的部门受理。当事人不服上级人民法院作出的复议裁定、决定等，提出监督申请的，由上级人民法院所在地同级人民检察院受理。人民检察院受理后，可以根据需要依照本规则有关规定将案件交由原审理、执行案件的人民法院所在地同级人民检察院办理。"第一百零八条（对执行活动提出检察建议的程序）："人民检察院对执行活动提出检察建议的，应当经检察长或者检察委员会决定，制作《检察建议书》，在决定之日起十五日内将《检察建议书》连同案件卷宗移送同级人民法院，并制作决定提出检察建议的《通知书》，发送当事人。"（申请材料的受理、审查期限、检察建议回复等细则有专章规定，引用前建议以最高人民检察院官网文本复核。）

🔴 注意区分：第220条列举的"当事人可以申请检察建议或者抗诉"三情形，是**审判监督**（针对生效裁判、导向再审）的通道；**执行检察监督**（第246条）以**检察建议**为主要形式、针对**执行活动**，其申请与审查程序不在第220条之内，而由《人民检察院民事诉讼监督规则》规范。援引时不得混用。

## 攻防要点

- **攻方（申请监督的当事人）**：① 锁定**执行活动违法**的具体事实（超标的查封、超期未执、违法终本、违法分配等），与 R-PR-205/213/214 的规则衔接论证违法性；② 厘清**监督类型**——执行问题走执行检察监督（第246条），不要误走第220条的审判监督通道；③ 就调查核实，向检察院提供**可核实的线索**（第221条）；④ 用检察建议督促执行法院纠正，与**内部救济（异议/复议，R-PR-208）**形成内外结合。
- **防方（执行法院/对方当事人）**：① 主张该事项属**审判监督**或应走**内部异议/复议**，不属执行检察监督范围；② 论证执行行为**合法**（依法查封、有正当理由的暂缓等）；③ 主张申请人**已重复申请**或未穷尽内部救济。
- **监督方式**：执行检察监督以**检察建议**为主（督促纠正），不同于审判监督的**抗诉**（导向再审）——主张时须选对监督方式。
- **内外救济的顺序**：执行异议/复议（R-PR-208）是**内部救济**、执行检察监督是**外部监督**，两者可并用，但功能不同（前者直接变更执行裁定，后者督促纠正）。

## 质证话术模板

- 申请执行检察监督："执行法院对本案的执行活动已逾××个月未采取任何查控措施，属消极执行、违法执行，依《民事诉讼法》第246条，本代理人向××人民检察院申请对民事执行活动进行法律监督，请求依法向执行法院提出检察建议。"
- 校正路径（区分监督类型）："本代理人主张的系**执行活动违法**，而非生效裁判错误；依《民事诉讼法》第246条应申请**执行检察监督**，不适用第220条关于当事人申请检察建议或抗诉（审判监督）的规定。"
- 调查核实："为查明执行法院是否存在违法终本，依《民事诉讼法》第221条，恳请人民检察院向执行法院及案外人调查核实财产调查记录与终本审查材料。"
- 内外结合："本案除已依《民事诉讼法》第236条提起执行行为异议、复议（内部救济）外，另依第246条申请执行检察监督（外部监督），两者并行不悖，共同督促纠正违法执行行为。"

- 执行检察监督是律师常忽略的**外部救济通道**：当内部救济（异议/复议，R-PR-208）不畅或执行法院消极执行时，向检察院申请监督往往是打破僵局的现实选择。
- **分野是第一关**：执行问题 → 执行检察监督（第246条，检察建议）；裁判问题 → 审判监督（第216~224条，抗诉/再审检察建议，第220条是当事人申请通道）。**把执行问题塞进第220条是典型路径错误**。
- **监督方式要选对**：执行监督以**检察建议**督促纠正，不是抗诉——不要期待"抗诉+再审"的后果。
