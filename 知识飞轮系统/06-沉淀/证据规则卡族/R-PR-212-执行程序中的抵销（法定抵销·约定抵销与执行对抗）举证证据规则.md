# R-PR-212 执行程序中的抵销（法定抵销·约定抵销与执行对抗）举证证据规则

## 裁判规则（证据规则·正向）

执行程序中被执行人主张抵销，其**实体依据**为法定抵销与约定抵销：**当事人互负债务，该债务的标的物种类、品质相同的，任何一方可以将自己的债务与对方的到期债务抵销**；但根据债务性质、按照当事人约定或者依照法律规定不得抵销的除外；**当事人主张抵销的，应当通知对方，通知自到达对方时生效；抵销不得附条件或者附期限**（民法典第568条）。**当事人互负债务、标的物种类、品质不相同**的，经协商一致，也可以抵销（民法典第569条，约定抵销）。债权转让场景下，债务人接到债权转让通知时对让与人享有债权且该债权**先于转让的债权到期或同时到期**的，可以向受让人主张抵销（民法典第549条第一项）。据此，执行中被执行人以对申请执行人（或债权受让人）享有的**到期债权**主张抵销，须满足"**互负债务 + 标的物种类品质相同 + 对方债务已到期 + 依法可抵销 + 已通知**"五项要件（法定抵销），或"**协商一致**"（约定抵销）。执行法院对抵销主张的审查、抵销对执行标的的冲减效力，及与到期债权执行（R-PR-195）、执行回转（R-PR-194）的衔接，构成执行抵销的程序框架（执行程序专条本地暂无源，见法条依据段）。

🔴 抵销五要件铁律（法定抵销）：**①互负债务 ②标的物种类品质相同 ③主张方债务已到期 ④不存在性质/约定/法定禁止抵销情形 ⑤已通知且通知到达生效**。"已到期"针对的是**对方（被抵销方）的债务**；主张方自己的债务不必已到期（可提前清偿），但被抵销的对方债务必须到期。

## 适用案由与场景

适用于：① 执行中，被执行人对申请执行人另有**生效债权**（如另案胜诉、已确认的到期债权），主张以之抵销执行债务；② 执行债务与被执行人债权**标的物种类、品质相同**（多为金钱债务间抵销）；③ **债权被转让**后，被执行人以对原让与人的到期债权向**受让人**主张抵销（民法典第549条）；④ 被执行人债权**尚未到期**或标的不同类，主张约定抵销（第569条）争议；⑤ 抵销主张与**到期债权执行**（R-PR-195 被执行人对外债权被执行）的交叉；⑥ 抵销后的**执行回转**与利息计算（R-PR-194/199）争议。典型：被执行人持另案生效判决确认的对申请执行人的债权，主张与本案执行债务抵销；或申请执行人已将债权转让，被执行人以对原债权人的到期债权向受让人主张抵销。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| **互负债务**（被执行人享有对申请执行人的债权） | **被执行人（主张抵销方）** | 生效判决/裁定/合同、债权转让凭证、已确认债权的凭据 |
| 债权**已到期**（对方债务到期，第568条） | 被执行人 | 债权到期日证明（判决履行期、合同履行期、催告后合理期限） |
| **标的物种类、品质相同**（第568条要件） | 被执行人 | 债权性质说明（金钱对金钱、种类物对种类物） |
| 不存在**禁止抵销**情形（债务性质/约定/法定，第568条但书） | 主张禁止抵销一方（申请执行人） | 债务具有人身专属性、当事人约定不得抵销、法律规定不得抵销的依据 |
| **抵销通知已到达对方**（第568条第二款） | 被执行人 | 抵销通知及**到达**证明（签收、邮寄回执、数据电文到达记录） |
| 约定抵销的**协商一致**（第569条） | 主张约定抵销方 | 双方达成的抵销合意（协议、往来函件、对账确认） |
| 债权转让中**抵销主张的时点与顺位**（第549条） | 被执行人 | 接到债权转让通知的时间、其债权到期时间与转让债权到期时间的先后 |
| 抵销数额与**执行余额**计算（衔接 R-PR-199） | 主张方 | 债权数额凭证、迟延履行利息计算、抵销后的余额核算 |

## 法条依据（本地核填·现行有效）

> 以下条文中民法典条款为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；执行程序中的抵销专条本地暂无源，标注待核填。

1. 《民法典》第568条（本地核填·现行有效）："当事人互负债务，该债务的标的物种类、品质相同的，任何一方可以将自己的债务与对方的到期债务抵销；但是，根据债务性质、按照当事人约定或者依照法律规定不得抵销的除外。当事人主张抵销的，应当通知对方。通知自到达对方时生效。抵销不得附条件或者附期限。"
2. 第569条（本地核填·现行有效）："当事人互负债务，标的物种类、品质不相同的，经协商一致，也可以抵销。"
3. 第549条（本地核填·现行有效）："有下列情形之一的，债务人可以向受让人主张抵销：（一）债务人接到债权转让通知时，债务人对让与人享有债权，且债务人的债权先于转让的债权到期或者同时到期。"
4. 第553条（本地核填·现行有效，关联）："债务人转移债务的，新债务人可以主张原债务人对债权人的抗辩；原债务人对债权人享有债权的，新债务人不得向债权人主张抵销。"
5. 第702条（本地核填·现行有效，关联）："债务人对债权人享有抵销权或者撤销权的，保证人可以在相应范围内拒绝承担保证责任。"
6. 执行程序中的抵销规则：《民事诉讼法》及《民诉法解释》**未设"执行抵销"专条**；被执行人主张抵销的执行处理（审查主体、主张方式、冲减执行的效力、与到期债权执行的衔接）散见于**司法解释性质文件与裁判规则**（本地法条银行**暂无源，待核填**，statute_text_pending，正式文书引用前须以官方文本/权威裁判核验）。

🔴 法源分层提示：执行抵销是**"实体抵销权 + 执行程序处理"的交叉**——实体要件适用民法典第568/569条，执行程序的处理规则本地暂无专条法源，实务中须结合最高法司法解释性质文件与类案裁判论证，**不得臆造执行抵销的程序条文**。

## 攻防要点

- **攻方（被执行人·主张抵销方）**：① 备齐**五要件证据链**（互负债务、种类品质相同、对方债务到期、无禁止抵销情形、通知到达）；② 以**另案生效裁判**确认的债权最有力（免于实体争议）；③ 严守"**通知到达生效**"——抵销通知须留到达证据（签收/回执/数据电文）；④ 债权被转让时，以第549条主张对受让人的抵销（须证明对让与人债权**先于或同时到期**）。
- **防方（申请执行人）**：① 攻击**债权未到期**（被抵销债权须到期）或**标的不同类**（种类品质不同）；② 主张存在**禁止抵销**情形（人身专属性、约定不得抵销、法定不得抵销）；③ 否认**通知到达**（抵销未生效）；④ 就债权转让，主张被执行人**债权后于转让债权到期**，不符合第549条第一项；⑤ 主张抵销债权的**真实性/确定性不足**（未生效、附条件、数额未定）。
- **程序对抗**：被执行人主张抵销可能需通过**执行异议**提出（因涉及执行数额的确定，属执行行为争议），或另行主张；执行法院对抵销的审查范围与效力是攻防焦点（本地无专条，须以实务规则论证）。
- **与 R-PR-195 衔接**：被执行人对**第三人**的到期债权，属 R-PR-195 代位执行范围；被执行人**对申请执行人本人**的债权，才落入本卡抵销范围——两角度的区分是常见混淆点。

## 质证话术模板

- 抵销主张（被执行人）："被执行人持××号生效判决确认的对申请执行人的到期债权××万元，双方互负金钱债务、种类品质相同、该债权已于×年×月×日到期，且不存在禁止抵销情形；被执行人的抵销通知已于×年×月×日送达申请执行人（附送达回证），依《民法典》第568条抵销已生效，请求以之冲减本案执行债务。"
- 攻击未到期（申请执行人）："被执行人主张抵销的对申请人债权，其履行期至×年×月×日尚未届满，依《民法典》第568条须以'**对方的到期债务**'为抵销对象，该债权尚未到期，不符抵销要件。"
- 攻击通知未到达（申请执行人）："被执行人主张已通知抵销，但未提交通知到达申请执行人的任何证据；依《民法典》第568条'通知自到达对方时生效'，抵销未生效，不得冲减执行。"
- 债权转让中的抵销（被执行人，第549条）："申请执行人已将本案债权转让给××，被执行人于收到转让通知时（×年×月×日）对原债权人××享有已于×年×月×日到期的债权，该债权**先于转让债权到期**，依《民法典》第549条第一项，被执行人可以向受让人主张抵销。"
- 禁止抵销抗辩（申请执行人）："被执行人据以主张抵销的债务系具有人身专属性的××给付义务，依《民法典》第568条但书'根据债务性质不得抵销'，不得主张抵销。"

## 相关笔记

- 执行抵销是**实体抵销权在执行程序中的落地**：法源上"**实体靠民法典、程序靠实务规则**"。民法典第568条五要件是审查基准，程序处理本地暂无专条，须谨慎论证。
- 最容易记混的一点：被执行人**对第三人**的到期债权 → 走**代位执行**（R-PR-195）；被执行人**对申请执行人本人**的债权 → 才谈**抵销**（本卡）。方向搞反，整条主张即告错位。
- **"通知到达生效"**（第568条第二款）是抵销的时间节点，务必固定送达证据；**抵销不得附条件或附期限**，附加条件的抵销通知无效。
- 债权转让场景（第549条）有个隐蔽门槛：被执行人对让与人的债权须**先于或同时于**转让债权到期，否则不得向受让人抵销——代理受让人的债权人时，这一点是绝佳的抗辩支点。
