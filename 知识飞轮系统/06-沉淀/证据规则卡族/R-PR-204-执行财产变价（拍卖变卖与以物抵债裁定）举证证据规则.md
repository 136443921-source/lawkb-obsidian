# R-PR-204 执行财产变价（拍卖、变卖与以物抵债裁定）举证证据规则

## 裁判规则（证据规则·正向）

执行中人民法院可交有关单位或直接变卖被执行人财产，且法院及其工作人员不得买受（解释第488条）；经申请执行人和被执行人同意且不损害其他债权人及公共利益，可不经拍卖、变卖直接作价交申请执行人抵偿债务（第489条）；财产无法拍卖或变卖的，经申请执行人同意可作价交付抵偿或交付管理，申请执行人拒收则退回被执行人（第490条）；拍卖成交或依法定程序裁定以物抵债的，标的物所有权自拍卖成交裁定或抵债裁定送达买受人/接受抵债物的债权人时转移（第491条）；执行标的物为特定物的应执行原物，原物毁损灭失经双方同意折价赔偿，协商不一致则终结执行、申请执行人可另诉（第492条）。本卡聚焦变价程序正当性与所有权转移的举证：拍卖/变卖/抵债是否经法定程序、是否损害其他债权人合法权益、抵债裁定送达与所有权转移时点、特定物毁损后的折价赔偿争议。

## 适用案由与场景

适用于：① 被执行人或其他债权人对"不经拍卖直接抵债"损害其权益提出异议；② 案外人对拍卖/抵债裁定所涉财产主张所有权（衔接执行异议之诉 R-PR-043/187）；③ 抵债裁定送达后所有权转移时点争议（影响第三人取得、另案执行顺位）；④ 特定物原物毁损灭失后的折价赔偿数额争议；⑤ 执行法院及其工作人员违规买受变卖财产的程序违法异议。典型：执行法院未经拍卖、仅依申请执行人与被执行人合意将核心设备作价抵债，后顺位债权人主张未损害其他债权人权益的认定错误，请求撤销抵债；或特定物执行中原物灭失，双方对折价赔偿数额无法协商一致。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 变价程序正当（拍卖/变卖/抵债经法定程序） | 执行法院（程序合法性的依职权证明） | 拍卖公告、评估报告、变卖/抵债合意笔录（第489条需双方同意）、裁定书及送达回证 |
| "不损害其他债权人合法权益和社会公共利益"（第489/490条要件） | 主张抵债/作价交申请执行人的一方 | 债权清单、各债权人受偿情况、无逃债损害证据 |
| 抵债裁定所有权转移时点 | 抵债裁定受领人（债权人/买受人） | 抵债裁定送达回证（第491条，送达时转移） |
| 特定物毁损灭失及折价数额 | 申请执行人（主张折价赔偿） vs 被执行人（异议数额） | 原物灭失鉴定、评估报告、双方协商记录（第492条） |
| 法院/工作人员违规买受 | 异议人（被执行人/其他债权人） | 买受主体证据、身份关联证据（第488条禁止） |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；民诉法关于查封扣押冻结与拍卖变卖的条款本地收录但未逐字核填，标注待核填。

1. 《民诉法解释》第488条（本地核填·现行有效）："人民法院在执行中需要变卖被执行人财产的，可以交有关单位变卖，也可以由人民法院直接变卖。对变卖的财产，人民法院或者其工作人员不得买受。"
2. 第489条（本地核填·现行有效）："经申请执行人和被执行人同意，且不损害其他债权人合法权益和社会公共利益的，人民法院可以不经拍卖、变卖，直接将被执行人的财产作价交申请执行人抵偿债务。对剩余债务，被执行人应当继续清偿。"
3. 第490条（本地核填·现行有效）："被执行人的财产无法拍卖或者变卖的，经申请执行人同意，且不损害其他债权人合法权益和社会公共利益的，人民法院可以将该项财产作价后交付申请执行人抵偿债务，或者交付申请执行人管理；申请执行人拒绝接收或者管理的，退回被执行人。"
4. 第491条（本地核填·现行有效）："拍卖成交或者依法定程序裁定以物抵债的，标的物所有权自拍卖成交裁定或者抵债裁定送达买受人或者接受抵债物的债权人时转移。"
5. 第492条（本地核填·现行有效）："执行标的物为特定物的，应当执行原物。原物确已毁损或者灭失的，经双方当事人同意，可以折价赔偿。双方当事人对折价赔偿不能协商一致的，人民法院应当终结执行程序。申请执行人可以另行起诉。"
6. 《执行工作规定》（法释〔2020〕21号）第43条（本地核填·现行有效）："被执行人的财产经拍卖、变卖或裁定以物抵债后，需从现占有人处交付给买受人或申请执行人的，适用民事诉讼法第二百四十九条、第二百五十条和本规定第41条、第42条的规定。"
7. 《民事诉讼法》关于查封、扣押、冻结与拍卖、变卖的条款（本地法条银行收录，待LTI逐字核填）：变价前置的查封扣押冻结及拍卖变卖一般规则，正式文书引用前须以官方文本二次核对。

🔴 所有权转移铁律：拍卖/抵债裁定**送达时**所有权即转移（第491条），不以过户登记为要件；据此抵债裁定送达后案外人再主张所有权的，须走执行异议之诉（R-PR-043/187）而非否定裁定本身。

## 攻防要点

- **攻方（后顺位债权人/案外人）**：击破第489/490条"不损害其他债权人合法权益"要件——证明抵债作价明显偏低、逃废债、未通知其他债权人；或证明特定物毁损后折价赔偿数额虚高。
- **防方（申请执行人/抵债受领人）**：稳固抵债合意（双方同意笔录）、评估作价公允、已通知其他债权人；以第491条送达时点主张所有权已合法转移，阻断案外人返还请求。
- **特定物规则**：特定物原物毁损灭失的，必须双方同意折价赔偿，否则终结执行、另诉（第492条）；被执行人不得强制以折价替代原物。
- **禁止买受**：法院及其工作人员不得买受变卖财产（第488条），违反构成严重程序违法，可提起执行异议并追责。

## 质证话术模板

- 异议抵债损害权益："执行法院未经拍卖即依双方合意将核心设备作价抵债，作价仅为评估值三成，且未通知本代理人代表的后顺位债权人，明显损害其他债权人合法权益，违反民诉法解释第489条，请求撤销抵债裁定。"
- 主张所有权已转移："抵债裁定已于×年×月×日送达本债权人，依第491条标的物所有权自送达时转移，案外人迟至抵债后始主张所有权，应提起执行异议之诉另行解决，不得否定本裁定效力。"
- 特定物折价争议："执行标的特定物已灭失，双方对折价赔偿数额协商不一致，依第492条应终结执行、申请执行人另诉，被执行人不得单方主张以折价抵充原债务。"
