# R-PR-220 执破融合深化（执转破移送·受理衔接·个别清偿撤销与出资加速）举证证据规则

## 裁判规则（证据规则·正向）

**执破融合的核心命题是：个别执行的"先到先得"与破产程序的"公平清偿"之间如何衔接。** 规则分四层：

**一、启动条件与自愿原则。** 执行中作为被执行人的企业法人符合破产法第2条第1款规定情形（"不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力"）的，执行法院**经申请执行人之一或者被执行人同意**，应当裁定中止对该被执行人的执行，将执行案件相关材料移送被执行人住所地法院（民诉法解释第511条）。**不得推定默示同意、不得依职权移送**（黔高法〔2023〕165号第6条）。

**二、移送期间的保全与处置。** 执行部门决定移送后、破产审判部门裁定受理**之前**，对被执行人的查封、扣押、冻结措施**不解除**；期限届满的由执行部门续行保全（黔高法165号第10条）；移送决定后应**同时中止执行**并通知其他执行法院，涉该被执行人的执行案件均中止（第13条）。

**三、受理后的程序出口。** 被执行人住所地法院裁定**受理**破产案件的，执行法院应当**解除**对被执行人财产的保全措施；裁定**宣告破产**的，执行法院应当裁定**终结**对该被执行人的执行（民诉法解释第513条第1款、黔高法165号第26条：宣告破产/批准重整计划并终止重整程序/认可和解协议并终止和解程序，三者均终结执行）。**不受理**（或驳回申请）的，执行法院应当**恢复**执行（第513条第2款、黔高法165号第21条：七日内恢复执行）；且**不得再次启动执转破**，当事人可直接向有管辖权法院申请破产（黔高法165号第25条）。

**四、实体追及——执行中已实现的清偿可能被"追回"。** 这是执破融合最锋利的一层：破产法第32条规定，人民法院受理破产申请**前六个月内**，债务人有破产法第2条第1款情形，仍对**个别债权人**进行清偿的，**管理人有权请求人民法院予以撤销**（个别清偿使债务人财产受益的除外）；第35条规定，受理破产申请后，债务人的出资人尚未完全履行出资义务的，**管理人应当要求该出资人缴纳所认缴的出资，而不受出资期限的限制**（出资加速到期）。**个别执行中已"落袋"的款项，在破产受理后可能被管理人追回按比例重分。**

🔴 追及铁律：**执转破受理 = 执行成果可能归零重来。** 执行程序中刚拿到的个别清偿（受理前六个月内），若被执行人在彼时已具备破产原因，管理人可依破产法第32条撤销；股东认缴未实缴的出资，管理人可依第35条加速追缴。执行债权人过早"落袋"并非终局安全。

## 适用案由与场景

适用于：① 企业法人作为被执行人**无财产可供执行或财产不足清偿全部债务**，申请执行人或被执行人申请/同意执转破；② 判断被执行人是否符合**执转破四项条件**（企业法人 + 破产原因 + 已穷尽财产调查措施 + 一方申请或同意）（黔高法165号第2条）；③ 判断是否存在**不宜移送情形**（国有独资/控股公司出资人不同意、群体性矛盾、财产去向不明有逃废债可能、涉非法集资等未审结刑案）（第3条）；④ 破产**受理后**，执行法院是否应**解除保全、终结执行**（民诉法解释第513条、黔高法165号第26条）；⑤ 债务人（破产人）在**受理前六个月内的个别清偿**是否可撤销（破产法第32条）；⑥ 受理后**股东出资加速到期**的追缴（破产法第35条）；⑦ 执行费用在破产程序中的**清偿路径**（黔高法165号第24条：评估费、公告费、保管费等可由破产审判部门参照破产费用规定，从债务人财产中随时清偿）。典型：申请执行人在执行中刚收到部分清偿款，三个月后被执行人被受理破产，管理人起诉请求撤销该个别清偿。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 被执行人系**企业法人** | 申请人 | 营业执照、企业类型登记信息 |
| 具备**破产原因**（不能清偿到期债务 + 资不抵债或明显缺乏清偿能力） | 申请人/被执行人 | 财产调查报告、资产负债表、审计报告、终本裁定、多案未清偿记录 |
| 已**穷尽财产调查措施**（执转破第三条件） | 执行部门（依《终本规定》第三条） | 财产查控记录、网络查控反馈、终本审查材料 |
| 有**申请执行人或被执行人同意** | 主张移送方 | 申请书、同意移送笔录（**释明笔录**，不得推定默示同意） |
| 存在**不宜移送情形**（第3条五项） | 反对移送方 | 出资人/国资部门不同意文件、群体性风险材料、财产去向不明线索、涉刑案材料 |
| 破产**受理**事实与时间点 | 主张衔接后果方 | 受理裁定书及送达回证（决定保全解除与执行中止的时点） |
| **宣告破产/批准重整计划/认可和解协议**（终结执行触发事由） | 主张终结方 | 相应裁定书（黔高法165号第26条三种情形） |
| **受理前六个月内的个别清偿**（可撤销） | 🔴 **管理人（主张撤销方）** | 清偿凭证、时间点（受理日回溯六个月）、清偿时已具备破产原因的证据；例外"使债务人财产受益"由被诉方举证 |
| 出资人**未完全履行出资义务**及认缴期限（第35条加速） | 管理人 | 公司章程、认缴与实缴记录、工商登记、出资凭证 |
| 执行费用在破产中的**随时清偿**（黔高法165号第24条） | 主张清偿方 | 评估费、公告费、保管费凭证与发生时间 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《企业破产法》第2条（本地核填·现行有效）："企业法人不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力的，依照本法规定清理债务。企业法人有前款规定情形，或者有明显丧失清偿能力可能的，可以依照本法规定进行重整。"
2. 第7条（本地核填·现行有效）："债务人有本法第二条规定的情形，可以向人民法院提出重整、和解或者破产清算申请。债务人不能清偿到期债务，债权人可以向人民法院提出对债务人进行重整或者破产清算的申请。企业法人已解散但未清算或者未清算完毕，资产不足以清偿债务的，依法负有清算责任的人应当向人民法院申请破产清算。"
3. 第19条（本地核填·现行有效）："人民法院受理破产申请后，有关债务人财产的保全措施应当解除，执行程序应当中止。"
4. 第20条（本地核填·现行有效）："人民法院受理破产申请后，已经开始而尚未终结的有关债务人的民事诉讼或者仲裁应当中止；在管理人接管债务人的财产后，该诉讼或者仲裁继续进行。"
5. 第21条（本地核填·现行有效）："人民法院受理破产申请后，有关债务人的民事诉讼，只能向受理破产申请的人民法院提起。"
6. 第32条（本地核填·现行有效）："人民法院受理破产申请前六个月内，债务人有本法第二条第一款规定的情形，仍对个别债权人进行清偿的，管理人有权请求人民法院予以撤销。但是，个别清偿使债务人财产受益的除外。"
7. 第35条（本地核填·现行有效）："人民法院受理破产申请后，债务人的出资人尚未完全履行出资义务的，管理人应当要求该出资人缴纳所认缴的出资，而不受出资期限的限制。"
8. 《民诉法解释》（2022修正）第511条（本地核填·现行有效）："在执行中，作为被执行人的企业法人符合企业破产法第二条第一款规定情形的，执行法院经申请执行人之一或者被执行人同意，应当裁定中止对该被执行人的执行，将执行案件相关材料移送被执行人住所地人民法院。"
9. 第512条（本地核填·现行有效）："被执行人住所地人民法院应当自收到执行案件相关材料之日起三十日内，将是否受理破产案件的裁定告知执行法院。不予受理的，应当将相关案件材料退回执行法院。"
10. 第513条（本地核填·现行有效）："被执行人住所地人民法院裁定受理破产案件的，执行法院应当解除对被执行人财产的保全措施。被执行人住所地人民法院裁定宣告被执行人破产的，执行法院应当裁定终结对该被执行人的执行。被执行人住所地人民法院不受理破产案件的，执行法院应当恢复执行。"
11. 第514条（本地核填·现行有效）："当事人不同意移送破产或者被执行人住所地人民法院不受理破产案件的，执行法院就执行变价所得财产，在扣除执行费用及清偿优先受偿的债权后，对于普通债权，按照财产保全和执行中查封、扣押、冻结财产的先后顺序清偿。"
12. 《贵州省高级人民法院关于执行案件移送破产审查工作指引》（黔高法〔2023〕165号·2023-10-12施行）第2条（本地核填·现行有效）："执行案件移送破产审查，应当同时符合下列条件：（一）被执行人是企业法人；（二）被执行人不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力；（三）符合《最高人民法院关于严格规范终结本次执行程序的规定（试行）》第三条规定的执行中已穷尽财产调查措施；（四）被执行人任一执行案件的申请执行人向执行部门申请或者经征询意见后同意移送的。"
13. 第3条（本地核填·现行有效）："执行案件有下列情形之一的，不宜启动移送破产审查程序：（一）被执行人是国有独资公司或国有控股公司，出资人或国有资产监督管理部门不同意移送破产审查的；（二）案件存在群体性矛盾等重大风险及不稳定因素；（三）仅有被执行企业一方同意移送破产审查，但其财产去向不明，有通过破产程序故意逃废债可能的；（四）被执行人存在涉嫌非法集资、非法吸收公众存款等未审结的刑事犯罪案件的；（五）其他不宜移送破产审查的情形。"
14. 第10条（本地核填·现行有效）："执行部门决定移送后，在破产审判部门裁定受理破产案件之前，对被执行人的查封、扣押、冻结措施不解除。查封、扣押、冻结期限在破产审查期间届满的，由执行部门负责办理续行保全措施。"
15. 第13条（本地核填·现行有效）："执行部门作出移送决定后，应当同时中止对被执行人的执行，并于作出决定之日起十日内书面通知已知其他执行法院，涉被执行人的执行案件均应中止执行。但同一执行案件中其他被执行人的执行不因此一并中止。"
16. 第21条（本地核填·现行有效）："不予受理或驳回申请的裁定生效后，破产审判部门应于五日内将裁定书送交执行部门，并将案件材料一并退回。执行部门应当在收到不予受理破产申请或驳回破产申请裁定后七日内，恢复对被执行人的执行。"
17. 第24条（本地核填·现行有效）："在此前的执行程序中产生的评估费、公告费、保管费等执行费用，可以由破产审判部门参照破产费用的规定，从债务人财产中随时清偿。"
18. 第25条（本地核填·现行有效）："对于裁定不予受理或者驳回申请的，人民法院均不得再次启动执行移送破产审查程序。申请执行人或被执行人以有新证据足以证明被执行人具备破产原因为由，再次要求将执行案件移送破产审查的，人民法院不予支持，可告知申请执行人或者被执行人直接向有管辖权的人民法院申请破产。"
19. 第26条（本地核填·现行有效）："有下列情形之一的，破产审判部门应当在裁定作出之日起五日内，将相关法律文书送交执行部门，执行部门应当裁定终结对该被执行人的执行程序：（一）裁定宣告破产的；（二）裁定批准重整计划并终止重整程序的；（三）裁定认可和解协议并终止和解程序的。"

🔴 层级提示：民诉法解释第511~514条是**全国通行**的执转破规则；黔高法〔2023〕165号是**贵州地方**的操作细则（条件、不宜移送情形、期限、材料、衔接），在贵州法院办案时**两者并引**，地方指引补充期限与材料细节。

## 攻防要点

- **攻方（申请执转破方）**：① 逐条对表**四项条件**（企业法人／破产原因／已穷尽财产调查／一方同意），缺一即被驳回（黔高法165号第2条）；② 用**终本裁定 + 财产调查报告**证明"已穷尽财产调查措施"；③ 移送前核查**五项不宜移送情形**，避免白移（第3条）；④ 紧盯**移送期间保全不解除**（第10条），防止财产脱保；⑤ 破产受理后主动配合**移交财产**（第22条），主张执行费用**随时清偿**（第24条）。
- **防方（被执行人/个别债权人）**：① 主张不符合**破产原因**或**无一方同意**（不得推定默示同意）；② 举出**不宜移送情形**（国资不同意、群体性风险、涉刑案）阻断移送；③ 就**受理前六个月的个别清偿**（破产法第32条），主张属"**使债务人财产受益**"的例外，或清偿时**不具备破产原因**；④ 就**出资加速**（第35条），主张已完全履行出资或认缴期限未至（但第35条明确"不受出资期限限制"）。
- **个别债权人的时间窗风险**：在债务人已有破产原因时受领个别清偿，若在**受理前六个月内**，随时可能被管理人撤销。受领前宜核查债务人是否已涉多案未清偿。
- **股东的双重暴露**：企业破产时，股东既可能被**执转破前的追加**（R-PR-219）追上，也可能被破产管理人**加速追缴出资**（破产法第35条）——两条路径独立存在。

## 质证话术模板

- 申请执转破"被执行人××公司系企业法人，因不能清偿到期债务且资产不足以清偿全部债务，经执行程序已穷尽财产调查措施（见终本审查材料），申请执行人××同意移送破产审查。依《民诉法解释》第511条，恳请裁定中止执行并移送被执行人住所地人民法院审查。"
- 移送期间保全"依《贵州省高级人民法院关于执行案件移送破产审查工作指引》第10条，移送后至受理前，对被执行人的查封、扣押、冻结措施不解除；本申请人申请续行对××财产（即将到期）的查封措施。"
- 受理后终结执行"被执行人住所地法院已裁定宣告破产，依《民诉法解释》第513条第1款及黔高法〔2023〕165号第26条，执行法院应当裁定终结对本被执行人的执行程序，解除对被执行人财产的保全措施。"
- 管理人撤销个别清偿（破产受理后）"债务人××公司在人民法院受理破产申请前六个月内，已具备《企业破产法》第2条第1款规定的破产原因，仍向个别债权人××清偿××元，依《企业破产法》第32条，管理人有权请求撤销该个别清偿。"
- 出资加速到期"依《企业破产法》第35条，人民法院受理破产申请后，出资人尚未完全履行出资义务的，管理人应当要求其缴纳所认缴的出资，而不受出资期限的限制。"

## 相关笔记

- **执破融合的"两面刃"**：对申请执行人而言，执转破既是**打破执行僵局**的出口（把无财产的僵尸企业推进破产，借助管理人追出资、撤销个别清偿），也是**风险**——自己刚拿到的个别清偿可能被追回（破产法第32条）。启动前必须做一次"自己的清偿是否在风险时间窗内"的自查。
- **"同意"是硬门槛**：民诉法解释第511条要求"经申请执行人之一或者被执行人同意"，黔高法165号第6条更明确"**不得推定默示同意，也不得依职权移送**"。释明笔录是必备证据。
- **两段时间轴的记忆法**：**受理前六个月**→ 个别清偿可撤销（第32条）；**受理后**→ 保全解除、执行中止、出资加速（第19、35条）。记牢这两条时间轴，执破融合的大半规则就通了。
- 🔴 **地方指引是贵州办案的加分项**：黔高法〔2023〕165号把移送条件、不宜移送情形、材料清单、期限、衔接流程写得非常具体（如第15条六项材料、第19条三十日审查期、第21条七日内恢复执行），贵州境内办案援引地方指引能显著提升说服力。
