# R-PR-314 不能单独作为定案根据的证据（第90条）

## 裁判规则（证据规则·正向）

第90条：下列证据不能单独作为认定案件事实的根据——（一）当事人的陈述；（二）无民事行为能力人或者限制民事行为能力人所作的与其年龄、智力状况或者精神健康状况不相当的证言；（三）与一方当事人或者其代理人有利害关系的证人陈述的证言；（四）存有疑点的视听资料、电子数据；（五）无法与原件、原物核对的复制件、复制品。即该五类证据须有其他证据补强、形成印证，方可作为定案根据。

## 适用案由与场景

全部案件通用。对方仅凭「当事人陈述」或「疑点录音/微信」或「无法核对的复制件」主张事实的，依第90条要求补强。吊顶6658（对方疑点录音须补强）、雅菲6660（复制件买卖合同须核对原件）、面瘫医疗案（利害相关证人证言须补强）。

## 举证责任分配

- 主张方：提供第90条五类证据的，须另行提供补强证据形成印证，否则事实不予认定。
- 对方：可主张对方证据落入第90条须补强，孤立证据不能定案。
- 法院：审查是否补强充分，未补强则不予单独认定。

**第九十条**　下列证据不能单独作为认定案件事实的根据：（一）当事人的陈述；（二）无民事行为能力人或者限制民事行为能力人所作的与其年龄、智力状况或者精神健康状况不相当的证言；（三）与一方当事人或者其代理人有利害关系的证人陈述的证言；（四）存有疑点的视听资料、电子数据；（五）无法与原件、原物核对的复制件、复制品。

## 攻防要点

- 第90条是「补强规则」武器：孤立的当事人陈述 / 疑点视听 / 无法核对复制件，单独不足定案。
- 与 R-PR-186（瑕疵证据补强）衔接：第90条是「不能单独定案」的法定清单，R-PR-186 是体系化补强规则——双卡互引。
- 与 R-PR-249（单一证据审核）/ R-PR-250（全案综合审查）联动：补强须达「印证」程度。
- 实务：对方提交无法与原件核对的合同复制件，直接引第90条并要求核对原件（衔接 R-PR-225、R-PR-253）。

## 质证话术模板（庭上可直接念）

【破孤证】"对方仅以无法与原件核对的复制件 / 疑点录音主张XX事实，依第90条不能单独作为定案根据，请贵院要求其补强，否则不予认定。"

【补强】"我方当事人陈述 / 视听资料虽属第90条情形，但已与XX书证、证人证言形成印证，补强充分，应予认定。"
