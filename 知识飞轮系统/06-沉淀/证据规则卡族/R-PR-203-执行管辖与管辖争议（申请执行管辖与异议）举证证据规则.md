# R-PR-203 执行管辖与管辖争议（申请执行管辖与异议）举证证据规则

## 裁判规则（证据规则·正向）

生效民事判决、裁定及刑事判决、裁定中的财产部分，由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行；法律规定由人民法院执行的其他法律文书，由被执行人住所地或者被执行的财产所在地人民法院执行（民诉法第235条）。本卡聚焦申请执行管辖连接点的举证：申请人须证明管辖连接点（一审法院、财产所在地、被执行人住所地）存在于受诉执行法院辖区内；被执行人提出管辖权异议的，须证明被申请财产不在该院辖区且非一审法院同级法院，或被执行人住所地不在该院辖区。管辖争议本质是对"连接点证据"的攻防，而非实体权利义务争议。

## 适用案由与场景

适用于：① 申请执行人向特定执行法院申请执行，该法院对"财产所在地/被执行人住所地"连接点的认定争议；② 被执行人提出执行管辖权异议，主张受诉法院无管辖权；③ 多个 possible 管辖法院竞合时申请人选择管辖的策略；④ 财产所在地发生位移（诉讼中查封地≠申请执行时所在地）导致的管辖连接点争议；⑤ 公证债权文书、仲裁裁决等"其他法律文书"由被执行人住所地或财产所在地法院执行的连接点证明。典型：被执行财产位于A地、被执行人住所地在B地，申请人向A地法院申请执行，被执行人异议称主要财产已转移至C地、A地仅余零星财产不足以执行，主张A地法院无管辖权。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 执行法院具有管辖连接点 | 申请执行人（立案阶段） | 一审法院裁判文书（一审管辖）、财产所在地证明（不动产登记、账户开户行、车辆登记地）、被执行人住所地证明（户籍/工商登记） |
| 管辖权异议成立（无连接点） | 异议人（被执行人） | 证明被申请财产不在受诉法院辖区且非一审法院同级、或被执行人住所地不在辖区的证据（财产现状查证、工商变更） |
| "财产所在地"动态连接点 | 双方 | 查封/冻结裁定载明的财产所在地、执行中财产尽调结果、财产转移轨迹 |
| 其他法律文书的执行连接点 | 申请执行人 | 仲裁裁决/公证债权文书 + 被执行人住所地或财产所在地证明 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；民诉法解释关于执行管辖的细化条款本地收录但未逐字核填，标注待核填。

1. 《中华人民共和国民事诉讼法》第235条（本地核填·现行有效，民诉法2023）："发生法律效力的民事判决、裁定，以及刑事判决、裁定中的财产部分，由第一审人民法院或者与第一审人民法院同级的被执行的财产所在地人民法院执行。法律规定由人民法院执行的其他法律文书，由被执行人住所地或者被执行的财产所在地人民法院执行。"
2. 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》关于执行管辖的细化条款（本地法条银行收录，待LTI逐字核填）：对"被执行的财产所在地""被执行人的住所地"认定标准及管辖权异议处理程序的细化，正式文书引用前须以官方文本二次核对。

🔴 连接点铁律：民事判决/裁定 → 一审法院 或 同级财产所在地法院二选一；其他法律文书（仲裁/公证）→ 被执行人住所地 或 财产所在地二选一。申请人只需证明任一连接点存在即确立管辖，无需全部具备。

## 攻防要点

- **攻方（申请执行人）**：稳固单一连接点证据即可。优先以"财产所在地"确立管辖（便于控制财产），备齐不动产登记、账户信息、车辆登记等客观证据；若财产所在地薄弱，退守"一审法院同级法院"或"被执行人住所地"。
- **防方（被执行人）**：管辖权异议须精准击破连接点——证明受诉法院辖区既非一审法院同级、亦无可供执行财产（零星财产不触发管辖）、被执行人住所地亦不在此。单纯"主要财产在异地"不足以排除管辖，须证明受诉辖区无财产。
- **策略提示**：管辖异议不得涉及实体抗辩；以管辖异议拖延执行须防范被认定滥用程序（可能承担迟延履行利息 R-PR-199）。

## 质证话术模板

- 确立管辖："据民诉法第235条，生效判决由与第一审人民法院同级的被执行人财产所在地人民法院执行。本代理人已提交不动产登记簿载明被执行房产位于贵院辖区，贵院依法具有执行管辖权。"
- 异议反驳："被执行人异议称财产已转移，但仅提交其单方陈述，未提交任何财产现状查证或变更登记证据；其住所地在贵院辖区工商登记未变，异议不能成立。"
- 提异议："被申请执行的机器设备实际存放于×市×区，不在贵院辖区；被执行人住所地亦在×市，贵院既非财产所在地亦非住所地法院，依第235条提出管辖权异议，请求移送有管辖权法院。"
