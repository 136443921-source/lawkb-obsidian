# R-PR-210 财产保全与执行衔接（保转执·解除与优先顺位）举证证据规则

## 裁判规则（证据规则·正向）

财产保全的一般规则：人民法院可依申请（必要时依职权）对当事人财产裁定保全、责令或禁止一定行为（民诉法第103条）；**保全限于请求的范围，或者与本案有关的财物**（第105条）；财产保全采**查封、扣押、冻结**或法律规定的其他方法，**保全财产后应当立即通知被保全财产的人**（第106条）；财产纠纷案件**被申请人提供担保**的，应当裁定解除保全（第107条）；**申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失**（第108条）；当事人对保全或先予执行裁定不服的，可以**申请复议一次**，复议期间不停止裁定执行（第111条）。衔接规则：保全的方法和措施**依照执行程序相关规定办理**（解释第156条）；**法律文书生效后、进入执行程序前**，债权人因对方转移财产等紧急情况可**向执行法院申请保全**，但债权人在履行期间届满后**五日内不申请执行的，应当解除保全**（解释第163条）；**保全裁定未经依法撤销或解除，进入执行程序后自动转为执行中的查封、扣押、冻结措施，期限连续计算**，无需重制裁定（解释第168条）；出现保全错误、撤回申请、诉请被生效裁判驳回等情形，应作出**解除保全裁定**，解除以登记方式实施的保全须向登记机关发协助执行通知书（解释第166条）；被保全人提供**其他等值担保财产**且有利于执行的，可裁定**变更保全标的物**（解释第167条）；被执行人住所地法院裁定**受理破产案件**的，执行法院应当**解除**对被执行人财产的保全措施（解释第513条）。

🔴 保转执核心：**保全与执行是同一控制链条的两端**——保全裁定进入执行后自动转为执行查封、期限连续计算（解释第168条），其**查封顺位**依解释第514条直接影响普通债权参与分配的受偿次序（衔接 R-PR-205）。

## 适用案由与场景

适用于：① 生效裁判作出后、申请执行前的"**空窗期**"，债权人申请保全及后续解除争议（解释第163条五日期限）；② 诉中/诉前保全进入执行程序后**自动转查封、期限连续计算**的认定（解释第168条）；③ 被保全人提供**等值担保**请求解除或变更保全标的物（民诉法第107条、解释第167条）；④ 保全错误致损的**赔偿**争议（民诉法第108条）；⑤ 被执行人被**受理破产**后执行法院解除保全、终结/恢复执行的衔接（解释第513条，衔接 R-PR-202）；⑥ 保全**顺位**与其他债权人的执行查封冲突（解释第514条，衔接 R-PR-205/191）。典型：判决生效后债权人未在五日内申请执行，被保全人主张应解除保全；或保全转执行后，轮候查封债权人主张首封顺位。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 保全必要性/紧急性（民诉法第103条） | **保全申请人** | 对方转移财产的证据、财产线索、情况紧急的证明 |
| 保全范围未超请求范围（第105条） | 保全申请人 | 诉讼请求金额、保全财产清单与估值 |
| 保全方法合法且已通知（第106条） | 法院（程序合法性）；被保全人可举证未通知 | 查封裁定、协助执行通知书、通知送达回证 |
| 保全后未在五日内申请执行应解除（解释第163条） | **被保全人（主张解除方）** | 生效文书送达日、履行期届满日、申请执行时间（倒推五日） |
| 保全自动转执行、期限连续（解释第168条） | 主张连续计算一方（多为首封/在先保全债权人） | 保全裁定及其未被撤销/解除的证明、进入执行程序时间 |
| 解除保全事由成就（解释第166条） | **主张解除方** | 保全错误证明、撤回申请凭证、驳回起诉/诉请的生效裁判 |
| 变更保全标的物（等值担保，解释第167条） | **被保全人（申请变更方）** | 提供的担保财产权属与估值资料、有利执行的说明 |
| 保全错误赔偿责任（民诉法第108条） | **被申请人（主张赔偿方）** | 保全错误的生效认定、因保全所遭受损失及因果关系的证据 |
| 破产受理解除保全（解释第513条） | 主张解除一方 / 法院 | 受理破产案件裁定书、宣告破产裁定 |
| 保全/执行**顺位**（解释第514条） | 主张优先顺位一方 | 各保全/查封的时间顺序材料、首封法院与立案时间 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民事诉讼法》（2023修正）第103条（本地核填·现行有效）："人民法院对于可能因当事人一方的行为或者其他原因，使判决难以执行或者造成当事人其他损害的案件，根据对方当事人的申请，可以裁定对其财产进行保全、责令其作出一定行为或者禁止其作出一定行为；当事人没有提出申请的，人民法院在必要时也可以裁定采取保全措施。"
2. 第105条（本地核填·现行有效）："保全限于请求的范围，或者与本案有关的财物。"
3. 第106条（本地核填·现行有效）："财产保全采取查封、扣押、冻结或者法律规定的其他方法。人民法院保全财产后，应当立即通知被保全财产的人。"
4. 第107条（本地核填·现行有效）："财产纠纷案件，被申请人提供担保的，人民法院应当裁定解除保全。"
5. 第108条（本地核填·现行有效）："申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失。"
6. 第111条（本地核填·现行有效）："当事人对保全或者先予执行的裁定不服的，可以申请复议一次。复议期间不停止裁定的执行。"
7. 《民诉法解释》第156条（本地核填·现行有效）："人民法院采取财产保全的方法和措施，依照执行程序相关规定办理。"
8. 第163条（本地核填·现行有效）："法律文书生效后，进入执行程序前，债权人因对方当事人转移财产等紧急情况，不申请保全将可能导致生效法律文书不能执行或者难以执行的，可以向执行法院申请采取保全措施。债权人在法律文书指定的履行期间届满后五日内不申请执行的，人民法院应当解除保全。"
9. 第166条（本地核填·现行有效）："裁定采取保全措施后，有下列情形之一的，人民法院应当作出解除保全裁定：（一）保全错误的；（二）申请人撤回保全申请的；（三）申请人的起诉或者诉讼请求被生效裁判驳回的；（四）人民法院认为应当解除保全的其他情形。解除以登记方式实施的保全措施的，应当向登记机关发出协助执行通知书。"
10. 第167条（本地核填·现行有效）："财产保全的被保全人提供其他等值担保财产且有利于执行的，人民法院可以裁定变更保全标的物为被保全人提供的担保财产。"
11. 第168条（本地核填·现行有效）："保全裁定未经人民法院依法撤销或者解除，进入执行程序后，自动转为执行中的查封、扣押、冻结措施，期限连续计算，执行法院无需重新制作裁定书，但查封、扣押、冻结期限届满的除外。"
12. 第513条（本地核填·现行有效）："被执行人住所地人民法院裁定受理破产案件的，执行法院应当解除对被执行人财产的保全措施。被执行人住所地人民法院裁定宣告被执行人破产的，执行法院应当裁定终结对该被执行人的执行。被执行人住所地人民法院不受理破产案件的，执行法院应当恢复执行。"

🔴 五日期限铁律："**法律文书生效后、进入执行程序前**"的保全（解释第163条），债权人须在**履行期间届满后五日内申请执行**，否则法院**应当解除保全**——这是保转执衔接中最易踩空的时间窗口。

## 攻防要点

- **攻方（被保全人/被执行人）**：① 以解释第163条"**五日内未申请执行应解除保全**"击破空窗期保全；② 以民诉法第107条/解释第167条提供**等值担保**请求解除或变更保全标的物；③ 以民诉法第108条主张保全错误赔偿；④ 以解释第166条主张诉请被驳回、保全错误等解除事由；⑤ 破产受理后依解释第513条请求解除保全。
- **防方（保全申请人/申请执行人）**：① 严守解释第163条**五日期限**，生效后及时申请执行，实现保全无缝转执行；② 以解释第168条主张保全**自动转查封、期限连续计算**，保住顺位；③ 以民诉法第105条论证保全**未超请求范围**；④ 对等值担保请求，审查担保财产是否**真实等值且有利于执行**。
- **顺位争夺**：解释第168条（保全转查封）+ 第514条（按保全与查封先后清偿）是保全债权人守住**首封利益**的法律链条，与 R-PR-205 的查封顺位规则联动。
- **赔偿风险**：民诉法第108条保全错误赔偿是悬在申请人头上的责任——保全申请须**审慎**，财产线索须**核实**。

## 质证话术模板

- 五日期限抗辩（被保全人）："本案生效判决指定的履行期间于×年×月×日届满，保全申请人迟至×年×月×日才申请执行，已超过《民诉法解释》第163条规定的五日，人民法院应当解除保全。"
- 保转执抗辩（申请执行人）："本案保全裁定于×年×月×日作出，未经撤销或解除，依《民诉法解释》第168条，进入执行程序后自动转为执行中的查封措施、期限连续计算，本债权人的查封顺位不受影响。"
- 等值担保解除（被保全人）："本被保全人提供名下××房产（评估价××元）作为其他等值担保财产，且该财产便于执行（已登记、无其他权利负担），依《民事诉讼法》第107条及《民诉法解释》第167条，请求裁定变更保全标的物、解除对原财产的保全。"
- 保全错误赔偿（被申请人）："保全申请人在无事实依据的情况下申请冻结本人经营账户，致本人×万元订单损失，经××生效裁判认定保全错误，依《民事诉讼法》第108条请求赔偿。"
- 破产受理解除（执行法院/被执行人）："被执行人住所地××法院已于×年×月×日裁定受理其破产案件，依《民诉法解释》第513条，执行法院应当解除对其财产的保全措施。"

## 相关笔记

- 财产保全与执行是**前后衔接的同一控制体系**：保全的目的一是防止转移财产、二是**提前锁定顺位**。解释第168条的"自动转查封、期限连续计算"与第514条的"按保全与查封先后清偿"合起来，构成保全债权人守住受偿优势的法律链条。
- **解释第163条的五日窗口**是本卡最实用也最易踩空的规则：法律文书生效后、进入执行程序前的保全，若债权人拖过履行期届满后五日才申请执行，保全会**被解除**——一把到手的顺位就此丢失。
- 保全错误赔偿（民诉法第108条）是双刃剑：申请人须核实财产线索、评估保全必要性；防范滥用保全损害被保全人利益。
- 与 R-PR-202 联动：被执行人进入破产后，保全须**解除**（解释第513条），单独突进执行不再是选项（"先下手为强"的查封优势在破产程序中被冻结）。
