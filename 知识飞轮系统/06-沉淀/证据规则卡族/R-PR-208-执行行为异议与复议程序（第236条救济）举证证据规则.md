# R-PR-208 执行行为异议与复议程序（第236条救济）举证证据规则

## 裁判规则（证据规则·正向）

当事人、利害关系人认为**执行行为违反法律规定**的，可以向负责执行的人民法院提出**书面异议**；人民法院应当自收到书面异议之日起**十五日内审查**，理由成立的裁定撤销或者改正，理由不成立的裁定驳回（民诉法第236条前段）。**当事人、利害关系人对异议裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议**（第236条后段）。据此形成"**书面异议（执行法院一审）→ 复议（上一级法院二审）**"的两级救济结构。反面界限：人民法院依民诉法第二百四十四条第二款、第三款规定裁定**不予执行仲裁裁决后，当事人对该裁定提出执行异议或者复议的，人民法院不予受理**（解释第476条）——即不予执行仲裁裁决裁定属法定不可异议、不可复议事项。另，被执行人通过仲裁程序将查封、扣押、冻结财产确权或分割给案外人的，不影响执行程序进行，**案外人不服的，可以根据民事诉讼法第二百三十四条规定提出异议**（解释第477条），据此通往执行异议之诉而非本条复议。本卡聚焦**复议阶段**的举证与审查：异议事由的举证责任、复议申请期限（十日）、复议审查范围（对执行行为合法性，非重新审理实体权属）。

## 适用案由与场景

适用于：① 当事人/利害关系人认为查封、扣押、冻结、拍卖、变价、分配等**执行行为违法**，提出书面异议后被驳回，进而向上一级法院申请复议；② 异议事由为执行法院超标的查封、未依法续行查封、未通知到场、违法分配执行款等程序违法情形（衔接 R-PR-205）；③ 对不予执行仲裁裁决裁定不服者被裁定不予受理的界限识别（解释第476条，防止误走异议/复议通道）；④ 案外人对执行标的提出异议（标的异议）与执行行为异议（行为异议）的**分流判断**（衔接 R-PR-193）。典型：被执行人对执行法院未依法保留生活必需品、超标的查封提出书面异议被驳回，向上一级法院申请复议；债权人认为执行法院分配顺序错误提起行为异议复议。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 执行行为"违反法律规定"（第236条要件） | **异议人（当事人/利害关系人）** | 执行裁定/通知/清单、查封时间与财产清单、送达回证、执行笔录，用以证明行为违法的客观事实 |
| 异议提出时限与形式（书面、主体适格） | 异议人 | 书面异议原件、递交时间凭证、主体身份证明（当事人或利害关系人） |
| **复议申请在十日期限内**（第236条后段） | **复议申请人** | 异议裁定送达回证、复议申请书及递交凭证（倒推十日） |
| 异议事由属"执行行为"而非"执行标的权属"（分流） | 提起方 | 异议指向的是程序行为（查封/变价/分配）还是标的物权属；指向权属应走第234条（衔接 R-PR-193） |
| 不予执行仲裁裁决裁定不得异议复议（解释第476条） | 法院依职权识别 | 原裁定性质（不予执行仲裁裁决裁定）、原法条依据（第244条二、三款） |
| 复议审查范围（合法性审查，不涉实体重新审理） | 上一级法院依职权 | 原执行案卷、异议审查记录、复议申请人提交的合法性证据 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《复议规定》本地暂无源，复议程序细化规则标注待核填。

1. 《民事诉讼法》（2023修正）第236条（本地核填·现行有效）："当事人、利害关系人认为执行行为违反法律规定的，可以向负责执行的人民法院提出书面异议。当事人、利害关系人提出书面异议的，人民法院应当自收到书面异议之日起十五日内审查，理由成立的，裁定撤销或者改正；理由不成立的，裁定驳回。当事人、利害关系人对裁定不服的，可以自裁定送达之日起十日内向上一级人民法院申请复议。"
2. 《民诉法解释》第476条（本地核填·现行有效）："依照民事诉讼法第二百四十四条第二款、第三款规定，人民法院裁定不予执行仲裁裁决后，当事人对该裁定提出执行异议或者复议的，人民法院不予受理。当事人可以就该民事纠纷重新达成书面仲裁协议申请仲裁，也可以向人民法院起诉。"
3. 第477条（本地核填·现行有效）："在执行中，被执行人通过仲裁程序将人民法院查封、扣押、冻结的财产确权或者分割给案外人的，不影响人民法院执行程序的进行。案外人不服的，可以根据民事诉讼法第二百三十四条规定提出异议。"
4. 《最高人民法院关于人民法院办理执行异议和复议案件若干问题的规定》（法释〔2015〕10号·2020修正）：异议审查标准、复议受理与审查程序、复议期限与裁定效力等（本地法条银行**暂无源，待补建**，statute_text_pending，正式文书引用前须以官方文本核验）。

🔴 两级救济铁律：**执行行为违法 → 书面异议（执行法院，15 日审查）→ 复议（上一级法院，10 日期限）**。复议期限自异议裁定**送达之日起十日**，逾期即失权；且复议只审查执行行为合法性，不重新审理标的物权属（权属争议走第234条执行异议之诉）。

## 攻防要点

- **攻方（异议人/复议申请人）**：① 精准锁定"执行行为违法"的**具体程序节点**（超标的查封、未续封、未通知到场、分配顺序错误等），配合 R-PR-205 的期限与顺位规则举证；② 严守**十日复议期限**（自异议裁定送达起算），并留存复议申请书递交凭证；③ 注意分流——如指向**执行标的权属**，应走第234条（衔接 R-PR-193），误走复议将被驳回。
- **防方（申请执行人/对方）**：① 以"异议指向的是实体权属争议、非执行行为违法"抗辩，主张应走执行异议之诉而非异议/复议；② 以复议申请**超十日**抗辩失权；③ 对不予执行仲裁裁决裁定，援引解释第476条主张异议/复议不予受理（程序封闭）；④ 论证执行行为符合查封期限、顺位、通知等法定要求。
- **程序辨析**：区分三类——**行为异议**（第236条，执行行为违法→异议+复议）、**标的异议**（第234条，执行标的权属→异议+执行异议之诉）、**许可执行之诉**（申请执行人对中止裁定）。错走通道将导致程序性驳回。
- **举证重心**：复议阶段以"执行行为违法的客观证据"为核心（程序性证据为主），而非实体权利证据。

## 质证话术模板

- 复议申请（期限）："本代理人于×年×月×日收到××号执行异议裁定，依《民事诉讼法》第236条应于裁定送达之日起十日内申请复议，本代理人于×年×月×日依法向××中级人民法院提交复议申请书（附送达回证及递交凭证），复议申请未逾期。"
- 击破执行行为违法："执行法院查封的××财产评估价远超本案债权及迟延履行利息总额，违反《民事诉讼法》第253条'不得超出被执行人应当履行义务的范围'，属执行行为违法，请求上一级法院复议后撤销超额查封。"
- 程序分流抗辩（对方误走复议）："异议人所主张的系对执行标的××房屋的**实体权属**争议，并非执行行为违法，依《民事诉讼法》第234条应通过执行异议之诉解决，其执行行为异议及复议申请不属本案审查范围。"
- 不予执行裁定界限（解释第476条）："原裁定系依《民事诉讼法》第244条第二、三款作出的不予执行仲裁裁决裁定，依《民诉法解释》第476条，当事人对该裁定提出执行异议或复议的，人民法院不予受理，本复议申请缺乏程序基础。"
- 复议审查范围限定："复议程序仅审查执行行为的合法性，不重新审理执行标的权属；复议申请人以'其对标的物享有所有权'为由请求复议，超出复议审查范围，应另循执行异议之诉。"

## 相关笔记

- 执行救济的第一道分流线是**"行为异议 vs 标的异议"**：前者针对执行**怎么做**（程序），走异议+复议（第236条）；后者针对执行**执行谁的财产**（权属），走异议+执行异议之诉（第234条）。律师最易犯的错是把权属争议装进行为异议，结果被程序性驳回。
- **十日期限**是复议的生死线，且自"异议裁定送达之日"起算（非作出日），务必固定送达回证。
- 解释第476条是**程序封闭条款**：不予执行仲裁裁决裁定不可异议不可复议，当事人只能重新仲裁或起诉——这是防止执行救济被滥用的重要界限。
