# R-PR-211 物之交付与行为执行（交付财物·迁出·指定行为）举证证据规则

## 裁判规则（证据规则·正向）

**交付财物或票证**：法律文书指定交付的财物或者票证，由执行员传唤双方当事人**当面交付**，或者由执行员**转交**并由被交付人签收；有关单位持有的，应当根据**协助执行通知书**转交并签收；有关公民持有的，人民法院通知其交出，**拒不交出的，强制执行**（民诉法第260条）。**强制迁出房屋或强制退出土地**：由**院长签发公告**，责令被执行人在指定期间履行，逾期不履行的由执行员强制执行（民诉法第261条）。**财产权证照转移**：需要办理有关财产权证照转移手续的，人民法院可以向有关单位发出协助执行通知书，有关单位必须办理（民诉法第262条）。**指定行为执行**：对判决、裁定和其他法律文书指定的行为，被执行人未按执行通知履行的，人民法院可以**强制执行，或者委托有关单位或者其他人完成，费用由被执行人承担**（民诉法第263条）。细化规则：生效法律文书确定被执行人**交付特定标的物**的，应当执行**原物**；原物被隐匿或非法转移的，人民法院有权责令其交出；**原物确已毁损或灭失**的，经双方当事人同意可以**折价赔偿**（执行工作规定第41条）。有关组织或个人持有指定交付的财物/票证，协同被执行人转移的，人民法院有权责令**限期追回**，逾期未追回的应裁定其**承担赔偿责任**（第42条）。被执行人拒不履行指定行为的，可以强制其履行；**可以替代履行的行为**可委托他人完成、费用由被执行人承担；**只能由被执行人完成的行为**，经教育仍拒不履行的，按妨害执行行为处理（第44条）。

🔴 行为二分铁律：指定行为执行分**"可替代履行"与"不可替代履行"**两类——可替代的，委托他人完成、费用由被执行人负担（效率优先）；不可替代的（如交付特定物、履行特定人身行为），只能强制或以妨害执行制裁，不得径行替代。

## 适用案由与场景

适用于：① 判决被交付人**交付特定财物/票证**（如车辆、提单、存单、证照）的执行及原物灭失后折价争议（民诉法第260条、执行工作规定第41条）；② **强制迁出房屋、退出土地**（如腾房、返还租赁物、退出占用地块）的执行（民诉法第261条）；③ 需要办理**财产权证照转移**手续的执行（车辆过户、不动产登记、股权变更登记，民诉法第262条）；④ 指定**行为**的执行（如办理过户、拆除障碍、恢复原状、刊登道歉声明）及**可替代/不可替代**履行的判断（民诉法第263条、执行工作规定第44条）；⑤ 第三人持有财物/票证协同被执行人转移的责任追究（执行工作规定第42条，衔接 R-PR-046 账户资金、R-PR-195 到期债权）。典型：判决腾退房屋，被执行人拒不迁出；判决交付特定批次的货物，货物已灭失而双方对折价无法协商；判决办理股权变更登记，被执行人拖延不办。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 交付义务存在及标的物特定（第260条、执行工作规定第41条） | **申请执行人** | 生效裁判主文（明确交付标的）、标的物特定化的证据（编号、型号、批次） |
| 标的物持有主体（被执行人自持 / 第三人持有） | 申请执行人 | 占有使用证据、第三人持有线索、协助执行通知书送达记录 |
| **原物毁损/灭失及折价**（执行工作规定第41条） | 主张折价一方 | 原物灭失的客观证据、评估报告、双方协商记录（需双方同意折价） |
| 强制迁出的公告送达与期限（第261条） | 法院（程序合法性）；被执行人可主张未依法公告 | 院长签发的公告、送达回证、指定履行期间届满证明 |
| 迁出时财物清点与交付（第261条） | 执行法院 / 主张财物损失方 | 执行笔录、财物清单、指定处所移交记录 |
| 证照转移协助义务（第262条） | 申请执行人 | 协助执行通知书、登记机关的办理记录 |
| 指定行为属**可替代 / 不可替代**（第263条、执行工作规定第44条） | 主张替代履行一方 | 行为性质说明（是否具人身专属性）、委托完成方案与费用凭证 |
| 第三人协同转移财物/票证的责任（执行工作规定第42条） | **申请执行人** | 第三人持有并协同转移的证据、责令追回通知、逾期未追回证明 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民事诉讼法》（2023修正）第260条（本地核填·现行有效）："法律文书指定交付的财物或者票证，由执行员传唤双方当事人当面交付，或者由执行员转交，并由被交付人签收。有关单位持有该项财物或者票证的，应当根据人民法院的协助执行通知书转交，并由被交付人签收。有关公民持有该项财物或者票证的，人民法院通知其交出。拒不交出的，强制执行。"
2. 第261条（本地核填·现行有效）："强制迁出房屋或者强制退出土地，由院长签发公告，责令被执行人在指定期间履行。被执行人逾期不履行的，由执行员强制执行。强制执行时，被执行人是公民的，应当通知被执行人或者他的成年家属到场；被执行人是法人或者其他组织的，应当通知其法定代表人或者主要负责人到场。拒不到场的，不影响执行。被执行人是公民的，其工作单位或者房屋、土地所在地的基层组织应当派人参加。执行员应当将强制执行情况记入笔录，由在场人签名或者盖章。强制迁出房屋被搬出的财物，由人民法院派人运至指定处所，交给被执行人。被执行人是公民的，也可以交给他的成年家属。因拒绝接收而造成的损失，由被执行人承担。"
3. 第262条（本地核填·现行有效）："在执行中，需要办理有关财产权证照转移手续的，人民法院可以向有关单位发出协助执行通知书，有关单位必须办理。"
4. 第263条（本地核填·现行有效）："对判决、裁定和其他法律文书指定的行为，被执行人未按执行通知履行的，人民法院可以强制执行或者委托有关单位或者其他人完成，费用由被执行人承担。"
5. 《执行工作规定》（法释〔2020〕21号）第41条（本地核填·现行有效）："生效法律文书确定被执行人交付特定标的物的，应当执行原物。原物被隐匿或非法转移的，人民法院有权责令其交出。原物确已毁损或灭失的，经双方当事人同意，可以折价赔偿。"
6. 第42条（本地核填·现行有效）："有关组织或者个人持有法律文书指定交付的财物或票证，在接到人民法院协助执行通知书或通知书后，协同被执行人转移财物或票证的，人民法院有权责令其限期追回；逾期未追回的，应当裁定其承担赔偿责任。"
7. 第44条（本地核填·现行有效）："被执行人拒不履行生效法律文书中指定的行为的，人民法院可以强制其履行。""对于可以替代履行的行为，可以委托有关单位或他人完成，因完成上述行为发生的费用由被执行人承担。""对于只能由被执行人完成的行为，经教育，被执行人仍拒不履行的，人民法院应当按照妨害执行行为的有关规定处理。"

🔴 原物优先铁律：交付特定标的物的执行**应执行原物**（第41条）；只有原物确已毁损或灭失且**经双方同意**才可折价赔偿——折价非任意替代，须双方合意，否则只能终结或另诉（与 R-PR-204 第492条特定物原物执行规则同构）。

## 攻防要点

- **攻方（申请执行人）**：① 主张**交付标的特定化**并证明原物仍在（占有、隐匿、非法转移线索），请求执行原物；② 对第三人持有的财物/票证，申请协助执行通知书，并在第三人协同转移时依第42条**责令限期追回、追究赔偿责任**；③ 对迁出房屋/退出土地，督促法院**依院长公告**限期履行、逾期强制执行（第261条）；④ 对证照转移，申请向登记机关发协助执行通知书（第262条）。
- **防方（被执行人/第三人）**：① 主张原物**已毁损/灭失**且**不同意折价**，阻断折价赔偿（第41条要求双方同意）；② 就强制迁出主张**未依法公告、未通知到场**等程序违法（第261条），提起执行行为异议（衔接 R-PR-208）；③ 就行为执行主张该行为**具有人身专属性、不可替代**，不得由他人代为完成（第44条第三款）；④ 第三人主张已尽协助义务、不存在协同转移。
- **可替代/不可替代之辨**：这是行为执行的核心攻防点——涉及**人身专属性的行为**（如特定艺术创作、需本人到场的行为）不可替代，只能以妨害执行制裁；**非人身专属性行为**（如一般过户、拆除）可委托他人完成，费用由被执行人负担。
- **搬迁损失**：强制迁出时被搬出财物**拒绝接收造成的损失由被执行人承担**（第261条末句），是被执行人转移损失的常见抗辩失败点。

## 质证话术模板

- 执行原物："生效判决明确判令被执行人交付××批次、编号××的特定货物，依《执行工作规定》第41条应执行原物；本代理人已查明该批货物仍存放于被执行人×仓库（附现场照片及占有证据），请求依法执行原物。"
- 折价抗辩（被执行人持不同意见）："被执行人主张原物灭失后折价赔偿，但依《执行工作规定》第41条，折价赔偿须**经双方当事人同意**，本代理人明确不予同意；原物能否寻回尚未穷尽，被执行人不得单方以折价替代原物交付。"
- 强制迁出程序抗辩："执行法院实施强制迁出前未依《民事诉讼法》第261条由院长签发公告并责令限期履行，程序违法，被执行人对该执行行为提出书面异议（衔接第236条）。"
- 行为可替代之辨："本案判决指定的行为系办理一般股权变更登记，不具人身专属性，属**可以替代履行**的行为；依《民事诉讼法》第263条及《执行工作规定》第44条，人民法院可委托有关单位完成，费用由被执行人承担。"
- 第三人协同转移追责："第三人××在接到协助执行通知书后，仍协同被执行人转移指定交付的××票证，依《执行工作规定》第42条，应责令其限期追回；逾期未追回的，请求裁定其承担赔偿责任。"

## 相关笔记

- 执行案件的"**物之交付与行为执行**"是金钱执行之外的另一大板块，判决主文若写"交付××特定物""办理××过户""拆除××"，均落入本卡范围。
- **原物优先 + 折价需双方同意**（第41条）与变价中的特定物规则（R-PR-204 第492条）是同一法理的两次落地：能交原物就交原物，不能交且双方合意才折价，避免以金钱赔偿替代物之交付的实体请求权。
- **可替代/不可替代之辨**（第44条）是行为执行的攻防枢纽：代理申请执行人应论证行为可替代以推动委托完成；代理被执行人则应主张人身专属性以阻断替代。
- 强制迁出的**公告前置**（院长签发、限期履行）是程序合法的关键，缺失即构成执行行为违法，可依第236条异议复议（衔接 R-PR-208）。
