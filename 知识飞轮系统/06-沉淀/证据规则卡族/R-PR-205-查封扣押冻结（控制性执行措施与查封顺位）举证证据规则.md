# R-PR-205 查封扣押冻结（控制性执行措施与查封顺位）举证证据规则

## 裁判规则（证据规则·正向）

执行中人民法院对未履行义务的被执行人享有查询、扣押、冻结、划拨、变价财产的权限，但**查询、扣押、冻结、划拨、变价的财产不得超出被执行人应当履行义务的范围**（民诉法第253条）；查封、扣押、冻结、拍卖、变卖的是"应当履行义务部分的财产"，且**必须保留被执行人及其所扶养家属的生活必需品**（第255条）；查封扣押财产时须通知被执行人/其成年家属或法定代表人、主要负责人到场，拒不到场不影响执行，并于场造具清单交被执行人一份（第256条）。**非经查封、扣押、冻结，人民法院不得处分被执行财产**；对银行存款等可直接扣划的财产，扣划裁定同时具有冻结法律效力（解释第484条）。查封性措施有法定**期限**：冻结存款不超过一年、查封扣押动产不超过两年、查封不动产及冻结其他财产权不超过三年，申请执行人申请延长的须在期限届满前办理续行手续、续行不超过原期限，法院亦可依职权续行（解释第485条）。诉前/诉中**保全裁定进入执行程序后自动转为执行中的查封扣押冻结，期限连续计算**，无需重制裁定（解释第168条）。参与分配时普通债权按**财产保全和执行中查封、扣押、冻结财产的先后顺序**清偿（解释第514条）。

## 适用案由与场景

适用于：① 被执行人或案外人主张查封**超出履行义务范围**（超标的查封）请求解除部分查封；② 查封期限届满未续行、措施失效后的财产处分争议；③ 案外人对查封财产主张权属（衔接 R-PR-193、执行异议之诉 R-PR-043/187）；④ 多个债权人竞合时的**查封顺位**争夺（首封 versus 轮候查封，直接影响参与分配受偿次序）；⑤ 保全裁定转执行查封的期限连续计算争议；⑥ 查封未依法通知到场、未造具清单的程序违法异议（衔接执行行为异议 R-PR-188）。典型：执行法院查封被执行人名下商铺及账户合计远超债务及利息，被执行人主张超标的查封请求解除超额部分；或首封一年后未续封、轮候查封债权人主张该财产已可供执行。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 查封财产"不得超出履行义务范围"（第253条） | **异议人（被执行人/案外人）**主张超标的 | 负债数额证据、债务金额与迟延履行利息计算、查封财产清单及评估报告、可执行财产总量统计 |
| 保留生活必需品（第255条） | 法院依职权审查，异议人可举证生活必需范围 | 被执行人及扶养家属人数、基本生活消费支出凭证、必需物品清单 |
| 查封程序合法（到场通知、造具清单，第256条） | 法院（程序合法性） | 到场通知送达回证、查封清单及签字、被执行人拒不到场记录 |
| 查封期限与续行（第485条） | **异议人**主张期限届满措施失效；**申请执行人**主张已合法续行 | 原查封裁定书及送达回证、续行查封手续、期限届满前办理的时间戳证据 |
| 保全转执行查封的期限连续（第168条） | 主张连续计算一方（通常为申请执行人或主张顺位在先者） | 保全裁定、进入执行程序的时间证明、执行中查封裁定 |
| 查封顺位（解释第514条） | 主张优先受偿在后位者须推翻顺位 | 各轮候查封/保全的时间顺序材料、首封法院及立案时间 |
| 案外人对查封财产主张权属 | 案外人（本证方） | 权属登记、买卖合同、付款凭证、占有使用证据（衔接 R-PR-193） |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《最高人民法院关于人民法院查封、扣押、冻结财产的规定》本地未收录，相关细化规则标注待核填。

1. 《民事诉讼法》（2023修正）第253条（本地核填·现行有效）："被执行人未按执行通知履行法律文书确定的义务，人民法院有权向有关单位查询被执行人的存款、债券、股票、基金份额等财产情况。人民法院有权根据不同情形扣押、冻结、划拨、变价被执行人的财产。人民法院查询、扣押、冻结、划拨、变价的财产不得超出被执行人应当履行义务的范围。人民法院决定扣押、冻结、划拨、变价财产，应当作出裁定，并发出协助执行通知书，有关单位必须办理。"
2. 第255条（本地核填·现行有效）："被执行人未按执行通知履行法律文书确定的义务，人民法院有权查封、扣押、冻结、拍卖、变卖被执行人应当履行义务部分的财产。但应当保留被执行人及其所扶养家属的生活必需品。采取前款措施，人民法院应当作出裁定。"
3. 第256条（本地核填·现行有效）："人民法院查封、扣押财产时，被执行人是公民的，应当通知被执行人或者他的成年家属到场；被执行人是法人或者其他组织的，应当通知其法定代表人或者主要负责人到场。拒不到场的，不影响执行。被执行人是公民的，其工作单位或者财产所在地的基层组织应当派人参加。对被查封、扣押的财产，执行员必须造具清单，由在场人签名或者盖章后，交被执行人一份。被执行人是公民的，也可以交他的成年家属一份。"
4. 《民诉法解释》第484条（本地核填·现行有效）："对被执行的财产，人民法院非经查封、扣押、冻结不得处分。对银行存款等各类可以直接扣划的财产，人民法院的扣划裁定同时具有冻结的法律效力。"
5. 第485条（本地核填·现行有效）："人民法院冻结被执行人的银行存款的期限不得超过一年，查封、扣押动产的期限不得超过两年，查封不动产、冻结其他财产权的期限不得超过三年。申请执行人申请延长期限的，人民法院应当在查封、扣押、冻结期限届满前办理续行查封、扣押、冻结手续，续行期限不得超过前款规定的期限。人民法院也可以依职权办理续行查封、扣押、冻结手续。"
6. 第168条（本地核填·现行有效）："保全裁定未经人民法院依法撤销或者解除，进入执行程序后，自动转为执行中的查封、扣押、冻结措施，期限连续计算，执行法院无需重新制作裁定书，但查封、扣押、冻结期限届满的除外。"
7. 第514条（本地核填·现行有效）："当事人不同意移送破产或者被执行人住所地人民法院不受理破产案件的，执行法院就执行变价所得财产，在扣除执行费用及清偿优先受偿的债权后，对于普通债权，按照财产保全和执行中查封、扣押、冻结财产的先后顺序清偿。"
8. 《最高人民法院关于人民法院查封、扣押、冻结财产的规定》（法释〔2004〕15号·2020修正）：轮候查封的启动与法律效力、查封异议提出期限等（本地法条银行**未收录**，statute_text_pending，待官方源核填后方可引为据）。

🔴 期限铁律：查封/冻结**期限届满即当然失效**，非经依法续行；被查封财产在期限届满后被处分的，处分行为存在效力瑕疵。异议人应紧盯"原查封裁定日期 + 法定期间（存款一年/动产两年/不动产三年）"倒推到期日，并核查法院是否在届满前办理续行手续。

## 攻防要点

- **攻方（被执行人/案外人）**：① 以第253条"不得超出履行义务范围"击破超标的查封，请求解除超额部分；② 以第255条击破未保留生活必需品；③ 以第485条主张期限届满且无合法续行，措施当然失效、财产恢复处分自由；④ 以第256条指出未通知到场、未造具清单，构成程序违法（衔接执行行为异议 R-PR-188）。
- **防方（申请执行人）**：① 提前在期限届满前办理续行查封（第485条明确"应当在期限届满前办理"）；② 证明查封范围与债务额相当（含迟延履行利息、执行费用）；③ 以第484条"非经查封不得处分"阻却被执行人对查封财产的处分，即便期限已过至处分前仍应主张；④ 以解释第514条主张己方在先查封顺位。
- **顺位对抗**：解释第514条确立"按查封先后顺序清偿"，轮候查封债权人须证明其保全/查封时间早于他人；首封利益是执行竞合中的核心争夺点。
- **保全衔接**：解释第168条的"自动转化、期限连续计算"是保全转执行的抗辩要点——申请执行人以保全在先对抗"执行中查封在后"的主张时，须证明保全裁定未获依法撤销或解除。

## 质证话术模板

- 超标的查封："执行法院查封的商铺评估价×万元，而本案债权本金仅×万元及相应利息，查封财产明显超出被执行人应当履行义务的范围，违反《民事诉讼法》第253条'不得超出被执行人应当履行义务的范围'的规定，请求解除超额部分的查封。"
- 期限届满抗辩："××号查封裁定作出于×年×月×日，查封类型为不动产，法定期限为三年，而执行法院直至×年×月×日仍未办理续行查封手续，依《民诉法解释》第485条该查封已经失效，被查封财产应恢复处分自由。"
- 保全连续计算对抗："本案保全裁定作出于×年×月×日，××号执行案件于×年×月×日进入执行程序，依据《民诉法解释》第168条保全裁定自动转为执行中的查封且期限连续计算，本代理人据此主张在先查封顺位，请求按《民诉法解释》第514条顺序清偿。"
- 程序违法："本次查封未通知被执行人到场、亦未当场造具清单并由在场人签名，违反《民事诉讼法》第256条规定的强制程序，构成执行行为违法，请求依《民事诉讼法》第236条提出执行行为异议。"
