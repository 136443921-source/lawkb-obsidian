# R-PR-213 执行中止、终结与终结本次执行（三制度体系化）举证证据规则

## 裁判规则（证据规则·正向）

**执行中止**：有法定六情形之一，人民法院**应当裁定中止执行**——①申请人表示可以延期执行；②案外人对执行标的提出确有理由的异议；③作为一方当事人的公民死亡，需等待继承人继承权利或承担义务；④作为一方当事人的法人或其他组织终止，尚未确定权利义务承受人；⑤人民法院认为应当中止执行的其他情形；**中止的情形消失后，恢复执行**（民诉法第267条）。**终结执行**：有法定六情形之一，人民法院**裁定终结执行**——①申请人撤销申请；②据以执行的法律文书被撤销；③作为被执行人的公民死亡，无遗产可供执行又无义务承担人；④追索赡养费、扶养费、抚养费案件的权利人死亡；⑤作为被执行人的公民因生活困难无力偿还借款，无收入来源，又丧失劳动能力；⑥人民法院认为应当终结执行的其他情形（民诉法第268条）。**终结本次执行（终本）**：经财产调查**未发现可供执行财产**，在申请执行人签字确认或者执行法院组成合议庭审查核实并经**院长批准**后，可以裁定终本；终本后**发现可供执行财产的，可再次申请执行，再次申请不受申请执行时效期间的限制**（解释第517条）。**撤销申请终结后的再申请**：因撤销申请而终结执行后，当事人在申请执行时效期间内再次申请执行的，人民法院应当受理（解释第518条）。**和解引致的中止/终结**：申请执行人与被执行人达成和解协议后请求中止执行或撤回执行申请的，人民法院可以裁定中止执行或终结执行（解释第464条）。**破产引致的终结/恢复**：被执行人住所地法院裁定宣告破产的，执行法院应当裁定终结对该被执行人的执行；不受理破产案件的，应当恢复执行（解释第513条）。

🔴 三制度分野铁律：**中止 = 暂停（可恢复）**；**终本 = 阶段性停止（财产调查无果，发现财产可再申请、不受时效限制）**；**终结 = 彻底结束（不再恢复，除撤销申请后时效内再申请）**。三者法律后果截然不同，代理时必须精准选择与抗辩。

## 适用案由与场景

适用于：① 案外人对执行标的提出确有理由的异议，是否**中止执行**的争议（衔接 R-PR-193）；② 当事人死亡/终止后，**权利义务承受人未确定**的中止与恢复；③ 被执行人**财产调查无果**是否终本、终本后**再次申请执行**的条件（衔接 R-PR-192）；④ 债权人**撤销申请**导致终结后，在时效内再次申请的受理（解释第518条，衔接 R-PR-206）；⑤ 执行和解后请求中止/撤回致终结的争议（解释第464条，衔接 R-PR-189）；⑥ 被执行人**宣告破产**后执行终结、不受理破产后恢复执行（解释第513条，衔接 R-PR-202）。典型：执行法院以"无财产可供执行"拟终本，申请执行人主张财产线索充足而反对；或被执行人被宣告破产后，债权人主张执行终结错误。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 中止情形成就（第267条五类） | **主张中止方** | 申请人延期意思表示、案外人异议理由、死亡/终止证明、权利义务承受人未确定的证据 |
| 中止情形消失后**恢复执行** | **申请恢复方** | 情形消失的证据（如承受人确定、异议被驳回） |
| 终结情形成就（第268条六类） | **主张终结方** | 撤销申请、文书被撤销的裁判、死亡无遗产证明、权利人身份证明、无收入来源及丧失劳动能力证明 |
| 终本条件（"财产调查未发现可供执行财产"） | **执行法院（依职权）**，可依申请执行人签字确认 | **财产调查记录**（查控系统反馈、银行/不动产/车辆查询回执）、申请执行人签字确认或合议庭审查+院长批准 |
| 终本后再申请执行（解释第517条） | **申请执行人** | 终本裁定、**发现可供执行财产**的新证据（不受时效限制） |
| 撤销申请终结后再申请（解释第518条） | 申请执行人 | 撤销申请及终结裁定、**再次申请在时效内**的证明 |
| 和解引致的中止/终结（解释第464条） | 请求中止/撤回方 | 和解协议、请求中止或撤回执行申请的意思表示 |
| 破产引致的终结/恢复（解释第513条） | 主张方 / 法院 | 受理破产裁定、宣告破产裁定 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」。

1. 《民事诉讼法》（2023修正）第267条（本地核填·现行有效）："有下列情形之一的，人民法院应当裁定中止执行：（一）申请人表示可以延期执行的；（二）案外人对执行标的提出确有理由的异议的；（三）作为一方当事人的公民死亡，需要等待继承人继承权利或者承担义务的；（四）作为一方当事人的法人或者其他组织终止，尚未确定权利义务承受人的；（五）人民法院认为应当中止执行的其他情形。中止的情形消失后，恢复执行。"
2. 第268条（本地核填·现行有效）："有下列情形之一的，人民法院裁定终结执行：（一）申请人撤销申请的；（二）据以执行的法律文书被撤销的；（三）作为被执行人的公民死亡，无遗产可供执行，又无义务承担人的；（四）追索赡养费、扶养费、抚养费案件的权利人死亡的；（五）作为被执行人的公民因生活困难无力偿还借款，无收入来源，又丧失劳动能力的；（六）人民法院认为应当终结执行的其他情形。"
3. 《民诉法解释》第517条（本地核填·现行有效）："经过财产调查未发现可供执行的财产，在申请执行人签字确认或者执行法院组成合议庭审查核实并经院长批准后，可以裁定终结本次执行程序。依照前款规定终结执行后，申请执行人发现被执行人有可供执行财产的，可以再次申请执行。再次申请不受申请执行时效期间的限制。"
4. 第518条（本地核填·现行有效）："因撤销申请而终结执行后，当事人在民事诉讼法第二百四十六条规定的申请执行时效期间内再次申请执行的，人民法院应当受理。"
5. 第464条（本地核填·现行有效）："申请执行人与被执行人达成和解协议后请求中止执行或者撤回执行申请的，人民法院可以裁定中止执行或者终结执行。"
6. 第513条（本地核填·现行有效）："被执行人住所地人民法院裁定受理破产案件的，执行法院应当解除对被执行人财产的保全措施。被执行人住所地人民法院裁定宣告被执行人破产的，执行法院应当裁定终结对该被执行人的执行。被执行人住所地人民法院不受理破产案件的，执行法院应当恢复执行。"

🔴 条号位移提示：解释第518条援引"民事诉讼法第二百四十六条"作为**申请执行时效**条号，而现行民诉法（2023修正）第246条实为**执行检察监督**条款、申请执行时效现位于**第250条**（参见 R-PR-206 位移警示），引用时须按现行文本核验。

## 攻防要点

- **攻方（申请执行人）**：① 反对不当**终本**——举证财产线索充足（查控系统遗漏、被执行人隐匿财产、到期债权等），主张"财产调查未发现可供执行财产"不成立；② 终本或终结后主张**恢复/再申请**——以解释第517条（发现财产、不受时效限制）、第518条（撤销申请后时效内）为通道；③ 对被执行人宣告破产而终结执行的，主张**仅在真正受理/宣告破产时**方可终结（解释第513条）。
- **防方（被执行人）**：① 以民诉法第268条六情形主张**终结执行**（如申请人撤销、文书被撤销）；② 以财产调查无果推动**终本**；③ 对"恢复执行"主张情形未消失或已过时效。
- **中止 vs 终结的误判风险**：中止是可恢复的暂停，终结是彻底结束——代理申请执行人须守住"能中止不终结"，避免轻易接受终结导致债权落空。
- **终本的双重属性**：终本既是对"无财产"的程序回应，也保留了**再次申请不受时效限制**的后续通道（解释第517条），是执行不能案件的缓冲机制（衔接 R-PR-192）。

## 质证话术模板

- 反对终本："执行法院拟以'无财产可供执行'裁定终本，但本代理人已查明被执行人名下××房产/对××的到期债权可供执行（附财产线索），'财产调查未发现可供执行财产'的条件不成立，依《民诉法解释》第517条不得终本。"
- 终本后再申请："本案已裁定终结本次执行程序，现被执行人新增××财产，依《民诉法解释》第517条，本代理人再次申请执行**不受申请执行时效期间的限制**，请求依法立案执行。"
- 撤销申请后时效内再申请："本案因本代理人撤销申请而终结执行，现本代理人在《民诉法解释》第518条及《民事诉讼法》第250条规定的申请执行时效期间内再次申请执行，人民法院应当受理。"
- 中止抗辩："案外人就执行标的××房产提出确有理由的异议，依《民事诉讼法》第267条第二项，人民法院应当裁定中止执行，至异议解决前不得对该标的继续处分。"
- 破产终结抗辩："被执行人住所地法院已裁定宣告被执行人××破产，依《民诉法解释》第513条，执行法院应当裁定终结对该被执行人的执行；但若系仅受理破产而未宣告，则不应终结。"

## 相关笔记

- 执行程序的"出口"有三：**中止（可恢复的暂停）、终本（阶段性停止+可再申请）、终结（彻底结束）**。律师代理申请执行人时，第一原则是**避免终结**——一旦终结（除撤销申请外）债权执行即告落空。
- **终本 ≠ 终结**：终本后只要发现财产即可再次申请，且**不受申请执行时效限制**（解释第517条）——这是执行不能案件保留希望的制度设计，代理人不应把终本误读为"案子没了"。
- **撤销申请要谨慎**：解释第518条给撤销申请留下"时效内再申请"的后路，但**受申请执行时效期间约束**（援引旧第246条，现行为第250条），一旦超期即无法再启动。
- 与 R-PR-202 联动：被执行人进入破产程序后，**宣告破产**才终结执行、**不受理破产**则恢复执行（解释第513条），两者不可混淆。
