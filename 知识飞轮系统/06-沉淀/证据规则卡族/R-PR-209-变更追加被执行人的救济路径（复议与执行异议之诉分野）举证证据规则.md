# R-PR-209 变更、追加被执行人的救济路径（复议与执行异议之诉分野）举证证据规则

## 裁判规则（证据规则·正向）

执行中，作为被执行人的**法人或者其他组织分立、合并**的，人民法院可以裁定**变更后的法人或者其他组织**为被执行人；被注销的，如果依照有关实体法的规定有权利义务承受人的，可以裁定**该权利义务承受人**为被执行人（解释第470条）。**其他组织在执行中不能履行**法律文书确定的义务的，人民法院可以裁定执行对该其他组织**依法承担义务的法人或者公民个人的财产**（解释第471条）。被执行人**名称变更**的，可以裁定**变更后的主体**为被执行人（解释第472条）。被执行人**死亡**的，其遗产继承人没有放弃继承的，可以裁定变更被执行人为**继承人**，由其在**遗产范围内**偿还；继承人放弃继承的，人民法院可以**直接执行被执行人的遗产**（解释第473条）。救济通道上：对变更、追加裁定不服，因该裁定本质属"**执行行为**"，可依民诉法第236条提起书面异议并申请复议（衔接 R-PR-208）；若争议指向**执行标的权属**，则依民诉法第234条提起执行异议之诉，此时**案外人应当就其对执行标的享有足以排除强制执行的民事权益承担举证证明责任**（解释第309条）。专项细化上，《变更、追加规定》（法释〔2016〕21号）就被申请人对变更、追加裁定不服的**救济方式（复议）**及其适用情形作出专门规范（本地暂无源，见法条依据段）。

🔴 分野铁律：变更、追加裁定指向的是"**谁是本案被执行人**"（**主体变更**，属执行行为）→ 救济走**异议+复议**（第236条）；案外人执行异议之诉指向的是"**某财产是否可供执行**"（**标的权属**）→ 救济走**异议+执行异议之诉**（第234条）。混淆二者将导致**救济通道错位**而被程序性驳回。

## 适用案由与场景

适用于：① 被执行法人分立、合并、注销、名称变更后，就被变更主体资格的争议与救济；② 其他组织不能履行时，对其背后承担义务的法人/个人（如个人独资企业出资人、合伙人对合伙债务）追加的争议；③ 被执行人（公民）死亡后，就继承人是否在遗产范围内承担责任、可否直接执行遗产的争议；④ 被变更/追加的主体对裁定不服，**救济路径选择**（复议 or 执行异议之诉）与举证责任；⑤ 与追加股东（未出资、抽逃出资、一人公司）等实体审查（衔接 R-PR-130~138）配套的救济程序。典型：被执行公司注销后，债权人申请变更其股东/清算义务人为被执行人，股东以"不应变更"提出救济；或个人独资企业不能清偿时追加出资人，出资人异议。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 变更情形存在（分立/合并/注销/名称变更，解释第470/472条） | **申请变更方（申请执行人）** | 工商登记档案、合并分立协议、注销登记、名称变更核准通知 |
| 权利义务承受人身份（注销后的承受人，第470条后段） | 申请变更方 | 实体法上的权利义务承继证据（清算报告、债务承担协议、继承关系） |
| 其他组织不能履行+背后主体的义务（第471条） | 申请变更方 | 其他组织财产不足清偿的证据、承担义务主体的法律依据（出资关系、合伙协议） |
| 继承人是否放弃继承、遗产范围（第473条） | 主张变更一方 vs 继承人 | 继承权公证/放弃声明、遗产清单、遗产价值评估 |
| 救济路径适格（复议 vs 执行异议之诉） | 提起救济方 | 原裁定的性质（变更/追加裁定 or 标的处置裁定）、争议指向（主体 vs 权属） |
| 案外人排除执行的实体权益（解释第309条，走异议之诉时） | **案外人（异议之诉原告）** | 足以排除强制执行的民事权益证据（权属登记、合同、付款、占有） |
| 追加股东出资瑕疵（衔接 R-PR-130~138） | 申请执行人（初步）vs 被追加股东 | 出资凭证、验资报告、银行流水、公司财产独立性证据 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《变更、追加规定》本地暂无源，救济程序细化规则标注待核填。

1. 《民诉法解释》第470条（本地核填·现行有效）："依照民事诉讼法第二百三十九条规定，执行中作为被执行人的法人或者其他组织分立、合并的，人民法院可以裁定变更后的法人或者其他组织为被执行人；被注销的，如果依照有关实体法的规定有权利义务承受人的，可以裁定该权利义务承受人为被执行人。"
2. 第471条（本地核填·现行有效）："其他组织在执行中不能履行法律文书确定的义务的，人民法院可以裁定执行对该其他组织依法承担义务的法人或者公民个人的财产。"
3. 第472条（本地核填·现行有效）："在执行中，作为被执行人的法人或者其他组织名称变更的，人民法院可以裁定变更后的法人或者其他组织为被执行人。"
4. 第473条（本地核填·现行有效）："作为被执行人的公民死亡，其遗产继承人没有放弃继承的，人民法院可以裁定变更被执行人，由该继承人在遗产的范围内偿还债务。继承人放弃继承的，人民法院可以直接执行被执行人的遗产。"
5. 第309条（本地核填·现行有效）："案外人或者申请执行人提起执行异议之诉的，案外人应当就其对执行标的享有足以排除强制执行的民事权益承担举证证明责任。"
6. 第477条（本地核填·现行有效）："在执行中，被执行人通过仲裁程序将人民法院查封、扣押、冻结的财产确权或者分割给案外人的，不影响人民法院执行程序的进行。案外人不服的，可以根据民事诉讼法第二百三十四条规定提出异议。"
7. 《民事诉讼法》（2023修正）第236条（本地核填·现行有效）：执行行为异议与复议的救济条款（详见 R-PR-208）。
8. 《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》（法释〔2016〕21号）：变更、追加被执行人的情形清单与被申请人**对变更、追加裁定不服的救济方式（复议）**及其期限、审查主体（本地法条银行**暂无源，待核填**，statute_text_pending，正式文书引用前须以官方文本核验）。

🔴 条号位移提示：解释第470条援引"民事诉讼法第二百三十九条"、第477条援引"第二百三十四条"，均为解释起草时对应的**旧条号**；现行民诉法（2023修正）相关条号已变化，引用时须按现行文本逐条核验，不得直接以旧号对应（参见 R-PR-206 同类位移警示）。

## 攻防要点

- **攻方（申请变更/追加一方·多为申请执行人）**：① 系统提交**主体变动证据链**（工商档案、合并分立协议、注销登记、继承证明）证明变更情形成立；② 就被注销主体，证明存在**实体法上的权利义务承受人**；③ 就其他组织，证明其**不能履行**且背后主体依法承担义务；④ 对继承人，证明其**未放弃继承**及遗产范围。
- **防方（被变更/追加主体·多为股东/承受人/继承人）**：① 主张**不符合法定变更、追加情形**（法定情形之外不得扩张）；② 就继承人，以**已放弃继承**抗辩，阻断变更；③ 主张**遗产范围有限**，仅在此范围内承担；④ **救济通道异议**——主张争议实为标的权属，应走执行异议之诉而非复议（或反之），制造程序性障碍。
- **程序分野**：变更、追加裁定（主体问题）→ **异议+复议**；执行标的权属 → **异议+执行异议之诉**（案外人负排除执行的举证责任，解释第309条）。选错通道是实务最高频的失分点。
- **与 R-PR-130~138 衔接**：追加股东的**实体要件**（未出资/抽逃/一人公司财产混同）在 R-PR-130~138 详列，本卡解决其**救济程序**侧。

## 质证话术模板

- 变更情形成立："被执行人××公司已于×年×月×日办理注销登记，依《民诉法解释》第470条，其清算义务人/股东××系实体法上的权利义务承受人，本代理人请求变更其为被执行人，附工商注销档案及清算报告为证。"
- 继承人抗辩："本人已于×年×月×日在继承开始前书面放弃继承（附放弃继承声明及公证），依《民诉法解释》第473条，人民法院不得裁定变更本人为被执行人；且即便执行遗产，亦仅以遗产实际价值为限。"
- 其他组织追加："被执行人××个人独资企业财产不足以清偿本案债务，依《民诉法解释》第471条，应裁定执行其出资人××的个人财产，附企业财产状况及出资关系证据。"
- 救济通道错位抗辩："异议人所提异议指向的是执行标的××房产的**实体权属**，并非变更、追加裁定的主体资格问题，依《民事诉讼法》第234条应提起执行异议之诉，其复议申请不属于本案审查范围。"
- 案外人排除执行（走异议之诉，解释第309条）："案外人主张排除执行，依《民诉法解释》第309条应就其对执行标的享有足以排除强制执行的民事权益承担举证证明责任；其仅提交买卖合同而未付款、未占有，举证不足。"

## 相关笔记

- 变更、追加当事人的案件，律师必须**先判断救济通道**：主体问题（谁是被执行人）→ 复议；权属问题（财产能不能执行）→ 执行异议之诉。**通道选错 = 白打一场**。
- 继承人变更（解释第473条）有个实用细节：**放弃继承 → 不得变更继承人**，但**可直接执行遗产**。即"变不了人，还能执行物"，代理人切勿误以为放弃继承即可完全阻断执行。
- 解释第470条援引"民诉法第二百三十九条"、第477条援引"第二百三十四条"均为**旧条号**，须按现行民诉法核验（同类位移警示见 R-PR-206）。
- 🔴 《变更、追加规定》（法释〔2016〕21号）是变更追加的**专门司法解释**，其第32条等条款专门规定被申请人对变更、追加裁定不服的**复议救济**，是本卡的程序核心法源。本地法条银行**暂无源**，已标 statute_text_pending；正式文书引用前须以官方文本核验或补建该源。
