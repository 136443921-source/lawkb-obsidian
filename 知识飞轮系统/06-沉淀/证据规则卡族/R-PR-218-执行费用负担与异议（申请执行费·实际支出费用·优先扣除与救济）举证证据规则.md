# R-PR-218 执行费用负担与异议（申请执行费·实际支出费用·优先扣除与救济）举证证据规则

## 裁判规则（证据规则·正向）

**执行费用由被执行人负担，并从执行所得价款中优先扣除**，这是执行分配的一条基础顺位规则。执行费用包含两类：① **执行申请费**——由申请执行人依法交纳，具体标准按《诉讼费用交纳办法》办理（执行工作规定第21项）；**实现担保物权**案件中，裁定拍卖、变卖担保财产的，申请费由**债务人、担保人**负担；裁定驳回申请的，申请费由**申请人**负担，申请人另行起诉的，已交申请费可从案件受理费中扣除（民诉法解释第204条）；拍卖、变卖担保财产的裁定作出后法院强制执行的，**按执行金额收取执行申请费**（第205条）。② **执行实际支出费用**——委托拍卖、组织变卖被执行人财产所发生的实际费用，**从所得价款中优先扣除**；所得价款超出执行标的数额和执行费用的部分，**应当退还被执行人**（执行工作规定第34项）；代履行的，"因完成上述行为发生的费用由被执行人承担"（民诉法第263条、执行工作规定第44项）。**优先扣除顺位**：参与分配执行中，"执行所得价款**扣除执行费用**，并清偿应当优先受偿的债权后"，普通债权按比例受偿（民诉法解释第508条）；执转破不同意或不受理破产时，"在**扣除执行费用**及清偿优先受偿的债权后"，普通债权按查封先后顺序清偿（第514条）。**救济通道**：对执行费用决定不服（如费用计算错误、不应由本方负担、扣除顺位错误），属对**执行行为**的异议，走民诉法第236条的执行行为异议与复议（衔接 R-PR-208）。

🔴 顺位铁律：执行费用的受偿顺位**优先于优先受偿债权**（第508、514条均表述为"扣除执行费用，并清偿应当优先受偿的债权"），更优先于普通债权。主张分配时先把执行费用从价款中"扣掉"，再谈优先债权、普通债权。

## 适用案由与场景

适用于：① 执行到位后法院从价款中扣除执行费用，当事人（尤以申请执行人）对**费用数额或负担主体**有异议；② **实现担保物权**案件中债务人、担保人与申请人之间就申请费负担发生争议（民诉法解释第204/205条）；③ **拍卖、变卖、代履行**产生实际支出费用（评估费、拍卖佣金、保管费、代履行费），被执行人主张不应扣除或应退还超出部分（执行工作规定第34/44项）；④ **参与分配**或**执转破不同意**情形下，就执行费用与优先债权、普通债权的**顺位**发生争议（民诉法解释第508/514条）；⑤ 胜诉方预交的应由败诉方负担的费用退还争议（第207条）。典型：执行回款100万元，法院扣除执行申请费与拍卖佣金后作出分配，申请执行人认为费用扣除过高、且应在抵押权人受偿后再扣。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 执行申请费的**计收标准与金额** | 执行法院（依《诉讼费用交纳办法》计收，制作费用清单） | 执行申请费计算清单、收费票据、《诉讼费用交纳办法》对应条款 |
| **实际支出费用**真实发生且必要 | **主张扣除方（通常为执行法院/申请执行人）** | 委托拍卖合同、佣金发票、评估报告与评估费票据、保管费凭证、代履行费用凭证 |
| 费用**应由被执行人负担** | 主张方 | 生效法律文书、执行通知、代履行费用发生的因果关系材料 |
| 应**退还被执行人**的超出部分（第34项） | 被执行人 | 所得价款、执行标的数额、执行费用数额的对比计算 |
| 实现担保物权申请费的**负担主体**（裁定拍卖变卖 vs 驳回） | 各方 | 实现担保物权裁定主文（准予拍卖变卖 / 驳回申请） |
| 优先扣除**顺位**（费用先于优先债权、普通债权） | 主张顺位者 | 分配方案、民诉法解释第508/514条 |
| 已交申请费可从案件受理费中**扣除**（第204条第2款） | 申请人 | 已交申请费票据、另行起诉的立案材料 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《诉讼费用交纳办法》（国务院令第481号）本地未收录，具体收费标准标注待核填。

1. 《民事诉讼法》（2023修正）第121条（本地核填·现行有效）："当事人进行民事诉讼，应当按照规定交纳案件受理费。财产案件除交纳案件受理费外，并按照规定交纳其他诉讼费用。当事人交纳诉讼费用确有困难的，可以按照规定向人民法院申请缓交、减交或者免交。收取诉讼费用的办法另行制定。"
2. 第263条（本地核填·现行有效）："对判决、裁定和其他法律文书指定的行为，被执行人未按执行通知履行的，人民法院可以强制执行或者委托有关单位或者其他人完成，费用由被执行人承担。"
3. 《执行工作规定》（法释〔2020〕21号）第21项（本地核填·现行有效）："执行申请费的收取按照《诉讼费用交纳办法》办理。"
4. 第34项（本地核填·现行有效）："拍卖、变卖被执行人的财产成交后，必须即时钱物两清。委托拍卖、组织变卖被执行人财产所发生的实际费用，从所得价款中优先扣除。所得价款超出执行标的数额和执行费用的部分，应当退还被执行人。"
5. 第44项（本地核填·现行有效）："被执行人拒不履行生效法律文书中指定的行为的，人民法院可以强制其履行。对于可以替代履行的行为，可以委托有关单位或他人完成，因完成上述行为发生的费用由被执行人承担。对于只能由被执行人完成的行为，经教育，被执行人仍拒不履行的，人民法院应当按照妨害执行行为的有关规定处理。"
6. 《民诉法解释》（2022修正）第204条（本地核填·现行有效）："实现担保物权案件，人民法院裁定拍卖、变卖担保财产的，申请费由债务人、担保人负担；人民法院裁定驳回申请的，申请费由申请人负担。申请人另行起诉的，其已经交纳的申请费可以从案件受理费中扣除。"
7. 第205条（本地核填·现行有效）："拍卖、变卖担保财产的裁定作出后，人民法院强制执行的，按照执行金额收取执行申请费。"
8. 第207条（本地核填·现行有效）："判决生效后，胜诉方预交但不应负担的诉讼费用，人民法院应当退还，由败诉方向人民法院交纳，但胜诉方自愿承担或者同意败诉方直接向其支付的除外。当事人拒不交纳诉讼费用的，人民法院可以强制执行。"
9. 第508条（本地核填·现行有效）："参与分配执行中，执行所得价款扣除执行费用，并清偿应当优先受偿的债权后，对于普通债权，原则上按照其占全部申请参与分配债权数额的比例受偿。清偿后的剩余债务，被执行人应当继续清偿。债权人发现被执行人有其他财产的，可以随时请求人民法院执行。"
10. 第514条（本地核填·现行有效）："当事人不同意移送破产或者被执行人住所地人民法院不受理破产案件的，执行法院就执行变价所得财产，在扣除执行费用及清偿优先受偿的债权后，对于普通债权，按照财产保全和执行中查封、扣押、冻结财产的先后顺序清偿。"
11. 《诉讼费用交纳办法》（国务院令第481号，现行有效，qcc-legal 逐字核填）申请执行费交纳与负担的核心条文：
- 第十四条第（一）项（申请费交纳标准——执行申请费分档计收）："依法向人民法院申请执行人民法院发生法律效力的判决、裁定、调解书，仲裁机构依法作出的裁决和调解书，公证机关依法赋予强制执行效力的债权文书，申请承认和执行外国法院判决、裁定以及国外仲裁机构裁决的，按照下列标准交纳：1. 没有执行金额或者价额的，每件交纳50元至500元。2. 执行金额或者价额不超过1万元的，每件交纳50元；超过1万元至50万元的部分，按照1.5％交纳；超过50万元至500万元的部分，按照1％交纳；超过500万元至1000万元的部分，按照0.5％交纳；超过1000万元的部分，按照0.1％交纳……"
- 第二十条（申请费预交规则——执行申请费执行后交纳）："申请费由申请人预交。但是，本办法第十条第（一）项、第（六）项规定的申请费不由申请人预交，执行申请费执行后交纳，破产申请费清算后交纳。"
- 第三十八条（申请费负担——由被执行人负担）："本办法第十条第（一）项、第（八）项规定的申请费由被执行人负担。执行中当事人达成和解协议的，申请费的负担由双方当事人协商解决；协商不成的，由人民法院决定……"
（注：原卡引"第38~40条"范围不准——第39条为海事案件费用、第40条为二审/再审新证据费用增加之负担，均非执行申请费交纳标准；执行申请费"不预交、执行后交纳、分档计收"之规范在第十四条第（一）项、第二十条及第三十八条，已据 qcc-legal 核正。）

🔴 条号提示：执行工作规定第34项所称"执行费用"是**实际支出费用**（评估、拍卖佣金、保管等），与第21项的**执行申请费**是两个概念；民诉法第263条/执行工作规定第44项的"费用"是**代履行费用**。三者均从被执行人处或执行所得价款中受偿，但发生依据与计算方式不同，援引时须分清。

## 攻防要点

- **攻方（申请执行人/被执行人主张费用异议）**：① 索要**执行费用计算清单**，逐项核对申请费计收标准与实际支出费用凭证；② 以**民诉法解释第34项**主张超出执行标的与执行费用的部分应**退还被执行人**；③ 以**第508/514条**主张执行费用优先扣除后应按顺位清偿，纠正分配方案顺位错误；④ 对费用决定不服，走**民诉法第236条执行行为异议**（衔接 R-PR-208），勿错走分配方案异议之诉（R-PR-214）。
- **防方（执行法院/对方当事人）**：① 出示**实际支出费用凭证**（拍卖合同、佣金发票、评估费票据）证明费用真实必要；② 论证申请费计收**符合《诉讼费用交纳办法》**；③ 主张该异议属**费用核定**而非执行行为违法，或已过异议期限。
- **顺位主张**：执行费用＞优先受偿债权＞普通债权——被抵押权人等优先债权人主张"先扣我的"时，以第508/514条文义（"扣除执行费用，并清偿应当优先受偿的债权"）反驳。
- **实现担保物权场景**：先看裁定主文是"准予拍卖变卖"（债务人、担保人负担申请费）还是"驳回申请"（申请人负担）——负担主体随裁定结论而定（第204条）。

## 质证话术模板

- 执行费用异议（执行行为异议）"本案分配方案在计算执行费用时将不属于必要支出的××费用一并扣除，且扣除顺位置于抵押权人受偿之前，违反《民诉法解释》第508条'执行所得价款扣除执行费用，并清偿应当优先受偿的债权后'的规定；本代理人依《民事诉讼法》第236条提出执行行为异议，请求撤销或改正该执行行为。"
- 超出部分应退还"依《执行工作规定》第34项，'所得价款超出执行标的数额和执行费用的部分，应当退还被执行人'。本案执行标的××元、执行费用××元，所得价款××元，超出部分依法应退还被执行人，恳请核实并退还。"
- 实现担保物权申请费负担"本案实现担保物权裁定主文为准予拍卖、变卖担保财产，依《民诉法解释》第204条，申请费应由债务人、担保人负担，不应由本申请人承担。"
- 代履行费用"被执行人对判决确定的××行为拒不履行，依《民事诉讼法》第263条及《执行工作规定》第44项，代履行所生费用应由被执行人承担，本代理人提交代履行合同及费用票据予以佐证。"

## 相关笔记

- **执行费用是"隐形的第一条顺位"**：无论参与分配（解释第508条）还是执转破不同意（第514条），法条表述都是"**扣除执行费用，并清偿应当优先受偿的债权**"——费用在最前。写分配方案代理意见时，务必先把这一层扣干净再谈优先债权与普通债权。
- **两个概念的坑**：当事人常把"申请执行费"与"评估费/拍卖佣金"混为一谈。前者按《诉讼费用交纳办法》计收（执行工作规定第21项），后者属**实际支出费用**，从所得价款**优先扣除**（第34项），凭证据说话。
- **救济路径不能错**：执行费用是"执行行为"层面的问题 → **执行行为异议/复议（民诉法第236条，衔接 R-PR-208）**；而"分配方案内容"层面的问题才是**分配方案异议之诉（解释第510条，R-PR-214）**。把费用问题塞进异议之诉，属路径错误。
- 🔴 《诉讼费用交纳办法》（国务院令第481号）是执行申请费**计收与负担的直接法源**，核心条文为第十四条第（一）项（分档标准）、第二十条（执行后交纳、不预交）、第三十八条（由被执行人负担），**已由 qcc-legal 逐字核填**（见法条依据段第11项；原卡"第38~40条"范围有误，已据 qcc-legal 核正）。
