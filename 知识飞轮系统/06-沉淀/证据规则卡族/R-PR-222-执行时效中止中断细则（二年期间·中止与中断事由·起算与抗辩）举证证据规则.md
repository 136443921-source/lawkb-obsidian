# R-PR-222 执行时效中止中断细则（二年期间·中止与中断事由·起算与抗辩）举证证据规则

## 裁判规则（证据规则·正向）

**申请执行时效是二年，其中止、中断准用法律关于诉讼时效的规定。** 民诉法第250条："申请执行的期间为二年。**申请执行时效的中止、中断，适用法律有关诉讼时效中止、中断的规定**。"起算点同样由该条规定：**从法律文书规定履行期间的最后一日起计算**；法律文书规定**分期履行**的，从**最后一期履行期限届满之日**起计算；法律文书**未规定履行期间**的，从**法律文书生效之日**起计算。

**中止细则（准用民法典第194条）**：在时效期间的**最后六个月内**，因下列障碍不能行使请求权的，时效中止——① 不可抗力；② 无民事行为能力人或者限制民事行为能力人没有法定代理人，或者法定代理人死亡、丧失民事行为能力、丧失代理权；③ 继承开始后未确定继承人或者遗产管理人；④ 权利人被义务人或者其他人控制；⑤ 其他导致权利人不能行使请求权的障碍。**法律效果**：自中止时效的原因**消除之日起满六个月，诉讼时效期间届满**（即中止期间不计入，消除后再给六个月）。

**中断细则（准用民法典第195条）**：有下列情形之一的，时效**中断**，**从中断、有关程序终结时起，时效期间重新计算**——① 权利人向义务人提出履行请求；② 义务人同意履行义务；③ 权利人提起诉讼或者申请仲裁；④ 与提起诉讼或者申请仲裁具有同等效力的其他情形。**在执行语境中的映射**：申请执行、双方达成执行和解、被执行人承诺履行/部分履行/提供担保等"同意履行"行为，均可构成中断事由。

**三条控制性规则**：① **法院不得主动适用**诉讼时效的规定（民法典第193条）——执行时效届满须由**被执行人提出抗辩**，法院不得依职权审查并主动驳回；② 时效的**期间、计算方法以及中止、中断的事由由法律规定，当事人约定无效**（第197条）；③ **除斥期间**（撤销权、解除权等权利的存续期间）**不适用**中止、中断和延长的规定，期间届满权利消灭（第199条）——**执行时效（可中止中断）与除斥期间（不可）必须分清**。

**特殊情形的时效处理（民诉法解释）**：① **终本后再次申请不受时效限制**——"终结本次执行程序后，申请执行人发现被执行人有可供执行财产的，可以再次申请执行。**再次申请不受申请执行时效期间的限制**"（第517条）；② **因撤销申请而终结执行后再申请的，须在二年时效内**——"因撤销申请而终结执行后，当事人在民事诉讼法第二百四十六条规定的申请执行时效期间内再次申请执行的，人民法院应当受理"（第518条）；③ 债权人依民诉法第261条（原第265条）请求继续执行，**不受**民诉法第246条（现为第250条）申请执行时效期间的限制（第515条）。

🔴 抗辩铁律：**执行时效届满不是"自动出局"，而是给被执行人一把抗辩的钥匙。** 依民法典第193条，法院**不得主动**援引时效驳回执行申请；被执行人**不提抗辩**，时效届满也照样执行。代理被执行人一方时，"时效届满"必须作为**主动抗辩**提出并举证。

## 适用案由与场景

适用于：① 申请执行时距法律文书确定的履行期限最后一日起**已逾二年**，被执行人提出时效抗辩；② 双方就**起算点**发生争议（履行期间的最后一日 / 分期履行的最后一期届满日 / 未规定履行期间的生效之日）（民诉法第250条）；③ 申请执行人主张**中止**（不可抗力、被控制等），被执行人否认障碍存在；④ 申请执行人主张**中断**（曾提出履行请求、被执行人同意履行、达成和解、申请执行），被执行人否认；⑤ 区分**执行时效与除斥期间**（第199条：撤销权、解除权存续期间不适用中止中断）；⑥ **终本后再次申请**（不受时效限制，第517条）与**撤销申请终结后再次申请**（须在时效内，第518条）的不同处理；⑦ 当事人以**约定**缩短、延长或排除执行时效（第197条：约定无效）。典型：判决2023年1月1日生效、要求2023年2月1日前履行；申请执行人2025年6月才申请执行，被执行人抗辩已过二年，申请执行人主张2024年3月曾与被执行人达成和解构成中断。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 时效**起算点**（履行期最后一日／分期最后届满日／生效日） | 主张未过时效方（通常为申请执行人） | 生效法律文书、履行期间约定、送达证明、生效证明 |
| **中止**事由存在（不可抗力、被控制等，民法典第194条） | 🔴 **申请执行人** | 不可抗力证明、人身受控材料、继承未确定材料、其他障碍证据 |
| 中止发生在**最后六个月内** | 申请执行人 | 障碍发生与持续的**时间证据**（与二年期间末段比对） |
| 中止原因**消除之日**（决定"满六个月"重新起算） | 申请执行人 | 障碍消除的时间证据 |
| **中断**事由存在（提出请求／同意履行／申请执行／同等效力情形，第195条） | 🔴 **申请执行人** | 催告函及送达凭证、被执行人承诺/还款/部分履行凭证、和解协议、担保材料、立案材料 |
| 中断后**程序终结时点**（决定重新计算的起点） | 申请执行人 | 和解终止/程序终结裁定或记录 |
| **时效届满**（被执行人抗辩的基础） | 🔴 **被执行人** | 生效文书与履行期届满日、申请执行立案时间，证明已逾二年且无中止中断 |
| 属**除斥期间**而非执行时效（第199条，不适用中止中断） | 主张适用除斥规则方 | 权利性质说明（撤销权/解除权等） |
| **终本后再次申请**（不受时效限制，第517条） | 申请执行人 | 前案终本裁定、发现可供执行财产的新证据 |
| **撤销申请终结后再次申请**（须在二年内，第518条） | 申请执行人 | 前案撤销申请终结的裁定、本次申请时间 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《执行程序若干问题解释》（法释〔2008〕13号·2020修正）本地未收录，其申请执行时效的具体适用条文标注待核填。

1. 《民事诉讼法》（2023修正）第250条（本地核填·现行有效）："申请执行的期间为二年。申请执行时效的中止、中断，适用法律有关诉讼时效中止、中断的规定。前款规定的期间，从法律文书规定履行期间的最后一日起计算；法律文书规定分期履行的，从最后一期履行期限届满之日起计算；法律文书未规定履行期间的，从法律文书生效之日起计算。"
2. 《民法典》第192条（本地核填·现行有效）："诉讼时效期间届满的，义务人可以提出不履行义务的抗辩。诉讼时效期间届满后，义务人同意履行的，不得以诉讼时效期间届满为由抗辩；义务人已经自愿履行的，不得请求返还。"
3. 第193条（本地核填·现行有效）："人民法院不得主动适用诉讼时效的规定。"
4. 第194条（本地核填·现行有效）："在诉讼时效期间的最后六个月内，因下列障碍，不能行使请求权的，诉讼时效中止：（一）不可抗力；（二）无民事行为能力人或者限制民事行为能力人没有法定代理人，或者法定代理人死亡、丧失民事行为能力、丧失代理权；（三）继承开始后未确定继承人或者遗产管理人；（四）权利人被义务人或者其他人控制；（五）其他导致权利人不能行使请求权的障碍。自中止时效的原因消除之日起满六个月，诉讼时效期间届满。"
5. 第195条（本地核填·现行有效）："有下列情形之一的，诉讼时效中断，从中断、有关程序终结时起，诉讼时效期间重新计算：（一）权利人向义务人提出履行请求；（二）义务人同意履行义务；（三）权利人提起诉讼或者申请仲裁；（四）与提起诉讼或者申请仲裁具有同等效力的其他情形。"
6. 第196条（本地核填·现行有效）："下列请求权不适用诉讼时效的规定：（一）请求停止侵害、排除妨碍、消除危险；（二）不动产物权和登记的动产物权的权利人请求返还财产；……"
7. 第197条（本地核填·现行有效）："诉讼时效的期间、计算方法以及中止、中断的事由由法律规定，当事人约定无效。当事人对诉讼时效利益的预先放弃无效。"
8. 第199条（本地核填·现行有效）："法律规定或者当事人约定的撤销权、解除权等权利的存续期间，除法律另有规定外，自权利人知道或者应当知道权利产生之日起计算，不适用有关诉讼时效中止、中断和延长的规定。存续期间届满，撤销权、解除权等权利消灭。"
9. 第200条（本地核填·现行有效）："民法所称的期间按照公历年、月、日、小时计算。"第201条（本地核填·现行有效）："按照年、月、日计算期间的，开始的当日不计入，自下一日开始计算。按照小时计算期间的，自法律规定或者当事人约定的时间开始计算。"第202条（本地核填·现行有效）："按照年、月计算期间的，到期月的对应日为期间的最后一日；没有对应日的，月末日为期间的最后一日。"
10. 《民诉法解释》（2022修正）第515条（本地核填·现行有效）："债权人根据民事诉讼法第二百六十一条规定请求人民法院继续执行的，不受民事诉讼法第二百四十六条规定申请执行时效期间的限制。"
11. 第517条（本地核填·现行有效）："经过财产调查未发现可供执行的财产，在申请执行人签字确认或者执行法院组成合议庭审查核实并经院长批准后，可以裁定终结本次执行程序。依照前款规定终结执行后，申请执行人发现被执行人有可供执行财产的，可以再次申请执行。再次申请不受申请执行时效期间的限制。"
12. 第518条（本地核填·现行有效）："因撤销申请而终结执行后，当事人在民事诉讼法第二百四十六条规定的申请执行时效期间内再次申请执行的，人民法院应当受理。"
13. 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉执行程序若干问题的解释》（法释〔2008〕13号·2020修正）第27~29条（申请执行时效的中止、中断及期间适用的具体规则）：**本地法条银行未收录，待核填**（statute_text_pending，正式文书引用前须以官方文本核验）。

## 攻防要点

- **攻方（申请执行人，主张未过时效）**：① 锁定**起算点**——通常以法律文书确定的**履行期间最后一日**为准；分期履行的以**最后一期届满日**为准（第250条），起算点越晚越有利；② 证明**中止**：障碍须落在**最后六个月内**（第194条），且要证明"原因消除之日"（决定再给六个月）；③ 证明**中断**：催告函 + 送达凭证、被执行人**同意履行/部分履行/提供担保**、和解协议、前次申请执行立案材料（第195条）；④ 用好**终本后再申请不受时效限制**（第517条）——这是实践中最常用的"续命"通道；⑤ 主张被执行人已**自愿履行或同意履行**，依第192条不得再以时效届满抗辩。
- **防方（被执行人，主张已过时效）**：① 以生效文书 + 履行期届满日 + 立案时间，计算已逾二年；② 逐项击破中止主张——障碍**不在最后六个月内**、**不构成"不能行使请求权"**、或已消除；③ 逐项击破中断主张——催告**未送达**、往来函件**不构成"提出履行请求"**、还款系**其他债务**、和解**未成立或已终止而期间未接续**；④ 主张申请执行人系**撤销申请终结**后再申请且已过二年（第518条），与终本情形区分；⑤ 警惕**除斥期间**抗辩不适用于执行时效（不搞混第199条）。
- **时间轴是唯一武器**：执行时效的一切争议都落在"某日发生了某事"上。整理**时间轴（生效日 → 履行期届满日 → 二年届满日 → 各中止/中断事件发生日 → 本次申请日）**，是这类案件的第一项工作。
- **法院不主动适用**（第193条）：被执行人若**未在原审或执行中提出时效抗辩**，法院不得主动驳回执行申请——这是申请执行人的程序保护，也是被执行人**必须主动抗辩**的理由。

## 质证话术模板

- 起算点"本案生效判决确定的履行期间为判决生效之日起十日内，判决于××年××月××日生效，依《民事诉讼法》第250条，申请执行期间自法律文书规定履行期间的最后一日起计算，即自××年××月××日起算二年，本次申请执行未过时效。"
- 中断"被执行人于××年××月××日与申请执行人达成执行和解并承诺分期履行，依《民法典》第195条第（二）项，'义务人同意履行义务'构成诉讼时效中断，时效期间自该日重新计算，本案申请执行时未过二年。"
- 中止"申请执行人因××（不可抗力/被义务人控制等），在二年期间的最后六个月内不能行使请求权，依《民法典》第194条，诉讼时效中止；该障碍于××年××月××日消除，自消除之日起满六个月时效期间方届满，本案申请执行在时效内。"
- 终本后再申请"前案已于××年××月××日裁定终结本次执行程序，本次申请系依《民诉法解释》第517条第2款'发现被执行人有可供执行财产的，可以再次申请执行'，'再次申请不受申请执行时效期间的限制'。"
- 被执行人的时效抗辩"本案生效法律文书确定的履行期为××年××月××日前，申请执行人首次申请执行的时间为××年××月××日，已逾二年，且无有效中止、中断事由。依《民法典》第192条，被执行人提出不履行义务的抗辩，恳请依法裁定不予执行。"
- 自愿履行后不得反悔"被执行人在时效期间届满后仍于××年××月××日向申请执行人履行××元，依《民法典》第192条第2款，'诉讼时效期间届满后，义务人同意履行的，不得以诉讼时效期间届满为由抗辩'。"

## 相关笔记

- **"二年"只是开始，起算点才是战场**：民诉法第250条给了三个起算规则（履行期最后一日／分期最后一期届满日／生效日）。实务中双方争的不是"是不是二年"，而是"从哪天开始数"。抓住起算点，往往直接决定胜负。
- **中止与中断的方向相反**：**中止**是"暂停"（障碍消除后**再给六个月**，民法典第194条），**中断**是"归零"（从中断或程序终结时起**重新计算二年**，第195条）。举证时要说清是"暂停"还是"归零"，两者法律效果完全不同。
- **法院不主动适用（第193条）是双向的**：对申请执行人是保护（对方不提抗辩，照样执行）；对被执行人是提醒（**必须主动抗辩并举证**，不抗辩等于放弃）。这条规则决定了"时效抗辩"在实务中的提出时机极为关键。
- **两种"再次申请"天差地别**：**终本后**再次申请 → **不受**时效限制（第517条）；**撤销申请终结后**再次申请 → **须在**二年内（第518条）。别把两者混为一谈。
- 🔴 **除斥期间不适用中止中断**（第199条）：撤销权、解除权等的存续期间，一天就是一天，不能中止不能中断。若把执行时效的规则套到除斥期间上，必错。
- 🔴 **条号位移**：解释第515、518条援引的"民诉法第246条"在现行法（2023）已位移——第246条现为执行检察监督条款，申请执行期间在**第250条**。
