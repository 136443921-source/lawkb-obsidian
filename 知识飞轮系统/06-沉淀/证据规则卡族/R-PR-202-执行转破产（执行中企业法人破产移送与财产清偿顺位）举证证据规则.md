# R-PR-202 执行转破产（执行中企业法人破产移送与财产清偿顺位）举证证据规则

## 裁判规则（证据规则·正向）

执行中作为被执行人的企业法人符合《企业破产法》第二条第一款规定情形（不能清偿到期债务，并且资产不足以清偿全部债务或者明显缺乏清偿能力）的，执行法院经申请执行人之一或者被执行人同意，应当裁定中止对该被执行人的执行，将执行案件相关材料移送被执行人住所地人民法院；被执行人住所地法院应在收到材料之日起三十日内就是否受理破产裁定告知执行法院，不予受理的退回材料、执行法院恢复执行；裁定受理破产的，执行法院解除保全、裁定终结对该被执行人的执行。当事人不同意移送破产或住所地法院不受理的，执行法院就执行变价所得财产，在扣除执行费用及清偿优先受偿债权后，对普通债权按查封、扣押、冻结财产的先后顺序清偿（民诉法解释第511—514条）。本卡聚焦三层举证：① 被执行人是否符合破产原因（资产/清偿能力）；② 移送破产同意主体与程序是否正当；③ 不受理破产后普通债权"按查封先后顺序清偿"与"按比例受偿"的界分（公民/其他组织适用参与分配按比例，企业法人不适用参与分配而按查封先后）。

## 适用案由与场景

适用于：① 被执行人为企业法人且财产不足以清偿全部债务，申请执行人或被执行人申请/同意移送破产；② 执行法院依职权或经同意裁定中止执行并移送破产材料；③ 住所地法院三十日内未告知裁定或裁定不予受理后的恢复执行争议；④ 受理破产后执行法院应否解除保全、终结执行；⑤ 当事人不同意移送或不受理破产后，普通债权按查封先后顺序清偿（与参与分配按比例受偿的界分）。典型：多个普通金钱债权人申请执行同一企业法人，部分债权人不同意移送破产，执行法院就变价款按首封先后清偿引发后顺位债权人异议。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 被执行人（企业法人）符合破产原因 | 申请/同意移送破产的一方（申请执行人或被执行人） | 资产负债表、审计报告、执行不能清偿的查证材料、终本裁定等证明"不能清偿到期债务+资产不足/明显缺乏清偿能力" |
| 移送程序经"申请执行人之一或被执行人同意" | 执行法院（程序正当性，依职权审查） | 同意移送的书面意见、执行法院中止执行裁定、移送材料清单 |
| 住所地法院是否受理破产 | 住所地法院（裁定告知） | 三十日内受理/不受理破产裁定（第512条） |
| 不受理破产后普通债权清偿顺位 | 主张首封优先的债权人 vs 主张比例受偿的债权人 | 各债权人查封、扣押、冻结时间节点证据、执行措施先后文书（第514条 vs 第508条界分） |
| 担保物权/优先受偿债权存在 | 主张优先受偿的债权人 | 抵押权登记、质权凭证、法定优先权依据（第514条"扣除优先受偿债权"） |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；企业破产法第二条第一款本地收录但未逐字核填，标注待核填。

1. 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第511条（本地核填·现行有效）："在执行中，作为被执行人的企业法人符合企业破产法第二条第一款规定情形的，执行法院经申请执行人之一或者被执行人同意，应当裁定中止对该被执行人的执行，将执行案件相关材料移送被执行人住所地人民法院。"
2. 第512条（本地核填·现行有效）："被执行人住所地人民法院应当自收到执行案件相关材料之日起三十日内，将是否受理破产案件的裁定告知执行法院。不予受理的，应当将相关案件材料退回执行法院。"
3. 第513条（本地核填·现行有效）："被执行人住所地人民法院裁定受理破产案件的，执行法院应当解除对被执行人财产的保全措施。被执行人住所地人民法院裁定宣告被执行人破产的，执行法院应当裁定终结对该被执行人的执行。被执行人住所地人民法院不受理破产案件的，执行法院应当恢复执行。"
4. 第514条（本地核填·现行有效）："当事人不同意移送破产或者被执行人住所地人民法院不受理破产案件的，执行法院就执行变价所得财产，在扣除执行费用及清偿优先受偿的债权后，对于普通债权，按照财产保全和执行中查封、扣押、冻结财产的先后顺序清偿。"
5. 《执行工作规定》（法释〔2020〕21号）第55条（本地核填·现行有效）："多份生效法律文书确定金钱给付内容的多个债权人分别对同一被执行人申请执行，各债权人对执行标的物均无担保物权的，按照执行法院采取执行措施的先后顺序受偿。多个债权人的债权种类不同的，基于所有权和担保物权而享有的债权，优先于金钱债权受偿。有多个担保物权的，按照各担保物权成立的先后顺序清偿。一份生效法律文书确定金钱给付内容的多个债权人对同一被执行人申请执行，执行的财产不足清偿全部债务的，各债权人对执行标的物均无担保物权的，按照各债权比例受偿。"
6. 第56条（本地核填·现行有效）："对参与被执行人财产的具体分配，应当由首先查封、扣押或冻结的法院主持进行。首先查封、扣押、冻结的法院所采取的执行措施如系为执行财产保全裁定，具体分配应当在该院案件审理终结后进行。"
7. 《企业破产法》第二条第一款（本地法条银行收录，待LTI逐字核填）：企业法人破产原因条款，作为第511条"符合企业破产法第二条第一款规定情形"的实体依据。

🔴 顺位界分铁律：公民或其他组织被执行人 → 适用参与分配，普通债权**按比例**受偿（民诉法解释第508条）；企业法人被执行人且不移送/不受理破产 → 普通债权**按查封先后顺序**清偿（第514条），不适用参与分配按比例。二者不得混淆。

## 攻防要点

- **攻方（后顺位/普通债权人）**：证明被执行人（企业法人）符合破产原因，推动移送破产以实现公平受偿；或在不移送时，证明自身查封时间先于对方以主张优先；质疑首封债权人查封时间的真实性（倒签、轮候未转首封）。
- **防方（首封债权人）**：稳固首封时间证据，主张按第514条先后顺序清偿；反对移送破产以免稀释受偿；证明被执行人不具备破产原因以阻断移送。
- **被执行人**：可主动同意移送破产以中止执行、赢得重整空间；但需承担破产原因举证责任。
- **程序节点**：住所地法院三十日告知期（第512条）为刚性期间，超期未告知可主张程序违法；受理破产后执行法院必须解除保全、终结执行（第513条），否则构成执行错误。

## 质证话术模板

- 主张移送破产："被执行人资产负债表显示净资产为负且经终本裁定确认无可供执行财产，符合《企业破产法》第二条第一款不能清偿到期债务且资产不足以清偿全部债务之情形，依民诉法解释第511条，申请执行人同意移送破产，请求裁定中止执行并移送被执行人住所地法院。"
- 反驳按比例受偿（企业法人）："被执行人为企业法人且未进入破产程序，依第514条普通债权应按查封先后顺序清偿，不适用第508条参与分配按比例规则，原告主张比例受偿无据。"
- 质疑首封时间："对方查封裁定载明的查封时间为×年×月×日，但本代理人调取的不动产登记簿显示该财产此前已为案外人查封/轮候，其'首封'实为轮候未转化为首封，顺位应后移。"

## 相关笔记

- 执行转破产是"执行不能"与"破产公平受偿"的衔接通道；律师代理多个债权人执行同一企业法人时，应第一时间评估破产原因与移送策略，避免陷入首封独享而自身后顺位落空。
- 第514条"按查封先后顺序"仅适用于普通债权且当事人不同意移送/不受理破产的情形；若存在担保物权等优先受偿债权，须先扣除（第514条但书）。
- 企业破产法第二条第一款待LTI逐字核填后，应将"资产不足以清偿全部债务"或"明显缺乏清偿能力"的证明标准（资产负债表、现金流、终本裁定等）补入本卡裁判规则。
