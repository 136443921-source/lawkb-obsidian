# R-PR-215 执行和解的担保（保证·物保与担保责任追究）举证证据规则

## 裁判规则（证据规则·正向）

在执行中，双方当事人**自行和解达成协议的**，执行员应当将协议内容**记入笔录**，由双方当事人签名或者盖章；申请执行人因**受欺诈、胁迫**与被执行人达成和解协议，或者当事人**不履行和解协议**的，人民法院可以**根据当事人的申请，恢复对原生效法律文书的执行**（民诉法第241条）。和解协议达成后请求中止执行或撤回执行申请的，人民法院可以裁定**中止执行或者终结执行**（解释第464条）。一方当事人不履行或者不完全履行和解协议的，对方申请执行**原生效法律文书**的，人民法院应当恢复执行，但和解协议**已履行的部分应当扣除**；和解协议**已经履行完毕**的，不予恢复执行（解释第465条）。申请执行期间因达成执行中和解协议而**中断**，自和解协议约定履行期限的最后一日起重新计算（解释第466条）。**和解担保的实体依据**：保证合同是为保障债权的实现，保证人和债权人约定，当债务人不履行到期债务或发生当事人约定情形时，保证人履行债务或承担责任的合同（民法典第681条）；保证人承担保证责任后，除当事人另有约定外，有权在其承担保证责任的范围内**向债务人追偿**，享有债权人对债务人的权利，但不得损害债权人利益（第700条）；保证人可以主张**债务人对债权人的抗辩**，债务人放弃抗辩的，保证人仍有权向债权人主张（第701条）。执行和解协议**约定担保条款**的（第三人保证或财产担保），担保人如何承担责任、是否可直接执行担保财产，由《执行和解规定》（法释〔2018〕3号）专门规范（本地暂无源，见法条依据段）。

🔴 和解担保的双层结构：**和解协议（主）+ 担保（从）**。被执行人不履行和解的，申请执行人可在**恢复执行原生效法律文书**（民诉法第241条、解释第465条）与**追究担保责任**之间选择；担保责任的范围与方式依其属**保证**还是**物保**，分别适用民法典保证规则或担保物权规则。

## 适用案由与场景

适用于：① 执行和解协议中约定**第三人保证**，被执行人不履行和解时，申请执行人请求**保证人承担责任**（衔接 R-PR-189）；② 和解协议中约定**财产担保**（抵押、质押），不履行和解时请求就担保财产受偿；③ 和解担保人主张**债务人对债权人的抗辩**（民法典第701条）而拒绝承担；④ 和解担保人承担后向被执行人**追偿**（第700条）；⑤ 和解协议因**欺诈、胁迫**达成的撤销与恢复执行（民诉法第241条）；⑥ **和解担保**与**执行担保**（民诉法第242条，暂缓执行的担保，R-PR-196）的区分。典型：申请执行人与被执行人达成分期还款和解协议，并由第三人提供连带责任保证；被执行人不履行后，申请执行人主张保证人承担保证责任。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 和解协议成立（入笔录、双方签名/盖章，第241条） | 主张和解成立方 | 执行笔录、双方签名或盖章、和解协议文本 |
| **担保条款成立**（保证/物保的意思表示） | **债权人（主张担保责任方）** | 保证书/保证条款、担保财产权属与登记、担保人签章 |
| 被执行人不履行或不完全履行和解（解释第465条） | **申请执行人** | 履行情况对账、部分履行的凭证、催告记录 |
| 恢复执行原文书及**扣除已履行部分**（第465条） | 申请执行人（主张恢复方） | 原生效法律文书、已履行部分凭证（用于扣除） |
| 和解协议已履行完毕（不予恢复，第465条） | **被执行人（主张已履行完毕方）** | 全部履行的收据、结清凭证 |
| 和解因**欺诈、胁迫**达成（第241条） | **主张撤销方（通常为申请执行人）** | 欺诈/胁迫的客观证据（虚假陈述、威胁记录等） |
| 保证人抗辩（民法典第701条）/免责事由 | **保证人** | 债务人对债权人的抗辩事由、债权人放弃物保致保证人减责的证据 |
| 保证人**追偿权**（民法典第700条） | 保证人（承担后） | 已承担保证责任的凭证、向债务人追偿的金额计算 |
| 和解担保与执行担保的区分 | 主张方 | 担保发生的**基础关系**（和解协议 vs 暂缓执行申请，第241条 vs 第242条） |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《执行和解规定》本地未收录，相关细化规则标注待核填。

1. 《民事诉讼法》（2023修正）第241条（本地核填·现行有效）："在执行中，双方当事人自行和解达成协议的，执行员应当将协议内容记入笔录，由双方当事人签名或者盖章。申请执行人因受欺诈、胁迫与被执行人达成和解协议，或者当事人不履行和解协议的，人民法院可以根据当事人的申请，恢复对原生效法律文书的执行。"
2. 《民诉法解释》第464条（本地核填·现行有效）："申请执行人与被执行人达成和解协议后请求中止执行或者撤回执行申请的，人民法院可以裁定中止执行或者终结执行。"
3. 第465条（本地核填·现行有效）："一方当事人不履行或者不完全履行在执行中双方自愿达成的和解协议，对方当事人申请执行原生效法律文书的，人民法院应当恢复执行，但和解协议已履行的部分应当扣除。和解协议已经履行完毕的，人民法院不予恢复执行。"
4. 第466条（本地核填·现行有效）："申请恢复执行原生效法律文书，适用民事诉讼法第二百四十六条申请执行期间的规定。申请执行期间因达成执行中的和解协议而中断，其期间自和解协议约定履行期限的最后一日起重新计算。"
5. 《民法典》第681条（本地核填·现行有效）："保证合同是为保障债权的实现，保证人和债权人约定，当债务人不履行到期债务或者发生当事人约定的情形时，保证人履行债务或者承担责任的合同。"
6. 第700条（本地核填·现行有效）："保证人承担保证责任后，除当事人另有约定外，有权在其承担保证责任的范围内向债务人追偿，享有债权人对债务人的权利，但是不得损害债权人的利益。"
7. 第701条（本地核填·现行有效）："保证人可以主张债务人对债权人的抗辩。债务人放弃抗辩的，保证人仍有权向债权人主张抗辩。"
8. 《最高人民法院关于执行和解若干问题的规定》（法释〔2020〕21号·2020修正，现行有效，qcc-legal 逐字核填；原法释〔2018〕3号经2020修正吸收）第十八条（和解担保条款的直接执行）："执行和解协议中约定担保条款，且担保人向人民法院承诺在被执行人不履行执行和解协议时自愿接受直接强制执行的，恢复执行原生效法律文书后，人民法院可以依申请执行人申请及担保条款的约定，直接裁定执行担保财产或者保证人的财产。"（注：直接执行担保财产／保证人财产以担保人向人民法院**承诺自愿接受直接强制执行**为要件，区别于一般保证追偿。）

🔴 区分铁律：**执行和解的担保**（和解协议中的第三人担保，本卡）≠ **执行担保**（民诉法第242条，被执行人或他人为**暂缓执行**提供的担保，R-PR-196）。前者从属于**和解协议**，后者从属于**暂缓执行**决定，救济路径与执行方式各不相同。

## 攻防要点

- **攻方（申请执行人）**：① 固定**担保条款**的证据（保证书、担保财产登记、担保人签章）；② 举证被执行人**不履行/不完全履行**和解，主张恢复执行原文书或**直接追究担保责任**；③ 就**欺诈、胁迫**达成的和解，举证撤销事由并请求恢复执行（第241条）；④ 计算**扣除已履行部分**（解释第465条），防止重复受偿。
- **防方（担保人）**：① 主张**担保未成立**（无书面、未签章、意思表示不真实）；② 以民法典第701条主张**债务人对债权人的抗辩**；③ 主张和解**已履行完毕**（解释第465条不予恢复）而免责；④ 就物保，主张**担保物权未有效设立**（未登记、未交付）；⑤ 区分和解担保与执行担保，攻击债权人**适用依据错误**。
- **保证人追偿**：保证人承担责任后依民法典第700条追偿，享有债权人对债务人的权利，但不得损害债权人利益。
- **和解中断时效**：解释第466条——和解致申请执行期间**中断**、自和解约定履行期最后一日起重新计算，是申请执行人对抗时效抗辩的重要依据（衔接 R-PR-206）。

## 质证话术模板

- 追究保证责任："被执行人与申请执行人达成的执行和解协议约定由本案保证人××承担连带保证责任（附和解协议及保证条款），被执行人不履行和解，依《民法典》第681条及和解协议约定，本代理人请求保证人××在保证范围内承担保证责任。"
- 恢复执行与扣除："被执行人不完全履行和解协议，依《民事诉讼法》第241条及《民诉法解释》第465条，请求恢复对原生效法律文书的执行，但和解协议**已履行的部分应当扣除**，本代理人已核算已履行金额××元。"
- 保证人抗辩（民法典第701条）："申请执行人主张的利息超出主债务范围，保证人依《民法典》第701条有权主张债务人对债权人的抗辩，对超出部分不承担保证责任。"
- 已履行完毕抗辩："和解协议约定的一切义务已由被执行人于×年×月×日全部履行完毕，依《民诉法解释》第465条，人民法院不予恢复执行，担保人亦不再承担责任。"
- 区分执行担保："债权人主张直接执行担保人财产，但本案第三人提供的担保系**和解协议项下的担保**，而非《民事诉讼法》第242条规定的**执行担保**；前者依《执行和解规定》处理，不得径行按执行担保规则执行担保人财产。"

## 相关笔记

- 执行和解+担保是实务中提高履行率的常用组合：**以第三人保证或财产担保换取被执行人分期履行**。代理申请执行人时，务必让担保条款**书面化、明确化**（保证方式、范围、期间），否则担保难以主张。
- **最高频的混淆**：和解担保（本卡）与执行担保（R-PR-196，民诉法第242条）——前者从属和解协议、后者从属暂缓执行决定，**基础法律关系不同，执行路径不同**，选错依据将导致主张落空。
- **保证人抗辩不可忽视**：保证人可主张债务人对债权人的抗辩（民法典第701条），甚至债务人放弃抗辩时保证人仍可主张——代理债权人时须预判保证人的抗辩空间。
- 🔴 《执行和解规定》（法释〔2020〕21号·2020修正，原法释〔2018〕3号）是和解担保**程序处理的直接法源**（担保条款效力、直接执行担保财产等），**已由 qcc-legal 逐字核填**（见法条依据段第8项第18条；2026-09-19），原卡待回源标记已清除。
