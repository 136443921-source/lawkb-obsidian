# R-PR-221 网络司法拍卖专门规则（拍卖优先·评估与保证金·流拍与以物抵债·成交裁定）举证证据规则

## 裁判规则（证据规则·正向）

**拍卖优先是执行变价的第一原则**：财产被查封、扣押后，执行员应当责令被执行人在指定期间履行；被执行人逾期不履行的，人民法院**应当拍卖**被查封、扣押的财产；**不适于拍卖**或者当事人双方同意不进行拍卖的，人民法院才可以委托有关单位变卖或者自行变卖（民诉法第258条）。**变卖是例外，拍卖是常态**。**网络司法拍卖**是司法拍卖的实现方式，其专门规则由《最高人民法院关于人民法院网络司法拍卖若干问题的规定》（法释〔2016〕18号）规范，与《关于人民法院民事执行中拍卖、变卖财产的规定》（法释〔2004〕16号·2020修正）共同构成拍卖变卖的完整规则体系（两文件本地法条银行**未收录，具体条文待核填**）。**本地有源的四组基础规则**：

① **方式选择与监督**——法院执行中需要拍卖被执行人财产的，**可以由人民法院自行组织拍卖，也可以交由具备相应资质的拍卖机构拍卖**；交拍卖机构拍卖的，人民法院应当**对拍卖活动进行监督**（民诉法解释第486条）。

② **评估与现场勘验的配合义务**——拍卖评估需要对现场进行检查、勘验的，人民法院应当责令被执行人、协助义务人予以配合；**不予配合的，人民法院可以强制进行**（第487条）。

③ **变卖与被执行人自行变卖**——需要变卖的，可以交有关单位变卖，也可以由人民法院直接变卖；**对变卖的财产，人民法院或者其工作人员不得买受**（第488条）；被执行人申请对查封财产**自行变卖**的，人民法院可以准许，但应当监督其按**合理价格在指定期限内**进行，并**控制变卖的价款**（执行工作规定第33项）。

④ **以物抵债与无法变价财产的处理**——经申请执行人和被执行人**同意**，且不损害其他债权人合法权益和社会公共利益的，人民法院可以不经拍卖、变卖，**直接将财产作价交申请执行人抵偿债务**，对剩余债务被执行人应当继续清偿（第489条）；财产**无法拍卖或者变卖**的，经申请执行人同意且不损害其他债权人及公共利益，可以**作价交付申请执行人抵偿债务或者交付其管理**；申请执行人拒绝接收或管理的，**退回被执行人**（第490条）。

⑤ **成交裁定与所有权转移时点**——拍卖成交或者依法定程序裁定以物抵债的，标的物所有权**自拍卖成交裁定或者抵债裁定送达买受人或者接受抵债物的债权人时转移**（第491条）。**价款与费用的清算**——拍卖、变卖成交后必须**即时钱物两清**；委托拍卖、组织变卖发生的**实际费用从所得价款中优先扣除**，超出执行标的与执行费用的部分**退还被执行人**（执行工作规定第34项）；担保物权财产的拍卖变卖价款，在**抵押权人、质押权人或留置权人优先受偿后**，其余额用于清偿申请执行人（第31项）；拍卖、变卖或以物抵债后需从现占有人处**交付**给买受人或申请执行人的，适用民诉法第249、250条及执行工作规定第41、42项（第43项）。

🔴 时点铁律：**所有权转移看"裁定送达"，不看"付款"或"交付"**。买受人或接受抵债物的债权人取得标的物所有权，以**拍卖成交裁定/抵债裁定送达**之时为准（解释第491条）——主张所有权、主张排除他人处分时，锚点在这一刻。

## 适用案由与场景

适用于：① 就执行财产**应采用拍卖还是变卖**发生争议（民诉法第258条拍卖优先）；② 被执行人或协助义务人**不配合评估现场检查、勘验**（解释第487条强制进行）；③ **被执行人申请自行变卖**被查封财产（执行工作规定第33项：合理价格、指定期限、控制价款）；④ **以物抵债**的成立条件（双方同意 + 不损害其他债权人及公共利益，解释第489/490条）；⑤ **流拍后**能否降价再拍、能否以物抵债、能否退还被执行人；⑥ **拍卖成交裁定送达时点**与所有权转移、买受人权利保护（第491条）；⑦ **拍卖佣金、评估费**等实际费用的优先扣除与退还（执行工作规定第34项，衔接 R-PR-218）；⑧ **拍卖标的腾退交付**（执行工作规定第43项，衔接 R-PR-211）。典型：房屋经网络司法拍卖成交，原占有人主张"未付款/未交房故所有权未转移"，买受人依成交裁定主张所有权已转移。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 财产**适于拍卖**（拍卖优先），或存在**不适于拍卖/双方同意不拍卖**的例外 | 主张变卖方 | 财产性质说明（鲜活、易腐、禁售等）、双方同意不拍卖的书面材料 |
| 交由拍卖机构拍卖时法院**已尽监督**（解释第486条） | 执行法院 | 委托拍卖材料、监督记录 |
| 被执行人或协助义务人**不予配合评估勘验** | 申请强制勘验方 | 通知与到场记录、拒绝配合的笔录、阻碍现场证据 |
| **变卖价格合理、期限指定、价款受控**（执行工作规定第33项） | 准许自行变卖方/被执行人 | 评估或市场价参考、指定期限文件、价款监管账户凭证 |
| **以物抵债**：双方同意 + 不损害其他债权人及公共利益（解释第489/490条） | 主张抵债方 | 双方同意书、其他债权人情况说明、财产作价依据 |
| 申请执行人**拒绝接收或管理**（第490条，退回被执行人） | 主张退回方 | 通知与拒绝记录 |
| **拍卖成交裁定/抵债裁定送达**时点（所有权转移） | 主张所有权者 | **送达回证**、成交裁定书、抵债裁定书 |
| **实际费用**优先扣除与超出部分退还（执行工作规定第34项） | 主张扣除/退还方 | 佣金发票、评估费票据、价款与执行标的对比计算 |
| 担保物权财产的**优先受偿后余额**（第31项） | 优先债权人/申请执行人 | 抵押权、质押权、留置权的设立与登记材料、优先受偿额计算 |
| 拍卖标的**交付/腾退**（第43项） | 买受人/申请执行人 | 成交裁定、交付通知、现占有人及占有依据 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《网络司法拍卖规定》（法释〔2016〕18号）与《拍卖变卖财产规定》（法释〔2004〕16号·2020修正）本地未收录，具体条文标注待核填。

1. 《民事诉讼法》（2023修正）第255条（本地核填·现行有效）："被执行人未按执行通知履行法律文书确定的义务，人民法院有权查封、扣押、冻结、拍卖、变卖被执行人应当履行义务部分的财产。但应当保留被执行人及其所扶养家属的生活必需品。采取前款措施，人民法院应当作出裁定。"
2. 第258条（本地核填·现行有效）："财产被查封、扣押后，执行员应当责令被执行人在指定期间履行法律文书确定的义务。被执行人逾期不履行的，人民法院应当拍卖被查封、扣押的财产；不适于拍卖或者当事人双方同意不进行拍卖的，人民法院可以委托有关单位变卖或者自行变卖。国家禁止自由买卖的物品，交有关单位按照国家规定的价格收购。"
3. 第262条（本地核填·现行有效）："在执行中，需要办理有关财产权证照转移手续的，人民法院可以向有关单位发出协助执行通知书，有关单位必须办理。"
4. 《民诉法解释》（2022修正）第486条（本地核填·现行有效）："依照民事诉讼法第二百五十四条规定，人民法院在执行中需要拍卖被执行人财产的，可以由人民法院自行组织拍卖，也可以交由具备相应资质的拍卖机构拍卖。交拍卖机构拍卖的，人民法院应当对拍卖活动进行监督。"
5. 第487条（本地核填·现行有效）："拍卖评估需要对现场进行检查、勘验的，人民法院应当责令被执行人、协助义务人予以配合。被执行人、协助义务人不予配合的，人民法院可以强制进行。"
6. 第488条（本地核填·现行有效）："人民法院在执行中需要变卖被执行人财产的，可以交有关单位变卖，也可以由人民法院直接变卖。对变卖的财产，人民法院或者其工作人员不得买受。"
7. 第489条（本地核填·现行有效）："经申请执行人和被执行人同意，且不损害其他债权人合法权益和社会公共利益的，人民法院可以不经拍卖、变卖，直接将被执行人的财产作价交申请执行人抵偿债务。对剩余债务，被执行人应当继续清偿。"
8. 第490条（本地核填·现行有效）："被执行人的财产无法拍卖或者变卖的，经申请执行人同意，且不损害其他债权人合法权益和社会公共利益的，人民法院可以将该项财产作价后交付申请执行人抵偿债务，或者交付申请执行人管理；申请执行人拒绝接收或者管理的，退回被执行人。"
9. 第491条（本地核填·现行有效）："拍卖成交或者依法定程序裁定以物抵债的，标的物所有权自拍卖成交裁定或者抵债裁定送达买受人或者接受抵债物的债权人时转移。"
10. 《执行工作规定》（法释〔2020〕21号）第31项（本地核填·现行有效）："人民法院对被执行人所有的其他人享有抵押权、质押权或留置权的财产，可以采取查封、扣押措施。财产拍卖、变卖后所得价款，应当在抵押权人、质押权人或留置权人优先受偿后，其余额部分用于清偿申请执行人的债权。"
11. 第33项（本地核填·现行有效）："被执行人申请对人民法院查封的财产自行变卖的，人民法院可以准许，但应当监督其按照合理价格在指定的期限内进行，并控制变卖的价款。"
12. 第34项（本地核填·现行有效）："拍卖、变卖被执行人的财产成交后，必须即时钱物两清。委托拍卖、组织变卖被执行人财产所发生的实际费用，从所得价款中优先扣除。所得价款超出执行标的数额和执行费用的部分，应当退还被执行人。"
13. 第43项（本地核填·现行有效）："被执行人的财产经拍卖、变卖或裁定以物抵债后，需从现占有人处交付给买受人或申请执行人的，适用民事诉讼法第二百四十九条、第二百五十条和本规定第41条、第42条的规定。"
14. 《最高人民法院关于人民法院网络司法拍卖若干问题的规定》（法释〔2016〕18号，2017-01-01施行）——规范**网络司法拍卖优先适用**、拍卖公告与信息公示、**保证金**交纳与**悔拍**的保证金不予退还、**流拍与降价再拍**（每次降价幅度限制）、**变卖与以物抵债**的衔接、拍卖财产的瑕疵与权利负担披露、拍卖成交后的价款交付与标的交付等：**本地法条银行未收录，待核填**（statute_text_pending，正式文书引用其具体条文前须以官方文本核验）。
15. 《最高人民法院关于人民法院民事执行中拍卖、变卖财产的规定》（法释〔2004〕16号·2020修正）——拍卖变卖的通用程序规定（评估、保留价、保证金、拍卖次数与降价、以物抵债、优先购买权等）：**本地法条银行未收录，待核填**（同上）。

🔴 **条号位移警示（本卡新增）**：《民诉法解释》第486条原文援引"**民事诉讼法第二百五十四条**"，而本地《民事诉讼法》（2023修正）**第254条实为"扣留、提取被执行人应当履行义务部分的收入"**（收入执行条款）；拍卖、变卖的执行措施依据现位于**第255条**，**拍卖优先**原则现位于**第258条**。援引拍卖变卖条文时，不得以解释内部援引的旧条号直接指代现行法，须逐条核验。

## 攻防要点

- **攻方（申请执行人/买受人）**：① 以**民诉法第258条"应当拍卖"**反驳被执行人"直接变卖更划算"的主张——拍卖是常态，变卖需具备"不适于拍卖或双方同意"的例外；② 被执行人**不配合评估勘验**时，申请法院**强制进行**（解释第487条）；③ 被执行人主张**自行变卖**的，要求其接受"合理价格 + 指定期限 + 价款受控"三项约束（执行工作规定第33项）；④ 买受人以**成交裁定送达回证**主张所有权已转移（解释第491条），对抗原占有人的"未付款/未交房"抗辩；⑤ 就实际费用主张**优先扣除、超出部分退还**（第34项，衔接 R-PR-218）；⑥ 拍卖标的腾退交付依第43项主张。
- **防方（被执行人/其他债权人）**：① 主张财产**不适于拍卖**（鲜活、易腐、禁售、价值极低）应行变卖，或主张**当事人双方同意不拍卖**；② 就**以物抵债**，主张未经其同意或**损害其他债权人合法权益和社会公共利益**（解释第489/490条），抵债不成立；③ 就**溢价分配**，主张担保物权人优先受偿后余额才归普通债权（第31项）；④ 就**拍卖程序瑕疵**（未公告、未评估、降价幅度违规、未披露权利负担），循**执行行为异议（民诉法第236条，衔接 R-PR-208）**；⑤ 主张**变卖价格明显低于市场价**损害其权益。
- **网拍特有的两个易错点**：**悔拍**与**降价再拍**的具体规则以《网络司法拍卖规定》为准（本地无源，具体幅度待核填）——在文书引用具体数字前务必回源核验，不得凭记忆填数。
- **拍卖与保护债权人利益的平衡**：以物抵债看似便捷，但"**不损害其他债权人合法权益和社会公共利益**"是硬条件；多个债权人时，抵债极易被其他债权人以该条件攻击。

## 质证话术模板

- 拍卖优先"对被执行人的财产，依《民事诉讼法》第258条，'被执行人逾期不履行的，人民法院应当拍卖被查封、扣押的财产'；被执行人主张直接变卖，但本案财产并非'不适于拍卖'，亦无当事人双方同意不拍卖的情形，故应依法拍卖。"
- 强制评估勘验"被执行人对拍卖前的现场检查、勘验不予配合，依《民诉法解释》第487条，'被执行人、协助义务人不予配合的，人民法院可以强制进行'，本申请人申请对涉案房屋强制进行现场勘验。"
- 成交裁定与所有权"本案标的物已由网络司法拍卖成交，成交裁定已于××年××月××日送达买受人。依《民诉法解释》第491条，'标的物所有权自拍卖成交裁定……送达买受人……时转移'，原占有人以未付款、未交房为由主张所有权未转移，于法无据。"
- 以物抵债的异议"本案执行财产未经申请执行人和被执行人双方同意，且作价明显低于市场价、损害其他债权人合法权益，不符合《民诉法解释》第489条规定的以物抵债条件，该抵债裁定应予纠正。"
- 费用优先扣除与退还"依《执行工作规定》第34项，'委托拍卖、组织变卖被执行人财产所发生的实际费用，从所得价款中优先扣除。所得价款超出执行标的数额和执行费用的部分，应当退还被执行人'，恳请核实本案佣金、评估费的扣除并按此退还超出部分。"

## 相关笔记

- **"应当拍卖"是命令句**：民诉法第258条用的是"人民法院**应当**拍卖"，不是"可以"。凡是主张走变卖、以物抵债的，都要先迈过"不适于拍卖或双方同意"这道门槛——这是实务中代理被执行人一方常被驳的点。
- **时点只认"裁定送达"**：所有权转移的锚点是**成交裁定/抵债裁定送达**（解释第491条），不是付款、不是交房、不是过户登记。买受人维权、原占有人抗辩，都要围绕"送达回证"这一份证据展开。
- **网拍规则"半本地化"的诚实处理**：民诉法解释第486~491条与执行工作规定第31/33/34/43项在本地有源，可以 verbatim 引用；但《网络司法拍卖规定》（法释〔2016〕18号）与《拍卖变卖财产规定》本地**暂无源**，涉及**保证金数额、悔拍后果、每次降价幅度、拍卖次数**等具体数字时，一律标 statute_text_pending，回源核验后再引用——绝不凭记忆填数字。
- 🔴 **条号位移**：解释第486条援引的"民诉法第254条"在现行法（2023）已位移——第254条现为收入执行条款，拍卖变卖依据在**第255条**，拍卖优先在**第258条**。
