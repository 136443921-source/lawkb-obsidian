# R-PR-207 仲裁裁决与公证债权文书执行（非诉执行依据·不予执行举证）举证证据规则

## 裁判规则（证据规则·正向）

对依法设立的仲裁机构的裁决，一方当事人不履行的，对方当事人可以向有管辖权的人民法院申请执行，**受申请的人民法院应当执行**（民诉法第248条前段）。但**被申请人提出证据证明仲裁裁决存在法定情形之一的，经人民法院组成合议庭审查核实，裁定不予执行**：（一）当事人在合同中没有订有仲裁条款或者事后没有达成书面仲裁协议的；（二）裁决的事项不属于仲裁协议的范围或者仲裁机构无权仲裁的；（三）仲裁庭的组成或者仲裁的程序违反法定程序的；（四）裁决所根据的证据是伪造的；（五）对方当事人向仲裁机构隐瞒了足以影响公正裁决的证据的；（六）仲裁员在仲裁该案时有贪污受贿，徇私舞弊，枉法裁决行为的（第248条中段）。**人民法院认定执行该裁决违背社会公共利益的，裁定不予执行**；裁定书应当送达双方当事人和仲裁机构（第248条后段）。**仲裁裁决被裁定不予执行的，当事人可以根据双方达成的书面仲裁协议重新申请仲裁，也可以向人民法院起诉**（第248条末段）。对公证机关依法赋予强制执行效力的债权文书，一方当事人不履行的，对方当事人可以申请执行，**受申请的人民法院应当执行；公证债权文书确有错误的，人民法院裁定不予执行**，并将裁定书送达双方当事人和公证机关（第249条）。人民法院制作的调解书的执行，适用执行程序编的规定（第245条）。涉外仲裁机构裁决的，一方当事人不履行的，对方当事人可以向**被申请人住所地或者财产所在地的中级人民法院**申请执行（第290条）。

🔴 结构要点：非诉执行依据采**"应当执行为原则、不予执行为例外"**的审查结构，举证责任以**被申请人（被执行人）**为主，且采**"提出证据证明"**的举证标准（非完全证明责任），与诉讼判决执行中被执行人几无抗辩空间形成鲜明对比。

## 适用案由与场景

适用于：① 被执行人以仲裁协议无效/未达成书面仲裁协议为由，申请不予执行仲裁裁决（第248条情形一）；② 裁决事项超出仲裁协议范围或仲裁机构无权仲裁（情形二）；③ 仲裁庭组成或程序违反法定程序（情形三）；④ 裁决所根据的证据系伪造（情形四）；⑤ 对方隐瞒足以影响公正裁决的证据（情形五）；⑥ 公证债权文书"确有错误"的认定与不予执行申请（第249条）；⑦ 涉外仲裁裁决向中级人民法院申请执行的管辖确定（第290条）。典型：买卖合同双方约定仲裁条款但一方主张未达成书面补充协议，裁决生效后被执行人申请不予执行；或以"公证债权文书给付内容不具体、违背事实"为由申请不予执行。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| **申请人（申请执行人）**：仲裁裁决执行力 | 申请执行人 | 仲裁裁决书及生效证明、仲裁协议（合同中的仲裁条款）、送达回证、被执行人未履行的证明 |
| 裁决事项**不属于仲裁协议范围/机构无权仲裁**（情形二） | **被申请人（提出抗辩方）** | 仲裁协议约定的仲裁事项范围、裁决书载明的裁决事项、合同标的与争议事项对照表 |
| **仲裁庭组成/程序违反法定程序**（情形三） | **被申请人** | 仲裁规则、仲裁员名册与选定记录、组庭通知、开庭通知及送达回证（证明未通知陈述机会） |
| 裁决所根据的**证据是伪造的**（情形四） | **被申请人** | 伪造证据的原件核验、鉴定意见、证言矛盾比对表、伪造行为的客观证据 |
| **对方隐瞒足以影响公正裁决的证据**（情形五） | **被申请人** | 该证据客观存在及对方持有的证明、未提交原因、足以影响公正裁决的关联性说明 |
| 仲裁员**贪污受贿徇私枉法**（情形六） | **被申请人** | 生效刑事判决/纪律处分决定等客观证据（此为客观证明事项，须客观证据支撑） |
| **违背社会公共利益**（第248条后段） | 法院依职权认定 | 通常涉及违背公序良俗、非法内容 |
| 受申请法院**应当执行**的适格性（管辖、执行依据形式要件） | 申请执行人 | 有管辖权法院的管辖连接点、债权文书公证赋予强制执行效力的证明文件 |
| **公证债权文书确有错误**（第249条） | **被申请人（提出不予执行抗辩方）** | 给付内容不明确的证明、与事实不符的证据、违反法律的依据；具体认定标准见法释〔2018〕18号（本地未收录，待核填） |
| 不予执行后的救济途径选择 | 被申请人 | 书面仲裁协议（可否重新仲裁）、可诉性判断 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；两份执行司法解释本地未收录，相关细化规则标注待核填。

1. 《民事诉讼法》（2023修正）第248条（本地核填·现行有效）："对依法设立的仲裁机构的裁决，一方当事人不履行的，对方当事人可以向有管辖权的人民法院申请执行。受申请的人民法院应当执行。被申请人提出证据证明仲裁裁决有下列情形之一的，经人民法院组成合议庭审查核实，裁定不予执行：（一）当事人在合同中没有订有仲裁条款或者事后没有达成书面仲裁协议的；（二）裁决的事项不属于仲裁协议的范围或者仲裁机构无权仲裁的；（三）仲裁庭的组成或者仲裁的程序违反法定程序的；（四）裁决所根据的证据是伪造的；（五）对方当事人向仲裁机构隐瞒了足以影响公正裁决的证据的；（六）仲裁员在仲裁该案时有贪污受贿，徇私舞弊，枉法裁决行为的。人民法院认定执行该裁决违背社会公共利益的，裁定不予执行。裁定书应当送达双方当事人和仲裁机构。仲裁裁决被人民法院裁定不予执行的，当事人可以根据双方达成的书面仲裁协议重新申请仲裁，也可以向人民法院起诉。"
2. 第249条（本地核填·现行有效）："对公证机关依法赋予强制执行效力的债权文书，一方当事人不履行的，对方当事人可以向有管辖权的人民法院申请执行，受申请的人民法院应当执行。公证债权文书确有错误的，人民法院裁定不予执行，并将裁定书送达双方当事人和公证机关。"
3. 第245条（本地核填·现行有效）："人民法院制作的调解书的执行，适用本编的规定。"
4. 第290条（本地核填·现行有效）："经中华人民共和国涉外仲裁机构裁决的，当事人不得向人民法院起诉。一方当事人不履行仲裁裁决的，对方当事人可以向被申请人住所地或者财产所在地的中级人民法院申请执行。"
5. 《最高人民法院关于仲裁裁决执行若干问题的规定》（法释〔2018〕5号）：申请执行的管辖、不予执行审查程序等细化规则（本地法条银行**未收录**，statute_text_pending，待官方源核填）。
6. 《最高人民法院关于公证债权文书执行若干问题的规定》（法释〔2018〕18号）："确有错误"的具体认定情形（本地法条银行**未收录**，statute_text_pending，待官方源核填，正式文书引用前须以 flk.npc.gov.cn / court.gov.cn 官方文本逐条核验）。

🔴 不予执行六情形是**封闭式法定事由**（第248条），不得类推扩张；被执行人主张情形外的其他瑕疵（如仲裁裁决说理不充分、仲裁员中立性质疑但无客观证据），法院不予支持。

## 攻防要点

- **攻方（被申请人/被执行人）**：严格对照第248条**六情形 + 社会公共利益**逐项举证。最有力的切入点是**情形一（无书面仲裁协议/无仲裁条款）与情形二（超范围、无权仲裁）**——只要仲裁协议根基不牢，整条执行路径即告崩塌；其次是**情形三（程序违法，尤其开庭通知未有效送达、剥夺陈述机会）**与**情形四（证据伪造）**。第六情形需刑事/纪律处分客观证据，纯猜测无法成立。公证债权文书则以举证"确有错误"（给付内容不具体、与事实不符等）为切入。
- **防方（申请执行人）**：① 以合同书、往来传真、聊天记录等证明**书面仲裁协议**的存在与效力（情形一双边击破）；② 以仲裁规则、组庭通知、送达回证证明**程序合法**（情形三击破）；③ 论证裁决事项**在仲裁协议约定的争议范围**内（情形二击破）；④ 对"证据伪造"抗辩，以该证据经质证且为对方提交、或早已在庭上核验为真，否定其伪造性；⑤ 提醒被申请人：不予执行裁定后仍可依书面仲裁协议重新仲裁或起诉（第248条末段），避免其误认程序终点。
- **不予执行 ≠ 债务消灭**：裁定不予执行后债权债务并不当然消灭，被执行人易误以为"裁定即脱债"，代理人须同步提示救济与重新申请仲裁/起诉的时效风险。
- **证据规模控制**：情形四、五须提交"证据存在性 + 对方持有/未提交 + 足以影响公正裁决"三层证明，单证难以支撑。

## 质证话术模板

- 无书面仲裁协议抗辩："双方签订的××合同第×条并未约定仲裁条款，事后亦未达成书面仲裁协议，依《民事诉讼法》第248条第一项，该裁决应予审查确认不予执行。"
- 超范围仲裁抗辩："本案仲裁协议约定的争议范围为'货物质量问题'，而××号裁决处理的却是逾期付款违约金及迟延利息，明显超出仲裁协议范围，属于第二项规定的情形，请求裁定不予执行。"
- 程序违法抗辩："仲裁庭组成人员变更组庭后未在法定期限内通知本代理人开庭，本人直至开庭日才知悉，剥夺了本代理人的陈述与辩论权利，符合第三项'仲裁的程序违反法定程序'的构成要件。"
- 证据伪造抗辩："××号裁决所依据的××份《收货单》上本代理人的签字系伪造，经×司法鉴定中心鉴定结论确认（附鉴定意见书），符合第四项'裁决所根据的证据是伪造的'情形，请求不予执行。"
- 公证债权文书错误抗辩："××公证处出具的赋予强制执行效力的债权文书仅载明'给付××公司人民币若干元'，给付数额与履行期限均不明确，不符合可执行执行依据的形式要件，属确有错误，请求裁定不予执行。"
- 阻断执行扩张："被申请执行人所提异议不符合第248条法定情形，受申请的人民法院本应依法执行；即便裁定不予执行，依该条末段其仍可依书面仲裁协议重新申请仲裁或另行起诉，债务并不消灭。"
