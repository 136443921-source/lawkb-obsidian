# R-PR-219 执行中的公司法人人格否认衔接（追加被执行人·另诉与执行异议之诉路径）举证证据规则

## 裁判规则（证据规则·正向）

**公司法人人格否认的实体依据是公司法第23条**：① **纵向否认**——公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担**连带责任**；② **横向否认**——股东利用其控制的**两个以上公司**实施前款行为的，各公司应当对任一公司的债务承担**连带责任**；③ **一人公司举证责任倒置**——只有一个股东的公司，**股东不能证明**公司财产独立于股东自己的财产的，应当对公司债务承担连带责任。**在执行程序中的衔接**存在两条路径，必须分清：**路径一（执行内变更/追加）**——限"**法定情形**"（民诉法解释第470~473条：法人分立合并→变更后的法人；法人或其他组织被注销→权利义务承受人；其他组织不能履行→执行对其承担义务的法人或个人财产；名称变更→变更后的主体；公民死亡→继承人或遗产），**追加股东是例外而非原则**，《变更追加规定》（法释〔2016〕21号）对可追加股东的**法定情形作了穷尽式列举**（未缴纳/未足额缴纳出资、抽逃出资、一人公司股东等）；**路径二（实体另诉或执行异议之诉）**——凡超出法定追加情形的主张（如滥用法人独立地位逃避债务的一般人格否认），执行法院**无权在执行程序内直接认定**，债权人应通过**另行提起法人人格否认之诉**或对追加裁定不服时提起**执行异议之诉**（衔接 R-PR-209）解决。

🔴 路径铁律：**"追加股东"是法定列举的例外，"人格否认"是实体审判事项。** 执行法院只能按《变更追加规定》列举的情形裁定追加；债权人主张"股东滥用法人独立地位逃避债务"的一般人格否认，**不能冀望执行法官在执行程序里直接认定**，须走实体诉讼。把实体否认硬塞进执行追加，是实务中最常见的路径错误。

## 适用案由与场景

适用于：① 公司作为被执行人无财产可供执行，债权人主张**股东出资不实、抽逃出资**，请求追加股东为被执行人（公司法解释三第13/14条 + 变更追加规定）；② 被执行人系**一人有限责任公司**，债权人主张股东财产与公司财产混同、请求追加股东（公司法第23条第3款，**举证责任倒置**）；③ 被执行人系**空壳公司**，实际控制人通过**多家公司转移财产**逃避债务，债权人主张横向人格否认（公司法第23条第2款）；④ 对执行法院**追加/不予追加**的裁定不服，判断应走**复议**还是**执行异议之诉**（衔接 R-PR-209）；⑤ 被执行法人**分立、合并、注销**后的主体承继（民诉法解释第470条）。典型：公司名下无财产，但其唯一股东个人账户与公司账户长期混同，债权人申请追加该股东为被执行人。

## 举证责任分配

| 争议焦点 | 举证负担方 | 关键证据 |
|---|---|---|
| 股东**未履行或未全面履行出资义务**（解释三第13条） | **债权人（申请人）** | 公司章程、股东出资记录、验资/审计报告、工商登记、银行进账凭证 |
| 股东**抽逃出资**及协助抽逃主体（第14条） | 债权人 | 虚假财报表、虚构债权债务转出、关联交易转出、资金流水 |
| **一人公司财产与股东财产混同**（公司法第23条第3款） | 🔴 **股东（举证责任倒置）** | 股东须举证财产独立：独立账簿、审计报告、财产分离凭证 |
| 股东**滥用法人独立地位、逃避债务、严重损害债权人利益**（第23条第1款） | 债权人（实体诉讼中） | 人格混同、财产混同、业务混同、过度支配与控制、资本显著不足等证据 |
| 股东**控制两个以上公司**实施否认行为（第23条第2款） | 债权人 | 股权控制关系、资金往来、人员/业务/财产交叉、同一实际控制人证据 |
| 被执行法人**分立、合并、注销**及权利义务承受人（解释第470条） | 申请人 | 工商变更/注销登记、合并协议、债权债务承继文件 |
| 追加裁定**是否属法定情形**（路径判断） | 申请人/审查方 | 《变更追加规定》列举情形与本案事实的对应 |

## 法条依据（本地核填·现行有效）

> 以下条文为法条银行本地权威源 verbatim 核填，标注「本地核填·现行有效」；《变更追加规定》（法释〔2016〕21号）本地未收录，追加股东的法定情形列举标注待核填。

1. 《公司法》（2023修订）第23条（本地核填·现行有效）："公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任。股东利用其控制的两个以上公司实施前款规定行为的，各公司应当对任一公司的债务承担连带责任。只有一个股东的公司，股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任。"
2. 《公司法解释三》（法释〔2020〕18号）第13条（本地核填·现行有效）："股东未履行或者未全面履行出资义务，公司或者其他股东请求其向公司依法全面履行出资义务的，人民法院应予支持。公司债权人请求未履行或者未全面履行出资义务的股东在未出资本息范围内对公司债务不能清偿的部分承担补充赔偿责任的，人民法院应予支持；未履行或者未全面履行出资义务的股东已经承担上述责任，其他债权人提出相同请求的，人民法院不予支持。……"
3. 第14条（本地核填·现行有效）："股东抽逃出资，公司或者其他股东请求其向公司返还出资本息、协助抽逃出资的其他股东、董事、高级管理人员或者实际控制人对此承担连带责任的，人民法院应予支持。公司债权人请求抽逃出资的股东在抽逃出资本息范围内对公司债务不能清偿的部分承担补充赔偿责任、协助抽逃出资的其他股东、董事、高级管理人员或者实际控制人对此承担连带责任的，人民法院应予支持；……"
4. 《民诉法解释》（2022修正）第470条（本地核填·现行有效）："依照民事诉讼法第二百三十九条规定，执行中作为被执行人的法人或者其他组织分立、合并的，人民法院可以裁定变更后的法人或者其他组织为被执行人；被注销的，如果依照有关实体法的规定有权利义务承受人的，可以裁定该权利义务承受人为被执行人。"
5. 第471条（本地核填·现行有效）："其他组织在执行中不能履行法律文书确定的义务的，人民法院可以裁定执行对该其他组织依法承担义务的法人或者公民个人的财产。"
6. 第472条（本地核填·现行有效）："在执行中，作为被执行人的法人或者其他组织名称变更的，人民法院可以裁定变更后的法人或者其他组织为被执行人。"
7. 第473条（本地核填·现行有效）："作为被执行人的公民死亡，其遗产继承人没有放弃继承的，人民法院可以裁定变更被执行人，由该继承人在遗产的范围内偿还债务。继承人放弃继承的，人民法院可以直接执行被执行人的遗产。"
8. 《变更追加规定》（法释〔2016〕21号）第14~22条（可追加股东的法定情形：未缴纳或未足额缴纳出资的股东、抽逃出资的股东、未经清算即注销的股东、一人公司股东、未经依法清算即办理注销登记的股东等）：**本地法条银行未收录，待核填**（statute_text_pending，正式文书引用前须以官方文本核验）。

🔴 **条号位移警示（本卡新增）**：《民诉法解释》第470条原文援引"**民事诉讼法第二百三十九条**"，而本地《民事诉讼法》（2023修正）**第239条实为"执行工作由执行员进行……"（执行机构与执行员条款）**；变更被执行人的实体依据现位于**第243条**（"作为被执行人的公民死亡的，以其遗产偿还债务。作为被执行人的法人或者其他组织终止的，由其权利义务承受人履行义务。"）。与 R-PR-205~207 已登记的条号位移同构，执行类条文援引须逐条核验现行条号，不得以旧条号直接指代。

## 攻防要点

- **攻方（债权人）**：① **先判路径**——股东出资不实、抽逃出资、一人公司混同属**执行内可追加**情形，走追加申请；一般"滥用法人独立地位逃避债务"属**实体否认**，须另诉。② 一人公司场景紧咬**举证责任倒置**（第23条第3款），要求股东证明财产独立，而非自己证明混同。③ 横向否认场景，用**股权控制关系 + 资金/人员/业务/财产交叉**的证据链证明"两个以上公司"为同一控制人操控（第23条第2款）。④ 对追加裁定不服，按 R-PR-209 的**复议/执行异议之诉分野**选对救济。
- **防方（股东/被执行人）**：① 主张本案不符合《变更追加规定》列举情形，**执行程序无权认定人格否认**，应告知债权人另行起诉；② 一人公司股东**主动提交独立账簿、审计报告**推翻混同推定（举证责任在己）；③ 论证公司财产独立、不存在混同、业务独立，或债务形成与股东行为无因果；④ 对追加提出异议，甚至提起**执行异议之诉**（自然人股东被追加时的路径）。
- **举证责任是胜负手**：一人公司（第23条第3款）是**倒置**，股东不举证即败；非一人公司（第23条第1款）是**谁主张谁举证**，债权人须扛全套混同证据。开打前先看公司是"一人"还是"多人"。
- **实体与程序的切换**：执行追加被驳回 ≠ 债权落空，可转**实体另诉**主张人格否认；反之，实体判决确认股东连带责任后，可据判决申请执行该股东。

## 质证话术模板

- 一人公司追加股东"被执行人××公司系一人有限责任公司，其唯一股东××个人财产与公司财产混同。依《公司法》第23条第3款，'只有一个股东的公司，股东不能证明公司财产独立于股东自己的财产的，应当对公司债务承担连带责任'，本申请人申请追加该股东为被执行人，请该股东举证证明其财产独立于公司。"
- 横向否认（多公司）"被执行人××公司无财产可供执行，其实际控制人通过控制的××公司、××公司转移资产、逃避债务。依《公司法》第23条第2款，'股东利用其控制的两个以上公司实施前款规定行为的，各公司应当对任一公司的债务承担连带责任'，本代理人提交股权控制关系、资金往来及人员交叉证据，主张各公司对本案债务承担连带责任。"
- 出资不实追加"××股东认缴出资××万元，实缴××万元，未履行出资义务。依《公司法解释三》第13条第2款，其应在未出资本息范围内对公司债务不能清偿部分承担补充赔偿责任，本申请人请求追加其为被执行人。"
- 路径抗辩（防方）"本申请人主张的系股东滥用公司法人独立地位、逃避债务的一般人格否认，属实体审理事项，非《变更追加规定》列举的执行内追加情形；执行法院无权在执行程序中直接认定，应告知债权人另行提起法人人格否认之诉。"

## 相关笔记

- **"追加"是清单，"否认"是审判**：执行法官能做的只是照着《变更追加规定》的清单裁定追加；一旦债权人主张的是"股东滥用法人独立地位逃避债务"这种需要实质判断的事项，执行程序就力不从心了。诉讼策略上必须先分清这两件事，再决定是**申请追加**还是**直接另诉**。
- **一人公司是天然的杠杆**：公司法第23条第3款把举证责任推给股东——债权人只要证明"公司是一人公司 + 债务未清偿"，剩下的由股东自证清白。实务中一人公司追加的成功率显著高于普通公司，原因就在这条倒置规则。
- **横向否认为"多壳公司"量身定做**：第23条第2款让债权人可以绕过逐层穿透，直接主张各公司对任一公司债务连带负责，是对付"金蝉脱壳"式逃债的利器。
- 🔴 **条号位移**：民诉法解释第470条援引的"民诉法第239条"在现行法（2023）已位移——第239条现为执行机构条款，变更被执行人依据在**第243条**。写文书援引时须以现行条号为准。
