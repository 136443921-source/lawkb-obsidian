# 黄赌类案件主体辩护三刀｜经验卡片

## 核心要点
1. **年龄刀**：除强奸罪满14周岁外，黄赌类普遍满16周岁才担刑责；周岁按公历生日第二天起算（法释〔2006〕1号第2条）；跨年龄段时间轴分段切割；交叉核验出生医学证明、接种本、入学登记、医院存根。
2. **性别刀**：强奸罪正犯传统上锁男性，但女性可构成共犯/主犯/间接正犯（事实支配路径）；强制侮辱罪对象仍限妇女（辱男不定此罪）。
3. **身份刀**：
   - 照护职责人员性侵罪（刑法第236条之一）：对满14不满16的未成年人负有监护/收养/看护/教育/医疗等特殊职责人员，自愿也入罪；
   - 婚内强奸：三道例外口子（登记未同居+坚持离婚、感情破裂长期分居、离婚诉讼期间），辩"夫妻关系存续+感情未破裂"；
   - 聚众淫乱罪只打首要分子+多次参加者（3次以上）；组织卖淫正犯=组织者，招募运送保镖管账=协助组织卖淫（法释〔2017〕13号第4条），但书：有照会所洗浴的保洁收银保安干正常劳务不认定；
   - 赌博机开设赌场重点打出资者经营者，受雇接送望风发牌未分利润一般不追刑责。
4. **五坑警示**：满14≠万能（八罪限制）；女嫌疑人≠从犯；结婚证≠绝对盾牌/废纸；会所上班≠协助卖淫；偶尔与幼女发生关系非免死金牌（自愿+轻微+无严重后果三条件）。

黄赌类刑事案件辩护、主体资格审查、罪名定性异议、量刑辩护。
