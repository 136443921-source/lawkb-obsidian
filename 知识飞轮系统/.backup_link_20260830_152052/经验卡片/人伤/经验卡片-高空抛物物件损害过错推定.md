# 经验卡片 - 高空抛物物件损害过错推定

## 规则锚定（源自 R-PI-133 / R-PI-135 / R-PI-136）

- **高空抛物**（第1254条，R-PI-133）：难以确定具体侵权人的，除能证明自己不是侵权人外，由**可能加害的建筑物使用人**给予**补偿**（公平分担，非过错赔偿）；物业未采必要安保措施的依第1198条担责；公安应依法及时调查；补偿后可向查明的侵权人追偿。
- **范围限定**：可能加害使用人限于物理上可能抛掷/坠落到达事发地点的专有部分使用人，非全楼连坐（R-PI-133 反向提示）。
- **搁置物脱落坠落**（第1253条，R-PI-135）：所有人/管理人/使用人过错推定；窨井等地下设施（第1258条，R-PI-136）管理人过错推定。
- **性质区分**：补偿≠赔偿，金额可按公平原则酌定，非按全部损失填平。

## 办案动作清单
- 原告：证明"从建筑物抛出/坠落" + 列物业共同被告。
- 住户被告：物理不可能抗辩排除。
- 物业：安保措施留痕减责/免责。
