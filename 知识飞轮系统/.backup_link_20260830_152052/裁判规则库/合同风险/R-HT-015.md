# R-HT-015 老年人意定监护协议-范本与审查要点（裁判规则）

## 规则摘要
- 意定监护的核心条款为**《民法典》第33条**：具有完全民事行为能力的成年人，可以与其近亲属、其他愿意担任监护人的个人或者组织**事先协商，以书面形式**确定自己的监护人，在自己丧失或者部分丧失民事行为能力时，由该监护人履行监护职责。

## 适用要点
- 意定监护的核心条款为《民法典》第33条：具有完全民事行为能力的成年人，可以与其近亲属、其他愿意担任监护人的个人或者组织事先协商，以书面形式确定自己的监护人，在自己丧失或者部分丧失民事行为能力时，由该监护人履行监护职责。
- 与法定监护、指定监护的根本区别：意定监护依被监护人（甲方）生前自主合意产生，且乙方监护资格顺位优先于甲方的法定监护人（范本第13条）。
- 协议目的（第1条）：须明确以保障甲方人身、财产及其他合法权益为目的，覆盖监护关系建立、职责范围、委托代理、临时照料、行为能力鉴定等。
- 监护事项（第2条）：范本采取"概括授予 + 列举"模式，列举八大类——人身照管、医疗照护、财产管理、文件保管、民生保障、非讼及诉讼法律事务、殡葬、遗产管理。审查时注意第2.3条"详细列举系为顺利履职而明确，并不否认监护权概括授予"。
- 委托代理（第3条）：适用于甲方尚未丧失行为能力但身体/认知衰退无法亲自处理事务时。重点审查：
- 第3.2条授权事项须由甲方依需求勾选（人身/医疗/财产/文件/民生/其他），因涉人身保障与财产处分，"请慎重选择"；

## 反例 / 常见错误
- 实务提示：监督人（丙方）的设置是本协议区别于普通委托协议的关键防线，审查时不应省略；财产管理人与监护人分离可进一步降低利益冲突风险。
- 监护启动（第5条）：约定乙方应及时向法院申请行为能力宣告的触发情形（丧失语言交流、意外致不能辨识、疾病致不可逆认知障碍等）；宣告前乙方依第4条履行临时照料，并第一时间告知丙方。
- 财产管理人限制（第10条）：不得自行或以甲方名义实施——对外借贷、对外担保、购置不动产/奢侈品、更改人寿保险受益人、放贷/参股/信托/炒股等融资活动、向乙方丙方或其近亲属单方面大额赠与。非同时具备"维护甲方利益 + 合理财产安排（公证提存/养老服务信托）+ 征得丙方同意"三要件，不得处分甲方财产。
- 财产处分"概括授权"陷阱：第10条已作负面清单，审查时须确认未通过其他条款变相扩大乙方财产处分权。
