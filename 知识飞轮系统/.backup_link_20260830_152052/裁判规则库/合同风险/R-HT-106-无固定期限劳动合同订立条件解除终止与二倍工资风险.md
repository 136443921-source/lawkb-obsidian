# R-HT-106 无固定期限劳动合同订立条件、解除终止与二倍工资风险

## 裁判规则
用人单位在劳动者连续工作满十年、连续订立二次固定期限劳动合同后续订、或初次实行劳动合同制度/国企改制时满十年且距退休不足十年等法定情形下，劳动者提出或同意续订的，必须订立无固定期限劳动合同；应订未订的，自应当订立之日起按月支付二倍工资。无固定期限合同无"期满终止"，解除仍适用《劳动合同法》第36-41条，但不得违反第42条禁止情形，违法解除的按经济补偿二倍支付赔偿金。

## 适用要点
1. "连续二次"以实际订立次数计，第二次合同到期续订即第三次签约，选择权在劳动者。
2. 通过关联单位轮换签约、强迫辞职重签规避工龄连续性的，原年限仍合并计算（实施条例第10条）。
3. 用工满一年未签书面合同的，视为已订立无固定期限合同并应立即补订，此前期间按月付二倍工资。
4. "自愿放弃签订无固定期限合同/自愿放弃社保"条款因违反强制性规定无效。
5. 由固定转无固定属续订，不得再次约定试用期；违法约定的试用期已履行的按期满月工资标准赔偿。

## 援引法条
《劳动合同法》第14条、第19条、第22条、第23条、第25条、第42条、第44条、第48条、第82条、第83条、第87条；《劳动合同法实施条例》第7条、第9条、第10条。
