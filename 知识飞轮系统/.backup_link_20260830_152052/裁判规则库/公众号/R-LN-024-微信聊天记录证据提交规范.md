# R-LN-024 微信聊天记录证据提交规范——三性审查·原始载体·完整无删改

## 规则表述
1. **属性定位**：微信记录属《民事诉讼法》第66条法定「电子数据」；真实性为三性审查核心难点。
2. **三性框架**：真实性（生成/存储/传输完整未被篡改）、合法性（取得不违法）、关联性（指向具体主体与待证事实）。
3. **举证铁三角**：①主体身份固定（个人信息页截图+对话确认+必要时法院向腾讯调证）；②原始载体保全（手机不得刷机格式化）；③内容完整无删改（连续编页、禁选择性截取）。
4. **增强真实性**：公证或区块链存证依《民事证据规定》第94条推定真实；存疑电子数据不能单独定案，须结合其他证据形成证据链。

## 适用场景
民间借贷、买卖合同、劳动争议等以微信沟通为核心的民商事举证；电子数据的取证、举证、质证。

## 攻防要点
- 微信证据败诉多因「三无」：无原始载体、无主体锁定、无完整性。立案前即发《取证告知书》禁止刷机。
- 对方常以「非本人使用」「已删改」抗辩，前置公证/存证可阻断争议。
- 不得仅交截图而丢失原始载体（上诉/再审仍须当庭演示）。

## 法条依据
《民事诉讼法》（2023修正）第66条；《民诉法解释》（2022修正）第116条；《民事证据规定》法释〔2019〕19号第14/15/23/90/93/94条；《人民法院在线诉讼规则》（2021）第16-19条。
