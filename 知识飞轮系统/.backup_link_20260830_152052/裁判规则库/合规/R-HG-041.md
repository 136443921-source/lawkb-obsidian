# R-HG-041 企业合规管理体系框架与治理架构

## 规则要旨
企业合规管理体系=**建立合规制度+完善运行机制+培育合规文化+强化监督问责**四要素。治理架构分层：党委（党组织）领导 → 董事会决策监督 → 经理层执行 → 主要负责人第一责任人（重大决策法律与合规双审制）→ 合规委员会统筹 → 首席合规官/业务及职能部门/监督部门各负其责。

## 合规要求四层
国家监管要求（法规/强制国标/监管规定/司法解释/党内法规）｜行业自律要求（规范/标准/惯例/最佳实践）｜国际监管要求（条约/规则/趋势）｜企业内部要求（章程/制度/承诺/合同义务）。

## 适用提示
- 依据 GB/T35770:2022 与 ISO37301:2021（国际通行的合规管理体系标准）。
- 指引非强制，但可作为律师执业质量基准与合规体检框架。
- 国企须强调党委(党组)统领；非公企业可由最高决策机构统筹。
