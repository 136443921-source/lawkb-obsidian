# R-CF-079 规章制度须民主程序制定公示告知方有效慈善组织劳动人事制度可参照

## 裁判规则

依《劳动合同法》第4条及最高法劳动争议司法解释（一）第50条，用人单位规章制度须同时满足**内容合法+程序民主+公示告知**三要件方可作为确定双方权利义务的依据：经职工代表大会或全体职工讨论、与工会或职工代表平等协商确定，并向劳动者公示或告知。举证责任在用人单位（三重证明：程序合法性/内容合法性/公示告知有效性）。母公司制度不能当然适用于子公司，须经本公司民主程序转化。口头宣布的制度、仅张贴公告无签收记录的，劳动争议中不予采信。

## 适用场景

慈善组织（基金会/社会团体/社会服务机构）内部劳动人事制度（员工手册/薪酬/奖惩）制定合规；劳动争议代理。

## 操作要点

1. 五步流程：起草→民主讨论→协商确定→公示告知→签收存档，步步留痕；
2. 七种公示方式组合使用（手册发放/培训/合同附件/考试/传阅/入职声明/OA），仅张贴公告不可取；
3. 制度全生命周期档案保存至员工离职后两年，法律更新后及时修订重走程序；
4. 依据《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》劳动人事章执行。
