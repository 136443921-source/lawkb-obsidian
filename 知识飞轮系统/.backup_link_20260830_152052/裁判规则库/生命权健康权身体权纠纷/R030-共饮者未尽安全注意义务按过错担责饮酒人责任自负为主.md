# R030 共饮者未尽安全注意义务的按过错担责，饮酒人责任自负为主

## 规则表述

共同饮酒属"情谊行为"，本身不产生法律关系；但共饮行为使饮酒人陷入危险状态后，基于先行行为，共饮者对彼此附随产生安全注意义务（提醒、劝阻、通知、扶助、照顾、护送、救助）。未履行该义务致人损害的，按**一般过错责任**认定，**按份责任**为主（无共同故意）；完全民事行为能力饮酒人对自身安全负最高注意义务，原则上自担主要责任，共饮者仅在特定情形下承担次要责任（常见担责比例 0.4%~10%）。

## 法律依据

- 《民法典》第1165条（过错责任）、第1172条（分别侵权按份责任）、第1173条（过失相抵）
- 贵州高院《共同饮酒者侵权责任纠纷案件审判要件指南》（黔高法〔2025〕189号）

## 要件拆解

1. 损害结果：酒精中毒、酒后意外（跌伤、溺亡、交通事故、猝死）等
2. 主观过错：强行劝酒的故意 / 违反安全注意义务的过失（理性人标准）
3. 不当行为：作为（强制劝酒、灌酒、赌酒）/ 不作为（未尽提醒、劝阻、照顾、救助、通知、护送）
4. 因果关系：不当行为与损害间具有直接或间接因果关系（有介入因素时综合四因素判断）

## 重点情形

- **明知不能饮酒仍劝酒**（高血压、心脏病、酒精过敏、服头孢）→ 不能以"曾劝阻"免责
- **放任酒驾**：明知饮酒且驾车回家未劝阻 → 担责；故意隐瞒驾车意图或经劝阻执意驾车 → 共饮者免责
- **组织者/邀请人**注意义务重于普通参与者
- **未成年人**：共饮者明知未成年人饮酒未尽提醒劝阻 → 承担比成年受害人更重过错责任
- 同桌各自饮酒未劝酒、中途离席者（离席时无明显醉态）、未饮酒未劝酒者 → 一般不担责
