# R-PI-090 群众性活动组织者的安全保障义务

## 规则表述

群众性活动的组织者负有安全保障义务，应当采取合理防范措施（人流管控、安全警示、应急预案、现场安保）。因组织混乱、管控缺位致参与者人身损害的，组织者依第 1198 条承担直接责任或第三人侵权时的补充责任。但参与者**擅自进入禁区、无视明确警示、自陷风险**的，可相应减轻或免除组织者责任。

## 要件

1. 活动属"群众性活动"（展会、赛事、促销、演出、婚庆等聚集性活动）；
2. 组织者未尽合理管控（超承载量、无分流、无警示、无应急）；
3. 损害与管控缺失具因果关系；
4. 参与者故意违规/自陷风险可作为减责抗辩。

## 适用要点（攻防）

- **参与者（攻）**：举证组织者超限承载、无安保预案、未及时救助；
- **组织者（防）**：举证已设最大承载量、清晰警示、现场安保与应急流程，主张受害人自陷风险减责。
