# R-PI-007 交通事故责任认定与保险理赔顺位（裁判规则）

## 规则摘要
- **交通事故认定书**（《道路交通安全法》第73条）是处理案件的**证据**，非行政确认行为，当事人不能单独就其提起行政诉讼。

## 适用要点
- 交通事故认定书（《道路交通安全法》第73条）是处理案件的证据，非行政确认行为，当事人不能单独就其提起行政诉讼。
- 责任比例常见格式：全责/主责（70%-90%）/同责（50%）/次责（10%-30%）/无责。
- 第一层：交强险（有责/无责分项限额）—— 不分责任比例，先行赔付
- 第二层：商业三者险（按保险合同+责任比例）
- 第三层：侵权人自负（按事故责任比例）
- 关键：交强险在责任限额内不区分事故责任比例据实赔付（先赔），这是与商业险最大的差异。

## 反例 / 常见错误
- 列明被告：侵权人 + 交强险保险人 + 商业险保险人一并列为被告，避免二次诉讼。
