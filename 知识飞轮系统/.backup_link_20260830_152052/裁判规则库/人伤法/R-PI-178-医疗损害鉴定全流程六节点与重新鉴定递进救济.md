# R-PI-178 医疗损害鉴定全流程六节点与重新鉴定递进救济

## 规则摘要
医疗损害鉴定成败多在鉴定开始前：申请时机、事项写法、材料质证、书面异议质量、救济顺序任一失控即输。鉴定意见仅为证据非判决，须过质证由法院独立判断。

## 六节点
1. **要不要鉴定**：只解决专门性事实（过错/因果/原因力），不解决责任划分/法律适用。
2. **申请时机红线**：法院指定期间提出+预交费，逾期视为放弃；负举证责任方不申请/不交费/不提供材料→举证不能。一审举证阶段定死，二审才想起已晚。
3. **申请写法**：只问专业问题，勿写"请求鉴定医院担全责"（把法律问题交鉴定人，法院退回）。合格："诊疗有无过错；如有，过错与损害因果及原因力大小"。
4. **材料地基**：《委托鉴定审查规定》——未经质证材料（含补充）不得作鉴定材料；有争议材料由法院认定。对方私递补充病历须提异议。
5. **书面异议五要素**：定位/前提(依据材料参数)/问题(违反何规则)/影响/请求(解释补正出庭)。可申专家辅助人出庭。
6. **救济顺序**：书面解释→补正→补充鉴定/质证→鉴定人出庭→最后重鉴。重鉴四类：无资格/程序严重违法/依据不足/其他不能作证据。

## 关键判例
- **指导案例24号**：受害人体质状况（骨质疏松）不属减轻侵权人责任法定情形→原因力≠责任比例，法院不机械按参与度打折。
- 公报(2021)最高法民终1079号：比例尺瑕疵不影响核心意见，不准重鉴→瑕疵≠推翻，异议质量胜数量。
