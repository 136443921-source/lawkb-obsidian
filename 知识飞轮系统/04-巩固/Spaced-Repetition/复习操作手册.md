## 🎯 核心机制（先读懂这一条）

**自动化判断"已复习"的唯一方式 = 修改笔记 frontmatter 中的 `review_date`**。

`refresh_review_queue.py` 只扫描 5 个字段：

| 字段 | 含义 | 示例 |
|---|---|---|
| `review_date` | 下次复习日期（核心，脚本按它与今天的差值判定到期） | `2026-09-14` |
| `importance` | 重要性 1-5 | `5` |
| `repetition` | 累计复习次数 | `1` |
| `interval` | 当前间隔天数 | `25` |
| `ease_factor` | 容易因子 EF（默认 2.5，下限 1.3） | `2.5` |

复习完成后把 `review_date` 推到未来 → 下次扫描自动从"待复习池"消失。**没有独立"已复习"按钮，改日期即标记。**

## 📋 复习五步法

### Step 1️⃣ 定位待复习笔记

- **方式 A（Dataview）**：任意笔记中写入并查看：
  ```dataview
  TABLE review_date, importance
  FROM ""
  WHERE review_date <= date(today)
  SORT importance DESC, review_date ASC
  LIMIT 50
  ```
- **方式 B（搜索）**：搜索 `review_date:2026-08-20` 定位某天到期；或打开 `复习队列.md` 查看清单。

### Step 2️⃣ 打开笔记 → 读完 → 自评

| 评分 | 记忆质量 | 判断标准 |
|---|---|---|
| 0-2 | 忘了/答错 | 提示也想不起来，需重学 |
| 3 | 勉强记住 | 反复看能想起，但表述不清 |
| 4 | 较好记住 | 闭眼能讲出核心要点（**默认档**） |
| 5 | 完美记住 | 能给别人讲一遍，能举一反三 |

### Step 3️⃣ 改 frontmatter（手动 或 一键模板）

- **一键方式（推荐）**：`Ctrl+Shift+T` → 选择「复习回写」模板 → 输入评分 q → 自动算好写入 5 字段。
- **手动方式**：按下表算好新值后直接编辑 frontmatter。

### Step 4️⃣ SM-2 速查表

| 评分 (q) | repetition | interval 计算 | ease_factor | 下次 review_date |
|---|---|---|---|---|
| 0-2 | 不变 | 重置为 1 | 下调（下限 1.3） | 今天 + 1 |
| 3 | +1 | 不变 | 不变 | 今天 + 当前 interval |
| 4（默认） | +1 | × EF | 不变 | 今天 + 新 interval |
| 5 | +1 | × EF × 1.1 | 不变 | 今天 + 新 interval |

> repetition=0 首次过 q≥3：interval 直接 = 1，repetition = 1。

### 批量回写脚本（5+ 篇时用）

位置：`知识飞轮系统/04-巩固/scripts/review_writeback.py`
用法：
```bash
# dry-run 预览（不写盘）
python3 review_writeback.py --pairs "笔记A:4,笔记B:5,笔记C:2"

# 确认后正式写入
python3 review_writeback.py --pairs "笔记A:4,笔记B:5,笔记C:2" --apply
```
安全铁律：默认 dry-run；`--apply` 前自动备份被修改文件到 `.review-backup-<日期>/`。

## ⚠️ 常见坑

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 只改 `review_date` 不改其余字段 | 统计失真（永远显示复习 0 次） | 5 字段一起改 |
| 日期写 `8/20` 而非 `2026-08-20` | 脚本正则匹配不到 → 笔记被剔除复习池 | 严格 ISO 格式 |
| 习惯性给 q=5 | 间隔越拉越长 → 2 个月后遗忘崩盘 | 大多数给 4，少量完美掌握给 5 |
| 忘记更新 `updated` | 无实际影响，但失去审计轨迹 | 一并更新 `updated: YYYY-MM-DDTHH:mm` |
