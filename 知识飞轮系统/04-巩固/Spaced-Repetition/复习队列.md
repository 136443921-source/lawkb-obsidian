## 五、SM-2算法说明

### 5.1 算法参数

| 参数 | 说明 | 初始值 |
|------|------|--------|
| `repetition` | 复习次数 | 0 |
| `ease_factor` (EF) | 容易因子 | 2.5 |
| `interval` | 复习间隔（天） | 1 |
| `review_date` | 下次复习日期 | 创建日期 + interval |

### 5.2 算法流程

1. **首次复习**（repetition = 0）：
   - interval = 1天
   - 下次复习：明天

2. **第二次复习**（repetition = 1）：
   - interval = 6天
   - 下次复习：6天后

3. **后续复习**（repetition ≥ 2）：
   - interval = interval × EF
   - 下次复习：interval天后

4. **更新EF**（基于复习评分q，0-5分）：
   - EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))
   - EF' ≥ 1.3（下限）

### 5.3 复习评分标准

| 评分 | 记忆质量 | 处理方式 |
|------|----------|----------|
| 0-2 | 忘记或错误 | interval重置为1，repetition不变 |
| 3 | 勉强记住 | interval不变，repetition+1 |
| 4 | 较好记住 | interval × EF，repetition+1 |
| 5 | 完美记住 | interval × EF × 1.1，repetition+1 |

## 六、复习操作指南

### 6.1 手动更新复习记录

复习完成后，请手动更新笔记的frontmatter：

```yaml
---
last_review: 2026-07-05  # 更新为今天
review_date: 2026-07-12  # 更新为下次复习日期（today + interval）
repetition: 1             # 复习次数+1
ease_factor: 2.6         # 根据评分更新EF
interval: 6               # 更新间隔
---
```
