# 决策看板

> 需要 Obsidian **Dataview** 插件（设置 → 第三方插件 → 关闭安全模式 → 浏览 → 搜 Dataview → 安装启用）。
> 路径不对就改 `FROM "知识飞轮系统/04-LOG/决策日志"` 里的文件夹名，和你实际放的一致。

---

## ⏰ 该复盘了

<!-- 到期未回填的决策。这张表是这套系统唯一强制你回头看的地方。 -->

```dataview
TABLE WITHOUT ID
  file.link AS "决策",
  date AS "决策日",
  review_date AS "应复盘",
  stakes AS "权重"
FROM "知识飞轮系统/04-LOG/决策日志"
WHERE type = "decision"
  AND verdict = "待验证"
  AND review_date <= date(today)
SORT review_date ASC
```

## 📊 全部决策

```dataview
TABLE
  date AS "日期",
  domain AS "领域",
  stakes AS "权重",
  reversible AS "可逆性",
  verdict AS "判定"
FROM "知识飞轮系统/04-LOG/决策日志"
WHERE type = "decision"
SORT date DESC
```

## 🎯 命中率

<!-- 数字不骗人。看清楚自己到底有多准。 -->

```dataviewjs
const pages = dv.pages('"知识飞轮系统/04-LOG/决策日志"')
  .where(p => p.type === "decision" && p.verdict !== "待验证");
const total = pages.length;
const correct = pages.where(p => p.verdict === "对了").length;
const wrong = pages.where(p => p.verdict === "错了").length;
const lucky = pages.where(p => p.verdict === "结论对但理由错").length;
const rate = total > 0 ? Math.round(correct / total * 100) : 0;
dv.paragraph(`**命中率 ${rate}%**（对了 ${correct} / 已判定 ${total}）`);
dv.paragraph(`错了 ${wrong} · 结论对但理由错 ${lucky}`);
```

## ❌ 翻车档案

<!--
  这套系统里最值钱的一张表。
  尤其注意「结论对但理由错」——那是靠运气赢的，比明摆着的错误更危险，
  因为它会让你误以为自己的推理是对的。
-->

```dataview
TABLE WITHOUT ID
  file.link AS "决策",
  date AS "日期",
  verdict AS "判定"
FROM "知识飞轮系统/04-LOG/决策日志"
WHERE type = "decision"
  AND (verdict = "错了" OR verdict = "结论对但理由错")
SORT date DESC
```

## 🔒 不可逆的重注

```dataview
TABLE WITHOUT ID
  file.link AS "决策",
  date AS "日期",
  verdict AS "判定"
FROM "知识飞轮系统/04-LOG/决策日志"
WHERE type = "decision" AND reversible = "不可逆"
SORT date DESC
```

## 🪞 季度自检：说一套做一套

> 每季度做一次。把下面的提示词发给你自己（或 WorkBuddy）：
>
> ```
> 对比 知识飞轮系统/06-沉淀/HOW-I-THINK.md 里我声明的价值观和决策启发式，
> 与 知识飞轮系统/04-LOG/决策日志/ 里我实际的决策结论。
> 找出不一致的地方——我嘴上说重视什么，实际却在牺牲什么。
> 列出 3 条，并说明这个 gap 暴露了我的什么真实偏好。
> ```
>
> **这个 delta 才是你思维里最真实的部分。**
> 人写下的价值观常常是理想中的自己，实际决策才暴露真实权重。
