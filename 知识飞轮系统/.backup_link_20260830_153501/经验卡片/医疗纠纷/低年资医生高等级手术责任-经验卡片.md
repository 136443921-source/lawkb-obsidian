# 低年资医生实施高等级手术的责任（手术分级管理制度）｜经验卡片

## 核心要点
1. **手术级别≠医生职称**：手术分级评价手术本身（一至四级）；医师授权评价该医师能否作为主要完成人实施某手术；三、四级手术逐项授权，授权原则上不得与职称职务挂钩（《医疗机构手术分级管理办法》第16条）。
2. **三张表必查**：医院当时有效的手术分级目录（三、四级须报送公示）、医师逐项授权、实际主要完成人（病历签名≠全程主要完成人；2025版监测指标单列"实际术者与计划术者一致率"）。
3. **六道授权门**：机构能力→目录定级→个人申请科室评估→复核批准（医务部门复核+委员会批准+医院正式行文，科主任口头同意无效）→逐项授权→动态再评估（四级评估周期≤1年，严重不良事件后暂停重新评估）。
4. **紧急越级三要件**（办法第21条）：急危重症+确需立即急诊手术挽救生命+现场无有权限术者；择期手术换人、常态排班缺人不属例外；紧急越级仍须报告并协调有权限医师到场。
5. **三本责任账**：①医院管理账（目录/授权/术前核对/明知无权限仍排班）；②医师执业账（明知无权限仍独立主刀、遇困难未求援→《医师法》第55条，警告/暂停执业/吊销）；③民事赔偿账（《民法典》第1218条：医疗机构或医务人员有过错的由医疗机构赔偿；内部追责另论；是否赔、赔多少落到具体过错与因果关系）。
6. **五条事实线+10类证据**：机构与目录线/个人授权线/计划-实际术者线/紧急例外与支援线/能力-损害因果线；固定执业许可、有效目录、资格培训、逐项授权、技术档案、术前决策、术中记录、排班到场、紧急越级资料、损害处置鉴定。
