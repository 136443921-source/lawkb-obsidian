# 医院捐赠合规管理-药企赞助红线（经验卡片）

## 应当做（do）
- "三无"捐赠医疗器械：某三甲医院接收慈善捐赠的血液透析装置，铭牌无注册人信息、无注册证号，实为未依法注册的医疗器械，医院被没收设备并处罚货值1倍罚款（50万元）。医院委屈点："是慈善捐的，不是我买的"——但依据《医疗器械监督管理条例》《医疗器械使用质量监督管理办法》，接收捐赠时医院有法定查验义务，慈善者身份不能成为违法
- 擅改捐赠用途：医院收钱签协议约定用于某科研项目，后挪作他用，捐赠人可依《公益事业捐赠法》要求改正；不改正的，政府可经征求捐赠人意见后将财产转给其他公益组织。
- 本质：捐赠的"公益"外衣掩盖不了"商业"内核，一旦与采购、招标挂钩，性质即变。
- 设立"预评估"制度，收之前先审查：收到捐赠申请不立刻收下，先查捐赠人是谁、背景是否干净、目的是否纯粹、物资是否合法合规、有无附带商业条件，把"挂羊头卖狗肉"的商业捐赠挡在门外。
- 专人专管，验收签字不能马虎：由院办、财务、资产管理、审计等部门共同参与、专人负责；接收设备须像采购一样严格查验产品资质、注册证、合格证，入库/入账/开票每一步有记录。
- 签好协议，公开信息：必须签订书面协议，明确捐赠财产、用途、双方权利义务、违约责任，由法定代表人（或授权代表）签字加盖公章；财务开具财政部门统一印制的公益事业捐赠票据；建立信息公开制度，每年3月31日前公布上一年受赠财产使用情况。
- 定向捐赠须严格按协议用途使用，变更用途须征得捐赠人同意。
- 合规不是束缚，而是保护。本文为法律合规建议，不构成具体法律意见；个案请咨询专业律师。

## 不应当做（dont）
- 一场商务舱机票，换来10万罚款 + 没收77万药款：2015年某药企为维系与上海某医院心内科主任关系，支付其赴欧洲心脏病学会的商务舱往返机票（57095元）；同期该医院向该药企采购6种药品合计77万余元。2017年上海某区市场监管局认定药企违反《药品管理法》，没收77万余元违法所得并罚款10万元。要害：钱款由药企"额外
- 医院自行发起公开募捐：疫情、灾害期间有的医院公开发起募捐，但《慈善组织公开募捐管理办法》规定不具有[[公开募捐资格|公开募捐资格]]的组织和个人不得开展公开募捐，医院一般不具备该资格（针对特定患者、不面向不特定公众的定向求助除外）。
- 建立审计和报告机制：内部建立违规风险报告制度，医务人员发现私下利益输送须勇于报告；定期组织捐赠专项审计，纳入院长经济责任审计；金额大、影响广的项目做绩效考评。
- 慈善组织接收企业（尤其是药企、医疗器械企业）捐赠时，同样负有查验义务——物资来源、注册资质、合格证明须逐一核验，不得以"对方是捐赠"为由豁免。
- 警惕"捐赠+采购/合作"的捆绑安排，避免构成变相利益输送或商业贿赂。
- 慈善组织自身不具备公开募捐资格的，不得代为或联合开展公开募捐。
