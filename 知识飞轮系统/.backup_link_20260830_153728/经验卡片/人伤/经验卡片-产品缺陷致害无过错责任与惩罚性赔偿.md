# 经验卡片 - 产品缺陷致害无过错责任与惩罚性赔偿

## 规则锚定（源自 R-PI-140 / R-PI-141 / R-PI-142）

1. **生产者无过错责任**（第1202条）：产品存在缺陷致害，生产者担责不问过错（R-PI-140）。
2. **受害人择一索赔权**（第1203条）：可向生产者或销售者请求赔偿，内部按缺陷源头追偿；第三人（运输/仓储）致缺陷的由生产者/销售者先行赔付后依第1204条追偿，受害人无须直告第三人（R-PI-140）。
3. **警示缺陷举证**（R-PI-141）：缺陷不存在的举证责任分配——生产者对"不存在缺陷/已尽警示"负举证责任。
4. **惩罚性赔偿**（第1207条，R-PI-142）：明知缺陷仍产售或未有效补救，致死亡或健康严重损害，可请求惩罚性赔偿；构成要件从严（主观明知 + 客观仍产售 + 结果死亡/重伤）；民法典未定倍率，须援引消法/食安法等单行法，仅证缺陷不足以获得。

## 办案动作清单
- 原告方：保留实物残骸+购买凭证；择一告销售者；惩罚性赔偿单独列项并附"明知"证据链。
- 生产者方：质检报告+符合标准证明+警示记录；主张发展风险抗辩/受害人不当使用。
