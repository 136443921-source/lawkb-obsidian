## 一、权威规则
民政部令第81号（新修订《慈善组织信息公开办法》，**2026-01-01 施行**）。

## 二、核心规则（时效速查）
| 事项 | 时限 |
|---|---|
| 年度工作报告和财务会计报告 | 每年 **5月31日** 前 |
| 重大资产变动/重大投资/重大交易/关联交易 | **30日内** |
| 基本信息（含重要关联方） | 形成后 **30日内** |
| 公开募捐活动结果 | 结束后 **3个月内** |
| 重大突发事件应急阶段募得款物接收 | 至少每 **5日** |

## 三、LTI 联动
LTI 模块6 R-CS-004（年报公开月份≠5 → WARNING）/ R-CS-005（重大变动公开天数≠30 → WARNING）。
