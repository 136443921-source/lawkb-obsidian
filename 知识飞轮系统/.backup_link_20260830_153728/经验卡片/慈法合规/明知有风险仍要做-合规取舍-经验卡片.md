# 合规最难解决：明知有风险仍要做（风险取舍）｜经验卡片

## 核心要点
1. **三类分层**：①不能碰的红线（虚构交易、不当利益、伪造材料）——不得包装成"商业选择"；②可做但须补足条件的风险（高风险第三方、重要数据、特殊合同责任）——明确条件+控制措施+责任人；③管理层主动取舍的经营风险——由有权限的人决定，不让一线/合规部门暗中承担。
2. **模糊最危险**：风险失控常因提醒未被说成"需要决定的问题"；合规的作用不是替企业说"不"，而是把模糊风险变成管理层必须回答的问题（风险是什么/有哪些控制/剩余后果/谁在什么权限内决定）。
3. **留痕决策**：重大风险决定至少记录事实背景、风险判断、可选方案、最终决定、附加条件、责任人；简明纪要优于邮件互抄。
4. **责任归位**：合规提底线条件建议、法务讲法律后果、财务测成本、业务说商业必要性；是否接受剩余风险最终是"有权管理者"的决定；警惕被当"背书人"。

## 使用场景
企业合规体系咨询、风险决策会议纪要设计、合规免责证据链构建。
