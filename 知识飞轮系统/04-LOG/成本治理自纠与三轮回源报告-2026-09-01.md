## 一、🚨 自纠：「外部并发消耗源」不存在

### 1.1 决定性反证

上一轮（13:17）据三次零调用静置实测（9.7 / 13.7 / 11.3 分/分钟）判定存在"与本机无关的外部并发消耗源"，并据此把 P0 升级为"请老强人工核查账号流水 / 轮换 API Key"。

若真存在 11 分/分钟的外部持续消费者，741 秒应掉约 **136 分**，实测仅掉 **2 分**。

### 1.2 真实机制：异步延迟结算

13:02–13:13 的密集调用，其扣费在随后 **5–15 分钟内陆续落账**，恰好全部落在我设定的"零调用静置窗口"内，被误读为背景消耗。**结算完毕后（13:17 之后）静置速率即归零** —— 这与"外部持续消耗"截然不符。

### 1.3 处置

- 【🚨元典外部消耗告警】**予以撤销**；
- "人工核查账号流水 / 检查订阅 / 轮换 API Key" **降级为可选**（一次性安全巡检仍值得做，但不再紧急）；
- 上一轮据此把 `rh_ptal_search` 改记「⛔ 未测定」属**过度修正**，现已实测补正。

## 三、三轮回源：3 例判例 + 1 处硬伤级纠错

三次 `top_k=1` 检索全部做真实 P1 功课，命中率 3/3，且产出超预期。

### 3.1 R-HT-119 —— 取得缺失的直接判例 + 🔴 纠正硬伤级法条引用

**（2020）宁01民终49号**（银川市中级人民法院，2020-05-30）：

- 约定"当面点清验收"的检验期间过短 → **仅为外观瑕疵异议期**；
- 防水性能属**隐蔽瑕疵**，合理期间由**法院酌定**，本案酌定 **一年**（理由："应至少包含一段下雨的季节"，与质保期一致）；
- 逾期未主张 → 依解释第20条不予支持；
- **商事主体负较高注意义务**，不得在合理期间外任意提异议。

🔴 **法条硬伤纠错（本轮最高价值）**：卡片原列"《买卖合同司法解释》第17、18、20、22条"系 **法释〔2012〕8号** 旧号，元典 `sxx` 已标 **"已被修改"**。经逐条核验，现行有效的是 **法释〔2020〕17号（2020 修正，2021-01-01 施行）**，条号**整体重排**：

| 旧号（法释〔2012〕8号） | 现行 |
|---|---|
| 第17条（合理期间认定） | **现行第12条** |
| 第18条（检验期间过短） | **已上升为《民法典》第622条**（法律位阶提高） |
| 第20条（期限经过后不支持） | **现行第14条** |
| 第15条（签收送货单推定检验） | **已上升为《民法典》第623条** |
| ❗ **现行第18条** | **已改为"逾期付款违约金"，与原第18条内容完全无关** |

→ 若沿用旧号引用将造成**硬伤级错误**。卡片已整体替换为经核验的现行条文，并新增「法条时效校正」专节。

**⭐ 顺带挖出对老强两案最有价值的一条**：《买卖合同司法解释》(2020修正)**第13条** —— 买受人在合理期限内提出异议后，出卖人以买受人**已支付价款、确认欠款数额、使用标的物**等为由主张其放弃异议的，**人民法院不予支持**。
→ 直接命中 **吊顶案 6658 / 雅菲案 6660** 的核心争点：**付款与欠条确认 ≠ 放弃质量异议**。

### 3.2 R-CF-095 —— 条号位移由"推断"升级为**书证确证**

`yyft=中华人民共和国慈善法第五十五条`（旧条号）二次命中 **（2020）京03民终5349号**，本轮带出**完整一审判决原文**：

> "《中华人民共和国慈善法》**第五十五条**规定……慈善组织确需变更募捐方案规定的捐赠财产用途的，应当报**民政部门备案**；确需变更捐赠协议约定的捐赠财产用途的，应当**征得捐赠人同意**。"

与现行 2023 修正版逐字比对，双重确证：

| 比对项 | 2016 版（一审援引） | 2023 修正版（元典核验） |
|---|---|---|
| 条号 | **第 55 条** | **第 56 条** |
| 备案机关表述 | 报**民政部门**备案 | 报**原备案的民政部门**备案 |

⛔ 已加重要限定：一审对第55条的援引已被**二审以"法律适用错误"纠正**（协议签于 2013 年，早于《慈善法》施行且不溯及既往），故该案是**旧版条号与用词的书证**，**不是**第55/56条的适用判例，不得表述为"某某判决认为……"。

### 3.3 R-LD-003 —— 补齐举证责任与证据失权规则

**（2014）鞍行终字第30号**（鞍山市中级人民法院，2014-08-19）：

依《工伤保险条例》**第19条**，职工认为是工伤、用人单位不认为是工伤的，**由用人单位承担举证责任**。该案单位四项举证全部失权：

| 单位举证 | 失权原因 |
|---|---|
| 交通事故责任认定书 | 仅证明事故主次责任，**无从证明是否"上下班途中"** |
| 书面证言 | 证人既未到人社局接受询问又未出庭 → 不具证明力 |
| 询问笔录 | 无其他有效证据印证 → 缺乏证明效力 |
| 二审新证人 | 依《行政诉讼证据规定》**第7条**，一审无正当事由未提供、二审提供**不予接纳** |

**待核项范围收窄**：要旨第 3 条拆为两半 —— 后半段「用人单位负举证责任」✅ 已获支撑；前半段「未划分责任不得径直作不利认定」⚠️ 仍无判例，不得作为确定规则使用。
