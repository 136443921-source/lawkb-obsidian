  再没有就标 `BLOCKED` 并**立即停摆**（≥3 篇 BLOCKED 即停），不空转、不凭记忆编内容。

### 2. 候选池脚本的 media_id 拼接陷阱（已修）
HTTP 通道返回的 `media_id` **已带 16 位库ID后缀**，旧脚本无条件再拼一次 →
`rawid + lib_id + lib_id`，与 ingested 集合永远匹配不上 → **去重全面失效**（5 库全顶格 60 条假候选）。
修复：`std_mid = mid if mid.endswith(lib_id) else mid + lib_id`，并新增 **rawid 级第三重去重**。
修复后：候选从 300 条（假）降到 **225 条（真）**。

### 3. 法释文号校正（子代理实证，重要）
- `法释〔2024〕12号` = **《民法典侵权责任编解释（一）》**（2024-09-27 施行），**不是**道交解释（二）
