### （2020）京03民终5349号 · 北京市第三中级人民法院 · 2020-09-29 · 二审改判

**基本事实**：2013 年，和众公司等三方与老基会（慈善组织）签订《捐赠协议》及《补充协议》，捐赠 2000 万元并约定**定向用途** —— 20%（400 万）用于"大爱无疆"资助贫困老人公益活动，80%（1600 万）用于"老年频道"申请建设。后老年频道因政策原因无法落实，捐赠人诉请解除协议并返还。

**四层裁判要旨：**

| 层级 | 裁判观点 | 实务价值 |
|---|---|---|
| ① **溯及力** | 协议签订于 2013 年，《慈善法》第112条自 2016-09-01 施行，且对溯及力无特别规定 → 依《立法法》第93条**不溯及既往**，应适用《合同法》《公益事业捐赠法》。**一审适用《慈善法》属法律适用错误，予以纠正** | ⛔ **重大警示**：2024-09-05 前订立的捐赠协议**不能直接援引《慈善法》第56条** |
| ② **⭐ 性质认定分水岭** | 按资金用途**分别认定**：20% 部分约定明确用于公益活动 → **公益捐赠**；80% 部分老基会**接受资金并非无偿**，负有"为甲方项目向政府发函、协助立项、挂牌、办理土地证"的义务，**明显超出其作为慈善组织依登记证书载明业务范围所应履行职责之范畴** → 属**合作关系**，不认定为慈善捐赠 | 本轮最有价值规则 |
| ③ **解除 vs 撤销** | 公益捐赠部分：依《合同法》第192条，赠与人享有的是**撤销赠与权**而非**解除权**；捐赠财产已按约转移 → 捐赠行为已完成 → **不支持解除**。合作部分：项目均无法继续履行，**合同目的无法实现** → **支持解除** | 请求权基础不可混用 |
| ④ **返还范围** | 判令返还合作部分 **1500 万元**；捐赠人事后书面同意转作其他公益项目的 100 万元认定为捐赠款不予返还；**利息不予支持**（无约定，且《退款申请书》未主张） | 事后同意变更用途的书面文件**不可逆**；利息须一并提出 |

### 双向攻防要点（已写入卡片）

- **🔵 蓝队（代理慈善组织）**：守住"无偿性"底线。凡协议中出现向政府发函、协助立项、办理证照、承诺收益等**超出法定业务范围的义务条款**，即埋下"名为捐赠、实为合作"的定性风险 —— 一旦被认定为合作关系，该部分资金**不再受"公益捐赠不可解除"保护**，须依《民法典》第563条返还。修订协议时应删除此类对价性义务条款。
- **🔴 红队（代理捐赠人）**：发现受赠慈善组织承担了超出法定职责的对价义务时，**优先主张该部分为合作关系并诉请解除返还**，而非走《慈善法》第56条"擅自变更用途"路径 —— 前者可直接要回本金，后者仅为改正/投诉举报，**救济力度悬殊**。
- **双方通用**：2024-09-05 前订立的协议**严禁直接援引第56条**（本例二审即以"法律适用错误"改判）。

> ⚠️ **定位修正**：该判例核心价值在"定性分水岭"与"溯及力"，而非"用途变更须同意"本身。R-CF-095 要旨第 1 条**仍源自法条释义**，引用须表述为"依《慈善法》第56条……"，不得表述为"司法实践认为……"。

### 修正后的「提前离岗三阶检验」（可直接使用）

```
第一阶：是否办理请假 / 下班交接手续，或经单位领导同意？
   ├─ 是 → 仍属"上下班"（赣09行终85号明示包含）→ 进入第二阶
   └─ 否 → 进入第二阶，但承担不利推定

第二阶：提前离岗是否具有客观正当理由？
   可证成事由（参照荣行初字第1号）：已完成当日主要工作 / 天气恶劣 /
   身体不适 / 临近节假日等符合常理的客观事由
   ├─ 有 → 属合理时间 → ✅ 认定工伤
   └─ 无 → 进入第三阶

第三阶：提前时长是否超出合理限度？
   ├─ 未超（数十分钟内 + 有正当理由）→ ✅ 认定工伤
   └─ 明显超出（赣09行终85号：提前 1 小时以上"明显超过合理限度"）→ ❌ 不予认定

⚠️ 加重情节：代打卡等规避考勤行为 → 直接推定"明知违规"，显著强化不予认定
```

### 攻防要点

- **红队（代理职工）**：① 优先固定**「已完成当日主要工作」**证据 —— 这是荣行初字第1号胜诉的**唯一实质支点**（交接班记录、系统日志、班组长证言、当日产量/工单）；② 叠加环境性事由，把"提前"锚定到"符合常理"而非"违反纪律"；③ **孤立援引"违反内部规定不影响工伤认定"的复函是无效动作**（宝行初67号已明确不予采信）；④ 正面主张单位"早退出事与本厂无关"条款与法相悖、无效。
- **蓝队（代理用人单位/社保部门）**：① 主攻**「无正当理由」**而非"违反规章"；② 固定考勤异常证据（监控、代打卡记录）证明"明知制度严格仍规避"；③ 量化提前时长主张"明显超过合理限度"；④ 政策说理备用（赣09行终85号原文）："劳动者提前下班应具有合理事由……必将严重侵害企业的生产经营秩序，损害企业利益……有违公平性，且会造成不良的社会导向。"
