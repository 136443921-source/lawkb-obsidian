# 审判要件卡（Trial Element Card）· 卡型定义与总索引

> **一句话**：审判要件卡回答**「该怎么判」**（正向裁判规则）；要件映射卡回答**「有没有引错」**（负向涵摄拦截）。**这是两套东西，不可互相替代。**

---

## 一、为什么必须新增这一卡型（关键区分）

| 维度 | 要件映射卡（已有） | **审判要件卡（本卡型）** |
|------|------------------|------------------------|
| 载体 | `lti_element_cards.json` + `lti_semantic_rules.json` | 知识飞轮规则卡 `R-PI-*` / `R-PR-*` |
| 回答的问题 | 「引用错了吗？」 | **「该怎么判？」** |
| 推理方向 | **负向拦截**（涵摄断裂检测） | **正向裁判**（审理思路→裁判结论） |
| 触发时机 | 文书生成**后**校验 | 庭审推演**中**引导推理 |
| 典型输出 | 「1165 不是无过错责任，请区分 1166」 | 「先查四要件，再按顺位比对，支持/不予支持分别是……」 |
| 消费方 | LTI 文本监控器（闸门） | **模拟法庭 `judge_reviewer`（法官心智）** |

> **结论**：把审判要件内容硬塞进 `lti_element_cards.json` 会破坏其负向拦截的语义纯度；反之，用负向拦截规则指导裁判则会陷入「只知不能怎么判、不知该怎么判」的困境。**必须物理隔离、双轨并行。**

## 二、字段规范（v1.0）

沿用《规则卡编号体系规范 v1.0.0》的编号与 frontmatter 骨架，**新增审判要件特有字段**：

```yaml
rule_id: R-PI-215              # 强制，白名单域码 + 三位补零
card_type: 审判要件卡           # 【新增强制】用于与要件映射卡物理区分
review_step: 第七部分 第三节一(一)   # 【新增】审理环节定位
elements:                      # 保留（与现有卡同构，可复用三元闸门）
  - id: E1
    name: 要件名
    desc: 涵摄内容
ruling:                        # 【新增·核心】正向裁判规则
  support: 支持的条件与结论
  reject: 不予支持/驳回的条件与结论
burden_of_proof: 举证责任分配   # 【新增】
geo_scope: 贵州省（…）          # 【新增】地域效力标注
negative_sample: true          # 保留（负向兼容）
negative_note: 翻车标本
```

**正文八段结构**（固定）：
1. 裁判规则（正向 · 该怎么判）—— 支持 / 不予支持
2. 审查要点（审理思路）
3. 构成要件与举证（elements 表 + 举证责任）
4. **法条依据（权威源回填，非凭记忆）**
5. 抗辩与但书
6. 翻车标本（负向拦截 · HIR）
7. 来源与地域效力
8. 关联（知识飞轮连接层）

## 三、铁律（建卡与使用均须遵守）

1. **法条正文回填铁律**：卡内 `elements` 仅描述要件，**绝不内嵌法条正文**；法条正文必须从本地权威源（`Documents/LawKB/法律法规库/`）或北大法宝/华宇元典核填，并标注来源与「现行有效」状态。
2. **铁律 R2（机器仅候选）**：审判要件卡给出的裁判结论是**候选推理**，不是自动裁判。法官/律师须结合个案证据人工拍板。
3. **地域效力标注铁律**：本书系贵州省高级人民法院组织编写的**裁判尺度统一指引，非全国统一司法解释**，跨省援引须核实当地口径。
4. **编号铁律**：域码只能用白名单 14 域（本次用 `PI` / `PR`），序号实地查库取最大值 +1，禁止凭记忆取号。

   指南据其细化的六种追加情形属**贵州高院裁判口径**，引用时须区分（R-PI-327）。
3. **零时起保条款**（R-PI-350）：收保费并完成核保后，「次日零时生效」不得用于制造保障空档；

## 五、消费方式：法官心智四步推理链（judge_reviewer）

模拟法庭 `judge_reviewer`（Reviewer & Procedural Commander）在实质审查阶段消费本卡型，按四步推进：

1. **定位审理环节** → 用 `review_step` 确定当前处于「原告诉请审查 / 被告抗辩审查 / 争议裁判规则」哪一环；
2. **逐项涵摄** → 用 `elements` 逐项比对本案事实是否落入要件；
3. **举证校验** → 用 `burden_of_proof` 判断哪一方未完成举证；
4. **裁判预判 + 但书提醒** → 用 `ruling.support` / `ruling.reject` 给出**候选结论**，并同时触发 `negative_note` 提示翻车风险。

> 输出仍须遵守 **铁律 R2**：机器只给候选，法官人工拍板。

   应当依《工伤保险条例》§14⑤、§19②认定为工伤。这是全书中举证责任倒置最强的一次运用。
3. **「未能冷静处理」「违反交通法规」「迟到早退」均不阻却**（R-GZ-036、R-GZ-038）：
   - 因工作事项争执未能冷静处理，**不足以阻却**履职认定；
   - 无相反证据推翻事故责任认定书的，**以职工违反交通法规抗辩不予采纳**；
   - 迟到早退只要符合 §14⑥，**就应当认定为工伤**（国务院法制办复函）。
4. **司法谦抑与循环打破**（R-GZ-042）：法院**一般不代替**行政部门作首次认定；

**🔴 本批最高价值产出：三个「想当然就会错」的判断**

1. **交通肇事是刑附民赔偿范围的唯一穿透通道**（R-PI-374）。
   一般刑附民排除死亡赔偿金、残疾赔偿金、精神损害；但**驾驶机动车过失肇事构成犯罪**的，
   依法释〔2021〕1号 §192 第三款转道交法 §76 确定赔偿责任，
   **无论是否投保交强险**，未达成调解和解的均按**人身损害民事案件**标准赔偿，
   **两金与精神损害全部回归**。
   —— 但**以驾车方式实施故意犯罪**（故意杀人、故意伤害、以危险方法危害公共安全）的**不穿透**，
   仍适用 §192 第一款、第二款。这是本批唯一的分水岭。
2. **「另诉」并不能突破两金排除**（R-PR-177）。本指南明确：另行提起民事诉讼，
   调解不成作出判决时**适用与附带民事诉讼相同的赔偿范围和标准**。
   **想拿两金，唯一现实通道是调解／和解协议**（§192 第四款），而非更换诉讼路径。
3. **被扶养人生活费不得随两金一并驳回**（R-PI-373）。其虽依人损解释第十六条**计入**两金，
   但司法实践要求**独立于两金计算后相加判决**，属**应支持**项目。
   这是刑附民赔偿计算最高频的错误。

**⚠️ 规范冲突：本批与 R-PI-132 的分歧（双向标注，不作单一结论）**

R-PR-177 记载的贵州高院口径为「另诉判决适用与附民相同的赔偿范围」；
而 R-PI-132「医疗事故罪刑附民仅赔物质损失与民事死亡赔偿金悖论」记载了另一实务观点：
另行提起民事侵权诉讼依《民法典》侵权责任编及人损解释**可主张死亡赔偿金、精神损害抚慰金等全部项目**。

两条口径存在实质分歧，**卡内已作双向互链并明确提示**：贵州省内案件按本批口径作预期管理，
省外或争取突破的须检索受诉法院当地口径与最新判例后再定策略。
**此分歧属实务争议点，正式文书援引前须核验受诉地裁判尺度。**

**其余四条方法论增量**

1. **量刑情节不得跨界到民事责任分担**（R-PI-376）：未成年人、自首、立功、累犯等
   从轻或从重处罚情节，**不得作为认定民事赔偿份额的依据**；份额仅按过错程度、地位作用、原因力比例确定。

   仅就已生效判决**未履行部分**承担连带责任。
3. **赔偿与量刑的三项禁止**（R-PR-174）：不得将民事赔偿与量刑直接挂钩、
   不得讨价还价、不得承诺刑罚；但**依法应当从宽的，即使无力赔偿也应当从宽**。
