# 请求权基础与法条竞合卡族（鉴定式）·总索引

> 本卡族依王泽鉴《民法思维：请求权基础理论体系》通说三分式，将「法条之间的关系」作**法条竞合／请求权竞合／请求权聚合**三分处理，并以鉴定式（Gutachtenstil）四阶（产生→消灭→可行使）嵌入「竞合审查节点」。覆盖用户刚需：**违约/侵权竞合（民法典第186条）、责任聚合、择一行使**。

## 二、三分式决策树

```
同一生活事实该当数个请求权基础？
├─ 否 → 各自独立分析（非竞合）
└─ 是 → 法条间是否排斥（特别—一般/吸收/位阶）？
        ├─ 是 → 法条竞合 → 仅适用其一（不适用186）
        └─ 否 → 数请求权给付目的是否同一（填补同一损害）？
                ├─ 是 → 请求权竞合（186）→ 择一行使
                └─ 否 → 请求权聚合（责任聚合）→ 可并用
```

## 三、关键区分（防翻车核心）

- **竞合 vs 聚合**：给付目的同一→择一（186）；目的各异→并用（179等）。
- **588 内部双层**：定金/违约金「择一」＋超过定金的损失「聚合补足」——同一第588条内并存。
- **996 是 186 例外**：仅「人格权严重精神损害」打破择一，转聚合。
- **1203 须隔离**：产品责任生产者/销售者选择属不真正连带，非竞合亦非聚合。
