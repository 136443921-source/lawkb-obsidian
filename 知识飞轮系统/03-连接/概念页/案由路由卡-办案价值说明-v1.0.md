# 案由路由卡在办案中的价值

## 0. 一句话结论

案由不是给案子起的"名字"，是立案那一刻同时锁死六个变量的"总开关"。
案由路由卡的价值不在"我知道这叫什么案由"，而在——**让你在写起诉状/答辩状之前，就看清这六个变量会朝哪边倒**，从而选战场而不是被分战场。

---

## 1. 一个动作锁死六个变量

| 变量 | 被案由怎么锁 | 实例 |
|---|---|---|
| ① 管辖法院 | 专属 → 一般 → 协议可改否 | 定成"装饰装修"可能撞不动产专属管辖；定成"买卖""承揽"是一般地域管辖 |
| ② 诉讼费用 | 财产案件按标的额 vs 非财产案件按件 | 同一笔钱，定错案由可能多交受理费并被要求补交 |
| ③ 举证责任 | 谁证明、证明到什么程度 | 买卖 §621/§623 检验期间；承揽 §787 定作人任意解除；医疗 §1218 过错 + §1222 过错推定 |
| ④ 期间 | 时效、除斥、检验期、保证期间 | 保证期间 §692 不中止不中断不延长，定性错即权利归零 |
| ⑤ 请求权基础 | 适用哪部法哪一条 | 案由错 → 引用法条体系整体错位 |
| ⑥ 类案检索入口 | 检索准不准、能否命中 | 2025 版"侵害患者知情同意权责任纠纷"→"医疗诊疗责任纠纷"，旧名检索即失效 |

## 2. 办案四阶段的发力点

### 2.1 立案·起诉（我方主动）

- **价值**：抢法院、抢节奏。立案庭通常按原告所写案由立案，我方在对方出现前已决定管辖、费用档位、举证框架。
- **动作**：立案前查 `code_2025` 字段，核死案由名、编号、管辖规则；起诉状写明"2025 版第 XXX 号案由"。
- **风险**：案由写错 → 移送管辖 + 补交受理费，白丢 3~6 个月，且不可逆。

### 2.2 答辩·异议（我方被动）

- **价值**：把对方的战场拆掉。
- **要点**：对方定错案由，不提异议＝视为认可其战场。答辩期内提"法律关系定性异议"，对方整套举证落空（其准备的是另一案由下的证据）。
- **动作**：收到起诉状 15 日内，用定性分野卡做相邻案由比对；打管辖异议 or 答辩状明确定性抗辩。
- **金句**：定性异议是最便宜的一招——一张纸，能废掉对方半年的举证准备。

### 2.3 庭审·释明（法官出场）

- **价值**：争点重排 + 取得变更诉请的合法通道。

**依据一**《最高人民法院关于民事诉讼证据的若干规定》(2019修正) **第五十三条**（现行有效，北大法宝核填 2026-09-06）：

> 诉讼过程中，当事人主张的法律关系性质或者民事行为效力与人民法院根据案件事实作出的认定不一致的，人民法院应当将法律关系性质或者民事行为效力作为焦点问题进行审理。但法律关系性质对裁判理由及结果没有影响，或者有关问题已经当事人充分辩论的除外。
> 存在前款情形，当事人根据法庭审理情况变更诉讼请求的，人民法院应当准许并可以根据案件的具体情况重新指定举证期限。

**依据二**《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》(法释〔2023〕13号) **第十五条**（现行有效，北大法宝核填 2026-09-06）：

> 人民法院认定当事人之间的权利义务关系，不应当拘泥于合同使用的名称，而应当根据合同约定的内容。当事人主张的权利义务关系与根据合同内容认定的权利义务关系不一致的，人民法院应当结合缔约背景、交易目的、交易结构、履行行为以及当事人是否存在虚构交易标的等事实认定当事人之间的实际民事法律关系。

- **实务推论**：第十五条把"合同叫什么名字"降格为不重要，把战场拉到"缔约背景 / 交易目的 / 交易结构 / 履行行为"四要素。**吊顶案定性之争应按此四要素组织证据，而非纠结合同抬头写"采购"还是"承揽"。**
- **动作**：庭前将两条写入代理词"法律关系定性"部分，主动请求法庭将定性列为争议焦点；法庭倾向与己方不同时，依证据规定 §53 申请变更诉请 + 重新指定举证期限。

### 2.4 文书·检索

- **价值**：编号不翻车、检索打得准。
- **背景**：2025 第三次修正（法〔2025〕226号，2026-01-01 施行）——929 → 1055 案由，十一部分 → 十二部分，206 处增删改。
- **风险**：引用 2020 版已废编号＝专业度硬伤，影响法官对整份文书的信任。
- **动作**：定稿前跑 `code_2020 / code_2025 / version_status / version_delta` 四件套校验。

## 4. 边界：它不能干什么

案由路由卡是**横向路由器**，不是纵向裁判规则：

- ❌ 不回答"这个案子该怎么判" → 那是**审判要件卡**的活
- ❌ 不回答"引用的法条对不对" → 那是**要件映射卡**的活
- ✅ 只回答：这个案子该定什么案由，以及定错会死在哪

**三卡型分工链**：
案由路由卡（选战场）→ 要件映射卡（查引用）→ 审判要件卡（怎么判）

---

## 5. 调用纪律

1. **立案/答辩前必查** —— 把"查案由"变成和"查时效"同级的强制动作
2. **文书定稿必过四件套校验** —— `code_2020` / `code_2025` / `version_status` / `version_delta`
3. **每季度回扫版本** —— 案由规定换版即编号整体作废（见《审判要件卡拆卡流水线》SKILL「坑 11」）
