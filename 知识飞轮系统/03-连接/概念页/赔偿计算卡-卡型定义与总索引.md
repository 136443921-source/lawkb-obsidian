# 赔偿计算卡（Compensation Calculation Card）· 卡型定义与总索引

> **一句话**：赔偿计算卡回答**「该算多少钱」**（正向定量——公式＋基数＋顺位＋抗辩扣减）；要件映射卡回答**「有没有引错」**（负向拦截）；审判要件卡回答**「该怎么判」**（正向裁判）。**三套东西，不可互相替代。**

---

## 一、为什么必须新增这一卡型（关键区分）

| 维度 | 要件映射卡（已有） | 审判要件卡（已有） | **赔偿计算卡（本卡型）** |
|------|------------------|------------------|---------------------------|
| 载体 | `lti_element_cards.json` + `lti_semantic_rules.json` | 知识飞轮规则卡 `R-PI-*` / `R-PR-*` | 知识飞轮规则卡 `R-PI-*(交通)` / `R-GZ-*(工伤)` |
| 回答的问题 | 「引用错了吗？」 | 「该怎么判？」 | **「该算多少钱？」** |
| 推理方向 | **负向拦截**（涵摄断裂检测） | **正向裁判**（审理思路→裁判结论） | **正向定量**（计算式→基数→顺位→扣减） |
| 触发时机 | 文书生成**后**校验 | 庭审推演**中**引导推理 | **赔偿清单 / 诉请金额精算 / 调解方案 / 和解测算时** |
| 典型输出 | 「1165 不是无过错责任」 | 「先查四要件，再按顺位比对」 | 「残疾赔偿金＝贵州城镇人均可支配收入 46289×20年×伤残指数；多等级按吸收原则＋附加指数」 |
| 消费方 | LTI 文本监控器（闸门） | 模拟法庭 `judge_reviewer`（法官心智） | **赔偿清单生成 / 诉请金额精算 / 调解与和解方案** |
| 特有字段 | `elements` / `negative_note` | `review_step` / `ruling.support` / `ruling.reject` / `burden_of_proof` / `geo_scope` | `card_subtype`（交通事故赔偿计算 / 工伤赔偿计算）/ `geo_scope` / 正文「计算步骤」公式块 / 待回源核填标记 |

> **结论**：把赔偿计算硬塞进审判要件卡会稀释其「定性裁判」语义纯度，塞进要件映射卡更不可能（后者只管引用对错、不碰数字）。赔偿计算有**强地域性基数**（贵州 2026 城镇人均可支配收入 46289 元/年、丧葬费 53285 元等）与**强顺位规则**（交强险→商业三者险→侵权人三层瀑布），必须用独立卡型承载，且**基数随统计年度滚动更新**——这是与定性卡最大的不同。

## 二、字段规范（v1.0）

沿用《规则卡编号体系规范 v1.0.0》的编号与 frontmatter 骨架，**新增赔偿计算特有字段**：

```yaml
rule_id: R-PI-259              # 强制，白名单域码 + 三位补零
card_type: 赔偿计算卡           # 【新增强制】用于与审判要件卡/要件映射卡物理区分
card_subtype: 交通事故赔偿计算   # 【新增】二选一：交通事故赔偿计算 / 工伤赔偿计算
geo_scope: 贵州省（城乡统一·同命同价）  # 【新增】地域效力 + 基数适用口径
source: 民法典第1179条（本地库核填·现行有效）；最高法人损解释；省级赔偿标准实时库/贵州省-2026年度赔偿标准
related_links:                 # 用真实文件名基名（坑9/坑18），禁双链、禁从 title 推导
  - R-PI-247-人身损害赔偿项目计算总表
```

**正文八段结构**（固定，与审判要件卡同构但第二段改为定量）：

1. 规则要旨（正向 · 怎么算）
2. **计算步骤（公式＋基数＋顺位，核心段）**
3. 构成要件与举证
4. **法条依据（权威源回填，非凭记忆；待回源项标「待回源核填」）**
5. 抗辩与但书（扣减规则：非医保用药、过错相抵、双赔边界等）
6. 翻车标本（HIR · 算错钱的典型情形）
7. 来源与地域效力
8. 关联（知识飞轮连接层）

## 三、铁律（建卡与使用均须遵守）

1. **基数年度刷新铁律**：所有金额基数（人均可支配收入、消费支出、丧葬费、各行业工资）**取自 `省级赔偿标准实时库/贵州省-2026年度赔偿标准.md`**，并标注统计年度；**跨年度援引须核实当年口径**（丧葬费禁用社保全口径 43947，须用 53285＝106570÷12×6）。
2. **法条正文回填铁律**：卡内法条正文必须从本地权威源（`Documents/LawKB/法律法规库/`）或北大法宝/华宇元典核填，标注来源与「现行有效」状态；**绝不凭记忆撰写条文字句**。
3. **待回源核填标记铁律**：本地无权威源的项目（如贵州省一次性工伤医疗/就业补助金具体月数、道交法第76条部分细则），**统一标「待回源核填（黔人社厅发〔2011〕27号及现行实施办法）」**，**不得臆造数字**——与既有 R-PI-247 口径一致。
4. **地域效力标注铁律**：贵州省高院口径为**裁判尺度统一指引，非全国统一司法解释**；交强险限额全国统一，但残疾/死亡赔偿金基数随省变动，跨省须核实当地口径。
5. **编号铁律**：域码只能用白名单（本次 `PI` 交通 / `GZ` 工伤），序号实地查库取最大值 +1，禁止凭记忆取号；GZ 域卡落 `公众号/` 目录以保域内连续。
