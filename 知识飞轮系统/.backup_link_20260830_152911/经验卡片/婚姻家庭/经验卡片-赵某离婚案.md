# 经验卡片：赵某离婚案（离婚纠纷·抚养权 + 房产分割）

> 类型化经验卡，锚定「赵某离婚案」场景。库内尚无该案专属卷宗，本卡提炼离婚纠纷两类高频争点（抚养权、夫妻共同房产分割）的实务要点，待实际案卷归档后补全案号与审判结果。法律要点援引裁判规则 R-HY-001 / R-HY-002 / R-HY-003。

## 一、争议焦点

1. **子女抚养权（两孩结构）**
   - 长子已**满八周岁**：须独立、中立征询其真实意愿（《民法典》第1084条第3款 + 解释一第46-48条，见 R-HY-002）。
   - 次女**不满两周岁**：以母亲直接抚养为原则，仅母亲存在法定例外（患有久治不愈传染病、有抚养条件不尽义务、其他子女确不宜随母生活）时方可由父亲抚养（第1084条第3款 + 解释一第44条，见 R-HY-001）。
   - 抚养费标准 + 探视权安排须一并主张。

2. **夫妻共同房产分割（婚后按揭 + 父母部分出资）**
   - 房屋婚后购买、登记于赵某名下、婚后共同还贷、赵某父母部分出资——是否共同财产？父母出资性质（赠与双方 vs 赠与一方 vs 借款）如何认定？
   - 若认定共同财产，房屋归属与补偿金额（含增值）如何计算？

## 二、裁判规则

- **抚养权分层规则**：
  - 不满两周岁 → 母亲原则（R-HY-001），例外严格限定于"子女确不宜随母生活"的行为/健康标准，非经济标准。
  - 两周岁以上 → "最有利于未成年子女"原则，综合经济、情感纽带、生活环境稳定性、家暴史等；八周岁以上尊重子女意愿（R-HY-002）。
- **房产三维判定规则（R-HY-003）**：
  - 婚后购买原则共同财产，"登记在谁名下"不破内部共有。
  - 父母婚后出资：无明确赠与一方意思 → 推定为对夫妻双方赠与（解释一第29条第2款）。
  - 婚前首付 + 登记个人 + 婚后共还 → 房归登记方，对另一方补偿（共同还贷本息 + 对应增值，解释一第77条）。
  - 一方擅自转移/变卖共有房 → 第1092条少分或不分，另一方可主张无权处分无效。

## 三、我方策略（以代理女方为例）

- **抚养权主攻**：次女直接引用 R-HY-001 母亲原则，预设对方须举证"子女确不宜随母生活"的法定例外（举证门槛高）；长子满八周岁，申请法庭单独、中立征询意愿，排除赵某在场施压。同步举证女方陪伴时长、子女就学稳定性（"改变生活环境明显不利"，解释一第46条第2项）。
- **房产确权**：主张房屋婚后购买、共同还贷，属共同财产；赵某父母转账无"赠与儿子个人"明示 → 适用第29条第2款推定为共同赠与。若赵某主张父母出资为"借款"，要求其举证借贷合意（仅备注"借款"不足，须出资时合意或借条）。
- **增值补偿预案**：若房屋判归赵某，按实务公式主张补偿——`补偿额 = 婚后共同还贷本息总额 ÷ 购房总支出 × 房屋现价值 × 50%`，并以评估报告锁定现价值。
- **防转移**：诉前/诉中核查房屋是否已被擅自过户亲属，发现即依第1092条主张处分无效并请求少分。

## 四、经验得失

- ✅ **得**：以"年龄分层 + 三维房产"框架拆解离婚争点，抚养权与财产分割两条线证据清单互不交叉、主张清晰；援引 R-HY 系列裁判规则增强说理论证力。
- ⚠️ **风险/失**：八周岁子女意愿可能被一方误导，须坚持法庭中立征询并留存笔录；父母出资性质易成拉锯点，应在接案初即固定出资凭证与备注原文，避免事后补证不被采信；按揭房增值计算依赖评估，需提前沟通评估机构与时点。

## 五、关键证据

- 身份与亲属关系：结婚证、两子女出生医学证明。
- 房产：房产证、购房合同、婚后还贷银行流水（证明共同还贷本息）、房屋现价值评估报告。
- 父母出资：赵某父母转账凭证 + 转账备注原文（核心：是否明示"赠与一方"）。
- 抚养能力：双方收入证明、子女就学/生活稳定性证明、家暴或感情破裂记录（聊天记录、报警记录）。

## 六、法律适用

- 《民法典》第1084条第3款（抚养权）、第1087条第1款（共同财产分割）、第1092条（隐藏转移少分不分）。
- 《婚姻家庭编解释一》第29条第2款（父母婚后出资推定）、第44-48条（抚养权）、第76-79条（房产分割）。
- 关联裁判规则：[[R-HY-001]]（不满两周岁母亲原则）、[[R-HY-002]]（两周岁以上最有利于子女）、[[R-HY-003]]（夫妻共同房产三维分割）。
