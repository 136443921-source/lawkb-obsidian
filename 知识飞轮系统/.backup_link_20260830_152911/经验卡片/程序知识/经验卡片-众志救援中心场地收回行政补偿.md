# 经验卡片：众志救援中心场地收回行政补偿

> 来源：众志救援中心场地使用收回案件（2020年政府发函商请、市政所批复"同意"使用国有场地并投入建设，现面临收回）；完整方法论与二分框架见 [[经验卡片-行政补偿与行政赔偿请求权]]。
> 适用场景：民办非企业单位/慈善组织基于政府批准使用国有场地并投入建设后，因政府拟收回场地而主张行政补偿或行政赔偿之情形。

## 一、案件画像（5维，供跨案件模式识别匹配）

- **案由**：行政补偿/行政赔偿纠纷 / 场地收回
- **争议焦点**：批准行为性质（行政协议/承诺）、信赖利益保护、收回合法性与补偿义务、补偿/赔偿二分
- **法律关系**：行政协议 + 行政补偿/赔偿 + 国有资产管理
- **证据类型**：批准文件、建设费用凭证、持续使用记录、现状照片、收回通知
- **标的额**：板房设施价值 + 搬迁费 + 临时安置费

## 二、核心方法论：补偿与赔偿的二分框架

> 这是本卡的核心资产——**先定性收回行为合法性，再选主张路径**，避免混用导致举证错位。

| 维度 | 行政补偿 | 行政赔偿 |
|---|---|---|
| 前提 | 合法收回/征收/终止行政协议 | 收回行为被确认违法（无依据/程序瑕疵/先违约再解除） |
| 性质 | 公平补偿（不问过错） | 违法损害赔偿（填平直接损失） |
| 范围 | 设施价值+搬迁+临时安置 | 直接损失（同上，但可主张履行利益酌定） |
| 举证 | 投入与损失证据 | 额外证明行政行为违法 |

**关键锚点**：无论走哪条路径，"有征收必有补偿"原则与信赖利益保护均构成底线权利，原批准程序瑕疵不消灭善意相对人的补偿请求权。

## 三、可复用服务话术（行政补偿/赔偿咨询）

1. "政府2020年发函商请、市政所批复'同意'，已构成行政承诺/行政协议，贵中心基于此投入建设，形成受法律保护的信赖利益。"
2. "收回场地不论定性为征收还是终止行政协议，均须补偿且遵循及时、公平原则——'无补偿则无征收'。"
3. "若政府无法说明收回的公共利益依据或未履行告知听证程序，可诉请确认收回行为违法并主张行政赔偿，赔偿不少于依法应得的补偿权益。"

## 四、行动四步法

1. **固定证据**：批准文件、建设费用凭证、持续使用记录、现状照片。
2. **主动发函**：向主管机关主张信赖利益，请求收回前协商补偿方案。
3. **评估合法性**：核查公共利益依据与正当程序，判断补偿/赔偿路径。
4. **协商不成则诉**：案由"行政协议纠纷"或"行政赔偿纠纷"，援引最高法案例支撑。

## 五、一句话经验

> 政府批准使用场地后收回，**先定性行为再选路径：合法收回走补偿、违法收回走赔偿，信赖利益是底线，原批准瑕疵不灭补偿请求权**——收回意向阶段即固定证据、主动发函锁定协商地位。
