# 贵州省慈善组织保值增值投资/专项基金/公开募捐三指引｜经验卡片

## 核心要点（贵州省慈善联合会2025年11月5日印发）
### 一、保值增值投资活动管理指引
1. **可投范围**：①银行及理财子公司、信托、证券、基金、期货、保险资管、金融资产投资公司发行的资管产品及银行存款；②发起设立/并购/参股方式股权投资；③委托受金融监管机构监管的机构投资。投资财产限非限定性资产及投资期间暂不需拨付的限定性资产；政府资助财产与约定不得投资财产禁投。
2. **负面清单8项**：直接买卖股票；直接购买商品及金融衍生品；投资人身保险产品；以投资名义向个人企业提供借款；不符国家产业政策；可能承担无限责任；违背宗旨损害信誉；非法集资等违法活动。
3. **机构选择**：优先合法资质+良好信誉+专业能力；不得选择与慈善组织存在利害关系的机构；单次投资超200万元须独立第三方信用风险评估报告。
4. **止损机制**：损失达投资金额5%启动止损程序并向理事会监事会报告。
5. **报备**：开展投资活动前10个工作日报业务主管单位→登记管理机关备案；单次<200万且周期≤1个月的按季度报送。
6. **信息公开**：在"慈善中国"、贵州省慈善信息管理平台及自有平台公布决策程序、资金规模、合作机构、预期收益；结束后2个月内公开收益情况；重大事项5个工作日内公开。

### 二、专项基金设立和管理指引
1. **性质**：慈善组织利用政府资助、定向捐赠、自有资金设立，专门资助符合宗旨的某一项公益事业；属基金组成部分，不具法人资格，慈善组织承担主体责任。
2. **设立条件**：启动资金不低于内部最低限额；名称=慈善组织全称+字号（业务范围）+专项基金；管理委员会3人以上单数。
3. **流程**：意向沟通→提交申请（申请书/发起方资质/管理办法草案/资金来源证明/团队资料）→合规性审查（宗旨/资金来源/可行性/失信记录/关联交易风险）→理事会审议→签捐赠协议→资金入账开票独立核算→成立管委会（理事会或授权机构2/3以上表决）。
4. **终止与清算**：完成目的/无法运作/捐赠方提出且同意/违规用资/公益支出未达比例等；剩余财产用于相同或相近宗旨，严禁分配给个人或营利组织；向社会公开终止公告与清算报告。

### 三、公开募捐活动管理指引
1. **资格**：依法登记满一年的慈善组织可申请[[公开募捐资格|公开募捐资格]]；不具备资格的组织须与有资格组织合作，不得自行募捐；有资格方对合作方评估、签书面协议、载明于募捐方案、负责款物管理与会计核算（全部收支入其账户）。
2. **方案内容9项**：名称（≤9汉字）、目的、起止时间地域、负责人、接受捐赠方式、受益人信息、募得款物用途、募捐成本（主动公开成本占比）、剩余财产处理。
3. **备案**：通过"慈善中国"线上提交；每项活动单独备案不得合并；活动10日前提交，材料不齐5日内补齐或撤回；突发事件可在活动开始后10日内补办；事项变化10日内补正。
4. **变更用途**：确需变更须理事会审议且赞成票≥2/3，报民政部门备案并向社会公开；有业务主管单位的报经同意。
5. **信息公开**：募捐周期超6个月至少每3个月公开一次，结束后3个月内全面公开；项目周期超6个月同样频率公开。

## 使用场景
厚德基金会等贵州慈善组织投资合规审查、专项基金设立、公开募捐方案备案与信息公开。
