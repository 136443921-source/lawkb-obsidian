# 经验卡片 - 机动车交通事故赔偿计算与保险顺位

## 规则锚定（源自 R-PI-007 / R-PI-057 / R-PI-006）

1. **赔付三层顺位**：①交强险（有责/无责分项限额，不区分事故责任比例据实先行赔付）→ ②商业三者险（按合同+责任比例）→ ③侵权人自负（按责）。交强险"不分责先行赔付"是与商业险最大差异（R-PI-007）。
2. **多等级伤残吸收原则**（R-PI-057）：最高伤残等级为基数，其余每级按 1/10 折算附加指数，附加指数之和不超过 10%。例：一处九级（20%）+ 一处十级（10%）→ 20%+1%=21%，非简单相加 30%。
3. **道交司法解释二**（法释〔2026〕9号，R-PI-006）为现行审理依据；无接触事故侵权人过错与损害有因果关系仍担责（R-PI-041）；好意同乘减责（[[R-PI-042|R-PI-042]]）；挂靠连带（[[R-PI-043|R-PI-043]]）；连环买卖未过户原车主不担责（[[R-PI-048|R-PI-048]]，指导案例19号）。

## 办案动作清单
- Step1 列共同被告：侵权人 + 两家保险人。
- Step2 评残：用《人体损伤致残程度分级》（2017 施行），禁用 GB 18667-2002。
- Step3 算赔偿：对接 `省级赔偿标准实时库/贵州省-2026年度赔偿标准.md`（残疾赔偿金基数 46,289 元/年）。
- Step4 过错折减：受害人过错依第1173条减轻（R-PI-153/034）。
