# 机动车交通事故责任纠纷规范指引（2026年8月整理）｜经验卡片

## 核心要点
1. **管辖**：因侵权行为提起的诉讼由侵权行为地或被告住所地法院管辖（民诉法第29条）；侵权行为地含实施地与结果发生地（民诉解释第24条）。
2. **责任主体体系**（民法典第1208-1217条）：
   - 租赁/借用：使用人担责，所有人/管理人有过错担相应责任（1209条）；
   - 转让未过户：受让人担责（1210条）；多次转让未登记，最后一次受让人担责（道交解释第2条）；
   - 挂靠：挂靠人与被挂靠人连带（1211条）；
   - 盗抢：盗窃人/抢劫人/抢夺人担责（1215条）；
   - 好意同乘：非营运机动车无偿搭乘，应减轻赔偿责任，故意或重大过失除外（1217条）。
3. **赔偿顺位**：交强险限额内先行 → 商业险按合同 → 不足由侵权人赔偿（1213条）。
4. **交强险特殊规则**：无证/醉驾/故意制造事故致第三人损害，保险公司在交强险限额内先行赔付后可追偿（道交解释第15条）；未投保交强险的由投保义务人限额内赔偿（第16条）。
5. **重大过失认定**：不能仅凭事故认定书"全责/主责"当然认定好意同乘中的重大过失，须综合客观行为与主观状态（法答网精选）。
6. **指导案例要点**：套牌连带（赵春明案）；受害人体质状况不影响减轻侵权人责任（荣宝英案）；家庭自用投保后网约车营运可主张商业三者险免责。

## 使用场景
交通事故案件起诉/应诉、责任主体与赔偿顺位分析、保险追偿。
