# 知识飞轮 · _outputs（交付固化区）

本目录固化历轮「慈法合规 R-CF 卡族」建卡/互链的可复用脚本，避免散落在 `/tmp` 被清理。

## p3_crosslink.py
**用途**：在 26 张卡的 `## 关联` 段内插入「判准↔操作 双向对应」块，建立 B 批判准卡（R-CF-143~152）↔ C 批操作卡（R-CF-156~171）的双向对应，并完成反向闭合（C↔B 及 P0 项）、清理自链接与行内重复。
**用法**：`python3 p3_crosslink.py`（默认 dry-run）；`python3 p3_crosslink.py --apply`（写入，幂等）。
**注意**：`DIR` 硬编码为 `06-沉淀/裁判规则库/慈法合规`，路径变更需改第 3 行。

## p4_reverselink.py
**用途**：将 P4 新判准卡 R-CF-174（定向募捐）、R-CF-175（激励金/配捐）反向挂载进目标 C 卡（159←174+175、163←175、164←175）的「判准↔操作 双向对应」块，插在「- 领域枢纽」行之前。
**用法**：同上，`--apply` 写入，幂等（已存在则跳过）。
**映射**：`ADD = {159:[174,175], 163:[175], 164:[175]}`。
