# 保证合同纠纷实务100问｜蓝红双视角审查

> 来源：三章约法（2026-07-26）｜关联 [[R-HT-079]]
> 系统梳理保证合同从成立、公司担保决议、保证方式与范围、主债务变更、保证期间/诉讼时效、起诉管辖、抗辩执行到代偿追偿的100个高频争议，依《民法典》《公司法》及担保制度解释。

## 🔵 蓝队（防御审查 · 债权人立场）

**条款风险点**
1. **保证方式留白**：未写明一般/连带→依法推定为**一般保证**（先诉抗辩权），债权人须先诉债务人。
2. **保证期间空白**：未约定或约定不明→主债务履行期届满之日起**6个月**，不发生中止中断延长；催错对象（仅催债务人）可能导致保证责任消灭。
3. **公司担保决议缺失**：仅看公章+法人签字不足，须审查章程、决议机关、关联股东回避；上市公司须核对公开披露。
4. **最高额保证限额模糊**：未区分"最高本金余额"与"最高债权总额"，利息费用另计易生争议。

**审查要点**
- 明确主债务、保证方式、范围、期间、送达地址；
- 公司担保合理审查决议（形式审查即可，不要求鉴定）；
- 展期/调息/借新还旧重新取得保证人书面确认。

**修改建议**
- 保证方式写明"连带责任保证"并排除先诉抗辩；
- 保证期间写明具体月数（建议长于6个月且明确起算）；
- 最高额保证明确"最高债权总额含本息费用"。

## 🔴 红队（攻击分析 · 保证人立场）

**漏洞与可抗辩空间**
1. **主合同变更加重债务**：未经保证人书面同意提高利率/增加违约金，对加重部分不担责（仅原范围）。
2. **保证期间届满签字不复活**：催收通知上签字仅证明收悉，不成立新保证。
3. **签字冒用/欺诈**：申请笔迹鉴定+印章管理反证；受欺诈胁迫须法定期限内行使撤销权。
4. **主债务时效抗辩**：保证人可援引债务人时效抗辩，明知时效届满仍担责后追偿不予支持。
5. **债权人怠于执行债务人财产**：一般保证人可主张在丧失优先受偿权益范围内免责。

**博弈策略**
- 签约前写明责任方式/上限/期间/不承担费用项目；
- 收到催收立即核对保证期间与诉讼时效；
- 代偿取得债权人收款确认+债务余额结算。

## 七步审查路径（可复用）
主债务成立有效 → 保证合同成立生效 → 主体资格与公司决议 → 责任边界(方式·范围·限额) → 保证期间依法行权 → 诉讼时效 → 抗辩与追偿。
