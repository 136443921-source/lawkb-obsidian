# [[人伤库-医疗纠纷诉讼全流程操作指引|医疗纠纷诉讼实务全流程操作指引]]

> 来源：公众号「医疗大健康法律圈」发布的实务操作指引，覆盖**收案评估 → 证据收集 → 病历封存 → 鉴定程序 → 赔偿计算 → 庭审攻防**全流程。本文提炼为结构化办案清单。

## 一、收案评估——接案即把关

医疗纠纷周期长、专业壁垒高，收案阶段须完成精准评估，避免"接得下、打不赢"。

### 1.1 是否构成医疗损害责任（四要件，《民法典》第1218条）
诊疗行为 + 损害后果 + 因果关系 + 过错，四项缺一不可，收案时逐一快速排查：

| 要件 | 审查要点 |
|------|----------|
| 诊疗行为 | 是否存在医方实施的诊断、治疗、护理、康复等行为 |
| 损害后果 | 患者死亡、残疾、器官损伤、医疗费增加等可量化损失 |
| 因果关系 | 损害与诊疗行为之间是否存在事实关联（初步判断即可） |
| 过错 | 医方是否违反诊疗规范、未尽告知义务、病历不完整等 |

- 易忽略点：美容整形、非法行医、疫苗不良反应等特殊类型是否属于医疗损害纠纷，需特别注意**案由选择**。

### 1.2 诉讼时效（《民法典》第188条）
- 适用3年普通诉讼时效，自权利人知道或应当知道权利受损及义务人之日起算。
- 实务技巧：不以出院日期作为唯一起算点；连续治疗、鉴定期间可主张时效中断；接案时务必要求当事人确认是否存在时效中断证据（微信记录、信访材料、投诉回执等）。

### 1.3 医方主体资格核查
- [[医疗机构执业许可证|医疗机构执业许可证]]的诊疗科目是否涵盖涉案诊疗行为；
- 医师执业证书的执业类别、范围、地点是否合规；
- 多点执业医师的执业备案情况；
- 会诊手续是否合规。

### 1.4 举证责任分配（核心规则）
- 原则：患者就"诊疗行为 + 损害后果 + 因果关系"承担举证责任；医方就"无过错"承担举证责任（《民法典》第1222条）。
- **推定过错**情形（第1222条）：(1) 违反诊疗规范；(2) 隐匿或拒绝提供病历；(3) 遗失、伪造、篡改或违法销毁病历。
- 代理提示：接受患方委托时，**不应依赖"举证责任倒置"旧观念**，应主动搜集证明医方过错的证据。

## 二、证据收集——胜负的基石

### 2.1 病历的封存与复印（核心操作）
1. 提出申请：向医方医务科/医患办提交书面封存申请（保留送达回执）；
2. 双方到场：封存时医患双方均应到场，制作封存笔录；
3. 复印备份：封存原件前先行复印全部病历，复印件由医方盖章确认；
4. 封存清单：逐页编号并制作封存清单，双方签字确认；
5. 保管方式：可委托医院或第三方保管，应拍照留存封存状态。

**主观病历 vs 客观病历：**
| 类型 | 范围 | 权利 |
|------|------|------|
| 客观病历 | 门诊/住院病历、体温单、医嘱单、检验报告、影像资料、知情同意书、手术记录、护理记录等 | 患者有权查阅、复制 |
| 主观病历 | 病程记录、会诊记录、死亡病例讨论、疑难病例讨论等 | 封存后用于鉴定，不能单独复制 |

### 2.2 其他关键证据
- 费用凭证：医疗费发票、费用日清单、自费药购药凭证；
- 影像资料：CT/MRI/X光原始DICOM数据（非仅胶片）；
- 药品/器械信息：植入物合格证、说明书、追溯码、条形码；
- 尸检报告：死亡案件应提醒家属在48小时内、具备冷冻条件时7日内完成尸检；
- 证人证言：同病房患者、家属证言（建议尽早公证或录音录像固化）。

### 2.3 证据保全要点
- 医方官网宣传、医生资质介绍截图公证；
- 微信/短信沟通记录通过公证处或可信时间戳固化；
- 要求医方书面说明、答复函等加盖公章。

## 三、鉴定程序——决定案件走向的核心环节

### 3.1 鉴定类型对比（双轨制）
| 项目 | [[医疗损害鉴定|医疗损害鉴定]] | 医疗事故技术鉴定 |
|------|--------------|------------------|
| 委托主体 | 法院、医调委、双方协商 | 卫生行政部门、法院 |
| 鉴定机构 | 司法鉴定机构 | 医学会 |
| 鉴定内容 | 过错、因果关系、原因力大小、损害程度 | 是否构成医疗事故及等级 |
| 法律效果 | 直接作为民事赔偿依据 | 可作为行政处理依据，民事诉讼中为证据之一 |
| 鉴定人出庭 | 原则上应出庭接受质询 | 实践出庭较少 |

- 律师策略：医方偏好医学会鉴定（行业保护倾向），患方倾向司法鉴定机构鉴定，申请时依委托方立场合理选择。

### 3.2 鉴定陈述书撰写（律师价值最高的工作之一）
1. 诊疗经过概述：简明、客观、按时间线梳理；
2. 医方过错归纳：逐条列明，每项对应病历页码和诊疗规范条款；
3. 因果关系论证：建立过错与损害后果的逻辑链条；
4. 引用诊疗规范：临床指南、技术操作规范、专家共识等；
5. 损害后果量化：医疗费、误工费、伤残等级等具体数据。
- 撰写要点：每条过错须有病历原文支撑（精确到页）；引用规范标注章节、条目、版本；语言客观专业，避免情绪化。

### 3.3 鉴定听证会参与
- 陈述策略：以书面陈述书为基础，口头补充关键要点，控制15-20分钟；
- 核心动作：用时间线图、对比表可视化呈现诊疗过错；
- 回避申请：发现鉴定人与医方存在关联关系时及时提出；
- 补充材料：听证会前可补充新证据，但应提前告知鉴定机构和对方当事人。

### 3.4 对鉴定意见异议的应对
- 申请鉴定人出庭：针对程序、方法、依据交叉询问；
- 申请重新鉴定：满足《民事证据规定》第40条法定情形；
- 申请专家辅助人出庭：另聘临床专家对鉴定意见提出专业性质疑；
- 书面质证意见：逐条批驳逻辑漏洞和事实错误。

## 四、赔偿计算——精细化量化

### 4.1 赔偿项目清单
| 赔偿项目 | 计算依据 | 注意事项 |
|----------|----------|----------|
| 医疗费 | 实际发生合理费用（含后续治疗费） | 需扣除医保报销部分（垫付除外） |
| 误工费 | 固定收入者按实际减少；无固定收入者按近三年平均或参照行业标准 | 误工期以鉴定意见或医嘱为准 |
| 护理费 | 护理人员收入或当地护工标准 × 护理期 | 护理依赖程度影响计算 |
| 交通费 | 实际发生合理就医交通费 | 保留票据 |
| 住院伙食补助费 | 当地出差伙食补助标准 × 住院天数 | 各地标准不同 |
| 营养费 | 根据伤残情况和医嘱确定 | 鉴定意见可给出营养期 |
| 残疾赔偿金 | 受诉法院所在地上一年度城/乡居民人均可支配收入 × 20年 × 伤残系数 | 60岁以上每增一岁减一年，75岁以上按5年 |
| 死亡赔偿金 | 受诉法院所在地上一年度城/乡居民人均可支配收入 × 20年 | 同上 |
| 丧葬费 | 受诉法院所在地上一年度职工月平均工资 × 6个月 | — |
| 被扶养人生活费 | 受诉法院所在地上一年度城/乡居民人均消费支出 | 未成年人计至18岁，无劳动能力又无生活来源者计20年 |
| 精神损害抚慰金 | 据过错程度、损害后果、当地经济水平酌定 | 死亡案件通常5-10万元区间 |
| 鉴定费 | 按实际票据 | 按责任比例分担 |

### 4.2 赔偿总额计算公式
- 过错参与度（原因力）是医疗纠纷特有调整因素，鉴定意见通常将原因力分为：完全（96%-100%）、主要（56%-95%）、同等（45%-55%）、次要（16%-44%）、轻微（5%-15%）、无（0%）。
- **赔偿公式：各项物质损失 × 过错参与度 + 精神损害抚慰金**。
- 2022年5月起残疾/死亡赔偿金统一城镇标准。

## 五、庭审策略与常见争议焦点应对

### 5.1 举证与质证重点
**患方代理质证重点：**
- 病历真实性：是否存在后补、修改痕迹（可委托笔迹/形成时间鉴定）；
- 病历完整性：有无缺页、间断、知情同意书缺失；
- 护理记录与医嘱一致性；
- 知情告知是否充分：知情同意书是否仅流于形式，替代医疗方案是否告知。

**医方代理举证重点：**
- 诊疗行为符合诊疗规范（准备对应规范章节条款）；
- 已尽合理诊疗义务和告知义务；
- 损害系疾病自然转归或患者特异体质所致；
- 存在患者不配合诊疗的情形。

### 5.2 鉴定意见庭审质证切入点
1. 鉴定资质：机构和鉴定人是否具备相应专业资质；
2. 鉴定材料：送检材料是否完整、真实；
3. 鉴定标准：引用标准是否正确、是否已废止；
4. 逻辑推理：从过错到损害后果的因果推理是否存在跳跃或矛盾；
5. 过错参与度：比例划分是否有充分依据。

### 5.3 专家辅助人制度（《民事诉讼法》第79条）
- 适用场景：鉴定意见对己方明显不利需专业反击；争议涉及尖端/冷门医学领域；需向法庭阐释复杂医学因果关系。
- 操作要点：尽早物色临床专家（建议从高校附属医院物色）；出庭前充分沟通细节、预演交叉询问；专家辅助人意见**不属于证据**，但可动摇鉴定意见的证明力。

## 六、结语

医疗纠纷诉讼是融合法律与医学的专业领域。律师核心竞争力在于：证据收集能力（病历审查与封存）、鉴定参与深度（陈述书与听证会）、赔偿计算精度（项目不漏、标准不低）、庭审质证锐度（针对鉴定意见和病历的精准攻击）。
