# [[法律检索报告的结构与实务方法（蓝红双视角）|法律检索报告的结构与实务方法（蓝红双视角）]]

> 来源：公开权威源降级摄入（汉坤《类案检索报告制作指南》、法大律师事务所实务文 + 最高法《关于统一法律适用加强类案检索的指导意见（试行）》2020）。原定 IMA「律师AI助手」库摄入，因 IMA 运行态掉线改用公开源。本文是低年级律师最关键的"经验积累引擎"。

## 一、蓝队视角（检索方·标准流程）

1. **拆解待决案件（决定检索走向）**
   - 顺序：基本事实 → 法律关系 → 争议焦点 → 法律适用规则。焦点归纳错，检索全偏。

2. **平台与检索方法**
   - 平台：中国裁判文书网、法信、北大法宝、威科先行、无讼（类案检索指导意见列举）。
   - 方法：关键词检索（最常用）、法条关联案件检索、案例关联检索。关键词宜简，按匹配度高低逐一查阅，结果多则在结果内二次缩小。

3. **报告结构（指导意见硬性要求）**
   - 必备：检索主体、时间、平台、方法、结果，类案裁判要旨，待决案件争议焦点。
   - 呈现顺序建议：检索目的 → 检索工具 → 关键词 → 法律法规 → 案例 → 检索结论 → 完成时间。

4. **案例排序优先级**
   - 最高院公报/指导性案例 > 最高院一般案例 > 本地高院 > 本院 > 其他法院；以说服力而非数量排序。

5. **结论客观中立**：法条注明发文字号/机关/日期；案例注明法院/案号/裁判日期；裁判要旨尽量原文引用，弱化部分用省略号。

## 二、红队视角（反检索·对抗面）

- **检索盲区打击**：对方"选择性检索"只呈现有利案例时，反向检索同争点的不同裁判口径，制造"法律适用分歧"，阻断类案参照（甚至可推动提级审理证明"重大分歧"）。
- **时效性核查**：对方引用的案例若所依法条已被废止或实质性修改，直接剔除其参考价值。
- **要旨与事实区分**：警惕对方将"个案事实"包装为"普遍裁判规则"；区分裁判要旨的适用条件，勿被断章取义。
- **反向锚点**：主动检索对我方有利但对方未提及的案例，在代理词中先发制人。

## 三、可复用模板（六段式）

```
一、检索说明（主体/时间/平台/方法）
二、检索目标（争议焦点，规范用语）
三、法律法规检索（发文字号+条款+施行时间）
四、案例检索（法院/案号/裁判日期/基本案情/裁判要旨原文）
五、检索结论（客观中立+分析）
六、附件（依据原文）
```
