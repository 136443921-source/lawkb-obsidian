# 慈善组织年度审计与财务报告公开合规 — 以基金会审计报告为例

> 隐私红线声明：本笔记仅从**慈善组织年度审计与财务公开**的合规视角提炼普适要求，将基金会年度审计报告作为法定公开文件进行合规分析，不涉及对任何自然人个人的评价或隐私披露。

## 一、年度财务报告须经审计（刚性义务）

依据新修订《慈善组织信息公开办法》(2026-01-01施行) **第六条**：
- 慈善组织应当于**每年5月31日前**，将年度工作报告和财务会计报告在慈善信息公开平台（"慈善中国"）向社会公开。
- 有业务主管单位的，须先经业务主管单位审查同意。
- **具有[[公开募捐资格|公开募捐资格]]的慈善组织，其年度财务会计报告须经审计。**

## 二、审计机构选聘合规

1. **独立第三方**：应委托具备资质的会计师事务所出具审计报告，确保独立性。
2. **选聘程序**：通过理事会决议确定审计机构，回避利害关系（审计机构与基金会理事/高管无利益冲突）。
3. **审计范围**：年度全部收支、资产负债、净资产变动、公益支出比例、管理费用、募捐成本（衔接2026年《[[关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定]]》）。
4. **审计意见运用**：无保留意见为合规基线；保留/否定/无法表示意见须作为重大风险向登记机关和公众说明。

## 三、财务数据公开要点

| 公开内容 | 时限 | 依据 |
|---|---|---|
| 年度工作报告+财务会计报告 | 每年5月31日前 | 办法第六条 |
| 重大资产变动/重大投资/重大交易及资金往来 | 发生后30日内 | 新修订办法新增 |
| 慈善项目终止剩余财产处理 | 终止后3个月内 | 办法第九条 |
| 慈善信托设立 | 设立后30日内 | 办法新增 |

## 四、三年审计报告对比的合规读法（方法论）

对连续年度审计报告做对比时，合规视角应关注：
1. **公益支出比例**是否达法定下限（年度支出规定）；
2. **管理费用/募捐成本**是否超标；
3. **净资产变动**与捐赠收入匹配性；
4. **审计意见一致性**；
5. **重大交易披露**完整性（关联交易、对外投资）。

> 注意：以上为组织财务合规分析框架，任何结论须基于经审计的公开报告，不得对未公开的个人薪酬/私人财务作推断。

## 五、对厚德基金会的动作清单

- [ ] 将"年度财务会计报告须经审计"写入《财务管理办法》并设5月31日死线
- [ ] 审计机构选聘：理事会决议 + 独立性声明 + 利益冲突回避
- [ ] 建立"重大资产变动30日内公开"内部预警机制
- [ ] 审计发现问题 → 限期整改 → 整改情况随年度报告公开
- [ ] 配合业务主管单位（如有）审查同意流程，预留提前量
