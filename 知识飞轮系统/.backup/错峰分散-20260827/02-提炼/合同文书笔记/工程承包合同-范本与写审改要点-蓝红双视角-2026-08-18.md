# 《工程承包合同》范本及写作要点 · 蓝红双视角提炼

> **一句话内核**：工程承包合同是工程项目的"宪法"——把"合理工期延误""验收合格"等模糊术语转化为**可量化、可举证**的操作指引；法律人的核心能力是"**风险翻译**"：将桩基检测、隐蔽工程验收、材料调差等技术术语翻译为权利救济路径，在付款节点与履约保函间设计制衡，在变更签证程序里埋设时效失权条款。

---

## 一、范本框架（26 条）

合同文件及解释顺序 / 语言文字与适用法律 / 图纸 / 工程概况 / 工程期限 / 工程质量和检查验收 / 工程合同总价 / 工程价款的支付与结算 / 施工准备 / 材料设备供应 / 施工与设计变更 / 甲乙双方驻工地代表 / 甲方工作 / 乙方工作 / 奖励惩罚与仲裁 / 工程负责人和工伤事故 / 保修 / 争议解决 / 违约责任 / 工程分包 / 不可抗力 / 保险 / 附则 / 生效与终止 / 合同份数。

**关键制度点（范本内嵌）**：
- 工期顺延 7 种情形（甲方场地/水电道路未通、甲供材料缺陷、重大设计变更、停水停电8小时或连续3天、监理签证不及时、未按约付款、不可抗力）——均需**甲方现场代表签证**。
- 隐蔽工程：乙方自检→填《隐蔽工程验收单》→监理 X 小时内到场验收签证→方可下道工序；监理未到场的，经质检部门检验合格可自行隐蔽。
- 已竣工未验收：甲方**提前使用即视同交验**；乙方应交不交的按拖延工期处理。
- 保修：土建 1 年、采暖 1 个采暖期、水电半年；乙方拒不修理可动用预留保修款。
- 付款：备料款+进度款按月核付，付至 95% 停止，保修期满付清尾款；甲方拖欠付日万分之X违约金。
- 材料检验：不合格材料不得进场；**任何一方强迫对方使用不合格材料要签证记录在案，后果由强迫方承担**。
- 设计变更：书面通知→7 天内与原设计单位商定→办手续后施工；超原标准规模须原批准单位审批。
- 未经验收甲方提前使用→质量等问题由甲方担责。

## 二、蓝队视角（审查/防守·护发包方或守约方）

1. **解释顺序定生死**：强势甲方把"本合同→工程说明书→招标文件→投标书→补充合同"排前面；务必约定"补充合同与本合同抵触处，以本合同为准"，防止后期补充协议架空主合同。
2. **工期条款**：顺延须"经甲方现场代表签证"——把顺延权收归书面签证，防止乙方单方主张顺延；明确竣工日期以**最后检验合格日期**为准。
3. **验收节点**：设置"甲方提前使用视同交验"+验收逾期视为合格的双向机制，防止工程悬而未验。
4. **付款制衡**：进度款按"核实的工程进度"支付，付至 95% 停付、保修期满结清——尾款即履约保证金；预留保修款可动用。
5. **分包管控**：分包单位和内容须甲方同意；禁止转包。
6. **保险**：乙方为场地内材料设备、危险作业职工、施工机械办理保险（意外伤害险强制）。

## 三、红队视角（攻击/对抗·护承包方或被诉方）

1. **甲方责任落空**：甲方未办妥征地拆迁、未通水电道路、图纸迟延、未按约付款→乙方可主张工期顺延+停窝工损失（范本第八条5款、第十一条2款均明确"由甲方负担/承担"）——这是乙方最有力的抗辩与反诉抓手。
2. **变更签证程序**：甲方要求加快/特殊施工方法→"所增费用由甲方负担"，但要办妥手续留痕；设计变更未批准前任何一方不得强行施工——甲方强行变更可拒绝。
3. **材料价差**：甲方供料指标由乙方采购的，政策性调价/价差由甲方补差；甲方指定厂家品种的按实结算——**价差条款是索赔富矿**，务必备齐调价依据。
4. **工伤事故责任切割**：范本约定"施工中伤亡事故和乙方管理不善造成的其他损失由乙方负责"——乙方代理时应抗辩：该约定不能对抗工伤法定责任，但可作内部追偿依据；同时审查甲方是否尽到提供安全作业条件义务。
5. **解释顺序反制**：强势乙方把"补充合同→本合同→招标文件→投标书→工程说明书"前置，防止甲方以招标文件细节刁难。
6. **不可抗力程序**：24 小时内通报+按约定时间报告损失，费用按范本分担（工程本身损害甲方担/人员伤亡所属单位担/乙方设备机械停工乙方担）——及时书面通报是免责前提。

## 四、执业启示

- **风险翻译能力**：把"合理工期延误"翻译成"7 种顺延情形+签证程序"；把"验收合格"翻译成"实测实量 vs 观感评定"的量化标准——合同价值在把模糊术语变成可举证规则。
- **烂尾项目应对**：签约阶段布好"刹车"（付款节点+签证程序+时效失权条款）与"安全气囊"（履约保函、保修款、保险），而非事后被动适用法定解除权。
- 范本第 16 条"提交工商行政管理部门仲裁"系旧制，实务应改为仲裁委员会或法院管辖并明确仲裁机构名称。
