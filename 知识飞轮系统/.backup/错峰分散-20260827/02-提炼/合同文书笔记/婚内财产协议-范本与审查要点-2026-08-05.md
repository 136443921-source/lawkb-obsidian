# 婚内财产协议（范本结构与审查要点）

> 来源：IMA「合同文书AI助手」公众号范本（男方甲方 / 女方乙方 双方）。
> 定位：婚内财产约定主线，衔接《民法典》婚姻家庭编·夫妻财产制约定。

## 一、协议结构（范本逐条）

| 条款 | 内容要点 |
|------|---------|
| 一、婚前财产约定 | 列明各自婚前房产/存款/股权，注明权证号，归各自个人所有 |
| 二、婚后所得归属 | 共同所有 / 分别所有 / 部分各自部分共同（三种模式勾选） |
| 三、房产特别约定 | 婚前首付+婚后共同还贷的增值分割、加名条件 |
| 四、债务承担 | 个人债务各自承担；共同债务共签共认 |
| 五、日常生活开支 | 共同账户额度、大额支出事前协商 |
| 六、违约责任 | 隐瞒财产/擅自处分的赔偿与救济 |
| 七、协议生效与变更 | 签字生效、变更需书面 |

## 二、蓝队（防御审查）要点

1. **财产范围须具体** — "归甲方个人所有"必须对应明确不动产/账户，并附权证号；笼统写"各自财产归各自"在发生争议时权属边界模糊，易生举证困难（《民法典》第 1065 条要求"书面形式"且内容明确）。
2. **婚前首付+婚后还贷的增值** — 应单独约定补偿计算方式（首付比例×增值），否则离婚分割时按共同还贷+增值处理，对首付方不利。
3. **债务隔离** — 必须明确"一方未经对方书面同意所负债务由举债方个人承担"，否则可能被认定为夫妻共同债务（第 1064 条共债共签）。
4. **处分限制** — 对重大财产（房产）设定单方处分无效/违约条款，并约定公示（如不动产登记备注）。

## 三、红队（攻击/抗辩）空间

- 一方可主张协议存在**胁迫或显失公平**请求撤销（《民法典》第 151/152 条），尤其在签署时机临近购房、一方信息弱势时。
- 协议**不能对抗善意第三人**：对外负债仍可能以共同财产清偿，仅内部追偿（第 1065 条第 3 款）。
- 约定"净身出户"类条款易被认定**限制离婚自由/违背公序良俗**而无效，须转化为财产分割对价而非惩罚。
