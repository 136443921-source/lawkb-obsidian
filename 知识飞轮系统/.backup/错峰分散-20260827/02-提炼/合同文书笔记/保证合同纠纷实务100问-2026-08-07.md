# 保证合同纠纷实务100问（保证责任七步审查路径）

> 来源：IMA「合同文书AI助手」公众号（作者：三章约法，2026-07-26）。
> 定位：以保证责任**七步审查路径**为主线，系统梳理《民法典》+《公司法》+ 担保制度解释下保证合同的成立、效力、资格、方式、范围、期间、行权、抗辩与追偿，共 100 个高频实务问题。
> 价值：比单篇模板更"体系化"，适合作为保证合同纠纷的**审查清单与抗辩手册**。

## 一、内容结构（八模块拆解）

| 模块 | 主题 |
|------|------|
| 一、成立·从属性·效力 | 保证意思认定、独立性约定无效、主合同无效后果、解除后责任 |
| 二、保证人资格·公司担保 | 自然人/公益机构资格、分支机构、公司决议程序、上市公司披露、债务加入参照担保 |
| 三、方式·范围·最高额 | 一般/连带区分、方式不明推一般保证、最高额保证债权确定 |
| 四、主债务变更·转让·共同保证 | 变更加重部分不担责、展期不当然顺延、债权/债务转让、共同保证追偿 |
| 五、保证期间·诉讼时效·破产 | 法院主动审查、不发生中止中断延长、方式不明推 6 个月 |
| 六、起诉·管辖·举证·保全 | 被告列明、诉讼请求写法、管辖与仲裁分别审查 |
| 七、抗辩·责任认定·执行 | 援引主债务抗辩、保证无效过错赔偿、先诉抗辩权执行顺序 |
| 八、代偿追偿·反担保 | 追偿条件、反担保效力、将来求偿权申报 |

## 二、蓝队视角（债权人风控要点）

1. **保证意思须清晰可证**（第 1–9 问）— 仅有"介绍/协调/督促"表述不成立保证；第三人单方保证书债权人接收未异议即成立；主合同见证人/经办人处签字不推定保证。
2. **公司担保"决议+善意"双核**（第 18–23 问）— 非关联担保须董事会/股东会决议；关联担保须股东会且关联股东回避；债权人须对决议作**合理形式审查**（章程、机关、表决、回避）方构成善意；上市公司须公开披露。
3. **保证方式必须写明**（第 30–32 问）— 方式不明依《民法典》第 686 条推**一般保证**（与原《担保法》相反）；"不能履行"通常一般保证，"不履行/无条件"通常连带。
4. **保证期间管理是生死线**（第 53–60 问）— 法院**主动审查**保证期间；不发生中止/中断/延长；未约定或约定不明 = 主债务届满起 **6 个月**；"至本息还清"视为约定不明亦推 6 个月。一般保证须对债务人起诉/仲裁，连带须向保证人明确主张。
5. **变更/展期须重新书面确认**（第 40–43、100 问）— 加重部分未经书面同意不担责；展期不当然顺延保证期间；借新还旧新旧保证人不同须证明知情的，否则新贷保证人不担责。

## 三、红队视角（保证人/债务人攻防要点）

- **保证意思抗辩**— 主张仅为见证人/经办人，或签字页孤立无对应保证条款；冒用签名可申请笔迹鉴定。
- **公司担保越权代表抗辩**（第 20–21 问）— 法定代表人未经决议构成越权代表；债权人非善意时保证合同对公司不生效，公司仅依过错赔偿。
- **保证期间届满抗辩**（第 53–58 问）— 债权人催错对象、采用错误行权方式（仅向债务人催收、仅内部签发未送达），保证责任消灭；期满后签字通常仅证收悉，不复活保证。
- **方式不明推一般保证**（第 32 问）— 合同措辞不清时，保证人可主张先诉抗辩权，债权人须先执行债务人财产。
- **主债务抗辩援引**（第 83–87 问）— 保证人得援引债务人对债权人的实体抗辩（未成立/已清偿/时效届满）；主债权超时效保证人可抗辩。
- **保证无效过错赔偿封顶**（第 85 问）— 保证无效后按过错赔偿，债权人保证人皆有过错不超债务人不能清偿 1/2；保证人无过错不赔。

## 四、实务风险卡片

- **最高频雷区**：保证方式不明（推一般保证）、保证期间过期（法院主动审、不中断）、公司担保决议缺失（债权人非善意）。
- **关键区分**：**保证期间 vs 诉讼时效**——前者决定责任能否发生/存续、法院主动查明、不中止中断延长、通常 6 个月；后者限制已成立请求权、须当事人抗辩、可中止中断、通常 3 年。
- **债务加入陷阱**（第 26–29 问）— 以"债务加入"名义承诺还款仍参照公司担保规则审查决议；表述不清时司法解释按保证认定。
- **破产衔接**（第 70、92、99 问）— 债权人可同时申报破产债权与向保证人主张，但不得重复受偿；附利息债权自破产受理日停止计息；保证人可申报将来求偿权。
- **公益衔接**：以公益为目的非营利学校/医院/养老机构不得为保证人（《民法典》第 683 条）；厚德基金会对外担保须审慎，营利性子公司另审章程与决议。
