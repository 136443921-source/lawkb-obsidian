# [[和解协议-范本与审查要点|和解协议-范本与审查要点]]（蓝红双视角）

> 原文：《[[合同库-和解协议模板|合同范本 | 和解协议模板（庭外和解）]]》（扬律讼典，2026-07-23）
> 关联：[[民事纠纷私了和解协议书（标准文本）— 蒸馏笔记]]、[[债权转让协议-范本与审查要点-2026-08-14]]

## 协议骨架（七条）
欠款确认 → 分期支付安排 → 履行后果（免违约/违约金10%+诉讼保全）→ 撤诉条件 → 结清条款 → 保密 → 生效

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 违约金10%是否过高 | 相对实际损失可能过高，法院可调减 | 结合损失评估，可约定"不超过实际损失30%"（参考违约金调整规则） |
| 撤诉与付款脱节 | 第四条约定甲方撤诉否则付款条款不生效，但未约定撤诉时限违约责任 | 明确撤诉期限+甲方逾期撤诉的违约责任；乙方可保留抗辩 |
| 收款账户错误风险 | 账号填写错误致款项错付 | 明确账户核对义务；错付风险由付款方承担 |
| "再无纠纷"范围 | 第五条结清条款未列明债权范围 | 明确覆盖范围（合同履行+货款+利息+违约金等）；保留未列明债权主张 |
| 保密必要性 | 和解场景下保密条款可能限制乙方维权 | 评估是否必要；可约定"除依法披露外" |
| 执行保障 | 仅约定违约可诉讼，未含强制执行公证 | 可考虑赋予强制执行效力公证，降低后续成本 |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **付款抗辩**：若甲方未按期撤诉，乙方可依第四条主张付款条款不生效（先诉抗辩或同时履行抗辩）
2. **违约金调减**：10%违约金若明显高于实际损失，可依《民法典》585条请求调减
3. **结清条款漏洞**：若协议未列明全部债权，可主张未结清部分继续主张
4. **履行抗辩**：甲方收款后不撤诉的，乙方可主张甲方违约并拒付尾款
5. **诉讼时效衔接**：和解协议本身形成新债，注意诉讼时效3年重新起算

## 裁判规则
- [[R-HT-063|R-HT-063]]：庭外和解协议约定的违约金过分高于实际损失的，违约方可请求法院或仲裁机构予以适当减少；和解协议形成新的债权债务关系，诉讼时效重新起算
- [[R-HT-064|R-HT-064]]：和解协议约定债权人未按期撤诉则付款条款不生效的，债务人可据此主张同时履行抗辩；债权人收取款项后不履行撤诉义务的构成违约

## 实务清单
- 债权人（甲方）：明确撤诉期限与违约责任/收款后及时撤诉/保留10%违约金
- 债务人（乙方）：核对结清范围/控制违约金比例/关注撤诉联动条款
- 双方：保留履行凭证/考虑公证赋予强制执行效力
