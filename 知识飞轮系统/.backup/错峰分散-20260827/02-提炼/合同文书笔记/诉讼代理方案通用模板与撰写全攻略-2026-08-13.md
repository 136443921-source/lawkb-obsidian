# 诉讼代理方案通用模板与撰写全攻略

> 来源：律思漫叙（2026-08-11）｜回补 w_2026-08-12 漏窗｜关联 [[R-HT-049]]
> 一句话价值：**诉讼代理方案 = 决策依据 + 行动纲领**，是贯穿案件全生命周期的作战蓝图，六大结构 + 三大思维。

## 一、定位与功能

1. **对委托人**：决策依据——说清案件进展、处境、可选方案、各方案胜算/成本/风险，给出务实建议而非法条复读。
2. **对承办团队**：行动纲领——证据收集、法律检索、庭审提纲、调解策略全部围绕方案轴心展开。

## 二、通用模板六大部分（蓝队结构视角）

| 部分 | 核心内容 | 撰写要点 |
|---|---|---|
| 开篇信 | 称谓规范、交代工作基础、明示团队配置、界定"供审阅决策"性质 | 用"基于现有材料"为策略调整留空间 |
| 案件基本情况 | 案件由来、对方诉请及依据、基本事实梳理 | 客观不带评价；区分"客观事实"vs"法律事实"；"无争议—有争议"框架；时间轴思维 |
| 核心法律分析 | 总体策略、核心抗辩/主张、辅助抗辩、质证意见 | 司法三段论（规范→事实涵摄→结论）；核心抗辩须"能推翻全部请求" |
| 反诉可行性 | 程序+实体两维度判断、有利/不利因素、替代方案 | 不偏不倚；重点分析最致命条款；替代方案=过错相抵融入本诉+保留另诉权+调解筹码 |
| 诉讼策略与执行计划 | 庭前/庭审/判决后三阶段 | 明确时间节点、责任分工（答辩状何时交、申请哪些调查令、鉴定机构选择、调解报价锚点） |
| 风险提示 | 每项"风险描述+不利影响+应对措施"三层 | 合同刚性约束/举证困难/法律适用不确定/保全执行/诉讼周期/商业关系破裂 |

## 三、三大贯穿思维（红队攻击视角）

1. **法官思维**：每句话预演"法官看到怎么想"，杜绝脱离事实的宏论和有论无据的断言。
2. **成本收益思维**：算清经济账/时间账/关系账；好的策略是最"经济"的策略（反诉败诉风险高时果断放弃，转为本诉抗辩消化）。
3. **动态应变思维**：申明方案"阶段性"，预设调整接口（"根据目前材料""若后续出现……调整为……"）。

## 四、避坑指南（红队攻击点：对方方案中的破绽）

1. **事实叙述大包大揽→构成自认**：对己不利事实用"原告主张""双方存在分歧"等中性表达，勿写"我方确实违约"。
2. **策略头重脚轻**：只分析法律性质、无执行路径 = 最大败笔。
3. **反诉分析变"必选项"推介**：绝不为显示主动鼓动客户提起胜算渺茫的反诉。
4. **风险提示走过场**："任何诉讼都有风险"等于没说；风险深度体现专业性。
5. **语言两极分化**：避免情绪化表达，也避免学术化堆砌。

## 五、可复用要点（执业提示）

- 辅助抗辩四方向：违约金调减（585条2款、超损失30%属过分高于）、因果关系抗辩、减损义务（591条）、履行条件未成就（结算/验收前置）。
- 违约金调减是主战场：法院全额驳回金钱给付概率不高，但调减幅度往往很大；准备损失对比数据+参考判例。
- 反诉替代路径：把"过错相抵+防止损失扩大"融入本诉答辩，实质达反诉效果且无败诉风险。
