# R-HT-017 居间（中介）合同"跳单"违约认定规则

## trigger（触发情形）
二手房/房屋买卖居间（中介）合同中，委托人看房后绕开原中介、经其他中介或更低价与同一出卖人成交，中介主张违约金。

## 裁判要旨
委托人利用特定中介提供的**独有**房源信息、交易机会绕开该中介直接订立合同的，构成"跳单"违约；但同一房源经多个中介公开发布的，委托人有权选择报价低、服务好的中介促成交易，不构成违约。

## 适用要点
1. 违约认定的核心：是否不当利用了特定中介的"独有媒介服务"，而非单纯以"最终是否经该中介成交"为准。
2. 起草跳单条款应明确"独家委托/独有房源信息"前提；笼统限制委托人比价选择的条款可能被认定无效。
3. 代理中介方：固定"独家委托+已提供特有服务"证据；代理买方：主张房源公开挂牌、有权自主比价。
4. 现行法依据：《民法典》第961—966条（中介合同）、第509条（诚信）、第577条（违约责任）。指导性案例裁判要点仅作裁判理由引述，不得作裁判依据。
