# R-PI-033 医疗损害责任：未尸检时鉴定意见效力与责任比例酌定规则

**trigger（触发情形）**：医疗损害责任纠纷中患者死亡、未做尸检（家属拒绝或尸体已灭失），双方就鉴定意见效力、责任比例、"上一年度"赔偿节点发生争议。

**裁判要旨**：
1. 尸检并非[[医疗损害鉴定|医疗损害鉴定]]的唯一必要依据；尸体灭失无法尸检时，鉴定机构结合经质证病历、产程记录等客观资料作出的合法鉴定意见，法院应予采信。
2. 鉴定意见给出原因力范围（如次要至同等）的，法院可结合诊疗过错程度、未尸检责任归属，在范围内酌定具体比例，不必参照关联案件。
3. 人身损害赔偿"上一年度"=本案一审法庭辩论终结时的上一统计年度；此前撤诉案件的辩论终结时间不适用于本案。

**适用要点**：
- 患方：未尸检仍应积极以病历/诊疗规范推动鉴定，固定客观资料，避免死因不明抗辩阻断索赔。
- 医方：举证诊疗合规，主张在鉴定原因力范围内取下限。
- 计算：赔偿标准年度以本次诉讼一审辩论终结时上溯，隔离前案节点。
