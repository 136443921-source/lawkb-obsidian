# R-PI-034 人身伤害（交通事故）：受害人特殊体质/损伤参与度不减轻侵权人责任

**trigger（触发情形）**：机动车交通事故致人伤残，鉴定意见给出"损伤参与度"（如受害人年老骨质疏松占25%），保险公司/侵权人主张按参与度系数扣减残疾赔偿金、精神损害抚慰金。

**裁判要旨**：
1. 受害人对事故无过错时，其特殊体质（年老、基础疾病）对损害后果的影响，**不属于**可以减轻侵权人责任的法定情形，不得按损伤参与度系数扣减残疾赔偿金等。
2. 交强险责任认定与残疾赔偿金计算均不适用"损伤参与度"扣减。

**适用要点**：
- 受害人代理：遇"参与度扣减"直接援引指导案例24号主张全额。
- 侵权人代理：严格区分"体质因素"（不可扣减）与"受害人过错"（可依法减轻），仅在后者成立时主张扣减。
- 边界：若受害人对损害发生/扩大确有过错（如违法通行被认定担责），依《民法典》第1173条减轻，与体质因素无关。
