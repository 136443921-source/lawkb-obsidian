# R-CF-074 社会组织行政处罚裁量：拒不检查/超范围活动的撤销与警告

## 规则要旨（贵州民政三案）
1. **撤销登记（从重）**：民办非企业单位多次拒接审计、逾期拒不提供资料接受监督检查 → 依《民办非企业单位登记管理暂行条例》第25条第1款第（三）项，参照《贵州省民政系统行政裁量权基准（试行）》序号11从重；涉罪线索移送公安。（贵州知行大学生公益援助站案）
2. **警告（从轻）**：年检填报不规范、超3月逾期整改，但系人员离职疏忽、无主观恶意、无对抗检查、主动补齐 → 依《社会团体登记管理条例》第30条第1款第（三）项，参照裁量基准序号3从轻。（黔南州船艇运动协会案）
3. **撤销登记**：超章程宗旨和业务范围使用资金（本案695万元） → 依《民办非企业单位登记管理暂行条例》第25条撤销。（遵义市致善社会工作服务中心案）

## 裁量逻辑
- "教育整改优先、撤销惩戒兜底"；对拒不配合监督检查"零容忍"。
- 综合全案事实审慎裁量：无主观恶意+立案后迅速整改→从轻；蓄意对抗/超范围巨额→从重。

## 内规衔接
依据《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》"监督改进"章节：年检年报、整改落实、日常监管为常态化底线；具体条款号以手册为准。
