# R-CF-088 慈善关联关系：三条底线与"建制度-理清单-控流程-强监督"四步体系

## 裁判规则
《慈善法》第14条划定关联关系边界：可能导致慈善组织、受益人利益或社会公共利益受损的特殊关系。慈善组织不得利用关联关系侵占慈善财产（虚列费用套取、低价转让资产、明捐暗退、高于市场价承接项目）；关联方必须回避自身相关决策（未回避的决策无效并追责）；不得隐瞒关联关系或不公开关联交易（《慈善组织信息公开办法》要求在"慈善中国"等平台公开，未公开责令整改、情节严重列入异常名录）。

## 适用要点
1. 关联方清单：主要捐赠人（年度捐赠占接收总额10%及以上）、发起人单位、理事来源单位（超1/3理事来自同一机构）、投资企业（持股超20%）、控制或影响决策的其他机构，以及发起人/理事/监事/秘书长等高管及其近亲属。
2. 四步体系：建制度（认定标准/审批权限/回避操作/违规处理）→理清单（首梳+每半年复核+审批前先查）→控流程（事前申报/回避表决/价格公允/留痕存档至少10年）→强监督（监事会每年核查、决策后10个工作日内公开、每年第三方审计）。
3. 分类处理：资源型关联合规合作；潜在风险型关联须全体非关联理事2/3以上同意；必要型关联设"防火墙"（第三方评估定价+完全回避+全程监督）。
4. 合规本质：通过规则筛选"良性关联"、剔除"风险关联"，守住公益初心。

## 援引法条
《慈善法》第14条；《慈善组织信息公开办法》（2026年1月1日施行）；《[[民间非营利组织会计制度|民间非营利组织会计制度]]》。
