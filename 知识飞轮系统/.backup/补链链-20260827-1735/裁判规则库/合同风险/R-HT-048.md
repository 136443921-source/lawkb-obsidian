# R-HT-048 政策调整致合同目的不能实现的责任划分

## 规则表述

涉矿产资源增资扩股、合作合同纠纷中，应依合同约定判断合同目的是否实现。当因**政策调整**导致合同目的不能实现时，应结合合同约定与政策调整因素确定双方责任。即便合同约定"无论因何种原因解除，一方均需返还出资并按比例承担违约责任"，法院仍应考虑政策调整的不可预见性，判令违约方承担**返还已收取出资款 + 未及时返还的资金占用费损失**，而非机械适用约定比例违约金。

## 要件

1. 政策调整须达到"订立合同时无法预见、继续履行显失公平"方触发民法典533情势变更审查；
2. 双方就合同目的实现与否各执一词时，法院查明目的实现原因；
3. 约定违约金明显过重且源于政策风险时，可据政策因素调整至合理区间（返还+资金占用费）；
4. 与民法典580（非金钱债务实际履行例外·合同僵局终止）协同适用。

## 适用要点（攻防）

- **主张目的不能实现方**：以政策不可预见 + 继续履行显失公平为枢轴，援引533/580；
- **主张继续履行方**：证成合同目的仍可实现、政策影响可消化；
- **违约金抗辩**：政策风险下约定比例违约金可请求酌减至资金占用费合理水平。
