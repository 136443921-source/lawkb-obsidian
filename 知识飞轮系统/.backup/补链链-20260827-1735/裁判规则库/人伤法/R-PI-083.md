# R-PI-083 篡改封存病历→过错推定→全责

## 规则表述

医疗机构工作人员**擅自启封、向已经封存的病历中加插材料**，破坏已封存病历的完整性、真实性和客观性，构成**故意篡改病历资料**；依《民法典》第 1222 条（原《侵权责任法》第 58 条）**推定医疗机构有过错**；篡改行为导致[[医疗损害鉴定|医疗损害鉴定]]不能、各方责任无法查明的，医疗机构应承担不利法律后果和**全部法律责任**。

## 要件

1. 存在病历**已经封存**的事实（医患双方在场、开列清单）；
2. 医疗机构或其工作人员**擅自启封并加插/修改**材料，使封存件出现版本冲突（如医嘱单两个版本）；
3. 该行为导致鉴定不能或责任无法查明；
4. 法律效果：过错推定 + 举证负担转移至医方 + 全责风险。

## 适用要点（攻防）

- **患方（攻）**：接案即主张封存；发现启封/加插痕迹，直接以第 1222 条第三款主张过错推定，将因果关系/过错举证转移给医方。
- **医方（防）**：严格封存启封程序（双方在场、清单签收）；任何病历补记须在封存前完成或依法定程序，严禁事后加插。
- **衔接**：行政层面触发《医疗纠纷预防和处理条例》处罚；民事层面与 R-PI-082（限制类技术未备案加重赔偿）同为"违规→责任加重"逻辑。
