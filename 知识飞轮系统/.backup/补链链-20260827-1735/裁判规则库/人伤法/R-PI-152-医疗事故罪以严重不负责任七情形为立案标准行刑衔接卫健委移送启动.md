# R-PI-152｜医疗事故罪以严重不负责任七情形为立案标准行刑衔接卫健委移送启动

## 裁判规则

医疗事故罪（《刑法》335条）以"严重不负责任"为核心认定标准，七种法定情形（最高检公安部《立案追诉标准（一）》）：擅离职守；拒绝对危急就诊人必要救治；擅自试验性医疗；严重违反查对复核制度；使用未经批准药品器械；**严重违反诊疗技术规范常规**；其他。构成要件四层（主体医务人员/过失/严重不负责任+死亡或严重损害后果/直接因果关系）。程序上系公诉案件，由卫健委行刑衔接移送公安立案，家属不能自诉追责。韩杰案（2026-05-28 二审维持，漏诊未查体未请会诊→违反诊疗规范）确立"未履行常规诊疗措施+造成死亡"的典型入罪路径。

## 适用范围

- 医疗事故罪立案与辩护（漏诊、延误、违反诊疗规范）
- 行刑衔接程序应对
- 刑事辩护中"严重不负责任"的否定与因果链抗辩

## 关联法条

- 《刑法》第335条
- 最高检公安部《关于公安机关管辖的刑事案件立案追诉标准的规定（一）》
- 《医疗事故处理条例》（一级甲等医疗事故认定）

## 实务要点

1. 辩护重点：① 未达"严重"程度（一般过失不入罪）；② 损害主要由疾病自然进展/多因介入导致（切断因果链）；③ 地方与学科医疗水平差异（罗翔"折中说"）
2. 患者执意转院须风险告知+签字确认（医院留痕抗辩）
3. 未尸检鉴定报告证明力可质疑；民营鉴定机构资质可审查
4. 医疗事故罪与民事[[医疗损害责任|医疗损害责任]]并行：民事过错比例（85%）不必然等于刑事"严重不负责任"评价
