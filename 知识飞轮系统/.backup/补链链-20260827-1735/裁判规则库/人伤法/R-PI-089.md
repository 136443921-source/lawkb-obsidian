# R-PI-089 第三人侵权时安全保障义务人的补充责任

## 规则表述

损害是**第三人**的行为直接造成，经营者、管理者或者组织者未尽到安全保障义务的，承担相应的**补充责任**，并**有权向第三人追偿**。义务人仅在"能够防止或制止损害却未尽合理限度安保"的**相应范围**内兜底，非全额连带责任。

## 要件

1. 损害由第三人侵权行为直接造成（第一责任人为第三人）；
2. 义务人未尽安保义务（可防未防、可止未止）；
3. 补充责任范围为"相应范围"——综合义务人过错程度、未尽义务的原因力、第三人主导性裁量（实务常见 30%–60%）；
4. 义务人承担后，向第三人**全额追偿**。

## 适用要点（攻防）

- **受害人（攻）**：证明第三人侵权 + 义务人"可防未防"（如监控可见却未制止/未报警救助），主张补充责任；
- **义务人（防）**：证明已尽合理限度（及时报警、救助、警示），将责任推回第三人，仅承担极小或零补充责任。
