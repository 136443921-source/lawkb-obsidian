# R-PI-168 医疗事故罪(335)与非法行医罪(336)罪间界分及严重不负责任认定

**规则**：
- **主体界分**：335主体为**医务人员**（有执业资格），336主体为**未取得医生执业资格者**。主体不适格直接排除335、可能落入336或无罪。
- **主观界分**：335仅**过失**（责任事故）；336可为过失或间接故意。
- **客观界分**：335限于**责任过失**（违规章/常规）；技术过失不构335。336责任/技术过失均可。
- **量刑**：335基本刑**3年以下有期或拘役**；336致死亡**10年以上有期+罚金**。
- **入罪门槛**：335须「严重不负责任」，以立案追诉标准一第56条七情形为据（擅离职守/拒救危急/擅自试验性医疗/严重违反查对复核/使用未经批准药械/严重违反诊疗规范/其他）；技术事故、难以预见并发症不构罪。
- 「严重损害身体健康」= 严重残疾、重伤、感染艾滋病/病毒性肝炎等难以治愈疾病。

**实务**：辩护应优先打主体不适格、技术过失、因果中断、七情形之外四向；即便构罪以抢救/赔偿谅解争取缓刑。
