# R028 医疗漏诊按原因力担责：赔偿按"生存期缩短"折算，丧葬费不予支持

## 规则表述

医疗机构存在**漏诊**过失（鉴别诊断不充分，如影像已示异常、血管造影排除梗死原因后未进一步排查占位病变），但患者死亡的根本原因是高龄、基础疾病及原发疾病恶性程度高的，医方仅就其过失与患者"**生存期缩短**"之间的因果关系承担按份赔偿责任（如 10%），死亡赔偿金按缩短年限折算，**丧葬费不予支持**；责任比例属法官在原因力框架下的自由裁量。

## 法律依据

- 《民法典》第1218条（医疗损害过错责任，患方举证）、第1219条（告知义务）
- 《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释》过错参与度/原因力规则
- 民诉法司法解释：当事人无足以反驳的相反证据的，鉴定结论证明力法院应当认定

## 要件拆解

1. 定性边界：漏诊（查到了没深究）≠ 误诊（查错了方向）；符合当时诊疗思维的初诊方向不构成过错
2. 过错成立点：初步诊断思路排除后（如造影无犯罪血管）未转向其他鉴别诊断
3. 因果关系分层：过失→生存期缩短（有因果）；生存期缩短→死亡（无因果，根本原因系原发疾病）
4. 证据规则：录音等单点证据仅证"未告知"，不能证"告知即治愈"；对抗鉴定需足以反驳的相反证据
