# R-HG-054 公司尽职调查材料清单：十三模块全覆盖

## 裁判规则
公司尽调材料清单应覆盖十三模块：主体资格、设立及历史沿革、股东及实控人（穿透至最终实控人）、董监高、组织结构与治理、业务、资产（土地房产/租赁/知识产权/设备）、重大债权债务、税务财务财政补贴、关联交易与同业竞争、重大资产变化及收购兼并、劳动社保公积金、诉讼仲裁行政处罚。尽调结论须以原始凭证（工商档案、出资流水、权属证书、涉诉检索截图、访谈记录）为支撑，股权与关联交易须穿透核查。

## 适用要点
1. 设立及历史沿革须全套工商档案+历次出资凭证（打款流水/验资/审计/评估）+股权转让个税完税凭证。
2. 股权结构图穿透至最终实际控制人；股东涉诉检索（裁判文书网+被执行人查询）截图留档。
3. 关联交易须统计近三年类型/内容/金额/定价依据并专项访谈；同业竞争须访谈+承诺协议。
4. 诉讼仲裁行政处罚模块：涉诉检索截图、全面访谈、未结案件卷宗、经营类处罚文书。

## 援引法条
尽调实务方法论类（《公司法》出资/治理相关条款为背景依据），无单一援引法条。
