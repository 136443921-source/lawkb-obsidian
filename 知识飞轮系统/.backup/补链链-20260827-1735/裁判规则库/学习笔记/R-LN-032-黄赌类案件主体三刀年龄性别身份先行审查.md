# R-LN-032 黄赌类案件主体三刀：年龄、性别、身份先行审查

## 裁判规则
黄赌类刑事案件中"主体适格"先于事实认定：除强奸罪（满14周岁）外，聚众淫乱、赌博等罪普遍要求年满16周岁；周岁按公历生日第二天起算；女性可构成强奸罪共犯/主犯/间接正犯；对未成年负有照护等特殊职责人员与其发生性关系自愿也入罪；聚众淫乱罪仅处罚首要分子与多次参加者（3次以上）；组织卖淫正犯与协助组织卖淫（法释〔2017〕13号第4条但书：有照会所等场所从事正常劳务的保洁收银保安不认定）须严格区分。

## 适用要点
1. 年龄辩护：交叉核验出生医学证明、接种本、入学登记、医院存根；跨年龄段时间轴分段切割，勿混入有罪段。
2. 婚内强奸三道例外口子：登记未同居+女方坚持离婚、感情破裂长期分居、离婚诉讼期间；辩"夫妻关系存续+感情未破裂"。
3. 强制侮辱罪对象仍限妇女；强制猥亵对象已扩至"他人"（刑修九）。
4. 赌博机开设赌场重点打出资者、经营者；受雇接送望风发牌未分利润、未拿高额固定工资的一般不追刑责。

## 援引法条
《刑法》第236条、第236条之一、第237条、第301条、第303条、第358条；法释〔2006〕1号第2条、第6条；法释〔2017〕13号第4条；两高两部2023年办理性侵害未成年人刑事案件意见。
