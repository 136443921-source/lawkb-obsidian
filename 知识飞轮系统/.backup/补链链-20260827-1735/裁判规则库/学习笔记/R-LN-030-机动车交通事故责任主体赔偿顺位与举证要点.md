# R-LN-030 机动车交通事故责任主体、赔偿顺位与举证要点

## 裁判规则
机动车交通事故责任依"交强险限额先行→商业险按约→侵权人补足"顺位赔偿；租赁/借用情形由使用人担责、所有人/管理人有过错承担相应责任；转让未过户由受让人担责（多次转让由最后一次受让人担责）；挂靠经营的挂靠人与被挂靠人承担连带责任；好意同乘应减轻赔偿责任但故意或重大过失除外；"全责/主责"认定不能当然等同于好意同乘中的重大过失，须综合全案事实判断。

## 适用要点
1. 交强险特殊情形：无证/醉驾/毒驾/故意制造事故致第三人损害，保险公司交强险限额内先行赔付后可追偿。
2. 未投保交强险的，投保义务人在交强险限额内赔偿；投保义务人与侵权人非同一人的共同担责。
3. 受害人体质状况不影响减轻侵权人责任（指导案例荣宝英案）。
4. 家庭自用投保后从事网约车营运致保险标的危险程度显著增加的，商业三者险可主张免责。
5. 法院应将承保交强险的保险公司列为共同被告。

## 援引法条
《民法典》第1208-1217条；《道路交通安全法》第76条；《民诉法》第29条；《民诉解释》第24条；《最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释》（2020修正）；《民法典侵权责任编解释（一）》（法释〔2024〕12号）第20-22条。
