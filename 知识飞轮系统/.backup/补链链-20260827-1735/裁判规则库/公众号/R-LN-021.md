# R-LN-021 终本后起诉/执行——查控、拒执与参与分配杠杆

## 规则表述
1. **终本非终结**：终结本次执行后，发现被执行人有可供执行财产的，申请执行人可申请**恢复执行**，不受申请执行时效限制。
2. **查控系统接入**：生效法律文书是接入法院网络查控系统（银行、网络资金、证券、车辆、不动产）的前提。
3. **拒执追责**：被执行人隐藏、转移、故意毁损财产或拒不报告财产，情节严重的，依**拒不执行判决、裁定罪**追责；可先行司法拘留。
4. **参与分配**：已取得执行依据的债权人，在被执行人财产被执行分配时，有权申请参与分配。

## 适用场景
债务人已被列为失信/终本案件被执行人，债权人评估是否起诉或恢复执行。

## 攻防要点
- 蓝队（债权人）：财产摸底→保全→申请执行→终本跟进四步；以拒执罪倒逼履行。
- 红队（债务人）：合法财产隔离与生活保障抗辩；对执行标的异议、执行行为异议救济。

## 法条依据
《民事诉讼法》执行编；《最高人民法院关于严格规范终结本次执行程序的规定》；《刑法》第 313 条拒执罪。
