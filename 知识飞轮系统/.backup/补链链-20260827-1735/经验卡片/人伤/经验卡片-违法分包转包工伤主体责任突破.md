# 经验卡片 - 违法分包转包工伤主体责任突破

## 规则锚定（源自 R-PI-045 / R-PI-030 / R-PI-050）

- **核心规则**：违法分包/转包，具备用工资格的发包方承担工伤主体责任，**突破劳动关系要件**（R-PI-045）。即不以存在直接劳动合同为必要，发包方对违法分包链条下的工伤兜底。
- **与陈长卫案交叉**：陈长卫劳务致害案二审改判供电局担 20% 无过错责任，印证"查违法分包链条全部主体"的实战价值（经验卡片-陈长卫劳务致害案.md）。
- **双轨**：工伤与第三人侵权，医疗费不得双赔、其余可兼得（R-PI-008/036/037）；新就业形态职业伤害待遇不抵扣侵权残疾赔偿金（[[R-PI-037|R-PI-037]]）。

## 办案动作清单
- Step1 查分包链：发包方资质、分包合同、实际施工人。
- Step2 申请工伤认定（条例 + 2026 裁判规则，R-PI-012/013）。
- Step3 待遇计算：项目与本人工资基数（[[R-PI-062|R-PI-062]]）、停工留薪期（[[R-PI-064|R-PI-064]]）。
- Step4 双赔协调：医疗费单赔、其余兼得。
