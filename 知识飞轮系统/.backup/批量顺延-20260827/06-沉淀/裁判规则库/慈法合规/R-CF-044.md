# R-CF-044 慈善活动支出连续不达标的行政处罚阶梯（慈善法第110条）（裁判规则）

## 规则摘要
慈善组织未按规定开展慈善活动、年度慈善活动支出和管理费用未达到法定标准的，由民政部门予以警告、责令限期改正；逾期不改正的，责令限期停止活动并进行整改；情节严重的，吊销登记证书并予以公告。东莞两案（2026-07-22 处罚、2026-07-30 披露）系慈善活动支出规则从纸面走向执法的信号性事件。

## 适用要点
- **处罚阶梯（慈善法第110条）**：
  1. 未达标 → 警告、责令限期改正；
  2. 逾期不改正 → 责令限期停止活动并整改；
  3. 情节严重 → 吊销登记证书并公告。
- **支出门槛（实务口径）**：
  - 非公募基金会：年度慈善活动支出 ≥ 上年末净资产 8%（东莞两案即因 2023、2024 连续年度支出 0 元或低于 6% 被警告）；
  - 公募基金会：年度慈善活动支出 ≥ 上年总收入 70%（《基金会管理条例》另有 6% 净资产口径，须结合章程与登记机关要求）；
  - 管理费用、募捐成本另有专门规定（民政部 2026 年制修订三项文件）。
- **抗辩基础**：留存支出凭证与年报底稿，是应对"未达标"认定与争取整改期的关键证据。
- **执法趋势**：民政部对 214 家全国性慈善组织 2025 年度报告开展形式审核与质量监测，常态化打击非法社会组织，执法已从"规则发布"转入"处罚落地"。

## 反例 / 常见错误
- 连续年度慈善活动支出为 0 元仍不整改，直接触发警告并累积至"情节严重"吊销风险。
- 仅以"无合适项目"抗辩未达标，未留存支出规划与年报底稿，丧失举证能力。
- 混淆公募/非公募支出口径，按错误比例自评导致实际不达标。

## 关联案件 / 组织
- 厚德基金会：依《[[贵州省厚德公益基金会合规管理手册（试行）（2025版）|贵州省厚德公益基金会合规管理手册（试行）（2025版）]]》建立慈善活动支出台账与年报底稿，确保年度支出达标。
- 东莞两案参照：东莞市嘉荣慈善基金会、东莞市桥头中学校友基金会。
