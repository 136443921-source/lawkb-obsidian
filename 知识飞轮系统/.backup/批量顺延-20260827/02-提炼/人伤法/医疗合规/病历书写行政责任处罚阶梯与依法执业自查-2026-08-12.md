# 病历书写行政责任处罚阶梯与依法执业自查

> 锚定 2026 年多地真实行政处罚：南县医院（使用非卫生技术人员+病历质量管理缺失）合并罚 **8.5万元**；烟台某机构病历不完整**警告+1万**；常德某机构未及时填门诊病历**警告+1万**；商丘万乐诊所/商丘仁爱医院均因未规范书写病历被罚。印证"病历书写无小事"已成卫生监督执法常态。

## 一、责任依据（行政监管三层）
- 《[[医疗纠纷预防和处理|医疗纠纷预防和处理]]条例》第15条：按规填写并妥善保管病历资料；
- 第47条（处罚）：未按规定填写/保管病历、未补记抢救病历等 → **警告 + 1万—5万罚款**；情节严重 → 对责任人员降级/撤职，对有关医务人员责令暂停 **1—6个月执业**；构成犯罪的追责。
- 《病历书写基本规范》第3条：客观、真实、准确、及时、完整、规范；第14条：门急诊病历就诊时及时完成。
- 《医疗质量管理办法》第17/23条：遵循诊疗指南与核心制度、加强病历质量管理。
- 《医疗质量安全核心制度要点》"病历管理制度"：可追溯、修改信息留痕。

## 二、处罚阶梯（以裁量基准为轴）
| 情节 | 处罚 |
|---|---|
| 未按规定填写/保管病历（一般） | 警告 + 1万—5万 |
| 初次/轻微/配合调查/已和解退赔（从轻） | 警告 + 1万（下限） |
| 未落实医疗质量安全管理制度1—6项（从轻） | 警告 + 1万—2万 |
| 使用3—4名非卫生技术人员 + 病历管理缺失（合并） | 警告 + 7万（人员）+ 1.5万（制度）= 8.5万 |
| 情节严重 | 责令暂停执业1—6月 / 降级撤职 |

## 三、依法执业自查清单（医疗机构合规闭环）
1. **病历时效**：门急诊病历就诊时完成；抢救病历如实补记并及时。
2. **六性底线**：客观、真实、准确、及时、完整、规范——零漏记/错记/补记违规。
3. **电子病历留痕**：修改信息可追溯，严禁篡改/违法销毁。
4. **告知归档**：知情同意书内容完整再签字，规范归档。
5. **核心制度**：查对复核、三级查房、会诊、危急值——逐项留证。
6. **人员资质**：禁用非卫生技术人员从事医疗卫生技术工作（重罚项）。
