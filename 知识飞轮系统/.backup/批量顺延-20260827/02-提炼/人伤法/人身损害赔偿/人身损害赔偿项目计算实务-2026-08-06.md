# [[人身损害赔偿项目计算实务（蓝红双视角）|人身损害赔偿项目计算实务（蓝红双视角）]]

> 来源：公开权威源降级摄入（黑龙江高院/重庆残联/山西法网普法文 + 《民法典》第1179条 + 《人身损害赔偿司法解释》第6–17条）。原定 IMA「人伤法律实务助手」库摄入，因 IMA 运行态掉线改用公开源。本文是定型化赔偿模式的实务操作母本。

## 一、蓝队视角（受害方·索赔清单）

1. **赔偿项目总纲（《民法典》第1179条）**
   - 一般伤害：医疗费、护理费、交通费、营养费、住院伙食补助费、误工费。
   - 致残：+ 辅助器具费 + 残疾赔偿金。
   - 致死：+ 丧葬费 + 死亡赔偿金。

2. **定型化计算（人身损害司法解释第6–17条）**
   - **医疗费**：凭票据实报；一审法庭辩论终结前实际发生数；后续治疗费凭医疗证明/鉴定结论确定必然发生的可一并赔。
   - **误工费**：固定收入按实际减少；无固定按近三年平均收入；不能举证按受诉法院所在地相同或相近行业上年度职工平均工资；误工时间算至定残前一日。
   - **护理费**：护理人员有收入参照误工费；无收入/雇护工按当地护工标准；原则1人；定残后按护理依赖程度定护理级别；期限最长20年。
   - **残疾赔偿金**：受诉法院地上年度城镇居民人均可支配收入 × 20年（60周岁以上每增1岁减1年，75周岁以上按5年）× 伤残赔偿系数。
   - **被扶养人生活费**、**精神损害抚慰金**（另依精神损害司法解释）。

3. **证据组织**：票据链完整、误工证明（工资流水/完税）、护理依赖鉴定、伤残等级鉴定。

## 二、红队视角（侵权方/保险人·抗辩面）

- **必要性异议**：赔偿义务人对医疗费必要性、合理性有异议的，承担举证责任——主动提司法鉴定的反制点。
- **过错相抵**：《民法典》第1173条（被侵权人过错减轻）；机动车—行人情形依《道交法》第76条，行人过错减轻，机动车无错承担≤10%。
- **误工费抗辩**：60岁以上仍可主张（须证明确仍劳动/务农/返聘），无收入证明则按定型化标准；自由职业须完税/收入凭证，否则不被支持。
- **残疾赔偿金攻击**：年龄、伤残等级可启动重新鉴定；系数与年限是直接压减点。
- **重复赔偿防范**：医疗费、护理费等实际支出项目在"第三方侵权+工伤"双重赔偿中不可兼得，仅伤残/死亡赔偿金等可并行。

## 三、可复用计算口径（蓝队模板）

```
总损失 = Σ(医疗费+误工费+护理费+交通费+住院伙食补助+营养费)
        + [致残] 残疾赔偿金 + 辅助器具费
        + [致死] 丧葬费 + 死亡赔偿金 + 精神损害抚慰金
实赔 = 总损失 × (1 − 过错相抵比例)
```
