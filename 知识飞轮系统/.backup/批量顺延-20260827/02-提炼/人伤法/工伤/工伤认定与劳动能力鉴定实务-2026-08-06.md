# [[工伤认定与劳动能力鉴定实务（蓝红双视角）|工伤认定与劳动能力鉴定实务（蓝红双视角）]]

> 来源：公开权威源降级摄入（呼和浩特人社局访谈 + 海淀法院法官释法 + 《[[工伤保险条例|工伤保险条例]]》）。原定 IMA「人伤法律实务助手」库摄入，因 IMA 运行态掉线改用公开源。实习律师处理工伤案件的高频操作指引。

## 一、蓝队视角（职工方·维权路径）

1. **认定情形（《工伤保险条例》第14条）**
   - 7项：工作时间场所原因受伤；预备/收尾性工作受伤；履职受暴力伤害；职业病；因工外出受伤/下落不明；上下班非本人主责交通事故；其他法定情形。
   - 视同（第15条）：工作岗位突发疾病48h内死亡；抢险救灾受伤；旧伤复发。

2. **申请时限（关键）**
   - 单位：事故/诊断之日起 30 日内。
   - 职工/近亲属/工会：单位未申请的，1 年内直接申请；**超1年不再受理**。
   - 单位30日内未申请期间，符合条例的工伤待遇等费用由单位承担。

3. **申请材料**：工伤认定申请表 + 劳动关系证明（含事实劳动关系）+ 医疗诊断证明。

4. **劳动能力鉴定**
   - 条件：认定工伤后，伤情相对稳定/停工留薪期满，存在残疾、影响劳动能力。
   - 主体：用人单位/职工/近亲属向市级劳鉴委申请；1–10级 + 生活自理障碍3级；60日（可延30）。

5. **双重赔偿**：第三方侵权致工伤，可同时主张[[工伤保险待遇|工伤保险待遇]]与民事侵权赔偿（医疗费等实际支出不可重复）。

6. **举证倒置**：职工/近亲属认为是工伤、单位不认为是的，**由单位承担举证责任**（第19条第2款）。

## 二、红队视角（用人单位/保险人·抗辩面）

- **不认工伤的举证**：单位须限期提交证据，否则承担举证不能后果。
- **排除情形（第16条）**：故意犯罪、醉酒或吸毒、自残或自杀——即使符合第14条亦不认（如醉酒驾驶全责不认工伤）。
- **时限抗辩**：职工超1年申请不予受理；但单位30日内未申请导致的待遇由单位自担，此点单位无法以职工超期抗辩。
- **劳动关系争议**：无合同且单位否认时，须先仲裁确认劳动关系再认定。
- **超过法定退休年龄务工农民**：工作时间内、因工作原因伤亡，仍适用《工伤保险条例》认定（最高法院答复口径）。

## 三、可复用流程清单

```
事故 → 30日内单位/1年内职工申请认定 → 60日作出决定
     → 伤情稳定申请劳鉴 → 60日出等级 → 申报待遇
未投保：全部由用人单位承担
```
