# 客户谈案与案情评估的标准流程（蓝红双视角）

> 来源：公开权威源降级摄入（多家律所服务流程实务文 + 《律师法》《律师服务收费管理办法》）。原定 IMA「律师AI助手」库摄入，因 IMA 运行态掉线改用公开源。本文覆盖从首次面谈到签署委托的全流程合规要点。

## 一、蓝队视角（谈案方·转化路径）

1. **首次面谈四步**
   - 了解案情 → 分析法律关系 → 初步评估可行性及风险（时效、证据缺口）→ 出具《案件初步分析及服务建议书》（会谈后 24–48 小时）。
   - 告知诉讼成本（时间/费用/精力）、替代方案（调解/律师函/支付令/举报），给当事人考虑时间，不催签。

2. **风险告知（强制）**
   - 签署《风险告知书》：诉讼风险、费用构成、审理周期。《律师法》第 31 条：律师不得向当事人承诺案件结果。

3. **委托转化**
   - 委托代理合同（明确代理范围：一审/二审/执行/再审；代理权限：一般代理 vs 特别授权；收费方式）+ 授权委托书，当面签、当面逐条解释。
   - 同步签署风险告知书、开具律师费发票，手续一次办结。

4. **利益冲突审查**
   - 同案多委托人须面签，防止代签/隐瞒其他当事人擅自委托；建立当事人档案（姓名/案由/报价/来源）。

## 二、红队视角（合规防御·红线）

- **禁止承诺结果**：《律师法》第 31 条明文禁止，违则面临行业处分；面谈中"胜诉率"问题应转化为"法律后果与风险评估"。
- **风险代理禁区**：《律师服务收费管理办法》（发改价格〔2006〕611号）第 11–12 条：婚姻、继承、工伤（请求给予社会保险待遇/最低生活保障）、请求支付抚养费/赡养费、刑事、行政、国家赔偿、群体性诉讼等**不得风险代理**；违规将导致合同条款无效并受处罚。
- **虚假陈述识别**：当事人陈述关键事实应录音转文字留存（警惕对方自带录音），重要事实交叉验证，不收原件。
- **收费合规**：政府指导价 + 公示；风险代理比例 15%–30% 区间，超出约定部分可能不被支持。

## 三、可复用谈案清单

- [ ] 主体资格核对（执业证/律所）
- [ ] 法律关系与请求法律依据初步判断
- [ ] 时效/证据缺口风险提示
- [ ] 风险告知书签署
- [ ] 利益冲突检索
- [ ] 委托合同代理范围/权限/收费逐条释明
- [ ] 风险代理禁区排除
