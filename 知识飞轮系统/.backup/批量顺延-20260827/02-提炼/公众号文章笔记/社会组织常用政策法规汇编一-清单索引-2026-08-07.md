## 三、蓝队视角（合规建设方：如何用好这份清单）

1. **建立"文件—章程—内制"三级映射表**：每部上位文件对应机构章程哪一条、对应内部哪份制度，形成可追溯的合规底稿。缺口一目了然。
2. **优先处理效力层级高的**：④（行政法规）> ①②⑤⑨⑩（部门规章/规范性文件）> ③（试行文件）。章程与内制冲突时按此顺序修正。
3. **⑥⑦配套阅读**：政策文件解决"能不能做"，答记者问解决"为什么这么定、怎么把握尺度"，后者对边界判断价值更高。
4. **本清单标注为"（一）"**，说明系列未完。后续分册发布时应持续跟踪补录。

## 四、红队视角（监督/审查方：清单反向即检查表）

| 反向检查项 | 高频问题 |
|---|---|
| 评比表彰是否报批 | 自设奖项、自办排行榜，未履行审批或备案 |
| 分支机构是否越权 | 分支机构独立开户、独立对外签约、独立收费 |
| 名誉职务是否合规 | 名誉职务实际参与决策，形成事实上的治理干预 |
| 章程是否已按修改后的条例更新 | 沿用旧版章程条款，登记事项与实际不符 |
| 理事会是否形骸化 | 长期不开会、决议由个别人代签、关联交易未回避 |
| 年检是否连续 | 连续未年检可能触发行政处理 |
