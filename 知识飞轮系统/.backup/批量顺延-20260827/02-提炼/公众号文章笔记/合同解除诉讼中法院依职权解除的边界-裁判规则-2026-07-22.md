# 合同解除诉讼中法院依职权解除的边界 — 裁判规则（2026-07-22）

> 来源：IMA 合同文书AI助手（仙幻羽，2026-07-21）。提炼为合同审查与诉讼代理可复用规则。

## 一、原则立场：法院不得依职权主动解除

1. **处分原则（不告不理）**：《民事诉讼法》第13条，诉讼请求的内容与变更由当事人自主决定，审判权应保持谦抑。
2. **解除权是形成权**：合同解除（合法前提下的终止）属形成权，须由权利人主动主张，法院方能审理裁判。当事人未提解除诉请，法院主动判解除 = 代替当事人行使形成权 + 剥夺对方举证/抗辩/辩论权，**构成程序违法**。
3. **无效 ≠ 解除**：
   - 合同无效：国家意志否定评价，法院**应依职权主动审查**无效事由，即便当事人未主张；
   - 合同解除：以合同有效为前提，属意思自治，须当事人主张，公权力不介入。
   - 二者法律后果迥异（无效→缔约过失/信赖利益；解除→履行利益/可得利益），法院在仅主张无效时直接判解除 = 变相变更诉讼策略，严重违反辩论原则。
4. **情势变更也须请求为前提**：《民法典》第533条"当事人可以请求"法院变更或解除，法院不得主动启动。

## 二、例外：可认定解除的两种情形

1. **诉请隐含解除意思**（最高法 利成公司、宝源公司与晶隆公司项目转让合同纠纷案规则）：
   - 不拘泥"解除合同"四字，看实质诉求是否以解除为前提（返还财产/赔偿/违约金在逻辑上只有解除后才成立）；
   - 从严把握两要件：①合同客观上已履行不能、维持效力无实际意义；②诉请与继续履行逻辑矛盾，只能建立在解除基础上。
2. **合同僵局司法终止**（《民法典》第580条第2款）：
   - 非金钱债务履行不能、标的不适于强制履行、履行费用过高等致目的无法实现，法院**根据当事人请求**终止权利义务（不影响违约责任）；
   - 常与"隐含解除意思"交织；须当事人一方表达不再履行意愿或诉请以不再履行为前提。

## 三、正确程序路径：法院释明

- 发现符合解除条件但当事人未提诉请 → **释明**其可变更/增加解除诉请，给予对方答辩举证期；
- 当事人明确增加的，一并审理；坚持不增加的，驳回其诉请并告知另行主张（如四川高院指导意见：相对方请求继续履行，审理认为履行不能的，释明变更；拒绝变更则驳回继续履行诉请）。

## 四、三个常见误区（代理提示）

1. 无效与解除不可相互替代（时效、除斥期间、举证标准、法律后果全不同）；
2. 履行不能≠自动解除，解除权仍归守约方，其可选择解除或主张其他违约责；
3. 《民法典》第580条后"违约方不能解除"不再是绝对规则——合同僵局下违约方**可请求**司法终止，但须：非恶意违约、继续履行显失公平、守约方拒解违反诚信，且必须经司法程序、不免除违约责任、由当事人主动提出。
