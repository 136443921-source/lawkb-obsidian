# 合规季度自查：六个信号 + 三个决定

> **一句话内核**：合规自查的价值不在覆盖面，而在**不中断**。每季度用六个问题过一遍，把小异常拦在变成大返工之前。

---

## 一、内容结构（四节拆解）

| 节次 | 命题 | 核心操作 |
|---|---|---|
| 01 | 每季度一次不是走形式，而是找信号 | 各岗位各带 1–2 个本季度新增/异常事项，用六问快速过一遍 |
| 02 | 检查时只做三个决定 | 是否需处理 / 谁来处理 / 什么时候回看；结论落到四列简表 |
| 03 | 不要把自查变成"找人背锅" | 重点是发现流程与管理缺口，而非立刻给个人定性 |
| 04 | 负责人也要看重复项 | 连续几个季度的同类问题，比单笔异常更值得投入 |

---

## 二、核心工具：季度六信号清单

| 每季度看什么 | 用一句话回答什么 |
|---|---|
| **合同和承诺** | 有没有已经答应客户、但还没完成内部确认的事项 |
| **费用和付款** | 有没有事后补批、收款主体变化或说不清用途的支出 |
| **第三方合作** | 有没有新合作方、关键供应商异常或履约投诉 |
| **人员变化** | 有没有关键员工入职、离职、岗位调整却没做交接 |
| **客户投诉** | 有没有重复投诉、未回复问题或已经影响交付的争议 |
| **异常和例外** | 有没有谁口头同意过特殊安排，却没有留下记录 |

**典型信号样本**（原文示例）：
- 销售：客户要求"先上线再签补充协议"
- 财务：某供应商本月更换收款账户
- 行政：关键员工下周离职，但客户资料仍在个人设备里

---

## 三、蓝队视角（防御方：企业怎么把动作做实）

### 1. 三个决定 + 四列简表
每个问题不开长会，只决定三件事：
1. 这**是不是**需要处理的问题
2. **谁**来处理
3. **什么时候**回看

台账只保留四列——**事项 / 负责人 / 截止时间 / 当前状态**。

> 写得太复杂，没人愿意维护；没有状态，又很难知道问题是否真的处理完。

状态标记建议：`待补材料` → `处理中` → `已完成待复查`

### 2. 处置分层
| 层级 | 典型事项 | 处置方式 |
|---|---|---|
| 轻 | 补一份材料、确认一次授权 | 当场关闭 |
| 中 | 需业务、财务、负责人共同判断 | 指定负责人 + 截止日 |
| 重 | 存在扩大风险敞口 | **先采取临时措施**：暂停付款 / 暂停对外承诺 / 保留相关资料 |

### 3. 心理安全设计（避免自查失真）
- 自查重点是**流程和管理缺口**，不是给个人定性；
- 明显违规或需问责的情形，仍按规则处理；
- 大部分日常事项，**先说清事实、影响与改进动作**比先追责更能防止重复发生。
- 逻辑闭环：员工愿意报告 → 企业才能早看到风险。

### 4. 负责人视角：看"重复项"
- 同一部门总是事后补审批 → **流程跟不上业务**
- 同一供应商反复出问题 → **合作管理没做实**
- 投诉总卡在同一环节 → **责任和授权需要调整**

> **连续两个季度零问题不必庆祝**——随机抽一个业务事项回看材料和流程，确认"没问题"是因为动作正常，还是因为大家没把异常带进自查。

## 四、红队视角（攻击方：这套自查会在哪里失守）

| 攻击点 | 破绽 | 加固动作 |
|---|---|---|
| **形式化走过场** | 各岗位只报"无异常"，自查沦为签字仪式 | 强制每岗位提交 1–2 个具体事项；引入随机抽查 |
| **无延续性** | 上季度未关闭事项无人回看 | 下季度**先看上次事项是否关闭**，再看新信号 |
| **记录散落** | 结论留在聊天记录里，检查时无法举证 | 统一落到四列简表，形成可调阅台账 |
| **追责导向反噬** | 自查变问责会 → 员工选择不报 | 事实/影响/改进三段式，先不定性 |
| **口头例外无痕** | "谁口头同意过特殊安排"是最隐蔽敞口 | 第六项信号专门捕捉；例外一律补书面 |
| **单点思维** | 只看单笔异常，忽略系统性缺陷 | 负责人层面强制做**重复项分析** |

## 五、实务风险卡片

**卡片 1｜"先上线再签补充协议"**
- 风险：已对外承诺但未完成内部确认，形成**无授权义务**，履约标准与责任边界不明。
- 动作：进入六信号第一项"合同和承诺"，临时措施可选暂停对外承诺，限期补签。

**卡片 2｜供应商更换收款账户**
- 风险：付款诈骗高发场景，同时是**利益输送/关联交易**的常见掩护。
- 动作：进入"费用和付款"+"第三方合作"双通道，付款前二次核验，必要时暂停付款。

**卡片 3｜关键员工离职，资料在个人设备**
- 风险：客户资料、商业秘密、个人信息外流；同时可能触发数据合规义务。
- 动作：进入"人员变化"，离职交接清单必须包含设备与数据回收留痕。

**卡片 4｜零问题季度**
- 风险：不是低风险，而是**信息不上浮**的征兆。
- 动作：随机抽查 1 个业务事项回溯材料与流程，验证自查真实性。
