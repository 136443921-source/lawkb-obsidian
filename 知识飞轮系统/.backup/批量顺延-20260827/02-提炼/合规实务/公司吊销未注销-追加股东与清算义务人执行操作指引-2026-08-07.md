# 公司"吊销未注销"：追加股东、清算义务人为被执行人操作指引

> **一句话内核**：债权终本 + 债务人公司吊销未注销 = 债权人突破法人独立地位的**最佳窗口期**。2024 年新《公司法》第 241 条第 2 款一锤定音：**强制注销不免除原股东、清算义务人责任**。

---

## 一、制度定位

"吊销未注销"指公司被吊销营业执照后，**未依法成立清算组清算并办理注销登记**，法人资格形式存续、实质僵尸。这一状态既为股东规避债务提供空间，也为债权人突破法人独立地位提供法律入口。

**四条责任路径**：
1. 清算义务人**怠于清算**的连带责任
2. 股东**出资补充**责任
3. **[[公司人格否认|公司人格否认]]**
4. **强制注销后责任保留**

---

## 二、法律渊源体系

| 法律渊源 | 核心条款 | 规范内容 |
|---|---|---|
| 《公司法》（2024） | 第 23、54、88、232、238、240、241 条 | 人格否认、出资加速到期、股权转让责任、清算义务、强制注销与责任保留 |
| 《公司法解释（二）》 | 第 18 条 | 股东怠于清算义务的连带责任 |
| 《公司法解释（三）》 | 第 13 条、第 18–20 条 | 股东出资补充责任、股权转让责任 |
| 《九民纪要》 | 第 10–14 条 | 人格混同认定、过度支配与控制、资本显著不足、小股东免责 |
| 《民事执行中变更、追加当事人规定》 | 第 17–21 条 | 追加股东/清算义务人为被执行人的执行程序 |

### 关键条文速记
- **第 23 条**：股东滥用法人独立地位和有限责任逃避债务，严重损害债权人利益 → **连带责任**；一人公司股东不能证明财产独立 → **连带责任**；横向人格否认（利用两个以上公司）亦纳入。
- **第 54 条**：公司**不能清偿到期债务**的，公司或已到期债权的债权人有权要求**未届出资期限**股东提前缴纳出资（出资加速到期）。
- **第 88 条**：转让未届期股权 → 受让人缴纳，**转让人补充责任**；出资不足/非货币显著低值即转让 → 转让人与受让人在出资不足范围内**连带**（受让人善意的由转让人承担）。
- **第 232 条**：**董事为清算义务人**，解散事由出现之日起 **15 日内**组成清算组。
- **第 241 条（新增）**：吊销/责令关闭/被撤销 + **满 3 年**未申请注销 → 登记机关可公示公告（**≥60 日**）后依职权注销；**注销后原股东、清算义务人责任不受影响**。

## 三、蓝队视角（债权人：如何攻下这一城）

### 1. 五阶段代理策略

| 阶段 | 操作要点 | 常见错误 |
|---|---|---|
| ① 调查摸底 | 查工商信息、股权结构、出资情况、吊销时间、是否清算 | 忽视股权变动记录，**遗漏原股东** |
| ② 选择责任路径 | 确定主攻方向：清算义务 / 出资补充 / 人格否认 | 眉毛胡子一把抓，未分主次 |
| ③ 收集证据 | 终本裁定、工商信息、验资报告、银行流水、关联关系线索 | 仅凭工商信息起诉，缺乏深入调查 |
| ④ 诉讼/执行异议 | 按责任路径选择另行起诉或执行程序 | 未区分诉讼与执行程序适用条件 |
| ⑤ 应对抗辩 | 逐一反驳"已出资""小股东"抗辩 | 缺乏反证思路 |

### 2. 责任路径决策树

```
步骤1  公司是否已被强制注销？
        ├─ 是 → 第241条第2款，责任不免除，可追加
        └─ 否 → 步骤2

步骤2  公司是否已清算？
        ├─ 未清算 → 清算连带责任路径（解释二第18条）
        └─ 已清算 → 步骤3

步骤3  股东是否已履行出资义务？
        ├─ 未履行 → 出资补充责任路径（解释三第13条、公司法第54条）
        └─ 已履行 → 步骤4

步骤4  是否存在人格混同、过度支配等情形？
        ├─ 是 → 公司人格否认路径（第23条、九民纪要第10-12条）
        └─ 否 → 仅追究清算义务人或出资不足者责任
```

### 3. 前期调查清单（七项）
- [ ] 查全国企业信用信息公示系统，确认公司状态（吊销/责令关闭/被撤销/注销）
- [ ] 查工商档案：股东名单、出资比例、法定代表人、董监事会成员
- [ ] 查**股权变动记录**，确认是否存在股权转让、减资
- [ ] 查验资报告，初判出资情况
- [ ] 核查是否被列为失信被执行人、是否有**终本裁定**
- [ ] 查关联企业信息，排查人格混同、过度支配线索
- [ ] 确认债权是否过诉讼时效，有无中断、延长情形

### 4. 证据目录模板

| 序号 | 证据名称 | 证明目的 | 来源 |
|---|---|---|---|
| 1 | 生效法律文书 | 对公司享有合法债权 | 法院档案室 |
| 2 | **终本执行裁定书** | 公司无财产可供执行 | 执行法院 |
| 3 | 工商信息打印件 | 公司被吊销且未注销 | 国家企业信用信息公示系统 |
| 4 | 工商档案查询件 | 股东名单、出资比例、董监事成员 | 工商行政管理局 |
| 5 | 股权变动记录 | 股权转让、减资等情形 | 工商行政管理局 |
| 6 | 验资报告 | 股东出资情况 | 工商档案室 |
| 7 | 银行流水 | 出资流向、财产混同 | 银行 / 申请法院调取 |
| 8 | 关联关系查询件 | 人格混同、过度控制 | 企查查 / 天眼查 |

## 四、红队视角（被告股东抗辩 × 债权人反制）

| 股东常见抗辩 | 债权人应对策略 |
|---|---|
| 我已履行出资义务，不存在出资不足 | 调取工商档案、查询出资流水，申请法院调查**验资报告真实性** |
| 我是小股东，不参与经营，不应担责 | 证明其**实际参与经营**或担任董监事会成员；或证明其知情但未采取清算措施 |
| 公司仍可清算，没有财产灭失 | 要求其提供账册、重要文件以证明可清算；**无法提供则推定无法清算** |
| 债务产生时我已转让股权，非股东 | 比对股权转让时间与债务产生时间；依第 88 条追究转让人补充责任 |
| 股权已转让，不应再承担清算责任 | 第 88 条：转让人对未履行出资的受让人承担补充责任 |

### 庭审攻防五要点
1. **明确请求权基础**：区分"清算连带责任"与"出资补充责任"，分别列明金额及计算依据
2. **举证责任分配是核心**：强调"财产灭失""无法清算"的举证责任在**股东（尤其控股股东）**
3. **反驳小股东免责**：说明其未参与经营、非董监事会成员、未选派人员，且账册由控股股东掌握
4. **反驳出资抗辩**：调取验资报告，必要时申请法院调查；查银行流水证明出资流向
5. **人格混同认定**：审查财产是否混同——账目、资金往来、利益输送

## 五、标杆案例：孙某某诉段某甲、段某乙案

- **入库编号**：2024-08-2-103-010（最高人民法院案例库）
- **审理法院**：山东省淄博市中级人民法院
- **案号**：（2021）鲁 03 民终 1919 号｜裁判日期：2021-08-26
- **案由**：民间借贷 / 股东损害公司债权人利益责任纠纷

**裁判要旨**：公司被吊销后一直未依法清算，债权人以主要财产、账册、重要文件灭失无法清算为由请求股东承担连带责任的，除审查是否灭失外，还应审查：①灭失是否**必然导致**无法清算；②灭失是否**由股东怠于履行义务**导致；③**小股东是否具有免责事由**。

**三步审查法（裁判理由拆解）**：
1. **财产/账册是否灭失** → 举证责任在**控股股东**。控股股东未提交财产状况证据、账册与重要文件 → 承担举证不能后果。
2. **是否无法清算** → 债权人提供**终本裁定书**完成初步举证，转由股东反证"公司能够清算"。股东自称"账目不确定是否齐全"、无证据 → 认定无法清算，构成怠于履行清算义务，**对本金及利息承担连带清偿责任**。
3. **各股东责任区分** → 出资比例较小、非董监事会成员、未选派人员、不掌握账册、不管理财产、对经营不起决定性作用 → 依《九民纪要》第 14 条**免责**。

> **提炼**：终本裁定 = 债权人初步举证工具；控股股东 = 举证责任承担主体；小股东免责三要件 = 非董监事 + 未选派人员 + 未参与经营管理。

## 六、实务风险卡片

**卡片 1｜清算义务人主体：董事还是股东？（过渡期陷阱）**
- 冲突：新《公司法》第 232 条明确**董事为清算义务人**；但《公司法解释（二）》第 18 条**未修改**，仍规定"有限责任公司的股东、股份有限公司的董事和控股股东"。
- 结论：新法施行后过渡期存在规范竞合。
- 动作：**同时将股东和董事列为被告**，由审判机关根据具体情形认定，避免"被告主体不当"被驳。

**卡片 2｜责任路径混淆（最常见实体错误）**
| 维度 | 清算连带责任 | 出资补充责任 |
|---|---|---|
| 构成要件 | 怠于履行清算义务**导致无法清算** | 未履行/未全面履行出资义务 |
| 责任范围 | 公司**全部债务**（本金+利息+迟延履行金） | 仅限**未出资本息范围** |
| 责任性质 | 连带 | **补充**（仅对公司不能清偿部分） |
- 动作：请求金额不得超出股东未出资范围，超出部分不予支持。

**卡片 3｜程序风险三雷**
- **执行异议被驳**：直接在执行程序追加须同时满足三条件——①公司已被吊销或注销；②股东存在未清算或未出资等法定事由；③有明确法律依据。
- **管辖错误**：股东损害公司债权人利益责任纠纷应向**被告住所地**法院起诉；债权未经生效判决确认即直接起诉股东，可能以"应先经审判确认债权"被裁驳。
- **诉讼时效**：依《公司法解释（三）》第 19 条，公司债权人的债权未过诉讼时效的，股东以出资义务超时效抗辩**不予支持**——但前提是主债权本身未过时效。

**卡片 4｜证据风险**
- 人格混同证据多在公司内部，外部难取。破解手段：申请法院调取工商档案、税务档案、银行流水；申请**司法审计**；向税务机关举报。
- 企查查等平台数据**更新滞后**，应以**工商档案原件**为准；验资报告可能虚假，应申请法院调查或司法审计。

**卡片 5｜强制注销后仍可追加**
- 依据：第 241 条第 2 款 + 《民事执行中变更、追加当事人规定》第 21 条（未经清算即被注销，导致无法清算的，清算义务人承担连带清偿责任）+ 第 17 条（被吊销但主体资格存续的不影响执行）。
- 结论：登记机关依职权强制注销，**不构成责任豁免事由**。

## 七、文书要点速查

**民事起诉状**
- 被告：股东（姓名、住所、股权比例、出资情况）+ 董事（新法下清算义务人）；第三人：债务人公司
- 诉请二选一：
  - 清算责任路径 → "判令被告 XX 对原告债务 XX 元承担**连带清偿责任**"
  - 出资补充路径 → "判令被告 XX 在**未出资本息 XX 元范围内**对原告债务承担**补充赔偿责任**"
- 事实与理由五段式：债权形成（含生效判决案号金额）→ 公司被吊销未清算 → 股东怠于清算/未出资 → 公司无法清算/不能清偿 → 法律依据（列明具体条款）

**[[执行异议申请书-王德明担保合同纠纷案|执行异议申请书]]**
- 申请请求：追加被申请人为（202X）XX 法执 XX 号案件的被执行人
- 申请理由五点：债权已生效确认 → 已终本无财产 → 公司吊销未依法清算 → 被申请人存在法定责任事由 → 引《民事执行中变更、追加当事人规定》具体条款
