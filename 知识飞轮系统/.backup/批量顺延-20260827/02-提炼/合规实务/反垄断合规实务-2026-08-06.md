# 反垄断合规实务（蓝红双视角）

> 来源：公开权威源降级摄入（《反垄断法》+ 市场监管总局《经营者集中反垄断合规指引》国市监反执二发〔2023〕74号 + 平台经济/公用事业指南）。原定 IMA「合规与政府监管AI助手」库摄入，因 IMA 运行态掉线改用公开源。

## 一、蓝队视角（企业方·红线清单）

1. **四类垄断行为**（《反垄断法》）：垄断协议、滥用市场支配地位、违法经营者集中、滥用行政权力排除限制竞争。

2. **纵向垄断协议红线**（第18条）
   - 固定向第三人转售商品的价格；限定向第三人转售商品的最低价格。
   - 公用事业指南细化：以利润/折扣/返利间接固定或限定转售价亦构成。

3. **滥用市场支配地位六项**（第22条 + 禁止滥用规定）
   - 不公平高价/低价；低于成本销售；拒绝交易；限定交易；搭售/附加不合理条件；条件相同者差别待遇。

4. **经营者集中申报**
   - 达申报标准须事先向市场监管总局申报，未申报或批准后实施前不得实施集中。
   - 法律责任：具排除限制竞争效果处上一年度销售额 10% 以下；不具效果处 500 万元以下；情节严重二至五倍。
   - 宽大制度：横向垄断协议主动报告并提供重要证据可减轻或免除处罚。

## 二、红队视角（抗辩/监管·攻防面）

- **纵向协议豁免**：能证明"不具有排除、限制竞争效果"的，不予禁止（公用事业指南第11条）——举证方向。
- **控制权认定扩张**：收购少数股权（如20%）若可单独否决年度计划、预算、高管任免，仍可能取得（共同）控制权，构成集中，须申报（指引案例）。
- **"抢跑"风险**：申报后、批准前完成主体登记/委派高管/实质整合，构成违法实施集中。
- **平台特殊形态**：轴辐协议（借纵向关系协调达成横向效果）、协同行为（间接证据链认定）依平台经济指南处理。

## 三、可复用申报判断流程

```
是否构成集中(合并/取得控制权/决定性影响)?
  → 是否达申报标准(营业额含关联集团合计)?
  → 是:签署协议后、实施前申报,获批前不得"抢跑"
  → 否但有排除限制效果证据:可能被要求申报
```
