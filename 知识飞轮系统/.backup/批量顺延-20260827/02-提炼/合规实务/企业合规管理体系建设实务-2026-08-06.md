# [[企业合规管理体系建设实务（蓝红双视角）|企业合规管理体系建设实务（蓝红双视角）]]

> 来源：公开权威源降级摄入（GB/T 35770-2022 解读 + 央企合规管理办法 + 新《公司法》第177条）。原定 IMA「合规与政府监管AI助手」库摄入，因 IMA 运行态掉线改用公开源。本文是企业合规体系建设的操作母本。

## 一、蓝队视角（建设方·落地路径）

1. **标准定位**
   - GB/T 35770-2022 等同采用 ISO 37301:2021，2022-10-12 实施，由"指南"转为"要求类、可认证"标准。
   - 新《公司法》第177条：国家出资公司应建立健全内部监督管理和风险控制制度、加强内部合规管理——首次以法律形式提出。

2. **PDCA 框架要件**
   - **组织环境**：内外部因素、相关方需求、识别合规义务（强制+自愿）、评估合规风险，确定体系范围。
   - **领导作用**：治理机构与最高管理者承诺、合规文化、合规方针、职责权限分配；合规团队须具独立性、能直接接触治理机构。
   - **策划**：合规目标（可测量）+ 风险应对措施。
   - **支持**：资源、聘用前尽职调查、培训、沟通、文件化信息（合规义务册/风险册）。
   - **运行**：合规审查嵌入业务流程（尤其合同订立）、第三方/外包尽职调查、举报程序、调查程序。
   - **绩效评价**：监视测量、内部审核、管理评审。
   - **改进**：纠正措施 + 体系变更。

3. **关键交付物**：合规义务清单、合规风险册、合规政策与行为准则、举报与调查机制、年度合规计划。

4. **央企特别要求**：《中央企业合规管理办法》2022-10-01 实施，各省市国资委配套出台办法。

## 二、红队视角（审查/监管·挑刺面）

- **形式合规陷阱**：仅发文不落地、合规团队无独立性（不能直达治理机构）、举报无反馈闭环——监管与认证均不认可。
- **体系审查机制**：内部审查（牵头部门自审）+ 外部审查（专业机构独立判断科学性/完备性/有效性），结果须"反哺"体系。
- **有效性评价**：审查内容含组织健全性、制度完备性、运行机制有效性、合规文化、信息化；关注"预防—发现—响应"三能力。

## 三、可复用建设清单

```
立项 → 环境分析+义务识别+风险评估 → 方针与治理架构
     → 制度与流程(嵌入业务) → 培训与文化建设
     → 举报/调查机制 → 内审+管理评审 → 改进闭环
```
