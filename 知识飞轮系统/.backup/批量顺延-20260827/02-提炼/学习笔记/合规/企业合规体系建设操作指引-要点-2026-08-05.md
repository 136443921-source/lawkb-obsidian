# 企业合规体系建设操作指引（2026 试行）要点

> 来源：IMA「合规与政府监管AI助手」《律师办理企业合规体系建设业务操作指引（2026）（试行）》（法务人俱乐部/各地律师协会口径）。
> 定位：律师受托搭建企业合规体系的业务操作标准，亦适用于[[慈善组织合规|慈善组织合规]]体系参照。

## 一、体系四要素（目录结构）

| 要素 | 内容 |
|------|------|
| 合规组织与职责 | 合规管理委员会/首席合规官、三道防线（业务—合规—审计） |
| 合规制度建设 | 行为准则、专项制度（反舞弊、数据、反垄断、出口等） |
| 合规运行机制 | 风险识别、尽职调查、培训、举报与调查、持续改进 |
| 合规文化建设 | 高层承诺、宣贯、考核与问责 |

## 二、不同类型企业合规要点

- **国有企业**：穿透式监管、党委（党组）前置研究、合规与内控法务一体化。
- **中小民营企业**：侧重交易合规（合同、劳动、税务）、避免"一套制度空转"。
- **社会组织（慈善组织）**：依《慈善法》及内部合规手册，覆盖募捐、关联交易、信息公开（参见[[贵州省厚德公益基金会合规管理手册（试行）（2025版）]]）。

## 三、律师办理方法论

1. 进场诊断：合规风险尽调 + 现状差距分析。
2. 体系设计：依行业监管密度分级配置制度。
3. 落地辅导：培训 + 演练 + 举报渠道搭建。
4. 持续运维：年度评审、监管动态跟踪。
