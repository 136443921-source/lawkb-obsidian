# 合作保密协议-范本与审查要点（蓝红双视角）

> 原文：《合同范本 | 合作保密协议模板（2026详细版）》（扬律讼典，2026-07-29）
> 关联：[[公司员工保密协议-范本与审查要点-2026-08-10]]、[[债权转让协议-范本与审查要点-2026-08-14]]

## 协议骨架（7条）
保密信息定义（含排除4类）→ 保密义务（15工作日销毁/归还）→ 允许的披露和使用 → 保密期限（合作结束之日起1年）→ 违约责任 → 适用法律及争议解决（原告住所地法院）→ 附则

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 单方保密失衡 | 仅披露方→接收方单向保密，接收方信息不受保护 | 若双方互相披露，改为双向保密（互相保密协议） |
| 保密信息定义过宽 | 1.1"全部非公开的、专有的、具有商业价值的"定义宽泛 | 尽量列举+兜底，避免口头披露未书面确认的信息也被覆盖；建立书面确认机制 |
| 保密期限过短 | 4.1保密期限至合作结束之日起1年届满 | 商业秘密类应延长至"合作结束后3-5年"或"信息公开为止"；技术秘密可比照竞业限制逻辑 |
| 管辖倾斜 | 6.2原告住所地法院——对接收方不利 | 接收方争取"被告住所地/协议履行地"，或至少"披露方住所地"改为"接收方住所地" |
| 人员约束不足 | 2.4要求接收方告知参与人员，但离职员工约束存疑 | 增加"接收方人员离职后保密义务继续有效"及接收方对人员违约的兜底责任 |
| 无违约金条款 | 5.1仅约定赔偿损失，举证难 | 增加违约金条款（如每次泄密固定金额）+赔偿范围明确含商业秘密价值损失 |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **信息非秘密抗辩**：援引1.4排除条款——公知信息/签署前已合法取得/第三方合法取得/独立得出，逐项核实信息来源
2. **用途抗辩**：保密信息用于"本次合作"目的内不违约，重点审查是否落入合作目的范围
3. **程序抗辩**：披露方未书面标记保密信息、未走2.5归还销毁流程的，可弱化违约认定
4. **免责披露**：3.1允许的披露（法律法规/法院监管/司法仲裁程序）是法定豁免，收集证据后可直接披露
5. **违约损失难证**：若约定无违约金，守约方须举证实际损失与因果关系，泄密类案件证明难度大，谈判空间在此

## 裁判规则
- R-HT-057：保密协议约定保密期限至合作结束之日起一年的，保密义务期满后接收方不再承担保密义务；商业秘密保护期应以信息是否公开为准
- R-HT-058：保密协议约定"原告住所地法院"管辖的，该约定有效但可能对接收方不利；格式条款排除对方主要权利的可能被认定无效

## 实务清单
- 签署前：明确保密范围（书面清单+口头确认机制）、保密期限、违约金
- 接收方：避免单方保密条款、争取对等、管辖争取被告住所地
- 履行中：人员入职/离职保密培训留痕、涉密文件分级管理、披露留痕
