# 合同审查实务方法论（体系化审查框架）

> 来源：IMA「合同文书AI助手」实务方法论文章（小枣实务笔记）。
> 核心命题：合同审查 ≠ 文字校对，核心是预判风险、分配风险、锁定救济路径。

## 一、审查前置三步（改条款前必做）

1. **厘清交易背景与当事人核心诉求** — 主动沟通交易模式、谈判底线、合作目的、过往磋商文件；脱离商业场景的法律修改无实际价值，多数风险冲突根源在于不了解双方真实需求。
2. **核查签约主体基础资质** — 区分企业法人、分公司、个体工商户、自然人；核验经营范围、资质许可、章程授权与内部决议（对外担保/重大交易）。
3. **锁定商业目标与谈判地位** — 明确我方底线（价格、交付、解除权），审查改动的每一处都对准商业诉求而非"看起来更严谨"。

## 二、四维审查框架

| 维度 | 审查焦点 |
|------|---------|
| 效力维度 | 主体资格、标的合法、形式要件（书面/审批/备案） |
| 风险维度 | 付款/交付/质量/违约/不可抗力条款的风险分配 |
| 救济维度 | 解除权、违约金、管辖、保全与举证便利 |
| 履行维度 | 通知方式、验收节点、变更与终止的程序闭环 |

## 三、蓝队应用要点

- 风险分配须与谈判地位匹配：弱势方争取**先票后款、分批验收、质保金**；强势方可收紧**单方解除、违约金上限**。
- 救济路径要"可落地"：管辖约定我方所在地、违约金兼具补偿与威慑、保留**合同解除后返还/赔偿**的明确计算。

## 四、红队提醒

- 过度修改可能破坏交易：把"商业灵活"写成"法律死锁"，反而增加履约争议。
- 模板套用陷阱：通用模板的"不可抗力""保密"条款常不适配具体行业，需结合业务重填。
