# [[房屋代持协议-范本与审查要点|房屋代持协议-范本与审查要点]]（蓝红双视角）

> 原文：《[[合同库-房屋代持协议|房屋代持协议（参考及注意事项）]]》（知法用法小分享，2026-08-01）
> 关联：[[债权转让协议-范本与审查要点-2026-08-14]]、[[婚内财产协议-范本与审查要点-2026-08-05]]

## 协议骨架（九部分+注意事项）
基本情况 → 代持关系及目的 → 代持条款（权利义务）→ 处置与过户 → 费用承担 → 违约责任 → 解除终止 → 争议解决（房屋所在地法院）→ 其他

## 法律定性（关键）
- 借名买房合同：对内（实际出资人与名义登记人）有效，对外（第三人）不必然对抗
- 物权以登记为准（《民法典》209条），代持人处分房屋给善意第三人，实际出资人难以对抗
- 政策性住房（经适房/限价房）代持可能因违反政策被认定无效
- 救济路径：执行异议之诉（《民诉法》234条）、确权之诉、合同之诉

## 🔵 蓝队（防御审查）：条款风险点与修改建议
| 风险点 | 审查要点 | 修改建议 |
|--------|---------|---------|
| 代持效力风险 | 规避限购/贷款便利/财产隔离的代持目的 | 明确告知政策风险；经适房等政策性住房不建议代持 |
| 出资证据链 | 仅约定"甲方承担全部费用"无凭证支撑 | 附件必须含：转账凭证、购房合同、还款流水、费用清单（附件1/2/3） |
| 名义登记人违约 | 擅自处分房屋仅约定违约金 | 增设"代持人将房屋抵押给出资人"担保条款（办理抵押登记），提高违约成本 |
| 名义登记人债务风险 | 乙方债权人可能申请执行房屋 | 提示甲方关注乙方信用状况；可约定乙方重大负债告知义务 |
| 继承/行为能力丧失 | 乙方死亡或丧失行为能力 | 明确继承人继续履行代持义务的条款+遗嘱/监护安排建议 |
| 争议解决 | 房屋所在地法院（对甲方有利）| 保留此管辖，同时明确过户税费承担主体 |

## 🔴 红队（攻击分析）：漏洞与可抗辩空间
1. **登记对抗攻击**：物权登记在乙方名下，乙方债权人执行房屋时，甲方仅能提执行异议之诉，须证明真实出资+未损害债权人利益
2. **政策无效抗辩**：若代持目的是规避限购政策购买经适房，可主张协议违反政策法规无效，乙方有权不配合过户
3. **善意取得风险**：乙方擅自出售给善意第三人并已过户的，第三人善意取得，甲方无法追回房屋只能索赔
4. **证据缺失抗辩**：甲方仅有协议无资金流水，主张实际出资难以证明
5. **公证缺失**：未公证的代持协议对抗力弱，甲方举证难度增大

## 裁判规则
- [[R-HT-059|R-HT-059]]：借名买房合同对实际出资人与名义登记人内部有效，但不得对抗善意第三人；物权登记于名义登记人名下的，其债权人申请执行时，实际出资人可通过执行异议之诉主张权利，但须证明真实出资关系
- [[R-HT-060|R-HT-060]]：为规避限购政策或购买政策性住房的借名买房合同，可能因违反政策规定被认定无效，实际出资人无权要求名义登记人继续履行过户义务

## 实务清单
- 出资人（甲方）：资金流水全覆盖+公证+代持人抵押担保+定期查阅产权状态
- 名义登记人（乙方）：明确无出资不担责边界、代持费用、风险提示书
- 争议发生：先证据保全（购房合同+流水+协议+公证）再选诉讼路径（确权/执行异议）
