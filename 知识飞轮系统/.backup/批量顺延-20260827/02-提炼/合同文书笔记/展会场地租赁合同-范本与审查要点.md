# 展会场地租赁合同（参考）— 范本与审查要点

> 模板来源：微信公众号「席雅若」（山东），发布时间 2026-07-27 18:00，收于 IMA 合同文书AI助手库。性质为**参考模板**，不可直接套用。

## 一、合同定位与交易结构

展会场地租赁合同是出租人将会展中心展厅/展位在布展—开展—撤展全周期交付承租人举办展会使用的租赁协议。区别于一般租赁：租赁周期短且含全流程、场地规范严格（消防/现场管理）、临时配套服务多、风险集中于活动特殊性。

## 二、核心条款结构（模板已含）

场地基本信息 → 租赁期限（布展/开展/撤展三段式 + 超时双倍租金）→ 费用及支付（一次性/分期，0.5%/日逾期违约金，超 3 日可解约没收定金）→ 场地押金（7 工作日无息退还，损坏直接扣减）→ 双方权责（出租方保证权属/基础配套/安保；承租方安全规范/不占消防通道/人员财产自担）→ 不可抗力与场地变更（政府征用可换场或退费不赔额外）→ 违约责任（擅自转租/变更用途没收押金+租金+20%违约金）→ 争议解决（场地所在地法院）。

## 三、蓝队审查要点（风险敞口）

1. **权属与用途风险**：出租方须保证场地合法出租权、无抵押查封；承租方不得擅自变更用途、转租转借——该约定有效，但对外仍受表见代理约束。
2. **周期与超时费**：三段式期限 + 提前 3 工作日书面申请延期 + 双倍超时租金，须明确"超时"起算点，避免开展期间临时搭建争议。
3. **押金扣减条款**：出租方单方从押金扣减损坏/欠费/清理费，须约定"事先告知 + 举证 + 异议期"，否则易被认定加重对方责任的格式条款。
4. **安全责任分配**：模板将展位区域内人员伤亡、展品损毁风险全归承租方。实务中若出租方提供的公共设施（电梯/照明/消防）缺陷致损，出租方仍可能依《民法典》第 1198 条（安全保障义务）担责，不可完全切割。
5. **不可抗力范围**：模板列举地震/台风/疫情/政策调整，建议补"政府临时管制/大型活动管控"并明确"已付费用无息退还"的计算口径。

## 四、实务建议

- 展会合同高频争议点在**安全责任、超时费、押金扣减、撤展恢复标准**，审查时把这几条做死。
- 给承租方话术："场地方说'区域内一切风险你扛'，但公共区域的安全保障义务他甩不掉；押金他想扣就扣也不行，必须留举证和异议空间。"
