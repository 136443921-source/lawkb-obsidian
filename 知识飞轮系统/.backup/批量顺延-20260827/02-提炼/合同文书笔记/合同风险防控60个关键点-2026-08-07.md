# 合同风险防控的60个关键点（体系化审查要点）

> 来源：IMA「合同文书AI助手」公众号范本（作者：云南省替代种植发展行业协会，2026-08-04）。
> 定位：企业合同全生命周期风控清单，覆盖**合同订立、合同履行、企业治理、企业用工、知产保护、涉外贸易**六大模块，衔接《民法典》合同编通则 + 公司法 + 劳动合同法 + 商标/著作权法 + 对外贸易规则。
> 价值：不是单篇模板，而是"签约—履约—治理—用工—知产—涉外"的**风险点穷举**，适合作为合同审查 checklist 的母表。

## 一、内容结构（六模块拆解）

| 模块 | 要点序号 | 核心主题 |
|------|---------|---------|
| 一、合同订立 | 1–12 | 书面化、留痕、公章、授权、定金、保证、抵押、质押、撤销权时效 |
| 二、合同履行 | 13–21 | 主体变更不影响合同、解约慎重、付款可靠、验收异议、商业秘密、不安抗辩、解除异议、止损、诉讼时效 |
| 三、企业治理 | 22–31 | 出资不实连带、隐名股东、股权收购登记、章程、勤勉义务、清算 |
| 四、企业用工 | 32–46 | 规章制度公示、先订合同后用工、服务期、竞业限制、调岗调薪、解雇法定理由 |
| 五、知产保护 | 47–56 | 研发检索、商标及时注册、贴牌审查、著作权登记、建立知产档案 |
| 六、涉外贸易 | 57–60 | 国家风险、贸易术语、法律适用、结算方式 |

## 二、蓝队视角（企业/债权人自身风控要点）

1. **书面化与留痕闭环**（第1–2、15 点）— 无合同不交易；发票、送货凭证、汇款凭证、验收记录、磋商邮件信函均须归档；履约变更须留书面凭证。这是维权证据链的地基。
2. **公章与授权管控**（第3–5 点）— 多页合同加盖骑缝章并紧邻末行签字盖章防换页；介绍信/授权委托书须明确列举授权范围，业务完成后及时收回。
3. **担保条款的"三明确"**（第8–11 点）— 保证须表述"由保证人为债务履行提供保证"的明确意思，避免"负责协调"等模糊表述；须写明保证方式与期间；抵押须登记设立，质押须转移占有。含糊表述将导致担保不成立或劣后。
4. **定金须明"定金"字样**（第7 点）— 仅写"订金/保证金"且未明确双倍返还内容的，法院不作为定金处理（《民法典》第 586、587 条）。
5. **撤销权时效刚性**（第6 点）— 欺诈、胁迫、重大误解、显失公平，须自知道或应知撤销事由起 **1 年内**（重大误解 **90 日**内）行使，否则撤销权消灭（《民法典》第 152 条）。
6. **不安抗辩权正确行使**（第18 点）— 对方经营恶化、转移财产、丧失商誉时，须先**通知中止**并等待合理担保，不得直接解除（《民法典》第 527、528 条）。
7. **诉讼时效管理**（第21 点）— 普通诉讼时效 3 年；可在届满前以信件/数据电文等可证明方式主张权利以中断。

## 三、红队视角（相对方可能利用的漏洞 / 攻防要点）

- **换页与内容篡改**— 多页合同未盖骑缝章、签字未紧邻末行，对方可能换页添加不利条款；签约时强制骑缝章 + 末行签署。
- **模糊保证表述击穿担保**— "负责解决/协调"不构成保证意思，债权人据此主张保证将不被支持；应要求措辞明确为"提供连带责任保证/一般保证"。
- **抵押未登记 = 担保落空**— 仅有抵押合同未登记，抵押权未设立，债权人对该财产无优先受偿权，且可能劣后于先登记者。
- **撤销权过期抗辩**— 对方以"受欺诈/重大误解"抗辩时，核对其知道撤销事由的时间节点，超 90 日/1 年则撤销权消灭。
- **不安抗辩滥用反制**— 若我方被错误主张不安抗辩，可立即提供适当担保以恢复履行，并追究对方擅自中止的违约责任。
- **诉讼时效届满抗辩**— 对方债权超 3 年且未中断的，可主张时效抗辩（法院不主动适用，须由保证人/债务人提出）。

## 四、实务风险卡片

- **最高频雷区**：担保条款模糊（第8–11）、定金字样缺失（第7）、抵押未登记（第11）— 三者直接导致"有担保等于没担保"。
- **证据雷区**：履约变更无书面凭证（第2）、验收异议逾期（第16）、解除异议逾期（第19）— 形式主义瑕疵吞噬实体权利。
- **用工雷区**：规章制度未民主公示（第33）→ 不能作为用工管理依据且面临支付经济补偿；先用工后签约超 1 个月 → 双倍工资风险（第34）。
- **知产雷区**：研发未检索（第47）、商标未及时注册（第51）、贴牌未审查知识产权合法性（第53）→ 投入打水漂或被诉侵权。
- **公益衔接**：本文虽为企业通用风控，但基金会等非营利法人对外担保仍受《民法典》第 683 条限制（机关/公益事业单位/社会团体不得为保证人），集团化办学或设立企业时须单列审查。
