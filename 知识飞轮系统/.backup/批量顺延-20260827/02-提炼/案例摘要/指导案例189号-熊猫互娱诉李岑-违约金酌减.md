# 案例摘要｜指导案例189号 熊猫互娱诉李岑、播爱游公司合同纠纷

**一句话**：网络主播违约跳槽，约定违约金明显过高且实际损失难确定时，法院可参考主播从平台获取的实际收益，结合平台前期投入、流量、主播个体商业价值合理酌定，而非机械以约定金额或"损失30%"为标准。

## 攻防要点

- **蓝队（平台/守约方）**：协议有效、排他性合作条款明确；主播未经同意至竞品平台直播构成根本违约；损失虽难量化，但平台带宽与主播前期投入巨大，应获合理赔偿。
- **红队（主播/违约方）**：5000万违约金显属过高；实际损失难以确定时，应适用《民法典》第585条第2款酌减；且熊猫公司存在履行瑕疵（欠付合作费），可主张先履行抗辩与责任相抵。

## 裁判逻辑链

1. 三方协议系合同关系非劳动关系 → 有效；
2. 微博"官宣"、直接至他平台直播 ≠ 有效解除通知 → 违约成立；
3. 违约金酌减以实际损失为基础，兼顾履行、过错、预期利益、公平诚信；
4. 网络直播行业损失难量化，苛重举证责任有违公平 → 以主播实际收益为基，结合平台投入/流量/个体价值酌定 → 300万调减为260万。

## 关联

- 规则：[[R-HT-027]]（违约金酌减·实际损失难以确定时的行业参照标准）
- 同域：R-HT-025（代持仅债权效力）、R-HT-026（代持不能排除强制执行）
- 合同审查提示：约定违约金宜设置梯度/计算式，避免"天价固定额"被整体酌减；主播类合同应预设损失计算口径。
