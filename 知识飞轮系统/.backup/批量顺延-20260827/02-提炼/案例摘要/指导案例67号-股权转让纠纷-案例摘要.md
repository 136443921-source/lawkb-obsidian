# 指导案例67号 股权转让纠纷 — 案例摘要

## 基本案情
汤长龙与周士海约定周士海将其持有的某公司6.35%股权（710万元）分四期转让给汤长龙，协议载明"永不反悔"。汤长龙付首期150万元后逾期付第二期，周士海公证解除协议并退回全部款项；汤龙次日补齐并继续履约，诉请确认解除无效、继续履行。股权已过户。

## 争议焦点
股权转让分期付款中，受让人逾期支付一期款项，转让人能否适用《合同法》第167条（现《民法典》第634条）分期付款买卖解除权解除合同？

## 裁判要旨
有限责任公司股权分期付款转让不适用《合同法》第167条分期付款买卖解除权。股权分期转让与消费分期买卖本质不同（非生活消费、出让人风险不同、无标的物使用费），不宜简单套用；受让人仅轻微逾期且合同目的可实现的，转让人不享有解除权。

## 可迁移规则
- 起草/审查股权分期转让协议时，不宜直接照搬"未付到期价款达1/5即可解除"的买卖条款；解除权应另作明确约定（如根本违约+催告）。
- 交易安全与诚实信用优先：股权已过户、受让人实际参与的，动辄解除将不利公司经营稳定。

## 对小强律师实务的启示
- **合同审查**：股权收购协议的解除条款应单独设计，避免误引买卖解除规则；可约定"逾期超X日+催告后Y日仍不履行"方得解除。
- **公司业务**：结合指导案例10号（公司决议撤销司法审查边界，R-SH-001），形成"股权转让 + 公司治理"商事服务包；厚德基金会对外投资/股权架构调整时参照适用。
