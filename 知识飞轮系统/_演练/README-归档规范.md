# _演练/ 演练卡隔离归档目录

## 用途
物理隔离 `is_simulation: true` 的**演练卡**，与真实经验池（`02-提炼/经验卡片/`、`06-沉淀/`、各连接枢纽）分离，避免演练内容被误当作真实判例/经验引用。

## 铁律
1. **演练卡绝不进入真实经验池**：不得出现在 `02-提炼/经验卡片/`、`06-沉淀/` 等真实知识路径；仅存放于此隔离目录。
2. **不得作真实判例引用**：本目录卡片的 `result`、`do`、`similarity_features` 均为推演/方法参考，引用真实结论须以真实裁判文书与真实卡为准。
3. **自动化跳过**：月度人格蒸馏（`automation-1783957225500`）、案件结案经验沉淀（`automation-1782558965591`）等读取经验卡的自动化，须显式排除本目录（按 `is_simulation: true` 跳过）。
4. **真实卡片不得 wikilink 指向本目录**：若存在 `[[经验卡片-…]]` 链接指向本目录文件，属悬挂/误连，须 repoint 至真实卡或删除。
