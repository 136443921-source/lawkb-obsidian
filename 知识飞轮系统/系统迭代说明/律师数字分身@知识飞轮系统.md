## 同定位：两个系统不是并列，而是上下位耦合

先纠正一个认知前提，否则分析会失准：**当前实际运行的「小强律师数字分身」是 skill 版（`lawyer-yourself-skill` v1.0.0，含人格蒸馏 + 进化模式 + LTI 闸 + 法随案例库 MCP），而非 2026-06-11 终止的那套独立系统**（原系统因 Neo4j/Redis/MinIO 依赖缺失、SQLAlchemy2.0+Pydantic2.0 兼容性受阻而停摆，代码封存在 `xiaoqiang-lawyer-system/`）。所以今天的"数字分身"= 静态人格镜像 + 推理执行层；而"知识飞轮"= 动态知识代谢 + 经验复利引擎。

两者的关系本质是：**飞轮给分身供"流"，分身给飞轮供"料"。** 分身若不接飞轮，就是一次性蒸馏的人格模具，知识会随立法更新而老化、且无法从没喂过的案件中获得直觉；飞轮若不接分身，知识只是躺在 Obsidian 里的笔记，到不了办案现场。

## 🔗 六层架构如何逐层赋能老强的业务能力

**⑤ 调用层（场景化知识推送）—— 最关键、已落地的接口。** 这是飞轮对分身最直接的增强，本质是**办案现场的 RAG 式注入**。当分身触发蓝队合同审查、庭审准备助手、文书写作、案件分析时，推送引擎从 Obsidian-LawKB 实时检索经验卡片、裁判规则、v1 合同规则库、法规更新，以独立章节附在输出末尾（相关性算法：标题匹配 +5、标签 +2/个、近期 +2）。效果：分身的每次输出不再是仅靠蒸馏时的静态知识，而是叠加了全库最新上下文——**直接抬升合同审查、庭审准备、文书草拟的产出质量**，且经 LTI 闸统一质控。这是"知识→实战"的闭环出口。

**⑥ 沉淀层（跨案件模式识别 + 案件导入与经验回填）—— 赋予"经验直觉"。** 分身 skill 版本身没有案件记忆。飞轮通过 5 维加权相似度（案由 30% + 争议焦点 25% + 法律关系 20% + 证据 15% + 标的 10%）在新案启动时召回历史案件的成败经验。这正是资深律师区别于实习生的核心能力——**从过往模式中识别当前案件的坑与突破口**。但注意：这一层当前是**空转的**（经验卡片 = 0，待你回填真实案件）。

**④ 巩固层（AI 主动提问式复习）—— 直接训练老强本人，而非分身。** 费曼式主动回忆（事实记忆 30% + 理解应用 40% + 分析评价 30%），SM-2 升级版动态调整间隔。这精准对口你当前"基础夯实期（6-8 月）"的实习考核需求——**提升的是你大脑里的留存率与应试/出庭反应速度**，同时薄弱点反馈回沉淀层。分身间接受益：你理解加深后通过"对话纠正"反哺分身的人格蒸馏。

**①②③ 供能层（采集 / 提炼 / 连接）—— 决定上层天花板。** 采集层（每日 08:30 自动摄入法规/案例/资讯，CaseDrop 每日 19:00 归档）解决分身"知识陈旧"；提炼层把原料蒸馏成结构化笔记/卡片，决定推送检索质量；连接层（Obsidian 双向链接）为推送的相关性算法提供图谱基础。这三层是飞轮自转的燃料，缺一则 ④⑤⑥ 沦为无米之炊。

## 🔄 复利闭环：为什么叫"飞轮"而非"数据库"

飞轮的关键不在六层各自能跑，而在**回路自驱**：

> 案件导入 → 生成经验卡片 → 跨案件模式识别召回 → 场景化推送注入办案 → 老强办得更好 → 更多案件导入 → 更丰富的经验卡片。

一旦回路转起来，老强的单位办案能力随案件累积呈**复利增长**而非线性增长。当前 17 个活跃自动化（月耗已从 23 任务 ~1.45M token 降本 45% 至 17 任务）保证了采集与巩固的持续运转——但闭环在"案件 → 经验卡片"这一环断了。

## ⚠️ 当前三大断点（诚实复盘）

1. **经验沉淀端 0 卡片（最高杠杆缺口）**。跨案件模式识别与场景化推送的"案件经验"数据源为空，导致⑥层与⑤层的"经验卡片"优先级（最高权重）形同虚设。根因不是系统缺陷，而是**尚无真实案件回填**。
2. **推送 ↔ 人格蒸馏未自动闭合**。飞轮把知识推到分身的输出里，但不会自动回流进 `lawyer-yourself-skill` 的 `self.md/persona.md`——进化模式仍是手动（追加材料 / 对话纠正）。即"用过的知识"没沉淀成分身的"本能"。
3. **分身能力边界**：skill 版没有原系统的向量检索与多源融合，案例权威检索依赖法随案例库 MCP；若 MCP 断开（当前 connector 状态未见 fasui-caselibrary 在线），分身的案例支撑力会塌缩。

**一句话总结**：飞轮是分身的"外部海马体"——它让分身从一次性蒸馏的静态模具，变成持续从办案现场吸入知识、吐出经验的活系统；而 ④层同时把你本人（老强）也训练进去。当前最大阻塞是**经验卡片为空**，把它填满，飞轮才会真正转起来。
