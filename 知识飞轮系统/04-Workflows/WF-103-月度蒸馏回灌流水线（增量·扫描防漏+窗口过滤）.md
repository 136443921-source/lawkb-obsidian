# 月度蒸馏回灌流水线（增量·扫描防漏+窗口过滤）

## 0. 目的

每月末把知识飞轮系统「本月新增/更新」且**尚未被索引**的经验卡片 / 裁判规则指针，追加进 `小强律师分身` `self.md` 的「经验索引区」表格（指针表，由月度蒸馏回灌）。

from intake_monthly_driver import MonthlyRun

## 2. 阶段与六-B 前置

`MONTHLY_STAGES = ["M0_backup","M1_scan","M2_append","M3_log","FINAL"]`
- **M0_backup（铁律前置）**：写入 self.md 前必须 `cp` 备份 + 校验字节数相等；记录 `last_backup`；self.md 异常即回滚。
- 每阶段 `run.stage_done(stage)`；异常 `run.record_fail(stage, note)`。

## 3. 扫描防护（safe_walk · 根治漏扫）

`BackfillScanner.safe_walk(d)` 已落地 **RULE-058 目录存在性否定结论二次源复核**：
- `os.path.isdir(d)` 不成立 → `GuardError`；
- `os.walk` 返回 0 个 `.md` 时**强制 `os.listdir(d)` 复核**：listdir 有 `.md` 而 walk 为 0 → `GuardError`（疑似遍历/沙箱拒绝）→ 上层告警中止，**绝不误判为空**。

扫描目录（DEFAULT_SCAN_DIRS）：
- `02-提炼/经验卡片`
- `06-沉淀/裁判规则库`
- `06-沉淀/通用裁判规则库`
（排除 `_template.md` / `README.md`；排除治理/元文件：以 `_` 开头或含「索引/快照/治理/体系规范/卡型定义/编号治理/执行记录/全量物理/README」）

## 4. 过滤口径（v2.2 · 非纯 created 月份）

候选 = **未索引 + (created 或 updated) 在窗口内**：
- `dec = updated if updated 不在污染集 else created`
- `in_window = dec >= month_start`
- 已索引（经验索引区已有该相对路径）→ 排除（dup）。

> 旧口径纯 `created` 月份会漏掉「本月更新但更早创建」的资产；新口径覆盖 edited/relink 资产。

## 5. 批戳污染防护（batch-stamp）

`detect_pollution`：同一 `updated` 戳出现次数 ≥ 5（`_Pollution_THRESHOLD`）且 ≥ 月首 → 视为 relink/治理批戳，改用 `created` 判定，避免整库同戳把旧卡拉进本月窗口。

## 6. 分类与 LTI

- 分类：`R-*` / 含 `rule_id` / `card_type` 含「裁判规则」 → `裁判规则-`；否则 `经验卡片-`。
- LTI：仅 `经验卡片` 类走 `wrap_output(text, ai_participation=['经验提炼与知识沉淀'])`；`LTIRejectError`(R101/C301) → 不索引，计入 `lti_blocked`。

## 7. 写入与轮次

- 写目标：`## 经验索引区` → `### 当前索引` 表（表头 `| 资产（指针） | 路径 | 一句话要点 |`），**仅追加**，插在 `> 索引随月度蒸馏增长` 注释行之前。
- 安全上限 v2.1：单轮新增 >150 行 或 总表 >1200 行 → 中止告警。专项补索引须**分轮 ≤50** 避开告警。
- 六-B 每轮写入前单独 `cp` 备份（**时间戳用毫秒级 `%f`**，避免同秒覆盖丢失回滚锚点）。
