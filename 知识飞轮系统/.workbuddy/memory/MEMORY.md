# 项目长期记忆（LawKB 知识飞轮系统）

> 仅记录跨会话有价值的事实/约定/架构，勿记临时调试。

## 架构前提（重要）

- **`rule_id` 是全局跨链「指针键」，不是唯一性约束。** 概念页(`canonical:`字段明文指向规范卡)、经验卡片、提炼索引、案例摘要、裁判规则库 五类卡故意共享同一 `rule_id` 构成双向链接骨架。任何"同 rule_id 多卡"都**不可**直接判为版本冲突/废卡。
- 因此「版本冲突 VC」类必须按**同目录级**判定（同目录内同 rule_id 且内容不同才算真撞号）；跨目录/跨卡型共享一律判 CR·不冲突（指针链接）。
