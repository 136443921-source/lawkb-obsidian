# 📥 CaseDrop — 历史 / 新案件材料投递口

本目录是「知识飞轮系统 · 经验沉淀端」的入口。把**真实案件材料**放进来，系统会自动归档并生成经验卡片，从而**激活数字分身（小强律师）的"经验直觉"**——这是当前飞轮唯一空转的环节。

> 💡 **Obsidian 入口**：在 `LawKB` vault 顶层已建立软链接 `CaseDrop`，你无需离开 Obsidian——直接在侧边栏点开 `CaseDrop` 文件夹，把案件材料拖进去即可（等同于写入 `/Users/chenyouqiang/Documents/CaseDrop/`）。

## 如何使用
1. 将案件材料（可多个文件）放入本目录：`/Users/chenyouqiang/Documents/CaseDrop/`
2. 每日 **19:00** 自动化「案件材料自动归档」会扫描本目录
3. 由「案件导入与经验回填」技能处理：提取要素 → 生成案件笔记（存入 `LawKB/案件管理/承办案件/`）→ 生成经验卡片（存入 `LawKB/知识飞轮系统/02-提炼/经验卡片/`）
4. 经验卡片随后被**月度自动化**蒸馏回数字分身 `xiaoqianglvshi/self.md`，分身逐月变"老练"

## 建议放入的材料
- 判决书 / 裁定书 / 调解书
- 起诉状 / 答辩状 / 代理词 / 质证意见
- 证据清单 / 庭审笔录 / 会见笔录
- 案件复盘笔记 / 战败总结

## ⚠️ 重要
- **真实材料**：系统不虚构案件，经验卡片的"处理结果"必须来自真实结案文书。
- **脱敏**：含当事人姓名、身份证号、手机号等隐私信息的，归档前请脱敏（隐去或替换为"某某"）。
- 放好后无需其他操作；如需立即处理，可直接说"回填历史案件"。
