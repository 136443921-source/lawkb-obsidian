## 二、核心法律分析与行动路径

### 🔴 第一优先：立即提出**执行异议**（《民事诉讼法》第232条）

**行动目标**：先中止对父母账户的执行，争取解冻。

#### 1. 法律依据

- **《民事诉讼法》第232条**：当事人、利害关系人认为执行行为违反法律规定的，可以向负责执行的人民法院提出书面异议。
- **《最高人民法院关于适用〈民事诉讼法〉执行程序若干问题的解释》第14条**：案外人对执行标的主张所有权或者有其他足以阻止执行标的转让、交付的实体权利的，可以依照《民事诉讼法》第234条（原227条）规定提出异议。
- **《民法典》第143条**：**无民事行为能力人实施的民事法律行为无效**；**虚假意思表示**的民事法律行为无效。
- **《民法典》第490条**：当事人采用合同书形式订立合同的，自当事人均**签名、盖章或者按指印时合同成立**。

#### 2. 核心论证

**保证合同上"王德明/XXX"的签名和指纹均非本人所签，系他人伪造冒签 → 担保合同并非担保人真实意思表示 → 担保合同不成立或无效 → 担保人无需承担担保责任 → 执行行为缺乏合法依据 → 应当中止执行、解除冻结**。

#### 3. 文书起草

**《执行异议申请书》核心框架**：

```
申请人（案外人）：王德明、XXX（你母亲）
被申请人（申请执行人）：某农商行/信用社
执行法院：习水县人民法院
执行案号：（2025）黔03XX执XX号（需从冻结文书中获取）

请求事项：
1. 立即中止对申请人王德明、XXX银行账户的执行措施（冻结、扣划）；
2. 解除对申请人银行账户的冻结措施；
3. 本案执行所依据的（2018）黔03XX民初XX号《民事判决书》/《民事调解书》所依据的《保证合同》系伪造，请求法院依法审查担保合同效力，撤销执行依据。

事实与理由：
（一）基本事实
申请人王德明、XXX系夫妻关系。2014年3月，案外人王方利以胜利砖厂名义向被申请人申请贷款50万元。被申请人工作人员罗肖知晓王方利征信黑名单仍推进贷款，并伪造申请人签名签订《保证合同》。

2018年，被申请人以王方利贷款逾期为由，向习水县人民法院起诉王方利及申请人。申请人自始至终未在《保证合同》上签名或按指印，该合同系被申请人工作人员协同王方利伪造。

（二）担保合同系伪造，申请人不应承担担保责任
根据《民法典》第143条、第490条之规定，民事法律行为应当基于真实意思表示。本案中，《保证合同》上"王德明"、"XXX"的签名和指纹均非申请人本人所留，系他人伪造冒签。申请人从未作出过担保的意思表示，该《保证合同》对申请人不发生法律效力。

（三）2018年诉讼存在严重程序违法与实体错误
1. 申请人从未收到法院传票，法院送达程序违法（《民事诉讼法》第88条、第92条）；
2. 2018年诉讼中作为核心证据的《保证合同》系伪造，且申请人2025年调取卷宗后发现，该案卷宗中的《保证合同》与申请人2018年在信用社看到的版本**完全不同**（非同一份），可能存在证据替换或伪造；
3. 申请人因信任王方利"已妥善解决"的告知而未出庭应诉，非因自身原因未能参加诉讼。

（四）申请人已准备申请司法鉴定，以证明签名与指纹之伪造
申请人已联系司法鉴定机构，愿自行垫付鉴定费用，对《保证合同》上"王德明"、"XXX"的签名和指纹进行司法鉴定。此系足以推翻原判决的新证据。

综上，被申请人基于伪造的《保证合同》申请强制执行，缺乏合法依据，严重侵害申请人合法权益。依据《民事诉讼法》第232条、第207条第1项、第3项之规定，特向贵院提出执行异议，恳请依法中止执行、解除冻结，并启动再审程序审查担保合同效力。

此致
习水县人民法院执行局

申请人：王德明、XXX
代理人：XXX（你的名字）
日期：2026年5月28日
```

**⚠️ 关键动作**：
1. 向执行法院提交《执行异议申请书》**同时**，书面申请**对《保证合同》上签名和指纹进行司法鉴定**（你自愿自付鉴定费，这点非常有利，说明你们不怕查）；
2. 如果法院驳回异议，可以向上一级法院申请**执行复议**（《民事诉讼法》第232条）。

### 🟠 第二优先：搞清楚2018年那个诉讼的真实卷宗——这是翻案的钥匙

#### 1. 必须调取的卷宗材料

你这句话极其重要：

> "调取后才发现担保合同和我2018年所看到的根本不是同一份"

这意味着：
- 2018年开庭时呈堂的"保证合同"和你2018年在信用社看到的版本**不一样**；
- 你爸当年因为王方利说"解决了"就没出庭/没答辩/没质证 → **等于放弃了抗辩机会**。

**必须去习水县人民法院档案室/审判管理办公室，调取2018年案件的完整卷宗**，重点看：

| 材料 | 核查要点 |
|------|----------|
| **送达回证** | 你父母是否真的签收了传票？地址对不对？签名是不是伪造的？ |
| **卷宗里附的那份《保证合同》** | 拍照留存，和你在信用社看到的版本**逐字比对**（尤其是签名页、日期、担保人信息） |
| **庭审笔录** | 有没有人替你父母出庭？委托手续是真的吗？你父母有没有签署授权委托书？ |
| **民事判决书/调解书** | 是原判决还是调解？如果是调解，你父母有没有签字？ |
| **王方利还款记录** | 2018年拍卖房产还了多少钱？剩余多少债务？为什么没执行完毕？ |

#### 2. 翻案的法律路径

**路径A：申请再审**（《民事诉讼法》第207条）

**适用条件**：
- 有**新的证据**，足以推翻原判决、裁定（第207条第1项）；
- 原判决、裁定认定的**基本事实缺乏证据证明**（第207条第2项）；
- 原判决、裁定认定事实的**主要证据是伪造的**（第207条第3项）← **这个最适用！**

**期限**：
- 通常：**判决生效后6个月内**；
- **例外**：如果"知道或应当知道"新证据的时间是**2025年4月15日**（你调取卷宗发现合同版本不一致之日），那么6个月期限到**2025年10月**；
- **现在（2026年5月）可能已经超过期限** → 需要立即核查2018年判决/调解的具体生效时间。

**突破口**：
- 强调2018年只是"怀疑"，且信任王方利说的"已妥善解决"，没有"知道"签名系伪造的确凿证据；
- 直到2025年4月15日调取卷宗对比两份合同，才"知道"主要证据系伪造；
- 依据《最高人民检察院民事诉讼监督规则》第27条："当事人申请再审超过法律规定的期限的，但不可归责于其自身原因的除外"，检察院应当受理。

**路径B：申请检察建议/抗诉**（《民事诉讼法》第216条）

**适用条件**：
- 法院驳回再审申请；
- 再审判决、裁定有明显错误；
- **再审申请超过法定期限，但不可归责于当事人自身原因**（最高检明确标准）。

**行动**：
1. 向**习水县人民检察院**提交《民事监督申请书》；
2. 附上证据：2018年冯刚的证言、2025年调取的卷宗中合同版本不一致的证据、笔迹/指纹鉴定申请；
3. 请求：检察院向法院提出**检察建议**，或向最高法院提出**抗诉**。

## 三、回答你四个疑惑（简截了当）

| 你的疑惑 | 实情 |
|---------|------|
| ① 2018年执行时为什么不一并还完？王方利有砖厂石粉厂 | 当年大概率是**终结本次执行**（"终本"）——法院查到房产拍卖还了一部分、余款"暂无可执行财产"就先挂起了，但债务并未消灭。后来银行发现你父母账户有钱，就申请**恢复执行**了 |
| ② 担保人是事业单位职工，连带保证为何不直接找担保人？ | 银行策略通常是**先榨借款人资产**（拍卖房），再回头找担保人——但前提必须是**担保真实有效**。如果担保是伪造的，这条链**从源头就断了** |
| ③ 有偿还能力还能核销表外？ | **核销到表外 = "账销案存"**，监管允许核销后仍继续追偿，但前提是**追偿程序到位、债权真实**。如果担保系伪造，那不仅不该核销，整笔贷款的基础材料都有问题 |
| ④ 为什么多年不催收，等利息滚大了再来？ | 这就是你说的"始作俑者安然无恙"最让人憋屈的部分——银行把贷款核销后催收压力变小了，但法律上的追偿权还在，利息照样滚。但这不是你们该承担的理由，恰恰说明**内部管理失控**。 |

## 四、给你的务实建议（最重要的一段）
