## 二、争议焦点
1. 合作协议是否已被合法解除（解除通知程序是否合法，《民法典》565 条第 2 款）
2. 我方是否已按约履行义务（履行记录证明，《民法典》509 条）
3. 对方付款 / 返还条件是否成就（同时履行抗辩 525 / 526 条）
4. 如解除，费用返还与损失赔偿范围（《民法典》566 / 584 条）

## 三、我方策略框架（可复用）
**三步应对法**：① 积极应诉（不可缺席）② 全面抗辩（事实 / 法律 / 程序三向）③ 灵活调解（降本速决）。
- **三大抗辩方向**：已履行 / 解除通知程序违法 / 付款条件未成就。
- **反诉评估**（《民诉法》54 条）：需与本诉牵连；证据充分才提，否则优先抗辩 + 调解。
- **另诉风险**（《民诉法》124 条）：易构成重复起诉，优先在本诉抗辩。
- **证据整理标准**：一级（证据分组）→ 二级（清单 + 证明目的）→ 三级（关键条款标注）；编号 `证据册-组别-序号`。
