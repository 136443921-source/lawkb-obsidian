# 案件关系图示例

## Excalidraw 插件安装完成

✅ Excalidraw 插件已成功安装并启用。

现在您可以在 Obsidian 中使用 Excalidraw 绘制案件关系图、证据链图等可视化图表。

## 使用方法

### 1. 创建新绘图
- 方式一：在命令面板中搜索 `Excalidraw: Create new drawing` 并执行
- 方式二：使用快捷键 `Cmd/Ctrl + Shift + E`
- 方式三：创建一个以 `.excalidraw` 或 `.excalidraw.md` 结尾的文件

### 2. 绘制案件关系图
典型案件关系图可以包含：
- **当事人节点**（原告、被告、第三人）
- **法律关系箭头**（借款、担保、侵权等）
- **证据节点**（合同、收条、录音、聊天记录）
- **时间轴线**（关键时间点标注）
- **争议焦点框**（突出核心争议问题）

### 4. 绘制证据链图建议

1. **中心节点**：案件核心事实
2. **一级证据**：直接证据（合同、转账记录）
3. **二级证据**：间接证据（聊天记录、录音）
4. **三级证据**：辅助证据（证人证言、鉴定意见）
5. **连接线标注**：证明内容、证明力强弱

### 5. 实际应用场景

- **借款合同纠纷**：可视化资金流向、担保关系
- **侵权案件**：绘制侵权行为与损害结果因果关系
- **复杂公司案件**：股权结构图、交易关系图
- **刑事案件**：作案时间线、证据关联图

## 插件配置提示

如需进一步配置 Excalidraw 插件：
1. 打开 Obsidian 设置
2. 进入「第三方插件」
3. 找到 Excalidraw 并点击设置图标
4. 可调整：
   - 默认绘图样式
   - 自动保存频率
   - 导出图片格式
   - 快捷键自定义
