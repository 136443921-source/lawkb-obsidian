# Templater 快速配置指南

**症状**：Templater 插件已安装启用，但创建新笔记时没有自动填充模板内容。

**根本原因**：Templater 没有配置模板文件夹路径，不知道从哪里获取模板。

---

## 🚀 **一分钟解决方案**

### **第1步：设置模板文件夹**
1. 打开 **设置**（`Command + ,`）
2. 左侧点击 **"核心插件"**
3. 找到 **"模板"**（不是 Templater）
4. ⚙️ 点击齿轮图标进入模板设置
5. **"模板文件夹位置"** → 点击 **"选择"**
6. 在弹出的文件选择器中，找到并选择你案例库中的 **"文书模板"** 文件夹
7. 点击 **"打开"**

### **第2步：设置 Templater（可选）**
1. 设置里点击左侧 **"社区插件"**
2. 找到 **"Templater"**，点击 ⚙️ 齿轮图标
3. 在设置页面里：
   - **"模板文件夹位置"** → 设置为 **"文书模板"**
   - **"触发模板插入"** → 确保开启
   - **"在新笔记中自动插入模板"** → 建议开启

### **第3步：重启测试**
1. 重启 Obsidian
2. 右键点击 **"案件"** 文件夹 → **"新建笔记"**
3. 输入文件名，看看是否自动填充模板

## 🔧 **高级配置方案**

如果上面的方法不工作，尝试这个：

### **方案A：使用 Templater 的命令**
1. 在任何笔记里，进入 **编辑模式**
2. 按 `Command + P` 打开命令面板
3. 搜索输入 **"Templater: Create new note from template"**
4. 选择这个命令
5. 选择你要用的模板（如"[[合同纠纷-模板|合同纠纷-模板]]|合同纠纷-模板|合同纠纷-模板|合同纠纷-模板|合同纠纷-模板|合同纠纷-模板|合同纠纷-模板|[[借款合同纠纷-模板|借款合同纠纷-模板]]|借款合同纠纷-模板|借款合同纠纷-模板|借款合同纠纷-模板|借款合同纠纷-模板|借款合同纠纷-模板"）
6. 新的笔记会自动创建并用模板填充

### **方案B：配置文件夹特定模板**
1. 在 Templater 设置中，找到 **"文件夹模板"**
2. 点击 **"添加新规则"**
3. **文件夹**：选择 **"案件"**
4. **模板**：选择 **"借款合同纠纷-模板|借款合同纠纷-模板.md"**
5. 保存后，所有在"案件"文件夹中创建的新笔记都自动使用这个模板

## ✅ **验证配置成功**

配置完成后，进行以下测试：

### **测试1：模板文件夹识别**
1. 打开设置 → 核心插件 → 模板
2. 检查 **"模板文件夹位置"** 是否正确显示

### **测试2：Templater 命令可用**
1. 按 `Command + P`
2. 输入 "Templater"，看是否有相关命令出现
3. 执行 **"Templater: Create new note from template"** 命令

### **测试3：自动填充效果**
1. 右键点击 **"案件"** 文件夹 → **"新建笔记"**
2. 命名为 **"测试模板生效"**
3. **期望结果**：笔记自动包含模板内容（案由、当事人等字段）

## 🆘 **常见问题解决**

### **Q1：模板文件夹选择后还是无效？**
- **检查**：模板文件夹里必须有 `.md` 文件
- **解决**：确保"文书模板"文件夹里有模板文件

### **Q2：Templater 设置里看不到齿轮图标？**
- **原因**：Templater 未完全启用
- **解决**：重启 Obsidian，重新启用 Templater

### **Q3：命令面板里没有 Templater 命令？**
- **原因**：插件加载异常
- **解决**：禁用 Templater，重启 Obsidian，重新启用

### **Q4：只想用 Obsidian 内置模板，不想用 Templater？**
- **操作**：完全启用内置"模板"插件
- **方法**：核心插件 → "模板" → 启用
- **用法**：在笔记中插入模板的快捷键是 `Ctrl + T`（或 `Command + T`）
