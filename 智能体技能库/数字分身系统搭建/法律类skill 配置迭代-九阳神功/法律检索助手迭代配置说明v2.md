**适用法律体系** 中国大陆 / 港澳台 丨 美国联邦 / 欧盟及其他亦适用但不推荐

> 本技能对文本中援引的法律条文执行 **对抗性验证** （adversarial verification）——主动寻找引用错误，而非被动接受。输出结果为供律师审阅的审查报告草稿，不构成法律意见，不替代执业律师的专业判断。

---

## 目录

## 能做什么

法条审查技能覆盖从"引用是否准确"到"用在这个案情是否合适"的完整链条，分八个步骤逐层深入：

| 审查维度 | 回答的问题 |
| --- | --- |
| 提取与结构化 | 文本中引用了哪些法条？引用类型是什么？初始风险如何？ |
| 时效性 | 这条法律还在用吗？引用的是不是旧版本？是否在过渡期？ |
| 原文比对 | 引用的文字和官方原文一致吗？ |
| 司法解释 | 法条的含义有没有被司法解释重新界定？ |
| 实质适用合理性 | 这条法律用在这个案情合不合适？有没有更强的依据？ |
| 管辖区适配 | 引用的法律和文件适用的地区匹配吗？ |
| 格式规范化 | 引用格式符合法律文书标准吗（含港澳台/国际/仲裁/规范性文件）？ |
| 报告输出 | 问题汇总、可分发性评估、修正建议优先级排序、法律体系一致性检查 |

## 举例：

### 单条法条审查

直接粘贴法条引用即可，技能自动识别并启动审查：

```
《民法典》第577条规定，当事人一方不履行合同义务或者履行合同义务不符合约定的，
应当承担继续履行、采取补救措施或者赔偿损失等违约责任。
```

若需评估实质适用合理性，附上案情摘要：

```
上述法条 + 案情：甲公司与乙公司签订货物买卖合同，乙公司拒绝收货并拒付货款，
甲公司主张要求乙公司支付货款并赔偿损失，请审查法条并评估是否有更强的请求权基础。
```

### 文件批量审查

上传合同、诉状、法律意见书等文件，技能自动提取全部法律引用并逐条审查：

```
[上传文件] + "请对文件中所有法条引用进行批量审查"
```

可附加参数：

```
[上传文件] --jurisdiction 香港 --depth 深度
```

| `--depth` | 快速 / 标准（默认）/ 深度 | 审查深度，见下节说明 |

## 审查深度说明

| 深度 | 适用场合 | 执行步骤 |
| --- | --- | --- |
| **快速** | 合同初审、快速浏览 | 时效性 + 原文比对（明显错误） |
| **标准** | 正式文件审查 | 全部八步 |
| **深度** | 诉状、法律意见书、上市文件 | 全部八步 + 引用链路追踪 + 司法解释四轨搜索（含地方高院）+ 请求权最优性评估 |

文件类型会触发深度自动推断：合同 / 诉状 / 法律意见书默认"深度"，普通文件默认"标准"。

## 八步审查流程

### 步骤一　提取与结构化引用清单

扫描输入文本，识别全部法律引用，结构化为：

```
引用ID | 法律名称 | 条款编号 | 援引声称的含义 | 出现位置 | 引用类型
```

引用类型标注：法律 / 行政法规 / 司法解释 / 部门规章 / 规范性文件 / 地方性法规 / 国际条约

同时询问或推断用户的 **适用意图** （用户对该条款的理解方式），为后续司法解释检测和实质适用评估做准备。支持同一法条多论点分别处理。

### 步骤二　时效性验证

追踪每条引用的时效链：

```
[原始法律] → [历次修订] → [当前有效版本] → [是否已整合入新法]
```

输出六种时效状态：

| 标记 | 含义 |
| --- | --- |
| ✓ 现行有效 | 当前版本，条款未变动 |
| ⚠ 已修订 | 法律有效，但引用的是旧版条文 |
| ✗ 已废止 | 法律已废止，并给出替代法律 |
| ⏳ 已通过未施行 | 已通过但尚未生效，不可作为现行依据 |
| 📋 草案阶段 | 尚在征求意见，不得引用 |
| ❓ 待核实 | 无法通过可用数据源确认 |

**过渡期版本判断** ：当法律存在新旧版本过渡期时，须询问法律行为发生时间，据此判断适用版本。

**高频废止节点提示：** 2021 年前起草的文件中，凡引用《合同法》《物权法》《侵权责任法》《担保法》《婚姻法》《继承法》等，均自动触发废止预警，并给出对应的《民法典》条款。

### 步骤三　原文比对

将援引文字与官方原文逐字比对，重点核查逻辑连词（"且"↔"或"）、模态词（"应当"↔"可以"）、否定词、数字期限、主体名称、但书条款等高风险差异点。

比对结果分五级：🟢 完全一致 / 🟡 轻微差异 / 🟠 实质差异 / 🔴 严重差异 / ⚪ 无法核实

### 步骤四　司法解释与适用性审查

**法条文本正确 ≠ 法律适用正确。** 本步骤检测司法解释是否已改变或明确了该条款的理解方式，独立于步骤三的文本比对并行执行。

执行四条搜索轨道 + 地方高院扩展：

- 轨道一：法条级搜索（该法条的整体司法解释体系）
- 轨道二：关键词级搜索（针对用户适用意图中的分歧点关键词）
- 轨道三：配套规定搜索（深度模式）
- 轨道四：指导性案例搜索（深度模式）
- 轨道四扩展：地方高院指导意见搜索（深度模式+地域性案件）

解释性差异分五级：IC-CD（严重）/ IC-SD（实质）/ IC-MN（轻微）/ IC-Info（提示）/ IC-Pending（发现但无法判定）

### 步骤五　实质适用合理性审查

结合用户提供的案件事实，从三个层次评估法条选择是否合适：

**构成要件匹配性** 逐项核查案件事实是否满足该法条的全部构成要件，指出缺失的要件并说明证明难点。

**请求权基础最优性** 判断当前条款是否是支持该论点最直接、效力最强的依据，检查是否存在特别法优先适用、新法优于旧法等替代选择。

**法律武器完备性** 识别"论证链断裂"或"请求权残缺"，给出补强建议：

| 补强类型 | 典型缺漏示例 |
| --- | --- |
| 权利依据 + 救济依据分离 | 引了《劳动合同法》第 48 条（违法解除后果），未引第 87 条（二倍赔偿金） |
| 实体 + 程序条款配合 | 主张合同无效引第 153 条，未引第 157 条（无效合同的返还处理） |
| 一般 + 特别条款叠加 | 消费者案件仅引民法典违约条款，未引《消费者权益保护法》第 55 条（三倍惩罚性赔偿） |
| 请求权竞合时的最优选择 | 合同责任与侵权责任可竞合，需评估哪条赔偿范围更广 |

输出实质适用合理性结论：

| 代号 | 含义 | 处理方式 |
| --- | --- | --- |
| SA-Full | 条款选择最优，构成要件齐备，论证完整 | 维持现有引用 |
| SA-Enhance | 当前条款可用，但有更强依据或可补充 | 给出补强条款 |
| SA-Weak | 构成要件存疑，或有更合适的条款 | 给出替代条款 + 利弊分析 |
| SA-Wrong | 条款与案情不符，构成要件明显欠缺 | 拒绝适用，给出正确替代 |
| SA-Pending | 案件事实不足，无法作出判断 | 列出所需补充的案情信息 |

> ⚠️
> 
> 若用户未提供案情，本步骤将主动询问核心事实后再执行，不可跳过。

### 步骤六　管辖区适配检查

确认文件适用法域，检查法域错配、地方性法规与上位法冲突、涉外合同准据法缺失等问题。管辖区不明时，在报告顶部显式标注推断依据，不静默假设。

### 步骤七　格式规范化建议

按法律文书标准检查引用格式，涵盖：

- 大陆法律：书名号、全称、条款编号汉字规则、款项层级精度、司法解释文号、规范性文件文号、地方性法规制定主体
- 港澳台：香港 Cap. 编号、澳门葡文法规编号、台湾无书名号格式
- 司法解释：须含法律全称 + 文号 + 条款
- 国际条约：须含条约全称 + 条款 + 中国批准/加入日期
- 仲裁规则：CIETAC、ICC 等独立引用规范

### 步骤八　输出审查报告

完成 18 项自检清单后输出报告，支持三种格式：

- **Markdown 报告** ：含执行摘要、逐条审查结果、修正建议汇总、置信度说明
- **DOCX 报告** ：专业排版，含封面、彩色差异比对表、可分发性评估
- **结构化 JSON** ：供系统集成或二次处理

批量模式额外输出法律体系一致性检查（识别同文件内的新旧法混引、管辖区混引）。

```
共检出引用：N 条
🔴 严重问题：X 条（需立即修正）
🟠 重要问题：X 条（建议修正）
🟡 轻微问题：X 条（格式优化）

❓ 待人工核实：X 条

```

### 逐条结果字段（v3.0.0）

每条引用的审查结果包含以下字段：

```
原文引用 / 所引法律（全称 + 条款）/ 时效状态（6种）
文本比对结论 + 差异详情
司法解释审查结论（IC 级别）
实质适用合理性（SA 代号 + 构成要件核查 + 请求权最优性 + 补强建议）

修正建议
```

- 审查结果概览表（含适用合理性列，按严重程度排序）
- 法律体系一致性检查（识别同一文件内的新旧法混引、管辖区混引）
- 分类总结：可继续使用 / 需修正内容 / 需更换法律 / 需重新理解 / 需评估适用性 / 需补强论证

## 置信度体系

| 等级 | 条件 |
| --- | --- |
| **高（H）** | ≥2 个官方来源且一致 + 确认最新版本 + 逐字比对完成 + 但书已检查 + 司法解释双轨搜索完成 + 用户意图已确认 + 构成要件已匹配 + 法律武器已评估 |
| **中（M）** | 1 个官方 + 1 个辅助来源一致 / 未能确认最新版本 / 仅完成法条级搜索 / 规范性文件引用（置信度上限M） |
| **低（L）** | 仅 1 个非官方来源 / 来源不一致 / 法律名称不确定 |

低置信度结论不可输出确定性判断，仅列出已获取信息并标注局限性。

**引用可信度标注规则：**

- 通过研究连接器（MCP）实时核实 → 标注 `[来源: XXX]`
- 基于模型知识推断 → 标注 `[待核实]`
- 无研究工具接入 → 报告头部注明"法条来源未经实时数据库核实"

## 边界与护栏

**不提供法律意见** 审查结论仅针对引用准确性与适用合理性分析，不判断诉讼策略的妥当性，不预测胜负。

**不直接修改源文件** 仅提供修正建议，实际修改由律师决定并执行。

**规范性文件边界** 规范性文件审查不替代对上位法的完整合规审查。

**实质适用合理性的边界** 构成要件匹配性分析基于用户提供的案情摘要，不替代律师阅卷和完整事实调查；补强建议为穷举式提示，不考虑诉讼时效、举证难度等策略因素。

**司法解释谨慎处理** 最高法解释、部门规章、地方规范性文件变动频繁，基于模型知识核实的此类引用一律标注 `[待核实]` 。

**争议法律领域** 引用涉及尚无定论的法律解释时，明确标注"存在解释争议"，不作倾向性结论。

**保密提示** 文档含当事人信息时，提醒用户在使用外部数据库核实时注意保密义务。

## 常见问题

**Q：我只想查一下某条法律还有没有效，要走完整流程吗？** 直接询问"《XX法》第X条是否现行有效"，技能会执行快速模式，仅完成时效性验证并给出结论。

**Q：没有提供案情，步骤五会怎么处理？** 技能会主动询问核心案件事实（当事人关系、争议行为、主张的权利/义务）后再执行实质适用评估。如明确表示不需要此步骤，可告知跳过，结论中会相应标注"实质适用合理性未评估"。

**Q：引用的是港澳台或境外法律怎么办？** 技能支持香港（elegislation.gov.hk）、澳门、台湾、美国联邦、欧盟等法域的审查，引用时请通过 `--jurisdiction` 参数或在文本中明确说明适用地区。

**Q：引用了部委通知/意见等规范性文件怎么处理？** 技能会自动识别规范性文件（红头文件），搜索发布机关官网核实，标注置信度上限为M，并检查是否与上位法冲突。

**Q：引用了法律草案/征求意见稿会怎样？** 技能会标注时效状态为"📋 草案阶段"，并以🔴醒目标注"引用草案不得作为现行法律依据"。

**Q：输出的报告可以直接交给法院或客户吗？** 不建议。报告为供律师审阅的审查草稿，顶部包含"不构成法律意见"审阅声明。律师复核确认后方可作为正式文件使用。

**Q：如何获得 DOCX 格式报告？** 完成审查后告知"请生成 DOCX 报告"，技能会调用报告生成脚本输出专业排版的 Word 文档。
