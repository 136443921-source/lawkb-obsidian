### （三）工作流程优化

#### 1. 新增庭审准备工作流程
```
1. 接收输入 - 用户发送案情文本（起诉状、答辩状、证据、陈述等）
2. 思维链分析：
   - 识别原被告、第三人关系
   - 校验一致性 - 检查起诉状列明的被告与证据链是否一致
   - 梳理证据链完整性
3. 分步输出 - 严格按照输出模板生成多格式文档
```

#### 2. 新增法律研究工作流程（直接联动法律备忘录智能体功能）
```
1. 明确法律问题 - 界定争议焦点
2. 确定法律领域 - 民事、商事、劳动等
3. 确定管辖层级 - 最高院、高院、中院
4. 检索法律法规 - 一级法源
5. 检索案例 - 指导性案例、典型案例、裁判文书
6. 分析综合 - 形成结论
7. 记录研究过程 - 检索词、数据库、依据
```

### （四）核心研究技能完善

#### 1. 法律法规体系（效力层级）
```
宪法 → 法律 → 行政法规 → 地方性法规 → 部门规章 → 地方政府规章

检索路径优先：
1. 国家法律法规数据库：https://flk.npc.gov.cn
2. 司法部法律法规数据库：https://www.moj.gov.cn
```

#### 2. 司法解释类型
- **解释**：对法律条文的具体理解
- **规定**：审判工作中的具体问题
- **批复**：对下级法院请示的答复
- **决定**：对既有司法解释的修改废止

检索路径优先：最高人民法院官方网站

#### 3. 案例效力层次
1. **指导性案例**（最高院发布）- 应当参照
2. **典型案例**（最高院各审判庭）- 参考价值
3. **公报案例**（最高院公报）- 代表性强
4. **普通裁判文书** - 因法院层级而异

检索路径优先：
- 人民法院案例库 (rmfyalk.court.gov.cn)
- 中国裁判文书网 (wenshu.court.gov.cn)

### （三）工作流程优化

#### 1. 新增阶段二技巧六：生成检索策略（用于庭审准备联动）
```
为庭审准备生成检索策略，而非编造案号：

1. 通用关键词生成：
   - 根据案件法律关系和争议焦点，生成通用关键词
   - 提供多个关键词组合，便于用户在不同数据库检索

2. 数据库专用检索指令生成：
   - 针对北大法宝、威科先行、法信等专业数据库，生成专用检索指令
   - 包括字段限定、布尔逻辑组合、排序方式等

3. 检索策略示例：[详见SKILL.md]
```

#### 2. 新增阶段三第七步：法律法规研读
```
对检索到的法律法规和司法解释进行深入研读，分析其适用：

1. 法条要义解读：
   - 解读法条的立法目的、构成要件、法律效果
   - 分析法条的适用条件和范围
   - 识别法条的例外情况和限制条件

2. 司法解释适用分析：
   - 分析司法解释对法律条文的具体理解和适用
   - 识别司法解释的适用范围和限制
   - 比较不同司法解释之间的关系

3. 法律法规研读报告：
   - 按效力位阶排列
   - 每个法规包含：法规名称、效力位阶、条款摘要、时效性、适用分析
```

#### 3. 新增阶段四第七步：裁判观点比较
```
比较不同地区法院的裁判观点，分析裁判尺度差异：

1. 裁判观点比较维度：
   - 法院层级：最高院 vs 高院 vs 中院
   - 地域差异：东部地区 vs 中部地区 vs 西部地区
   - 时间变化：早期裁判 vs 近期裁判
   - 法官裁量：严格适用法律 vs 自由裁量

2. 裁判观点比较表格：[详见SKILL.md]

3. 裁判观点比较分析：
   - 分析不同观点的法律依据
   - 分析不同观点的裁判尺度差异
   - 提出应对策略和建议
```

#### 4. 新增阶段五第四部分：裁判观点比较分析

### （三）工作流程优化

#### 1. 新增阶段一第四步：法律争议识别
```
识别案件中的法律争议焦点：

1. 事实争议焦点识别：
   - 识别案件中事实认定的争议点
   - 分析各方当事人对同一事实的不同主张
   - 评估证据证明力，判断事实认定的可能性

2. 法律争议焦点识别：
   - 识别案件中法律适用的争议点
   - 分析各方当事人对法律理解的不同观点
   - 评估法律适用不确定性，判断法律适用可能性

3. 法律争议焦点表格：[详见SKILL.md]
```

#### 2. 新增阶段二第一步：法律法规研读
```
对检索到的法律法规和司法解释进行深入研读，分析其适用：

1. 法条要义解读：
   - 解读法条的立法目的、构成要件、法律效果
   - 分析法条的适用条件和范围
   - 识别法条的例外情况和限制条件

2. 司法解释适用分析：
   - 分析司法解释对法律条文的具体理解和适用
   - 识别司法解释的适用范围和限制
   - 比较不同司法解释之间的关系

3. 法律法规研读报告：
   - 按效力位阶排列
   - 每个法规包含：法规名称、效力位阶、条款摘要、时效性、适用分析
```

#### 3. 新增阶段二第二步：案例分析
```
检索并分析相关案例、裁判文书：

1. 案例检索策略：
   - 根据法律争议焦点，生成案例检索策略
   - 提供通用关键词和数据库专用检索指令
   - **不编造案号**，用户需使用专业数据库实际检索

2. 案例比对分析：
   - 多个相似案例的裁判要点、判决结果、事实差异的系统比对
   - 比较不同地区法院的裁判观点，分析裁判尺度差异

3. 案例摘要：[详见SKILL.md]
```

#### 4. 新增阶段三第四步：法律意见分析报告（用于庭审准备联动）
```
生成详细的法律意见分析报告，用于庭审准备：

1. 法律意见分析报告结构：
   - 法律问题界定

### （二）联动说明优化

- 庭审准备助手引用备忘录结论和法律意见分析报告，启动庭审准备流程

#### 4. 法律检索助手 → 庭审准备助手
- 检索完成后，输出检索报告
- 检索报告包含"庭审准备建议"和"检索策略"部分，可直接用于庭审准备
- 庭审准备助手可直接接收检索报告，自动解析"庭审准备建议"和"检索策略"部分，生成庭审准备材料

#### 5. 庭审准备助手 → AI模拟法庭法官
- 庭审准备完成后，生成模拟庭审数据
- 传递给AI模拟法庭法官，启动模拟庭审

#### 6. AI模拟法庭法官 → 庭审准备助手（反馈优化）
- 模拟庭审完成后，输出庭审报告和反馈
