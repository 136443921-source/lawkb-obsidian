## 🔄 活文档同步机制（2026-09-16 锚定 · v1.4.1）

> 本索引为**活文档**：心智资产库（6 个席位 skill 目录 + 飞轮 `05-调用` + 中枢 `PROJ`/`DEC`/`WF`）一旦变动，中枢文档自动跟随，无需人工重跑。

| 组件 | 说明 |
|---|---|
| 同步引擎 | `~/.workbuddy/skills/_common/scripts/mind_asset_index_sync.py`（读源卡 frontmatter + 库扫描，比对索引单元格） |
| 定时自动化 | **`c47e30c5`**（recurring，每 4 小时 `--apply` 巡检；无变动不刷每日日志，有变动才记「🧠 心智资产索引同步」小节） |
| 联动① 状态跟随 | persona 卡 `status` 漂移 → 自动修正（源卡硬事实；已含「DRAFT 1/4 判据」自动回补，零信息丢失） |
| 联动② 库变动检测 | 新增 persona 卡（席位目录内）／新增席位 skill（含席位关键词且索引未提及）／新增训练备忘录（`05-调用`）／源卡被删 → **仅报告提示，不自动写入** |
| 联动③ 成熟度 | 默认只报告不覆盖；`--with-maturity` 才改（权威数据绝不静默覆盖） |
| 退出码 | 0=无变动 / 1=有漂移或库变动 / 2=执行错误（供 automation 判断） |

> ⚠️ **补登边界**：联动②检测到的「新增资产」只提示，结构性补登（写入第一节主权表 / 第三节备忘录表 / 统计表 / 版本历史）由人工或后续会话完成——这是为守住「先排查确认再批量修改」铁律，避免脚本误伤人工精修的章节结构。
