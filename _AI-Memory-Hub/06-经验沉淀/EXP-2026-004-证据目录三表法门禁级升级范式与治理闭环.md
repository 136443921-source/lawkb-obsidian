# 证据目录三表法「提示词级→门禁级」升级范式与 8 项治理闭环

> 类别：方法论级教训。本次不是踩了一个具体的坑，而是走通了一条「把提示词级纪律升级为门禁级机制」的完整路径，并在此过程中揪出三类系统性问题。沉淀的是可复用的升级判据、审计范式与核验铁律。

## 一、背景链路（一次走完的完整闭环）

学习《证据目录三表工作流》→ 判定增量 → 落规则卡 WF-131 → 按 B 方案落地 → 架构纠正 → 一致性审计 → 完整能力复盘 → 8 项治理 + 1 处残留修正 → 复盘沉淀。主线只有一个：把三表法的**四个方法内核**（证明对象判断句 / 空白期检测 / 三档风险+五类补强 / 自认风险栏），从「靠人自觉」逐级升到「靠机制兜底」。

## 二、教训一：学习类文章先做「增量判定」，不急着建卡

拿到一篇方法论文章，第一动作不是"新建一张卡"，而是先回答：**本文增量在哪、现有资产缺哪块**。

- 本案实例：三表法的实体规则，R-PR 系列 314 张卡已覆盖；真正增量是**编排工作流层**的四个方法内核 → 故落 `04-Workflows/WF-131`（编排卡），而非再建证据法规则卡。
- 判据：**先查现有卡族，再决定落点**，避免重复建卡（呼应编号治理 P0-4 的"先查重再建"）。

## 三、教训二：「提示词级 → 门禁级」升级三件套

任何"靠自觉执行"的纪律，只要**出错不可逆**，就不能停留在提示词级。升级需三件套齐备，缺一不算机制化：

| 件 | 作用 | 本案实例 |
|---|---|---|
| **gate-config 强制步骤** | 门禁层硬阻断 | 自认风险栏扫描（🔴L3，未改写即阻断）、case-state 已回写（🟡L2） |
| **meta 结构化字段** | 单一事实源留痕 | case-state.json `syncPolicy`（唯一权威源声明 + 旧版指纹） |
| **自动化兜底** | 无人值守监控 | `timeline_gap_scan.py` 挂 recurring automation 每日扫空白期 |

- **升级判据**：出错后果不可逆（自认表述、红蓝复核漏点、状态滞后）→ 升 L3/L2；出错可补救 → 维持 L1/L2 抽检。
- **"人工询问"是门禁断层**：gate-config 已写"红蓝复核 L3"，但技能流程层仍在 `AskUserQuestion` 询问 → 强制没传导下来。**门禁层与流程层必须同源**，改了 gate-config 还要回头改技能 SKILL.md 的触发动作。

## 四、教训三：「有实无名 / 有名无实」双向审计

文档层与实际系统不一致，有两种方向，都要抓：

1. **有实无名**（实际存在、文档漏记）——如"作战室"物理存在但运维手册/索引零记录。靠"对照实际系统逐项 grep 文档"抓。
2. **有名无实**（文档记载、实际不存在）——如文档列了 `sync_case_state.py` 脚本、记忆里"最佳实践库"路径，实测磁盘都没有。靠"文档记载的文件/路径逐一实测是否存在"抓。

- 一句话：**文档 ≠ 事实，双向都要核**。漏记让资产"隐形"，虚记让引用"悬空"。

## 五、教训四：「双原件冲突」治理范式

同一状态文件存在两份（桌面旧版 vs 中枢 L0 新版），内容是冲突的。治理范式：**不在个人目录删文件，而在 L0 显式声明唯一权威源 + 旧版 MD5 指纹 + "不得引用"**。

- 好处：既安全（不碰个人目录），又留痕（下次见到旧版指纹即知读错），还自证（声明含 MD5 长度校验，呼应"长标识写全值"铁律）。

## 六、教训五：实体核验铁律——写「已建/存在」前必实测

本轮两个实证，都指向同一条铁律：

1. **误报**：资产总账记"类案卡/裁判规则卡未实测到实体"，实际 `find` 一跑 19 张全在——系核验路径/时点误报。
2. **虚记路径**：记忆里"红队攻击点沉到 05-调用/最佳实践库"，实测该子目录不存在——正确落点是"诉讼文书复核调用记录 + 红队心智模型"。

- 铁律：**凡断言"已建/存在/缺失/不存在"，先跑一次 `find`/实测再下笔**；否定型结论（"不存在"）更要换第二种方法复核（呼应"零结果双证"）。

## 七、可复用动作清单（下案直接抄）

1. 学习新方法论 → 先做增量判定（现有卡族缺口在哪）→ 再定落点。
2. 纪律出错不可逆 → 升级三件套（gate-config 强制步骤 + meta 字段 + 自动化兜底）。
3. 改门禁后 → 回头同步改技能流程层触发动作（消灭"门禁强了、流程还在问"的断层）。
4. 文档与实际系统 → 双向审计（grep 文档 + find 实测）。
5. 多原件冲突 → L0 声明唯一权威源 + 旧版指纹，不删个人目录文件。
6. 断言存在/缺失 → 先实测，否定型结论二次复核。
