# WF-136 · 接案·开卷底稿四表工作流

> **只沉淀方法论与工作流事实，不含任何个案卷宗、案号、当事人姓名或证据原件。**

## 一、适用场景

律师接新案、读卷宗时，把「通读卷宗」变成「复核四张可回查的表」。定位在 **CLM G0→G1 接案前置**。
**AI 摆原料，律师做判断**：不下实体结论、不给诉讼策略、不评估胜算、不产出对外文书；全部输出标「待律师复核」。

## 二、开工前前置（缺一不开始）

1. 现读 `case-state.json` 取案号与诉讼地位，引用带「（源：case-state.json#字段 @日期）」；OCR 不替代 L0。
2. 确认诉讼地位六值；无法判断必问律师；二审不得沿用一审立场。
3. 列 `hdr.source_scope`（纳入清单 + 排除项单列）；定 `hdr.coord_mode` 三档（时间轴永远不写 P）。
4. 写 `hdr.mix_case_guard`（关联案件隔离）。
5. 读字段 SSOT，**禁凭记忆造字段**。

## 三、四步工作流（顺序不可乱）

**先事实 → 后关系 → 后焦点 → 后利弊**

| 步 | 产出 | 关键红线 |
|---|---|---|
| S1 时间线 | 每节点带来源坐标；`status` 四值用边框线型编码 | 缺口写「卷内未见……（不得推定未发生/未支付）」，**禁补位幻觉** |
| S2 法律关系 | 列**全部**主体与逐层关系；案由争点 → 双案由并行拆解 | 模糊时**并列两种可能、不给倾向**；涉意思/授权走 E1004 三层，缺层强制「存疑」 |
| S3 双列焦点 | 左列对方主张**逐字原文**；右列只从材料生成 | 两列独立生成（R 列生成时不读入 L 列）；**禁替对方总结后反驳**；禁大词；程序先决排实体焦点前 |
| S4 利弊三栏 | 按 `S3.D.id` 横排三栏 + 缺失事实锁定清单 | 利否整列固定「🔴 待律师确认」；`reading` 由 `burden × sufficiency` 机械派生；禁动作句 |

**三套状态不可串用**：`st.proof_status`（事实层）／`st.sufficiency`（要件举证层）／`st.卷内印证`（裁判对照层）。
`❌卷内未见 ≠ ❌缺失 ≠ 待核`；**卷内未见 ≠ 事实不存在**。

### 3.1 缺料时的合法落点（r2 补丁，重要）

`S3.L.verbatim` 因原件缺位只能写「［须从××原文逐字回填］」时，`S3.D.pair` 记「无对应」，
`S3.D.delta_verdict` **只能取第五值「待 L 列回填」**，不得硬填「真问题／话术包装／隐含焦点／程序先决」。
→ 防止在缺料下硬做差额判定，守住禁补位幻觉。
`S3.D.gap_fact[]` 仍 **1:1** 进入 `S4.missing.gap_ref`，措辞原样、不可压缩改写；拆分记 `split_from`；`gate.gap_coverage = 100%`。

## 四、上游依赖契约（`RULE-060` 单向派发）

| 项 | 值 |
|---|---|
| 上游 | `case-file-review`（L2 法律服务中台能力模块 · 席位调用） |
| 派生来源 | 引用坐标三档、时间线字段、五维提取、要件表七栏、`burden × sufficiency` 读表规则、LTI 26 占位符、利否待确认、「卷内未见 ≠ 事实不存在」、L0 真值 |
| 硬规则 | 下游**禁自定义**字段名／LTI 维度／规则码／版本号；上游升版须先做 drift check；**禁止通过改 `settings.json` 改变上游挂载通道** |

> 踩坑留痕：`skillOverrides` 无键 ≠ 未挂载。判断挂载必须查**中枢呈批件 + 技能主文件 + 席位路由表 + 安装登记表**四证，
> 不能只看一个配置文件。另：中文／混合编码文件用 bash grep 会静默失效，零结果须换第二工具复核。

## 五、三道门禁与交付

`草稿 → ① 红蓝复核 → ② LTI 双闸门（两层 REJECT=0）→ ③ 六维门禁(G2+G6) → 律师签字`

- LTI 版本与维度口径**现读中枢 `RULE-060`**，下游禁自定义。
- AI19：对外提交附《AI辅助使用说明-对外版》，内部留痕另存《AI辅助使用记录-内部版》。
- 脱敏流向：案件目录内实名（打码证件）／中枢只留方法论／公开全脱敏。
- 四表不是对外文书；据其产出诉状/代理词须另按法〔2016〕221 号重排。
- 命名 `YYYYMMDD_类型_版本`，禁「最终版／final」。

## 六、验收判据（拿已办结旧案跑）

1. **流程走全**：四步不跳步，缺口不脑补。
2. **颗粒度**：焦点须是能直接进办案动作的**中观句**，非「合同效力」类大词。
3. **边界**：模糊不给倾向、不虚构对方立场、不打利否标签、缺料走「待 L 列回填」。

> 验收须区分「**材料子集验收**」与「**完整跑卷能力**」：前者三项全过**不等于**后者已验证，
> 未解闸前保留 `activation_gate`，不得用于真实出卷。

## 七、产出与红线清单

`forbidden_fields`：建议打法／诉讼策略／胜算／实体结论／定性意见／调解底线／倾向性意见。
每任务自检：六-B 安全（写入前备份 + dry-run）｜否定型结论换第二工具复核｜变体矩阵｜E1004｜本地源引证｜法条精准「第X条」｜当事人信息实地核实｜长标识写全值｜混案识别｜起草前读本地源。
