## 何时用（触发条件）

客户要求**数据不出所 / 涉密 / 内网隔离**时，替代 `03-克隆迁移SOP` 的 Step 4 标准克隆流程。
标准克隆（接受数据出所）仍走 03。

## 流程主干（Phase 0–7）

Phase 0 前置（硬件/网络/账号/**备份基线**）→ Phase 1 骨架落地（dry-run→apply→占位符→残留校验）
→ Phase 2 推理层配置 → Phase 3 技能安装与版本锁 → Phase 4 连接器
→ Phase 5 人格层 L1 加密注入 → Phase 6 知识层 L2 分层导入 + 脱敏门禁
→ Phase 7 LTI 门禁校准 + SOP-03 试点闭环 + 交付留痕

## 六个易错卡点

1. **形态必须先选**（A 单机密文 / B 律所内网 / C 涉密隔离），选错全盘返工；建议先做 A
2. **Phase 0 备份未建 → 禁止任何写入**（无回滚基线不许动手）
3. **版本锁「目标所实装版本」不得留空交付**（空 = 没锁 = 跨所复制必错配）
4. **断网时法条须返回 `statute_text_pending`**，绝不凭记忆编条文
5. **人格层加密后必须 round-trip 解密验证** sha256 一致，未验证不许交付
6. **LTI REJECT=0 才准交付**

## 成熟度（别把规划当现货）

- ✅ 可用：clone-lawtwin.sh、desensitize_check.py、技能版本锁、人格层 openssl+钥匙串加密
- ⚠️ 待建设（M1）：推理层 inference.yaml 抽象、LTI 门禁独立进程化
