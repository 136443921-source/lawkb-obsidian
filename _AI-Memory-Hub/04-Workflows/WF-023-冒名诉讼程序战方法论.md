# WF-023 · 冒名诉讼程序战方法论

> 沉淀自民事买卖合同纠纷被告代理实践：原告起诉状署名与身份证 / 营业执照登记的姓名不一致，构成冒名起诉，依民法典第143条"意思表示真实"要件攻击原告主体适格性。

## 适用场景
- 你方为**被告**，收到诉状后发现：原告署名姓名 ≠ 其身份证姓名 / 营业执照登记姓名（统一社会信用代码第14位校验码亦不一致）。
- 怀疑原告非真实交易相对方（实际买受人为案外第三人），起诉主体存在冒名嫌疑。
- 拟以"程序异议 + 实体抗辩"双线推进：先打掉原告主体资格，再退守实体。

## 核心教义锚点
- **民法典第143条**：具备下列条件的民事法律行为有效——（一）行为人具有相应的民事行为能力；（二）**意思表示真实**；（三）不违反法律、行政法规的强制性规定，不违背公序良俗。
- 冒名诉讼本质：原告"授权委托 / 起诉的意思表示自始未作出"或指向错误主体 → 第143条"意思表示真实"要件不满足 → 起诉缺乏合法基础。
- 程序战主轴：**起诉真实性异议书**（主张原告主体不适格）→ **庭后代理词**（实体抗辩 + 程序异议闭环）→ **授权委托书专项分析**（验证授权链条真实性）。

## 标准步骤
1. **主体核验**：比对起诉状署名、原告身份证号、营业执照统一社会信用代码第14位校验码，锁定姓名 / 主体不一致点。
2. **关键证据固定**：整理能证明真实交易相对方的证据（如通话录音，须已在庭上播放固化），指向实际买受人。
3. **起草起诉真实性异议书**：依第143条主张原告意思表示不真实、主体不适格，请求驳回起诉。
4. **红蓝复核**：文稿过「诉讼文书红蓝复核工作流」（蓝队防御完整性 + 红队预驳回攻击）。
5. **LTI 门禁**：过 LTI 五维 QC（见 WF-002），`REJECT=0` 才准交付。
6. **六维法理逻辑门禁**：补全请求权基础、要件满足、推理链，无断点后落盘。
7. **双轨交付 + 归档**：按 WF-001 双轨生成（修订版 + 干净签字版），同步桌面办案系统 + 本中枢项目页。

## 红线
- 个案卷宗隐私（当事人姓名 / 证件号 / 银行账号 / 证据原件）**严禁进入中枢**，只在本地办案系统处理；本卡仅沉淀方法论。
- 慎用"虚假诉讼"等刑事定性，宁以"存疑 / 主体不适格"表述，避免越界。
- 引用法条须精准到「第143条」，不写"相关规定"；条文以 pkulaw 主源核验，不凭记忆灌。
