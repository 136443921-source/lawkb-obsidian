# WF-084 · 一人公司运营节奏（日 / 周 / 月 / 季排班）

> **来源**：《一人公司运营方案 · 律师数字分身系统 v1.1》§3，老强 2026-09-25 批准由表格转 SOP。
> **适用对象**：这台一人公司全部数字员工（操作工 40 + 心智席位 14 = 54）与唯一股东（老强）。
> **与其他 SOP 的关系**：`WF-数字员工增员减员更新花名册` 管**编制变动**；本 SOP 管**日常运营节奏**，二者互补不冲突。

---

## ① 适用的部门 / 中台

| 中台 | 日常运营主责 |
|---|---|
| 法律服务中台 | 咨询线 / 文书线生产，蓝红队 + QC 两道闸门 |
| 数字资产中台 | 操作工调度、编制登记、知识飞轮运维 |
| 运营中台 | IMA 摄入、周报、self-improve、**经营五段（获客/转化/交付/复购/知产）** |
| 可视化中台 | 9655 驾驶舱监控、监控周报、积分专题 |
| 对外交付合规前置层 | 出件前脱敏 + 免责 **强制前置门禁**（SEAT-14） |

## ④ 产出与验收（四件套）

| 四件套 | 要求 |
|---|---|
| **执行者** | 落到具体席位 / 操作工 id，不写"系统" |
| **时点** | 与 §② 时点对齐，迟到须在下次节奏补记并注明原因 |
| **产出** | 文件 / 报告 / 留痕（memory.md 或日志行），**禁止静默成功** |
| **验收** | 产出 < 60% 视为未达（**静默成功熔断**），须上报并建卡（PREF-009） |

---

## ⑤ 红线

1. **四类 R 动作（对外出件 / 定价发布 / 批量删改 / 新增改造）仅老强可决策**，节奏表不得赋予数字员工自主权。
2. 所有文本制品过 **LTI（REJECT=0 才准交付）**。
3. 个案卷宗禁止入中枢（当事人隐私 / 证件号 / 手机号 / 证据原件内容）。
4. 禁止静默覆盖；写入前 `cp` 备份（**六-B 铁律**，P0-1 扩展至所有写入型自动化）。
5. 蓝队家族四席独立（RULE-BLUE-DISAMBIG）；AI 模拟法官 ≠ QC 审判长（RULE-QCJUDGE-DISAMBIG）。
6. 增减员必须三处同步（花名册 json + md + 运营副本）。
7. 引用法条只能引本地权威源，否则标 `statute_text_pending`。
