# 🧠 WF-046 · 心智卡实战转正四判据取证流水线

> **用途**：把一个 `status: DRAFT` 的角色心智卡，通过**一场真实对抗**转正为 `ACTIVE`。
> **已实践 3 次**：蓝队（2026-09-14）→ 书记员（2026-09-15 凌晨）→ 红队（2026-09-15）。
> **核心价值**：转正不是把 `DRAFT` 改成 `ACTIVE`，是**跑出四项证据**。改字段一秒钟，取证要一场实战。

---

## 一、为什么需要这条流水线

心智卡（人格系统卡）是角色的"行为操作系统"。起草出来只是**设计稿**，未经实战检验的卡：
- 档位参数（如红队 L1-L4）**只写在纸上，没在产物里出现过**
- 四维度/四防御/四攻击**散在 SKILL 正文里，不可观测**
- 弹药是否真能命中**未经验证**

**判据的意义**：把"我觉得它行"换成"这四项可验证的事实已经发生"。

---

## 二、四判据（通用结构 · 四方同构）

| # | 判据 | 要回答的问题 | 取证落点 |
|---|---|---|---|
| **1** | **档位可辨识** | 产物头部是否带 profile 字段？档位与权重是否可观测？ | 产物 frontmatter + 正文头部 `xxx_profile` |
| **2** | **维度可追溯** | N 个维度是否逐维展开、每维附判据与落点？ | 产物第二部分逐维章节 |
| **3** | **反面案例对照生效** | 弹药是否来自真实弹药库（防御要点卡 / 裁判规则卡 / 标本库）？法条是否自本地源核验？ | 产物弹药命中声明 + 法条核验源 |
| **4** | **实抗一轮** | 是否与对手席位真打过一轮，且有回应产物？ | 攻击方产物 → 防御方 v2 回应 |

**四方映射**：
- 🔴 攻（红队）：`attack_profile` / 四攻击维度 / 文书防御要点卡 / 战报 × 蓝队回应
- 🔵 防（蓝队）：`defense_profile` / 四防御维度 / 反面案例库分区 / 体检稿 × 红队战报
- 📝 录（书记员）：`record_profile` / 四记录维度 / 失误标本库 / 三件套 × 跨案验证
- ⚖️ 审（法官）：`verdict_profile` / 四裁决维度 / 审判要件卡矩阵 / 推演裁决 × eval_suite

---

## 三、五步执行

### 步骤 1 · 选靶（不凭记忆，实地读源文件）
- 选**最新、最真实**的现役产物作攻击/检验标的（优先在办真实案件，而非演练卡）
- **必须实地读源文件**（`textutil -convert txt` 抽 docx，或直接读 md），**禁止凭记忆写战报**
- 确认标的版本（如"v5 版"）与已对抗过的版本（如 v4）不同——**新靶子才有新证据**

> ⚠️ 踩坑：演练卡被误当真实案件会引发误判（老强曾纠正"罗江辉案非演练卡"）。选靶时先确认案件属性。

### 步骤 2 · 取弹药（本地源优先，禁止硬凑编号）
- 弹药一级位：`裁判规则库`（取 `negative_note` / `ruling.reject` / `elements`）
- 弹药二级位：`文书防御要点卡` / `标本库` / 法律法规库
- **法条必须自本地法律法规库核验原文**——凭记忆必错（本流水线实证：欲引民诉法解释 209 条论证"补正规则"，核验后发现 209 条实为"明确被告"规则）
- **无对口罩时按降级规则显式标注**（如"无对口 rule_id，不硬凑编号"），**绝不编造**

### 步骤 3 · 出战报（带着 profile 打）
- 头部必带 `{tier, weights}`；按案由选权重预设（红队：evidence_heavy / law_heavy / procedure_heavy）
- S/A/B 三级表四列不可缺：`威胁等级 | 破绽定位 | 攻击逻辑与推演 | 紧急补救建议`
- **S 级 2-3 条封顶**（AI 天然倾向全标 S 级以显自己厉害，须自控）
- 只打**宏观战略漏洞**，严禁在标点、错别字上浪费篇幅
- **每条攻击必须能落地为补救动作**，否则只是在挑毛病

### 步骤 4 · 对手回应（能认的认，该顶的顶）
- 逐条回应，标注：接受 / 部分接受 / 反驳
- **反驳必须落在依据差异上**（如"该条针对 A 情形，本案是 B 情形，性质不同"），不得立场性否认
- 短处**不辩解**（完全接受项直接认）
- 好的攻击会**催生新预案**——把它写成专章（本轮红队逼出「补正应对预案」5 步）

### 步骤 5 · 取证转正 + 埋点回写
- 卡片 frontmatter 补：`status: ACTIVE` / `activated` / `activated_by` / `activation_criteria_met: 4/4` / `activation_evidence`（四项逐条）
- **补齐同构字段**（如红队缺 `symmetry` / `attack_profile` 规范，与另三卡五章对齐）
- 协同效果日志埋点（命中 / 规则 / 问题三要素）
- 跑成熟度脚本 `--refresh`
- 回写：席位绑定配置（单一事实源）→ 中枢项目页 → 每日日志

---

## 四、准入与准出

**准入**：卡片五章已齐（人格定位 / 行为准则 / 输出准则 / 禁区 / 接驳）+ 档位参数已定义。

**准出（全部满足方可转正）**：
- [ ] 四项判据全部达成，且有**产物可指**（不是口头声称）
- [ ] 至少 1 场与对手席位的真实对抗 + 对手回应产物
- [ ] 引用的法条**全部自本地权威源核验**（凭记忆的条文一律标 `statute_text_pending`）
- [ ] 埋点已入协同效果日志，成熟度脚本已刷新
- [ ] 席位绑定配置（单一事实源）已同步，跑 `seat_config_verify.py` 无漂移

## 五、踩坑清单

| 坑 | 表现 | 规避 |
|---|---|---|
| **凭记忆写战报** | 没读源文件就开打，攻击点与实际文书对不上 | 步骤 1 强制实地读源 |
| **法条凭记忆** | 引错条号（209 条实证） | 步骤 2 强制本地源核验 |
| **硬凑 rule_id** | 弹药库无对口罩时编个编号充数 | 降级规则显式标注 |
| **S 级通胀** | 满篇 S 级，失去分级意义 | 2-3 条封顶 |
| **只改 status 不取证** | frontmatter 改了 ACTIVE，但四项判据无产物支撑 | 准出清单五项 |
| **回应全盘接受** | 防御方不敢反驳，对抗变走过场 | 反驳须带依据差异 |
| **选错靶子** | 拿演练卡当真实案件，或拿已对抗过的旧版本 | 步骤 1 确认属性 + 版本新鲜度 |
