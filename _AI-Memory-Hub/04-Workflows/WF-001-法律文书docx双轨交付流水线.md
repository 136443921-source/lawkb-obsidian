# WF-001 · 法律文书 docx 双轨交付流水线

> 沉淀自 2026-09-01（2026）黔0330民初6658号 吊顶案庭后 23-28 号共 6 份文书的生成实践。

## 适用场景
任何需向老强交付的正式法律文书（起诉状/答辩状/代理词/法律意见书/合同/上诉状等）。

## 双轨定义
- **轨一（修订标记版）**：用 python-docx 生成，红字删除线 = 旧表述，绿字 = 新增表述，供老强审阅改动。
- **轨二（干净签字版）**：剔除所有修订标记与 LTI/AI 内部附注，仅留终稿，供打印签字/归档。

## 标准步骤
1. **起草**：按模板要素结构成文，加粗富文本用 `add_run().bold = True`。
2. **LTI 门禁**：先过 LTI 五维 QC（见 WF-002），`REJECT=0` 才准交付。
3. **双轨生成**：`python-docx` 输出修订版 + 干净版两个文件。
4. **归档同步**：双份同步至桌面「小强律师办案系统」对应案件目录 + 本中枢项目页；剔除 LTI/AI 内部附注标记。
5. **回传**：按回传规则（先删旧版 → 文末标回传日期 → 报告新 id + 清理清单）。

## 红线
- 禁止论文化写法：无加粗元信息块、无编号小标题、无独立「法律依据」板块（依据最高法法〔2016〕221号）。
- 草稿态 / 待 LTI 校验 / 两库断开 等提示词须加粗重点提醒。
- 个案卷宗隐私（当事人姓名/证件号/证据原件）不得进入中枢，只在本地办案系统处理。

## 产出
- `<案号>-<序号>-<文书名>-修订版.docx`
- `<案号>-<序号>-<文书名>-干净版.docx`
