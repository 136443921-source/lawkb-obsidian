# WF-146 · 对外文书证据引用四查闸门

> **一句话**：对外文书（投诉书/检举/控告/申请书/代理词/答辩状等）每一条**证据与事实引用**，落笔前必须依次过完**四道闸门**（案号归属核验 → 关键字段图像核读 → 多源交叉印证 → 反偏差自问），一道不过即退回卷宗重核；**进攻性文书四闸全强制**，防守/说理文书至少过①②。
>
> **唯一事实源**：本卡与 `RULE-060` 同属中枢，口径以中枢为准；常驻注入副本 `~/.workbuddy/rules/evidence-four-gates.md` 为派生产物，不得自定义。

---

## 一、为什么铁律防不住（根因，2026-11-22 事故复盘）

> **触发**：投诉书 v2.0/v3.0 连续四轮返工，老强逐条纠正后追问「铁律也防不住你犯错，是什么原因」。

**核心洞察**：现有铁律全是**结果约束**（禁止做什么），缺**过程闸门**（落笔前强制查什么）。铁律告诉我「不许混编」，却没告诉我「怎么在落笔前识别出自己在混编」。我犯的错，是**在「没意识到自己在犯错」的情况下犯的错**，不是「明知故犯」——铁律管得住后者，管不住前者。

| # | 犯的错 | 表层原因 | 深层根因 | 对应铁律为何失效 |
|---|---|---|---|---|
| 1 | 把 6658 锦绣明天案笔录当 6660 雅菲案材料 | 两案被告都叫刘九零、刘维 | **用「字面相关性」顶替「案号归属判定」**——笔录冒出「焦鹏雅菲软装经营部」就当它是 6660，没看开头当事人是丁戊祥、没看「这两个案子」合并提示 | 铁律9「不混编」是禁令，未下沉成「每条引用前必写案号+页码+当事人」的操作步骤 |
| 2 | 「陈争宇」错名、「印章地址无从辨识」 | 采信 PDF 文字层 | **OCR 文字层采信，缺「图像级逐字核读」**——关键字段没回原始页渲染成图核对就下了结论 | 铁律「实地核实」缺前置工序：没规定「六类关键字段必须过图像」 |
| 3 | 「代理函电话=委托人电话」误判 | 起诉状两字段同号 | **单点证据→异常结论，缺多源交叉**——没交叉核对代理函上白纸黑字的「律师电话：15285201499」 | 「否定型结论双证」失效，因为我根本没意识到「电话=委托人」是个需要双证的异常断言 |
| 4（最深） | 反复把中性现象凑成指控 | 起草「进攻性」文书 | **动机偏差**——带着「找对方问题」的目的，把「一字之差/同号/模糊」往不利方向拧 | 任何「禁止」类铁律都管不住认知层面的选择性解读 |

## 二、四道闸门（核心）

每条事实/证据引用，**依次过完四闸才准落笔**，一道不过即退回卷宗重核。

| 闸门 | 治什么 | 强制动作 | 检验标准 |
|---|---|---|---|
| **① 案号归属核验** | 混案 | 写明该材料属于哪个案号、页码、当事人身份；见「两个案子 / 合并 / 另一案」或对方案主体（丁戊祥、锦绣明天等）→ 判为跨案，禁入本案 | 每条引用都能答出「**案号 + 页码 + 当事人**」三要素 |
| **② 关键字段图像核读** | OCR 误差 | 人名 / 身份证号 / 电话 / 金额 / 机构名 / 日期**六类字段**，必须渲染原始 PDF 页为图逐字核读，禁只凭文字层；文字层与图像不一致**以图像为准** | 六类字段各留一张核读记录 |
| **③ 多源交叉印证** | 单点推断 | 任何「A=B 或 A≠B」断言（同号 / 不符 / 不一致），须第二份独立材料交叉印证；**单点不得推「异常」** | 每个异常断言都挂「第二来源」 |
| **④ 反偏差自问** | 动机偏差 | 落笔前先问「这会不会是我为了撑投诉/控告过度解读？」；中性现象（一字之差 / 同号 / 模糊）**默认采最中性解释，宁缺毋滥** | 凑不实的指控，宁可删不硬凑 |

## 三、分级执行（按文书性质）

| 文书性质 | 示例 | 执行闸门 |
|---|---|---|
| 🔴 **进攻性**（高风险） | 投诉书、检举、控告、信访、刑事报案 | **四闸全强制**，任一不过即退回 |
| 🟡 **防守/说理** | 答辩状、代理词、质证意见、上诉状 | 至少过 **①②**；涉及「对方/第三人异常」断言时再补③④ |
| 🟢 **内部底稿** | 事实卡、复盘、作战室笔记 | 可豁免，但须标「未经四查，不得对外引用」 |

---

## 四、标准步骤

1. 起草前，先把要引用的证据/事实清单列出来，逐条标「案号 + 页码 + 当事人」三要素（闸门①）。
2. 六类关键字段（人名/身份证号/电话/金额/机构名/日期）回卷宗原始 PDF 页，渲染成图逐字核读（闸门②）。
3. 凡「A=B / A≠B」异常断言，找第二份独立材料交叉印证（闸门③）。
4. 落笔前自问动机：这条指控是不是我把中性现象往不利方向拧了？（闸门④）。
5. 全部通过后，再走 LTI 双闸门（`RULE-060` §二）与 WF-130 自证七项。

---

## 五、红线

- **禁凭记忆写关键字段**：六类字段必须回卷宗/原始材料实地核读，不得凭上下文或记忆占位。
- **禁只凭 OCR 文字层下结论**：关键字段文字层与图像不一致时，以图像为准，否则判为「未核读」。
- **禁单点推异常**：任何「同号/不符/不一致」的异常断言，无第二来源即不成立，宁删不凑。
- **禁跨案引用**：材料归属另一案号（见合并笔录/对方主体）即禁入本案，即便字面相关。
- **反偏差铁律**：进攻性文书起草时，默认对「模糊/一字之差/同号」采最中性解释，不硬凑指控。

## 六、与既有铁律的关系（互补，不取代）

| 既有铁律/卡 | 管什么 | 本卡补什么 |
|---|---|---|
| 铁律9（6658/6660 不混编） | 结果禁令 | 补「落笔前必写案号+页码+当事人」的**过程闸门**，防「没意识到在混编」 |
| WF-130 自证七项 | 分析类交付自证 | 本卡四闸是自证七项在**证据引用**环节的前置细化 |
| 「否定型结论双证」铁律 | 否定结论须双证 | 闸门③把双证前置到「异常断言」落笔前 |
| 「单点证据须实证」铁律 | 单点结论须实证 | 闸门③的同源强化 |
| LTI 双闸门（RULE-060） | 交付前质量门禁 | 本卡四闸是**起草前/落笔前**闸门，LTI 是**交付前**闸门，前后夹击 |
| 铁律「实地核实」 | 实地核实要求 | 闸门②补「六类字段必须过图像」的前置工序 |
