# WF-002 · 法条 LTI 九维 QC 门禁

> 每份法律文书交付前必须通过的文本监控器门禁。任一维度 REJECT 即不得交付；`REJECT=0` 才准交付。
> **真源定义**：`lti_dimensions_v9.json`（v4.9.0，upgraded_from v4.8.1 五维）。本工作流须与该真源保持一致——修改维度/阈值/版本前**先读真源**，不得凭记忆或旧版本（如 v4.8.1 五维）填写。

## 九维定义
| 维度 | 含义 | 类型 | 校验要点 |
|---|---|---|---|
| **R** (Rule) | 法条真实性 | 基座 | 条号/条文须真实存在，优先以 pkulaw（北大法宝）/华宇元典/qcc-legal 多源核验，绝不凭记忆灌条文 |
| **L** (Logic) | 法理逻辑 | 基座 | 请求权基础、要件满足、推理链无断点 |
| **C** (Consistency) | 一致性 | 基座（自动） | 金额（301）、名称（302）、案号（304）等全文一致，无前后矛盾 |
| **T** (Trace) | 溯源 | 基座（部分自动） | 每条关键依据标注来源（法条/判例/内规），可回溯 |
| **P** (Procedure) | 程序 | 基座（自动） | 程序性事项（期限/管辖/送达/举证）无误 |
| **S** (Strategy) | 策略契合度 | 扩展 | 服务本案核心争点与诉讼目标，不节外生枝、不暴露己方弱点 |
| **V** (Risk) | 风险预判 | 扩展 | 识别被驳回/不予准许风险点，预判对方反击位 |
| **W** (Wording) | 表达规范 | 扩展（部分自动） | 法言法语中性、无主观溢美词、无冗余 |
| **E** (Evidence) | 证据闭环 | 扩展（部分自动） | 每项事实主张能指到具体证据，无"主张飘空"；当事人意思/授权类事实须建陈述时间轴+矛盾扫描（E1004） |

> 基座五维（R/L/C/T/P）承接 v4.8.1；**S/V/W/E 为 v4.9.0 扩展维度**。自动维：C、P；部分自动：R、T、W、E；手动：L、S、V。
> 门禁：「逐维勾选；任一 ❌ 即阻断交付，须归零后方可交付；⚠️ 属提交前补强，补完即归零；REJECT = 0 才准交付。」

## E 维度·矛盾陈述扫描门禁（E1004 · 2026-10-10 新增）

> **触发**：6658 司法制裁评估误判根因——据开庭笔录单句"我委托了律师"定论"授权真实获本人承认"，忽略丁戊祥庭前四否认（两份手书 + 两份录音）。与「否定型结论铁律」**阴阳对称**：那条防"单点否定结论未实证"（假阴性），本条防"单点肯定结论未实证"（假阳性）。
> **机制**：E 维度由纯手动调整为**部分自动**（同 T/W）。`lti_qc9.py` 的 `check_E` 在检测到当事人意思 / 授权类肯定表述（获本人承认 / 已追认 / 真实意思为 / 授权真实…）且全文无"矛盾扫描"标记（陈述时间轴 / 矛盾 / 悬而未决 / 未认定授权有效…）时，自动 ⚠️ WARN E1004 提示；**不阻断**，交人工确认。该检查项同时列入 E 维度人工门禁清单。

**下笔前必做五步（当事人意思 / 授权类事实）**：
1. 🔴 **建陈述时间轴**：同一争点，把该当事人全案各时点陈述（通话 / 书面 / 录音 / 笔录）列成轴，不止看一处。
2. 🔴 **矛盾即悬置**：时间轴 ≥2 处不一致 → 该事实标"悬而未决 / 争议中"，禁写"已确认 / 获承认"，须注矛盾点。
3. 🔴 **法院采信三分层**：仅「法院实质认定」可作已确认；「当事人陈述」可能被矛盾 / 未采信；「证据未入定案册」≠ 对立陈述被证实。
4. 🔴 **未采用 ≠ 自认成立**：法院不采用某录音 / 书证，仅使该材料不能进事实认定，不验证对立陈述；法院沉默 ≠ 授权有效（典型"程序回避"）。
5. 🟢 **单点结论须实证**：任何"授权真实 / 已追认 / 真实意思为 X"类肯定结论，下笔前须完成 1-4 并留痕。

## 标准步骤
1. 文书草稿完成后调用 LTI 文本监控器（v4.9.0，九维 R/L/C/T/P/S/V/W/E；R001–R020 / R016 / R101–R116 / C301–C304 / T501–T503 / P401–P404 / S701–S703 / V801–V803 / W901–W903 / E1001–E1004）。
2. 逐维检查，记录各维度 PASS / ⚠️待补强 / ❌ REJECT。
3. 仅当九维全部 PASS 或仅余可补强项（`REJECT=0`）才允许进入 docx 双轨交付（见 WF-001）。
4. 若有 ❌ REJECT：回到起草环节修正 → 重新过门禁，直至 `REJECT=0`。

## 红线
- **本地源引证铁律**：仅引用本地法律法规库源，否则标 `statute_text_pending` 不得引为文档源；权威数据绝不静默覆盖。
- 引用法条须精准到「第X条」，不写"相关规定"等模糊表述。
- 当事人信息须从桌面原始材料（如起诉状 PDF）实地核实填写，不凭记忆占位。
- **维度/配置真源铁律（v4.9.0 新增）**：引用 LTI 维度、版本、阈值须以 `lti_dimensions_v9.json` 为准，不得凭记忆或本工作流旧版本（如 v4.8.1 五维）填写——本工作流曾因未对齐真源而误写"五维"，已立经验卡警示（见相关笔记）。
