# WF-028 · 知识飞轮卡库接线

> 把一个 AI 技能接上知识飞轮卡库，使其从"凭模型通用知识裸判"转为"可回溯卡源的规则裁判"。

## 一、适用场景
- 某技能自述或实测**未消费卡库**（典型症状：SKILL.md 写"依赖内置知识，无需额外资产文件"）。
- 新建卡组（审判要件卡 / 裁判规则卡）后，需要把消费方技能接上。
- 周期性普查：批量检查 `~/.workbuddy/skills/*/SKILL.md` 的卡库引用数，找出"零挂载"技能。

## 二、目的
消除"有弹无枪"——让技能的输出**可回溯到 rule_id 卡源**，而非凭模型通用知识裸判。

## 三、制品路径（固定）
- 卡库根：`/Users/chenyouqiang/Documents/LawKB/知识飞轮系统/06-沉淀/裁判规则库/<域>/`
- 经验卡：`.../02-提炼/经验卡片/`
- 案由路由（**定性入口**）：`.../06-沉淀/裁判规则库/案由路由/`（R-AY-*）
- 调用记录落点：`.../05-调用/<对应域>调用记录/`

## 四、五步 SOP

### ① 接线诊断（引用计数法）
```bash
F=<技能路径>/SKILL.md
for k in 裁判规则库 审判要件 知识飞轮 06-沉淀 02-提炼 案由路由 review_step elements burden_of_proof ruling negative_note geo_scope; do
  printf "%-16s %s\n" "$k" "$(grep -c "$k" "$F")"
done
```
- 全部为 0 → **零挂载（有弹无枪）**，必须接线。
- 部分非 0 → 已接线，检查字段级消费是否完整（尤其 `negative_note` / `geo_scope` 常被漏）。

### ② 域卡组盘点（先查再接，禁凭记忆）
```bash
cd /Users/chenyouqiang/Documents/LawKB/知识飞轮系统/06-沉淀/裁判规则库
grep -rl -E '^type:.*审判要件' <域>/ | wc -l     # 某域审判要件卡数
ls <域>/*.md | wc -l                              # 某域规则卡总量
```
- ⚠️ **必查"域覆盖匹配度"**：审判要件卡域分布不均。若目标案由**无对口审判要件卡**，须写明降级规则，**不得让技能"查不到卡就退回通用知识裸判"**。

### ③ 资源段重写
替换原"无需额外资产"类自述为：
1. **作废声明**：引原文 + 标注"已作废" + 作废日期与原因。
2. **域卡组表**：域 / 目录 / 审判要件卡数 / 该域总卡数 / 号段。
3. **定性入口**：强制先走 `案由路由/`（R-AY-*）定案由，再进域卡组。**案由定性错，后续检索全跑偏**。
4. **检索指令模板**（可执行 bash，含绝对路径）：案由定性 / 环节定位 / 审判要件卡清单 / 精读字段。
5. **域覆盖诚实提示**：本批卡覆盖哪些案由、不覆盖哪些、无对口卡时降级消费什么。

### ④ 各工作流步骤注入检索指令（按阶段绑定消费字段）
| 工作流阶段 | 消费字段 | 硬约束 |
|---|---|---|
| 定性 / 立案审查 | `review_step`、案由路由 R-AY-* | 先定案由；**禁自拟要件** |
| 事实调查 / 证据审查 | `elements[].name/desc`、`burden_of_proof` | 逐项涵摄 E1..En，标「已证 / 未证 / 存疑」；明示举证责任归属 |
| 法律发现 / 辩论 | `ruling.support` + `ruling.reject`、**`negative_note`** | support/reject **成对呈现**；negative_note 翻车标本转负向检验（含金量最高） |
| 裁判 / 输出 | `ruling`、`geo_scope`、卡内法条依据 | **禁无源说理**，须回溯 `rule_id`；跨省援引须核当地口径 |

### ⑤ 版本与验证
1. frontmatter `version` 升版 + `updated` 改当天；变更日志录入（含作废项说明）。
2. 复核引用计数由 0 变正。
3. **实战验证**：拿一个真实在办案件跑一遍，产出调用记录落 `05-调用/<域>调用记录/`，命名 `YYYYMMDD-<案号/事项>-<技能>v<版本>接线验证.md`。
4. **LTI 校验**（铁律）：所有输出经 `wrap_output` 校验，未通过禁止输出。

## 五、铁律与坑
- **先备份再改**（六-B）：`cp -n <SKILL.md> /tmp/<name>-bak-$(date +%Y%m%d-%H%M)/SKILL.md`。
- **防误套域**（接线后**新增**风险）：接线前无卡可套，接线后可能把"商品房买卖 / 保险合同"要件误套到一般买卖 / 装饰装修。资源段必须写明域边界 + 降级规则。
- **geo_scope 分区**：审判要件卡多为「贵州省·贵州高院口径，跨省援引须核当地口径」；案由路由卡多为「全国·最高法统一口径」。**引用须区分，不得混为一谈**。
- **法条回源**：卡内法条已元典核填（含施行日期 / 时效），正式文书引用前仍按卡内「官方核验指引」二次核对 + LTI 校验。
- **禁凭记忆写卡数量 / 号段**：每次接线前必须实地 grep 复测（曾记忆记 13 张、实测 353 张，严重失真）。
- **只改 `~/.workbuddy/skills/<技能>/SKILL.md` 文本，不碰 `workbuddy.db`**。

## 六、实战案例（2026-09-08 · 法官心智 v3.0.0）
- 接线前：卡库相关引用**全为 0**，自述"无需额外的脚本或资产文件"。
- 接线后：引用数 裁判规则库 9 / 审判要件 12 / review_step 7 / 案由路由 5 / negative_note 5。
- 实战增量：R-AY-001 命中 6658 吊顶案 → 挖出「交易含安装 → 定性装饰装修 → 属建设工程 → **不动产专属管辖**（民诉法§34①＋解释§28）」抗辩链，而纯买卖 / 承揽仅一般合同管辖（§24）。此为零挂载时不可能提出的战术点。
- 诚实标注：合同域审判要件卡为商品房＋保险，与吊顶案不适配，已降级消费 R-HT-110/116/125/231 并标注。
