# WF-128 · 协同效果日志命中率口径与轨迹卡命中埋点

> 把「知识飞轮 → 小强律师分身」协同质量的度量口径固化：命中率统计覆盖飞轮三类知识资产（经验卡 / 裁判规则 / 思维轨迹卡），并定义「轨迹卡命中：<卡名>」埋点格式。

## 一、适用场景
- 维护或扩展 `05-调用/协同效果日志.md` 的命中率统计口径。
- 每次法律实务问答/交付后追加埋点行、或月度「协同效果月报」自动化（每月28日23:30）汇总时，需统一命中判定标准。
- 飞轮新增知识资产类型（如思维轨迹卡）时，补口径使其纳入统计，避免"已沉淀却永不命中"的虚假缺口。

## 二、目的
消除口径盲区：轨迹卡已沉淀 24 张（截至 2026-10-28），但短反馈回路扫描显示其「命中」长期为 0（在 05-调用 全域 grep 卡名/topic 0 命中），并非真无价值，而是调用从未以标准格式写入日志。纳入口径后，命中率才完整反映飞轮三类资产的协同效果。

## 三、制品路径（固定）
- 命中率唯一数据源：`/Users/chenyouqiang/Documents/LawKB/知识飞轮系统/05-调用/协同效果日志.md`
- 月度汇总：`.../05-调用/协同效果月报-YYYY-MM.md`（每月28日自动化生成）
- 推送/反馈佐证：`.../05-调用/知识推送日志-YYYY-MM.md`、`.../05-调用/短反馈回路运行日志.md`

## 四、三类命中埋点格式（核心 SOP）
每行埋点格式：`- [YYYY-MM-DD HH:MM] 类型；<命中字段>；问题:<问题摘要>`

| 命中类型 | 字段格式 | 说明 |
|---|---|---|
| 经验卡命中（既有） | `命中:经验卡片-<卡名>` | 检索 02-提炼/经验卡片/ 命中 |
| 规则命中（既有） | `规则:R-XXX` 或 `命中:裁判规则库<R-id>` | 检索 06-沉淀/裁判规则库/ 命中 |
| **轨迹卡命中（2026-10-28 新增）** | `轨迹卡命中：<卡名>` | 实际复用某张思维轨迹卡（推理链/排查链）并产生实质输出时记录 |

**轨迹卡命中判定三要素：**
1. **触发条件**：某次问答/交付**实际复用**了某张思维轨迹卡（如 R-LN-129 静默失效排查推理链重建、债务未清偿债权人撤销权防控、自动化真跑回写双层判别等），且该卡推理链/排查链对输出有实质贡献。
2. **统计归属**：该格式行计入「命中行数」，**分子+1、分母+1**（与经验卡/规则命中同列，不单设分母）。
3. **不命中边界**：仅提及、未实际复用推理链 → 不记此行（避免虚高）。

## 五、命中率与月报统计逻辑
- **命中率 = 命中行数 / 埋点总行数**（分母=总问答/交付行数）。
- **命中行数 = 经验卡命中 + 规则命中 + 轨迹卡命中**（含「轨迹卡命中：<卡名>」行）。
- **采纳率/被修改率**：另行采集用户反馈信号（采纳/有用/采纳并修改），无反馈不计入分母（防虚高）；详见日志「采纳率/被修改率 采集模板」。
- 月报自动化口径同步：扫描埋点明细时，命中即"经验卡或规则或轨迹卡命中——含「轨迹卡命中：<卡名>」行"。

## 六、铁律与坑
- **六-B 备份前置**：修改 `协同效果日志.md` 单源文件前，必须 `cp -n` 时间戳备份并 `ls -l` 核对字节数一致，异常即回滚（源自事故 ERR-20260810-001）。本次扩展已备份至 `/tmp/协同效果日志_20261028-233700.md`。
- **不虚高**：轨迹卡命中须"实际复用推理链"，反对凑数；未复用仅提及不计。
- **口径漂移防护**：新增知识资产类型时须同步更新本 WF 与日志顶部口径说明、埋点明细速查、月报统计逻辑三处，保持一致。
- **否定型结论双源**：断言"轨迹卡命中=0"须附检索式与变体清单（如 `轨迹卡-R-LN-129`、`R-LN-129` 等多变体 grep），不得单次命中 0 即下结论。
