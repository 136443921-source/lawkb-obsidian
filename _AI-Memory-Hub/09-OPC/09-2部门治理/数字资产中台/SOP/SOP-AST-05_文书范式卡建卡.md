## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检——引总册 §三 / §五。
- 格式：必符文书格式铁律——引总册 §八。
- 资产治理：LawKB 独立仓库，中枢 git `backfill.py`——引总册 §七。

## 五、异常处理

| 异常 | 处理 |
|---|---|
| LTI REJECT≠0 | 退回修改 |
| 格式铁律不符 | 重排，不得交付论文化写法 |
| 静默成功（产出不足） | 熔断中止 |
