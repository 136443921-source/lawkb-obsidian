## 一、目的与适用范围

- **目的**：把法院《类案审判要件指南》类 PDF 拆解为知识飞轮"审判要件卡"并六层挂载落库，供模拟法庭法官智能体喂"正向裁判规则"。
- **适用范围**：拿到审判要件指南 / 裁判指引 / 类案指南类 PDF，需入库裁判规则。
- **不适用**：非要件类卡（走对应 AST SOP）。
- **源流程（权威）**：`审判要件卡拆卡流水线` — 路径 `~/.workbuddy/skills/审判要件卡拆卡流水线/SKILL.md`　★ **正文以该源为准**

## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0 才准交付）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检五条（cp 备份 / dry-run）——引总册 §三 / §五。
- 法条引用：pkulaw 主源 verbatim 回填，本地源引证，否则标 `statute_text_pending`——引总册 §六。
- 资产治理：LawKB 独立仓库，中枢 git `backfill.py`，跨案隔离——引总册 §七。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| LTI REJECT≠0 | 退回修改，不得带草稿态对外 |
| 卡号冲突 / 重名 | 查号器重取，禁覆盖（引 `lawkb-rule-id-governance`） |
| 法条待回源 | 标 `statute_text_pending`，不引为文档源（引 `statute-pending-clear`） |
| 静默成功（产出不足） | 熔断中止，不写盘 |
