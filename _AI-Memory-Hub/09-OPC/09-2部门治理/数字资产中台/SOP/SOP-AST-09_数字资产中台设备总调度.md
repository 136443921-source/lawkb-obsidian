**版本**：v0.1　**日期**：2026-09-24　**Owner**：数字资产中台（数字资产运维官·KF-DEV 设备主机；C 承接）　**性质**：部门业务流程 SOP（纯文档，不碰配置）
**编号**：SOP-AST-09　**落点**：`部门治理/数字资产中台/SOP/SOP-AST-09_数字资产中台设备总调度.md`
**维护**：修订须总经理执行、老强批准；与源规范冲突以总册 + 数字资产中台·部门规章制度为准

> 链接式 SOP：本册不重抄各设备流程正文，只写"何时调 / 谁调 / 过哪道门禁 / 落哪"。流程细节以各设备接入 SOP（SOP-AST-10）与资产运维官 skill 为准。本 SOP 为数字资产中台设备的**统一调度入口（设备总线）**，禁止智能体绕开门禁直连设备产制品。

---

## 一、目的与适用范围

- **目的**：规范数字资产中台设备的统一调度（当前 **KF-DEV 知识飞轮设备**），确保**设备总线单一入口**、制品统一过 LTI 门禁、统一落点与资产治理（LawKB 独立仓库 + 中枢 `backfill.py`）。
- **适用范围**：所有经数字资产中台设备产出的制品（知识卡 / 回补产物 / 驾驶舱刷新 / 资产登记册条目）。
- **不适用**：纯内部笔记 / 不产制品的会话；卡族 CRUD 流程本身（走 SOP-AST-01~08）。
- **源规范（权威）**：`数字资产中台·部门规章制度.md` §二（知识飞轮设备运维职责）/ §三-B（知识飞轮设备）；`资产运维官` skill（席位心智与作业手册 v1.0）；横向铁律总册。

## 三、标准步骤（链接式 · 设备总线单一入口）

| 步 | 动作（调哪个 / 谁调） | 责任方 | 产出落点 | 源规范章节 |
|---|---|---|---|---|
| 1 | 提调度申请（设备ID=KF-DEV + 输入材料 + 关联项目），设备主机（数字资产运维官）派工授权 | 发起方 / 设备主机 | 调度工单 | 规章制度 §二 |
| 2 | 设备总线路由到对应设备接入 SOP：KF-DEV → **SOP-AST-10** | 设备总线（数字资产中台调度职责） | — | 各设备 SOP |
| 3 | 设备产出草稿态制品 + 写 `制品元数据 frontmatter`（设备_id: KF-DEV / 制品类型 / 门禁状态 / 落点…） | 操作工（知识飞轮系统 / 资产运维官） | 制品文件头 | 资产运维官 skill |
| 4 | 设备总线**统一过 LTI（双轨门禁）**：轨 A 本地 `lti_verify.py`；轨 A 缺失 / 未过 → 轨 B 经 qcc-legal / pkulaw 权威源实拉核验；任一 REJECT=0 才准交付；各设备不得自过 | 监督层（LTI） | 门禁通过 | 总册 §二 / 业务中台方案 §3.6 |
| 5 | 资产治理入库：LawKB 独立仓库物理隔离 + 中枢 git `backfill.py`（禁裸 git）+ 双目录同步；知识卡进卡库（06-沉淀） | 运营中台协同 | LawKB + 中枢 | 总册 §七 |
| 6 | 资产登记册 SSOT 回写（KF-DEV 产出计入 `asset_registry.json`，owner=数字资产运维官） | 设备主机（资产运维官） | 登记册 | 资产运维官 skill §八 |
| 7 | 资产健康看板 / 飞轮驾驶舱刷新（在制 / 产能 / 门禁通过率 / 漂移） | 可视化中台协同 | 驾驶舱 | 资产运维官 skill §七 |

> **红线（单一入口）**：数字资产中台设备**禁止智能体绕开门禁直连产制品**；任何制品须经本总线步骤 1→4→5。

---

## 四、质量门禁（强制）

- 文本制品：必过 LTI（双轨门禁，REJECT=0；本地源缺失走轨 B 权威源实拉）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检五条——引总册 §三 / §五。
- 构建产物：必过静默成功熔断（产出 < 期望 60% 即中止）——引总册 §四。
- 法条 / 内规引用：必走 pkulaw 主源回填，禁凭记忆——引总册 §六。
- 资产治理：LawKB 独立仓库，中枢 git `backfill.py`——引总册 §七。
- 制品元数据：未带 frontmatter 的制品不得入库 / 不得上屏——引资产运维官 skill。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| 绕门禁直连（未走总线） | 退回，制品不得出库；记入治理复盘 |
| LTI 两轨均 REJECT≠0 | 退回修改，不得带草稿态对外 |
| 本地源缺失未转轨 B | 强制启用降级轨 B（qcc-legal / pkulaw 实拉），不得因源缺失阻断交付 |
| 静默成功（产出不足） | 熔断中止，不写盘，报告设备主机 |
| 四类 R 触发（对外终稿 / 批量删改） | 立即移交老强，本部门不决策（引总册 §一） |
| 资产登记册与实测不符 | 判文档漂移，回写本册（引资产运维官 skill 铁律） |
