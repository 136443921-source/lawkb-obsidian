## 四、防冲突铁律（部门治理层专用）

1. **红线不进部门文件**：四类 R / LTI / 六-B / 静默成功 一律"引总册 §X"，部门文件禁止重抄、禁止改口径。
2. **SOP 链接式不重写**：部门 SOP 只写"何时调 / 谁调 / 落哪 / 门禁"，流程正文链接源 skill，不与原文漂移。
3. **模板分两类**：岗位型中台（有数字员工，如业务 / 可视化中台·IT 运维员）用三-A 章节；流程型中台（无数字员工，如数字资产中台）用三-B 章节。
4. **DRAFT 如实标**：QC-Controller 审判长双模等 DRAFT 岗位，规章制度 / SOP 中须标 DRAFT，不写定型。
5. **效力层级**：公司章程 ＞ 横向铁律总册 ＞ 部门规章制度 ＞ 部门 SOP。
6. **双目录同步**：中枢 `09-OPC/部门治理/` 为主存，workspace 副本为工作态；以中枢为准。
7. **对外经营线引用**：商业运营 SOP 总册（`09-OPC/商业化运营/商业运营SOP总册_对外经营线.md`）为对外经营横向册，部门文件引用其业态 / 经营流程时"引 商业化运营/总册 §X"，不重抄；三业态产品线定义卡同目录。
