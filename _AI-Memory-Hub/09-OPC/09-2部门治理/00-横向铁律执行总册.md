## 0. 本册定位（必读）

> 本册是**操作化引用册**，不是章程重述。每条铁律给"触发 / 动作 / 门禁 / 违例处理"四件套，权威口径以 `公司章程.md` 对应章节为准。
> **部门规章制度 / 部门 SOP 一律"引用本册编号"，禁止在部门文件里重抄、禁止改口径**——这是防知识冲突打架的核心护栏。

**效力层级**：公司章程（宪法）＞ 本册 ＞ 部门规章制度 ＞ 部门 SOP。

## 一、四类 R 动作红线（公司级最高闸门）

**权威源**：公司章程 §3　**性质**：仅老强可决策

| 编号 | R 动作 | 触发场景 | 动作要求 | 违例处理 |
|---|---|---|---|---|
| R-1 | 对外出具法律意见 / 文书**终稿** | 任何对外法律文本定稿 | 须老强（执业律师）终确认，标"AI 辅助 / 待律师确认"不得冒用署名 | 回滚 + 治理复盘记过 |
| R-2 | 商业化定价 / SKU / 规则包发布 | 新定价 / 新 SKU / 规则包上架 | 须老强拍板；唯一收口 `05-商业化运营备忘录-v1.0.md` | 回滚 + 复盘 |
| R-3 | 删除 / 批量改写任何单源文件 | rm / 覆盖 / 批量改写 | 须老强批；执行前 `cp -n` 防覆盖至 `/tmp/时间戳` | 回滚 + 追责 |
| R-4 | 新增 / 改造子系统 | 新建 skill / 自动化 / 管线 | 须老强批；派发总经理 A、LTI R（回归） | 回滚 + 复盘 |

> 总经理越权即违规：回滚 + 报告老强 + 治理复盘记过（详见总经理职权 §3）。数字员工不适用自主决策四类 R。

## 二、LTI 交付门禁（文本制品前置强制）

**权威源**：公司章程 §4　**性质**：交付前置，REJECT=0 才准交付

| 项 | 执行要求 |
|---|---|
| 触发 | 任何文本制品（含校验报告 / 清单 / 草稿）写入磁盘 / present 前 |
| 动作 | 必过 LTI（R001–R116），**REJECT=0 才准交付** |
| 五维 QC | R 法条真实性 / L 法理逻辑 / C 一致性（金额·名称·案号）/ T 溯源 / P 程序 |
| 六维法理门禁 | 教义路径 + 要件映射 + 举证责任 + 时效 + 管辖 + 效力层级 |
| 回归基线 | 改门禁后必跑 `tests/test_lti.py` 三连（T1 BLOCK / T2 PASS / 真实文书无误报） |
| 草稿态标示 | 未过 LTI / 草稿态须加粗标红重点提示，不得带权威源光环对外 |

## 五、破坏性操作预检（五条）

## 八、商业化收口 + 文书格式铁律

**权威源**：公司章程 §8　**性质**：对外收口 / 格式强制

| 项 | 执行要求 |
|---|---|
| 商业化唯一收口 | 新产出（定价 / SKU / 客户线索 / 交付 SOP / 知产 / 制品）一律追写 `05-商业化运营备忘录-v1.0.md`，不另起新文件；对外前脱敏 |
| 文书格式铁律 | 据最高法法〔2016〕221号：A4 / 仿宋三号 16pt / 标题宋体 22pt / 行距固定 28 磅 / 页边距上 3.3 下 3.2 左 2.7 右 2.4cm / 页脚居中页码 |
| 禁止论文化写法 | 无加粗元信息块 / 无编号小标题 / 无独立法律依据板块 |
| 交付物默认 docx | LTI 未过 / 草稿态提示须加粗标红 |
| 红线 | `~/lawtwin-open/` 仅放 L0，绝不进业务产物 |

> **治理层 SOP 收口（互补）**：对外经营业态的治理 SOP 与三业态产品线定义卡另收敛至 `09-OPC/商业化运营/`（`商业运营SOP总册_对外经营线.md` + 三份产品线卡），权威源为 `公司章程.md` §8.1/§8.2；本条仅管"产出收口 + 格式"，二者互补不冲突。
