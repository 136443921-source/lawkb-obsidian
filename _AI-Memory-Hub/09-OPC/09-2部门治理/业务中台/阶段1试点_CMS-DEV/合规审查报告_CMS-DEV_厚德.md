## 五、整改建议（可交付动作）

1. **方案补正**：依慈善法第11条补全募捐方案法定要素，报民政备案（第23条）。
2. **资格核验**：确认公开募捐资格在有效期内，联合劝募须以资格为前提（第22条）。
3. **财务闸门**：依《民间非营利组织会计制度》建分账+年度预算比例预警。
4. **公开台账**：依慈善法第77条建季度信息公开推送机制。
5. **内规回填**：小德依《合规管理手册（2025版）》将上表"内规对应"补为精准条号（R1内规精准，禁写"相关规定"）。
