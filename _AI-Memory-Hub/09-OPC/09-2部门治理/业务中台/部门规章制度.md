## 一、部门定位与归属

- **部门名**：业务中台
- **职能归属**：业务 中台（OPC 四大中台之首）
- **汇报线**：→ 总经理（律所主任·管理合伙人）→ 老强（超级管理员·唯一股东）
- **部门定位一句话**：分身系统诉讼与非诉法律业务的**交付中枢**，承接谈案 / 出庭 / 非诉审查 / 慈善合规 / 模拟法庭推演等核心业务，向总经理汇报、受监督层（LTI）门禁。

## 二、部门职责边界（与章程 RACI 对齐）

| 职责 | 性质（A/R/C/I） | 说明 | 是否触四类 R |
|---|---|---|---|
| 诉讼业务交付（谈案 / 出庭准备 / 攻防策略） | A | 蓝队诉讼律师主导 | 对外终稿→是（R-1 须老强） |
| 非诉业务交付（合同审查 / 非诉文书） | A | 蓝队非诉律师主导 | 对外终稿→是（R-1 须老强） |
| 对抗式挑刺（预驳回攻击 / 内部战报） | A | 红队律师主导 | 否（内部） |
| 裁判推演（审判要件 / 模拟裁决） | A | AI 模拟法官主导 | 对外裁决→是（R-1 须老强） |
| 庭审记录（笔录 / 证据台账） | A | 模拟法庭书记员主导 | 否（内部） |
| 慈善合规审查（业务 / 财务 / 联合劝募） | A | 小德慈善合规主导 | 对外合规报告→是（R-1 须老强） |
| 庭审准备辅助（大事记 / 证据整理） | A | 蓝队律师助理主导 | 否（助理定位） |
| 程序质控 / 质量闸门（QC） | A | QC-Controller 审判长双模（DRAFT） | 否（内部） |
| 内部派工协调 | C | 承接总经理派工 | 否（总经理 A/R） |
| 知识入库调度 | C | 飞轮摄入 / 回传（协同数字资产中台） | 否（LTI R） |
| 模拟法庭科室统筹（庭长派工 / 推演配置 / 归档回写） | A | AI 模拟法官（庭长）主导，书记员协同；QC 虚线借调质量闸门 | 否（内部） |
| 庭审战情室复盘（中台级共享） | A | QC 双模审判长（参谋长）主导，跨工作流复用 | 否（内部） |
| 设备调度（设备总线·四台设备统一挂载 / 派工 / 制品过门禁） | A（总经理派工；C 承接） | 设备总线单一入口（SOP-BUS-05）；CLM/CMS/Cont-LCM/MCM 直连禁止，须总线调度；制品统一 frontmatter（方案 §3.5） | 否（内部） |

> 凡涉及四类 R（对外出件 / 定价发布 / 批量删改单源 / 新增改造子系统）的职责，本部门不得自主决策，须移交老强（引总册 §一）。

### 三-B（模拟法庭科室 · 业务中台子科室）· 成员与归属

> 模拟法庭科室为业务中台**子科室**（仿法条银行科室 B 形态），由 AI 模拟法官**兼任庭长**；采用「实线 + 虚线 + 中台共享」三态归属，权属顺、零章程改动、不增编。

| 成员 | 归属态 | 成熟度 | 科室角色 | 红线 / 边界 |
|---|---|---|---|---|
| 数字员工·AI 模拟法官（庭长） | **实线**（科室负责人） | 98/100·最高 | 实体裁判推演 + 科室派工/配置/归档 | 四类 R + 禁以"审判长"名义对外出裁决 |
| 数字员工·模拟法庭书记员 | **实线** | 64/100·M4 | 庭审记录（到庭/纪律/证据状态机/三件套） | 四类 R 须老强拍板 |
| 数字员工·QC-Controller 审判长双模 | **虚线借调**（实线仍归中台/总经理） | 78/100·M3（ACTIVE） | 推演时质量闸门（程序质控），只闸程序不闸裁判 | RULE-QCJUDGE-DISAMBIG；推演结束虚线解除 |
| 庭审战情室（中台级复盘功能） | **中台级共享**（非科室成员） | — | 战情复盘（参谋长=QC），可服务多工作流 | 参谋长只做程序/态势复盘，不闸实体裁判 |

> **单元不拆解**：模拟法官/书记员/QC 不被拆散补别岗；模拟法官仍可跨域服务蓝队/红队法官视角预判（98 分共享资产）。科室治理 SOP 见 `SOP-BUS-04_模拟法庭科室治理.md`；庭审战情室归属与参谋长职责见 `数字员工岗位手册.md` 第9章。

## 四、内部协调与派工规则

- **派工来源**：承接总经理派工；跨中台任务由总经理协调优先级（引总经理职权 §2）。
- **优先级机制**：对外出件（R-1 待老强确认）＞ 知识入库（协同数字资产中台）＞ 稳定性监测。
- **交接规则**：值班 / 自动化异常交接须含"在办清单 + 门禁状态 + 待老强确认项"；DRAFT 岗（QC）产出须标 DRAFT 不混入 ACTIVE 战绩。

## 五、质量门禁承接

- 所有文本制品过 LTI（REJECT=0 才准交付）——引总册 §二。
- 所有写入 / 批量动作过六-B + 破坏性预检五条——引总册 §三 / §五。
- 构建产物流程过静默成功熔断——引总册 §四。
- 对外终稿（R-1）一律标"AI 辅助 / 待律师确认"，不得冒用律师署名——引总册 §一 / §八。

## 七、交接与复盘

- **日常复盘**：周复盘向总经理汇报（业务交付量 / 门禁通过率 / DRAFT 岗进展）。
- **治理复盘**：配合周五周报 + 周日 self-improve（引总册 / 公司章程 §7）。
- **异常闭环**：HIR 幻觉事故 / 工具事故 → 建卡 + 复盘（协同可视化中台·IT 运维员）。
