# SOP-BUS-05：业务中台设备总调度

**版本**：v0.2（P0 固化 · 门禁双轨）　**日期**：2026-09-24　**Owner**：业务中台（总经理派工；C 承接）　**性质**：部门业务流程 SOP（纯文档，不碰配置）
**编号**：SOP-BUS-05　**落点**：`部门治理/业务中台/SOP/SOP-BUS-05_业务中台设备总调度.md`
**维护**：修订须总经理执行、老强批准；与源规范冲突以总册 + 设备化方案为准

> 链接式 SOP：本册不重抄各设备流程正文，只写"何时调 / 谁调 / 过哪道门禁 / 落哪"。流程细节以各设备接入 SOP（SOP-BUS-06~09）与源 skill 为准。本 SOP 为四台设备的**统一调度入口（设备总线）**，禁止智能体绕开门禁直连设备产制品。

---

## 一、目的与适用范围

- **目的**：规范案件生命周期（CLM）/ 小德合规（CMS）/ 合同生命周期（Cont-LCM）/ 模拟法庭（MCM）四台标准设备的统一调度，确保**设备总线单一入口**、制品统一过 LTI 门禁、统一落点与监控。
- **适用范围**：所有经四台设备产出的制品（案件档案包 / 合规审查报告 / 合同审查报告 / 推演战报）。
- **不适用**：纯内部笔记 / 不产制品的会话。
- **源规范（权威）**：`业务中台/四大子系统设备化接入方案_v0.1.md` §3.2 / §3.5；`业务中台·部门规章制度.md` §二（设备调度职责）。

|---|---|---|

| 跨设备编排（CLM 触发 CMS 等） | 阶段 2 视需启用"设备编排层" | 总经理 |

## 三、标准步骤（链接式 · 设备总线单一入口）

| 步 | 动作（调哪个 / 谁调） | 责任方 | 产出落点 | 源规范章节 |
|---|---|---|---|---|
| 1 | 提调度申请（设备ID + 输入材料 + 关联案件/项目），总经理派工授权 | 发起数字员工 / 总经理 | 调度工单 | 方案 §3.2 |
| 2 | 设备总线路由到对应设备接入 SOP：CLM→SOP-BUS-06 / CMS→SOP-BUS-07 / Cont-LCM→SOP-BUS-08 / MCM→SOP-BUS-09 | 设备总线（业务中台调度职责） | — | 各设备 SOP |
| 3 | 设备产出草稿态制品 + 写 `制品元数据 frontmatter`（设备_id / 制品类型 / 门禁状态 / 落点…） | 操作工（对应数字员工） | 制品文件头 | 方案 §3.5 |
| 4 | 设备总线**统一过 LTI（双轨门禁，见方案 §3.6）**：轨A 本地 `lti_verify.py`；轨A 缺失/未过 → 轨B 经 qcc-legal/pkulaw 权威源实拉核验；任一 REJECT=0 才准交付；各设备不得自过 | 监督层（LTI） | 门禁通过 | 方案 §3.6 / 总册 §二 |
| 5 | R-1 类（对外终稿）移交老强终确认，未经确认不得标"终稿" | 总经理 / 老强 | 终稿 | 总册 §一 |
| 6 | 入库 / 回传 LawKB + 中枢 git `backfill.py`（禁裸 git） | 运营中台协同 | LawKB + 中枢 | 总册 §七 |
| 7 | C9 治理中台屏（9655）刷新在制 / 产能 / 门禁通过率 | 可视化中台协同 | 9655 屏 | 方案 §6 |

> **红线（单一入口）**：四台设备**禁止智能体绕开门禁直连产制品**；任何制品须经本总线步骤 1→4。

---

## 四、质量门禁（强制）

- 文本制品：必过 LTI（双轨门禁，REJECT=0；本地源缺失走轨 B 权威源实拉，引方案 §3.6）——引总册 §二 / 方案 §3.6。
- 写入 / 批量：必过六-B + 破坏性预检五条——引总册 §三 / §五。
- 构建产物：必过静默成功熔断（产出 < 期望 60% 即中止）——引总册 §四。
- 法条引用：必走 pkulaw 主源回填，禁凭记忆——引总册 §六。
- 制品元数据：未带 frontmatter 的制品不得入库 / 不得上屏——引方案 §3.5。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| 绕门禁直连（未走总线） | 退回，制品不得出库；记入治理复盘 |
| LTI 两轨均 REJECT≠0 | 退回修改，不得带草稿态对外 |
| 本地源缺失未转轨 B | 强制启用降级轨 B（qcc-legal/pkulaw 实拉），不得因源缺失阻断交付（引方案 §3.6） |
| R-1 未确认即标终稿 | 撤销"终稿"标记，移交老强；记违规 |
| 静默成功（产出不足） | 熔断中止，不写盘，报告 owner |
| 四类 R 触发（对外终稿 / 批量删改） | 立即移交老强，本部门不决策（引总册 §一） |
