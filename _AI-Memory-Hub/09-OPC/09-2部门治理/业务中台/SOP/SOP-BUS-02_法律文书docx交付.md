## 一、目的与适用范围

- **目的**：将"起草内容"经 LTI 门禁校验后，转为可用 docx 交付物（含加粗富文本），并归档 / 双目录同步。
- **适用范围**：所有需交付的法律文书终稿（诉讼 / 非诉 / 合规报告等）转 docx。
- **不适用**：纯 md 草稿（不对外）、非文书类产物。
- **源流程（权威）**：`法律文书docx交付流水线` — 路径 `~/.workbuddy/skills/法律文书docx交付流水线/SKILL.md`　★ **正文以该源为准**

## 三、标准步骤（链接式）

| 步 | 动作（调哪个 / 谁调） | 责任方 | 产出落点 | 源流程章节 |
|---|---|---|---|---|
| 1 | 通道选择（python-docx 生成） | 交付流水线 | 选定通道 | 法律文书docx交付流水线 §通道 |
| 2 | 生成（含加粗富文本，按格式铁律排版） | 交付流水线 | docx → `桌面办案系统/案件/庭审十件套` + 腾讯文档 | 法律文书docx交付流水线 §生成 |
| 3 | `LTI 文本监控器` 门禁校验（REJECT=0） | 监督层 | 门禁通过才准交付 | 总册 §二 / 公司章程 §4 |
| 4 | 备份 / 归档 / 双目录同步（cp -n 防覆盖） | 运营中台协同 | 归档 + 中枢回传 | 法律文书docx交付流水线 §归档；总册 §五 / §七 |

> 格式须符最高法法〔2016〕221号：A4 / 仿宋三号 16pt / 标题宋体 22pt / 行距固定 28 磅 / 页边距上 3.3 下 3.2 左 2.7 右 2.4cm / 页脚居中页码；禁止论文化写法（引总册 §八）。

## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0 才准交付）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检五条（cp 备份 / dry-run / 安全扫描）——引总册 §三 / §五。
- 格式：必符文书格式铁律（最高法法〔2016〕221号）——引总册 §八。
- 法条引用：必走 pkulaw 主源回填——引总册 §六。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| LTI REJECT≠0 | 退回修改，不得带草稿态对外 |
| 格式铁律不符 | 重排，不得交付论文化写法文档 |
| 四类 R 触发（对外终稿） | 移交老强终确认（引总册 §一） |
| 静默成功（产出缺失） | 熔断中止，不写盘 |
