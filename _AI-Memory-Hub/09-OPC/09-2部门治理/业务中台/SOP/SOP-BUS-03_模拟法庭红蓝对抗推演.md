## 一、目的与适用范围

- **目的**：诉讼文书红蓝复核定稿后，推进全流程红蓝对抗庭审模拟，产庭审记录 / 判决书 / 裁决书 / 调解书，并回写知识飞轮（建卡 / 经验）。
- **适用范围**：已明案源 + 庭前文书定稿后，需庭审推演的场景（培训 / 预演 / 策略验证）。
- **不适用**：真实对外庭审（须老强以执业律师身份出席）；真实对外裁决（R-1 须老强）。
- **源流程（权威）**：`模拟法庭红蓝对抗工作流` — 路径 `~/.workbuddy/skills/模拟法庭红蓝对抗工作流/SKILL.md`；封装 `模拟法庭主控协调器` + `三轮冲击控制器` + `模拟法庭庭审系统`（路径各自 SKILL.md）　★ **正文以该源为准**

## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0 才准交付）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检五条——引总册 §三 / §五。
- 构建产物：必过静默成功熔断——引总册 §四。
- 裁判心智：AI 模拟法官推演仅内部，严禁以"审判长"名义对外出裁决——引总册 §一 / 岗位手册 §4·§9。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| 静默成功（产出不足） | 熔断中止，不写盘，报告 owner |
| LTI REJECT≠0 | 退回修改，不得带草稿态对外 |
| 四类 R 触发（对外裁决 / 终稿） | 立即移交老强，本部门不决策（引总册 §一） |
| QC 未转正（DRAFT） | 闸门结论标 DRAFT，不混入 ACTIVE 战绩，须 WF-046 取证转正 |
