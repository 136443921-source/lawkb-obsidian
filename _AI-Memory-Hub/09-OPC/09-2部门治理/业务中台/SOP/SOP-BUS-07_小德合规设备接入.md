# SOP-BUS-07：小德合规设备接入（CMS）

**版本**：v0.1　**日期**：2026-09-24　**Owner**：业务中台（数字员工·小德慈善合规主导）　**性质**：部门业务流程 SOP（纯文档，不碰配置）
**编号**：SOP-BUS-07　**落点**：`部门治理/业务中台/SOP/SOP-BUS-07_小德合规设备接入.md`
**维护**：修订须总经理执行、老强批准；与源规范冲突以总册 + 设备化方案为准

> 链接式 SOP：CMS 为**智能体型设备**（复用数字员工·小德慈善合规，**不新建智能体**）。本册只写"何时调 / 谁调 / 产出落哪 / 门禁怎么过"，并在其岗位说明增"设备主机"职责段（不重抄流程正文）。流程细节以现有合规 SOP 与 `数字员工岗位手册.md` 为准。

---

## 一、目的与适用范围

- **目的**：规范 CMS 设备作为小德慈善合规"设备主机"的职责段落地与调用，标准化产出 `合规审查报告`（法律依据 + 内规条款 + 风险提示 + 整改建议）。
- **适用范围**：慈善组织业务合规 / 财务合规 / 联合劝募 / 信息公开等合规审查。
- **不适用**：诉讼业务（走 CLM）/ 合同非诉（走 Cont-LCM）。
- **源规范（权威）**：`四大子系统设备化接入方案_v0.1.md` §2（CMS 设备卡）/ §3.1 / §3.5；`数字员工岗位手册.md`（小德章）；`业务中台·部门规章制度.md` §二（设备调度）。

## 三、标准步骤（链接式）

## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检——引总册 §三 / §五。
- 静默成功熔断：产不足 60% 中止——引总册 §四。
- 法条 / 内规引用：pkulaw 主源 + 内规条款精准（第X条），禁凭记忆——引总册 §六。
- 制品元数据：必带 frontmatter（含 R-1 标记）——引方案 §3.5。

---

## 五、异常处理

| 异常 | 处理 |
|---|---|
| LTI REJECT≠0 | 退回修改，不得带草稿态对外 |
| 内规条款引用不准（非第X条） | 退回补正，不得引用模糊"相关规定" |
| 对外报告未老强确认即标终稿 | 撤销"终稿"，移交老强；记违规 |
| 绕门禁直连 | 退回，制品不得出库（引 SOP-BUS-05 红线） |
