## 一、目的与适用范围

- **目的**：每日全量重扫小强驾驶舱十屏（C1–C9+C0+门户+评分卡），提炼整改项按 P0–P4 排列交老强核实。
- **适用范围**：每日 08:00 自动巡检（`律所主任·驾驶舱监控` / automation b178bd74 / 30acc8c1）。
- **源流程（权威）**：`律所主任·驾驶舱监控` SKILL.md / `xiaoqiang-cockpit-hub` SKILL.md　★ **正文以该源为准**

---

## 二、触发条件

| 触发 | 说明 |
|---|---|
| 每日 08:00 | 驾驶舱监控自动化触发（L1 屏级巡检） |
| 每日 08:30 | L2 系统级巡检（含第 7 项"驾驶舱健康"：门户可达 / 评分卡 JSON 可解析 / 刷新脚本 success / 各屏非空）——驾驶舱自身也属被运维设备，见接管方案 §4.2 |
| 事故级（P0） | 门户挂 / 评分卡 NaN / 案号外泄 / **驾驶舱不可达** / 刷新脚本失败 → 立即单独告警老强（不含在非打扰时段） |

> ⚠️ **打扰纪律（2026-09-24 老强裁决 · 已生效）**：**P0 即时单独告警**；P1 进日报；P2–P4 仅入周报；**每日 20:00–08:00 非 P0 不主动打扰**（老强可随时自查）。告警等级调整权在老强。

## 五、异常处理

| 异常 | 处理 |
|---|---|
| P0 事故（门户挂/案号外泄） | 立即单独告警老强，不混日报 |
| 四类 R 触发（屏增=新增改造） | 移交总经理/老强拍板（引总册 §一 / 09102 §2） |
| **前端点击无反应类故障**（漏项 L-7） | 按 `00-系统总览与运维中心/前端点击无反应排查SOP-运维卡片.md` 排查；**结论回写 `SOP-VIS-04` 大屏修复台账**（本册 §五） |
| **修复类动作**（改坏要修） | 一律先建 **SOP-VIS-04 台账行**、过六-B 再动手；**只修"坏"，不改形态** |
| **大屏重复故障** | 同一根因季度内 ≥2 次 → 升 P1 并进周报（SOP-VIS-04 §三 第 6 步） |
