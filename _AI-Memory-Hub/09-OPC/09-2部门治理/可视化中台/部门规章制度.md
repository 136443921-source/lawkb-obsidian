## 一、部门定位与归属

- **部门名**：可视化中台
- **职能归属**：可视化 中台（OPC 四大中台之四，含 IT 运维员）
- **汇报线**：→ 总经理（律所主任·管理合伙人）→ 老强（超级管理员·唯一股东）
- **部门定位一句话**：分身系统**可见性中枢**——9655 驾驶舱全量监控、屏增审批（权属总经理）、IT 运维事故登记与闭环，向总经理汇报、受监督层（LTI）门禁。

---

## 二、部门职责边界（与章程 RACI 对齐）

| 职责 | 性质（A/R/C/I） | 说明 | 是否触四类 R |
|---|---|---|---|
| 驾驶舱全量巡检（十屏） | A | 每日 08:00 巡检 + P0–P4 整改清单 | 否（只读监控） |
| 屏增审批（新增治理中台屏） | A/R（权属总经理） | 屏增需求提报 + 总经理拍板 | 屏增=新增改造→是（R-4 须老强） |
| IT 运维事故登记 / 闭环 | A | HIR 幻觉事故 / 工具事故建卡复盘 | 否（内部） |
| 监控刷新编排 | C | 承接总经理（可视化治理 §2） | 否 |
| 跨中台监控交接 | C | 承接总经理派工 | 否 |

> 凡涉及四类 R（对外出件 / 定价发布 / 批量删改单源 / 新增改造子系统）的职责，本部门不得自主决策，须移交老强（引总册 §一）。屏增审批（新增屏=新增改造）权属总经理，本中台仅提报需求 + 落地执行，不决策。

## 三-A（岗位型中台用）· 下属数字员工与汇报

| 数字员工（岗位隐喻） | 归属 | 成熟度 | 核心职责 | 禁用动作 |
|---|---|---|---|---|
| 数字员工·IT 运维员 | 本中台 | 专家级 | 系统事故检测 / 取证复测 / 建工具事故卡 + 配对轨迹卡 / 互联接入 / 复盘 | 四类 R 须老强拍板 |

> 岗位细则以 `数字员工岗位手册.md` 为准；IT 运维员为"每一次工具/自动化出事，都变成一张可检索、可互联、可复用的卡"的席位。

## 三-B（流程型中台用）· 归口流程清单

| 流程名 | 归属 SOP | owner | 说明 |
|---|---|---|---|
| 驾驶舱全量运维 | SOP-VIS-01 | 可视化中台 | 十屏巡检 + 整改清单 + 刷新编排 |
| 屏增审批 | SOP-VIS-02 | 可视化中台（权属总经理） | 屏增需求提报 + 总经理拍板 + 落地 |

> 流程型部分无独立数字员工，"部门管理"= 流程归口管理；SOP 链接见第四节。

---

## 四、内部协调与派工规则

- **派工来源**：承接总经理派工；跨中台任务由总经理协调优先级（引总经理职权 §2）。
- **优先级机制**：事故级（P0 门户/评分卡挂 / 案号外泄）→ 立即告警老强 ＞ 屏增需求提报 ＞ 例行巡检。
- **交接规则**：事故交接须含"事故卡 + 复测结论 + 待老强确认项"。

---

## 五、质量门禁承接

- 所有文本制品过 LTI（REJECT=0 才准交付）——引总册 §二。
- 所有写入 / 批量动作过六-B + 破坏性预检五条——引总册 §三 / §五。
- 构建产物流程过静默成功熔断——引总册 §四。

## 七、交接与复盘

- **日常复盘**：周复盘向总经理汇报（十屏可用率 / 事故闭环率 / 屏增进度）。
- **治理复盘**：配合周五周报 + 周日 self-improve（引 03-治理复盘模板 / 公司章程 §7）。
- **异常闭环**：HIR 幻觉事故 / 工具事故 → IT 运维员建卡 + 复盘（引 IT 运维员职责）。
