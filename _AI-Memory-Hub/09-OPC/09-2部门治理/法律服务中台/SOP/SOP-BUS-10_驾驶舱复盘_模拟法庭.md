**编号**：SOP-BUS-10　**落点**：`部门治理/法律服务中台/SOP/SOP-BUS-10_驾驶舱复盘_模拟法庭.md`

## 一、目的与适用范围

- **目的**：规范"通过 9655 驾驶舱 C6 模拟法庭中台屏开展模拟法庭复盘"的闭环动作，把运行态异常转化为整改与屏上指标刷新。
- **适用范围**：MCM 设备运行态监控异常后的复盘与整改（红蓝对抗推演、裁判推演、战情复盘）。
- **不适用**：实际对外出具裁判 / 裁决（禁以"审判长"名义对外，R-1 须老强）。
- **源规范（权威）**：`SOP-BUS-05` §三（设备总线）/ `SOP-BUS-09` §三（MCM 接入）/ `模拟法庭设备运行管理制度` §六·§七 / C6 屏（监控设置 + 复盘方法论）/ `00-横向铁律执行总册.md` §二~§五。

## 三、标准步骤（链接式 · 闭环）

| 步 | 动作（调哪个 / 谁调） | 责任方 | 产出落点 | 源规范章节 |
|---|---|---|---|---|
| 1 | **C6 看异常**：在制设备/产能/门禁通过率/QCJUDGE 守持/三处齐套率/抽检 任一标红 | 可视化中台（C6） | 异常清单 | C6 屏 §一/§二 |
| 2 | **调战报**：经设备总线（SOP-BUS-05 步1）授权调出 MCM 推演战报+复盘 | 模拟法官(庭长) | 战报文件 | SOP-BUS-05 / SOP-BUS-09 |
| 3 | **红蓝复盘**：QC（参谋长，中台级）就程序/态势复盘；守 RULE-QCJUDGE-DISAMBIG 仅闸程序，不闸实体裁判 | QC（参谋长） | 复盘要点 | 制度 §七 / RULE-QCJUDGE-DISAMBIG |
| 4 | **整改**：程序瑕疵/引用错漏/同步缺失 → 整改清单（含 R-1 未触发核验） | 模拟法官 + 操作工 | 整改清单 | 制度 §八 |
| 5 | **三处回写**：办案隔离目录 + 中枢 + git backfill 齐套（md5 零残留），cp -n 防覆盖 | 运营中台协同 | 三处落点 | 制度 §五 / SOP-BUS-05 步6 |
| 6 | **C6 刷新**：指标回填本屏（门禁通过率/齐套率等），闭环 | 可视化中台 | C6 屏刷新 | C6 屏 §三 |

> **闭环铁律**：步5 三处未齐套（md5 零残留）不得进入步6 标"已归档"；步3 QC 越界评判实体裁判即违规退回（RULE-QCJUDGE-DISAMBIG）。

## 四、质量门禁（强制）

- 文本制品：必过 LTI（REJECT=0）——引总册 §二。
- 写入 / 批量：必过六-B + 破坏性预检五条（含 cp -n 防覆盖 / dry-run / 确认幂等）——引总册 §三 / §五。
- 静默成功熔断：产出 < 60% 中止——引总册 §四。
- 法条引用：pkulaw 主源，禁凭记忆——引总册 §六。
- 制品元数据：必带 frontmatter——引方案 §3.5。
- **QC 边界**：QC 仅闸程序合规，绝不评判模拟法官实体裁判推演（RULE-QCJUDGE-DISAMBIG）。

## 五、异常处理

| 异常 | 处理 |
|---|---|
| C6 屏源数据断流 | 降 P1 + 修复；临时以试点脱敏快照呈现 |
| 步3 QC 越界评判实体裁判 | 退回，违反 RULE-QCJUDGE-DISAMBIG，记违规 |
| 步5 三处未齐套 | 补全 cp -n + git backfill，未齐套不得标"已归档" |
| LTI REJECT≠0 | 退回修改，不得带草稿态对外 |
| 四类 R 触发（对外裁决 / 终稿） | 移交老强（引总册 §一） |
