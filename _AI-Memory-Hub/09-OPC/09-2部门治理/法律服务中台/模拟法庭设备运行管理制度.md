# 模拟法庭设备运行管理制度

**版本**：v1.0　**日期**：2026-09-24　**Owner**：法律服务中台（模拟法官·庭长主导）　**性质**：部门管理制度（纯文档，不碰配置）
**编号**：REG-BUS-MCM　**落点**：`部门治理/法律服务中台/模拟法庭设备运行管理制度.md`
**维护**：修订须总经理执行、老强批准；与源规范冲突以总册 + 设备化方案 + SOP-BUS-05/09 为准

> 本制度固化 MCM（模拟法庭）设备**常驻运行**管理要求：派工 / 门禁（LTI 双轨）/ 三处同步 / 抽检 / C6 监控 / 复盘。流程细节以 `SOP-BUS-05`（设备总调度）、`SOP-BUS-09`（MCM 接入）、`SOP-BUS-10`（驾驶舱复盘）为准，本制度不重抄流程正文。

---

## 一、目的与适用范围

- **目的**：将阶段1试点（MCM-DEV，载体=6658 冒名诉讼程序战红蓝对抗，REJECT=0、QCJUDGE-DISAMBIG 落地、6 项抽检全过）固化为常驻运行制度，明确 MCM 设备"谁派工 / 怎么过门禁 / 落哪 / 怎么监控 / 怎么复盘"。
- **适用范围**：诉讼 / 仲裁案件的红蓝对抗推演、裁判推演、战情复盘（经 MCM 设备产出 `推演战报 + 复盘报告`）。
- **不适用**：实际对外出具裁判 / 裁决（禁以"审判长"名义对外，R-1 须老强）。
- **源规范（权威）**：`四大子系统设备化接入方案_v0.1.md` §2（MCM 设备卡）/ §3 / §6；`法律服务中台·部门规章制度.md` §二（设备调度）/ §三-B（模拟法庭子科室）；`SOP-BUS-05` / `SOP-BUS-09` / `SOP-BUS-10`；`00-横向铁律执行总册.md` §一~§七。

---

## 二、设备定位与编制

- **设备形态**：MCM 为**智能体型设备**，复用模拟法庭子科室（AI 模拟法官+书记员+QC 虚线借调），**不新建智能体、编制不变**。
- **设备主机**：AI 模拟法官兼任设备主机（庭长即设备主机），经设备总线（SOP-BUS-05）授权后调度 MCM；书记员为实线成员；QC 虚线借调任质量闸门 + 中台级战情室参谋长。职责段详见 `数字员工岗位手册 v1.1`〔设备主机职责段〕。
- **制品**：`推演战报 + 复盘报告`（程序 / 态势，不闸实体裁判），须带 `制品元数据 frontmatter`（设备_id: MCM-DEV）。

---

## 三、派工与单一入口

- 任一数字员工需调用 MCM 产制品，须经**设备总线单一入口**（SOP-BUS-05 步1→步4）：提调度申请（设备ID + 输入材料 + 关联案件）→ 总经理派工授权 → 总线路由到 SOP-BUS-09 → 设备产出草稿态制品。
- **红线**：四台设备**禁止智能体绕开门禁直连产制品**；任何制品须经总线步骤 1→4。

---

## 四、运行门禁（强制）

- **LTI 双轨门禁**：制品统一过 LTI（轨A 本地 `lti_verify.py`；轨A 缺失/未过 → 轨B 经 qcc-legal/pkulaw 权威源实拉核验）；**任一 REJECT=0 才准交付**，各设备不得自过——引总册 §二 / 方案 §3.6。
- **QC 边界**：QC 仅闸程序合规（门禁/引用规范/流程），**绝不评判模拟法官实体裁判推演**（RULE-QCJUDGE-DISAMBIG）。
- **写入 / 批量**：必过六-B + 破坏性预检五条——引总册 §三 / §五。
- **静默成功熔断**：产出 < 期望 60% 即中止——引总册 §四。
- **法条引用**：必走 pkulaw 主源回填，禁凭记忆——引总册 §六。
- **制品元数据**：未带 frontmatter 的制品不得入库 / 不得上屏——引方案 §3.5。

## 七、驾驶舱复盘闭环

- 经 C6 屏发现异常（在制超标 / 门禁 REJECT≠0 / 三处不同步）→ 调战报 → 红蓝复盘（QC 参谋长，程序/态势，不闸裁判）→ 整改 → 三处回写 → C6 刷新。
- 闭环细则见 `SOP-BUS-10_驾驶舱复盘（模拟法庭）`。6658 实例见 `阶段1试点_MCM-DEV/推演战报_复盘_MCM-DEV_6658.md`。

---

## 八、异常处理

| 异常 | 处理 |
|---|---|
| 绕门禁直连（未走总线） | 退回，制品不得出库；记入治理复盘 |
| LTI 两轨均 REJECT≠0 | 退回修改，不得带草稿态对外 |
| 本地源缺失未转轨 B | 强制启用降级轨 B（qcc-legal/pkulaw 实拉），不阻断交付 |
| QC 越界评判实体裁判 | 退回，违反 RULE-QCJUDGE-DISAMBIG，记违规 |
| 三处同步缺失 | 补全 cp -n + git backfill，未齐套不得标"已归档" |
| 四类 R 触发（对外终稿 / 批量删改） | 立即移交老强，本部门不决策（引总册 §一） |
