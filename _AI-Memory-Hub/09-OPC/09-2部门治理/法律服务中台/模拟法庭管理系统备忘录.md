## 二、开展一次模拟庭审（操作 SOP · 五步）

1. **准备**：起本地服务 `trace_server.py`（端口 8765）；或直接浏览器开 `agent_orchestration_tracer.html`（已开 CORS，可跨域轮询）→ 点「开启 LIVE 监听」。
2. **启动编排**：对主任编排引擎说「开始模拟庭审」（或指定案件，如「用 6660 雅菲案实跑」）。引擎按 **准备 → 就位 → 对抗 → 回写** 四阶段自动拉五方席位并实跑红蓝对抗。
3. **实时观看（看过程）**：LIVE 模式下，席位卡片逐秒点亮 + 对抗过程流（调查 / 质证 / 辩论 / 法官总结）逐句浮现。
4. **回放 / 纯净观摩**：点「🎬 重播过程」离线逐句回放（1200ms）；点「👁 纯净观摩」隐藏技术细节，仅留对抗流供当事人观摩。
5. **产出归档**：引擎产出对抗实录 HTML（如 6660 实录）+ 调用记录（落 `知识飞轮系统/05-调用/模拟法庭调用记录/`）+ 协同日志埋点。
