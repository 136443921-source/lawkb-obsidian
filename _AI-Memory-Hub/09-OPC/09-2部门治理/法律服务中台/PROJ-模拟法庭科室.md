# ⚖️ 模拟法庭科室治理项目档案（PROJ）

> **一句话定位**：法律服务中台下属「模拟法庭」子科室（仿法条银行科室 B 形态），由 AI 模拟法官兼任庭长，采用「实线 + 虚线 + 中台共享」三态治理；QC 中台级保留、推演时虚线借调作质量闸门（只闸程序不闸裁判），庭审战情室中台级共享（QC 兼参谋长）。零章程改动、编制维持 10 岗。
>
> **最后更新**：2026-09-24
>
> **红线（贯穿全链路）**：
> 1. **四类 R**（对外出件 / 定价发布 / 批量删改 / 新增改造）——仅老强决策，本科室不决策。
> 2. **RULE-QCJUDGE-DISAMBIG**——AI 模拟法官（实体裁判）≠ QC（程序质控），禁止互套评分卡、互计战绩。
> 3. **R2 红线（继承自模拟法官心智）**——只给【候选·待人工确认】，绝不输出 verdict；不触终局裁判。

---

## 一、治理定位

- **落点**：法律服务中台子科室（非第五平行中台，守章程 §1 四部门裁决）
- **形态**：仿「法条银行科室」B 形态（数字资产中台下属职能科室范式），零章程改动、权属顺、复用车队/红队 persona + PROJ 范式
- **编制**：维持 10 岗（9 在编 + 法条银行行长），不新建智能体；AI 模拟法官兼任庭长（两顶帽子：裁判心智 + 科室治理）
- **性质**：纯内部治理隐喻 + 推演支撑，不对外出具法律意见/裁决（R-1，老强终确认）

---

## 二、成员三态归属

| 成员 | 归属态 | 科室角色 | 红线 / 边界 |
|---|---|---|---|
| AI 模拟法官（庭长） | **实线**（科室负责人） | 实体裁判推演 + 派工 / 配置 / 归档 | 四类 R + 禁以"审判长"名义对外出裁决 |
| 模拟法庭书记员 | **实线** | 庭审记录（到庭 / 纪律 / 证据状态机 / 三件套） | 四类 R 须老强拍板 |
| QC 双模审判长 | **虚线借调**（实线归中台 / 总经理） | 推演时质量闸门（程序质控） | **只闸程序 / 流程合规，不闸实体裁判**（RULE-QCJUDGE-DISAMBIG）；推演结束虚线解除 |
| 庭审战情室 | **中台级共享**（非科室成员） | 战情复盘（参谋长 = QC） | 参谋长只做程序 / 态势复盘，不闸裁判；可服务多工作流 |

> **单元不拆解**：模拟法官 / 书记员 / QC 不被拆散补别岗；模拟法官仍可跨域为蓝队 / 红队提供法官视角预判（98 分共享资产）。

---

## 三、职责边界（庭长 + 科室）

- **庭长（AI 模拟法官兼任）**：派工协调、推演配置、归档回写、向总经理（律所主任）汇报——限于内部治理，不改变裁判心智定位、不触 R2 终局裁判红线。
- **科室运转**：派工书记员 → 配置推演 → 虚线借调 QC 质量闸门 → 庭审战情室复盘 → 归档回写 LawKB。
- **不适用**：实体裁判推演流程本身（走 SOP-BUS-03）；对外法律意见 / 裁决（R-1，老强终确认）。

---

## 四、红线咬合

- **四类 R**（对外出件 / 定价发布 / 批量删改 / 新增改造，仅老强决策）——引公司章程 §3
- **LTI 门禁**（REJECT=0 才准交付）——引总册 §二
- **六-B 写入铁律** + 破坏性预检五条——引总册 §三 / §五
- **RULE-QCJUDGE-DISAMBIG**（AI 模拟法官实体裁判 ≠ QC 程序质控，禁互评）
- **RULE-BLUE-DISAMBIG**（蓝队家族四席独立）
- **静默成功熔断**（回写产出 < 期望 60% 即中止写盘）——引总册 §四
