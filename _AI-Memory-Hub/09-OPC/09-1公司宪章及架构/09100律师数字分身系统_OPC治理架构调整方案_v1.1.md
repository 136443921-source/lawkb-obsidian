# 律师数字分身系统 · 一人公司（OPC）治理架构调整方案
**版本**：v1.1（决策固化版）　**日期**：2026-09-22　**状态**：5 项开放问题已裁决，可进入 Phase 1 落地
**前身**：v0.1（讨论稿，2026-09-22，待对齐）　**驱动锚点**：治理权责梳理 / 全栈整合 / 对外经营体 / 先出文档后动配置

> ⚠️ 本方案仍为**设计稿**，不改任何配置。v1.1 在 v0.1 基础上固化了老强裁决的 5 项开放问题，并引入 **9655 驾驶舱（私有化单机密文版）** 作为可视化唯一基准。

## 0. 一句话结论

分身系统 = **老强（超级管理员/唯一股东）控股 + 律所主任·管理合伙人（总经理）管内治**的拟一人公司；四大中台（业务/数字资产/运营/可视化）向总经理汇报、受 LTI 监督层门禁、以 **LawKB 独立仓库为法人资产**；对外按**私有部署 / 法律咨询外包 / 知识付费（规则包）**三种业态经营，所有可视化收口到 **9655 驾驶舱**。治理结构从"散落"变为"有章程、有汇报线、有归责闸、有资产隔离"。

## 4. 权责矩阵（RACI）—— 治理权责梳理核心交付（v1.1 更新）

R=最终决策　A=执行　C=被咨询　I=被告知

| 事项 | 老强(超级管理员) | 总经理(律所主任) | 四大中台 | 监督层(LTI) | 资产层 |
|---|---|---|---|---|---|
| 对外出具法律意见/文书终稿 | **R/A**（人工确认） | C | A（起草） | R（门禁） | I |
| 商业化定价/SKU/规则包发布 | **R** | C | — | I | I |
| 知识入库（飞轮） | I | C | A | R（校验） | C |
| 批量删除/改写配置 | **R/A** | C | — | R（门禁） | I |
| 新增/改造子系统 | R | A（派发） | A | R（回归） | I |
| 内部治理运转（日报/派工） | I | **A/R**（总经理职权） | C | C | I |
| 治理复盘（年审） | **R** | A | C | C | I |
| nominee 接管（失能/继承） | 预设 | A | — | I | C |
| 知产登记结论 | R | C | — | I | A |
| **9655 驾驶舱改造/屏增** | I | **R/A**（总经理管可视化） | A(可视化中台) | C | I |

> **红线（v1.1 固化）**：四类 R 动作（对外出件 / 定价发布 / 批量删改 / 新增改造）老强为唯一最终决策人；总经理在"内部治理运转"享 A/R 职权，但不得越过四类 R 动作。

## 5. 责任隔离与归责边界（对外经营体 · 按三种业态深挖）

### 5.1 对外业态与责任深度（v1.1 裁决）

| 业态 | 产品形态 | 归责边界 | 责任架构深度 |
|---|---|---|---|
| **私有部署** | 分身系统 + 9655 驾驶舱打包为可单机部署单元，交付客户/内部 | 交付前数据脱敏 + 密文；运行环境隔离；**产品缺陷归拟法人（老强），客户使用产出由其自担**（需服务协议免责条款） | 最深：独立部署包 + 部署 SOP + 密文存储 |
| **法律咨询外包** | 分身作老强团队"外包法律助理"，出草稿，老强终确认 | 草稿标"AI 辅助/待律师确认"；**终稿归老强担责**；不得冒用律师署名 | 中：人工确认节点 + 署名合规 |
| **知识付费（规则包）** | LawKB 规则卡/裁判规则库打包成"规则包"售卖 | 知产归属拟法人；**售卖前脱敏（去当事人隐私/证件号）**；授权范围明示 | 中：知产登记 + 脱敏管线 |

### 5.2 自动动作边界（可无人值守）
检索、类案、文书**草稿**起草、格式转换、数据监测、知识摄入、周报、9655 监控刷新。产物一律标"草稿态/待 LTI 校验"，不得带权威源光环直接对外。

### 5.3 人工确认节点（必须老强拍板，系统不得自动）
对外出具法律意见/文书**终稿**；定价/SKU/规则包发布；知产登记；删除/批量改写单源文件；nominee 接管触发。

### 5.4 兜底与隔离护栏
- 老强=唯一股东，以"认缴出资"（系统资产+个人时间）为限担责。
- 内部错误产物若绕过 LTI 门禁出库 → 治理失效，追责回到"未跑门禁"环节。
- 代码化（Phase 4）：四类 R 动作前置 `pre-action-guard` 拦截弹确认；"静默成功"熔断（产出<期望60%即中止写盘）。
