## 1. 数字员工定义与法律边界

- **定义**：数字员工 = 职能岗位隐喻，指向具备特定心智模型 / 专项能力的智能体，归属某中台、向总经理汇报。
- **法律分层**：
  - **硬法（公司法 / 劳动法）**：AI 非自然人 / 法人，不能成为法律意义的"员工 / 雇员"——本编制仅限内部治理定义，不创设法律主体。
  - **专门法（律师法）**：数字员工可起草 / 辅助，但对外出具法律意见须**老强（执业律师）终确认**，不得冒用律师署名。
- **与现有映射同源**：律所主任 = 总经理（治理席隐喻），数字员工 = 岗位隐喻，体系一致，不冲突。
- **用途边界（老强裁决）**：**纯内部治理**——仅用于提升内部治理精度，不对外呈现 / 不对外以"数字团队"名义承揽业务；对外披露条款本次 **N/A**（如后续转内外混合，须在 Phase 4 补披露条款）。

## 5. 必须守住的红线

1. **四类 R 动作红线不变**：数字员工不得对外出件 / 定价 / 批量删改 / 新增改造，须老强拍板。
2. **LTI 门禁全覆盖**：数字员工所有文本制品过 LTI，REJECT=0 才准交付。
3. **对外披露合规（防御性保留）**：纯内部治理下当前不对外呈现，本条**暂 N/A**；如后续转"内外混合"或"完全对外"，须补 `AI 辅助 / 待律师确认` 披露条款（Phase 4 代码化时一并）。
4. **蓝队家族四席独立**：蓝队诉讼 / 蓝队非诉 / 蓝队律师助理 / 红队对抗 不混用 / 不折算 / 不合并（老强铁律 `RULE-BLUE-DISAMBIG`）。
5. **AI 模拟法官 ≠ QC 审判长**：二者不同心智（98/100 vs 50/100），禁止互套评分卡、禁止互计战绩（老强铁律 `RULE-QCJUDGE-DISAMBIG`）。
6. **归责闭环**：数字员工失误 → 追责回老强（唯一股东，有限责任以认缴出资为限）。
