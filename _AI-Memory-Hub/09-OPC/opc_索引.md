## 更新纪律

1. **按职能归属定位**：治理层变动 → 查上表"职能归属"→ 更新对应文件 + 末尾变更记录追加一行
2. **章程最高效力**：冲突以 `公司章程.md` 为准；其修订须**老强（超级管理员）批准**
3. **写入前查重**：中枢优先；冲突以中枢 `status:active` 最新版为准
4. **双目录同步**：中枢 `09-OPC` 为主存，workspace 副本为工作态；以中枢为准
5. **不越红线**：四类 R 动作（对外出件 / 定价发布 / 批量删改 / 新增改造）仅老强可决策
