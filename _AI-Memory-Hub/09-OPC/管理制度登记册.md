## 七、维护纪律（登记册更新触发）

1. **新增制度** → 建册登记新行（编号 + 范围 + 使用人 + 受控状态），不得先建制度后补登记。
2. **制度修订** → 同步更新版本、受控状态与本册对应行，**页眉版本须与变更记录同步**（§五整改规矩）。
3. **制度废止** → 状态改 ⛔，保留历史行，并从其他文件的引用处清理。
4. **受控缺陷** → 每次巡检后回填 §五缺陷表，整改完成销项。
5. **归口**：数字资产运维官（日常维护）→ 律所主任复核 → **老强（唯一股东）批准**，与 `RULE-EMP-ROSTER-UPDATE` 同构。
6. **不重复造册**：制度本身内容写各自归口文件（09100–09106 / 09-2 各中台 / 09-3 / 09-4），本册**只登记元数据，不重抄制度正文**（链接式，防漂移）。
