## 一、对外经营线定位与归位（A/B/C）

**权威源**：`对外经营耦合与业务开拓建议方案_v0.1.md` §4　**性质**：经营侧闭环归口

| 方案 | 归位 | 说明 | 状态 |
|---|---|---|---|
| A | 扩展运营中台 →「运营·商业中台」（双轨：内治轨 + 商业轨） | 获客/交付履约是运营职能自然延伸；四中台映射稳定 | ⏳ 目标态 |
| B | 新增第五中台「商业运营中台」 | 经营与生产彻底分离，职责最清晰；需改 v1.1 四中台映射 + 章程 | ⏳ 远期可选 |
| **C（当前采用）** | 维持四中台，本册为横向册 + 三业态项目制，老强直管 + 总经理派工 | 文档先行、风险最低；试点跑顺后升 A | ✅ 生效 |

> **当前采用 C**：对外经营线由老强（唯一股东）直管、总经理（律所主任）派工；商业轨暂挂运营中台，待试点（规则包）跑顺后按 A 升「运营·商业中台」。

## 二、端到端经营闭环（五段）

| 阶段 | 动作 | 归属中台 | 红线 / 收口 |
|---|---|---|---|
| ① 获客 Lead | 内容获客（讲座/文章/规则包样品）+ 渠道（公益平台 `gongyi-open-mcp` / 律师同行 / 企业法务）+ 线索归集 | 运营中台-商业轨 | 线索收口 `05-商业化运营备忘录 §客户线索`（引 总册 §八） |
| ② 转化 Conversion | 商机分级(A/B/C) → 报价(引备忘录 L1–L4) → 服务协议(含免责/署名合规条款) | 运营中台-商业轨 + 老强 | **R-2** 定价/SKU 老强拍板（引 总册 §一） |
| ③ 交付 Delivery | 调对应业态 SOP：私有部署走部署 SOP / 规则包走脱敏 SOP / 文书走代写 SOP | 四中台按 RACI 供给 | 全部过 LTI(REJECT=0) + 四类 R 人工确认节点（引 总册 §二/§一） |
| ④ 复购 Retention | 交付确认 + 回款 + 客户成功回访 + 规则包订阅更新 + 9655 监控服务续费 | 运营中台-商业轨 | 对外传播材料脱敏（去当事人隐私/证件号） |
| ⑤ 知产 IP | 知产登记 / 脱敏管线 / 署名合规 / 年度商业化合规审计 | 数字资产中台 + 老强 | **R-2** 知产登记老强批；数字员工披露 Phase 4 补 |

## 三、三业态产品线总览（详卡见各 `产品线-*.md`）

| 业态 | 交付物形态 | 能力供给中台 | 归责边界 | 责任深度 |
|---|---|---|---|---|
| 独立部署 | 分身系统 + 9655 驾驶舱 + 部署 SOP + 密文存储（可单机运行单元） | 业务中台 + 数字资产中台 + 可视化中台 + 运营中台 | 产品缺陷归老强(拟法人)；客户使用产出自担（服务协议免责） | 最深 |
| 规则包 | LawKB 裁判规则库/审判要件卡/经验卡 **脱敏**打包 | 数字资产中台(核心) + 业务中台(质检) | 知产归拟法人；售前脱敏；授权范围明示 | 中 |
| 文书代写 | 文书草稿 → 老强终确认终稿，标"AI 辅助/待律师确认" | 业务中台(蓝队非诉/诉讼起草+红队预审) + 数字资产中台(卡库) | 草稿标 AI 辅助；**终稿老强担责**；不得冒用律师署名 | 中 |
