## 0. 一句话

分身作老强团队"外包法律助理"起草文书，出草稿标"AI 辅助 / 待律师确认"，老强终确认终稿；归入 v1.1 §5.1「法律咨询外包」业态品类，不另立第四业态。

---

## 1. 交付物形态

- 文书草稿（起诉状 / 答辩状 / 代理词 / 合同 / 合规报告 等）
- 老强终确认终稿（标"AI 辅助 / 待律师确认"，不得冒用律师署名）
- 配套检索 / 类案依据（引本地权威源，禁凭记忆）

---

## 2. 能力供给中台（RACI）

| 中台 | 供给内容 | 性质 |
|---|---|---|
| 业务中台 | 蓝队非诉 / 蓝队诉讼 起草 + 红队律师 预审 | A |
| 数字资产中台 | 卡库接线（审判要件 / 裁判规则 / 文书范式） | C |
| 老强 | 终确认终稿（R-1） | R |

---

## 3. 端到端步骤（链接式 SOP，已落地可引）

| 步 | 动作 | 责任方 | 落点 | 门禁 |
|---|---|---|---|---|
| 1 | 需求澄清（事项 / 体裁 / 当事人信息） | 老强 / 运营中台-商业轨 | 商机池 | 引 总册 §八 |
| 2 | 蓝队起草（合同 / 诉讼文书） | 业务中台 | 文书草稿 | 引 `SOP-BUS-02_法律文书docx交付` |
| 3 | 红队预审（预驳回攻击） | 业务中台 | 文书草稿 | 引 `SOP-BUS-01_诉讼文书红蓝复核` |
| 4 | 老强终确认终稿 | 老强（R-1） | 终稿 docx | R-1 + LTI(REJECT=0) |
| 5 | 交付（标"AI 辅助 / 待律师确认"） | 运营中台-商业轨 | 客户 | 署名合规（引 总册 §八） |

---

## 4. 归责边界

- 草稿标"AI 辅助 / 待律师确认"；**终稿归老强（执业律师）担责**；不得冒用律师署名。
- 内部错误产物若绕过 LTI 门禁出库 → 治理失效，追责回"未跑门禁"环节。
- 责任架构深度：**中**（人工确认节点 + 署名合规）。

---

## 5. 质量门禁 / 红线

- 起草 / 预审全过 LTI(REJECT=0)；终稿 R-1 老强拍板。
- 对外传播材料脱敏（去当事人隐私 / 证件号）。
- 数字员工不对外以"数字团队"名义承揽（披露条款 Phase 4 补，引 `数字员工编制方案_v1.0.md` §5.3）。
