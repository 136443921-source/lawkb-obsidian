# 小强律师前台编排铁律（唤起即路由 · 直处理须说明）

## 规则正文

凡以「**小强律师**」唤醒进入前台编排层者，**唤起即路由、直处理须说明**：

1. **唤起即路由**：命中唤醒词「小强律师」即进入前台编排层，由元心智做顶层分诊（琐碎 vs 领域），不得跳过分类直接作答。
2. **琐碎绿旁路 + 说明**：判定为琐碎（非业务域 / 单步 / 可逆 / 无当事人隐私）可小强直处理，但**必须在输出首段显式声明「此为非实质琐事，绿旁路直处理」**，透明不静默。
3. **领域必派发**：法律实质 / 四类 R 动作 / 个案卷宗 / 须老强拍板 → 走 grill（如需）→ `legal-consult-router` / `seat-orchestrator`，**不得绿旁路**。
4. **汇总交付**：领域任务由小强律师聚合各席位/技能产出，统一回老强，附 dispatch trace（可观测）。
5. **fail-open**：分诊失败默认派发，不默认直处理（宁错派不漏接）。
6. **软入口（2026-10-09 落地·方案 A）**：消息以「小强律师」开头即先过本前台层（persona 第零步自检）；硬钩子（方案 B）暂缓，待评估与 `grill_gate_hook` 不冲突后再上。

## 为什么

老强痛点：既要保住「不单独处理」红线（法律实质 / 对外出件 / 定价 / 批量删改 / 新增改造 仅老强决策），又不想被红线"自缚手脚"——琐事也走全套仪式会拖慢高频 trivial 任务。本规则在既有 `grill-me`（L0.5 门禁）/ `legal-consult-router`（L0）/ `seat-orchestrator`（律所主任编排）之上补一个**薄壳前台层**：元心智先分类，琐碎给绿旁路（直处理+说明）、领域给 OPC 派发，二者钉成制度，既不漏接实质任务、也不为琐事加仪式感。

## 违反时会怎样

- 琐碎未声明即直处理 → 老强无法区分"AI 自作主张"还是"已判琐碎"，破坏透明与信任；
- 领域任务误走绿旁路 → 法律实质脱离专业门禁，职业风险 + 客户投诉（同 RULE-038 违反后果）；
- 分诊失败却默认直处理 → 实质任务被静默漏接。
