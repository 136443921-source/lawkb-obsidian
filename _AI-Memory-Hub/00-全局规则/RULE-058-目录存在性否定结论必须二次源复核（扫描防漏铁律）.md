# 目录存在性否定结论必须二次源复核（扫描防漏铁律）

## 1. 铁律正文

凡程序对「目录 0 文件 / 目录不存在」得出**否定结论**（空库、漏扫、未建、零引用），**必须二次源复核**，否则视为「未验证」，不得据以下一步动作（尤其不得据此跳过写入或判定为空）。

二次源复核最低标准（任一对）：
- `test -d` + `ls` / `os.listdir` 复核真空 vs 遍历失败；
- `find` 的 `2>/dev/null` 必须去掉或用 `2>&1` 暴露权限/沙箱拒绝；
- 至少两种遍历手段（`os.walk` ↔ `os.listdir` ↔ `find`）交叉，单一手段命中 0 不构成证据。

## 2. 事故锚点（固化来源）

**2026-10-29 月度回灌漏扫裁判规则库事故**：首轮（2026-10-28）回灌对 `06-沉淀/裁判规则库` 跑 `find ... 2>/dev/null` 返回 0（实为沙箱/权限偶发拒绝，被 `2>/dev/null` 吞掉），未做二次源复核即误判「该目录为空（0 文件）」，导致 **387 张裁判规则卡（349 R-*）+ 通用裁判规则库 42 张全部漏扫**，约 **218 张本月新增规则卡漏索引**进 self.md 经验索引区。事后 `ls`/`glob` 复核，目录从未为空。

根因 = 违反本卡 + 否定型结论铁律（单次 grep/find 命中 0 ≠ 不存在）。

## 3. 落地防护（已写入 intake_monthly_driver.py · BackfillScanner.safe_walk）

- `safe_walk(d)`：`os.path.isdir(d)` 不成立 → `GuardError`；
- `os.walk` 返回 0 个 `.md` 时，**强制 `os.listdir(d)` 复核**：
  - listdir 也 0 → 确为空（正常，返回空列表）；
  - listdir 有 `.md` 而 walk 为 0 → 报 `GuardError("walk 返回0但ls发现N个.md，疑似遍历失败")` → 上层告警并中止该阶段（不写、不误判）。

## 4. 适用范围

- 月度回灌 / 每日摄入 / 知识飞轮扫描等一切「遍历目录→判定有无资产」的只读扫描；
- 扩展到所有「声明某目录/某文件为空或不存在」的断言点（含备份校验、去重跳过、迁移前侦查）。

## 5. 关联铁律

- 否定型结论·文档与实物双源交叉验证铁律（user memory 常驻）：单次检索命中 0 只能写「以当前检索式未命中」，不得写「零引用/不存在」；
- 技术标识变体假阴性铁律：否定结论须用多种书写变体交叉检索；
- 六-B 安全铁律（写入前备份 + 写入后校验）。
