# 知识飞轮系统建卡四原则

**规则正文**：自 2026-09-21 起，至少半年内（至 2027-03-21 前，或老强另有裁定前），知识飞轮所有新卡建设必须遵守以下四原则；任何**非常规域建卡 / 超配额建卡 / 需破质量门禁的卡**，一律先交老强裁决，不得自行建。

**原则一 · 配额锚定核心域（70 / 15 / 15）**
每周新增卡配额分配：核心 6 域（人伤 / 合同 / 慈善 / 证据 / 公司法 / 劳动）吃掉 **70%**；执行程序域补缺占 **15%**；其余域合计 **15%**（仅补强不扩量，不冲量）。

**原则二 · 先回填后扩量**
`statute_text_pending: true` 的 pending 卡优先清，再扩新卡。清空按「本地银行可填 → 待华宇元典mcp可填 → 真缺口永久待回源」三类逐卡处置；真缺口卡（本地司法文件 / 草案 / 省级标准）任何源都填不了，**禁翻 false**。

**原则三 · 基础设施域提质不扩量**
概念页 / 经验卡片 / 案由路由停止冲量，设质量门禁（LTI 五维 + 字数下限 + 引用锚点），重在质量而非数量。

**原则四 · 杠杆效应**
本地法条银行已零成本建成保险 / 消法 / 人损解释 / 技术合同 4 部法，核心域新卡引用边际成本趋零——重投核心域性价比高于低频域；低频域即使引用免费也不值得投入 curation 时间。

**为什么**：建库精力是稀缺资源，按业务对齐度 × 规模分配 ROI 最高；先填坑（pending）再扩量避免「红负担」长期占位阻塞 LTI 门禁；基础设施域重在质量而非数量；本地法条银行把高频引用成本压到零，核心域投入产出比最优。

**违反时会怎样**：精力被低频 / 虚高域稀释致核心域覆盖不足；pending 红卡长期阻塞门禁；基础设施域冲量致质量下降、召回噪声；绕过「交老强裁决」则建出越界卡需回滚。

**例外裁决**：任何非常规域建卡、超配额建卡、或需破质量门禁的卡，一律先交老强裁决，不得自行建。
