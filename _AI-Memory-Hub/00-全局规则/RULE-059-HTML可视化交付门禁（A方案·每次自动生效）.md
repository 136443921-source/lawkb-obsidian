# RULE-059 · HTML 可视化交付门禁

## 触发条件（自动，无需老强提醒）

只要产出物是 `.html`（看板 / 大屏 / 战情室卡族 / 推演页 / 预览页 / cockpit 子应用 / 单文件可视化），**起草前与交付前各走一遍**，不跳步。

## 三条硬线

**① 反模式 0 容忍**
10 类 AI 痕迹，出现任一即 REJECT：
标题小徽章 · 通用英文字体(Inter/Roboto/Arial) · 紫蓝渐变铺白底 · 装饰性模糊色块 · 全场大圆角 · 模板三段式 · 空话文案 · 低对比深色字 · 无意义动画 · 通用图库照片。

**② 对比度硬门槛（自己算，不凭感觉）**
- 正文 ≥ 4.5:1
- 大字（≥18px 或 ≥14px 粗体）≥ 3:1
- 徽章**禁用实心底 + 白字**（实测 amber 仅 2.17:1），一律 15% 透明底 + 同色亮字
- `--tx3` 已于 2026-10-31 由 `#6b7280`（3.91:1 不合格）提亮至 **`#7d8794`（5.19:1 AA）**；`#6b7280` 禁止再用

**③ 形态铁律**
单文件自足（CSS/JS 内联）· 离线可开 · **禁任何境外 CDN**（Tailwind CDN / Google Fonts / unpkg）· `lang="zh-CN"` + UTF-8 · 语义标签齐全 · 仅一个 h1 · 有可见 focus 态 · 尊重 prefers-reduced-motion。

## 交付时必须附的评分表

18 项三表（反模式 6 + 设计原则 5 + 可访问性 7），逐项 ✅/⚠️/❌，给 `Score X/18`。
结论三档：PASS ／ PASS-A（⚠️≤2 且表一无❌）／ **REJECT（不得交付）**。

> 与 LTI 同构：**REJECT=0 才准交付**。

## 边界（不得越界）

- ❌ **不碰 docx**：法〔2016〕221号排版铁律（A4／仿宋三号16pt／宋体22pt／28磅／页边距）与本文 px 刻度是**两套体系，一个数字都不许互搬**。
- ❌ 不管内容正确性（法条真实性/金额/案号/一致性）——那是 LTI 交付门禁（回 `RULE-060`）。
- ❌ 不授权批量改存量：现有 139 个 HTML（桌面 31 + LawKB 108）**不强制改造**，随下次维护顺手升级；批量前须老强点头 + `cp` 备份。

## 来源与实测依据（2026-10-31）

- frontend-design-pro 插件 6 技能实测：`skillOverrides` 无关闭条目、插件 `enabled=true`，**技能可用**；`claude-in-chrome` MCP 不存在 → 其浏览器三链路（Dribbble 趋势 / 网站扒色 / 实时调色板）**不可用**，仅吃静态 fallback 库。
- 现状实证：cockpit-v2 19 个子应用 **16 份各自写 `:root`**、仅 3 份引 `subapp_shell.css`、`subapp_common.css` **0 引用（死资产）**；四套深色底并存（#0b0d12 / #0b1020 / #0f1115 / #0e1117）。
- 对比度实测（基准 #0f1115）：tx 15.68 / tx2 7.43 / **tx3 3.91→5.19（2026-10-31 已修）** / red 4.80 / purple 5.03 / amber 8.69 / teal 5.58 / blue 5.26 / green 9.83。
