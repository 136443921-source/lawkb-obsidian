# 🤝 合规业务双席配合交接单模板（小德 × 🔵蓝队非诉律师）

> **用途**：处理小强律师合规业务（尤其慈善域 A 域）时，**小德（慈善合规专家·内容权威源）** 与 **🔵蓝队非诉律师（CMS 运维主导·运营总监+质控总监）** 的配合交接单一事实源。
> **铁律依据**：`RULE-BLUE-DISAMBIG` 第 8 条（2026-09-28 老强拍板固化）。
> **核心口诀**：小德「说得对」（定内容标准）；蓝队「转得动、查得出、改得掉」（做系统运维闭环）。**禁止互相甩锅**。
> **关联**：`蓝队非诉律师×小德慈善合规-关系复盘-2026-09-28.md`、PROJ-007 活文档。

---

## 一、填写总则

1. **一单业务填一张**；按「业务类型」选路由（见第三节）。
2. **质量责任切分**：内容标准归小德，系统闭环归蓝队；本单须显式勾选质量责任人，**不得两边都默认对方兜底**。
3. **入口收口**：纯慈善合规类请求统一由 `小德慈善合规中枢` 收口（慈善行业合同 / 机构制度·体检·治理）。
4. **门禁贯穿**：所有对客交付物须经 `LTI 五维 R/L/C/T/P（REJECT=0）` + `非诉文书红蓝复核工作流`（蓝队建设→红队挑刺→整改闭环）。

## 二、交接单字段表（每份业务必填）

| 字段 | 说明 | 填写方 |
|---|---|---|
| **业务编号** | 案件号类（如 6658/6660）或 `CMS-YYYYMMDD-序号` | 发起人 |
| **业务类型** | 慈善行业合同 / 慈善机构制度·体检·治理 / 通用商事合同 / 医院合规 / 涉诉涉裁（红线转诉讼席） | 入口席 |
| **入口席** | 小德慈善合规中枢（纯慈善合规统一入口） | 系统 |
| **小德动作（内容权威源）** | 注入慈善监管规则（139 条内规 + 慈法卡库）/ 出制度文本·体检报告·整改台账 | 小德 |
| **蓝队动作（CMS 运维主导 / 合同把关）** | 合同层把关执行（A 合同审查）**或** 系统运维收尾（纳入 CMS 台账 + 跑守卫 + 四通道回写 + 季度卡库喂养） | 蓝队 |
| **交付物归属** | 制度文本/体检报告/整改台账（小德内容）｜审查意见·修订版（蓝队合同）｜运维台账（蓝队运维） | 按域 |
| **质量责任人** | 内容标准：**小德**；系统闭环：**蓝队** | 双席 |
| **SLA** | 参照小德中枢 D6–D10 交付物 SLA（公募体检 10 工作日 / 募捐日历 5 工作日 / 成本测算 3 工作日 / 制度模板 5 工作日） | 小德中枢 |
| **收尾动作** | ① 蓝队跑 `cms_change_guard.sh mark "摘要"` ② 四通道回写（本卡 + CMS 母本 + 经验卡 + 日志）③ 卡库喂养（季度配额） | 蓝队 |
| **门禁** | LTI 五维 REJECT=0 + 非诉文书红蓝复核工作流 | 双席 |

## 三、路由分叉速查（谁接、谁交、怎么配合）

| 业务类型 | 入口/主导 | 小德角色 | 蓝队角色 | 配合动作 |
|---|---|---|---|---|
| **慈善行业合同**（捐赠/联合劝募/物资采购/志愿服务协议） | 小德中枢收口 | 先注入慈善监管规则（139 条内规 + 慈法卡库） | 合同层把关执行方（A 合同审查） | 小德→转合同文书管理 L0→蓝队审查→红队复核→LTI→交付 |
| **慈善机构制度/体检/治理**（非合同） | 小德中枢核心流程 | 内容权威源，出制度文本/体检报告/整改台账 | 系统层运维：纳入 CMS 台账、跑守卫、追闭环、季度审计卡库喂养 | 小德「写得对」，蓝队「转得动、查得出、改得掉」 |
| **通用商事合同 / 非慈善合同** | 蓝队直接承接（合同 C 域传统强项） | 不介入（无慈善主体） | 唯一出口：审查报告/修订版/非诉意见书 | 蓝队独立闭环，过 LTI + 红蓝复核 |
| **医院合规** | 子模板 B（医院合规与纠纷处理） | 不介入 | B 域建设（六域框架 + 8 章医疗指南重映射） | 蓝队独立建设，LTI + 《医疗纠纷条例》《广告法》核验 |
| **涉诉/涉裁/合同违约/侵权** | 红线转小强律师数字分身系统 | 仅补充慈善维度 | 不接（不出庭、不对抗） | 双席均退场，交诉讼席 |

## 四、禁止项（红线）

- 🚫 小德做**对抗式挑刺**（那是 🔴红队 的活）；
- 🚫 蓝队在「**慈善组织内部合规制度建设**」上越界小德（蓝队只做合同层把关 + CMS 运维，不搭制度）；
- 🚫 A 域交付物「**两边都以为对方兜底**」——必须在本单显式勾选质量责任人（内容标准/系统闭环）；
- 🚫 把助理（🔵-A）供料计入任一蓝队席战绩（RULE 第 2 条）。
