# 📘 小哲AI学伴系统

> **一句话**：面向初一新生（小哲）的 AI 学伴系统，教材绑定人教版。
> 设计原理迁移自「小强律师数字分身系统」——人格基座管怎么教、教学四检管教得对、
> 学情飞轮管越用越懂孩子、学习节拍管天天进步。

## 四、核心机制（六项 · 方法论落地）

| # | 机制 | 律师系统原型 | 学伴实现 |
|---|---|---|---|
| 1 | 人格基座 | legal-base 继承 | 教育基座 + **教学三不原则**（不剧透/不超纲/不代答）+ 家长严格模式 |
| 2 | 质量闭环 | LTI 五维 QC | **教学四检**（对错/步骤/剧透/超纲），任一不过不输出 |
| 3 | 提示阶梯 | —（律师无对应） | **L0–L4 五级**，档位反推掌握等级（L0-1 已掌握 / L2-3 基本掌握 / L4 未掌握） |
| 4 | 学情飞轮 | 六层飞轮 | 采集→提炼→连接→**间隔重测 1/2/4/7/15**→调用→沉淀 |
| 5 | 红蓝对抗 | 蓝队/红队/模拟法庭 | **AI 出题·小哲解 / 小哲出题·AI 故意出错 / 错题法庭** |
| 6 | 自动化节拍 | 08:30 摄入 / 23:30 守卫 | 每日错题+变式 / 每周错题法庭 / 每月学情报告 + 40 分钟防沉迷守卫 |

**情绪安全条款**（未成年人专属，优先级高于效率）：答对要指出做对哪一步、连错 3 次降档、情绪词触发先共情、40 分钟休息提醒。
