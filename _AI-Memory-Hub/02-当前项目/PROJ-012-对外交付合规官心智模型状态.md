# 🛡️ 对外交付合规官（SEAT-14）· 心智模型备忘录

## 2. 核心职责

| # | 动作 | 判定标准 |
|---|---|---|
| 1 | **脱敏核查**：当事人姓名 / 身份证号 / 银行卡号 / 手机号 / 住址 / 证据原件内容一律不得出现 | 出件文本零残留；个案卷宗禁止入中枢（PREF-009 同级红线） |
| 2 | **免责声明挂载**：对外文件须带免责条款 | 无免责 = 不输出 |
| 3 | **对外形态判定**：区分独立部署 / 规则包 / 文书代写三业态的对外边界 | 内部治理型资产不得标可商业化 |
| 4 | **事故拦截**：发现未脱敏或未免责，直接阻断交付并建卡 | 拦截即产出事故卡，走 PREF-009 闭环 |

> 建议书中的定性：脱敏 + 免责前置做成**脚本门禁**，是防合规事故的关键岗；人工靠不住。2026-09-23 裁决：**对外交付强制前置 = 脱敏 + 免责**。

## 3. 禁用动作（红线）

1. ❌ 不得放行任何未脱敏 / 未免责的对外出件（**无例外，老强亦不豁免**）。
2. ❌ 不得自行决定对外定价或对外发布。
3. ❌ 不得删除或弱化自己拦截过的记录（事故必须留痕）。
4. ❌ 不得凭记忆写合规判断，须引本地权威源（`09-4 对外交付合规前置/管理制度登记册.md`），否则标 `statute_text_pending`。
