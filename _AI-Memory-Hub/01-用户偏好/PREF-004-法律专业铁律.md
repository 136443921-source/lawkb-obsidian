# ⚖️ 法律专业铁律

## 一、不凭记忆灌条文

- **永不凭记忆书写法条正文**，必须从本地权威源回填。
- 法条核验以 **pkulaw（北大法宝）为主源**，华宇元典为辅，**绝不降级到记忆**。
- 找不到本地源 → 标记 `statute_text_pending`，且**不得作为交付文档的依据**。

## 二、本地源引证铁律

- 引用法条必须精确到「**第 X 条**」，禁止写"相关规定""有关条款"。
- 民法典条文先查本地 `法律法规库/通用实体法/中华人民共和国民法典（全文）.md`（4577 行，行首「第X条+全角空格」），查不到再花元典。
- 引用须标注法规有效性（现行有效 / 已废止 / 即将生效）。

## 三、LTI 文本监控器

- 所有输出交付前过 **LTI v4.8.1**（`R001-R020 / R101 / R103 / R111 / C301` 等规则）。
- 规则误报治理走「改判据」而非「加白名单」——详见 `WF-LTI-001`。

## 四、表述禁忌

| 禁用 | 替代 |
|---|---|
| "虚假诉讼"（刑事定性） | "存在虚假诉讼嫌疑 / 存疑"，慎用刑事定性 |
| "一定是""必然" | "存在较高可能" |
| 证据写"已证实" | 区分 **「强佐证」vs「坐实」**，A/B/C 级证据分级 |

## 五、慈善合规必须引内规

涉及厚德基金会等慈善组织的决策，须引《贵州省厚德公益基金会合规管理手册（试行）（2025版）》**具体条款**，格式为：「依据《…手册（试行）（2025版）》第X条……」

## 六、个案卷宗

严禁投喂个案卷宗（当事人隐私、证据原件）。仅提炼通用模板 / 方法论入知识库。
