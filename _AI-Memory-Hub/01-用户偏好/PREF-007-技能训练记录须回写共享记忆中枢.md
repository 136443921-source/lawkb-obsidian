# 技能训练记录须回写共享记忆中枢

> 2026-09-14 老强明确要求："蓝队出庭律师心智模型训练的相关记录应存入 LawKB 共享记忆文件内。"

## 偏好内容

**凡是针对 AI 技能的训练 / 解剖 / 调优活动，其记录必须回写 LawKB 共享记忆中枢**，不得只停留在业务目录或单次会话的 memory 里。

## 具体落位约定

| 内容类型 | 落位 |
|---|---|
| 训练方法论、解剖模板、可复用步骤 | `04-Workflows/WF-xxx.md` |
| 训练项目当前状态、成熟度基线、待办 | `02-当前项目/PROJ-xxx.md` |
| 训练相关的技术/流程决策 | `03-决策档案/DEC-YYYY-NNN.md` |
| 单日训练流水 | `04-每日日志/YYYY-MM-DD.md` |

## 配套约束（老强一贯铁律，训练场景同样适用）

- **先备份再改**：改技能文件前 `cp` 到 /tmp 时间戳目录
- **先 dry-run 再写入**：批量修改前先跑 `--dry-run`
- **先查重再建条目**：中枢已存在同类条目则更新，禁止近似重复笔记
- **不凭记忆引用**：技能路径、行号、指标值须实地 grep 复测后再写
- **隐私红线**：个案卷宗（当事人/证件号/证据原件）禁止入中枢，只提炼方法论

## 为什么重要

老强同时推进多个 AI 技能（蓝队、红队、法官、书记员等）的训练，若记录散落各处，换设备或换会话即失忆。中枢是唯一能让他"随时看清每个技能长到什么程度"的地方。
