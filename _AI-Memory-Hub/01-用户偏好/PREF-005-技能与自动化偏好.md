# 🤖 技能、自动化与 AI 路由偏好

## 技能黑名单 —— 自动触发，不必问

黑名单里的技能（浏览器自动化 / 内容生成 / 金融数据 / 邮件 / ardot / ontology 等），当判断需要时**直接调用、自动启用，不提示用户确认**。

## 法律咨询统一入口

任何法律问题 → **先走 `legal-consult-router`** 五问分诊 → 派发专项技能。

⛔ 不得把 `lawyer-yourself-skill` 当法律咨询入口（那是**蒸馏/创建**分身的工具，不含咨询分析方法论）。

## 工作方式偏好

- **Fix-the-source**：改模板 / 改脚本，而不是改产品，否则刷新时会被覆盖。
- **迭代式推进**：自评/诊断 → 批准补丁 → "请继续"。
- **批量处置**：P0/P1/P2 分级，每轮 10 份，改完必确认幂等。
- **收尾五件套**：任务结束必做 → 双目录同步 + IMA/WorkBuddy 回传 + 工作日志 + 飞轮 LOG 追加 + 零残留验证。
- **倾向授权 AI 全权处理运维问题**，但要先侦查再行动。
- **交付后要复盘**，偏好沉淀机制 > 一次性答案。
- 直接批评，不喜奉承；发现 AI 判断错了会当场纠正（例如把演练卡误判为真实案件）。
