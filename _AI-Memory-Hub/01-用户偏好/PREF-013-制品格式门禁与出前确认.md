# 📄 制品格式门禁（2026-11-13 老强立）

> **原话**：「以后系统所出的制品，我没要求出 doc 或 docx 版，就不能出，要出前请先让我确认，请把我的偏好存入系统记忆。」

## 规则

1. **默认禁止**：老强未明确要求 Word 版（`.doc` / `.docx`），系统**不得产出**任何 Word 制品。
2. **出前确认**：AI 判断需要出 Word 时，须**先征询并得到老强明确确认**；未确认＝NO-GO。禁止以「阅读版更方便」「历史模板」「顺手一起给」「沿用 [39] 默认 docx 优先」为由自动产出。
3. **明确指令＝已确认**：老强当轮明确说「出 docx / Word 版」即可直接执行，不再二次追问。
4. **默认交付形态**：对话呈现 + 必要的非 Word 中间产物（`.md` 等）。
5. **范围**：只管 Word 类制品（含阅读版／双轨版／签字版／快照版）；不扩及 `.md/.html/.pdf/.xlsx/.pptx/图片`。范围如需扩大须老强明示。
6. **场景全域（2026-11-13 老强裁定 A）**：本门禁覆盖**全部业务场景，含法律文书**（起诉状／答辩状／代理词／合同／意见书／报告等），不因「正式文书」「旧惯例」「双轨交付」自动产 Word；仅老强当轮明确要求 Word 时才出。**本裁定只解决「场景」，不扩大第 5 条的格式范围**。
