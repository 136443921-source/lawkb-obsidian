# 📄 法律文书交付与排版铁律

## 交付清单（缺一不可）

1. **DOCX 双轨**：带修订标记版（红删/绿增）+ 干净签字版，两版都要给。
2. **LTI 五维 QC**（`R`法条真实性 / `L`法理逻辑 / `C`一致性 / `T`溯源 / `P`程序），**REJECT=0 才准交付**。
3. **六维法理逻辑门禁**轮询通过。
4. 归档到桌面 `小强律师办案系统/<案件>/`，每案独立成夹，`00_-12_` 统一编号。
5. 庭审十件套（编号 00–21）三处同步存储。
6. **剔除 LTI / AI 内部附注标记**后再给客户。
7. 偏好最终存**腾讯文档（doc 格式）**。

## 排版硬参数（依据最高法法〔2016〕221号标准）

| 项 | 参数 |
|---|---|
| 纸张 | A4 |
| 正文 | 仿宋三号 16pt |
| 标题 | 宋体 22pt，居中 |
| 行距 | **固定 28 磅** |
| 页边距 | 上 3.3 / 下 3.2 / 左 2.7 / 右 2.4 cm |
| 页码 | 页脚居中 |

## 禁止的"论文化"写法

- ❌ 加粗元信息块
- ❌ 编号小标题（`一、（一）1.` 套娃）
- ❌ 独立成节的「法律依据」板块

## 公文四段式

事故表态等正式公文：**事故概况 → 管理问题 → 整改措施 → 举一反三**，800–1000 字，落款单位 + 日期。

## 起草前铁律

**先读本地源文件（md / 案卷）确认一致性**，不凭范文凭记忆空谈。当事人信息从桌面原始材料（起诉状 PDF 等）**实地核实**，不填占位符。
