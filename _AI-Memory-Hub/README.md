# 🧠 AI 共享记忆中枢（AI-Memory-Hub）

> **一句话**：Obsidian LawKB 库是老强所有 AI 项目与设备**唯一永久记忆中枢**；各平台原生 memory、聊天记录、项目上下文一律降级为**辅助缓存**，冲突时以本中枢最新有效版本为准。

## 1. 目录契约

| 目录 | 放什么 | 谁写 |
|---|---|---|
| `00-全局规则/` | 协议本身、仲裁规则、字段 schema、读写时序 | 仅人工确认后更新，AI 不擅自改 |
| `01-用户偏好/` | 老强的表达风格、输出格式、工具偏好、黑名单 | 任务结束自动提炼 |
| `02-当前项目/` | 每个活跃项目的事实状态（案号、阶段、下一步） | 任务结束自动提炼 |
| `03-决策档案/` | 重要决策：考虑了什么、否了什么、什么信号会推翻 | 任务结束自动提炼 |
| `04-Workflows/` | 可复用工作流卡 / SOP 卡（流程型知识资产） | 任务结束自动提炼 |
| `04-每日日志/` | `YYYY-MM-DD.md` 按天追加的原始提炼流水 | 复盘脚本 + 各 AI |
| `05-归档/` | 被淘汰 / 被取代的旧条目，**只读** | 复盘脚本自动搬运 |
| `06-经验沉淀/` | 经验卡 / 事故卡 / 思维轨迹卡等可复用知识资产（EXP-*） | 任务结束自动提炼 |
| `07-卡族总索引/` | 知识飞轮各卡族「卡型定义与总索引」统一指针目录（IDX-CARDFAMILY） | 新增 / 迁移卡族时同步更新 |
| `08-心智资产/` | 四方 persona 心智卡 + 对抗标本源统一指针目录（IDX-MINDASSET） | 新增 / 迁移心智资产时同步更新 |
| `99-脚本/` | 读写与复盘脚本 | 人工维护 |

> ⚠️ 目录契约于 2026-09-15 同步磁盘现状：补登 `04-Workflows/`、`06-经验沉淀/`、`07-卡族总索引/`、`08-心智资产/`（此前漏登记）。新增卡族总索引请统一写入 `07-卡族总索引/_索引.md`；新增 persona 心智卡 / 对抗标本源指针请统一写入 `08-心智资产/_索引.md`。

## 2. 三时序铁律

```
┌─ 任务开始前 ─────────────────────────────────────┐
│ read_hub.py --brief   → 装载规则+偏好+活跃项目+近期决策 │
│ 不读 = 不准开工（等价于 agent 失忆状态）              │
└──────────────────────────────────────────────────┘
                        ↓
                   执行任务
                        ↓
┌─ 任务结束后 ─────────────────────────────────────┐
│ write_back.py --type <rule|preference|decision|    │
│               project-fact|workflow> --dry-run 先试 │
│ 提炼 → 查重 → 冲突仲裁 → 落库 → 刷新索引            │
└──────────────────────────────────────────────────┘
             ↓ 每日 01:00（次日 08:00 幂等补跑）
┌─ 复盘 ───────────────────────────────────────────┐
│ daily_review.py  扫四类素材 → 去重 → 解冲突 → 淘汰  │
└──────────────────────────────────────────────────┘
```

## 4. 红线

1. **绝不删除** `05-归档/` 内任何文件——那是审计留痕。
2. **绝不批量覆写**旧条目；冲突走 `superseded` 链式指向。
3. **绝不在未备份的情况下改 `00-全局规则/`**——那棵树改一次影响所有设备。
4. 个案卷宗（当事人隐私、证据原件）**禁止入中枢**，只提炼方法论与工作流事实。
