# DEC-2026-033 · 同号冲突方案 B 落地（改 rule_id 不改名，34组归零）

## 背景

MOC 全量重扫发现 **34 组同号冲突**。老强初始提议「保留主库副本、其余改名加后缀」。

## 关键实证（决定了方案选择）

| 指标 | 实测 |
|---|---|
| 68 个冲突文件被 wikilink 引用 | **516~844 次**（视扫描范围） |
| 被引用的冲突文件 | **67 / 68**（仅 1 个零引用） |
| wikilink 引用对象 | **完整文件基名**（如 `[[R-RA-001-名誉权侵权四要件举证分配]]`），**不是 rule_id** |

**决定性推论**：两个同号文件因基名不同，**wikilink 本来就不冲突**；改 `rule_id` **零断链**，改名才断链。

## 决策：方案 B（只改 frontmatter rule_id + 登记 aliases）

**同时否决了三个自动判据**（实测均不可靠）：
1. `card_family` 优先 → 102 张卡双空，多数族判定失真
2. 路径（裁判规则库/ 优先）→ PR 域判反（该域 296 张绝大多数在证据规则卡族）
3. 域内多数族 → 大量"未标族"成为多数，R-CS-001/R-HT-302 判反

**最终采用唯一客观可解释判据**：**引用次数多者保留原号**（影响最小原则），引用平手时比字节数（内容更完整）。

方案 B 必然产生「文件名 ≠ rule_id」。已在 `_规则卡编号体系规范.md` 新增「四之二」节，
明确 G2 在「有 rule_id + 有 aliases + 文件名不变 + dups 为空」四条件齐备时属**合法状态**。
