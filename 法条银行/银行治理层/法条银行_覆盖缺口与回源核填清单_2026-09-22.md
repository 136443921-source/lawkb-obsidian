# 法条银行 · 覆盖缺口与回源核填清单（结合 OPC 一人公司治理）

> 一句话结论：
> 1. **OPC 一人公司治理直接依赖的法条中，《律师法》是硬缺口（未收录）**，《价格法》《反垄断法》是商业化定价业态的潜在缺口；其余治理锚点（公司法/民法典/个保法/数据安全/著作权/商标/广告法/消法/反不正当竞争/劳动合同）**均已收录但几乎全部「版本状态=未标 + statute_text_pending=未标」，需 MCP 回源核填版本指纹**。
> 2. 台账 95 行中，**仅约 13 行达「双证一致/官网印证」**，约 60+ 行处于「未标」待核状态；**statute_text_pending:true 实质卡仅 1 张**（慈善法 2023 备份卡）。
> 3. 补全清单（2026-09-21）P0-#2/3/4/5（保险法/消法/人损解释/技术合同解释）**实际已落入台账**——清单相对台账存在状态漂移，应以台账为准、补全清单状态待回填纠正。

## 一、OPC 一人公司治理架构的法条消费域 & 覆盖状态

对标 `09100 治理架构调整方案` §1 映射表 + `09101 公司章程` §1 拟法人定位 + `09104 数字员工编制方案` §1 法律分层：

| OPC 治理法律要素 | 对应法条 / 法域 | 法条银行覆盖状态 | 处置类别 |
|---|---|---|---|
| 一人公司映射（唯一股东/执行董事/章程/法人资产隔离） | **公司法（2023修订）** 第11、57-60、227条（一人公司特别规定：一个自然人只能设一个一人公司；股东不能证明财产独立→连带责任；章程由股东制定） | ✅ 已收录（row 84）但 **版本状态=未标 / pending=未标** | 需 MCP 核填 |
| 对外出具法律意见须执业律师终确认、不得冒用律师署名 | **律师法** | ❌ **未收录（硬缺口）** | 未覆盖·须建 |
| 失能即冻结、待法定继承（nominee C 方案） | 民法典继承编（第1121-1163条，已含全文卡） | ✅ 已收录（row 87）但 pending=未标 | 需 MCP 核填 |
| 对外交付强制前置=数据脱敏（2026-09-23 裁决） | **个人信息保护法 / 数据安全法 / 网络安全法** | ✅ 已收录（row 90/95/98）但均 **未标** | 需 MCP 核填 |
| 规则包业态知产归属拟法人 | **著作权法 / 商标法 / 专利法** | ✅ 已收录（row 99/92/89）但均 **未标** | 需 MCP 核填 |
| 数字员工对外明示（不得虚假宣传/知情权，§8.2 红线） | **广告法 / 消费者权益保护法** | ✅ 已收录（row 72/95）但均 **未标** | 需 MCP 核填 |
| 商业化定价/SKU 合规边界（R-2 老强拍板） | **反不正当竞争法（2025修订）/ 价格法 / 反垄断法** | ⚠️ 反不正当竞争法已收录（row 91 未标）；**价格法/反垄断法未收录** | 反不正当竞争法需核填；价/反垄断未覆盖·须建 |
| 数字员工「非法律雇员」硬法论证（§1 硬法：公司法/劳动法） | **劳动合同法（2012修正）** | ✅ 已收录（row 86）但 **未标** | 需 MCP 核填 |
| 法人独立责任、认缴出资为限担责 | 民法典（法人/代理编，已含全文卡） | ✅ 已收录 row 87 | 需 MCP 核填 |
| 服务协议免责条款（私有部署业态） | 民法典合同编（已含全文卡） | ✅ 已收录 row 87 | 需 MCP 核填 |

**OPC 治理专项结论**：① 治理骨架法条（公司法/民法典）已收录，但**版本指纹 0 核验**，LTI 门禁下虽不拦（pending 未标≠true），但作为「一人公司映射」权威依据的版本可信度未达标；② **《律师法》是 OPC 治理对外「文书代写业态」的合规根法，必须补建**（09104 已明文援引为专门法底线）；③ **价格法/反垄断法**是三业态定价的法定规制依据，建议补建。
