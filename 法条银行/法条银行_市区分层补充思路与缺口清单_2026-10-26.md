# 法条银行 · 市区分层补充思路与缺口清单（对标华宇元典）

> 本文档目标：① 复盘本地法条银行家底；② 用元典（yuandian-mcp）实跑数据对标国家/省级覆盖；③ 诚实识别**真实缺口**（纠正"元典完全不收市/区"的误解）；④ 给出两大执业方向（慈善组织合规 + 人伤）需补充的市/区及实操口径清单；⑤ 给出可落地的补充思路方案。

---

## 一、本地法条银行现状复盘（按层级统计）

> 数据基准：治理短索引 `data_asof: 2026-10-15`（实库 106 张 statute 卡；目录文件约 118，含 B 型资讯/案例卡）。结论：**重国家、稀省级、市/区与实操口径层为零**。

### 1.1 各子库体量（A/B 型合计）

| 子库 | 文件数 | 层级属性 | 备注 |
|---|---:|---|---|
| 通用法律法规 | 26 | 国家法律为主 | 商标法/著作权/消保/个保/数据安全/网安/广告法为**空壳卡（C 类）** |
| 司法解释 | 19 | 国家司法解释 | 人伤相关较全（人身损害/医疗损害/道交/交通肇事） |
| 医事法律法规库 | 19 | 国家法律+行政法规+部门规章 | 医疗方向国家队较齐 |
| 通用实体法 | 13 | 国家法律 | 民法典全文巨石卡 |
| 行政法律规章 | 13 | 行政法规+部门规章 | 含企业所得税扣除凭证、劳动关系确立通知 |
| 慈善合规类法律法规 | 11 | 国家法律+行政法规+民政部规章 | 慈善方向国家队较齐 |
| 通用程序法 | 6 | 国家法律+司法解释 | — |
| 监管类 | 6 | 民政部/发改等规章 | 含取缔非法社会组织(77号)、社会组织评估(82号) |
| 地方性法规·贵州 | 5 | **省级** | 实为 3 张黔高法司法文件 + 2 张省条例/高院管理 |
| 最高院指导案例 / 法律资讯周报 | (B 型) | 案例/资讯 | 非 statute |
| **市级 / 区级 / 部门实操口径** | **0** | — | ⚠️ **系统性空层** |

### 1.2 核心结论

- **国家层面（法律/行政法规/司法解释/部门规章）**：覆盖率高，仅个别空壳（商标/著作权/消保/个保/数据安全/网安/广告法）。这不是本次补充重点。
- **省级层面（贵州）**：只有 5 张，且 3 张是黔高法司法文件，**省级地方性法规/政府规章/省级部门规范性文件专题几乎空白**。
- **市级 / 区级 / 实操口径层**：**0 张**。这是本次补充的绝对主战场。

### 2.2 覆盖度矩阵（元典 vs 本地银行）

| 层级 | 元典覆盖 | 本地银行现状 | 缺口性质 | 是否需本地补 |
|---|---|---|---|---|
| 国家法律/行政法规/司法解释 | 🟢 全覆盖 | 🟢 基本全覆盖 | 个别空壳 | 低（回填空壳即可） |
| 部委规章 | 🟢 覆盖好 | 🟢 较好 | 少量待回填 | 低 |
| 省级地方性法规/政府规章 | 🟢 覆盖好（实证：黔政府令208） | 🟡 仅 5 张且偏司法文件 | 缺省级专题 | **中** |
| 省级部门规范性文件（省人社厅/省税务局/省民政厅） | 🟢 覆盖较好（实证 B/C 组） | 🔴 几乎无 | **重大缺口（常被误判为元典不收）** | **高** |
| 设区的市文件（市府规章/市部门） | 🟡 选择性（安顺/遵义/贵阳医疗纠纷在） | 🔴 0 | 缺口（非医疗类市文件） | **高** |
| 区级（市辖区）文件 | 🔴 基本不收（region 枚举无市/区） | 🔴 0 | **系统性缺口** | **高（刚需）** |
| 地方司法文件（高院/中院明传·纪要·解答） | 🔴 基本不收（实证：黔高法明传46 not_found） | 🟡 仅 3 张黔高法 | **重大缺口（人伤裁判尺度刚需）** | **高** |
| 内部实操口径（答复/指引/办事指南/裁量基准） | 🔴 选择性/少 | 🔴 0 | 缺口 | **高** |
| 年度动态标准（赔偿基数/待遇调整） | 🔴 不实时维护 | 🔴 0 | **重大缺口（人伤计算刚需）** | **高（最高优先）** |

### 2.3 诚实澄清（重要，避免重复造卡）

> 老强原判断"地方税务局、人社局、地方政府发布的实操口径往往不在元典收录范围"——**部分成立、部分需修正**：
> - ✅ **成立的部分**：区级（市辖区）文件元典结构上看不到；地方司法审判尺度（高院明传/中院纪要/解答）元典基本不收；内部答复/裁量基准/办事指南选择性缺失；年度动态基数不实时维护。
> - ❌ **需修正的部分**：**省级部门规范性文件（省人社厅、省税务局、省民政厅）元典收得相当好**，部分设区的市税务局/市政府的公开规范性文件也收。因此补充时**不要**把"所有省/市部门文件"都搬进本地银行——先查 `yuandian_verify`，元典已收录且现行有效的，**只需建一张"索引桩 + 本地核验"薄卡**，把精力放在元典系统性缺失的层（区级 / 地方司法文件 / 内部口径 / 年度动态标准）。

## 四、补充思路方案（落地 6 步）

### 4.1 第一步：分层建模（把"法规金字塔"写进 Schema）

在现有 RULE-038 A 型卡基础上，扩展 `effect_rank` 取值，把四层显式建模：

```
effect_rank 取值扩展建议：
  法律 | 行政法规 | 司法解释 | 部门规章
  | 地方性法规(省级) | 地方政府规章(省级)
  | 省级部门规范性文件        ← 元典有，本地建"薄索引卡"
  | 设区的市规范性文件        ← 元典选择性，本地补薄卡
  | 区级实操口径              ← 元典系统性缺失，本地建"全卡"
  | 地方司法文件(审判尺度)    ← 元典不收，本地建"全卡"（如明传46先例）
  | 年度动态标准              ← 元典不维护，本地建"全卡+滚动"
  | 内部实操口径(答复/指引/裁量基准) ← 元典少，本地建"全卡+免责标注"
```

> 沿用现有 `yuandian_verify` 字段（已有先例）：元典未收录 → 标 `not_found` + `本地独有`；元典已收 → 标 `found` + 建薄索引卡，不重复灌全文。

### 4.2 第二步：确立采集源清单（市/区 + 实操口径去哪找）

| 来源类型 | 具体入口 |
|---|---|
| 政府公报 | 《贵州省人民政府公报》《贵阳市人民政府公报》（历年卷，市/区文件常登载） |
| 部门官网 | 贵州省民政厅 / 省人社厅 / 省税务局 / 省卫健委 / 省医保局 官网"规范性文件"栏目 |
| 市局官网 | 贵阳市民政局 / 市人社局 / 市税务局 / 市卫健委 / 市医保局 官网"办事指南/通知公告" |
| 区局口径 | 各区（云岩/南明/观山湖/花溪…）政府网 + 办税厅/社保经办大厅 **现场取材料清单** |
| 法院口径 | 贵州高院官网"审判业务/司法文件" + 各中院官网；明传/纪要/解答多不公开，靠案例反推 + 同行交流 |
| 年度基数 | 贵州高院每年《人身损害赔偿计算标准》通知 + 省统计局公报 + 省人社厅待遇调整通知 |

### 4.3 第三步：卡片化规范（实操口径的特殊免责）

实操口径/内部指引/年度标准类卡，frontmatter 增加：

```yaml
effect_rank: 区级实操口径 | 地方司法文件 | 年度动态标准 | 内部实操口径
is_authoritative_law: false        # 明确"非立法文件"
citation_restriction: 不得条号级引用，仅供办案口径参考   # 类比现有"公众号源禁条号级引用"
review_interval: 90 | 365         # 动态标准设滚动复核
yuandian_verify: not_found         # 本地独有，差异化价值标记
dynamic_base: true                 # 年度基数类标记，便于脚本滚动
```

> 延续铁律：实操口径类**禁条号级引用**、标"仅供参考"；年度动态标准类设 `review_interval` 强制滚动，避免用过期的赔偿基数/待遇数字。

### 4.4 第四步：优先级与批次（避免一次性铺开）

- **P0（最高优先，先补）**：人伤年度动态基数标准（人身损害赔偿计算标准、工伤待遇核定口径、工伤保险规程全文）—— 这是办案天天要查、元典不维护的"硬缺口"。
- **P1（次优先）**：省级部门实操口径 + 贵阳市级文件（已确证元典有但需本地薄卡/现行版的，如贵阳医疗纠纷办法现行版）。
- **P2（收口）**：区级实操口径（社区慈善、区工伤认定/医疗纠纷经办指南）—— 元典结构性缺失，按办案实际逐步积累。
- **P3（长期）**：内部口径/裁量基准/已失效但有用文件。

> 节奏建议：每轮补 10 份（沿用你"批量更新10份/轮"纪律），先 dry-run 列清单 → 老强核定 → 再建卡，保持幂等。

### 4.5 第五步：目录规划（放在哪）

在 `法条银行/` 下现有 `地方性法规·贵州/` 旁，新增子目录承接补充层（不破坏现有结构）：

```
法条银行/
├── 地方性法规·贵州/            （现有：省条例+黔高法司法文件）
├── 实操口径与动态标准/          ← 新增
│   ├── 慈善合规·省级实操/
│   ├── 慈善合规·市区实操/
│   ├── 人伤·交通/
│   ├── 人伤·工伤/
│   ├── 人伤·医疗/
│   └── 年度动态基数/            ← 人伤赔偿/工伤待遇年度数字集中放
└── 银行治理层/                  （现有：Schema/制度/台账）
```

> 台账：`银行治理层/_本地法条银行_覆盖台账.md` 增加"层级"列，把市/区/实操口径层单独登记，便于 LTI 与管线检索区分"权威法源"与"实操口径"。

### 4.6 第六步：维护机制（让补充层活起来）

- **年度基数类**：设 `review_interval`，每年贵州高院/省人社厅发文后 15 日内滚动更新一版（可走你现有的"每日摄入/周报"自动化思路，定向抓取公报）。
- **省级部门文件**：建卡时标 `yuandian_verify: found` 薄索引， quarterly 抽查是否失效。
- **区级/内部口径**：随办案实际触发采集（遇到一个区税务局口径就建一张），不强行铺开。
- **失效标记**：沿用 `sxx` 枚举 + `superseded_by`，贵阳医疗纠纷办法(2019失效) 这类必须标红，避免引到旧规。

> 你本地银行是"**国家重仓、省级稀、市/区与实操口径为零**"；元典是"**国家+省级（含省级部门规范性文件）收得好、部分市级公开文件也收、但区级/地方司法审判尺度/内部口径/年度动态基数系统性缺失**"。**补充主战场 = 元典结构性缺失的四类（区级、地方司法文件、内部实操口径、年度动态标准）+ 你两大方向的省级部门实操**，且凡元典已收录的只需建"薄索引卡"，把力气花在真正本地独有、天天要查的刚需上。
