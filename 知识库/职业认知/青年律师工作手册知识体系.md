## 使用指南

### 1. 知识链接
- 使用`[[ ]]`双链语法建立知识点间的关联
- 链接到具体的法律法规，如[[民法典]]
- 链接到相关司法判例，如[[最高人民法院指导案例]]

### 2. 知识更新
- 定期回顾和更新卡片内容
- 添加新的法规变化和判例发展
- 结合自身实践补充实务经验

### 3. 知识应用
- 在实际案件中使用相应卡片作为检查清单
- 在谈判前复习相关谈判技巧卡片
- 在合同审查时对照思维体系卡片

### 4. 知识扩展
- 为每个"待创建"卡片创建具体内容
- 根据专业领域需求添加新的卡片模块
- 与团队成员共享和协作完善知识体系

## 技术实现

### Obsidian配置建议
1. **插件安装**：
   - Dataview：用于查询和统计卡片
   - Templater：快速创建标准卡片模板
   - Tasks：管理知识学习任务
   - Canvas：可视化知识关系图谱

2. **文件夹结构**：
   ```
   LawKB/
   ├── 知识卡片/
   │   ├── 职业认知/
   │   ├── 业务技能/
   │   ├── 合同审查/
   │   ├── 诉讼技能/
   │   ├── 综合能力/
   │   ├── 专业领域/
   │   └── 工具方法/
   └── 法律法规/
       ├── 民法典/
       ├── 司法解释/
       └── 指导案例/
   ```

3. **查询示例**：
   ```dataview
   TABLE 主题, 标签, 创建日期
   FROM "知识卡片"
   SORT 创建日期 DESC
   ```
