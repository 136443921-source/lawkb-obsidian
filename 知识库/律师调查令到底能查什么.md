# 律师调查令到底能查什么？



民事诉讼里最让当事人和律师头疼的，莫过于“取证难”“执行难”这两个坎。很多时候，明明当事人占理，却因为拿不到关键证据，只能看着对方隐匿事实、逃避责任；还有些案件，判决下来了，却找不到被执行人的财产线索，胜诉判决最终变成一张“法律白条”。而律师调查令，就是在实务中破解这两个难题最常用的工具之一。

**0****1**什么是调查令
从法律依据来说，《中华人民共和国律师法》第三十五条第二款：律师凭执业证书和律师事务所证明，就能向有关单位或者个人调查与承办法律事务有关的情况。《[[中华人民共和国民事诉讼法|中华人民共和国民事诉讼法]]|中华人民共和国民事诉讼法|中华人民共和国民事诉讼法|中华人民共和国民事诉讼法|中华人民共和国民事诉讼法|中华人民共和国民事诉讼法|中华人民共和国民事诉讼法 1》第六十七条第二款：当事人及其诉讼代理人因客观原因不能自行收集的证据，法院应当调查收集，而调查令，就是这种“调查收集”的延伸，让律师的调查行为有了法律“背书”，也让被调查单位没有了拒绝的合理理由。

这里有个关键点，律师调查令只能调取“当事人及其代理人因客观原因不能自行收集的证据”，那些我们自己能拿到的、或者法院必须亲自调取的证据，申请调查令也没用。

**0****2**调查令能查些什么
（一）身份信息类

**1.自然人身份信息：**包括户籍登记信息、身份证信息、婚姻登记信息（结婚证、离婚证、离婚协议）、社保记录、征信记录，还有被执行人的手机号、固定电话等。

2. 法人及非法人组织身份信息：包括工商登记信息（含内档）、统一社会信用代码、法定代表人信息、股东信息、股权变更记录等。

注意：调取这些身份信息，只能用于本案的诉讼或执行，绝对不能泄露给第三方，更不能用于与案件无关的用途。

**（二）财产信息类**

1.不动产信息：房屋、土地的所有权登记信息、抵押信息、查封记录，还有拆迁补偿协议等。

2. 动产信息：车辆登记信息、过户记录、抵押查封信息，还有船舶、航空器等大型动产的登记信息。

3. 金融资产信息：这是最核心、也是最容易找到财产线索的部分，包括银行存款账户信息、银行流水、理财产品、股票、基金，还有微信、支付宝等第三方支付平台的账户信息、转账记录。

4. 其他财产信息：包括股权、商标权、专利权等无形资产，还有被执行人的工资收入、租金收入等。

**（三）交易及往来信息类**

1.合同及履行凭证：各类合同原件、复印件，还有送货单、收货单、付款凭证、发票等。

2. 通信及社交信息：手机通话记录、短信、电子邮件，还有微信、QQ、抖音等社交平台的实名信息、聊天记录。

3. 相关单位备案信息：公安部门的出警记录、询问笔录，税务部门的纳税记录，医院的病历资料、诊断证明等。

**（四）其他与案件相关的辅助证据**

除了上面三类常见信息，只要是与案件事实直接相关、又无法自行收集的证据，都可以申请律师调查令调取，比如：

1. 证人相关信息：虽然调查令一般不能直接调取证人证言，但可以凭调查令调取证人的身份信息、联系方式，方便联系证人、核实证言真实性。有时候证人拒绝配合作证，也能通过调取相关辅助信息，间接佐证证人证言的可信度。

2. 鉴定相关信息：比如鉴定机构的资质证明、鉴定报告附件、鉴定过程记录等。

3. 劳动争议相关信息：比如用人单位的考勤记录、工资发放记录、劳动合同备案记录等。

**（五）执行阶段的专项调查**

执行阶段的调查令，针对性更强，主要围绕“被执行人的履行能力、财产隐匿转移情况”展开，除了上面说的财产信息，还能查这些专项内容：

1. 被执行人是否违反限制消费令、限制出境的相关记录；

2. 被执行人与利害关系人的财产往来、债权债务关系；

3. 被执行人涉嫌拒不执行判决、裁定罪的相关证据；

4. 被执行人的经营场所、生产设备、原材料等信息。


这些信息虽然不是直接的财产，但能反映被执行人的履行能力，帮助法院采取强制措施。

**0****3**这些情况调查令查不了
（一）法院必须亲自调取的证据

根据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第九十六条规定，有五类证据，必须由法院依职权调取，不能通过调查令调取，比如**涉及国家利益、社会公共利益的证据，涉及亲子关系、收养关系等身份关系的证据，还有公益诉讼相关证据等。**

（二）律师能自行调取的证据

调查令的核心是“弥补自行取证的不足”，如果凭自己的能力，或者凭律师执业证书、律师事务所证明就能调取的证据，就没必要申请调查令。

（三）法律禁止查询的涉密信息

涉及国家秘密、商业秘密、个人隐私且与案件无关的信息，绝对不能用调查令调取；即使与案件有关，如果调取后可能损害国家利益、他人合法权益，也不能调取，只能申请法院依职权调取。

（四）与案件无关的信息

调查令的调查范围，必须与案件待证事实直接相关，与案件无关的信息，即使申请了，法院也不会批准。

（五）其他不宜用调查令调取的证据

根据各地实务操作，证人证言、物证（需要法院现场勘验）、需要专业机构鉴定的证据（需要法院委托）等，也不宜用调查令调取。

**0****4**注意事项
（一）申请条件

1. 申请人：只能是案件当事人的代理律师，当事人本人不能申请——这是很多当事人的误区，以为自己能直接向法院申请调查令，其实不行，必须委托律师代为申请。

2. 申请阶段：起诉、审理、执行阶段都能申请，再审审查阶段基本上都不能申请；起诉阶段只能调取与立案相关的证据，审理阶段要在举证期限届满前申请，执行阶段要在执行完毕前申请。

3. 所需材料：申请书、授权委托书、律师事务所指派函、律师执业证书、调查令使用承诺书。其中，申请书一定要写详细，列明调查事项、调查目的、被调查单位、证据线索，不能含糊其辞。

**（二）使用规范**

1. 持令要求：持调查令调查时，必须主动出示调查令和执业证书，向被调查单位说明调查目的和范围，不能隐瞒、误导对方。

2. 保密义务：凭调查令获取的证据和信息，只能用于本案诉讼，不能泄露、散布，不能用于与案件无关的用途。

3. 期限要求：调查令的有效期由法院确定，最长15个工作日，过期自动失效；如果因为正当理由没完成调查，可以申请延长一次。

4. 证据提交：调取证据后，要在5个工作日内把全部证据和调查回执提交给法院；如果调查令没使用，也要在期限届满后5个工作日内归还法院入卷，不能私自留存。

**（三）不配合调查的后果**

实务中，会经常遇到被调查单位以“领导不在”“内部规定”为由，拒绝配合调查，很多人觉得，不配合也没关系——这种想法大错特错。律师持令调查，等同于法官亲自外出调查，被调查单位和个人有义务配合，无正当理由拒绝配合，会面临严重的法律后果。

根据《民事诉讼法》相关规定，被调查单位无正当理由拒绝配合的，法院可对单位处以5万元以上100万元以下罚款，对个人处以10万元以下罚款；对仍不配合的个人，可予以15日以下司法拘留，还可以向其上级主管部门提出纪律处分建议。

**0****5**写在最后
回到大家最关心的问题，律师调查令到底能查什么？其实答案很简单，它能查的，是与案件事实相关、无法自行收集，且不违反法律规定的证据；它不能查的，是超出法律边界、与案件无关，或者应当由法院亲自调取的信息。
