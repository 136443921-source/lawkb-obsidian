## 一、判例库结构

```
贵州法院判例库/

├── 贵州省高级人民法院
│   ├── 民事判例/

├── 其他市州中院（遵义/毕节/黔东南等）
└── 基层法院典型案例/
```

---

## 二、判例入库标准

### ✅ 应当入库的判例
1. **最高人民法院指导性案例**（贵州法院应当参照）
2. **贵州省高院发布的典型案例**（年度案例报告）
3. **贵阳中院典型案例**（辖区内有指导意义）
4. **新型/疑难案件**（法律适用有争议）
5. **与本省经济社会发展相关案件**（如脱贫攻坚、生态环保、大数据等）

### ❌ 可以不入库的判例
1. 事实清楚、法律适用明确的普通案件
2. 程序性裁定（如驳回起诉、管辖权异议等）
3. 已废止法律适用的判例

## 六、使用方法

### 场景1：准备类似案件诉讼
```
1. 在判例库中搜索类似案由
2. 查看法院争议焦点归纳
3. 参考法院适用法律条文
4. 借鉴法院裁判理由表述
```

### 场景2：法律检索补充
```
1. 在法条检索后，到判例库验证适用
2. 查看同级/上级法院类似案件裁判规则
3. 评估我方主张被法院支持的可能性
```
