# 第 9 章 · 知识飞轮｜造你自己的"电池"

> **你要准备的东西**：前七章装好的手（WorkBuddy）、脑子（Obsidian）、料仓（IMA）、案件保险柜，上一章刚建好的总记忆；一个你最近办完的案子
> **今天要过的六关**：给知识建三个房间 → 炼第一张要点卡 → 再提一张规则卡 → 装电机 → 装动能回收 → 验收
> **总共用时**：约 2 小时 15 分（可以分两天做）
> **做完你会得到**：三个装知识的房间 + 一张八段要点卡 + 一张三小段规则卡 + 一句办案前固定要说的话 + 一份黑匣子
> **本章施工第一总成**：三电系统（动力电池＝知识飞轮）

---
## 开始之前，先记住一句话

**这颗电池，不是买来的，是炼出来的。**

前面七章，你把手（WorkBuddy）、脑子（Obsidian）、料仓（IMA）、案件保险柜都装好了，立了铁律、接上大脑，上一章刚造出所有部件共用的总记忆。可总记忆记的是**你是谁、你的规矩、你在办什么**——它不记知识。车要会办案，还得有燃料：法条怎么查、这类争点怎么拆、上次那个坑是怎么绕过去的。

所以这一章，给这台车造它的第一颗「电池」：**一个知识库**。

但最反直觉的一点是：**这颗电池，你下载不到、也买不到。** 网上下载的「法律资料大全」，是一堆没读过的文件，不是电池。真电池，是你把一个一个案子，**亲手炼成一张一张卡**，攒出来的。

**别人给你的是柴火，你得自己炼成炭。这一章，学炼炭。**

顺带说清一句：**这一章不造任何看板，只造能被搜出来的卡。** 卡躺着不算数，得有一下「办案时自己想起来」的劲，那才叫装上了电机。

另外说句让你安心的：这一章**全在 Obsidian 里做**，而 Obsidian 在苹果电脑和 Windows 电脑上长得**一模一样**——两种电脑照着做就行，不用分。

**六关，约两小时。做完之后，你有一台会自己越用越有劲的车。**

## 第一关 · 给知识建三个房间（15 分钟）

### ① 做什么

你的知识，现在散在各处——微信收藏、网页剪藏、随手记的便签。这一关，让 WorkBuddy 帮你在 Obsidian 库里**建一个专门放知识的家**，现在就建三个「房间」。现在它们**还不存在**，这一关把它们**造出来**。

### ② 怎么做

**第 1 步**：跟 WorkBuddy 说：

> **跟 WorkBuddy 说：**
> 「我要给自己的知识建一个家。帮我在我的 Obsidian 库里建三个文件夹，分别放三样东西：① 从外面收进来、原样不动的材料；② 正在整理、正在拆的卡；③ 已经做好、以后不再改的卡。建好告诉我这三个文件夹各叫什么名字。」

**第 2 步**：它可能会问你「你的 Obsidian 库在哪个文件夹？」——你把它打开给你看（或直接告诉它库的位置）。

**第 3 步**：等它回你一句，说建好了，并念给你**三个文件夹的名字**。

### ③ 你会看到什么

打开 Obsidian，看左边文件列表，出现了**三个新文件夹**。WorkBuddy 会告诉你，它给这三个房间起了名：

```
第一个，收进来还没动的材料
第二个，放正在拆的卡的
第三个，做好不再改的卡
```

它会念出三个具体的名字，用数字开头，好让它们排在最上面。**看到左边多出三个文件夹、名字念得清顺序，第一关就过了。**

**对照一下**：如果只出现一两个，或者三个名字你分不清哪个该先放、哪个该后放，直接说「重新建一遍，名字要让我一眼看出顺序」。房间少了、顺序乱了，第二关的卡就没地方落。

### ④ 为什么要分三个房间，不塞一个里

因为**你以后会存几百个文件**。分三个房间的好处是：**你永远知道该去哪儿找，也永远知道哪一步没做完**——收进来的材料在第一个，做到一半的在第二个，做完的在第三个。

**三个房间，就是一条流水线。** 现在空的没关系，先把工位摆好。

**三个房间只是起步这一套，不是标准答案。** 房间不止这一种——以后东西多了，你开始纠结「这条该放哪」，再加新房间，用到哪种加哪种。别现在就纠结要不要一次多建几个。

## 第二关 · 炼第一张要点卡（30 分钟）

### ① 做什么

拿你最近办完的一个案子，让 WorkBuddy 帮你把它**炼成一张「能反复用的卡」**——这张卡记住的，是这个案子里**最该被记住的那几个「要点」**。这张卡现在**还不存在**，这一关把它**造出来**。

### ② 怎么做

**第 1 步**：准备三样东西（**不用整理，直接抄**）：

- 这个案子的**争议焦点**（一句话）
- 法院最后**怎么说的**（判决书「本院认为」那一段，直接复制）
- 你觉得**最扎心的那一点**（哪句话让你当时答不上来）

**第 2 步**：跟 WorkBuddy 说：

> **跟 WorkBuddy 说：**
> 「帮我把下面这个案子，拆成一张以后能反复用的卡。这张卡要能回答这几件事：
> ① 这个案子讲了一条什么规则（一句话说清）；
> ② 法官会按什么顺序查这条规则；
> ③ 要满足哪几个条件、每个条件由谁举证；
> ④ 这条规则的法律原文（逐字引用，标出哪部法第几条）；
> ⑤ 什么情况下这条规则不适用；
> ⑥ 用这条规则的人，常在哪里用错；
> ⑦ 这个案子是哪个法院判的、在哪个省有效。
> 另外：当事人一律用『甲』『乙』代替，不出现任何真名、身份证号、电话、地址；法条核不到原文的地方写待核三个字，别自己编。最后存成一个文件，放进我刚建好的、『放做好卡』的那个文件夹里。」

（把你在第 1 步准备的三样东西，粘在这段话下面。）

**第 3 步**：等它写完。**如果它说「需要你确认编号」，你回一句「编号先不定，你随便写个临时的」。**

### ③ 你会看到什么

打开 Obsidian，点进「放做好卡」那个文件夹，里面出现了**一个新文件**。点开它，你会看到它被分成了**好几个带小标题的部分**。WorkBuddy 会告诉你，它把这张卡拆成了**八段**：

```
① 一句话规则  ② 法官怎么查  ③ 几个条件、谁举证  ④ 法条原文
⑤ 什么情况不适用  ⑥ 常在哪里用错  ⑦ 哪个法院判的、哪个省有效  ⑧ 关联（这一段空着）
```

它还会告诉你：**这张卡叫「要点卡」**——因为它记的是「一个案子的要点」。

**看到这八段小标题都在，第二关就过了。**

**对照一下**：把第④段念一遍。合格的写法是「哪部法、第几条、原文照抄」；写成一句笼统的概括，或者干脆空着没写「待核」，就是没拆到位，让它重做。第⑥段也要分开看——它写的是「用的人常在哪儿用错」，不是「什么情况不适用」（那是第⑤段）。

顺便检查两件事（很重要）：

- [ ] 通篇有没有真名？**有就让它改**
- [ ] 第④段法条是逐字引用的，还是「根据相关法律规定」糊过去的？**是后者就让它重写**

### ④ 为什么要点卡要八段齐全、能直接抄

WorkBuddy 交给你的卡，要像下面这个样子的**完整度**（内容换成你的案子）。你不用自己写，拿它当尺子量：

```
一、裁判规则
职工在上下班途中，受到非本人主要责任的交通事故伤害的，应当认定为工伤。
三个要件缺一不可：①合理时间合理路线；②交通事故造成；③职工不承担主要责任。

二、审查要点
法官一般按这个顺序查：第一步查时间路线；第二步查事故性质；第三步查责任划分。

三、构成要件与举证
要件1：上下班途中 —— 职工一方举证（考勤、排班、通勤路线）
要件2：交通事故 —— 职工一方举证（交通事故认定书）
要件3：非本人主要责任 —— 职工一方举证（交警责任认定书）

四、法条依据
《工伤保险条例》第十四条：（六）在上下班途中，受到非本人主要责任的
交通事故或者城市轨道交通、客运轮渡、火车事故伤害的；……

五、抗辩与但书
- 职工负主要或全部责任的，不认定工伤。
- 故意犯罪、醉酒、吸毒、自残自杀的，不认定工伤。

六、翻车标本
错误做法：把「上下班途中」理解成「家门到公司的直线」，认为顺路买菜不算。

七、来源与地域效力
来源：《工伤保险条例》第十四条第（六）项（行政法规，全国有效）。

八、关联
（这一步你来，见第四关）
```

**拿它当尺子，重点看三处：**

| 看哪里 | 合格的样子 | 不合格的样子 |
|---|---|---|
| ③ 几个条件 | 每个条件都写了**谁举证** | 只写条件，不写谁举证 |
| ④ 法条 | 逐字引用 + 标了哪部法第几条 | 「根据相关法律规定」 |
| ⑥ 用错点 | 写的是**错用**这条规则的样子 | 写的是「什么情况不适用」（那是⑤） |

**第三处最容易做错。** 记住：⑤回答「这条规则什么时候不能用」，⑥回答「用的人常在哪儿用错」。**一个是规则的边界，一个是人的错误，两段都要有。**

## 第三关 · 再提一张规则卡（25 分钟）

### ① 做什么

上一关那张「要点卡」，记的是**一个案子的全貌**。但真正能让你「下次直接抄」的，是藏在里面那条**一句话就能说清的规则**。这一关，让 WorkBuddy 从这张要点卡里，**再拧出一张更精炼的「规则卡」**——一句话规则 + 适用条件 + 出处。这张卡现在**还不存在**，这一关把它**造出来**。

### ② 怎么做

**第 1 步**：跟 WorkBuddy 说：

> **跟 WorkBuddy 说：**
> 「刚做好的那张要点卡里，有一条能直接拿来用的规则。帮我再单独做一张更小的卡，只放三样东西：① 这条规则，用一句话说清；② 什么情况下能用它、什么情况下不能用；③ 这条规则出自哪部法第几条、哪个法院（核不到原文就写待核）。做好告诉我，这两张卡是什么关系、分别什么时候用。」

**第 2 步**：等它回你。它会告诉你：那张大的叫**要点卡**（记一个案子的全貌），这张小的叫**规则卡**（记一条能直接抄的规则）。

### ③ 你会看到什么

打开 Obsidian，「放做好卡」那个文件夹里，多了一个**更小的新文件**。点开它，只有**三小段**：

```
① 一句话规则
② 适用 / 不适用
③ 出处
```

**看到这张小卡只有这三段、而且每段都不空，第三关就过了。**

**对照一下**：如果那句「规则」读起来像「办案要注意风险」，就是提空了，让它回到要点卡里重新挑一句更具体的；如果第②段只写了「适用」、没写「不适用」，让它补上——少了后半句，你跨省办案时会误用。

### ④ 为什么要点卡和规则卡要分家

因为**它们的用处不一样**：

| 卡 | 记什么 | 什么时候用 |
|---|---|---|
| **要点卡** | 一个案子的**全貌**（八段） | 你要彻底搞懂一个案子时，翻它 |
| **规则卡** | 一条规则的**一句话**（三段） | 你办案时想「这条规则怎么说来着」，直接抄它 |

**一个案子，炼出一张要点卡 + 一张规则卡，是正常的。** 规则卡是「能直接抄的结论」，要点卡是「这个结论怎么来的」。**先有要点卡，才有规则卡**——不先搞清楚案子，提出来的规则一定是虚的。

## 第四关 · 装电机（30 分钟）

### ① 做什么

卡有了两张，但还**孤零零的、没有标签、互相找不到**。这一关，让 WorkBuddy 给卡贴上标签、再把相关的卡连起来——**给知识库装上「电机」，让它以后「查得到」**。这些标签和连线现在**还不存在**，这一关让 WorkBuddy **现场加上**。

### ② 怎么做

**第 1 步**：跟 WorkBuddy 说（贴标签）：

> **跟 WorkBuddy 说：**
> 「给刚做好的那两张卡，贴几个标签，让我以后能这样筛它们：按『编号』找到它、按『类型』分清它是要点卡还是规则卡、按『在哪个地方有效』判断能不能用、按『法条核没核到原文』标个警报、按『什么时候该复查』提醒我。加在卡的最顶上，加完告诉我每个标签叫什么、有什么用。」

**第 2 步**：等它回你，说标签加好了、每个叫什么。

**第 3 步**：跟 WorkBuddy 说（连起来）：

> **跟 WorkBuddy 说：**
> 「帮我把刚做的要点卡和规则卡连起来——从规则卡能点一下跳回要点卡，从要点卡也能跳到规则卡。先数清我现在一共几张卡，就在这几张里连，别去连还不存在的卡。连完告诉我连了哪几张、怎么点开验证。」

### ③ 你会看到什么

打开那张卡，**文件最顶上多了一小块灰色的区域**，里面躺着几行字——那就是标签。WorkBuddy 会告诉你，它给这五行起了什么名。**这些名字是它造完才告诉你的，你不用提前记**：

| 标签叫什么 | 干什么 | 你以后怎么用 |
|---|---|---|
| 编号 | 卡的身份证号 | 按它找卡，卡多了不撞号 |
| 卡是哪一类 | 分清要点卡还是规则卡 | 分清「记全貌的」和「能直接抄的」 |
| 在哪个地方有效 | 这条规则在哪个地方管用 | **跨省办案别误用**（最重要） |
| 出处核没核 | 红色警报灯 | 标「待核」的卡，**绝不许引到文书里** |
| 哪天该回来复查 | 法律会改，到点提醒自己 | 到点翻出来再看一眼 |

再往下看「关联」那一块，出现了**几串蓝色的字**——点一下，就跳到另一张卡。反过来，被连的那张卡底部，也会出现你这张卡的名字。

**标签加上了 + 两个方向都能跳，第四关前半就过了。**

**第 4 步**：再让 WorkBuddy 定一句每次办案前都能照着说的固定话：

> **跟 WorkBuddy 说：**
> 「帮我定一句每次办案前都能说的固定话。要求：先在我这三个房间里搜这件事有没有现成的卡；搜到就念给我听，并告诉我是哪张卡、编号是什么；没搜到就直接说『没有』，不许现编、不许拿通用道理凑数。把这句话存进上一章那个总记忆的『规矩』房间，取名叫『办案前一句话』。」

**第 5 步**：拿一个你手上真在办的问题，说一次这句话。

**看到「有就念出卡、没有就老实说没有」，第四关就过了。** 对照一下：如果你问一个库里根本没有的问题，它却回了一大段听着挺有理的建议，说明那句话缺了「不许现编」那半句，让它改回去重存。这一关验的不是它有多能答，是它**肯不肯说没有**。

### ④ 为什么「查得到」是知识库的命根子

因为**存了查不到，等于没存**。你以后会攒几百张卡，标签是「筛子」（按省份筛、按类型筛、按红卡筛），连线是「网」（办一个案子，相关的卡会一起被你想起）。

**这一章不看灯，也不看分数。** 上一章验的是「四个房间在不在、协议写没写」，验的是东西在不在；这一章验的是**搜不搜得到**。电池有没有电，不看外壳，看它能不能带动一次。搜不到也别急着重建——那只说明你还没炼到那一张，回头按第二关再炼一张就是。

**「在哪个地方有效」这个标签最重要**——某省高院的尺度，去外省不一定好用。你跨省办案时闭着眼引用一张「本省口径」的卡，可能当场翻车。**贴上「在哪有效」，等于给每张卡划了地界——出了界，就别硬用。**

## 第五关 · 装动能回收（25 分钟）

### ① 做什么

车刹车时不把劲白白扔掉，反过来给电池充上电。办案也一样：**每办完一件，把「当时为什么这么判断」写回去**，让下一回少卡一次。这一关造一个专门装这个的东西——**黑匣子**。现在它**还不存在**，这一关把它**造出来**。

### ② 怎么做

**第 1 步**：跟 WorkBuddy 说：

> **跟 WorkBuddy 说：**
> 「帮我建一个黑匣子。每办完一件事，往里写三段：
> ① 当时面对的是什么；
> ② 我为什么选了这条路、**另外那条为什么没选**；
> ③ 下次遇到同类，先翻哪张卡。
> 不写流水账，不写『今天完成了 XX』。出处核不实的写『待核』。建好告诉我它放在哪。」

**第 2 步**：拿这一章那个案子，当场写第一条。让它把第②段念给你听。

**第 3 步**：定下什么时候写——**一个案子了结就写一条**，不攒到周五，不攒到月底。攒着攒着，「另外那条为什么没选」就先忘了。

### ③ 你会看到什么

黑匣子里躺着第一条，三段都在；第②段里能读到「当时还考虑过……，没选它，因为……」。

**看到「三段齐 + 第②段写出了没选的那条路」，第五关就过了。**

**对照一下**：如果第一条读下来是「已办结，结果良好」，那就是流水账，直接说「重写，第②段要写为什么没选另一条」。三段里最值钱的就是第②段，少了它，黑匣子只是个日程本。

### ④ 为什么存推理，不存结论

因为**结论会过时，推理不会**。一条结论三个月后可能因为新规定就变了；但「我当时是怎么一步步查出来的」——这条**思考的路**，永远有用。半年后翻出「当时是因为没有书面确认才这么判断」，你一眼就知道：这次有书面确认，得换条路了。

**存结论，你得到一句会过期的答案；存推理，你得到一条能反复走的路。** 这也是「动能回收」的真正意思：**办案不是在消耗你，是在给你的库充电。**

全书凡是记「为什么这么定、事后谁担责」的，都叫**黑匣子**；它跟上一章总记忆里那个「日志」房间不是一回事——日志记「今天干到哪了」，黑匣子记「当时为什么这么定」。

## 第六关 · 验收（10 分钟）

### ① 做什么

最后一关，把这一章该有的东西清点一遍，尤其是**有没有不该露出去的东西混进卡里**。

### ② 怎么做

**第 1 步**：跟 WorkBuddy 说：

> **跟 WorkBuddy 说：**
> 「帮我清点这一章的结果：① 三个房间都在吗；② 要点卡是八段、规则卡是三小段吗，各自放在对的地方吗；③ 卡顶上的五行标签齐吗、两张卡能互相跳吗；④ 用『办案前一句话』搜一个真问题，能捞到卡吗；⑤ 有没有把当事人真名、钥匙、密码这类东西写进卡里——有就单独指出来。五样都查清，告诉我结果。」

**第 2 步**：等它回你，别自己翻。

### ③ 你会看到什么

它回你一句，大意是「**五样齐、没发现真名钥匙**」。看到这句，第六关就过了，这一章也就过了。

**对照一下**：如果它回「发现一条像真名的内容」，别自己去找，直接说「把它拿出来删掉，再清点一遍」；如果第④样没过（搜不到），回去补第四关那句固定话；如果三个房间少了一个，回去补第一关。

**卡住或结果对不上，别自己翻，去「卡住了怎么办」照现象找原因，说一句话就行。**

### ④ 为什么验收要专门查「真名、钥匙、密码」

因为**卡是要被反复搜出来、反复念给你听的**。第 4 章你就把案件保密材料单独锁进了案件保险柜，第 7 章也定过「钥匙永远不进记忆、记忆永远不存钥匙」。真名一旦写进卡，等于每搜一次就念一次；钥匙一旦写进卡，等于挂在了公告栏上。

**这一章不看灯、不看分数，也不数卡量。** 卡攒到几张不是这一章该验的——第一周手上就两张，很正常。这一章只验「该有的在不在、该搜的搜不搜得到、不该写的有没有混进来」。

## 第一周怎么安排（别一天做完）

六个关不用一次过完。**一次做完的人，第二天就忘了自己建过什么。** 第二关那张卡，你得隔一夜再回来看，才看得出哪段含糊；第四关那句固定话，也得隔天用平常心试一次，才知道顺不顺口。

| 哪天 | 做什么 | 用时 | 做完的标志（去哪看） |
|---|---|---|---|
| **第 1 天** | 第一关：给知识建三个房间 | 15 分钟 | Obsidian 左侧多出三个文件夹 |
| **第 2 天** | 第二关：炼要点卡 | 30 分钟 | 「放做好卡」里一张卡，八段齐 |
| **第 3 天** | 第三关：提规则卡 | 25 分钟 | 同一房间里一张三小段的小卡 |
| **第 4 天** | 第四关：贴标签 + 连起来 + 定一句话 | 30 分钟 | 顶部灰区 + 蓝字能跳 + 总记忆「规矩」房间有「办案前一句话」 |
| **第 5 天** | 第五关：装动能回收 | 25 分钟 | 黑匣子第一条，三段齐 |
| **第 6 天** | 第六关：清点 | 10 分钟 | 「五样齐、没发现真名钥匙」 |
| **第 7 天** | 复查：拿一件真事走一遍 | 10 分钟 | 这次它自己把卡捞出来了，你没重讲一遍 |

**总共约 2 小时 15 分钟，摊在一周里。**

**为什么不能一天做完？** 赶着一天做完，等于把所有「隔一夜再看」的验证机会都放弃了。**第 7 天那步最容易被跳过，也最要紧**——拿一件你上周真办过的事，先说那句固定话。它把卡捞出来了，这一整套就成立了；它说没有，说明你的卡还只是躺着的纸，回去补第二关和第四关。

## 第二周开始，只做一件事

**每了结一个案子，炼一张要点卡、一张规则卡，写一条黑匣子。** 不多不少，一案一组。

**先把两件事的关系说清**，别做成两套互相打架的规矩：第六关的「每周看一眼」，是**检查有没有漏**；这里的「每案一组」，是**往里添东西**。一个查、一个添，都要做，不是二选一。

**第一周刚起步，手上只有两张卡是正常的**，别看着数字小就以为线断了。等办上三四个案子，节奏自己就出来了。

**为什么是「一案一组」而不是「每天五组」？** 因为痛的地方才有知识，顺利的地方只有结论。一天硬凑五张，凑出来的全是空话卡；一个案子了结时老老实实写一组，一年下来就是一串真能用的东西。**能坚持一年，比一个月猛冲然后放弃，划算得多。**

## 长成 · 卡攒多了之后

现在你只有三个房间。等库长到一定程度，你会自然感到「不够用」。**按下面这张表加，别提前加。**

| 什么时候加 | 加什么 | 你为什么会有这个需求 |

| 总在纠结「这条该放哪」 | 再加一个房间 | 三个房间分不清了 |

| 出过一次**说不清**的事故 | 再建一个「日志」的房间 | 你想知道「上周到底改了什么」 |

**加的时候不用重新搭。** 直接对 WorkBuddy 说「帮我再建一个放 XX 的房间」，它会帮你建好、把卡归位。

顺带说两件事：

1. **卡不止这两种。** 这一章你学了「要点卡」和「规则卡」——最典型的两种。后面办案的卡、算钱的卡、管流程的卡，各长各的样子。手艺是同一个（炼炭），卡型用到哪种再学哪种。
2. **换电脑要把库搬过去。** 卡是你一个个案子炼出来的，丢了没法重炼——当时的判断理由，过三个月自己都记不全。搬完让 WorkBuddy 清点一遍：三个房间还在、卡还在、蓝字还跳得动。

**换电脑时，两种电脑做的事一模一样，只是打开文件夹的地方名字不同：**

| 你要做的事 | 苹果（macOS） | Windows |
|---|---|---|
| 找到知识库、整个拷走 | 在**访达（Finder）**里找到那个文件夹 | 在**文件资源管理器**里找到同一个文件夹 |
| 拷到新电脑后确认齐不齐 | 在访达里数三个房间 | 在文件资源管理器里数三个房间 |
| 路径长什么样 | `文档/我的数字分身/…` | `文档\我的数字分身\…` |

**别在 WorkBuddy 里分系统**：你只说「帮我把知识库清点一遍」，它会自己认出你在用哪种电脑，用那种电脑的方式帮你做。

## 卡住了怎么办

下面九条，是真实卡过的地方。**你大概率会卡在其中某一条。**

### 卡 1 · WorkBuddy 不知道你的 Obsidian 库在哪

**现象**：第一关它问你「库在哪个文件夹」，你答不上来。

**怎么办**：直接说：

```
我的 Obsidian 库在哪我也不确定，帮我找一下（或：我打开 Obsidian 给你看，你告诉我库的路径）。
```

**让它帮你找，别自己翻半天。**

### 卡 2 · 建出来的卡不是八段

**现象**：WorkBuddy 写了六段、十段，或者揉成三段。

**怎么办**：**不要自己改。** 直接回它一句：

```
不对，请严格按我说的那七个方面来写，一个都不许少，另外再加一个空着的「关联」段。
```

一句话就够。它第一次没对齐，通常是你没把「要哪几个方面」说全。

### 卡 3 · 法条是编的

**现象**：第④段写着「根据相关法律规定」，或者引用了一个你查不到的条文。

**怎么办**：直接说：

```
第④段的法条我不确认。请逐字引用原文，并写明是哪部法、第几条。核不到原文就写待核，不要自己概括。
```

**然后让它把「出处核没核」那一行改成「没核到」。** 这样以后一搜就能揪出来。

### 卡 4 · 要点卡和规则卡分不清 / 规则卡是空话

**现象**：第三关提出来的规则卡，写的是「合同要注意风险」这种空话，或者跟要点卡重复了。

**怎么办**：直接说：

```
这张规则卡太空了。请把它写具体：一句话说清「什么情况、怎么办」，再写「什么情况下能用、什么情况下不能用」，最后写「出自哪部法第几条」。说不清出处，就写待核。
```

**规则卡必须是「能直接抄的」**——空话规则，谁都抄不了。

### 卡 5 · 标签没加上 / 灰区没出现

**现象**：第四关做完，卡片顶部没有灰色区域，或者标签乱了。

**怎么办**：直接说：

```
标签没加上。帮我重新在卡的最顶上，按标准格式加那几个标签，加完念给我听。
```

**别自己手敲标签，容易敲错引号导致整张卡读不出来。** 让它来。

### 卡 6 · 卡连不起来 / 蓝字点不动

**现象**：第四关连完，点蓝字没反应，或反链里看不到。

**怎么办**：直接说：

```
卡连不起来，帮我确认连的那两张卡是不是真实存在、名字写对没，重新连一遍。
```

**连不上的根子，常常是那张卡名字没对上。** 让它核对名字。

### 卡 7 · 黑匣子写着写着变成日记

**现象**：翻回去全是「今天联系了甲、明天交材料」。

**怎么办**：直接回 WorkBuddy：

```
这几条不合格。按三段重写，重点补第②段：当时另外那条路是什么、为什么没选。删掉流水账。
```

### 卡 8 · 卡越建越多，一个都用不上

**现象**：库里有三十张卡，办案时一张都想不起来用。

**怎么办**：这是最正常的阶段。原因基本两条：

1. **卡太泛**——「合同要注意风险」这种卡，谁都用不上，拆细到某个具体争点就有用了
2. **没装电机**——第四关那句固定话没进总记忆，或者从没说过，卡躺着没人捞

**处方**：这周别建新卡，把「办案前一句话」拿出来，拿三个真问题各说一次。**说完你会发现，一半的卡其实该拆细。**

### 卡 9 · 不知道该拆哪个案子

**现象**：想拆卡，但觉得手头每个案子「好像没什么可拆的」。

**怎么办**：**只挑那个让你吃过亏的。** 被驳回的那个、被对方打了个措手不及的那个、被法官问住的那一次。

**痛的地方才有知识，顺利的地方只有结论。**
