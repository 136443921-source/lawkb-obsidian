## 22.1 地图是什么（10 分钟）

### 这一节干什么

讲清两件事：这张地图管什么、不管什么；地图上为什么是两条线，不是一条。这一节不写电脑，只在纸上写三个词。

### 动手

**第 1 步**：拿那页白纸，横着写三个词，中间空开：

```
我在哪          我要去哪          下一步
```

**第 2 步**：在"我在哪"下面，写两个数——你现在攒了多少张卡（记不清就写"不知道"），四个工位你现在各自什么水平（用"生"或"熟"两个字，别的不用写）。

**第 3 步**：把纸翻过来，在背面写一句：

```
这张纸不考我。
```

写完把笔放下，听三句话。

### 一句话收束

**地图不告诉你有多强，只告诉你现在在哪、下一步往哪迈。**

下面三句话说清它跟第 21 章那张表的分工。

**第一句：地图不解决"车好不好"，只解决"往哪开"。**

上一章那张十块表，验的是**东西在不在**——柜子在不在、门禁在不在、工位在不在。那是车况。

这一章装的地图，管的是**接下来长什么**——往哪个方向长、先长哪一块、多久长一截。

这两件事经常被混成一件。混了会怎么样？你会拿"我的东西都在"当"我在进步"。柜子里的案卷一年比一年多，可你办案还是从桌面翻文件夹；卡库里的卡攒到两百张，可你四个工位一个都没用顺。**东西在长，人没长。**

**第二句：为什么是两条线，不是一条。**

地图上要画两条线，各看各的：

**系统线——看你攒的东西有多少。** 就是卡量，一目了然。

**工位线——看你用它办事有多顺。** 这个不好数，得靠档位。

为什么不合成一条？因为这两条经常脱节，而且脱节的方式正好相反：

一种人卡量三百张，规则库漂亮得像本书，但办一个案子还是从桌面翻文件夹、从微信里找聊天记录。**书读得多，手不熟。**

另一种人四个工位闭着眼都能用，案子从进到出全在系统里跑，可卡库就那二十张，全靠脑子记。**手熟，家底薄。**

这两种人往下一站走的办法完全不同：前者要停下来炼卡，后者要停下来建库。**只看一条线，你永远不知道该补哪头。**

**第三句：这张地图只标"下一个路口"，不标终点。**

因为它没有终点。500 张之后还有，E 档之后还有——那部分不在本书里，在你自己的案子上。

所以别指望这张地图给你一个"到站了"的时刻。**它的用处是让你每次抬头，都看得见下一个路口在哪。** 看得见下一个路口的人，不会在原地待三年。

这也解释了 22.2 为什么只让你定一个目的地，不是定一份人生规划。**地图画得太满，等于没画。**

## 22.2 设定目的地（25 分钟）

### 这一节干什么

把"目的地"写成两句能看见的话——系统线一句、工位线一句。写完存成《我的成长地图》。这一节做完，你手里就有地图的第一版。

### 动手

**第 1 步：先认清什么样的目的地算合格。**

不合格的有三种，八成你会写出其中一种：

- **"我要变强。"** —— 不合格。看不见，"强"到什么程度算强？
- **"我要成为专家。"** —— 不合格。谁都说自己是专家。
- **"我要把知识库做大。"** —— 不合格。多大算大？

合格的只有一个标准：**写完之后，你能回答"到那天我怎么知道到了"。**

答不出来，就是没写目的地，只是写了个愿望。

**第 2 步：系统线的目的地，别写成数字。**

第一反应肯定是"卡量到 100 张"。先别写这个数——数字是**结果**，不是目的地。数字写上去，你会为了凑数炼一堆用不上的卡。

改成"到那天我想让它替我干成什么事"。照着这个句式写：

```
____ 个月后，我办一个 ____ 类型的案子，能不用从头想——
把案由说一句，它能把我自己攒的同类规则、同类案子全调出来。
```

照着改一句你自己的。比如做人身损害的，可能是"办一个交通事故的案子，伤残等级和赔偿项目不用现翻"；做合同的，可能是"审一份采购合同，付款和违约那几条的坑不用现想"。

写完之后再倒推一句：**这件事，大概要多少张卡撑着？** 心里给个数，写在这句后面，标注"（估）"。

**第 3 步：工位线的目的地，用三个台阶说。**

四个工位（案件、合同文书、庭审、合规）各写一句"到那天什么样"。写的时候只用三个词：

- **会做**——照着步骤能做完，但要翻书、要回头看笔记。
- **熟练**——不用翻书，顺手就做完了。
- **精通**——能拆开重装，能教别人怎么做。

样例：

```
案件工位：熟练
合同文书工位：熟练
庭审工位：会做
合规工位：会做
```

**这里有个坑，先说明白：四个工位不要都写"精通"。**

四个都写精通，等于一个都没定。而且不现实——庭审工位你一年可能就上几次庭，练不到精通。**工位线只写"我要把哪一个推上一级"，剩下的维持现状，这才是能执行的。**

**第 4 步：让它把人话写成人话。**

你刚写的那些，自己看得懂，但过三个月就未必。发这一段，让它整理成能长期存的样子：

```
我刚定了这套系统的成长目的地，帮我整理成一段能长期存的话，别改我的意思，只做三件事：

1）我说的"要让它替我干成什么事"，帮我补一句"我怎么知道到了"——用能看见的动作说，别说"能力提升"
2）四个工位我标了会做/熟练/精通，帮我排一下：哪个最低，哪个最高
3）把我写的口语整理成两条：系统线一句、工位线一句

整理完就停，别替我加目标。
```

最后那句"别替我加目标"很重要。你不说，它会很热心地给你补上五六个目标——那些是它的目标，不是你的。

**第 5 步：存进 Obsidian。**

让它写成 Obsidian 库里的一个文件，文件名就叫 `我的成长地图`。

> **苹果和 Windows 这一步没区别**——都是在 Obsidian 里新建一个笔记，把内容贴进去，`Cmd+S`（苹果）或 `Ctrl+S`（Windows）保存。

在标题下面加一行：`建立日期：2026-__-__`。以后每次回来改数字，这一行别动——**它是你这张地图的出生证**。

### 做完，你眼前是什么样

Obsidian 左边文件列表里多出一个 `我的成长地图`，点开，从上往下应该是这个样子：

```
我的成长地图
建立日期：2026-11-12

## 系统线目的地
半年后，我办一个交通事故的案子，伤残等级和赔偿项目不用现翻——
把案由说一句，它能把我攒的同类规则和同类案子全调出来。
我怎么知道到了：办这类案子时，我一次都没去翻纸质笔记。
估：100 张上下。

## 工位线目的地
案件工位：熟练（当前最低）
合同文书工位：熟练
庭审工位：会做
合规工位：会做（当前最低）

## 里程碑
（22.3 填）

## 当前站 → 下一站
（22.4 填）

## 90 天路线
（22.5 填）
```

**对照着看两处，就知道写对没有：**

1. **系统线那句，有没有"我怎么知道到了"这一行。** 没有就是没写目的地，回去补。
2. **工位线里，有没有两三个工位是同一个词。** 如果四个都写"熟练"，说明你在敷衍自己——真实的水平不会四个一样齐。

## 22.3 里程碑路标（30 分钟）

### 这一节干什么

在目的地中间插上三个路标，再给工位线配上五档刻度。做完你就知道自己踩在哪一格——**这一节是整张地图里唯一能"看见自己位置"的地方。**

### 动手

**第 1 步：系统线三个路标，照抄，别改。**

| 路标 | 到这一站能干什么 |
| --- | --- |
| **20 张** | 知识库能转起来，够自用 |
| **100 张** | 常用规则基本覆盖，办案不慌 |
| **500 张** | 自己的「裁判规则库」成型，越用越强 |

三个路标是全书定死的，三种人能对上号：

- **20 张**那条线，真正的意思不是"攒够 20 张"，是"这套东西第一次转起来了"。你能炼出卡、卡能被调出来用，闭环通了。**通了比多重要。**
- **100 张**那条线，是"不用现翻"的临界点。常用的那批规则你都有了，办案不必每次回头查。
- **500 张**那条线，是"这套东西开始像你自己的了"。别人给的规则你也有，但里面有两百张是你从自己案子里抠出来的——那部分别人抄不走。

**第 2 步：先数你现在有多少张卡。**

别自己翻文件夹数。翻十分钟数出个大概，还是错的。发这一句：

```
我的知识卡存在 <你放卡的那个文件夹>。
帮我数一下现在一共有多少张，只数卡，别把别的东西算进去。
数完直接告诉我数字，别给我分析。
```

尖括号里要填路径。**怎么找到它**：

- **苹果**：在**访达**里找到那个文件夹，按住 `Option` 右键点它，选「将 xxx 拷贝为路径名称」，粘进去。
- **Windows**：在**资源管理器**里找到那个文件夹，点一下地址栏，路径会变成可复制的一串，`Ctrl+C` 粘进去。

拿到数字，记在纸上"我在哪"下面。

**如果这个数是 0 或者个位数，别慌**——那说明你第 9 章炼卡炼完就没再炼。这不是失败，这是这次要改的事。

**第 3 步：工位线五档，也照抄。**

| 档位 | 到这一档说明 |
| --- | --- |
| **A（最生）** | 刚搭完，会做但慢、要翻步骤 |
| **B** | 会做，不用翻步骤了 |
| **C** | 熟练，顺手就能干 |
| **D** | 很熟，能拆解、能变通 |
| **E（最精）** | 精通，能教别人、能带人 |

**第 4 步：把三个台阶和五档对上——这是最容易糊的地方。**

22.2 里你写的是三个台阶（会做 / 熟练 / 精通），这里给的是五档（A 到 E）。两套东西不冲突，它们是**方向和刻度**的关系：

- **三个台阶是方向**：你现在这一级，下一级往哪走。
- **五档是刻度**：在这一级里面，你踩在哪一格。

对上关系是这样的：

| 台阶 | 对应档位 | 差在哪 |
| --- | --- | --- |
| **会做** | A → B | A 要翻步骤，B 不用翻了 |
| **熟练** | C → D | C 顺手就能干，D 能拆能改 |
| **精通** | E | 能教别人、能带人 |

**为什么要分两套，而不直接说五档？**

因为只分五档，你会盯着格子发愁，不知道该往哪个方向挪；只分三级，你会长期停在"我已经熟练了"这句自我安慰里——**"熟练"这一个词，从"不用翻书"到"能拆解变通"，中间差着两年。**

三级告诉你方向，五档告诉你还有多远。**两样都要。**

**第 5 步：四个工位各打一个档。**

一个一个来，每个只问自己一句：**这个工位，我上一次用它办事，翻没翻步骤？**

- 翻了 → A
- 没翻，但做得慢、还要想 → B
- 没翻，顺手就完了 → C
- 顺手，还顺手改过它的做法 → D
- 能带着别人按你的做法做 → E

**打完你一定会发现一件事：四个工位里有一个明显比别的低一档。**

那个最低的，先记住它。22.4 要挑它。

**第 6 步：把这行结论写进地图。**

```
## 里程碑
系统线：20 张 / 100 张 / 500 张
工位线：A 会做但慢 · B 会做不用翻 · C 熟练 · D 能拆能变 · E 能教人

我现在：卡量 __ 张 ｜ 案件 __ ｜ 合同文书 __ ｜ 庭审 __ ｜ 合规 __
最低的那一个是：______
```

### 做完，你眼前是什么样

地图页里多了一张三行的路标表、一张五档表，还有一行"我现在"。这一行是整张地图上最有用的东西——**它是个坐标，不是个评价。**

**对照着看两处：**

1. **"我现在"这一行，卡量是不是数出来的数**（不是"大概一百来张"）。是估的，回去重数。
2. **四个工位后面是不是都填了字母**，不许有空格。实在拿不准的，填个字母再标个"？"，也比空着强——**空着的地方，你永远不会回来看。**

## 22.4 路线导航（25 分钟）

### 这一节干什么

从"我现在在哪"走到"下一站"，把这段路拆成三个动作：什么时候查、什么时候炼、什么时候升级。做完你手里有一段能走的路，不是一句"我要努力"。

### 动手

**第 1 步：先定"下一站"，只定一个。**

不是三个路标一起冲。**只冲离你最近的那一个。**

照你 22.3 数出来的卡量对号：

| 你现在 | 下一站 |
| --- | --- |
| 20 张以下 | **20 张**（先把轮子转起来） |
| 20–99 张 | **100 张**（覆盖常用规则） |
| 100–499 张 | **500 张**（长成你自己的） |
| 500 张以上 | **卡量不再是主角**，下一站是工位升一档 |

**为什么只冲一个？** 因为你同时冲三个，三个都到不了。这是最常见的一种失败：年初定了三个目标，年底一个没动，还觉得自己挺忙。**一次只盯一个数，一年能挪三次。**

**第 2 步：工位线也挑一个，挑最低的那个。**

就是 22.3 第 5 步里你记住的那个最低档工位。

**为什么先补最低的，而不是把已经顺手的再练熟？** 因为四个工位是连着用的。一个案子进来，案件工位走完要出文书，出完文书要准备开庭——最低的那一环会把整条链拖住。

举个具体的：你案件工位是 C，合同文书工位是 A。那么每个案子到最后出文书那一步，你都得停下来翻步骤、找模板、反复改格式。**前面九步都很快，第十步把所有时间吃回去了。**

**低的那个不补，其余三个的熟练度都是白练。**

**第 3 步：把这段路拆成三个动作。**

这三个动作有各自的时间尺度，混在一起你就会"天天很忙但没进展"：

| 动作 | 干什么 | 多久一次 |
| --- | --- | --- |
| **查** | 办案时把查到的、找到的好东西留下来，别让它随案子一起结束 | 天天，顺手就做 |
| **炼** | 把留下来的东西炼成卡 | 一周一次，固定一个时间 |
| **升级** | 卡进了档、工位进了一档，回来改地图上的数字 | 一月一看 |

**三者的关系是：查是进水，炼是过滤，升级是水位线上涨。**

只查不炼——水一直进，池子没底，全漏了。这类人文件夹越来越满，卡量一直不动。
只炼不查——过滤得很勤，可没水进来，炼来炼去就那几张。这类人卡库三个月不涨。
查炼都做、从不升级——水位其实涨了，但你没看，所以一直觉得自己没进步。**这一类最可惜，白干了。**

**第 4 步：让它按你现在的数算下一站。**

```
我的成长地图在 Obsidian 里，文件名叫「我的成长地图」。
我现在卡量是 __ 张，四个工位档位是：案件 __ ｜ 合同文书 __ ｜ 庭审 __ ｜ 合规 __。

按地图上的三个路标和五档刻度，帮我做三件事：
1）告诉我我的下一站是哪个路标，为什么是它而不是下一个
2）告诉我最低的那个工位，从这一档到下一档，具体差在哪一件事上——说一件能做的动作，别说"多练练"
3）照我一周炼 3 张的节奏，算一下到下一站大概要几周

算完就停，别替我排计划。
```

第 2 条是这段话的重点：**"差在哪一件事上"**。它要是回你"需要多练习、提高熟练度"，那就是废话，让它重说——要一个能当天做的动作，比如"下次审合同，先不看模板，自己把争议条款列一遍再对照"。

**第 5 步：写一句"这段路的代价"。**

这一步最容易跳过，但它是整张地图能不能走完的关键。

照着上面的周数，写一句实话：

```
到下一站：约 __ 周（一周炼 3 张，按现在的节奏）
中间我不能停超过 __ 周，否则前面的要重来。
```

**为什么非要写这个？** 因为人定目标的时候不算成本，走的时候才发现贵。算一遍你就知道：如果 20 张到 100 张要半年，那这半年里每周得固定拿出两个小时炼卡——**这两个小时从哪来？从刷手机里来，还是从加班里来？**

写下来，你才知道这个目标是"能完成"还是"想想而已"。**算过代价的目标叫计划，没算过的叫许愿。**

### 做完，你眼前是什么样

地图里多了一段：

```
## 当前站 → 下一站
当前站：卡量 __ 张 ｜ 最低工位：______（__ 档）
下一站：卡量 __ 张（或：工位升到 __ 档）
这一段拆成：查（天天）→ 炼（每周一次）→ 升级（每月一看）
差的那一件事：______________________
代价：约 __ 周，中间不能停超过 __ 周
```

**对照着看一处**：那段"差的那一件事"，是不是一个**动作**。如果是"提高熟练度""加强练习"这种话，回去让它重说——那种话贴在墙上一年也不会有任何变化。

## 22.5 90 天路线图落地（30 分钟）

### 这一节干什么

把 90 天切成三段，每段写死一件事，做成一张能贴在桌前的表。做完这一节，这张地图就从"一张图"变成"一个日程"。

### 动手

**第 1 步：三段照抄，别改。**

| 阶段 | 天数 | 目标 |
| --- | --- | --- |
| **打基础** | 前 30 天 | 四个工位各过一遍 |
| **练熟练** | 中间 30 天 | 挑两个最常用的工位练到熟练 |
| **冲路标** | 后 30 天 | 卡量冲一档、工位上一档 |

**第 2 步：搞清为什么是这个顺序，不能倒过来。**

**为什么先"各过一遍"，而不是直接挑两个练熟？**

因为你现在还不知道哪个工位是你真正最常用的。你以为你知道，但那是"你以为的常用"，不是"真实的常用"。

不过一遍就挑，你会挑那个你最感兴趣的，或者最近刚学过的。三个月后统计一下自己实际办的事，多半发现最常用的根本是另一个。**先全过一遍，让真实的使用频率浮出来，再挑。**

**为什么"练熟练"要放在"冲卡量"前面？**

因为卡量是靠**用**攒出来的，不是靠炼攒出来的。

你天天办案子，办的过程中查东西、留下来、周末炼——卡量自然涨。你不常用，逼自己坐下来炼，炼出来的是死卡：格式对、内容空，写的时候就没想过用在哪。

**先有用起来的动作，才有值得炼的东西。** 顺序倒了，你会炼出一堆漂亮但用不上的卡，然后怀疑这套方法没用。

**第 3 步：三段填成一张 12 周的表。**

90 天按 4 周一算，是三段各 4 周。让 WorkBuddy 照你的情况填：

```
我的成长地图在 Obsidian 里，文件名叫「我的成长地图」。
下一站和代价都写在里面了。

帮我做一张 90 天的表：12 周，分三段——前 4 周 / 中间 4 周 / 后 4 周。
三段分别对应：四个工位各过一遍 / 挑两个最常用的练到熟练 / 卡量冲一档 + 工位上一档。

每一周只写一件事，写成一个动作，别写"继续推进"这种话。
四个工位各过一遍那一段，帮我排个先后——哪个先过，说一句为什么。

表做完就停。
```

**"每一周只写一件事"这条要盯住。** 一周写三件事的表，第二周就废了。

**四个工位先过哪个**，它给的先后如果不对，你自己改。常见的合理顺序是：**先过你手上案子最急的那个工位**——有真案子在里面跑，才练得动；没有真案子，过一遍等于参观。

**第 4 步：给后 30 天定一个"到站标准"。**

"卡量冲一档"这个说法太软。后 30 天开始前，写一句硬的：

```
第 90 天那天，我怎么知道到了：
1）卡量从 __ 张到了 __ 张（数字对得上）
2）______ 工位从 __ 档到了 __ 档（能说出一件以前做不了、现在能做出来的事）
```

第 2 条比第 1 条重要。卡量可以对凑，工位挪一档凑不了——**"以前做不了、现在能做出来"这件事，假不了。**

**第 5 步：让它把这张表单独存一页，方便贴在桌前。**

```
把这张 12 周的表单独存成 Obsidian 里另一个文件，就叫「我的 90 天」。
只要表本身，不要分析，不要鼓励的话。
```

存在 Obsidian 里，或者直接打印出来贴桌前。**地图在库里，日程在眼前**——这是两样东西，都得有。

### 做完，你眼前是什么样

Obsidian 里多出一个 `我的 90 天`，点开是一张 12 行的表：

```
我的 90 天
起始日：2026-11-12

第 1 段 · 打基础（第 1–4 周）：四个工位各过一遍
第 1 周：过案件工位——挑一个在办的案子，从进到出走完一遍
第 2 周：过合同文书工位——…
第 3 周：过庭审工位——…
第 4 周：过合规工位——…

第 2 段 · 练熟练（第 5–8 周）：挑两个最常用的练到熟练
第 5 周：…
…

第 3 段 · 冲路标（第 9–12 周）：卡量冲一档 + 工位上一档
第 9 周：…
…

到站标准（第 90 天）：
1）卡量 __ 张 → __ 张
2）______ 工位 __ 档 → __ 档，能做出一件以前做不了的事
```

**对照着看两处：**

1. **每一周是不是只有一件事**。有两周写了三件的，回去砍到一件。
2. **后 30 天那段的"到站标准"，是不是两个数**（卡量 + 工位）。只有一个数的，补上另一个——只追一个数，另一个一定会退。

## 22.6 验收（10 分钟）

### 这一节干什么

照四条硬线，确认这张地图真装好了。**四条全过才算装上，缺一条就回去补。**

### 动手

一条一条来，每条只答"是 / 不是"：

| # | 硬线 | 怎么查 | 是 / 不是 |
| --- | --- | --- | --- |
| 1 | **两条线都有** | 地图里系统线和工位线各有一句目的地，不是只有一句 | ☐ |
| 2 | **位置是数出来的** | 卡量是数出来的数字；四个工位都填了字母，没有空格 | ☐ |
| 3 | **下一站只有一个** | 只有一个卡量目标 + 一个要往上挪的工位，不是四个都要 | ☐ |
| 4 | **90 天写死了** | `我的 90 天` 在库里，12 周每周一件，到站标准是两个数 | ☐ |

**第 3 条要多说一句，因为它最容易被违反。**

人的本能是想一次全补上——卡量要冲、四个工位都要升、最好三个月变成另一个人。这么定的结果基本一样：第一个月很猛，第二个月松，第三个月忘了。

**只留一个卡量目标、一个工位。** 剩下三个工位维持现状不掉队就行。

这不是降低标准，这是**让标准能被执行**。一年挪三次的人，比定了十个目标一个没动的人，强得多。

### 一句话收束

**这张地图装好了，这本书就交完了——往后你不用再问"下一步干什么"，抬一下头就知道。**

**附录 C** 里第 22 章的合格线就一句话：地图上能看清自己的位置和下一站。跟这四条是同一件事。

## 22.7 把这套给别人搭一遍（60 分钟）

### 这一节干什么

把你这一路搭出来的东西**交给另一个人用**——不是替他重装一遍，是把「路怎么走」交出去。做完你手里会多两样：一张《交付十步》清单，一封写给对方的说明。

### 动手

**先说清这一节的门槛。** 这一节一个字都不造新东西。讲的是**交付和移植**——同一套办法，换一个人、换一个行当，怎么重走一遍。要是讲着讲着开始给他造新部件，那就跑偏了。

**为什么要做这件事？** 你把它搭出来，只证明你会用；你能把它交给另一个人，才证明你真懂了。中间差的不是熟练，是**你知道哪一步不能省**。

十步，一步不能少，顺序也不能换——**每一步都踩在前一步上。**

**顺序为什么不能换？** 举两个最常见的反例：定位没定就去装技能，装完他天天不用；流程没配就先建定时任务，跑出来的东西没人看。**这两件事我都见过**——不是他不努力，是顺序反了，力气全花在没接上的那一截上。

**第 1 步：定分身定位。**

三个问题，一个都不能含糊：**他做哪一行？他的客户是谁？他天天重复干的活是哪三件？**

答不出来就先别往下走。**定位没定，后面配什么都是猜**——你会给他配一堆用不上的东西，他还不好意思说。

> 让 WorkBuddy 问他这三个问题，把答案压成三句话，存成 `00_定位.md`。

**第 2 步：建目录。**

你在第 8 章定的那张房间表，**别直接抄给他**——让他按自己那一行重新分房间。你只在旁边问一句：「这个房间里不放什么？」

**为什么不能抄你的？** 因为房间是按「他天天找什么」分的，不是按「你天天找什么」分的。抄过去，三个月后他那套就全乱了。

> **跟 WorkBuddy 说：**「我要给他建目录。先问他三句：他天天要找的东西有哪几类？哪一类最多？哪一类绝对不能跟别的混？问完按他的答案画一张房间表，每个房间后面写一句『不放什么』。」

**第 3 步：写三个规则文件。**

这一步最容易糊弄，也最要命。**只写三个，不要多**：

| 文件 | 写什么 | 一句话判据 |
|---|---|---|
| 身份与红线 | 他是谁、干什么、哪几件事绝对不做 | 红线写成「不许」，不写「尽量」 |
| 流程与触发词 | 一件活分几步、每步叫什么、他喊哪句话起哪一步 | 每步都有一句他能原样说出口的话 |
| 格式与风格 | 交付物长什么样、字号行距页边距、口气是硬还是软 | 参数写死，风格给一个例子 |

**为什么只三个？** 因为再多他就不看了。**规则文件的价值不在全，在他会不会翻第二次。**

> **跟 WorkBuddy 说：**「帮我起三个文件：`01_身份与红线.md`、`02_流程与触发词.md`、`03_格式与风格.md`。每个文件先只放标题和三个小标题，内容等他一条一条往里填——**不要替他编**，他还没说的，你问了再写。」

**第 4 步：配知识来源。**

讲清三件事：哪些该进料仓、哪些只能留在本地、哪些一个字都不许出去。**这一步讲的是边界，不是技术。**

> 让 WorkBuddy 带他做一次分类：拿他十份真实材料，一份一份问「这个能不能进料仓」。

**为什么必须用他自己的材料？** 用你的材料练，他只会点头；用他自己的，他才会犹豫——**犹豫的那几份，就是他以后会出事的地方。**

**第 5 步：装技能。**

照第 19 章那两张表走：先三问过一遍，再按「动不动」分三列抄下来。**别一次装一堆。**

装完只留一句交代：**「装了不等于开着。哪几个真能自己动，你自己数一遍。」**

**第 6 步：配流程，当场跑一次。**

这是十步里最关键的一步——**流程、技能、触发词，三样必须对得上**：流程有几步、每步用哪个技能、喊哪句话起这一步。**三样里有一样对不上，他喊了没反应，以后就再也不喊了。**

配完**当场跑一次**，用一件他真实的活，从头到尾走一遍。跑不通就停下改，别往后走。

**第 7 步：建定时任务。**

照第 17 章那三条标准过筛：**这件事值不值得定期干、干完有没有产物、不看会不会出事。** 三条都过才建。

建完把「名字 / 什么时候跑 / 上次跑是几号」记下来。**别记「正常运行」——那是感觉，不是事实。**

> **跟 WorkBuddy 说：**「按这三条标准，把他说的那几件事过一遍筛，过不了的直接划掉，别留着好看。过了的建成定时任务，建完告诉我：叫什么、什么时候跑、上次跑是几号。」

**第 8 步：四项测试。**

四件事，一件都不能省，**当场做，不许他说「我知道了」**：

| # | 测什么 | 怎么算过 |
|---|---|---|
| 1 | 能干活 | 给它一件真活，产物能直接用，或改两处就能用 |
| 2 | 会拦人 | 故意喂一条假法条，它拦下来并说清拦在哪 |
| 3 | 记得住 | 关掉重开，它还记得他是谁、在办什么 |
| 4 | 找得到 | 问它「上次那份东西在哪」，它能指到具体文件 |

**前三项是底线，第四项最容易被放过。** 第四项过不了，说明目录是乱的——他半年后一定找不到东西。

**第 9 步：填知识库，抽查质量。**

先让他填够自己那一行能用的量，再**随机抽几份看质量**。抽的时候只看三样：出处核得到吗、说法和别处一致吗、有没有把「查不到」写成肯定句。

**为什么要抽？** 因为堆得多不等于能用。**堆进去一堆错的，比只放几份对的更危险**——错的会被当成依据引出去。

**第 10 步：正式投用，收集反馈，迭代。**

投用那天起，让他每周记一句：**这周哪件事它帮上了、哪件事它帮倒忙了。** 记满一段再回来改一次规则文件。

**十步走完不是结束，是开始。** 你交给他的不是一套装好的系统，是**一套会自己长的办法**——这一步不交，他过些日子一定退回手工。

**投用后第一个月，只看三样**：他有没有主动打开过、有没有一件事是它做完他只改了两笔、有没有一件事他宁可自己干。**第三样出现得多，说明定位或流程有问题——回去改，别怪他不用。**

### 做完，你眼前是什么样

一张《交付十步》清单，十行都打了勾；最下面一行小字写着「第 8 步四项测试：全过」。

对方那边，你打开他的库，能看到：`00_定位.md` 三句话、三个规则文件、一张房间表、一份技能三列表、一张定时任务点名表。

**十步的勾有一个是空的，就别跟人说「搭好了」。** 空的那一步，就是他过些日子放弃的地方。

**第一次交付，别指望十步一遍过。** 第 6 步和第 8 步通常要来回两三趟——这不是你没讲清，是每换一个人，总有一两处对不上。**把对不上的那几处记下来，下次给别人搭就快多了。**
