# 术语索引表

> **版本**：v1.0 ｜ **用途**：《智能车机：律师数字分身系统的 0 到 1》全书核心术语的「认知导航」
>
> 这份术语索引不是「词典」，是「地图」。它不给你背定义，它帮你在读完这本书之后，**把散落在 13 章里的概念，重新收拢成一整套**。每条术语后面都标了章号，想不起来就翻回去看。

## 二、起手篇（第 1–2 章）｜先立规矩、再接大脑

| 术语 | 一句话定义 |
|---|---|
| 红线（第 1 章） | 绝对不能碰的三条规矩：数据不出本机 / 不编法条 / 不代点 UI。 |
| 中枢（第 1 章） | 所有东西共用的「家」，单一事实源的物理形态。 |
| 四层底盘（第 1 章） | 这台车的四层：**大脑**（想）/ **记忆**（记）/ **人格**（是谁）/ **数据**（知道啥）。 |
| 门（门户）（第 1 章） | 浏览器能打开的那扇门，本机服务 `127.0.0.1:9655`。 |
| 自动再着（第 1 章） | 车熄了能自己再点着的机制（launchd / 任务计划程序）——底盘，不是可有可无。 |
| 大脑（推理层）（第 2 章） | 让车「会想」的那条路，**可插拔、一主一备**，断了自动切。 |
| 心智模型卡 / 人格卡（第 2 章） | 把「你怎么想、你是谁」写成卡，钥匙不写进文件。 |

## 三、造大脑篇（第 3–5 章）｜记忆、知识、门禁

| 术语 | 一句话定义 |
|---|---|
| 记忆母舰（第 3 章） | 所有系统共用的「总记忆」，单一事实源。 |
| 记忆协议（第 3 章） | 谁读谁写、全程留痕的规矩——进来先读，出去必写，防记忆打架。 |
| 冲突仲裁（第 3 章） | 两条记忆打架了，旧值/新值/谁赢，写清规则。 |
| 知识库（电池）（第 4 章） | 亲手炼出来的那颗「电池」，不是下载来的——办案即炼卡。 |
| 要点卡 / 规则卡（第 4 章） | 记一个案子全貌的卡 / 记一条能直接抄规则的卡。 |
| 标签（属性）（第 4 章） | 卡顶灰区的几行字，用来筛卡。 |
| 红卡（第 4 章） | 法条没核到原文的卡，绝不许引到文书。 |
| 留痕（存推理）（第 4 章） | 存「怎么想的」，不存结论——决策留痕。 |
| 门禁（第 5 章） | 盯着每次输出、一发现「编」就拦下来的独立检查员。 |
| 一本正经地胡说（第 5 章） | AI 记不清时硬编一个像真的答案，还自带条号。 |
| 0 才放行（第 5 章） | 查出一处问题就整份不放行的死规矩。 |
| 待回填（第 5 章） | 核不到原文就老实标出的三个字，代表「草稿、不能对外用」。 |

## 四、四工位篇（第 6–9 章）｜按「办案最痛」排序

| 术语 | 一句话定义 |
|---|---|
| 案件工位（第 6 章） | 不让案子死在「忘」上的工位。 |
| 状态即数据（第 6 章） | 把案件「当前状态」变成可读数据，而非脑子印象。 |
| 期限门禁（第 6 章） | 九道门 + 三级 + 一张台账，关键期限节点的强制检查。 |
| 双管线（第 6 章） | 内部全量 / 对外脱敏，绝不共用。 |
| 合同资产库（第 7 章） | 审过的、争议的、可复用的合同。 |
| 红蓝复核（第 7 章） | 蓝队守、红队攻，一人打两场——红队只出战报，不许改合同。 |
| 格式铁律（第 7 章） | 仿宋三号 16pt / 宋体 22pt / 行距固定 28 磅等排版标准。 |
| 庭审工位（第 8 章） | 开庭前先打一仗的工位——四张椅子：审判长 / 对方代理人（红队）/ 我方代理人（蓝队）/ 书记员。 |
| 证据分级（第 8 章） | 哪些能用、哪些是软肋（F 表 / E1004 三层核验），证据按「三层」过。 |
| 合规工位（第 9 章） | 让散落规则自己转的工位——一张每周自己跑的表。 |

## 九、易混术语辨析（长得像、意思不同的几对，别混）

| 一对 | 区别（一句话） |
|---|---|
| 要点卡 vs 规则卡（第 4 章） | 要点卡记「一个案子**全貌**」，规则卡记「一条能**直接抄**的规则」。 |
| 蓝队 vs 红队（第 7 / 8 章） | 蓝队 = 己方守方（逐字找错、找漏），红队 = 对手攻方（找怎么击穿它）。口诀：**红队只出战报，不许改合同。** |
| 红线 vs 门禁（第 1 / 5 章） | 红线是「**不能碰的规矩**」（写在纸上的三条），门禁是「**盯着每次输出、一发现编就拦下**的检查员」。 |
| 记忆母舰 vs 知识库（第 3 / 4 章） | 记忆母舰是「**总记忆**」（谁读谁写、防打架），知识库是「**炼出来的电池**」（办案办出来的卡）。 |
| 充电桩 vs 本地快照（第 11 章） | 充电桩是「**权威来路**」（联网查），本地快照是「**断网降级**」（本地存一份）。 |
| 智能体 vs 流水线（第 10 章） | 智能体是「**有编制的 AI 员工**」（谁在干活），流水线是「**把重复劳动写成的流程**」（怎么干）。 |
| 律师 ADIS vs 能力成长地图（第 12 / 13 章） | 律师 ADIS 是「**开车**的操作台」（今天怎么开），成长地图是「**导航**去哪」（往哪个台阶走）。 |
| 0 才放行 vs 待回填（第 5 章） | 0 才放行是「查出一处问题**整份不放行**」，待回填是「核不到原文**老实标出**、不能对外用」。 |

## 十、十句速记（把全书术语串成一段话）

> 你的答案是把数字分身**造一辆车**：先立**红线**、装**中枢**和**四层底盘**，再接一个**可插拔的大脑**。造**记忆母舰**（协议 + 冲突仲裁），炼**知识库**（要点卡 + 规则卡，红卡不出门），装**门禁**（0 才放行、待回填）。然后造四个**工位**——**案件**（状态即数据 + 期限门禁）、**合同文书**（红蓝复核 + 格式铁律）、**庭审**（四张椅子 + 证据分级）、**合规**（每周自己跑的表）。再装**发动机舱**——**智能体 + 流水线**、**充电桩 + 成本账本**。最后统一造 **10 屏律师 ADIS**（评分引擎 + OTA），装一张**能力成长地图**（三台阶 + 查炼升 + 90 天路线），照着上路，越用越强。
