# 《智能车机：律师数字分身系统的 0 到 1》出版咨询报告

> 出具：图书共创专家 ｜ 日期：2026-11-02 ｜ 对象：老强（作者）
> 范围：书稿评价 + 出版标准差距 + 出版要求 + 著作权登记 + 书号获取 + 费用预算
> 数据来源：全书 20 份成稿统稿数据（本地实测）+ 联网核实（行业公开报价、国家新闻出版署规范）

---

## 一句话结论

**作为「三书三部曲」的第二本，这本书的定位红利是第一本无法替代的——它是「操作书」，是第一本「操作止步线」的全部承接者，两书「道 + 术」合体才闭环；但它离「可送审定稿」同样差一个「三审三校」，且因为含大量脚本 / prompt / 命令，排版复杂度高于第一本。** 字数约 10.3 万字，自费出版单书号约需 **2.2～4.2 万元**；更优解是借三部曲的「丛书化」谈公费或丛书号，摊薄成本。

## 一、书稿评价（基于全书 20 份成稿实测数据）

### 1. 这是一本什么书

| 维度 | 判断 |
|---|---|
| 定位 | 「操作书 / 施工手册」而非「认知书」——教律师「怎么一步步把数字分身系统造出来」，认知层回指第一本 |
| 目标读者 | 训练中的律师 + WorkBuddy 小白（只会议话、Obsidian 基本操作） |
| 赛道 | 法律实务 + AI 工具落地 的交叉区，是当前「AI 概念书多、AI 落地操作书少」的**真蓝海** |
| 体量 | 序章 1 + 正文 13 章 + 附录 5 + 后记 1 = 20 份，纯汉字约 10.3 万字（含标点约 11–12 万字） |

### 2. 四个出版级优点

1. **姊妹篇定位是战略资产**：第一本《律师数字分身》全书设「操作止步线」，把「怎么配、参数怎么填、prompt 怎么写」全部移交本书——两书「道 + 术」严丝合缝，这是丛书编辑最看重的「系列完整性」。
2. **「减法」即产品力**：从 v3.0「18 屏 = 18 章」自我推翻为 v4.0「13 章 + 10 屏」，砍掉繁重冗余、主线回归新手真实搭建顺序——这种「敢砍」的判断，比「堆功能」更显作者成熟，是编辑会圈点的专业决策。
3. **体例统一度高到罕见**：13 章全部走「六关操作流」（每关四块 + 9 个收尾块），红蓝角色映射正确、章名与大纲零偏差、10 屏口径三处一致——在 AI 辅助写作里这种「成品度」很少见。
4. **零门槛 + 双系统，读者面宽**：通篇「对 WorkBuddy 说一句朴素的话」，苹果 / Windows 并列写清，把「律师 + 技术」的门槛砍到只剩「会说人话」，扩大了可触达读者群。

### 3. 三个需警惕的风险点

1. **操作内容的「时效性」**：书中大量脚本、prompt、命令、目录结构（如 `127.0.0.1:9655`、launchd / 任务计划程序），出版后工具版本一升级就可能过时——这是操作书的天生风险，需在书中明确「工具版本基线」并在营销端承诺「配套更新」。
2. **技术名词与代码排版的合规**：正文含命令、路径、JSON 字段等，出版社需按「代码 / 等宽字体」规范排版，否则读者会抄错；这是排版成本高于纯文字书的主因。
3. **AI 落地书的同质化竞争正在加剧**：虽然「落地操作书」仍是蓝海，但「AI + 律师」选题热度上升，需靠「真实翻车案例 + 姊妹篇闭环」守住差异化。

## 二、与出版标准的差距（核心，按优先级排序）

| 差距 | 现状 | 出版标准 | 缺口 |
|---|---|---|---|
| **1. 编校质量** | AI 辅助初稿，未专业校对 | 三审三校（初审/复审/终审 + 三校一核） | **最大缺口**，需专业编辑逐字打磨 |
| **2. 体例规范** | 目前是 Markdown 源文件，含大量代码块 | 需符合 CY/T 120-2015（封面版式）、代码/表格规范排版 | 需转排版 + 代码块规范处理 |
| **3. 齐清定** | 已「齐」（20 份全）、已「定」（对齐 v4.0） | 齐、清、定 | 基本达标，「清」需排版后确认 |
| **4. 原创性/查重** | AI 辅助，脚本/prompt 原创 | 原创性核查、引文出处规范 | 需查重 + 规范技术名词 |
| **5. 敏感性审查** | 法律实务 + 真实案例（已脱敏：吊顶案→甲案） | 政治导向、法律风险三审把关 | 需法律编辑专项核查 |
| **6. 书名/装帧/定价** | 作者自拟 | 出版社编辑市场化打磨 | 需出版社参与 |

> **关键判断**：差距 1（编校）和 2（体例，含代码排版）是「必做项」，其他是「配合项」。这本书**不需要重写，需要的是「专业编辑打磨 + 代码规范化排版」**。

## 三、行业出版要求（中国大陆图书出版流程）

### 标准流程（6 步，全周期约 6～12 个月）

1. **选题申报**：向出版社提交选题表 + 目录 + 样章，出版社论证市场价值与合规性；
2. **三审三校**（核心，2～4 个月）：初审（责编，看政治导向/逻辑/语言）→ 复审（编室主任，看深度/数据）→ 终审（总编，定调）；配三校（逐字校对错别字、标点、格式、代码）；
3. **申请书号 + CIP**（1～2 个月）：由出版社向国家新闻出版署统一申请 ISBN + CIP；**个人无法直接申请，必须绑定出版社**；
4. **设计排版**：封面、版式按 CY/T 120-2015 标准（代码块需等宽字体 + 行号规范）；
5. **印刷 + 样书缴送**：开具印刷委托书，出版一个月内向国家新闻出版署、国家图书馆、中国版本图书馆缴送样书；
6. **发行**：入库、上架。

### 三条硬门槛

- **书号实名制**：书号由出版社申请，作者需提供身份证/营业执照、完整书稿、出版计划；
- **重大选题备案**：内容涉及政治、军事、宗教、民族、外交等敏感问题需额外备案（本书不触发）；
- **地图审核**：书稿若含地图需审图（本书无地图，不涉及）。

## 四、著作权登记程序

> **先澄清**：著作权「创作完成即自动产生」，**不需要登记才享有**。登记的作用是「维权取证方便」——发生抄袭、盗版纠纷时，登记证书是最直接的证据。

| 项 | 内容 |
|---|---|
| 登记机构 | 中国版权保护中心（www.ccopyright.com.cn），或省级版权局 |
| 费用 | 约 **300 元/件**（文字作品，以官方最新公示为准） |
| 周期 | 受理后约 **25 个工作日**（不含补正时间） |
| 所需材料 | ① 申请表 ② 身份证复印件 ③ 权利归属证明 ④ 作品样本（书稿电子版）⑤ 承诺书 |
| 办理方式 | 官网注册 → 在线填写 → 上传材料 → 缴费 → 审查 → 领电子证书 |

> **建议**：三本定稿后，对**每本书**各做一次作品著作权登记（三本约 900 元）。不必逐章登记。

## 五、「版号」如何获取（关键澄清）

图书出版语境下准确说法是「**书号**」，由两部分构成：

| 名称 | 全称 | 作用 | 谁申请 |
|---|---|---|---|
| **ISBN** | 国际标准书号 | 图书的「身份证」，一书一号 | 出版社向新闻出版署申请 |
| **CIP** | 图书在版编目数据 | 图书的「户口」，公开发行/评职称关键凭证 | 出版社申请，可在新闻出版署官网查询 |

> ⚠️ **「版号」是游戏/音像/电子出版物的说法**，图书出版没有这个称谓。老强要拿的是 **ISBN + CIP 双齐全的「国内单书号」**。

### 获取路径（两条）

| 路径 | 说明 | 费用 | 适用 |
|---|---|---|---|
| **公费出版** | 出版社看中市场价值，主动签约 | 作者 0 元 + 版税（6%～10%） | 选题有明确市场潜力 |
| **自费出版** | 作者承担全部费用 | 书号管理费 1.5～5 万 | 职称评审、品牌背书、个人出版 |

> **三部曲的特殊机会**：三本成套的「丛书」是出版社喜闻乐见的形态。可优先谈「**丛书号**」（一套 3 本共用一号，约 3 万，成本摊薄）或「**公费丛书**」（三本一起签，议价能力更强）。但注意：丛书号不能分册独立定价发行，若想每本独立公开发行、独立评职称，仍需各自单书号。

## 六、费用预算（2026 年市场参考价，约 10 万字单书号）

### 自费出版全预算（按「省级社 + 印 1000 册」估算）

| 项目 | 费用区间 | 说明 |
|---|---|---|
| 书号管理费（省级社） | 1.5～2.5 万 | 国家级/百佳社 3～5 万；字数不影响书号费 |
| 三审三校费 | 0.15～0.5 万 | 约 15～50 元/千字 × 10 万字 |
| 封面设计 | 0.05～0.3 万 | 模板 500～1000，定制 1500～3000 |
| 内文排版（含代码块） | 0.15～0.4 万 | 含脚本/prompt 的等宽排版，单价高于纯文字 |
| 印刷装订（1000 册） | 0.3～0.6 万 | 10 万字约 200 页，比第一本薄 |
| 著作权登记 | 约 300 元 | 一次性 |
| **合计** | **约 2.2～4.2 万** | 省级社 + 1000 册 |

### 不同书号类型总价对照（约 10 万字）

| 类型 | 总费用 | 能否独立公开发行 | 适用 |
|---|---|---|---|
| **国内单书号（推荐）** | 2.2～4.2 万 | ✅ ISBN+CIP 齐全 | 公开发行、评职称 |
| 丛书号（三部曲共用一号） | 约 3 万/套 | ⚠️ 不能分册独立定价 | 系列套书、品牌背书 |
| 电子音像书号 | 约 2 万 | ❌ 只能「盘+书」，无 CIP | 内部交流、赠送 |

### 公费出版预算

| 项 | 说明 |
|---|---|
| 作者投入 | **0 元**（出版社承担全部） |
| 作者收益 | 版税 6%～10%（首印）× 定价 × 销量 |
| 前提 | 出版社认可选题市场价值，通常需「作者行业影响力 + 选题明确卖点」 |

## 七、给老强的行动建议（按顺序）

1. **三本打包谈出版，别单本单谈**——三部曲的「道 + 术 + 商业」完整链条，是单本无法比拟的议价筹码，优先探「公费丛书」；
2. **先做「专业编校」**（约 0.3～0.6 万），重点打磨：AI 味、代码块排版规范、脚本/prompt 的可抄性校验、工具版本基线标注；
3. **同步做著作权登记**（每本 300 元，定稿后一次性办理）；
4. **选题申报试探市场**——向 2～3 家法律类/科技经管类出版社投选题（目录 + 序章 + 第 1 章样章），看能否走公费；
5. **公费无果再考虑自费**——自费锁定「国内单书号（ISBN+CIP）」，预算 2.2～4.2 万，签合同前核对书号类型、版权归属、配套更新条款。
