## 四、术语关系速查（易混的词组）

| 易混组 | 关系一句话 |
|---|---|
| 记忆中枢 / 单一事实源 / 中枢 | 记忆中枢是「总称」，单一事实源是「原则」，中枢是「存放处」——同一件事的三个侧面 |
| 卡片 / 规则 | 卡片是「资料」（这件事长什么样），规则是「结论」（遇到这种情况怎么办）——先存卡，再炼规则 |
| LC 卡 / R-CL 规则 | LC 卡记「过程与资料」，R-CL 出「结论」——一个管这次检索留了什么，一个管下次直接套什么 |
| 红蓝复核 / 红蓝对抗 | 红蓝复核在「文书上」挑刺（第一道门禁），红蓝对抗在「庭上」推演（模拟法庭）——一个守门，一个练兵 |
| F 表 / E1004 | F 表是「摆事实」（静态盘点证据），E1004 是「下结论」（证据冲突时的三层核验）——先摆清，再谨慎下 |
| 数字分身 / Agent / AI | 数字分身是一种 Agent（智能体），AI 是它们背后的技术能力 |
