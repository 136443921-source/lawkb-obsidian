# 第 17 章　能力地图：青年律师的六项核心能力

> **本篇说明**：这是第五篇「成长篇」的第 1 章。前面四篇，你把数字分身的四部件搭了起来、在个案里跑通了一遍。但从这一篇开始，问题变了——**有了系统之后，你怎么用它，把自己「喂」成一个越来越值钱的律师？** 成长篇三章（第 17—19 章）一起回答这件事：第 17 章讲「目标」（能力地图，先看清要长成什么样），第 18 章讲「路线」（90 天怎么一步步搭），第 19 章讲「装备」（工具链怎么配齐）。三章从「看清目标」到「规划路线」再到「配齐装备」，建议连着读。

> **本章三轨标注**（器 × 道 × 心）：
>
> | 轨 | 本章踩哪条线 |
> |---|---|
> | 【器】搭哪个部件 | 本章搭「能力地图 + 自评表」——六项能力流水线 + 六项自评打分 + 短板托底件对照表 |
> | 【道】撬动哪个倍增点 | 把「补能力」从「广撒网全练」变成「精准补短板」——先看清哪块板短，数字分身只补下限 |
> | 【心】哪一步转弯 | 第十六次观念转弯：从「什么都会一点」，到「看清自己哪块板短」 |

---

> 你办了三年案子，自认为什么都会一点：会查法条、会写文书、会理证据、会跑程序，跟当事人也能聊上几句。可前几天师父一句轻飘飘的话，把你问住了——**「你说说，你到底哪项强、哪项弱？」**

> 你张了张嘴，愣是答不上来。

> 那一刻你突然发现，自己这三年，一直在「**什么都会一点、什么都不精**」里打转。忙是真的忙，可要说自己「值多少钱、靠什么值钱」，说不清楚。

这不是你一个人的毛病。大多数青年律师，都缺一张**能力地图**——把你办案要用的几项本事，一张图摊开，看清哪块强、哪块弱。

而搭数字分身这件事，最大的浪费，就是「**还没看清地图，就急着搭系统**」。系统再好，用在你根本不缺的那块板上，等于白搭；真正漏水的那块板，反而一直漏着。

所以这一章，先不教你搭任何东西。先带你，把地图看清。

## 17.1　六项核心能力：不是六个筐，是一条流水线

先说结论：青年律师的看家本事，拆到底，是**六项核心能力**——检索、证据、写作、程序、沟通、风控。

看到「六项」，你可能会下意识把它当成「六个筐」，一项一项往里填。错。**这六项不是并列的六个筐，是一条流水线上的六个环节。** 你办案，从拿到一个案子到结案，走的就是这条流水线：

1. **检索**——先「找得到」。法条在哪、类案在哪、规则在哪，找不到，后面全是空中楼阁；
2. **证据**——再「理得清」。当事人说了一堆，哪些有证据、哪些是空口，理不清，你写的东西就是无根之木；
3. **写作**——然后「写得出」。把理清的事实和结论，写成结构清楚、法条精准的文书，写不出，前面的功夫都白费；
4. **程序**——全程「走得对」。管辖、期限、流程这些硬约束，一步走错，全盘皆输；
5. **沟通**——对外「说得明」。对当事人、对对方、对法院，预期管得住，事才办得顺；
6. **风控**——最后「兜得住」。把那些低频但致命的错，在交出去之前拦下来。

看清楚这条链的分工：**检索、证据、写作，是「出活」的三项**，决定你「会不会办」；**程序、风控，是「守门」的两项**，决定你「稳不稳」；**沟通，是唯一横切全程的一项**——从接案到结案，你无时无刻不在沟通，所以它不占某个固定环节，而是渗透在每一个环节里。

「沟通横切全程」这六个字，值得你多停一秒。你想想——**检索，是「跟数据库沟通」；证据，是「跟当事人沟通」；写作，是「跟法官沟通」；程序，是「跟法院沟通」；风控，是「跟自己沟通」**（把那个想偷懒的自己，摁住再查一遍）。**所以沟通不是第六项，它是前五项「怎么落地」的那根线。**

也正因为它横切全程，它成了最「藏不住」的一项——**你检索强不强，别人未必看得出；但你跟当事人说话靠不靠谱，三句话就露了。** 而且它还是最「靠人」的一项：检索、写作可以靠系统托底，但「跟一个焦虑的当事人把话说到位」，系统只能给你话术模板，最后那句「拍板的话」，还得你自己说。

**所以沟通，是六项里唯一「系统能帮你、却替不了你」的一项。** 这一点，到第 19 章配工具链时，你还会再遇到——有些东西，是机制能托的；有些东西，机制只能「递到嘴边」，吞不吞得下去，看你自己。

为什么偏偏是这六项，不是五项、不是七项？因为**办案这件事，本身就只有这六个动作**。你拆任何一个案子，从头到尾，逃不出「找 → 理 → 写 → 走 → 说 → 守」这六步。

我给你验证一下这个「六步」的必然性——你随便拿一个案子，从接手到结案，一步步对：

- 接手后第一件事，是**找**法条、找类案（检索）；
- 然后**理**当事人给的证据、理事实（证据）；
- 接着**写**起诉状、代理词（写作）；
- 全程**走**程序，管期限、管流程（程序）；
- 随时要**说**——跟当事人说、跟法院说（沟通）；
- 最后交出去之前，还得**守**——查一遍有没有致命的错（风控）。

**六步，一步都省不掉。** 少一项，流水线就断一处：检索断了，输不进料；写作断了，出不了货；程序断了，中途翻车；风控断了，带病交付。**六项能力，不是我从哪本书上抄来的清单，是「办案」这条链本身的样子。**

我给你看「断链」长什么样，你就知道每一步为什么都不能省——

**检索断了**：一个合同纠纷，你凭记忆以为「违约金上限是 30%」，没去查。庭上一说，对方律师冷笑：「那是旧司法解释，早废止了。」**你整段主张，当场塌了。** 检索断，断在「进料口」——后面全是用错料在加工。

**证据断了**：当事人拍胸脯说「他肯定还欠我钱」，你没核证据，就把这话写进了文书。庭上对方拿出转账记录，证明早还清了。**你写的事实，是无根之木，风一吹就倒。** 证据断，断在「地基」——上面盖得再漂亮，底下是空的。

**程序断了**：案子赢了，可你忘了上诉期是哪天，等想起来，早就过了。**你赢了官司，却丢了权利。** 程序断，断在「中途」——前面全对，一步走错，全盘皆输。

**风控断了**：文书写得漂漂亮亮，交出去才发现案号写错一位。**一个数字，让整份文书成了废纸。** 风控断，断在「出口」——交出去那一下，没人拦。

**看出来了吗？六步里断任何一步，翻车的样子都不一样——但都是「翻车」。** 这，就是为什么说六项能力是一条流水线，不是六个筐：**筐之间是独立的，一个空了别的还能装；链条是串联的，一节断了，整条链都废。**

> **金句：能力不是六个筐，是六个环节。** 你缺的从来不是「某一筐没装满」，是「某一段链子断了」——而断在哪，决定你会在哪翻车。

## 17.2　三困局落到身上，就是能力短板

现在，把这六项，接回第 1 章。还记得第 1 章那三个困局吗——**经验留不住、质量靠运气、风险没人兜**？当时我说，那是「一个病根（成果没变成资产）的三个症状」。这一章，我要把话再说透一层：**这三个症状，落到你身上，就是能力短板。**

| 第 1 章的三困局 | 背后是谁的能力短板 | 为什么必然 |
|---|---|---|
| 经验留不住（从头再来） | 检索、证据、写作 | 这三项是「越用越熟」的经验型能力，最吃复利；经验存不住，这三项每次都得从头再来 |
| 质量靠运气（交付带病） | 写作、风控 | 交付质量靠写作功底兜，风险敞口靠风控意识兜；这两项一波动，交付就带病 |
| 风险没人兜（低频高损） | 程序、风控 | 期限、管辖这些程序问题是风险最高发的点，而风控是最后那道总闸门 |

你发现没有：**写作和风控，被提到了两次。** 这不是笔误，是它们在告诉你——这两项是「枢纽能力」（卡在关键收口上的能力），一个卡在出活的收口，一个卡在守门的收口，**最值得先补。**

为什么「枢纽」这么重要？因为**它卡在「最后一道」的位置上。** 写作，是你所有检索、证据功夫的「出口」——前面做得再好，写不出来，全白费；风控，是你所有成果交出去的「闸门」——前面全对，交出去那一刻错一个案号，全盘崩。**这两块板，短一寸，比别处短一尺还致命。** 因为它俩是「最后一道」，前面所有的努力，都要从它俩这道口上过。

我给你看「最后一道口」有多要命——

一个案子，你检索做足了（找到关键法条）、证据理清了（F 表编得整整齐齐）、程序也没错（期限都在台账上）。**前面的四步，全对了。** 可就差最后一步「写作」——你写代理词时，把法条条号抄错了一位，「第 577 条」写成了「第 584 条」。

**结果呢？法官看到你的文书，发现法条引错了，整份代理词的可信度，当场打了对折。** 前面四步做得再好，这一笔写错，全毁了。

反过来，一个案子，你证据、程序都有点瑕疵，但写作功底扎实、交出去前风控又扫了一遍——**那点瑕疵，被你「最后一道」兜住了，没漏出去。**

**这就是「枢纽」的杀伤力：它不在前面，在最后。** 前面错了，还有机会补；最后一道错了，直接交出去，没得补救。**所以写作和风控这两块板，短一寸，比别处短一尺更致命——因为它们卡在「无可挽回」的位置上。**

你可能注意到，**沟通没进这张表**——不是漏了，是因为它横切全程，三个困局都沾它。三个困局的病根，都是「依赖会累、会忘、会波动的人」，而沟通，恰恰是最典型「靠人」的环节。

所以，第 1 章问「为什么你越忙越不值钱」，答案在这一章变具体了：**因为你没看清，自己漏的是哪几块板子。** 三困局不是天上掉下来的，是你六项能力里那几块短板的「发作」。**能力短板，就是三困局的源头。**

> **金句：三困局是「症状」，能力短板是「病灶」。** 治症状，你永远在救火；治病灶，你才真正断了根。

## 17.3　能力自评表：先给自己照个 X 光

看清了地图，下一步是照 X 光——知道自己哪项几斤几两。别急着搭系统，先老老实实给自己打个分。

下面这张表，每项能力，我从 1 分到 5 分，标出「弱」和「强」各自长什么样。你对着自己最近办的三个案子，一项一项打：

| 能力 | 弱（1—2 分）长什么样 | 强（4—5 分）长什么样 | 自评分 |
|---|---|---|---|
| 检索 | 只会百度或凭记忆，找到的法条可能是失效的 | 有固定的类案库、法条库，几分钟定位到有效版本 | |
| 证据 | 事实说一堆，证据对不上；哪些坐实、哪些存疑说不清 | 每条事实有出处，能分清「已坐实 / 存疑 / 待核」 | |
| 写作 | 文书堆砌、结构乱，法条写「相关规定」 | 结构清楚、法条精准到第几条，交前过一遍质检 | |
| 程序 | 漏过上诉期、错过举证期，期限靠脑子记 | 有期限台账，到期前主动提醒 | |
| 沟通 | 乱承诺、该说的没说、不该说的乱说，当事人预期失控 | 话术有章可循，预期管得住，还留痕 | |
| 风控 | 没有风险意识，错案号、失效法条直接交出去 | 交前有固定检查项，低频高损的错能被拦住 | |

打分之前，先给你一个提醒：**人天生会高估自己。** 尤其「守门」那几项，没出过事的，你容易给自己打 4 分，觉得「我挺细心的」。可「细心」是状态，不是能力——第 1 章就说过，状态会波动。

所以打分时别凭感觉，凭「**最近三个案子里，这一项有没有出过错**」：

- 出过一次漏期限，程序就别打 3 分以上；
- 写错过一次案号，风控就得老老实实往下压；
- 有过一次当事人闹「你怎么当初不说清楚」，沟通就得扣分。

**照 X 光，最怕的是自己给自己美颜。** 你给自己打的每一分，都要有「证据」——不是「我觉得」，是「最近这三个案子，它到底有没有掉过链子」。没证据的 4 分，等于没拍。

我给你还原一个「美颜翻车」现场，你就知道自欺有多要命——

一个律师自评「程序 4 分」，理由很充分：「我很细心，从来没漏过期限。」可你让他查「最近三个案子的上诉期、举证期都是哪天」，他支支吾吾，半天对不上——**原来他「没漏过」，不是因为「细心」，是因为「还没遇到过那种期限特别紧、又特别忙的案子」。**

结果呢？下一个案子，恰好赶上他手里同时压了三个案，其中两个的上诉期挤在同一周。他「细心」的记性，在连轴转里崩了——**漏掉一个上诉期，客户的权利白白丢了。**

**这就是「细心」的真相：它经不起「忙」的考验。** 你自评 4 分，评的是「状态最好时的你」；可真正决定出不出事的，是「最忙、最慌、最累时的你」。**所以照 X 光，别照「状态最好的自己」，要照「最狼狈的那个自己」**——那才是你执业安全真正依赖的底线。

> **金句：照 X 光，别给自己美颜。** 你评的每一分，都要经得起「最忙的那个你」来复核。

## 17.4　数字分身补的是「下限」，不是「上限」

照完 X 光，你可能急了：短板这么多，我一项一项练，练到猴年马月？

先别急。这一节要告诉你一个关键的判断——**数字分身补的，不是你的「上限」，是你的「下限」。**

什么意思？把每项能力拆成两层看：

- **上限**，是你状态最好、时间充裕时能发挥出的水平；
- **下限**，是你凌晨三点、被催得心慌、连轴转时，还保得住的那条底线。

你写作 4 分，是说你的上限有 4 分；但凌晨三点赶工时，你能发挥出来的，可能只有 2 分。**真正决定你执业安全的，不是上限，是下限。** 一个案子翻车，从来不是因为你的上限不够高，而是因为某一刻的下限跌穿了。

这个「上限」和「下限」的差别，我给你摆一个具体场景，你一看就懂——

同样是「写代理词」这件事：

- **上限状态下的你**：时间充裕、精神饱满，你精雕细琢，四段式立得清、法条核得准、占位符一个个填掉。写出来的文书，能打 4 分、5 分。
- **下限状态下的你**：凌晨三点，明天九点开庭，你已经连轴转了三天，眼睛发花。这时候你写出来的代理词，可能法条条号顺手抄错、事实段的 F 号漏标、占位符没填就发出去。**这份文书，可能只有 2 分，甚至更低。**

**而翻车，永远发生在「下限状态」下。** 你不可能在你「状态最好」的时候翻车——状态好时，你什么都能注意到。真正让你出事的，永远是那个「凌晨三点、被催得心慌」的你。**所以，决定你执业安全的，从来不是你最好的时候能写多好，是你最糟的时候会不会写错。**

这，就是「下限」比「上限」更要命的原因。**上限决定你「能多好」，下限决定你「会多糟」——而翻车，看的是后者。**

而「下限」这个东西，靠「更努力」救不了。为什么？因为下限跌穿的那一刻，恰恰是你最累、最慌、最不可能「更努力」的那一刻。**你没法在自己最脆弱的时候，命令自己更用力。** 这是第 1 章那句老话的翻版：依赖会累、会忘、会波动的人，就守不住下限。

守得住下限的，只有机制——一套不会累、不会忘、不看心情的规则。**这就是数字分身的定位：它不替你练能力，它替你托下限。**

每一项短板，数字分身都有对应的「托底件」（针对这块短板配的机制）：

| 能力短板 | 会出什么事 | 数字分身用什么托 | 托住的下限 |
|---|---|---|---|
| 检索 | 找不到、找到失效的法条 | 记忆中枢（类案卡、法条卡）+ 工具链（权威数据库） | 查过的，下次直接调 |
| 证据 | 事实对不上证据、存疑硬写坐实 | F 表（事实编号表）+ E1004（三层核验） | 每条事实有出处，下结论先核 |
| 写作 | 法条写错、结构乱 | 模板 + SOP（标准操作流程）+ 质量门禁（LTI 九维） | 交前过一道闸 |
| 程序 | 漏期限、记错流程 | 案件生命周期台账 + 自动化提醒 | 期限有人盯、到期会响 |
| 沟通 | 乱承诺、预期失控 | 沟通 SOP（话术模板）+ 记忆中枢（当事人偏好） | 话术有章、预期有管 |
| 风控 | 低频高损的错没人拦 | 质量门禁 + 十条铁律 | 每次从头扫一遍 |

看这张表，你会发现一个规律：**每一项托底件，都是前面四篇你学过的东西。** 检索靠底座篇的「知识飞轮」（记忆中枢 + 工具链），证据靠实战篇的 F 表和 E1004，写作靠方法篇的 LTI 门禁，程序靠「案件生命周期」，风控靠附录篇的十条铁律。

**数字分身不是另起炉灶，它是把你前面学的零件，精准装到你最短的那几块板上。** 这才是「成长篇」要教你的第一件事——你前面四篇攒下的所有零件，从这一章开始，有了一个明确的「装法」：**哪块板短，就把哪个零件装上去。**

> **金句：能力决定你能飞多高，系统决定你不会摔多惨。** 青年律师最该补的，从来不是飞得更高，是别摔下去。

## 17.5　样例：李律师的能力地图

讲这么多，落到一个真实（脱敏）的例子，你就全懂了。

我认识一个青年律师，姓李。他对着 17.3 那张表，认认真真给自己照了次 X 光，自评下来：

| 能力 | 检索 | 证据 | 写作 | 程序 | 沟通 | 风控 |
|---|---|---|---|---|---|---|
| 自评分 | 3 | 2 | 4 | 2 | 4 | 1 |

你一眼就能看出他的命门在哪：**他「出活」的板子（写作 4、沟通 4）挺长，可「守门」的板子（证据 2、程序 2、风控 1）几乎全是短的。**

这意味着什么？他写出来的文书漂漂亮亮，可底下的事实是「存疑」的、期限是「脑子里记的」、风险是「没人扫的」。**这种人，最容易出那种「看起来很专业、翻车很突然」的事故**——因为他的短板，全埋在看不见的地方。

照完这张表，李律师本来很焦虑：「短板这么多，我一项一项练，练到猴年马月？」但用 17.4 的「托下限」思路一看，答案立刻清晰了——**他不用把六项全练到 5 分，那是练不完的。** 他要做的，是看清证据、程序、风控三块板短，然后**只针对这三块，装上对应的托底件**：

- **证据 2 分** → 装 F 表 + E1004，把「存疑硬写坐实」的毛病托住；
- **程序 2 分** → 装案件生命周期台账 + 自动化提醒，把「漏期限」的毛病托住；
- **风控 1 分** → 装质量门禁 + 十条铁律，把「错案号、失效法条直接交出去」的毛病托住。

**短板还是那三块短板，但底下垫了东西，跌不穿了。** 李律师没变成「六项全能」，但他最危险的三块板，从此有了护栏——这，就比「苦练六项」实在得多。

你照完自己的 X 光，大概率也会得到一个类似的结论：**你的短板，往往集中在「守门」的那几项。** 为什么？因为出活的能力，天天被师父、被当事人盯着，逼着你练；守门的能力，没人盯，全凭自觉——而自觉，恰恰是第 1 章早就说过、最靠不住的东西。

我拆开说，你就知道「没人盯」有多危险——

**出活的能力，有人盯着。** 你写的文书不好，师父当场给你退回来；你查的法条错了，庭上对方当场给你点破；你理的事实对不上，当事人一眼就看出来。**这些短板，藏不住——它天天在「露馅」，所以你会被逼着去补。**

**守门的能力，没人盯。** 你漏没漏期限，只有你自己知道（漏了，也是等出事那天才知道）；你风控有没有扫，扫了还是没扫，别人看不出来；你该不该提醒当事人风险，你不说，也没人知道你没说。**这些短板，藏得深——它平时不露馅，直到「砰」地一声翻车。**

**所以，出活的短板是「明伤」，疼，但你会治；守门的短板是「暗疾」，不疼，所以你会拖。** 而暗疾，恰恰是拖到最后、最要命的那种。**你照 X 光，最该照出的，就是这些「暗疾」**——因为明伤你自己看得见，暗疾，只有主动照，才照得出来。

> **金句：出活的能力，市场会逼你练；守门的能力，只有你自己会丢。** 而丢掉的，往往是最要命的那几块板。

## 17.6　【体系思维】能力地图，是成长篇的「第一张图」

讲到这，带你退后一步，把这一章，放回全书这条线上看。

成长篇三章，是一根「看清 → 规划 → 装齐」的链子：

- **第 17 章（本章）**：看清**目标**——六项能力地图，知道自己哪块板短；
- **第 18 章**：规划**路线**——90 天、13 周，把这些托底件按顺序一件件装；
- **第 19 章**：配齐**装备**——工具链，用哪几个工具把这条链子搭起来。

**看清目标、规划路线、配齐装备——这，就是「把自己喂成一个越来越值钱的律师」的三步。** 而本章「能力地图」，是这三步里的**第一步，也是最不能省的一步**。

为什么「最不能省」？因为**没有地图，后面两步全是瞎走。** 你连自己哪块板短都不知道，第 18 章的 90 天路线图，你装什么？第 19 章的工具链，你配给谁用？**方向错了，越努力越偏——这是全书反复出现的那句老话，在成长篇的入口处，又响了一次。**

再往大里看，这一章，是**全书从「搭系统」转向「用系统」的那个转折点。** 前面四篇——底座篇、方法篇、实战篇——你一直在「搭」：搭记忆中枢、搭门禁、搭文书流水线、搭模拟法庭。但从这一章起，问题变了：**你不再问「系统怎么搭」，你问「系统怎么用在我身上」。**

这个转折，我打个比方，你一下就懂——

前面四篇，你像是在「**造一台机器**」：底座篇造了记忆中枢（发动机），方法篇造了门禁（质检闸），实战篇造了文书流水线和模拟法庭（生产线 + 练兵场）。机器造好了，零件齐了，能转了。

但从这一章起，问题变成了「**用这台机器干什么**」。而答案，不是「用它办案」——那太浅了。真正的答案是：**用它，把自己「喂」成一个越来越值钱的律师。**

**造机器和用机器，是两个完全不同的阶段。** 造机器时，你关心「零件齐不齐、转不转得动」；用机器时，你关心「它能不能补我的短板、让我涨本事」。很多人在「造机器」上花了大力气，机器造得漂漂亮亮，可「用机器」这步，从来没开始过——**机器成了摆设，人还是原来那个人。**

**而「用在我身上」的第一件事，就是「照个 X 光，看清我是谁、我缺什么」。** 这，就是能力地图的意义——它是你从「会搭系统」迈向「会用系统成长」的那块跳板。

> **金句：先看清短板，再定路线，最后装工具。** 能力地图是成长篇的第一张图——图看不清，后面全是瞎走。

## 17.7　【成长心路】从「什么都会一点」，到「看清哪块板短」

最后，说点掏心窝的。

我见过两种「忙」的青年律师，天差地别。

**第一种，是「什么都会一点」。** 他今天查法条、明天写文书、后天跑程序，什么活儿都接、什么活儿都干，忙得脚不沾地。你问他「你哪项强、哪项弱」，他答不上来。**他忙了三年，忙成了一个「什么都行、什么都不精」的人**——看起来很努力，可一说到「你值多少钱、靠什么值钱」，他卡壳了。

**第二种，是「看清哪块板短」。** 他同样忙，但他心里有张地图——知道自己证据弱、程序弱，于是把有限的精力，优先砸在这两块上。他可能不接那么多活儿，但**他每接一个案子，都在补自己最短的那块板。** 三年下来，他的短板一块块补上了，人越来越值钱。

**同样是「忙」，一个在「广撒网」，一个在「精准补短板」。** 差别在哪？**前者把「忙」当成了「成长」，后者把「补短板」当成了「成长」。** 而真相是——**忙碌本身不产生成长，只有「把劲儿使在最短的那块板上」才产生成长。** 你天天在长板上练，练得再勤，短板还是短；而你值多少钱，恰恰是短板决定的（木桶原理：一个桶装多少水，看的是最短那块板）。

这里有个更扎心的真相，我必须点破——**你为什么总忍不住练长板？因为练长板「爽」。**

- 你写作强，写一份漂亮文书，师父夸你、当事人谢你，**成就感满满**；
- 你程序弱，去啃期限台账，枯燥、没人夸、还容易出错，**一点爽感都没有**。

**人天生爱做「有正反馈」的事，躲「没反馈」的事。** 而长板，全是正反馈；短板，全是没反馈。所以你一有空，就扑向长板，把短板丢在角落——**你不是不知道短板重要，是短板「练起来不爽」，于是你一拖再拖。**

**可执业的残酷在于：市场不看你「爽不爽」，只看你「漏不漏」。** 你长板再长，短板漏一次，就是一次事故。所以，别再用「练长板很爽」当借口——**真正让你成长的，恰恰是那些「不爽」的短板。** 而能力地图的作用，就是逼你正视这些「不爽」的地方，把劲儿，从「爽」的地方，掰到「该补」的地方。

我特别想让你记住这个分水岭，因为它几乎是「学生思维」和「执业思维」之间，最典型的一道坎：

- 「什么都会一点」的人，还带着「全面发展」的学生心态——他想的是「我什么都要会」；
- 「看清哪块板短」的人，已经切换成执业思维——他想的是「我最缺哪块，先补哪块」。

**而这两者之间，就差「照一张能力地图」这一个动作。** 这个动作，看起来只是「打个分、圈两块短板」，可它恰恰是把你从「盲目努力」拽到「精准成长」的那只手。

我当年，就是从第一种人，硬生生变成第二种人的。转变的那一刻，就是本章开篇那个场景——师父一句「你哪项强、哪项弱」，把我问住了。那一刻我才懂：**我不是不努力，我是没方向——我一直在「什么都练」，却从没想过「我最该练哪块」。**

所以这一章，我最想让你带走的，不是「六项能力是哪六项」，而是这一次观念转弯：

> **从「什么都会一点」，转到「看清自己哪块板短」。**

一个律师的成长，从来不体现在「会的东西越来越多」，而体现在——**他能一眼看出自己哪块板短，然后把劲儿精准地使上去。** 那种「我知道我缺什么、我知道我该怎么补」的清醒，比「我什么都会一点」的忙碌，值钱一百倍。

那这一步转弯，具体怎么迈出去？给你三个起手动作，今天就做：

**第一个动作：花 20 分钟，给自己照张 X 光。** 对着 17.3 那张表，六项能力各打一个分。**记住，别凭感觉，凭「最近三个案子里它有没有掉过链子」。**

**第二个动作：圈出最狠的两块短板。** 别贪多，先把分数最低的两项圈出来——**那才是你接下来 90 天真正要补的。** 圈多了，等于没圈。

**第三个动作：给这两块短板，抄下对应的托底件。** 对照 17.4 那张表——证据短就装 F 表、程序短就装台账、风控短就装门禁。**抄下来，贴在你抬头就能看到的地方。**

三个动作，一个照 X 光、一个圈短板、一个配托底，正好对应本章的三板斧。**你今天把这三件小事做了，明天起，你的努力就有了方向——不再「什么都练」，而是「精准补短板」。**

## 17.8　【认知锚点】读完这一章，问自己三个问题

合上书之前，问自己三个问题：

| # | 问题 | 想明白了没 |
|---|---|---|
| 1 | 我知道六项能力是哪六项，以及它们「找理写走说守」的流水线关系吗？——不知道，就还没看清地图。 | |
| 2 | 我给自己照过 X 光了吗？——没凭「最近三个案子出没出错」打分，等于没拍。 | |
| 3 | 我圈出「最狠的两块短板」了吗？——数字分身只补下限，但前提是，你得先知道下限跌在哪。 | |

三个问题，只要有一个让你停下来想了三秒，这一章就没白读。

而这三个问题，背后其实是**三次「照镜子」**——逼你从三个角度看清自己：

- **第一照，照「结构」**——六项能力流水线，照的是「你办案的完整链条长什么样」；
- **第二照，照「长短」**——自评表，照的是「你这条链子上，哪几节是短的」；
- **第三照，照「下限」**——短板托底，照的是「你最短的那几块板，跌穿了会出什么事」。

**三次照镜子，照的都不是「你多努力」，而是「你的短板在哪、跌穿了会怎样」。** 一个律师的成长，只要这三次照都照清楚了，他就不会走偏——他知道自己缺什么、知道该补什么、知道补了能托住什么。这，就是「看清自己」的完整含义：**不是知道自己会什么，是知道自己缺什么。**

而「看清自己缺什么」，恰恰是全书走到这里，最该停下来说的一句话。因为——

**前面十几章，你一直在学「怎么搭系统」。** 你学了知识飞轮、学了四段式、学了 F 表、学了模拟法庭……每一样，都是「工具」。工具本身没有方向，它可以帮你补任何一块板，也可能被用在你根本不缺的那块板上。

**从这一章起，工具有了方向。** 方向就是：**先看清自己哪块板短，再让工具去补那块板。** 没有这一步，你前面学的所有工具，都可能「用错地方」——把劲儿使在长板上，短板照样漏。

所以，能力地图这一章，看起来「什么都没教你搭」，可它恰恰是**全书最关键的转向之一**：它把你从「囤工具的人」，变成了「会给自己把脉的人」。**一个囤工具的人，工具再多，还是不知道往哪用；一个会给自己把脉的人，工具不多，但每一件都用在刀刃上。**

记住这一章，你只要带走一句话就够了：**先看清自己缺什么，再决定补什么——方向，永远比努力重要。** 而第 18 章的 90 天路线图，就是照着这个方向，给你画的一张施工图。

**下一章接线**：本章把「目标」看清了——你知道自己哪块板短、该补什么。但「知道该补什么」和「真的补上」，中间还差一张「施工图」。那就是第 18 章「90 天成长路线图」的事——它告诉你，这些托底件按什么顺序、花多少天、一件一件装上去。而六项能力自评表、补短板配置清单这些具体工具，是第二本书《智能车机：律师数字分身系统的 0 到 1》的事。

## 本章要点

1. **六项核心能力**（检索、证据、写作、程序、沟通、风控）不是六个筐，是办案流水线的六个环节——找、理、写、走、说、守；
2. **前三项是「出活」的**（会不会办），**后两项是「守门」的**（稳不稳），沟通横切全程；写作、风控是「枢纽能力」，最值得先补；
3. **三困局落到身上就是能力短板**——能力短板，就是三困局的源头；治症状不如治病灶；
4. **能力分「上限」和「下限」**——决定执业安全的是下限，而守住下限靠机制，不靠「更努力」；
5. **数字分身补的是「下限」**——每块短板都有对应的托底件，且都是前面四篇学过的零件，精准装到最短的板上。
