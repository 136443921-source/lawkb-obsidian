# Workbuddy做PPT进阶版之宝藏工具ppt-master

 

ppt-master是什么




ppt-master是github一个开源项目（MIT协议，免费），36.8k的start。它的核心能力是：**从任何文档生成原生可编辑的PPTX文件**。

 

什么叫"原生可编辑"？就是生成的PPT在PowerPoint里每一个文本框、每一张图、每一个图表都可以直接点击编辑，不是扁平化的图片打包。这点跟市面上很多AI生PPT的工具不一样——它们出的PPT常是一张图片套一个PPT壳子，你什么都改不了。

 

安装和配置

 

在WB对话框直接说：

 

```
装一下https://github.com/hugohe3/ppt-master 这个skill
```

 

装完重启就能用。如果需要AI自动配图，在项目目录下建一个```
.env
```

文件配好API Key就行或者是吧APi key丢给workbuddy，让他自行配置 。不配Key也能用，配图会自动从网上搜索。

完整的流水线

 

ppt-master的工作流大致分为以下几个环节，每一步的输出是下一步的输入。

 

环节干什么需要你做什么**源文件处理**读你的文件/文字/网页链接，转成它能处理的内容给素材**模板分析**如果你给了参考PPT，它会分析模板风格并全局套用可投喂参考PPT**策略规划**分析内容，出设计大纲，确定风格、配色、页面结构三阶段确认**图片获取**AI生图或联网搜图，自动配到对应页面配好Key就自动跑**页面生成**逐页生成可编辑的SVG，再转为PPTX原生形状不用管，等就行**输出**导出原生可编辑的PPTX文件拿文件直接用 

策略规划阶段：三阶段确认

 

素材给完之后，进入策略规划阶段。这是整个流程中最需要你参与的环节。它把内容分析完之后，会分三个阶段逐步确认PPT的方向——不是一步到位，而是先出初步方案，确认后再细化，再确认，再最终定稿。这样不容易跑偏。

 

我做《背影》课件的时候，它问的大概是：

 

**用什么演示模式？**

几个选项：简报型、教学型、故事型等。我做课件，选了教学型。

 

**给出建议页数。13页**

**用什么视觉风格？**

列了18种：瑞士极简、玻璃拟态、暗夜科技、复古海报、孟菲斯波普……我选了偏民国典雅的风格，跟《背影》的氛围搭。

 

**每页大概放什么？**

页码内容设计要点01**封面** — 背影水彩背景 + 楷书大字 + 朱砂印落款02**学习目标**五大目标，朱砂印数字标记03**作者简介**朱自清肖像 + 生平 + 代表作品04**写作背景**1917-1925 时间轴 + 时代背景05**段落结构**五段式瀑布流结构图06**车站送别**场景图 + 原文引文 + 文本细读07**望父买橘** ★经典场景大图 + 原文全文 + 分析卡片08**关键词句·动作**蹒跚·探身·攀·缩 四字详解 + 动作链09**关键词句·外貌**外貌对比 + "努力的样子" + "朱红的橘子"10**情感主线**父亲行为 vs 儿子反应 双栏对照11**中心思想**独特视角·以小见大·白描手法12**课堂小结**五项目标回顾 + 课后思考13**封底**"唉！我不知何时再能与他相见！"我确认没问题。

同时ppt-master模板能力：创造自己的模板包

 

ppt-master有一个独立的工作流专门做模板。

 

你手头有公司或者学校的PPT模板文件，直接丢给它。它会分析这套模板的配色、字体、版式、页眉页脚，然后生成一个可复用的模板包。以后不管做什么PPT，都可以让新内容套用这个模板包，出来的PPT风格统一。

 

还有一个```
beautify
```

模式：如果你有一份已经做好的PPT但排版不太好看，丢给它重新排版。它保留你的文字和数据不变，只重做布局和视觉。

 

我做《背影》课件时没用这个功能，直接选了内置风格。但如果你做公司汇报PPT，用自己的模板包比较省事。

 

配图

 

配图有两种方式，不需要自己去找：

 

**AI生成**：配好API Key，它根据每页内容自动生图。支持多种图片后端。我给《背影》生成了一组民国风格的插画——老火车站、月台、父亲爬月台的背影剪影，风格统一。

 

**联网搜图**：没配Key或者想要真实图片，它自动从网络开放图库搜索合适的图片，零配置即可用。配Pexels或Pixabay的Key可以获得更高清的结果。

 

演讲备注

 

指定一个角色，比如"语文老师"，它会根据每页内容自动生成对应的演讲备注。备注不是简单重复PPT上的文字，而是像真人讲课的口吻。

页面切换和内容动画

 

ppt-master会为PPT自动添加两种动画。在策略规划阶段可以选择：

 

**页面切换（过渡动画）：** 从一页翻到下一页时的效果，有推入、淡入淡出等。我给课件选了推入，中速。

 

**内容动画：** 同一页里的内容按顺序依次出现。比如一页上有标题、正文、配图三个元素，会先出标题，再出正文，最后出图。讲课的时候用这种逐项出现的方式，能控制学生的注意力，讲到哪亮到哪。

 

不想要动画的话，关掉就行。

 

导出的文件

 

所有环节走完之后，拿到的是一个```
.pptx
```

文件。这个文件在PowerPoint里打开，每个文本框、每张图、每个图表都可以直接点进去改，不是一张张扁平的大图。

 

适合什么场景

 

• 结构复杂的PPT（课件、汇报、方案书）

• 对视觉效果有要求的PPT

• 有固定模板需要套用的PPT

• 需要配图和演讲备注的PPT

 

简单的三五页内容，直接用WB自带能力更快。但要出一份像样的完整PPT，ppt-master的流水线比手动做省事得多。

 

几点提醒

 

• ppt-master是开源项目，免费，MIT协议

• 配图Key提前配好，不配也能用——联网搜图,官网推荐是GPT image 2 

• 第一次跑会问一系列问题，都是选择题

• 有参考PPT的话投喂给它，效果更统一

• 初稿出来后内容需要过一遍，有些表述改成自己的话
