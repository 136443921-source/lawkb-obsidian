## 一、项目基本情况概述
根据《贵州省遵义市习水县全域分布式光伏综合开发计划书（2026.05.31）》内容，本项目核心要素如下：

| 项目要素          |                                            具体内容                                                                                                                      |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **项目名称**      | 贵州省遵义市习水县户用分布式光伏+公共资源建筑屋顶光伏综合开发项目                                                                                                                                    |
| **投资主体**      | 青岛海尔光伏新能源有限公司                                                                                                                                                        |
| **项目建设地点**    | 贵州省遵义市习水县全域范围，涵盖县域内城乡居民自有住宅屋顶、机关事业单位、学校、医院、乡镇政务楼、公共场馆、园区配套建筑等公共资源建筑屋顶、工厂、商场、园区等建筑屋顶                                                                                  |
| **项目建设性质**    | 新建分布式光伏发电清洁能源项目，属于国家"双碳"战略、乡村振兴、千乡万村沐光行动重点扶持类项目                                                                                                                      |
| **项目建设模式**    | 分为三大板块：<br>1. 户用光伏板块：以农户自有屋顶为载体，采用"农户自愿参与、企业投资建设、统一运维"模式，主流采用全额上网模式；<br>2. 公共建筑屋顶光伏板块：整合县域公共闲置屋顶资源，统一规模化建设，采用全额上网模式；<br>3. 工商业光伏板块：厂区、园区、商超等闲置屋顶无需额外改造用地，零占地就能产生持续收益 |
| **项目建设周期及规模** | 整体项目分三期建设，总周期24个月：<br>1. 一期（1-6个月）：资源摸排、备案审批、试点工程建设；<br>2. 二期（7-18个月）：全域规模化推广建设；<br>3. 三期（19-24个月）：竣工验收、并网发电、运维体系搭建、项目复盘优化。<br>户用光伏建设规模约为200兆瓦，公共建筑屋顶光伏建设规模约为100兆瓦   |
| **项目总体目标**    | 立足习水县气候资源、城乡建筑禀赋，规模化开发屋顶光伏清洁能源，打造遵义市县域分布式光伏示范项目。实现县域清洁能源替代、农户增收、公共机构节能降本、电网负荷优化多重效益，助力习水县完成能耗双控目标，赋能乡村振兴与绿色低碳县域建设                                                    |
| **项目总投资额**    | 约9亿元人民币                                                                                                                                                              |
| **厚德基金会角色**   | 基层摸排、困难农户筛选、落地协调与收益监管                                                                                                                                                |
| **项目合作模式**    | 海尔光伏输出全链条光伏技术、设备建设与数字化运维能力；厚德基金会负责基层摸排、困难农户筛选、落地协调与收益监管；农户零出资，出租屋顶获取稳定租金；村集体依托光伏发电收益壮大集体经济                                                                           |
