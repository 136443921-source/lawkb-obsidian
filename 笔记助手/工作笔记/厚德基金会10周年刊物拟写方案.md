# 厚德十年 · 公益如初

## 贵州省厚德公益基金会 10周年珍藏刊 拟写方案（v1.1）

> 时间跨度：2015 — 2025 ｜ 地点：中国·贵州·习水 ｜ 理念：尽我所能 人人公益  
> 方案拟写：小强律师（实习律师）｜ 编制日期：2025年8月5日  
> 本方案基于《5周年珍藏刊（2015—2019）》全文研读 + 6家标杆基金会周年出版物对标分析编制

---

## 一、方案定位与目标（Positioning & Goals）

### 核心定位

**「纪念册 + 成绩单 + 感谢信 + 招募令」四合一**

不是简单的年报堆砌，而是一本**有温度、有数据、有故事、有未来**的机构品牌旗舰出版物。既是对过去十年的庄重致敬，也是面向下一个十年的战略宣言。

| 关键指标 | 说明               |
| ---- | ---------------- |
| 10年  | 完整发展周期回顾         |
| 3类读者 | 捐赠人 / 合作方 / 公众   |
| 双载体  | 印刷画册 + 电子 H5/PDF |

### 目标读者与对应诉求

| 读者群体       | 核心诉求         | 内容侧重                  |
| ---------- | ------------ | --------------------- |
| 发起人 / 理事单位 | 信任确认、影响力展示   | 治理成果、财务透明、战略方向        |
| 企业合作伙伴     | CSR价值验证、品牌联动 | 合作案例、社会影响数据、联合署名展示    |
| 政府主管部门     | 合规性、区域贡献度    | 党建参与、脱贫攻坚衔接乡村振兴、本地化成效 |
| 志愿者 / 义工   | 归属感、被认可      | 人物故事、参与记录、成长轨迹        |
| 受益人及公众     | 情感共鸣、公信力建立   | 真实故事、项目效果、透明数据        |

## 二、5周年珍藏刊深度复盘（5th Anniversary Review）

### 基础信息

- **名称**：《贵州省厚德公益基金会 2015—2019 年报（珍藏刊）》
- **规格**：A4，109页，约11万字（含图表）
- **时间跨度**：2015.03（注册）— 2019.12（共5个完整年度）
- **设计语言**：红白主色调（中国红+雪色白），心形/眼睛/耳朵三重寓意 Logo 贯穿全册

### 栏目结构（共14个一级栏目）

1. **走进厚德（4页）**：简介 / 文化体系（定位·初衷·愿景·宗旨·目标·使命）/ 团队名单 / 组织架构图
2. **理事长寄语（2页）**：李彬理事长亲笔致辞，回顾五年历程，致谢各方
3. **卷首语（2页）**：秘书长陈友强执笔，以"功崇惟志 以终为始"为题
4. **数字说厚德（10页）**：五年累计收支饼图 / 分年度收支柱状图 / 四大领域累计支出 / 受益人数 / 义工人次
5. **公益足迹（10页）**：习水/赤水/仁怀三县地图标注 / 41乡镇203村居115学校覆盖 / 善款乡镇分布柱状图
6. **大事记（2页）**：2015—2019逐年条目式记录（注册/项目启动/荣誉获得/合作签约等）
7. **项目报告（核心板块，47页，占43%）**：四大领域——弱势群体关怀 / 青少年成长与发展 / 青年公益支持 / 救灾减灾。每个项目含：简介 → 受益群体 → 资助方式 → 开展时间 → 数字说项目(年度数据+累计) → 区域足迹图 → 现场照片 → 受助人感言
8. **社会公众参与（4页）**：义工分类统计表（党员/商会/社会/学生）2015—2019趋势 / 志愿者故事2篇
9. **公益组织合作与交流（10页）**：9家合作组织简介（支教协会/雁行中国/爱心公益会/义工联合会等）+ 参访交流照片
10. **公益实践及社会影响（6页）**：FTI透明指数满分截图 / 自媒体平台数据（公众号/订阅号/微博/官网粉丝&阅读量）
11. **公众募款（6页）**：99公益日 / 腾讯乐捐 / 企业配捐 / 公益打榜 / 爱心接龙 / 每月一捐 / 子项目列表
12. **审计报告 & 财务报表（7页）**：专项信息审核报告全文 + 资产负债表/业务活动表/现金流量表
13. **公益合作伙伴（2页）**：企业/机构 Logo 墙
14. **封底（1页）**：编委会名单 / 联系方式 / 二维码

### 优势评估

**做得好的 ✅**

- **结构完整**：从理念到项目到财务到审计，形成闭环
- **数据扎实**：每个项目都有分年度+累计数字，乡镇级资金分布细化到村
- **视觉统一**：红色主调+图标系统+页眉 slogan 一致性强
- **合规过硬**：FTI满分+AAAA级+审计报告全文披露
- **有人情味**：受助学生发言、志愿者手记、支教诗歌穿插其中
- **地图叙事**：公益足迹图直观展示地理覆盖面

**可升级空间 🔺**

- **缺少"十年视角"**：无跨周期趋势分析（如项目迭代路径、筹款结构演变）
- **故事偏浅**：人物故事多为单次感言，缺乏 longitudinal 追踪（同一受益人5年变化）
- **影响测量不足**：以"投入指标"（发了多少书包/多少钱）为主，缺乏"产出/outcome 指标"
- **设计偏传统**：纯印刷画册思维，无互动元素/二维码跳转/视频入口
- **行业对标缺失**：未将自己放在贵州乃至全国基金会坐标系中定位
- **未来导向弱**：几乎全是回顾，对下个五年的战略展望仅寄语中一笔带过

## 三、行业对标分析（Benchmarking）

### 参考样本选取逻辑

选取了 **4类6家** 机构的周年出版物作为对标：资助型 / 运作型 / 区域性 / 全国性 / 教育公益 / 综合救助。

| 机构            | 类型           | 周年出版物                        | 可借鉴亮点                                                                 |
| ------------- | ------------ | ---------------------------- | --------------------------------------------------------------------- |
| **南都公益基金会**   | 资助型/全国       | 10周年年报（2007—2017）            | "支持民间公益"使命贯穿始终；银杏伙伴→景行计划→好公益平台的战略演进线清晰；五周年设专门"历程"时间轴                  |
| **上海真爱梦想**    | 运作型/教育/全国    | 十年公益报告（2008—2018）            | 以"干杯梦想"诗歌体卷首营造仪式感；PPPS跨界赋能方法论提炼；SGS国际认证+拉姆·查兰管理奖作为公信力背书；梦想中心数量增长曲线可视化 |
| **壹基金**       | 运作型/救灾+儿童/全国 | 年度影响力报告                      | 每年度一个主题句（如"每个人都是公益英雄"）；项目效果用"前后对比"呈现；大量使用信息图(infographic)             |
| **敦和基金会**     | 资助型/文化+社区    | 五周年/十周年特刊                    | 文化艺术品位高，设计获设计奖项；"善经济"概念先行；项目与国学/艺术跨界融合呈现                              |
| **中国乡村发展基金会** | 运作型/扶贫/全国    | 年度报告+影响力报告双轨制                | 双轨制——年报走合规路线，影响力报告走传播路线；小额信贷等项目的"社会投资回报(SROI)"测算                      |
| **新加坡慈善局模板**  | 监管指引         | Annual Report Template Guide | 强制要求：活动回顾+受益人证言+志愿者证言+重大事件里程碑；推荐"管理层讨论与分析(MD\&A)"章节                   |

### 对标提炼：10周年刊应具备的6大要素

1. **时间纵深** —— 十年不是五个两年的叠加，要有演进脉络
2. **战略叙事** —— 从"做了什么"升维到"为什么做→怎么做→走向哪里"
3. **影响证明** —— 从输出指标进阶到 outcome 指标
4. **人物弧光** —— 追踪同一批人10年的变化（受益人/志愿者/员工）
5. **行业坐标** —— 把自己放在贵州/西南/全国基金会的什么位置
6. **未来契约** —— 不只是回顾，要发出下一个十年的邀请

## 四、10周年刊栏目方案（Proposed Structure）

### 整体框架：六大篇章 + 附录

- **建议总篇幅**：约 150—172 页（含封面、篇章隔页与附录页码；比5周年的109页增加约 38%—58%，体现十年厚度）
- **建议开本**：A4变体或方形 210×210mm（区别于5周年的标准A4，增强收藏感）

### 📖 第一篇 · 序章 —— "十年回望"（8—10页）

| 栏目     | 内容要点                                            | 页数  | 创新点                                   |
| ------ | ----------------------------------------------- | --- | ------------------------------------- |
| 封面     | "厚德十年 公益如初"主题视觉；2015—2025年份标识；可考虑烫金/凹凸工艺        | 1   | 不同于5周年的红白书法风，建议引入**时间轴意象**（如一条红线穿引十年） |
| 扉页     | 十年版 Logo 演绎（原Logo+十年元素叠加）；"2015·种子 ｜ 2025·森林"隐喻 | 1   | Logo动态演化展示                            |
| 理事长寄语  | 李彬理事长致辞：十年节点上的反思与展望——不只致谢，更要有**行业观察和战略判断**      | 2   | 可配十年前后的对比照片（同地点/同人）                   |
| 十年·一句话 | 每年选一句"年度关键词"+一张年度代表照片，组成十年时间走廊                  | 2—3 | 类似《南方周末》新年贺词风格，每年一句定义当年的精神气质          |
| 目录     | 六大篇章导航 + 视觉化页码                                  | 1   | 每个篇章配一幅微型插图                           |
| 卷首语    | 秘书长或邀请外部公益领袖（如徐永光/王振耀等）撰写序言                     | 1—2 | 外部视角增加权威性和客观性                         |

### 🏛️ 第二篇 · 认识厚德 —— "我们是谁"（12—14页）

| 栏目   | 内容要点                                      | 页数 | vs 5周年升级点                                 |
| ---- | ----------------------------------------- | -- | ----------------------------------------- |
| 十年履历 | 完整组织介绍 + 文化体系更新版（如有修订）                    | 2  | 新增"十年文化演进"说明哪些理念在深化                       |
| 团队图谱 | 理事会/监事会/秘书处 + 四大专业委员会 + 历届成员致敬墙           | 2  | 5周年只有当届名单；10周年应设**历届成员墙**（致敬已离任者）         |
| 治理之路 | 从"六化管理"(制度/流程/标准/数字化/精细化/规范)到当前治理体系的演进时间轴 | 2  | 新增：**治理能力建设的关键节点图**（何时引入FTI/何时获4A/何时通过审计） |
| 荣誉殿堂 | 十年所获荣誉/认证/评级的时间线展示（AAAA/FTI满分/先进集体等）      | 2  | 5周年散落在各处；10周年集中展示更有冲击力                    |
| 十年影像 | 精选20—30张十年经典瞬间（成立大会/第一次发放/99公益日现场/抗疫行动等）  | 4  | 5周年图片分散在各项目中；10周年集中做**影像长廊**              |

### 📊 第三篇 · 数字厚德 —— "十年成绩单"（20—24页）

| 栏目          | 内容要点                                               | 页数 | vs 5周年升级点                                 |
| ----------- | -------------------------------------------------- | -- | ----------------------------------------- |
| 十年关键数据仪表盘   | 累计收入/支出/受益人数/覆盖地域/义工人次/合作组织数——首页即见全貌               | 2  | 5周年数据在第9页才出现；10周年建议**前置到第2篇之后立即呈现**       |
| 收入结构十年演变    | 2015—2024（2025预估）收入构成变迁图：发起人捐赠↓ vs 互联网筹款↑ vs 投资收益↑ | 2  | 5周年只有静态饼图；10周年做**趋势面积图**展现筹款多元化进程         |
| 支出领域十年分布    | 四大领域支出的十年堆积面积图 + 占比变迁                              | 2  | 展现战略重心迁移（如青少年领域占比是否持续上升）                  |
| 公益足迹升级版     | 地图从3县扩展到实际覆盖的所有区县；增加**热力图**密度表达                    | 3  | 5周年是静态标注；10周年建议用GIS热力图                    |

| 财务精要        | 十年主要财务指标趋势图（资产负债/公益支出比例/管理费率）+ 最近两年审计报告摘要          | 4  | 5周年放全文审计报告（7页）；10周年建议**摘要+扫码看全文**，节省空间给故事 |
| FTI & 透明度专题 | FTI评分历年曲线 + 透明度建设里程碑                               | 2  | 5周年只放了1张满分截图；10周年做成**透明度建设故事线**           |

### ❤️ 第四篇 · 公益践行 —— "十年项目志"（48—56页，核心板块）

这是最重的部分，但**不能是5周年的简单加长版**。建议按以下逻辑重构：

#### 4.1 项目矩阵总览（2—3页）

- 一张**项目生命周期矩阵图**：横轴=四大领域，纵轴=时间（2015—2025），每个项目用色块表示存续期
- 一目了然看到：哪些项目持续了10年？哪些是新生的？哪些已结束/转型？

#### 4.2 核心项目深度报告（36—42页，每个重点项目4—6页）

| 项目                       | 建议页数 | 十年叙事角度                                           |
| ------------------------ | ---- | ------------------------------------------------ |
| **我的大学·厚德圆梦**            | 6页   | 488名受助学生中追踪10位代表（从入学到就业/深造的完整轨迹）；"圆梦校友网络"是否成型    |
| **122安全书包计划**            | 5页   | 9035个书包背后的交通安全意识调研（是否有事故率下降数据？）；产品迭代史（从第一代到当前版本） |
| **365温暖包/暖冬行动**          | 5页   | 从"送物资"到"送陪伴"的模式升级；受益儿童的前后对比照（多年跟踪）               |
| **6+1困境儿童助养 → 为梦想插上翅膀**  | 5页   | 项目更名背后的战略思考；月捐模式的发展曲线                            |
| **李彬励志奖学金**              | 3页   | 48名获奖者的去向追踪（多少人在回馈家乡？）                           |
| **青年公益支持（支教/宣讲/产业帮扶）**   | 5页   | 支教协会10年合作回顾——"反哺故土"的人才循环是否形成？                    |
| **救灾减灾（8.11洪灾/新冠疫情/其他）** | 4页   | 从灾害响应到常态化备灾的能力建设路径                               |
| **益童乐园 / 社区发展**          | 3—4页 | 易地扶贫搬迁后续服务的新探索（2020年后新方向）                        |
| **已结束项目专题**              | 2页   | 危房改造/爱心桥等项目虽已结束，但其历史意义值得专页纪念                     |

#### 4.3 受益人故事与伙伴故事（6—8页）

这是10周年刊区别于年报的最大增量价值所在。本篇（第四章）聚焦**我们服务的人**与**并肩的人**：

- **受益人追踪**（红）：选取3—5名最早一批受助人，讲述他们10年的变化（如：2015年的贫困大学生→2025年的医生/教师/公务员）。这是"影响证明"的核心素材（呼应第三章对标要素③）。
- **员工/伙伴**（绿）：秘书处员工、合作组织负责人的十年坚守故事；"反哺故土"的人才循环如何在秘书处与合作方之间发生。

> 💡 义工/志愿者的十年故事已独立成章，详见**第五篇·致敬捐赠人和义工（依靠谁）**，本篇不再重复，避免跨篇割裂。

#### 4.4 公众参与与社会影响（4—6页）

- 十年义工增长趋势图（2015年400人次 → 202X年?）【义工人物故事见第五篇，本篇只放数据趋势】
- 互联网筹款进化史（从零到月捐800人的路径）
- 自媒体十年数据（粉丝/阅读量/互动量的增长曲线）
- 合作组织生态图（从9家扩展到?家的网络图谱）

### 🤝 

> 💡 捐赠人故事应取得书面授权（见第七章合规清单第4项）；涉及重大捐赠人（单笔>当年总收入5%）披露须经理事会审批。

#### 5.3 义工故事（8—10页，建议4—6位代表）

每人1.5—2页，统一结构：**他们是谁 → 第一次参加 → 十年里最难忘的一次 → 公益如何改变了他们自己**。建议组合：

| 类型        | 代表             | 故事角度                        |
| --------- | -------------- | --------------------------- |
| 第一批"老义工"  | 2015年即参与的核心义工  | 从活动执行者到"厚德精神"承载者；十年身份变迁     |
| 学生义工      | 大学生/中学生志愿者     | "公益第一课"；是否有人从受助者变为助人者（反哺闭环） |
| 党员 / 商会义工 | 党组织、商会成员       | 党建引领下的常态化参与                 |
| 专业义工      | 医生/教师/设计师/摄影师等 | 用专业能力做公益的独特价值               |
| 返乡青年义工    | 在外习水/贵州籍青年     | "反哺故土"的人才循环在义工群体的体现         |
| 家庭 / 亲子义工 | 一家三代或亲子组合      | 公益作为一种家庭教育与代际传承             |

> 💡 未成年人义工照片须监护人同意并做必要保护处理（见第七章合规清单第2项）。

#### 5.4 致敬墙（2—3页）

- **捐赠人名录**：十年累计捐赠人（按金额分级，充分尊重匿名意愿；匿名者以"爱心人士"统一标注）
- **义工名录 / 服务时长榜**：列出十年累计服务时长居前者，或按年份/类型呈现的义工矩阵
- **"十年功勋"特别致敬**：为服务满十年的核心义工、连续捐赠十年的个人设立专属致敬位
- 设计上采用"名录 + 头像网格"形式，配合红白金三色、网格化排版（呼应第五章设计语言升级）

#### 5.5 数据视角：捐赠人与义工（1—2页）

- 十年累计捐赠人数量、月捐人增长曲线、复捐率（如有数据）
- 义工累计服务总时长、年度人次趋势（与第四章4.4"公众参与"数据呼应，此处做"人"的汇总）
- 用一张"十年同行者"关系图谱收束本篇：捐赠人—义工—受益人—员工的连接网络

#### 与相邻篇章的分工

- 本篇讲**故事与致敬**；**第四章4.4** 讲义工/筹款的**数据趋势**；**第六章展望篇** 讲机构与战略伙伴的致谢——三者互补不重复。
- 重要人物若同时是捐赠人又是义工，归口本篇"双重身份"小节统一呈现，避免跨篇割裂。

## 五、设计语言建议（Design Direction）

### 5周年 vs 10周年设计语言对比

| 维度 | 5周年设计语言   | 10周年设计语言（建议）              |

### 基于《慈善法》及内部合规手册的强制检查项

| #  | 检查项                               | 法规依据                                   | 责任方     |
| -- | --------------------------------- | -------------------------------------- | ------- |

## 九、风险提示与应对（Risks & Mitigation）

### ⚠️ 主要风险

- **内容风险**：受益人故事可能因人员流动无法追溯；早期档案不完整
- **时间风险**：生产周期约4个月，需尽早启动
- **预算风险**：设计/印刷费用波动较大
- **合规风险**：肖像权/隐私权授权遗漏
- **舆情风险**：数据表述不当引发误解

### ✅ 应对策略

- 提前2个月开始受益人/义工摸底，建立"可联系名单"
- 设立**双周 milestone** 检查机制
- 设计费采用**固定总价合同**，印刷费多方比价
- 建立**授权书台账**，一人一档
- 所有关键数据须经财务+法务**双重签核**
