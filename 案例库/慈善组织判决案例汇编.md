## 案例一：(2023)宁0104民初1901号 — 永康润达公司诉宁夏燕宝慈善基金会合同纠纷案

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **案号** | （2023）宁0104民初1901号 |
| **审理法院** | 宁夏回族自治区银川市兴庆区人民法院 |
| **判决日期** | 2023年4月6日 |
| **审判员** | 任涛 |
| **原告** | 永康市润达休闲用品有限公司 |
| **被告一** | 宁夏燕宝慈善基金会 |
| **被告二** | 宁夏英泰利机电设备有限公司 |
| **案由** | 合同纠纷 |

### 二、案件事实

**合同签订过程：**

1. **居间协议（2022年10月10日）**：原告与英泰利公司签订《居间协议》，约定英泰利公司负责促成原告与燕宝基金会的折叠床采购合同，居间费6万元，英泰利公司负责货款回收。

2. **折叠床买卖合同（2022年10月11日）**：原告与燕宝基金会签订合同，出售10000张折叠床，含税单价95元/张，总价95万元。约定"双方法定代表人或授权委托代理人签字且加盖单位合同专用章或公章"生效。**但实际仅加盖印章，无签字**。

3. **追加订单（2022年10月21日）**：英泰利公司要求增加购买2000张，单价75元/张（不含运费），支付定金9万元，原告垫付运费16,500元。

4. **燕宝基金会与英泰利公司另签合同（2022年10月24日）**：二者另行签订10000张折叠床买卖合同，英泰利公司委托代理人董健签字。

**履行情况：**

| 事项 | 详情 |
|------|------|
| 原告交货 | 2022年10月12日-31日，发货12,003张折叠床 |
| 燕宝基金会付款 | 2022年11月9日，向**英泰利公司**支付95万元 |
| 英泰利公司向原告付款 | 仅于2022年11月15日付30万元 |
| 未付余额 | 72.65万元（95万+16.65万-30万-9万） |

### 三、争议焦点

1. 燕宝基金会与原告之间的买卖合同是否生效（存在签字瑕疵）？
2. 燕宝基金会是否应向原告支付货款？
3. 英泰利公司应承担何种责任？

### 四、法院裁判

**法院认定：**

1. **合同有效**：虽然《折叠床买卖合同》仅有印章无法定代表人或委托代理人签字，存在形式上的瑕疵，但不影响合同效力。

2. **燕宝基金会不承担付款责任**：实际交易链条为"原告→英泰利公司→燕宝基金会"，基金会已向其合同相对方英泰利公司支付95万元，完成了付款义务。

3. **英泰利公司承担付款责任**：依据《居间协议》，英泰利公司负责货款回收，约定"若买方未付款，由英泰利公司承担支付"。依据《民法典》第927条（委托合同）的规定，应由英泰利公司向原告支付货款。

### 五、判决结果

| 判项 | 内容 |
|------|------|
| **第一项** | 被告**宁夏英泰利机电设备有限公司**支付货款**72.65万元**，并按每日**5‰**支付自2022年11月10日起的违约金 |
| **第二项** | 驳回原告对燕宝基金会的诉讼请求及诉讼代理费的请求 |
| **诉讼费** | 11,936元，由英泰利公司负担 |

### 六、对慈善组织的启示

1. **签约规范至关重要**：基金会在签订合同时应严格遵循生效条件，避免形式瑕疵引发争议
2. **注意交易结构风险**：多层交易结构下应注意合同相对性原则
3. **合同管理需完善**：本案中基金会同时与两个主体就同一批货物签订合同，暴露了合同管理漏洞

## 案例二：吴幽与中国矿业大学教育发展基金会赠与合同纠纷案（2022年）

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **审理法院** | 江苏省徐州市铜山区人民法院 |
| **立案时间** | 2022年 |
| **执行立案** | 2023年1月3日 |
| **原告** | 中国矿业大学教育发展基金会 |
| **被告** | 吴幽（中国矿业大学2008级校友、镜湖资本创始合伙人） |
| **案由** | 赠与合同纠纷 |
| **执行标的** | 1104.89万元 |

### 二、案件背景

- **2019年**：正值中国矿业大学建校110周年，吴幽公开承诺向母校捐赠**1100万元**，用于设立高端人才计划基金、贫困生海外实习基金、名人名师讲座基金和创新创业基金
- 学校副校长代表学校与吴幽签署了捐赠协议，学校接受捐赠并颁发证书
- **后因"经济大环境及基金遇到困难"**，吴幽未履行捐赠承诺

### 三、争议焦点

**核心争议**：公开承诺的公益捐赠是否可以因经济困难而拒绝履行？

**法律依据**：
- 《慈善法》第41条：捐赠人通过广播、电视、报刊、互联网等媒体公开承诺捐赠的，应当按照捐赠协议履行捐赠义务
- 《民法典》第658条：经过公证的赠与合同或者依法不得撤销的具有救灾、扶贫、助残等公益、道德义务性质的赠与合同，赠与人不得任意撤销
- 《民法典》第666条：赠与人经济状况显著恶化，严重影响其生产经营或者家庭生活的，可以不再履行赠与义务（穷困抗辩）

### 四、案件处理结果

该案以**调解**方式结案，调解协议约定：
1. 吴幽分期付款：2022年10月20日前付200万元；余款900万元于2022年12月31日前付清
2. 若任一期未按时足额履行，基金会可就全部未付款申请执行
3. 案件受理费减半收取43,900元，保全费5,000元，均由吴幽负担

**执行阶段（2023年）**：
- 吴幽未按调解协议履行
- 被列为**失信被执行人**（俗称"老赖"）
- 受到限制消费令

### 五、案例启示

1. **公益捐赠不可随意反悔**：公开承诺的公益捐赠具有法律强制力
2. **穷困抗辩需严格证明**：主张经济困难需证明"经济状况显著恶化，严重影响生产经营或家庭生活"
3. 此案为**教育基金会维权典型案例**，引发社会广泛关注

## 案例三：(2002)云高民三终字第26号 — 美国妈妈联谊会诉丽江妈妈联谊会捐赠纠纷案

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **案号** | （2002）云高民三终字第26号 |
| **审理法院** | 云南省高级人民法院 |
| **上诉人/捐赠人** | 美国妈妈联谊会 |
| **被上诉人/受赠人** | 丽江妈妈联谊会 |
| **案由** | 捐赠纠纷 |

### 二、案件事实

- 丽江妈妈联谊会取得美国妈妈联谊会的捐赠款项后，**未按照捐赠人指定的用途使用捐赠财产**，违背了捐赠人的意愿
- 美国妈妈联谊会请求撤销捐赠并要求返还

### 三、争议焦点

**核心争议**：公益捐赠的捐赠人在受赠人未按照约定使用捐赠财产的情况下，是否享有法定撤销权？

### 四、裁判要旨

**云南省高院认定**：《民法典》第663条规定的法定撤销权**并未将具有公益性质的赠与合同排除在外**。若受赠人不履行赠与合同约定的义务（包括未按指定用途使用捐赠财产），赠与人有权行使法定撤销权，要求返还相应捐赠财产。

**法律适用**：
- 《民法典》第663条：受赠人有下列情形之一的，赠与人可以撤销赠与：（一）严重侵害赠与人或者赠与人近亲属的合法权益；（二）对赠与人有扶养义务而不履行；（三）不履行赠与合同约定的义务
- 撤销权自知道或应当知道撤销事由之日起一年内行使

### 五、判决结果

判决丽江妈妈联谊会向美国妈妈联谊会**返还未按指定用途使用的两笔捐赠款项**。

### 六、经典意义

1. 这是中国**较早涉及慈善捐赠纠纷的典型案例**（2002年）
2. 明确了**公益捐赠合同同样适用法定撤销权**
3. 强调受赠人对捐赠财产负有**依约使用义务**

## 案例四：指导案例174号 — (2015)甘民初字第45号 中国绿发会诉雅砻江流域水电开发有限公司环境公益诉讼案

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **案号** | （2015）甘民初字第45号 |
| **审理法院** | 四川省甘孜藏族自治州中级人民法院 |
| **原告** | 中国生物多样性保护与绿色发展基金会（绿发会） |
| **被告** | 雅砻江流域水电开发有限公司 |
| **案由** | 环境民事公益诉讼 |
| **地位** | 最高人民法院**指导案例第174号** |

### 二、案件事实

- 五小叶槭被评定为"极危"/"极度濒危"物种，案涉种群位于四川省雅江县，是当今世界残存**最大且唯一还有自然繁衍能力的种群**
- 雅砻江公司负责建设的牙根梯级水电站项目处于**预可研阶段**（尚未开工建设）
- 绿发会认为水电站及配套公路建设将直接威胁五小叶槭的生存，提起**预防性公益诉讼**

### 三、裁判规则（最高人民法院提炼）

> 人民法院审理环境民事公益诉讼案件，应当贯彻**绿色发展理念和风险预防原则**，根据现有证据和科学技术认为项目建成后可能对案涉地濒危野生植物生存环境造成破坏，存在影响其生存的**潜在风险**，从而损害生态环境公共利益的，可以判决被告采取**预防性措施**，将对濒危野生植物生存的影响纳入建设项目的环境影响评价。

### 四、核心裁判要旨

1. **风险预防原则**：不应以缺乏充分的科学定论为由，推迟采取避免或减轻威胁的措施
2. **预防优于救济**：生态破坏往往具有不可逆性，应防患于未然
3. **生态优先原则**：应将生态优先贯穿到水电规划开发全过程

### 五、判决结果

| 判项 | 内容 |
|------|------|
| **第一项** | 被告应将五小叶槭的生存作为环评重要内容，环评报告**经审批通过后才能继续开展下一步工作** |
| **第二项** | 原告为诉讼产生的必要费用4万元、合理律师费1万元，从其他环境公益诉讼资金中支付 |
| **第三项** | 驳回原告要求"暂停一切建设工程"的请求（因项目尚未开工） |

一审判决后当事人未上诉，判决已生效。

### 六、对慈善组织的意义

1. 明确了**社会组织（基金会）提起环境公益诉讼**的主体资格
2. 确立了**预防性公益诉讼**的裁判规则
3. 为慈善组织参与**生态环境保护**提供了法律路径参考

## 案例五：(2021)粤01民初576号 — 中国绿发会诉肖习文生态破坏民事公益诉讼案

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **案号** | （2021）粤01民初576号 |
| **审理法院** | 广东省广州市中级人民法院 |
| **裁判日期** | 2021年9月13日 |
| **原告** | 中国生物多样性保护与绿色发展基金会 |
| **被告** | 肖习文（在押服刑人员） |
| **案由** | 生态破坏民事公益诉讼 |

### 二、案件事实

- 肖习文非法收购、出售国家保护野生动物穿山甲**共65只**（其中确定死亡59只）
- 已被刑事判决认定犯非法收购、出售珍贵、濒危野生动物罪
- 绿发会作为社会组织提起民事公益诉讼，要求赔偿生态环境修复费用

### 三、法院认定

**关于原告主体资格**：绿发会系在民政部登记的基金会法人，专门从事环境保护公益活动**连续五年以上且无违法记录**，具备提起生态破坏民事公益诉讼的主体资格。

**关于赔偿数额的认定**：

| 计算要素 | 详情 |
|----------|------|
| 基准价值 | 8000元/只（依据《野生动物及其制品价值评估方法》） |
| 保护倍数 | 五倍（国家二级保护野生动物） |
| 单只价值 | 8000元×5＝4万元/只 |
| 确定死亡数量 | 59只 |
| **生态环境修复费用** | **59只×4万元＝236万元** |

### 四、判决结果

1. 被告赔偿生态环境修复费用**236万元**（上缴国库，用于修复被损害的生态环境）
2. 被告赔偿律师费1万元及差旅费1,500元
3. 被告在**国家级媒体**上发表赔礼道歉声明
4. 案件受理费25,772元由被告负担

本案系缺席判决。

### 五、典型意义

1. 确认了基金会提起环境公益诉讼的**资格条件**（连续五年+无违法记录）
2. 明确了生态环境修复费用的**计算方法**（基准价值×保护级别倍数）
3. 体现了**"刑民衔接"**的公益诉讼模式

## 案例六：延长县慈善协会诉刘某某等民间借贷纠纷案

### 一、基本信息

| 项目 | 内容 |
|------|------|
| **审理法院** | 陕西省延长县人民法院（待核实） |
| **原告** | 延长县慈善协会 |
| **被告** | 刘某某（借款人配偶）、呼某某某、呼某某泽（借款人子女）、李某某 |
| **案由** | 民间借贷纠纷 |

### 二、案件背景

- 延长县慈善协会曾向呼某某鹏提供借款
- 呼某某鹏将利息清至2019年3月8日
- 2020年呼某某鹏**因公殉职**
- 借款到期后，慈善协会起诉继承人，请求在继承遗产范围内偿还借款

### 三、对慈善组织的启示

**该案揭示了一个重要问题**：慈善组织将资金用于对外借款（而非慈善活动支出），是否合规？

**合规风险分析**：
- 依据《慈善法》及《[[关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定]]|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定|关于慈善组织开展慈善活动年度支出、管理费用和募捐成本的规定》，慈善组织的财产应当全部用于慈善目的
- 对外借款可能面临**慈善支出比例不合规**的风险
- 借款回收困难还会带来**慈善财产损失风险**
