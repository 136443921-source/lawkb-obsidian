### R001：高压电经营者承担无过错责任，不因发包关系免除

| 项目 | 内容 |
|------|------|
| **规则编号** | R001 |
| **规则内容** | 高压电经营者承担无过错责任，不因发包关系免除 |
| **适用条件** | 高压电致人损害 + 经营者与受害人无直接合同关系 |
| **法律依据** | 《民法典》第1239条 |
| **案例支持** | （2023）黔03民终5221号 |
| **与本案关联** | 高（核心裁判规则） |
| **规则类型** | 法律适用规则 |
| **适用案件类型** | 高压电致人损害案件 |
| **备注** | 特别法（《民法典》第1239条）优于一般法 |

**规则详述**：

根据《民法典》第1239条："从事高空、高压、地下挖掘活动或者使用高速轨道运输工具造成他人损害的，经营者应当承担侵权责任；但是，能够证明损害是因受害人故意或者不可抗力造成的，不承担责任。"

本案中，遵义供电局是高压电经营者，陈长卫系被高压电击伤。供电局主张"三牌更换"属于原分包范围，其已发包给光明公司，应免责。但二审法院认为：供电局作为高压电经营者，不能证明损害是受害人故意造成，应承担无过错责任，不因发包关系免除。

**适用要点**：
1. 高压电经营者承担无过错责任
2. 经营者不能证明损害是受害人故意造成 → 承担责任
3. 发包关系不能免除经营者的无过错责任

### R002："重新立项"视为新的合同关系，不属于原分包范围

| 项目 | 内容 |
|------|------|
| **规则编号** | R002 |
| **规则内容** | "重新立项"视为新的合同关系，不属于原分包范围 |
| **适用条件** | 原合同未履行完毕 + 发包方重新立项 + 原承包方无力完成 |
| **法律依据** | 《民法典》合同编相关条款 |
| **案例支持** | （2023）黔03民终5221号 |
| **与本案关联** | 高（关键事实认定） |
| **规则类型** | 事实认定规则 |
| **适用案件类型** | 建设工程合同纠纷、劳务受害纠纷 |
| **备注** | 关键证据：原承包方"无力完成"的书面说明 |

**规则详述**：

本案中，一审认定"三牌更换"属于原分包范围，供电局无责。但二审法院根据以下证据，认定"三牌更换"不属于原分包范围：
1. 光明公司2021年11月1日重新立项任务书（项目施工费用2.55万元）
2. 润通公司2021年11月1日《35kV线路工程后续工作报告》（载明"无力完成剩余三牌挂设"）

二审法院认为：若"三牌更换"属于原分包范围，润通公司无力完成即构成违约，而非"后续工作"。重新立项表明"三牌更换"是一个新的合同关系，不属于原分包范围。

**适用要点**：
1. 原承包方"无力完成"的书面说明 → 证明不属于原合同范围
2. 发包方重新立项 → 证明是一个新的合同关系
3. 关键证据：重新立项任务书、原承包方"无力完成"的书面说明

**规则详述**：

1. 光明公司违法分包 → 过错
2. 润通公司违法转包 → 过错
