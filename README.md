# 法律职业知识库

> 基于 Obsidian 的双链笔记系统，专为法律从业者设计

## 目录结构

- 📁 **案件** - 个人承办案件全流程记录
- 📁 **法规** - 法律法规、司法解释摘要与索引
- 📁 **文书模板** - 起诉状、答辩状、代理词等模板库
- 📁 **庭审记录** - 开庭笔录、质证要点、判决摘要
- 📁 **判例索引** - 最高人民法院指导案例、类案检索
- 📁 **客户档案** - 客户基本信息、案件历史、沟通记录
- 📁 **学习笔记** - 资格备考、专题研究、技能提升

## 核心使用方法

### 1. 案件管理
- 每个案件创建一个独立笔记（如 `案件/2026-张三-借款合同纠纷.md`）
- 使用 YAML Frontmatter 记录元数据：
  ```yaml
  ---
  案由: 借款合同纠纷
  当事人: 张三（原告） vs 李四（被告）
  标的额: 100,000元
  立案日期: 2026-04-15
  管辖法院: 贵阳市中级人民法院
  状态: 审理中
  律师: 老强
  ---
  ```

### 2. 双链笔记
- 内部链接：`[[法规/民法典-合同编]]`
- 外部链接：`[最高人民法院指导案例24号](http://...)`
- 标签：`#借款合同 #证据不足 #笔迹鉴定`

### 3. 快速检索
- **按案由**：`#借款合同`
- **按状态**：`#审理中` `#已结案`
- **按法院**：`#贵阳市中院`

使用 `[[案件/...]]` 链接自动生成关联案件网络。

## 技术配置

### Obsidian 插件推荐
1. **Dataview** - 自动生成案件统计表
2. **Templater** - 文书模板快速插入
3. **Calendar** - 庭审日期跟踪
4. **Excalidraw** - 绘制案件关系图

- iCloud 同步（建议开启）
