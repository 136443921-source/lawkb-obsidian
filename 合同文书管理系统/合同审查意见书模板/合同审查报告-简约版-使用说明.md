## 一、模板概述

### 1.1 模板定位
本模板为**简约版合同审查报告**标准格式，适用于：
- ✅ 快速审查场景
- ✅ 内部参考使用
- ✅ 风险点聚焦输出
- ✅ 时间有限的审查工作

### 1.2 与标准版的区别

| 对比项 | 简约版（本模板） | 标准版 |
|--------|------------------|--------|
| **内容深度** | 聚焦10维度核心风险点 | 10维度全面审查 + 详细分析 |
| **法律分析** | 简要说明 | 详细法律分析和法条依据 |
| **风险量化** | 简要评分 | 完整量化评估 + 可视化图表 |
| **附录** | 无 | 风险量化评估表 + 法条依据清单 + 类案参考索引 |
| **适用场景** | 快速审查、内部参考 | 正式交付、客户汇报 |
| **完成时间** | 约15-20分钟 | 约30-40分钟 |

## 二、使用流程

### 2.1 启动审查
1. 上传合同文件（DOCX/PDF/图片）或直接粘贴合同文本
2. 系统自动触发**门禁控制器**（contract-review-gate-keeper）
3. 完成**背调三问**和**商业背景补充三问**
4. 门禁检查通过后，进入第一阶段（合同文本提取）

### 2.2 执行审查
按照蓝队律师合同审查系统 v9.0.0 的**四步推理流程**执行：
1. **第一步**：智能识别合同类型和关键条款
2. **第二步**：形式要件审查（主体资格、签署权限）
3. **第三步**：实质内容审查（权利义务、违约责任、风险分配）
4. **第四步**：逻辑校验和条款一致性审查

### 2.3 生成报告
1. 完成10维度审查后，系统自动生成审查报告草稿
2. 使用 **AskUserQuestion 工具** 弹出选择对话框：
   - 选项1：生成简约版合同（10维度审查方向）
   - 选项2：生成标准版合同（9大部分+附录）
3. 选择"简约版"后，基于本模板生成正式报告

### 2.4 LTI验证
**输出前强制检查**：
1. 调用 LTI v2.0 文本监察官系统检查
2. 检查结果为 `PASS` 或 `AUTO_FIX` 才允许输出
3. 检查结果为 `REJECT` 的，**禁止输出**，需返回修改

## 三、模板填写说明

### 3.1 基本信息（必填）
| 字段 | 填写说明 | 示例 |
|------|----------|------|
| 合同名称 | 填写合同全称，与合同首页标题一致 | 《公益筹款平台合作服务协议-审查意见书-20260525|公益筹款平台合作服务协议-审查意见书-20260525|公益筹款平台合作服务协议》 |
| 审查日期 | 填写审查完成日期，格式：YYYY年MM月DD日 | 2026年5月25日 |
| 委托方 | 填写甲方全称 | 贵州省厚德公益基金会 |

### 3.2 审查方法（系统自动生成）
- **1.1 审查目的**：系统自动填充
- **1.2 审查范围**：根据实际审查范围调整
- **1.3 审查依据**：根据合同类型自动匹配法律法规
- **1.4 审查方法**：固定内容，无需修改

### 3.3 合同及商业背景分析（需填写）
#### 2.1 签署方身份与地位
- **委托方（甲方）**：填写甲方完整信息，标注信息完整性（✅完整 / ⚠️缺失 / ❌错误）
- **受委托方（乙方）**：填写乙方完整信息，重点检查：
  - 统一社会信用代码是否为18位
  - 法定代表人/执行事务合伙人是否填写
  - 联系方式是否完整
- **谈判地位分析**：简要说明双方谈判地位

#### 2.2 交易目的和商业背景
- 简要说明合同签署起因、交易目的
- 列出特殊情形（如有）

#### 2.3 委托方核心要求
- **合同目标**：列出委托方的主要目标（3-5条）
- **重点关注条款**：列出需要重点审查的条款（3-5条）
- **不可接受的条款或条件**：列出委托方明确不能接受的条款

### 3.4 10维度审查结果（核心部分，需逐一填写）
每个维度按以下格式填写：

#### 维度X：[维度名称]审查
1. **审查结果**：
   - 列出审查发现的问题（用✅/⚠️/❌标注）
   - 对无问题的项目，标注✅

2. **问题清单**：
   - 用表格列出所有问题
   - **风险等级**：🔴高 / 🟡中 / ⚪低
   - **问题**：简要描述问题
   - **修改建议**：给出具体修改建议

**填写要点**：
- 高风险问题（🔴）必须修改，详细说明问题和修改建议
- 中风险问题（🟡）建议修改，说明风险和修改建议
- 低风险问题（⚪）可选优化，简要说明

### 3.5 风险评估（核心部分，需填写）
#### 4.1 合同条款总体评估
- **合同结构**：评价合同结构是否完整
- **条款内容**：列出优点和问题

#### 4.2 法律风险
- 总结存在的风险等级和数量

#### 4.3 总体评估
- 给出合同整体风险评价

#### 4.4 风险列示
按高风险、中风险、低风险分类列出：
- **高风险问题**：必须修改，详细说明问题、风险分析和修改建议
- **中风险问题**：建议修改，说明风险分析和修改建议
- **低风险问题**：可选优化，简要说明

### 3.6 审查结论（必填）
#### 5.1 总体评价
- 总结合同整体情况
- 说明存在的风险数量

#### 5.2 签署建议
分三类给出建议：
1. **必须修改后才能签署**：列出必须修改的事项
2. **建议修改后再签署**：列出建议修改的事项
3. **可选优化**：列出可选优化事项

#### 5.3 风险提示
- 列出最重要的3-5个风险提示

### 3.7 特别声明（系统自动生成）
- **6.1 免责声明**：固定内容，无需修改
- **6.2 审查人员**：系统自动填充
- **6.3 LTI v2.0文本监察官参与说明**：系统自动添加

## 四、风险等级标注规范

### 4.1 风险等级定义
| 等级 | 图标 | 定义 | 处理要求 |
|------|------|------|----------|
| **高风险** | 🔴 | 条款违法/违规，可能造成重大损失 | **必须修改**，停止签署 |
| **中风险** | 🟡 | 条款不合理，可能引发争议 | **建议修改**，如对方坚持不修改，需经管理层审批 |
| **低风险** | ⚪ | 表述模糊，有优化空间 | **可选优化**，或作为谈判中的让步筹码 |

### 4.2 风险量化评分（参考）
| 分数区间 | 风险等级 | 处理建议 |
|---------|----------|----------|
| 90-100分 | 🔴 高风险 | 必须立即修改，停止签署 |
| 75-89分 | 🟠 中高风险 | 建议修改，如对方坚持不修改，需经管理层审批 |
| 60-74分 | 🟡 中风险 | 建议修改，如对方坚持不修改，可以接受 |
| 45-59分 | 🟢 中低风险 | 可接受，或作为谈判中的让步筹码 |
| 0-44分 | ⚪ 低风险 | 可以接受 |

## 五、修改建议撰写规范

### 5.1 修改建议结构
每条修改建议应包含以下要素：

1. **修改标签**：【必须修改】/【强烈建议修改】/【建议修改】/【可选优化】
2. **位置**：指出需要修改的条款位置（如：第三条第2款）
3. **原条款**：引用原条款内容
4. **问题**：说明原条款存在的问题和风险
5. **修改建议**：给出修改后的条款内容（用下划线或加粗标注修改部分）
6. **修改理由**：说明为什么要这样修改
7. **法律依据**：列出支持修改的法律法规（可选，简约版可省略）

### 5.2 撰写示例
```
1. 【必须修改】补充约定审计工作的完成期限
   - **位置**：乙方的责任（第三条）、审计收费（第四条）
   - **原条款**："乙方应于出具审计报告征求意见稿，甲方书面回复无异议后5个工作日内出具正式审计报告"
   - **问题**：未约定征求意见稿出具时限，可能导致审计进度失控
   - **修改建议**：
     "乙方应于本约定书签订之日起【60】个工作日内出具审计报告征求意见稿；甲方书面回复无异议后5个工作日内，乙方出具正式审计报告。"
   - **修改理由**：明确约定审计工作的完成期限，确保甲方能够合理使用审计报告。
   - **法律依据**：《民法典》第五百一十条（合同约定不明的补充）。
```

## 六、注意事项

### 6.1 审查质量把控
1. **无背调不审查**：必须完成背调三问和商业背景补充三问，否则禁止进入第一阶段
2. **10维度全覆盖**：确保10个维度都进行了审查，不得遗漏
3. **高风险必修改**：高风险问题必须修改，不得妥协
4. **修改建议可操作**：修改建议应具体、明确、可操作，避免模糊表述

### 6.2 LTI验证强制要求
1. **未通过LTI不输出**：所有输出前必须通过LTI v2.0文本监察官系统检查
2. **检查结果处理**：
   - `PASS`：允许输出
   - `AUTO_FIX`：输出修正后文本
   - `REJECT`：禁止输出，返回修改
3. **文本监察官参与说明**：输出文档末尾必须附上LTI参与说明

### 6.3 时间控制
1. **简约版审查时间**：控制在15-20分钟内完成
2. **标准版审查时间**：控制在30-40分钟内完成
3. **超时处理**：如超时，应优先完成高风险问题审查，中低风险可简化处理

### 6.4 文档保存
1. **保存路径**：
   - 审查报告（Markdown）：`/Users/chenyouqiang/Documents/LawKB/法律文书/合同审查意见书/`
   - 修改版合同（DOCX）：`/Users/chenyouqiang/Documents/LawKB/法律文书/修改版合同/`
2. **文件命名**：`[合同名称]_审查报告_简约版_YYYYMMDD.md`
3. **版本管理**：如多次修改，在文件名中加入版本号（v1.0、v2.0等）

## 八、附录：模板检查清单

### 8.1 输出前自查清单
在完成审查报告前，请对照以下清单进行自查：

- [ ] ✅ 基本信息已填写完整
- [ ] ✅ 10维度审查结果已填写完整（无遗漏维度）
- [ ] ✅ 高风险问题已详细列出，并给出修改建议
- [ ] ✅ 中风险问题已列出，并给出修改建议
- [ ] ✅ 低风险问题已列出（可选）
- [ ] ✅ 审查结论已给出明确签署建议
- [ ] ✅ LTI v2.0文本监察官参与说明已添加
- [ ] ✅ 文档已保存至正确路径
- [ ] ✅ 文件命名符合规范

### 8.2 常见错误防范
1. **错误**：遗漏某个维度的审查
   - **防范**：使用10维度审查清单，逐项打勾

2. **错误**：修改建议模糊，不可操作
   - **防范**：修改建议应具体、明确，给出修改后的条款内容

3. **错误**：高风险问题未要求必须修改
   - **防范**：高风险问题必须标注【必须修改】，并详细说明理由

4. **错误**：未通过LTI验证就输出
   - **防范**：严格执行LTI验证流程，未通过不输出
