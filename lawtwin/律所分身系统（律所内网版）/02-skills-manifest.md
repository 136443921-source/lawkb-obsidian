# 02-skills-manifest · 律所数字分身技能安装清单 + 版本锁 v1.0

> 作用：本清单是模板的「开箱即用基线」。克隆到新所后，管理员按优先级安装技能，并把**实际安装版本号回填到「版本锁」列**，作为该所后续复制/回滚的基准。
> 配套：总体方案 §5、SOP-01（部署初始化）。
> 命名约定：本库文件统一 `0x-` 前缀（见 README）。

---

## 一、怎么用这份清单（克隆流程）

1. 在目标所 WorkBuddy 中，按 `优先级` 顺序安装技能（市场搜索 / SkillManage 导入）。
2. 每个技能装完后，把 Skill 实际版本号填进「版本锁」列（格式：`vX.Y.Z` 或 `YYYYMMDD` 快照）。
3. 连接器（L6）在 WorkBuddy 连接器页授权启用，确认 `enabled=true`，记录连接状态。
4. 装完跑 **SOP-01 检查清单**：投一个测试法律问题，确认 legal-consult-router 能分诊。
5. 全部回填后，本文件即成为该所的「版本锁基线」，复制到其他分所时对齐此表。

> ⚠️ 版本锁纪律：清单中的「版本锁」列初始为 `安装时锁定`。**不得留空交付**——没有版本号的清单等于没锁，跨所复制会错配。
