# 03-克隆迁移SOP · 跨所克隆律所数字分身模板 v1.0

> 配套：总体方案 §4（目录骨架）、02-skills-manifest（版本锁基线）、01-SOP手册（SOP-01~07 日常运营）。
> 定位：本 SOP 解决"如何把 `lawtwin-open` 模板克隆成**另一家所**的数字分身"，是建新所实例的前置流程；建完即转入 01-SOP手册 的日常运营。

---

## 一、目的

让目标所照此把 `lawtwin-open` 模板克隆成本所数字分身：**版本对齐、行为一致、经验可互通**，且不踩令牌迁移、占位符遗漏、隐私外泄三个坑。

## 二、适用范围

- ✅ 新所首次部署；同一品牌下分所复制。
- ❌ 不适用于涉密业务主导所需私有化变体——此时**架构不变**，仅部署形态改为本地/私有（连接器与知识库私有化），步骤 4 改为私有部署。

## 三、角色

| 角色 | 职责 |
|---|---|
| 源所管理员 | 提供「版本锁基线」（02-skills-manifest 基线记录区已填） |
| 目标所管理员 | 落地克隆、装技能、重授权、写隔离 README |
| 目标所助手 | 占位符替换辅助、知识入库 |

## 四、前置条件

- [ ] 源所 `02-skills-manifest.md` 的「版本锁基线记录区」已填 actual 版本号
- [ ] 目标所已开通 WorkBuddy 席位与知识库
- [ ] 目标所已明确本所名（用于占位符替换）

## 五、步骤（6 步）

**Step 1 · 取模板骨架**
复制 `lawtwin-open/` 目录到目标所知识库（保留 README / 00 / 01 / 02）。不要复制源所任何案件数据或个人记忆。

**Step 2 · 占位符全局替换**
对目标所库内文件执行批量替换：`[律所名]`→本所名、`[律师名]`→本所负责人、`[案由]`→适用案由。
- ⚠️ 先 dry-run 确认命中范围，再执行；替换后 grep 确认无残留 `[律所名]`。

**Step 3 · 技能安装 + 版本对齐**
按 `02-skills-manifest` 的 P0→P1→P2 顺序安装；**版本须对齐源所基线**。装完把目标所实际版本号回填本所 manifest 的「版本锁」列。
- 若某技能目标所装到更高版本，记录差异并评估是否回退基线，避免出现行为分叉。

**Step 4 · 连接器本所重授权**
IMA 知识库 / QQ·智能体邮箱 / 华宇元典等，在目标所 WorkBuddy **重新授权**，确认 `enabled=true`。
- ⚠️ **跨所令牌不可复用**：旧所令牌不迁移、不复制，否则调用必失败或串所。

**Step 5 · 隔离规则落地**
目标所同样建立「律所分身 ↔ 律师个人分身」文件隔离，写本所 `README.md`（沿用本库 README 的四项铁律）。

**Step 6 · 试点闭环验证**
选 1 个高频案由，跑通 `01-SOP手册` 的 SOP-03（文书→蓝队→红队→LTI→交付），验证全链路通、LTI REJECT=0。

## 六、检查清单

- [ ] 模板骨架已复制，README / 00 / 01 / 02 齐全
- [ ] 占位符全量替换，grep 无残留 `[律所名]`
- [ ] 技能版本与源所基线一致（差异已记录/评估）
- [ ] 连接器已本所授权，`enabled=true`，旧所令牌未迁移
- [ ] 隔离规则已写本所 README（四铁律）
- [ ] 试点案由闭环通过，LTI REJECT=0

## 七、输出物

- 目标所 `lawtwin-open` 库（含本所基线版本锁）
- 本所隔离 `README.md`
- 试点闭环报告（案由 + 文书样本 + LTI 结果）

## 八、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 复制源所连接器令牌 | 跨所失效/串所 | 目标所重新授权 |
| 漏替换占位符 | 交付物带错所名 | dry-run→替换→grep 核验 |
| 版本不对齐基线 | 行为差异、经验不通 | 按 manifest 版本锁安装 |
| 把当事人数据一并迁 | 隐私违规 | 只迁方法论/模板，数据留源所 |
| 跳 Step 6 直接推广 | 链路未验证就铺开 | 先单案由闭环再复制 |

## 九、经验互通说明

因各所共用同一版本基线 + 同一卡片 Schema（裁判规则卡/审判要件卡/经验卡），**方法论级卡片可跨所共享**（经脱敏后放入共享卡池）。当事人维度的卷宗、隐私数据**严禁跨所流动**。

> 克隆完成即转入 `01-SOP手册` 的 SOP-01~07 做日常运营；本 SOP 仅在"开新所实例"时触发。
