## 二、双源关系图：方法论 ↔ 四化（合并核心洞察）

方法论"四件套"与"四化"不是两套东西，是一一映射的：

| 方法论组件 | 对应四化 | 机制 |
|---|---|---|
| **EV 架构**（本地优先 + 黑匣子 + OTA + 快照） | 🔒 数据不出所 ＋ 🏦 人走资产在 | 本地 `127.0.0.1` 只进不出；`09-快照备份` + `case-state.json` 让资产可回滚、可追溯、不随人走 |
| **知识飞轮（六层）** | 📚 经验可沉淀 | 采集→提炼→连接→巩固→调用→沉淀，越用越深，是"深度未至"的补齐机制 |
| **模拟法庭 + 红蓝对抗 + 决策思维树** | 🚀 带教成长快 | 学员"看老师怎么想、跟老师怎么辩"，实战化训练 |
| **LTI 文本监控器（R/L/C/T/P + 六维）** | 四化的**质量公约数** | REJECT=0 才准交付，是"敢把 AI 用于出文"的底气，贯穿沉淀/不出所/带教 |
| **四模板联动**（画像↔基座↔RBAC） | 🏦 人走资产在 | 纪律同源、行为可分；一份模板驱动全席位，离职只带走个人叠加层 |
| **三层剥离 L0/L1/L2** | 🔒 数据不出所（约束） | L0 开源、L1/L2 私有，护城河在"只有你本地才有的语料+思维指纹+规则沉淀" |

> **关键判断**：方法论给的是"可复制的骨架 + 私有资产护城河"；四化评估暴露的是"骨架已立、资产已沉淀，但**让多人用起来、把人培养起来的运营闭环还没建**"。后续所有缺口都落在"运营闭环 + 度量"上，而非从零造。

## 三、方法论母本精要（来自 v2.0，压缩保留）

> 完整展开见 [[小强律师数字分身系统/10-律所数字分身中台/02-中小律所数字分身模板方法论|方法论 v2.0]]。此处只留骨架，便于本备忘录自洽。

### 3.1 错位竞争矩阵（中小所拼"纪律闭环"）
- 大所路线拼**模型深度**，中小所路线拼**执业纪律可复制**（门禁 + 飞轮）。
- 核心卖点：把老强验证过的"出文必过机检、法条必回源、经验必沉淀"做成开关，让任意律师获得同等守门强度。
- **最锋利的一把刀 = 数据不出所**（对标 Harvey/AlphaClaw 上云路线的本质差异）。

### 3.2 核心方法论四件套
1. **EV 架构**：三电=飞轮+质检 / 补能=连接器 / 智驾=决策思维 / 座舱=模拟法庭 / 黑匣子=车规日志 / OTA=自动化。
2. **知识飞轮（LawKB 六层）**：问答前先检索、任务后必沉淀，雪球越滚越深。
3. **LTI 文本监控器**：五维 QC + 六维法理门禁，REJECT=0 才准交付。
4. **四模板联动**：律师画像 → self.md ↔ legal-base ↔ cockpit RBAC，一份模板驱动全席位。

### 3.3 三层剥离（护城河在 L1/L2）
| 层 | 内容 | 开源决策 |
|---|---|---|
| **L0 内核** | EV 六模块骨架、四模板协议、LTI 判据逻辑（不含条文库）、MCP 适配器接口（无密钥无数据） | ✅ Apache-2.0 |
| **L1 人格层** | self.md / persona.md / HOW-I-THINK / 决策日志 / 律师画像实例 | ❌ 绝不开源（含可识别个人信息） |
| **L2 数据层** | LawKB 卡库、裁判规则库、案件卷宗、客户档案 | ❌ 绝不开源（保密义务约束） |

### 3.4 六条合规红线 + 工程红线
1. 绝不打包商业数据库数据（pkulaw/元典只留适配器接口）；2. 绝不出现真实案号/当事人/身份证/手机号（pre-commit 阻断）；3. AIGC 标识；4. 非律师执业声明；5. 不得宣称已备案/认证；6. 境外托管评估。
**工程红线（写入模板 `safety` 段随席位继承）**：永不代用户点 UI ／ 不落地令牌明文 ／ 法条必回源。

### 3.5 产品形态：Person / Practice / Firm
| 层 | 对应 | 价值主张 |
|---|---|---|
| **Person** | 律师个人分身 | "你的经验不会因休假而停摆" |
| **Practice** | 专业组（人伤/慈善/合同） | "组里最好那个人的打法，全组都能用" |
| **Firm** | 所级质控 | "主任不用逐份看文书，也能守住底线" |

> **卖点不是"AI 替你写文书"，是"律所的知识不再随人走"。** 这句话主任听得懂，也愿意付钱——它与"人走资产在"四化是同义反复。

### 3.6 路线图（方法论侧）
阶段 0 脱敏与分层（硬前置）→ 阶段 1 内核骨架开源 → 阶段 2 模板化与种子库 → 阶段 3 商业化闭环。当前个人分身跑通/画像模板化/骨架脚手架/脱敏门禁均✅已完成；开源发布+试点⬜待启动。

## 四、四化成熟度评估（来自 9360 复盘，实扫）

> 评估基准 2026-09-17。驾驶舱自身健康度总评 **77.2 / 良好 B**（见 [[_AI-Memory-Hub/02-当前项目/PROJ-SYS-9360COCKPIT-运维备忘录|运维备忘录]]），**不等于四化成熟度**。

### 4.1 成熟度矩阵（4 维 × 4 因子）
| 维度 | 架构底座 | 工具/技能 | 流程闭环 | 度量反馈 | 综合 |
|---|---|---|---|---|---|
| 🔒 数据不出所 | 85 | 70 | 55 | 40 | **65** |
| 🏦 人走资产在 | 80 | 65 | 45 | 35 | **58** |
| 📚 经验可沉淀 | 75 | 78 | 50 | 38 | **62** |
| 🚀 带教成长快 | 60 | 55 | 35 | 30 | **45** |

> 评分口径：架构底座=设计是否成立；工具/技能=现有技能是否覆盖；流程闭环=是否有端到端 SOP 且自动触发；度量反馈=是否有量化指标回看改进。100=成熟可用，60=有基础待补，40 以下=基本缺失。

### 4.2 四维现状（已落地 / 缺口 / 所需技能）

**🔒 数据不出所（65）**
- ✅ 已落地：`serve_nocache.py --bind 127.0.0.1` 仅本机回环；LawKB 本地 git 单一事实源；红线"严禁上传第三方云"；脱敏《EV 架构白皮书》为唯一对外出口。
- ⚠️ 缺口：无工具化数据分级拦截；连接器出网未审计；无加密自托管备份（机毁=资产没）；多人共享缺内网安全发布。
- 🛠 所需：`数据不出所护栏`技能（P0）＋ LawKB 加密自托管备份（P0）＋ 连接器出网审计（P1）＋ 内网发布 SOP（P1）。

**🏦 人走资产在（58）**
- ✅ 已落地：816 规则卡/205 经验卡 git 版本化且独立于个人；rbac 角色模型；D5 离职清除 UI（实查 200 在线）；快照与黑匣子可追溯。
- ⚠️ 缺口：无入职 SOP；离职流程未联动 D5；知识归属/署名缺失；数字分身是"个人"非"所级"。
- 🛠 所需：`新人接入 LawKB` SOP（P0）＋ `离职知识交接单`自动化（P0）＋ 知识归属模型（P1）＋ 所级分身基座拆分（P1）。

**📚 经验可沉淀（62）**
- ✅ 已落地：飞轮 01-采集→06-沉淀 全链路；每日摄入 15 篇 + LTI 缓存；LTI/冲突仲裁质检门禁；三条拆卡流水线。
- ⚠️ 缺口：无"结案→萃取"触发器；质检未覆盖全部沉淀路径；tacit 知识未捕获；复用度量缺失。
- 🛠 所需：`案件结案复盘卡`自动化（P0）＋ `沉淀质量门禁流水线`（P0）＋ 经验卡萃取模板库（P1）＋ 复用度量埋点（P2）。

**🚀 带教成长快（45）**
- ✅ 已落地：模拟法庭 C6 + 红蓝对抗 + 战情室；C2 决策思维树可见；角色化看板；小德合规培训素材。
- ⚠️ 缺口：无带教看板；无能力矩阵/成长路线；训练无排期；无导师-学员配对模型。
- 🛠 所需：带教看板（P0）＋ `实习律师能力矩阵`SOP（P0）＋ 红蓝训练排期自动化（P1）＋ 导师制配对+复盘会（P1）。

## 八、合规红线与资产分层（对所有四化的约束）

> 本节来自方法论 v2.0 §8，是所有四化动作的硬边界，任何缺口技能落地都不得突破。

1. **数据不出所 与 L2 私有 一致性**：加密备份必须落**自托管**（内网 Gitea/NAS），绝不上第三方云；连接器出网审计须证明"不含当事人 PII"。
2. **脱敏门禁前置**：任何对外传播（白皮书/培训/演示）前，先过 `desensitize_check.py`（MOD 11-2 / Luhn / 信用代码校验位验证），命中即阻断。
3. **L1 人格层绝不入库/绝不开源**：`11-人格层-L1私有/` 与 `10-` 仅同库目录分层，开仓库须复制到全新空仓库从零提交，切勿携带 LawKB 历史。
4. **工程红线随席位继承**：永不代用户点 UI ／ 不落地令牌明文 ／ 法条必回源。
5. **非律师执业声明 + AIGC 标识**：所有产出物预留标识位，本工具不提供法律意见。
