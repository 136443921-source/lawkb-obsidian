# lawtwin-open · 律所数字分身开放模板库

> 建立日期：2026-09-16 ｜ 来源：小强律师 AI 助手（老强指令）

## 一、本库定位

本目录专存 **「律所分身」** 资料——即**组织级、可复制**的中小律所数字分身模板与方案（双基座 + L0 路由 + 20+ 专项技能 + 知识飞轮 + LTI 门禁 + 红蓝对抗 + 驾驶舱 + 自动化）。

与 **「律师分身」**（`/Users/chenyouqiang/Documents/LawKB/小强律师数字分身系统/`，即小强个人数字分身）**严格文件隔离**：

| 维度 | 律所分身（本库） | 律师分身（小强系统） |
|---|---|---|
| 对象 | 组织 / 中小律所整体 | 律师个人（小强） |
| 内容 | 可复制模板、SOP、方案 | 个人案件、个人技能、个人记忆 |
| 性质 | 开放、可克隆、品牌无关 | 私有、个人执业资产 |

## 二、隔离铁律（务必遵守）

1. **单向归属**：凡涉及「律所分身 / 中小律所模板 / 组织级数字分身」的资料，**全部存入本库**；**不得**写入 `小强律师数字分身系统/` 或其子目录。
2. **互不混入**：律师个人的案件卷宗、个人偏好、个人记忆，**不得**存入本库。
3. **命名前缀**：本库文件用 `00-/01-/02-…` 序号前缀，保持与模板方案一致，便于克隆时对齐。
4. **隐私隔离**：当事人证件号 / 银行卡 / 手机号 / 证据原件**禁止入本库**，只提炼方法论与模板。
