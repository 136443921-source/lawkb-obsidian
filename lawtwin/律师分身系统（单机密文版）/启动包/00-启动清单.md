# 律师分身·单机密文版 · 启动清单（配 `启动包/` 脚本）

> 本清单与 `启动包/` 内脚本一一对应。每步先 dry-run / 校验，再落地。状态：⬜ 未做 / 🔄 进行中 / ✅ 完成。

---

## Step 0 · 备份基线（六-B 铁律，先建再动）
- [ ] `mkdir -p /tmp/lawtwin_deploy_<时间戳>` 并 `cp -n -R` 现有知识库
- [ ] 确认无备份基线 = 立即停手

## Step 1 · 骨架实例化
- [ ] `bash 启动包/bootstrap.sh --dry-run`（确认零写入）
- [ ] `bash 启动包/bootstrap.sh --apply`（生成 01–06 子目录 + logs）
- [ ] 残留校验：`grep -rn "\[律师名\]\|\[案由\]"` 输出为空

## Step 2 · 推理层配置（M1 已交付 v0.1.0）
- [ ] `cp 启动包/inference.A.yaml 02-配置/inference.yaml`
- [ ] 编辑 `base_url` / `model` / `network.mode`（密钥只走 `api_key_env`，绝不落盘）
- [ ] 校验：`cd ~/lawtwin-open/core && ./lawtwin-infer validate && ./lawtwin-infer selftest && ./lawtwin-infer check`

## Step 3 · 技能安装与版本锁
- [ ] 按 P0→P1→P2 安装；每装一个回填「目标所实装版本」列（见总体方案 §六，不得留空）
- [ ] P0 三件套先通：`legal-consult-router` + `lawyer-yourself-skill` + `LTI 文本监控器`
- [ ] 投测试问题，确认 `legal-consult-router` 能五问分诊并派发

## Step 4 · 连接器配置
- [ ] 法条源（pkulaw/元典）接入；离线用本地法规库快照兜底
- [ ] 跨所令牌由客户管理员重新授权（AI 不代点 UI、不打印明文）

## Step 5 · L1 人格层加密（密文核心）
- [ ] 生成 `profile.yaml` → `lawyer-yourself-skill` 的 `combine.sh` → `self.md`
- [ ] `bash 启动包/crypto-l1.sh encrypt 03-人格层L1 lawyer-l1`
- [ ] 确认：密文权限 600 + round-trip sha256 一致 + 密码存钥匙串（不打印明文）

## Step 6 · 知识层导入（L2）
- [ ] 分层裁剪：通用✅ / 行业✅（按订阅）/ 客户私有✅留本机 / 源所私有层🚫绝不交付
- [ ] 导入离线法规快照，记快照日期+核验日期
- [ ] 脱敏门禁：`python3 启动包/desensitize_check.py . --strict` 退出码 0

## Step 7 · 门禁校准与试点闭环
- [ ] LTI 五维自检（R101 条号越界、C301 金额硬矛盾能阻断）
- [ ] 跑通 1 个高频试点案由全链路：起草→蓝队→红队→LTI→交付，`REJECT=0`
- [ ] 填写部署记录表（一客户一表），密码/令牌安全移交
