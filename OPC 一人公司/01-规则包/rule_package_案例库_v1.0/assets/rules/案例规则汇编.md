## R-CS-007 

*类型：案例规则卡 ｜ 更新：2026-09-18T20:35*

**规则摘要**
《最高人民法院关于著作权民事纠纷案件适用法律若干问题的决定》（法释〔2026〕18号，2026年9月1日施行）实质性限缩"报刊转载法定许可"边界：**报纸、期刊与互联网信息服务提供者之间、互联网信息服务提供者之间相互转载已发表作品，应当经著作权人许可并支付报酬**——网络互转载不再适用法定许可。

**适用要点**
1. **互联网转载须许可付费**：媒体网站互转载、互联网信息服务提供者互转载已发表作品，"先许可、后使用"；
2. **法定许可范围扩张中的限缩**："报纸、期刊"明确为"主管部门批准出版的纸质报纸、期刊以及与其内容和版面格式相一致的数字化版本"——纸质报刊的数字化版本可适用法定许可，但互联网平台之间的转载不行；
3. **"公之于众"认定去主体限定**：删去"著作权人自行或者经著作权人许可"的限定——作品因他人侵权行为而被公开，也构成"公之于众"；"公之于众"只要求"向不特定的人公开"，不以公众知晓为构成要件；
4. **新增案由**："因申请诉前、诉中停止侵害著作权和与著作权有关的权益行为引发的损害责任纠纷案件"。

## R-CS-008

**规则摘要**
制作并出售盗版的软件安全认证工具（"加密狗"），属于《刑法》第217条第（六）项规定的**"故意避开或者破坏权利人为其作品采取的技术措施"**情形，构成侵犯著作权罪——人民法院案例库参考案例（2026年9月2日入库）。

**适用要点**
- 明确了软件著作权刑事保护中"技术措施"条款的适用边界：保护对象不限于作品本身，**绕过技术措施的工具有效供给行为本身可入罪**；
- 辩护侧注意点：需审查"加密狗"与特定软件作品的技术对应关系、行为人对"避开/破坏"性质的主观明知；
- 与 R-DRFT-20260912-02（著作权司法解释修改）组合使用，覆盖著作权民刑两域的最新规则。

## R-GS-004 R-GS-004 董事清算义务人15日未清算可强制清算

*类型：通用裁判规则卡 ｜ 更新：2026-09-18T20:35*

**规则摘要**
公司股东会决议解散的，董事作为清算义务人应在解散事由出现之日起**15日内**组成清算组；未履行的，股东等利害关系人可申请法院指定清算组强制清算，法院应予受理。

**适用要点**
- 股东：清算义务人（董事）怠于履职时，依本规则申请强制清算；造成损失可另诉赔偿（R-HG-055）。
- 董事：须严守15日组清算组义务，否则个人赔偿责任风险。
