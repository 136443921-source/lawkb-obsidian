## R-LN-042 供应商视角合同审查交易留痕举证执行全流程实操与股东穿透执行

*类型：办案方法论卡 ｜ 更新：2026-09-23T12:48*

**规则摘要**
**核实主体 → 明确标的与价款 → 把握风险（违约/拖欠）条款 → 约定清楚管辖条款**

| 检查项 | 细化要点 |
|---|---|
| **对方主体** | 营业执照（统一社会信用代码）、经办人身份证；对方为公司的，确认法定代表人与**经办权限**，索要**授权委托书并加盖公章**；自然人的须**核验身份证原件**（防无权代理/超越权限） |
| **公司资信与对外关系** | 国家企业信用信息公示系统 / 天眼查 / 企查查查分支、被执行记录、股权穿透（**截图存证**） |

**关键条款设计要点**：
- **付款**：明确付款节点（含对账单、开票条件）、付款账户、担保/保证金、逾期利息或违约金计算方法；
- **交付与验收**：指定检验标准、取样方案、验收期、验收人名单、验收单样式（签字盖章为佳）；
- **履约担保**：推荐定金 / 履约保证金、连带保证（自然人或第三方）、银行保函；
- **违约条款**：对双方主要违约行为分别设定（供方：迟延交货、质量不符；采购方：迟延付款、迟延验收、拒收合格货物）；
- **争议解决**：约定供应商所在地法院管辖，或选择仲裁（须写明**具体仲裁机构名称**）；**明确约定律师费、差旅费由败诉方承担**；
- **所有权保留**（注意）：民法典已作规范，但须注意**登记/公示**问题，**不可当作万能条款**（见法条）。

**适用要点**
- **第641条**（所有权保留）：当事人可以在买卖合同中约定买受人未履行支付价款或者其他义务的，标的物的所有权属于出卖人。**出卖人对标的物保留的所有权，未经登记，不得对抗善意第三人**。
- **第642条**（取回权）：买受人未按约定支付价款经催告仍未支付 / 未完成特定条件 / 出卖、出质或作其他不当处分的，出卖人有权取回标的物；协商不成的，**可参照适用担保物权的实现程序**。
- **第586条**：定金合同自实际交付定金时成立；**定金数额不得超过主合同标的额的 20%**，超过部分不产生定金效力。
- **第587条**（定金罚则）：给付定金方不履行致合同目的不能实现的，无权请求返还；收受方不履行的，应当**双倍返还**。
- **第588条**：既约定违约金又约定定金的，一方违约时对方**可以选择适用**违约金或者定金条款；定金不足弥补损失的，可请求赔偿超过定金数额的损失。
- **第538条**（无偿处分撤销）：债务人以放弃债权、放弃债权担保、无偿转让财产等方式无偿处分财产权益，或恶意延长到期债权履行期限，影响债权实现的，债权人可请求法院撤销。
- **第539条**（不合理对价撤销）：以明显不合理低价转让 / 高价受让 / 为他人债务提供担保，影响债权实现且相对人知道或应当知道的，债权人可请求撤销。
- **第541条**：撤销权自债权人知道或应当知道撤销事由之日起 **1 年**内行使；自债务人行为发生之日起 **5 年**内没有行使的，该撤销权消灭。

## R-LN-043 民间借贷举证指引与五大法律风险防范要点

*类型：办案方法论卡 ｜ 更新：2026-09-23T12:48*

**规则摘要**
《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》第1条：民间借贷是**自然人、法人和非法人组织之间**进行资金融通的行为。**经金融监管部门批准设立的从事贷款业务的金融机构及其分支机构**因发放贷款引发的纠纷**不适用**本规定。
→ 银行贷款、蚂蚁借呗、京东白条等**持牌金融机构**提供的信贷服务，属金融借贷，非民间借贷。

**适用要点**
| 风险类型 | 具体表现 | 防范措施 |
|---|---|---|
| **① 合同订立** | 仅口头约定无书面合同；条款不规范不完整；仅口头约定利息被抗辩为"无息借款" | **必须签订书面合同**，明确金额、用途、利息计算方式、还款时间与方式、违约责任；核对借款人身份信息 |
| **② 款项交付** | 现金交付无收条；转账未备注"借款"，被抗辩为**赠与** | 优先银行/微信/支付宝转账，**转账备注注明"借款"及借款信息**；现金交付/还款须出具收条（写明金额、时间、方式） |
| **③ 利息约定** | 约定利率超上限；未约定利息则逾期利息难主张 | 明确约定利息且**不超上限**（见 R-HT-107）；未约定或约定不明的**视为无息**；逾期利息须明确计算方式 |
| **④ 诉讼时效** | 时效届满且无催讨证据，抗辩成立则败诉 | 时效内以短信、微信、书面函件催讨并**保留记录**；期限将至可通过**签订还款协议重新约定还款期限**以中断时效 |
| **⑤ 担保不规范** | 保证人无担保能力；未明确一般/连带；**抵押未登记**（押房本无抵押效力） | 选择有担保能力的保证人，明确担保方式、范围、期限；**不动产抵押须及时办理抵押登记**；质押须妥善保管质物 |

## R-LN-044 民间借贷全维度裁判规则利息计算与刑民交叉辨析

*类型：通用裁判规则卡 ｜ 更新：2026-09-18T20:35*

**规则摘要**
- **《民法典》第679条**：自然人之间的借款合同，**自贷款人提供借款时成立** —— 属**实践性合同**，仅有合意而无交付，合同不成立。
- 合同形式不限：借条、欠条、借款合同、口头借款、微信等电子数据形式均可达成合意。
- **审查两要素 = 借款合意 + 资金交付**：
  - 原告手持**有疑点**的借条（金额涂改、签名模糊）且无转账记录或现金交付证据 → "**孤证存疑不采信**"，大概率不支持；
  - 原告仅提供转账凭证，被告抗辩"这是货款/赠与"但**无法举证** → 法院通常**认定借贷关系成立**；
  - 被告有效举证令法官对借贷事实存疑的，举证责任仍回到原告，原告举证不能则败诉。

**适用要点**
- **第679条**：自然人之间的借款合同，自贷款人**提供借款时成立**。
- **第680条**：禁止高利放贷，借款的利率不得违反国家有关规定。**借款合同对支付利息没有约定的，视为没有利息**。约定不明确且不能达成补充协议的，按交易方式、习惯、市场利率等确定；**自然人之间借款的，视为没有利息**。
- **第668条**：借款合同应当采用书面形式，但是**自然人之间借款另有约定的除外**；内容一般包括种类、币种、用途、数额、利率、期限和还款方式。
- **第561条**（冲抵顺序）：实现债权的有关费用 → 利息 → 主债务。
- **第670条**：借款的利息不得预先在本金中扣除；预先扣除的，按实际借款数额返还并计算利息。
- **第192条**：诉讼时效期间届满的，义务人可以提出不履行义务的抗辩；届满后义务人同意履行的，不得以时效届满抗辩；已自愿履行的，不得请求返还。
- **第193条**：**人民法院不得主动适用诉讼时效的规定**。
- **第143条**：民事法律行为有效三要件——行为人有相应民事行为能力、意思表示真实、不违反法律行政法规强制性规定且不违背公序良俗。
- **第153条**：违反法律、行政法规强制性规定的民事法律行为无效（但书除外）；违背公序良俗的无效。

## R-LN-046 共同饮酒者注意义务边界与责任比例认定

*类型：实务规则卡 ｜ 更新：2026-09-22T08:44*

**规则摘要**
共同饮酒系**自主、自发的社交行为**，对同饮人人身安全以**自我保护为主**、以他人的安全保障义务为**补充**。基于共同饮酒这一**先行行为**，同饮人相互之间产生**附随的特殊照顾义务**：饮酒中**提醒、劝阻**，饮酒后**妥善照顾**，处于醉酒状态时**及时通知家属、及时救助、及时送医**。

该义务以**补充性**为核心边界，以**普通人可预见、可实施**为限，**不要求专业救助能力**，但**拒绝履行基本照料即构成过错**。责任分担遵循**过错责任 + 过失相抵**，由饮酒人自负主要责任，同饮者仅按轻微过错承担**次要补充责任**（原型案例判赔 **8%**）。

**一句话口径**：有劝酒/斗酒/强迫 → 同饮者责任显著上升；无劝酒但疏于照料 → 轻微补充责任（个位数百分比）；已劝阻已安置已护送已通知 → 免责。

**适用要点**
**《中华人民共和国民法典》第一千一百七十三条**（本地·法律法规库/通用实体法/中华人民共和国民法典（全文）.md）

> 第一千一百七十三条　被侵权人对同一损害的发生或者扩大有过错的，可以减轻侵权人的责任。

*效力状态：现行有效*

**《中华人民共和国民法典》第一千一百六十五条**（本地·同上）

> 第一千一百六十五条　行为人因过错侵害他人民事权益造成损害的，应当承担侵权责任。
> 依照法律规定推定行为人有过错，其不能证明自己没有过错的，应当承担侵权责任。

*效力状态：现行有效*

## R-LN-047 辩护人调取讯问同步录音录像的程序抗辩路径

*类型：实务规则卡 ｜ 更新：2026-09-22T08:44*

**规则摘要**
同步录音录像不是可有可无的材料，而是**证明取证合法与否的核心证据**，是非法取证的"照妖镜"。其三重作用：**还原真实讯问场景**、**核对笔录是否伪造删减篡改**、**作为排除非法证据的最关键依据**。

**核心逻辑（一句话，全程贯穿）**：
> 不给录像 = 无法证明取证合法 = 供述必须排除

**全域程序公式**：
> 书面申请 + 全程留痕 + 当庭固定拒供事实 + 庭外监督兜底 → 推定/认定取证违法 → 相关供述排除

**适用要点**
> ⚠️ **本卡所涉全部刑事程序法条，本地法律法规库均无源（库内仅有《仲裁法》《民事诉讼法（2023）》），一律不默写正文，逐条标注待回源，不得作文书引用源。**

**《中华人民共和国刑事诉讼法(2018修正)》第一百二十三条**

> 侦查人员在讯问犯罪嫌疑人的时候，可以对讯问过程进行录音或者录像；对于可能判处无期徒刑、死刑的案件或者其他重大犯罪案件，应当对讯问过程进行录音或者录像。
> 录音或者录像应当全程进行，保持完整性。

*效力状态：现行有效（企查查·法律数据核填·2026-09-13；发文字号 中华人民共和国主席令第10号；施行日期 2018-10-26）·[溯源](http://legal.qcc.com/regulation/42e7882d93b949d6d53ecac79a244d0f/229)*
**《中华人民共和国刑事诉讼法(2018修正)》第五十六条**

> 采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。
> 在侦查、审查起诉、审判时发现有应当排除的证据的，应当依法予以排除，不得作为起诉意见、起诉决定和判决的依据。

*效力状态：现行有效（企查查·法律数据核填·2026-09-13；发文字号 中华人民共和国主席令第10号；施行日期 2018-10-26）·[溯源](http://legal.qcc.com/regulation/42e7882d93b949d6d53ecac79a244d0f/88)*
**《中华人民共和国刑事诉讼法(2018修正)》第七十四条**

> 人民法院、人民检察院和公安机关对符合逮捕条件，有下列情形之一的犯罪嫌疑人、被告人，可以监视居住：
> （一）患有严重疾病、生活不能自理的；
> （二）怀孕或者正在哺乳自己婴儿的妇女；
> （三）系生活不能自理的人的唯一扶养人；

> 对符合取保候审条件，但犯罪嫌疑人、被告人不能提出保证人，也不交纳保证金的，可以监视居住。
> 监视居住由公安机关执行。

**《人民检察院刑事诉讼规则(2019)》第七十五条**

> 对于公安机关立案侦查的案件，存在下列情形之一的，人民检察院在审查逮捕、审查起诉和审判阶段，可以调取公安机关讯问犯罪嫌疑人的录音、录像，对证据收集的合法性以及犯罪嫌疑人、被告人供述的真实性进行审查：

> （三）犯罪嫌疑人、被告人提出讯问活动违反法定程序或者翻供，并提供相关线索或者材料的；
> （四）犯罪嫌疑人、被告人或者辩护人提出讯问笔录内容不真实，并提供相关线索或者材料的；
> （五）案情重大、疑难、复杂的。
> 人民检察院调取公安机关讯问犯罪嫌疑人的录音、录像，公安机关未提供，人民检察院经审查认为不能排除有刑讯逼供等非法取证行为的，相关供述不得作为批准逮捕、提起公诉的依据。

## R-LN-048 庭前会议非法证据排除的申请与审查

*类型：实务规则卡 ｜ 更新：2026-09-21T01:57*

**规则摘要**
非法证据排除**不等于**只排除刑讯逼供。**诱供、骗供、超时讯问、疲劳审讯、应当同步录音录像而未录制、笔录与当庭陈述矛盾**，均属法定非法取证情形，均应在**庭前会议**提出并要求审查。

**三条核心口径**：
1. **应录未录**：一般案件可以不录，但**重大案件、可能判处十年以上、认罪认罚具结**案件，法律**强制**必须全程录音录像 → 应当录像而未录，**程序违法**；
2. **无录像**：即**无法证明讯问合法、笔录真实**；笔录与被告人当庭陈述完全矛盾 → **该笔录不能作为定案依据**；
3. **排非不限于刑讯逼供**：诱供、骗供、超时讯问、疲劳审讯同样必须排除；庭前会议**不能只审查刑讯逼供**，否则**没有法律依据**。

**一句话公式**：应录未录 + 无录像 + 笔录与当庭陈述矛盾 → 供述不具有证据资格 → 依法排除

**适用要点**
> 以下条文经华宇元典 MCP（yuandian_rh_ft_detail，参数 fgmc + 中文条号）逐条核填，标注现行有效性；引用前仍建议与最高法官网/国家法律法规数据库官方文本最终核对。原卡「应录未录→排除」错挂第 123 条，现纠正为落在**刑诉法解释第 74 条**（第 123 条仅规定「双录范围」，非排除后果）。

- **《中华人民共和国刑事诉讼法》(2018 修正) 第 123 条**（强制录音录像范围，现行有效·元典核填）：侦查人员在讯问犯罪嫌疑人的时候，可以对讯问过程进行录音或者录像；对于可能判处无期徒刑、死刑的案件或者其他重大犯罪案件，应当对讯问过程进行录音或者录像。录音或者录像应当全程进行，保持完整性。
- **《中华人民共和国刑事诉讼法》(2018 修正) 第 56 条**（非法证据排除核心，现行有效·元典核填）：采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。在侦查、审查起诉、审判时发现有应当排除的证据的，应当依法予以排除，不得作为起诉意见、起诉决定和判决的依据。
- **《中华人民共和国刑事诉讼法》(2018 修正) 第 119 条**（传唤拘传时限，现行有效·元典核填）：传唤、拘传持续的时间不得超过十二小时；案情特别重大、复杂，需要采取拘留、逮捕措施的，传唤、拘传持续的时间不得超过二十四小时。不得以连续传唤、拘传的形式变相拘禁犯罪嫌疑人。传唤、拘传犯罪嫌疑人，应当保证犯罪嫌疑人的饮食和必要的休息时间。
- **《关于办理刑事案件严格排除非法证据若干问题的规定》(法发〔2017〕15号) 第 1—5 条**（现行有效·元典核填）：
  - 第 1 条：严禁刑讯逼供和以威胁、引诱、欺骗以及其他非法方法收集证据，不得强迫任何人证实自己有罪。
  - 第 2 条：采取殴打、违法使用戒具等暴力方法或者变相肉刑的恶劣手段，使犯罪嫌疑人、被告人遭受难以忍受的痛苦而违背意愿作出的供述，应当予以排除。
  - 第 3 条：采用以暴力或者严重损害本人及其近亲属合法权益等进行威胁的方法，使犯罪嫌疑人、被告人遭受难以忍受的痛苦而违背意愿作出的供述，应当予以排除。
  - 第 4 条：采用非法拘禁等非法限制人身自由的方法收集的犯罪嫌疑人、被告人供述，应当予以排除。
  - 第 5 条：采用刑讯逼供方法使犯罪嫌疑人、被告人作出供述，之后受该刑讯逼供影响而作出的重复性供述（重复自白），应当一并排除（但更换侦查/检察/审判人员并告知权利后自愿供述的除外）。
- **庭前会议审查排非申请的功能依据**：原卡所引《人民法院办理刑事案件庭前会议规程》（2017）中央正文元典未收录；现行全国依据为《人民法院办理刑事案件排除非法证据规程（试行）》（法发〔2024〕12号，2024-07-25 施行），规定庭前会议中申请排除非法证据并提供线索或材料的，应了解情况、听取意见并就合法性作出处理。本条仅作程序功能说明，引用请以官方文本为准。
- **《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》(2021) 第 74 条**（现行有效，应录未录后果正解）：依法应当对讯问过程录音录像的案件，相关录音录像未随案移送的，必要时，人民法院可以通知人民检察院在指定时间内移送。人民检察院未移送，导致不能排除属于刑事诉讼法第五十六条规定的以非法方法收集证据情形的，对有关证据应当依法排除；导致有关证据的真实性无法确认的，不得作为定案的根据。

## R-LN-050 违法发放贷款罪四要件与出罪辩点清单

*类型：实务规则卡 ｜ 更新：2026-09-23T15:52*

**规则摘要**
**一句话立场**：贷款出现不良，是银行业务的固有经营风险，**绝不能简单等同于刑事犯罪**。

违法发放贷款罪（《刑法》第 186 条）的成立，须**同时具备四个条件，缺一不可**：

| # | 要件 | 关键点 | 缺位后果 |
|---|---|---|---|
| ① | **主体** | 银行或其他**持牌**金融机构及其工作人员 | 非持牌机构人员、单纯借款人不构成本罪 |
| ② | **主观** | **故意**（滥用职权）或**重大过失**（玩忽职守、未尽审查义务） | 履职瑕疵、一般过失 → **出罪** |
| ③ | **行为** | 违反的是**"国家规定"**（法律、行政法规级） | 仅违反**银行内部规章/操作细则** → 只是合规问题，**不具违法性** |
| ④ | **结果** | 违法发放贷款**数额 ≥ 200 万**，或造成**直接经济损失 ≥ 50 万** | 未达门槛 → 不追诉 |

**四个条件的关系**：①②③是**构成要件**，④是**追诉门槛**；④不达标时，即便①②③全中也不立案；①②③缺其一，数额再大也是无罪。

**本罪的攻击面排序**（辩护火力分配）：②主观（最大空间）→ ③"国家规定"（最锋利）→ ④损失认定（最技术）→ ①主体（个案偶发）。

## R-LN-051 交通肇事罪有效辩护与缓刑适用清单

*类型：实务规则卡 ｜ 更新：2026-09-22T08:44*

**规则摘要**
> **交通肇事罪，从不是"出了事、有伤亡"就必然定罪。**
> **交警的责任认定书不是铁证，逃逸的认定不靠形式，酒驾毒驾也未必一概定重罪。**

**总纲**：本罪是**过失犯罪**，刑事审判的重点是**实质合理性，而非机械套用规则**。辩护从来不是**否定事故本身**，而是回到**事实与证据**，拆解**责任、主观过错与因果关系**。

**四大突破口（本卡骨架）**：

| # | 突破口 | 核心命题 | 打掉后效果 |
|---|---|---|---|
| ① | **责任认定** | 行政责任 ≠ 刑事责任；刑事须**实质审查** | 推翻全责 → 仅次要责任 → **无罪** |
| ② | **逃逸** | 核心是"**为逃避法律追究而逃跑**"，**不是**"离开现场" | 打掉逃逸 → 刑期回到**三年以下** |
| ③ | **酒驾毒驾定性** | **过失 → 交通肇事罪；故意 → 以危险方法危害公共安全罪** | 改定交通肇事罪（**2 年** vs 十年以上） |
| ④ | **因逃逸致人死亡** | 须有**刑法上的因果关系**：逃逸导致得不到及时救治 | 降档为"交通运输肇事后逃逸"（**7 年以上 → 3 年**） |

**量刑三档速记**：**3 年以下**（基本档）→ **3—7 年**（肇事后逃逸或有其他特别恶劣情节）→ **7 年以上**（因逃逸致人死亡）。

**适用要点**
### ✅ 已核填（华宇元典 · 现行有效）

- **《中华人民共和国刑法（2023 修正）》第一百三十三条**（发布 2023-12-29，**施行 2024-03-01**，时效性：**现行有效**）：
  > 【交通肇事罪】违反交通运输管理法规，因而发生重大事故，致人重伤、死亡或者使公私财产遭受重大损失的，处三年以下有期徒刑或者拘役；交通运输肇事后逃逸或者有其他特别恶劣情节的，处三年以上七年以下有期徒刑；因逃逸致人死亡的，处七年以上有期徒刑。

- **《中华人民共和国刑法（2023 修正）》第七十二条**（发布 2023-12-29，**施行 2024-03-01**，时效性：**现行有效**）：
  > 【适用条件】对于被判处拘役、三年以下有期徒刑的犯罪分子，同时符合下列条件的，可以宣告缓刑，对其中不满十八周岁的人、怀孕的妇女和已满七十五周岁的人，应当宣告缓刑：（一）犯罪情节较轻；（二）有悔罪表现；（三）没有再犯罪的危险；（四）宣告缓刑对所居住社区没有重大不良影响。
  > 宣告缓刑，可以根据犯罪情况，同时禁止犯罪分子在缓刑考验期限内从事特定活动，进入特定区域、场所，接触特定的人。
  > 被宣告缓刑的犯罪分子，如果被判处附加刑，附加刑仍须执行。

  📌 **"不满十八周岁 / 怀孕的妇女 / 已满七十五周岁"是"应当"宣告缓刑，不是"可以"**——符合时法院**没有裁量空间**。

## R-LN-052 交通肇事罪定罪量刑标准与缓刑适用规则

*类型：实务规则卡 ｜ 更新：2026-09-23T12:48*

**规则摘要**
> **交通肇事罪是过失犯罪，也是普通人最容易触及的刑事风险——它常年位居刑事起诉数量前十，且是前十中唯一的过失犯罪。**
> **办案口诀：先算够不够罪，再算落在哪一档，最后才算能不能缓。三步不能跳，更不能倒着推。**

**三档量刑台阶（刑法第 133 条 + 交通肇事刑案解释第 2、4 条）**：

| 档位 | 刑期 | 触发条件（择一即可） |
|---|---|---|
| **基础档** | **3 年以下** 或拘役 | 死 1 / 重伤 3 人 + 全主责；死 3 人 + 同等责；财产损失 + 全主责 + 无力赔 ≥ 30 万；**重伤 1 人 + 全主责 + 六种降门槛情形之一** |
| **加重档** | **3—7 年** | 死 2 / 重伤 5 人 + 全主责；死 6 人 + 同等责；无力赔 ≥ 60 万 + 全主责；**已构成犯罪 + 逃逸/酒驾/严重超载/无证等恶劣情节** |
| **顶格档** | **7 年以上** | **仅两种**：① 因逃逸致被害人**得不到救助而死亡**；② 带离现场**隐藏或遗弃**致其死亡或严重残疾 → **转定故意杀人罪/故意伤害罪** |

**⭐ 本卡最重要的两个命题**：

1. **"入罪钥匙"与"升档钥匙"不能重复用**。逃逸、酒驾、超载、无证这一批恶劣情节——在**尚未达到定罪标准**时，它们是**把行为拉进犯罪圈的钥匙**（例：重伤 1 人 + 逃逸 = 基本犯，3 年以下）；在**已经构成犯罪**之后，它们才是**把刑期推上去的钥匙**（例：死 1 人 + 主责 + 逃逸 = 3—7 年）。**同一情节不能既用来入罪、又用来升档。**
2. **缓刑的第一道门是刑期，不是态度**。刑法第 72 条把缓刑的前提锁死在"**判处拘役、三年以下有期徒刑**"。**一旦落入 3—7 年档，无论赔偿多到位、谅解多真诚，都出不了缓刑。**所以"打档"永远优先于"求情"。

**适用要点**
### ✅ 已核填（华宇元典 · 现行有效）

- **《中华人民共和国刑法（2023 修正）》第一百三十三条**（发布 2023-12-29，**施行 2024-03-01**，时效性：**现行有效**）：
  > 【交通肇事罪】违反交通运输管理法规，因而发生重大事故，致人重伤、死亡或者使公私财产遭受重大损失的，处三年以下有期徒刑或者拘役；交通运输肇事后逃逸或者有其他特别恶劣情节的，处三年以上七年以下有期徒刑；因逃逸致人死亡的，处七年以上有期徒刑。

- **《中华人民共和国刑法（2023 修正）》第七十二条**（**施行 2024-03-01**，时效性：**现行有效**）：
  > 【适用条件】对于被判处拘役、三年以下有期徒刑的犯罪分子，同时符合下列条件的，可以宣告缓刑，对其中不满十八周岁的人、怀孕的妇女和已满七十五周岁的人，应当宣告缓刑：（一）犯罪情节较轻；（二）有悔罪表现；（三）没有再犯罪的危险；（四）宣告缓刑对所居住社区没有重大不良影响。
  > 宣告缓刑，可以根据犯罪情况，同时禁止犯罪分子在缓刑考验期限内从事特定活动，进入特定区域、场所，接触特定的人。
  > 被宣告缓刑的犯罪分子，如果被判处附加刑，附加刑仍须执行。

  📌 **"三年以下有期徒刑"是缓刑的硬门槛**——本卡全部缓刑讨论都以此为前提。

  > 交通肇事具有下列情形之一的，属于"有其他特别恶劣情节"，处三年以上七年以下有期徒刑：（一）死亡二人以上或者重伤五人以上，负事故全部或者主要责任的；（二）死亡六人以上，负事故同等责任的；（三）造成公共财产或者他人财产直接损失，负事故全部或者主要责任，无能力赔偿数额在六十万元以上的。

## R-LN-053 损害公司利益责任纠纷裁判规则与双通道救济

*类型：实务规则卡 ｜ 更新：2026-09-23T12:48*

**规则摘要**
> **公司及其股东对违反忠实勤勉义务、损害公司利益的高管，法律给了两条救济通道。**
> **公司直接诉讼是"公司自己告"，股东代表诉讼是"股东代公司告"——两条通道的原告、被告、第三人、前置程序、胜诉利益归属全部不同，选错通道会直接被驳回起诉。**

**⭐ 选通道的三秒判断**：

| 判断点 | 公司直接诉讼 | 股东代表诉讼 |
|---|---|---|
| **谁能告** | 公司（由**监事会/监事**或**董事会/董事**代表） | **有限公司股东**（无门槛）；**股份公司股东**（连续 180 日以上 + 单独或合计持股 1% 以上） |
| **原告名义** | **公司自己**为原告 | 股东**以自己的名义**，但**为公司利益** |
| **告谁** | 侵害公司利益的行为人 | **董事、高管**（违反第 188 条情形），**或任何公司之外侵害公司利益的第三人** |
| **公司地位** | **原告** | **第三人** |
| **前置程序** | 无（公司自己决定即告） | ⭐ **必须先书面请求监事会/董事会起诉**，被拒、30 日未起诉、或情况紧急方可自行起诉 |
| **胜诉利益** | 归公司（本来就是原告） | **归公司**（股东只是代位，不直接受偿） |

**两条请求权（易混，务必分清）**：

| | 规范 | 保护对象 | 原告 | 利益归属 |
|---|---|---|---|---|
| **损害公司利益** | **公司法第 188 条** | **公司** | 公司（直接诉讼）/ 股东（代表诉讼） | **归公司** |
| **损害股东利益** | **公司法第 190 条** | **股东** | **股东自己** | **归股东自己** |

> 📌 **最常见的低级错误**：股东利益受损时套用第 188 条走代表诉讼——**第 190 条是股东直接诉权，不需要前置程序，胜诉利益直接归股东**。开局先分清"**损害的是公司的钱还是股东的钱**"。

**⭐ 前置程序的豁免规则（本卡最值钱的一条）**：
> 前置程序针对的是**公司治理的一般情况**——即在股东书面申请之时，**存在公司有关机关提起诉讼的可能性**。
> **如果查明的相关事实表明，根本不存在该种可能性的，人民法院不应当以原告未履行前置程序为由驳回起诉。**
> → 实务落点：**证明董事会/监事会被被告实际控制、或被诉人本人就是董事/监事、或公司已陷入僵局**，即可**豁免前置程序**、直接起诉。

**适用要点**
### ✅ 已核填（华宇元典 · 现行有效）

- **《中华人民共和国公司法（2023 修订）》第一百八十条**（发布 2023-12-29，**施行 2024-07-01**，时效性：**现行有效**）：
  > 董事、监事、高级管理人员对公司负有**忠实义务**，应当采取措施避免自身利益与公司利益冲突，**不得利用职权牟取不正当利益**。
  > 董事、监事、高级管理人员对公司负有**勤勉义务**，执行职务应当为公司的**最大利益**尽到管理者通常应有的**合理注意**。
  > 公司的**控股股东、实际控制人**不担任公司董事但**实际执行公司事务**的，适用前两款规定。

  📌 **第 3 款是 2023 修订新增**——**"影子董事"不挂名也负忠实勤勉义务**，追责主体范围显著扩张。

- **《中华人民共和国公司法（2023 修订）》第一百八十八条**（**施行 2024-07-01**，**现行有效**）：
  > 董事、监事、高级管理人员**执行职务**违反法律、行政法规或者公司章程的规定，**给公司造成损失的，应当承担赔偿责任**。

- **《中华人民共和国公司法（2023 修订）》第一百八十九条**（**施行 2024-07-01**，**现行有效**）— **股东代表诉讼的完整规则**：
  > 董事、高级管理人员有前条规定的情形的，**有限责任公司的股东**、**股份有限公司连续一百八十日以上单独或者合计持有公司百分之一以上股份的股东**，可以**书面请求监事会**向人民法院提起诉讼；监事有前条规定的情形的，前述股东可以**书面请求董事会**向人民法院提起诉讼。
  > 监事会或者董事会收到前款规定的股东书面请求后**拒绝提起诉讼**，或者**自收到请求之日起三十日内未提起诉讼**，或者**情况紧急、不立即提起诉讼将会使公司利益受到难以弥补的损害的**，前款规定的股东有权**为公司利益以自己的名义直接**向人民法院提起诉讼。
  > **他人侵犯公司合法权益**，给公司造成损失的，本条第一款规定的股东可以依照前两款的规定向人民法院提起诉讼。
  > 公司**全资子公司**的董事、监事、高级管理人员有前条规定情形，或者他人侵犯公司全资子公司合法权益造成损失的，有限责任公司的股东、股份有限公司连续一百八十日以上单独或者合计持有公司百分之一以上股份的股东，可以依照前三款规定书面请求**全资子公司**的监事会、董事会向人民法院提起诉讼或者**以自己的名义直接**向人民法院提起诉讼。

  📌 第 4 款为 **2023 修订新增的双重代表诉讼**，旧法（2018）无此通道。

- **《中华人民共和国公司法（2023 修订）》第一百九十条**（**施行 2024-07-01**，**现行有效**）：
  > 董事、高级管理人员违反法律、行政法规或者公司章程的规定，**损害股东利益的，股东可以向人民法院提起诉讼**。

  ⚠️ 与第 188 条**请求权基础不同**：本条是**股东的直接诉权**，**无需前置程序**，**胜诉利益归股东自己**。

  > 营利法人的**控股出资人、实际控制人、董事、监事、高级管理人员**不得利用其**关联关系**损害法人的利益；利用关联关系造成法人损失的，**应当承担赔偿责任**。

  > 股东提起股东代表诉讼，被告以**行为发生时原告尚未成为公司股东**为由抗辩该股东不是适格原告的，人民法院不予支持。

- **九民纪要 第 25 条【正确适用前置程序】**（本地同文件 **第 129 行**）：

- **九民纪要 第 26 条【股东代表诉讼的反诉】**（本地同文件 **第 130 行**）：
  > 股东依据《公司法》第 151 条第 3 款的规定提起股东代表诉讼后，被告以**原告股东恶意起诉侵犯其合法权益**为由提起反诉的，人民法院**应予受理**。被告以**公司在案涉纠纷中应当承担侵权或者违约等责任**为由对公司提出的反诉，因不符合反诉的要件，人民法院应当**裁定不予受理**；已经受理的，裁定驳回起诉。

- **九民纪要 第 27 条【股东代表诉讼的调解】**（本地同文件 **第 131 行**）：
  > 公司是股东代表诉讼的**最终受益人**，为避免因原告股东与被告通过调解损害公司利益，人民法院应当**审查调解协议是否为公司的意思**。只有在调解协议经**公司股东（大）会、董事会决议通过**后，人民法院才能出具调解书予以确认。至于具体决议机关，取决于公司章程的规定；**公司章程没有规定的，人民法院应当认定公司股东（大）会为决议机关**。

## R-LN-054 司法介入法定代表人涤除登记的受理条件与执行路径

*类型：实务规则卡 ｜ 更新：2026-09-22T08:44*

**规则摘要**
> **"无实质关联"是核心前提，"穷尽内部救济"是程序要件，"无新法定代表人"并非绝对阻碍，"无逃债恶意"则是排除权利滥用的关键。**
> **法律为无实质关联的自然人松绑，不纵容公司以内部自治为由拖延变更登记；同时也绝不允许个人借涤除登记规避法定责任。**

**⭐ 四要素审查框架（法院的裁判公式）**：

| # | 要素 | 性质 | 举证方向 |
|---|---|---|---|
| ① | **无实质关联** | **核心前提**（实体） | 证明**不参与公司经营、与公司无实质利益关联** |
| ② | **穷尽内部救济** | **程序要件** | 证明**已行使公司法和章程赋予的全部权利仍无法变更** |
| ③ | **无新法定代表人** | ❌ **非阻碍** | 无需举证——**公司未确定新法定代表人不影响涤除** |
| ④ | **无逃债恶意** | **排除权利滥用**（实体） | 证明**离职/无决策参与**，涤除不会损害债权人、不影响公司正常经营 |

**一句话定性**：这是**"实体正当性 + 程序必要性"的双闸门**——**光有实体理由没走程序，法院不管；光走完程序但仍有实质关联，法院不判。**

**三种案件类型的胜诉预期（决定接不接、怎么接）**：

| 类型 | 特征 | 预期 |
|---|---|---|
| **挂名型** 🟢 | 基于劳动关系、亲友情谊应实控人请求挂名，**不参与经营决策** | **最易获支持**（离职后主张典型可诉） |
| **冒名型** 🟡 | 身份信息在**不知情、未授权**下被冒用 | **举证难**：须**笔迹鉴定 + 从未参与经营证明**；因注册验证（人脸识别、签字确认）趋严，**此类案件已较少见** |
| **规避执行型** 🔴 | 法定代表人**仍与公司有实质关联**（股东、实控人、核心管理人员），因被限高而主张涤除 | **一般驳回**——法院重点审查对象 |

**适用要点**
### ✅ 已核填（华宇元典 · 现行有效）

- **《中华人民共和国公司法（2023 修订）》第十条**（发布 2023-12-29，**施行 2024-07-01**，时效性：**现行有效**）：
  > 公司的法定代表人按照公司章程的规定，由**代表公司执行公司事务的董事或者经理**担任。
  > **担任法定代表人的董事或者经理辞任的，视为同时辞去法定代表人。**
  > **法定代表人辞任的，公司应当在法定代表人辞任之日起三十日内确定新的法定代表人。**

  📌 **第 2 款是 2023 修订新增**——**"辞任董事/经理 = 同时辞去法定代表人"**，无需另行作出辞去法定代表人的意思表示。**第 3 款的 30 日是公司的义务期间**，对应本卡第二步第 6 项的"继续履职"规则。

- **《中华人民共和国公司法（2023 修订）》第十一条**（**施行 2024-07-01**，**现行有效**）：
  > 法定代表人以公司名义从事的民事活动，其法律后果由公司承受。
  > 公司章程或者股东会对法定代表人职权的限制，**不得对抗善意相对人**。
  > 法定代表人因执行职务造成他人损害的，由公司承担民事责任。公司承担民事责任后，依照法律或者公司章程的规定，**可以向有过错的法定代表人追偿**。

  📌 **第 3 款解释了"为什么要涤除"**——法定代表人因执行职务致害的，**对外先由公司担责，但公司可向有过错者追偿**。挂名者**对外风险有限、对内风险仍在**，这是涤除诉讼的**利益驱动点**。

- **《中华人民共和国公司法（2023 修订）》第三十五条**（**施行 2024-07-01**，**现行有效**）：
  > 公司申请变更登记，应当向公司登记机关提交公司法定代表人签署的变更登记申请书、依法作出的变更决议或者决定等文件。
  > 公司变更登记事项涉及修改公司章程的，应当提交修改后的公司章程。
  > **公司变更法定代表人的，变更登记申请书由变更后的法定代表人签署。**

  ⚠️ **第 3 款是本卡第五步执行路径的关键障碍**——"**由变更后的法定代表人签署**"。**公司拒不配合又未确定新法人的，变更登记路径会卡死**，故诉请应**同时包含"涤除登记信息"**。

**关键体感矛盾**：UI 显示这些连接器 connected（因为 enabled=true 进了已连接列表），但一调用就 未连接 / 401 Bearer missing。——这正是"假连接"的招牌表现。

**适用要点**
> 本节是 2026-09-16 22:43 复盘的新结论：**即便 enabled=true 且已 UI 重连、且已彻底退出整个进程重开，连接器仍 discovery failed——根因已不在"批量清令牌"（R-LN-113 本职）、也不在"单点 OAuth 过期"（§四），而在 OAuth 握手层本地失败**。

**日志实证的死因（daemon.log，UTC 时间戳）**：
- [McpApps] discovery failed for connector:pkulaw: Unauthorized
- streamableHttp connect failed: OAuth loopback callback server is not started; sse connect failed: SSE error: Non-200 status code (405)

**与三兄弟的精确区分**：

| 维度 | R-LN-113 本职（批量清令牌） | §四 单点 OAuth 过期 | **本判（OAuth 握手失败）** |
|---|---|---|---|
| enabled | true（但无令牌） | true | **true（重连已写回）** |
| 重连效果 | UI 解绑重连写回令牌即活 | 重连刷新令牌即活 | **重连仍 Unauthorized（握手没成）** |
| 彻底重启 | 会话旧快照→重开可治 | 重开可治 | **重开无效（令牌仍无效）** |
| 日志关键词 | 无（只是无令牌） | 偶发 401 | **Unauthorized + OAuth loopback callback server is not started** |
| 真因 | 迁移批量剥令牌 | 令牌自然过期 | **本地 OAuth loopback 回调服务起不来 → 握手失败** |

**判定公式（速判·第四件）**：

connector-states.json 顶层三标志全 True（已确认迁移过）
  AND enabled=true（重连已写回）
  AND 多次 UI 重连 + 彻底退出重开整个进程仍 discovery failed: Unauthorized
  AND 日志含 "OAuth loopback callback server is not started"
  ⇒ OAuth 握手层失败（本地 loopback 或平台侧 OAuth 机制）
  ⇒ 处置：盯浏览器授权页是否弹出并回跳；没弹/弹了回不来=本地 loopback 问题
    （查 localhost 回调端口被占 / 防火墙 / 代理）；反复 Unauthorized=平台侧 OAuth 机制问题，
    把 Unauthorized + OAuth loopback callback server is not started 两行发 WorkBuddy 支持
  ⇒ 「解绑重连 / 彻底重启」对此类无效，勿反复重连白耗

**为什么重启治不了（修正铁律三的认知）**：
- R-LN-113 铁律三原写"开新对话 / 重启即可"——那只对**会话工具表旧快照**有效（框架没热加载新工具）。
- 本判是 **OAuth 令牌本身无效**（本地 loopback 回调没起，刷新机制失效），重开只重启框架、不重发 OAuth 握手，令牌依旧无效 → 仍 Unauthorized。两者根因不同、处置不同，勿混。

→ 与 R-LN-055（查不到 ≠ 断线）/ R-LN-059（此刻 ≠ 永远）/ R-LN-113（连接全绿 ≠ 令牌在）并列，构成**「连接器故障判定四件套」**，互补不重叠。
