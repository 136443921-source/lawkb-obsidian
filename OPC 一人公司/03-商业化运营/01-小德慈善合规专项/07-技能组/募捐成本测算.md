## 第零步 · 需求拷问前置门禁（grill-me-legal-preprocessor）

无年度数据（捐赠收入/总收入/总支出/净资产）、无组织类型、无是否持公募资格信息的请求，先过门禁。

- **触发**：只说"测算一下"而无具体数据。
- **越权红线**：门禁阶段不判断达标与否。

## 一、适用范围

✅ 适用：年度支出比例、管理费用比例、**募捐成本 3% 红线**的测算、达标判定、差异归因与整改建议；
年度合规自检、年检前体检、申请公募资格前的条件校验（第 5 条第五项）。

⛔ 不适用：具体数值的会计调整与账务处理（→ 税务/会计线）、刑事或行政处罚应对（→ 小强律师数字分身系统）。

## 二、铁律（本技能的第一原则）

> **所有数值必须实算。禁凭记忆、估算或"大概比例"直接落笔。**
> 依据：本地源引证铁律 —— 凡写入交付件的数值，须列明**公式、代入值、数据来源**。

执行方式：
```
python3 ~/.workbuddy/skills/小德慈善合规中枢/scripts/公募红线测算.py <子命令> <参数>
# 口径速查见 ~/.workbuddy/skills/小德慈善合规中枢/references/数值红线速查.md
```
三个子命令：`cost`（募捐成本 3% 上限）/ `public`（公募 70% 与 10%·13%）/ `nonpublic`（非公募净资产分档）。

## 三、法律依据与口径

| 事项 | 依据 / 口径 |
|---|---|
| 募捐成本上限 | **年度募捐成本不得高于前三年捐赠收入平均数的 3%** |
| 募捐成本范围 | 为开展募捐活动直接发生的场地设备、人员差旅、专业技术服务等必要费用；为获得捐赠财产而应计入当期费用的汇兑损失（减汇兑收益）等 |
| **不得计入募捐成本** | 募捐活动中涉及**本组织场地设备和工作人员**的相关费用 |
| 核算归集 | 在"**筹资费用**"项目下核算和归集，据实列支 |
| 共同费用分配 | 慈善活动、其他业务活动、管理活动、募捐活动共同发生且不能直接归属的，按合理方法分配 |
| 管理费用构成 | 办公费、水电费、邮电费、物业管理费、差旅费、折旧费、修理费、租赁费、无形资产摊销费、资产盘亏损失、因预计负债产生的损失、聘请中介机构费等 |
| 可支配项 | **监事会等监督机构的工作经费**和**党建工作经费**可从管理费用列支 |
| 支出下限（公募） | 基金会/社会团体/社会服务机构：年度慈善活动支出**不得低于上年总收入 70%** |
| 管理费上限（公募） | 基金会 **≤ 当年总支出 10%**；社会团体、社会服务机构 **≤ 13%** |
| 分档（非公募） | 基金会按净资产 6000 万/800 万/400 万分档（6%·12% … 8%·20%）；社会团体、社会服务机构 1000 万以上档 6%·13% |
| 支出计算口径 | **到达最终受益人的款物应当作为慈善活动支出**；慈善活动支出应当主要用于受益人 |
| 吊销当年 | 被依法吊销资格证书的当年，年度支出和管理费用**按具有公开募捐资格的标准执行**（第 23 条第 3 款） |

## 四、标准作业流程

### 步骤 1 · 取数（必须来自审计/财务报表，不采信口头）

必取四项：① 前三年捐赠收入（算 3% 用）；② 上年总收入；③ 当年总支出；④ 上年末净资产。
来源优先级：**上年度审计报告 > 财务报表 > 机构自报**，并在报告中标注来源。

### 步骤 2 · 定性（决定用哪套比例，判错则结论反向）

```
是否持有有效期内公开募捐资格证书？
   ├─ 是 → public 口径（70% / 10% 或 13%）
   ├─ 否 → nonpublic 口径（净资产分档）
   └─ 当年曾被依法吊销 → 仍按 public 口径（第 23 条第 3 款）
```

### 步骤 3 · 实算（跑脚本，不手算）

```bash
# 募捐成本上限
python3 .../公募红线测算.py cost --donations 2023 1200000 2024 1500000 2025 1800000

# 公募口径
python3 .../公募红线测算.py public --last-year-income 5000000 --total-expense 6000000 --type 基金会

# 非公募口径
python3 .../公募红线测算.py nonpublic --net-assets 5000000 --total-expense 4000000 --type 基金会
```

组织类型参数：`基金会` / `社会团体` / `社会服务机构`（只有 `基金会` 走 10%，其余走 13%）。

### 步骤 4 · 达标判定

| 指标 | 判定 |
|---|---|
| 年度募捐成本 | ≤ 3% 上限 → 达标；超出 → 红线，须整改 |
| 慈善活动支出 | ≥ 下限 → 达标；不足 → 须调节（注意"到达最终受益人的款物"口径） |
| 管理费用 | ≤ 上限 → 达标；超出 → 须压减 |

### 步骤 5 · 差异归因与整改建议

不达标时按序排查：
1. 是否**口径错配**（公募/非公募用混、基数取错年）
2. 是否把**本组织场地设备与工作人员费用**计入了募捐成本（须剔除）
3. 是否将共同费用**未按合理方法分摊**
4. 是否存在**超限营销、广告投放**（3% 红线的主要来源）
5. 是否向受益人及其利害关系人转嫁了募捐成本（第 10 条禁止）

### 步骤 6 · 出报告

结构：基本情况 → 数据来源 → 测算过程（公式+代入值+结果）→ 达标判定 → 差异归因 → 整改建议。

## 六、常见错误 / 反例（最高价值段 · 直接转风险提示）

1. ❌ **基数取错**：用"本年捐赠收入"而非"前三年平均数" → 结论可能反向
2. ❌ **口径混用**：把 70%/13% 套在非公募组织上，或把 6%/12% 套在公募组织上
3. ❌ **边界取错**：6000 万"含本数"、400 万"低于"与"高于"的临界值
4. ❌ **漏项**：只算慈善活动支出，忘算管理费用
5. ❌ **成本范围错**：把本组织场地设备与人员费用计入募捐成本 → 变相突破 3%
6. ❌ **遗漏吊销当年特殊规则**（第 23 条第 3 款按公募口径）
7. ❌ **忽略"到达最终受益人的款物应作为慈善活动支出"** → 支出下限口径算窄，误判不达标
8. ❌ **凭"行业惯例 5%–18% 管理费"作答** → 该口径已被 2026 年新规取代，属硬伤
9. ❌ **口头估算直接写进报告** → 违反数值实算铁律
