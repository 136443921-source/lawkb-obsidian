# 初中生 AI 学伴系统搭建方法论

> **一句话**：把"律师分身系统"证明有效的**设计原理**（不是功能，是原理）迁移到教育场景——学伴系统 = 学伴人格基座 + 教学质检闭环 + 学情飞轮 + 出题对抗 + 门禁教学法 + 学习节拍。

---

## 一、迁移总纲：三个可迁移的原理 + 三个必须改造的差异

### ✅ 三个可迁移的原理（律师系统已验证）

| # | 原理 | 律师系统的实证 | 迁移到学伴 |
|---|---|---|---|
| 1 | **人格基座统领一切** | 本体 + legal-base 基座，所有子技能继承人格与门禁（37 技能铁律） | 学伴人格 + 教育基座（统一教学原则，所有功能模块继承） |
| 2 | **质量闭环是护城河** | LTI 五维质检：正确引用 0 误报、错误量化可检出——"AI 输出可信" | 教学四检：答案必须"对、全、不剧透、不超纲"才可出——**孩子学到的不能是错的** |
| 3 | **飞轮让知识越用越多** | 六层飞轮：采集→提炼→连接→巩固→调用→沉淀（655 规则/211 卡） | 学情飞轮：错题→知识点→图谱→复习→讲题调用→学情沉淀 |

### ⚠️ 三个必须改造的差异（不能照搬）

| 差异 | 律师场景 | 学伴场景 | 改造要点 |
|---|---|---|---|
| 用户 | 成年律师（专业、抗压） | **未成年人**（需鼓励、防挫败、防沉迷） | 激励优先：阶梯目标、进步可视化、失败也记"努力点"；控制单次时长 |
| 内容 | 法律推理（多解、争议） | **教学知识（标准答案 + 教学法）** | 答案确定性优先；讲题走"提示升级阶梯"（先引导再揭晓），**不剧透是教学法铁律** |
| 参与者 | 老强单方使用 | **孩子 + 家长双角色** | 家长端：学情看板、质检复核、干预开关；孩子端：纯净学习界面 |

## 二、能力架构：律师八维 → 学伴八维

| 律师八维 | 学伴八维 | 核心能力 |
|---|---|---|
| 学（知识摄入） | **学** | 教材同步知识摄入（人教版，按学期/章节）；错题自动采集 |
| 写（文书起草） | **练** | 讲题辅导（分步引导）；同类题变式训练 |
| 辩（红蓝对抗） | **测** | 出题-解题对抗；单元自测；错题重测 |
| 管（案件全周期） | **管** | 学习计划（日/周/月）；目标管理；时间盒 |
| 检（质检防幻觉） | **检** | 教学四检：答案对错 / 步骤完整 / 是否剧透 / 是否超纲 |
| 控（程序门禁） | **控** | 教学门禁：先问孩子思路→给提示（阶梯）→再揭晓；不代答 |
| 合（合规非诉） | **合** | 家长端：学情报告、干预建议、使用监督（防沉迷/隐私） |
| 律（自动化节拍） | **励** | 激励反馈：进步曲线、成就徽章、错题清零庆祝 |

## 三、六大核心机制迁移（施工核心）

### 机制 1：人格基座（继承铁律 → 教学三不原则）
- **律师版**：所有法律技能 `extends: legal-base`（人格+门禁机械可检测）。
- **学伴版**：所有教学模块继承「教育基座」，内置**三不原则**：
  1. **不剧透**：先引导孩子自己想到，不直接给答案（提示按 3 级阶梯升级：思路提示→式子提示→答案）。
  2. **不超纲**：只用人教版当前学期已学知识点，超前内容明确标注"超纲，了解即可"。
  3. **不代答**：不替孩子写作业/作文，只辅导方法；家长端可一键开启"严格模式"。

### 机制 2：教学质检闭环（LTI → 教学四检）
- **律师版**：LTI 五维（法条真实性/逻辑/一致性/溯源/程序），R101 阻断、正确引用零误报。
- **学伴版**：「教学四检」门禁——所有讲题/答案解析输出前强制过检：
  1. **对错检**：答案与标准答案/教材核对（知识点库锚定，防 AI 幻觉）。
  2. **步骤检**：解题步骤完整、可复现（不能"答案对但过程跳步"）。
  3. **剧透检**：孩子未作答/未请求时，禁止先给答案。
  4. **超纲检**：涉及知识点是否在本学期教学范围内。
  - **四检不过 = 不输出**（类比 LTI REJECT），宁可让孩子等，不能让孩子学到错的。

### 机制 3：学情飞轮（知识飞轮六层 → 学情六层）
| 层 | 律师飞轮 | 学情飞轮 |
|---|---|---|
| 01 采集 | IMA 5库×3篇/日 | 错题/作业/测验采集（拍照或录入） |
| 02 提炼 | 经验卡/裁判规则 | 错题归因（概念不清/计算失误/审题粗心）→ 知识点标签 |
| 03 连接 | 概念页/图谱 | 知识点图谱（前驱后继关系：如"一元一次方程"前置"有理数运算"） |
| 04 巩固 | 间隔复习（1/2/4/7/15天） | **错题间隔重测**（同一遗忘曲线） |
| 05 调用 | 场景化推送（办案时调） | 讲题时自动调取该知识点历史错题/易错点 |
| 06 沉淀 | 规则库/经验卡 | 学情档案（薄弱点画像、进步曲线、学期报告） |

### 机制 4：出题-解题对抗（红蓝对抗 → 教与考互验）
- **律师版**：蓝队防御+红队攻击+模拟法庭。
- **学伴版**：
  - **AI 出题、孩子解题**：针对薄弱知识点出变式题（防"背题"）。
  - **孩子出题、AI 解题**：让孩子当"老师"出题考 AI，AI 故意在关键步骤出错→孩子找茬（**费曼学习法**，检测真懂还是假懂）。
  - **错题庭审**：每周"错题法庭"——孩子复述错题思路，AI 扮演"质疑者"逐条挑战，孩子辩护（对应律师庭审推演）。

### 机制 5：教学门禁体系（G0-G8 门禁 → 学习环节门禁）
- **律师版**：七道门禁（入案必检/出文必检/庭前推演…）。
- **学伴版**：
  - **讲题门禁**：孩子先说出自己的思路（哪怕错的）→ AI 才能介入（防"等着被喂答案"）。
  - **计划门禁**：AI 不代排全部计划，孩子参与制定（自主感→内驱力）。
  - **结项门禁**：错题未重测通过，不进入下一批新题（类比"未过机检不出文"）。

### 机制 6：学习节拍（自动化节拍 → 日/周/月）
- **律师版**：每日摄入 8:30、每周复习、每月蒸馏、监测守卫 23:30。
- **学伴版**：
  - **每日**：课后 10 分钟错题录入 + 1 题变式训练（AI 自动出）。
  - **每周**：错题法庭 + 周学情小结（进步/薄弱）。
  - **每月**：学情报告（家长端）+ 知识点图谱更新 + 下月计划。
  - **守卫**：学习时长/连续登录监控（防沉迷），超时自动"休息提醒"。

## 四、学伴系统专属设计（律师系统没有的部分）

1. **激励系统**：进步可视化（曲线/徽章/连续打卡），错题清零庆祝——孩子需要正向反馈，不能像律师一样"有错就批"。
2. **家长双端**：家长看"学情报告 + 质检记录 + 干预建议"；孩子看"学习界面"（纯净，无家长数据）。
3. **隐私与安全**：学情数据本地化（像律师案件卷宗一样管理）；AI 输出过质检才可见。
4. **学段对齐**：严格绑定人教版教材目录（每学期知识点清单=质检的"法条库"）。

## 五、实施路线（阶段化）

| 阶段 | 内容 | 里程碑 |
|---|---|---|
| **MVP（2-4 周）** | 教育基座 + 讲题辅导（三不原则+四检）+ 错题采集 | 孩子能用、家长能看、答案不剧透不超纲 |
| **完善（1-2 月）** | 学情飞轮（图谱+间隔重测）+ 出题对抗 + 学习节拍 | 薄弱点可追踪、错题闭环 |
| **闭环（季度）** | 月度学情报告 + 家长干预 + 激励系统 | 形成"学习→检测→沉淀→提升"自转 |

## 六、老强的独特优势（方法论之外的护城河）

1. **你是质检员**：律师复核文书的手艺，直接用来复核学伴输出——每周抽 3 道 AI 讲过的题检查"四检"是否守住（像 LTI 抽查一样）。
2. **你在用成熟系统**：学伴系统的每个机制，你都能在律师分身系统里找到"已跑通的原型"——遇到问题回看原型怎么解。
3. **知识管理基因**：你的飞轮/归档/台账习惯，天然适合"学情档案"管理。

---

## 七、方法论一句话总结

> **学伴系统不是"会讲题的 AI"，而是"有教学原则、有质量门禁、有知识积累、有学习节奏的学习分身"——人格基座管它怎么教，四检管它教得对，飞轮管它越用越懂孩子，节拍管它天天进步。这四点，正是小强律师分身系统跑通的真东西。**
