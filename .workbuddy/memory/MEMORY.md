## 🤖 大批量回补「主控—子代理」架构
三段式：① 主控脚本 HTTP 挖候选池（翻页+文件夹递归+三重去重）→ ② 主控分配 rule_id 产出 `选文清单.json` → ③ 每库一子代理并行蒸馏（取全文→采集笔记→规则卡）。
铁律：① 子代理看不到主控 `/tmp` → 作业文件落 LawKB 实体路径；② MCP 在子会话随机注入 → 子代理首步探活，探不到走 `_raw/<rule_id>.md` 兜底，≥3 篇 BLOCKED 即停摆回报主控；③ **取号双维度**（文件名 `find R-<域>-*.md | tail` + 全库 frontmatter `rule_id` 扫描，取较大者+1），分配后立即写回治理表与排期表；④ 回写幂等（dry-run→apply→复跑验证）；⑤ **未取到全文一律不写 ingested**。
**子代理报「本地库无源」≠ 真无源**：民法典条文一律先查本地 `法律法规库/通用实体法/中华人民共和国民法典（全文）.md`（4577 行，行首「第X条+全角空格」），查不到再花元典。

## 📖 本地民法典抽取（幂等用行号切块，勿用正则）
按行首条号切块（起于「第X条」止于下一「第X条」/文件尾），阿拉伯条号→中文数字（10-19「十X」、整十不加「零」），回填标 `（本地·...md:起止行号）`。正则 lookahead 对"锚点标题已删"卡会失效→重复插入。

3. **程序法 vs 实体法标题格式不同**：民诉法为 `**第XXX条**`（加粗+全角），民法典为「第X条」，工伤保险条例正文无独立条号行 → Grep 锚点须按文件实测，不可套用。
