## ⭐ 核心指令（用户明示，2026-07-23）

**「将所有存储知识投喂给知识飞轮系统，让飞轮系统根据系统提炼沉淀，赋能小强律师数字分身。」**

- **性质**：长期 standing directive，优先级高于一次性任务。
- **目标**：LawKB 内所有已存储的法律知识，应持续汇入「知识飞轮系统」六层架构，经 AI 提炼/沉淀后，反哺「小强律师数字分身系统」（lawyer-yourself-skill / 律师数字分身系统），提升其法律专业能力。
- **含义拆解**：
  1. **投喂源（"所有存储知识"）**：指 LawKB 工作区内全部法律知识库，至少覆盖：
     - `知识库/`（合同审查知识库、医法知识库、慈法知识库、问答知识库、职业认知、学习洞察）
     - `案例库/`、`法律法规库/`、`合同类法律文书/`、`人伤专业领域/`、`学习笔记/`、`案件管理/`、`贵州法院判例库/`
     - 原始/待整理区（`未整理文章/`、`Clippings/`、`笔记助手/`）需先做预处理再投喂
  2. **投喂目标**：`知识飞轮系统/` 六层架构（01-采集 / 02-提炼 / 03-体系 / 04-巩固 / 05-…/ 06-…）
  3. **机制**：飞轮系统按既有流程「提取关键知识点 → 理解并结构化 → 存储学习成果 → 提炼沉淀」；与每日摄入自动化子任务 A3（扫描 `知识库/`）同源，应拓宽至上述全部源。
  4. **赋能对象**：小强律师数字分身（法律专业特化数字分身），即通过飞轮沉淀的知识增强其合同审查、案件分析、法条解读、人伤法等领域能力。

- **执行约束**：
  - 投喂前须**去重**（检查知识飞轮系统内是否已存在同名/同主题笔记），避免重复沉淀。
  - 大规模投喂应**分批、可回滚**，先建映射再写入，禁止一次性全量盲写（防重复/覆盖）。
  - 与每日摄入自动化协同：子任务 A3 目前仅扫描 `知识库/`，本指令要求逐步扩展覆盖上列全部源。
