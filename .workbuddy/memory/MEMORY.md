# LawKB 知识飞轮系统 - 长期运行原则

## ⭐ 核心指令
投喂存储→知识飞轮→赋能小强律师数字分身。分批沉淀、投喂前去重、大批量分批+可回滚。

## 🔒 跨会话硬约束
1. 互链用 `[[文件名(不含.md)]]` 2. 个案卷宗禁投喂（仅通用模板/方法论）3. 思政中性沉淀不附政治解读 4. 慈善决策须引《贵州省厚德公益基金会合规管理手册（试行）（2025版）》具体条款 5. 法律问题先 lawyer-yourself-skill

## 🔴 门禁/校验脚本「扫描 0 张」= 警报，不是通过
看**扫描数**不看结论行；N=0 或远小于预期即判「未验证」；换口径复核（时间窗+全库各跑）；逐项审 `exclude`/`skip`/`!=` 目录清单；修完必须有**可解释跳变**才算生效。与否定型结论铁律同源：先自问「该指标能否证伪目标命题」，不能则无效。

## 🔴 状态字段「工具 absent」时标未实测，禁沿用历史值
余额/配额/连接状态类字段，工具不可用时一律标「未实测」并注明原因，不得用历史值冒充当期值；有机会即补实测并回写更正。元典余额≠元典可用性，须分开实测。

## 🧠 HOW-I-THINK 只读硬约束
`HOW-I-THINK.md` 是老强思维权重文件，**只有老强能批**。任何自动化/子代理只产出 diff 式建议稿+提醒审阅，不得以任何形式修改（含 frontmatter/变更日志/任何小节）。违反=越权改写用户思维权重。

## 🔌 通道故障处置
- **IMA**：配置态（enabled=false/不在索引）→ UI 重新信任/授权+重启；运行态掉线→等恢复不 --apply。恢复判定以 `get_knowledge_list` 实调成功（access_status:3）为准，优先于 connector-states.json 配置读数。IMA OpenAPI wiki v1 无取全文端点→取全文走 ima-mcp `fetch_media_content`。
- **元典 unauthorized**：查 `.credentials.v3.json` 的 `mcpOAuth.<conn>.expiresAt` 未过期则非 Key 失效而是头未注入；向 `~/.workbuddy/connectors/<id>/mcp.json` 注入 `headers:{"Authorization":"Bearer <Key>"}` 即生效。Key 明文不回显不落日志。
- **qcc-legal** 报 `MCP error 300008 当前积分余额不足`→整个通道不可用，充值 https://agent.qcc.com/ ；降级：元典+本地法条银行双通道，卡脚注声明「qcc 缺位」。

## 🆔 media_id 与 220030
格式 `wechatarticle_<32位用户ID>_<32位rawid><16位库ID>`（库ID直拼 rawid 后无分隔符）；rawid 必取全 32 位，8 位截断即 220030。**220030 终态**：内容侧持久损坏（端点健康但对照样本成功、目标全失败）→ 绝不写 ingested，登记 `failed_220030`（retry，幂等），窗口维持 open；须用户在 IMA 内「查看/重新处理」或等后端自愈后回补。排查须跑对照组。

## 🤖 大批量回补「主控—子代理」架构
三段式：① 主控 HTTP 挖候选池（翻页+文件夹递归+三重去重）→ ② 分配 rule_id 产出清单 → ③ 每库一子代理并行蒸馏。铁律：作业文件落 LawKB 实体路径（子代理看不到主控/tmp）；子代理首步探活，探不到走 `_raw/<rule_id>.md` 兜底（≥3 篇 BLOCKED 即停摆回报）；取号双维度（文件名 `find R-<域>-*.md|tail` + 全库 frontmatter `rule_id` 扫描，取较大者+1）；回写幂等（dry-run→apply→复跑）；未取到全文一律不写 ingested。民法典条文先查本地 `中华人民共和国民法典（全文）.md`（4577 行，行首「第X条+全角空格」）。

## 📖 本地民法典抽取
按行首条号切块（起「第X条」止下一「第X条」/文件尾），阿拉伯条号→中文数字（10-19「十X」、整十不加「零」），回填标 `（本地·...md:起止行号）`。勿用正则 lookahead（对"锚点标题已删"卡失效→重复插入）。

## 🚨 法条银行「版本陷阱」与「格式陷阱」
1. 回填前必看 frontmatter 的 `sxx`/`version_mismatch`/`version_note`：`工伤保险条例.md` 标 `sxx:⚠️版本存疑`+`version_mismatch:true`（现行 2010 修订/2011 施行，本地载 2004）→ 禁据以回填，改走元典。`sxx:待核验/版本存疑` 时走元典/qcc。
2. 条文行首可能带全角缩进（如 `　　（六）…`）→ grep/`^第十四条` 零命中但条文存在。**否定型铁律**：grep 零命中→仍不得断定「本地没有」→ 第三步查文件真实格式。禁据锚点零命中就断言缺失。
3. 程序法 vs 实体法标题格式不同：民诉法 `**第XXX条**`（加粗+全角），民法典「第X条」，工伤条例正文无独立条号行→ Grep 锚点须按文件实测，不可套用。

## 🏷️ 标签索引治理
`gen_tag_index.py` 整文件覆盖重写 `标签索引.md`（单源真相）→ 执行前强制六-B cp 备份（`.bak_<YYYYMMDD-HHMMSS>`，`ls -l` 比对字节数==源），异常秒回滚。脚本块级正则 `\s*` 可跨行贪婪匹配→产生空/纯数字标签「解析假象」；核对脏标签规模须逐行解析复核，不可直接采信脚本 dirty 统计。

## ⚖️ 法条时代校正 & 源可信度
- 司法解释须核元典 `sxx`+年份；民法典后条号重排（旧买卖解释18→622、15→623）；慈善法2023 用途变更 55→56；新旧条号双检索。
- 🔴 **程序法条号陷阱**：《民诉法(2023)》再审事由=§211（⑨剥夺辩论权/⑩未经传票缺席），§207=「申请实现担保物权」；实务文常引旧 §207。程序法条号必须查本地 `中华人民共和国民事诉讼法（2023）.md`（格式 `**第XXX条**`）；单通道（元典）不足以定条号。
- 本地程序法已收：民诉法2023（§137/176/177/211）、仲裁法、公司法2023；缺刑诉法/行政诉讼法/宪法→走元典。
- 公众号(mp.weixin.qq.com)转载法规禁条号级引用（只作线索，须 court.gov.cn/人民法院报/省级法院官方三方交叉核验）。
- 元典可查「尚未生效」新法（`validity_status:"尚未生效"`+`effective_date`）→ 卡必须加「不得提前援引未生效罚则」。元典不收录复函类/动态公告目录→标「待补源」，禁编造条文。

## 🔴 思维指纹蒸馏（HOW-I-THINK）关键防坑
- 决策卡结构解析须用 **Python 逐卡 regex**（shell `grep "③"` 在决策卡零命中的编码假阴性会误判）。
- 卡引用核验须走**双通道**（文件名变体：精确/去`决策卡-`前缀/去日期后缀/下划线日期 + `decision_id`/`id`/标题编号别名），只按文件名精确匹配会虚低覆盖率。
- **三层覆盖率口径**：① 真·证据引用（②区`- 证据：[[…]]`+⑤区反模式+③区价值观表）② 全文 `[[...]]` 命中（含文末自动反链+变更日志，虚高）③ 仅反链/变更日志（实质未蒸馏）。报覆盖率必须注明口径。
- **「同名不同义」陷阱**：本地民诉法标题格式为**阿拉伯数字** `**第238条**`，用中文数字「第二百三十八条」检索零命中→须先 Read 文件实测格式再检索。
- 镜像文档（frontmatter maturity/卡片 verdict）须随真源滚动刷新；建卡后 N 天未填「推理哪里错了」栏→提醒回填，批量回填=伪造。
