## 一、第1个月：庭审争点整理

### 1.1 核心目标
> 能够独立归纳案件核心争议点（自评 3分→5分）

### 1.2 每周执行计划

| 周次 | 核心任务 | 具体行动 | 交付成果 |
|------|---------|----------|---------|
| **第1周** | 学习裁判文书结构 | 精读3份民商事一审判决书，标注争点归纳部分 | 《判决书争点标注笔记》 |
| **第2周** | 提炼争点归纳方法 | 总结"法官如何归纳争点"的规律 | 《争点归纳方法1.0》 |
| **第3周** | 庭审观摩（真实案件） | 旁听2次真实庭审，记录法官提问焦点 | 《庭审观摩笔记》 |
| **第4周** | 导师一对一研讨 | 与李晓辉律师研讨1次，验证争点归纳方法 | 《导师反馈记录》 |

### 1.3 本周任务（第1周详细版）

**📋 本周学习目标**：掌握判决书争点结构

**📂 学习材料清单**：
1. 厚德基金会诉百益社工中心案（一审判决书）—— 正在办理的案件
2. 最高法指导性案例（民商事类）3份
3. 贵州法院典型案例（贵阳中院）3份

**📝 学习方法**：
```
每份判决书按以下结构拆解：
├─ 案件基本情况（当事人、案由）
├─ 原告诉称（核心主张）
├─ 被告辩称（核心抗辩）
├─ 法院归纳的争议焦点（⭐ 重点）
├─ 法院认定事实（证据采信）
├─ 法院适用法律（法条引用）
└─ 判决结果
```

## 二、第2个月：庭审辩论策略

### 2.1 核心目标
> 能够形成逻辑清晰的辩论框架（自评 1分→3分）

### 2.2 每周执行计划

| 周次 | 核心任务 | 具体行动 | 交付成果 |
|------|---------|----------|---------|
| **第5周** | 学习优秀代理词 | 研读5份资深律师代理词/辩论意见 | 《优秀文书摘录笔记》 |
| **第6周** | 撰写模拟辩论意见 | 针对真实案件，撰写2份辩论意见 | 《模拟辩论意见》×2 |
| **第7周** | 导师批改反馈 | 请李晓辉律师批改辩论意见 | 《批改反馈记录》 |
| **第8周** | 模拟法庭演练 | 参与所内模拟法庭1次，承担辩论环节 | 《模拟法庭复盘》 |

### 2.3 辩论框架模板（初步版）

```
## 庭审辩论框架模板

### 一、开场陈述（1-2分钟）
- 简要重申我方核心主张
- 明确本案争议焦点

### 二、事实辩论（证据环节）
- 对我方有利证据的强调
- 对方证据的"三性"质疑（真实性/合法性/关联性）

### 三、法律适用辩论
- 我方主张适用的法条及理由
- 对方适用法条的驳斥

### 四、价值权衡辩论（如有）
- 公平原则/诚信原则/公序良俗

### 五、总结陈述
- 重申核心观点
- 请求法院支持我方主张
```
