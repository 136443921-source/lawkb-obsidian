## 二、人伤领域核心法律知识总结

### （一）交通事故领域

#### 1. 主要法律依据

- **《道路交通安全法》**（2021年修正）
- **《道路交通安全法实施条例》**（2017年修订）
- **《最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释》**（2026年新修订，6月30日施行）
- **《机动车交通事故责任强制保险条例》**（2019年修订）

#### 2. 核心实务要点

**（1）事故现场处置**

- 立即抢救伤员、保护现场、报警（122）
- 拍照固定证据：全景、车辆位置、碰撞点、刹车痕、车牌
- 获取对方信息：驾驶证、行驶证、保险单、联系方式

**（2）责任认定与复核**

- 交警《事故认定书》是核心证据
- 不服认定：3日内向上一级公安机关申请复核
- 复核以一次为限

**（3）赔偿项目与计算**

| 赔偿项目 | 计算标准 | 注意事项 |
|---------|---------|---------|
| 医疗费 | 实际发生费用（凭票据） | 包括后续治疗费 |
| 误工费 | 误工时间×收入状况 | 有固定收入按实际减少计算 |
| 护理费 | 护理期×护工标准 | 护理期需鉴定或医嘱 |
| 交通费 | 实际发生费用 | 应与就医地点、时间、人数相符 |
| 住宿费 | 实际发生费用 | 外地治疗产生的合理费用 |
| 住院伙食补助费 | 当地国家机关一般工作人员出差伙食补助标准 | 通常50-100元/天 |
| 营养费 | 根据伤残情况参照医疗机构意见 | 需医嘱加强营养 |
| 残疾赔偿金 | 受诉法院所在地上一年度城镇居民人均可支配收入×20年×伤残系数 | 60岁以上每增1岁减1年，75岁以上按5年 |
| 残疾辅助器具费 | 普通适用器具的合理费用 | 需配置机构意见 |
| 丧葬费 | 受诉法院所在地上一年度职工月平均工资×6个月 | 固定标准 |
| 死亡赔偿金 | 受诉法院所在地上一年度城镇居民人均可支配收入×20年 | 同残疾赔偿金年龄调整规则 |
| 被扶养人生活费 | 城镇居民人均消费性支出×抚养年限÷扶养人数 | 累计不超过人均可支配收入 |
| 精神损害抚慰金 | 根据侵权情节、后果等因素确定 | 通常5000-100000元 |

**（4）保险理赔顺序**

1. 交强险优先赔付（医疗费用限额1.8万元、死亡伤残限额18万元、财产损失限额2000元）
2. 超出部分由商业三者险按责任比例赔付
3. 仍不足的由侵权人承担

**（5）2026年新司法解释重点**

- "开门杀"责任认定：驾驶人、乘车人均可能承担责任
- "好意同乘"减责规则：good will passenger 可减轻赔偿
- 替代性交通工具费用：合理费用可获赔偿

#### 3. 诉讼实务要点

- **起诉材料**：事故认定书、医疗费票据、误工证明、伤残鉴定书、保险单等
- **诉讼时效**：3年（自知道或应当知道权利被侵害时起算）
- **管辖法院**：事故发生地或被告住所地法院
- **伤残鉴定**：治疗终结后及时进行，过早过晚都不利

### （二）工伤工亡事故领域

#### 1. 主要法律依据

- **《[[工伤保险条例|工伤保险条例]]|工伤保险条例|工伤保险条例|工伤保险条例|工伤保险条例|工伤保险条例|工伤保险条例|工伤保险条例|工伤保险条例》**（2010年修订）
- **《工伤认定办法》**（2011年施行）
- **《劳动能力鉴定管理办法》**（2013年施行）
- **《关于执行〈工伤保险条例〉若干问题的意见》**（人社部发〔2013〕34号等）

#### 2. 核心实务要点

**（1）工伤认定情形**

**应当认定工伤**：
1. 在工作时间和工作场所内，因工作原因受到事故伤害
2. 工作时间前后在工作场所内，从事与工作有关的预备性或收尾性工作受到事故伤害
3. 在工作时间和工作场所内，因履行工作职责受到暴力等意外伤害
4. 患职业病
5. 因工外出期间，由于工作原因受到伤害或发生事故下落不明
6. 在上下班途中，受到非本人主要责任的交通事故或城市轨道交通、客运轮渡、火车事故伤害
7. 法律、行政法规规定应当认定为工伤的其他情形

**视同工伤**：
1. 在工作时间和工作岗位，突发疾病死亡或在48小时之内经抢救无效死亡
2. 在抢险救灾等维护国家利益、公共利益活动中受到伤害
3. 职工原在军队服役，因战、因公负伤致残，已取得革命伤残军人证，到用人单位后旧伤复发

**不得认定工伤或视同工伤**：
1. 故意犯罪
2. 醉酒或吸毒
3. 自残或自杀

**（2）工伤认定流程**

```
事故发生
    ↓
用人单位30日内申请（或劳动者1年内申请）
    ↓
社会保险行政部门受理
    ↓
调查核实
    ↓
作出工伤认定决定（60日内）
    ↓
送达双方
    ↓
不服可申请行政复议或提起行政诉讼
```

**（3）劳动能力鉴定**

- **鉴定时机**：伤情相对稳定后存在残疾、影响劳动能力的
- **鉴定等级**：1-10级，1级最重，10级最轻
- **鉴定内容**：劳动功能障碍程度 + 生活自理障碍程度
- **鉴定周期**：设区的市级劳动能力鉴定委员会，必要时可延长30日

**（4）工伤保险待遇计算**

| 待遇项目 | 支付主体 | 标准 |
|---------|---------|------|
| 医疗费 | 工伤保险基金 | 符合目录和标准 |
| 住院伙食补助费 | 工伤保险基金 | 统筹地区人民政府规定 |
| 交通、食宿费 | 工伤保险基金 | 统筹地区人民政府规定 |
| 康复费 | 工伤保险基金 | 符合规定 |
| 辅助器具费 | 工伤保险基金 | 因日常生活或就业需要，经鉴定确认 |
| 停工留薪期工资 | 用人单位 | 原工资福利待遇不变，不超过12个月 |
| 生活护理费 | 工伤保险基金 | 按生活自理障碍等级，统筹地区上年度职工月平均工资比例 |
| 一次性伤残补助金 | 工伤保险基金 | 按伤残等级，27-7个月工资 |
| 伤残津贴 | 工伤保险基金或用人单位 | 1-4级由基金支付，5-6级由单位支付（难以安排工作） |
| 一次性工伤医疗补助金 | 工伤保险基金 | 解除或终止劳动合同时支付，具体标准由省、自治区、直辖市人民政府规定 |
| 一次性伤残就业补助金 | 用人单位 | 解除或终止劳动合同时支付，具体标准由省、自治区、直辖市人民政府规定 |
| 丧葬补助金 | 工伤保险基金 | 6个月统筹地区上年度职工月平均工资 |
| 供养亲属抚恤金 | 工伤保险基金 | 按职工本人工资比例，配偶40%，其他亲属30% |
| 一次性工亡补助金 | 工伤保险基金 | 上一年度全国城镇居民人均可支配收入的20倍 |

**（5）实务难点**

- **劳动关系确认**：未签合同的，需先确认劳动关系（仲裁前置）
- **工伤认定超时**：用人单位未及时申请的，期间费用由用人单位承担
- **派遣工工伤**：劳务派遣期间，被派遣劳动者受伤的，派遣单位为申请主体
- **第三人侵权**：可同时主张工伤待遇和民事侵权赔偿（部分地区医疗费等实际支出项目不可双赔）

### （三）医疗事故/医疗损害责任领域

#### 1. 主要法律依据

- **《民法典》第七编第六章"医疗损害责任"**（第1218-1228条）
- **《医疗事故处理条例》**（2002年施行）
- **《最高人民法院关于审理医疗损害责任纠纷案件适用法律若干问题的解释》**（2020年修正）
- **《医疗损害司法鉴定指南》**（2021年）
- **《人体损伤致残程度分级》**（2017年施行）

#### 2. 核心实务要点

**（1）医疗损害责任归责原则**

- **一般情形**：过错责任（患者需证明医疗机构有过错）
- **例外情形**（推定医疗机构有过错）：
  1. 违反法律、行政法规、规章以及其他有关诊疗规范的规定
  2. 隐匿或者拒绝提供与纠纷有关的病历资料
  3. 遗失、伪造、篡改或者违法销毁病历资料

**（2）举证责任分配**

- **患者举证**：存在诊疗关系、损害后果、医疗过错、因果关系（通常通过鉴定完成）
- **医疗机构举证**：免责事由（如紧急情况下合理诊疗、患者过错等）

**（3）医疗鉴定**

**两种鉴定模式**：

| 鉴定类型 | 组织主体 | 适用情形 |
|---------|---------|---------|
| 医疗事故技术鉴定 | 医学会 | 行政处理、医疗事故争议 |
| 医疗损害司法鉴定 | 司法鉴定机构 | 诉讼案件、民事赔偿 |

**鉴定内容**：
1. 医疗机构是否存在过错
2. 过错与损害后果之间是否存在因果关系
3. 原因力大小（责任程度）

**过错参与度参考标准**：
- 完全责任：100%
- 主要责任：60%-90%
- 同等责任：40%-60%
- 次要责任：20%-40%
- 轻微责任：10%-20%
- 无责任：0%

**（4）病历的重要性**

- **病历是核心证据**：医疗纠纷中，病历是判断医疗机构是否存在过错的关键
- **病历瑕疵的法律后果**：
  - 伪造、篡改病历 → 推定过错
  - 病历书写不规范 → 可能影响鉴定甚至导致败诉
  - 未及时书写病历 → 可能被认定未尽注意义务

**（5）维权途径选择**

| 途径 | 优点 | 缺点 | 适用情形 |
|-----|------|------|---------|
| 协商 | 快速、成本低 | 赔偿可能不足 | 事实清楚、争议不大 |
| 医调委调解 | 专业、免费 | 无强制执行力 | 双方均有诚意 |
| 行政处理 | 可行政处罚 | 不直接解决赔偿 | 需追究医疗机构责任 |
| 诉讼 | 判决有强制力 | 周期长、成本高 | 争议大、赔偿额高 |

**（6）诉讼时效**

- **一般情形**：3年（知道或应当知道权利被侵害时起算）
- **特殊情况**：
  - 隐匿病历的，从发现或应当发现时起算
  - 体内遗留异物等，从取出或应当取出时起算
  - 最长保护期：自权利被侵害之日起20年

#### 3. 贵州省高院审理指引（黔高法〔2025〕237号）

- 强调病历封存、启封的程序规范
- 明确医疗损害鉴定的委托程序
- 统一过错责任程度的认定标准
- 规范多家医疗机构责任分担

### （四）人身损害（互殴）领域

#### 1. 主要法律依据

- **《民法典》侵权责任编**（第1164-1258条）
- **《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》**（2022年修正）
- **《人体损伤致残程度分级》**（2017年施行）

#### 2. 核心实务要点

**（1）侵权责任构成要件**

1. 违法行为
2. 损害事实
3. 因果关系
4. 主观过错

**（2）多人侵权责任分担**

- **共同侵权**：承担连带责任（二人以上共同实施）
- **教唆、帮助侵权**：与行为人承担连带责任
- **共同危险行为**：无法确定具体侵权人的，行为人承担连带责任
- **无意思联络的数人侵权**：
  - 原因力能够区分的，各自承担相应责任
  - 原因力无法区分的，平均承担责任

**（3）过失相抵规则**

- 被侵权人对损害发生也有过错的，可减轻侵权人责任
- 实务中常见于互殴案件：根据双方过错程度分担责任

**（4）赔偿项目**

与交通事故赔偿项目基本相同，但**不计算精神损害抚慰金**（互殴双方均有过错，通常不支持）

## 三、人伤案件通用实务技能

### （一）证据收集与固定

#### 1. 证据类型

| 证据类型 | 常见形式 | 注意事项 |
|---------|---------|---------|
| 书证 | 合同、票据、病历、鉴定意见 | 提交原件，复制件需核对 |
| 物证 | 受损物品、衣物等 | 妥善保管，防止灭失 |
| 视听资料 | 录音、录像、监控视频 | 保证真实性、完整性 |
| 证人证言 | 目击证人书面或口头证言 | 最好出庭作证 |
| 当事人陈述 | 当事人描述事发经过 | 结合其他证据审查 |
| 鉴定意见 | 伤残鉴定、三期鉴定、医疗过错鉴定 | 选择有资质的鉴定机构 |
| 勘验笔录 | 法院现场勘验记录 | 申请法院勘验 |

#### 2. 证据保全

- **诉前保全**：情况紧急的，可在起诉前申请证据保全
- **诉中保全**：起诉后申请法院调查取证
- **病历封存**：医疗纠纷中，及时封存病历（医患双方共同在场）

### （二）伤残鉴定实务

#### 1. 鉴定标准

- **《人体损伤致残程度分级》**（2017年1月1日起施行）
- 统一适用于人身损害致残程度等级鉴定
- 分为10个等级（1级最重，10级最轻）

#### 2. 鉴定时机

- **一般原则**：治疗终结、伤情稳定
- **具体时间**：
  - 组织器官损伤：治疗终结后
  - 功能障碍：治疗后效果稳定
  - 精神/智力障碍：通常6个月后
  - 骨折：通常3-6个月后（视愈合情况）

#### 3. 鉴定委托

- **双方共同委托**：成本低、速度快，但效力可能受质疑
- **法院委托**：诉讼中申请法院委托，效力强，但程序较长

### （三）三期鉴定（误工、护理、营养期）

#### 1. 鉴定依据

- **《人身损害误工期、护理期、营养期评定规范》**（GA/T 1193-2014）
- 公安机关鉴定标准，诉讼中可参考

#### 2. 实务意义

- **误工期**：确定误工费计算期限
- **护理期**：确定护理费计算期限
- **营养期**：确定营养费计算期限

### （四）法律文书撰写

#### 1. 常见文书类型

- 起诉状
- 证据清单
- 伤残鉴定申请书
- 调查取证申请书
- 财产保全申请书
- 代理词
