# 《人体损伤致残程度分级》学习笔记

**学习日期**：2026年6月19日（周四）  
**学习时间**：2小时  
**资料来源**：司法部《人体损伤致残程度分级》（2016年发布，2017年1月1日施行）  
**学习目标**：掌握伤残等级评定标准

---

## 一、概述

### （一）基本信息

| 项目 | 内容 |
|------|------|
| **标准名称** | 《人体损伤致残程度分级》 |
| **发布机关** | 最高人民法院、最高人民检察院、公安部、国家安全部、司法部 |
| **发布日期** | 2016年4月 |
| **施行日期** | 2017年1月1日 |
| **适用范围** | 人身损害致残程度等级鉴定 |

### （二）立法目的

进一步规范人体损伤致残程度鉴定，统一司法鉴定标准和司法实践。

---

## 二、核心概念

### （一）损伤

**定义**：各种因素造成的人体组织器官结构破坏和/或功能障碍。

**要点**：
- 包括结构破坏和功能障碍两个方面
- 可以是物理因素、化学因素、生物因素等造成

### （二）残疾

**定义**：人体组织器官结构破坏或者功能障碍，以及个体在现代临床医疗条件下难以恢复的生活、工作、社会活动能力不同程度的降低或者丧失。

**要点**：
- 强调"难以恢复"
- 包括能力降低和丧失两个层面
- 涵盖生活、工作、社会活动三个方面

---

## 三、致残程度等级划分

### （一）等级设置

| 等级 | 致残率 | 程度描述 |
|------|--------|---------|
| **一级** | 100% | 人体致残率最高，极重度残疾 |
| **二级** | 90% | 重度残疾 |
| **三级** | 80% | 重度残疾 |
| **四级** | 70% | 中度残疾 |
| **五级** | 60% | 中度残疾 |
| **六级** | 50% | 中度残疾 |
| **七级** | 40% | 轻度残疾 |
| **八级** | 30% | 轻度残疾 |
| **九级** | 20% | 轻度残疾 |
| **十级** | 10% | 轻度残疾 |

**要点**：
- 共10个等级
- 每级致残率相差10%
- 等级划分依据见附录A

### （二）各等级核心致残情形（摘要）

#### 1. 一级致残（极重度）

- 颅脑脊髓损伤致持续性植物生存状态
- 日常生活完全不能自理
- 三肢以上缺失/功能严重丧失
- 器官移植术后伴严重功能障碍

#### 2. 十级致残（轻度）

- 颅脑、脊髓及周围神经损伤：轻度智力缺损或精神障碍，日常生活有关的活动能力轻度受限
- 头面部损伤：一眼低视力1级，一侧眼睑下垂或畸形
- 脊柱损伤：颈椎或腰椎畸形愈台，颈部或腰部活动度丧失10%以上
- 体表损伤：皮肤损伤致瘢痕形成达体表面积4%以上

**注**：具体分级条款详见标准正文5.2-5.10章节。

## 四、判定原则

### （一）鉴定基础

**原则**：以损伤治疗后果或者结局为依据，客观评价组织器官缺失和/或功能障碍程度，科学分析损伤与残疾之间的因果关系，实事求是地进行鉴定。

**要点**：
1. **依据治疗后果**：不是依据损伤当时情况
2. **客观评价**：组织器官缺失 + 功能障碍程度
3. **因果关系**：科学分析损伤与残疾之间的关系
4. **实事求是**：不夸大、不缩小

### （二）多处致残处理

**规则**：受伤人员符合两处以上致残程度等级者，鉴定意见中应该分别写明各处的致残程度等级。

**示例**：
- 左眼失明（八级）
- 右腿骨折（十级）
- 鉴定意见：八级伤残、十级伤残

### （三）鉴定时机

**要求**：应在原发性损伤及其与之确有关联的并发症治疗终结或者临床治疗效果稳定后进行鉴定。

**要点**：
- 治疗终结后
- 临床治疗效果稳定后
- 不能过早鉴定（以免后果未稳定）

### （四）伤病关系处理

**分析顺序**：
1. 损伤与原有伤、病共存时
2. 先分析损伤与残疾后果之间的因果关系
3. 按作用力大小依次表述为：
   - 完全作用
   - 主要作用
   - 同等作用
   - 次要作用
   - 轻微作用
   - 没有作用

**处理规则**：
- 除损伤"没有作用"以外，均应按照实际残情鉴定致残程度等级
- 同时说明损伤与残疾后果之间的因果关系
- 判定损伤"没有作用"的，不应进行致残程度鉴定

---

## 五、判定依据

**综合以下因素判定致残程度等级**：

### （一）人体组织器官结构破坏、功能障碍程度

**要点**：
- 结构破坏：器官缺失、缺损、畸形
- 功能障碍：器官功能降低或丧失

### （二）损伤对医疗、护理的依赖程度

**要点**：
- 医疗依赖：是否需要长期服药、治疗
- 护理依赖：是否需要他人护理（完全护理依赖、大部分护理依赖、部分护理依赖）

### （三）残疾引起的社会交往和心理因素影响

**要点**：
- 社会交往：是否能正常社交
- 心理因素：是否有心理障碍（抑郁、焦虑等）

---

## 六、附则要点

### （一）未列情形处理

**规则**：遇有标准致残程度分级系列中未列入的致残情形，可根据残疾的实际情况，依据标准附录A的规定，并比照最相似等级的条款，确定其致残程度等级。

**要点**：
- 附录A是等级划分依据
- 可以比照最相似等级条款
- 需要说明理由

### （二）重复鉴定禁止

**规则**：同一部位和性质的残疾，不应采用标准条款两条以上或者同一条款两次以上进行鉴定。

**要点**：
- 避免重复评价
- 同一残疾只能用一条条款

### （三）重要术语定义

| 术语 | 定义 |
|------|------|
| **四肢大关节** | 肩、肘、腕、髋、膝、踝等六大关节 |
| **牙齿折断** | 冠折1/2以上，或者牙齿部分缺失致牙髓腔暴露 |
| **四肢重要神经** | 臂丛及其分支神经（正中神经、尺神经、桡神经和肌皮神经等）和腰骶丛及其分支神经（坐骨神经、腓总神经和胫神经等） |
| **四肢重要血管** | 与四肢重要神经伴行的同名动、静脉 |

### （四）特殊情形鉴定规则

#### 1. 移植、再植或者再造成活组织器官的损伤

**规则**：根据实际后遗功能障碍程度参照相应分级条款进行鉴定。

**示例**：
- 断手再植成功后，手功能部分丧失
- 按实际功能障碍程度评定伤残等级

#### 2. 永久性植入式假体损坏

**规则**：永久性植入式假体（如颅骨修补材料、种植牙、人工支架等）损坏引起的功能障碍，可参照相应分级条款进行鉴定。

**示例**：
- 颅骨修补材料损坏
- 种植牙损坏
- 人工支架损坏

### （五）其他说明

| 事项 | 规则 |
|------|------|
| **精神分裂症等内源性疾病** | 不是外界致伤因素直接作用所致，不宜作为致残程度等级鉴定的依据，但应对外界致伤因素与疾病之间的因果关系进行说明 |
| **未成年人** | 指年龄未满18周岁者 |
| **面部瘢痕测量** | 0～6周岁者按标准规定值50%计，7～14周岁者按80%计 |
| **数量、部位规定** | 注明"以上"、"以下"者，均包含本数（有特别说明的除外） |

## 七、学习心得与实务要点

### （一）学习心得

1. **标准体系**：《人体损伤致残程度分级》是人身损害案件的核心技术标准的核心
2. **等级划分**：10级伤残等级，每级相差10%，需要熟记各等级核心情形
3. **判定原则**：以治疗后果为依据，科学分析因果关系
4. **判定依据**：结构破坏 + 功能障碍 + 医疗护理依赖 + 心理社会影响

### （二）实务要点

#### 1. 伤残鉴定时机选择

**问题**：何时申请伤残鉴定？

**答案**：
- 治疗终结后
- 临床治疗效果稳定后
- 一般是受伤后3-6个月（根据伤情而定）

#### 2. 多处伤残的处理

**问题**：多处伤残如何计算赔偿？

**答案**：
- 鉴定意见分别写明各处的致残程度等级
- 赔偿时按最高等级 + 附加指数计算
- 具体计算方法见《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》

#### 3. 伤病关系处理

**问题**：原有疾病对伤残评定的影响？

**答案**：
- 分析损伤与残疾后果之间的因果关系
- 按作用力大小表述
- 损伤有作用的，按实际残情鉴定

#### 4. 未成年人特殊规则

**问题**：未成年人伤残评定有何特殊？

**答案**：
- 面部瘢痕测量：0～6周岁按50%计，7～14周岁按80%计
- 需要考虑生长发育因素
