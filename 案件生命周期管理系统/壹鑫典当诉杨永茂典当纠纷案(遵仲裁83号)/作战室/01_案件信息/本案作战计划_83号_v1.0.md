## 四、WBS 工作分解（按双线）

### X 线（保房 / 执行对抗）
- X1 执行程序应对（核实是否已立案执行、执行标的）
- X2 执行和解方案起草（以"已实付 27 万≈清偿完毕 + 多付抵销"为谈判基线）
- X3 唯一住房保障申请（若进入拍卖，主张唯一住房）
- X4 代偿过户三步流程（代偿 → 法院账户过账 → 赠与过户，严禁私下回流）
- X5 董洪平助攻（离婚协议 2024-01-25 使其无份额无债务，隔离其责任）

### Y 线（追多付 / 权利追索）
- Y1 《代偿确认书》+ 债权让与（G2，P0）
- Y2 结算金额异议函发出（要求重新核算 / 退还多收 18,056.82 / 确认 27 万即清偿完毕）
- Y3 诉前财产保全申请（股权/账户，抢优先顺位窗口）
- Y4 三条穿透路径成文：
  - 路径 A：直追四股东（张修利/吕飞/张雪梅/飞宏）
  - 路径 B：双利（张修利独资一人公司）→ 财产混同推定（公司法 23-3，举证责任倒置）
  - 路径 C：双利 2000 万认缴未实缴 → 出资加速到期（公司法 54 条）
- Y5 债权人撤销权（民法典 538/539/541，针对可撤销行为）
- Y6 穿透补证四项（G5）：双利实缴状态 / 资金来源 / 1079.21 万负债构成 / 三关联方被执行失信记录

### 跨线
- Z1 核定裁决书送达日期（迟延利息起算，影响最终对账）
- Z2 收据现金 3 万置信度核实（微信/转账凭证齐备性）
- Z3 壹鑫银行账户与当物清单诉前调取
