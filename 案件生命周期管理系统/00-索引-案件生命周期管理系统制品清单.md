## 🎯 子系统定位（案件全程驾驶舱 · 手册对应「本地资料子树 / 08-案件库」）

**生命周期六阶段**（每阶段对应子系统与铁律）：

| 阶段 | 动作 | 路由子系统 / 铁律 |
| --- | --- | --- |
| ① 受理 / 分案 | 入案回填、案号与当事人实地核实 | G0 门禁 · 入案先回填 |
| ② 事实核查 / 证据 | 跨案模式识别、证据 A/B/C 分级 | 跨案模式识别 · 「强佐证」vs「坐实」 |
| ③ 文书起草 / 审查 | 起诉状 / 答辩状 / 合同 / 非诉文书 | 合同文书 L0（诉讼 route-out）/ 小德 G8（非诉合规） |
| ④ 庭审推演 | 红蓝对抗可视化推演 | 模拟法庭子系统（座舱·影子模式） |
| ⑤ 裁判 / 执行 | 判决拆解、执行异议、再审辩护 | 判决书拆解 / 执行异议工作法 |
| ⑥ 复盘沉淀 | 蒸馏进 HOW-I-THINK、经验卡回流 | 决策思维系统 · 知识飞轮 |
