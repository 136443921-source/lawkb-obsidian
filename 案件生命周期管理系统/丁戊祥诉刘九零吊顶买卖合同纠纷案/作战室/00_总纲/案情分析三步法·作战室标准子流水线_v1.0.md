# 案情分析三步法 · 作战室标准子流水线 v1.0

> **来源**：律师实务文章《律师三步吃透新案法》＋本作战室既有 F 系统 / 开卷综述 / 红蓝对抗 提炼
> **适用**：所有新收 / 新接案件的开卷阅卷阶段（stage 1–2）
> **落位**：各案 `作战室/00_总纲/`（本卡为通用标准，复制至各案作战室即可复用）
> **关联 case-state 节点**：`G_open`（见 case-state.json `openThreeSteps` 字段）
> **生效**：2026-10-28

---

## 一、定位与效力

- 本卡定义「开卷三步」标准子流水线，作为 case-state 的 **G_open 节点**执行规程。
- 与既有体系映射：

| 三步法概念 | 本作战室既有对应物 |
|---|---|
| 第一步·事实时间线 | 案件笔记 **事实编号 F 系统**（F7│事实陈述│材料出处│印证情况│冲突标记│证明状态四档） |
| 第二步·争议焦点 | `03_法律研究` 争议焦点分析 ＋ 类案卡族 LC-001~013 |
| 第三步·一页大事记 | 开卷综述（内部版）＋ 脱敏分级（案件目录内实名 / 中枢只留方法论 / 公开甲乙丙） |
| 反向喂料（红队预判） | **红蓝对抗系统**（红队攻击＝对方视角布防） |

- **冲突仲裁**：与 case-state(L0) / 全局铁律冲突 → 以 L0 / 铁律为准，当场向老强报告冲突，不得自行取舍。

## 二、三步流水线（标准动作）

### 第一步：事实时间线（搭底座）

- **目标**：按时间顺序梳理所有案件事实，建分析底座。
- **提示词要点**：要求 AI 通读材料，每条含「日期 / 事件 / 主体 / 证据出处」；单独列「存疑清单」；**禁止推测，只用材料记载**。
- **产物**：`01_案件信息/事实编号表_MD`（F 编号五要素 ＋ 证明状态四档）。
- **适用**：材料体量大的建工 / 合伙 / 多方借贷案件；30 页以下小案可跳至第二步。
- **铁律联动**：F 系统禁推测；E1004 三层验证（当事人意思 / 授权类肯定结论）。

### 第二步：争议焦点提炼（定主攻）

- **目标**：确定主攻方向，提炼案件核心争议。
- **提示词要点**：基于时间线 ＋ 诉状，列明每个焦点的「争点 / 双方主张 / 请求权基础·抗辩 / 关键证据与缺口」，按裁判影响排序。
- **产物**：`03_法律研究/争议焦点表_MD` ＋ 类案卡族引用。
- **适用**：所有诉讼案件，尤其多焦点 / 竞合 / 本反诉交织案。

### 第三步：一页案件大事记（开卷即能用）

- **目标**：生成汇报级摘要，开卷即能用。
- **提示词要点**：综合前两步，输出「基本信息 / 时间线精编 / 焦点清单 / 证据缺口 / 程序节点 / 待办」，语言兼顾非法律背景客户。
- **产物**：`03_法律研究/开卷综述_MD`（内部版，含证据缺口与风险提示）。
- **适用**：带团队律师 / 需高频向客户汇报者；独立小案可省略。
- ⚠️ **外发纪律**：内部版含证据缺口 / 风险提示，**外发前须重制客户版**（仅保留进展事实 ＋ 下一步安排），严禁直接转发客户。

## 三、进阶与减法策略

- **反向喂料（红队预判）**：应诉案件（被告立场）将对方起诉状 ＋ 证据喂给 AI，指令「假设你是原告代理人，梳理事实和诉求支撑点」，从而预判对方逻辑、变猜测为布防。→ 落位 `03_法律研究/红队视角推演_MD`，与红蓝对抗系统同源（prompt 模板见同目录 `6658红队视角推演_prompt模板_v1.0.md`）。
- **减法版**：小额速裁 / 调解案只跑第一步；老律师带团队时，初级律师跑三步产出大事记，主办律师仅复核一页纸 → 实现流程托底。

---

## 四、三条铁律（与作战室红线同频）

1. **AI 不碰证明力**：案情分析阶段 AI 只摆事实，不判断「这条证据能否证明那个事实」——证明状态四档由老强 / 主办认定。
2. **存疑 ≠ 虚构**：存疑清单是线索而非结论，必须调原始材料核实，不可直接当事实用于客户对质或代理意见。
3. **脱敏纪律（新增「脱敏预检」门禁）**：当事人姓名 / 证件号 / 银行卡进 AI 前必须处理；建议在 AI ingestion 前加**显式预检勾选**（是否已打码），避免实习律师直接把原卷丢给 AI。

## 五、翻车预警 ↔ 既有红线对照（验证）

| 文章翻车点 | 本作战室对应红线 |
|---|---|
| 材料不齐就开跑（AI 自行填补缺失） | 铁律7 实地核实 ＋ 案件目录先核清点 ＋ F 系统禁推测 |
| 存疑清单当事实 | E1004 三层 ＋ 证明状态「存疑」档（丁戊祥授权案已踩过） |
| 大事记直接转发客户 | 脱敏分级（内部版含证据缺口 / 风险提示，外发须重制客户版） |

> ✅ **结论**：文章翻车预警与本作战室红线高度重合——三步法不是「补课」，而是从外部印证了红蓝对抗 ＋ F 系统 ＋ 脱敏分级的设计方向正确。

## 六、验收与团队落地

- **验收方法**：用已办结旧案完整跑三步，对照当年阅卷笔录，找出 AI 漏事实 / 排错顺序 / 漏焦点的地方，将经验补入提示词 → 让输出越来越贴合个人办案风格。
- **团队 SOP**：实习 / 初级律师负责跑三步初稿，主办律师复核定稿。AI 承担「第一遍阅卷」的机械工作，律师省下时间聚焦核心判断。

- **G_open 未过不得进 G1 检索门禁**；开卷综述未经老强确认不得作为后续文书事实基线。
