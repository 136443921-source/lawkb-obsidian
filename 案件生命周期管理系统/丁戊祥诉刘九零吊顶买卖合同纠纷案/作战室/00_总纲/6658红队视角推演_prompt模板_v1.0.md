## 二、核心 Prompt（直接复制使用，按需替换 `[ ]` 占位）

### Prompt A：假设你是原告代理人

```
你现在是（2026）黔0330民初6658号案【原告：丁戊祥、习水县锦绣明天装饰材料经营部】的代理律师。
已知一审我方（原告）败诉：法院驳回对被告刘九零、刘维的全部付款诉请，仅判黄茂姣、欧派店付尾款 2855 元。

请基于以下材料，站在原告 / 上诉人的立场，梳理：
1. 我方（原告）一审的诉讼请求与事实主张；
2. 一审判决驳回对刘九零、刘维诉请的核心理由（法院认定的合同相对性、黄茂姣实际买受人）；
3. 我方可上诉的争点（哪些事实 / 法律认定最可能被翻盘）；
4. 我方二审应重点攻击的证据缺口与法律漏洞；
5. 我方上诉状的逻辑主线与请求权基础。

材料（已脱敏，仅列要点）：
- 起诉状主张：刘九零、刘维为合同相对方，应连带付吊顶货款；
- 关键事实：2026-07-14 / 08-24 刘维与丁戊祥通话录音（证据⑦⑧）；08-19 丁戊祥《情况说明》自认黄茂姣带客选货付订金；08-24 法官电话询问丁戊祥（证据⑨）；
- 一审认定：合同相对性 ＋ 黄茂姣实际买受人，刘九零 / 刘维脱责。

要求：
- 仅基于材料，禁止虚构；
- 列「我方最脆弱点」与「最可攻击点」两栏；
- 最后给出蓝队（被告方）应重点布防的三条。
```

### Prompt B：红队攻击弹药清单（蓝队布防用）

```
基于上方原告代理人视角的梳理，请切换为【被告刘九零、刘维的代理律师（蓝队）】，
针对原告可能的二审攻击点，逐条给出布防证据与反驳逻辑：
- 每个原告攻击点 → 对应我方证据（引用证据编号⑦⑧⑨ 及一审判决书段落）→ 反驳法条（民法典合同相对性相关条文，须带生效版本与条号）→ 预期法官采信度。
输出「红队攻击点 ｜ 蓝队布防证据 ｜ 反驳法条 ｜ 采信预判」四列表。
```

## 三、使用纪律（铁律）

- ⚠️ **脱敏**：prompt 中当事人姓名保留（案件目录内实名允许），但证件号 / 银行卡 / 手机须打码；**绝不将原始案卷整本丢给公网模型**，走本地 / 受控通道（与 `案情分析三步法` 脱敏预检门禁联动）。
- ⚠️ **红队输出仅作布防推演**，**不得直接作为对外文书事实基线**；布防结论须老强复核。
- **E1004 联动**：涉及「丁戊祥授权 / 意思」类结论，走三层验证，禁写「已确认」（丁戊祥庭前四否认 vs 庭上确认授权 → 只能写「存疑」）。
