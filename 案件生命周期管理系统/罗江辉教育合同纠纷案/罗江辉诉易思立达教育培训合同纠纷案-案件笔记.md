# 案件笔记：罗江辉诉易思立达教育培训合同纠纷案

> 真实承办案件（承办：老强 实习律师）。依据 (2026)黔0103民初□□□□号（案号待核实） 民事判决书（2026-05 判决）。

## 一、案件要素
- **案由**：教育培训合同纠纷（预付式消费）
- **我方身份**：原告 — 罗江辉
- **对方当事人**：被告1 贵阳市云岩区易思立达培训学校；被告2 贵州茂楠教育咨询有限公司
- **审理法院**：贵阳市云岩区人民法院，案号 (2026)黔0103民初□□□□号（案号待核实）
- **诉讼标的**：剩余课时费 ¥7,083.00 + 资金占用损失（LPR）
- **处理结果**：**部分胜诉** — 合同解除 + 退费7,083元 + LPR利息均获支持；被告2连带责任被驳回；利息起算日由主张的2025-03-01调整为起诉之日

## 二、胜败诉要点
- **成功策略**：① 精准适用《预付式消费解释》第18条，提前算好折扣单价（7,830÷260=30.12元/课时），被告主张原价但举证不能 → 按折扣价判；② 闭店通知+未复课+无复课时间表三重事实锁死"合同目的不能实现"=根本违约（《民法典》第563条+解释第13条）；③ 课时数举证：原告提供微信/课程记录，被告有异议但拿不出自己的课程记录 → 举证妨碍规则认定174课时。
- **失败教训**：① 被告2连带责任证据链过浅（仅"代出具收据"，缺银行流水/人员混同/财务混同）；代理词写了"法院调取银行流水"但判决显示原告未取得该证据 → 代理词与证据脱节（信誉风险）；② 利息起算日主张2025-03-01但无《解除通知》送达证据 → 法院改为起诉之日，暴露证据保全意识不足。

## 三、可复用知识
- 预付式消费三件套：付款凭证 + 剩余课时证据 + 经营者违约证据（闭店通知）。
- 退费按折扣价计算（解释第18条）；经营者主张原价未举证 → 举证不能。
- 所有法律行为（解除通知、催告函）的送达环节必须保留书面凭证。
- 追加被告前先做证据可行性评估，避免证据链仅到"代收据"一层。
