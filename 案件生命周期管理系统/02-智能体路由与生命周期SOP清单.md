## 三、从接案到结案 SOP 清单（七阶段 + G0–G8）

> 每阶段：关键动作 → 门禁（不过不往前走）→ 路由智能体 → 产出物。

### ① 接案建档（G0）— 撰写案情笔录（案件备忘录）
- **关键动作**：利益冲突审查、收案审批表、委托代理合同、**撰写案情笔录（案件备忘录）**、建档（初始化 case-state.json）
- **门禁 G0**：利益冲突通过 + 审批表完成 + 合同签署 + 已建档
- **路由智能体**：收案暂无专门 agent（人工 + checklist）；建档由 CLM `case-state.json` 承载；重大决策用 `decision-capture` 留痕
- **产出**：案情笔录（案件备忘录）+ case-state.json（阶段1，G0 待过）

### ② 检索研究（G1·pkulaw／元典／北大法宝）— 完成接案三件套（案情笔录 + 法律检索报告 + 类案检索报告）
- **关键动作**：法律检索报告（元典 + 北大法宝 **二源互补**，含相反观点 + 本地口径 + 风险）、类案检索报告（元典 case vector + 北大法宝 + 法随案例库 **三源互补**）、检索结论归档
- **门禁 G1**：法律检索报告已出 + 类案检索报告已出 + 结论已归档 → **接案三件套齐备**
- **路由智能体**：北大法宝 MCP（pkulaw）+ 元典 MCP（yuandian-mcp）+ 法随案例库 MCP；归档用 `ima` 知识库
- **产出**：法律检索报告、类案检索报告（与①案情笔录合成**接案三件套**）

### ③ 法律文书起草（庭审六件套 · G2）— docx交付 + LTI
- **关键动作**：**庭审六件套**起草 + 红蓝复核、证据目录/质证
- **门禁 G2**：文书经蓝队+红队复核通过 + 证据目录齐备 + 质证齐备
- **路由智能体**：`法律文书docx交付流水线` + `LTI`；证据整理用 `ima` 存证
- **产出**：庭审六件套（docx 修订版 + 清洁签字版双轨）

### ④ 庭审查庭 - 模拟法庭系统（G3）— mock-trial + 审判要件卡
- **关键动作**：庭前准备清单、模拟法庭推演、庭审记录、庭后复盘
- **门禁 G3**：庭前清单通过 + 庭审记录已生成 + 复盘已写
- **路由智能体**：`mock-trial-control-center` + 本会话专家 `mock-trial-simulator` + `审判要件卡拆卡流水线`
- **产出**：庭审预案、庭后复盘

### ⑤ 客户协作（G4）— 汇报 + 微信/邮件推送
- **关键动作**：客户会议纪要、材料清单、五段式工作汇报、对外进度推送
- **门禁 G4**：会议纪要已存 + 材料清单已交付 + 工作汇报已发
- **路由智能体**：`案件全生命周期·案件工作汇报` skill + `案件全生命周期·调解和解方案` skill；对外推送用 CLM `send_client_brief` + `agent-mail`
- **产出**：工作汇报、当事人进度页/简报

### ⑥ 程序执行（G5）— 程序推进包
- **关键动作**：立案 / 保全 / 送达 / 期限四项核验
- **门禁 G5**：四项全过才放行（签收日 = 期限起算）
- **路由智能体**：`案件全生命周期·程序推进包` skill（已建）
- **产出**：程序节点登记（回写 case-state.json deadlines）

### ⑦ 风控归档（G6 / G8）— LTI + 合规
- **关键动作**：对外文书 LTI 防火墙、文件校对、非诉合规门禁 G8、结案
- **门禁 G6 + G8**：所有对外文书过 LTI（REJECT=0）+ 非诉交付物过 G8（合规体检 + 留痕 + 经验卡）
- **路由智能体**：`LTI 文本监控器`；`lawkb-legal-consistency-audit` 增强 G6；G8 非诉专项（小德慈善/医院合规）
- **产出**：终稿、合规留痕

### 结案回流（G7）— mind-distill + 飞轮
- **关键动作**：经验卡片 → 提炼 → 模板优化 → 检查点迭代
- **门禁 G7**：归档 + 提炼 + 模板优化 + 检查点迭代 + 回流登记
- **路由智能体**：`mind-distill` + LawKB 飞轮（06-沉淀）+ 编排器 SOP 检查点回写
- **产出**：经验卡、SOP/门禁迭代
