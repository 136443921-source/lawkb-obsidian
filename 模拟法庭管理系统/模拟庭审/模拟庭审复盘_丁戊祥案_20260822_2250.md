本案已从"实体攻防"升级为"**起诉合法性总闸战**"——被告方要的不是在合同相对性上赢，而是在**程序上终结案件**。模拟价值：
1. 预演对方（黄茂姣/律师阵营）最可能的**三种反扑招数**及击破路径；
2. 校验我方证据链（签名写错/无公章/本人否认/红章自认/授权委托书）在对抗压力下是否闭合；
3. 明确**临场最大变量**（丁戊祥是否到庭、是否反悔）及应对预案。

## 四、临场最大变量与预案

1. **丁戊祥不到庭**：程序战推进受阻 → 坚持笔迹鉴定+调取授权委托书；实体战同步备位；
2. **丁戊祥到庭但反悔**（称"起诉是我授意的"）：立即出示《未起诉说明》原件+现场照，申请法官当庭询问"为何此前书面否认、何时改变主意、授权何人起诉"——**当场对质**；
3. **丁戊祥到庭确认未起诉**：程序战当场锁定，请求当庭裁定驳回起诉+审查冒名诉讼；
4. **法官倾向"补正继续审理"**：立即切换实体战（合同相对性+买受人黄茂姣+金额矛盾），并继续保留追责后手。

## 五、风险提示（执业层面）

1. **与丁戊祥的接触合规**：所有取证（书写说明、拍照、补签）须有见证人/录音，防被反指"诱导伪证"（《刑法》306条/《律师法》40⑤）；
2. **笔迹鉴定周期**：耗时数月，程序战节奏需与法院排期配合，勿孤注一掷等鉴定；
3. **刑事控告审慎**：虚假诉讼罪有认定门槛，作为威慑牌而非必胜牌（民诉法115条+刑法307条之一）；
4. **勿在庭审中过度主张**：避免"必然虚假诉讼"等绝对化表述，用"恳请审查"留余地（10号异议书已规范）。

## 六、可复用方法论：冒名诉讼庭审攻防清单（沉淀）

**识别四查**：无公章 / 本人否认 / 签名与登记姓名不符 / 幕后利害关系人操控
**证据三件套**：本人书面说明+现场照 / 盖章自认书证 / 登记信息（身份证+营业执照）
**庭审三请求**：通知到庭核实 / 笔迹鉴定（起诉状+授权委托书一并）/ 调取委托材料查实际委托人
**反扑三应对**：笔误补正→"前提是本人所签" / 授权真实→"签名真实≠授权起诉+查委托人" / 诱导伪证→"见证人+录音+现场照"
