## 一、胜诉概率评估

| 维度 | 概率 | 依据 |
|---|---|---|
| 实体抗辩（驳回诉请） | 约 80% | 告错主体 + 自认货款结清证据链完整，类案规则 R1/R2 支撑 |
| 程序异议（裁定驳回起诉） | 约 30% | 原告系供货商、与交易有关联，主体资格审查存在不确定性 |
| 费用转嫁（诉讼费由原告负担） | 约 75% | 原告败诉时依《诉讼费用交纳办法》第二十九条自然转嫁 |
| 恶意诉讼另案索赔 | 约 45% | 需另案认定"恶意"（明知无据仍诉），证据链已较完整 |

| 路径 | 评分 | 建议 |

## 三、论证薄弱点（3 项）

1. **订货单签名性质**：验收 vs 合意，仍系胜负手——须当庭强制核对原件，必要时申请笔迹/形成时间鉴定辅助；
2. **自认的诉讼外属性**：法院可能不认定诉讼自认，须以"主动交付被告保存+签署照片+门店电话锁定"补强"明知"；
3. **恶意定性未被采纳**：模拟裁决未认定滥用诉权——本诉应聚焦"驳回诉请+费用转嫁"，恶意追偿另案推进。

## 四、红队攻击点清单（4 项）及应对

| 攻击点 | 应对 |
|---|---|
| A 诉讼外自认不当然构成诉讼自认 | 强调证据9系原告亲笔签署并主动交付被告保存，属高证明力书证（证据规定第3条精神+诚信原则），即使非诉讼自认亦可作为认定事实依据 |
| B "黄茂姣已付"系代付、不消灭被告义务 | 自认内容明确"定金谁支付的：黄茂姣付的""尾款（黄茂姣已付）"，指向真实买受人付款结清；"代付"无证据，系推测 |
| C 署名"焦聪鹏"与"焦联鹏"主体同一存疑 | 签署照片+门店（五洲国际 B2-1-8）+电话（18785239010）锁定同一经营体，可申请身份核对 |
| D 订货单客户栏签名=买卖合意 | 签收系受黄茂姣指示的验收行为；微信"窗帘谈好5000那我喊他下单"证明缔约主体为黄茂姣 |

## 五、下一步策略建议

1. **本诉收口**：主打"驳回诉请+费用转嫁"（实体），程序异议（裁定驳回起诉）保留切换；
2. **当庭必做**：证据9原件+签署照片当庭出示，强调"原告亲笔、拍照、主动交被告刘维保存"；申请当庭核对订货单原件签名；
3. **联动线**：与吊顶案（6658）联动——两案起诉状联系电话相同（15285201499）、住所同片区，若吊顶案丁戊祥否认起诉成立，可交叉引用强化窗帘案起诉真实性存疑；
4. **追偿线**：本诉胜诉后另案提起恶意诉讼损害赔偿之诉（参照吊顶案 17_恶意诉讼赔偿起诉状），收集律师费发票、差旅凭证、误工证明固定损失。
