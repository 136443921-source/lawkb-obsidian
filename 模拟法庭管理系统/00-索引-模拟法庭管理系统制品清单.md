## 🗂️ 归档约定（2026-09-06 确立）
> **一句话**：凡「模拟法庭管理系统」产出的所有文本（含**模拟法庭三件套：判决书 + 庭审笔录 + 庭审预案报告**，及推演纪要 / 战情室分析 / 推演态势 JSON），**全部存入 `LawKB/模拟法庭管理系统`**，按 **「案件 + 案号」建夹**归拢。

- **夹命名规则**：`（案号）案件名`，如 `（2026）黔0330民初6658号 丁戊祥诉刘九零吊顶买卖合同纠纷`
- **三件套落位**：
  - `模拟庭审判决书` → `模拟法庭/<案号案名>/`
  - `模拟庭审笔录` → `模拟法庭/<案号案名>/`
  - `庭审预案报告` → `模拟法庭/<案号案名>/`
  - 推演纪要 / 战情室 / 推演态势 JSON 等同夹归档
- **历史文件**：2026-08 批次为扁平命名（`丁茂祥案_…_20260823.md`），新案自 6658 起一律改「案号案名」夹式，旧文件暂不搬迁。
