# 判例摘要投喂 · LC-002~LC-009 全量（→ 6658 法官智能体）

> 来源卡族：`06-沉淀/类案检索报告卡族/LC-002~009`
> 用途：为 6658 模拟法庭「冒名诉讼程序战 + 合同相对性防御」红蓝对抗提供正向裁判规则与类案锚点；LC-005~009 同系争点亦喂 雅菲案6660（合同相对性/货款已清/滥用诉权）。

## 一、冒名起诉·程序战类（被告方有利，→ 31号代理词）

- **LC-002 （2024）辽72民初109号**：原告限期内未确认起诉状/授权委托书签名系本人所签 → 无法确认诉讼请求为真实意思表示 → 驳回。援引 民诉法122条3项。
- **LC-003 （2025）京0111民初3288号**：起诉书及授权委托书签名均非原告本人（系配偶代签），原告一级伤残限制/无行为能力，仅"点头眨眼" → 不能认定真实起诉意思 → 驳回。援引 民诉法157条1款3项。本案以"起诉条件瑕疵"程序驳回，未升格虚假诉讼刑事，与 6658 口径一致（慎用"虚假诉讼"刑事定性）。
- **LC-004 （2021）湘3101民初5382号**：起诉状原告名称与营业执照不符 + 授权委托书委托人名称与印章不符 → 不具备原告起诉条件 → 驳回。援引 民诉法119条1款1项/154条1款3项/解释208条3款。

**正向裁判规则（喂法官智能体）**：
1. 诉讼行为须基于当事人真实意思表示；签名/授权真实性是起诉合法先决要件。
2. 法院可主动审查并裁定驳回，无需原告事后追认；冒名起诉不适用无权代理追认。
3. 与 6658 映射：丁茂祥（身份证 522132197804302816）↔ 丁戊祥（营业执照 92520330MACJE5T94X，第14位为5）姓名不一致 + 授权意思自始未作出（民法典143条）→ 同源"起诉意思表示真实"要件缺失。

## 二、合同相对性·包工包料业主不担责类（→ 雅菲案6660 + 6658 合同相对性防御）

- **LC-005 （2025）赣07民终5351号**：彭某将装修包工包料发包曾某，材料由曾某采购并签收，销售单客户签字为曾某 → 彭某（业主）非合同相对人，不担责；上诉人以"实际受益人"主张连带被驳回。援引 民法典626条 + 民诉法177条1款1项。
- **LC-006 （2022）浙07民终1245号**：舒子旺房屋包工包料给孙祝平，结算单由孙祝平出具 → 舒子旺（业主）非相对人；"业主未付清工程款"抗辩与出卖人无关可另诉。援引 合同相对性 + 民诉法177条1款1项。
- **LC-007 （2022）湘0721民初1928号**：承揽人曹建福签"代购人"仍为直接买受人担责，高双清（业主/发包人）不担责；无代理事实 + 自主采购 → 签名人系买受人。援引 合同法130/159条 + 买卖合同解释1条1款。

**正向裁判规则**：包工包料下，材料买卖合同相对人为施工方/实际采购人；业主非买受人即不担责；"实际受益人""业主参与选购""业主未付清工程款"均不构成业主付款责任。映射：黄茂姣为实际采购买受人，刘九零/刘维（业主）非买卖相对人。

## 三、选样签字定性类（业主选样/签收 ≠ 付款义务）

- **LC-008 （2025）赣0730民初2913号**：业主李某红带承包方选材料、代付定金，法院认定"业主自选"仅系选材决定权，材料款计入包工包料总价，付款主体为承包方温某春，驳回对业主诉请。援引 民法典509/579/626条。
- **LC-009 （2017）浙0212民初376号**：项目经理高宏方在送货单签字系履职行为不担责，买方/付款人为承包方方东。援引 合同法130/159/161条。

**正向裁判规则**：业主"选样/代付部分/签收"不等于承担付款义务；签字仅证明收货/选样事实，非付款合意。封堵原告以"被告在销售单签字"推定刘九零/刘维为买受人的举证逻辑。

## 四、对抗提示（红蓝）

- 🔵 被告（刘九零/刘维）：程序战用 LC-002/003/004 封堵"庭后补授权/追认"；实体防御用 LC-005~009 锁定合同相对性，黄茂姣为实际买受人。
- 🔴 原告可能主张"姓名笔误""业主受益应担责""被告签收即买受"，须以 LC-004（姓名不一致≠笔误）、LC-005/007（受益/签收≠责任）、LC-008/009（选样/履职≠付款）逐条反制。
