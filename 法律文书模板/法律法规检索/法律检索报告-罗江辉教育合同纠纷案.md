——罗江辉诉易思立达培训学校、茂楠教育咨询有限公司教育培训合同纠纷案
## 一、检索目的

就原告罗江辉与被告1贵阳市云岩区易思立达培训学校（以下简称"易思立达"）、被告2贵州茂楠教育咨询有限公司（以下简称"茂楠教育"）之间的教育培训合同纠纷，进行系统法律检索，查明以下问题：

1. 被告1单方中止绘画课程是否构成**根本违约**，原告是否有权**解除合同并要求全额退费**
2. 原告主张按**LPR计算逾期退费的资金占用损失**是否有法律依据
3. 被告2出具收据/代收费行为是否应与被告1承担**连带责任**
4. **格式条款**（如有"概不退款"等）对原告的影响
5. 其他对本案有利的法律依据和判例支撑

### （二）司法解释

#### 3.《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》（法释〔2025〕4号，2025年5月1日起施行，现行有效）

> ⚠ **特别提示**：本解释于2025年5月1日起施行，原告于2024年11月主张退费。根据"法不溯及既往"原则，本案事实发生于施行前，但根据司法实践，司法解释适用于一审尚未审结的案件。**建议在起诉状中援引本解释作为裁判说理的参照依据。**

| 条款 | 内容 | 与本案关联 |
|------|------|-----------|
| **第1条**（适用范围） | 在零售、住宿、餐饮、健身、出行、理发、美容、**培训**、养老、旅游等生活消费领域，经营者收取预付款后多次或者持续向消费者兑付商品或者提供服务产生的纠纷适用本解释。 | ✅ **明确将培训领域纳入适用范围**。 |
| **第4条**（名义经营者责任） | 经营者允许他人使用其营业执照或者以其他方式允许他人使用其名义与消费者订立预付式消费合同，消费者请求经营者承担民事责任，经营者以其并非实际经营者为由提出抗辩的，人民法院对其抗辩不予支持。 | ⚠ 对被告2的分析：被告2（茂楠教育）是否同意被告1使用其名义出具收据，是关键事实认定问题。如果可以证明被告2允许被告1使用其公章出具收据，则被告2应承担相应民事责任。 |
| **第5条**（特许方责任） | 同一品牌商业特许经营体系内...特许人对消费者损失产生或者扩大有过错，消费者请求特许人根据其过错承担民事责任的，人民法院应予支持。 | ⚠ 如被告1与被告2存在品牌特许或合作关系，被告2可能承担过错责任。 |
| **第7条**（经营者清算义务） | 经营者收取预付款后因经营困难不能按照合同约定兑付商品或者提供服务的，应当及时依法清算。经营者依法应当清算但未及时进行清算，造成消费者损失，消费者请求经营者的清算义务人依法承担民事责任的，人民法院应予支持。 | ✅ 被告1闭店停课且未依法清算，其清算义务人（法定代表人高文秀）可能需承担民事责任。 |
| **第9条**（格式条款无效） | 消费者主张经营者提供的下列格式条款无效，人民法院应予支持：（一）**排除消费者依法解除合同或者请求返还预付款的权利**；（二）不合理地限制消费者转让预付式消费合同债权；（三）约定消费者遗失记名预付卡后不补办；（四）约定经营者有权单方变更兑付商品或者提供服务的价款、种类、质量、数量等合同实质性内容；...（七）其他排除或者限制消费者权利、减轻或者免除经营者责任、加重消费者责任等对消费者不公平、不合理情形。 | ✅ 如被告1的闭店通知或收据中有"概不退款"等条款，依法无效。 |
| **第13条**（消费者单方解除权） | 消费者请求解除预付式消费合同，经营者存在下列情形之一的，人民法院应予支持：...（三）**承诺在合同约定期限内提供不限次数服务却不能正常提供**；（四）法律规定或者合同约定消费者享有解除合同权利的其他情形。 | ✅ **核心条款**。被告1闭店无法继续提供课程服务，原告有权单方解除合同。 |
| **第15条**（剩余预付款返还） | 预付式消费合同解除、无效、被撤销或者确定不发生效力，消费者请求经营者**返还剩余预付款并支付利息**的，人民法院应予支持。返还预付款本金应为预付款扣减已兑付商品或者提供服务的价款后的余额。 | ✅ **核心条款**。明确支持返还剩余预付款并支付利息。 |
| **第16条**（利息计算标准） | 当事人对返还预付款利息计付标准有约定的，按照约定处理。没有约定或者约定不明：因**经营者原因**返还预付款的，按照预付式消费合同成立时**一年期贷款市场报价利率（LPR）** 计算利息。 | ✅ **核心条款**。因被告1闭店原因（经营者原因）退费，LPR利息计算有明确依据。 |
| **第17条**（利息起算时间） | 预付式消费合同解除、无效、被撤销或者确定不发生效力，消费者请求返还预付款的，自合同解除、被确认无效、被撤销或者确定不发生效力时起计算利息。当事人就返还预付款利息起算时间作出对消费者更有利的约定或者法律另有规定的，按照当事人约定或者法律规定处理。 | ✅ 原告主张自**2025年3月1日**（被告1发出闭店通知、原告要求退费之日）起算LPR利息，该起算时间合理。 |
| **第18条**（非因消费者原因退款计算） | 非因消费者原因返还预付款的，人民法院按下列方式计算已兑付商品或者提供服务的价款：（一）经营者向消费者提供折扣商品或者服务的，**按折扣价**计算已兑付商品或者提供服务的价款；（二）经营者向消费者赠送消费金额的，根据消费者实付金额与实付金额加赠送金额之比计算优惠比例，按优惠比例计算已兑付商品或者提供服务的价款。 | ✅ **有利条款**。因被告1闭店（非消费者原因），退费应按折扣价/优惠比例计算，有利于原告。 |
| **第23条**（惩罚性赔偿） | 经营者收取预付款后**终止营业，既不按照约定兑付商品或者提供服务又恶意逃避消费者申请退款**，消费者请求经营者承担**惩罚性赔偿责任**的，人民法院依法予以支持。经营者行为涉嫌刑事犯罪的，人民法院应当将犯罪线索移送公安机关。 | ⚠ 如果被告1在闭店后**恶意逃避退款**（如拉黑原告等），可主张惩罚性赔偿（退一赔三）。需关注被告1是否有转移资产、恶意逃避债务等行为。 |
| **第25条**（举证责任倒置） | **经营者控制合同文本或者记录消费内容、消费次数、消费金额、预付款余额等信息的证据**，无正当理由拒不提交，消费者主张该证据的内容不利于经营者的，人民法院可以根据消费者的主张认定争议事实。 | ✅ **有利条款**。被告1控制课时记录等证据，如拒不提交，法院可采信原告主张。 |

### （三）部门规章

#### 4.《教育部等六部门关于加强校外培训机构预收费监管工作的通知》（教监管函〔2021〕2号，现行有效）

> 要求校外培训机构预收学费应全额纳入监管账户，严禁诱导学员使用培训贷方式缴纳费用。培训机构预收费用须全部进入培训机构专用账户，不得使用本机构其他账户或非本机构账户收取培训费用。

✅ **本案事实关联**：被告1要求原告通过其工作人员提供的个人账户（支付宝/微信）缴费，违反了上述规定。该违规行为可作为法官内心确信的辅助论据。

#### 5.《国务院办公厅关于规范校外培训机构发展的意见》（国办发〔2018〕80号）

> 严格规范校外培训机构收费行为，收费时段与教学安排应协调一致，不得一次性收取时间跨度超过3个月的费用。

⚠ 如被告1一次性收取的课时费超过3个月的费用期限，违反上述规定。

## 五、结论与建议

### （一）对本案有利的法律依据

| 序号  | 有利依据                   | 理由                                             |
| --- | ---------------------- | ---------------------------------------------- |
| 1   | **《民法典》第563条**         | 被告1闭店停课，以自己的行为表明不履行主要债务，合同目的无法实现，**原告有权解除合同**  |
| 2   | **《消费者权益保护法》第53条**     | 经营者以预收款方式提供服务，未按约定提供的，**应当退回预付款并承担利息**——直接适用条款 |
| 3   | **《预付式消费解释》第1条**       | 明确将**培训领域**纳入解释适用范围                            |
| 4   | **《预付式消费解释》第13条第（三）项** | 承诺提供服务却不能正常提供——**消费者有权单方解除合同**                 |
| 5   | **《预付式消费解释》第15条**      | 解除合同后，经营者应**返还剩余预付款并支付利息**                     |
| 6   | **《预付式消费解释》第16条**      | 因经营者原因退费，按**LPR**计算利息——原告主张有明确依据               |
| 7   | **《预付式消费解释》第18条**      | 非消费者原因退费，**按折扣价计算**，有利于原告                      |
| 8   | **《预付式消费解释》第9条**       | 如存在"概不退款"格式条款，**依法无效**                         |
| 9   | **《预付式消费解释》第25条**      | 经营者拒不提交消费记录的，**法院可采信消费者主张**                    |
| 10  | **判例支持**               | 培训机构闭店退费案已有大量支持消费者诉求的判例                        |

### （二）对本案不利的法律依据/风险提示

| 序号 | 不利因素 | 风险分析与应对策略 |
|------|---------|------------------|
| 1 | **被告2连带责任认定存在不确定性** | 根据济南槐荫区法院的裁判规则，关联公司代收款项"≠必然承担连带责任"。**应对策略**：原告应重点举证被告2长期为被告1出具收据、代收学费，而非临时性协助；核查被告1与被告2之间是否存在账户混同、财务混同的情形；申请法院调取被告1与被告2的银行流水，查证款项往来情况。 |
| 2 | **无书面合同，事实合同关系的证明** | 虽无书面合同，但有缴费记录（微信/支付宝转账）、课程服务记录（174剩余课时）、闭店通知等辅助证明。**证据建议**：收集所有4次转账记录截图、收据原件/扫描件、与工作人员的微信聊天记录、闭店通知图片，形成完整的证据链条。 |
| 3 | **《预付式消费解释》施行时间** | 本解释于2025年5月1日施行，原告退费纠纷发生在2024年11月。但根据司法实践，司法解释适用于一审尚未审结的案件，**建议在起诉状中援引本解释作为裁判说理依据**。 |

### （三）初步诉讼策略

#### 核心论证逻辑

```
大前提（法规依据）：
《消费者权益保护法》第53条 + 《民法典》第563条 + 《预付式消费解释》第13条/第15条
→ 经营者以预收款方式提供服务，未按约定提供的，消费者有权解除合同并要求退还预付款及利息

小前提（案件事实）：
被告1（易思立达）收取原告预付款 ¥7,083.00
→ 被告1发布闭店通知中止绘画课程
→ 剩余174课时未上

结论：
被告1构成根本违约 → 原告有权解除合同 → 被告1应退还未消费课时费 + LPR利息
被告2（茂楠教育）长期为被告1出具收据、代收费 → 主张连带责任（需进一步举证）
```
