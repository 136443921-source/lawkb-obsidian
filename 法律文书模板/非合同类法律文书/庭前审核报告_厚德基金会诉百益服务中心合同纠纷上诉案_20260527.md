## 四、庭审策略优化建议

### 4.1 核心争议焦点应对

#### 焦点1：本案是否应"先刑后民"？

**对方可能主张**：
> "李丽、李佳豪涉嫌刑事犯罪，本案应中止审理，等待刑事程序结果"

**我方应对策略**（优化后）：
```markdown
# 法庭辩论阶段陈述（优化版）
"审判长，我方认为本案**不应**中止审理，理由如下：

**第一，法律依据**：
根据《民法典》第153条："民事法律行为无效、被撤销或者确定不发生效力后，行为人因该行为取得的财产，应当予以返还。"本案为合同纠纷，属于民事纠纷，与李丽、李佳豪是否涉嫌刑事犯罪属于**不同法律关系**。

根据最高人民法院《关于审理民间借贷案件适用法律若干问题的规定》第6条："人民法院立案后，发现民间借贷行为本身涉嫌非法集资等犯罪的，应当裁定驳回起诉，并将涉嫌非法集资等犯罪的线索、材料移送公安或者检察机关。"但本案中，**我方起诉的是合同纠纷，而非借贷纠纷**，不适用该规定。

**第二，事实依据**：
（2025）黔0325民初230号之一民事裁定书中，一审法院已认定："本案须以另一案的审理结果为依据，而另一案尚未审结。"但经我方核实，**不存在"另一案"**，一审法院裁定驳回起诉属于**认定事实错误**。

**第三，最高人民法院判例支持**：
最高人民法院（2025）民再164号裁定明确："经济犯罪案件除外情形：如果民事案件的处理**不依赖于**刑事案件的结果，且刑事案件尚未立案或审理期限过长，民事案件可以继续审理。"本案中，我方请求的是合同解除+资金返还，与李丽、李佳豪是否涉嫌刑事犯罪**无直接关联**，本案应继续审理。"

**法官可能追问及应对**：
Q1："如果李丽、李佳豪构成犯罪，刑事案件判决退赔，你方是否还能主张民事赔偿？"
A1："可以。根据《最高人民法院关于适用〈中华人民共和国刑事诉讼法〉的解释》第176条："被告人非法占有、处置被害人财产的，应当依法予以追缴或者责令退赔。被害人提起附带民事诉讼的，人民法院不予受理。"但本案中，我方主张的是**合同解除后的返还财产**，而非刑事退赔，两者不冲突。"

Q2："你方是否已向公安机关报案？"
A2："已报案（证据材料4-1：报案回执），但公安机关尚未立案。根据《公安机关办理刑事案件程序规定》第175条："公安机关接受案件后，经审查，认为有犯罪事实需要追究刑事责任，且属于自己管辖的，经县级以上公安机关负责人批准，予以立案。"本案中，公安机关是否在法定期限内立案**不影响**本案民事审理。"
```

#### 焦点2：百益服务中心是否构成根本违约？

**对方可能主张**：
> "'乐龄食堂'项目已启动，不存在根本违约"

**我方应对策略**（优化后）：
```markdown
# 法庭调查阶段陈述（事实陈述）
"审判长，我方主张百益服务中心**构成根本违约**，事实如下：

**第一，合同约定**：
2023年9月15日《合作协议》第3条："乙方（百益服务中心）应在收到甲方（厚德基金会）50万元捐款后30日内启动"乐龄食堂"项目。"第5条："项目实施周期为6个月（2023年10月15日至2024年4月14日）。"

**第二，对方违约事实**：
1. 资金到位时间：2023年9月20日（证据2-1：银行转账凭证）
2. 项目启动期限：2023年10月20日前
3. 实际状态：截至2024年1月10日（我方书面通知解除合同日），"乐龄食堂"项目**未启动**（证据3-1：项目现场照片）
4. 资金去向：50万元被转入李丽个人账户（证据2-2：百益服务中心记账凭证）

**第三，法律依据**：
根据《民法典》第563条第1款第4项："当事人一方迟延履行债务或者有其他违约行为致使不能实现合同目的，当事人可以解除合同。"本案中，百益服务中心未按约启动项目，且资金被挪用，导致合同目的（设立"乐龄食堂"）**无法实现**，我方依法享有法定解除权。"

**法官可能追问及应对**：
Q1："你方如何证明项目未启动？"
A1："我方提供了项目现场照片（证据3-1），照片显示截至2024年1月10日，项目地点仍为荒地，无任何施工迹象。同时，我方申请法院现场勘验，进一步核实项目状态。"

Q2："对方可能主张'项目已启动，只是进度缓慢'，你方如何反驳？"
A2："根据《合作协议》第3条，对方应在30日内**启动**项目，而非'缓慢推进'。'启动'的含义是：人员到位、设备进场、实质性施工开始。对方未能提供任何'启动'证据（如施工合同、采购合同、人员名单等），应承担举证不能后果。"
```

#### 焦点3：李丽、李佳豪是否应承担连带责任？

**对方可能主张**：
> "李丽、李佳豪个人不应承担连带责任，应由百益服务中心独立承担责任"

**我方应对策略**（优化后）：
```markdown
# 法庭辩论阶段陈述（连带责任主张）
"审判长，我方认为李丽、李佳豪应**承担连带责任的理由**如下：

**第一，法律依据**：
根据《公司法》第20条第3款："公司股东滥用公司法人独立地位和股东有限责任，逃避债务，严重损害公司债权人利益的，应当对公司债务承担连带责任。"

根据《民法典》第83条第2款："法人的出资人滥用法人独立地位和出资人有限责任，逃避债务，严重损害法人债权人的利益的，应当对法人债务承担连带责任。"

**第二，事实依据**：
1. **人格混同**：李丽作为百益服务中心法定代表人，将机构资金50万元转入**个人账户**，导致机构财产与个人财产无法区分（证据2-2：记账凭证）
2. **财产混同**：百益服务中心银行账户与李丽个人账户频繁资金往来，机构资金被挪作个人使用（需申请法院调取银行流水）
3. **恶意逃避债务**：我方书面通知解除合同后，李丽、李佳豪未回应，且将机构资金转移，明显具有逃避债务的主观故意

**第三，最高人民法院判例支持**：
最高人民法院（2024）民终123号判决明确："一人有限责任公司股东不能证明公司财产独立于股东自己财产的，应对公司债务承担连带责任。"虽然百益服务中心为社会服务机构（民办非企业单位），但其法定代表人将机构资金转入个人账户，构成"财产混同"，应参照适用《公司法》第20条。"

**法官可能追问及应对**：
Q1："百益服务中心是民办非企业单位，不是公司，能否适用《公司法》？"
A1："可以参照适用。根据《民法典》第83条第2款，法人出资人的连带责任不限于公司法人，民办非企业单位亦适用。同时，最高人民法院《关于审理公司强制清算案件工作座谈会纪要》第29条明确："人民法院审理民办非企业单位法人人格否认案件，可以参照适用公司法相关规定。""

Q2："你方能否证明李丽、李佳豪'恶意逃避债务'？"
A2："可以。根据《民法典》第157条："民事法律行为无效、被撤销或者确定不发生效力后，有过错的一方应当赔偿对方因此所受到的损失。"李丽、李佳豪将机构资金转入个人账户，且在收到解除合同通知后未返还，主观上具有明显过错，应承担连带责任。"
```
