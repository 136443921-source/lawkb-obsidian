# 操作指南：验证最高人民法院（2025）民再164号裁定

**重要性**：⚠️⚠️⚠️（高风险点4——最高法院判例未验证）

## 为什么必须验证最高法院判例？

1. **避免引用虚假判例**：
   - 如果判例不存在或文号错误，对方律师会当庭驳斥："对方引用的判例不存在"，我方将丧失可信度
   - 法官也可能当庭要求："请出示判例原件或官方出处"

2. **确保判例适用性**：
   - 即使判例真实存在，也可能与本案事实不符（例如：判例是"涉众型经济犯罪"，本案是"普通合同纠纷"）
   - 必须确认判例的"裁判要旨"是否支持我方主张

3. **准备替代品**：
   - 如果判例不存在或不适配，必须立即寻找替代判例或法条依据

## 验证方法（3种）

### 方法1：通过"中国裁判文书网"验证（最权威）

**网址**：https://wenshu.court.gov.cn/

**步骤**：
1. 进入"中国裁判文书网"官网
2. 在搜索框输入："(2025)民再164号"
3. 点击"搜索"
4. 查看搜索结果：
   - **如果找到**：点击进入裁定书全文，核对以下内容：
     - 裁判日期是否正确（2025年）
     - 裁判要旨是否包含"先刑后民""经济犯罪嫌疑""驳回起诉"等关键词
     - 裁判要旨是否支持"不应当仅因有关联的刑事案件尚未审结就驳回起诉"
   - **如果未找到**：可能文号记错，尝试搜索：
     - "(2025)民再___号"（模糊搜索）
     - "先刑后民""经济犯罪嫌疑""驳回起诉"（关键词搜索）

**优点**：最权威（最高法院官网）  
**缺点**：裁判文书网可能更新滞后（最新判例可能还未上传）

### 方法2：通过"北大法宝"或"威科先行"验证（最专业）

**网址**：
- 北大法宝：https://www.pkulaw.com/
- 威科先行：https://law.wkinfo.com.cn/

**步骤**：
1. 登录"北大法宝"或"威科先行"（需要账号，如果没有可以请律所图书馆帮忙）
2. 在搜索框输入："(2025)民再164号"
3. 点击"搜索"
4. 查看搜索结果：
   - **如果找到**：查看判例全文、裁判要旨、关联法条
   - **如果未找到**：查看"相似判例"（系统会自动推荐类似判例）

**优点**：最专业（法律数据库，收录完整）  
**缺点**：需要付费账号

### 方法3：通过"最高人民法院官网"验证（最直接）

**网址**：https://www.court.gov.cn/

**步骤**：
1. 进入"最高人民法院官网"
2. 点击"裁判文书"栏目
3. 在搜索框输入："(2025)民再164号"
4. 查看搜索结果

**优点**：最直接（最高法院官方发布）  
**缺点**：官网搜索功能较弱，可能找不到

## 可能的结果及应对方案

### 结果A：判例真实存在，且裁判要旨支持我方主张（✅ 最佳）

**应对方案**：
1. **打印裁定书全文**（加盖法院章或律所章）
2. **在庭审前提交给法庭**（作为参考判例）
3. **在庭审辩论阶段引用**：
   > "根据最高人民法院(2025)民再164号裁定，不应当仅因有关联的刑事案件尚未审结就驳回起诉。本案事实清楚，应当继续审理。"

### 结果B：判例真实存在，但裁判要旨不适用于本案（⚠️ 风险）

**可能原因**：
- 判例是"涉众型经济犯罪"，本案是"普通合同纠纷"
- 判例是"刑事案件直接影响民事案件处理结果"，本案是"刑事案件与民事案件有关联但非同一法律事实"

**应对方案**：
1. **不使用该判例**，寻找其他更适配的判例
2. **或者**，在庭审中限定该判例的适用范围：
   > "最高人民法院(2025)民再164号裁定虽然涉及'涉众型经济犯罪'，但其确立的'先刑后民'适用条件同样适用于本案。"

### 结果C：判例不存在或文号错误（❌ 严重错误）

**应对方案**：
1. **立即删除《庭审准备报告》中所有引用该判例的内容**
2. **寻找替代依据**：
   - 替代判例：搜索"先刑后民""经济犯罪嫌疑""驳回起诉"等关键词，寻找其他最高法院判例
   - 替代法条：《最高人民法院关于在审理经济纠纷案件中涉及经济犯罪嫌疑若干问题的规定》第11条、《九民会议纪要》第105条、第129条
3. **在庭审中不使用该判例**，改用其他依据

## 风险提示

1. **时间风险**：如果判例不存在，需要时间寻找替代依据
   - **应对方案**：提前准备"替代依据清单"（见附件）
2. **对方驳斥风险**：对方律师可能当庭指出"判例不适用"或"判例不存在"
   - **应对方案**：提前准备《判例适用性说明》（见附件）
3. **法官不接受风险**：法官可能认为"判例不是法条，没有约束力"
   - **应对方案**：强调"判例的参考价值"，而非"约束力"

## 附件1：《替代依据清单》

### 如果"(2025)民再164号裁定"不存在，可以使用以下依据：

1. **《最高人民法院关于在审理经济纠纷案件中涉及经济犯罪嫌疑若干问题的规定》第11条**：
   > "人民法院作为经济纠纷受理的案件，经审理认为不属经济纠纷案件而有经济犯罪嫌疑的，应当裁定驳回起诉，将有关材料移送公安机关或检察机关。"

2. **《九民会议纪要》第105条**：
   > "人民法院在审理民事案件时，如果民事案件与刑事案件有关联，但民事案件的处理不以刑事案件的审理结果为依据的，民事案件应当继续审理。"

3. **《九民会议纪要》第129条**：
   > "民事案件与刑事案件应当分别审理的情形包括：（1）民事案件与刑事案件不是同一法律事实的；（2）民事案件的处理不以刑事案件的审理结果为依据的。"

4. **其他最高法院判例**（需要重新搜索）：
   - 搜索关键词："先刑后民""经济犯罪嫌疑""驳回起诉""不当驳回起诉"

## 附件2：《判例适用性说明》框架

**如果对方律师驳斥："该判例不适用于本案"，我方回应**：

> "审判长，我方引用的最高人民法院(2025)民再164号裁定，虽然具体案情与本案不完全相同，但其确立的'先刑后民'适用条件具有普遍指导意义。
> 
> 该判例明确：'不应当仅因有关联的刑事案件尚未审结就驳回起诉。'本案中，我方起诉的是合同纠纷，与马婵娟涉嫌的犯罪并非同一法律事实，本案应当继续审理。
> 
> 即使该判例的具体案情与本案不同，但其确立的法律适用原则是一致的。我方请求法庭参考该判例的裁判要旨。"
