## 📝 具体修改建议（逐条列出）

### 1. 附件"承诺书"修改建议

#### 原条款：
```
本人 身份证号码： 于 年 月 日起在
百邦劳务有限公司工作。因本人个人原因，本人自愿不参加社会保险，本人要求
公司将公司应缴纳的社会保险费（包括个人应缴部分和公司应缴部分）以现金形
式每月与工资一并支付给我本人，即公司每月支付的工资包括了公司应缴纳的社
会保险费（包括个人应缴部分和公司应缴部分）。
现我本人郑重承诺：今后不得以
公司未为本人缴纳社会保险向公司主张任何权利，因未参加社会保险而产生的一
切法律后果由我本人自行承担。
```

#### 问题：
- 违反《社会保险法》第58条、第60条
- 参加社会保险是强制性规定，不得约定放弃
- 用人单位必须依法缴纳社会保险，不得以现金替代

#### 修改建议：
**删除**该条款（整份"承诺书"）

#### 修改后条款：
（删除）

#### 法律依据：
- 《中华人民共和国社会保险法》第58条："用人单位应当自用工之日起三十日内为其职工向社会保险经办机构申请办理社会保险登记。"
- 《中华人民共和国社会保险法》第60条："用人单位应当自行申报、按时足额缴纳社会保险费"

---

### 2. 第七条（安全责任条款）修改建议

#### 原条款：
```
第七条 乙方不履行或不按约定履行本合同约定的义务时，向甲方支付因其违约给甲方造
成的经济损失。乙方务必严格按照国家和行业安全生产操作规范作业，因违规生产等自身原因导
致的安全生产事故，乙方应对自身行为负责。
```

#### 问题：
- 违反《安全生产法》第53条
- 生产安全事故责任应依法承担，不得通过协议免除或减轻
- 要求乙方对安全事故"自行负责"，过度免除甲方责任，加重乙方责任

#### 修改建议：
**删除**"乙方务必严格按照国家和行业安全生产操作规范作业，因违规生产等自身原因导致的安全生产事故，乙方应对自身行为负责。"该部分，改为依法约定双方安全责任。

#### 修改后条款：
```
第七条 乙方不履行或不按约定履行本合同约定的义务时，向甲方支付因其违约给甲方造成的损失。
因甲方未提供安全生产条件导致的安全事故，由甲方承担责任；因乙方故意或重大过失导致的安全事故，由乙方承担相应责任。
```

#### 法律依据：
- 《中华人民共和国安全生产法》第53条："生产经营单位不得以任何形式与从业人员订立协议，免除或者减轻其对从业人员因生产安全事故伤亡依法应承担的责任。"

### 3. 第九条（五）（保险金条款）修改建议

#### 原条款：
```
（五）甲方为乙方所从事的劳务活动所投保的商业保险，如发生保险事故，保险公司赔付的
保险金，优先用于抵偿甲方应承担的雇主责任或工伤责任。
```

#### 问题：
- 违反《保险法》第39条
- 人身保险的受益人不得为被保险人及其近亲属以外的人
- 用人单位不得通过商业保险免除自身法定责任

#### 修改建议：
**删除**该条款

#### 修改后条款：
（删除）

#### 法律依据：
- 《中华人民共和国保险法》第39条："人身保险的受益人由被保险人或者投保人指定。投保人指定受益人时须经被保险人同意。投保人为与其有劳动关系的劳动者投保人身保险，不得指定被保险人及其近亲属以外的人为受益人。"

### 5. 第四条（劳务报酬条款）修改建议

#### 原条款：
```
6、乙方完成本合同约定的工作内容后，甲方应当以现金或转账形式向乙方支付劳务报酬，
劳务报酬标准由甲乙方协商确定，以每月工作量为标准进行计发，但不低于甲方所在地人民
政府规定的最低小时工资标准。甲方向乙方支付劳务报酬的周期为月/季度。
支付劳务报酬的其他约定: /
```

#### 问题：
- 劳务报酬标准不明确，易引发争议
- 付款周期不明确（"月/季度"）
- "支付劳务报酬的其他约定"空白

#### 修改建议：
1. **明确**劳务报酬标准（建议：按工程量结算，单价XXX元/工日或XXX元/项目）
2. **明确**付款周期（建议："按月进度付款，每月X日前支付上月报酬"）
3. **补齐**"支付劳务报酬的其他约定"（如：逾期付款违约金、付款条件等）

#### 修改后条款：
```
6、乙方完成本合同约定的工作内容后，甲方应当以现金或转账形式向乙方支付劳务报酬，
劳务报酬标准：按工程量结算，单价为XXX元/工日（或XXX元/项目）。
甲方应于每月X日前，向乙方支付上月劳务报酬。
甲方逾期付款的，应按每日万分之X的标准向乙方支付违约金。
支付劳务报酬的其他约定：无（或填写具体约定）。
```

#### 法律依据：
- 《中华人民共和国民法典》第510条："合同生效后，当事人就质量、价款或者报酬、履行地点等内容没有约定或者约定不明确的，可以协议补充；不能达成补充协议的，按照合同相关条款或者交易习惯确定。"

### 6. 第八条（合同解除条款）修改建议

#### 原条款：
```
第八条 甲乙双方可以随时终止劳务合同。乙方离职应提交辞职申请，乙方无故不提交辞职
申请的，视为默认终止劳务合同，施工队长或项目经理有权做终止劳务合同证明。
```

#### 问题：
- "可以随时终止劳务合同"，未约定提前通知期限
- 对乙方不利，乙方可能突然失业，无准备时间

#### 修改建议：
**补充**提前通知期限

#### 修改后条款：
```
第八条 甲乙双方可以随时终止劳务合同，但应提前X天书面通知对方。
乙方离职应提交辞职申请，甲方解除劳动合同的，应提前X天书面通知乙方。
```

#### 原条款：

第十条 甲乙双方因履行本合同发生争议，应协商解决；协商不成的，任何一方均有权向合同签订地有管辖权的人民法院起诉。

## 💡 谈判策略建议

### 第一优先级（必须争取）：

1. **删除附件"承诺书"中关于"自愿不参加社会保险"的条款**
   - **策略：** 坚决要求修改，明确告知甲方：根据《社会保险法》第58条、第60条，这些条款违法，无效。如甲方坚持不修改，建议拒绝签署。
   - **话术：** "根据《社会保险法》第58条，用人单位必须为职工缴纳社会保险，不得约定放弃。这个条款违法，必须删除。"

2. **删除第七条中"乙方对安全事故自行负责"的条款**
   - **策略：** 坚决要求修改，明确告知甲方：根据《安全生产法》第53条，这些条款违法，无效。如甲方坚持不修改，建议拒绝签署。
