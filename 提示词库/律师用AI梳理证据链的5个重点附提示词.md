# 律师用 AI「梳理证据链」的 5 个重点（附提示词）

梅嘉欣

iCourt 法律 AI 研究员

本文是《法律人 AI 智能体搭建手册》系列文章的第三篇。

前两节内容已经详细讲述了搭建智能体、构建 AI 知识库的方法，本节内容将聚焦在如何能让智能体梳理案件时间线和证据链。

在法律实务中，案件时间线是还原事实真相的核心脉络，证据链则是支撑诉讼主张的关键骨架，二者的梳理质量直接影响案件研判与诉讼策略制定。

借助智能体高效完成这两项工作，既能降低人工梳理的时间成本，又能保证梳理结果的逻辑性与全面性，是法律人提升工作效率的重要路径。


## 让智能体梳理案件时间线和证据链

## 
### 一、准备工作：资料收集与数字化

### 

智能体的高效运作依赖于高质量的数据输入，资料收集与数字化是让智能体发挥作用的前提。

智能体本质上是基于输入数据进行分析、归纳与输出的工具，其输出结果的精准度与输入资料的质量呈正相关。若原始资料存在残缺、格式混乱、信息失真等问题，智能体的输出结果必然会偏离预期，甚至可能产生错误的时间线与证据链，对案件处理造成误导。


因此，法律人在启动智能体工作前，需完成以下三项核心任务，为智能体的高效运作筑牢基础。


1、收集范围与清单

明确需要让智能体进行梳理的全部文字案件材料，涵盖案件卷宗、当事人陈述、证人证言、书证、物证照片及相关鉴定报告、庭审笔录等与案件事实相关的所有书面资料，确保无关键材料遗漏。




2、数字化与可读性

提供的材料尽量扫描清晰、可识别，且尽量将其转为可复制文本的 PDF 或 DOC 格式。




对于纸质材料，需使用高清扫描仪进行扫描，分辨率不低于 300dpi，确保扫描后的文件文字清晰、无模糊、无畸变；对于照片、截图等图片类材料，需使用 OCR（光学字符识别）工具将图片中的文字提取出来，转化为可编辑的文本格式。




智能体对可复制文本的识别效率与准确性远高于图片格式，若直接输入图片材料，智能体可能无法准确提取其中的关键信息，进而影响时间线与证据链的梳理质量。




同时，在数字化转换完成后，需对文本内容进行初步校对，修正因扫描或 OCR 识别产生的错别字、语句不通顺等问题，确保输入智能体的材料具备良好的可读性。




3、敏感信息处理




对材料中的敏感信息进行脱敏、匿名化处理，必要时分批输入，避免过度暴露隐私或商业机密。




### 二、具体操作：让智能体满足你的需求

### 


#### 1、**明确角色设定，锚定智能体的工作定位**

角色设定是驯化智能体的核心，需根据案件梳理需求，为智能体设定具体的角色，并明确其工作目标、专业要求与输出标准。

智能体的角色定位直接决定其思考维度与输出风格，若角色设定模糊，智能体的输出结果可能会缺乏专业性与针对性，无法满足法律实务的需求。

因此，法律从业者需结合案件的类型、性质与梳理目标，为智能体设定精准的角色，并撰写详细的角色指令。

例如，在梳理民事案件的时间线与证据链时，可将智能体的角色设定为「资深法律助理」，并给出如下角色指令：

你现在是一名资深法律助理，具备扎实的民事诉讼法、证据法知识与丰富的案件梳理经验。你的任务是协助处理案件的相关材料，梳理案件完整时间线，构建逻辑严密的证据链。输出内容需符合法律实务规范，语言精准简练，逻辑清晰，能够直接为案件分析与诉讼策略制定提供支持。

角色设定需具备针对性，避免模糊表述。例如，若案件涉及刑事领域，可将智能体角色设定为「刑事案助理」，并强调对刑事诉讼证据规则、案件侦查流程的理解；若案件涉及商事仲裁，可设定为「商事仲裁助理」，并明确对仲裁规则、商事交易习惯的掌握要求。

#### 2、**制定工作要求，规范智能体的操作逻辑**

工作要求是智能体开展工作的「行动指南」，需明确智能体在梳理时间线与证据链过程中的具体操作步骤、判断标准与输出格式。

若缺乏清晰的工作要求，智能体的梳理工作可能会陷入无序状态，导致时间线混乱、证据链逻辑断层等问题。因此，法律人可根据案件特点，制定具体、可操作的工作规程，确保智能体的操作逻辑符合法律实务的梳理标准。

时间线梳理：

（1）以「时间节点」为核心，从案件资料中提取所有与案件事实相关的时间信息，包括行为发生时间、人物、事件进展时间等；

（2）按照「从前往后」的时间顺序排列时间节点，同一时间节点存在多个事件的，按照「事件重要程度」排序；

（3）每个时间节点真实来源于案件事实与证据材料，不得编造；

（4）对于时间表述模糊的内容（如「2024年中旬」），需结合其他材料进行合理推断，并标注「推断时间」及依据；

（5）时间线需完整覆盖案件事实与证据材料内容，无重要时间节点遗漏。

证据链构建：

（1）以「案件核心事实」为导向，将证据材料按照「基础证据-补强证据-反驳证据」的逻辑分类；

（2）每个证据需明确「证据名称-证据类型-证明目的」；

（3）证据链的构建需遵循「客观性、关联性、合法性」原则，确保证据之间相互印证，形成闭环，无逻辑断层；

（4）对于存在矛盾的证据，需单独列出，并分析矛盾点及可能的原因；

（5）证据链中的证据需要完全形成于证据材料，不得自行编造。

工作要求的制定需具体、可操作，避免使用抽象表述。同时，需根据案件的复杂程度调整要求细节。
#### 3、设定输出规范，统一智能体的成果形式

输出规范是确保智能体成果符合法律实务需求的关键，需明确时间线与证据链的输出格式、语言风格与内容要求，设定统一的输出规范，能够让智能体的输出结果直接满足案件分析、诉讼文书撰写等实务需求，避免后续二次整理的麻烦。

输出格式规范：

（1）案件时间线需要清晰标注每个时间节点的核心信息；

（2）证据链采用「层级结构」形式，以核心事实为一级标题，对应证据为二级内容，每个证据的详细信息为三级内容；

（3）输出内容仅需包含「时间线梳理结果」/「证据链构建结果」即可，无需其他说明或解释。

语言风格规范：

（1）采用法律专业术语，表述精准简练，避免口语化、模糊化表述；

（2）逻辑清晰，层次分明，使用「一、二、三」「（一）（二）（三）」等规范序号；

（3）基于输入材料进行分析，不添加主观臆断或未证实的内容。

内容要求规范：

（1）时间线需无遗漏、无错误，时间节点与案件事实、证据材料准确对应；

（2）证据链需逻辑严密，证据之间相互印证，明确每个证据的证明目的；

（3）针对梳理过程中发现的问题（如证据缺失、时间矛盾等），需提出具体的解决方案与建议。
#### 4、提示词示例

（1）时间线梳理
# 角色

你是一名专业时间线梳理助手，擅长梳理材料中的事件时间线

# 任务

基于用户上传的材料，完成事件时间线梳理工作

### 要求

1. 梳理材料中的关键事件的事件时间线，按照时间顺序排列；

2. 按时间（精确到日，无精确日期标注为「待确认」）进行排序，修正时序矛盾并标注；每个事件需绑定对应证据（格式：证据编号+证据名称）；

3. 以列表形式输出；

4. 输出的内容要全部来源于材料，不要编造任何信息。

（2）证据链构建
# 角色

你是一名专业律师，擅长根据案情基本信息构建我方证据链

# 任务

基于案情基本信息，对用户上传的材料进行证据链构建

# 思路

1. 结合案情信息，分析我方当事人诉讼请求。

2. 结合案情信息及我方当事人诉讼请求，将材料按照「基础证据-补强证据-反驳证据」的逻辑分类。

3. 每个证据按照「证据名称-证据类型-证明目的」输出内容，证明目的需要支持我方当事人诉讼请求。

# 要求

1. 证据链的构建需遵循「客观性、关联性、合法性」原则，确保证据之间相互印证，形成闭环，无逻辑断层。

2. 对于存在矛盾的证据，需单独列出，并分析矛盾点及可能的原因。

3. 证据链中的证据需要完全形成于证据材料，不得自行编造。

4. 当我方诉讼请求对应的证据缺失时，需要指出并给出补充方向。

# 输出

1. 证据链采用「层级结构」形式，以核心事实为一级标题，对应证据为二级内容，每个证据的详细信息为三级内容。

2. 基于输入材料进行分析，不添加主观臆断或未证实的内容。

以上是两个提示词示例，在使用智能体梳理时间线或构建证据链时可以根据具体的要求对提示词进行修改，以满足自身的需求。
### 三、进阶技巧：输出可视化

智能体输出的列表、层级文本等内容虽逻辑清晰，但对于复杂案件（如多主体、多事件的商事纠纷、群体性侵权纠纷等），纯文本形式的时间线与证据链往往难以直观展现案件事实的复杂脉络，也不便于向当事人、办案团队清晰展示案件核心要点。

因此，将智能体梳理完成的时间线和证据链转化为可视化成果，是提升智能体输出价值的重要进阶技巧。可视化成果能够将抽象的文字信息转化为直观的图表，帮助法律人快速把握案件核心脉络，同时也能提升与当事人、办案团队的沟通效率。

对于输出可视化的部分，可以将智能体输出的结果，导入专业工具网站进行二次加工，操作简单且灵活性强。以时间线梳理为例：

1、在提示词中要求输出格式
```
请使用符合语法的Mermaid输出时间线，注意冒号/括号/顿号的使用，涉及时分秒的使用文字描述：「14时20分」）示例：```mermaidtimeline    title: 案涉关键时间轴    2024-05-10 14时20分: 合同签订（信息来源：材料A）    2024-06-15 08时10分: 首期履行（来源：材料B）    2024-08-01: 发生争议```
```

2、将输出结果复制后导入至专业网站进行格式转换

## 常见错误与纠偏方法

## 


在使用智能体梳理案件时间线与证据链的过程中，由于操作不当或对智能体的认知不足，法律人可能会陷入一些常见误区，导致智能体的输出结果质量低下，甚至对案件处理产生负面影响。




因此，识别这些常见错误，并掌握相应的纠偏方法，是确保智能体有效发挥作用的关键。




### 一、一次性倾倒所有案件材料，数据过载

### 


部分法律人在使用智能体时，未对案件材料进行拆分与筛选，将所有案件材料一次性全部输入智能体，导致智能体面临数据过载的问题，可能出现：信息遗漏、信息错误等情况。




解决方法如下。

#### 


1、材料拆分后分批输入

根据案件事实的发展阶段，将案件材料拆分为若干个模块。每个模块的材料体量不宜过大，以智能体能够高效处理为准。将拆分后的材料模块分批次输入智能体。

在输入每个模块的材料后，先让智能体梳理该模块的时间线与证据链，待输出结果符合预期后，再输入下一个模块的材料。同时，在输入下一批次材料时，可要求智能体将新梳理的内容与之前的内容进行整合，确保最终输出的时间线与证据链具有连贯性。

2、冗余信息筛选

在材料拆分的同时，对每个模块的材料进行筛选，剔除与案件事实无关的冗余信息。例如，当事人的无关闲聊记录、与案件争议焦点无关的背景资料等，均可予以剔除，减少智能体的处理负担，提升关键信息的识别效率。
### 二、过度信任智能体输出结果，对于案件细节不做核对

部分法律人将智能体/AI 工具视为「万能工具」，过度信任智能体/AI 工具输出的结果，直接将其用于案件研判、诉讼文书撰写等实务工作，未对输出结果的细节进行人工核对。

在使用智能体/AI工具时，法律人需建立「智能体梳理+人工核对」的双重保障机制。人工核对需聚焦于输出结果的关键细节，主要包括三个方面：




时间节点的准确性，将智能体输出的时间线与案件材料进行比对，核实结果是否与材料一致；




证据链的逻辑性，检查证据的分类是否合理、证明目的是否准确、证据之间是否形成完整的逻辑闭环，是否存在矛盾证据未被识别的情况；




关键信息的完整性，核对是否存在关键时间节点、核心证据被遗漏的情况，确保输出结果全面覆盖案件事实。




在人工核对的过程中，法律人需结合自身的法律专业知识与实务经验，对智能体输出的结果进行专业判断。
