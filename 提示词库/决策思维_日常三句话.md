# 日常三句话

> 不用记命令，复制粘贴就行。高频只用第一句。

---

## ① 抓决策（每周用几次）

做完一个让你犹豫过的决定，直接发：

```
我刚决定：<一句话说清>。按决策卡记一条。
```

WorkBuddy 会建卡 → 逐条追问三行 → 你答完收工。**3 分钟。**

变体：

```
我在纠结 <A 还是 B>，帮我记一张决策卡，顺便用我 HOW-I-THINK 里的框架推一下。
```

```
<粘贴一段聊天/邮件背景>。这里面有个决定我要拍，记卡，问我那三行。
```

---

## ② 季度蒸馏（每 3 个月一次）

```
读取 知识飞轮系统/04-LOG/决策日志/ 里所有已复盘的决策卡，加上 知识飞轮系统/06-沉淀/HOW-I-THINK.md 现有内容，
做一次思维蒸馏：

1. 我反复出现的决策模式（3-5 条，每条附证据链接）
2. 我的坑里，哪些是同一个根因
3. 「说一套做一套」检查：我声明的价值观 vs 我实际的决策，
   找出 3 个不一致，说明这个 gap 暴露了我什么真实偏好
4. 我该把哪些领域加进盲区

先给我看建议，我确认后再写入 HOW-I-THINK.md。
```

顺手做的：

```
扫一遍 知识飞轮系统/04-LOG/决策日志/，列出该复盘但还没回填的卡，按逾期天数排序。
```

```
我最近三个月是不是在同一个问题上反复犯错？查一下。
```

---

## ③ 调用分身（蒸馏完成后）

```
@skill:how-i-think

<你的问题或情境>

用我的框架拆解，用我的价值观取舍，用我的表达风格回答。
我的笔记里没写过的情况，直接说不知道，别编。
```

装进别的地方用：

```
把 how-i-think 这个 Skill 打包成 zip，我要放到另一台机器上。
```

---

## 三个坑，提前避开

**坑 1：什么都想记。**
一天记 5 张卡，三天后你会放弃这套系统。**只记会肉疼的。**
判断标准：这个决定错了，你会不会后悔半年？会，才记。

**坑 2：隔夜补记。**
第二天写的"理由"基本是事后合理化。宁可当天花 3 分钟，
也不要一周后花 30 分钟写一篇漂亮的、但假的推理。

**坑 3：把推理写成公文。**
"基于对多维度因素的综合考量" —— 这句话信息量为零。
写"因为 deadline 只剩两天，我没精力评估 B，这是我偷懒了"
才是真数据，半年后回看才知道自己当时是怎么想的。

---

## 检验这套系统是否活着

三个月后问自己一个问题：

> 我能不能把 HOW-I-THINK.md 发给一个不认识我的人，
> 让他看完后，在新问题上做出和我大致相同的选择？

能 → 你的思维已经被蒸馏出来了，装进机器人只是接口问题。
不能 → 说明卡的「为什么排除其他」那栏还写得太浅，回去补。
