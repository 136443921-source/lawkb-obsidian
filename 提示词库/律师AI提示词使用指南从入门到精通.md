# 律师AI提示词使用指南：从入门到精通

  用好 AI，从写对提示词开始2026年，DeepSeek 等大模型早已走进律所，“遇事不决找 AI” 成了不少律师的日常。

  AI 输出质量，完全取决于你输入质量。律师本就靠严谨表达吃饭，写好 Prompt，本就是新时代律师的核心竞争力。

  今天这篇，一次性把**律师 AI 提示词方法论 + 可直接复制的实战指令**全给你，让 AI 秒变你的专属资深法务助理！🚀

## 一、万能公式：好 Prompt 只靠 3 要素🎯

不管用豆包、DeepSeek 还是 Kimi，记住一句话：

**定身份 + 讲背景 + 提要求 = 高质量回答**

- ✅ **定身份**越具体越精准。“10 年知识产权律师”＞“资深律师”＞“律师”，角色越清晰，输出越专业。
- 📋 **讲背景**业务类型、合同场景、管辖地区、客户立场……不给背景，AI 只能瞎猜，**幻觉全是这么来的**。
- 🔧 **提要求**明确格式：表格 / 逐条 / 清单 / 文书模板明确风格：法言法语 / 通俗解读 / 庭审话术明确重点：只看风险 / 只找漏洞 / 只列法条

  进阶版直接用这套结构：**角色设定 + 任务拆解 + 限制条件 + 输出格式**通杀所有大模型。

## 二、4 套顶级框架，拿来就用📚

不用自己瞎琢磨，这 4 套框架覆盖 90% 法律场景。

### 1️⃣ LEGAL 万能框架

适合法条解释、合同审查、案件摘要、法律问答、条款提取。

- L：Legal Area 法律领域
- E：Entity 主体身份
- G：Goal 任务目标
- A：Action 具体动作
- L：Limitation 限制条件

### 2️⃣ ICA 合同审查三步法

专治复杂合同，大幅减少 AI 幻觉。

- I = Identify 定位条款
- C = Check 风险核查
- A = Act 修改 / 补充 / 标注风险

### 3️⃣ 模块化提示

复杂任务别一口气喂给 AI。想写合规备忘录→先拆：① 梳理法规 → ② 检索判例 → ③ 出具建议逐段生成、逐段审核，质量稳得一批。

### 4️⃣ 分块信息输入

案情复杂、证据多时，按块投喂：

- 核心信息
- 主体关系
- 时间线
- 辅助材料AI 理解更快，逻辑更不乱。

## 四、红线必看！用 AI 千万别踩坑🚨

美国律协 ABA 512 号意见明确律师 AI 伦理义务，每一条都关系执业风险：

- 🔴 **Rule 1.1 专业能力**AI 只是起点，**最终必须人工核验**，不能甩锅给模型。
- 🔒 **Rule 1.6 保密义务**严禁直接上传客户真实姓名、案号、隐私信息！务必脱敏，免费版模型更要警惕数据被用于训练。
- ⚠️ **Rule 3.3 对法庭诚实**AI 会编判例、造法条！已有律师因提交 AI 虚构案例被处罚，切记**逐条核对**。
- 🧾 **Rule 5.3 监督义务**AI 输出必须由律师复核把关，承担最终责任。

## 五、高手进阶：让 AI 真正为你赋能💎

1. **模块化拆解**越复杂的任务，越要拆碎了喂。
2. **迭代优化 Prompt**先粗后细，逐步加限制，越用越精准。
3. **强制核验机制**法条、案号、判例，一律人工复核。
4. **严格脱敏**客户信息绝不裸奔进公共 AI。
5. **沉淀个人模板**把常用指令做成固定模板，形成自己的法律 AI 工作流。
