## 🎯 一、提示词设计核心方法论

### 1. 万能公式（必背）

```
定身份 + 讲背景 + 提要求 = 高质量回答
```

**示例**：

```
你是拥有10年经验的知识产权律师（定身份）。
我们公司正在开展跨境技术合作（讲背景）。
请起草一份技术许可协议，包含专利实施地域限制、改进技术归属、不可抗力定义（提要求）。
```

### 2. LEGAL框架（适合法条解释、合同审查、案件摘要）

- **L** = Legal Area（法律领域）
- **E** = Entity（主体身份）
- **G** = Goal（任务目标）
- **A** = Action（具体动作）
- **L** = Limitation（限制条件）

### 3. ICA三步法（专治复杂合同）

- **I** = Identify（定位条款）
- **C** = Check（风险核查）
- **A** = Act（修改/补充/标注风险）

### 4. 反幻觉指令（必加）

```
**反幻觉指令**：所有引用的条文必须注明出处及生效/修正日期。如不确定，标注"⚠️需人工核对"。
```

### 5. 隐私保护提醒（必加）

```
**隐私保护提醒**：输出中禁止出现真实身份证号、手机号、公司全称，一律用【】代替。
```

### 场景2：法规检索

**触发关键词**：法规检索、法律检索、查找法条、相关法律规定

**提示词模板**：

```
# 任务
请根据【法域，如：中国大陆现行有效法律】，检索关于【具体问题，如：建设工程价款优先受偿权】的规定。

# 要求
1. 列出核心法条（名称+文号+条款全文+最后一次修正日期）
2. 解释该法条的构成要件/适用条件
3. 补充至少一条相关司法解释或指导性案例的核心要点（注明案号或文号）
4. 如有多个层级规定（法律、行政法规、部门规章），用表格对比其异同

**反幻觉指令**：所有引用的条文必须注明出处及生效/修正日期。如不确定，标注"⚠️需人工核对"。
```

### 场景3：起诉状/答辩状起草

```
# 任务
请根据以下信息起草一份【文书名称】：

- 当事人信息：【原告/被告/第三人，用"甲方/乙方"代替真实姓名，我会最后替换】
- 诉讼请求：【具体列明金额、行为等】
- 事实与理由：【按时间线提供关键节点，脱敏处理】
- 法律依据：【至少2条具体法条及条文内容】

# 格式要求
符合中华人民共和国法院标准格式，所有待填数据（身份证号、住址、日期、金额）用【】标出。

**隐私保护提醒**：输出中禁止出现真实身份证号、手机号、公司全称，一律用【】代替。
```

### 场景4：案件分析策略

**触发关键词**：案件分析、案例分析、诉讼策略、案件策略

**提示词模板**：

```
# 任务
我正在代理一起【案由】案件，关键事实如下（有利点：列出；不利点：列出）。
请按以下逻辑分析：

1. 法律适用：本案应适用的主要法律及司法解释（注明条文及日期）
2. 争议焦点预判：法院最可能归纳的3个争议焦点
3. 己方优势与劣势（各3点，附法律依据）
4. 对方可能主张的核心抗辩及我的反驳思路

**反幻觉指令**：所有法律依据须注明准确条文号及生效日。无法确认的标注"需核对"。

# 预设追问链（可接着发送）
- 追问1："请针对我方的第【X】个劣势，提出3个证据补强或法律论证方案。"
- 追问2："如果我方无法补充该证据，法官最可能怎么判？请模拟三种心证。"
- 追问3："请用最通俗的话向法官解释本案的核心法律关系，不超过200字。"
```

### 场景5：证据审查与质证意见

**触发关键词**：证据审查、质证意见、质证、证据清单

**提示词模板**：

```
# 任务
请对以下证据清单进行审查，并生成**质证意见**（针对对方证据）或**证据补强建议**（针对己方证据）。

证据清单（脱敏后）：【编号、名称、证明目的、形式】

# 输出要求（表格形式）
| 证据编号 | 真实性质疑点 | 合法性质疑点 | 关联性质疑点 | 法律依据 | 质证建议/补强方案 |

# 特别指令
1. 对"真实性"质疑，重点关注是否为原件、有无篡改可能、电子证据的完整性校验
2. 对"合法性"质疑，关注取证手段是否违法、是否侵犯商业秘密或个人隐私
3. 对"关联性"质疑，关注是否与争议焦点直接相关、是否为间接证据需其他证据佐证
4. 每个质疑点必须附上《民事诉讼法》或《民事诉讼证据规定》的具体条文

**反幻觉指令**：引用证据规则时必须注明条文号及司法解释名称、生效日期。
```

### 场景6：合同结构扫描（底线六要素核查）

**触发关键词**：合同结构扫描、合同底线、核心条款核查

**提示词模板**：

```
# 角色设定
你是一位严谨的【行业，如：互联网/TMT】行业法务专家，拥有10年行业经验。

# 任务
请阅读附件中的《【合同名称】》。

# 背景知识（我的标准）
我作为甲方，在此类交易中必须包含以下6大核心机制，这是我的底线：
1. 明确的交付时间表与里程碑
2. 验收标准及不合格的整改流程
3. 源代码及知识产权归属甲方
4. 乙方人员的保密及竞业限制
5. 数据安全与隐私保护条款（特别是用户数据）
6. 针对延期的违约金计算公式

# 输出要求
请扫描合同，逐一核对上述6点是否存在。
如果存在，请引用原文所在的条款号，并概括其核心含义；
如果缺失，请用红色粗体警示：「【缺失风险】」，并简要说明缺失该条款可能对甲方造成的具体危害。
```

## ⚠️ 三、ABA 512号意见红线（必看）

### 1. Rule 1.1 专业能力

- AI只是起点，**最终必须人工核验**，不能甩锅给模型

### 2. Rule 1.6 保密义务

- 严禁直接上传客户真实姓名、案号、隐私信息
- 务必脱敏，免费版模型更要警惕数据被用于训练

### 3. Rule 3.3 对法庭诚实

- AI会编判例、造法条！
- 已有律师因提交AI虚构案例被处罚，切记**逐条核对**

### 4. Rule 5.3 监督义务

- AI输出必须由律师复核把关，承担最终责任

## 🚀 四、高级技巧

### 1. 模块化拆解

越复杂的任务，越要拆碎了喂。 先粗后细，逐步加限制，越用越精准。

### 2. 迭代优化Prompt

```
第1步："我想写一篇AI工具测评文章，目标读者是职场新人。先帮我列5个候选标题，每个附一句话解释为什么好。"
第2步："标题我选第3个。帮我列大纲，5个章节，每个写2-3句话说明内容。"
第3步："大纲没问题。现在按大纲写正文，1500字左右，风格轻松口语化。"
```

### 3. 强制核验机制

法条、案号、判例，一律人工复核。

### 4. 严格脱敏

客户信息绝不裸奔进公共AI。

### 5. 沉淀个人模板

把常用指令做成固定模板，形成自己的法律AI工作流。

## 📝 五、通用前置安全咒语（每次使用可粘贴在提示词最前端）

```
请严格遵守以下规则输出内容：

1. 所有引用法条均标注「请核实现行有效版本」，不虚构任何法条与司法案例
2. 所有输出内容均为法律文书辅助草拟/分析框架，不等同于正式法律意见
3. 所有不确定内容统一标注「⚠️ 待核实：______」，不得脑补案件事实
4. 专业分析采用法言法语，向客户解释内容切换为通俗大白话
5. 输出中禁止出现真实身份证号、手机号、公司全称，一律用【】代替
```

## 🎯 六、使用技巧

1. **无需一次性使用全部提示词**，仅需匹配当日工作场景
2. **复制对应提示词 → 填全【】内占位信息 → 粘贴至AI对话框**
3. **拿到第一版输出后，可通过单句指令迭代优化**
    - 示例："第3点过于笼统，将验收标准细化为三级可勾选判定规则"
4. **效果远优于一次性求全输出**
